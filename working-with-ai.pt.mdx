O AI Core foi feito para que alguém que não sabe programar possa pedir a uma IA para alterar um script ou escrever um novo, e receber um resultado que se encaixa.

Abra a pasta de dados do servidor no Claude Code (ou em outro agente de programação: ele lê o `AGENTS.md`) e peça com suas próprias palavras. A IA encontra:

| Arquivo | O que contém |
| --- | --- |
| `CLAUDE.md` | Objetivos, estrutura, decisões, o processo de build e de verificação. |
| `.claude/rules/` | Regras por tema, carregadas quando arquivos correspondentes são editados. |
| `.claude/skills/aicore-fivem`, `aicore-ui`, `aicore-mysql` | Conhecimento de motor FiveM, NUI e SQL. |
| `resources/[ai]/<script>/CLAUDE.md` | O que cada script faz e por quê. |
| `docs/compat/` | Superfícies dos frameworks e notas sobre scripts de terceiros. |

<Callout type="warn">
Ainda é recomendado testar o código gerado antes de colocá-lo em um servidor ao vivo.
</Callout>

## Preciso de IA?

Não. O desenvolvimento com IA é opcional. O AI Core funciona como um framework de FiveM comum e não precisa de nenhum serviço de IA para rodar.
