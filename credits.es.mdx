AI Core se apoya en el trabajo de la comunidad de código abierto de FiveM. Su puente de frameworks responde a las API de ESX, QBCore, Qbox y vRP, su lib cubre lo que ofrece ox_lib y muchos scripts `ai-*` se escribieron leyendo los scripts de código abierto de abajo: sus funciones, lugares por defecto (mostradores, NPC, puntos, cámaras), valores de configuración y, donde la licencia lo permite, su código. Gracias a todos los que los crearon y compartieron.

AI Core se publica bajo la GNU GPL v3 (`LICENSE` en cada repositorio), lo que lo mantiene compatible con los proyectos GPL y LGPL de los que aprendió. Cada proyecto conserva sus propios derechos de autor; los nombres de abajo son marcas de sus dueños y se usan solo para describir la compatibilidad.

## Frameworks

| Proyecto | Autores | Licencia | Qué toma AI Core de él |
| --- | --- | --- | --- |
| [ESX Legacy](https://github.com/esx-framework/esx_core) | ESX Framework | GPL-3.0 | API del puente `es_extended` (xPlayer, eventos, callbacks), modelo de trabajos y cuentas |
| [QBCore](https://github.com/qbcore-framework/qb-core) | QBCore Framework | GPL-3.0 | API del puente `qb-core` (objeto Player, metadatos, eventos, comandos), objetos compartidos, trabajos, bandas, lugares por defecto |
| [Qbox](https://github.com/Qbox-project/qbx_core) | Qbox Project | GPL-3.0 | API del puente `qbx_core`, ideas de varios trabajos y grupos, muchos scripts qbx_* listados abajo |
| [ox_core](https://github.com/overextended/ox_core) | Overextended | LGPL-3.0 | Modelo de datos e ideas de diseño con autoridad del servidor |
| [ND Core](https://github.com/ND-Framework/ND_Core) | ND Framework | GPL-3.0 | Comparación de frameworks |
| [vRP](https://github.com/ImagicTheCat/vRP) | ImagicTheCat | MIT | API del puente `vrp` (vRP 1, 2 y 3) |
