## Требования

| Зависимость | Версия | Зачем |
| --- | --- | --- |
| FXServer (artifact) с txAdmin | рекомендуется 38039 или новее | Новые сборки сами видят смерть игроков. |
| MariaDB (или MySQL) | актуальная | База данных. AI Core сам создаёт свои таблицы. |
| [Bun](https://bun.sh) | актуальная | Только для изменения или сборки скриптов; каждый скрипт уже собран. |

## Установка через txAdmin (рекомендуется)

<Steps>
<Step>

### Запустите txAdmin

Скачайте свежий artifact FXServer и запустите: txAdmin откроется в браузере. Следуйте [официальному руководству](https://docs.fivem.net/docs/server-manual/setting-up-a-server-txadmin/) до шага развёртывания.

</Step>
<Step>

### Используйте рецепт AI Core

Выберите **Popular Recipes > Remote URL Template** и вставьте:

```text
https://raw.githubusercontent.com/aifivem/aicore-server/main/recipe/ai-core.yaml
```

</Step>
<Step>

### Заполните данные

Имя сервера, лицензионный ключ с [portal.cfx.re](https://portal.cfx.re/) и база данных. Рецепт запишет `server.cfg` и `env.cfg`, подключит базу и скачает все скрипты `ai-*`. Импортировать SQL не нужно.

</Step>
<Step>

### Станьте администратором

Зайдите на сервер. Приветственная карточка покажет строку для `permission.cfg`. После перезапуска **F10** откроет [админ-панель](/ru/docs/admin-panel) с мастером настройки.

</Step>
</Steps>

<Callout>
Название, описание, теги, язык, баннеры и ссылка на Discord в списке серверов задаются на [portal.cfx.re/servers](https://portal.cfx.re/servers), а не в `server.cfg`.
</Callout>
