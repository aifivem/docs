## Требования

| Зависимость | Версия | Зачем |
| --- | --- | --- |
| FXServer (artifact) с txAdmin | 38039 или новее | Это нужно ai-core: сервер сам видит смерть игроков. |
| MariaDB (или MySQL) | актуальная | База данных. AI Core сам создаёт свои таблицы. |
| [Bun](https://bun.sh) | актуальная | Только для изменения или сборки скриптов. Каждый скрипт поставляется уже собранным, поэтому для работы сервера инструменты сборки не нужны. |

## Установка через txAdmin (рекомендуется)

<Steps>
<Step>

### Запустите txAdmin

Скачайте свежий artifact FXServer и запустите его: txAdmin откроется в браузере. Следуйте [официальному руководству](https://docs.fivem.net/docs/server-manual/setting-up-a-server-txadmin/) до шага развёртывания.

</Step>
<Step>

### Используйте рецепт AI Core

Выберите **Popular Recipes > Remote URL Template** и вставьте:

```text
https://raw.githubusercontent.com/aifivem/aicore-server/main/recipe/ai-core.yaml
```

</Step>
<Step>

### Заполните данные

Введите имя сервера, лицензионный ключ с [portal.cfx.re](https://portal.cfx.re/) и данные базы. Рецепт запишет `server.cfg` и `env.cfg`, подключит базу данных и скачает все скрипты `ai-*`. SQL-файл импортировать не нужно: AI Core и скрипты сами создают и обновляют свои таблицы при первом запуске.

</Step>
<Step>

### Станьте администратором

Зайдите на сервер. Приветственная карточка покажет строку, которая делает вас администратором: добавьте её в `permission.cfg` и перезапустите сервер. Затем нажмите **F10**, чтобы открыть [админ-панель](/ru/docs/admin-panel); её мастер настройки проведёт вас через первые настройки.

</Step>
</Steps>

<Callout>
Название сервера в списке, описание, теги, язык, баннеры и ссылка на Discord задаются на [portal.cfx.re/servers](https://portal.cfx.re/servers), а не в `server.cfg`.
</Callout>

## Установка вручную

<Steps>
<Step>

### Получите папку сервера

Скачайте папку сервера (cfg-файлы, `recipe/`, `tools/`, `template/`). Для каждого скрипта `ai-*` скачайте `<name>.zip` из его последнего релиза на GitHub и распакуйте в `resources/[ai]/`. Если нужны только файлы, которые запускает сервер, без исходников, используйте вместо него `<name>-runtime.zip`.

</Step>
<Step>

### Настройте секреты

Скопируйте `env.example.cfg` в `env.cfg`, впишите лицензионный ключ и подключение к базе данных, затем создайте базу данных.

</Step>
<Step>

### Запустите сервер

Запустите FXServer (txAdmin), указав эту папку как папку данных сервера.

</Step>
</Steps>

## Структура

| Путь | Что |
| --- | --- |
| `server.cfg` | Список ресурсов и подключение конфигов. |
| `env.cfg` | Лицензия, слоты, адреса, база данных, RCON. Свой для каждой машины, никогда не попадает в git. |
| `security.cfg` | Строгие настройки безопасности FiveM. Никогда их не ослабляйте: каждый скрипт написан под них. |
| `permission.cfg` | Администраторы и права ACE. |
| `misc.cfg` | Язык и другие общие convar. |
| `resources/[ai]/` | Скрипты AI Core, по одной папке на каждый скрипт `ai-*`. |
| `resources/[standalone]/` | Сторонние ресурсы, которые вы добавляете. |
| `packages/` | Пакеты `@aifivem/*` (для разработчиков). |
| `template/` | Шаблон для новых скриптов: `bun run new <name> "<description>"`. |
