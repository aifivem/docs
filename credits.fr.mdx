AI Core repose sur le travail de la communauté open source de FiveM. Son pont de frameworks répond aux API d’ESX, QBCore, Qbox et vRP, sa lib couvre ce qu’offre ox_lib, et de nombreux scripts `ai-*` ont été écrits en lisant les scripts open source ci-dessous : leurs fonctions, leurs lieux par défaut (comptoirs, PNJ, emplacements, caméras), leurs valeurs de configuration et, quand la licence le permet, leur code. Merci à tous ceux qui les ont créés et partagés.

AI Core est publié sous la GNU GPL v3 (`LICENSE` dans chaque dépôt), ce qui le garde compatible avec les projets GPL et LGPL dont il s’est inspiré. Chaque projet conserve ses propres droits d’auteur ; les noms ci-dessous sont des marques de leurs propriétaires et ne servent qu’à décrire la compatibilité.

## Frameworks

| Projet | Auteurs | Licence | Ce qu’AI Core en reprend |
| --- | --- | --- | --- |
| [ESX Legacy](https://github.com/esx-framework/esx_core) | ESX Framework | GPL-3.0 | API du pont `es_extended` (xPlayer, événements, callbacks), modèle des métiers et des comptes |
| [QBCore](https://github.com/qbcore-framework/qb-core) | QBCore Framework | GPL-3.0 | API du pont `qb-core` (objet Player, métadonnées, événements, commandes), objets partagés, métiers, gangs, lieux par défaut |
| [Qbox](https://github.com/Qbox-project/qbx_core) | Qbox Project | GPL-3.0 | API du pont `qbx_core`, idées de multi-métier et de groupes, de nombreux scripts qbx_* listés plus bas |
| [ox_core](https://github.com/overextended/ox_core) | Overextended | LGPL-3.0 | Modèle de données et idées de conception où le serveur fait autorité |
| [ND Core](https://github.com/ND-Framework/ND_Core) | ND Framework | GPL-3.0 | Comparaison des frameworks |
| [vRP](https://github.com/ImagicTheCat/vRP) | ImagicTheCat | MIT | API du pont `vrp` (vRP 1, 2 et 3) |
