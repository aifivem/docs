**AI Core** é um framework de FiveM gratuito e de código aberto, escrito do zero em **TypeScript**, para tornar o desenvolvimento de servidores mais fácil, mais inteligente e acessível a todos.

Inspirado em ESX, QBCore e Qbox, o AI Core junta uma arquitetura pensada para IA, compatibilidade entre frameworks, integração automática de recursos e gerenciamento dentro do jogo. Cerca de quarenta scripts `ai-*` cobrem um servidor de roleplay completo, da tela de personagens a empregos, veículos, casas e crime.

## Por que AI Core

<Cards>
  <Card title="Feito para desenvolver com IA">
    Instruções para IA, regras de desenvolvimento e uma arquitetura TypeScript consistente.
  </Card>
  <Card title="Compatível com ESX, QBCore e Qbox">
    Scripts existentes de ESX, QBCore e Qbox rodam sem alterações, inclusive os pagos.
  </Card>
  <Card title="Integração automática">
    Detecta inventários, sistemas de chaves, celulares, dispatch, roupas e mais, e se adapta.
  </Card>
  <Card title="Tudo dentro do jogo">
    Cada configuração de cada script fica em um painel de administração no jogo, não em arquivos de config.
  </Card>
  <Card title="O servidor decide">
    Configurações de segurança do FiveM rígidas; cada pedido do cliente é verificado no servidor.
  </Card>
  <Card title="Feito para escalar">
    Cada sistema é planejado para milhares de jogadores e milhões de registros, e medido.
  </Card>
</Cards>
