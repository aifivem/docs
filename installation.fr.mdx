## Prérequis

| Dépendance | Version | Pourquoi |
| --- | --- | --- |
| FXServer (artifact) avec txAdmin | 38039 ou plus récent | ai-core en a besoin : le serveur voit lui-même la mort des joueurs. |
| MariaDB (ou MySQL) | dernière version | La base de données. AI Core crée ses propres tables. |
| [Bun](https://bun.sh) | dernière version | Uniquement pour modifier ou compiler des scripts. Chaque script est livré compilé, faire tourner un serveur ne demande donc aucun outil de build. |

## Installer avec txAdmin (recommandé)

<Steps>
<Step>

### Lancer txAdmin

Téléchargez le dernier artifact FXServer et lancez-le : txAdmin s’ouvre dans votre navigateur. Suivez le [guide officiel](https://docs.fivem.net/docs/server-manual/setting-up-a-server-txadmin/) jusqu’à l’étape de déploiement.

</Step>
<Step>

### Utiliser la recette AI Core

Choisissez **Popular Recipes > Remote URL Template** et collez :

```text
https://raw.githubusercontent.com/aifivem/aicore-server/main/recipe/ai-core.yaml
```

</Step>
<Step>

### Remplir les informations

Saisissez le nom de votre serveur, votre clé de licence de [portal.cfx.re](https://portal.cfx.re/) et la base de données. La recette écrit `server.cfg` et `env.cfg`, connecte la base de données et télécharge chaque script `ai-*`. Il n’y a aucun fichier SQL à importer : AI Core et les scripts créent et mettent à jour leurs propres tables au premier démarrage.

</Step>
<Step>

### Devenir administrateur

Rejoignez le serveur. Une carte de bienvenue affiche la ligne qui fait de vous un administrateur : ajoutez-la dans `permission.cfg` et redémarrez. Appuyez ensuite sur **F10** pour ouvrir le [panneau d’administration](/fr/docs/admin-panel) ; son guide de configuration vous accompagne dans les premiers réglages.

</Step>
</Steps>

<Callout>
Le nom, la description, les tags, la langue, les bannières et le lien Discord de la liste des serveurs se règlent sur [portal.cfx.re/servers](https://portal.cfx.re/servers), pas dans `server.cfg`.
</Callout>

## Installer à la main

<Steps>
<Step>

### Récupérer le dossier du serveur

Téléchargez le dossier du serveur (les fichiers cfg, `recipe/`, `tools/`, `template/`) et placez chaque script `ai-*` dans `resources/[ai]/`.

</Step>
<Step>

### Configurer les secrets

Copiez `env.example.cfg` en `env.cfg`, renseignez votre clé de licence et la connexion à la base de données, puis créez la base de données.

</Step>
<Step>

### Démarrer le serveur

Démarrez FXServer (txAdmin) avec ce dossier comme dossier de données du serveur.

</Step>
</Steps>

## Organisation

| Chemin | Contenu |
| --- | --- |
| `server.cfg` | La liste des ressources et les inclusions de config. |
| `env.cfg` | Licence, slots, endpoints, base de données, RCON. Propre à la machine, jamais dans git. |
| `security.cfg` | Réglages de sécurité FiveM stricts. Ne les assouplissez jamais : chaque script est écrit pour eux. |
| `permission.cfg` | Administrateurs et permissions ACE. |
| `misc.cfg` | Langue et autres convars partagées. |
| `resources/[ai]/` | Les scripts AI Core, chaque dossier `ai-*` étant son propre dépôt git. |
| `resources/[standalone]/` | Les ressources tierces que vous ajoutez. |
| `packages/` | Les packages `@aifivem/*` (développeurs). |
| `template/` | Modèle pour les nouveaux scripts : `bun run new <name> "<description>"`. |
