## Prérequis

| Dépendance | Version | Pourquoi |
| --- | --- | --- |
| FXServer (artifact) avec txAdmin | 38039 ou plus récent recommandé | Les builds récents détectent eux-mêmes la mort des joueurs. |
| MariaDB (ou MySQL) | récente | La base de données. AI Core crée ses tables lui-même. |
| [Bun](https://bun.sh) | récente | Uniquement pour modifier ou compiler des scripts ; chaque script est livré compilé. |

## Installer avec txAdmin (recommandé)

<Steps>
<Step>

### Lancer txAdmin

Téléchargez le dernier artifact FXServer et lancez-le : txAdmin s’ouvre dans le navigateur. Suivez le [guide officiel](https://docs.fivem.net/docs/server-manual/setting-up-a-server-txadmin/) jusqu’au déploiement.

</Step>
<Step>

### Utiliser la recette AI Core

Choisissez **Popular Recipes > Remote URL Template** et collez :

```text
https://raw.githubusercontent.com/aifivem/aicore-server/main/recipe/ai-core.yaml
```

</Step>
<Step>

### Remplir les informations

Nom du serveur, clé de licence de [portal.cfx.re](https://portal.cfx.re/) et base de données. La recette écrit `server.cfg` et `env.cfg`, connecte la base et télécharge chaque script `ai-*`. Aucun fichier SQL à importer.

</Step>
<Step>

### Devenir administrateur

Rejoignez le serveur. Une carte de bienvenue affiche la ligne à ajouter dans `permission.cfg`. Après le redémarrage, **F10** ouvre le [panneau d’administration](/fr/docs/admin-panel) et son guide de configuration.

</Step>
</Steps>

<Callout>
Le nom, la description, les tags, la langue, les bannières et le lien Discord de la liste des serveurs se règlent sur [portal.cfx.re/servers](https://portal.cfx.re/servers), pas dans `server.cfg`.
</Callout>
