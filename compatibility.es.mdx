Casi todos los scripts de FiveM están escritos para ESX, QBCore o Qbox, así que poder ejecutarlos es un objetivo principal. AI Core no incluye scripts de terceros ni favorece a ningún proveedor: instalas los tuyos.

## Tres capas

<Steps>
<Step>

### Puente de frameworks

AI Core proporciona `es_extended`, `qb-core` y `qbx_core` y responde a sus exports, objetos core, objetos de jugador, callbacks, eventos e inclusiones de archivos (`@qb-core/shared/locale.lua`, `@es_extended/imports.lua`, `@qbx_core/modules/playerdata.lua`), de modo que los scripts escritos para ESX, QBCore o Qbox ven a AI Core como su framework y funcionan sin cambios. Sus menús, avisos de texto, barras de progreso y cuadros de entrada se dibujan con la propia interfaz de AI Core.

</Step>
<Step>

### Capas de integración

AI Core y los scripts `ai-*` necesitan cosas que proporcionan otros scripts. Cada categoría tiene una interfaz y cada script compatible es un adaptador. AI Core detecta el script instalado al iniciar y cuando los scripts se inician o se detienen; el panel de administración puede cambiar la elección.

| Categoría | Ejemplos |
| --- | --- |
| Inventario | ai-inventory, ox_inventory, qb-inventory, tgiann-inventory y más |
| Llaves de vehículos | ai-vehiclekeys, qbx_vehiclekeys y otros |
| Dispatch (alertas policiales) | ai-policealert y scripts de alertas |
| Teléfono | tgiann-phone, lb-phone |
| Ropa | ai-appearance, tgiann-clothing |
| Muerte | ai-death |
| Clima y hora | ai-weathersync, qb-weathersync, Renewed-Weathersync, cd_easytime |
| Prisión | ai-prison, qb-prison |
| Menú radial | ai-radialmenu, qb-radialmenu, ox_lib |

</Step>
<Step>

### Sustitutos

Varios scripts `ai-*` responden a la API del script al que reemplazan, así que los scripts de terceros funcionan con ellos sin adaptador: ai-mysql sustituye a oxmysql (también a mysql-async y ghmattimysql), ai-inventory a ox_inventory y qb-inventory, ai-target a ox_target, ai-voice a pma-voice, ai-chat a chat, ai-vehicles y ai-vehiclekeys a los scripts de vehículos de Qbox.

</Step>
</Steps>

Consulta la lista de [scripts compatibles](/es/scripts) para ver con qué se integra AI Core hoy.

## Reemplazar un script ai-*

Si instalas un script de pago que reemplaza a uno `ai-*` (por ejemplo, otro inventario), AI Core te dice qué carpeta borrar y rechaza las conexiones mientras ambos estén en marcha, para que dos scripts nunca se peleen por la misma tarea.

## Añadir un script

Dar soporte a un script nuevo es un trabajo pequeño y repetible: copia la plantilla de adaptador de la categoría, rellena sus llamadas y añade una línea al registro. Puedes pedírselo a tu IA.
