AI Core est conçu pour qu’une personne qui ne sait pas coder puisse demander à une IA de modifier un script ou d’en écrire un nouveau, et obtenir un résultat qui s’intègre.

Ouvrez le dossier de données de votre serveur dans Claude Code (ou un autre agent de code : il lit `AGENTS.md`) et demandez avec vos propres mots. L’IA trouve :

| Fichier | Ce qu’il contient |
| --- | --- |
| `CLAUDE.md` | Objectifs, structure, décisions, le processus de build et de vérification. |
| `.claude/rules/` | Des règles par thème, chargées quand les fichiers correspondants sont modifiés. |
| `.claude/skills/aicore-fivem`, `aicore-ui`, `aicore-mysql` | Connaissances sur le moteur FiveM, la NUI et le SQL. |
| `resources/[ai]/<script>/CLAUDE.md` | Ce que fait chaque script et pourquoi. |
| `docs/compat/` | Les surfaces des frameworks et des notes sur les scripts tiers. |

<Callout type="warn">
Il reste recommandé de tester le code généré avant de le mettre sur un serveur en production.
</Callout>

## Ai-je besoin de l’IA ?

Non. Le développement assisté par IA est facultatif. AI Core fonctionne comme un framework FiveM classique et n’a besoin d’aucun service d’IA pour tourner.

## Lire cette documentation avec votre IA

Chaque page ici existe aussi en Markdown : ajoutez `.md` à son URL, ou utilisez le bouton **Copier le Markdown** en haut de la page. Toute la documentation se trouve sur [`/llms-full.txt`](/llms-full.txt).
