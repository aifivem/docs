AI Core is built so that someone who cannot code can ask an AI to change a script or write a new one, and get a result that fits.

Open your server data folder in Claude Code (or another coding agent: it reads `AGENTS.md`) and ask in your own words. The AI finds:

| File | What it holds |
| --- | --- |
| `CLAUDE.md` | Goals, structure, decisions, the build and check process. |
| `.claude/rules/` | Topic rules that load when matching files are edited. |
| `.claude/skills/aicore-fivem`, `aicore-ui`, `aicore-mysql` | FiveM engine, NUI and SQL knowledge. |
| `resources/[ai]/<script>/CLAUDE.md` | What each script does and why. |
| `docs/compat/` | Framework surfaces and notes on third-party scripts. |

<Callout type="warn">
Testing generated code is still recommended before you put it on a live server.
</Callout>

## Do I need AI?

No. AI-assisted development is optional. AI Core works as a regular FiveM framework and needs no AI service to run.
