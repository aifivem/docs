## Requisitos

| Dependencia | Versión | Para qué |
| --- | --- | --- |
| FXServer (artifact) con txAdmin | 38039 o superior recomendado | Las versiones nuevas permiten que el servidor detecte por sí mismo la muerte de los jugadores. Las versiones antiguas siguen funcionando. |
| MariaDB (o MySQL) | la última | La base de datos. AI Core crea sus propias tablas. |
| [Bun](https://bun.sh) | la última | Solo para cambiar o compilar scripts. Cada script viene con su compilación, así que para tener un servidor en marcha no hacen falta herramientas de compilación. |

## Instalar con txAdmin (recomendado)

<Steps>
<Step>

### Inicia txAdmin

Descarga el último artifact de FXServer e inícialo: txAdmin se abre en tu navegador. Sigue la [guía oficial](https://docs.fivem.net/docs/server-manual/setting-up-a-server-txadmin/) hasta el paso de despliegue.

</Step>
<Step>

### Usa la receta de AI Core

Elige **Popular Recipes > Remote URL Template** y pega:

```text
https://raw.githubusercontent.com/aifivem/aicore-server/main/recipe/ai-core.yaml
```

</Step>
<Step>

### Rellena los datos

Introduce el nombre de tu servidor, tu clave de licencia de [portal.cfx.re](https://portal.cfx.re/) y la base de datos. La receta escribe `server.cfg` y `env.cfg`, conecta la base de datos y descarga cada script `ai-*`. No hay ningún archivo SQL que importar: AI Core y los scripts crean y actualizan sus propias tablas en el primer inicio.

</Step>
<Step>

### Hazte administrador

Entra al servidor. Una tarjeta de bienvenida muestra la línea que te hace administrador: añádela a `permission.cfg` y reinicia. Después pulsa **F10** para abrir el [panel de administración](/es/docs/admin-panel); su guía de configuración te acompaña en los primeros ajustes.

</Step>
</Steps>

<Callout>
El nombre, la descripción, las etiquetas, el idioma, los banners y el enlace de Discord de la lista de servidores se configuran en [portal.cfx.re/servers](https://portal.cfx.re/servers), no en `server.cfg`.
</Callout>

## Instalar a mano

<Steps>
<Step>

### Consigue la carpeta del servidor

Descarga la carpeta del servidor (los archivos cfg, `recipe/`, `tools/`, `template/`) y pon cada script `ai-*` en `resources/[ai]/`.

</Step>
<Step>

### Configura los secretos

Copia `env.example.cfg` a `env.cfg`, rellena tu clave de licencia y la conexión a la base de datos y después crea la base de datos.

</Step>
<Step>

### Inicia el servidor

Inicia FXServer (txAdmin) con esta carpeta como carpeta de datos del servidor.

</Step>
</Steps>

## Estructura

| Ruta | Qué |
| --- | --- |
| `server.cfg` | La lista de recursos y los includes de configuración. |
| `env.cfg` | Licencia, slots, endpoints, base de datos, RCON. Propio de cada máquina, nunca en git. |
| `security.cfg` | Ajustes de seguridad de FiveM estrictos. No los relajes nunca: cada script está escrito para ellos. |
| `permission.cfg` | Administradores y permisos ACE. |
| `misc.cfg` | Idioma y otras convars compartidas. |
| `resources/[ai]/` | Los scripts de AI Core; cada carpeta `ai-*` es su propio repositorio git. |
| `resources/[standalone]/` | Los recursos de terceros que añadas. |
| `packages/` | Los paquetes `@aicore-fivem/*` (desarrolladores). |
| `template/` | Plantilla para scripts nuevos: `bun run new <name> "<description>"`. |
