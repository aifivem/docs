## Requisitos

| Dependencia | Versión | Para qué |
| --- | --- | --- |
| FXServer (artifact) con txAdmin | 38039 o superior recomendado | Las versiones nuevas detectan por sí solas la muerte de los jugadores. |
| MariaDB (o MySQL) | reciente | La base de datos. AI Core crea sus propias tablas. |
| [Bun](https://bun.sh) | reciente | Solo para cambiar o compilar scripts; cada script incluye su compilación. |

## Instalar con txAdmin (recomendado)

<Steps>
<Step>

### Inicia txAdmin

Descarga el último artifact de FXServer e inícialo: txAdmin se abre en el navegador. Sigue la [guía oficial](https://docs.fivem.net/docs/server-manual/setting-up-a-server-txadmin/) hasta el paso de despliegue.

</Step>
<Step>

### Usa la receta de AI Core

Elige **Popular Recipes > Remote URL Template** y pega:

```text
https://raw.githubusercontent.com/aifivem/aicore-server/main/recipe/ai-core.yaml
```

</Step>
<Step>

### Rellena los datos

Nombre del servidor, clave de licencia de [portal.cfx.re](https://portal.cfx.re/) y la base de datos. La receta escribe `server.cfg` y `env.cfg`, conecta la base y descarga cada script `ai-*`. No hay archivo SQL que importar.

</Step>
<Step>

### Hazte administrador

Entra al servidor. Una tarjeta de bienvenida muestra la línea para `permission.cfg`. Tras reiniciar, **F10** abre el [panel de administración](/es/docs/admin-panel) con su guía de configuración.

</Step>
</Steps>

<Callout>
El nombre, la descripción, las etiquetas, el idioma, los banners y el enlace de Discord de la lista de servidores se configuran en [portal.cfx.re/servers](https://portal.cfx.re/servers), no en `server.cfg`.
</Callout>
