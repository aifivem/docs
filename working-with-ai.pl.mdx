AI Core jest zbudowany tak, aby ktoś, kto nie umie programować, mógł poprosić AI o zmianę skryptu lub napisanie nowego i dostać wynik, który pasuje.

Otwórz folder danych serwera w Claude Code (lub innym agencie programistycznym: czyta on `AGENTS.md`) i poproś własnymi słowami. AI znajdzie:

| Plik | Co zawiera |
| --- | --- |
| `CLAUDE.md` | Cele, strukturę, decyzje, proces budowania i sprawdzania. |
| `.claude/rules/` | Zasady tematyczne, które wczytują się przy edycji pasujących plików. |
| `.claude/skills/aicore-fivem`, `aicore-ui`, `aicore-mysql` | Wiedzę o silniku FiveM, NUI i SQL. |
| `resources/[ai]/<script>/CLAUDE.md` | Co robi każdy skrypt i dlaczego. |
| `docs/compat/` | API frameworków i notatki o skryptach zewnętrznych. |

<Callout type="warn">
Przed wgraniem wygenerowanego kodu na działający serwer nadal zaleca się go przetestować.
</Callout>

## Czy potrzebuję AI?

Nie. Programowanie z pomocą AI jest opcjonalne. AI Core działa jak zwykły framework FiveM i do działania nie potrzebuje żadnej usługi AI.

## Czytaj tę dokumentację ze swoim AI

Każda strona jest dostępna także jako Markdown: dodaj `.md` do jej adresu URL lub użyj przycisku **Kopiuj Markdown** na górze strony. Cała dokumentacja jest pod [`/llms-full.txt`](/llms-full.txt).
