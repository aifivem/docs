AI Core opiera się na pracy społeczności open source FiveM. Jego most frameworków odpowiada na API ESX, QBCore i Qbox, jego lib pokrywa to, co oferuje ox_lib, a wiele skryptów `ai-*` powstało na podstawie poniższych skryptów open source: ich funkcji, domyślnych miejsc (lad, NPC, punktów, kamer), wartości konfiguracji oraz, tam gdzie pozwala licencja, ich kodu. Dziękujemy wszystkim, którzy je stworzyli i udostępnili.

AI Core jest wydany na licencji GNU GPL v3 (`LICENSE` w każdym repozytorium), dzięki czemu pozostaje zgodny z projektami GPL i LGPL, na których się uczył. Każdy projekt zachowuje własne prawa autorskie; poniższe nazwy są znakami towarowymi ich właścicieli i służą tylko do opisu zgodności.

## Frameworki

| Projekt | Autorzy | Licencja | Co AI Core z niego bierze |
| --- | --- | --- | --- |
| [ESX Legacy](https://github.com/esx-framework/esx_core) | ESX Framework | GPL-3.0 | API mostu `es_extended` (xPlayer, zdarzenia, callbacki), model prac i kont |
| [QBCore](https://github.com/qbcore-framework/qb-core) | QBCore Framework | GPL-3.0 | API mostu `qb-core` (obiekt Player, metadane, zdarzenia, komendy), wspólne przedmioty, prace, gangi, domyślne miejsca |
| [Qbox](https://github.com/Qbox-project/qbx_core) | Qbox Project | GPL-3.0 | API mostu `qbx_core`, pomysły na wiele prac i grupy, wiele skryptów qbx_* wymienionych niżej |
| [ox_core](https://github.com/overextended/ox_core) | Overextended | LGPL-3.0 | Model danych i pomysły na projekt, w którym decyduje serwer |
| [ND Core](https://github.com/ND-Framework/ND_Core) | ND Framework | GPL-3.0 | Porównanie frameworków |
| [vRP](https://github.com/ImagicTheCat/vRP) | ImagicTheCat | MIT | Porównanie frameworków |
