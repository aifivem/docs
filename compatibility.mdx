Almost every FiveM script is written for ESX, QBCore or Qbox, so running them is a main goal. AI Core ships no third-party scripts and favours no vendor: you install your own.

## Three layers

<Steps>
<Step>

### Framework bridge

AI Core provides `es_extended`, `qb-core` and `qbx_core` and answers their exports, core objects and events, so scripts written for ESX, QBCore or Qbox see AI Core as their framework and run unchanged.

</Step>
<Step>

### Integrations

AI Core and the `ai-*` scripts need things other scripts provide: inventory, target, notify, phone, fuel, vehicle keys and more. Each category has one interface and each supported script is one adapter file. AI Core detects the installed script on start, and the admin panel can override the choice per category.

</Step>
<Step>

### Per-script notes

Every tested third-party script gets a note: tested version, status and known limits.

</Step>
</Steps>

See the [compatible scripts](/scripts) list for what AI Core integrates with today.

## Adding a script

Supporting a new script is one small, repeatable job: copy the category's adapter template, fill in its calls, add one line to the registry. You can ask your AI to do it.
