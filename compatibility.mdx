Almost every FiveM script is written for ESX, QBCore or Qbox, so running them is a main goal. AI Core ships no third-party scripts and favours no vendor: you install your own.

## Three layers

<Steps>
<Step>

### Framework bridge

AI Core provides `es_extended`, `qb-core` and `qbx_core` and answers their exports, core objects, player objects, callbacks, events and file includes (`@qb-core/shared/locale.lua`, `@es_extended/imports.lua`, `@qbx_core/modules/playerdata.lua`), so scripts written for ESX, QBCore or Qbox see AI Core as their framework and run unchanged. Their menus, text prompts, progress bars and input dialogs are drawn with AI Core's own UI.

</Step>
<Step>

### Integration layers

AI Core and the `ai-*` scripts need things other scripts provide. Each category has one interface and each supported script is one adapter. AI Core detects the installed script at start and when scripts start or stop; the admin panel can override the choice.

| Category | Examples |
| --- | --- |
| Inventory | ai-inventory, ox_inventory, qb-inventory, tgiann-inventory and more |
| Vehicle keys | ai-vehiclekeys, qbx_vehiclekeys and others |
| Dispatch (police alerts) | ai-policealert and alert scripts |
| Phone | tgiann-phone, lb-phone |
| Clothing | ai-appearance, tgiann-clothing |
| Death | ai-death |
| Weather and time | ai-weathersync, qb-weathersync, Renewed-Weathersync, cd_easytime |
| Prison | ai-prison, qb-prison |
| Radial menu | ai-radialmenu, qb-radialmenu, ox_lib |

</Step>
<Step>

### Stand-ins

Several `ai-*` scripts answer the API of the script they replace, so third-party scripts work with them without an adapter: ai-mysql stands in for oxmysql (also mysql-async and ghmattimysql), ai-inventory for ox_inventory and qb-inventory, ai-target for ox_target, ai-voice for pma-voice, ai-chat for chat, ai-vehicles and ai-vehiclekeys for the Qbox vehicle scripts.

</Step>
</Steps>

See the [compatible scripts](/scripts) list for what AI Core integrates with today.

## Replacing an ai-* script

If you install a paid script that replaces an `ai-*` one (for example another inventory), AI Core tells you which folder to delete and refuses joins while both run, so two scripts never fight over the same job.

## Adding a script

Supporting a new script is one small, repeatable job: copy the category's adapter template, fill in its calls, add one line to the registry. You can ask your AI to do it.
