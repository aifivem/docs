Jede Einstellung, die ein Serverbetreiber anpasst, steht in einem Panel im Spiel: Framework-Einstellungen, Jobs und Gangs, Geldkonten und eine Tab-Gruppe für jedes `ai-*`-Skript. Nichts muss in einer Config-Datei bearbeitet werden.

Öffne es mit **F10** (oder `/aiadmin`). Nur Admins können es öffnen (ACE `ai.admin`, siehe `permission.cfg`).

## So funktioniert es

- **Sofort gespeichert.** Jede Änderung prüft der Server und speichert sie sofort; Spieler sehen sie ohne Neustart.
- **Keine falschen Werte.** Zahlen haben ihre Grenzen und Einheiten, Items, Jobs, Gangs und Konten werden aus Listen gewählt, und das Panel lehnt ab, was der Server ablehnen würde, mit einer verständlichen Meldung.
- **Orte werden in der Welt gesetzt.** Ein Punktfeld bietet *Use my position*, *Teleport* und eine Auswahl mit freier Kamera (fliegen, auf den Boden zielen, mit dem Mausrad die Ausrichtung drehen). Bereiche werden Ecke für Ecke gezeichnet und beim Bearbeiten in der Welt angezeigt.
- **Auswahlhilfen für Spieldinge.** Fahrzeug-, Ped- und Objektmodelle mit Suche und Bildern, Karten-Blips aus einem Bildraster, Farben mit Vorlagen, Türen und Props per Kamera gewählt.
- **Kopieren und importieren.** Datensatz-Tabs (Shops, Garagen, Jobs...) kopieren jeden Datensatz als JSON und importieren eingefügte Datensätze.
- **Lesbare Dateien.** Jedes Skript speichert seine Einstellungen in `data/*.json` mit einem JSON Schema daneben, sodass ein Editor auch eine Bearbeitung von Hand erklärt und prüft.

## Was drin ist

| Bereich | Was du einstellst |
| --- | --- |
| Dashboard | Spieler online, Updates deiner Skripte, empfohlene kostenlose Skripte. |
| Players | Online- und Offline-Charaktere: Geld, Jobs, Gangs, Name, Metadaten, töten und wiederbeleben. |
| General | Servermarke, Szene des Charakterbildschirms, Spawnpunkte und die Spawnauswahl, Interaktionsstil (prompt oder target), PvP, welches Inventar / Schlüsselsystem / Dispatch / Kleidungsskript AI Core nutzt. |
| Jobs, gangs, accounts | Ränge, Gehälter, Chefränge, Dienstregeln, Prime Time, Geldkonten. |
| Commands, keybinds | Jeder Befehl mit seinem Zugriff, die Standardtaste jeder Tastenbelegung und ihr HUD-Hinweis. |
| Logs | Die Anbieter Konsole, Discord, Fivemanage und FiveM Stats, Stufen, Webhooks. |
| Jedes `ai-*`-Skript | Eigene Tabs: Orte, Preise, Regeln, Items. |

## Einrichtungshilfe

Auf einem neuen Server öffnet sich das Panel mit einer Einrichtungshilfe: die Marke, der erste Spawnpunkt, der Charakterbildschirm und die Skripte, die du behältst. Bis sie abgeschlossen ist, sehen Spieler nach dem Spawnen eine Willkommenskarte, und Admins können die Hilfe von dort aus öffnen.
