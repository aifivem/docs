O AI Core se apoia no trabalho da comunidade de código aberto do FiveM. Sua ponte de frameworks responde às APIs do ESX, QBCore e Qbox, sua lib cobre o que o ox_lib oferece, e muitos scripts `ai-*` foram escritos lendo os scripts de código aberto abaixo: seus recursos, locais padrão (balcões, NPCs, pontos, câmeras), valores de configuração e, onde a licença permite, seu código. Obrigado a todos que os criaram e compartilharam.

O AI Core é distribuído sob a GNU GPL v3 (`LICENSE` em cada repositório), o que o mantém compatível com os projetos GPL e LGPL com que aprendeu. Cada projeto mantém seus próprios direitos autorais; os nomes abaixo são marcas de seus donos e são usados apenas para descrever a compatibilidade.

## Frameworks

| Projeto | Autores | Licença | O que o AI Core tira dele |
| --- | --- | --- | --- |
| [ESX Legacy](https://github.com/esx-framework/esx_core) | ESX Framework | GPL-3.0 | API da ponte `es_extended` (xPlayer, eventos, callbacks), modelo de empregos e contas |
| [QBCore](https://github.com/qbcore-framework/qb-core) | QBCore Framework | GPL-3.0 | API da ponte `qb-core` (objeto Player, metadados, eventos, comandos), itens compartilhados, empregos, gangues, locais padrão |
| [Qbox](https://github.com/Qbox-project/qbx_core) | Qbox Project | GPL-3.0 | API da ponte `qbx_core`, ideias de vários empregos e grupos, muitos scripts qbx_* listados abaixo |
| [ox_core](https://github.com/overextended/ox_core) | Overextended | LGPL-3.0 | Modelo de dados e ideias de design com autoridade do servidor |
| [ND Core](https://github.com/ND-Framework/ND_Core) | ND Framework | GPL-3.0 | Comparação de frameworks |
| [vRP](https://github.com/ImagicTheCat/vRP) | ImagicTheCat | MIT | Comparação de frameworks |
