## Requisitos

| Dependência | Versão | Para quê |
| --- | --- | --- |
| FXServer (artifact) com txAdmin | 38039 ou mais recente | O ai-core precisa dele: o próprio servidor vê a morte dos jogadores. |
| MariaDB (ou MySQL) | mais recente | O banco de dados. O AI Core cria suas próprias tabelas. |
| [Bun](https://bun.sh) | mais recente | Só para alterar ou compilar scripts. Cada script já vem com seu build, então rodar um servidor não precisa de ferramentas de build. |

## Instalar com o txAdmin (recomendado)

<Steps>
<Step>

### Inicie o txAdmin

Baixe o artifact mais recente do FXServer e inicie: o txAdmin abre no seu navegador. Siga o [guia oficial](https://docs.fivem.net/docs/server-manual/setting-up-a-server-txadmin/) até a etapa de implantação.

</Step>
<Step>

### Use a receita do AI Core

Escolha **Popular Recipes > Remote URL Template** e cole:

```text
https://raw.githubusercontent.com/aifivem/aicore-server/main/recipe/ai-core.yaml
```

</Step>
<Step>

### Preencha os dados

Digite o nome do seu servidor, sua chave de licença do [portal.cfx.re](https://portal.cfx.re/) e o banco de dados. A receita escreve `server.cfg` e `env.cfg`, conecta o banco de dados e baixa cada script `ai-*`. Não há arquivo SQL para importar: o AI Core e os scripts criam e atualizam suas próprias tabelas na primeira inicialização.

</Step>
<Step>

### Torne-se administrador

Entre no servidor. Um cartão de boas-vindas mostra a linha que torna você administrador: adicione-a ao `permission.cfg` e reinicie. Depois aperte **F10** para abrir o [painel de administração](/pt/docs/admin-panel); o guia de configuração dele leva você pelas primeiras configurações.

</Step>
</Steps>

<Callout>
O nome, a descrição, as tags, o idioma, os banners e o link do Discord da lista de servidores são configurados em [portal.cfx.re/servers](https://portal.cfx.re/servers), não no `server.cfg`.
</Callout>

## Instalar à mão

<Steps>
<Step>

### Pegue a pasta do servidor

Baixe a pasta do servidor (os arquivos cfg, `recipe/`, `tools/`, `template/`) e coloque cada script `ai-*` em `resources/[ai]/`.

</Step>
<Step>

### Configure os segredos

Copie `env.example.cfg` para `env.cfg`, preencha sua chave de licença e a conexão com o banco de dados, depois crie o banco de dados.

</Step>
<Step>

### Inicie o servidor

Inicie o FXServer (txAdmin) com esta pasta como pasta de dados do servidor.

</Step>
</Steps>

## Estrutura

| Caminho | O quê |
| --- | --- |
| `server.cfg` | A lista de recursos e os includes de config. |
| `env.cfg` | Licença, slots, endpoints, banco de dados, RCON. Específico da máquina, nunca no git. |
| `security.cfg` | Configurações de segurança do FiveM rígidas. Nunca as afrouxe: cada script é escrito para elas. |
| `permission.cfg` | Administradores e permissões ACE. |
| `misc.cfg` | Idioma e outras convars compartilhadas. |
| `resources/[ai]/` | Os scripts do AI Core, cada pasta `ai-*` seu próprio repositório git. |
| `resources/[standalone]/` | Recursos de terceiros que você adiciona. |
| `packages/` | Os pacotes `@aifivem/*` (desenvolvedores). |
| `template/` | Modelo para novos scripts: `bun run new <name> "<description>"`. |
