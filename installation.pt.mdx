## Requisitos

| Dependência | Versão | Para quê |
| --- | --- | --- |
| FXServer (artifact) com txAdmin | 38039 ou mais recente recomendado | Builds novos detectam sozinhos a morte dos jogadores. |
| MariaDB (ou MySQL) | recente | O banco de dados. O AI Core cria suas próprias tabelas. |
| [Bun](https://bun.sh) | recente | Só para alterar ou compilar scripts; cada script já vem compilado. |

## Instalar com o txAdmin (recomendado)

<Steps>
<Step>

### Inicie o txAdmin

Baixe o artifact mais recente do FXServer e inicie: o txAdmin abre no navegador. Siga o [guia oficial](https://docs.fivem.net/docs/server-manual/setting-up-a-server-txadmin/) até a etapa de implantação.

</Step>
<Step>

### Use a receita do AI Core

Escolha **Popular Recipes > Remote URL Template** e cole:

```text
https://raw.githubusercontent.com/aifivem/aicore-server/main/recipe/ai-core.yaml
```

</Step>
<Step>

### Preencha os dados

Nome do servidor, chave de licença do [portal.cfx.re](https://portal.cfx.re/) e o banco de dados. A receita escreve `server.cfg` e `env.cfg`, conecta o banco e baixa cada script `ai-*`. Não há arquivo SQL para importar.

</Step>
<Step>

### Torne-se administrador

Entre no servidor. Um cartão de boas-vindas mostra a linha para o `permission.cfg`. Depois de reiniciar, **F10** abre o [painel de administração](/pt/docs/admin-panel) com o guia de configuração.

</Step>
</Steps>

<Callout>
O nome, a descrição, as tags, o idioma, os banners e o link do Discord da lista de servidores são configurados em [portal.cfx.re/servers](https://portal.cfx.re/servers), não no `server.cfg`.
</Callout>
