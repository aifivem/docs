Every setting a server owner tunes lives in one in-game panel: framework settings, jobs and gangs, money accounts, and a tab group for each `ai-*` script. Nothing has to be edited in a config file.

Open it with **F10** (or `/aiadmin`). Only admins can open it (ACE `ai.admin`, see `permission.cfg`).

## How it works

- **Live save.** Every change is checked by the server and saved at once; players see it without a restart.
- **No wrong values.** Numbers have their limits and units, items, jobs, gangs and accounts are picked from lists, and the panel refuses what the server would refuse, with a plain message.
- **Places are set in the world.** A point field offers *Use my position*, *Teleport* and a free camera pick (fly, aim at the floor, scroll for the heading). Areas are drawn corner by corner and shown in the world while you edit them.
- **Pickers for game things.** Vehicle, ped and object models with search and pictures, map blips from a picture grid, colours with presets, doors and props picked with the camera.
- **Copy and import.** Records tabs (shops, garages, jobs...) copy every record as JSON and import pasted records.
- **Files you can read.** Each script keeps its settings in `data/*.json` with a JSON Schema next to it, so an editor explains and checks a hand edit too.

## What is in it

| Section | What you set |
| --- | --- |
| Dashboard | Players online, updates of your scripts, recommended free scripts. |
| Players | Online and offline characters: money, jobs, gangs, name, metadata, kill and revive. |
| General | Server brand, character screen scene, spawn points and the spawn chooser, interaction style (prompt or target), which inventory / key system / dispatch / clothing script AI Core uses. |
| Jobs, gangs, accounts | Grades, salaries, boss grades, duty rules, prime time, money accounts. |
| Commands, keybinds | Every command with its access, every keybind's default key and its HUD hint. |
| Logs | Console, Discord, Fivemanage and FiveM Stats providers, levels, webhooks. |
| Each `ai-*` script | Its own tabs: places, prices, rules, items. |

## Setup guide

On a new server the panel opens on a setup guide: the brand, the first spawn point, the character screen and the scripts to keep. Until it is finished, players see a welcome card after spawning, and admins can open the guide from it.
