## Voraussetzungen

| Abhängigkeit | Version | Wozu |
| --- | --- | --- |
| FXServer (Artifact) mit txAdmin | 38039 oder neuer | ai-core braucht es: der Server erkennt Spielertode selbst. |
| MariaDB (oder MySQL) | aktuell | Die Datenbank. AI Core legt seine Tabellen selbst an. |
| [Bun](https://bun.sh) | aktuell | Nur zum Ändern oder Bauen von Skripten. Jedes Skript enthält seinen Build, ein laufender Server braucht also keine Build-Werkzeuge. |

## Mit txAdmin installieren (empfohlen)

<Steps>
<Step>

### txAdmin starten

Lade das neueste FXServer-Artifact herunter und starte es: txAdmin öffnet sich in deinem Browser. Folge der [offiziellen Anleitung](https://docs.fivem.net/docs/server-manual/setting-up-a-server-txadmin/) bis zum Deployment-Schritt.

</Step>
<Step>

### Das AI-Core-Rezept nutzen

Wähle **Popular Recipes > Remote URL Template** und füge ein:

```text
https://raw.githubusercontent.com/aifivem/aicore-server/main/recipe/ai-core.yaml
```

</Step>
<Step>

### Angaben ausfüllen

Gib deinen Servernamen, deinen Lizenzschlüssel von [portal.cfx.re](https://portal.cfx.re/) und die Datenbank ein. Das Rezept schreibt `server.cfg` und `env.cfg`, verbindet die Datenbank und lädt jedes `ai-*`-Skript herunter. Es gibt keine SQL-Datei zu importieren: AI Core und die Skripte legen ihre Tabellen beim ersten Start selbst an und halten sie aktuell.

</Step>
<Step>

### Dich zum Admin machen

Betritt den Server. Eine Willkommenskarte zeigt die Zeile, die dich zum Admin macht: Füge sie in `permission.cfg` ein und starte neu. Drücke dann **F10**, um das [Admin-Panel](/de/docs/admin-panel) zu öffnen; seine Einrichtungshilfe führt dich durch die ersten Einstellungen.

</Step>
</Steps>

<Callout>
Name, Beschreibung, Tags, Sprache, Banner und Discord-Link in der Serverliste werden auf [portal.cfx.re/servers](https://portal.cfx.re/servers) gesetzt, nicht in `server.cfg`.
</Callout>

## Von Hand installieren

<Steps>
<Step>

### Den Server-Ordner holen

Lade den Server-Ordner herunter (die cfg-Dateien, `recipe/`, `tools/`, `template/`) und lege jedes `ai-*`-Skript in `resources/[ai]/`.

</Step>
<Step>

### Geheimnisse einrichten

Kopiere `env.example.cfg` nach `env.cfg`, trage deinen Lizenzschlüssel und die Datenbankverbindung ein und lege dann die Datenbank an.

</Step>
<Step>

### Den Server starten

Starte FXServer (txAdmin) mit diesem Ordner als Server-Datenordner.

</Step>
</Steps>

## Aufbau

| Pfad | Was |
| --- | --- |
| `server.cfg` | Die Ressourcenliste und die Config-Includes. |
| `env.cfg` | Lizenz, Slots, Endpunkte, Datenbank, RCON. Maschinenspezifisch, nie in git. |
| `security.cfg` | Strenge FiveM-Sicherheitseinstellungen. Lockere sie nie: Jedes Skript ist für sie geschrieben. |
| `permission.cfg` | Admins und ACE-Berechtigungen. |
| `misc.cfg` | Sprache und andere gemeinsame Convars. |
| `resources/[ai]/` | Die AI-Core-Skripte, jeder `ai-*`-Ordner ein eigenes git-Repository. |
| `resources/[standalone]/` | Ressourcen von Drittanbietern, die du hinzufügst. |
| `packages/` | Die `@aicore-fivem/*`-Pakete (Entwickler). |
| `template/` | Vorlage für neue Skripte: `bun run new <name> "<description>"`. |
