## Wymagania

| Zależność | Wersja | Po co |
| --- | --- | --- |
| FXServer (artifact) z txAdmin | 38039 lub nowsza | ai-core tego wymaga: serwer sam wykrywa śmierć graczy. |
| MariaDB (lub MySQL) | aktualna | Baza danych. AI Core sam tworzy swoje tabele. |
| [Bun](https://bun.sh) | aktualna | Tylko do zmiany lub budowania skryptów. Każdy skrypt ma dołączony gotowy build, więc do uruchomienia serwera nie potrzebujesz narzędzi do budowania. |

## Instalacja z txAdmin (zalecana)

<Steps>
<Step>

### Uruchom txAdmin

Pobierz najnowszy artifact FXServer i uruchom go: txAdmin otworzy się w przeglądarce. Postępuj według [oficjalnego poradnika](https://docs.fivem.net/docs/server-manual/setting-up-a-server-txadmin/) aż do kroku wdrożenia.

</Step>
<Step>

### Użyj przepisu AI Core

Wybierz **Popular Recipes > Remote URL Template** i wklej:

```text
https://raw.githubusercontent.com/aifivem/aicore-server/main/recipe/ai-core.yaml
```

</Step>
<Step>

### Uzupełnij dane

Wpisz nazwę serwera, klucz licencyjny z [portal.cfx.re](https://portal.cfx.re/) i dane bazy danych. Przepis zapisuje `server.cfg` i `env.cfg`, łączy bazę danych i pobiera każdy skrypt `ai-*`. Nie ma pliku SQL do importu: AI Core i skrypty same tworzą i aktualizują swoje tabele przy pierwszym starcie.

</Step>
<Step>

### Zostań administratorem

Wejdź na serwer. Karta powitalna pokaże linię, która daje ci uprawnienia administratora: dodaj ją do `permission.cfg` i zrestartuj serwer. Potem naciśnij **F10**, aby otworzyć [panel administratora](/pl/docs/admin-panel); jego przewodnik konfiguracji przeprowadzi cię przez pierwsze ustawienia.

</Step>
</Steps>

<Callout>
Nazwę, opis, tagi, język, banery i link do Discorda na liście serwerów ustawia się na [portal.cfx.re/servers](https://portal.cfx.re/servers), nie w `server.cfg`.
</Callout>

## Instalacja ręczna

<Steps>
<Step>

### Pobierz folder serwera

Pobierz folder serwera (pliki cfg, `recipe/`, `tools/`, `template/`). Dla każdego skryptu `ai-*` pobierz `<name>.zip` z jego najnowszego wydania na GitHubie i rozpakuj go do `resources/[ai]/`. Jeśli chcesz tylko pliki uruchamiane przez serwer, bez źródeł, użyj zamiast tego `<name>-runtime.zip`.

</Step>
<Step>

### Ustaw sekrety

Skopiuj `env.example.cfg` do `env.cfg`, wpisz klucz licencyjny i połączenie z bazą danych, a potem utwórz bazę danych.

</Step>
<Step>

### Uruchom serwer

Uruchom FXServer (txAdmin) z tym folderem jako folderem danych serwera.

</Step>
</Steps>

## Układ

| Ścieżka | Co |
| --- | --- |
| `server.cfg` | Lista zasobów i dołączane pliki konfiguracyjne. |
| `env.cfg` | Licencja, sloty, endpointy, baza danych, RCON. Zależny od maszyny, nigdy w git. |
| `security.cfg` | Surowe ustawienia bezpieczeństwa FiveM. Nigdy ich nie luzuj: każdy skrypt jest pod nie napisany. |
| `permission.cfg` | Administratorzy i uprawnienia ACE. |
| `misc.cfg` | Język i inne wspólne convary. |
| `resources/[ai]/` | Skrypty AI Core, jeden folder na każdy skrypt `ai-*`. |
| `resources/[standalone]/` | Zasoby zewnętrzne, które dodajesz. |
| `packages/` | Pakiety `@aifivem/*` (dla deweloperów). |
| `template/` | Szablon nowych skryptów: `bun run new <name> "<description>"`. |
