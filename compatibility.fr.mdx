Presque tous les scripts FiveM sont écrits pour ESX, QBCore ou Qbox, les faire tourner est donc un objectif principal. AI Core ne fournit aucun script tiers et ne favorise aucun éditeur : vous installez les vôtres.

## Trois couches

<Steps>
<Step>

### Pont de framework

AI Core fournit `es_extended`, `qb-core` et `qbx_core` et répond à leurs exports, objets core, objets joueur, callbacks, événements et inclusions de fichiers (`@qb-core/shared/locale.lua`, `@es_extended/imports.lua`, `@qbx_core/modules/playerdata.lua`), si bien que les scripts écrits pour ESX, QBCore ou Qbox voient AI Core comme leur framework et tournent sans modification. Leurs menus, invites de texte, barres de progression et boîtes de saisie sont dessinés avec l’interface propre à AI Core.

</Step>
<Step>

### Couches d’intégration

AI Core et les scripts `ai-*` ont besoin de choses que d’autres scripts fournissent. Chaque catégorie a une seule interface et chaque script pris en charge est un adaptateur. AI Core détecte le script installé au démarrage et quand des scripts démarrent ou s’arrêtent ; le panneau d’administration peut forcer le choix.

| Catégorie | Exemples |
| --- | --- |
| Inventaire | ai-inventory, ox_inventory, qb-inventory, tgiann-inventory et d’autres |
| Clés de véhicule | ai-vehiclekeys, qbx_vehiclekeys et d’autres |
| Dispatch (alertes police) | ai-policealert et scripts d’alerte |
| Téléphone | tgiann-phone, lb-phone |
| Vêtements | ai-appearance, tgiann-clothing |
| Mort | ai-death |
| Météo et heure | ai-weathersync, qb-weathersync, Renewed-Weathersync, cd_easytime |
| Prison | ai-prison, qb-prison |
| Menu radial | ai-radialmenu, qb-radialmenu, ox_lib |

</Step>
<Step>

### Remplaçants

Plusieurs scripts `ai-*` répondent à l’API du script qu’ils remplacent, si bien que les scripts tiers fonctionnent avec eux sans adaptateur : ai-mysql remplace oxmysql (ainsi que mysql-async et ghmattimysql), ai-inventory remplace ox_inventory et qb-inventory, ai-target ox_target, ai-voice pma-voice, ai-chat chat, ai-vehicles et ai-vehiclekeys les scripts de véhicules Qbox.

</Step>
</Steps>

Consultez la liste des [scripts compatibles](/fr/scripts) pour voir avec quoi AI Core s’intègre aujourd’hui.

## Remplacer un script ai-*

Si vous installez un script payant qui remplace un script `ai-*` (par exemple un autre inventaire), AI Core vous indique quel dossier supprimer et refuse les connexions tant que les deux tournent, pour que deux scripts ne se disputent jamais la même tâche.

## Ajouter un script

Prendre en charge un nouveau script est une petite tâche répétable : copiez le modèle d’adaptateur de la catégorie, remplissez ses appels, ajoutez une ligne au registre. Vous pouvez demander à votre IA de le faire.
