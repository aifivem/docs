Каждая настройка, которую меняет владелец сервера, находится в одной панели в игре: настройки фреймворка, работы и банды, денежные счета и группа вкладок для каждого скрипта `ai-*`. Ничего не нужно править в конфиг-файлах.

Откройте её клавишей **F10** (или `/aiadmin`). Открыть её могут только администраторы (ACE `ai.admin`, см. `permission.cfg`).

## Как это работает

- **Сохранение сразу.** Сервер проверяет каждое изменение и сразу его сохраняет; игроки видят его без перезапуска.
- **Без неверных значений.** У чисел есть границы и единицы измерения, предметы, работы, банды и счета выбираются из списков, а панель отклоняет то, что отклонил бы сервер, с понятным сообщением.
- **Места задаются в мире.** Поле точки предлагает *Use my position*, *Teleport* и выбор свободной камерой (летите, наведите на пол, прокрутите колесо для направления). Зоны рисуются угол за углом и показываются в мире, пока вы их редактируете.
- **Выбор игровых объектов.** Модели транспорта, педов и объектов с поиском и картинками, блипы карты из сетки картинок, цвета с готовыми вариантами, двери и пропы выбираются камерой.
- **Копирование и импорт.** Вкладки с записями (магазины, гаражи, работы...) копируют все записи в JSON и импортируют вставленные записи.
- **Понятные файлы.** Каждый скрипт хранит свои настройки в `data/*.json` с JSON Schema рядом, поэтому редактор объясняет и проверяет и ручную правку.

## Что в ней есть

| Раздел | Что вы настраиваете |
| --- | --- |
| Dashboard | Игроки онлайн, обновления ваших скриптов, рекомендуемые бесплатные скрипты. |
| Players | Персонажи онлайн и офлайн: деньги, работы, банды, имя, метаданные, убийство и реанимация. |
| General | Бренд сервера, сцена экрана персонажей, места появления и выбор места появления, стиль взаимодействия (prompt или target), PvP, какой скрипт инвентаря / ключей / диспетчера / одежды использует AI Core. |
| Jobs, gangs, accounts | Ранги, зарплаты, ранги босса, правила дежурства, прайм-тайм, денежные счета. |
| Commands, keybinds | Каждая команда с её доступом, клавиша по умолчанию и подсказка на HUD для каждой привязки клавиш. |
| Logs | Провайдеры Console, Discord, Fivemanage и FiveM Stats, уровни, вебхуки. |
| Каждый скрипт `ai-*` | Свои вкладки: места, цены, правила, предметы. |

## Мастер настройки

На новом сервере панель открывается с мастером настройки: бренд, первое место появления, экран персонажей и скрипты, которые нужно оставить. Пока он не завершён, игроки после появления видят приветственную карточку, а администраторы могут открыть мастер из неё.
