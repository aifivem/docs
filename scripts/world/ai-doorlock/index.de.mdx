ai-doorlock verschließt Türen, Tore, Garagentore und Schranken. Admins fügen eine Tür hinzu, indem sie in der Welt darauf zielen; Spieler, die sie benutzen dürfen, schließen sie mit einem Hinweis ab und auf, der direkt auf der Tür schwebt.

## Was es im Spiel macht

- **Abschließen.** Geh zu einer Tür, auf die du Zugriff hast: Der Hinweis **Lock ...** oder **Unlock ...** schwebt auf dem Türflügel, der dir am nächsten ist. Drücke die Interaktionstaste. Jeder Spieler sieht sofort denselben Zustand.
- **Wer abschließen darf.** Mitglieder der Jobs (optional nur im Dienst) oder Gangs der Tür. Spieler ohne Zugriff sehen den Hinweis nicht. Eine Tür ohne Jobs und ohne Gangs kann jeder abschließen.
- **Türtypen.** Schwingtüren (einfach, doppelt) bleiben offen, bis sie zugefallen sind, und schließen dann ab. Schiebetüren und Tore schließen sofort ab. Garagentore und Schranken behalten die eigene Bewegung des Spiels.
- **Schlösser halten überall.** Ein Schloss hält auch, wenn die Tür weit weg und auf deinem Bildschirm nicht geladen ist.
- **Nach einem Neustart** nimmt jede Tür ihren Zustand **Locked at start** an.

## Installation

Wird vom Rezept von AI Core installiert. Von Hand: `ensure ai-doorlock` nach `ai-core`. 94 Türen liegen fertig bereit: die Polizeistationen Mission Row und Paleto Bay, das Gefängnis Bolingbroke, Pacific Standard, Paleto Bank und die fünf Fleeca-Banken, Luxury Autos und Pickle Rental.

<Callout type="warn">
Betreibe ai-doorlock und ox_doorlock nie zusammen: ai-doorlock beantwortet bereits die Exports von ox_doorlock, und AI Core weist Spieler ab, solange beide laufen.
</Callout>

## Panel-Einstellungen

Admin-Panel > **Door locks** > Tab **Doors**: Türen, die abschließen, wer sie abschließen darf und wie sie starten. Ein Datensatz pro Tür (**New door** / **Delete door**). Eine gelöschte Tür bleibt offen.

### Door (Tür)

Wähle zuerst den Türtyp, dann die Tür in der Welt.

| Einstellung | Was sie ändert | Standard für neue |
| --- | --- | --- |
| Name | Wird im Hinweis angezeigt (`Lock Police front doors`). 1-48 Zeichen. | |
| Door type | **Single door**, **Double door**, **Sliding door / gate**, **Double sliding door** oder **Garage door / barrier**. Entscheidet, wie viele Türobjekte du auswählst und wie die Tür abschließt: Schwingtüren schließen ab, sobald sie zu sind, Schiebetüren und Tore sofort, Garagentore und Schranken behalten die eigene Bewegung des Spiels. | Single door |
| Door | Wähle die Tür in der Welt mit der freien Kamera (sie wird umrandet, wenn du darauf zielst): Ihr Modell und ihre genaue Position werden eingetragen. Bei einer Doppeltür einer der beiden Flügel. Ein Knopf daneben teleportiert dich zur Tür. | |
| Second door | Nur bei einer Doppeltür oder doppelten Schiebetür: Wähle den anderen Flügel auf dieselbe Weise. Andere Türtypen ignorieren es. | |

### Access (Zugriff)

Wer sie ab- und aufschließen darf und wie sie startet.

| Einstellung | Was sie ändert | Einheit | Standard für neue |
| --- | --- | --- | --- |
| Jobs | Nur Mitglieder dieser Jobs können sie nutzen. Lass Jobs und Gangs leer für alle. | | leer |
| Gangs | Mitglieder dieser Gangs können sie ebenfalls nutzen. | | leer |
| Only on duty | Job-Mitglieder müssen in diesem Job im Dienst sein. | an / aus | aus |
| Locked at start | Der Zustand nach einem Serverneustart. | an / aus | an |
| Reach | Wie nah der Spieler für den Hinweis sein muss. Tore und Garagentore brauchen mehr. 1-15, in Schritten von 0.5. | m | 2.5 |

## Befehle und Tastenbelegungen

Keine. Der Hinweis nutzt die Interaktionstaste (standardmäßig **E**).

## Logs

Jedes Ab- und Aufschließen geht an den Log-Kanal `doors`, mit dem Spieler, der es getan hat.

## Was es ersetzt

`fxProvide`: **ox_doorlock**. `exports.ox_doorlock:setDoorState(id, state)` und `exports.ox_doorlock:getDoor(id)` erreichen ai-doorlock. Der bereitgestellte Name wirkt nach einem vollständigen Serverstart.

## Andere Türschloss-Skripte

Der Türschloss-Layer von AI Core funktioniert auch mit tgiann-doorlock, ox_doorlock, qb-doorlock, cd_doorlock und rcore_doorlock. Wähle eines im Admin-Panel: **Server** > **General** > **Door lock script** (**Automatic** nimmt das erste laufende) und stoppe ai-doorlock. Skripte, die Tür-IDs speichern (die Türen von ai-robberies), müssen dann die Tür-IDs dieses Skripts nutzen.

## Bekannte Grenzen

- Eine Tür kann höchstens jede halbe Sekunde umgeschaltet werden, und ein Spieler kann es zweimal pro Sekunde versuchen („Wait a moment“).
- Eine Tür, deren Objekt das Spiel an dieser Stelle nicht hat (eine Kartenänderung hat es entfernt), zeigt keinen Hinweis.
- Das Abschließen einer offenen Schwingtür wartet, bis sie zu ist; wird sie 15 Sekunden lang offen gehalten, wird sie zwangsweise geschlossen.
