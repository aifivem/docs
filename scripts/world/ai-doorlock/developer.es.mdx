<Callout type="info">
Para cerrar o abrir puertas desde tu propio script, usa `doors.setLocked(id, locked, by?)` y `doors.isLocked(id)` de la lib (servidor). Pasan por la capa de cerraduras de ai-core y funcionan con el script de cerraduras que use el servidor. Los exports de abajo son los que llama la capa mientras ai-doorlock está activo.
</Callout>

Una puerta se nombra por su id del panel: la clave del registro en `data/doors.json` (se muestra en la lista de puertas del panel). Tipados como `AiDoorlockServerExports` en `@aicore-fivem/shared`.

```ts title="TypeScript"
import { resourceExport } from "@aicore-fivem/lib/server";
const doorlock = resourceExport("ai-doorlock");
```

## Exports de servidor

### SetDoorState

Cierra o abre una puerta para todos, sin comprobar acceso ni distancia.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
SetDoorState(id: string, locked: boolean): void
```

```lua title="Lua"
exports['ai-doorlock']:SetDoorState(id, locked)
```

#### Parámetros

<TypeTable
  type={{
    id: { type: 'string', description: 'El id de la puerta en el panel.', required: true },
    locked: { type: 'boolean | number', description: '`true` o `1` cierra. Cualquier otra cosa abre.', required: true },
  }}
/>

#### Devuelve

Nada. Un id que no es una puerta del panel no hace nada.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const doorlock = resourceExport("ai-doorlock");

// Un cierre total: cierra todas las puertas de la lista de la comisaría.
const STATION_DOORS = ["mrpd_front", "mrpd_back", "mrpd_back_gate"]; // ids por defecto del panel
export function lockdown(): void {
  for (const id of STATION_DOORS) doorlock.SetDoorState(id, true);
}
```
</Tab>
<Tab value="Lua">
```lua
-- Un cierre total: cierra todas las puertas de la lista de la comisaría.
local STATION_DOORS = { 'mrpd_front', 'mrpd_back', 'mrpd_back_gate' } -- ids por defecto del panel
local function lockdown()
  for _, id in ipairs(STATION_DOORS) do
    exports['ai-doorlock']:SetDoorState(id, true)
  end
end
```
</Tab>
</Tabs>

### IsLocked

Si una puerta está cerrada ahora.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
IsLocked(id: string): boolean
```

```lua title="Lua"
local locked = exports['ai-doorlock']:IsLocked(id)
```

#### Devuelve

`true` cuando está cerrada. `false` cuando está abierta o el id no es una puerta del panel.

## API de ox_doorlock

ai-doorlock hace `provide` de `ox_doorlock` y responde a dos de sus exports de servidor:

| Export | Qué hace |
| --- | --- |
| `setDoorState(id, state)` | Lo mismo que `SetDoorState`: `true` o `1` cierra, cualquier otra cosa abre. |
| `getDoor(id)` | `{ id, name, state }` (`state` 1 cerrada, 0 abierta; `name` es el nombre del panel), o `nil` para un id desconocido. |

Los demás exports de ox_doorlock no se responden.

## GlobalState

El estado de cierre de cada puerta es la clave de GlobalState `door:<id>` (`true` = cerrada), legible en el servidor y en cualquier cliente. Se quita cuando se borra la puerta.

```lua title="Lua (cliente o servidor)"
local locked = GlobalState['door:mrpd_front'] == true
```

## Eventos

| Nombre | Tipo | Qué hace |
| --- | --- | --- |
| `ai-doorlock:toggle` | callback de cliente | `(id) -> { ok, locked }`: un jugador cambia una puerta después de que el servidor compruebe la distancia y el acceso. Interno; limitado a 2 por segundo por jugador, y 500 ms por puerta. |
