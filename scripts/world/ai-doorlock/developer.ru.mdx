<Callout type="info">
Чтобы запирать или отпирать двери из своего скрипта, используйте `doors.setLocked(id, locked, by?)` и `doors.isLocked(id)` из lib (сервер). Они идут через слой замков дверей ai-core и работают с любым скриптом замков дверей, который запущен на сервере. Экспорты ниже являются тем, что вызывает слой, пока активен ai-doorlock.
</Callout>

Дверь называется по её id в панели: ключ записи в `data/doors.json` (показывается в списке дверей панели). Типизированы как `AiDoorlockServerExports` в `@aicore-fivem/shared`.

```ts title="TypeScript"
import { resourceExport } from "@aicore-fivem/lib/server";
const doorlock = resourceExport("ai-doorlock");
```

## Серверные экспорты

### SetDoorState

Запирает или отпирает дверь для всех без какой-либо проверки доступа или расстояния.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
SetDoorState(id: string, locked: boolean): void
```

```lua title="Lua"
exports['ai-doorlock']:SetDoorState(id, locked)
```

#### Параметры

<TypeTable
  type={{
    id: { type: 'string', description: 'Id двери в панели.', required: true },
    locked: { type: 'boolean | number', description: '`true` или `1` запирает. Любое другое значение отпирает.', required: true },
  }}
/>

#### Возвращает

Ничего. Id, который не является дверью панели, ничего не делает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const doorlock = resourceExport("ai-doorlock");

// Блокировка: запереть все перечисленные двери участка.
const STATION_DOORS = ["mrpd_front", "mrpd_back", "mrpd_back_gate"]; // id из панели по умолчанию
export function lockdown(): void {
  for (const id of STATION_DOORS) doorlock.SetDoorState(id, true);
}
```
</Tab>
<Tab value="Lua">
```lua
-- Блокировка: запереть все перечисленные двери участка.
local STATION_DOORS = { 'mrpd_front', 'mrpd_back', 'mrpd_back_gate' } -- id из панели по умолчанию
local function lockdown()
  for _, id in ipairs(STATION_DOORS) do
    exports['ai-doorlock']:SetDoorState(id, true)
  end
end
```
</Tab>
</Tabs>

### IsLocked

Заперта ли дверь сейчас.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
IsLocked(id: string): boolean
```

```lua title="Lua"
local locked = exports['ai-doorlock']:IsLocked(id)
```

#### Возвращает

`true`, если заперта. `false`, если отперта или id не является дверью панели.

## ox_doorlock API

ai-doorlock делает `provide` для `ox_doorlock` и отвечает на два его серверных экспорта:

| Экспорт | Что делает |
| --- | --- |
| `setDoorState(id, state)` | То же, что `SetDoorState`: `true` или `1` запирает, любое другое значение отпирает. |
| `getDoor(id)` | `{ id, name, state }` (`state` 1 заперта, 0 отперта; `name` является названием из панели) или `nil` для неизвестного id. |

Другие экспорты ox_doorlock не поддерживаются.

## GlobalState

Состояние замка каждой двери хранится в ключе GlobalState `door:<id>` (`true` = заперта), который можно читать на сервере и на каждом клиенте. Он удаляется, когда дверь удаляют.

```lua title="Lua (клиент или сервер)"
local locked = GlobalState['door:mrpd_front'] == true
```

## События

| Имя | Тип | Что делает |
| --- | --- | --- |
| `ai-doorlock:toggle` | client callback | `(id) -> { ok, locked }`: игрок переключает дверь после того, как сервер проверит расстояние и доступ. Внутреннее; не чаще 2 раз в секунду на игрока и 500 мс на дверь. |
