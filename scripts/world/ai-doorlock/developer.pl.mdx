<Callout type="info">
Aby zamykać lub otwierać drzwi z własnego skryptu, używaj `doors.setLocked(id, locked, by?)` i `doors.isLocked(id)` z biblioteki (serwer). Przechodzą przez warstwę zamków drzwi ai-core i działają z każdym skryptem zamków drzwi, którego używa serwer. Poniższe eksporty to to, co wywołuje ta warstwa, gdy ai-doorlock jest aktywny.
</Callout>

Drzwi są nazywane według ich ID z panelu: klucza rekordu w `data/doors.json` (widocznego na liście drzwi w panelu). Typowane jako `AiDoorlockServerExports` w `@aicore-fivem/shared`.

```ts title="TypeScript"
import { resourceExport } from "@aicore-fivem/lib/server";
const doorlock = resourceExport("ai-doorlock");
```

## Eksporty serwera

### SetDoorState

Zamyka lub otwiera drzwi dla wszystkich, bez sprawdzania dostępu i odległości.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
SetDoorState(id: string, locked: boolean): void
```

```lua title="Lua"
exports['ai-doorlock']:SetDoorState(id, locked)
```

#### Parametry

<TypeTable
  type={{
    id: { type: 'string', description: 'ID drzwi z panelu.', required: true },
    locked: { type: 'boolean | number', description: '`true` lub `1` zamyka. Cokolwiek innego otwiera.', required: true },
  }}
/>

#### Zwraca

Nic. ID, które nie jest drzwiami z panelu, nic nie robi.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const doorlock = resourceExport("ai-doorlock");

// Blokada: zamknij wszystkie wymienione drzwi posterunku.
const STATION_DOORS = ["mrpd_front", "mrpd_back", "mrpd_back_gate"]; // domyślne ID z panelu
export function lockdown(): void {
  for (const id of STATION_DOORS) doorlock.SetDoorState(id, true);
}
```
</Tab>
<Tab value="Lua">
```lua
-- Blokada: zamknij wszystkie wymienione drzwi posterunku.
local STATION_DOORS = { 'mrpd_front', 'mrpd_back', 'mrpd_back_gate' } -- domyślne ID z panelu
local function lockdown()
  for _, id in ipairs(STATION_DOORS) do
    exports['ai-doorlock']:SetDoorState(id, true)
  end
end
```
</Tab>
</Tabs>

### IsLocked

Czy drzwi są teraz zamknięte.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
IsLocked(id: string): boolean
```

```lua title="Lua"
local locked = exports['ai-doorlock']:IsLocked(id)
```

#### Zwraca

`true`, gdy zamknięte. `false`, gdy otwarte albo ID nie jest drzwiami z panelu.

## API ox_doorlock

ai-doorlock robi `provide` dla `ox_doorlock` i odpowiada na dwa z jego eksportów serwera:

| Eksport | Co robi |
| --- | --- |
| `setDoorState(id, state)` | To samo co `SetDoorState`: `true` lub `1` zamyka, cokolwiek innego otwiera. |
| `getDoor(id)` | `{ id, name, state }` (`state` 1 zamknięte, 0 otwarte; `name` to nazwa z panelu) albo `nil` dla nieznanego ID. |

Inne eksporty ox_doorlock nie są obsługiwane.

## GlobalState

Stan zamka każdych drzwi to klucz GlobalState `door:<id>` (`true` = zamknięte), czytelny na serwerze i na każdym kliencie. Jest usuwany, gdy drzwi zostaną usunięte.

```lua title="Lua (klient lub serwer)"
local locked = GlobalState['door:mrpd_front'] == true
```

## Zdarzenia

| Nazwa | Rodzaj | Co robi |
| --- | --- | --- |
| `ai-doorlock:toggle` | callback klienta | `(id) -> { ok, locked }`: gracz przełącza drzwi po sprawdzeniu przez serwer odległości i dostępu. Wewnętrzne; limit 2 na sekundę na gracza i 500 ms na drzwi. |
