ai-doorlock verrouille les portes, les portails, les portes de garage et les barrières. Les administrateurs ajoutent une porte en la visant dans le monde ; les joueurs autorisés la verrouillent et la déverrouillent avec une invite qui flotte sur la porte elle-même.

## Ce qu’il fait en jeu

- **Verrouillage.** Approchez-vous d’une porte à laquelle vous avez accès : l’invite **Lock ...** ou **Unlock ...** flotte sur le battant le plus proche de vous. Appuyez sur la touche d’interaction. Chaque joueur voit le même état immédiatement.
- **Qui peut la verrouiller.** Les membres des métiers de la porte (éventuellement en service uniquement) ou de ses gangs. Les joueurs sans accès ne voient pas l’invite. Une porte sans métier ni gang peut être verrouillée par tout le monde.
- **Types de portes.** Les portes battantes (simples, doubles) restent déverrouillées jusqu’à ce qu’elles soient fermées, puis se verrouillent. Les portes coulissantes et les portails se verrouillent immédiatement. Les portes de garage et les barrières gardent le mouvement propre au jeu.
- **Les serrures tiennent partout.** Une serrure tient même quand la porte est loin et n’est pas chargée sur votre écran.
- **Après un redémarrage**, chaque porte reprend son état **Locked at start**.

## Installation

Installé par la recipe d’AI Core. À la main : `ensure ai-doorlock` après `ai-core`. 94 portes sont prêtes : les commissariats de Mission Row et de Paleto Bay, la prison de Bolingbroke, Pacific Standard, la banque de Paleto et les cinq banques Fleeca, Luxury Autos et Pickle Rental.

<Callout type="warn">
Ne faites jamais tourner ai-doorlock et ox_doorlock ensemble : ai-doorlock répond déjà aux exports d’ox_doorlock, et AI Core refuse les joueurs tant que les deux tournent.
</Callout>

## Réglages du panneau

Panneau d’administration > **Door locks** > onglet **Doors** : les portes qui se verrouillent, qui peut les verrouiller et leur état de départ. Un enregistrement par porte (**New door** / **Delete door**). Une porte supprimée reste ouverte.

### Door

Choisissez d’abord le type de porte, puis la porte dans le monde.

| Réglage | Ce qu’il change | Défaut pour une nouvelle |
| --- | --- | --- |
| Name | Affiché sur l’invite (`Lock Police front doors`). 1-48 caractères. | |
| Door type | **Single door**, **Double door**, **Sliding door / gate**, **Double sliding door** ou **Garage door / barrier**. Détermine combien d’objets de porte vous choisissez et comment la porte se verrouille : les portes battantes se verrouillent une fois fermées, les portes coulissantes et les portails immédiatement, les portes de garage et les barrières gardent le mouvement propre au jeu. | Single door |
| Door | Choisissez la porte dans le monde avec la caméra libre (elle est entourée quand vous la visez) : son modèle et sa position exacte sont remplis. Pour une porte double, un des deux battants. Un bouton à côté vous téléporte jusqu’à la porte. | |
| Second door | Uniquement pour une porte double ou une porte coulissante double : choisissez l’autre battant de la même façon. Les autres types de portes l’ignorent. | |

### Access

Qui peut la verrouiller et la déverrouiller, et son état de départ.

| Réglage | Ce qu’il change | Unité | Défaut pour une nouvelle |
| --- | --- | --- | --- |
| Jobs | Seuls les membres de ces métiers peuvent l’utiliser. Laissez les métiers et les gangs vides pour tout le monde. | | vide |
| Gangs | Les membres de ces gangs peuvent aussi l’utiliser. | | vide |
| Only on duty | Les membres d’un métier doivent être en service dans ce métier. | activé / désactivé | désactivé |
| Locked at start | L’état après un redémarrage du serveur. | activé / désactivé | activé |
| Reach | À quelle distance le joueur doit être pour avoir l’invite. Les portails et les portes de garage demandent plus. 1-15, par pas de 0.5. | m | 2.5 |

## Commandes et raccourcis clavier

Aucun. L’invite utilise la touche d’interaction (**E** par défaut).

## Logs

Chaque verrouillage et déverrouillage va dans le canal de logs `doors` avec le joueur qui l’a fait.

## Ce qu’il remplace

`fxProvide` : **ox_doorlock**. `exports.ox_doorlock:setDoorState(id, state)` et `exports.ox_doorlock:getDoor(id)` atteignent ai-doorlock. Le nom fourni prend effet après un démarrage complet du serveur.

## Autres scripts de serrures

La couche serrures d’AI Core fonctionne aussi avec tgiann-doorlock, ox_doorlock, qb-doorlock, cd_doorlock et rcore_doorlock. Choisissez-en un dans le panneau d’administration : **Server** > **General** > **Door lock script** (**Automatic** prend le premier qui tourne) et arrêtez ai-doorlock. Les scripts qui stockent des id de portes (les portes d’ai-robberies) doivent alors utiliser les id de portes de ce script.

## Limites connues

- Une porte peut changer d’état au plus toutes les demi-secondes, et un joueur peut essayer deux fois par seconde (« Wait a moment »).
- Une porte dont le jeu n’a pas l’objet à cet endroit (une modification de carte l’a retiré) n’affiche aucune invite.
- Verrouiller une porte battante ouverte attend qu’elle soit fermée ; si elle est maintenue ouverte pendant 15 secondes, elle est fermée de force.
