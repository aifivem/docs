ai-admin gives admins their tools in the game: a quick menu (**F9**), noclip, teleports, heal and revive, vehicle spawn and delete, items and inventories, money, jobs and gangs, announcements and warnings, weather and time. The commands admins know from QBCore and ESX work with the same names and arguments.

Every tool is decided on the server: only admins (ACE `ai.admin`, given in ai-core's admin list) can use them. Every change is logged on the `actions` channel with the admin who made it.

## What it does in the game

- **Quick menu (F9).** Noclip on / off, teleport to waypoint, heal or revive yourself, spawn or delete a vehicle, **Players** (each online player: go to, bring, heal, revive, give item, open inventory, warn), announcement, weather and time, always show the map, and a button to the admin panel.
- **Noclip.** Fly through the world: **W A S D** fly, **Q / E** up and down, **Shift** faster, **Ctrl** slower, **Space** down to the ground, **V** changes the view, the mouse wheel changes the speed level (a wheel click resets it). The keys show on the HUD while flying. Noclip has no default key: bind **Admin: noclip on / off** in the key settings, or use `/noclip`.
- **Admin vehicle.** `/car` or the menu spawns a vehicle with the admin in the driver seat and the keys (temporary key). The admin's previous admin car is deleted.
- **Revive** also fills hunger and thirst, so the player does not die again from an empty need.
- **Warnings.** A warning stays on the player's screen with the reason until they press "I understand".
- **Announcements** show to every player as "Announcement: message" with the style and time from the Messages tab.
- **Close the server.** `/closeserver` kicks every player without admin rights and refuses new joins until `/openserver` or a restart.

## Installation

Installed by the AI Core recipe. By hand: `ensure ai-admin` after `ai-core`.

For `/addpermission` and `/removepermission`, `permission.cfg` needs these lines:

```ini title="permission.cfg"
add_ace resource.ai-admin command.add_principal allow
add_ace resource.ai-admin command.remove_principal allow
```

## Panel settings

Admin panel > **Admin tools**. The quick menu (F9) and noclip keys are set in ai-core's **Keybinds** tab.

### Tab: Settings

How noclip moves and what the admin car comes with.

**Noclip**: speed levels while flying: the mouse wheel changes the level, a wheel click resets it, Shift, Alt and Ctrl multiply it while held.

| Setting | What it changes | Unit | Default |
| --- | --- | --- | --- |
| Start speed | Speed level when noclip starts and after a wheel click. 0.1-50. | | 1 |
| Highest speed | The mouse wheel stops at this level. 1-100. | | 16 |
| Wheel step | Level change per mouse wheel notch; also the lowest level. 0.1-10. | | 0.5 |
| Shift | Speed multiplier while Shift is held. 1-20. | x | 2 |
| Alt | Speed multiplier while Alt is held. 1-50. | x | 4 |
| Ctrl | Speed multiplier while Ctrl is held (below 1 slows down). 0.01-1. | x | 0.05 |

**Admin vehicle**: what a vehicle spawned with /car or the admin menu comes with. The admin always sits in the driver seat with the keys.

| Setting | What it changes | Unit | Default |
| --- | --- | --- | --- |
| Fully upgraded | Engine, brakes, transmission, suspension and armour at their top level, turbo and xenons on. | on / off | off |
| Fuel | 0-100, steps of 5. | % | 100 |
| Engine running | The engine is already on when the admin sits in. | on / off | on |

### Tab: Messages

Send an announcement to everyone or a warning to one player. Every message is logged with the admin who sent it.

**Announcement**: a notification every player sees. The style and time also apply to /announce and the quick menu (F9).

| Setting | What it changes | Default |
| --- | --- | --- |
| Message | Up to 300 characters; shown as "Announcement: message". | |
| Style | **Info**, **Success**, **Warning** or **Error**: color and icon of the notification. | Warning |
| Time on screen | Seconds the announcement stays. 2-60. | 10 |
| Send now | Sends the message to everyone; the message box empties afterwards. An empty message is refused. | |

**Warning**: an admin warning for one online player: it stays on their screen until they confirm it. Also in the quick menu (F9) > Players.

| Setting | What it changes |
| --- | --- |
| Player | Players online when the panel opened; reopen the panel for players who joined since. You cannot warn yourself. |
| Reason | What the player did wrong, up to 300 characters; the player reads it as written. Required. |
| Send now | Sends the warning to the player; the form empties afterwards. |

### Tab: World

Weather and time for everyone, through the weather script that runs. A change applies at once; the weather script may change the weather later on its own. Changes are refused while no weather script runs.

**Weather**: shows what an admin set last (here, with /weather or in the quick menu).

| Setting | What it changes | Default |
| --- | --- | --- |
| Weather | Picking one sets it for everyone now: Extra sunny, Clear, Neutral, Smog, Foggy, Overcast, Clouds, Clearing, Rain, Thunder, Snow, Blizzard, Light snow, Christmas snow, Halloween. | Not set by an admin |
| Blackout | City lights off for everyone. | off |

**Time**: changing the hour or minute sets the clock for everyone; it keeps running unless it is stopped.

| Setting | What it changes | Unit | Default |
| --- | --- | --- | --- |
| Hour | 0 to 23. | h | 12 |
| Minute | 0 to 59, steps of 5. | min | 0 |
| Stop the clock | The time stays where it is until switched off. | on / off | off |

## Commands

`<x>` is required, `[x]` is optional. `id` is a player's server id. Every command is for admins (ACE `ai.admin`) unless the table says otherwise.

### Movement and players

| Command | Arguments | What it does |
| --- | --- | --- |
| `/noclip` | | Noclip on or off. |
| `/tpm` | | Teleport to the waypoint. |
| `/tp` | `<coords>`: `x y z`, `x, y, z`, or `x y` (onto the ground) | Teleport to coordinates. |
| `/goto` | `<id>` | Teleport to a player. |
| `/bring` | `<id>` | Bring a player to you. |
| `/heal` | `[id]` (empty: yourself) | Full health. A downed player must be revived instead. |
| `/revive` | `[id]` (empty: yourself) | Revive and heal; also fills hunger and thirst. |
| `/coords` | | Show your position (also printed in F8). |

### Vehicles

| Command | Arguments | What it does |
| --- | --- | --- |
| `/car` | `<model>` (for example `adder`) | Spawn a vehicle and sit in it. |
| `/dv` | | Delete the vehicle you sit in or stand next to. |
| `/givekey` | `[id]` (empty: yourself) | Give the keys of the vehicle you sit in or stand next to. |
| `/dvall` | | Delete every vehicle nobody sits in. |
| `/dvp` | | Delete every ped that is not a player. |
| `/dvo` | | Delete every object. |

### Items and money

| Command | Arguments | What it does |
| --- | --- | --- |
| `/giveitem` | `<id> <item> [count]` (count default 1) | Give a player an item. |
| `/removeitem` | `<id> <item> [count]` (no count: all of it) | Take an item from a player. |
| `/clearinv` | `<id>` | Empty a player's inventory. |
| `/openinv` | `<id>` | Open a player's inventory. |
| `/items` | | Open the item list and take items. |
| `/givemoney` (`/giveaccountmoney`) | `<id> <account> <amount>` (account: cash, bank...) | Give a player money on an account. |
| `/setmoney` (`/setaccountmoney`) | `<id> <account> <amount>` | Set a player's account balance. |

### Jobs, gangs and permissions

| Command | Arguments | Who | What it does |
| --- | --- | --- | --- |
| `/setjob` | `<id> <job> <grade>` (grade 0 = lowest) | Admins | Give a player a job and rank (`unemployed` takes every job away). |
| `/setgang` | `<id> <gang> <grade>` | Admins | Give a player a gang and rank (`none` takes every gang away). |
| `/job` | | Everyone | Show your job and rank. |
| `/gang` | | Everyone | Show your gang and rank. |
| `/addpermission` | `<id> <permission>` (admin, mod, god) | Admins | Put a player in a permission group until they leave (`group.<permission>`). |
| `/removepermission` | `<id> <permission>` | Admins | Take a player out of a permission group. |

### Server, messages and world

| Command | Arguments | What it does |
| --- | --- | --- |
| `/admin` | | Open the admin panel (a shorter name for ai-core's `/aiadmin`). |
| `/adminmenu` | | Open the quick admin menu. |
| `/announce` | `<message>` | Announce a message to everyone. |
| `/weather` | `<type>`: EXTRASUNNY, CLEAR, CLOUDS, RAIN, THUNDER, SNOW, XMAS... | Set the weather for everyone. |
| `/time` | `<hour> [minute]` (0-23, 0-59) | Set the time of day. |
| `/blackout` | `<on>`: 1 = on, 0 = off | Turn the city lights off (1) or on (0). |
| `/freezetime` | `<on>`: 1 = on, 0 = off | Stop the clock (1) or let it run (0). |
| `/closeserver` | `[reason]` | Close the server: players without admin rights are kicked and cannot join. Not kept over a restart. |
| `/openserver` | | Open the server again. |

`/togglepvp` (QB's command) is ai-core's own: it flips ai-core's PvP setting.

## Keybinds

| Default key | What it does |
| --- | --- |
| F9 | Admin: quick menu |
| none | Admin: noclip on / off (bind it yourself, or the owner sets a default in ai-core's Keybinds tab) |

## Known limits

- `/addpermission` lasts until the player leaves (as in QB). Permanent admins go in ai-core's admin list.
- `/heal` on a downed player does not get them up: use `/revive`.
- The World tab shows what an admin set last, not what the weather script changed later.
