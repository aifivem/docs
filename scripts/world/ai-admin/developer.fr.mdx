ai-admin n’a aucun export. Tout ce qu’il fait passe par AI Core, donc les mêmes appels sont ouverts à votre propre script :

| Outil d’ai-admin | Ce qu’il appelle (lib, serveur) |
| --- | --- |
| Soin, réanimation, est à terre | `medical` (fonctionne avec le script de mort qui tourne, quel qu’il soit) |
| La réanimation remplit les besoins | `needs.refill` |
| Clés de la voiture d’administration, `/givekey` | `vehicleKeys.give(source, vehicle, "temporary")` |
| `/car` | `spawnVehicle` après que `vehicleType(model, admin)` a vérifié le modèle |
| Commandes d’objets, ouverture d’inventaire | `inventory` (fonctionne avec l’inventaire qui tourne, quel qu’il soit) |
| `/items`, menu « Give item » | `itemPicker` |
| Météo, heure, blackout, gel de l’heure | `world` (tout script météo avec le contrat de qb-weathersync) |
| `/closeserver` | `AddConnectionCheck` d’ai-core |
| Logs | `aiLog("actions", ...)` |

## Permission

Chaque commande d’administration est enregistrée avec `addCommand(..., { restricted: true })`, ce qui signifie ACE `ai.admin`. Le callback d’action du menu rapide vérifie `isAdmin()` sur le serveur. Un joueur peut toujours désactiver le noclip ; l’activer est demandé au serveur.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify } from "@aifivem/lib/server";

// Votre propre commande réservée aux administrateurs, avec la même permission que celles d’ai-admin.
addCommand("cleanarea", { help: "Clean the area", restricted: true }, (source) => {
  notify(source, "Area cleaned", "success");
});
```
</Tab>
<Tab value="Lua">
```lua
-- Votre propre commande réservée aux administrateurs, avec la même permission que celles d’ai-admin.
aiLib.addCommand('cleanarea', { help = 'Clean the area', restricted = true }, function(source)
  aiLib.notify(source, 'Area cleaned', 'success')
end)
```
</Tab>
</Tabs>

## Export facultatif qu’il appelle

Le **Always show the map** du menu rapide appelle l’export client `SetMinimapAlways(on)` d’ai-hud quand ai-hud tourne.

## Events

Tous les events d’ai-admin sont internes (son client et son serveur) ; ne les appelez pas depuis d’autres scripts.

| Nom | Type | Ce qu’il fait |
| --- | --- | --- |
| `ai-admin:access` | callback client | Indique si le joueur peut ouvrir le menu rapide. |
| `ai-admin:noclip` | callback client | Demande l’activation du noclip. |
| `ai-admin:players` | callback client | La liste des joueurs en ligne pour le menu. |
| `ai-admin:action` | callback client | Une action du menu rapide (administrateur vérifié sur le serveur). |
| `ai-admin:giveItems` | callback client | Les objets choisis dans le sélecteur d’objets (50 lignes au plus). |
| `ai-admin:worldState` | callback client | La météo et l’heure pour le menu météo et heure. |
| `ai-admin:client:toggleNoclip` | serveur vers client | Bascule le noclip. |
| `ai-admin:client:teleport` | serveur vers client | Téléporte vers un point choisi par le serveur. |
| `ai-admin:client:openMenu` / `openItems` | serveur vers client | Ouvre le menu rapide ou le sélecteur d’objets. |
| `ai-admin:client:coords` | serveur vers client | Affiche la position du joueur. |
| `ai-admin:client:warned` | serveur vers client | Affiche un avertissement d’administration. |
