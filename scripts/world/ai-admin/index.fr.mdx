ai-admin donne aux administrateurs leurs outils en jeu : un menu rapide (**F9**), le noclip, les téléportations, le soin et la réanimation, l’apparition et la suppression de véhicules, les objets et les inventaires, l’argent, les métiers et les gangs, les annonces et les avertissements, la météo et l’heure. Les commandes que les administrateurs connaissent de QBCore et d’ESX fonctionnent avec les mêmes noms et les mêmes arguments.

Chaque outil est décidé sur le serveur : seuls les administrateurs (ACE `ai.admin`, donnée dans la liste des administrateurs d’ai-core) peuvent les utiliser. Chaque changement est enregistré dans le canal `actions` avec l’administrateur qui l’a fait.

## Ce qu’il fait en jeu

- **Menu rapide (F9).** Noclip activé / désactivé, téléportation au point de passage, se soigner ou se réanimer, faire apparaître ou supprimer un véhicule, **Players** (chaque joueur en ligne : aller vers lui, l’amener, le soigner, le réanimer, lui donner un objet, ouvrir son inventaire, l’avertir), annonce, météo et heure, toujours afficher la carte, et un bouton vers le panneau d’administration.
- **Noclip.** Volez à travers le monde : **W A S D** pour voler, **Q / E** pour monter et descendre, **Shift** plus vite, **Ctrl** plus lentement, **Espace** pour descendre jusqu’au sol, **V** change la vue, la molette change le niveau de vitesse (un clic de molette le réinitialise). Les touches s’affichent sur le HUD pendant le vol. Le noclip n’a pas de touche par défaut : assignez **Admin: noclip on / off** dans les réglages des touches, ou utilisez `/noclip`.
- **Véhicule d’administration.** `/car` ou le menu fait apparaître un véhicule avec l’administrateur au volant et les clés (clé temporaire). La voiture d’administration précédente de l’administrateur est supprimée.
- **La réanimation** remplit aussi la faim et la soif, pour que le joueur ne meure pas à nouveau à cause d’un besoin vide.
- **Avertissements.** Un avertissement reste à l’écran du joueur avec la raison jusqu’à ce qu’il appuie sur « I understand ».
- **Les annonces** s’affichent pour chaque joueur sous la forme « Announcement: message » avec le style et la durée de l’onglet Messages.
- **Fermer le serveur.** `/closeserver` expulse chaque joueur sans droits d’administration et refuse les nouvelles connexions jusqu’à `/openserver` ou un redémarrage.

## Installation

Installé par la recipe d’AI Core. À la main : `ensure ai-admin` après `ai-core`.

Pour `/addpermission` et `/removepermission`, `permission.cfg` a besoin de ces lignes :

```ini title="permission.cfg"
add_ace resource.ai-admin command.add_principal allow
add_ace resource.ai-admin command.remove_principal allow
```

## Réglages du panneau

Panneau d’administration > **Admin tools**. Les touches du menu rapide (F9) et du noclip se règlent dans l’onglet **Keybinds** d’ai-core.

### Onglet : Settings

Comment se déplace le noclip et ce qu’inclut la voiture d’administration.

**Noclip** : niveaux de vitesse pendant le vol : la molette change le niveau, un clic de molette le réinitialise, Shift, Alt et Ctrl le multiplient tant qu’ils sont maintenus.

| Réglage | Ce qu’il change | Unité | Défaut |
| --- | --- | --- | --- |
| Start speed | Niveau de vitesse au démarrage du noclip et après un clic de molette. 0.1-50. | | 1 |
| Highest speed | La molette s’arrête à ce niveau. 1-100. | | 16 |
| Wheel step | Changement de niveau par cran de molette ; aussi le niveau le plus bas. 0.1-10. | | 0.5 |
| Shift | Multiplicateur de vitesse tant que Shift est maintenu. 1-20. | x | 2 |
| Alt | Multiplicateur de vitesse tant qu’Alt est maintenu. 1-50. | x | 4 |
| Ctrl | Multiplicateur de vitesse tant que Ctrl est maintenu (en dessous de 1, ralentit). 0.01-1. | x | 0.05 |

**Admin vehicle** : ce qu’inclut un véhicule apparu avec /car ou le menu d’administration. L’administrateur est toujours au volant avec les clés.

| Réglage | Ce qu’il change | Unité | Défaut |
| --- | --- | --- | --- |
| Fully upgraded | Moteur, freins, transmission, suspension et blindage au niveau maximum, turbo et xénons activés. | activé / désactivé | désactivé |
| Fuel | 0-100, par pas de 5. | % | 100 |
| Engine running | Le moteur tourne déjà quand l’administrateur s’installe. | activé / désactivé | activé |

### Onglet : Messages

Envoyez une annonce à tout le monde ou un avertissement à un joueur. Chaque message est enregistré avec l’administrateur qui l’a envoyé.

**Announcement** : une notification que voit chaque joueur. Le style et la durée s’appliquent aussi à /announce et au menu rapide (F9).

| Réglage | Ce qu’il change | Défaut |
| --- | --- | --- |
| Message | Jusqu’à 300 caractères ; affiché sous la forme « Announcement: message ». | |
| Style | **Info**, **Success**, **Warning** ou **Error** : couleur et icône de la notification. | Warning |
| Time on screen | Secondes pendant lesquelles l’annonce reste affichée. 2-60. | 10 |
| Send now | Envoie le message à tout le monde ; la zone de message se vide ensuite. Un message vide est refusé. | |

**Warning** : un avertissement d’administration pour un joueur en ligne : il reste à son écran jusqu’à ce qu’il le confirme. Aussi dans le menu rapide (F9) > Players.

| Réglage | Ce qu’il change |
| --- | --- |
| Player | Les joueurs en ligne à l’ouverture du panneau ; rouvrez le panneau pour les joueurs arrivés depuis. Vous ne pouvez pas vous avertir vous-même. |
| Reason | Ce que le joueur a fait de mal, jusqu’à 300 caractères ; le joueur le lit tel qu’écrit. Obligatoire. |
| Send now | Envoie l’avertissement au joueur ; le formulaire se vide ensuite. |

### Onglet : World

La météo et l’heure pour tout le monde, via le script météo qui tourne. Un changement s’applique immédiatement ; le script météo peut changer la météo plus tard de lui-même. Les changements sont refusés tant qu’aucun script météo ne tourne.

**Weather** : affiche ce qu’un administrateur a réglé en dernier (ici, avec /weather ou dans le menu rapide).

| Réglage | Ce qu’il change | Défaut |
| --- | --- | --- |
| Weather | En choisir une la règle pour tout le monde maintenant : Extra sunny, Clear, Neutral, Smog, Foggy, Overcast, Clouds, Clearing, Rain, Thunder, Snow, Blizzard, Light snow, Christmas snow, Halloween. | Non réglée par un administrateur |
| Blackout | Lumières de la ville éteintes pour tout le monde. | désactivé |

**Time** : changer l’heure ou la minute règle l’horloge pour tout le monde ; elle continue de tourner sauf si elle est arrêtée.

| Réglage | Ce qu’il change | Unité | Défaut |
| --- | --- | --- | --- |
| Hour | 0 à 23. | h | 12 |
| Minute | 0 à 59, par pas de 5. | min | 0 |
| Stop the clock | L’heure reste où elle est jusqu’à désactivation. | activé / désactivé | désactivé |

## Commandes

`<x>` est obligatoire, `[x]` est facultatif. `id` est l’id serveur d’un joueur. Chaque commande est réservée aux administrateurs (ACE `ai.admin`) sauf indication contraire dans le tableau.

### Déplacement et joueurs

| Commande | Arguments | Ce qu’elle fait |
| --- | --- | --- |
| `/noclip` | | Active ou désactive le noclip. |
| `/tpm` | | Téléporte au point de passage. |
| `/tp` | `<coords>` : `x y z`, `x, y, z`, ou `x y` (sur le sol) | Téléporte à des coordonnées. |
| `/goto` | `<id>` | Téléporte vers un joueur. |
| `/bring` | `<id>` | Amène un joueur jusqu’à vous. |
| `/heal` | `[id]` (vide : vous-même) | Santé au maximum. Un joueur à terre doit être réanimé à la place. |
| `/revive` | `[id]` (vide : vous-même) | Réanime et soigne ; remplit aussi la faim et la soif. |
| `/coords` | | Affiche votre position (aussi écrite dans F8). |

### Véhicules

| Commande | Arguments | Ce qu’elle fait |
| --- | --- | --- |
| `/car` | `<model>` (par exemple `adder`) | Fait apparaître un véhicule et vous installe dedans. |
| `/dv` | | Supprime le véhicule dans lequel vous êtes assis ou à côté duquel vous vous tenez. |
| `/givekey` | `[id]` (vide : vous-même) | Donne les clés du véhicule dans lequel vous êtes assis ou à côté duquel vous vous tenez. |
| `/dvall` | | Supprime chaque véhicule dans lequel personne n’est assis. |
| `/dvp` | | Supprime chaque ped qui n’est pas un joueur. |
| `/dvo` | | Supprime chaque objet. |

### Objets et argent

| Commande | Arguments | Ce qu’elle fait |
| --- | --- | --- |
| `/giveitem` | `<id> <item> [count]` (count 1 par défaut) | Donne un objet à un joueur. |
| `/removeitem` | `<id> <item> [count]` (sans count : la totalité) | Retire un objet à un joueur. |
| `/clearinv` | `<id>` | Vide l’inventaire d’un joueur. |
| `/openinv` | `<id>` | Ouvre l’inventaire d’un joueur. |
| `/items` | | Ouvre la liste des objets pour en prendre. |
| `/givemoney` (`/giveaccountmoney`) | `<id> <account> <amount>` (account : cash, bank...) | Donne de l’argent à un joueur sur un compte. |
| `/setmoney` (`/setaccountmoney`) | `<id> <account> <amount>` | Règle le solde du compte d’un joueur. |

### Métiers, gangs et permissions

| Commande | Arguments | Qui | Ce qu’elle fait |
| --- | --- | --- | --- |
| `/setjob` | `<id> <job> <grade>` (grade 0 = le plus bas) | Administrateurs | Donne un métier et un grade à un joueur (`unemployed` retire tous les métiers). |
| `/setgang` | `<id> <gang> <grade>` | Administrateurs | Donne un gang et un grade à un joueur (`none` retire tous les gangs). |
| `/job` | | Tout le monde | Affiche votre métier et votre grade. |
| `/gang` | | Tout le monde | Affiche votre gang et votre grade. |
| `/addpermission` | `<id> <permission>` (admin, mod, god) | Administrateurs | Place un joueur dans un groupe de permission jusqu’à ce qu’il parte (`group.<permission>`). |
| `/removepermission` | `<id> <permission>` | Administrateurs | Retire un joueur d’un groupe de permission. |

### Serveur, messages et monde

| Commande | Arguments | Ce qu’elle fait |
| --- | --- | --- |
| `/admin` | | Ouvre le panneau d’administration (un nom plus court pour le `/aiadmin` d’ai-core). |
| `/adminmenu` | | Ouvre le menu rapide d’administration. |
| `/announce` | `<message>` | Annonce un message à tout le monde. |
| `/weather` | `<type>` : EXTRASUNNY, CLEAR, CLOUDS, RAIN, THUNDER, SNOW, XMAS... | Règle la météo pour tout le monde. |
| `/time` | `<hour> [minute]` (0-23, 0-59) | Règle l’heure de la journée. |
| `/blackout` | `<on>` : 1 = activé, 0 = désactivé | Éteint (1) ou rallume (0) les lumières de la ville. |
| `/freezetime` | `<on>` : 1 = activé, 0 = désactivé | Arrête l’horloge (1) ou la laisse tourner (0). |
| `/closeserver` | `[reason]` | Ferme le serveur : les joueurs sans droits d’administration sont expulsés et ne peuvent pas se connecter. Non conservé après un redémarrage. |
| `/openserver` | | Rouvre le serveur. |

`/togglepvp` (la commande de QB) appartient à ai-core : elle inverse le réglage PvP d’ai-core.

## Raccourcis clavier

| Touche par défaut | Ce qu’elle fait |
| --- | --- |
| F9 | Admin: quick menu (menu rapide) |
| aucune | Admin: noclip on / off (assignez-la vous-même, ou le propriétaire règle une touche par défaut dans l’onglet Keybinds d’ai-core) |

## Limites connues

- `/addpermission` dure jusqu’à ce que le joueur parte (comme dans QB). Les administrateurs permanents vont dans la liste des administrateurs d’ai-core.
- `/heal` sur un joueur à terre ne le relève pas : utilisez `/revive`.
- L’onglet World affiche ce qu’un administrateur a réglé en dernier, pas ce que le script météo a changé ensuite.
