ai-admin daje administratorom ich narzędzia w grze: szybkie menu (**F9**), noclip, teleporty, leczenie i reanimację, tworzenie i usuwanie pojazdów, przedmioty i ekwipunki, pieniądze, prace i gangi, ogłoszenia i ostrzeżenia, pogodę i czas. Komendy, które administratorzy znają z QBCore i ESX, działają z tymi samymi nazwami i argumentami.

O każdym narzędziu decyduje serwer: mogą z nich korzystać tylko administratorzy (ACE `ai.admin`, nadawane na liście administratorów ai-core). Każda zmiana jest logowana na kanale `actions` razem z administratorem, który ją wprowadził.

## Co robi w grze

- **Szybkie menu (F9).** Noclip wł. / wył., teleport do punktu na mapie, uleczenie lub reanimacja siebie, utworzenie lub usunięcie pojazdu, **Players** (każdy gracz online: idź do, przyprowadź, ulecz, reanimuj, daj przedmiot, otwórz ekwipunek, ostrzeż), ogłoszenie, pogoda i czas, zawsze pokazuj mapę oraz przycisk do panelu administratora.
- **Noclip.** Lataj przez świat: **W A S D** lot, **Q / E** w górę i w dół, **Shift** szybciej, **Ctrl** wolniej, **Spacja** w dół do ziemi, **V** zmienia widok, kółko myszy zmienia poziom prędkości (kliknięcie kółkiem go resetuje). Klawisze są widoczne w HUD-zie podczas lotu. Noclip nie ma domyślnego klawisza: przypisz **Admin: noclip on / off** w ustawieniach klawiszy albo użyj `/noclip`.
- **Pojazd administratora.** `/car` lub menu tworzy pojazd z administratorem na miejscu kierowcy i kluczami (klucz tymczasowy). Poprzednie auto administratora jest usuwane.
- **Reanimacja** uzupełnia też głód i pragnienie, więc gracz nie umrze znowu z powodu pustej potrzeby.
- **Ostrzeżenia.** Ostrzeżenie zostaje na ekranie gracza z powodem, dopóki nie naciśnie „I understand”.
- **Ogłoszenia** są widoczne dla każdego gracza jako „Announcement: message” ze stylem i czasem z zakładki Messages.
- **Zamknięcie serwera.** `/closeserver` wyrzuca każdego gracza bez uprawnień administratora i odrzuca nowe połączenia do `/openserver` lub restartu.

## Instalacja

Instalowany przez przepis AI Core. Ręcznie: `ensure ai-admin` po `ai-core`.

Dla `/addpermission` i `/removepermission` plik `permission.cfg` potrzebuje tych linii:

```ini title="permission.cfg"
add_ace resource.ai-admin command.add_principal allow
add_ace resource.ai-admin command.remove_principal allow
```

## Ustawienia w panelu

Panel administratora > **Admin tools**. Klawisze szybkiego menu (F9) i noclipa ustawia się w zakładce **Keybinds** ai-core.

### Zakładka: Settings

Jak porusza się noclip i z czym przychodzi auto administratora.

**Noclip**: poziomy prędkości podczas lotu: kółko myszy zmienia poziom, kliknięcie kółkiem go resetuje, Shift, Alt i Ctrl mnożą go, gdy są przytrzymane.

| Ustawienie | Co zmienia | Jednostka | Domyślnie |
| --- | --- | --- | --- |
| Start speed | Poziom prędkości po włączeniu noclipa i po kliknięciu kółkiem. 0.1-50. | | 1 |
| Highest speed | Kółko myszy zatrzymuje się na tym poziomie. 1-100. | | 16 |
| Wheel step | Zmiana poziomu na jeden ząbek kółka myszy; także najniższy poziom. 0.1-10. | | 0.5 |
| Shift | Mnożnik prędkości, gdy Shift jest przytrzymany. 1-20. | x | 2 |
| Alt | Mnożnik prędkości, gdy Alt jest przytrzymany. 1-50. | x | 4 |
| Ctrl | Mnożnik prędkości, gdy Ctrl jest przytrzymany (poniżej 1 spowalnia). 0.01-1. | x | 0.05 |

**Admin vehicle**: z czym przychodzi pojazd utworzony przez /car lub menu administratora. Administrator zawsze siedzi na miejscu kierowcy z kluczami.

| Ustawienie | Co zmienia | Jednostka | Domyślnie |
| --- | --- | --- | --- |
| Fully upgraded | Silnik, hamulce, skrzynia biegów, zawieszenie i pancerz na najwyższym poziomie, turbo i ksenony włączone. | wł. / wył. | wył. |
| Fuel | 0-100, co 5. | % | 100 |
| Engine running | Silnik jest już włączony, gdy administrator wsiada. | wł. / wył. | wł. |

### Zakładka: Messages

Wyślij ogłoszenie do wszystkich lub ostrzeżenie do jednego gracza. Każda wiadomość jest logowana razem z administratorem, który ją wysłał.

**Announcement**: powiadomienie, które widzi każdy gracz. Styl i czas dotyczą też /announce i szybkiego menu (F9).

| Ustawienie | Co zmienia | Domyślnie |
| --- | --- | --- |
| Message | Do 300 znaków; widoczne jako „Announcement: message”. | |
| Style | **Info**, **Success**, **Warning** lub **Error**: kolor i ikona powiadomienia. | Warning |
| Time on screen | Ile sekund ogłoszenie zostaje. 2-60. | 10 |
| Send now | Wysyła wiadomość do wszystkich; potem pole wiadomości się czyści. Pusta wiadomość jest odrzucana. | |

**Warning**: ostrzeżenie administratora dla jednego gracza online: zostaje na jego ekranie, dopóki go nie potwierdzi. Także w szybkim menu (F9) > Players.

| Ustawienie | Co zmienia |
| --- | --- |
| Player | Gracze online w chwili otwarcia panelu; otwórz panel ponownie dla graczy, którzy dołączyli później. Nie możesz ostrzec siebie. |
| Reason | Co gracz zrobił źle, do 300 znaków; gracz czyta to tak, jak zostało napisane. Wymagane. |
| Send now | Wysyła ostrzeżenie do gracza; potem formularz się czyści. |

### Zakładka: World

Pogoda i czas dla wszystkich, przez działający skrypt pogody. Zmiana działa od razu; skrypt pogody może później sam zmienić pogodę. Zmiany są odrzucane, gdy nie działa żaden skrypt pogody.

**Weather**: pokazuje, co administrator ustawił ostatnio (tutaj, przez /weather lub w szybkim menu).

| Ustawienie | Co zmienia | Domyślnie |
| --- | --- | --- |
| Weather | Wybranie jednej ustawia ją teraz dla wszystkich: Extra sunny, Clear, Neutral, Smog, Foggy, Overcast, Clouds, Clearing, Rain, Thunder, Snow, Blizzard, Light snow, Christmas snow, Halloween. | Not set by an admin |
| Blackout | Światła miasta wyłączone dla wszystkich. | wył. |

**Time**: zmiana godziny lub minuty ustawia zegar dla wszystkich; biegnie dalej, chyba że zostanie zatrzymany.

| Ustawienie | Co zmienia | Jednostka | Domyślnie |
| --- | --- | --- | --- |
| Hour | Od 0 do 23. | h | 12 |
| Minute | Od 0 do 59, co 5. | min | 0 |
| Stop the clock | Czas zostaje tam, gdzie jest, dopóki tego nie wyłączysz. | wł. / wył. | wył. |

## Komendy

`<x>` jest wymagane, `[x]` jest opcjonalne. `id` to ID gracza na serwerze. Każda komenda jest dla administratorów (ACE `ai.admin`), chyba że tabela mówi inaczej.

### Ruch i gracze

| Komenda | Argumenty | Co robi |
| --- | --- | --- |
| `/noclip` | | Noclip wł. lub wył. |
| `/tpm` | | Teleport do punktu na mapie. |
| `/tp` | `<coords>`: `x y z`, `x, y, z` lub `x y` (na ziemię) | Teleport do współrzędnych. |
| `/goto` | `<id>` | Teleport do gracza. |
| `/bring` | `<id>` | Przyprowadź gracza do siebie. |
| `/heal` | `[id]` (puste: ty) | Pełne zdrowie. Powalonego gracza trzeba zamiast tego reanimować. |
| `/revive` | `[id]` (puste: ty) | Reanimuj i ulecz; uzupełnia też głód i pragnienie. |
| `/coords` | | Pokaż swoją pozycję (wypisywaną też w F8). |

### Pojazdy

| Komenda | Argumenty | Co robi |
| --- | --- | --- |
| `/car` | `<model>` (na przykład `adder`) | Utwórz pojazd i w nim usiądź. |
| `/dv` | | Usuń pojazd, w którym siedzisz lub przy którym stoisz. |
| `/givekey` | `[id]` (puste: ty) | Daj klucze do pojazdu, w którym siedzisz lub przy którym stoisz. |
| `/dvall` | | Usuń każdy pojazd, w którym nikt nie siedzi. |
| `/dvp` | | Usuń każdego peda, który nie jest graczem. |
| `/dvo` | | Usuń każdy obiekt. |

### Przedmioty i pieniądze

| Komenda | Argumenty | Co robi |
| --- | --- | --- |
| `/giveitem` | `<id> <item> [count]` (count domyślnie 1) | Daj graczowi przedmiot. |
| `/removeitem` | `<id> <item> [count]` (bez count: wszystko) | Zabierz graczowi przedmiot. |
| `/clearinv` | `<id>` | Opróżnij ekwipunek gracza. |
| `/openinv` | `<id>` | Otwórz ekwipunek gracza. |
| `/items` | | Otwórz listę przedmiotów i bierz przedmioty. |
| `/givemoney` (`/giveaccountmoney`) | `<id> <account> <amount>` (account: cash, bank...) | Daj graczowi pieniądze na konto. |
| `/setmoney` (`/setaccountmoney`) | `<id> <account> <amount>` | Ustaw saldo konta gracza. |

### Prace, gangi i uprawnienia

| Komenda | Argumenty | Kto | Co robi |
| --- | --- | --- | --- |
| `/setjob` | `<id> <job> <grade>` (grade 0 = najniższy) | Administratorzy | Daj graczowi pracę i rangę (`unemployed` zabiera każdą pracę). |
| `/setgang` | `<id> <gang> <grade>` | Administratorzy | Daj graczowi gang i rangę (`none` zabiera każdy gang). |
| `/job` | | Wszyscy | Pokaż swoją pracę i rangę. |
| `/gang` | | Wszyscy | Pokaż swój gang i rangę. |
| `/addpermission` | `<id> <permission>` (admin, mod, god) | Administratorzy | Dodaj gracza do grupy uprawnień, dopóki nie wyjdzie (`group.<permission>`). |
| `/removepermission` | `<id> <permission>` | Administratorzy | Usuń gracza z grupy uprawnień. |

### Serwer, wiadomości i świat

| Komenda | Argumenty | Co robi |
| --- | --- | --- |
| `/admin` | | Otwórz panel administratora (krótsza nazwa dla `/aiadmin` z ai-core). |
| `/adminmenu` | | Otwórz szybkie menu administratora. |
| `/announce` | `<message>` | Ogłoś wiadomość wszystkim. |
| `/weather` | `<type>`: EXTRASUNNY, CLEAR, CLOUDS, RAIN, THUNDER, SNOW, XMAS... | Ustaw pogodę dla wszystkich. |
| `/time` | `<hour> [minute]` (0-23, 0-59) | Ustaw porę dnia. |
| `/blackout` | `<on>`: 1 = wł., 0 = wył. | Wyłącz (1) lub włącz (0) światła miasta. |
| `/freezetime` | `<on>`: 1 = wł., 0 = wył. | Zatrzymaj zegar (1) lub pozwól mu biec (0). |
| `/closeserver` | `[reason]` | Zamknij serwer: gracze bez uprawnień administratora są wyrzucani i nie mogą dołączyć. Nie przetrwa restartu. |
| `/openserver` | | Otwórz serwer ponownie. |

`/togglepvp` (komenda QB) należy do ai-core: przełącza ustawienie PvP w ai-core.

| Domyślny klawisz | Co robi |
| --- | --- |
| F9 | Admin: szybkie menu |

## Znane ograniczenia

- `/addpermission` trwa, dopóki gracz nie wyjdzie (jak w QB). Stali administratorzy trafiają na listę administratorów ai-core.
- `/heal` na powalonym graczu go nie podnosi: użyj `/revive`.
- Zakładka World pokazuje, co administrator ustawił ostatnio, a nie to, co skrypt pogody zmienił później.
