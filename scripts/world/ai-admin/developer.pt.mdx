O ai-admin não tem exports. Tudo o que ele faz passa pelo AI Core, então as mesmas chamadas estão abertas para o seu próprio script:

| Ferramenta do ai-admin | O que ela chama (lib, servidor) |
| --- | --- |
| Curar, reanimar, está caído | `medical` (funciona com qualquer script de morte que estiver rodando) |
| Reanimar enche as necessidades | `needs.refill` |
| Chaves do carro de administrador, `/givekey` | `vehicleKeys.give(source, vehicle, "temporary")` |
| `/car` | `spawnVehicle` depois que `vehicleType(model, admin)` verifica o modelo |
| Comandos de itens, abrir inventário | `inventory` (funciona com qualquer inventário que estiver rodando) |
| `/items`, menu "Give item" | `itemPicker` |
| Clima, hora, apagão, congelar | `world` (qualquer script de clima com o contrato do qb-weathersync) |
| `/closeserver` | `AddConnectionCheck` do ai-core |
| Logs | `aiLog("actions", ...)` |

## Permissão

Todo comando de administrador é registrado com `addCommand(..., { restricted: true })`, o que significa ACE `ai.admin`. O callback de ação do menu rápido verifica `isAdmin()` no servidor. Um jogador sempre pode desligar o noclip; ligá-lo é pedido ao servidor.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify } from "@aifivem/lib/server";

// Seu próprio comando só para administradores, com a mesma permissão dos comandos do ai-admin.
addCommand("cleanarea", { help: "Clean the area", restricted: true }, (source) => {
  notify(source, "Area cleaned", "success");
});
```
</Tab>
<Tab value="Lua">
```lua
-- Seu próprio comando só para administradores, com a mesma permissão dos comandos do ai-admin.
aiLib.addCommand('cleanarea', { help = 'Clean the area', restricted = true }, function(source)
  aiLib.notify(source, 'Area cleaned', 'success')
end)
```
</Tab>
</Tabs>

## Export opcional que ele chama

O **Always show the map** do menu rápido chama o export de cliente `SetMinimapAlways(on)` do ai-hud quando o ai-hud está rodando.

## Eventos

Todos os eventos do ai-admin são internos (do cliente e do servidor dele); não os chame a partir de outros scripts.

| Nome | Tipo | O que faz |
| --- | --- | --- |
| `ai-admin:access` | callback do cliente | Se o jogador pode abrir o menu rápido. |
| `ai-admin:noclip` | callback do cliente | Pede para ligar o noclip. |
| `ai-admin:players` | callback do cliente | A lista de jogadores online para o menu. |
| `ai-admin:action` | callback do cliente | Uma ação do menu rápido (administrador verificado no servidor). |
| `ai-admin:giveItems` | callback do cliente | Os itens escolhidos no seletor de itens (no máximo 50 linhas). |
| `ai-admin:worldState` | callback do cliente | O clima e a hora para o menu Weather and time. |
| `ai-admin:client:toggleNoclip` | servidor para cliente | Alterna o noclip. |
| `ai-admin:client:teleport` | servidor para cliente | Teleporta para um ponto que o servidor escolheu. |
| `ai-admin:client:openMenu` / `openItems` | servidor para cliente | Abre o menu rápido ou o seletor de itens. |
| `ai-admin:client:coords` | servidor para cliente | Mostra a posição do jogador. |
| `ai-admin:client:warned` | servidor para cliente | Mostra um aviso de administrador. |
