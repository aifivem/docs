ai-admin’in export’u yoktur. Yaptığı her şey AI Core üzerinden gider, bu yüzden aynı çağrılar senin script’ine de açıktır:

| ai-admin aracı | Neyi çağırır (lib, server) |
| --- | --- |
| İyileştirme, diriltme, yerde mi | `medical` (hangi ölüm script’i çalışıyorsa onunla çalışır) |
| Diriltme ihtiyaçları doldurur | `needs.refill` |
| Admin aracı anahtarları, `/givekey` | `vehicleKeys.give(source, vehicle, "temporary")` |
| `/car` | `vehicleType(model, admin)` modeli kontrol ettikten sonra `spawnVehicle` |
| Eşya komutları, envanter açma | `inventory` (hangi envanter çalışıyorsa onunla çalışır) |
| `/items`, menüdeki "Give item" | `itemPicker` |
| Hava, saat, karartma, saati durdurma | `world` (qb-weathersync sözleşmesine uyan her hava script’i) |
| `/closeserver` | ai-core’un `AddConnectionCheck` fonksiyonu |
| Loglar | `aiLog("actions", ...)` |

## Yetki

Her admin komutu `addCommand(..., { restricted: true })` ile kaydedilir; bu ACE `ai.admin` anlamına gelir. Hızlı menünün eylem callback’i server’da `isAdmin()` kontrol eder. Bir oyuncu noclip’i her zaman kapatabilir; açmak server’dan istenir.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify } from "@aicore-fivem/lib/server";

// ai-admin’inkiyle aynı yetkiye sahip, sadece adminlere açık kendi komutun.
addCommand("cleanarea", { help: "Clean the area", restricted: true }, (source) => {
  notify(source, "Area cleaned", "success");
});
```
</Tab>
<Tab value="Lua">
```lua
-- ai-admin’inkiyle aynı yetkiye sahip, sadece adminlere açık kendi komutun.
aiLib.addCommand('cleanarea', { help = 'Clean the area', restricted = true }, function(source)
  aiLib.notify(source, 'Area cleaned', 'success')
end)
```
</Tab>
</Tabs>

## Çağırdığı isteğe bağlı export

Hızlı menünün **Always show the map** seçeneği, ai-hud çalışıyorsa ai-hud’un `SetMinimapAlways(on)` client export’unu çağırır.

## Event’ler

ai-admin’in bütün event’leri dahilidir (kendi client’ı ve server’ı); onları başka script’lerden çağırma.

| Ad | Tür | Ne yapar |
| --- | --- | --- |
| `ai-admin:access` | client callback’i | Oyuncunun hızlı menüyü açıp açamayacağı. |
| `ai-admin:noclip` | client callback’i | Noclip’i açmayı iste. |
| `ai-admin:players` | client callback’i | Menü için çevrim içi oyuncu listesi. |
| `ai-admin:action` | client callback’i | Tek bir hızlı menü eylemi (admin server’da kontrol edilir). |
| `ai-admin:giveItems` | client callback’i | Eşya seçicide seçilen eşyalar (en fazla 50 satır). |
| `ai-admin:worldState` | client callback’i | Weather and time menüsü için hava ve saat. |
| `ai-admin:client:toggleNoclip` | server’dan client’a | Noclip’i değiştir. |
| `ai-admin:client:teleport` | server’dan client’a | Server’ın seçtiği bir noktaya ışınla. |
| `ai-admin:client:openMenu` / `openItems` | server’dan client’a | Hızlı menüyü ya da eşya seçiciyi aç. |
| `ai-admin:client:coords` | server’dan client’a | Oyuncunun konumunu göster. |
| `ai-admin:client:warned` | server’dan client’a | Bir admin uyarısı göster. |
