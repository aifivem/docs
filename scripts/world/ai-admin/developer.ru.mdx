У ai-admin нет экспортов. Всё, что он делает, идёт через AI Core, поэтому те же вызовы доступны вашему собственному скрипту:

| Инструмент ai-admin | Что он вызывает (lib, сервер) |
| --- | --- |
| Лечение, реанимация, проверка без сознания | `medical` (работает с любым запущенным скриптом смерти) |
| Реанимация восполняет потребности | `needs.refill` |
| Ключи от машины администратора, `/givekey` | `vehicleKeys.give(source, vehicle, "temporary")` |
| `/car` | `spawnVehicle` после того, как `vehicleType(model, admin)` проверит модель |
| Команды предметов, открытие инвентаря | `inventory` (работает с любым запущенным инвентарём) |
| `/items`, пункт меню "Give item" | `itemPicker` |
| Погода, время, блэкаут, остановка времени | `world` (любой скрипт погоды с контрактом qb-weathersync) |
| `/closeserver` | `AddConnectionCheck` из ai-core |
| Логи | `aiLog("actions", ...)` |

## Права

Каждая админ-команда регистрируется через `addCommand(..., { restricted: true })`, что означает ACE `ai.admin`. Колбэк действий быстрого меню проверяет `isAdmin()` на сервере. Игрок всегда может выключить noclip; включение запрашивается у сервера.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify } from "@aifivem/lib/server";

// Ваша собственная команда только для администраторов, с теми же правами, что у ai-admin.
addCommand("cleanarea", { help: "Clean the area", restricted: true }, (source) => {
  notify(source, "Area cleaned", "success");
});
```
</Tab>
<Tab value="Lua">
```lua
-- Ваша собственная команда только для администраторов, с теми же правами, что у ai-admin.
aiLib.addCommand('cleanarea', { help = 'Clean the area', restricted = true }, function(source)
  aiLib.notify(source, 'Area cleaned', 'success')
end)
```
</Tab>
</Tabs>

## Необязательный экспорт, который он вызывает

**Always show the map** в быстром меню вызывает клиентский экспорт ai-hud `SetMinimapAlways(on)`, когда ai-hud запущен.

## События

Все события ai-admin внутренние (его клиент и его сервер); не вызывайте их из других скриптов.

| Имя | Тип | Что делает |
| --- | --- | --- |
| `ai-admin:access` | client callback | Может ли игрок открыть быстрое меню. |
| `ai-admin:noclip` | client callback | Запросить включение noclip. |
| `ai-admin:players` | client callback | Список игроков онлайн для меню. |
| `ai-admin:action` | client callback | Одно действие быстрого меню (администратор проверяется на сервере). |
| `ai-admin:giveItems` | client callback | Предметы, выбранные в окне выбора предметов (не больше 50 строк). |
| `ai-admin:worldState` | client callback | Погода и время для меню Weather and time. |
| `ai-admin:client:toggleNoclip` | сервер к клиенту | Переключить noclip. |
| `ai-admin:client:teleport` | сервер к клиенту | Телепорт в точку, выбранную сервером. |
| `ai-admin:client:openMenu` / `openItems` | сервер к клиенту | Открыть быстрое меню или окно выбора предметов. |
| `ai-admin:client:coords` | сервер к клиенту | Показать позицию игрока. |
| `ai-admin:client:warned` | сервер к клиенту | Показать предупреждение администратора. |
