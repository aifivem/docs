ai-admin gibt Admins ihre Werkzeuge im Spiel: ein Schnellmenü (**F9**), Noclip, Teleports, Heilen und Wiederbeleben, Fahrzeuge spawnen und löschen, Items und Inventare, Geld, Jobs und Gangs, Ankündigungen und Verwarnungen, Wetter und Zeit. Die Befehle, die Admins von QBCore und ESX kennen, funktionieren mit denselben Namen und Argumenten.

Jedes Werkzeug wird auf dem Server entschieden: Nur Admins (ACE `ai.admin`, in der Admin-Liste von ai-core vergeben) können sie nutzen. Jede Änderung wird auf dem Kanal `actions` mit dem Admin geloggt, der sie gemacht hat.

## Was es im Spiel macht

- **Schnellmenü (F9).** Noclip an / aus, Teleport zum Wegpunkt, dich selbst heilen oder wiederbeleben, ein Fahrzeug spawnen oder löschen, **Players** (jeder Spieler online: hingehen, herholen, heilen, wiederbeleben, Item geben, Inventar öffnen, verwarnen), Ankündigung, Wetter und Zeit, Karte immer anzeigen und ein Knopf zum Admin-Panel.
- **Noclip.** Durch die Welt fliegen: **W A S D** fliegen, **Q / E** hoch und runter, **Shift** schneller, **Strg** langsamer, **Leertaste** hinunter zum Boden, **V** ändert die Ansicht, das Mausrad ändert die Geschwindigkeitsstufe (ein Klick mit dem Rad setzt sie zurück). Die Tasten erscheinen beim Fliegen im HUD. Noclip hat keine Standardtaste: Belege **Admin: noclip on / off** in den Tasteneinstellungen oder nutze `/noclip`.
- **Admin-Fahrzeug.** `/car` oder das Menü spawnt ein Fahrzeug mit dem Admin auf dem Fahrersitz und den Schlüsseln (vorübergehender Schlüssel). Das vorherige Admin-Auto des Admins wird gelöscht.
- **Wiederbeleben** füllt auch Hunger und Durst, damit der Spieler nicht erneut an einem leeren Bedürfnis stirbt.
- **Verwarnungen.** Eine Verwarnung bleibt mit dem Grund auf dem Bildschirm des Spielers, bis er „I understand“ drückt.
- **Ankündigungen** erscheinen für jeden Spieler als „Announcement: message“ mit dem Stil und der Zeit aus dem Tab Messages.
- **Den Server schließen.** `/closeserver` wirft jeden Spieler ohne Admin-Rechte hinaus und lehnt neue Beitritte ab bis `/openserver` oder zu einem Neustart.

## Installation

Wird vom Rezept von AI Core installiert. Von Hand: `ensure ai-admin` nach `ai-core`.

Für `/addpermission` und `/removepermission` braucht die `permission.cfg` diese Zeilen:

```ini title="permission.cfg"
add_ace resource.ai-admin command.add_principal allow
add_ace resource.ai-admin command.remove_principal allow
```

## Panel-Einstellungen

Admin-Panel > **Admin tools**. Die Tasten für das Schnellmenü (F9) und Noclip werden im Tab **Keybinds** von ai-core eingestellt.

### Tab: Settings

Wie Noclip sich bewegt und womit das Admin-Auto kommt.

**Noclip**: Geschwindigkeitsstufen beim Fliegen: Das Mausrad ändert die Stufe, ein Klick mit dem Rad setzt sie zurück, Shift, Alt und Strg multiplizieren sie, solange gehalten.

| Einstellung | Was sie ändert | Einheit | Standard |
| --- | --- | --- | --- |
| Start speed | Geschwindigkeitsstufe, wenn Noclip startet und nach einem Klick mit dem Rad. 0.1-50. | | 1 |
| Highest speed | Das Mausrad hält bei dieser Stufe an. 1-100. | | 16 |
| Wheel step | Stufenänderung pro Raste des Mausrads; auch die niedrigste Stufe. 0.1-10. | | 0.5 |
| Shift | Geschwindigkeitsmultiplikator, solange Shift gehalten wird. 1-20. | x | 2 |
| Alt | Geschwindigkeitsmultiplikator, solange Alt gehalten wird. 1-50. | x | 4 |
| Ctrl | Geschwindigkeitsmultiplikator, solange Strg gehalten wird (unter 1 verlangsamt). 0.01-1. | x | 0.05 |

**Admin vehicle** (Admin-Fahrzeug): womit ein mit /car oder dem Admin-Menü gespawntes Fahrzeug kommt. Der Admin sitzt immer mit den Schlüsseln auf dem Fahrersitz.

| Einstellung | Was sie ändert | Einheit | Standard |
| --- | --- | --- | --- |
| Fully upgraded | Motor, Bremsen, Getriebe, Fahrwerk und Panzerung auf höchster Stufe, Turbo und Xenon an. | an / aus | aus |
| Fuel | 0-100, in Schritten von 5. | % | 100 |
| Engine running | Der Motor läuft schon, wenn der Admin einsteigt. | an / aus | an |

### Tab: Messages

Eine Ankündigung an alle oder eine Verwarnung an einen Spieler senden. Jede Nachricht wird mit dem Admin geloggt, der sie gesendet hat.

**Announcement** (Ankündigung): eine Benachrichtigung, die jeder Spieler sieht. Stil und Zeit gelten auch für /announce und das Schnellmenü (F9).

| Einstellung | Was sie ändert | Standard |
| --- | --- | --- |
| Message | Bis zu 300 Zeichen; angezeigt als „Announcement: message“. | |
| Style | **Info**, **Success**, **Warning** oder **Error**: Farbe und Symbol der Benachrichtigung. | Warning |
| Time on screen | Sekunden, die die Ankündigung bleibt. 2-60. | 10 |
| Send now | Sendet die Nachricht an alle; das Nachrichtenfeld wird danach geleert. Eine leere Nachricht wird abgelehnt. | |

**Warning** (Verwarnung): eine Admin-Verwarnung für einen Spieler online: Sie bleibt auf seinem Bildschirm, bis er sie bestätigt. Auch im Schnellmenü (F9) > Players.

| Einstellung | Was sie ändert |
| --- | --- |
| Player | Spieler, die online waren, als das Panel geöffnet wurde; öffne das Panel erneut für Spieler, die seitdem beigetreten sind. Du kannst dich nicht selbst verwarnen. |
| Reason | Was der Spieler falsch gemacht hat, bis zu 300 Zeichen; der Spieler liest es so, wie es geschrieben ist. Pflicht. |
| Send now | Sendet die Verwarnung an den Spieler; das Formular wird danach geleert. |

### Tab: World

Wetter und Zeit für alle, über das laufende Wetterskript. Eine Änderung gilt sofort; das Wetterskript kann das Wetter später von selbst ändern. Änderungen werden abgelehnt, solange kein Wetterskript läuft.

**Weather** (Wetter): zeigt, was ein Admin zuletzt gesetzt hat (hier, mit /weather oder im Schnellmenü).

| Einstellung | Was sie ändert | Standard |
| --- | --- | --- |
| Weather | Eine Auswahl setzt es sofort für alle: Extra sunny, Clear, Neutral, Smog, Foggy, Overcast, Clouds, Clearing, Rain, Thunder, Snow, Blizzard, Light snow, Christmas snow, Halloween. | Not set by an admin |
| Blackout | Die Lichter der Stadt für alle aus. | aus |

**Time** (Zeit): Eine Änderung von Stunde oder Minute stellt die Uhr für alle; sie läuft weiter, sofern sie nicht angehalten ist.

| Einstellung | Was sie ändert | Einheit | Standard |
| --- | --- | --- | --- |
| Hour | 0 bis 23. | h | 12 |
| Minute | 0 bis 59, in Schritten von 5. | min | 0 |
| Stop the clock | Die Zeit bleibt stehen, bis es ausgeschaltet wird. | an / aus | aus |

## Befehle

`<x>` ist Pflicht, `[x]` ist optional. `id` ist die Server-ID eines Spielers. Jeder Befehl ist für Admins (ACE `ai.admin`), sofern die Tabelle nichts anderes sagt.

### Bewegung und Spieler

| Befehl | Argumente | Was er macht |
| --- | --- | --- |
| `/noclip` | | Noclip an oder aus. |
| `/tpm` | | Teleport zum Wegpunkt. |
| `/tp` | `<coords>`: `x y z`, `x, y, z` oder `x y` (auf den Boden) | Teleport zu Koordinaten. |
| `/goto` | `<id>` | Teleport zu einem Spieler. |
| `/bring` | `<id>` | Einen Spieler zu dir holen. |
| `/heal` | `[id]` (leer: du selbst) | Volle Gesundheit. Ein Spieler am Boden muss stattdessen wiederbelebt werden. |
| `/revive` | `[id]` (leer: du selbst) | Wiederbeleben und heilen; füllt auch Hunger und Durst. |
| `/coords` | | Deine Position anzeigen (auch in F8 ausgegeben). |

### Fahrzeuge

| Befehl | Argumente | Was er macht |
| --- | --- | --- |
| `/car` | `<model>` (zum Beispiel `adder`) | Ein Fahrzeug spawnen und einsteigen. |
| `/dv` | | Das Fahrzeug löschen, in dem du sitzt oder neben dem du stehst. |
| `/givekey` | `[id]` (leer: du selbst) | Die Schlüssel des Fahrzeugs geben, in dem du sitzt oder neben dem du stehst. |
| `/dvall` | | Jedes Fahrzeug löschen, in dem niemand sitzt. |
| `/dvp` | | Jeden Ped löschen, der kein Spieler ist. |
| `/dvo` | | Jedes Objekt löschen. |

### Items und Geld

| Befehl | Argumente | Was er macht |
| --- | --- | --- |
| `/giveitem` | `<id> <item> [count]` (count standardmäßig 1) | Einem Spieler ein Item geben. |
| `/removeitem` | `<id> <item> [count]` (ohne count: alles davon) | Einem Spieler ein Item nehmen. |
| `/clearinv` | `<id>` | Das Inventar eines Spielers leeren. |
| `/openinv` | `<id>` | Das Inventar eines Spielers öffnen. |
| `/items` | | Die Item-Liste öffnen und Items nehmen. |
| `/givemoney` (`/giveaccountmoney`) | `<id> <account> <amount>` (account: cash, bank...) | Einem Spieler Geld auf ein Konto geben. |
| `/setmoney` (`/setaccountmoney`) | `<id> <account> <amount>` | Das Kontoguthaben eines Spielers setzen. |

### Jobs, Gangs und Berechtigungen

| Befehl | Argumente | Wer | Was er macht |
| --- | --- | --- | --- |
| `/setjob` | `<id> <job> <grade>` (grade 0 = niedrigster) | Admins | Einem Spieler einen Job und Rang geben (`unemployed` nimmt jeden Job weg). |
| `/setgang` | `<id> <gang> <grade>` | Admins | Einem Spieler eine Gang und einen Rang geben (`none` nimmt jede Gang weg). |
| `/job` | | alle | Deinen Job und Rang anzeigen. |
| `/gang` | | alle | Deine Gang und deinen Rang anzeigen. |
| `/addpermission` | `<id> <permission>` (admin, mod, god) | Admins | Einen Spieler in eine Berechtigungsgruppe setzen, bis er geht (`group.<permission>`). |
| `/removepermission` | `<id> <permission>` | Admins | Einen Spieler aus einer Berechtigungsgruppe nehmen. |

### Server, Nachrichten und Welt

| Befehl | Argumente | Was er macht |
| --- | --- | --- |
| `/admin` | | Das Admin-Panel öffnen (ein kürzerer Name für `/aiadmin` von ai-core). |
| `/adminmenu` | | Das Admin-Schnellmenü öffnen. |
| `/announce` | `<message>` | Eine Nachricht an alle ankündigen. |
| `/weather` | `<type>`: EXTRASUNNY, CLEAR, CLOUDS, RAIN, THUNDER, SNOW, XMAS... | Das Wetter für alle setzen. |
| `/time` | `<hour> [minute]` (0-23, 0-59) | Die Tageszeit setzen. |
| `/blackout` | `<on>`: 1 = an, 0 = aus | Die Lichter der Stadt aus- (1) oder einschalten (0). |
| `/freezetime` | `<on>`: 1 = an, 0 = aus | Die Uhr anhalten (1) oder laufen lassen (0). |
| `/closeserver` | `[reason]` | Den Server schließen: Spieler ohne Admin-Rechte werden hinausgeworfen und können nicht beitreten. Bleibt über einen Neustart nicht erhalten. |
| `/openserver` | | Den Server wieder öffnen. |

`/togglepvp` (der Befehl von QB) gehört zu ai-core: Er schaltet die PvP-Einstellung von ai-core um.

## Tastenbelegungen

| Standardtaste | Was sie macht |
| --- | --- |
| F9 | Admin: Schnellmenü |
| keine | Admin: Noclip an / aus (belege sie selbst, oder der Betreiber setzt im Tab Keybinds von ai-core einen Standard) |

## Bekannte Grenzen

- `/addpermission` gilt, bis der Spieler geht (wie bei QB). Dauerhafte Admins kommen in die Admin-Liste von ai-core.
- `/heal` bei einem Spieler am Boden bringt ihn nicht auf die Beine: Nutze `/revive`.
- Der Tab World zeigt, was ein Admin zuletzt gesetzt hat, nicht, was das Wetterskript später geändert hat.
