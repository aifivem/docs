ai-admin nie ma eksportów. Wszystko, co robi, przechodzi przez AI Core, więc te same wywołania są dostępne dla twojego własnego skryptu:

| Narzędzie ai-admin | Co wywołuje (biblioteka, serwer) |
| --- | --- |
| Leczenie, reanimacja, czy powalony | `medical` (działa z każdym działającym skryptem śmierci) |
| Reanimacja uzupełnia potrzeby | `needs.refill` |
| Klucze do aut administratora, `/givekey` | `vehicleKeys.give(source, vehicle, "temporary")` |
| `/car` | `spawnVehicle` po sprawdzeniu modelu przez `vehicleType(model, admin)` |
| Komendy przedmiotów, otwieranie ekwipunku | `inventory` (działa z każdym działającym ekwipunkiem) |
| `/items`, menu „Give item” | `itemPicker` |
| Pogoda, czas, blackout, zamrożenie | `world` (każdy skrypt pogody z kontraktem qb-weathersync) |
| `/closeserver` | `AddConnectionCheck` z ai-core |
| Logi | `aiLog("actions", ...)` |

## Uprawnienia

Każda komenda administracyjna jest rejestrowana przez `addCommand(..., { restricted: true })`, co oznacza ACE `ai.admin`. Callback akcji szybkiego menu sprawdza `isAdmin()` na serwerze. Gracz zawsze może wyłączyć noclip; o włączenie prosi się serwer.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify } from "@aicore-fivem/lib/server";

// Twoja własna komenda tylko dla administratorów, z tym samym uprawnieniem co w ai-admin.
addCommand("cleanarea", { help: "Clean the area", restricted: true }, (source) => {
  notify(source, "Area cleaned", "success");
});
```
</Tab>
<Tab value="Lua">
```lua
-- Twoja własna komenda tylko dla administratorów, z tym samym uprawnieniem co w ai-admin.
aiLib.addCommand('cleanarea', { help = 'Clean the area', restricted = true }, function(source)
  aiLib.notify(source, 'Area cleaned', 'success')
end)
```
</Tab>
</Tabs>

## Opcjonalny eksport, który wywołuje

**Always show the map** w szybkim menu wywołuje eksport klienta ai-hud `SetMinimapAlways(on)`, gdy działa ai-hud.

## Zdarzenia

Wszystkie zdarzenia ai-admin są wewnętrzne (jego klient i jego serwer); nie wywołuj ich z innych skryptów.

| Nazwa | Rodzaj | Co robi |
| --- | --- | --- |
| `ai-admin:access` | callback klienta | Czy gracz może otworzyć szybkie menu. |
| `ai-admin:noclip` | callback klienta | Prośba o włączenie noclipa. |
| `ai-admin:players` | callback klienta | Lista graczy online do menu. |
| `ai-admin:action` | callback klienta | Jedna akcja szybkiego menu (administrator sprawdzany na serwerze). |
| `ai-admin:giveItems` | callback klienta | Przedmioty wybrane w wyborze przedmiotów (najwyżej 50 wierszy). |
| `ai-admin:worldState` | callback klienta | Pogoda i czas dla menu Weather and time. |
| `ai-admin:client:toggleNoclip` | serwer do klienta | Przełącz noclip. |
| `ai-admin:client:teleport` | serwer do klienta | Teleport do punktu wybranego przez serwer. |
| `ai-admin:client:openMenu` / `openItems` | serwer do klienta | Otwórz szybkie menu lub wybór przedmiotów. |
| `ai-admin:client:coords` | serwer do klienta | Pokaż pozycję gracza. |
| `ai-admin:client:warned` | serwer do klienta | Pokaż ostrzeżenie administratora. |
