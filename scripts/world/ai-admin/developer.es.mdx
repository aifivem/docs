ai-admin no tiene exports. Todo lo que hace pasa por AI Core, así que las mismas llamadas están disponibles para tu propio script:

| Herramienta de ai-admin | Lo que llama (lib, servidor) |
| --- | --- |
| Curar, reanimar, está abatido | `medical` (funciona con el script de muerte que esté en uso) |
| Reanimar llena las necesidades | `needs.refill` |
| Llaves del coche de administrador, `/givekey` | `vehicleKeys.give(source, vehicle, "temporary")` |
| `/car` | `spawnVehicle` después de que `vehicleType(model, admin)` compruebe el modelo |
| Comandos de objetos, abrir inventario | `inventory` (funciona con el inventario que esté en uso) |
| `/items`, "Give item" del menú | `itemPicker` |
| Clima, hora, apagón, detener el reloj | `world` (cualquier script de clima con el contrato de qb-weathersync) |
| `/closeserver` | `AddConnectionCheck` de ai-core |
| Logs | `aiLog("actions", ...)` |

## Permiso

Cada comando de administración se registra con `addCommand(..., { restricted: true })`, lo que significa ACE `ai.admin`. El callback de acciones del menú rápido comprueba `isAdmin()` en el servidor. Un jugador siempre puede desactivar el noclip; activarlo se pide al servidor.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify } from "@aifivem/lib/server";

// Tu propio comando solo para administradores, con el mismo permiso que los de ai-admin.
addCommand("cleanarea", { help: "Clean the area", restricted: true }, (source) => {
  notify(source, "Area cleaned", "success");
});
```
</Tab>
<Tab value="Lua">
```lua
-- Tu propio comando solo para administradores, con el mismo permiso que los de ai-admin.
aiLib.addCommand('cleanarea', { help = 'Clean the area', restricted = true }, function(source)
  aiLib.notify(source, 'Area cleaned', 'success')
end)
```
</Tab>
</Tabs>

## Export opcional que llama

**Always show the map** del menú rápido llama al export de cliente `SetMinimapAlways(on)` de ai-hud cuando ai-hud está en marcha.

## Eventos

Todos los eventos de ai-admin son internos (su cliente y su servidor); no los llames desde otros scripts.

| Nombre | Tipo | Qué hace |
| --- | --- | --- |
| `ai-admin:access` | callback de cliente | Si el jugador puede abrir el menú rápido. |
| `ai-admin:noclip` | callback de cliente | Pedir activar el noclip. |
| `ai-admin:players` | callback de cliente | La lista de jugadores conectados para el menú. |
| `ai-admin:action` | callback de cliente | Una acción del menú rápido (el administrador se comprueba en el servidor). |
| `ai-admin:giveItems` | callback de cliente | Los objetos elegidos en el selector de objetos (como mucho 50 filas). |
| `ai-admin:worldState` | callback de cliente | El clima y la hora para el menú de clima y hora. |
| `ai-admin:client:toggleNoclip` | servidor a cliente | Cambiar el noclip. |
| `ai-admin:client:teleport` | servidor a cliente | Teletransportar a un punto que eligió el servidor. |
| `ai-admin:client:openMenu` / `openItems` | servidor a cliente | Abrir el menú rápido o el selector de objetos. |
| `ai-admin:client:coords` | servidor a cliente | Mostrar la posición del jugador. |
| `ai-admin:client:warned` | servidor a cliente | Mostrar una advertencia de administrador. |
