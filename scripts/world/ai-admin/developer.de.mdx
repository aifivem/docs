ai-admin hat keine Exports. Alles, was es tut, läuft über AI Core, daher stehen dieselben Aufrufe auch deinem eigenen Skript offen:

| Werkzeug von ai-admin | Was es aufruft (Lib, Server) |
| --- | --- |
| Heilen, wiederbeleben, ist am Boden | `medical` (funktioniert mit jedem laufenden Todesskript) |
| Wiederbeleben füllt Bedürfnisse | `needs.refill` |
| Schlüssel des Admin-Autos, `/givekey` | `vehicleKeys.give(source, vehicle, "temporary")` |
| `/car` | `spawnVehicle`, nachdem `vehicleType(model, admin)` das Modell geprüft hat |
| Item-Befehle, Inventar öffnen | `inventory` (funktioniert mit jedem laufenden Inventar) |
| `/items`, Menü „Give item“ | `itemPicker` |
| Wetter, Zeit, Stromausfall, Uhr anhalten | `world` (jedes Wetterskript mit dem Vertrag von qb-weathersync) |
| `/closeserver` | `AddConnectionCheck` von ai-core |
| Logs | `aiLog("actions", ...)` |

## Berechtigung

Jeder Admin-Befehl wird mit `addCommand(..., { restricted: true })` registriert, was ACE `ai.admin` bedeutet. Der Aktions-Callback des Schnellmenüs prüft `isAdmin()` auf dem Server. Ein Spieler kann Noclip immer ausschalten; das Einschalten wird beim Server angefragt.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify } from "@aicore-fivem/lib/server";

// Dein eigener Befehl nur für Admins, mit derselben Berechtigung wie die von ai-admin.
addCommand("cleanarea", { help: "Clean the area", restricted: true }, (source) => {
  notify(source, "Area cleaned", "success");
});
```
</Tab>
<Tab value="Lua">
```lua
-- Dein eigener Befehl nur für Admins, mit derselben Berechtigung wie die von ai-admin.
aiLib.addCommand('cleanarea', { help = 'Clean the area', restricted = true }, function(source)
  aiLib.notify(source, 'Area cleaned', 'success')
end)
```
</Tab>
</Tabs>

## Optionaler Export, den es aufruft

**Always show the map** im Schnellmenü ruft den Client-Export `SetMinimapAlways(on)` von ai-hud auf, wenn ai-hud läuft.

## Events

Alle Events von ai-admin sind intern (sein Client und sein Server); rufe sie nicht aus anderen Skripten auf.

| Name | Art | Was es macht |
| --- | --- | --- |
| `ai-admin:access` | Client-Callback | Ob der Spieler das Schnellmenü öffnen darf. |
| `ai-admin:noclip` | Client-Callback | Anfrage, Noclip einzuschalten. |
| `ai-admin:players` | Client-Callback | Die Liste der Spieler online für das Menü. |
| `ai-admin:action` | Client-Callback | Eine Aktion des Schnellmenüs (Admin auf dem Server geprüft). |
| `ai-admin:giveItems` | Client-Callback | Die in der Item-Auswahl gewählten Items (höchstens 50 Zeilen). |
| `ai-admin:worldState` | Client-Callback | Wetter und Zeit für das Menü Weather and time. |
| `ai-admin:client:toggleNoclip` | Server an Client | Noclip umschalten. |
| `ai-admin:client:teleport` | Server an Client | Zu einem Punkt teleportieren, den der Server gewählt hat. |
| `ai-admin:client:openMenu` / `openItems` | Server an Client | Das Schnellmenü oder die Item-Auswahl öffnen. |
| `ai-admin:client:coords` | Server an Client | Die Position des Spielers anzeigen. |
| `ai-admin:client:warned` | Server an Client | Eine Admin-Verwarnung anzeigen. |
