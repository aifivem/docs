ai-properties sells houses and apartments. A player buys one at its front door, gets a private copy of its interior, a stash, and can hand keys to other characters.

## What it does in the game

- **Buying.** At a property's door, a free property shows **Name: for sale, $price**. Press the interact key and pick **Buy for $...**. The price is taken from the panel's money account (bank by default).
- **Entering.** Owners and key holders see **Enter ...** at the door. Everyone else sees **... (locked)**. The screen fades and you are inside your own copy of the interior: other owners of the same interior are in their own copies and never meet you.
- **Inside.** At the entry point, **Property menu** opens: **Go outside**, **Open the stash**, **Keys** (owner only) and **Sell the property** (owner only).
- **Keys.** The owner gives a key to the person standing next to them inside the property (**Give a key to the person next to you**), and takes keys back from the list (**Take the key back**). The list shows holders even when they are offline.
- **Stash.** Owners and key holders open the same stash. A new buyer starts with an empty stash: the stash belongs to the property and its owner.
- **Selling.** The owner sells from the property menu (**Yes, sell it**) and gets back the panel's share of the price.
- **Police.** With the panel switch on, on-duty police (the panel's police jobs) can enter any owned property.
- **Logging out inside.** A character who leaves the game inside a property comes back at its front door.
- **Map.** Owners and key holders see their properties on the map. Properties for sale show only if their map switch is on.

## Installation

Installed by the AI Core recipe. By hand: `ensure ai-properties` after `ai-core`. The tables `ai_properties_owned` and `ai_properties_keys` are created on the first start.

Default content: six apartments (Grove Street 1, South Rockford Drive, Morningwood Blvd, Integrity Way, Tinsel Towers, Fantastic Plaza) and two interiors (Small apartment, Apartment).

## Panel settings

Admin panel > **Properties**.

### Tab: Properties

Houses and apartments players buy at their door. One record per property (**New property** / **Delete property**). Deleting a property whose owner still has it keeps the database row until it is sold.

**Property** card: each property is a private copy of its interior.

| Setting | What it changes | Unit | Default for new |
| --- | --- | --- | --- |
| Name | Shown at the door and on the map. 1-48 characters. | | |
| Door | Stand at the front door, facing out: players leave here. | point + heading | |
| Interior | The id of an interior from the Interiors tab (`low`, `medium`...). | | low |
| Price | 0-1,000,000,000. | $ | 50,000 |
| Show on the map while for sale | Owners always see their own properties. | on / off | off |

### Tab: Interiors

Places players are taken to inside a property. One record per interior (**New interior** / **Delete interior**). Properties using a deleted interior can no longer be entered.

**Interior** card: the property menu (exit, stash, keys, sell) is at the entry point.

| Setting | What it changes |
| --- | --- |
| Name | The interior's name (1-48 characters). |
| Entry point | Where players appear inside, and where the property menu is. |

### Tab: Settings

Money, stash size and police access. Used by every property.

| Setting | What it changes | Unit | Default |
| --- | --- | --- | --- |
| Money account | Purchases take from and sales pay into this account. | | bank |
| Sale refund | Share of the price paid back when the owner sells. 0-100. | % | 50 |
| Stash slots | 1-200. | | 40 |
| Stash weight | In grams (150000 = 150 kg). 1,000-10,000,000. | g | 150,000 |
| Police can enter | On-duty police enter any owned property. | on / off | on |
| Police jobs | The jobs that count as police for entering (up to 10). | | police |
| Own property blip | How owners and key holders see their properties on the map (icon, color, size). | | icon 40, color 3, size 0.65 |
| For sale blip | Properties for sale with the map switch on. | | icon 40, color 3, size 0.65 |

## Commands and keybinds

None. Doors and the property menu use the interact key (**E** by default). Get out of a vehicle before using a door.

## Known limits

- Only one account pays for a property: the whole price must be in it.
- Key holders' names are stored when the key is given; a renamed character shows its old name in the owner's key list.
- A property has one owner. There is no rent or shared ownership.
