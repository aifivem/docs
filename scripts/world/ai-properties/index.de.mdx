ai-properties verkauft Häuser und Wohnungen. Ein Spieler kauft eine an ihrer Haustür, bekommt eine private Kopie ihres Innenraums und ein Lager und kann anderen Charakteren Schlüssel geben.

## Was es im Spiel macht

- **Kaufen.** An der Tür einer Immobilie zeigt eine freie Immobilie **Name: for sale, $price**. Drücke die Interaktionstaste und wähle **Buy for $...**. Der Preis wird vom Geldkonto aus dem Panel abgebucht (standardmäßig Bank).
- **Betreten.** Besitzer und Schlüsselinhaber sehen an der Tür **Enter ...**. Alle anderen sehen **... (locked)**. Der Bildschirm wird ausgeblendet, und du bist in deiner eigenen Kopie des Innenraums: Andere Besitzer desselben Innenraums sind in ihren eigenen Kopien und begegnen dir nie.
- **Drinnen.** Am Eintrittspunkt öffnet sich **Property menu**: **Go outside**, **Open the stash**, **Keys** (nur Besitzer) und **Sell the property** (nur Besitzer).
- **Schlüssel.** Der Besitzer gibt der Person, die drinnen neben ihm steht, einen Schlüssel (**Give a key to the person next to you**) und nimmt Schlüssel aus der Liste zurück (**Take the key back**). Die Liste zeigt Inhaber auch, wenn sie offline sind.
- **Lager.** Besitzer und Schlüsselinhaber öffnen dasselbe Lager. Ein neuer Käufer beginnt mit einem leeren Lager: Das Lager gehört zur Immobilie und ihrem Besitzer.
- **Verkaufen.** Der Besitzer verkauft über das Immobilienmenü (**Yes, sell it**) und bekommt den Anteil des Preises aus dem Panel zurück.
- **Polizei.** Mit eingeschaltetem Panel-Schalter kann Polizei im Dienst (die Polizeijobs aus dem Panel) jede Immobilie im Besitz betreten.
- **Drinnen ausloggen.** Ein Charakter, der das Spiel in einer Immobilie verlässt, kommt an ihrer Haustür zurück.
- **Karte.** Besitzer und Schlüsselinhaber sehen ihre Immobilien auf der Karte. Zum Verkauf stehende Immobilien erscheinen nur, wenn ihr Kartenschalter an ist.

## Installation

Wird vom Rezept von AI Core installiert. Von Hand: `ensure ai-properties` nach `ai-core`. Die Tabellen `ai_properties_owned` und `ai_properties_keys` werden beim ersten Start angelegt.

Standardinhalt: sechs Wohnungen (Grove Street 1, South Rockford Drive, Morningwood Blvd, Integrity Way, Tinsel Towers, Fantastic Plaza) und zwei Innenräume (Small apartment, Apartment).

## Panel-Einstellungen

Admin-Panel > **Properties**.

### Tab: Properties

Häuser und Wohnungen, die Spieler an ihrer Tür kaufen. Ein Datensatz pro Immobilie (**New property** / **Delete property**). Das Löschen einer Immobilie, die ihr Besitzer noch hat, behält die Datenbankzeile, bis sie verkauft wird.

Karte **Property**: Jede Immobilie ist eine private Kopie ihres Innenraums.

| Einstellung | Was sie ändert | Einheit | Standard für neue |
| --- | --- | --- | --- |
| Name | Wird an der Tür und auf der Karte angezeigt. 1-48 Zeichen. | | |
| Door | Stell dich an die Haustür, mit Blick nach draußen: Spieler gehen hier hinaus. | Punkt + Ausrichtung | |
| Interior | Die ID eines Innenraums aus dem Tab Interiors (`low`, `medium`...). | | low |
| Price | 0-1.000.000.000. | $ | 50.000 |
| Show on the map while for sale | Besitzer sehen ihre eigenen Immobilien immer. | an / aus | aus |

### Tab: Interiors

Orte, an die Spieler in einer Immobilie gebracht werden. Ein Datensatz pro Innenraum (**New interior** / **Delete interior**). Immobilien, die einen gelöschten Innenraum nutzen, können nicht mehr betreten werden.

Karte **Interior**: Das Immobilienmenü (verlassen, Lager, Schlüssel, verkaufen) liegt am Eintrittspunkt.

| Einstellung | Was sie ändert |
| --- | --- |
| Name | Der Name des Innenraums (1-48 Zeichen). |
| Entry point | Wo Spieler drinnen erscheinen und wo das Immobilienmenü ist. |

### Tab: Settings

Geld, Lagergröße und Polizeizugang. Wird von jeder Immobilie genutzt.

| Einstellung | Was sie ändert | Einheit | Standard |
| --- | --- | --- | --- |
| Money account | Käufe werden von diesem Konto abgebucht und Verkäufe darauf gezahlt. | | bank |
| Sale refund | Anteil des Preises, der beim Verkauf durch den Besitzer zurückgezahlt wird. 0-100. | % | 50 |
| Stash slots | 1-200. | | 40 |
| Stash weight | In Gramm (150000 = 150 kg). 1.000-10.000.000. | g | 150.000 |
| Police can enter | Polizei im Dienst betritt jede Immobilie im Besitz. | an / aus | an |
| Police jobs | Die Jobs, die beim Betreten als Polizei gelten (bis zu 10). | | police |
| Own property blip | Wie Besitzer und Schlüsselinhaber ihre Immobilien auf der Karte sehen (Symbol, Farbe, Größe). | | Symbol 40, Farbe 3, Größe 0.65 |
| For sale blip | Zum Verkauf stehende Immobilien mit eingeschaltetem Kartenschalter. | | Symbol 40, Farbe 3, Größe 0.65 |

## Befehle und Tastenbelegungen

Keine. Türen und das Immobilienmenü nutzen die Interaktionstaste (standardmäßig **E**). Steig aus dem Fahrzeug, bevor du eine Tür benutzt.

## Bekannte Grenzen

- Nur ein Konto bezahlt eine Immobilie: Der ganze Preis muss darauf sein.
- Die Namen der Schlüsselinhaber werden gespeichert, wenn der Schlüssel vergeben wird; ein umbenannter Charakter erscheint in der Schlüsselliste des Besitzers mit seinem alten Namen.
- Eine Immobilie hat einen Besitzer. Es gibt keine Miete und kein gemeinsames Eigentum.
