ai-properties продаёт дома и квартиры. Игрок покупает жильё у входной двери, получает отдельную копию его интерьера, тайник и может раздавать ключи другим персонажам.

## Что он делает в игре

- **Покупка.** У двери свободного жилья показывается **Name: for sale, $price**. Нажмите клавишу взаимодействия и выберите **Buy for $...**. Цена списывается с денежного счёта из панели (по умолчанию банк).
- **Вход.** Владельцы и владельцы ключей видят у двери **Enter ...**. Все остальные видят **... (locked)**. Экран затемняется, и вы внутри своей собственной копии интерьера: другие владельцы того же интерьера находятся в своих копиях и никогда с вами не встречаются.
- **Внутри.** В точке входа **Property menu** открывает: **Go outside**, **Open the stash**, **Keys** (только владелец) и **Sell the property** (только владелец).
- **Ключи.** Владелец даёт ключ человеку, который стоит рядом с ним внутри жилья (**Give a key to the person next to you**), и забирает ключи из списка (**Take the key back**). Список показывает владельцев ключей, даже когда они офлайн.
- **Тайник.** Владельцы и владельцы ключей открывают один и тот же тайник. Новый покупатель начинает с пустым тайником: тайник принадлежит жилью и его владельцу.
- **Продажа.** Владелец продаёт из меню жилья (**Yes, sell it**) и получает обратно долю цены из панели.
- **Полиция.** При включённом переключателе панели полиция на дежурстве (полицейские работы из панели) может войти в любое жильё, у которого есть владелец.
- **Выход из игры внутри.** Персонаж, который выходит из игры внутри жилья, возвращается к его входной двери.
- **Карта.** Владельцы и владельцы ключей видят своё жильё на карте. Жильё на продажу показывается, только если включён его переключатель карты.

## Установка

Устанавливается рецептом AI Core. Вручную: `ensure ai-properties` после `ai-core`. Таблицы `ai_properties_owned` и `ai_properties_keys` создаются при первом запуске.

Содержимое по умолчанию: шесть квартир (Grove Street 1, South Rockford Drive, Morningwood Blvd, Integrity Way, Tinsel Towers, Fantastic Plaza) и два интерьера (Small apartment, Apartment).

## Настройки панели

Админ-панель > **Properties**.

### Вкладка Properties

Дома и квартиры, которые игроки покупают у их двери. Одна запись на жильё (**New property** / **Delete property**). При удалении жилья, которое всё ещё принадлежит владельцу, строка в базе данных остаётся, пока его не продадут.

Карточка **Property**: каждое жильё является отдельной копией своего интерьера.

| Настройка | Что меняет | Единица | По умолчанию для новых |
| --- | --- | --- | --- |
| Name | Показывается у двери и на карте. 1-48 символов. | | |
| Door | Встаньте у входной двери лицом наружу: здесь игроки выходят. | точка + направление | |
| Interior | Id интерьера из вкладки Interiors (`low`, `medium`...). | | low |
| Price | 0-1,000,000,000. | $ | 50,000 |
| Show on the map while for sale | Владельцы всегда видят своё жильё. | вкл. / выкл. | выкл. |

### Вкладка Interiors

Места, куда игроки попадают внутри жилья. Одна запись на интерьер (**New interior** / **Delete interior**). В жильё, которое использует удалённый интерьер, больше нельзя войти.

Карточка **Interior**: меню жилья (выход, тайник, ключи, продажа) находится в точке входа.

| Настройка | Что меняет |
| --- | --- |
| Name | Название интерьера (1-48 символов). |
| Entry point | Где игроки появляются внутри и где находится меню жилья. |

### Вкладка Settings

Деньги, размер тайника и доступ полиции. Используется для каждого жилья.

| Настройка | Что меняет | Единица | По умолчанию |
| --- | --- | --- | --- |
| Money account | Покупки списываются с этого счёта, а продажи выплачиваются на него. | | bank |
| Sale refund | Доля цены, которая возвращается, когда владелец продаёт. 0-100. | % | 50 |
| Stash slots | 1-200. | | 40 |
| Stash weight | В граммах (150000 = 150 кг). 1,000-10,000,000. | г | 150,000 |
| Police can enter | Полиция на дежурстве входит в любое жильё, у которого есть владелец. | вкл. / выкл. | вкл. |
| Police jobs | Работы, которые считаются полицией для входа (до 10). | | police |
| Own property blip | Как владельцы и владельцы ключей видят своё жильё на карте (иконка, цвет, размер). | | иконка 40, цвет 3, размер 0.65 |
| For sale blip | Жильё на продажу с включённым переключателем карты. | | иконка 40, цвет 3, размер 0.65 |

## Команды и привязки клавиш

Нет. Двери и меню жилья используют клавишу взаимодействия (по умолчанию **E**). Выйдите из транспорта, прежде чем использовать дверь.

## Известные ограничения

- За жильё платит только один счёт: вся цена должна быть на нём.
- Имена владельцев ключей сохраняются при выдаче ключа; переименованный персонаж показывается со старым именем в списке ключей владельца.
- У жилья один владелец. Аренды и совместного владения нет.
