ai-exitsleeping hat einen Server-Export, drei Client-Exports und vier lokale Hook-Events (die bearbeitbaren Hooks des Originalskripts). Keiner ist in `@aifivem/shared` typisiert: In TypeScript rufst du sie mit `callExport` auf.

## Server-Exports

### AddCreateCheck

Fügt eine Prüfung hinzu, die läuft, wenn ein Spieler sich ausloggt. Gib `false` zurück, um keinen schlafenden Körper zu hinterlassen (eine Wohnung, eine Event-Zone, ein Gefängnis). Nutze sie, wenn dein Skript Orte kennt, an denen kein Körper bleiben darf.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
AddCreateCheck(id: string, check: (source: number, charId: number, coords: { x: number; y: number; z: number; heading: number }) => boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:AddCreateCheck(id, function(source, charId, coords) return true end)
```

#### Parameter

<TypeTable
  type={{
    id: { type: 'string', description: 'Ein Name für deine Prüfung. Dieselbe ID erneut hinzuzufügen ersetzt die alte Prüfung. Eine leere ID wird ignoriert.', required: true },
    check: { type: '(source, charId, coords) => boolean', description: 'Wird mit der Server-ID, der Charakter-ID und der Position des Spielers beim Ausloggen aufgerufen. Gib `false` zurück, um keinen Körper zu hinterlassen.', required: true },
  }}
/>

#### Rückgabewert

Nichts. Die Prüfung wird von selbst entfernt, wenn deine Ressource stoppt.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

// Keine schlafenden Körper in der Event-Arena (200 m um ihre Mitte).
const ARENA = { x: -324.0, y: -1968.0, z: 21.6 };
callExport("ai-exitsleeping", "AddCreateCheck", "arena",
  (_source: number, _charId: number, c: { x: number; y: number; z: number }) =>
    Math.hypot(c.x - ARENA.x, c.y - ARENA.y) > 200,
);
```
</Tab>
<Tab value="Lua">
```lua
-- Keine schlafenden Körper in der Event-Arena (200 m um ihre Mitte).
local ARENA = vector3(-324.0, -1968.0, 21.6)
exports['ai-exitsleeping']:AddCreateCheck('arena', function(source, charId, coords)
  return #(vector3(coords.x, coords.y, coords.z) - ARENA) > 200.0
end)
```
</Tab>
</Tabs>

<Callout type="info">
Für einen festen Ort erledigt ein **Hidden area** im Panel dasselbe ohne Code.
</Callout>

## Client-Exports

### PlayerLoaded

Weckt den Körper des lokalen Spielers und beginnt, die Körper in der Umgebung anzuzeigen. Rufe es aus einem Spawn-Skript nach dessen eigenem endgültigen Spawn auf, und nur, wenn **Wake up on** im Panel auf **PlayerLoaded export (spawn script)** steht.

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
PlayerLoaded(): void
```

```lua title="Lua"
exports['ai-exitsleeping']:PlayerLoaded()
```

#### Rückgabewert

Nichts. Ein zweiter Aufruf vor dem nächsten Charakterwechsel tut nichts.

### SetHidden

Versteckt jeden schlafenden Körper auf diesem Client, solange irgendein Grund besteht. Nutze es, solange der Spieler an einem Ort ist, an dem Körper falsch aussehen würden (ein Shell-Innenraum, eine Zwischensequenz).

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
SetHidden(reason: string, hidden: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetHidden('myshell', true)
```

#### Parameter

<TypeTable
  type={{
    reason: { type: 'string', description: 'Dein Name für den Grund. Gründe werden pro aufrufender Ressource geführt.', required: true },
    hidden: { type: 'boolean', description: '`true` fügt den Grund hinzu, `false` entfernt ihn. Körper erscheinen wieder, wenn kein Grund mehr besteht.', required: true },
  }}
/>

#### Rückgabewert

Nichts. Deine Gründe werden entfernt, wenn deine Ressource stoppt.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/client";

export function enterShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", true);
}
export function leaveShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", false);
}
```
</Tab>
<Tab value="Lua">
```lua
local function enterShell() exports['ai-exitsleeping']:SetHidden('shell', true) end
local function leaveShell() exports['ai-exitsleeping']:SetHidden('shell', false) end
```
</Tab>
</Tabs>

### SetCarryBlocked

Blendet die Trageoption auf diesem Client aus, solange irgendein Grund besteht (deine eigenen Regeln: ein Minispiel, ein Gefängnis).

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
SetCarryBlocked(reason: string, blocked: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetCarryBlocked('minigame', true)
```

#### Rückgabewert

Nichts. Dieselben Regeln für Gründe wie bei `SetHidden`. Tragen ist im Fahrzeug, am Boden und gefesselt bereits gesperrt.

## Hook-Events

Lokale Events (nicht über das Netzwerk gesendet), auf die du hören kannst.

### ai-exitsleeping:created

Für einen Charakter, der sich ausgeloggt hat, wurde ein schlafender Körper erstellt. **Seite:** Server.

<TypeTable
  type={{
    charId: { type: 'number', description: 'Die Charakter-ID.', required: true },
    view: { type: 'SleeperView', description: 'Der Körper. Felder unten.', required: true },
  }}
/>

### ai-exitsleeping:removed

Ein schlafender Körper ist weg (aufgewacht, abgelaufen, ausgeschaltet). **Seite:** Server. Argument: `charId: number`.

### ai-exitsleeping:positionChanged

Die Position eines Körpers hat sich geändert (getragen, gefahren, abgelegt). **Seite:** Server. Argumente: `charId: number`, `coords: { x, y, z, heading }`.

### ai-exitsleeping:client:pedSpawned

Auf diesem Client wurde ein schlafender Ped erstellt. **Seite:** Client. Argumente: `ped: number` (ein lokaler, nicht vernetzter Ped), `view: SleeperView`.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Server: jeden Körper loggen, der erscheint und verschwindet.
on("ai-exitsleeping:created", (charId: number, view: { x: number; y: number; z: number }) => {
  console.log(`character ${charId} fell asleep at ${view.x}, ${view.y}, ${view.z}`);
});
on("ai-exitsleeping:removed", (charId: number) => {
  console.log(`character ${charId} woke up`);
});
```
</Tab>
<Tab value="Lua">
```lua
-- Server: jeden Körper loggen, der erscheint und verschwindet.
AddEventHandler('ai-exitsleeping:created', function(charId, view)
  print(('character %d fell asleep at %.1f, %.1f, %.1f'):format(charId, view.x, view.y, view.z))
end)
AddEventHandler('ai-exitsleeping:removed', function(charId)
  print(('character %d woke up'):format(charId))
end)
```
</Tab>
</Tabs>

## Interne Events

`ai-exitsleeping:wake`, `area`, `client:area`, `look`, `startCarry`, `stopCarry`, `putInVehicle`, `takeOut` laufen zwischen seinem eigenen Client und Server; rufe sie nicht auf.
