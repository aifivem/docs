ai-exitsleeping ma jeden eksport serwera, trzy eksporty klienta i cztery lokalne zdarzenia hooków (edytowalne hooki oryginalnego skryptu). Żadne nie są typowane w `@aifivem/shared`: w TypeScript wywołuj je przez `callExport`.

## Eksporty serwera

### AddCreateCheck

Dodaje sprawdzenie, które uruchamia się, gdy gracz się wylogowuje. Zwróć `false`, aby nie zostawiać śpiącego ciała (mieszkanie, strefa wydarzenia, więzienie). Używaj, gdy twój skrypt zna miejsca, w których ciało nie może zostać.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
AddCreateCheck(id: string, check: (source: number, charId: number, coords: { x: number; y: number; z: number; heading: number }) => boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:AddCreateCheck(id, function(source, charId, coords) return true end)
```

#### Parametry

<TypeTable
  type={{
    id: { type: 'string', description: 'Nazwa twojego sprawdzenia. Ponowne dodanie tego samego ID zastępuje stare sprawdzenie. Puste ID jest ignorowane.', required: true },
    check: { type: '(source, charId, coords) => boolean', description: 'Wywoływane z ID gracza na serwerze, ID postaci i pozycją przy wylogowaniu. Zwróć `false`, aby nie zostawiać ciała.', required: true },
  }}
/>

#### Zwraca

Nic. Sprawdzenie jest usuwane samo, gdy twój zasób się zatrzymuje.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

// Bez śpiących ciał na arenie wydarzeń (200 m wokół jej środka).
const ARENA = { x: -324.0, y: -1968.0, z: 21.6 };
callExport("ai-exitsleeping", "AddCreateCheck", "arena",
  (_source: number, _charId: number, c: { x: number; y: number; z: number }) =>
    Math.hypot(c.x - ARENA.x, c.y - ARENA.y) > 200,
);
```
</Tab>
<Tab value="Lua">
```lua
-- Bez śpiących ciał na arenie wydarzeń (200 m wokół jej środka).
local ARENA = vector3(-324.0, -1968.0, 21.6)
exports['ai-exitsleeping']:AddCreateCheck('arena', function(source, charId, coords)
  return #(vector3(coords.x, coords.y, coords.z) - ARENA) > 200.0
end)
```
</Tab>
</Tabs>

<Callout type="info">
Dla stałego miejsca **Hidden area** w panelu robi to samo bez kodu.
</Callout>

## Eksporty klienta

### PlayerLoaded

Budzi ciało lokalnego gracza i zaczyna pokazywać ciała w pobliżu. Wywołuj to ze skryptu spawnu po jego własnym ostatecznym spawnie i tylko wtedy, gdy **Wake up on** w panelu to **PlayerLoaded export (spawn script)**.

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
PlayerLoaded(): void
```

```lua title="Lua"
exports['ai-exitsleeping']:PlayerLoaded()
```

#### Zwraca

Nic. Drugie wywołanie przed następną zmianą postaci nic nie robi.

### SetHidden

Ukrywa każde śpiące ciało na tym kliencie, dopóki trwa jakikolwiek powód. Używaj, gdy gracz jest w miejscu, w którym ciała wyglądałyby źle (wnętrze shella, przerywnik).

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
SetHidden(reason: string, hidden: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetHidden('myshell', true)
```

#### Parametry

<TypeTable
  type={{
    reason: { type: 'string', description: 'Twoja nazwa powodu. Powody są przechowywane osobno dla każdego wywołującego zasobu.', required: true },
    hidden: { type: 'boolean', description: '`true` dodaje powód, `false` go usuwa. Ciała pojawiają się znowu, gdy nie zostaje żaden powód.', required: true },
  }}
/>

#### Zwraca

Nic. Twoje powody są usuwane, gdy twój zasób się zatrzymuje.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/client";

export function enterShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", true);
}
export function leaveShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", false);
}
```
</Tab>
<Tab value="Lua">
```lua
local function enterShell() exports['ai-exitsleeping']:SetHidden('shell', true) end
local function leaveShell() exports['ai-exitsleeping']:SetHidden('shell', false) end
```
</Tab>
</Tabs>

### SetCarryBlocked

Ukrywa opcję noszenia na tym kliencie, dopóki trwa jakikolwiek powód (twoje własne zasady: minigra, więzienie).

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
SetCarryBlocked(reason: string, blocked: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetCarryBlocked('minigame', true)
```

#### Zwraca

Nic. Te same zasady powodów co w `SetHidden`. Noszenie jest już zablokowane w pojeździe, podczas powalenia i podczas skucia.

## Zdarzenia hooków

Lokalne zdarzenia (niewysyłane przez sieć), których możesz nasłuchiwać.

### ai-exitsleeping:created

Utworzono śpiące ciało dla postaci, która się wylogowała. **Strona:** serwer.

<TypeTable
  type={{
    charId: { type: 'number', description: 'ID postaci.', required: true },
    view: { type: 'SleeperView', description: 'Ciało. Pola poniżej.', required: true },
  }}
/>

### ai-exitsleeping:removed

Śpiące ciało zniknęło (obudziło się, wygasło, zostało przełączone). **Strona:** serwer. Argument: `charId: number`.

### ai-exitsleeping:positionChanged

Zmieniła się pozycja ciała (noszone, przewożone, odłożone). **Strona:** serwer. Argumenty: `charId: number`, `coords: { x, y, z, heading }`.

### ai-exitsleeping:client:pedSpawned

Na tym kliencie utworzono śpiącego peda. **Strona:** klient. Argumenty: `ped: number` (lokalny, niesieciowy ped), `view: SleeperView`.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Serwer: loguj każde ciało, które się pojawia i znika.
on("ai-exitsleeping:created", (charId: number, view: { x: number; y: number; z: number }) => {
  console.log(`character ${charId} fell asleep at ${view.x}, ${view.y}, ${view.z}`);
});
on("ai-exitsleeping:removed", (charId: number) => {
  console.log(`character ${charId} woke up`);
});
```
</Tab>
<Tab value="Lua">
```lua
-- Serwer: loguj każde ciało, które się pojawia i znika.
AddEventHandler('ai-exitsleeping:created', function(charId, view)
  print(('character %d fell asleep at %.1f, %.1f, %.1f'):format(charId, view.x, view.y, view.z))
end)
AddEventHandler('ai-exitsleeping:removed', function(charId)
  print(('character %d woke up'):format(charId))
end)
```
</Tab>
</Tabs>

## Zdarzenia wewnętrzne

`ai-exitsleeping:wake`, `area`, `client:area`, `look`, `startCarry`, `stopCarry`, `putInVehicle`, `takeOut` działają między jego własnym klientem a serwerem; nie wywołuj ich.
