ai-exitsleeping’in bir server export’u, üç client export’u ve dört yerel hook event’i vardır (orijinal script’in düzenlenebilir hook’ları). Hiçbiri `@aicore-fivem/shared` içinde tiplenmemiştir: TypeScript’te onları `callExport` ile çağır.

## Server export’ları

### AddCreateCheck

Bir oyuncu çıkış yaptığında çalışan bir kontrol ekler. Uyuyan beden bırakmamak için `false` döndür (bir daire, bir etkinlik bölgesi, bir hapishane). Script’in bir bedenin kalmaması gereken yerleri biliyorsa kullan.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
AddCreateCheck(id: string, check: (source: number, charId: number, coords: { x: number; y: number; z: number; heading: number }) => boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:AddCreateCheck(id, function(source, charId, coords) return true end)
```

#### Parametreler

<TypeTable
  type={{
    id: { type: 'string', description: 'Kontrolün için bir ad. Aynı id’yi tekrar eklemek eski kontrolün yerine geçer. Boş bir id yok sayılır.', required: true },
    check: { type: '(source, charId, coords) => boolean', description: 'Çıkışta oyuncunun server id’si, karakter id’si ve konumuyla çağrılır. Beden bırakmamak için `false` döndür.', required: true },
  }}
/>

#### Dönüş değeri

Hiçbir şey. Resource’un durduğunda kontrol kendiliğinden kaldırılır.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aicore-fivem/lib/server";

// Etkinlik arenasının içinde uyuyan beden yok (merkezinin 200 m çevresi).
const ARENA = { x: -324.0, y: -1968.0, z: 21.6 };
callExport("ai-exitsleeping", "AddCreateCheck", "arena",
  (_source: number, _charId: number, c: { x: number; y: number; z: number }) =>
    Math.hypot(c.x - ARENA.x, c.y - ARENA.y) > 200,
);
```
</Tab>
<Tab value="Lua">
```lua
-- Etkinlik arenasının içinde uyuyan beden yok (merkezinin 200 m çevresi).
local ARENA = vector3(-324.0, -1968.0, 21.6)
exports['ai-exitsleeping']:AddCreateCheck('arena', function(source, charId, coords)
  return #(vector3(coords.x, coords.y, coords.z) - ARENA) > 200.0
end)
```
</Tab>
</Tabs>

<Callout type="info">
Sabit bir yer için paneldeki bir **Hidden area** aynı işi kodsuz yapar.
</Callout>

## Client export’ları

### PlayerLoaded

Yerel oyuncunun bedenini uyandırır ve etraftaki bedenleri göstermeye başlar. Bir doğuş script’inden, onun kendi son doğuşundan sonra ve sadece paneldeki **Wake up on** değeri **PlayerLoaded export (spawn script)** olduğunda çağır.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
PlayerLoaded(): void
```

```lua title="Lua"
exports['ai-exitsleeping']:PlayerLoaded()
```

#### Dönüş değeri

Hiçbir şey. Bir sonraki karakter değişiminden önceki ikinci çağrı hiçbir şey yapmaz.

### SetHidden

Herhangi bir sebep geçerli olduğu sürece bu client’taki her uyuyan bedeni gizler. Oyuncu bedenlerin yanlış görüneceği bir yerdeyken (bir shell iç mekân, bir ara sahne) kullan.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
SetHidden(reason: string, hidden: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetHidden('myshell', true)
```

#### Parametreler

<TypeTable
  type={{
    reason: { type: 'string', description: 'Sebep için senin verdiğin ad. Sebepler çağıran resource başına tutulur.', required: true },
    hidden: { type: 'boolean', description: '`true` sebebi ekler, `false` kaldırır. Hiç sebep kalmayınca bedenler tekrar görünür.', required: true },
  }}
/>

#### Dönüş değeri

Hiçbir şey. Resource’un durduğunda sebeplerin kaldırılır.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aicore-fivem/lib/client";

export function enterShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", true);
}
export function leaveShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", false);
}
```
</Tab>
<Tab value="Lua">
```lua
local function enterShell() exports['ai-exitsleeping']:SetHidden('shell', true) end
local function leaveShell() exports['ai-exitsleeping']:SetHidden('shell', false) end
```
</Tab>
</Tabs>

### SetCarryBlocked

Herhangi bir sebep geçerli olduğu sürece bu client’ta taşıma seçeneğini gizler (kendi kuralların: bir mini oyun, bir hapishane).

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
SetCarryBlocked(reason: string, blocked: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetCarryBlocked('minigame', true)
```

#### Dönüş değeri

Hiçbir şey. Sebep kuralları `SetHidden` ile aynıdır. Taşıma araçtayken, yere düşmüşken ve kelepçeliyken zaten engellidir.

## Hook event’leri

Dinleyebileceğin yerel event’ler (ağ üzerinden gönderilmez).

### ai-exitsleeping:created

Çıkış yapan bir karakter için uyuyan bir beden oluşturuldu. **Taraf:** Server.

<TypeTable
  type={{
    charId: { type: 'number', description: 'Karakter id’si.', required: true },
    view: { type: 'SleeperView', description: 'Beden. Alanları aşağıda.', required: true },
  }}
/>

### ai-exitsleeping:removed

Uyuyan bir beden gitti (uyandı, süresi doldu, kapatıldı). **Taraf:** Server. Argüman: `charId: number`.

### ai-exitsleeping:positionChanged

Bir bedenin konumu değişti (taşındı, araçla götürüldü, yere bırakıldı). **Taraf:** Server. Argümanlar: `charId: number`, `coords: { x, y, z, heading }`.

### ai-exitsleeping:client:pedSpawned

Bu client’ta uyuyan bir ped oluşturuldu. **Taraf:** Client. Argümanlar: `ped: number` (yerel, ağa bağlı olmayan bir ped), `view: SleeperView`.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Server: beliren ve kaybolan her bedeni logla.
on("ai-exitsleeping:created", (charId: number, view: { x: number; y: number; z: number }) => {
  console.log(`character ${charId} fell asleep at ${view.x}, ${view.y}, ${view.z}`);
});
on("ai-exitsleeping:removed", (charId: number) => {
  console.log(`character ${charId} woke up`);
});
```
</Tab>
<Tab value="Lua">
```lua
-- Server: beliren ve kaybolan her bedeni logla.
AddEventHandler('ai-exitsleeping:created', function(charId, view)
  print(('character %d fell asleep at %.1f, %.1f, %.1f'):format(charId, view.x, view.y, view.z))
end)
AddEventHandler('ai-exitsleeping:removed', function(charId)
  print(('character %d woke up'):format(charId))
end)
```
</Tab>
</Tabs>

## Dahili event’ler

`ai-exitsleeping:wake`, `area`, `client:area`, `look`, `startCarry`, `stopCarry`, `putInVehicle`, `takeOut` kendi client’ı ile server’ı arasındadır; bunları çağırma.
