У ai-exitsleeping один серверный экспорт, три клиентских экспорта и четыре локальных события-хука (редактируемые хуки оригинального скрипта). Ни один не типизирован в `@aifivem/shared`: в TypeScript вызывайте их через `callExport`.

## Серверные экспорты

### AddCreateCheck

Добавляет проверку, которая выполняется, когда игрок выходит. Верните `false`, чтобы не оставлять спящее тело (квартира, зона мероприятия, тюрьма). Используйте, когда ваш скрипт знает места, где тело не должно оставаться.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
AddCreateCheck(id: string, check: (source: number, charId: number, coords: { x: number; y: number; z: number; heading: number }) => boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:AddCreateCheck(id, function(source, charId, coords) return true end)
```

#### Параметры

<TypeTable
  type={{
    id: { type: 'string', description: 'Имя вашей проверки. Повторное добавление того же id заменяет старую проверку. Пустой id игнорируется.', required: true },
    check: { type: '(source, charId, coords) => boolean', description: 'Вызывается с серверным id игрока, id персонажа и позицией при выходе. Верните `false`, чтобы не оставлять тело.', required: true },
  }}
/>

#### Возвращает

Ничего. Проверка удаляется сама, когда ваш ресурс останавливается.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

// Никаких спящих тел внутри арены мероприятия (200 м вокруг её центра).
const ARENA = { x: -324.0, y: -1968.0, z: 21.6 };
callExport("ai-exitsleeping", "AddCreateCheck", "arena",
  (_source: number, _charId: number, c: { x: number; y: number; z: number }) =>
    Math.hypot(c.x - ARENA.x, c.y - ARENA.y) > 200,
);
```
</Tab>
<Tab value="Lua">
```lua
-- Никаких спящих тел внутри арены мероприятия (200 м вокруг её центра).
local ARENA = vector3(-324.0, -1968.0, 21.6)
exports['ai-exitsleeping']:AddCreateCheck('arena', function(source, charId, coords)
  return #(vector3(coords.x, coords.y, coords.z) - ARENA) > 200.0
end)
```
</Tab>
</Tabs>

<Callout type="info">
Для фиксированного места то же самое без кода делает **Hidden area** в панели.
</Callout>

## Клиентские экспорты

### PlayerLoaded

Будит тело локального игрока и начинает показывать тела вокруг. Вызывайте его из скрипта появления после его собственного окончательного появления, и только когда **Wake up on** в панели установлено в **PlayerLoaded export (spawn script)**.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
PlayerLoaded(): void
```

```lua title="Lua"
exports['ai-exitsleeping']:PlayerLoaded()
```

#### Возвращает

Ничего. Второй вызов до следующей смены персонажа ничего не делает.

### SetHidden

Скрывает все спящие тела на этом клиенте, пока действует хотя бы одна причина. Используйте, пока игрок находится там, где тела выглядели бы неуместно (интерьер-шелл, катсцена).

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
SetHidden(reason: string, hidden: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetHidden('myshell', true)
```

#### Параметры

<TypeTable
  type={{
    reason: { type: 'string', description: 'Ваше имя для причины. Причины хранятся отдельно для каждого вызывающего ресурса.', required: true },
    hidden: { type: 'boolean', description: '`true` добавляет причину, `false` убирает её. Тела снова показываются, когда не остаётся ни одной причины.', required: true },
  }}
/>

#### Возвращает

Ничего. Ваши причины удаляются, когда ваш ресурс останавливается.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/client";

export function enterShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", true);
}
export function leaveShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", false);
}
```
</Tab>
<Tab value="Lua">
```lua
local function enterShell() exports['ai-exitsleeping']:SetHidden('shell', true) end
local function leaveShell() exports['ai-exitsleeping']:SetHidden('shell', false) end
```
</Tab>
</Tabs>

### SetCarryBlocked

Скрывает опцию переноски на этом клиенте, пока действует хотя бы одна причина (ваши собственные правила: мини-игра, тюрьма).

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
SetCarryBlocked(reason: string, blocked: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetCarryBlocked('minigame', true)
```

#### Возвращает

Ничего. Те же правила причин, что и у `SetHidden`. Переноска и так заблокирована в транспорте, без сознания и в наручниках.

## События-хуки

Локальные события (не отправляются по сети), которые можно слушать.

### ai-exitsleeping:created

Для вышедшего персонажа создано спящее тело. **Сторона:** сервер.

<TypeTable
  type={{
    charId: { type: 'number', description: 'Id персонажа.', required: true },
    view: { type: 'SleeperView', description: 'Тело. Поля ниже.', required: true },
  }}
/>

### ai-exitsleeping:removed

Спящее тело исчезло (проснулось, истекло, переключено). **Сторона:** сервер. Аргумент: `charId: number`.

### ai-exitsleeping:positionChanged

Позиция тела изменилась (несут, везут, положили). **Сторона:** сервер. Аргументы: `charId: number`, `coords: { x, y, z, heading }`.

### ai-exitsleeping:client:pedSpawned

На этом клиенте создан спящий пед. **Сторона:** клиент. Аргументы: `ped: number` (локальный, не сетевой пед), `view: SleeperView`.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Сервер: записывать в лог каждое тело, которое появляется и исчезает.
on("ai-exitsleeping:created", (charId: number, view: { x: number; y: number; z: number }) => {
  console.log(`character ${charId} fell asleep at ${view.x}, ${view.y}, ${view.z}`);
});
on("ai-exitsleeping:removed", (charId: number) => {
  console.log(`character ${charId} woke up`);
});
```
</Tab>
<Tab value="Lua">
```lua
-- Сервер: записывать в лог каждое тело, которое появляется и исчезает.
AddEventHandler('ai-exitsleeping:created', function(charId, view)
  print(('character %d fell asleep at %.1f, %.1f, %.1f'):format(charId, view.x, view.y, view.z))
end)
AddEventHandler('ai-exitsleeping:removed', function(charId)
  print(('character %d woke up'):format(charId))
end)
```
</Tab>
</Tabs>

## Внутренние события

`ai-exitsleeping:wake`, `area`, `client:area`, `look`, `startCarry`, `stopCarry`, `putInVehicle`, `takeOut` ходят между его собственным клиентом и сервером; не вызывайте их.
