ai-exitsleeping a un export serveur, trois exports client et quatre events de hook locaux (les hooks modifiables du script d’origine). Aucun n’est typé dans `@aifivem/shared` : en TypeScript, appelez-les avec `callExport`.

## Exports serveur

### AddCreateCheck

Ajoute une vérification qui s’exécute quand un joueur se déconnecte. Renvoyez `false` pour ne laisser aucun corps endormi (un appartement, une zone d’événement, une prison). Utilisez-la quand votre script connaît des endroits où un corps ne doit pas rester.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
AddCreateCheck(id: string, check: (source: number, charId: number, coords: { x: number; y: number; z: number; heading: number }) => boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:AddCreateCheck(id, function(source, charId, coords) return true end)
```

#### Paramètres

<TypeTable
  type={{
    id: { type: 'string', description: 'Un nom pour votre vérification. Ajouter à nouveau le même id remplace l’ancienne vérification. Un id vide est ignoré.', required: true },
    check: { type: '(source, charId, coords) => boolean', description: 'Appelée avec l’id serveur du joueur, l’id du personnage et la position à la déconnexion. Renvoyez `false` pour ne laisser aucun corps.', required: true },
  }}
/>

#### Retour

Rien. La vérification est retirée d’elle-même quand votre ressource s’arrête.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

// Pas de corps endormis dans l’arène d’événement (200 m autour de son centre).
const ARENA = { x: -324.0, y: -1968.0, z: 21.6 };
callExport("ai-exitsleeping", "AddCreateCheck", "arena",
  (_source: number, _charId: number, c: { x: number; y: number; z: number }) =>
    Math.hypot(c.x - ARENA.x, c.y - ARENA.y) > 200,
);
```
</Tab>
<Tab value="Lua">
```lua
-- Pas de corps endormis dans l’arène d’événement (200 m autour de son centre).
local ARENA = vector3(-324.0, -1968.0, 21.6)
exports['ai-exitsleeping']:AddCreateCheck('arena', function(source, charId, coords)
  return #(vector3(coords.x, coords.y, coords.z) - ARENA) > 200.0
end)
```
</Tab>
</Tabs>

<Callout type="info">
Pour un endroit fixe, une **Hidden area** dans le panneau fait la même chose sans code.
</Callout>

## Exports client

### PlayerLoaded

Réveille le corps du joueur local et commence à afficher les corps alentour. Appelez-le depuis un script d’apparition après sa propre apparition finale, et uniquement quand le **Wake up on** du panneau vaut **PlayerLoaded export (spawn script)**.

**Côté :** client · **Attend :** non

```ts title="Signature"
PlayerLoaded(): void
```

```lua title="Lua"
exports['ai-exitsleeping']:PlayerLoaded()
```

#### Retour

Rien. Un second appel avant le prochain changement de personnage ne fait rien.

### SetHidden

Masque chaque corps endormi sur ce client tant qu’au moins une raison est active. Utilisez-le pendant que le joueur est dans un endroit où les corps auraient l’air déplacés (un intérieur shell, une cinématique).

**Côté :** client · **Attend :** non

```ts title="Signature"
SetHidden(reason: string, hidden: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetHidden('myshell', true)
```

#### Paramètres

<TypeTable
  type={{
    reason: { type: 'string', description: 'Votre nom pour la raison. Les raisons sont conservées par ressource appelante.', required: true },
    hidden: { type: 'boolean', description: '`true` ajoute la raison, `false` la retire. Les corps réapparaissent quand il ne reste aucune raison.', required: true },
  }}
/>

#### Retour

Rien. Vos raisons sont retirées quand votre ressource s’arrête.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/client";

export function enterShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", true);
}
export function leaveShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", false);
}
```
</Tab>
<Tab value="Lua">
```lua
local function enterShell() exports['ai-exitsleeping']:SetHidden('shell', true) end
local function leaveShell() exports['ai-exitsleeping']:SetHidden('shell', false) end
```
</Tab>
</Tabs>

### SetCarryBlocked

Masque l’option de port sur ce client tant qu’au moins une raison est active (vos propres règles : un mini-jeu, une prison).

**Côté :** client · **Attend :** non

```ts title="Signature"
SetCarryBlocked(reason: string, blocked: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetCarryBlocked('minigame', true)
```

#### Retour

Rien. Mêmes règles de raisons que `SetHidden`. Le port est déjà bloqué dans un véhicule, à terre et menotté.

## Events de hook

Des events locaux (non envoyés sur le réseau) que vous pouvez écouter.

### ai-exitsleeping:created

Un corps endormi a été créé pour un personnage qui s’est déconnecté. **Côté :** serveur.

<TypeTable
  type={{
    charId: { type: 'number', description: 'L’id du personnage.', required: true },
    view: { type: 'SleeperView', description: 'Le corps. Champs ci-dessous.', required: true },
  }}
/>

### ai-exitsleeping:removed

Un corps endormi a disparu (réveillé, expiré, désactivé). **Côté :** serveur. Argument : `charId: number`.

### ai-exitsleeping:positionChanged

La position d’un corps a changé (porté, transporté en véhicule, posé). **Côté :** serveur. Arguments : `charId: number`, `coords: { x, y, z, heading }`.

### ai-exitsleeping:client:pedSpawned

Un ped endormi a été créé sur ce client. **Côté :** client. Arguments : `ped: number` (un ped local, non réseau), `view: SleeperView`.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Serveur : journaliser chaque corps qui apparaît et disparaît.
on("ai-exitsleeping:created", (charId: number, view: { x: number; y: number; z: number }) => {
  console.log(`character ${charId} fell asleep at ${view.x}, ${view.y}, ${view.z}`);
});
on("ai-exitsleeping:removed", (charId: number) => {
  console.log(`character ${charId} woke up`);
});
```
</Tab>
<Tab value="Lua">
```lua
-- Serveur : journaliser chaque corps qui apparaît et disparaît.
AddEventHandler('ai-exitsleeping:created', function(charId, view)
  print(('character %d fell asleep at %.1f, %.1f, %.1f'):format(charId, view.x, view.y, view.z))
end)
AddEventHandler('ai-exitsleeping:removed', function(charId)
  print(('character %d woke up'):format(charId))
end)
```
</Tab>
</Tabs>

## Events internes

`ai-exitsleeping:wake`, `area`, `client:area`, `look`, `startCarry`, `stopCarry`, `putInVehicle`, `takeOut` circulent entre son propre client et son serveur ; ne les appelez pas.
