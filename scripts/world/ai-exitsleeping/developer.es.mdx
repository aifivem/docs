ai-exitsleeping tiene un export de servidor, tres exports de cliente y cuatro eventos hook locales (los hooks editables del script original). Ninguno está tipado en `@aifivem/shared`: en TypeScript llámalos con `callExport`.

## Exports de servidor

### AddCreateCheck

Añade una comprobación que se ejecuta cuando un jugador cierra sesión. Devuelve `false` para no dejar cuerpo dormido (un apartamento, una zona de evento, una cárcel). Úsalo cuando tu script conozca lugares donde no debe quedarse un cuerpo.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
AddCreateCheck(id: string, check: (source: number, charId: number, coords: { x: number; y: number; z: number; heading: number }) => boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:AddCreateCheck(id, function(source, charId, coords) return true end)
```

#### Parámetros

<TypeTable
  type={{
    id: { type: 'string', description: 'Un nombre para tu comprobación. Añadir otra vez el mismo id reemplaza la comprobación anterior. Un id vacío se ignora.', required: true },
    check: { type: '(source, charId, coords) => boolean', description: 'Se llama con el id de servidor, el id de personaje y la posición del jugador al cerrar sesión. Devuelve `false` para no dejar cuerpo.', required: true },
  }}
/>

#### Devuelve

Nada. La comprobación se quita sola cuando tu recurso se detiene.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

// Sin cuerpos dormidos dentro de la arena del evento (200 m alrededor de su centro).
const ARENA = { x: -324.0, y: -1968.0, z: 21.6 };
callExport("ai-exitsleeping", "AddCreateCheck", "arena",
  (_source: number, _charId: number, c: { x: number; y: number; z: number }) =>
    Math.hypot(c.x - ARENA.x, c.y - ARENA.y) > 200,
);
```
</Tab>
<Tab value="Lua">
```lua
-- Sin cuerpos dormidos dentro de la arena del evento (200 m alrededor de su centro).
local ARENA = vector3(-324.0, -1968.0, 21.6)
exports['ai-exitsleeping']:AddCreateCheck('arena', function(source, charId, coords)
  return #(vector3(coords.x, coords.y, coords.z) - ARENA) > 200.0
end)
```
</Tab>
</Tabs>

<Callout type="info">
Para un lugar fijo, una **Hidden area** del panel hace lo mismo sin código.
</Callout>

## Exports de cliente

### PlayerLoaded

Despierta el cuerpo del jugador local y empieza a mostrar los cuerpos de alrededor. Llámalo desde un script de aparición después de su propia aparición final, y solo cuando el **Wake up on** del panel sea **PlayerLoaded export (spawn script)**.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
PlayerLoaded(): void
```

```lua title="Lua"
exports['ai-exitsleeping']:PlayerLoaded()
```

#### Devuelve

Nada. Una segunda llamada antes del siguiente cambio de personaje no hace nada.

### SetHidden

Oculta todos los cuerpos dormidos en este cliente mientras haya algún motivo activo. Úsalo mientras el jugador está en un lugar donde los cuerpos se verían mal (el interior de un shell, una cinemática).

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
SetHidden(reason: string, hidden: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetHidden('myshell', true)
```

#### Parámetros

<TypeTable
  type={{
    reason: { type: 'string', description: 'Tu nombre para el motivo. Los motivos se guardan por recurso que llama.', required: true },
    hidden: { type: 'boolean', description: '`true` añade el motivo, `false` lo quita. Los cuerpos vuelven a mostrarse cuando no queda ningún motivo.', required: true },
  }}
/>

#### Devuelve

Nada. Tus motivos se quitan cuando tu recurso se detiene.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/client";

export function enterShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", true);
}
export function leaveShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", false);
}
```
</Tab>
<Tab value="Lua">
```lua
local function enterShell() exports['ai-exitsleeping']:SetHidden('shell', true) end
local function leaveShell() exports['ai-exitsleeping']:SetHidden('shell', false) end
```
</Tab>
</Tabs>

### SetCarryBlocked

Oculta la opción de cargar en este cliente mientras haya algún motivo activo (tus propias reglas: un minijuego, una cárcel).

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
SetCarryBlocked(reason: string, blocked: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetCarryBlocked('minigame', true)
```

#### Devuelve

Nada. Las mismas reglas de motivos que `SetHidden`. Cargar ya está bloqueado en un vehículo, abatido y esposado.

## Eventos hook

Eventos locales (no se envían por la red) que puedes escuchar.

### ai-exitsleeping:created

Se creó un cuerpo dormido para un personaje que cerró sesión. **Lado:** Servidor.

<TypeTable
  type={{
    charId: { type: 'number', description: 'El id del personaje.', required: true },
    view: { type: 'SleeperView', description: 'El cuerpo. Campos abajo.', required: true },
  }}
/>

### ai-exitsleeping:removed

Un cuerpo dormido ha desaparecido (despertó, caducó, se desactivó). **Lado:** Servidor. Argumento: `charId: number`.

### ai-exitsleeping:positionChanged

Ha cambiado la posición de un cuerpo (cargado, llevado en vehículo, dejado en el suelo). **Lado:** Servidor. Argumentos: `charId: number`, `coords: { x, y, z, heading }`.

### ai-exitsleeping:client:pedSpawned

Se creó un ped dormido en este cliente. **Lado:** Cliente. Argumentos: `ped: number` (un ped local, no en red), `view: SleeperView`.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Servidor: registra en el log cada cuerpo que aparece y desaparece.
on("ai-exitsleeping:created", (charId: number, view: { x: number; y: number; z: number }) => {
  console.log(`character ${charId} fell asleep at ${view.x}, ${view.y}, ${view.z}`);
});
on("ai-exitsleeping:removed", (charId: number) => {
  console.log(`character ${charId} woke up`);
});
```
</Tab>
<Tab value="Lua">
```lua
-- Servidor: registra en el log cada cuerpo que aparece y desaparece.
AddEventHandler('ai-exitsleeping:created', function(charId, view)
  print(('character %d fell asleep at %.1f, %.1f, %.1f'):format(charId, view.x, view.y, view.z))
end)
AddEventHandler('ai-exitsleeping:removed', function(charId)
  print(('character %d woke up'):format(charId))
end)
```
</Tab>
</Tabs>

## Eventos internos

`ai-exitsleeping:wake`, `area`, `client:area`, `look`, `startCarry`, `stopCarry`, `putInVehicle`, `takeOut` son entre su propio cliente y su servidor; no los llames.
