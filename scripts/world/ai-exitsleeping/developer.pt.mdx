O ai-exitsleeping tem um export do servidor, três exports do cliente e quatro eventos de hook locais (os hooks editáveis do script original). Nenhum é tipado em `@aifivem/shared`: em TypeScript chame-os com `callExport`.

## Exports do servidor

### AddCreateCheck

Adiciona uma verificação que roda quando um jogador sai do jogo. Retorne `false` para não deixar corpo dormindo (um apartamento, uma zona de evento, uma prisão). Use quando seu script conhece lugares onde um corpo não deve ficar.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
AddCreateCheck(id: string, check: (source: number, charId: number, coords: { x: number; y: number; z: number; heading: number }) => boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:AddCreateCheck(id, function(source, charId, coords) return true end)
```

#### Parâmetros

<TypeTable
  type={{
    id: { type: 'string', description: 'Um nome para a sua verificação. Adicionar o mesmo id de novo substitui a verificação antiga. Um id vazio é ignorado.', required: true },
    check: { type: '(source, charId, coords) => boolean', description: 'Chamada com o id do servidor do jogador, o id do personagem e a posição na saída. Retorne `false` para não deixar corpo.', required: true },
  }}
/>

#### Retorno

Nada. A verificação é removida sozinha quando seu recurso para.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

// Sem corpos dormindo dentro da arena do evento (200 m ao redor do centro dela).
const ARENA = { x: -324.0, y: -1968.0, z: 21.6 };
callExport("ai-exitsleeping", "AddCreateCheck", "arena",
  (_source: number, _charId: number, c: { x: number; y: number; z: number }) =>
    Math.hypot(c.x - ARENA.x, c.y - ARENA.y) > 200,
);
```
</Tab>
<Tab value="Lua">
```lua
-- Sem corpos dormindo dentro da arena do evento (200 m ao redor do centro dela).
local ARENA = vector3(-324.0, -1968.0, 21.6)
exports['ai-exitsleeping']:AddCreateCheck('arena', function(source, charId, coords)
  return #(vector3(coords.x, coords.y, coords.z) - ARENA) > 200.0
end)
```
</Tab>
</Tabs>

<Callout type="info">
Para um lugar fixo, uma **Hidden area** no painel faz o mesmo sem código.
</Callout>

## Exports do cliente

### PlayerLoaded

Acorda o corpo do jogador local e começa a mostrar os corpos ao redor. Chame-o a partir de um script de spawn depois do spawn final dele, e só quando o **Wake up on** do painel for **PlayerLoaded export (spawn script)**.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
PlayerLoaded(): void
```

```lua title="Lua"
exports['ai-exitsleeping']:PlayerLoaded()
```

#### Retorno

Nada. Uma segunda chamada antes da próxima troca de personagem não faz nada.

### SetHidden

Esconde todos os corpos dormindo neste cliente enquanto houver algum motivo ativo. Use enquanto o jogador está em um lugar onde os corpos ficariam estranhos (um interior shell, uma cutscene).

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
SetHidden(reason: string, hidden: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetHidden('myshell', true)
```

#### Parâmetros

<TypeTable
  type={{
    reason: { type: 'string', description: 'O nome que você dá ao motivo. Os motivos são mantidos por recurso que chama.', required: true },
    hidden: { type: 'boolean', description: '`true` adiciona o motivo, `false` o remove. Os corpos aparecem de novo quando não sobra nenhum motivo.', required: true },
  }}
/>

#### Retorno

Nada. Seus motivos são removidos quando seu recurso para.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/client";

export function enterShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", true);
}
export function leaveShell(): void {
  callExport("ai-exitsleeping", "SetHidden", "shell", false);
}
```
</Tab>
<Tab value="Lua">
```lua
local function enterShell() exports['ai-exitsleeping']:SetHidden('shell', true) end
local function leaveShell() exports['ai-exitsleeping']:SetHidden('shell', false) end
```
</Tab>
</Tabs>

### SetCarryBlocked

Esconde a opção de carregar neste cliente enquanto houver algum motivo ativo (suas próprias regras: um minigame, uma prisão).

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
SetCarryBlocked(reason: string, blocked: boolean): void
```

```lua title="Lua"
exports['ai-exitsleeping']:SetCarryBlocked('minigame', true)
```

#### Retorno

Nada. Mesmas regras de motivos que `SetHidden`. Carregar já é bloqueado em um veículo, enquanto caído e enquanto algemado.

## Eventos de hook

Eventos locais (não enviados pela rede) que você pode escutar.

### ai-exitsleeping:created

Um corpo dormindo foi criado para um personagem que saiu do jogo. **Lado:** Servidor.

<TypeTable
  type={{
    charId: { type: 'number', description: 'O id do personagem.', required: true },
    view: { type: 'SleeperView', description: 'O corpo. Campos abaixo.', required: true },
  }}
/>

### ai-exitsleeping:removed

Um corpo dormindo sumiu (acordou, expirou, foi desligado). **Lado:** Servidor. Argumento: `charId: number`.

### ai-exitsleeping:positionChanged

A posição de um corpo mudou (carregado, levado em um veículo, colocado no chão). **Lado:** Servidor. Argumentos: `charId: number`, `coords: { x, y, z, heading }`.

### ai-exitsleeping:client:pedSpawned

Um ped dormindo foi criado neste cliente. **Lado:** Cliente. Argumentos: `ped: number` (um ped local, não em rede), `view: SleeperView`.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Servidor: registra no log todo corpo que aparece e desaparece.
on("ai-exitsleeping:created", (charId: number, view: { x: number; y: number; z: number }) => {
  console.log(`character ${charId} fell asleep at ${view.x}, ${view.y}, ${view.z}`);
});
on("ai-exitsleeping:removed", (charId: number) => {
  console.log(`character ${charId} woke up`);
});
```
</Tab>
<Tab value="Lua">
```lua
-- Servidor: registra no log todo corpo que aparece e desaparece.
AddEventHandler('ai-exitsleeping:created', function(charId, view)
  print(('character %d fell asleep at %.1f, %.1f, %.1f'):format(charId, view.x, view.y, view.z))
end)
AddEventHandler('ai-exitsleeping:removed', function(charId)
  print(('character %d woke up'):format(charId))
end)
```
</Tab>
</Tabs>

## Eventos internos

`ai-exitsleeping:wake`, `area`, `client:area`, `look`, `startCarry`, `stopCarry`, `putInVehicle`, `takeOut` ficam entre o cliente e o servidor dele; não os chame.
