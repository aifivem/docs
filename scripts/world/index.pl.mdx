Te skrypty kształtują świat wokół graczy i dają administratorom ich narzędzia w grze.

| Skrypt | Co robi |
| --- | --- |
| [ai-properties](/pl/docs/scripts/world/ai-properties) | Domy i mieszkania z prywatnym wnętrzem, schowkiem i kluczami. |
| [ai-doorlock](/pl/docs/scripts/world/ai-doorlock) | Zamki drzwi wskazywane w świecie, z dostępem dla prac i gangów. |
| [ai-smallresources](/pl/docs/scripts/world/ai-smallresources) | Pasy, tempomat, kucanie, siadanie, noszenie i wiele drobnych funkcji. |
| [ai-exitsleeping](/pl/docs/scripts/world/ai-exitsleeping) | Wylogowani gracze zostają w świecie jako śpiące ciała. |
| [ai-pedscale](/pl/docs/scripts/world/ai-pedscale) | Wzrost i szerokość postaci. |
| [ai-admin](/pl/docs/scripts/world/ai-admin) | Noclip, teleporty, reanimacja, pojazdy i szybkie menu dla administratorów. |
