<Callout type="info">
Para leer el cinturón o los gestos desde tu propio script, usa `seatbelt.isOn()` / `seatbelt.onChange(fn)` y `gestures.isHandsUp()` / `gestures.isPointing()` de la lib (cliente; en Lua `aiLib.seatbelt`, `aiLib.gestures`). Pasan por ai-core y funcionan con el script de cinturón o de emotes que esté en uso. Los exports de abajo son los que lee ai-core mientras responde ai-smallresources.
</Callout>

Los tres exports están en el cliente, son síncronos y leen al jugador local. `GetSeatbelt` está tipado como `AiSmallResourcesClientExports` en `@aicore-fivem/shared`; `IsHandsUp` e `IsPointing` no están tipados (usa `callExport`).

```ts title="TypeScript"
import { resourceExport, callExport } from "@aicore-fivem/lib/client";
const small = resourceExport("ai-smallresources");
```

## Exports de cliente

### GetSeatbelt

Si el jugador local lleva puesto el cinturón.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
GetSeatbelt(): boolean | null
```

```lua title="Lua"
local worn = exports['ai-smallresources']:GetSeatbelt() -- true, false o nil
```

#### Devuelve

`true` cuando está abrochado, `false` cuando no. `null` cuando la función Seatbelt está desactivada en el panel, o el jugador no está en un vehículo con cinturón.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { seatbelt } from "@aicore-fivem/lib/client";

// El icono de cinturón de un HUD: leer una vez y después seguir los cambios.
let worn = seatbelt.isOn();
seatbelt.onChange((value) => {
  worn = value;
});
```
</Tab>
<Tab value="Lua">
```lua
-- El icono de cinturón de un HUD: leer una vez y después seguir los cambios.
local worn = aiLib.seatbelt.isOn()
aiLib.seatbelt.onChange(function(value)
  worn = value
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Léelo en una acción o en un cambio de vehículo, nunca en cada frame.
</Callout>

### IsHandsUp

Si el jugador local tiene las manos arriba (el gesto **X**).

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
IsHandsUp(): boolean
```

```lua title="Lua"
local up = exports['ai-smallresources']:IsHandsUp()
```

#### Devuelve

`true` mientras tiene las manos arriba, `false` en otro caso.

### IsPointing

Si el jugador local está señalando (el gesto **B**).

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
IsPointing(): boolean
```

```lua title="Lua"
local pointing = exports['ai-smallresources']:IsPointing()
```

#### Devuelve

`true` mientras señala, `false` en otro caso.

## Eventos

### ai-smallresources:seatbelt

Se dispara en el cliente local cuando cambia el cinturón. El nombre es `SEATBELT_EVENT` en `@aicore-fivem/shared`. ai-core lo reenvía como su propio evento de cinturón, que escucha `seatbelt.onChange` de la lib; prefiere ese.

**Lado:** Cliente (evento local)

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true` abrochado, `false` no. `null` mientras la función está desactivada o el jugador no está en un vehículo con cinturón.', required: true },
  }}
/>

```lua title="Lua"
AddEventHandler('ai-smallresources:seatbelt', function(worn)
  print('seat belt', worn)
end)
```

Todos los demás eventos de ai-smallresources son internos (su cliente y su servidor).

## State bags y metadata

| Nombre | En | Tipo | Significado |
| --- | --- | --- | --- |
| `aiHold` | jugador | `string \| false` | El objeto de noticias que sujeta el jugador (`newscam`, `newsmic`, `newsboom`). |
| `aiCarrying` | jugador | `number` | El jugador está cargando a alguien (su id de servidor). |
| `aiCarriedBy` | jugador | `number` | Alguien está cargando al jugador (su id de servidor). |
| `aiDiving` | jugador | `boolean` | El jugador lleva puesto el equipo de buceo. |
| `aiRealPlate` | vehículo | `string` | La matrícula real mientras hay puesta una matrícula falsa. |
| `aiMoored` | vehículo | `boolean` | El barco está atado a un amarre. |
| `diveOxygen` | metadata de personaje (ai-core) | `number` | Segundos de aire que quedan en la botella de buceo. |
| `aiPlayerCount` / `aiMaxPlayers` | GlobalState | `number` | Jugadores conectados y plazas, se fijan mientras Discord Rich Presence está activado. |

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Servidor: la matrícula real de un vehículo, sea falsa o no.
export function realPlate(vehicle: number): string {
  const real = Entity(vehicle).state.aiRealPlate as string | undefined;
  return real ?? GetVehicleNumberPlateText(vehicle);
}
```
</Tab>
<Tab value="Lua">
```lua
-- Servidor: la matrícula real de un vehículo, sea falsa o no.
local function realPlate(vehicle)
  return Entity(vehicle).state.aiRealPlate or GetVehicleNumberPlateText(vehicle)
end
```
</Tab>
</Tabs>

## Objetos usables

Registrados a través de la capa de inventario de ai-core, así que funcionan con el inventario que esté en uso: `binoculars`, `firework1`-`firework4`, `newscam`, `newsmic`, `newsboom`, `fakeplate`, `notepad`, `note` (metadata `text` y `description`), `diving_gear`, `diving_fill`.
