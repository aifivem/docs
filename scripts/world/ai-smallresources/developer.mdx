<Callout type="info">
To read the seat belt or gestures from your own script, use the lib's `seatbelt.isOn()` / `seatbelt.onChange(fn)` and `gestures.isHandsUp()` / `gestures.isPointing()` (client; Lua `aiLib.seatbelt`, `aiLib.gestures`). They go through ai-core and work with whichever seat belt or emote script runs. The exports below are what ai-core reads while ai-smallresources answers.
</Callout>

All three exports are on the client, synchronous, and read the local player. `GetSeatbelt` is typed as `AiSmallResourcesClientExports` in `@aicore-fivem/shared`; `IsHandsUp` and `IsPointing` are not typed (use `callExport`).

```ts title="TypeScript"
import { resourceExport, callExport } from "@aicore-fivem/lib/client";
const small = resourceExport("ai-smallresources");
```

## Client exports

### GetSeatbelt

Whether the local player wears a seat belt.

**Side:** Client · **Waits:** no

```ts title="Signature"
GetSeatbelt(): boolean | null
```

```lua title="Lua"
local worn = exports['ai-smallresources']:GetSeatbelt() -- true, false or nil
```

#### Returns

`true` when buckled, `false` when not. `null` when the Seatbelt feature is switched off in the panel, or the player is not in a vehicle with a seat belt.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { seatbelt } from "@aicore-fivem/lib/client";

// A HUD's belt icon: read once, then follow changes.
let worn = seatbelt.isOn();
seatbelt.onChange((value) => {
  worn = value;
});
```
</Tab>
<Tab value="Lua">
```lua
-- A HUD's belt icon: read once, then follow changes.
local worn = aiLib.seatbelt.isOn()
aiLib.seatbelt.onChange(function(value)
  worn = value
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Read it on an action or a vehicle change, never every frame.
</Callout>

### IsHandsUp

Whether the local player has their hands up (the **X** gesture).

**Side:** Client · **Waits:** no

```ts title="Signature"
IsHandsUp(): boolean
```

```lua title="Lua"
local up = exports['ai-smallresources']:IsHandsUp()
```

#### Returns

`true` while the hands are up, `false` otherwise.

### IsPointing

Whether the local player is pointing (the **B** gesture).

**Side:** Client · **Waits:** no

```ts title="Signature"
IsPointing(): boolean
```

```lua title="Lua"
local pointing = exports['ai-smallresources']:IsPointing()
```

#### Returns

`true` while pointing, `false` otherwise.

## Events

### ai-smallresources:seatbelt

Fires on the local client when the seat belt changes. The name is `SEATBELT_EVENT` in `@aicore-fivem/shared`. ai-core passes it on as its own seat belt event, which the lib's `seatbelt.onChange` listens to; prefer that.

**Side:** Client (local event)

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true` buckled, `false` not. `null` while the feature is off or the player is not in a vehicle with a seat belt.', required: true },
  }}
/>

```lua title="Lua"
AddEventHandler('ai-smallresources:seatbelt', function(worn)
  print('seat belt', worn)
end)
```

Every other event of ai-smallresources is internal (its client and its server).

## State bags and metadata

| Name | On | Type | Meaning |
| --- | --- | --- | --- |
| `aiHold` | player | `string \| false` | The news item the player holds (`newscam`, `newsmic`, `newsboom`). |
| `aiCarrying` | player | `number` | The player is carrying someone (their server id). |
| `aiCarriedBy` | player | `number` | The player is carried by someone (their server id). |
| `aiDiving` | player | `boolean` | The player wears the diving gear. |
| `aiRealPlate` | vehicle | `string` | The real plate while a fake plate is fitted. |
| `aiMoored` | vehicle | `boolean` | The boat is tied to a mooring. |
| `diveOxygen` | character metadata (ai-core) | `number` | Seconds of air left in the dive tank. |
| `aiPlayerCount` / `aiMaxPlayers` | GlobalState | `number` | Players online and slots, set while Discord Rich Presence is on. |

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Server: the real plate of a vehicle, fake or not.
export function realPlate(vehicle: number): string {
  const real = Entity(vehicle).state.aiRealPlate as string | undefined;
  return real ?? GetVehicleNumberPlateText(vehicle);
}
```
</Tab>
<Tab value="Lua">
```lua
-- Server: the real plate of a vehicle, fake or not.
local function realPlate(vehicle)
  return Entity(vehicle).state.aiRealPlate or GetVehicleNumberPlateText(vehicle)
end
```
</Tab>
</Tabs>

## Usable items

Registered through ai-core's inventory layer, so they work with whichever inventory runs: `binoculars`, `firework1`-`firework4`, `newscam`, `newsmic`, `newsboom`, `fakeplate`, `notepad`, `note` (metadata `text` and `description`), `diving_gear`, `diving_fill`.
