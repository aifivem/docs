ai-smallresources собирает мелкие функции, которые нужны большинству серверов: ремень безопасности, круиз-контроль, приседание, указание пальцем, поднятые руки, сидение на скамейках, переноска игроков, мелкие предметы, настройки мира GTA, плотность населения, телепорты, лифты и Discord Rich Presence. У каждой функции свой переключатель в панели, поэтому вы выключаете то, что уже делает другой скрипт.

## Что он делает в игре

**Вождение**
- **Ремень безопасности** (**K**): пристёгнутый игрок не может выйти из транспорта и переживает более быстрые аварии. Без ремня авария на скорости выше значения из панели выбрасывает водителя через лобовое стекло. HUD показывают состояние ремня.
- **Круиз-контроль** (**Y**): держит текущую скорость как максимальную скорость транспорта до повторного нажатия.
- **Без пересаживания между сиденьями**, **без радио в транспорте**, **без руления мышью** для наземного транспорта и лодок, **без управления в воздухе** (после прыжка транспорт приземляется так же, как взлетел).
- **Предмет фальшивого номера** (`fakeplate`): ставит случайный номер на транспорт, от которого у вас есть ключи (полоса 6 секунд лицом к транспорту); повторное использование возвращает настоящий номер. Гаражи хранят настоящий номер.
- **Швартовочный трос**: пешком рядом с лодкой в пределах 12 м от швартова (вкладка Moorings) **Tie the boat to the dock** замораживает её, чтобы она не дрейфовала и её нельзя было угнать; **Untie the boat** освобождает её.

**Игрок**
- **Приседание** (**Левый Ctrl**), **указание пальцем** (**B**, видят все), **поднятые руки** (**X**, также в транспорте), **падение** (удерживайте **M** пешком).
- **Сидение на объектах**: стулья, скамейки и табуреты из вкладки Seats (364 модели уже готовы) получают подсказку **Sit down**; **X** встаёт. Если запущен скрипт target, сиденья используют глаз взаимодействия вместо подсказки.
- **Переноска игроков**: пункт радиального меню **Carry** поднимает ближайшего игрока на плечо или кладёт его. Игрок без сознания или в наручниках поднимается сразу; любого другого сначала спрашивают (10 секунд на ответ). После отказа вы ждёте 30 секунд, прежде чем спросить снова.
- **Подножка** (**G** во время бега): сбивает с ног игрока прямо перед вами.
- **Блокировка подглядывания из-за угла**, **бег в помещениях**, **без автоматического шлема**, **головные уборы не слетают**, **без камеры бездействия**, **кик за AFK** через заданное в панели число минут (администраторов никогда не кикает).

**Бой**
- Без боевой стойки после драки, без удара пистолетом, без выглядывания из укрытия вслепую, по желанию без смертельных хедшотов с одного выстрела, без распрыжки, без подбираемых предметов GTA, без оружия из транспорта.

**Предметы**
- `binoculars`: камера с приближением (колёсико мыши приближает, **Backspace** убирает бинокль).
- От `firework1` до `firework4`: ставятся на землю (полоса 3 секунды), срабатывают через 5 секунд; игроки в пределах 400 м их видят.
- `notepad`: пишет страницу, которая становится предметом `note`; использование записки показывает её текст (подсказка инвентаря тоже его показывает).
- `newscam`, `newsmic`, `newsboom`: реквизит съёмочной группы новостей, держится в руке и виден всем. С камерой **H** переключает на вид новостной камеры.
- `diving_gear`: надевает или снимает баллон и маску; пока они надеты, игрок дышит под водой, пока баллон не опустеет. `diving_fill` заправляет баллон. Воздух хранится для каждого персонажа и расходуется только под водой.

**Мир и население**
- Без уровня розыска GTA и полиции ИИ, без полицейского и экстренного транспорта и NPC GTA, области без транспорта, припаркованного GTA (больницы, полицейские участки, тюрьма, базы), без самолётов GTA, без полицейского радио, тихие звуки города, скрытые части HUD GTA, без мусоровозов.
- Плотность пешеходов, людей в сценариях, трафика и припаркованных машин в процентах.

**Места**
- **Телепорты**: подсказка на обоих концах (**Go: ...**) переносит игрока на другой конец. Два уже готовы (офис Weazel News, переработка кокаина).
- **Лифты**: подсказка на каждом этаже (**...: choose a floor**) показывает остальные. Один уже готов (Humane Labs).

**Discord Rich Presence**: название вашего приложения, картинки, две текстовые строки с живыми плейсхолдерами и до двух кнопок-ссылок в профиле Discord каждого игрока.

## Установка

Устанавливается рецептом AI Core. Вручную: `ensure ai-smallresources` после `ai-core`.

Предметы должны быть в списке предметов вашего инвентаря: `binoculars`, `firework1`, `firework2`, `firework3`, `firework4`, `newscam`, `newsmic`, `newsboom`, `fakeplate`, `notepad`, `note`, `diving_gear`, `diving_fill` (в ai-inventory они есть).

## Настройки панели

Админ-панель > **Small features**. Шесть вкладок. Значения по умолчанию берутся из `data/settings.json`.

### Вкладка Teleports

Двери, которые переносят игроков между двумя точками. Одна запись на телепорт (**New teleport** / **Delete teleport**). Подсказка на обоих концах переносит игрока на другой конец.

| Настройка | Что меняет |
| --- | --- |
| Name | Показывается в подсказке (`Go: Weazel News office`). |
| First end | Один конец с направлением, куда смотрит игрок по прибытии. |
| Second end | Другой конец. |
| Jobs | Пользоваться могут только участники этих работ. Оставьте работы и банды пустыми, чтобы было доступно всем. |
| Gangs | Участники этих банд тоже могут пользоваться. |
| Only on duty | Участники работы должны быть на дежурстве в этой работе. |

### Вкладка Elevators

Лифты с несколькими этажами: подсказка на каждом этаже показывает остальные. Одна запись на лифт (**New elevator** / **Delete elevator**).

| Настройка | Что меняет |
| --- | --- |
| Name | Название лифта в подсказке. |
| Floors | Не меньше двух, до 20, сверху вниз или в любом удобном порядке. В каждой строке **Floor name**, **Floor point** (игрок прибывает туда лицом в её направлении) и **Job** (на этот этаж могут ехать только участники этой работы; пусто для всех). |

### Вкладка Moorings

| Настройка | Что меняет |
| --- | --- |
| Name | Название швартова. |
| Mooring spot | Встаньте на краю причала, где стоят лодки. |

| --- | --- | --- |
| Object | Модель стула, скамейки или табурета. | |

| Place straight on the seat | Для табуретов и кабинок, к которым игрок не может подойти; иначе он подходит к сиденью. | выкл. |

### Вкладка Discord

Что показывают профили Discord игроков, пока они играют на этом сервере (Rich Presence).

**Discord application** (приложение Discord): создайте приложение на discord.com/developers (Applications > New Application). Его название является заголовком, который Discord показывает над строками, например название вашего сервера.

| Настройка | Что меняет | По умолчанию |
| --- | --- | --- |
| Discord Rich Presence | Показывает название вашего приложения, картинки, текстовые строки и кнопки в профиле Discord каждого игрока. Нужен id приложения. Выкл.: у игроков остаётся собственное присутствие FiveM. | выкл. |
| Application id | На discord.com/developers откройте своё приложение, General Information, и скопируйте Application ID (от 17 до 20 цифр). Он публичный, это не секрет. | пусто |

**Pictures** (картинки): загрузите картинки в своё приложение в разделе Rich Presence > Art Assets (не меньше 512 x 512 px), затем введите здесь их имена. Новая картинка может появиться в Discord через несколько минут.

| Настройка | Что меняет |
| --- | --- |
| Large picture | Имя Art Asset вашего приложения: большая квадратная картинка рядом с текстом, обычно ваш логотип. Пусто: без картинки. |
| Large picture text | Показывается, когда кто-то наводит мышь на большую картинку. |
| Small picture | Имя Art Asset вашего приложения: маленькая круглая картинка в углу большой. Пусто: без маленькой картинки. |
| Small picture text | Показывается, когда кто-то наводит мышь на маленькую картинку. |

**Text lines** (текстовые строки): две строки под названием приложения; Discord сам считает время игры рядом с ними. Обе строки пусты: собственный текст FiveM.

| Настройка | Что меняет | По умолчанию |
| --- | --- | --- |
| First line | Верхняя строка, до 128 символов. Обновляется сама, когда меняется значение плейсхолдера (улица не чаще раза в 15 секунд). | `{players}/{maxPlayers} players` |
| Second line | Нижняя строка, до 128 символов, с теми же плейсхолдерами. | `Playing as {name}` |

Плейсхолдеры:

| Плейсхолдер | Превращается в |
| --- | --- |
| `{players}` | Игроки онлайн |
| `{maxPlayers}` | Слоты сервера |
| `{name}` | Имя персонажа |
| `{id}` | Серверный id |
| `{job}` | Работа |
| `{street}` | Улица, на которой находится игрок |

**Buttons** (кнопки): до двух кнопок под присутствием, которые открывают ссылку, например приглашение в ваш Discord или сайт. Их видят и нажимают другие люди; самому игроку Discord их не показывает.

| Настройка | Что меняет |
| --- | --- |
| Buttons | Не больше двух, показываются в этом порядке (**Add button**). **Button text**: до 32 символов. **Link**: страница, которую открывает кнопка; должна начинаться с `https://`. |

<Callout type="info">
Выключение Rich Presence возвращает собственное присутствие FiveM, но только если его выставил ai-smallresources. Другой скрипт присутствия, запущенный рядом, никогда не перезаписывается.
</Callout>

Нет.

## Привязки клавиш

Игроки меняют их в настройках клавиш GTA (раздел FiveM); владелец меняет значения по умолчанию в админ-панели (**Keybinds**). Клавиша ничего не делает, пока её функция выключена.

| Клавиша по умолчанию | Что делает |
| --- | --- |
| K | Ремень безопасности |
| Y | Круиз-контроль |
| Левый Ctrl | Приседание |
| B | Указать пальцем |
| X | Поднять руки |
| M (удерживать) | Упасть (пешком) |
| G | Подножка во время бега |
| X | Встать с сиденья |
| H | Вид новостной камеры (пока держите камеру) |
| Backspace | Убрать бинокль |
| Колёсико мыши вверх / вниз | Бинокль: приблизить / отдалить |

## Другие скрипты

- **Эмоции:** когда запущен tgiann-emotes, codem-emotemenu, rpemotes или 0r-animmenu, его поднятые руки и указание пальцем имеют приоритет, а клавиши жестов ai-smallresources остаются выключенными. Слой жестов AI Core отвечает другим скриптам из того, который запущен.
- **Ремень безопасности:** HUD с собственным ремнём безопасности (tgiann-lumihud, tgiann-hudv2, tgiann-modern-hud) или qbx_seatbelt слой ремня безопасности AI Core читает первым; выключите переключатель Seatbelt, если используете один из них.

## Известные ограничения

- Поднятые руки никогда не начинаются поверх анимации другого скрипта (наручники, сдача) и заканчиваются, когда эту анимацию заменяют.
- Области без припаркованного транспорта убирают каждую машину, припаркованную GTA в этой области, а не только экстренные: держите размеры маленькими.
- Если забрать предмет `diving_gear`, пока снаряжение надето, оно не снимается (как в Qbox). Снимает его перезапуск или смена персонажа.
- Фейерверки нельзя ставить из транспорта.
