<Callout type="info">
Aby odczytać pas bezpieczeństwa lub gesty z własnego skryptu, używaj `seatbelt.isOn()` / `seatbelt.onChange(fn)` i `gestures.isHandsUp()` / `gestures.isPointing()` z biblioteki (klient; w Lua `aiLib.seatbelt`, `aiLib.gestures`). Przechodzą przez ai-core i działają z każdym działającym skryptem pasów lub emotek. Poniższe eksporty to to, co czyta ai-core, gdy odpowiada ai-smallresources.
</Callout>

Wszystkie trzy eksporty są na kliencie, synchroniczne i czytają lokalnego gracza. `GetSeatbelt` jest typowany jako `AiSmallResourcesClientExports` w `@aifivem/shared`; `IsHandsUp` i `IsPointing` nie są typowane (używaj `callExport`).

```ts title="TypeScript"
import { resourceExport, callExport } from "@aifivem/lib/client";
const small = resourceExport("ai-smallresources");
```

## Eksporty klienta

### GetSeatbelt

Czy lokalny gracz ma zapięty pas bezpieczeństwa.

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
GetSeatbelt(): boolean | null
```

```lua title="Lua"
local worn = exports['ai-smallresources']:GetSeatbelt() -- true, false albo nil
```

#### Zwraca

`true`, gdy zapięty, `false`, gdy nie. `null`, gdy funkcja Seatbelt jest wyłączona w panelu albo gracz nie jest w pojeździe z pasem bezpieczeństwa.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { seatbelt } from "@aifivem/lib/client";

// Ikona pasa w HUD-zie: odczytaj raz, potem śledź zmiany.
let worn = seatbelt.isOn();
seatbelt.onChange((value) => {
  worn = value;
});
```
</Tab>
<Tab value="Lua">
```lua
-- Ikona pasa w HUD-zie: odczytaj raz, potem śledź zmiany.
local worn = aiLib.seatbelt.isOn()
aiLib.seatbelt.onChange(function(value)
  worn = value
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Odczytuj to przy akcji lub zmianie pojazdu, nigdy w każdej klatce.
</Callout>

### IsHandsUp

Czy lokalny gracz ma ręce w górze (gest **X**).

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
IsHandsUp(): boolean
```

```lua title="Lua"
local up = exports['ai-smallresources']:IsHandsUp()
```

#### Zwraca

`true`, dopóki ręce są w górze, w przeciwnym razie `false`.

### IsPointing

Czy lokalny gracz wskazuje palcem (gest **B**).

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
IsPointing(): boolean
```

```lua title="Lua"
local pointing = exports['ai-smallresources']:IsPointing()
```

#### Zwraca

`true` podczas wskazywania, w przeciwnym razie `false`.

## Zdarzenia

### ai-smallresources:seatbelt

Wywoływane na lokalnym kliencie, gdy zmienia się pas bezpieczeństwa. Nazwa to `SEATBELT_EVENT` w `@aifivem/shared`. ai-core przekazuje je dalej jako własne zdarzenie pasa bezpieczeństwa, którego nasłuchuje `seatbelt.onChange` z biblioteki; wybieraj właśnie to.

**Strona:** klient (zdarzenie lokalne)

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true` zapięty, `false` nie. `null`, gdy funkcja jest wyłączona albo gracz nie jest w pojeździe z pasem bezpieczeństwa.', required: true },
  }}
/>

```lua title="Lua"
AddEventHandler('ai-smallresources:seatbelt', function(worn)
  print('seat belt', worn)
end)
```

Każde inne zdarzenie ai-smallresources jest wewnętrzne (jego klient i jego serwer).

## State bagi i metadane

| Nazwa | Na | Typ | Znaczenie |
| --- | --- | --- | --- |
| `aiHold` | gracz | `string \| false` | Przedmiot reporterski, który trzyma gracz (`newscam`, `newsmic`, `newsboom`). |
| `aiCarrying` | gracz | `number` | Gracz kogoś niesie (jego ID na serwerze). |
| `aiCarriedBy` | gracz | `number` | Gracz jest przez kogoś niesiony (jego ID na serwerze). |
| `aiDiving` | gracz | `boolean` | Gracz ma na sobie sprzęt do nurkowania. |
| `aiRealPlate` | pojazd | `string` | Prawdziwa tablica, gdy założona jest fałszywa. |
| `aiMoored` | pojazd | `boolean` | Łódź jest przycumowana. |
| `diveOxygen` | metadane postaci (ai-core) | `number` | Sekundy powietrza pozostałe w butli do nurkowania. |
| `aiPlayerCount` / `aiMaxPlayers` | GlobalState | `number` | Gracze online i sloty, ustawiane, gdy Discord Rich Presence jest włączone. |

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

```ts
// Serwer: prawdziwa tablica pojazdu, fałszywa czy nie.
export function realPlate(vehicle: number): string {
  const real = Entity(vehicle).state.aiRealPlate as string | undefined;
  return real ?? GetVehicleNumberPlateText(vehicle);
}
```

```lua
-- Serwer: prawdziwa tablica pojazdu, fałszywa czy nie.
local function realPlate(vehicle)
  return Entity(vehicle).state.aiRealPlate or GetVehicleNumberPlateText(vehicle)
end
```
</Tab>

## Przedmioty do użycia

Rejestrowane przez warstwę ekwipunku ai-core, więc działają z każdym działającym ekwipunkiem: `binoculars`, `firework1`-`firework4`, `newscam`, `newsmic`, `newsboom`, `fakeplate`, `notepad`, `note` (metadane `text` i `description`), `diving_gear`, `diving_fill`.
