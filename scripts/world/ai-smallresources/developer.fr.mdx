<Callout type="info">
Pour lire la ceinture de sécurité ou les gestes depuis votre propre script, utilisez `seatbelt.isOn()` / `seatbelt.onChange(fn)` et `gestures.isHandsUp()` / `gestures.isPointing()` de la lib (client ; en Lua `aiLib.seatbelt`, `aiLib.gestures`). Ils passent par ai-core et fonctionnent avec le script de ceinture ou d’emotes qui tourne, quel qu’il soit. Les exports ci-dessous sont ce que lit ai-core tant qu’ai-smallresources répond.
</Callout>

Les trois exports sont côté client, synchrones, et lisent le joueur local. `GetSeatbelt` est typé `AiSmallResourcesClientExports` dans `@aifivem/shared` ; `IsHandsUp` et `IsPointing` ne sont pas typés (utilisez `callExport`).

```ts title="TypeScript"
import { resourceExport, callExport } from "@aifivem/lib/client";
const small = resourceExport("ai-smallresources");
```

## Exports client

### GetSeatbelt

Indique si le joueur local porte une ceinture de sécurité.

**Côté :** client · **Attend :** non

```ts title="Signature"
GetSeatbelt(): boolean | null
```

```lua title="Lua"
local worn = exports['ai-smallresources']:GetSeatbelt() -- true, false ou nil
```

#### Retour

`true` quand il est attaché, `false` sinon. `null` quand la fonctionnalité Seatbelt est désactivée dans le panneau, ou que le joueur n’est pas dans un véhicule équipé d’une ceinture.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { seatbelt } from "@aifivem/lib/client";

// L’icône de ceinture d’un HUD : lire une fois, puis suivre les changements.
let worn = seatbelt.isOn();
seatbelt.onChange((value) => {
  worn = value;
});
```
</Tab>
<Tab value="Lua">
```lua
-- L’icône de ceinture d’un HUD : lire une fois, puis suivre les changements.
local worn = aiLib.seatbelt.isOn()
aiLib.seatbelt.onChange(function(value)
  worn = value
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Lisez-le lors d’une action ou d’un changement de véhicule, jamais à chaque frame.
</Callout>

### IsHandsUp

Indique si le joueur local a les mains en l’air (le geste **X**).

**Côté :** client · **Attend :** non

```ts title="Signature"
IsHandsUp(): boolean
```

```lua title="Lua"
local up = exports['ai-smallresources']:IsHandsUp()
```

#### Retour

`true` tant que les mains sont levées, `false` sinon.

### IsPointing

Indique si le joueur local pointe du doigt (le geste **B**).

**Côté :** client · **Attend :** non

```ts title="Signature"
IsPointing(): boolean
```

```lua title="Lua"
local pointing = exports['ai-smallresources']:IsPointing()
```

#### Retour

`true` pendant le pointage, `false` sinon.

## Events

### ai-smallresources:seatbelt

Se déclenche sur le client local quand la ceinture change. Le nom est `SEATBELT_EVENT` dans `@aifivem/shared`. ai-core le relaie comme son propre event de ceinture, que le `seatbelt.onChange` de la lib écoute ; préférez celui-ci.

**Côté :** client (event local)

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true` attaché, `false` non. `null` tant que la fonctionnalité est désactivée ou que le joueur n’est pas dans un véhicule équipé d’une ceinture.', required: true },
  }}
/>

```lua title="Lua"
AddEventHandler('ai-smallresources:seatbelt', function(worn)
  print('seat belt', worn)
end)
```

Tous les autres events d’ai-smallresources sont internes (son client et son serveur).

## State bags et métadonnées

| Nom | Sur | Type | Signification |
| --- | --- | --- | --- |
| `aiHold` | joueur | `string \| false` | L’objet de reportage que tient le joueur (`newscam`, `newsmic`, `newsboom`). |
| `aiCarrying` | joueur | `number` | Le joueur porte quelqu’un (son id serveur). |
| `aiCarriedBy` | joueur | `number` | Le joueur est porté par quelqu’un (son id serveur). |
| `aiDiving` | joueur | `boolean` | Le joueur porte l’équipement de plongée. |
| `aiRealPlate` | véhicule | `string` | La vraie plaque tant qu’une fausse plaque est posée. |
| `aiMoored` | véhicule | `boolean` | Le bateau est attaché à un amarrage. |
| `diveOxygen` | métadonnée de personnage (ai-core) | `number` | Secondes d’air restantes dans la bouteille de plongée. |
| `aiPlayerCount` / `aiMaxPlayers` | GlobalState | `number` | Joueurs en ligne et places, réglés tant que Discord Rich Presence est activé. |

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Serveur : la vraie plaque d’un véhicule, fausse plaque ou non.
export function realPlate(vehicle: number): string {
  const real = Entity(vehicle).state.aiRealPlate as string | undefined;
  return real ?? GetVehicleNumberPlateText(vehicle);
}
```
</Tab>
<Tab value="Lua">
```lua
-- Serveur : la vraie plaque d’un véhicule, fausse plaque ou non.
local function realPlate(vehicle)
  return Entity(vehicle).state.aiRealPlate or GetVehicleNumberPlateText(vehicle)
end
```
</Tab>
</Tabs>

## Objets utilisables

Enregistrés via la couche inventaire d’ai-core, ils fonctionnent donc avec l’inventaire qui tourne, quel qu’il soit : `binoculars`, `firework1`-`firework4`, `newscam`, `newsmic`, `newsboom`, `fakeplate`, `notepad`, `note` (métadonnées `text` et `description`), `diving_gear`, `diving_fill`.
