ai-pedscale hat keine Exports und keine Events für andere Skripte. Die Größe eines Charakters kann an zwei Stellen gelesen werden.

## Spielerzustand `aiPedScale`

Wird am Spieler gesetzt, wenn sein Charakter lädt, und bei jeder Änderung. `{ height: number, width: number }`, `1` = normal. Wird entfernt, wenn die Größe wieder 1 x 1 ist. Nur vom Server geschrieben.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Client: die Größe eines anderen Spielers (1, wenn nicht skaliert).
export function heightOf(serverId: number): number {
  const scale = Player(serverId).state.aiPedScale as { height: number; width: number } | undefined;
  return scale?.height ?? 1;
}
```
</Tab>
<Tab value="Lua">
```lua
-- Client: die Größe eines anderen Spielers (1, wenn nicht skaliert).
local function heightOf(serverId)
  local scale = Player(serverId).state.aiPedScale
  return scale and scale.height or 1
end
```
</Tab>
</Tabs>

## Charakter-Metadaten `pedScale`

Die gespeicherte Größe in den Charakter-Metadaten von ai-core, `{ height, width }`. Lies sie auf dem Server mit `GetPlayerData(source).metadata.pedScale`.

<Callout type="warn">
Schreibe `pedScale` nicht aus einem anderen Skript: ai-pedscale hält seine eigene Kopie im Speicher und würde die Änderung nicht zeichnen. Nutze das Panel oder die Befehle.
</Callout>
