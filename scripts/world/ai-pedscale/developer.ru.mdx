У ai-pedscale нет экспортов и событий для других скриптов. Размер персонажа можно прочитать в двух местах.

## Состояние игрока `aiPedScale`

Выставляется на игроке, когда загружается его персонаж, и при каждом изменении. `{ height: number, width: number }`, `1` = обычный. Удаляется, когда размер снова 1 x 1. Пишет только сервер.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Клиент: рост другого игрока (1, если не масштабирован).
export function heightOf(serverId: number): number {
  const scale = Player(serverId).state.aiPedScale as { height: number; width: number } | undefined;
  return scale?.height ?? 1;
}
```
</Tab>
<Tab value="Lua">
```lua
-- Клиент: рост другого игрока (1, если не масштабирован).
local function heightOf(serverId)
  local scale = Player(serverId).state.aiPedScale
  return scale and scale.height or 1
end
```
</Tab>
</Tabs>

## Метаданные персонажа `pedScale`

Сохранённый размер в метаданных персонажа ai-core, `{ height, width }`. Читайте его на сервере через `GetPlayerData(source).metadata.pedScale`.

<Callout type="warn">
Не пишите `pedScale` из другого скрипта: ai-pedscale хранит собственную копию в памяти и не отрисует изменение. Используйте панель или команды.
</Callout>
