ai-pedscale’in diğer script’ler için export’u ve event’i yoktur. Bir karakterin boyutu iki yerden okunabilir.

## Oyuncu state’i `aiPedScale`

Oyuncunun karakteri yüklendiğinde ve her değişiklikte oyuncu üzerinde ayarlanır. `{ height: number, width: number }`, `1` = normal. Boyut 1 x 1’e döndüğünde kaldırılır. Sadece server yazar.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Client: başka bir oyuncunun boyu (ölçeklenmemişse 1).
export function heightOf(serverId: number): number {
  const scale = Player(serverId).state.aiPedScale as { height: number; width: number } | undefined;
  return scale?.height ?? 1;
}
```
</Tab>
<Tab value="Lua">
```lua
-- Client: başka bir oyuncunun boyu (ölçeklenmemişse 1).
local function heightOf(serverId)
  local scale = Player(serverId).state.aiPedScale
  return scale and scale.height or 1
end
```
</Tab>
</Tabs>

## Karakter metadata’sı `pedScale`

ai-core’un karakter metadata’sında saklanan boyut, `{ height, width }`. Server’da `GetPlayerData(source).metadata.pedScale` ile oku.

<Callout type="warn">
`pedScale` değerini başka bir script’ten yazma: ai-pedscale bellekte kendi kopyasını tutar ve değişikliği çizmez. Paneli ya da komutları kullan.
</Callout>
