ai-pedscale n’a ni export ni event pour les autres scripts. La taille d’un personnage peut se lire à deux endroits.

## State de joueur `aiPedScale`

Réglé sur le joueur au chargement de son personnage et à chaque changement. `{ height: number, width: number }`, `1` = normal. Retiré quand la taille revient à 1 x 1. Écrit uniquement par le serveur.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Client : la hauteur d’un autre joueur (1 s’il n’est pas redimensionné).
export function heightOf(serverId: number): number {
  const scale = Player(serverId).state.aiPedScale as { height: number; width: number } | undefined;
  return scale?.height ?? 1;
}
```
</Tab>
<Tab value="Lua">
```lua
-- Client : la hauteur d’un autre joueur (1 s’il n’est pas redimensionné).
local function heightOf(serverId)
  local scale = Player(serverId).state.aiPedScale
  return scale and scale.height or 1
end
```
</Tab>
</Tabs>

## Métadonnée de personnage `pedScale`

La taille stockée dans les métadonnées de personnage d’ai-core, `{ height, width }`. Lisez-la sur le serveur avec `GetPlayerData(source).metadata.pedScale`.

<Callout type="warn">
N’écrivez pas `pedScale` depuis un autre script : ai-pedscale garde sa propre copie en mémoire et ne dessinerait pas le changement. Utilisez le panneau ou les commandes.
</Callout>
