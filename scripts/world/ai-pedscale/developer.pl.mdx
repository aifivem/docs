ai-pedscale nie ma eksportów ani zdarzeń dla innych skryptów. Rozmiar postaci można odczytać w dwóch miejscach.

## Stan gracza `aiPedScale`

Ustawiany na graczu, gdy jego postać się wczytuje, i przy każdej zmianie. `{ height: number, width: number }`, `1` = normalnie. Usuwany, gdy rozmiar wraca do 1 x 1. Zapisywany tylko przez serwer.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Klient: wzrost innego gracza (1, gdy nie jest skalowany).
export function heightOf(serverId: number): number {
  const scale = Player(serverId).state.aiPedScale as { height: number; width: number } | undefined;
  return scale?.height ?? 1;
}
```
</Tab>
<Tab value="Lua">
```lua
-- Klient: wzrost innego gracza (1, gdy nie jest skalowany).
local function heightOf(serverId)
  local scale = Player(serverId).state.aiPedScale
  return scale and scale.height or 1
end
```
</Tab>
</Tabs>

## Metadane postaci `pedScale`

Zapisany rozmiar w metadanych postaci ai-core, `{ height, width }`. Odczytuj go na serwerze przez `GetPlayerData(source).metadata.pedScale`.

<Callout type="warn">
Nie zapisuj `pedScale` z innego skryptu: ai-pedscale trzyma własną kopię w pamięci i nie narysowałby zmiany. Używaj panelu lub komend.
</Callout>
