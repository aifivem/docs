ai-pedscale no tiene exports ni eventos para otros scripts. El tamaño de un personaje se puede leer en dos sitios.

## Estado de jugador `aiPedScale`

Se fija en el jugador cuando carga su personaje y en cada cambio. `{ height: number, width: number }`, `1` = normal. Se quita cuando el tamaño vuelve a 1 x 1. Solo lo escribe el servidor.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Cliente: la altura de otro jugador (1 si no está escalado).
export function heightOf(serverId: number): number {
  const scale = Player(serverId).state.aiPedScale as { height: number; width: number } | undefined;
  return scale?.height ?? 1;
}
```
</Tab>
<Tab value="Lua">
```lua
-- Cliente: la altura de otro jugador (1 si no está escalado).
local function heightOf(serverId)
  local scale = Player(serverId).state.aiPedScale
  return scale and scale.height or 1
end
```
</Tab>
</Tabs>

## Metadata del personaje `pedScale`

El tamaño guardado en la metadata de personaje de ai-core, `{ height, width }`. Léelo en el servidor con `GetPlayerData(source).metadata.pedScale`.

<Callout type="warn">
No escribas `pedScale` desde otro script: ai-pedscale guarda su propia copia en memoria y no dibujaría el cambio. Usa el panel o los comandos.
</Callout>
