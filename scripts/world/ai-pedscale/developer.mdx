ai-pedscale has no exports and no events for other scripts. A character's size can be read in two places.

## Player state `aiPedScale`

Set on the player when their character loads and on every change. `{ height: number, width: number }`, `1` = normal. Removed when the size is back to 1 x 1. Written by the server only.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Client: the height of another player (1 when not scaled).
export function heightOf(serverId: number): number {
  const scale = Player(serverId).state.aiPedScale as { height: number; width: number } | undefined;
  return scale?.height ?? 1;
}
```
</Tab>
<Tab value="Lua">
```lua
-- Client: the height of another player (1 when not scaled).
local function heightOf(serverId)
  local scale = Player(serverId).state.aiPedScale
  return scale and scale.height or 1
end
```
</Tab>
</Tabs>

## Character metadata `pedScale`

The stored size in ai-core's character metadata, `{ height, width }`. Read it on the server with `GetPlayerData(source).metadata.pedScale`.

<Callout type="warn">
Do not write `pedScale` from another script: ai-pedscale keeps its own copy in memory and would not draw the change. Use the panel or the commands.
</Callout>
