O ai-pedscale não tem exports nem eventos para outros scripts. O tamanho de um personagem pode ser lido em dois lugares.

## State do jogador `aiPedScale`

Definido no jogador quando o personagem dele carrega e a cada mudança. `{ height: number, width: number }`, `1` = normal. Removido quando o tamanho volta a 1 x 1. Escrito só pelo servidor.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Cliente: a altura de outro jogador (1 quando não está escalado).
export function heightOf(serverId: number): number {
  const scale = Player(serverId).state.aiPedScale as { height: number; width: number } | undefined;
  return scale?.height ?? 1;
}
```
</Tab>
<Tab value="Lua">
```lua
-- Cliente: a altura de outro jogador (1 quando não está escalado).
local function heightOf(serverId)
  local scale = Player(serverId).state.aiPedScale
  return scale and scale.height or 1
end
```
</Tab>
</Tabs>

## Metadata de personagem `pedScale`

O tamanho guardado na metadata de personagem do ai-core, `{ height, width }`. Leia-o no servidor com `GetPlayerData(source).metadata.pedScale`.

<Callout type="warn">
Não escreva `pedScale` a partir de outro script: o ai-pedscale mantém sua própria cópia na memória e não desenharia a mudança. Use o painel ou os comandos.
</Callout>
