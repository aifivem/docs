ai-pedscale makes characters taller, shorter, wider or thinner. Admins set the size from the panel or with commands; it stays on the character across restarts and every player near sees it.

## What it does in the game

- **Height and width.** `1` is the normal size. Height `0.85` is 15 % shorter, `1.1` is 10 % taller. Width scales on top of height.
- **Seen by everyone.** Other players' sizes are drawn within the panel's draw distance; further away everyone looks normal.
- **Kept.** The size is saved on the character (ai-core metadata), so it comes back on every login and restart.

<Callout type="warn">
Only the look changes: hitboxes, collisions and aiming stay at the normal size; some animations and sitting in a vehicle show the normal size for a moment; wider characters glitch more than taller or shorter ones. That is why width starts switched off.
</Callout>

## Installation

Installed by the AI Core recipe. By hand: `ensure ai-pedscale` after `ai-core`. No database table.

## Panel settings

Admin panel > **Character size**.

### Tab: Size

How tall and how wide characters may be made, and who may use /setheight and /setwidth.

**Commands**: `/setheight <size> [id]`, `/setwidth <size> [id]` and `/resetscale [id]`. Admins can always change every size in the Change a size tab.

| Setting | What it changes | Default |
| --- | --- | --- |
| Who may use them | **Admins only** or **Everyone (own size)**. Everyone: each player changes only their own size, admins anyone's. Applies after the script restarts. | Admins only |

**Height**: 1 is the normal height; the character keeps it on every server restart.

| Setting | What it changes | Unit | Default |
| --- | --- | --- | --- |
| Allow height changes | Off: /setheight is refused (sizes already set stay). | on / off | on |
| Smallest | The shortest a character can be made (0.85 = 15 % shorter). 0.5-1, steps of 0.01. | x | 0.85 |
| Largest | The tallest a character can be made (1.1 = 10 % taller). 1-1.5, steps of 0.01. | x | 1.1 |

**Width**: width scales on top of height; it glitches more, so it starts switched off.

| Setting | What it changes | Unit | Default |
| --- | --- | --- | --- |
| Allow width changes | Off: /setwidth is refused and widths are drawn as normal. | on / off | off |
| Smallest | The thinnest a character can be made. 0.5-1. | x | 0.9 |
| Largest | The widest a character can be made. 1-1.5. | x | 1.15 |
| Drawn within | Other players' sizes are drawn this close; further away everyone looks normal (saves client time). 20-300, steps of 10. | m | 100 |

### Tab: Players

Everyone online and their size right now (1 = normal): **Id**, **Character**, **Height**, **Width**. Read only; change a size in the next tab.

### Tab: Change a size

Pick an online player, then change their height or width: it applies at once and stays on their character. The limits and on / off switches come from the Size tab.

| Setting | What it changes | Unit |
| --- | --- | --- |
| Player | Search a name or citizen id. Players online when the panel opened; reopen the panel for players who joined since. | |
| Height | 1 = normal height. | x |
| Width | 1 = normal width; only drawn while width changes are allowed. | x |

## Commands

| Command | Arguments | Who | What it does |
| --- | --- | --- | --- |
| `/setheight` | `<value>` size (1 = normal), `[id]` player server id (empty: yourself) | Admins (`ai.admin`); with **Everyone (own size)**, every player for their own size | Set a character's height. Refused outside the panel's limits or while height changes are off. |
| `/setwidth` | `<value>`, `[id]` | Same | Set a character's width. Refused outside the limits or while width changes are off. |
| `/resetscale` | `[id]` | Same | Give a character the normal size again. |

From the server console, the id is required.

## Keybinds

None.

## Logs

Every size change goes to the `sizes` log channel: who changed it, whose size, and the new size.

## Known limits

- Hitboxes, collisions and aiming stay at the normal size.
- Changing **Who may use them** takes effect only after the script restarts.
