## Varsayılan tuşlar

Her oyuncu her tuşu GTA’nın tuş ayarlarından değiştirebilir; varsayılanı sunucu sahibi admin panelinden (**Tuşlar**) değiştirir.

| Tuş | Eylem |
| --- | --- |
| F10 | Admin paneli (adminler) |
| F9 | Admin hızlı menüsü (adminler) |
| F1 | Radyal menü |
| F2 | Envanter |
| F6 | Polis menüsü (mesaide) |
| E | Ekrandaki istemle etkileşim |
| Home (basılı tut) | Skor tablosu |
| Backspace | Süren eylemi iptal et |
