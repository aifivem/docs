<Callout type="info">
Чтобы выдать, забрать или проверить ключи из своего скрипта, используйте `vehicleKeys.give(source, vehicle, purpose)`, `vehicleKeys.remove` и `vehicleKeys.has` из lib (сервер). Они идут через слой ключей ai-core и работают с любым скриптом ключей, который запущен на сервере. Экспорты ниже являются тем, что вызывает этот слой, пока ai-vehiclekeys является активной системой ключей.
</Callout>

Все экспорты серверные, синхронные и отвечают и под `ai-vehiclekeys`, и под `qbx_vehiclekeys`. Транспорт задаётся хэндлом серверной сущности (число) или номером (текст). Номера сравниваются в нормализованном виде (пробелы и регистр не важны).

```ts title="TypeScript"
import { resourceExport, callExport } from "@aifivem/lib/server";
const keys = resourceExport("ai-vehiclekeys"); // типизированы: HasKeys, GiveKeys, RemoveKeys
// SetLockState и IsPlayerNearVehicle не типизированы: callExport("ai-vehiclekeys", "SetLockState", vehicle, "lock")
```

## Серверные экспорты

### HasKeys

Есть ли у игрока ключ от транспорта: как у владельца, как у участника работы или банды, которой он принадлежит, или через ключ, выданный в эту сессию.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
HasKeys(source: number, vehicle: number | string): boolean
```

```lua title="Lua"
local has = exports['ai-vehiclekeys']:HasKeys(source, vehicle)
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
    vehicle: { type: 'number | string', description: 'Серверная сущность транспорта или номер.', required: true },
  }}
/>

#### Возвращает

`true`, если у игрока есть ключ. Иначе `false`, в том числе для несуществующей сущности.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const keys = resourceExport("ai-vehiclekeys");

onNet("myscript:openTrunk", (netId: number) => {
  const source = globalThis.source;
  const vehicle = NetworkGetEntityFromNetworkId(netId);
  if (!keys.HasKeys(source, vehicle)) return;
  // ... открыть багажник
});
```
</Tab>
<Tab value="Lua">
```lua
RegisterNetEvent('myscript:openTrunk', function(netId)
  local source = source
  local vehicle = NetworkGetEntityFromNetworkId(netId)
  if not exports['ai-vehiclekeys']:HasKeys(source, vehicle) then return end
  -- ... открыть багажник
end)
```
</Tab>
</Tabs>

### GiveKeys

Выдаёт игроку ключ на эту сессию. Игрок хранит его, пока не выйдет с сервера или не сменит персонажа. Выдача ключа, который у игрока уже есть, ничего не делает.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
GiveKeys(source: number, vehicle: number | string): void
```

```lua title="Lua"
exports['ai-vehiclekeys']:GiveKeys(source, vehicle)
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
    vehicle: { type: 'number | string', description: 'Серверная сущность транспорта или номер.', required: true },
  }}
/>

#### Возвращает

Ничего. Если игрок прямо сейчас сидит в этом транспорте, его клиенту сообщается (`ai-vehiclekeys:client:granted`): блокировка двигателя снимается, и двигатель заводится.

### RemoveKeys

Забирает у игрока ключ сессии. Ключи владения (владелец, автопарк работы или банды) забрать нельзя: они следуют за владельцем транспорта.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
RemoveKeys(source: number, vehicle: number | string): void
```

```lua title="Lua"
exports['ai-vehiclekeys']:RemoveKeys(source, vehicle)
```

#### Возвращает

Ничего.

### SetLockState

Запирает или отпирает транспорт на сервере без какой-либо проверки ключа.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
SetLockState(vehicle: number, state: "lock" | "unlock" | boolean | number): void
```

```lua title="Lua"
exports['ai-vehiclekeys']:SetLockState(vehicle, 'lock')
```

#### Параметры

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Серверная сущность транспорта. Номер здесь не принимается.', required: true },
    state: { type: '"lock" | true | 2 | any', description: '`"lock"`, `true` или `2` запирают двери. Любое другое значение отпирает их.', required: true },
  }}
/>

#### Возвращает

Ничего. Несуществующая сущность ничего не делает.

### IsPlayerNearVehicle

Стоит ли игрок в пределах 5 м от транспорта.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
IsPlayerNearVehicle(source: number, vehicle: number): boolean
```

```lua title="Lua"
local near = exports['ai-vehiclekeys']:IsPlayerNearVehicle(source, vehicle)
```

#### Возвращает

`true` в пределах 5 м. `false`, если дальше или если любой из аргументов не число.

## События

Собственные события ai-vehiclekeys внутренние (клиентские колбэки между его клиентом и сервером). Не вызывайте их из других скриптов.

| Имя | Тип | Что делает |
| --- | --- | --- |
| `ai-vehiclekeys:check` | client callback | `(netId) -> boolean`: есть ли у игрока ключ, запрашивается, когда он садится. |
| `ai-vehiclekeys:toggleLock` | client callback | `(netId) -> { ok, locked? }`: клавиша замка. |
| `ai-vehiclekeys:giveNearest` | client callback | `(netId) -> { ok }`: передать ключи ближайшему игроку. |
| `ai-vehiclekeys:client:granted` | сервер к клиенту | `(netId)`: ключ пришёл, пока игрок сидит в этом транспорте; двигатель может завестись. |

## Используемый предмет

`lockpick` регистрируется как используемый предмет через слой инвентаря ai-core. Предмет расходуется, только когда ломается.
