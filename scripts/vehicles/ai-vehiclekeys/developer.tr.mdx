<Callout type="info">
Kendi script’inden anahtar vermek, almak ya da kontrol etmek için lib’in `vehicleKeys.give(source, vehicle, purpose)`, `vehicleKeys.remove` ve `vehicleKeys.has` fonksiyonlarını kullan (server). Bunlar ai-core’un anahtar katmanından geçer ve server hangi anahtar script’ini çalıştırıyorsa onunla çalışır. Aşağıdaki export’lar, aktif anahtar sistemi ai-vehiclekeys iken bu katmanın çağırdıklarıdır.
</Callout>

Bütün export’lar server’dadır, senkrondur ve hem `ai-vehiclekeys` hem `qbx_vehiclekeys` adı altında cevap verir. Araç, server entity handle’ı (number) ya da plakadır (text). Plakalar normalize edilerek karşılaştırılır (boşluklar ve büyük/küçük harf önemli değildir).

```ts title="TypeScript"
import { resourceExport, callExport } from "@aifivem/lib/server";
const keys = resourceExport("ai-vehiclekeys"); // tipli: HasKeys, GiveKeys, RemoveKeys
// SetLockState ve IsPlayerNearVehicle tipli değil: callExport("ai-vehiclekeys", "SetLockState", vehicle, "lock")
```

## Server export’ları

### HasKeys

Bir oyuncunun bir aracın anahtarını tutup tutmadığı: sahibi olarak, sahibi olan meslek veya çetenin üyesi olarak ya da bu oturumda verilmiş bir anahtarla.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
HasKeys(source: number, vehicle: number | string): boolean
```

```lua title="Lua"
local has = exports['ai-vehiclekeys']:HasKeys(source, vehicle)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    vehicle: { type: 'number | string', description: 'Server’daki bir araç entity’si ya da bir plaka.', required: true },
  }}
/>

#### Dönüş değeri

Oyuncuda anahtar varsa `true`. Aksi halde `false`; var olmayan bir entity için de.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const keys = resourceExport("ai-vehiclekeys");

onNet("myscript:openTrunk", (netId: number) => {
  const source = globalThis.source;
  const vehicle = NetworkGetEntityFromNetworkId(netId);
  if (!keys.HasKeys(source, vehicle)) return;
  // ... bagajı aç
});
```
</Tab>
<Tab value="Lua">
```lua
RegisterNetEvent('myscript:openTrunk', function(netId)
  local source = source
  local vehicle = NetworkGetEntityFromNetworkId(netId)
  if not exports['ai-vehiclekeys']:HasKeys(source, vehicle) then return end
  -- ... bagajı aç
end)
```
</Tab>
</Tabs>

### GiveKeys

Oyuncuya bu oturum için bir anahtar verir. Oyuncu server’dan çıkana ya da karakter değiştirene kadar onu tutar. Oyuncunun zaten tuttuğu bir anahtarı vermek hiçbir şey yapmaz.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
GiveKeys(source: number, vehicle: number | string): void
```

```lua title="Lua"
exports['ai-vehiclekeys']:GiveKeys(source, vehicle)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    vehicle: { type: 'number | string', description: 'Server’daki bir araç entity’si ya da bir plaka.', required: true },
  }}
/>

#### Dönüş değeri

Hiçbir şey. Oyuncu şu an o araçta oturuyorsa client’ına haber verilir (`ai-vehiclekeys:client:granted`): motor engeli kalkar ve motor çalışır.

### RemoveKeys

Oyuncudan bir oturum anahtarını alır. Sahiplik anahtarları (sahip, meslek ya da çete filosu) alınamaz: aracın sahibini takip ederler.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
RemoveKeys(source: number, vehicle: number | string): void
```

```lua title="Lua"
exports['ai-vehiclekeys']:RemoveKeys(source, vehicle)
```

#### Dönüş değeri

Hiçbir şey.

### SetLockState

Bir aracı server’da, hiçbir anahtar kontrolü yapmadan kilitler ya da açar.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
SetLockState(vehicle: number, state: "lock" | "unlock" | boolean | number): void
```

```lua title="Lua"
exports['ai-vehiclekeys']:SetLockState(vehicle, 'lock')
```

#### Parametreler

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Server’daki bir araç entity’si. Burada plaka kabul edilmez.', required: true },
    state: { type: '"lock" | true | 2 | any', description: '`"lock"`, `true` ya da `2` kapıları kilitler. Başka her değer açar.', required: true },
  }}
/>

#### Dönüş değeri

Hiçbir şey. Var olmayan bir entity’de hiçbir şey yapmaz.

### IsPlayerNearVehicle

Bir oyuncunun bir araca 5 m mesafede durup durmadığı.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
IsPlayerNearVehicle(source: number, vehicle: number): boolean
```

```lua title="Lua"
local near = exports['ai-vehiclekeys']:IsPlayerNearVehicle(source, vehicle)
```

#### Dönüş değeri

5 m içindeyse `true`. Daha uzaktaysa ya da argümanlardan biri number değilse `false`.

## Event’ler

ai-vehiclekeys’in kendi event’leri iç kullanım içindir (kendi client’ı ile server’ı arasındaki client callback’leri). Başka script’lerden çağırma.

| Ad | Tür | Ne yapar |
| --- | --- | --- |
| `ai-vehiclekeys:check` | client callback’i | `(netId) -> boolean`: oyuncunun anahtar tutup tutmadığı, bir koltuğa oturduğunda sorulur. |
| `ai-vehiclekeys:toggleLock` | client callback’i | `(netId) -> { ok, locked? }`: kilit tuşu. |
| `ai-vehiclekeys:giveNearest` | client callback’i | `(netId) -> { ok }`: anahtarları en yakındaki oyuncuya ver. |
| `ai-vehiclekeys:client:granted` | server’dan client’a | `(netId)`: o araçta otururken bir anahtar geldi; motor çalışabilir. |

## Kullanılabilir eşya

`lockpick`, ai-core’un envanter katmanı üzerinden kullanılabilir eşya olarak kaydedilir. Eşya sadece kırıldığında harcanır.
