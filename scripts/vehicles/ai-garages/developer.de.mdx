<Callout type="info">
Aus deinem eigenen Skript nutzt du den Layer `garages` der Lib (Server): `garages.impound(vehicle, by?)`, `garages.store(vehicle, garage?, by?)`, `garages.open(source, garage?)` und `garages.stored(source)`. Er funktioniert mit dem Garagenskript, das der Server gerade nutzt. Die Exports unten sind das, was der Layer aufruft, solange ai-garages das aktive Garagenskript ist. ai-garages kann seine Liste nicht aus der Ferne öffnen, daher antwortet `garages.open` damit mit `false`.
</Callout>

Typisiert als `AiGaragesServerExports` in `@aicore-fivem/shared` (`garages.ts`). Alle drei sind synchron.

```ts title="TypeScript"
import { resourceExport } from "@aicore-fivem/lib/server";
const garages = resourceExport("ai-garages");
```

## Server-Exports

### ImpoundVehicle

Schickt ein Fahrzeug im Besitz in den Abschlepphof: speichert seinen Zustand (Sprit, Motor, Karosserie), löscht die Entity und setzt seinen Status auf `impound`. Der Besitzer bekommt es an einem Abschlepphof gegen die Gebühr zurück.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
ImpoundVehicle(vehicle: number): boolean
```

```lua title="Lua"
local ok = exports['ai-garages']:ImpoundVehicle(vehicle)
```

#### Parameter

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Eine serverseitige Fahrzeug-Entity.', required: true },
  }}
/>

#### Rückgabewert

`true`, wenn es abgeschleppt wurde. `false`, wenn die Entity nicht existiert oder kein Fahrzeug im Besitz von ai-vehicles ist; lösche es dann selbst.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const garages = resourceExport("ai-garages");

export function towAway(vehicle: number): void {
  if (!garages.ImpoundVehicle(vehicle)) DeleteEntity(vehicle); // nicht im Besitz: einfach entfernen
}
```
</Tab>
<Tab value="Lua">
```lua
local function towAway(vehicle)
  if not exports['ai-garages']:ImpoundVehicle(vehicle) then
    DeleteEntity(vehicle) -- nicht im Besitz: einfach entfernen
  end
end
```
</Tab>
</Tabs>

### StoreVehicle

Parkt ein Fahrzeug im Besitz in einer der Garagen des Panels: speichert seinen Zustand, löscht die Entity, setzt seinen Status auf `garage`.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
StoreVehicle(vehicle: number, garage: string): boolean
```

```lua title="Lua"
local ok = exports['ai-garages']:StoreVehicle(vehicle, garage)
```

#### Parameter

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Eine serverseitige Fahrzeug-Entity.', required: true },
    garage: { type: 'string', description: 'Eine Garagen-ID aus dem Panel (`"pillbox"`, `"legion"`). Abschlepphöfe werden abgelehnt.', required: true },
  }}
/>

#### Rückgabewert

`true`, wenn es abgestellt wurde. `false` bei einem Fahrzeug, das nicht im Besitz ist, einer Garagen-ID, die nicht existiert, oder einem Abschlepphof.

### GetStoredVehicles

Die Fahrzeuge des Charakters eines Spielers, die nicht draußen sind: in einer Garage geparkt oder wartend im Abschlepphof. Fuhrpark-Fahrzeuge sind nicht enthalten.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
GetStoredVehicles(source: number): GaragedVehicle[]
```

```lua title="Lua"
local list = exports['ai-garages']:GetStoredVehicles(source)
```

#### Rückgabewert

Ein Array von `GaragedVehicle`. Leer, wenn der Spieler keinen geladenen Charakter hat.

#### GaragedVehicle

<TypeTable
  type={{
    plate: { type: 'string', description: 'Das Kennzeichen.', required: true },
    model: { type: 'string | null', description: 'Der Spawn-Name (`"sultan"`).', required: true },
    garage: { type: 'string | null', description: 'Die Garagen-ID; `null`, wenn es keine hat (abgeschleppte Fahrzeuge).', required: true },
    impounded: { type: 'boolean', description: '`true`, wenn es im Abschlepphof wartet.', required: true },
  }}
/>

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const list = garages.GetStoredVehicles(source);
const impounded = list.filter((v) => v.impounded).map((v) => v.plate);
console.log(`impounded: ${impounded.join(", ") || "none"}`);
```
</Tab>
<Tab value="Lua">
```lua
local impounded = {}
for _, v in ipairs(exports['ai-garages']:GetStoredVehicles(source)) do
  if v.impounded then impounded[#impounded + 1] = v.plate end
end
print('impounded: ' .. (#impounded > 0 and table.concat(impounded, ', ') or 'none'))
```
</Tab>
</Tabs>

## Events

Die Callbacks von ai-garages sind intern (von seinem Client an seinen Server). Rufe sie nicht aus anderen Skripten auf.

| Name | Art | Was es macht |
| --- | --- | --- |
| `ai-garages:list` | Client-Callback | `(garageId)`: die Fahrzeuge, die der Spieler dort herausholen kann. Begrenzt auf 2 pro 2 Sekunden. |
| `ai-garages:takeOut` | Client-Callback | `(garageId, vehicleId)`: spawnt das Fahrzeug am Ausfahrtspunkt. |
| `ai-garages:park` | Client-Callback | `(garageId, netId, props)`: parkt das Fahrzeug, das der Spieler fährt. |
