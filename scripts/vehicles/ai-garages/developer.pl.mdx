<Callout type="info">
Z własnego skryptu używaj warstwy `garages` z biblioteki (serwer): `garages.impound(vehicle, by?)`, `garages.store(vehicle, garage?, by?)`, `garages.open(source, garage?)` i `garages.stored(source)`. Działa z każdym skryptem garaży, którego używa serwer. Poniższe eksporty to to, co wywołuje ta warstwa, gdy ai-garages jest aktywnym skryptem garaży. ai-garages nie potrafi otworzyć swojej listy z daleka, więc `garages.open` odpowiada z nim `false`.
</Callout>

Typowane jako `AiGaragesServerExports` w `@aifivem/shared` (`garages.ts`). Wszystkie trzy są synchroniczne.

```ts title="TypeScript"
import { resourceExport } from "@aifivem/lib/server";
const garages = resourceExport("ai-garages");
```

## Eksporty serwera

### ImpoundVehicle

Wysyła posiadany pojazd na parking policyjny: zapisuje jego stan (paliwo, silnik, karoseria), usuwa encję i ustawia jego stan na `impound`. Właściciel odbiera go na parkingu policyjnym za opłatą.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
ImpoundVehicle(vehicle: number): boolean
```

```lua title="Lua"
local ok = exports['ai-garages']:ImpoundVehicle(vehicle)
```

#### Parametry

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Encja pojazdu po stronie serwera.', required: true },
  }}
/>

#### Zwraca

`true`, gdy pojazd został odholowany. `false`, gdy encja nie istnieje albo nie jest posiadanym pojazdem z ai-vehicles; wtedy usuń ją sam.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const garages = resourceExport("ai-garages");

export function towAway(vehicle: number): void {
  if (!garages.ImpoundVehicle(vehicle)) DeleteEntity(vehicle); // nieposiadany: po prostu go usuń
}
```
</Tab>
<Tab value="Lua">
```lua
local function towAway(vehicle)
  if not exports['ai-garages']:ImpoundVehicle(vehicle) then
    DeleteEntity(vehicle) -- nieposiadany: po prostu go usuń
  end
end
```
</Tab>
</Tabs>

### StoreVehicle

Parkuje posiadany pojazd w jednym z garaży z panelu: zapisuje jego stan, usuwa encję, ustawia jego stan na `garage`.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
StoreVehicle(vehicle: number, garage: string): boolean
```

```lua title="Lua"
local ok = exports['ai-garages']:StoreVehicle(vehicle, garage)
```

#### Parametry

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Encja pojazdu po stronie serwera.', required: true },
    garage: { type: 'string', description: 'ID garażu z panelu (`"pillbox"`, `"legion"`). Parkingi policyjne są odrzucane.', required: true },
  }}
/>

#### Zwraca

`true`, gdy pojazd został zaparkowany. `false` dla pojazdu, który nie jest posiadany, nieistniejącego ID garażu lub parkingu policyjnego.

### GetStoredVehicles

Pojazdy postaci gracza, które nie są wyjęte: zaparkowane w garażu lub czekające na parkingu policyjnym. Pojazdy flot nie są uwzględniane.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
GetStoredVehicles(source: number): GaragedVehicle[]
```

```lua title="Lua"
local list = exports['ai-garages']:GetStoredVehicles(source)
```

#### Zwraca

Tablica `GaragedVehicle`. Pusta, gdy gracz nie ma wczytanej postaci.

#### GaragedVehicle

<TypeTable
  type={{
    plate: { type: 'string', description: 'Tablica rejestracyjna.', required: true },
    model: { type: 'string | null', description: 'Nazwa spawnu (`"sultan"`).', required: true },
    garage: { type: 'string | null', description: 'ID garażu; `null`, gdy go nie ma (pojazdy odholowane).', required: true },
    impounded: { type: 'boolean', description: '`true`, gdy czeka na parkingu policyjnym.', required: true },
  }}
/>

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const list = garages.GetStoredVehicles(source);
const impounded = list.filter((v) => v.impounded).map((v) => v.plate);
console.log(`impounded: ${impounded.join(", ") || "none"}`);
```
</Tab>
<Tab value="Lua">
```lua
local impounded = {}
for _, v in ipairs(exports['ai-garages']:GetStoredVehicles(source)) do
  if v.impounded then impounded[#impounded + 1] = v.plate end
end
print('impounded: ' .. (#impounded > 0 and table.concat(impounded, ', ') or 'none'))
```
</Tab>
</Tabs>

## Zdarzenia

Callbacki ai-garages są wewnętrzne (od jego klienta do jego serwera). Nie wywołuj ich z innych skryptów.

| Nazwa | Rodzaj | Co robi |
| --- | --- | --- |
| `ai-garages:list` | callback klienta | `(garageId)`: pojazdy, które gracz może tam wyjąć. Limit 2 na 2 sekundy. |
| `ai-garages:takeOut` | callback klienta | `(garageId, vehicleId)`: tworzy pojazd w punkcie wyjazdu. |
| `ai-garages:park` | callback klienta | `(garageId, netId, props)`: parkuje pojazd, którym jedzie gracz. |
