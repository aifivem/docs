<Callout type="info">
Kendi script’inden lib’in `garages` katmanını kullan (server): `garages.impound(vehicle, by?)`, `garages.store(vehicle, garage?, by?)`, `garages.open(source, garage?)` ve `garages.stored(source)`. Server hangi garaj script’ini çalıştırıyorsa onunla çalışır. Aşağıdaki export’lar, aktif garaj script’i ai-garages iken katmanın çağırdıklarıdır. ai-garages listesini uzaktan açamaz, bu yüzden onunla `garages.open` `false` döner.
</Callout>

`@aifivem/shared` içinde (`garages.ts`) `AiGaragesServerExports` olarak tiplenmiştir. Üçü de senkrondur.

```ts title="TypeScript"
import { resourceExport } from "@aifivem/lib/server";
const garages = resourceExport("ai-garages");
```

## Server export’ları

### ImpoundVehicle

Sahipli bir aracı çekilmiş araç otoparkına gönderir: durumunu (yakıt, motor, kaporta) kaydeder, entity’yi siler ve durumunu `impound` yapar. Sahibi aracı ücret karşılığında bir çekilmiş araç otoparkından geri alır.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
ImpoundVehicle(vehicle: number): boolean
```

```lua title="Lua"
local ok = exports['ai-garages']:ImpoundVehicle(vehicle)
```

#### Parametreler

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Server’daki bir araç entity’si.', required: true },
  }}
/>

#### Dönüş değeri

Otoparka çekildiyse `true`. Entity yoksa ya da ai-vehicles’ın sahipli bir aracı değilse `false`; o durumda onu kendin sil.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const garages = resourceExport("ai-garages");

export function towAway(vehicle: number): void {
  if (!garages.ImpoundVehicle(vehicle)) DeleteEntity(vehicle); // sahipli değil: sadece kaldır
}
```
</Tab>
<Tab value="Lua">
```lua
local function towAway(vehicle)
  if not exports['ai-garages']:ImpoundVehicle(vehicle) then
    DeleteEntity(vehicle) -- sahipli değil: sadece kaldır
  end
end
```
</Tab>
</Tabs>

### StoreVehicle

Sahipli bir aracı paneldeki garajlardan birine park eder: durumunu kaydeder, entity’yi siler, durumunu `garage` yapar.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
StoreVehicle(vehicle: number, garage: string): boolean
```

```lua title="Lua"
local ok = exports['ai-garages']:StoreVehicle(vehicle, garage)
```

#### Parametreler

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Server’daki bir araç entity’si.', required: true },
    garage: { type: 'string', description: 'Paneldeki bir garaj id’si (`"pillbox"`, `"legion"`). Çekilmiş araç otoparkları reddedilir.', required: true },
  }}
/>

#### Dönüş değeri

Park edildiyse `true`. Sahipli olmayan bir araç, var olmayan bir garaj id’si ya da çekilmiş araç otoparkı için `false`.

### GetStoredVehicles

Bir oyuncunun karakterinin dışarıda olmayan araçları: bir garajda park halinde ya da çekilmiş araç otoparkında bekleyenler. Filo araçları dahil değildir.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
GetStoredVehicles(source: number): GaragedVehicle[]
```

```lua title="Lua"
local list = exports['ai-garages']:GetStoredVehicles(source)
```

#### Dönüş değeri

`GaragedVehicle` dizisi. Oyuncunun yüklü bir karakteri yoksa boştur.

#### GaragedVehicle

<TypeTable
  type={{
    plate: { type: 'string', description: 'Plaka.', required: true },
    model: { type: 'string | null', description: 'Spawn adı (`"sultan"`).', required: true },
    garage: { type: 'string | null', description: 'Garaj id’si; garajı yoksa `null` (otoparka çekilmiş araçlar).', required: true },
    impounded: { type: 'boolean', description: 'Çekilmiş araç otoparkında bekliyorsa `true`.', required: true },
  }}
/>

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const list = garages.GetStoredVehicles(source);
const impounded = list.filter((v) => v.impounded).map((v) => v.plate);
console.log(`impounded: ${impounded.join(", ") || "none"}`);
```
</Tab>
<Tab value="Lua">
```lua
local impounded = {}
for _, v in ipairs(exports['ai-garages']:GetStoredVehicles(source)) do
  if v.impounded then impounded[#impounded + 1] = v.plate end
end
print('impounded: ' .. (#impounded > 0 and table.concat(impounded, ', ') or 'none'))
```
</Tab>
</Tabs>

## Event’ler

ai-garages’ın callback’leri iç kullanım içindir (kendi client’ından kendi server’ına). Başka script’lerden çağırma.

| Ad | Tür | Ne yapar |
| --- | --- | --- |
| `ai-garages:list` | client callback’i | `(garageId)`: oyuncunun orada çıkarabileceği araçlar. 2 saniyede en fazla 2 kez. |
| `ai-garages:takeOut` | client callback’i | `(garageId, vehicleId)`: aracı çıkış noktasında spawn eder. |
| `ai-garages:park` | client callback’i | `(garageId, netId, props)`: oyuncunun sürdüğü aracı park eder. |
