<Callout type="info">
Из своего скрипта используйте слой `garages` из lib (сервер): `garages.impound(vehicle, by?)`, `garages.store(vehicle, garage?, by?)`, `garages.open(source, garage?)` и `garages.stored(source)`. Он работает с любым скриптом гаражей, который запущен на сервере. Экспорты ниже являются тем, что вызывает слой, пока ai-garages является активным скриптом гаражей. ai-garages не может открыть свой список издалека, поэтому с ним `garages.open` отвечает `false`.
</Callout>

Типизированы как `AiGaragesServerExports` в `@aifivem/shared` (`garages.ts`). Все три синхронные.

```ts title="TypeScript"
import { resourceExport } from "@aifivem/lib/server";
const garages = resourceExport("ai-garages");
```

## Серверные экспорты

### ImpoundVehicle

Отправляет личный транспорт на штрафстоянку: сохраняет его состояние (топливо, двигатель, кузов), удаляет сущность и выставляет его состояние в `impound`. Владелец получает его обратно на штрафстоянке за плату.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
ImpoundVehicle(vehicle: number): boolean
```

```lua title="Lua"
local ok = exports['ai-garages']:ImpoundVehicle(vehicle)
```

#### Параметры

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Серверная сущность транспорта.', required: true },
  }}
/>

#### Возвращает

`true`, если транспорт отправлен на штрафстоянку. `false`, если сущность не существует или не является личным транспортом ai-vehicles; тогда удалите его сами.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const garages = resourceExport("ai-garages");

export function towAway(vehicle: number): void {
  if (!garages.ImpoundVehicle(vehicle)) DeleteEntity(vehicle); // не личный: просто удалить
}
```
</Tab>
<Tab value="Lua">
```lua
local function towAway(vehicle)
  if not exports['ai-garages']:ImpoundVehicle(vehicle) then
    DeleteEntity(vehicle) -- не личный: просто удалить
  end
end
```
</Tab>
</Tabs>

### StoreVehicle

Паркует личный транспорт в одном из гаражей панели: сохраняет его состояние, удаляет сущность, выставляет его состояние в `garage`.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
StoreVehicle(vehicle: number, garage: string): boolean
```

```lua title="Lua"
local ok = exports['ai-garages']:StoreVehicle(vehicle, garage)
```

#### Параметры

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Серверная сущность транспорта.', required: true },
    garage: { type: 'string', description: 'Id гаража из панели (`"pillbox"`, `"legion"`). Штрафстоянки отклоняются.', required: true },
  }}
/>

#### Возвращает

`true`, если транспорт поставлен. `false` для транспорта, который не является личным, для несуществующего id гаража или для штрафстоянки.

### GetStoredVehicles

Транспорт персонажа игрока, который не находится снаружи: стоит в гараже или ждёт на штрафстоянке. Транспорт автопарков не включается.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
GetStoredVehicles(source: number): GaragedVehicle[]
```

```lua title="Lua"
local list = exports['ai-garages']:GetStoredVehicles(source)
```

#### Возвращает

Массив `GaragedVehicle`. Пустой, если у игрока нет загруженного персонажа.

#### GaragedVehicle

<TypeTable
  type={{
    plate: { type: 'string', description: 'Номер.', required: true },
    model: { type: 'string | null', description: 'Имя для создания (`"sultan"`).', required: true },
    garage: { type: 'string | null', description: 'Id гаража; `null`, если его нет (транспорт на штрафстоянке).', required: true },
    impounded: { type: 'boolean', description: '`true`, если он ждёт на штрафстоянке.', required: true },
  }}
/>

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const list = garages.GetStoredVehicles(source);
const impounded = list.filter((v) => v.impounded).map((v) => v.plate);
console.log(`impounded: ${impounded.join(", ") || "none"}`);
```
</Tab>
<Tab value="Lua">
```lua
local impounded = {}
for _, v in ipairs(exports['ai-garages']:GetStoredVehicles(source)) do
  if v.impounded then impounded[#impounded + 1] = v.plate end
end
print('impounded: ' .. (#impounded > 0 and table.concat(impounded, ', ') or 'none'))
```
</Tab>
</Tabs>

## События

Колбэки ai-garages внутренние (от его клиента к его серверу). Не вызывайте их из других скриптов.

| Имя | Тип | Что делает |
| --- | --- | --- |
| `ai-garages:list` | client callback | `(garageId)`: транспорт, который игрок может там забрать. Не чаще 2 раз за 2 секунды. |
| `ai-garages:takeOut` | client callback | `(garageId, vehicleId)`: создаёт транспорт в точке выезда. |
| `ai-garages:park` | client callback | `(garageId, netId, props)`: паркует транспорт, которым управляет игрок. |
