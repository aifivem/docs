<Callout type="info">
Depuis votre propre script, utilisez la couche `garages` de la lib (serveur) : `garages.impound(vehicle, by?)`, `garages.store(vehicle, garage?, by?)`, `garages.open(source, garage?)` et `garages.stored(source)`. Elle fonctionne avec le script de garage que fait tourner le serveur, quel qu’il soit. Les exports ci-dessous sont ce qu’appelle la couche tant qu’ai-garages est le script de garage actif. ai-garages ne peut pas ouvrir sa liste à distance, donc `garages.open` répond `false` avec lui.
</Callout>

Typés `AiGaragesServerExports` dans `@aicore-fivem/shared` (`garages.ts`). Les trois sont synchrones.

```ts title="TypeScript"
import { resourceExport } from "@aicore-fivem/lib/server";
const garages = resourceExport("ai-garages");
```

## Exports serveur

### ImpoundVehicle

Envoie un véhicule possédé à la fourrière : enregistre son état (carburant, moteur, carrosserie), supprime l’entité et règle son état sur `impound`. Le propriétaire le récupère à une fourrière contre les frais.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
ImpoundVehicle(vehicle: number): boolean
```

```lua title="Lua"
local ok = exports['ai-garages']:ImpoundVehicle(vehicle)
```

#### Paramètres

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Une entité véhicule côté serveur.', required: true },
  }}
/>

#### Retour

`true` quand il a été mis en fourrière. `false` quand l’entité n’existe pas ou n’est pas un véhicule possédé d’ai-vehicles ; supprimez-la alors vous-même.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const garages = resourceExport("ai-garages");

export function towAway(vehicle: number): void {
  if (!garages.ImpoundVehicle(vehicle)) DeleteEntity(vehicle); // non possédé : simplement le retirer
}
```
</Tab>
<Tab value="Lua">
```lua
local function towAway(vehicle)
  if not exports['ai-garages']:ImpoundVehicle(vehicle) then
    DeleteEntity(vehicle) -- non possédé : simplement le retirer
  end
end
```
</Tab>
</Tabs>

### StoreVehicle

Gare un véhicule possédé dans un des garages du panneau : enregistre son état, supprime l’entité, règle son état sur `garage`.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
StoreVehicle(vehicle: number, garage: string): boolean
```

```lua title="Lua"
local ok = exports['ai-garages']:StoreVehicle(vehicle, garage)
```

#### Paramètres

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Une entité véhicule côté serveur.', required: true },
    garage: { type: 'string', description: 'Un id de garage du panneau (`"pillbox"`, `"legion"`). Les fourrières sont refusées.', required: true },
  }}
/>

#### Retour

`true` quand il a été garé. `false` pour un véhicule qui n’est pas possédé, un id de garage qui n’existe pas, ou une fourrière.

### GetStoredVehicles

Les véhicules du personnage d’un joueur qui ne sont pas sortis : garés dans un garage ou en attente à la fourrière. Les véhicules de flotte ne sont pas inclus.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
GetStoredVehicles(source: number): GaragedVehicle[]
```

```lua title="Lua"
local list = exports['ai-garages']:GetStoredVehicles(source)
```

#### Retour

Un tableau de `GaragedVehicle`. Vide quand le joueur n’a pas de personnage chargé.

#### GaragedVehicle

<TypeTable
  type={{
    plate: { type: 'string', description: 'La plaque.', required: true },
    model: { type: 'string | null', description: 'Le nom d’apparition (`"sultan"`).', required: true },
    garage: { type: 'string | null', description: 'L’id du garage ; `null` quand il n’en a pas (véhicules en fourrière).', required: true },
    impounded: { type: 'boolean', description: '`true` quand il attend à la fourrière.', required: true },
  }}
/>

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const list = garages.GetStoredVehicles(source);
const impounded = list.filter((v) => v.impounded).map((v) => v.plate);
console.log(`impounded: ${impounded.join(", ") || "none"}`);
```
</Tab>
<Tab value="Lua">
```lua
local impounded = {}
for _, v in ipairs(exports['ai-garages']:GetStoredVehicles(source)) do
  if v.impounded then impounded[#impounded + 1] = v.plate end
end
print('impounded: ' .. (#impounded > 0 and table.concat(impounded, ', ') or 'none'))
```
</Tab>
</Tabs>

## Events

Les callbacks d’ai-garages sont internes (de son client vers son serveur). Ne les appelez pas depuis d’autres scripts.

| Nom | Type | Ce qu’il fait |
| --- | --- | --- |
| `ai-garages:list` | callback client | `(garageId)` : les véhicules que le joueur peut sortir à cet endroit. Limité à 2 toutes les 2 secondes. |
| `ai-garages:takeOut` | callback client | `(garageId, vehicleId)` : fait apparaître le véhicule au point de sortie. |
| `ai-garages:park` | callback client | `(garageId, netId, props)` : gare le véhicule que conduit le joueur. |
