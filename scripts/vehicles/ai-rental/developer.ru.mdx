У ai-rental нет экспортов и нет базы данных. Арендованный транспорт является обычным созданным транспортом:

- его номер начинается с **Plate start** из панели (по умолчанию `RNT`), за которым идут цифры, всего 8 символов;
- его state bag `fuel` равен 100 при появлении;
- арендатор получает ключи через слой ключей ai-core с назначением `"rental"`, поэтому скрипт ключей, который знает об аренде, может обрабатывать их отдельно.

Это не личный транспорт: [ai-vehicles](/ru/docs/scripts/vehicles/ai-vehicles/developer) о нём не знает, а гаражи отказываются его парковать.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Сервер: является ли этот транспорт арендованным? (начало номера по умолчанию "RNT")
export function isRental(vehicle: number): boolean {
  return GetVehicleNumberPlateText(vehicle).trim().startsWith("RNT");
}
```
</Tab>
<Tab value="Lua">
```lua
-- Сервер: является ли этот транспорт арендованным? (начало номера по умолчанию "RNT")
local function isRental(vehicle)
  local plate = GetVehicleNumberPlateText(vehicle):gsub('^%s+', '')
  return plate:sub(1, 3) == 'RNT'
end
```
</Tab>
</Tabs>

<Callout type="warn">
Начало номера является настройкой панели. Если владелец его изменит, проверка вроде той, что выше, тоже должна измениться.
</Callout>

## События

События ai-rental внутренние (его клиент и его сервер); не вызывайте их из других скриптов.

| Имя | Тип | Что делает |
| --- | --- | --- |
| `ai-rental:rent` | client callback | `(locationId, vehicleKey) -> { ok, plate, minutes }`: арендовать транспорт из списка. Не больше 2 вызовов за 5 секунд. |
| `ai-rental:giveBack` | client callback | `(locationId) -> { ok, refund }`: вернуть арендованный транспорт у стойки. |
| `ai-rental:state` | сервер к клиенту | `(active: boolean)`: есть ли у игрока аренда (показывает подсказку возврата). |
