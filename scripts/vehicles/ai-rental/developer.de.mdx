ai-rental hat keine Exports und keine Datenbank. Ein gemietetes Fahrzeug ist ein einfaches gespawntes Fahrzeug:

- sein Kennzeichen beginnt mit dem **Plate start** aus dem Panel (standardmäßig `RNT`), gefolgt von Ziffern, insgesamt 8 Zeichen;
- sein State Bag `fuel` ist beim Erscheinen 100;
- der Mieter bekommt die Schlüssel über den Schlüssel-Layer von ai-core mit dem Zweck `"rental"`, sodass ein Schlüsselskript, das Mieten kennt, sie gesondert behandeln kann.

Es ist kein Fahrzeug im Besitz: [ai-vehicles](/de/docs/scripts/vehicles/ai-vehicles/developer) kennt es nicht, und Garagen lehnen das Parken ab.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Server: Ist dieses Fahrzeug eine Miete? (Standard-Kennzeichenanfang "RNT")
export function isRental(vehicle: number): boolean {
  return GetVehicleNumberPlateText(vehicle).trim().startsWith("RNT");
}
```
</Tab>
<Tab value="Lua">
```lua
-- Server: Ist dieses Fahrzeug eine Miete? (Standard-Kennzeichenanfang "RNT")
local function isRental(vehicle)
  local plate = GetVehicleNumberPlateText(vehicle):gsub('^%s+', '')
  return plate:sub(1, 3) == 'RNT'
end
```
</Tab>
</Tabs>

<Callout type="warn">
Der Kennzeichenanfang ist eine Panel-Einstellung. Wenn der Betreiber ihn ändert, muss sich eine Prüfung wie die oben auch ändern.
</Callout>

## Events

Die Events von ai-rental sind intern (sein Client und sein Server); rufe sie nicht aus anderen Skripten auf.

| Name | Art | Was es macht |
| --- | --- | --- |
| `ai-rental:rent` | Client-Callback | `(locationId, vehicleKey) -> { ok, plate, minutes }`: ein Fahrzeug der Liste mieten. Begrenzt auf 2 Aufrufe pro 5 Sekunden. |
| `ai-rental:giveBack` | Client-Callback | `(locationId) -> { ok, refund }`: die Miete an der Theke zurückgeben. |
| `ai-rental:state` | Server an Client | `(active: boolean)`: ob der Spieler eine Miete hat (zeigt den Rückgabehinweis). |
