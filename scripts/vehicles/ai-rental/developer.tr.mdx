ai-rental’ın export’u ve veritabanı yoktur. Kiralanan araç sıradan bir spawn edilmiş araçtır:

- plakası paneldeki **Plate start** (varsayılan `RNT`) ile başlar ve rakamlarla devam eder, toplam 8 karakterdir;
- belirdiğinde `fuel` state bag’i 100’dür;
- kiralayan, anahtarları ai-core’un anahtar katmanı üzerinden `"rental"` amacıyla alır; böylece kiralamaları tanıyan bir anahtar script’i onları ayrı ele alabilir.

Sahipli bir araç değildir: [ai-vehicles](/tr/docs/scripts/vehicles/ai-vehicles/developer) onu bilmez ve garajlar park etmeyi reddeder.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Server: bu araç kiralık mı? (varsayılan plaka başlangıcı "RNT")
export function isRental(vehicle: number): boolean {
  return GetVehicleNumberPlateText(vehicle).trim().startsWith("RNT");
}
```
</Tab>
<Tab value="Lua">
```lua
-- Server: bu araç kiralık mı? (varsayılan plaka başlangıcı "RNT")
local function isRental(vehicle)
  local plate = GetVehicleNumberPlateText(vehicle):gsub('^%s+', '')
  return plate:sub(1, 3) == 'RNT'
end
```
</Tab>
</Tabs>

<Callout type="warn">
Plaka başlangıcı bir panel ayarıdır. Sunucu sahibi onu değiştirirse yukarıdaki gibi bir kontrolün de değişmesi gerekir.
</Callout>

## Event’ler

ai-rental’ın event’leri iç kullanım içindir (kendi client’ı ve server’ı); başka script’lerden çağırma.

| Ad | Tür | Ne yapar |
| --- | --- | --- |
| `ai-rental:rent` | client callback’i | `(locationId, vehicleKey) -> { ok, plate, minutes }`: listeden bir araç kirala. 5 saniyede en fazla 2 çağrı. |
| `ai-rental:giveBack` | client callback’i | `(locationId) -> { ok, refund }`: kiralık aracı tezgâhta iade et. |
| `ai-rental:state` | server’dan client’a | `(active: boolean)`: oyuncunun kiralık aracı olup olmadığı (iade istemini gösterir). |
