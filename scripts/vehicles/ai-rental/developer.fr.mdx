title: ai-rental pour les développeurs
description: Ce qu’ai-rental expose aux autres scripts.

---

ai-rental n’a ni export ni base de données. Un véhicule loué est un simple véhicule apparu :

- sa plaque commence par le **Plate start** du panneau (`RNT` par défaut) suivi de chiffres, 8 caractères au total ;
- son state bag `fuel` vaut 100 quand il apparaît ;
- le locataire reçoit les clés via la couche clés d’ai-core avec l’usage `"rental"`, donc un script de clés qui connaît les locations peut les traiter à part.

Ce n’est pas un véhicule possédé : [ai-vehicles](/fr/docs/scripts/vehicles/ai-vehicles/developer) ne le connaît pas, et les garages refusent de le garer.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Serveur : ce véhicule est-il une location ? (préfixe de plaque par défaut "RNT")
export function isRental(vehicle: number): boolean {
  return GetVehicleNumberPlateText(vehicle).trim().startsWith("RNT");
}
```
</Tab>
<Tab value="Lua">
```lua
-- Serveur : ce véhicule est-il une location ? (préfixe de plaque par défaut "RNT")
local function isRental(vehicle)
  local plate = GetVehicleNumberPlateText(vehicle):gsub('^%s+', '')
  return plate:sub(1, 3) == 'RNT'
end
```
</Tab>
</Tabs>

<Callout type="warn">
Le préfixe de plaque est un réglage du panneau. Si le propriétaire le change, une vérification comme celle ci-dessus doit changer aussi.
</Callout>

## Events

Les events d’ai-rental sont internes (son client et son serveur) ; ne les appelez pas depuis d’autres scripts.

| Nom | Type | Ce qu’il fait |
| --- | --- | --- |
| `ai-rental:rent` | callback client | `(locationId, vehicleKey) -> { ok, plate, minutes }` : louer un véhicule de la liste. Limité à 2 appels toutes les 5 secondes. |
| `ai-rental:giveBack` | callback client | `(locationId) -> { ok, refund }` : rendre la location au comptoir. |
| `ai-rental:state` | serveur vers client | `(active: boolean)` : indique si le joueur a une location (affiche l’invite de restitution). |
