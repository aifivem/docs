ai-rental nie ma eksportów ani bazy danych. Wypożyczony pojazd to zwykły utworzony pojazd:

- jego tablica zaczyna się od **Plate start** z panelu (domyślnie `RNT`), po którym następują cyfry, łącznie 8 znaków;
- jego state bag `fuel` wynosi 100, gdy się pojawia;
- wypożyczający dostaje klucze przez warstwę kluczy ai-core z celem `"rental"`, więc skrypt kluczy, który zna wypożyczenia, może traktować je osobno.

Nie jest to posiadany pojazd: [ai-vehicles](/pl/docs/scripts/vehicles/ai-vehicles/developer) go nie zna, a garaże odmawiają jego zaparkowania.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Serwer: czy ten pojazd jest wypożyczony? (domyślny początek tablicy "RNT")
export function isRental(vehicle: number): boolean {
  return GetVehicleNumberPlateText(vehicle).trim().startsWith("RNT");
}
```
</Tab>
<Tab value="Lua">
```lua
-- Serwer: czy ten pojazd jest wypożyczony? (domyślny początek tablicy "RNT")
local function isRental(vehicle)
  local plate = GetVehicleNumberPlateText(vehicle):gsub('^%s+', '')
  return plate:sub(1, 3) == 'RNT'
end
```
</Tab>
</Tabs>

<Callout type="warn">
Początek tablicy to ustawienie w panelu. Jeśli właściciel go zmieni, sprawdzenie takie jak powyżej też musi się zmienić.
</Callout>

## Zdarzenia

Zdarzenia ai-rental są wewnętrzne (jego klient i jego serwer); nie wywołuj ich z innych skryptów.

| Nazwa | Rodzaj | Co robi |
| --- | --- | --- |
| `ai-rental:rent` | callback klienta | `(locationId, vehicleKey) -> { ok, plate, minutes }`: wypożycz pojazd z listy. Limit 2 wywołań na 5 sekund. |
| `ai-rental:giveBack` | callback klienta | `(locationId) -> { ok, refund }`: oddaj wypożyczony pojazd przy ladzie. |
| `ai-rental:state` | serwer do klienta | `(active: boolean)`: czy gracz ma wypożyczony pojazd (pokazuje podpowiedź zwrotu). |
