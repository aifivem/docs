ai-rental lässt Spieler an einer Theke ein Fahrzeug gegen Gebühr und Kaution mieten. Die Kaution kommt zurück, wenn das Fahrzeug rechtzeitig zurückgegeben wird, weniger, wenn es beschädigt ist.

## Was es im Spiel macht

- Geh zu einer Verleihtheke (innerhalb von 2 m) und drücke beim Hinweis **Rent a vehicle at ...** die Interaktionstaste. Ein Menü listet die Fahrzeuge mit Gebühr, Kaution und Mietdauer.
- Wähle eines: Gebühr und Kaution werden zusammen vom Konto aus dem Panel abgebucht. Das Fahrzeug erscheint an der Spawnstelle der Station mit vollem Tank, einem Kennzeichen, das mit dem Kennzeichenanfang aus dem Panel beginnt (zum Beispiel `RNT12345`), den Schlüsseln und dir auf dem Fahrersitz.
- Bring es in die Nähe der Theke zurück (innerhalb des Rückgaberadius) und drücke beim Hinweis **Give the rental back** die Interaktionstaste. Die Kaution kommt abhängig vom Zustand des Fahrzeugs zurück (Motor- und Karosseriezustand): Ein perfektes Auto gibt die ganze Kaution zurück, ein Wrack nichts.
- Wenn die Mietdauer abläuft, verschwindet das Fahrzeug und die Kaution wird einbehalten. Eine Mietdauer von 0 läuft, bis das Fahrzeug zurückgegeben wird.
- Eine Miete pro Spieler gleichzeitig. Das Verlassen des Servers beendet die Miete: Das Fahrzeug wird gelöscht und die Kaution einbehalten.

## Installation

Wird vom Rezept von AI Core installiert. Von Hand: `ensure ai-rental` nach `ai-core`. Keine Datenbanktabelle. Eine Verleihstation liegt fertig bereit: LSIA Car Rental am Flughafen, die einen Dinka Blista, einen Declasse Asea, einen Bravado Bison und einen Pegassi Faggio für 60 Minuten vermietet.

## Panel-Einstellungen

Admin-Panel > **Vehicle rental**.

### Tab: Rental points

Wo Spieler Fahrzeuge mieten, welche Fahrzeuge der Liste sie dort mieten können und wie lange. Ein Datensatz pro Station (**New rental point** / **Delete rental point**). Das Löschen einer Station entfernt sie, ihren Blip und ihre Fahrzeugliste; dort gerade gemietete Fahrzeuge bleiben, bis sie zurückgegeben werden oder ihre Zeit endet.

Karte **Rental point**: die Theke, zu der Spieler gehen, und wo das gemietete Fahrzeug erscheint.

| Einstellung | Was sie ändert | Einheit | Standard für neue |
| --- | --- | --- | --- |
| Name | Wird im Hinweis und im Menü angezeigt. 1-48 Zeichen. | | |
| Counter | Spieler mieten hier (2 m) und geben Fahrzeuge in der Umgebung zurück (Rückgaberadius in Settings). | Punkt | |
| Vehicle spawn | Wo und in welche Richtung das gemietete Fahrzeug erscheint; der Mieter sitzt sofort darin. | Punkt + Ausrichtung | |
| Map blip | Zeigt diese Station auf der Karte. | an / aus | an |
| Blip look | Symbol, Farbe und Größe des Blips dieser Station. | | Symbol 225, Farbe 2, Größe 0.7 |
| Rental time | Wenn sie abläuft, verschwindet das Fahrzeug und die Kaution wird einbehalten. 0 = bis zur Rückgabe. 0-1440. | min | 60 |

Karte **Vehicles**: Fahrzeuge aus der Fahrzeugliste, die diese Station vermietet; Gebühr und Kaution werden im Tab Vehicles eingestellt.

| Einstellung | Was sie ändert |
| --- | --- |
| Vehicles | Bis zu 30 Zeilen (**Add vehicle**), jede aus der Liste des Tabs Vehicles gewählt. |

### Tab: Vehicles

Jedes Fahrzeug, das gemietet werden kann, mit Name, Gebühr und Kaution; Verleihstationen wählen aus dieser Liste. Ein Datensatz pro Fahrzeug (**New vehicle** / **Delete vehicle**). Das Löschen eines Fahrzeugs entfernt es aus jeder Station, die es angeboten hat; gerade gemietete Fahrzeuge bleiben, bis sie zurückgegeben werden oder ihre Zeit endet.

| Einstellung | Was sie ändert | Einheit | Standard für neue |
| --- | --- | --- | --- |
| Model | Der Modellname des Fahrzeugs im Spiel (auch Add-on-Fahrzeuge). Bis zu 32 Zeichen. | | blista |
| Name | Der Name im Mietmenü. 1-48 Zeichen. | | |
| Fee | Wird beim Mieten bezahlt, nie zurückgegeben. 0-1.000.000. | $ | 150 |
| Deposit | Wird beim Mieten bezahlt, zurückgegeben, wenn das Fahrzeug rechtzeitig zurückgebracht wird. 0-1.000.000. | $ | 300 |

### Tab: Settings

Geld und Kennzeichen jeder Miete. Gilt für jede Verleihstation.

| Einstellung | Was sie ändert | Einheit | Standard |
| --- | --- | --- | --- |
| Paid from | Das ai-core-Konto, von dem Gebühr und Kaution abgebucht werden und auf das die Kaution zurückgeht. | | bank |
| Plate start | Bis zu 4 Buchstaben vor der Kennzeichennummer, damit gemietete Fahrzeuge leicht zu erkennen sind. Das Kennzeichen hat insgesamt 8 Zeichen. | | RNT |
| Return radius | Wie nah an der Theke ein gemietetes Fahrzeug sein muss, um es zurückzugeben. 3-50. | m | 15 |

## Befehle und Tastenbelegungen

Keine. Die Hinweise nutzen die Interaktionstaste (standardmäßig **E**).

## Bekannte Grenzen

- Mieten existieren nur im Speicher: Ein Neustart der Ressource löscht jedes gemietete Fahrzeug und behält die Kautionen ein.
- Ein auf der Spawnstelle geparktes Fahrzeug blockiert das Mieten („Something is parked on the spawn spot“).
- Nur ein Konto bezahlt: Gebühr und Kaution zusammen müssen darauf passen.
