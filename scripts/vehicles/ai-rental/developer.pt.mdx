O ai-rental não tem exports nem banco de dados. Um veículo alugado é um veículo criado comum:

- sua placa começa com o **Plate start** do painel (`RNT` por padrão) seguido de dígitos, 8 caracteres no total;
- seu state bag `fuel` é 100 quando ele aparece;
- quem aluga recebe as chaves pela camada de chaves do ai-core com o propósito `"rental"`, então um script de chaves que conhece aluguéis pode tratá-los à parte.

Ele não é um veículo próprio: o [ai-vehicles](/pt/docs/scripts/vehicles/ai-vehicles/developer) não o conhece, e as garagens se recusam a estacioná-lo.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Servidor: este veículo é um aluguel? (início de placa padrão "RNT")
export function isRental(vehicle: number): boolean {
  return GetVehicleNumberPlateText(vehicle).trim().startsWith("RNT");
}
```
</Tab>
<Tab value="Lua">
```lua
-- Servidor: este veículo é um aluguel? (início de placa padrão "RNT")
local function isRental(vehicle)
  local plate = GetVehicleNumberPlateText(vehicle):gsub('^%s+', '')
  return plate:sub(1, 3) == 'RNT'
end
```
</Tab>
</Tabs>

<Callout type="warn">
O início da placa é uma configuração do painel. Se o dono mudá-lo, uma verificação como a de cima também precisa mudar.
</Callout>

## Eventos

Os eventos do ai-rental são internos (do cliente e do servidor dele); não os chame a partir de outros scripts.

| Nome | Tipo | O que faz |
| --- | --- | --- |
| `ai-rental:rent` | callback do cliente | `(locationId, vehicleKey) -> { ok, plate, minutes }`: aluga um veículo da lista. Limitado a 2 chamadas a cada 5 segundos. |
| `ai-rental:giveBack` | callback do cliente | `(locationId) -> { ok, refund }`: devolve o aluguel no balcão. |
| `ai-rental:state` | servidor para cliente | `(active: boolean)`: se o jogador tem um aluguel (mostra o aviso de devolução). |
