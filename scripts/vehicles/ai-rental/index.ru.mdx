ai-rental позволяет игрокам арендовать транспорт у стойки за плату и залог. Залог возвращается, когда транспорт вернули вовремя, и меньше, если он повреждён.

## Что он делает в игре

- Подойдите к стойке аренды (в пределах 2 м) и нажмите клавишу взаимодействия у **Rent a vehicle at ...**. Меню показывает транспорт с его платой, залогом и временем аренды.
- Выберите один: плата и залог списываются вместе со счёта из панели. Транспорт появляется в точке появления пункта с полным баком, номером, который начинается с начала номера из панели (например, `RNT12345`), ключами, а вы сидите на месте водителя.
- Пригоните его обратно к стойке (в пределах радиуса возврата) и нажмите клавишу взаимодействия у **Give the rental back**. Залог возвращается в зависимости от состояния транспорта (двигатель и кузов): идеальная машина возвращает весь залог, разбитая ничего.
- Когда время аренды истекает, транспорт исчезает, а залог остаётся у пункта. Время аренды 0 длится, пока транспорт не вернут.
- Одна аренда на игрока одновременно. Выход с сервера заканчивает аренду: транспорт удаляется, а залог остаётся у пункта.

## Установка

Устанавливается рецептом AI Core. Вручную: `ensure ai-rental` после `ai-core`. Таблицы в базе данных нет. Один пункт аренды уже готов: LSIA Car Rental в аэропорту, который сдаёт Dinka Blista, Declasse Asea, Bravado Bison и Pegassi Faggio на 60 минут.

## Настройки панели

Админ-панель > **Vehicle rental**.

### Вкладка Rental points

Где игроки арендуют транспорт, какой транспорт из списка можно там арендовать и на сколько. Одна запись на пункт (**New rental point** / **Delete rental point**). Удаление пункта удаляет его, его блип и его список транспорта; транспорт, арендованный там сейчас, остаётся, пока его не вернут или не истечёт его время.

Карточка **Rental point**: стойка, к которой подходят игроки, и место, где появляется арендованный транспорт.

| Настройка | Что меняет | Единица | По умолчанию для новых |
| --- | --- | --- | --- |
| Name | Показывается в подсказке и меню. 1-48 символов. | | |
| Counter | Игроки арендуют здесь (2 м) и возвращают транспорт вокруг неё (радиус возврата в Settings). | точка | |
| Vehicle spawn | Где и в каком направлении появляется арендованный транспорт; арендатор сразу садится в него. | точка + направление | |
| Map blip | Показывает этот пункт на карте. | вкл. / выкл. | вкл. |
| Blip look | Иконка, цвет и размер блипа этого пункта. | | иконка 225, цвет 2, размер 0.7 |
| Rental time | Когда оно истекает, транспорт исчезает, а залог остаётся у пункта. 0 = пока не вернут. 0-1440. | мин | 60 |

Карточка **Vehicles**: транспорт из списка транспорта, который сдаёт этот пункт; плата и залог задаются во вкладке Vehicles.

| Настройка | Что меняет |
| --- | --- |
| Vehicles | До 30 строк (**Add vehicle**), каждая выбирается из списка вкладки Vehicles. |

### Вкладка Vehicles

Весь транспорт, который можно арендовать, с его названием, платой и залогом; пункты аренды выбирают из этого списка. Одна запись на транспорт (**New vehicle** / **Delete vehicle**). Удаление транспорта убирает его из каждого пункта аренды, который его предлагал; транспорт, арендованный сейчас, остаётся, пока его не вернут или не истечёт его время.

| Настройка | Что меняет | Единица | По умолчанию для новых |
| --- | --- | --- | --- |
| Model | Название модели транспорта в игре (дополнительный транспорт тоже). До 32 символов. | | blista |
| Name | Название в меню аренды. 1-48 символов. | | |
| Fee | Платится при аренде, никогда не возвращается. 0-1,000,000. | $ | 150 |
| Deposit | Платится при аренде, возвращается, когда транспорт вернули вовремя. 0-1,000,000. | $ | 300 |

### Вкладка Settings

Деньги и номера каждой аренды. Действует для каждого пункта аренды.

| Настройка | Что меняет | Единица | По умолчанию |
| --- | --- | --- | --- |
| Paid from | Счёт ai-core, с которого списываются плата и залог и на который возвращается залог. | | bank |
| Plate start | До 4 букв перед номером, чтобы арендованный транспорт было легко узнать. Номер всего 8 символов. | | RNT |
| Return radius | Насколько близко к стойке должен быть арендованный транспорт, чтобы его вернуть. 3-50. | м | 15 |

## Команды и привязки клавиш

Нет. Подсказки используют клавишу взаимодействия (по умолчанию **E**).

## Известные ограничения

- Аренды живут только в памяти: перезапуск ресурса удаляет весь арендованный транспорт и оставляет залоги у пунктов.
- Транспорт, стоящий в точке появления, блокирует аренду ("Something is parked on the spawn spot").
- Платит только один счёт: плата и залог вместе должны на нём помещаться.
