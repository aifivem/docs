title: ai-rental para desarrolladores
description: Lo que ai-rental expone a otros scripts.

---

ai-rental no tiene exports ni base de datos. Un vehículo alquilado es un vehículo normal sacado al mundo:

- su matrícula empieza por el **Plate start** del panel (`RNT` por defecto) seguido de dígitos, 8 caracteres en total;
- su state bag `fuel` es 100 cuando aparece;
- quien alquila recibe las llaves a través de la capa de llaves de ai-core con el propósito `"rental"`, así que un script de llaves que conozca los alquileres puede tratarlos aparte.

No es un vehículo en propiedad: [ai-vehicles](/es/docs/scripts/vehicles/ai-vehicles/developer) no lo conoce, y los garajes se niegan a aparcarlo.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Servidor: ¿es este vehículo un alquiler? (inicio de matrícula por defecto "RNT")
export function isRental(vehicle: number): boolean {
  return GetVehicleNumberPlateText(vehicle).trim().startsWith("RNT");
}
```
</Tab>
<Tab value="Lua">
```lua
-- Servidor: ¿es este vehículo un alquiler? (inicio de matrícula por defecto "RNT")
local function isRental(vehicle)
  local plate = GetVehicleNumberPlateText(vehicle):gsub('^%s+', '')
  return plate:sub(1, 3) == 'RNT'
end
```
</Tab>
</Tabs>

<Callout type="warn">
El inicio de matrícula es un ajuste del panel. Si el dueño lo cambia, una comprobación como la de arriba también debe cambiar.
</Callout>

## Eventos

Los eventos de ai-rental son internos (su cliente y su servidor); no los llames desde otros scripts.

| Nombre | Tipo | Qué hace |
| --- | --- | --- |
| `ai-rental:rent` | callback de cliente | `(locationId, vehicleKey) -> { ok, plate, minutes }`: alquilar un vehículo de la lista. Limitado a 2 llamadas cada 5 segundos. |
| `ai-rental:giveBack` | callback de cliente | `(locationId) -> { ok, refund }`: devolver el alquiler en el mostrador. |
| `ai-rental:state` | servidor a cliente | `(active: boolean)`: si el jugador tiene un alquiler (muestra el aviso de devolución). |
