ai-rental has no exports and no database. A rented vehicle is a plain spawned vehicle:

- its plate starts with the panel's **Plate start** (`RNT` by default) followed by digits, 8 characters in total;
- its `fuel` state bag is 100 when it appears;
- the renter gets the keys through ai-core's key layer with the purpose `"rental"`, so a key script that knows rentals can treat them apart.

It is not an owned vehicle: [ai-vehicles](/docs/scripts/vehicles/ai-vehicles/developer) does not know it, and garages refuse to park it.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Server: is this vehicle a rental? (default plate start "RNT")
export function isRental(vehicle: number): boolean {
  return GetVehicleNumberPlateText(vehicle).trim().startsWith("RNT");
}
```
</Tab>
<Tab value="Lua">
```lua
-- Server: is this vehicle a rental? (default plate start "RNT")
local function isRental(vehicle)
  local plate = GetVehicleNumberPlateText(vehicle):gsub('^%s+', '')
  return plate:sub(1, 3) == 'RNT'
end
```
</Tab>
</Tabs>

<Callout type="warn">
The plate start is a panel setting. If the owner changes it, a check like the one above must change too.
</Callout>

## Events

ai-rental's events are internal (its client and its server); do not call them from other scripts.

| Name | Kind | What it does |
| --- | --- | --- |
| `ai-rental:rent` | client callback | `(locationId, vehicleKey) -> { ok, plate, minutes }`: rent a vehicle of the list. Limited to 2 calls per 5 seconds. |
| `ai-rental:giveBack` | client callback | `(locationId) -> { ok, refund }`: give the rental back at the counter. |
| `ai-rental:state` | server to client | `(active: boolean)`: whether the player has a rental (shows the return prompt). |
