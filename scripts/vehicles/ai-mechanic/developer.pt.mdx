O ai-mechanic não tem exports. Outros scripts interagem com ele pelo que ele escreve.

## O que ele escreve

- **Tuning.** Uma compra escreve o state bag `ai:props` do veículo (o cliente do ai-core no dono da entidade o aplica) e, para um veículo próprio, salva as props completas com o [`SaveTuning`](/pt/docs/scripts/vehicles/ai-vehicles/developer#savetuning) do ai-vehicles. Placa, vida do motor e da lataria e sujeira são sempre tirados da entidade, então uma compra nunca os altera.
- **Reparos** salvam só a vida do motor e da lataria com o `SaveVehicle` do ai-vehicles.
- **Vida, deformação e sujeira** só podem ser alteradas pelo cliente que é dono da entidade, então o servidor envia `ai-mechanic:client:fix` para esse cliente.

## Baús

Uma oficina de emprego com ponto de baú registra um baú chamado `mechanic_<shopId>` (por exemplo `mechanic_lscustoms_burton`) para os membros do emprego da oficina, com os slots e o peso do painel. Abra-o a partir do seu próprio script pela camada de inventário da lib.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aicore-fivem/lib/server";

// Conta os kits de reparo no baú da oficina de Burton.
const kits = inventory.getItemCount("mechanic_lscustoms_burton", "repairkit");
```
</Tab>
<Tab value="Lua">
```lua
-- Conta os kits de reparo no baú da oficina de Burton.
local kits = aiLib.inventory.getItemCount('mechanic_lscustoms_burton', 'repairkit')
```
</Tab>
</Tabs>

## Item usável

O **Kit item** do painel (`repairkit` por padrão) é registrado como usável pela camada de inventário do ai-core. Ele leva o motor de um veículo até o valor **Engine health after** do painel e só é gasto quando o trabalho termina.

## Eventos

Todos os eventos do ai-mechanic são internos (do cliente e do servidor dele); não os chame a partir de outros scripts.

| Nome | Tipo | O que faz |
| --- | --- | --- |
| `ai-mechanic:buy` | callback do cliente | `(netId, change, base)`: compra uma mudança de tuning na oficina em que o jogador está. |
| `ai-mechanic:repair` | callback do cliente | `(netId)`: repara o veículo em uma oficina. |
| `ai-mechanic:stash` | callback do cliente | `(shopId)`: abre o baú de uma oficina de emprego. |
| `ai-mechanic:wash` | callback do cliente | `(netId)`: lava o veículo em um lava-rápido. |
| `ai-mechanic:bill` | callback do cliente | `(target, amount, reason)`: um mecânico em serviço cobra o jogador mais próximo. Limitado a 3 a cada 10 segundos. |
| `ai-mechanic:client:fix` | servidor para o dono da entidade | `(netId, engine)`: conserta a lataria (`engine` null), define a vida do motor, ou lava (`-1`). |
