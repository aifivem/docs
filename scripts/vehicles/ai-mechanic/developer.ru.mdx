У ai-mechanic нет экспортов. Другие скрипты встречаются с ним через то, что он пишет.

## Что он пишет

- **Тюнинг.** Покупка пишет state bag транспорта `ai:props` (клиент ai-core у владельца сущности его применяет) и для личного транспорта сохраняет полные props через [`SaveTuning`](/ru/docs/scripts/vehicles/ai-vehicles/developer#savetuning) из ai-vehicles. Номер, состояние двигателя и кузова и грязь всегда берутся из сущности, поэтому покупка их никогда не меняет.
- **Ремонт** сохраняет только состояние двигателя и кузова через `SaveVehicle` из ai-vehicles.
- **Здоровье, деформацию и грязь** может менять только клиент, которому принадлежит сущность, поэтому сервер отправляет `ai-mechanic:client:fix` этому клиенту.

## Тайники

Рабочая мастерская с точкой тайника регистрирует тайник с именем `mechanic_<shopId>` (например, `mechanic_lscustoms_burton`) для участников работы мастерской, со слотами и весом из панели. Открывайте его из своего скрипта через слой инвентаря lib.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aifivem/lib/server";

// Посчитать ремкомплекты в тайнике мастерской Burton.
const kits = inventory.getItemCount("mechanic_lscustoms_burton", "repairkit");
```
</Tab>
<Tab value="Lua">
```lua
-- Посчитать ремкомплекты в тайнике мастерской Burton.
local kits = aiLib.inventory.getItemCount('mechanic_lscustoms_burton', 'repairkit')
```

## Используемый предмет

**Kit item** из панели (по умолчанию `repairkit`) регистрируется как используемый через слой инвентаря ai-core. Он поднимает двигатель транспорта до значения **Engine health after** из панели и расходуется, только когда работа закончена.

## События

Все события ai-mechanic внутренние (его клиент и его сервер); не вызывайте их из других скриптов.

| Имя | Тип | Что делает |
| --- | --- | --- |
| `ai-mechanic:buy` | client callback | `(netId, change, base)`: купить одно изменение тюнинга в мастерской, где находится игрок. |
| `ai-mechanic:repair` | client callback | `(netId)`: отремонтировать транспорт в мастерской. |
| `ai-mechanic:stash` | client callback | `(shopId)`: открыть тайник рабочей мастерской. |
| `ai-mechanic:wash` | client callback | `(netId)`: помыть транспорт на автомойке. |
| `ai-mechanic:bill` | client callback | `(target, amount, reason)`: механик на дежурстве выставляет счёт ближайшему игроку. Не больше 3 за 10 секунд. |
| `ai-mechanic:client:fix` | сервер к владельцу сущности | `(netId, engine)`: починить кузов (`engine` null), установить состояние двигателя или помыть (`-1`). |
