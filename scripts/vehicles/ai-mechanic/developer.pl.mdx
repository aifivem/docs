ai-mechanic nie ma eksportów. Inne skrypty spotykają się z nim przez to, co zapisuje.

## Co zapisuje

- **Tuning.** Zakup zapisuje state bag `ai:props` pojazdu (nakłada go klient ai-core u właściciela encji), a dla posiadanego pojazdu zapisuje pełne props przez [`SaveTuning`](/pl/docs/scripts/vehicles/ai-vehicles/developer#savetuning) z ai-vehicles. Tablica, stan silnika i karoserii oraz brud są zawsze brane z encji, więc zakup nigdy ich nie zmienia.
- **Naprawy** zapisują tylko stan silnika i karoserii przez `SaveVehicle` z ai-vehicles.
- **Zdrowie, deformację i brud** może zmienić tylko klient, który jest właścicielem encji, więc serwer wysyła `ai-mechanic:client:fix` do tego klienta.

## Schowki

Warsztat pracy z punktem schowka rejestruje schowek o nazwie `mechanic_<shopId>` (na przykład `mechanic_lscustoms_burton`) dla członków pracy warsztatu, ze slotami i wagą z panelu. Otwieraj go z własnego skryptu przez warstwę ekwipunku biblioteki.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aicore-fivem/lib/server";

// Policz zestawy naprawcze w schowku warsztatu w Burton.
const kits = inventory.getItemCount("mechanic_lscustoms_burton", "repairkit");
```
</Tab>
<Tab value="Lua">
```lua
-- Policz zestawy naprawcze w schowku warsztatu w Burton.
local kits = aiLib.inventory.getItemCount('mechanic_lscustoms_burton', 'repairkit')
```
</Tab>
</Tabs>

## Przedmiot do użycia

**Kit item** z panelu (domyślnie `repairkit`) jest rejestrowany jako przedmiot do użycia przez warstwę ekwipunku ai-core. Podnosi stan silnika pojazdu do wartości **Engine health after** z panelu i jest zużywany tylko po zakończeniu pracy.

## Zdarzenia

Wszystkie zdarzenia ai-mechanic są wewnętrzne (jego klient i jego serwer); nie wywołuj ich z innych skryptów.

| Nazwa | Rodzaj | Co robi |
| --- | --- | --- |
| `ai-mechanic:buy` | callback klienta | `(netId, change, base)`: kup jedną zmianę tuningu w warsztacie, w którym jest gracz. |
| `ai-mechanic:repair` | callback klienta | `(netId)`: napraw pojazd w warsztacie. |
| `ai-mechanic:stash` | callback klienta | `(shopId)`: otwórz schowek warsztatu pracy. |
| `ai-mechanic:wash` | callback klienta | `(netId)`: umyj pojazd w myjni. |
| `ai-mechanic:bill` | callback klienta | `(target, amount, reason)`: mechanik na służbie wystawia rachunek najbliższemu graczowi. Limit 3 na 10 sekund. |
| `ai-mechanic:client:fix` | serwer do właściciela encji | `(netId, engine)`: napraw karoserię (`engine` null), ustaw stan silnika albo umyj (`-1`). |
