ai-mechanic n’a aucun export. Les autres scripts le rencontrent à travers ce qu’il écrit.

## Ce qu’il écrit

- **Tuning.** Un achat écrit le state bag `ai:props` du véhicule (le client d’ai-core sur le propriétaire de l’entité l’applique) et, pour un véhicule possédé, enregistre les props complètes avec [`SaveTuning`](/fr/docs/scripts/vehicles/ai-vehicles/developer#savetuning) d’ai-vehicles. La plaque, la santé du moteur et de la carrosserie et la saleté sont toujours lues sur l’entité, donc un achat ne les change jamais.
- **Les réparations** n’enregistrent que la santé du moteur et de la carrosserie avec le `SaveVehicle` d’ai-vehicles.
- **La santé, la déformation et la saleté** ne peuvent être changées que par le client propriétaire de l’entité, donc le serveur envoie `ai-mechanic:client:fix` à ce client.

## Stockages

Un atelier de métier avec un point de stockage enregistre un stockage nommé `mechanic_<shopId>` (par exemple `mechanic_lscustoms_burton`) pour les membres du métier de l’atelier, avec les emplacements et le poids du panneau. Ouvrez-le depuis votre propre script via la couche inventaire de la lib.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aicore-fivem/lib/server";

// Compter les kits de réparation dans le stockage de l’atelier de Burton.
const kits = inventory.getItemCount("mechanic_lscustoms_burton", "repairkit");
```
</Tab>
<Tab value="Lua">
```lua
-- Compter les kits de réparation dans le stockage de l’atelier de Burton.
local kits = aiLib.inventory.getItemCount('mechanic_lscustoms_burton', 'repairkit')
```
</Tab>
</Tabs>

## Objet utilisable

Le **Kit item** du panneau (`repairkit` par défaut) est enregistré comme utilisable via la couche inventaire d’ai-core. Il fait remonter le moteur d’un véhicule à la valeur **Engine health after** du panneau et n’est consommé que lorsque le travail se termine.

## Events

Tous les events d’ai-mechanic sont internes (son client et son serveur) ; ne les appelez pas depuis d’autres scripts.

| Nom | Type | Ce qu’il fait |
| --- | --- | --- |
| `ai-mechanic:buy` | callback client | `(netId, change, base)` : acheter un changement de tuning dans l’atelier où se trouve le joueur. |
| `ai-mechanic:repair` | callback client | `(netId)` : réparer le véhicule dans un atelier. |
| `ai-mechanic:stash` | callback client | `(shopId)` : ouvrir le stockage d’un atelier de métier. |
| `ai-mechanic:wash` | callback client | `(netId)` : laver le véhicule dans une station de lavage. |
| `ai-mechanic:bill` | callback client | `(target, amount, reason)` : un mécanicien en service facture le joueur le plus proche. Limité à 3 toutes les 10 secondes. |
| `ai-mechanic:client:fix` | serveur vers propriétaire de l’entité | `(netId, engine)` : réparer la carrosserie (`engine` null), régler la santé du moteur, ou laver (`-1`). |
