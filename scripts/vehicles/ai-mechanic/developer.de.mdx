ai-mechanic hat keine Exports. Andere Skripte begegnen ihm über das, was es schreibt.

## Was es schreibt

- **Tuning.** Ein Kauf schreibt den State Bag `ai:props` des Fahrzeugs (der Client von ai-core beim Besitzer der Entity wendet ihn an) und speichert bei einem Fahrzeug im Besitz die vollständigen Props mit [`SaveTuning`](/de/docs/scripts/vehicles/ai-vehicles/developer#savetuning) von ai-vehicles. Kennzeichen, Motor- und Karosseriezustand und Schmutz werden immer von der Entity übernommen, sodass ein Kauf sie nie ändert.
- **Reparaturen** speichern nur Motor- und Karosseriezustand mit `SaveVehicle` von ai-vehicles.
- **Zustand, Verformung und Schmutz** kann nur der Client ändern, dem die Entity gehört, daher sendet der Server `ai-mechanic:client:fix` an diesen Client.

## Lager

Eine Job-Werkstatt mit Lagerpunkt registriert ein Lager namens `mechanic_<shopId>` (zum Beispiel `mechanic_lscustoms_burton`) für die Mitglieder des Jobs der Werkstatt, mit den Slots und dem Gewicht aus dem Panel. Öffne es aus deinem eigenen Skript über den Inventar-Layer der Lib.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aicore-fivem/lib/server";

// Die Reparatursets im Lager der Werkstatt Burton zählen.
const kits = inventory.getItemCount("mechanic_lscustoms_burton", "repairkit");
```
</Tab>
<Tab value="Lua">
```lua
-- Die Reparatursets im Lager der Werkstatt Burton zählen.
local kits = aiLib.inventory.getItemCount('mechanic_lscustoms_burton', 'repairkit')
```
</Tab>
</Tabs>

## Benutzbares Item

Das **Kit item** aus dem Panel (standardmäßig `repairkit`) wird über den Inventar-Layer von ai-core als benutzbar registriert. Es bringt den Motor eines Fahrzeugs auf den Wert **Engine health after** aus dem Panel und wird erst verbraucht, wenn die Arbeit fertig ist.

## Events

Alle Events von ai-mechanic sind intern (sein Client und sein Server); rufe sie nicht aus anderen Skripten auf.

| Name | Art | Was es macht |
| --- | --- | --- |
| `ai-mechanic:buy` | Client-Callback | `(netId, change, base)`: eine Tuningänderung in der Werkstatt kaufen, in der der Spieler ist. |
| `ai-mechanic:repair` | Client-Callback | `(netId)`: das Fahrzeug in einer Werkstatt reparieren. |
| `ai-mechanic:stash` | Client-Callback | `(shopId)`: das Lager einer Job-Werkstatt öffnen. |
| `ai-mechanic:wash` | Client-Callback | `(netId)`: das Fahrzeug in einer Waschanlage waschen. |
| `ai-mechanic:bill` | Client-Callback | `(target, amount, reason)`: Ein Mechaniker im Dienst stellt dem nächsten Spieler eine Rechnung. Begrenzt auf 3 pro 10 Sekunden. |
| `ai-mechanic:client:fix` | Server an Entity-Besitzer | `(netId, engine)`: die Karosserie reparieren (`engine` null), den Motorzustand setzen oder waschen (`-1`). |
