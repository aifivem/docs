Les scripts de véhicules fonctionnent ensemble à travers AI Core : [ai-vehicles](/fr/docs/scripts/vehicles/ai-vehicles) stocke chaque véhicule possédé, et les autres scripts les achètent, les garent, les verrouillent, les ravitaillent, les réparent et les louent. Les clés, le carburant et les garages peuvent chacun être remplacés par un script tiers pris en charge ; les autres continuent de fonctionner, car ils interrogent AI Core plutôt que de s’appeler entre eux.

| Script | Ce qu’il fait |
| --- | --- |
| [ai-vehicles](/fr/docs/scripts/vehicles/ai-vehicles) | Véhicules possédés par les personnages, les métiers et les gangs : le stockage sur lequel reposent les autres scripts de véhicules. Remplace qbx_vehicles. |
| [ai-vehiclekeys](/fr/docs/scripts/vehicles/ai-vehiclekeys) | Clés, verrouillage (U), moteur (M), crochetage et démarrage aux fils. Remplace qbx_vehiclekeys. |
| [ai-fuel](/fr/docs/scripts/vehicles/ai-fuel) | Consommation de carburant et stations-service avec pistolet et tuyau ; les modèles électriques ne consomment rien. |
| [ai-garages](/fr/docs/scripts/vehicles/ai-garages) | Garages publics, de métier et de gang, et fourrières payantes. |
| [ai-vehicleshop](/fr/docs/scripts/vehicles/ai-vehicleshop) | Concessions avec catalogue, aperçu en salle d’exposition et couleurs. |
| [ai-vehiclesales](/fr/docs/scripts/vehicles/ai-vehiclesales) | Parcs d’occasion : les joueurs mettent leurs véhicules en vente, les autres les essaient et les achètent ; rachat par le concessionnaire. |
| [ai-rental](/fr/docs/scripts/vehicles/ai-rental) | Points de location avec frais et caution. |
| [ai-mechanic](/fr/docs/scripts/vehicles/ai-mechanic) | Réparation, tuning avec aperçu en direct, ateliers de métier, stations de lavage, kit de réparation. |
| [ai-sirens](/fr/docs/scripts/vehicles/ai-sirens) | Gyrophares, tonalités de sirène, klaxon pneumatique et rampes lumineuses ONX. |

## Comment ils s’articulent

<Steps>
<Step>
Un joueur achète une voiture chez **ai-vehicleshop**. Elle est créée dans **ai-vehicles**, possédée par son personnage, et sort avec les clés.
</Step>
<Step>
**ai-vehiclekeys** connaît le propriétaire grâce à ai-vehicles : seul le propriétaire (ou les membres du métier ou du gang propriétaire) peut la verrouiller et la démarrer.
</Step>
<Step>
**ai-fuel** vide le réservoir pendant la conduite ; le niveau est enregistré avec le véhicule.
</Step>
<Step>
**ai-garages** la gare avec son apparence, son carburant et ses dégâts. Un véhicule perdu dans le monde attend à la fourrière.
</Step>
<Step>
**ai-mechanic** la répare et la modifie. C’est le seul script qui change le tuning enregistré de la voiture.
</Step>
<Step>
**ai-vehiclesales** permet au joueur de la vendre à un autre joueur, avec la même plaque, la même apparence et le même coffre.
</Step>
</Steps>

## Ordre de démarrage

Dans `server.cfg`, démarrez `ai-vehicles` juste après `ai-core`, puis les autres scripts de véhicules. La recipe d’AI Core s’en charge pour vous.
