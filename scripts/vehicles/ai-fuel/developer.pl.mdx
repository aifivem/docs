ai-fuel nie ma eksportów. Paliwo pojazdu to state bag encji `fuel` (0-100), utrzymywany przez serwer.

<Callout type="info">
Odczytuj i ustawiaj paliwo przez `fuel.get(vehicle)` i `fuel.set(vehicle, level)` z biblioteki (serwer; `fuel.get` także na kliencie). Przechodzą przez warstwę paliwa ai-core (w Lua wywołaj jej eksporty `GetVehicleFuel` i `SetVehicleFuel` na `ai-core`), która czyta i zapisuje bag `fuel`, gdy działa ai-fuel, i rozmawia z innym skryptem paliwa, gdy serwer używa zamiast niego innego. Twój skrypt działa wtedy z każdym skryptem paliwa.
</Callout>

## Odczyt i ustawianie paliwa

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { fuel } from "@aifivem/lib/server";

// Zatankuj pojazd, za który gracz właśnie zapłacił na własnej stacji.
export function fillUp(vehicle: number): void {
  const before = fuel.get(vehicle);
  fuel.set(vehicle, 100);
  console.log(`fuel ${before} -> 100`);
}
```
</Tab>
<Tab value="Lua">
```lua
-- ai-lib nie ma odpowiednika `fuel` w Lua: wywołaj eksporty paliwa ai-core (ta sama warstwa).
-- Zatankuj pojazd, za który gracz właśnie zapłacił na własnej stacji.
local function fillUp(vehicle)
  local before = exports['ai-core']:GetVehicleFuel(vehicle) -- liczba lub nil
  exports['ai-core']:SetVehicleFuel(vehicle, 100) -- false dla złego pojazdu
  print(('fuel %s -> 100'):format(before))
end
```
</Tab>
</Tabs>

<Callout type="warn">
Nie zapisuj bagu `fuel` z klienta: serwer odrzuca zapisy klientów (tryb strict state bag), a ai-fuel i tak przyjmuje od klienta kierowcy tylko niższe wartości.
</Callout>

## State bagi

| Bag | Na | Typ | Znaczenie |
| --- | --- | --- | --- |
| `fuel` | encja pojazdu | `number` | Paliwo 0-100. Ustawiane przez serwer. ai-vehicles nadaje je przy tworzeniu posiadanego pojazdu. |
| `aiFuelNozzle` | gracz | `{ x, y, z, netId } \| undefined` | Dystrybutor, którego pistolet trzyma gracz (`x, y, z`), i ID sieciowe pojazdu, do którego jest podłączony (`netId`, `null`, gdy jest w ręce). Każdy klient w pobliżu używa tego do rysowania pistoletu i węża. |

```lua title="Lua (klient)"
local vehicle = GetVehiclePedIsIn(PlayerPedId(), false)
local level = Entity(vehicle).state.fuel -- liczba 0-100 albo nil przed pierwszym ustawieniem
```

## Zdarzenia

To własne zdarzenia klient-serwer ai-fuel. Są wymienione, abyś rozpoznał je w logach; nie wywołuj ich z innych skryptów.

| Nazwa | Rodzaj | Co robi |
| --- | --- | --- |
| `ai-fuel:consume` | zdarzenie klienta | `(netId, fuel)`: kierowca zgłasza niższy poziom. Limit 2 na sekundę; przyjmowane są tylko niższe wartości. |
| `ai-fuel:takeNozzle` | callback klienta | `(x, y, z)`: weź pistolet z dystrybutora. Limit 1 na sekundę. |
| `ai-fuel:plug` | callback klienta | `(netId \| null)`: podłącz pistolet do pojazdu albo go wyjmij. Limit 2 na sekundę. |
| `ai-fuel:returnNozzle` | zdarzenie klienta | Odwieś pistolet. Limit 1 na sekundę. |
| `ai-fuel:refuel` | callback klienta | Prowadzi pasek postępu, pobiera opłatę i tankuje do pełna. |
