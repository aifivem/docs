ai-vehicleshop sells vehicles. One catalog holds every vehicle with its price and category; each shop sells some of those categories.

## What it does in the game

- Walk to a shop's counter and press the interact key at **Browse ...**. The camera moves to the showroom and the screen shows the shop's categories.
- Pick a vehicle to see it on the preview spot, and pick one of eight colors.
- **Buy** takes the price from the first account that can pay it (bank first by default). The vehicle is created in [ai-vehicles](/docs/scripts/vehicles/ai-vehicles), owned by your character, and waits at the delivery spot with the keys. The color stays until the first time you park it (then the garage saves its full look).
- If the vehicle cannot be made, the money goes back to the account it came from.
- A shop with jobs or gangs set (a police dealer, a gang shop) shows its prompt and blip only to members.

## Installation

Installed by the AI Core recipe. By hand: `ensure ai-vehicleshop` after `ai-core` and `ai-vehicles`.

It comes with six shops: Premium Deluxe Motorsport, Luxury Vehicle Shop, Marina Shop, Air Shop, Truck Motor Shop and Sanders Motorcycles, and a catalog of 34 vehicles in the compacts, sedans, SUVs, sports, super, muscle, off-road, vans and motorcycles categories.

<Callout type="warn">
The Marina, Air and Truck shops sell the categories `boats`, `helicopters`, `planes`, `commercial`, `industrial` and `utility`, which have no vehicles in the default catalog. Add vehicles with those categories in the **Catalog** tab, or those shops stay empty.
</Callout>

## Panel settings

Admin panel > **Vehicle shops**.

### Tab: Catalog

Every vehicle players can buy, its price and category. One record per vehicle (**New vehicle** / **Remove vehicle from the catalog**). Removing a vehicle from the catalog does not take it from players who own one.

| Setting | What it changes | Unit | Default for new |
| --- | --- | --- | --- |
| Model | The GTA spawn name (sultan, adder, bati). Lower case letters, digits and `_`, 2-32 characters. | | |
| Name | Shown in the shop. Empty uses the game's own name. Up to 48 characters. | | empty |
| Price | 0-100,000,000, steps of 1,000 in the panel. | $ | 10,000 |
| Category | Shops sell the categories they list (sedans, sports, motorcycles...). | | sedans |

### Tab: Shops

Where players buy vehicles and which categories each shop sells. One record per shop (**New shop** / **Delete shop**).

**Shop** card: where players open the shop and what it sells.

| Setting | What it changes | Unit | Default for new |
| --- | --- | --- | --- |
| Shop name | Shown on the prompt and the screen. 1-48 characters. | | |
| Counter | Stand where players open the shop and use your position. | point | |
| Reach | How far from the counter the prompt shows. 1-30. | m | 5 |
| Categories | Catalog categories this shop sells (up to 30). | | empty |
| Jobs | Only members of these jobs can use it. Leave jobs and gangs empty for everyone. | | empty |
| Gangs | Members of these gangs can use it too. | | empty |
| Only on duty | Job members must be on duty in that job. | on / off | off |
| Map blip | Shows this shop on the map, with the look from the Settings tab. | on / off | on |

**Showroom** card: where the previewed vehicle stands, where the camera looks from and where bought vehicles come out.

| Setting | What it changes |
| --- | --- |
| Preview spot | Stand where the shown vehicle should be, facing its front direction. |
| Camera | Look at the preview spot with the game camera and use the camera position. |
| Delivery spot | Where bought vehicles appear, facing your direction. |

**NPC** card: an optional clerk at the counter (**Model**, **What it does**, **Where it stands**). Leave the model empty for none. Players see it within 50 m.

### Tab: Settings

How purchases are paid and how shops look on the map.

| Setting | What it changes | Default |
| --- | --- | --- |
| Accounts | Tried in this order until one has enough money. | bank, cash |
| Shop (Map blips) | The blip of shops (icon, color, size). | icon 326, color 3, size 0.7 |
| Motorcycle shop (Map blips) | A shop that sells only the motorcycles category. | icon 226, color 3, size 0.7 |

## Commands and keybinds

None. The shop prompt uses the interact key (**E** by default) and shows on foot only. **ESC** closes the shop.

## Known limits

- Colors are eight preset GTA colors. There are no mods and no test drive in the shop (a test drive exists at the used car lots of [ai-vehiclesales](/docs/scripts/vehicles/ai-vehiclesales)).
- The preview vehicle exists only on the buyer's screen; other players do not see it.
