```ts title="TypeScript"
import { resourceExport } from "@aifivem/lib/server";
const shop = resourceExport("ai-vehicleshop");
```

## Exports de servidor

### GetCatalogPrice

El precio de un modelo en el catálogo del panel. Úsalo para valorar un vehículo (una recompra, un seguro, un impuesto). ai-vehiclesales lo usa para la oferta del concesionario.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
GetCatalogPrice(model: string): number | null
```

```lua title="Lua"
local price = exports['ai-vehicleshop']:GetCatalogPrice(model) -- number o nil
```

#### Parámetros

<TypeTable
  type={{
    model: { type: 'string', description: 'El nombre de spawn (`"sultan"`). No importan las mayúsculas.', required: true },
  }}
/>

#### Devuelve

El precio en dólares. `null` cuando ningún vehículo del catálogo tiene ese modelo, o `model` no es texto.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const shop = resourceExport("ai-vehicleshop");

// El seguro paga el 40 % del precio de catálogo.
export function insurancePayout(model: string): number {
  const price = shop.GetCatalogPrice(model);
  return price === null ? 0 : Math.floor(price * 0.4);
}
```
</Tab>
<Tab value="Lua">
```lua
-- El seguro paga el 40 % del precio de catálogo.
local function insurancePayout(model)
  local price = exports['ai-vehicleshop']:GetCatalogPrice(model)
  if not price then return 0 end
  return math.floor(price * 0.4)
end
```
</Tab>
</Tabs>

## Eventos

El callback de compra de ai-vehicleshop es interno (de su cliente a su servidor); no lo llames desde otros scripts. Comprueba en el servidor el concesionario, la distancia, el acceso y el catálogo.
