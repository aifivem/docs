```ts title="TypeScript"
import { resourceExport } from "@aicore-fivem/lib/server";
const shop = resourceExport("ai-vehicleshop");
```

## Server exports

### GetCatalogPrice

A model's price in the panel's catalog. Use it to value a vehicle (a buy-back, insurance, a tax). ai-vehiclesales uses it for the dealer's offer.

**Side:** Server · **Waits:** no

```ts title="Signature"
GetCatalogPrice(model: string): number | null
```

```lua title="Lua"
local price = exports['ai-vehicleshop']:GetCatalogPrice(model) -- number or nil
```

#### Parameters

<TypeTable
  type={{
    model: { type: 'string', description: 'The spawn name (`"sultan"`). Case does not matter.', required: true },
  }}
/>

#### Returns

The price in dollars. `null` when no catalog vehicle has that model, or `model` is not text.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const shop = resourceExport("ai-vehicleshop");

// Insurance pays out 40 % of the catalog price.
export function insurancePayout(model: string): number {
  const price = shop.GetCatalogPrice(model);
  return price === null ? 0 : Math.floor(price * 0.4);
}
```
</Tab>
<Tab value="Lua">
```lua
-- Insurance pays out 40 % of the catalog price.
local function insurancePayout(model)
  local price = exports['ai-vehicleshop']:GetCatalogPrice(model)
  if not price then return 0 end
  return math.floor(price * 0.4)
end
```
</Tab>
</Tabs>

## Events

ai-vehicleshop's buy callback is internal (its client to its server); do not call it from other scripts. It checks the shop, the distance, access and the catalog on the server.
