```ts title="TypeScript"
import { resourceExport } from "@aicore-fivem/lib/server";
const shop = resourceExport("ai-vehicleshop");
```

## Серверные экспорты

### GetCatalogPrice

Цена модели в каталоге панели. Используйте её, чтобы оценить транспорт (выкуп, страховка, налог). ai-vehiclesales использует её для предложения дилера.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
GetCatalogPrice(model: string): number | null
```

```lua title="Lua"
local price = exports['ai-vehicleshop']:GetCatalogPrice(model) -- число или nil
```

#### Параметры

<TypeTable
  type={{
    model: { type: 'string', description: 'Имя для создания (`"sultan"`). Регистр не важен.', required: true },
  }}
/>

#### Возвращает

Цена в долларах. `null`, если ни у одного транспорта каталога нет такой модели или `model` не текст.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const shop = resourceExport("ai-vehicleshop");

// Страховка выплачивает 40 % цены из каталога.
export function insurancePayout(model: string): number {
  const price = shop.GetCatalogPrice(model);
  return price === null ? 0 : Math.floor(price * 0.4);
}
```
</Tab>
<Tab value="Lua">
```lua
-- Страховка выплачивает 40 % цены из каталога.
local function insurancePayout(model)
  local price = exports['ai-vehicleshop']:GetCatalogPrice(model)
  if not price then return 0 end
  return math.floor(price * 0.4)
end
```
</Tab>
</Tabs>

## События

Колбэк покупки ai-vehicleshop внутренний (от его клиента к его серверу); не вызывайте его из других скриптов. Он проверяет на сервере автосалон, расстояние, доступ и каталог.
