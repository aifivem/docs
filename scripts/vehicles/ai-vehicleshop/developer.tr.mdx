`@aifivem/shared` içinde (`exports.ts`) `AiVehicleshopServerExports` olarak tiplenmiştir.

```ts title="TypeScript"
import { resourceExport } from "@aifivem/lib/server";
const shop = resourceExport("ai-vehicleshop");
```

## Server export’ları

### GetCatalogPrice

Bir modelin paneldeki katalogda fiyatı. Bir aracın değerini biçmek için kullan (geri alım, sigorta, vergi). ai-vehiclesales bunu bayinin teklifi için kullanır.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
GetCatalogPrice(model: string): number | null
```

```lua title="Lua"
local price = exports['ai-vehicleshop']:GetCatalogPrice(model) -- number ya da nil
```

#### Parametreler

<TypeTable
  type={{
    model: { type: 'string', description: 'Spawn adı (`"sultan"`). Büyük/küçük harf önemli değildir.', required: true },
  }}
/>

#### Dönüş değeri

Dolar cinsinden fiyat. Katalogda o modele sahip araç yoksa ya da `model` metin değilse `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const shop = resourceExport("ai-vehicleshop");

// Sigorta katalog fiyatının %40’ını öder.
export function insurancePayout(model: string): number {
  const price = shop.GetCatalogPrice(model);
  return price === null ? 0 : Math.floor(price * 0.4);
}
```
</Tab>
<Tab value="Lua">
```lua
-- Sigorta katalog fiyatının %40’ını öder.
local function insurancePayout(model)
  local price = exports['ai-vehicleshop']:GetCatalogPrice(model)
  if not price then return 0 end
  return math.floor(price * 0.4)
end
```
</Tab>
</Tabs>

## Event’ler

ai-vehicleshop’un satın alma callback’i iç kullanım içindir (kendi client’ından kendi server’ına); başka script’lerden çağırma. Server’da galeriyi, mesafeyi, erişimi ve kataloğu kontrol eder.
