ai-vehicleshop продаёт транспорт. Один каталог содержит весь транспорт с его ценой и категорией; каждый автосалон продаёт часть этих категорий.

## Что он делает в игре

- Подойдите к стойке автосалона и нажмите клавишу взаимодействия у **Browse ...**. Камера переезжает в шоурум, а экран показывает категории автосалона.
- Выберите транспорт, чтобы увидеть его в точке предпросмотра, и выберите один из восьми цветов.
- **Buy** списывает цену с первого счёта, который может её оплатить (по умолчанию сначала банк). Транспорт создаётся в [ai-vehicles](/ru/docs/scripts/vehicles/ai-vehicles), принадлежит вашему персонажу и ждёт в точке выдачи вместе с ключами. Цвет сохраняется до первой парковки (тогда гараж сохраняет его полный вид).
- Если транспорт не удаётся создать, деньги возвращаются на счёт, с которого пришли.
- Автосалон с заданными работами или бандами (полицейский дилер, магазин банды) показывает свою подсказку и блип только участникам.

## Установка

Устанавливается рецептом AI Core. Вручную: `ensure ai-vehicleshop` после `ai-core` и `ai-vehicles`.

Он поставляется с шестью автосалонами: Premium Deluxe Motorsport, Luxury Vehicle Shop, Marina Shop, Air Shop, Truck Motor Shop и Sanders Motorcycles, и каталогом из 34 транспортов в категориях compacts, sedans, SUVs, sports, super, muscle, off-road, vans и motorcycles.

<Callout type="warn">
Автосалоны Marina, Air и Truck продают категории `boats`, `helicopters`, `planes`, `commercial`, `industrial` и `utility`, в которых нет транспорта в каталоге по умолчанию. Добавьте транспорт с этими категориями во вкладке **Catalog**, иначе эти автосалоны останутся пустыми.
</Callout>

## Настройки панели

Админ-панель > **Vehicle shops**.

### Вкладка Catalog

Весь транспорт, который могут купить игроки, его цена и категория. Одна запись на транспорт (**New vehicle** / **Remove vehicle from the catalog**). Удаление транспорта из каталога не забирает его у игроков, которые им владеют.

| Настройка | Что меняет | Единица | По умолчанию для новых |
| --- | --- | --- | --- |
| Model | Имя для создания в GTA (sultan, adder, bati). Строчные буквы, цифры и `_`, 2-32 символа. | | |
| Name | Показывается в автосалоне. Пусто использует собственное название игры. До 48 символов. | | пусто |
| Price | 0-100,000,000, с шагом 1,000 в панели. | $ | 10,000 |
| Category | Автосалоны продают категории из своего списка (sedans, sports, motorcycles...). | | sedans |

### Вкладка Shops

Где игроки покупают транспорт и какие категории продаёт каждый автосалон. Одна запись на автосалон (**New shop** / **Delete shop**).

Карточка **Shop**: где игроки открывают автосалон и что он продаёт.

| Настройка | Что меняет | Единица | По умолчанию для новых |
| --- | --- | --- | --- |
| Shop name | Показывается в подсказке и на экране. 1-48 символов. | | |
| Counter | Встаньте там, где игроки открывают автосалон, и используйте свою позицию. | точка | |
| Reach | На каком расстоянии от стойки показывается подсказка. 1-30. | м | 5 |
| Categories | Категории каталога, которые продаёт этот автосалон (до 30). | | пусто |
| Jobs | Пользоваться могут только участники этих работ. Оставьте работы и банды пустыми, чтобы было доступно всем. | | пусто |
| Gangs | Участники этих банд тоже могут пользоваться. | | пусто |
| Only on duty | Участники работы должны быть на дежурстве в этой работе. | вкл. / выкл. | выкл. |
| Map blip | Показывает этот автосалон на карте с видом из вкладки Settings. | вкл. / выкл. | вкл. |

Карточка **Showroom**: где стоит транспорт для предпросмотра, откуда смотрит камера и где выезжает купленный транспорт.

| Настройка | Что меняет |
| --- | --- |
| Preview spot | Встаньте там, где должен стоять показываемый транспорт, лицом в его переднюю сторону. |
| Camera | Посмотрите на точку предпросмотра камерой игры и используйте позицию камеры. |
| Delivery spot | Где появляется купленный транспорт, лицом в вашу сторону. |

Карточка **NPC**: необязательный продавец у стойки (**Model**, **What it does**, **Where it stands**). Оставьте модель пустой, чтобы его не было. Игроки видят его в пределах 50 м.

### Вкладка Settings

Как оплачиваются покупки и как автосалоны выглядят на карте.

| Настройка | Что меняет | По умолчанию |
| --- | --- | --- |
| Accounts | Проверяются в этом порядке, пока на одном не хватит денег. | bank, cash |
| Shop (Map blips) | Блип автосалонов (иконка, цвет, размер). | иконка 326, цвет 3, размер 0.7 |
| Motorcycle shop (Map blips) | Автосалон, который продаёт только категорию motorcycles. | иконка 226, цвет 3, размер 0.7 |

## Команды и привязки клавиш

Нет. Подсказка автосалона использует клавишу взаимодействия (по умолчанию **E**) и показывается только пешком. **ESC** закрывает автосалон.

## Известные ограничения

- Цвета являются восемью готовыми цветами GTA. В автосалоне нет модификаций и тест-драйва (тест-драйв есть на площадках подержанных машин [ai-vehiclesales](/ru/docs/scripts/vehicles/ai-vehiclesales)).
- Транспорт для предпросмотра существует только на экране покупателя; другие игроки его не видят.
