Typowany jako `AiVehicleshopServerExports` w `@aifivem/shared` (`exports.ts`).

```ts title="TypeScript"
import { resourceExport } from "@aifivem/lib/server";
const shop = resourceExport("ai-vehicleshop");
```

## Eksporty serwera

### GetCatalogPrice

Cena modelu w katalogu z panelu. Używaj jej do wyceny pojazdu (odkup, ubezpieczenie, podatek). ai-vehiclesales używa jej do oferty dealera.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
GetCatalogPrice(model: string): number | null
```

```lua title="Lua"
local price = exports['ai-vehicleshop']:GetCatalogPrice(model) -- liczba lub nil
```

#### Parametry

<TypeTable
  type={{
    model: { type: 'string', description: 'Nazwa spawnu (`"sultan"`). Wielkość liter nie ma znaczenia.', required: true },
  }}
/>

#### Zwraca

Cena w dolarach. `null`, gdy żaden pojazd w katalogu nie ma tego modelu albo `model` nie jest tekstem.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const shop = resourceExport("ai-vehicleshop");

// Ubezpieczenie wypłaca 40 % ceny katalogowej.
export function insurancePayout(model: string): number {
  const price = shop.GetCatalogPrice(model);
  return price === null ? 0 : Math.floor(price * 0.4);
}
```
</Tab>
<Tab value="Lua">
```lua
-- Ubezpieczenie wypłaca 40 % ceny katalogowej.
local function insurancePayout(model)
  local price = exports['ai-vehicleshop']:GetCatalogPrice(model)
  if not price then return 0 end
  return math.floor(price * 0.4)
end
```
</Tab>
</Tabs>

## Zdarzenia

Callback zakupu ai-vehicleshop jest wewnętrzny (od jego klienta do jego serwera); nie wywołuj go z innych skryptów. Sprawdza na serwerze salon, odległość, dostęp i katalog.
