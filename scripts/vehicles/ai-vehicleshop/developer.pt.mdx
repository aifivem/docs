```ts title="TypeScript"
import { resourceExport } from "@aifivem/lib/server";
const shop = resourceExport("ai-vehicleshop");
```

## Exports do servidor

### GetCatalogPrice

O preço de um modelo no catálogo do painel. Use-o para avaliar um veículo (uma recompra, um seguro, um imposto). O ai-vehiclesales o usa para a oferta do revendedor.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
GetCatalogPrice(model: string): number | null
```

```lua title="Lua"
local price = exports['ai-vehicleshop']:GetCatalogPrice(model) -- número ou nil
```

#### Parâmetros

<TypeTable
  type={{
    model: { type: 'string', description: 'O nome de spawn (`"sultan"`). Maiúsculas e minúsculas não importam.', required: true },
  }}
/>

#### Retorno

O preço em dólares. `null` quando nenhum veículo do catálogo tem esse modelo, ou `model` não é texto.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const shop = resourceExport("ai-vehicleshop");

// O seguro paga 40 % do preço de catálogo.
export function insurancePayout(model: string): number {
  const price = shop.GetCatalogPrice(model);
  return price === null ? 0 : Math.floor(price * 0.4);
}
```
</Tab>
<Tab value="Lua">
```lua
-- O seguro paga 40 % do preço de catálogo.
local function insurancePayout(model)
  local price = exports['ai-vehicleshop']:GetCatalogPrice(model)
  if not price then return 0 end
  return math.floor(price * 0.4)
end
```
</Tab>
</Tabs>

## Eventos

O callback de compra do ai-vehicleshop é interno (do cliente dele para o servidor dele); não o chame a partir de outros scripts. Ele verifica a loja, a distância, o acesso e o catálogo no servidor.
