import { resourceExport } from "@aifivem/lib/server";

## Server-Exports

### GetCatalogPrice

Der Preis eines Modells im Katalog des Panels. Nutze ihn, um ein Fahrzeug zu bewerten (ein Rückkauf, eine Versicherung, eine Steuer). ai-vehiclesales nutzt ihn für das Angebot des Händlers.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
GetCatalogPrice(model: string): number | null
```

```lua title="Lua"
local price = exports['ai-vehicleshop']:GetCatalogPrice(model) -- Zahl oder nil
```

#### Parameter

<TypeTable
  type={{
    model: { type: 'string', description: 'Der Spawn-Name (`"sultan"`). Groß-/Kleinschreibung spielt keine Rolle.', required: true },
  }}
/>

#### Rückgabewert

Der Preis in Dollar. `null`, wenn kein Katalogfahrzeug dieses Modell hat oder `model` kein Text ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const shop = resourceExport("ai-vehicleshop");

// Die Versicherung zahlt 40 % des Katalogpreises aus.
export function insurancePayout(model: string): number {
  const price = shop.GetCatalogPrice(model);
  return price === null ? 0 : Math.floor(price * 0.4);
}
```
</Tab>
<Tab value="Lua">
```lua
-- Die Versicherung zahlt 40 % des Katalogpreises aus.
local function insurancePayout(model)
  local price = exports['ai-vehicleshop']:GetCatalogPrice(model)
  if not price then return 0 end
  return math.floor(price * 0.4)
end
```
</Tab>
</Tabs>

## Events

Der Kauf-Callback von ai-vehicleshop ist intern (von seinem Client an seinen Server); rufe ihn nicht aus anderen Skripten auf. Er prüft auf dem Server den Händler, die Entfernung, den Zugriff und den Katalog.
