## Exports serveur

### GetCatalogPrice

Le prix d’un modèle dans le catalogue du panneau. Utilisez-le pour estimer un véhicule (un rachat, une assurance, une taxe). ai-vehiclesales l’utilise pour l’offre du concessionnaire.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
GetCatalogPrice(model: string): number | null
```

```lua title="Lua"
local price = exports['ai-vehicleshop']:GetCatalogPrice(model) -- nombre ou nil
```

#### Paramètres

<TypeTable
  type={{
    model: { type: 'string', description: 'Le nom d’apparition (`"sultan"`). La casse n’a pas d’importance.', required: true },
  }}
/>

#### Retour

Le prix en dollars. `null` quand aucun véhicule du catalogue n’a ce modèle, ou que `model` n’est pas un texte.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const shop = resourceExport("ai-vehicleshop");

// L’assurance rembourse 40 % du prix du catalogue.
export function insurancePayout(model: string): number {
  const price = shop.GetCatalogPrice(model);
  return price === null ? 0 : Math.floor(price * 0.4);
}
```
</Tab>
<Tab value="Lua">
```lua
-- L’assurance rembourse 40 % du prix du catalogue.
local function insurancePayout(model)
  local price = exports['ai-vehicleshop']:GetCatalogPrice(model)
  if not price then return 0 end
  return math.floor(price * 0.4)
end
```
</Tab>
</Tabs>

## Events

Le callback d’achat d’ai-vehicleshop est interne (de son client vers son serveur) ; ne l’appelez pas depuis d’autres scripts. Il vérifie la concession, la distance, l’accès et le catalogue sur le serveur.
