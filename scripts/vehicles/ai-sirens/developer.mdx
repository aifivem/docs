ai-sirens has client exports only. They do the same as the driver's keys. `vehicle` is optional: without it, the vehicle the player sits in is used. A vehicle that is not an emergency vehicle (class 18 and in the panel's model list) is ignored.

<Callout type="warn">
Changes (tone, siren) are asked from the server, which accepts them only from the driver. Call the setters on the driver's client. Lights (`SetLights`, `ToggleLights`) are the game's own siren light state on that client.
</Callout>

Lua calls them as `exports['ai-sirens']:Name(...)`. They are not typed in `@aifivem/shared`: in TypeScript use `callExport("ai-sirens", "Name", ...args)` from `@aifivem/lib/client`.

## Client exports

### SetLights

Turns the emergency lights on or off (and the ONX lightbar's, if any).

**Side:** Client · **Waits:** no

```ts title="Signature"
SetLights(vehicle: number | undefined, on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-sirens']:SetLights(vehicle, true)
```

#### Parameters

<TypeTable
  type={{
    vehicle: { type: 'number | undefined', description: 'A vehicle handle; `nil` / `undefined` for the one the player sits in.' },
    on: { type: 'boolean', description: '`true` turns the lights on. Anything else turns them off.', required: true },
  }}
/>

#### Returns

`true` when the vehicle is an emergency vehicle and the lights were set. `false` otherwise.

### ToggleLights

Flips the emergency lights.

**Side:** Client · **Waits:** no

```ts title="Signature"
ToggleLights(vehicle?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-sirens']:ToggleLights()
```

#### Returns

`true` when the vehicle is an emergency vehicle. `false` otherwise.

### SetSirenTone

Sets the main siren tone. A tone above 0 turns the lights on first.

**Side:** Client · **Waits:** no (the server answers later; the local value shows at once)

```ts title="Signature"
SetSirenTone(vehicle: number | undefined, tone: 0 | 1 | 2 | 3): boolean
```

```lua title="Lua"
local ok = exports['ai-sirens']:SetSirenTone(nil, 2)
```

#### Parameters

<TypeTable
  type={{
    vehicle: { type: 'number | undefined', description: 'A vehicle handle; `nil` / `undefined` for the one the player sits in.' },
    tone: { type: 'number', description: '0 = off, 1-3 = a tone. Decimals are rounded down; other values are refused.', required: true },
  }}
/>

#### Returns

`true` when the request was sent. `false` for a vehicle that is not an emergency vehicle or a tone outside 0-3. A request the server does not confirm within 1.5 seconds counts as refused and the old tone shows again.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/client";

// A pursuit script: tone 2 when the chase starts.
export function startPursuit(): void {
  if (!callExport("ai-sirens", "SetSirenTone", undefined, 2)) return;
  console.log("pursuit tone on");
}
```
</Tab>
<Tab value="Lua">
```lua
-- A pursuit script: tone 2 when the chase starts.
local function startPursuit()
  if not exports['ai-sirens']:SetSirenTone(nil, 2) then return end
  print('pursuit tone on')
end
```
</Tab>
</Tabs>

### ToggleSiren

Stops the siren if it runs, otherwise starts it on tone 1 (turning the lights on first).

**Side:** Client · **Waits:** no

```ts title="Signature"
ToggleSiren(vehicle?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-sirens']:ToggleSiren()
```

#### Returns

`true` when the request was sent, `false` for a vehicle that is not an emergency vehicle.

### CycleTone

The next tone: 1, 2, 3, then 1 again. With the siren off it starts tone 1 (turning the lights on first).

**Side:** Client · **Waits:** no

```ts title="Signature"
CycleTone(vehicle?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-sirens']:CycleTone()
```

#### Returns

`true` when the request was sent, `false` for a vehicle that is not an emergency vehicle.

### GetSirenTone

The current main siren tone.

**Side:** Client · **Waits:** no

```ts title="Signature"
GetSirenTone(vehicle?: number): number
```

```lua title="Lua"
local tone = exports['ai-sirens']:GetSirenTone(vehicle)
```

#### Returns

0 (off) to 3. Also 0 for a vehicle that is not an emergency vehicle.

### AreLightsOn

Whether the emergency lights are on.

**Side:** Client · **Waits:** no

```ts title="Signature"
AreLightsOn(vehicle?: number): boolean
```

```lua title="Lua"
local on = exports['ai-sirens']:AreLightsOn(vehicle)
```

#### Returns

`true` when on. `false` when off or not an emergency vehicle.

### GetAirManuState

The airhorn and manual siren state.

**Side:** Client · **Waits:** no

```ts title="Signature"
GetAirManuState(vehicle?: number): number
```

```lua title="Lua"
local state = exports['ai-sirens']:GetAirManuState(vehicle)
```

#### Returns

`0` off, `1` airhorn, `2` manual siren, `3` both. 0 for a vehicle that is not an emergency vehicle.

### GetLightbarModel

The ONX lightbar model attached to the vehicle.

**Side:** Client · **Waits:** no

```ts title="Signature"
GetLightbarModel(vehicle?: number): string | null
```

```lua title="Lua"
local model = exports['ai-sirens']:GetLightbarModel(vehicle)
```

#### Returns

The model name (`"onx_pol_lbar_mdn1a"`), or `null` when the vehicle has none or is not an emergency vehicle.

## State bags

Written only by the server after its checks. Read them on any client to know a vehicle's siren state.

| Bag | Type | Meaning |
| --- | --- | --- |
| `siren:lx` | `number` | Main siren tone: 0 off, 1-3 a tone. |
| `siren:manu` | `number` | Airhorn / manual siren: 0 off, 1 horn, 2 manual, 3 both. |
| `siren:lightbar` | `string` | The ONX lightbar model attached (absent: none). |

```lua title="Lua (client)"
local vehicle = GetVehiclePedIsIn(PlayerPedId(), false)
local tone = Entity(vehicle).state['siren:lx'] or 0
```

## Events

| Name | Kind | What it does |
| --- | --- | --- |
| `ai-sirens:setState` | client to server | `(netId, key, value)`: the driver asks for a tone or airhorn change, or the network owner sets the lightbar model. The server accepts only listed emergency models, a value above 0 only from the driver, a reset to 0 from a player within 10 m while the driver seat is empty, and only lightbar models the panel lists. Internal: use the exports. |
