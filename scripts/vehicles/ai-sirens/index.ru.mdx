ai-sirens даёт водителю спецтранспорта управление его огнями и сиреной. Каждый игрок рядом видит огни и слышит тот же тон.

## Что он делает в игре

Управление сиреной получает только транспорт класса спецтранспорта (класс GTA 18), указанный в панели. Сидя на месте водителя такого транспорта:

- **Огни.** **Q** включает или выключает спецсигналы. Выключение огней также останавливает сирену.
- **Сирена.** **Левый Alt** запускает сирену на тоне 1 (огни должны быть включены) или останавливает её.
- **Тон.** **Y** переключает на следующий тон (1, 2, 3, снова 1), пока работает сирена. При выключенной сирене удержание проигрывает ручную сирену.
- **Пневмосигнал.** Удерживайте **E** для пневмосигнала.
- **Пожарные машины** сохраняют свой вой на тоне 1, а их пневмосигнал и тон 3 являются звуками пожарной машины. **Скорая помощь** (и другие указанные модели) проигрывает powercall на тоне 1.
- **Выход из машины.** При включённом переключателе панели звук сирены останавливается, когда водитель выходит; огни остаются включёнными.
- **Световые балки ONX.** Машина без опознавательных знаков с набором световых балок ONX получает балку, выбранную слотом тюнинга (по умолчанию слот 49). Игра каждого игрока рисует свою копию, и она мигает вместе с огнями транспорта. Транспорт со световой балкой ONX использует тоны ONX.
- Далёкие полицейские сирены GTA, которые играют сами по себе, можно заглушить.

## Установка

Устанавливается рецептом AI Core. Вручную: `ensure ai-sirens` после `ai-core`.

Для световых балок стримьте модели световых балок ONX (`emergency-b-lightbars`) и установите слоту тюнинга транспорта значение из списка панели (в тюнинг-мастерской или своим скриптом).

<Callout type="warn">
Дополнительные полицейские, пожарные машины и машины скорой помощи нужно добавить в **Emergency vehicle models**, иначе сервер отклонит смену их сирены.
</Callout>

## Настройки панели

Админ-панель > **Sirens**.

### Вкладка Sirens

Как звучит спецтранспорт: тоны, пневмосигнал, пожарные машины и скорая помощь.

**General** (общее): спецтранспорт (класс 18) получает клавиши сирены: огни, сирена, тон, пневмосигнал; их слышит каждый игрок рядом.

| Настройка | Что меняет | По умолчанию |
| --- | --- | --- |
| No distant sirens | Заглушает далёкие полицейские сирены GTA, которые играют сами по себе. | вкл. |
| Siren stops when the driver gets out | Вкл.: уход с места водителя выключает звук сирены (огни остаются). | вкл. |
| Emergency vehicle models | Сирены, пневмосигнал и световые балки получают только эти модели; добавьте сюда свои дополнительные полицейские, пожарные машины и машины скорой помощи. Пусто: весь транспорт класса спецтранспорта. До 200. | ambulance, fbi, fbi2, firetruk, lguard, pbus, police, police2, police3, police4, policeb, policeold1, policeold2, policet, pranger, riot, riot2, sheriff, sheriff2 |
| Firetruck models | Эти сохраняют свой вой на тоне 1, их пневмосигнал и тон 3 являются звуками пожарной машины. | firetruk |
| Ambulance tone models | Тон 1 этих моделей проигрывает powercall скорой помощи. | ambulance, firetruk, lguard |

**Tones** (тоны): игровые звуки трёх тонов сирены для обычного спецтранспорта.

| Настройка | По умолчанию |
| --- | --- |
| Тон 1 | `VEHICLES_HORNS_SIREN_1` |
| Тон 2 | `VEHICLES_HORNS_SIREN_2` |
| Тон 3 | `VEHICLES_HORNS_POLICE_WARNING` |

### Вкладка Lightbars

Световые балки ONX, прикрепляемые по слоту тюнинга, и тоны сирены ONX.

**ONX lightbars** (световые балки ONX): нужен стрим моделей световых балок ONX (emergency-b-lightbars); игра каждого игрока рисует свою копию, по сети ничего не создаётся.

| Настройка | Что меняет | По умолчанию |
| --- | --- | --- |
| Attach lightbars | Выкл.: световые балки не прикрепляются. | вкл. |
| Tuning slot | Слот модификации транспорта, который выбирает световую балку (49 в наборе ONX). 0-49. | 49 |
| Models with ONX tones | Эти всегда используют тоны ONX; транспорт со световой балкой ONX использует их в любом случае. | пусто |
| Lightbar per slot value | Какую модель световой балки прикрепляет каждое значение слота тюнинга (**Add a lightbar**: **Slot value** 0-100, **Lightbar model**). До 40 строк. | 4-13: полицейские балки `onx_pol_lbar_*`, 14-16: `onx_ems_lbar_*`, 17-19: `onx_amb_lbar_*` |

**ONX tones** (тоны ONX): тоны сирены транспорта со световой балкой ONX или из списка выше.

| Настройка | По умолчанию |
| --- | --- |
| Тон 1 | `RESIDENT_VEHICLES_SIREN_WAIL_02` |
| Тон 2 | `RESIDENT_VEHICLES_SIREN_QUICK_02` |
| Тон 3 | `VEHICLES_HORNS_POLICE_WARNING` |

## Команды

Нет.

## Привязки клавиш

Действуют только на месте водителя спецтранспорта. Игроки меняют их в настройках клавиш GTA (раздел FiveM); владелец меняет значения по умолчанию в админ-панели (**Keybinds**).

| Клавиша по умолчанию | Что делает |
| --- | --- |
| Q | Сирена: спецсигналы вкл. / выкл. |
| Левый Alt | Сирена: основная сирена вкл. / выкл. |
| Y | Сирена: следующий тон (удерживайте для ручной сирены, пока она выключена) |
| E | Сирена: пневмосигнал (удерживать) |

Во время управления спецтранспортом эти клавиши перехватывают клавиши клаксона, радио и кинематографической камеры игры.

## Известные ограничения

- Сервер не может прочитать класс транспорта, поэтому доверяет списку **Emergency vehicle models**. Пустой список позволяет любой модели менять состояние сирены.
- Звук щелчка из внешних звуковых ресурсов и синхронизация тонов режима погони оригинального tgiann-siren-control не включены; вместо щелчка проигрывается игровой звук.
