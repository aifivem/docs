ai-sirens ma tylko eksporty klienta. Robią to samo co klawisze kierowcy. `vehicle` jest opcjonalne: bez niego używany jest pojazd, w którym siedzi gracz. Pojazd, który nie jest pojazdem uprzywilejowanym (klasa 18 i na liście modeli w panelu), jest ignorowany.

<Callout type="warn">
O zmiany (ton, syrena) prosi się serwer, który przyjmuje je tylko od kierowcy. Wywołuj settery na kliencie kierowcy. Światła (`SetLights`, `ToggleLights`) to własny stan świateł syreny gry na tym kliencie.
</Callout>

Lua wywołuje je jako `exports['ai-sirens']:Name(...)`. Nie są typowane w `@aicore-fivem/shared`: w TypeScript używaj `callExport("ai-sirens", "Name", ...args)` z `@aicore-fivem/lib/client`.

## Eksporty klienta

### SetLights

Włącza lub wyłącza światła uprzywilejowane (oraz belki świetlnej ONX, jeśli jest).

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
SetLights(vehicle: number | undefined, on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-sirens']:SetLights(vehicle, true)
```

#### Parametry

<TypeTable
  type={{
    vehicle: { type: 'number | undefined', description: 'Uchwyt pojazdu; `nil` / `undefined` dla pojazdu, w którym siedzi gracz.' },
    on: { type: 'boolean', description: '`true` włącza światła. Cokolwiek innego je wyłącza.', required: true },
  }}
/>

#### Zwraca

`true`, gdy pojazd jest pojazdem uprzywilejowanym i światła zostały ustawione. W przeciwnym razie `false`.

### ToggleLights

Przełącza światła uprzywilejowane.

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
ToggleLights(vehicle?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-sirens']:ToggleLights()
```

#### Zwraca

`true`, gdy pojazd jest pojazdem uprzywilejowanym. W przeciwnym razie `false`.

### SetSirenTone

Ustawia główny ton syreny. Ton powyżej 0 najpierw włącza światła.

**Strona:** klient · **Czeka:** nie (serwer odpowiada później; lokalna wartość pojawia się od razu)

```ts title="Sygnatura"
SetSirenTone(vehicle: number | undefined, tone: 0 | 1 | 2 | 3): boolean
```

```lua title="Lua"
local ok = exports['ai-sirens']:SetSirenTone(nil, 2)
```

#### Parametry

<TypeTable
  type={{
    vehicle: { type: 'number | undefined', description: 'Uchwyt pojazdu; `nil` / `undefined` dla pojazdu, w którym siedzi gracz.' },
    tone: { type: 'number', description: '0 = wyłączona, 1-3 = ton. Części dziesiętne są zaokrąglane w dół; inne wartości są odrzucane.', required: true },
  }}
/>

#### Zwraca

`true`, gdy żądanie zostało wysłane. `false` dla pojazdu, który nie jest uprzywilejowany, lub tonu spoza 0-3. Żądanie, którego serwer nie potwierdzi w ciągu 1,5 sekundy, liczy się jako odrzucone i znowu widać stary ton.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aicore-fivem/lib/client";

// Skrypt pościgu: ton 2, gdy zaczyna się pościg.
export function startPursuit(): void {
  if (!callExport("ai-sirens", "SetSirenTone", undefined, 2)) return;
  console.log("pursuit tone on");
}
```
</Tab>
<Tab value="Lua">
```lua
-- Skrypt pościgu: ton 2, gdy zaczyna się pościg.
local function startPursuit()
  if not exports['ai-sirens']:SetSirenTone(nil, 2) then return end
  print('pursuit tone on')
end
```
</Tab>
</Tabs>

### ToggleSiren

Zatrzymuje syrenę, jeśli działa, w przeciwnym razie uruchamia ją na tonie 1 (najpierw włączając światła).

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
ToggleSiren(vehicle?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-sirens']:ToggleSiren()
```

#### Zwraca

`true`, gdy żądanie zostało wysłane, `false` dla pojazdu, który nie jest uprzywilejowany.

### CycleTone

Następny ton: 1, 2, 3, potem znowu 1. Przy wyłączonej syrenie uruchamia ton 1 (najpierw włączając światła).

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
CycleTone(vehicle?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-sirens']:CycleTone()
```

#### Zwraca

`true`, gdy żądanie zostało wysłane, `false` dla pojazdu, który nie jest uprzywilejowany.

### GetSirenTone

Bieżący główny ton syreny.

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
GetSirenTone(vehicle?: number): number
```

```lua title="Lua"
local tone = exports['ai-sirens']:GetSirenTone(vehicle)
```

#### Zwraca

Od 0 (wyłączona) do 3. Także 0 dla pojazdu, który nie jest uprzywilejowany.

### AreLightsOn

Czy światła uprzywilejowane są włączone.

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
AreLightsOn(vehicle?: number): boolean
```

```lua title="Lua"
local on = exports['ai-sirens']:AreLightsOn(vehicle)
```

#### Zwraca

`true`, gdy włączone. `false`, gdy wyłączone lub pojazd nie jest uprzywilejowany.

### GetAirManuState

Stan klaksonu syreny i ręcznej syreny.

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
GetAirManuState(vehicle?: number): number
```

```lua title="Lua"
local state = exports['ai-sirens']:GetAirManuState(vehicle)
```

#### Zwraca

`0` wyłączone, `1` klakson, `2` ręczna syrena, `3` oba. 0 dla pojazdu, który nie jest uprzywilejowany.

### GetLightbarModel

Model belki świetlnej ONX zamontowanej na pojeździe.

**Strona:** klient · **Czeka:** nie

```ts title="Sygnatura"
GetLightbarModel(vehicle?: number): string | null
```

```lua title="Lua"
local model = exports['ai-sirens']:GetLightbarModel(vehicle)
```

#### Zwraca

Nazwa modelu (`"onx_pol_lbar_mdn1a"`) albo `null`, gdy pojazd jej nie ma lub nie jest uprzywilejowany.

## State bagi

Zapisywane tylko przez serwer po jego sprawdzeniach. Czytaj je na dowolnym kliencie, aby znać stan syreny pojazdu.

| Bag | Typ | Znaczenie |
| --- | --- | --- |
| `siren:lx` | `number` | Główny ton syreny: 0 wyłączona, 1-3 ton. |
| `siren:manu` | `number` | Klakson / ręczna syrena: 0 wyłączone, 1 klakson, 2 ręczna, 3 oba. |
| `siren:lightbar` | `string` | Zamontowany model belki świetlnej ONX (brak: żadnej). |

```lua title="Lua (klient)"
local vehicle = GetVehiclePedIsIn(PlayerPedId(), false)
local tone = Entity(vehicle).state['siren:lx'] or 0
```

## Zdarzenia

| Nazwa | Rodzaj | Co robi |
| --- | --- | --- |
| `ai-sirens:setState` | klient do serwera | `(netId, key, value)`: kierowca prosi o zmianę tonu lub klaksonu albo właściciel sieciowy ustawia model belki świetlnej. Serwer przyjmuje tylko modele uprzywilejowane z listy, wartość powyżej 0 tylko od kierowcy, reset do 0 od gracza w promieniu 10 m, gdy miejsce kierowcy jest puste, i tylko modele belek świetlnych wymienione w panelu. Wewnętrzne: używaj eksportów. |
