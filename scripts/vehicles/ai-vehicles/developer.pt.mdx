O ai-vehicles só tem exports do servidor. A maioria é síncrona (sem Promise, sem espera em Lua); os que podem ler a base de dados - `FindVehicle`, `GetVehiclesOf`, `SetPlate`, `DeleteVehicleByPlate`, `AdoptVehicle` - e o `SpawnVehicle` respondem por um callback. Os tipos ficam em `@aifivem/shared` (`vehicles.ts`).

```ts title="TypeScript"
import { resourceExport } from "@aifivem/lib/server";
const vehicles = resourceExport("ai-vehicles");
```

```lua title="Lua"
local vehicles = exports['ai-vehicles']
```

<Callout type="info">
Para dar, tirar ou verificar chaves, guardar um veículo em uma garagem ou ler o combustível, use as camadas da lib (`vehicleKeys`, `garages`, `fuel`): elas funcionam com qualquer script de chaves, garagem ou combustível que o servidor rode. Chame o ai-vehicles diretamente só para a posse em si.
</Callout>

## Exports do servidor

### CreateVehicle

Registra um novo veículo próprio e o estaciona. Use quando um jogador ganha um veículo (uma compra, uma recompensa, um presente de administrador). Ele não cria o carro no mundo: tire-o com `SpawnVehicle` ou deixe o jogador buscá-lo em uma garagem.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
CreateVehicle(owner: VehicleOwner, model: string, garage: string | null, props?: VehicleProps): { id: number; plate: string } | null
```

```lua title="Lua"
local created = exports['ai-vehicles']:CreateVehicle(owner, model, garage, props) -- { id = number, plate = string } ou nil
```

#### Parâmetros

<TypeTable
  type={{
    owner: { type: 'VehicleOwner', description: 'Quem será o dono.', required: true },
    model: { type: 'string', description: 'O nome do modelo (`"sultan"`). Guardado em minúsculas. O modelo não é verificado: passe um modelo que exista.', required: true },
    garage: { type: 'string | null', description: 'O id da garagem do ai-garages onde ele espera (`"pillbox"`). `null`: sem garagem (um veículo de frota então aparece em todas as garagens do seu emprego ou gangue).', required: true },
    props: { type: 'VehicleProps', description: 'Uma aparência inicial. Ignorada quando não é um objeto `VehicleProps` válido. A placa dentro dela é sempre substituída pela do próprio veículo.' },
  }}
/>

#### Retorno

`{ id, plate }` do novo veículo. `null` quando `owner` não é um dono válido ou `model` não é texto.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");
const vehicles = resourceExport("ai-vehicles");

// Dá ao jogador um Sultan, estacionado na garagem Motel Parking.
export function giveSultan(source: number): string | null {
  const character = core.GetCharacter(source);
  if (!character) return null;
  const created = vehicles.CreateVehicle(
    { type: "character", id: String(character.id) },
    "sultan",
    "pillbox",
  );
  return created?.plate ?? null;
}
```
</Tab>
<Tab value="Lua">
```lua

    { type = 'character', id = tostring(character.id) }, 'sultan', 'pillbox')

end
```

### GetPlateOwners

Todos os veículos próprios na memória como `[plate, ownerType, ownerId]`. Um script que precisa verificar muitas placas (um sistema de chaves) lê isso uma vez na sua inicialização, depois acompanha o evento [`ai-vehicles:owners`](#ai-vehiclesowners), em vez de chamar um export a cada verificação.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"

```


#### Retorno

Um array de trios. Vazio quando não há nenhum veículo na memória.

### FindVehicle

Um veículo próprio pela matrícula exata, **mesmo um cujo dono não está online**: o ai-vehicles responde da memória quando tem o veículo e lê a base de dados quando não tem. É esta a busca para uma matrícula que um jogador escreveu - uma consulta no MDT, um depósito, uma barreira que verifica de quem é o carro à frente.

**Lado:** Servidor · **Espera:** não (a resposta chega em `done`)

```ts title="Assinatura"
FindVehicle(plate: string, done: (vehicle: OwnedVehicle | null) => void, shape?: "framework"): void
```

```lua title="Lua"
exports['ai-vehicles']:FindVehicle(plate, function(vehicle) end, shape)
```

#### Parâmetros

<TypeTable
  type={{
    plate: { type: 'string', description: 'A matrícula, tal como o veículo a tem. É uma correspondência exata: um pedaço de matrícula não encontra nada.', required: true },
    done: { type: '(vehicle: OwnedVehicle | null) => void', description: 'Chamado com o veículo, ou `null` quando nenhum veículo próprio tem essa matrícula.', required: true },
    shape: { type: '"framework"', description: 'Responde `props` na forma do ox_lib / qb-core com `fuelLevel`, para um script que aplica o aspeto ele mesmo.' },
  }}
/>

#### Retorno

Nada. O `done` recebe um [OwnedVehicle](#ownedvehicle) ou `null`.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const vehicles = resourceExport("ai-vehicles");

/** De quem é a matrícula, online ou não. */
export function ownerOf(plate: string): Promise<string | null> {
  return new Promise((resolve) =>
    vehicles.FindVehicle(plate, (vehicle) => resolve(vehicle?.owner.id ?? null)),
  );
}
```
</Tab>
<Tab value="Lua">
```lua
local function ownerOf(plate)
  local p = promise.new()
  exports['ai-vehicles']:FindVehicle(plate, function(vehicle)
    p:resolve(vehicle and vehicle.owner.id or nil)
  end)
  return Citizen.Await(p)
end

CreateThread(function()
  print(ownerOf('AI123ABC') or 'não é de ninguém')
end)
```
</Tab>
</Tabs>

<Callout type="info">
Não existe busca por todas as matrículas guardadas. Para os veículos de um dono use [GetVehiclesOf](#getvehiclesof); para as matrículas em memória, [GetPlateOwners](#getplateowners).
</Callout>

### GetVehiclesOf

Todos os veículos de um dono, **incluindo uma personagem que não está online**. O [GetVehicles](#getvehicles) só responde por donos que o ai-vehicles tem em memória; este lê a base de dados quando precisa.

**Lado:** Servidor · **Espera:** não (a resposta chega em `done`)

```ts title="Assinatura"
GetVehiclesOf(owner: VehicleOwner, done: (vehicles: OwnedVehicle[]) => void, shape?: "framework"): void
```

```lua title="Lua"
exports['ai-vehicles']:GetVehiclesOf(owner, function(vehicles) end, shape)
```

#### Parâmetros

<TypeTable
  type={{
    owner: { type: 'VehicleOwner', description: 'Os veículos de quem: uma personagem (`{ type: "character", id: "12" }`, o id da personagem como texto), uma frota de emprego ou gangue, ou um resource que o detém.', required: true },
    done: { type: '(vehicles: OwnedVehicle[]) => void', description: 'Chamado com os veículos do dono. Vazio para um dono sem veículos ou desconhecido.', required: true },
    shape: { type: '"framework"', description: 'Responde cada `props` na forma do ox_lib / qb-core com `fuelLevel`.' },
  }}
/>

#### Retorno

Nada. O `done` recebe um array de [OwnedVehicle](#ownedvehicle).

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { characters, resourceExport } from "@aifivem/lib/server";

const vehicles = resourceExport("ai-vehicles");

/** A lista de garagem de uma personagem, online ou não. */
export async function garageOf(citizenid: string) {
  const charId = await characters.idOf(citizenid);
  if (charId === null) return [];
  return new Promise((resolve) =>
    vehicles.GetVehiclesOf({ type: "character", id: String(charId) }, resolve),
  );
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
  local p = promise.new()
  exports['ai-vehicles']:GetVehiclesOf({ type = 'character', id = '12' }, function(list) p:resolve(list) end)
  for _, v in ipairs(Citizen.Await(p)) do
    print(('%s %s (%s)'):format(v.plate, v.model, v.state))
  end
end)
```
</Tab>
</Tabs>

### SaveVehicle

**Lado:** Servidor · **Espera:** não

### SaveTuning

Salva as props completas, tuning incluído (`mods`, `neon`). Feito só para oficinas de tuning: a própria oficina de tuning do AI Core, o ai-mechanic, é o único script ai-* que o chama.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
SaveTuning(id: number, props: VehicleProps): void
```

```lua title="Lua"
exports['ai-vehicles']:SaveTuning(id, props)
```

#### Retorno

Nada. Props inválidas são ignoradas. A placa dentro das props é sempre substituída pela do próprio veículo.

<Callout type="warn">
Nunca passe props que vieram direto do cliente de um jogador sem verificá-las no servidor: o que você salvar aqui é o tuning do carro daqui em diante.
</Callout>

### DeleteVehicleByPlate

Apaga um veículo próprio pela matrícula, **com o dono online ou não**: a sua linha e todas as entidades do mundo que tenham essa matrícula.

**Lado:** Servidor · **Espera:** não (a resposta chega em `done`)

```ts title="Assinatura"
DeleteVehicleByPlate(plate: string, done?: (result: DeleteByPlateResult) => void): void
```

<TypeTable
  type={{

  }}
/>

#### Retorno

### AdoptVehicle

Torna um veículo que já está no mundo num veículo próprio: fica `out`, é acompanhado como um que o ai-vehicles criou, e o dono pode estacioná-lo. É o que faz um `/admincar` de administrador.

**Lado:** Servidor · **Espera:** não (a resposta chega em `done`)

```ts title="Assinatura"
AdoptVehicle(owner: VehicleOwner, entity: number, model: string, props: unknown, done?: (result: AdoptVehicleResult) => void): void
```

```lua title="Lua"
exports['ai-vehicles']:AdoptVehicle(owner, entity, model, props, function(result) end)
```

#### Parâmetros

<TypeTable
  type={{
    owner: { type: 'VehicleOwner', description: 'De quem é a partir de agora.', required: true },
    entity: { type: 'number', description: 'A entidade do veículo no servidor.', required: true },
    model: { type: 'string', description: 'O nome de modelo da entidade (`"sultan"`). O servidor não consegue ler um nome de modelo sozinho: você passa-o e o ai-vehicles compara-o com a entidade.', required: true },
    props: { type: 'unknown', description: 'O aspeto lido num cliente: `VehicleProps` da lib, ou a forma do ox_lib / qb-core. Tem de ser do mesmo modelo.', required: true },
    done: { type: '(result: AdoptVehicleResult) => void', description: 'Chamado com o resultado.' },
  }}
/>

#### Retorno

Nada. O `done` recebe um [AdoptVehicleResult](#adoptvehicleresult): `{ ok: true, id, plate }`, ou `{ ok: false, error }`. A entidade mantém a sua própria matrícula quando é uma personalizada válida (as regras do [SetPlate](#setplate)); senão recebe a gerada.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

/** Dá ao administrador o carro em que está sentado. */
export async function adminCar(source: number, charId: number, entity: number) {
  const look = await triggerClientCallback<{ model: string; props: unknown }>("mycars:look", source);
  if (!look) return;
  vehicles.AdoptVehicle({ type: "character", id: String(charId) }, entity, look.model, look.props, (result) => {
    if (!result.ok) console.log(`não foi adotado: ${result.error}`);
  });
}
```

### SpawnVehicle

Cria a entidade de um veículo próprio no mundo com sua aparência, placa, combustível e state bags, e dá as chaves a `asker` pelo sistema de chaves ativo. O estado do veículo passa a ser `out`.

**Lado:** Servidor · **Espera:** não (o resultado chega em `cb`)

```ts title="Signature"
SpawnVehicle(id: number, at: { x: number; y: number; z: number; heading: number }, asker: number, cb: (netId: number | null) => void, purpose?: KeyPurpose, setup?: VehicleSetup): void
```

```lua title="Lua"
exports['ai-vehicles']:SpawnVehicle(id, at, asker, function(netId) end, purpose, setup)
```

#### Parâmetros

<TypeTable
  type={{
    id: { type: 'number', description: 'O id do veículo.', required: true },
    at: { type: '{ x, y, z, heading }', description: 'Onde ele aparece. `heading` em graus; `w` é aceito no lugar de `heading`, um ausente vale 0. Um ponto com uma coordenada que não é número não cria nada e `cb` nunca é chamado.', required: true },
    asker: { type: 'number', description: 'Id do servidor de um jogador perto do ponto. O cliente dele informa ao servidor o tipo do modelo, e ele recebe as chaves.', required: true },
    cb: { type: '(netId: number | null) => void', description: 'Chamado com o id de rede da nova entidade, ou `null` quando ela não pôde ser criada.', required: true },
    purpose: { type: 'KeyPurpose', description: 'Por que quem pede recebe a chave: `"purchase"`, `"garage"`, `"job"`, `"rental"` ou `"temporary"`. Sistemas de chaves que os diferenciam usam isso.', default: '"garage"' },
    setup: { type: 'VehicleSetup', description: 'Uma aparência mantida com um veículo que ainda não tem props (por exemplo `{ colors: [12, 12] }`), aplicada em cada spawn até o primeiro salvamento de props.' },
  }}
/>

#### Retorno

Nada. `cb` recebe o id de rede, ou `null` quando o veículo não existe, já está fora, está sendo criado neste momento, ou o jogo não conseguiu criá-lo.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

  const ped = GetPlayerPed(String(source));
  const [x, y, z] = GetEntityCoords(ped);
  const heading = GetEntityHeading(ped);
  vehicles.SpawnVehicle(vehicleId, { x: x + 3, y, z, heading }, source, (netId) => {
    if (netId === null) console.log(`vehicle ${vehicleId} could not come out`);
  });
}
```
</Tab>

## Eventos

### ai-vehicles:owners

Disparado quando veículos entram na memória do ai-vehicles ou mudam de dono, e quando placas saem da memória. Um lote por tick do servidor. Leia `GetPlateOwners` uma vez na inicialização, depois aplique esses lotes para manter uma cópia de placa para dono. O nome é `VEHICLES_EVENTS.owners` em `@aifivem/shared`.

**Lado:** Servidor (evento local, não enviado aos clientes)

<TypeTable
  type={{
    puts: { type: 'Array<[plate: string, type: VehicleOwnerType, id: string]>', description: 'Veículos que entraram na memória ou ganharam um novo dono.', required: true },
    removes: { type: 'string[]', description: 'Placas que saíram da memória (o dono ficou offline, o veículo foi apagado).', required: true },
  }}
/>

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";
import { VEHICLES_EVENTS } from "@aifivem/shared";

const owners = new Map<string, string>();
for (const [plate, type, id] of resourceExport("ai-vehicles").GetPlateOwners())
  owners.set(plate, `${type}:${id}`);

on(VEHICLES_EVENTS.owners, (puts: [string, string, string][], removes: string[]) => {
  for (const [plate, type, id] of puts) owners.set(plate, `${type}:${id}`);
  for (const plate of removes) owners.delete(plate);
});
```
</Tab>
<Tab value="Lua">

```lua
  for _, row in ipairs(puts) do owners[row[1]] = row[2] .. ':' .. row[3] end
  for _, plate in ipairs(removes) do owners[plate] = nil end
end)
```

## State bags

O ai-vehicles define estes em todo veículo próprio que cria. Os nomes ficam em `VEHICLE_BAGS` (`@aifivem/shared`).

| Bag | Tipo | Significado |
| --- | --- | --- |
| `ai:owned` | `true` | A entidade é um veículo próprio. |
| `ai:vid` | `number` | O id dele no ai-vehicles. |
| `ai:props` | `VehicleProps` | A aparência salva. O cliente do ai-core que é dono da entidade a aplica. |
| `ai:setup` | `VehicleSetup` | Uma aparência de spawn para um veículo sem props, aplicada uma vez. |
| `fuel` | `number` | Combustível 0-100. O script de combustível cuida dele daí em diante. |

```lua title="Lua (client)"
local vehicle = GetVehiclePedIsIn(PlayerPedId(), false)
if Entity(vehicle).state['ai:owned'] then
  print('owned vehicle', Entity(vehicle).state['ai:vid'])
end
```

## qbx_vehicles API

O ai-vehicles faz `provide` de `qbx_vehicles`, então essas chamadas chegam a ele. Os formatos seguem o Qbox: `state` é `0` fora, `1` garagem, `2` apreensão.

| Export | O que faz |
| --- | --- |
| `GetPlayerVehicles(filters: { citizenid?, garage? })` | Veículos de um personagem online, opcionalmente só de uma garagem. Retorna `{ id, citizenid, modelName, garage, state, depotPrice, props }[]`. |
| `GetPlayerVehicle(id: number)` | Um veículo no mesmo formato, ou `nil`. |
| `CreatePlayerVehicle(request: { model, citizenid, garage?, props? })` | Cria um veículo para um personagem online. Retorna o id, ou `nil, { code, message }` (`bad_request`, `not_found`). |
| `SetPlayerVehicleOwner(id: number, citizenid: string)` | Novo dono (online). `true` quando funcionou. |
| `DeletePlayerVehicles(idType: "plate" \| "vehicleId", idValue)` | Apaga um veículo. `true` quando encontrado. |
| `GetVehicleIdByPlate(plate: string)` | O id, ou `nil`. |
| `DoesPlayerVehiclePlateExist(plate: string)` | `true` quando a placa tem dono. |
| `SaveVehicle(entity: number, options: { props?, state?, garage? })` | Salva um veículo criado no mundo, tuning incluído. Aceita as props do AI Core ou o formato de props do ox_lib / qb-core. Props de outro modelo que não o da entidade são recusadas (estado e garagem ainda são salvos). |

`GetPlayerVehicle` retorna as props no formato `VehicleProps` do AI Core, não no do ox_lib. `depotPrice` é sempre `0`.
