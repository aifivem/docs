ai-vehicles hat nur Server-Exports. Die meisten sind synchron (kein Promise, kein Warten in Lua); die, die die Datenbank lesen können - `FindVehicle`, `GetVehiclesOf`, `SetPlate`, `DeleteVehicleByPlate`, `AdoptVehicle` - und `SpawnVehicle` antworten über einen Callback. Die Typen stehen in `@aifivem/shared` (`vehicles.ts`).

```ts title="TypeScript"
import { resourceExport } from "@aifivem/lib/server";
const vehicles = resourceExport("ai-vehicles");
```

```lua title="Lua"
local vehicles = exports['ai-vehicles']
```

<Callout type="info">
Um Schlüssel zu geben, zu nehmen oder zu prüfen, ein Fahrzeug in einer Garage abzustellen oder den Sprit zu lesen, nutze die Layer der Lib (`vehicleKeys`, `garages`, `fuel`): Sie funktionieren mit dem Schlüssel-, Garagen- oder Spritskript, das der Server gerade nutzt. Rufe ai-vehicles nur für den Besitz selbst direkt auf.
</Callout>

## Server-Exports

### CreateVehicle

Registriert ein neues Fahrzeug im Besitz und parkt es. Nutze es, wenn ein Spieler ein Fahrzeug bekommt (ein Kauf, eine Belohnung, ein Geschenk eines Admins). Es spawnt das Auto nicht: Hol es mit `SpawnVehicle` heraus oder lass den Spieler es an einer Garage abholen.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
CreateVehicle(owner: VehicleOwner, model: string, garage: string | null, props?: VehicleProps): { id: number; plate: string } | null
```

```lua title="Lua"
local created = exports['ai-vehicles']:CreateVehicle(owner, model, garage, props) -- { id = number, plate = string } oder nil
```

#### Parameter

<TypeTable
  type={{
    owner: { type: 'VehicleOwner', description: 'Wem es gehören wird.', required: true },
    model: { type: 'string', description: 'Der Modellname (`"sultan"`). Wird in Kleinbuchstaben gespeichert. Das Modell wird nicht geprüft: Übergib ein Modell, das existiert.', required: true },
    garage: { type: 'string | null', description: 'Die Garagen-ID von ai-garages, in der es wartet (`"pillbox"`). `null`: keine Garage (ein Fuhrpark-Fahrzeug erscheint dann in jeder Garage seines Jobs oder seiner Gang).', required: true },
    props: { type: 'VehicleProps', description: 'Ein Startaussehen. Wird ignoriert, wenn es kein gültiges `VehicleProps`-Objekt ist. Das Kennzeichen darin wird immer durch das eigene des Fahrzeugs ersetzt.' },
  }}
/>

#### Rückgabewert

`{ id, plate }` des neuen Fahrzeugs. `null`, wenn `owner` kein gültiger Besitzer ist oder `model` kein Text ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");
const vehicles = resourceExport("ai-vehicles");

// Gibt dem Spieler einen Sultan, geparkt in der Garage Motel Parking.
export function giveSultan(source: number): string | null {
  const character = core.GetCharacter(source);
  if (!character) return null;
  const created = vehicles.CreateVehicle(
    { type: "character", id: String(character.id) },
    "sultan",
    "pillbox",
  );
  return created?.plate ?? null;
}
```
</Tab>
<Tab value="Lua">
```lua

local function giveSultan(source)
  local character = exports['ai-core']:GetCharacter(source)

  local created = exports['ai-vehicles']:CreateVehicle(
    { type = 'character', id = tostring(character.id) }, 'sultan', 'pillbox')
  return created and created.plate
end
```

### FindVehicle

Ein Fahrzeug im Besitz über sein genaues Kennzeichen, **auch eines, dessen Besitzer nicht online ist**: ai-vehicles antwortet aus dem Speicher, wenn es das Fahrzeug hält, und liest sonst die Datenbank. Das ist die Suche für ein Kennzeichen, das ein Spieler eingetippt hat - eine MDT-Abfrage, ein Abschleppplatz, eine Schranke, die prüft, wem das Auto davor gehört.

**Seite:** Server · **Wartet:** nein (die Antwort kommt in `done`)

```ts title="Signature"
FindVehicle(plate: string, done: (vehicle: OwnedVehicle | null) => void, shape?: "framework"): void
```

```lua title="Lua"
exports['ai-vehicles']:FindVehicle(plate, function(vehicle) end, shape)
```

#### Parameter

<TypeTable
  type={{
    plate: { type: 'string', description: 'Das Kennzeichen, so wie das Fahrzeug es trägt. Das ist eine genaue Übereinstimmung: ein Teil eines Kennzeichens findet nichts.', required: true },
    done: { type: '(vehicle: OwnedVehicle | null) => void', description: 'Wird mit dem Fahrzeug gerufen, oder mit `null`, wenn kein Fahrzeug im Besitz dieses Kennzeichen hat.', required: true },
    shape: { type: '"framework"', description: 'Antwortet `props` in der Form von ox_lib / qb-core mit `fuelLevel`, für ein Script, das den Look selbst anwendet.' },
  }}
/>

#### Rückgabe

Nichts. `done` bekommt ein [OwnedVehicle](#ownedvehicle) oder `null`.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const vehicles = resourceExport("ai-vehicles");

/** Wem das Kennzeichen gehört, online oder nicht. */
export function ownerOf(plate: string): Promise<string | null> {
  return new Promise((resolve) =>
    vehicles.FindVehicle(plate, (vehicle) => resolve(vehicle?.owner.id ?? null)),
  );
}
```
</Tab>
<Tab value="Lua">
```lua
local function ownerOf(plate)
  local p = promise.new()
  exports['ai-vehicles']:FindVehicle(plate, function(vehicle)
    p:resolve(vehicle and vehicle.owner.id or nil)
  end)
  return Citizen.Await(p)
end

CreateThread(function()
  print(ownerOf('AI123ABC') or 'niemand besitzt es')
end)
```
</Tab>
</Tabs>

<Callout type="info">
Es gibt keine Suche über alle gespeicherten Kennzeichen. Für die Fahrzeuge eines Besitzers nimm [GetVehiclesOf](#getvehiclesof), für die Kennzeichen im Speicher [GetPlateOwners](#getplateowners).
</Callout>

### GetVehiclesOf

Jedes Fahrzeug eines Besitzers, **auch eines Charakters, der nicht online ist**. [GetVehicles](#getvehicles) antwortet nur für Besitzer, die ai-vehicles im Speicher hält; dieses liest die Datenbank, wenn es muss.

**Seite:** Server · **Wartet:** nein (die Antwort kommt in `done`)

```ts title="Signature"
GetVehiclesOf(owner: VehicleOwner, done: (vehicles: OwnedVehicle[]) => void, shape?: "framework"): void
```

```lua title="Lua"
exports['ai-vehicles']:GetVehiclesOf(owner, function(vehicles) end, shape)
```

#### Parameter

<TypeTable
  type={{
    owner: { type: 'VehicleOwner', description: 'Wessen Fahrzeuge: ein Charakter (`{ type: "character", id: "12" }`, die Charakter-ID als Text), eine Job- oder Gang-Flotte, oder eine haltende Resource.', required: true },
    done: { type: '(vehicles: OwnedVehicle[]) => void', description: 'Wird mit den Fahrzeugen des Besitzers gerufen. Leer für einen Besitzer ohne Fahrzeuge oder einen unbekannten.', required: true },
    shape: { type: '"framework"', description: 'Antwortet jedes `props` in der Form von ox_lib / qb-core mit `fuelLevel`.' },
  }}
/>

#### Rückgabe

Nichts. `done` bekommt ein Array von [OwnedVehicle](#ownedvehicle).

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { characters, resourceExport } from "@aifivem/lib/server";

const vehicles = resourceExport("ai-vehicles");

/** Die Garagenliste eines Charakters, online oder nicht. */
export async function garageOf(citizenid: string) {
  const charId = await characters.idOf(citizenid);
  if (charId === null) return [];
  return new Promise((resolve) =>
    vehicles.GetVehiclesOf({ type: "character", id: String(charId) }, resolve),
  );
}
```
</Tab>
<Tab value="Lua">
```lua

  exports['ai-vehicles']:GetVehiclesOf({ type = 'character', id = '12' }, function(list) p:resolve(list) end)
  for _, v in ipairs(Citizen.Await(p)) do
    print(('%s %s (%s)'):format(v.plate, v.model, v.state))
  end
end)
```
</Tab>
</Tabs>

### SaveTuning

Speichert vollständige Props, Tuning inklusive (`mods`, `neon`). Nur für Tuningwerkstätten gedacht: Die eigene Tuningwerkstatt von AI Core, ai-mechanic, ist das einzige ai-*-Skript, das es aufruft.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
SaveTuning(id: number, props: VehicleProps): void
```

```lua title="Lua"
exports['ai-vehicles']:SaveTuning(id, props)
```

#### Rückgabewert

Nichts. Ungültige Props werden ignoriert. Das Kennzeichen in den Props wird immer durch das eigene des Fahrzeugs ersetzt.

<Callout type="warn">
Übergib nie Props, die direkt vom Client eines Spielers kommen, ohne sie auf dem Server zu prüfen: Was du hier speicherst, ist ab jetzt das Tuning des Autos.
</Callout>

### AdoptVehicle

Macht ein Fahrzeug, das schon in der Welt steht, zu einem Fahrzeug im Besitz: es wird `out`, wird verfolgt wie eines, das ai-vehicles selbst gespawnt hat, und sein Besitzer kann es parken. Das ist, was ein Admin-`/admincar` macht.

**Seite:** Server · **Wartet:** nein (die Antwort kommt in `done`)

```ts title="Signature"
AdoptVehicle(owner: VehicleOwner, entity: number, model: string, props: unknown, done?: (result: AdoptVehicleResult) => void): void
```

```lua title="Lua"
exports['ai-vehicles']:AdoptVehicle(owner, entity, model, props, function(result) end)
```

#### Parameter

<TypeTable
  type={{
    owner: { type: 'VehicleOwner', description: 'Wem es von jetzt an gehört.', required: true },
    entity: { type: 'number', description: 'Die Fahrzeug-Entity auf dem Server.', required: true },
    model: { type: 'string', description: 'Der Modellname der Entity (`"sultan"`). Der Server kann einen Modellnamen nicht selbst lesen, also übergibst du ihn und ai-vehicles prüft ihn gegen die Entity.', required: true },
    props: { type: 'unknown', description: 'Der auf einem Client gelesene Look: lib `VehicleProps`, oder die Form von ox_lib / qb-core. Er muss zum selben Modell gehören.', required: true },
    done: { type: '(result: AdoptVehicleResult) => void', description: 'Wird mit dem Ergebnis gerufen.' },
  }}
/>

#### Rückgabe

Nichts. `done` bekommt ein [AdoptVehicleResult](#adoptvehicleresult): `{ ok: true, id, plate }`, oder `{ ok: false, error }`. Die Entity behält ihr eigenes Kennzeichen, wenn das ein gültiges eigenes ist (die Regeln von [SetPlate](#setplate)); sonst bekommt sie das generierte.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

  const look = await triggerClientCallback<{ model: string; props: unknown }>("mycars:look", source);
  if (!look) return;
```

```lua
end)
```

### SpawnVehicle

Erstellt die Entity eines Fahrzeugs im Besitz in der Welt mit Aussehen, Kennzeichen, Sprit und State Bags und gibt `asker` die Schlüssel über das aktive Schlüsselsystem. Der Status des Fahrzeugs wird `out`.

**Seite:** Server · **Wartet:** nein (das Ergebnis kommt in `cb`)

```ts title="Signatur"
SpawnVehicle(id: number, at: { x: number; y: number; z: number; heading: number }, asker: number, cb: (netId: number | null) => void, purpose?: KeyPurpose, setup?: VehicleSetup): void
```

```lua title="Lua"
exports['ai-vehicles']:SpawnVehicle(id, at, asker, function(netId) end, purpose, setup)
```

#### Parameter

<TypeTable
  type={{
    id: { type: 'number', description: 'Die Fahrzeug-ID.', required: true },
    at: { type: '{ x, y, z, heading }', description: 'Wo es erscheint. `heading` in Grad; `w` wird statt `heading` angenommen, ein fehlender Wert ist 0. Ein Punkt mit einer Koordinate, die keine Zahl ist, spawnt nichts, und `cb` wird nie aufgerufen.', required: true },

    cb: { type: '(netId: number | null) => void', description: 'Wird mit der Network-ID der neuen Entity aufgerufen oder mit `null`, wenn sie nicht erstellt werden konnte.', required: true },
    purpose: { type: 'KeyPurpose', description: 'Warum der Anfragende den Schlüssel bekommt: `"purchase"`, `"garage"`, `"job"`, `"rental"` oder `"temporary"`. Schlüsselsysteme, die diese unterscheiden, nutzen es.', default: '"garage"' },

/>

#### Rückgabewert

Nichts. `cb` bekommt die Network-ID oder `null`, wenn das Fahrzeug nicht existiert, schon draußen ist, gerade gespawnt wird oder das Spiel es nicht erstellen konnte.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

  const ped = GetPlayerPed(String(source));
  const [x, y, z] = GetEntityCoords(ped);
  const heading = GetEntityHeading(ped);
  vehicles.SpawnVehicle(vehicleId, { x: x + 3, y, z, heading }, source, (netId) => {
    if (netId === null) console.log(`vehicle ${vehicleId} could not come out`);
  });

```

<Tab value="Lua">

```lua
  local ped = GetPlayerPed(source)
  local coords = GetEntityCoords(ped)
  local at = { x = coords.x + 3.0, y = coords.y, z = coords.z, heading = GetEntityHeading(ped) }
  exports['ai-vehicles']:SpawnVehicle(vehicleId, at, source, function(netId)
    if not netId then print(('vehicle %d could not come out'):format(vehicleId)) end
  end)
end
```
</Tab>

</Callout>

## Events

### ai-vehicles:owners

Wird ausgelöst, wenn Fahrzeuge in den Speicher von ai-vehicles kommen oder den Besitzer wechseln und wenn Kennzeichen den Speicher verlassen. Ein Paket pro Server-Tick. Lies `GetPlateOwners` einmal beim Start und wende dann diese Pakete an, um eine Kopie von Kennzeichen zu Besitzer aktuell zu halten. Der Name ist `VEHICLES_EVENTS.owners` in `@aifivem/shared`.

**Seite:** Server (lokales Event, nicht an Clients gesendet)

<TypeTable
  type={{
    puts: { type: 'Array<[plate: string, type: VehicleOwnerType, id: string]>', description: 'Fahrzeuge, die in den Speicher gekommen sind oder einen neuen Besitzer haben.', required: true },
    removes: { type: 'string[]', description: 'Kennzeichen, die den Speicher verlassen haben (der Besitzer ist offline gegangen, das Fahrzeug wurde gelöscht).', required: true },
  }}
/>

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";
import { VEHICLES_EVENTS } from "@aifivem/shared";

const owners = new Map<string, string>();
for (const [plate, type, id] of resourceExport("ai-vehicles").GetPlateOwners())
  owners.set(plate, `${type}:${id}`);

on(VEHICLES_EVENTS.owners, (puts: [string, string, string][], removes: string[]) => {
  for (const [plate, type, id] of puts) owners.set(plate, `${type}:${id}`);
  for (const plate of removes) owners.delete(plate);
});
```
</Tab>
<Tab value="Lua">
```lua
local owners = {}
for _, row in ipairs(exports['ai-vehicles']:GetPlateOwners()) do
  owners[row[1]] = row[2] .. ':' .. row[3]
end

AddEventHandler('ai-vehicles:owners', function(puts, removes)
  for _, row in ipairs(puts) do owners[row[1]] = row[2] .. ':' .. row[3] end
  for _, plate in ipairs(removes) do owners[plate] = nil end
end)
```
</Tab>
</Tabs>

## State Bags

ai-vehicles setzt diese an jedem Fahrzeug im Besitz, das es spawnt. Die Namen stehen in `VEHICLE_BAGS` (`@aifivem/shared`).

| Bag | Typ | Bedeutung |
| --- | --- | --- |
| `ai:owned` | `true` | Die Entity ist ein Fahrzeug im Besitz. |
| `ai:vid` | `number` | Seine ID in ai-vehicles. |
| `ai:props` | `VehicleProps` | Das gespeicherte Aussehen. Der Client von ai-core, dem die Entity gehört, wendet es an. |
| `ai:setup` | `VehicleSetup` | Ein Spawn-Aussehen für ein Fahrzeug ohne Props, einmal angewendet. |
| `fuel` | `number` | Sprit 0-100. Das Spritskript verwaltet ihn von da an. |

```lua title="Lua (Client)"
local vehicle = GetVehiclePedIsIn(PlayerPedId(), false)
if Entity(vehicle).state['ai:owned'] then
  print('owned vehicle', Entity(vehicle).state['ai:vid'])
end
```

## qbx_vehicles API

ai-vehicles `provide`t `qbx_vehicles`, sodass diese Aufrufe es erreichen. Die Strukturen folgen Qbox: `state` ist `0` draußen, `1` Garage, `2` Abschlepphof.

| Export | Was er macht |
| --- | --- |
| `GetPlayerVehicles(filters: { citizenid?, garage? })` | Fahrzeuge eines Online-Charakters, optional nur aus einer Garage. Gibt `{ id, citizenid, modelName, garage, state, depotPrice, props }[]` zurück. |
| `GetPlayerVehicle(id: number)` | Ein Fahrzeug in derselben Struktur oder `nil`. |
| `CreatePlayerVehicle(request: { model, citizenid, garage?, props? })` | Erstellt ein Fahrzeug für einen Online-Charakter. Gibt die ID zurück oder `nil, { code, message }` (`bad_request`, `not_found`). |
| `SetPlayerVehicleOwner(id: number, citizenid: string)` | Neuer Besitzer (online). `true`, wenn es geklappt hat. |
| `DeletePlayerVehicles(idType: "plate" \| "vehicleId", idValue)` | Löscht ein Fahrzeug. `true`, wenn gefunden. |
| `GetVehicleIdByPlate(plate: string)` | Die ID oder `nil`. |
| `DoesPlayerVehiclePlateExist(plate: string)` | `true`, wenn das Kennzeichen im Besitz ist. |
| `SaveVehicle(entity: number, options: { props?, state?, garage? })` | Speichert ein gespawntes Fahrzeug, Tuning inklusive. Nimmt die Props von AI Core oder die Props-Struktur von ox_lib / qb-core. Props eines anderen Modells als die Entity werden abgelehnt (Status und Garage werden trotzdem gespeichert). |

`GetPlayerVehicle` gibt Props in der Struktur `VehicleProps` von AI Core zurück, nicht in der von ox_lib. `depotPrice` ist immer `0`.
