ai-vehicles’ın sadece server export’ları vardır. Hepsi senkrondur (Promise yok, Lua’da bekleme yok); tek istisna, cevabını bir callback ile veren `SpawnVehicle`’dır. Tipler `@aifivem/shared` içindedir (`vehicles.ts`).

```ts title="TypeScript"
import { resourceExport } from "@aifivem/lib/server";
const vehicles = resourceExport("ai-vehicles");
```

```lua title="Lua"
local vehicles = exports['ai-vehicles']
```

<Callout type="info">
Anahtar vermek, almak ya da kontrol etmek, bir aracı garaja koymak veya yakıtı okumak için lib’in katmanlarını (`vehicleKeys`, `garages`, `fuel`) kullan: server hangi anahtar, garaj ya da yakıt script’ini çalıştırıyorsa onunla çalışırlar. ai-vehicles’ı doğrudan sadece sahipliğin kendisi için çağır.
</Callout>

## Server export’ları

### CreateVehicle

Yeni bir sahipli aracı kaydeder ve park eder. Bir oyuncu araç edindiğinde kullan (satın alma, ödül, admin hediyesi). Arabayı spawn etmez: `SpawnVehicle` ile çıkar ya da oyuncunun onu bir garajdan almasına izin ver.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
CreateVehicle(owner: VehicleOwner, model: string, garage: string | null, props?: VehicleProps): { id: number; plate: string } | null
```

```lua title="Lua"
local created = exports['ai-vehicles']:CreateVehicle(owner, model, garage, props) -- { id = number, plate = string } ya da nil
```

#### Parametreler

<TypeTable
  type={{
    owner: { type: 'VehicleOwner', description: 'Kimin sahibi olacağı.', required: true },
    model: { type: 'string', description: 'Model adı (`"sultan"`). Küçük harfle saklanır. Model kontrol edilmez: var olan bir model ver.', required: true },
    garage: { type: 'string | null', description: 'Aracın beklediği ai-garages garaj id’si (`"pillbox"`). `null`: garaj yok (bir filo aracı o zaman mesleğinin veya çetesinin her garajında görünür).', required: true },
    props: { type: 'VehicleProps', description: 'Başlangıç görünüşü. Geçerli bir `VehicleProps` nesnesi değilse yok sayılır. İçindeki plaka her zaman aracın kendi plakasıyla değiştirilir.' },
  }}
/>

#### Dönüş değeri

Yeni aracın `{ id, plate }` değeri. `owner` geçerli bir sahip değilse ya da `model` metin değilse `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");
const vehicles = resourceExport("ai-vehicles");

// Oyuncuya Motel Parking garajında park halinde bir Sultan verir.
export function giveSultan(source: number): string | null {
  const character = core.GetCharacter(source);
  if (!character) return null;
  const created = vehicles.CreateVehicle(
    { type: "character", id: String(character.id) },
    "sultan",
    "pillbox",
  );
  return created?.plate ?? null;
}
```
</Tab>
<Tab value="Lua">
```lua
-- Oyuncuya Motel Parking garajında park halinde bir Sultan verir.
local function giveSultan(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return nil end
  local created = exports['ai-vehicles']:CreateVehicle(
    { type = 'character', id = tostring(character.id) }, 'sultan', 'pillbox')
  return created and created.plate
end
```
</Tab>

### SpawnVehicle

Sahipli bir aracın entity’sini dünyada görünüşü, plakası, yakıtı ve state bag’leriyle oluşturur ve anahtarları aktif anahtar sistemi üzerinden `asker`’a verir. Aracın durumu `out` olur.

```ts title="Signature"

```

#### Parametreler

<TypeTable
  type={{
    id: { type: 'number', description: 'Araç id’si.', required: true },
    at: { type: '{ x, y, z, heading }', description: 'Belirdiği yer. `heading` derece cinsinden; `heading` yerine `w` de kabul edilir, verilmezse 0’dır. Koordinatlarından biri number olmayan bir nokta hiçbir şey spawn etmez ve `cb` hiç çağrılmaz.', required: true },
    asker: { type: 'number', description: 'Noktanın yakınındaki bir oyuncunun server id’si. Onun client’ı server’a modelin tipini söyler ve anahtarları o alır.', required: true },

    setup: { type: 'VehicleSetup', description: 'Henüz props’u olmayan bir araçla tutulan görünüş (örneğin `{ colors: [12, 12] }`); ilk props kaydına kadar her spawn’da uygulanır.' },
  }}
/>

#### Dönüş değeri

Hiçbir şey. `cb` network id’sini alır; araç yoksa, zaten dışarıdaysa, şu an spawn ediliyorsa ya da oyun onu oluşturamadıysa `null` alır.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const vehicles = resourceExport("ai-vehicles");

export function bringOut(source: number, vehicleId: number): void {
  const ped = GetPlayerPed(String(source));
  const [x, y, z] = GetEntityCoords(ped);
  const heading = GetEntityHeading(ped);
  vehicles.SpawnVehicle(vehicleId, { x: x + 3, y, z, heading }, source, (netId) => {
    if (netId === null) console.log(`vehicle ${vehicleId} could not come out`);
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local function bringOut(source, vehicleId)
  local ped = GetPlayerPed(source)
  local coords = GetEntityCoords(ped)
  local at = { x = coords.x + 3.0, y = coords.y, z = coords.z, heading = GetEntityHeading(ped) }
  exports['ai-vehicles']:SpawnVehicle(vehicleId, at, source, function(netId)
    if not netId then print(('vehicle %d could not come out'):format(vehicleId)) end
  end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Zaten dışarıda olan bir araç reddedilir (`cb(null)`). Dışarıdayken entity’si sonradan kaybolursa impound durumuna geçer.
</Callout>

## Event’ler

### ai-vehicles:owners

Araçlar ai-vehicles’ın belleğine girdiğinde ya da sahip değiştirdiğinde ve plakalar bellekten çıktığında tetiklenir. Server tick’i başına bir toplu paket. Açılışta `GetPlateOwners`’ı bir kez oku, sonra plakadan sahibe bir kopya tutmak için bu paketleri uygula. Adı `@aifivem/shared` içinde `VEHICLES_EVENTS.owners`’dır.

**Taraf:** Server (yerel event, client’lara gönderilmez)

<TypeTable
  type={{
    puts: { type: 'Array<[plate: string, type: VehicleOwnerType, id: string]>', description: 'Belleğe giren ya da yeni bir sahip alan araçlar.', required: true },
    removes: { type: 'string[]', description: 'Bellekten çıkan plakalar (sahibi çevrim dışı oldu, araç silindi).', required: true },
  }}
/>

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";
import { VEHICLES_EVENTS } from "@aifivem/shared";

const owners = new Map<string, string>();
for (const [plate, type, id] of resourceExport("ai-vehicles").GetPlateOwners())
  owners.set(plate, `${type}:${id}`);

on(VEHICLES_EVENTS.owners, (puts: [string, string, string][], removes: string[]) => {
  for (const [plate, type, id] of puts) owners.set(plate, `${type}:${id}`);
  for (const plate of removes) owners.delete(plate);
});
```
</Tab>
<Tab value="Lua">
```lua
local owners = {}
for _, row in ipairs(exports['ai-vehicles']:GetPlateOwners()) do
  owners[row[1]] = row[2] .. ':' .. row[3]
end

AddEventHandler('ai-vehicles:owners', function(puts, removes)
  for _, row in ipairs(puts) do owners[row[1]] = row[2] .. ':' .. row[3] end
  for _, plate in ipairs(removes) do owners[plate] = nil end
end)
```
</Tab>
</Tabs>

## State bag’ler

ai-vehicles bunları spawn ettiği her sahipli araçta ayarlar. Adlar `VEHICLE_BAGS` içindedir (`@aifivem/shared`).

| Bag | Tip | Anlamı |
| --- | --- | --- |
| `ai:owned` | `true` | Entity sahipli bir araçtır. |
| `ai:vid` | `number` | ai-vehicles’taki id’si. |
| `ai:props` | `VehicleProps` | Kayıtlı görünüş. Entity’nin sahibi olan ai-core client’ı bunu uygular. |
| `ai:setup` | `VehicleSetup` | Props’u olmayan bir araç için spawn görünüşü, bir kez uygulanır. |
| `fuel` | `number` | Yakıt 0-100. Bundan sonra onu yakıt script’i tutar. |

```lua title="Lua (client)"
local vehicle = GetVehiclePedIsIn(PlayerPedId(), false)
if Entity(vehicle).state['ai:owned'] then
  print('owned vehicle', Entity(vehicle).state['ai:vid'])
end
```

## qbx_vehicles API

ai-vehicles `qbx_vehicles` adını `provide` eder, bu yüzden bu çağrılar ona ulaşır. Yapılar Qbox’u izler: `state` değeri `0` dışarıda, `1` garajda, `2` çekilmiş araç otoparkında demektir.

| Export | Ne yapar |
| --- | --- |
| `GetPlayerVehicles(filters: { citizenid?, garage? })` | Çevrim içi bir karakterin araçları, istenirse sadece tek bir garajdakiler. `{ id, citizenid, modelName, garage, state, depotPrice, props }[]` döner. |
| `GetPlayerVehicle(id: number)` | Aynı yapıda tek bir araç ya da `nil`. |
| `CreatePlayerVehicle(request: { model, citizenid, garage?, props? })` | Çevrim içi bir karakter için araç oluşturur. Id’yi ya da `nil, { code, message }` (`bad_request`, `not_found`) döner. |
| `SetPlayerVehicleOwner(id: number, citizenid: string)` | Yeni sahip (çevrim içi). İşe yaradıysa `true`. |
| `DeletePlayerVehicles(idType: "plate" \| "vehicleId", idValue)` | Tek bir aracı siler. Bulunduysa `true`. |
| `GetVehicleIdByPlate(plate: string)` | Id ya da `nil`. |
| `DoesPlayerVehiclePlateExist(plate: string)` | Plaka sahipliyse `true`. |
| `SaveVehicle(entity: number, options: { props?, state?, garage? })` | Spawn edilmiş bir aracı modifiye dahil kaydeder. AI Core’un props’unu ya da ox_lib / qb-core props yapısını kabul eder. Entity’den farklı bir modelin props’u reddedilir (state ve garage yine kaydedilir). |

`GetPlayerVehicle` props’u ox_lib’in değil, AI Core’un `VehicleProps` yapısında döner. `depotPrice` her zaman `0`’dır.
