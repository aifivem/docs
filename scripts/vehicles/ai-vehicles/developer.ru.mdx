У ai-vehicles только серверные экспорты. Большинство синхронные (без Promise, без ожидания в Lua); те, что могут читать базу - `FindVehicle`, `GetVehiclesOf`, `SetPlate`, `DeleteVehicleByPlate`, `AdoptVehicle` - и `SpawnVehicle` отвечают через колбэк. Типы находятся в `@aifivem/shared` (`vehicles.ts`).

```ts title="TypeScript"
import { resourceExport } from "@aifivem/lib/server";
const vehicles = resourceExport("ai-vehicles");
```

```lua title="Lua"
local vehicles = exports['ai-vehicles']
```

<Callout type="info">
Чтобы выдать, забрать или проверить ключи, поставить транспорт в гараж или прочитать топливо, используйте слои lib (`vehicleKeys`, `garages`, `fuel`): они работают с любым скриптом ключей, гаражей или топлива, который запущен на сервере. Вызывайте ai-vehicles напрямую только для самого владения.
</Callout>

## Серверные экспорты

### CreateVehicle

Регистрирует новый личный транспорт и ставит его в гараж. Используйте, когда игрок получает транспорт (покупка, награда, подарок администратора). Машину не создаёт: выведите её через `SpawnVehicle` или позвольте игроку забрать её в гараже.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
CreateVehicle(owner: VehicleOwner, model: string, garage: string | null, props?: VehicleProps): { id: number; plate: string } | null
```

```lua title="Lua"
local created = exports['ai-vehicles']:CreateVehicle(owner, model, garage, props) -- { id = number, plate = string } или nil
```

#### Параметры

<TypeTable
  type={{
    owner: { type: 'VehicleOwner', description: 'Кто будет владельцем.', required: true },
    model: { type: 'string', description: 'Название модели (`"sultan"`). Хранится в нижнем регистре. Модель не проверяется: передавайте существующую модель.', required: true },
    garage: { type: 'string | null', description: 'Id гаража ai-garages, в котором он ждёт (`"pillbox"`). `null`: без гаража (тогда транспорт автопарка показывается в каждом гараже своей работы или банды).', required: true },
    props: { type: 'VehicleProps', description: 'Начальный вид. Игнорируется, если это не корректный объект `VehicleProps`. Номер внутри всегда заменяется собственным номером транспорта.' },
  }}
/>

#### Возвращает

`{ id, plate }` нового транспорта. `null`, если `owner` не является корректным владельцем или `model` не текст.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");
const vehicles = resourceExport("ai-vehicles");

// Даёт игроку Sultan, поставленный в гараж Motel Parking.
export function giveSultan(source: number): string | null {
  const character = core.GetCharacter(source);
  if (!character) return null;
  const created = vehicles.CreateVehicle(
    { type: "character", id: String(character.id) },
    "sultan",
    "pillbox",
  );
  return created?.plate ?? null;
}
```
</Tab>
<Tab value="Lua">
```lua
-- Даёт игроку Sultan, поставленный в гараж Motel Parking.
local function giveSultan(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return nil end
  local created = exports['ai-vehicles']:CreateVehicle(
    { type = 'character', id = tostring(character.id) }, 'sultan', 'pillbox')
  return created and created.plate
end
```
</Tab>
</Tabs>

<TypeTable
  type={{

Массив `OwnedVehicle`. Пустой для некорректного владельца, владельца без транспорта или персонажа офлайн.


```lua title="Lua"

```

#### Возвращает

Массив троек. Пустой, если в памяти нет транспорта.

### FindVehicle

Одна личная машина по точному номеру, **в том числе та, чей владелец не в сети**: ai-vehicles отвечает из памяти, когда машина у него, и читает базу, когда её там нет. Это поиск по номеру, который набрал игрок: запрос в MDT, штрафстоянка, шлагбаум, проверяющий, чья машина перед ним.

**Сторона:** сервер · **Ожидание:** нет (ответ приходит в `done`)

```ts title="Сигнатура"
FindVehicle(plate: string, done: (vehicle: OwnedVehicle | null) => void, shape?: "framework"): void
```

```lua title="Lua"
exports['ai-vehicles']:FindVehicle(plate, function(vehicle) end, shape)
```

#### Параметры

<TypeTable
  type={{
    plate: { type: 'string', description: 'Номер в том виде, в каком он у машины. Это точное совпадение: часть номера ничего не найдёт.', required: true },
    done: { type: '(vehicle: OwnedVehicle | null) => void', description: 'Вызывается с машиной или с `null`, если ни у одной личной машины нет такого номера.', required: true },
    shape: { type: '"framework"', description: 'Отвечает `props` в форме ox_lib / qb-core с `fuelLevel` - для скрипта, который сам применяет внешний вид.' },
  }}
/>

#### Возвращает

Ничего. `done` получает [OwnedVehicle](#ownedvehicle) или `null`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const vehicles = resourceExport("ai-vehicles");

/** Чей это номер, в сети владелец или нет. */
export function ownerOf(plate: string): Promise<string | null> {
  return new Promise((resolve) =>
    vehicles.FindVehicle(plate, (vehicle) => resolve(vehicle?.owner.id ?? null)),
  );
}
```
</Tab>
<Tab value="Lua">
```lua
local function ownerOf(plate)
  local p = promise.new()
  exports['ai-vehicles']:FindVehicle(plate, function(vehicle)
    p:resolve(vehicle and vehicle.owner.id or nil)
  end)
  return Citizen.Await(p)
end

CreateThread(function()
  print(ownerOf('AI123ABC') or 'ничей')
end)
```
</Tab>
</Tabs>

<Callout type="info">
Поиска по всем сохранённым номерам нет. За машинами одного владельца - [GetVehiclesOf](#getvehiclesof), за номерами в памяти - [GetPlateOwners](#getplateowners).
</Callout>

### GetVehiclesOf

Все машины одного владельца, **включая персонажа, который не в сети**. [GetVehicles](#getvehicles) отвечает только за владельцев, которых ai-vehicles держит в памяти; этот читает базу, когда нужно.

**Сторона:** сервер · **Ожидание:** нет (ответ приходит в `done`)

```ts title="Сигнатура"
GetVehiclesOf(owner: VehicleOwner, done: (vehicles: OwnedVehicle[]) => void, shape?: "framework"): void
```

```lua title="Lua"
exports['ai-vehicles']:GetVehiclesOf(owner, function(vehicles) end, shape)
```

#### Параметры

<TypeTable
  type={{
    owner: { type: 'VehicleOwner', description: 'Чьи машины: персонаж (`{ type: "character", id: "12" }`, id персонажа текстом), парк работы или банды, либо ресурс, который их держит.', required: true },
    done: { type: '(vehicles: OwnedVehicle[]) => void', description: 'Вызывается с машинами владельца. Пусто для владельца без машин или неизвестного.', required: true },
    shape: { type: '"framework"', description: 'Отвечает каждый `props` в форме ox_lib / qb-core с `fuelLevel`.' },
  }}
/>

#### Возвращает

Ничего. `done` получает массив [OwnedVehicle](#ownedvehicle).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

/** Список гаража персонажа, в сети он или нет. */
export async function garageOf(citizenid: string) {
  const charId = await characters.idOf(citizenid);
  if (charId === null) return [];
  return new Promise((resolve) =>
    vehicles.GetVehiclesOf({ type: "character", id: String(charId) }, resolve),
  );
}
```
</Tab>

### SaveVehicle

**Сторона:** сервер · **Ожидание:** нет

### SaveTuning

Сохраняет полные props, включая тюнинг (`mods`, `neon`). Предназначен только для тюнинг-мастерских: собственная тюнинг-мастерская AI Core, ai-mechanic, является единственным скриптом ai-*, который его вызывает.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
SaveTuning(id: number, props: VehicleProps): void
```

```lua title="Lua"
exports['ai-vehicles']:SaveTuning(id, props)
```

#### Возвращает

Ничего. Некорректные props игнорируются. Номер внутри props всегда заменяется собственным номером транспорта.

<Callout type="warn">
Никогда не передавайте props, пришедшие прямо с клиента игрока, не проверив их на сервере: всё, что вы здесь сохраните, с этого момента становится тюнингом машины.
</Callout>

### AdoptVehicle

Делает машину, которая уже стоит в мире, личной: она переходит в `out`, отслеживается как та, что ai-vehicles создал сам, и владелец может её припарковать. Это то, что делает админская `/admincar`.

**Сторона:** сервер · **Ожидание:** нет (ответ приходит в `done`)

```ts title="Сигнатура"
AdoptVehicle(owner: VehicleOwner, entity: number, model: string, props: unknown, done?: (result: AdoptVehicleResult) => void): void
```

```lua title="Lua"

```

    model: { type: 'string', description: 'Имя модели сущности (`"sultan"`). Сервер сам имя модели не прочитает, поэтому вы передаёте его, а ai-vehicles сверяет его с сущностью.', required: true },

    done: { type: '(result: AdoptVehicleResult) => void', description: 'Вызывается с результатом.' },
  }}
/>

#### Возвращает

Ничего. `done` получает [AdoptVehicleResult](#adoptvehicleresult): `{ ok: true, id, plate }` или `{ ok: false, error }`. Сущность сохраняет свой номер, если это допустимый собственный номер (правила [SetPlate](#setplate)); иначе получает сгенерированный.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

Создаёт сущность личного транспорта в мире с его видом, номером, топливом и state bags и выдаёт ключи `asker` через активную систему ключей. Состояние транспорта становится `out`.

**Сторона:** сервер · **Ожидание:** нет (результат приходит в `cb`)



#### Параметры

<TypeTable
  type={{
    id: { type: 'number', description: 'Id транспорта.', required: true },
    at: { type: '{ x, y, z, heading }', description: 'Где он появляется. `heading` в градусах; вместо `heading` принимается `w`, отсутствующее значение равно 0. Точка с нечисловой координатой ничего не создаёт, и `cb` никогда не вызывается.', required: true },

## События

### ai-vehicles:owners

Срабатывает, когда транспорт попадает в память ai-vehicles или меняет владельца, и когда номера уходят из памяти. Один пакет за серверный тик. Прочитайте `GetPlateOwners` один раз при старте, затем применяйте эти пакеты, чтобы держать копию «номер – владелец». Имя `VEHICLES_EVENTS.owners` в `@aifivem/shared`.

**Сторона:** сервер (локальное событие, не отправляется клиентам)

<TypeTable
  type={{
    puts: { type: 'Array<[plate: string, type: VehicleOwnerType, id: string]>', description: 'Транспорт, который попал в память или получил нового владельца.', required: true },
    removes: { type: 'string[]', description: 'Номера, которые ушли из памяти (владелец вышел, транспорт удалён).', required: true },
  }}
/>

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";
import { VEHICLES_EVENTS } from "@aifivem/shared";

const owners = new Map<string, string>();
for (const [plate, type, id] of resourceExport("ai-vehicles").GetPlateOwners())
  owners.set(plate, `${type}:${id}`);

on(VEHICLES_EVENTS.owners, (puts: [string, string, string][], removes: string[]) => {
  for (const [plate, type, id] of puts) owners.set(plate, `${type}:${id}`);
  for (const plate of removes) owners.delete(plate);
});
```
</Tab>
<Tab value="Lua">
```lua
local owners = {}
for _, row in ipairs(exports['ai-vehicles']:GetPlateOwners()) do
  owners[row[1]] = row[2] .. ':' .. row[3]
end

AddEventHandler('ai-vehicles:owners', function(puts, removes)
  for _, row in ipairs(puts) do owners[row[1]] = row[2] .. ':' .. row[3] end
  for _, plate in ipairs(removes) do owners[plate] = nil end
end)
```
</Tab>
</Tabs>

## State bags

ai-vehicles выставляет их на каждом личном транспорте, который создаёт. Имена находятся в `VEHICLE_BAGS` (`@aifivem/shared`).

| Bag | Тип | Значение |
| --- | --- | --- |
| `ai:owned` | `true` | Сущность является личным транспортом. |
| `ai:vid` | `number` | Его id в ai-vehicles. |
| `ai:props` | `VehicleProps` | Сохранённый вид. Его применяет клиент ai-core, которому принадлежит сущность. |
| `ai:setup` | `VehicleSetup` | Вид при создании для транспорта без props, применяется один раз. |
| `fuel` | `number` | Топливо 0-100. Дальше за ним следит скрипт топлива. |

```lua title="Lua (клиент)"
local vehicle = GetVehiclePedIsIn(PlayerPedId(), false)
if Entity(vehicle).state['ai:owned'] then
  print('owned vehicle', Entity(vehicle).state['ai:vid'])
end
```

## qbx_vehicles API

ai-vehicles делает `provide` для `qbx_vehicles`, поэтому эти вызовы доходят до него. Форматы следуют Qbox: `state` равно `0` снаружи, `1` гараж, `2` штрафстоянка.

| Экспорт | Что делает |
| --- | --- |
| `GetPlayerVehicles(filters: { citizenid?, garage? })` | Транспорт персонажа онлайн, по желанию только одного гаража. Возвращает `{ id, citizenid, modelName, garage, state, depotPrice, props }[]`. |
| `GetPlayerVehicle(id: number)` | Один транспорт в том же формате или `nil`. |
| `CreatePlayerVehicle(request: { model, citizenid, garage?, props? })` | Создаёт транспорт для персонажа онлайн. Возвращает id или `nil, { code, message }` (`bad_request`, `not_found`). |
| `SetPlayerVehicleOwner(id: number, citizenid: string)` | Новый владелец (онлайн). `true`, если получилось. |
| `DeletePlayerVehicles(idType: "plate" \| "vehicleId", idValue)` | Удаляет один транспорт. `true`, если найден. |
| `GetVehicleIdByPlate(plate: string)` | Id или `nil`. |
| `DoesPlayerVehiclePlateExist(plate: string)` | `true`, если номер принадлежит личному транспорту. |
| `SaveVehicle(entity: number, options: { props?, state?, garage? })` | Сохраняет созданный транспорт, включая тюнинг. Принимает props AI Core или формат props ox_lib / qb-core. Props другой модели, чем у сущности, отклоняются (состояние и гараж всё равно сохраняются). |

`GetPlayerVehicle` возвращает props в формате `VehicleProps` AI Core, а не ox_lib. `depotPrice` всегда `0`.
