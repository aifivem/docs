## Как его вызывать

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

// Типизированы как AiCoreServerExports в @aicore-fivem/shared.
const core = resourceExport("ai-core");
const character = core.GetCharacter(source);
```

Чаще всего вы не вызываете экспорты ai-core сами: их оборачивают вспомогательные функции lib (`money`, `inventory`, `online`, `onCharacter`, `vehicleKeys`, `dispatch`...).
</Tab>
<Tab value="Lua">
```lua
local character = exports['ai-core']:GetCharacter(source)
```

Или через вспомогательные функции ai-lib для Lua (`shared_script '@ai-lib/init.lua'`, затем `aiLib.inventory`, `aiLib.online`...).
</Tab>
</Tabs>

## Мосты фреймворков

Скриптам, написанным для ESX, QBCore, Qbox или vRP, собственный API ai-core не нужен: ai-core отвечает на их API (`ESX.GetPlayerFromId`, `QBCore.Functions.GetPlayer`, `exports.qbx_core:GetPlayer`, Proxy и Tunnel из vRP). На что отвечает каждый мост и его ограничения описаны на странице [Совместимость](/ru/docs/compatibility).

## State bags и GlobalState

| Ключ | Где | Значение |
| --- | --- | --- |
| `ai:duty:<job>` | GlobalState | Число участников этой работы на дежурстве. |
| `ai:pvp` | GlobalState | Могут ли игроки наносить урон друг другу. |
| `ai:inventory`, `ai:vehicleKeys`, `ai:appearance`, `ai:medical`, `ai:fuel`, `ai:garages`, `ai:mdt`, `ai:notify` | GlobalState | Имя ресурса скрипта, который ai-core использует для этой задачи. |

Полный список с их форматами находится в справочниках [серверных экспортов](/ru/docs/developers/api/core-server) и [событий](/ru/docs/developers/api/events).
