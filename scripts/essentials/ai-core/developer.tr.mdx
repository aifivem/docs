## Nasıl çağrılır

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

// @aifivem/shared içinde AiCoreServerExports olarak tiplenmiştir.
const core = resourceExport("ai-core");
const character = core.GetCharacter(source);
```

Çoğu zaman ai-core’un export’larını kendin çağırmazsın: lib’in yardımcıları (`money`, `inventory`, `online`, `onCharacter`, `vehicleKeys`, `dispatch`...) onları sarar.
</Tab>
<Tab value="Lua">
```lua
local character = exports['ai-core']:GetCharacter(source)
```

Ya da ai-lib’in Lua yardımcılarıyla (`shared_script '@ai-lib/init.lua'`, sonra `aiLib.inventory`, `aiLib.online`...).
</Tab>
</Tabs>

## Framework köprüleri

ESX, QBCore, Qbox ya da vRP için yazılmış script’lerin ai-core’un kendi API’sine ihtiyacı yoktur: ai-core onlarınkini cevaplar (`ESX.GetPlayerFromId`, `QBCore.Functions.GetPlayer`, `exports.qbx_core:GetPlayer`, vRP’nin Proxy ve Tunnel’ı). Her köprünün neyi cevapladığı ve sınırları [Uyumluluk](/tr/docs/compatibility) sayfasında.

## State bag’ler ve GlobalState

| Anahtar | Nerede | Değer |
| --- | --- | --- |
| `ai:duty:<job>` | GlobalState | O meslekte mesaideki üye sayısı. |
| `ai:pvp` | GlobalState | Oyuncuların birbirine zarar verip veremeyeceği. |
| `ai:inventory`, `ai:vehicleKeys`, `ai:appearance`, `ai:medical`, `ai:fuel`, `ai:garages`, `ai:mdt`, `ai:notify` | GlobalState | ai-core’un o iş için kullandığı script’in resource adı. |

Şekilleriyle birlikte tam liste [server export’ları](/tr/docs/developers/api/core-server) ve [event’ler](/tr/docs/developers/api/events) referanslarında.
