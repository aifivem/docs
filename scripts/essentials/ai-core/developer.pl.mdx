## Jak go wywołać

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

// Typowane jako AiCoreServerExports w @aifivem/shared.
const core = resourceExport("ai-core");
const character = core.GetCharacter(source);
```

Przeważnie nie wywołujesz eksportów ai-core sam: opakowują je funkcje pomocnicze biblioteki (`money`, `inventory`, `online`, `onCharacter`, `vehicleKeys`, `dispatch`...).
</Tab>
<Tab value="Lua">
```lua
local character = exports['ai-core']:GetCharacter(source)
```

Albo przez funkcje pomocnicze Lua z ai-lib (`shared_script '@ai-lib/init.lua'`, potem `aiLib.inventory`, `aiLib.online`...).
</Tab>
</Tabs>

## Mosty frameworków

Skrypty napisane dla ESX, QBCore, Qbox lub vRP nie potrzebują własnego API ai-core: ai-core odpowiada na ich API (`ESX.GetPlayerFromId`, `QBCore.Functions.GetPlayer`, `exports.qbx_core:GetPlayer`, Proxy i Tunnel z vRP). Na co odpowiada każdy most i jakie ma ograniczenia, opisuje strona [Zgodność](/pl/docs/compatibility).

## State bagi i GlobalState

| Klucz | Gdzie | Wartość |
| --- | --- | --- |
| `ai:duty:<job>` | GlobalState | Liczba członków tej pracy na służbie. |
| `ai:pvp` | GlobalState | Czy gracze mogą się nawzajem ranić. |
| `ai:inventory`, `ai:vehicleKeys`, `ai:appearance`, `ai:medical`, `ai:fuel`, `ai:garages`, `ai:mdt`, `ai:notify` | GlobalState | Nazwa zasobu skryptu, którego ai-core używa do tego zadania. |

Pełna lista z kształtami jest w dokumentacji [eksportów serwera](/pl/docs/developers/api/core-server) i [zdarzeń](/pl/docs/developers/api/events).
