title: ai-voice dla deweloperów

icon: Code

ai-voice odpowiada na pma-voice 7.x: każdy poniższy eksport, który ma pma-voice, odpowiada też pod `exports['pma-voice']`. Serwer jest właścicielem całego stanu głosu (zasięg, częstotliwości, rozmowy, głośniki, wyciszenia) i zapisuje state bagi gracza; klienci tylko proszą. Żaden eksport nie czeka. Nie są typowane w `@aifivem/shared`: z TypeScript używaj `callExport("ai-voice", name, ...args)` z biblioteki.

## Eksporty serwera

### setPlayerRadio

Ustawia gracza na częstotliwości radiowej i czyni ją aktywną (tą, na której mówi). Nazwa z pma-voice.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
setPlayerRadio(source: number, channel: number | string): void
```

```lua title="Lua"
exports['pma-voice']:setPlayerRadio(source, 5)
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'ID gracza na serwerze.', required: true },
    channel: { type: 'number | string', description: 'Częstotliwość, od 0.01 do 1 000 000 (działa też ciąg z liczbą). `0` opuszcza każdą częstotliwość.', required: true },
  }}
/>

#### Zwraca

Nic. Rzuca wyjątek, gdy `channel` nie jest liczbą. Nic nie robi, gdy radio jest wyłączone w panelu. Częstotliwość, do której gracz nie może dołączyć (częstotliwość pracy albo `addChannelCheck`, który się nie zgadza), jest odrzucana z powiadomieniem „You cannot join this frequency”. Dołączenie do nowej częstotliwości opuszcza poprzednią aktywną; częstotliwości, których gracz tylko słucha, zostają.

### setPlayerCall

Wprowadza gracza do rozmowy telefonicznej lub go z niej wyprowadza. Nazwa z pma-voice.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
setPlayerCall(source: number, callId: number | string): void
```

<TypeTable
  type={{
    source: { type: 'number', description: 'ID gracza na serwerze.', required: true },
    callId: { type: 'number | string', description: 'ID rozmowy (dowolna liczba wybrana przez twój skrypt telefonu, obaj gracze dostają tę samą). `0` rozłącza.', required: true },
  }}
/>

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

let nextCall = 1000;

/** Connects two players; returns the call id to end it later. */
export function connect(caller: number, target: number): number {
  const id = nextCall++;
  callExport("ai-voice", "setPlayerCall", caller, id);
  callExport("ai-voice", "setPlayerCall", target, id);
  return id;
}

export function hangUp(...players: number[]): void {
  for (const p of players) callExport("ai-voice", "setPlayerCall", p, 0);
}
```
</Tab>
<Tab value="Lua">
```lua
local nextCall = 1000

local function connect(caller, target)
    nextCall = nextCall + 1
    exports['pma-voice']:setPlayerCall(caller, nextCall)
    exports['pma-voice']:setPlayerCall(target, nextCall)
    return nextCall
end

local function hangUp(a, b)
    exports['pma-voice']:setPlayerCall(a, 0)
    exports['pma-voice']:setPlayerCall(b, 0)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Gra gracza nie może sama dołączyć do rozmowy (klientowe `setCallChannel`), chyba że skrypt telefonu pozwolił na to przez `addCallCheck` albo właściciel włączył **Let players' games join calls**. Wprowadzaj graczy do rozmów z serwera.
</Callout>

### getPlayersInRadioChannel

Członkowie częstotliwości. Odpowiada też jako `GetPlayersInRadioChannel`. Nazwa z pma-voice.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
getPlayersInRadioChannel(channel: number | string): Record<string, boolean>
```

#### Zwraca

Tabela z kluczami według ID na serwerze (jako ciąg) z `true`, gdy ten członek mówi, w przeciwnym razie `false`. `{}` dla pustej częstotliwości lub złej wartości.

### addChannelCheck

Dodaje własną zasadę dla jednej częstotliwości: twoja funkcja decyduje, kto może dołączyć. Usuwana, gdy twój zasób się zatrzymuje. Nazwa z pma-voice.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
addChannelCheck(channel: number, check: (source: number) => boolean): void
```

```lua title="Lua"
exports['pma-voice']:addChannelCheck(911, function(source)
    return exports['ai-core']:GetDutyJob(source) == 'ambulance'
end)
```

Najpierw sprawdzane są zasady częstotliwości z panelu; potem twoja funkcja musi odpowiedzieć wartością prawdziwą. Rzuca wyjątek, gdy `check` nie jest funkcją.

### overrideRadioNameGetter

Zastępuje nazwę, którą członkowie radia widzą nawzajem (gdy **Send names to radio members** jest włączone). Nazwa z pma-voice.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
overrideRadioNameGetter(channel: unknown, getter: (source: number) => string): void
```

Pierwszy argument jest ignorowany (zgodność z pma-voice); getter jest używany dla każdej częstotliwości.

### isValidPlayer

```ts title="Sygnatura"
isValidPlayer(source: number): boolean
```

`true`, gdy ai-voice zna gracza (dołączył i jest skonfigurowany).

### setPlayerProximityMode

Przełącza gracza na jeden z zasięgów z panelu.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
setPlayerProximityMode(source: number, index: number): boolean
```

<TypeTable
  type={{
    source: { type: 'number', description: 'ID gracza na serwerze.', required: true },
    index: { type: 'number', description: 'Pozycja na liście **Ranges** w panelu, od 1.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy przełączono. `false`, gdy gracz jest nieznany, `index` jest poza listą albo `addProximityCheck` odmówił.

### setPlayerRange

Daje graczowi własny zasięg (megafon, mikrofon na scenie) albo przywraca mu wybrany przez niego zasięg.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
setPlayerRange(source: number, metres: number | null): boolean
```

<TypeTable
  type={{
    source: { type: 'number', description: 'ID gracza na serwerze.', required: true },
    metres: { type: 'number | null', description: 'Zasięg, od 0,5 do 100 m. `null` wraca do zasięgu wybranego przez gracza.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy ustawiono. `false`, gdy gracz jest nieznany, `metres` jest poza 0,5-100 albo `addProximityCheck` odmówił.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport, onClientEvent } from "@aifivem/lib/server";

// Przedmiot megafon: 30 m, gdy jest trzymany.
onClientEvent("myscript:megaphone", { args: ([on]) => (typeof on === "boolean" ? [on] : null) }, (source, on) => {
  callExport("ai-voice", "setPlayerRange", source, on ? 30 : null);
});
```
</Tab>
<Tab value="Lua">
```lua
RegisterNetEvent('myscript:megaphone', function(on)
    local src = source
    exports['ai-voice']:setPlayerRange(src, on == true and 30.0 or nil)
end)
```
</Tab>
</Tabs>

### getPlayerProximity

```ts title="Sygnatura"
getPlayerProximity(source: number): { index: number; distance: number; mode: string } | null
```

Bieżący zasięg gracza: `index` (pozycja na liście), `distance` w metrach, `mode` (nazwa zasięgu). `null` dla nieznanego gracza.

### toggleMute

Wycisza gracza albo odcisza wyciszonego. To samo co `/muteply`.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
toggleMute(source: number, seconds?: number): boolean
```

<TypeTable
  type={{
    source: { type: 'number', description: 'ID gracza na serwerze.', required: true },
    seconds: { type: 'number', description: 'Jak długo trwa wyciszenie (najwyżej rok). Ignorowane przy odciszaniu.', default: '900' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy wyciszenie zostało przełączone, `false` dla nieznanego gracza. Gracz dostaje powiadomienie; wywoływane jest zdarzenie serwera `pma-voice:playerMuted`. Wyciszenia są przechowywane według licencji, więc przetrwają ponowne połączenie.

### addProximityCheck

Dodaje zasadę dla zmian zasięgu. Twoja funkcja dostaje `(source, index, distance)`; odpowiedź `false` odrzuca zmianę (zarówno z klawisza gracza, jak i z eksportów). Usuwana, gdy twój zasób się zatrzymuje.

```ts title="Sygnatura"
addProximityCheck(check: (source: number, index: number, distance: number) => boolean | void): void
```

### Kilka częstotliwości

| Eksport | Zwraca | Co robi |
| --- | --- | --- |
| `addPlayerRadioListen(source, channel)` | `boolean` | Pozwala graczowi słyszeć jeszcze jedną częstotliwość bez mówienia na niej. `false` przy limicie **Frequencies at once** z panelu, gdy nie jest to dozwolone lub przy wyłączonym radiu. Staje się aktywna, gdy gracz nie miał żadnej. |
| `removePlayerRadioListen(source, channel)` | `boolean` | Opuszcza częstotliwość. `false`, gdy gracza na niej nie było. |
| `setPlayerRadioActive(source, channel)` | `boolean` | Czyni jedną z częstotliwości gracza tą, na której mówi. `false`, gdy go na niej nie ma. |
| `getPlayerRadioChannels(source)` | `{ active: number, channels: number[] } \| null` | Aktywna częstotliwość (0 = brak) i każda częstotliwość, którą gracz słyszy. |

### Dodatki telefonu

| Eksport | Zwraca | Co robi |
| --- | --- | --- |
| `addCallCheck(check: (source, callId) => boolean)` | nic | Pozwala skryptowi telefonu zezwalać na dołączanie z gry gracza: odpowiedź `true` wpuszcza tego gracza do tej rozmowy. Usuwane, gdy twój zasób się zatrzymuje. |
| `setPlayerCallSpeaker(source, on)` | `boolean` | Włącza lub wyłącza głośnik rozmowy gracza. |
| `getPlayerCallSpeaker(source)` | `boolean` | Czy jest włączony. |

### Inne

| Eksport | Zwraca | Co robi |
| --- | --- | --- |
| `setPlayerSubmix(source, name \| null)` | nic | Trwały efekt na głosie gracza: nazwa submixu zarejestrowanego przez klientów (bag `submix` z pma-voice). `null` go usuwa. |
| `getBackend()` | `"mumble" \| "enhanced"` | Używany system głosu. |

## Eksporty klienta

Eksporty klienta pma-voice (wszystkie także pod `exports['pma-voice']`):

| Eksport | Co robi |
| --- | --- |
| `setRadioChannel(channel)`, `SetRadioChannel`, `addPlayerToRadio` | Prosi serwer o aktywną częstotliwość (0 opuszcza każdą częstotliwość). Częstotliwości prac są sprawdzane na serwerze. |
| `removePlayerFromRadio()` | Opuszcza każdą częstotliwość. |
| `setCallChannel(callId)`, `SetCallChannel`, `addPlayerToCall` | Prosi o dołączenie do rozmowy. Odrzucane, chyba że pozwala na to `addCallCheck` skryptu telefonu albo włączone jest **Let players' games join calls**. |
| `removePlayerFromCall()` | Rozłącza (zawsze dozwolone). |
| `setRadioVolume(percent)` / `getRadioVolume()`, `setCallVolume(percent)` / `getCallVolume()` | Własne głośności gracza, przechowywane na jego komputerze. |
| `setVoiceProperty(name, value)`, `SetMumbleProperty`, `SetTokoProperty` | `radioEnabled`, `micClicks`. |
| `overrideProximityRange(metres, disableCycle)` / `clearProximityOverride()` | Zasięg od klienta. Odrzucane na Enhanced. |
| `setAllowProximityCycleState(blocked)` | Blokuje lub odblokowuje klawisz zasięgu. |
| `overrideProximityCheck(fn)` / `resetProximityCheck()`, `setVoiceState(mode, channel)` | Tylko Legacy (Mumble). |
| `toggleMutePlayer(serverId)` | Wycisza innego gracza tylko dla tego gracza. |
| `toggleRadioAnim()` / `getRadioAnimState()` | Przełącznik animacji radia gracza. |
| `addRadioDisableBit(bit)` / `removeRadioDisableBit(bit)` | Blokuje mówienie przez radio, dopóki ustawiony jest jakikolwiek bit (skrypt, który na chwilę wyłącza radio). |
| `registerCustomSubmix(...)`, `setEffectSubmix(...)` | Własne submixy pma-voice, w rejestrze submixów ai-voice. |

Własne eksporty klienta ai-voice:

| Eksport | Co robi |
| --- | --- |
| `addRadioChannel(channel)` / `removeRadioChannel(channel)` / `setActiveRadioChannel(channel)` | Kilka częstotliwości od strony klienta (sprawdzane na serwerze). |
| `getRadioChannels()` | Aktywna częstotliwość i lista. |
| `setCallSpeaker(on)` / `getCallSpeaker()` | Głośnik rozmowy gracza. |
| `setRadioAnimDisabled(disabled)` | Wyłącza animację radia dla tego gracza. |
| `createSubmix(name, spec)` / `getSubmix(name)` / `editSubmix(name, spec)` / `listSubmixes()` | Efekty głosu. Nazwa jest tworzona raz na sesję gry i używana ponownie; gra ma tylko 40 slotów wspólnych z własnym dźwiękiem. |
| `cycleProximity()` | Przechodzi do następnego zasięgu, jak klawisz. |
| `getBackend()` | `"mumble"` lub `"enhanced"`. |
| `isRadioTalking()` | Czy klawisz radia jest przytrzymany. |

## State bagi

Zapisywane przez serwer na każdym graczu (`Player(source).state`, po stronie klienta `LocalPlayer.state`). Czytaj je; nigdy ich nie zapisuj.

| Bag | Wartość |
| --- | --- |
| `proximity` | `{ index: number, distance: number, mode: string }`: bieżący zasięg. |
| `radioChannel` | `number`: aktywna częstotliwość, 0 gdy brak. |
| `callChannel` | `number`: ID rozmowy, 0 gdy brak. |
| `callSpeaker` | `boolean`: głośnik rozmowy jest włączony. |
| `muted` | `boolean`: wyciszony przez administratora. |
| `submix` | `string`: trwały efekt głosu ustawiony przez `setPlayerSubmix`. |

GlobalState: `ai-voice:backend` (`"mumble"` lub `"enhanced"`), `ai-voice:takeover` (skrypty, które przynoszą własny efekt radia lub telefonu). ai-voice czyta bag `dead` z AI Core i bag `isDead` z pma-voice.

## Zdarzenia

| Zdarzenie | Strona | Argumenty | Kiedy jest wywoływane |
| --- | --- | --- | --- |
| `pma-voice:setTalkingMode` | klient (lokalne) | `index: number` | Zmienił się zasięg gracza. |
| `pma-voice:radioActive` | klient (lokalne) | `talking: boolean` | Gracz zaczął lub przestał mówić przez radio. |
| `pma-voice:toggleRadioAnim` | klient (lokalne) | | Zmienił się przełącznik animacji radia. |
| `pma-voice:playerMuted` | serwer (lokalne) | `target: number, by: number, muted: boolean, seconds: number` | Gracz został wyciszony lub odciszony (`by` wynosi 0 dla eksportu). |

Zdarzenia sieciowe pma-voice (`pma-voice:syncRadioData`, `addPlayerToRadio`, `removePlayerFromRadio`, `setTalkingOnRadio`, `clSetPlayerRadio`, `syncCallData`, `addPlayerToCall`, `removePlayerFromCall`, `clSetPlayerCall`) zachowują nazwy i dane dla UI radia, które ich nasłuchują. Zdarzenia radia przenoszą częstotliwość jako dodatkowy ostatni argument; tabele członków mają klucze tekstowe.
