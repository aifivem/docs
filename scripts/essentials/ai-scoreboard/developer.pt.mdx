O ai-scoreboard **não tem exports** nem eventos feitos para outros scripts. Tudo o que ele mostra vem do AI Core, então você muda o placar mudando os dados do AI Core:

- **Jogadores e nomes** vêm dos personagens carregados (`onCharacter`, `online.name` da lib).
- **Contagens de quem está em serviço** vêm do estado de serviço do AI Core (`online.onDutyFor` da lib, GlobalState `ai:duty:<job>`). Um jogador conta assim que o AI Core o coloca em serviço (export `SetDuty`, ou o evento de serviço de um script da ponte). Veja os [exports do servidor do ai-core](/pt/docs/developers/api/core-server).

Se você quer os mesmos números no seu próprio script, leia-os do AI Core, não do placar:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Lado do cliente: a contagem de policiais em serviço, o mesmo número que o placar mostra.
const police = Number(GlobalState["ai:duty:police"] ?? 0);
console.log(`${police} police on duty`);
```
</Tab>
<Tab value="Lua">
```lua
-- Lado do cliente ou do servidor.
local police = GlobalState['ai:duty:police'] or 0
print(('%d police on duty'):format(police))
```
</Tab>
</Tabs>

## Eventos internos

Esses nomes pertencem ao cliente e ao servidor do próprio ai-scoreboard. Eles estão listados para você reconhecê-los nos logs; não os chame a partir de outros recursos.

| Nome | Tipo | O que carrega |
| --- | --- | --- |
| `ai-scoreboard:board` | Callback do cliente para o servidor | Responde as contagens mostradas agora (pedidas a cada aperto de tecla, com limite de frequência). |
| `ai-scoreboard:subscribe` | Callback do cliente para o servidor | Inscreve o jogador na lista de jogadores. Uma lista completa vem uma vez, depois só as mudanças. |
| `ai-scoreboard:client:roster` | Servidor para cliente (latente) | `(seq, rows)`: a lista inteira de jogadores. |
| `ai-scoreboard:client:changes` | Servidor para cliente | `(seq, puts, removes)`: jogadores que entraram ou saíram, no máximo uma vez por segundo. |
