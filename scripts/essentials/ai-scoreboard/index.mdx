ai-scoreboard shows a board over the game: players online out of the server's maximum, the number of on-duty members of the jobs you pick, and the list of players with their ids (and names, if you allow it).

## What it does in the game

- **Players online.** The count and the server's maximum.
- **On-duty counts.** One line per job you list in the panel, for example "Police 4". Only members who are on duty count.
- **Player list.** Server ids, character names, or both, as the panel allows. Names are hidden by default, because roleplay servers usually do not show them.
- **Hold or press.** By default the board shows while the key is held. The panel can switch it to one press to open and one press to close.
- The board takes no mouse or keyboard focus: the player keeps moving and talking while it shows.

## Installation

The AI Core txAdmin recipe installs it. By hand: put the folder in `resources/[ai]/` and add `ensure ai-scoreboard` to `server.cfg` after `ensure ai-core`. It needs OneSync and ai-core. It has no database table.

## Panel settings

Open the admin panel (**F10**) and pick **Scoreboard**. Everything is on one tab.

**Key**

| Setting | What it changes | Values | Default |
| --- | --- | --- | --- |
| Key works by | **Holding it**: the board shows while the key is held. **Pressing to open and close**: one press opens it, the next press closes it. | Holding it / Pressing to open and close | Holding it |

The key itself is not set here. It is set in the **Keybinds** tab under "Show the scoreboard" (Home unless changed), and each player can still change it in GTA's key settings.

**Players**: player ids help reports; names are often hidden on roleplay servers.

| Setting | What it changes | Values | Default |
| --- | --- | --- | --- |
| Show ids | The server id of each player in the list. | on / off | on |
| Show names | The character name of each player in the list. | on / off | off |

**Job counts**: how many members of these jobs are on duty. Up to 12 rows.

| Setting | What it changes | Values | Default |
| --- | --- | --- | --- |
| Job | The job's name as written in the **Jobs** tab (lower case, for example `police`). | 2 to 32 characters: `a-z`, `0-9`, `_` | |
| Shown as | The text on the board. | 1 to 32 characters | |

Rows shipped with the script: `police` (Police), `ambulance` (EMS), `mechanic` (Mechanics), `taxi` (Taxi).

## Commands

None.

## Keybinds

| Default key | What it does | Name in GTA settings |
| --- | --- | --- |
| Home | Shows the scoreboard (hold, or press to open and close) | Show the scoreboard |

## Works with other scripts

It reads players, characters and on-duty counts from AI Core, so on-duty counts include jobs from any script that puts players on duty through AI Core (or through the ESX / QB bridge).

## Known limits

- Changing **Show ids** or **Show names** closes every open board. The next open shows the new setting.
- If a key set in the panel does nothing in the game, check the key in the **Keybinds** tab and the player's own binding in GTA **Settings > Key Bindings > FiveM**: a player's own binding wins.
