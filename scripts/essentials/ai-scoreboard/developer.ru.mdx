У ai-scoreboard **нет экспортов** и нет событий для других скриптов. Всё, что он показывает, берётся из AI Core, поэтому вы меняете содержимое табло, меняя данные AI Core:

- **Игроки и имена** берутся из загруженных персонажей (`onCharacter`, `online.name` из lib).
- **Число людей на дежурстве** берётся из состояния дежурства AI Core (`online.onDutyFor` из lib, GlobalState `ai:duty:<job>`). Игрок учитывается, как только AI Core ставит его на дежурство (экспорт `SetDuty` или событие дежурства скрипта-моста). См. [серверные экспорты ai-core](/ru/docs/developers/api/core-server).

Если вам нужны те же числа в своём скрипте, читайте их из AI Core, а не из табло:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Клиентская сторона: число полицейских на дежурстве, то же, что показывает табло.
const police = Number(GlobalState["ai:duty:police"] ?? 0);
console.log(`${police} police on duty`);
```
</Tab>
<Tab value="Lua">
```lua
-- Клиентская или серверная сторона.
local police = GlobalState['ai:duty:police'] or 0
print(('%d police on duty'):format(police))
```
</Tab>
</Tabs>

## Внутренние события

Эти имена принадлежат собственному клиенту и серверу ai-scoreboard. Они перечислены, чтобы вы узнавали их в логах; не вызывайте их из других ресурсов.

| Name | Kind | What it carries |
| --- | --- | --- |
| `ai-scoreboard:board` | Колбэк от клиента к серверу | Отвечает числами, которые показываются прямо сейчас (запрашивается при каждом нажатии клавиши, с ограничением частоты). |
| `ai-scoreboard:subscribe` | Колбэк от клиента к серверу | Подписывает игрока на список игроков. Один раз приходит полный список, затем только изменения. |
| `ai-scoreboard:client:roster` | Сервер к клиенту (latent) | `(seq, rows)`: весь список игроков. |
| `ai-scoreboard:client:changes` | Сервер к клиенту | `(seq, puts, removes)`: игроки, которые зашли или вышли, не чаще раза в секунду. |
