ai-scoreboard hat **keine Exports** und keine Events, die für andere Skripte gedacht sind. Alles, was es anzeigt, kommt aus AI Core, du änderst die Tafel also, indem du die Daten von AI Core änderst:

- **Spieler und Namen** kommen von geladenen Charakteren (`onCharacter`, `online.name` der Lib).
- **Die Anzahl im Dienst** kommt aus dem Dienststatus von AI Core (`online.onDutyFor` der Lib, GlobalState `ai:duty:<job>`). Ein Spieler zählt, sobald AI Core ihn in den Dienst setzt (Export `SetDuty` oder das Dienst-Event eines Brückenskripts). Siehe [Server-Exports von ai-core](/de/docs/developers/api/core-server).

Wenn du dieselben Zahlen in deinem eigenen Skript willst, lies sie aus AI Core, nicht aus dem Scoreboard:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Clientseitig: die Anzahl der Polizisten im Dienst, dieselbe Zahl, die das Scoreboard zeigt.
const police = Number(GlobalState["ai:duty:police"] ?? 0);
console.log(`${police} police on duty`);
```
</Tab>
<Tab value="Lua">
```lua
-- Client- oder serverseitig.
local police = GlobalState['ai:duty:police'] or 0
print(('%d police on duty'):format(police))
```
</Tab>
</Tabs>

## Interne Events

Diese Namen gehören zum eigenen Client und Server von ai-scoreboard. Sie sind aufgeführt, damit du sie in Logs erkennst; rufe sie nicht aus anderen Ressourcen auf.

| Name | Art | Was es überträgt |
| --- | --- | --- |
| `ai-scoreboard:board` | Callback Client an Server | Antwortet mit den aktuell angezeigten Zahlen (bei jedem Tastendruck abgefragt, mit Rate-Limit). |
| `ai-scoreboard:subscribe` | Callback Client an Server | Abonniert die Spielerliste für den Spieler. Eine vollständige Liste folgt einmal, danach nur Änderungen. |
| `ai-scoreboard:client:roster` | Server an Client (latent) | `(seq, rows)`: die ganze Spielerliste. |
| `ai-scoreboard:client:changes` | Server an Client | `(seq, puts, removes)`: Spieler, die beigetreten sind oder gegangen sind, höchstens einmal pro Sekunde. |
