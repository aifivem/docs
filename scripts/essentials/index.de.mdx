Das sind die Skripte, die ein Roleplay-Server vom ersten Tag an betreibt. [ai-core](/de/docs/scripts/essentials/ai-core) ist Pflicht: jedes andere `ai-*`-Skript braucht es. [ai-mysql](/de/docs/scripts/essentials/ai-mysql) und [ai-lib](/de/docs/scripts/essentials/ai-lib) werden von fast allem gebraucht. Die übrigen kann man jeweils durch ein Drittanbieter-Skript derselben Art ersetzen (ein anderes Inventar-, HUD-, Sprach- oder Kleidungsskript), weil die anderen Skripte sie über AI Core erreichen.

| Skript | Was es macht | Ersetzt |
| --- | --- | --- |
| [ai-core](/de/docs/scripts/essentials/ai-core) | Das Framework: Spieler, Charaktere, der Charakterbildschirm, Geld, Jobs und Gangs, Berechtigungen, das Admin-Panel und die Framework-Brücke. | es_extended, qb-core, qbx_core, vrp, UI-Ressourcen von ESX und QB |
| [ai-mysql](/de/docs/scripts/essentials/ai-mysql) | Die Datenbank-Engine für Drittanbieter-Skripte. | oxmysql, mysql-async, ghmattimysql |
| [ai-lib](/de/docs/scripts/essentials/ai-lib) | Benachrichtigungen, Fortschrittsbalken, Hinweise, Menüs, Eingabedialoge und Minispiele für jedes Skript; die AI-Core-Helfer für Lua- und JavaScript-Ressourcen. | |
| [ai-loading](/de/docs/scripts/essentials/ai-loading) | Der Ladebildschirm. | |
| [ai-appearance](/de/docs/scripts/essentials/ai-appearance) | Charaktereditor, Kleidungsgeschäfte und Friseure. | |
| [ai-inventory](/de/docs/scripts/essentials/ai-inventory) | Raster-Inventar, Drops, Lager, Kofferräume, Shops, Crafting, Waffen. | ox_inventory, qb-inventory |
| [ai-hud](/de/docs/scripts/essentials/ai-hud) | Das HUD und die Bedürfnisse (Hunger, Durst, Stress). | |
| [ai-chat](/de/docs/scripts/essentials/ai-chat) | Chat mit Kanälen und Befehlsvorschlägen. | chat |
| [ai-voice](/de/docs/scripts/essentials/ai-voice) | Sprachchat nach Nähe, Funk und Telefonate. | pma-voice, mumble-voip, tokovoip |
| [ai-radialmenu](/de/docs/scripts/essentials/ai-radialmenu) | Das Radialmenü (F3). | qb-radialmenu, tgiann-radialmenu-target |
| [ai-target](/de/docs/scripts/essentials/ai-target) | Das Target-Auge. | ox_target |
| [ai-scoreboard](/de/docs/scripts/essentials/ai-scoreboard) | Spieler online und Anzahl im Dienst (Pos1). | |
| [ai-weathersync](/de/docs/scripts/essentials/ai-weathersync) | Zeit und Wetter, für alle gleich. | qb-weathersync |

## Startreihenfolge

Die `server.cfg` startet sie in dieser Reihenfolge (das Rezept erledigt das für dich): `ai-mysql`, dann `ai-core`, dann die anderen. Ein Skript, das ein anderes „ersetzt“, gilt für jede andere Ressource als dieses Skript: Installiere das Original nicht daneben.
