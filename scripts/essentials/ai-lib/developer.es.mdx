ai-lib lleva `@aicore-fivem/lib` para los recursos que no empaquetan el paquete npm. Las funciones en sí se documentan una sola vez, en la referencia de la lib:

- [La lib: resumen](/es/docs/developers/lib)
- [Lib: funciones de cliente](/es/docs/developers/api/lib-client)
- [Lib: funciones de servidor](/es/docs/developers/api/lib-server)
- [Lib: funciones compartidas](/es/docs/developers/api/lib-shared)
- [Lua (`aiLib`)](/es/docs/developers/api/lua): los equivalentes en Lua y su orden de argumentos

## Cargarlo

<Tabs items={['Lua', 'JavaScript', 'TypeScript']}>
<Tab value="Lua">
```lua title="fxmanifest.lua"
fx_version 'cerulean'
game 'gta5'
lua54 'yes'

dependency 'ai-lib'
shared_script '@ai-lib/init.lua'
client_script 'client.lua'
server_script 'server.lua'
```

```lua title="client.lua"
local L = aiLib.locale()
aiLib.notify(L('WELCOME'), 'success')
```

Los módulos se cargan en el primer uso (`aiLib.Points`, `aiLib.progress`...), dentro de tu recurso, así que los puntos, teclas y callbacks que creas pertenecen a tu recurso y desaparecen cuando se detiene. Las funciones que esperan (`triggerServerCallback`, `menu.show`, `progress`, `spawnVehicle`, `progressFor`) deben ejecutarse dentro de un thread o de un handler de evento.
</Tab>
<Tab value="JavaScript">
```lua title="fxmanifest.lua"
dependency 'ai-lib'
client_script '@ai-lib/dist/client.js'
server_script '@ai-lib/dist/server.js'
client_script 'client.js'
server_script 'server.js'
```

```js title="client.js"
aiLib.notify("Welcome", "success");
```

El global `aiLib` contiene las funciones compartidas de la lib más las de cliente o de servidor de ese lado.
</Tab>
<Tab value="TypeScript">
Los recursos TypeScript hechos con la plantilla de AI Core importan el paquete en su lugar y no cargan los archivos de ai-lib:

```ts
import { notify } from "@aicore-fivem/lib/client";
notify("Welcome", "success");
```

Aun así necesitan ai-lib en marcha: las llamadas de interfaz van a sus exports.
</Tab>
</Tabs>

## Exports de cliente

Las funciones `notify`, `progress`, `showPrompt`, `menu`, `input`, `skillCheck` y `lockpick` de la lib los llaman por ti; usa las funciones de la lib. Están tipados como `AiLibClientExports` en `@aicore-fivem/shared` (`resourceExport("ai-lib")`). Los avisos, menús y zonas pertenecen al recurso que llama y desaparecen cuando se detiene.

### Notify

Muestra una tarjeta de notificación en la pantalla de este jugador.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
Notify(notification: Notification): void
```

```lua title="Lua"
exports['ai-lib']:Notify({ text = 'Saved', kind = 'success' })
-- lo mismo con la lib: aiLib.notify('Saved', 'success')
```

#### Notification

<TypeTable
  type={{
    text: { type: 'string', description: 'El mensaje, ya traducido. Se corta a 300 caracteres.', required: true },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'Color e icono. Cualquier otro valor cuenta como `"info"`.', required: true },
    title: { type: 'string', description: 'Una línea de título, hasta 60 caracteres.' },
    duration: { type: 'number', description: 'Milisegundos en pantalla, 1000-30000.', default: '4000' },
  }}
/>

#### Devuelve

Nada. Una notificación sin `text` se descarta. Cuando el dueño eligió otro script de notificaciones en el panel, la tarjeta va allí; si ese script no la acepta, la dibuja ai-lib.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="client.ts"
import { notify } from "@aicore-fivem/lib/client";

notify("Your vehicle was stored", "success", 5000);
```

```ts title="server.ts"
import { notify, onClientEvent } from "@aicore-fivem/lib/server";

// La misma tarjeta en la pantalla de un jugador, enviada desde el servidor.
onClientEvent("myscript:collectPay", (source) => {
  notify(source, "You were paid $500", "info");
});
```
</Tab>
<Tab value="Lua">
```lua
-- cliente
aiLib.notify('Your vehicle was stored', 'success', 5000)

-- servidor
aiLib.notify(source, 'You were paid $500', 'info')
```
</Tab>
</Tabs>

### ShowProgress and HideProgress

Muestra la barra de progreso durante un tiempo, o la oculta. Solo la barra: el script que llama lleva la acción, su animación y la lógica de cancelar. Usa en su lugar `progress` (cliente) o `progressFor` (servidor) de la lib, que hacen todo eso.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
ShowProgress(label: string, duration: number): void
HideProgress(): void
```

<TypeTable
  type={{
    label: { type: 'string', description: 'Texto de la barra, ya traducido. Se corta a 60 caracteres.', required: true },
    duration: { type: 'number', description: 'Cuánto tarda la barra en llenarse, en milisegundos.', required: true },
  }}
/>

Mientras se muestra la barra, la tecla de cancelar (**Backspace**) dispara el evento local `ai-lib:client:cancelProgress`.

### ShowPrompt and HidePrompt

Muestra o actualiza uno de los avisos del recurso que llama, o lo oculta. Usa `showPrompt` / `hidePrompt` de la lib, o mejor `Points` de la lib, que muestra y oculta los avisos por distancia por ti.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
ShowPrompt(id: string, text: string, at?: PromptAnchor): void
HidePrompt(id: string): void
```

<TypeTable
  type={{
    id: { type: 'string', description: 'El id de tu aviso. Mostrar otra vez el mismo id lo actualiza.', required: true },
    text: { type: 'string', description: 'El texto, ya traducido ("Open the shop").', required: true },
    at: { type: '{ x, y, z } | { anchors: { entity, offset: { x, y, z } }[] }', description: 'Dibuja el aviso sobre un punto del mundo, o sobre puntos de entidades (desplazamientos en el espacio propio de la entidad, así que se mueve con una puerta que gira; se muestra el punto más cercano al jugador). Si se omite: la lista a la derecha de la pantalla.' },
  }}
/>

Cuando el jugador pulsa la tecla de interacción mientras tu aviso está arriba, se dispara el evento local `ai-lib:client:promptPressed (resource, id)`; `onPromptPressed` de la lib lo filtra para tu recurso.

### CloseDialog

Cierra el menú o cuadro de entrada abierto del recurso que llama. La llamada `menu.show` / `input` que espera responde `null`, como si el jugador lo hubiera cerrado. **Lado:** Cliente · **Espera:** no.

```ts title="Firma"
CloseDialog(): void
```

### Exports internos

Los usan las propias funciones de la lib. Tú no los llamas.

| Export | Lo usa |
| --- | --- |
| `OpenMenu(requestId, request)`, `OpenInput(requestId, request)`, `OpenMinigame(requestId, request)` | `menu.show`, `input`, `skillCheck`, `lockpick` de la lib. Las respuestas vuelven como `ai-lib:client:menuResult` / `inputResult` con el id de la petición. |
| `AddZone(key, shape, interval, inside)`, `RemoveZone(key)` | `Zones` de la lib en recursos JavaScript: ai-lib comprueba las zonas de todos los recursos con un solo temporizador y responde con `ai-lib:client:zone (owner, key, inside)`. |
| `AddModelPoint(key, def, entity)`, `RemoveModelPoint(key)` | `Points.addModel` / `addVehicle` de la lib en modo aviso: ai-lib encuentra el objeto más cercano y responde con `ai-lib:client:modelPoint (owner, key, entity)`. |

## Eventos

| Evento | Lado | Argumentos | Qué es |
| --- | --- | --- | --- |
| `ai-lib:client:notify` | Servidor a cliente | `notification: Notification` | Muestra una tarjeta en la pantalla de ese jugador. Lo envía `notify(source, text, kind?, duration?)` de la lib de servidor. |
| `ai-lib:client:promptPressed` | Cliente (local) | `resource: string, id: string` | Se pulsó la tecla de interacción mientras el aviso de ese recurso estaba arriba. |
| `ai-lib:client:cancelProgress` | Cliente (local) | ninguno | Se pulsó la tecla de cancelar mientras se muestra una barra de progreso. |
