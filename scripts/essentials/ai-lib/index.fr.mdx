ai-lib a deux rôles :

1. **L’interface joueur que partagent tous les scripts.** Les cartes de notification, la barre de progression et sa touche d’annulation, les invites à droite de l’écran et la touche d’interaction, les menus, les boîtes de saisie, et les mini-jeux de crochetage et de test d’habileté. Chaque script `ai-*`, le pont d’AI Core (scripts ESX et QB) et vos propres scripts dessinent à travers lui, donc tout le serveur a le même aspect.
2. **Les utilitaires AI Core pour les autres ressources.** Une ressource Lua ajoute une ligne à son manifeste et obtient `aiLib.notify`, `aiLib.Points`, `aiLib.addCommand`, `aiLib.progress` et le reste. Les ressources JavaScript simples chargent ses bundles. C’est ainsi que les scripts Lua utilisent AI Core comme le font les scripts TypeScript.

L’interface fonctionne sans ai-core, vous pouvez donc utiliser ai-lib seul. Les utilitaires qui lisent les joueurs, l’argent ou les objets ont besoin d’ai-core.

## Ce qu’il fait en jeu

- **Notifications.** Des cartes de quatre types (succès, erreur, info, avertissement), 4 secondes par défaut.
- **Barre de progression.** Une seule barre pour tous les scripts. Le joueur annule une action annulable avec **Retour arrière**.
- **Invites.** Des boîtes « Press E to ... » à droite, ou flottant au-dessus d’un point du monde (une porte). Une seule touche d’interaction (**E**) pour tous les scripts ; l’invite la plus récente est au-dessus.
- **Menus et boîtes de saisie.** Des listes avec icônes, des sous-menus (Échap revient en arrière, maintenir Échap ferme), des interrupteurs, et des formulaires avec des champs de texte et de nombre.
- **Mini-jeux.** Un crochetage (déplacer le crochet, tourner la serrure) et un test d’habileté (appuyer sur le vert).
- **Toujours au premier plan.** Les menus et les notifications s’affichent par-dessus tous les autres écrans, écran des personnages compris.

## Installation

La recipe txAdmin d’AI Core l’installe. À la main : placez le dossier dans `resources/[ai]/` et ajoutez `ensure ai-lib` à `server.cfg`, après `ensure ai-core` quand vous faites tourner AI Core. Il nécessite OneSync. Il n’a pas de table de base de données.

## Réglages du panneau

ai-lib n’a pas d’onglet propre. Deux réglages de l’onglet **General** d’AI Core le modifient :

| Réglage (onglet General) | Ce qu’il change | Défaut |
| --- | --- | --- |
| Carte **Notifications**, Notification script | Où s’affichent les cartes de notification : les cartes propres à ai-lib, ou un autre script de notification que vous avez installé. Quand ce script s’arrête, les cartes d’ai-lib reviennent. Les invites restent toujours celles d’ai-lib. | ai-lib |
| Carte **Interaction**, Interaction style | Prompt and key (les invites d’ai-lib), ou Target eye (un script de ciblage comme [ai-target](/fr/docs/scripts/essentials/ai-target)). | Prompt and key |

## Commandes

Aucune.

## Raccourcis clavier

| Touche par défaut | Ce qu’elle fait | Nom dans les réglages de GTA |
| --- | --- | --- |
| E | Utilise l’invite du dessus (ou le marqueur de ciblage qui a le focus) | Interact with the prompt on screen |
| Retour arrière | Annule l’action en cours (une barre de progression qui le permet) | Cancel the running action |

Changez la valeur par défaut pour tout le monde dans l’onglet **Keybinds** du panneau ; chaque joueur peut changer la sienne dans les réglages des touches de GTA.

## Fonctionne avec d’autres scripts

- **Interface ESX et QB.** Le pont d’AI Core dessine `esx_context`, `esx_textui`, `esx_notify`, `esx_progressbar`, `esx_menu_*`, `qb-menu`, `qb-input` et `progressbar` avec les menus, invites, cartes et la barre d’ai-lib, donc ces scripts ressemblent au reste du serveur.
- **D’autres scripts de notification** peuvent prendre en charge les cartes (onglet General, ci-dessus).

## Limites connues

- Les noms d’icônes des menus sont une liste Font Awesome fixe ; un nom inconnu affiche un point.
- Les ressources Lua vérifient elles-mêmes leurs zones et leurs points de modèles ; les ressources JavaScript confient les leurs à ai-lib, qui les vérifie toutes sur un seul minuteur.
