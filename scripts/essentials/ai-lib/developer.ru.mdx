ai-lib несёт `@aicore-fivem/lib` для ресурсов, которые не включают npm-пакет в сборку. Сами функции описаны один раз, в справочнике lib:

- [Lib: обзор](/ru/docs/developers/lib)
- [Lib: клиентские функции](/ru/docs/developers/api/lib-client)
- [Lib: серверные функции](/ru/docs/developers/api/lib-server)
- [Lib: общие функции](/ru/docs/developers/api/lib-shared)
- [Lua (`aiLib`)](/ru/docs/developers/api/lua): двойники на Lua и порядок их аргументов

## Как его загрузить

<Tabs items={['Lua', 'JavaScript', 'TypeScript']}>
<Tab value="Lua">
```lua title="fxmanifest.lua"
fx_version 'cerulean'
game 'gta5'
lua54 'yes'

dependency 'ai-lib'
shared_script '@ai-lib/init.lua'
client_script 'client.lua'
server_script 'server.lua'
```

```lua title="client.lua"
local L = aiLib.locale()
aiLib.notify(L('WELCOME'), 'success')
```

Модули загружаются при первом использовании (`aiLib.Points`, `aiLib.progress`...) внутри вашего ресурса, поэтому точки, привязки клавиш и колбэки, которые вы создаёте, принадлежат вашему ресурсу и исчезают, когда он останавливается. Функции, которые ждут (`triggerServerCallback`, `menu.show`, `progress`, `spawnVehicle`, `progressFor`), должны выполняться внутри потока или обработчика события.
</Tab>
<Tab value="JavaScript">
```lua title="fxmanifest.lua"
dependency 'ai-lib'
client_script '@ai-lib/dist/client.js'
server_script '@ai-lib/dist/server.js'
client_script 'client.js'
server_script 'server.js'
```

```js title="client.js"
aiLib.notify("Welcome", "success");
```

Глобальная переменная `aiLib` содержит общие функции lib плюс клиентские или серверные функции этой стороны.
</Tab>
<Tab value="TypeScript">
Ресурсы на TypeScript, собранные по шаблону AI Core, вместо этого импортируют пакет и не загружают файлы ai-lib:

```ts
import { notify } from "@aicore-fivem/lib/client";
notify("Welcome", "success");
```

Им всё равно нужен запущенный ai-lib: вызовы интерфейса идут в его экспорты.
</Tab>
</Tabs>

## Клиентские экспорты

`notify`, `progress`, `showPrompt`, `menu`, `input`, `skillCheck` и `lockpick` из lib вызывают их за вас; используйте функции lib. Они типизированы как `AiLibClientExports` в `@aicore-fivem/shared` (`resourceExport("ai-lib")`). Подсказки, меню и зоны принадлежат вызывающему ресурсу и исчезают, когда он останавливается.

### Notify

Показывает карточку уведомления на экране этого игрока.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
Notify(notification: Notification): void
```

```lua title="Lua"
exports['ai-lib']:Notify({ text = 'Saved', kind = 'success' })
-- то же через lib: aiLib.notify('Saved', 'success')
```

#### Notification

<TypeTable
  type={{
    text: { type: 'string', description: 'Сообщение, уже переведённое. Обрезается до 300 символов.', required: true },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'Цвет и иконка. Любое другое значение считается `"info"`.', required: true },
    title: { type: 'string', description: 'Строка заголовка, до 60 символов.' },
    duration: { type: 'number', description: 'Миллисекунды на экране, 1000-30000.', default: '4000' },
  }}
/>

#### Возвращает

Ничего. Уведомление без `text` отбрасывается. Если владелец выбрал в панели другой скрипт уведомлений, карточка идёт туда; если этот скрипт её не принимает, её рисует ai-lib.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="client.ts"
import { notify } from "@aicore-fivem/lib/client";

notify("Your vehicle was stored", "success", 5000);
```

```ts title="server.ts"
import { notify, onClientEvent } from "@aicore-fivem/lib/server";

// Та же карточка на экране одного игрока, отправленная с сервера.
onClientEvent("myscript:collectPay", (source) => {
  notify(source, "You were paid $500", "info");
});
```
</Tab>
<Tab value="Lua">
```lua
-- клиент
aiLib.notify('Your vehicle was stored', 'success', 5000)

-- сервер
aiLib.notify(source, 'You were paid $500', 'info')
```
</Tab>
</Tabs>

### ShowProgress и HideProgress

Показывает полосу прогресса на время или скрывает её. Только полосу: действие, его анимацию и логику отмены выполняет вызывающий скрипт. Используйте вместо этого `progress` (клиент) или `progressFor` (сервер) из lib, которые делают всё это.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
ShowProgress(label: string, duration: number): void
HideProgress(): void
```

<TypeTable
  type={{
    label: { type: 'string', description: 'Текст на полосе, уже переведённый. Обрезается до 60 символов.', required: true },
    duration: { type: 'number', description: 'Сколько заполняется полоса, в миллисекундах.', required: true },
  }}
/>

Пока полоса показывается, клавиша отмены (**Backspace**) вызывает локальное событие `ai-lib:client:cancelProgress`.

### ShowPrompt и HidePrompt

Показывает или обновляет одну из подсказок вызывающего ресурса или скрывает её. Используйте `showPrompt` / `hidePrompt` из lib, а лучше `Points` из lib, который сам показывает и скрывает подсказки по расстоянию.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
ShowPrompt(id: string, text: string, at?: PromptAnchor): void
HidePrompt(id: string): void
```

<TypeTable
  type={{
    id: { type: 'string', description: 'Id вашей подсказки. Повторный показ того же id обновляет её.', required: true },
    text: { type: 'string', description: 'Текст, уже переведённый ("Open the shop").', required: true },
    at: { type: '{ x, y, z } | { anchors: { entity, offset: { x, y, z } }[] }', description: 'Рисует подсказку над точкой мира или над местами на сущностях (смещения в собственном пространстве сущности, поэтому она движется вместе с открывающейся дверью; показывается место, ближайшее к игроку). Если не указано: список справа на экране.' },
  }}
/>

Когда игрок нажимает клавишу взаимодействия, пока ваша подсказка сверху, срабатывает локальное событие `ai-lib:client:promptPressed (resource, id)`; `onPromptPressed` из lib фильтрует его для вашего ресурса.

### CloseDialog

Закрывает открытое меню или диалог ввода вызывающего ресурса. Ожидающий вызов `menu.show` / `input` отвечает `null`, как если бы его закрыл игрок. **Сторона:** клиент · **Ожидание:** нет.

```ts title="Сигнатура"
CloseDialog(): void
```

### Служебные экспорты

Ими пользуются собственные функции lib. Вы их не вызываете.

| Экспорт | Кем используется |
| --- | --- |
| `OpenMenu(requestId, request)`, `OpenInput(requestId, request)`, `OpenMinigame(requestId, request)` | `menu.show`, `input`, `skillCheck`, `lockpick` из lib. Ответы возвращаются как `ai-lib:client:menuResult` / `inputResult` с id запроса. |
| `AddZone(key, shape, interval, inside)`, `RemoveZone(key)` | `Zones` из lib в ресурсах на JavaScript: ai-lib проверяет зоны всех ресурсов одним таймером и отвечает `ai-lib:client:zone (owner, key, inside)`. |
| `AddModelPoint(key, def, entity)`, `RemoveModelPoint(key)` | `Points.addModel` / `addVehicle` из lib в режиме подсказок: ai-lib находит ближайший объект и отвечает `ai-lib:client:modelPoint (owner, key, entity)`. |

## События

| Событие | Сторона | Аргументы | Что это |
| --- | --- | --- | --- |
| `ai-lib:client:notify` | Сервер к клиенту | `notification: Notification` | Показывает карточку на экране этого игрока. Её отправляет серверная `notify(source, text, kind?, duration?)` из lib. |
| `ai-lib:client:promptPressed` | Клиент (локальное) | `resource: string, id: string` | Клавиша взаимодействия нажата, пока подсказка этого ресурса была сверху. |
| `ai-lib:client:cancelProgress` | Клиент (локальное) | нет | Клавиша отмены нажата, пока показывается полоса прогресса. |
