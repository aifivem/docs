Ce sont les scripts qu’un serveur roleplay fait tourner dès le premier jour. [ai-core](/fr/docs/scripts/essentials/ai-core) est obligatoire : tous les autres scripts `ai-*` en ont besoin. [ai-mysql](/fr/docs/scripts/essentials/ai-mysql) et [ai-lib](/fr/docs/scripts/essentials/ai-lib) sont nécessaires à presque tout. Chacun des autres peut être remplacé par un script tiers du même type (un autre inventaire, HUD, script de voix ou de vêtements), car les autres scripts les atteignent à travers AI Core.

| Script | Ce qu’il fait | Remplace |
| --- | --- | --- |
| [ai-core](/fr/docs/scripts/essentials/ai-core) | Le framework : joueurs, personnages, écran des personnages, argent, métiers et gangs, permissions, panneau d’administration et pont de framework. | es_extended, qb-core, qbx_core, vrp, ressources d’interface ESX et QB |
| [ai-mysql](/fr/docs/scripts/essentials/ai-mysql) | Le moteur de base de données pour les scripts tiers. | oxmysql, mysql-async, ghmattimysql |
| [ai-lib](/fr/docs/scripts/essentials/ai-lib) | Notifications, barre de progression, invites, menus, boîtes de saisie et mini-jeux pour chaque script ; les utilitaires AI Core pour les ressources Lua et JavaScript. | |
| [ai-loading](/fr/docs/scripts/essentials/ai-loading) | L’écran de chargement. | |
| [ai-appearance](/fr/docs/scripts/essentials/ai-appearance) | Création de personnage, magasins de vêtements et barbiers. | |
| [ai-inventory](/fr/docs/scripts/essentials/ai-inventory) | Inventaire en grille, objets au sol, stockages, coffres de véhicule, magasins, fabrication, armes. | ox_inventory, qb-inventory |
| [ai-hud](/fr/docs/scripts/essentials/ai-hud) | Le HUD et les besoins (faim, soif, stress). | |
| [ai-chat](/fr/docs/scripts/essentials/ai-chat) | Chat avec canaux et suggestions de commandes. | chat |
| [ai-voice](/fr/docs/scripts/essentials/ai-voice) | Voix de proximité, radio et appels téléphoniques. | pma-voice, mumble-voip, tokovoip |
| [ai-radialmenu](/fr/docs/scripts/essentials/ai-radialmenu) | Le menu radial (F3). | qb-radialmenu, tgiann-radialmenu-target |
| [ai-target](/fr/docs/scripts/essentials/ai-target) | L’œil de ciblage. | ox_target |
| [ai-scoreboard](/fr/docs/scripts/essentials/ai-scoreboard) | Joueurs en ligne et nombre de personnes en service (Origine / Home). | |
| [ai-weathersync](/fr/docs/scripts/essentials/ai-weathersync) | Heure et météo, identiques pour tous. | qb-weathersync |

## Ordre de démarrage

`server.cfg` les démarre dans cet ordre (la recipe s’en charge pour vous) : `ai-mysql`, puis `ai-core`, puis les autres. Un script qui « remplace » un autre compte comme ce script pour toutes les autres ressources : n’installez pas l’original à côté.
