These are the scripts a roleplay server runs from the first day. [ai-core](/docs/scripts/essentials/ai-core) is required: every other `ai-*` script needs it. [ai-mysql](/docs/scripts/essentials/ai-mysql) and [ai-lib](/docs/scripts/essentials/ai-lib) are needed by almost everything. The rest can each be replaced by a third-party script of the same kind (another inventory, HUD, voice or clothing script), because the other scripts reach them through AI Core.

| Script | What it does | Stands in for |
| --- | --- | --- |
| [ai-core](/docs/scripts/essentials/ai-core) | The framework: players, characters, the character screen, money, jobs and gangs, permissions, the admin panel and the framework bridge. | es_extended, qb-core, qbx_core, vrp, ESX and QB UI resources |
| [ai-mysql](/docs/scripts/essentials/ai-mysql) | The database engine for third-party scripts. | oxmysql, mysql-async, ghmattimysql |
| [ai-lib](/docs/scripts/essentials/ai-lib) | Notifications, progress bar, prompts, menus, input dialogs and minigames for every script; the AI Core helpers for Lua and JavaScript resources. | |
| [ai-loading](/docs/scripts/essentials/ai-loading) | The loading screen. | |
| [ai-appearance](/docs/scripts/essentials/ai-appearance) | Character creator, clothing stores and barbers. | |
| [ai-inventory](/docs/scripts/essentials/ai-inventory) | Grid inventory, drops, stashes, trunks, shops, crafting, weapons. | ox_inventory, qb-inventory |
| [ai-hud](/docs/scripts/essentials/ai-hud) | The HUD and the needs (hunger, thirst, stress). | |
| [ai-chat](/docs/scripts/essentials/ai-chat) | Chat with channels and command suggestions. | chat |
| [ai-voice](/docs/scripts/essentials/ai-voice) | Proximity voice, radio and phone calls. | pma-voice, mumble-voip, tokovoip |
| [ai-radialmenu](/docs/scripts/essentials/ai-radialmenu) | The radial menu (F3). | qb-radialmenu, tgiann-radialmenu-target |
| [ai-target](/docs/scripts/essentials/ai-target) | The target eye. | ox_target |
| [ai-scoreboard](/docs/scripts/essentials/ai-scoreboard) | Players online and on-duty counts (Home). | |
| [ai-weathersync](/docs/scripts/essentials/ai-weathersync) | Time and weather, the same for everyone. | qb-weathersync |

## Start order

`server.cfg` starts them in this order (the recipe does it for you): `ai-mysql`, then `ai-core`, then the others. A script that "stands in for" another one counts as that script for every other resource: do not install the original next to it.
