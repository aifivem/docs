<Callout type="info">
Adicione seus itens através do AI Core, não do ai-radialmenu: `radial.add(item)` da lib em TypeScript ou `aiLib.radial.add(item)` em Lua. O AI Core guarda os itens, os entrega a qualquer menu radial que o servidor rode, os dá de novo a um menu radial que reinicia, e os remove quando seu recurso para. Chamar o ai-radialmenu diretamente prende seu script a um único menu.
</Callout>

## Adicionando um item (forma recomendada)

### radial.add

Adiciona um item ao menu, ou substitui o item com o mesmo `id`.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
radial.add(item: RadialItem): void
```

```lua title="Lua"
aiLib.radial.add(item)
```

#### Parâmetros

#### RadialItem

<TypeTable
  type={{
    id: { type: 'string', description: 'Id único. Adicionar o mesmo id de novo substitui o item.', required: true },
    label: { type: 'string', description: 'Texto no cartão, já traduzido (`Locale("...")`).', required: true },
    icon: { type: 'string', description: 'Um nome de ícone sólido do Font Awesome sem `fa-` (`car`, `key`, `handcuffs`), ou uma url de imagem.' },
    parent: { type: 'string', description: 'O item em que este entra: `"vehicle"` (`RADIAL_VEHICLE` de `@aifivem/shared`, a categoria de veículo embutida) ou o id de outro item. Omitido: o menu principal.' },
    items: { type: 'RadialItem[]', description: 'Subitens. O cartão então abre um submenu em vez de rodar `onPressed`. Uma categoria sem subitem visível se esconde.' },
    canShow: { type: '() => boolean', description: 'O item só aparece enquanto isso retorna true. Lido toda vez que o menu abre e em `radial.refresh()`. Uma função que lança erro esconde o item.' },
    onPressed: { type: '() => void', description: 'Roda no seu recurso quando o jogador escolhe o item. O menu verifica `canShow` de novo antes e recusa com uma notificação quando ele não vale mais.' },
    keepOpen: { type: 'boolean', description: 'Mantém o menu aberto depois do clique e o atualiza (portas, extras).', default: 'false' },
    whileDead: { type: 'boolean', description: 'Mantém o item enquanto o jogador está caído. Todos os outros itens se escondem nesse caso.', default: 'false' },
  }}
/>

#### Retorno

Nada.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { radial, notify, onPlayerData, getPlayerData } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import Locale from "common/locale";

// Uma categoria de polícia no menu principal, mostrada só em serviço.
radial.add({
  id: "police",
  label: Locale("RADIAL_POLICE"),
  icon: "shield-halved",
  canShow: () => getPlayerData("duty") === "police",
  items: [
    { id: "police_cuff", label: Locale("RADIAL_CUFF"), icon: "handcuffs", onPressed: () => emit("myscript:cuffNearest") },
  ],
});

// Um item dentro da categoria de veículo embutida.
radial.add({
  id: "myscript_windows",
  label: Locale("RADIAL_WINDOWS"),
  icon: "car-side",
  parent: RADIAL_VEHICLE,
  keepOpen: true,
  onPressed: () => notify(Locale("WINDOWS_TOGGLED"), "info"),
});

// O serviço mudou: lê de novo todos os canShow de um menu aberto.
onPlayerData("duty", () => radial.refresh());
```
</Tab>

<Callout type="warn">
Adicione seus itens uma vez, quando seu recurso inicia. Não os adicione de novo quando o menu radial reinicia: o AI Core faz isso por você. `canShow` roda a cada abertura, então mantenha-o leve (leia dados em cache, sem chamadas ao servidor).
</Callout>

### radial.remove

Remove um dos seus itens pelo id. **Lado:** Cliente · **Espera:** não.

```ts title="Signature"
radial.remove(id: string): void
```

```lua title="Lua"
aiLib.radial.remove('myscript_windows')
```

### radial.refresh

Lê de novo todos os `canShow` de um menu aberto. Chame depois que os dados que o seu `canShow` lê mudaram enquanto o menu pode estar aberto. **Lado:** Cliente · **Espera:** não.

```ts title="Signature"
radial.refresh(): void
```

```lua title="Lua"
aiLib.radial.refresh()
```

## Exports do cliente do próprio ai-radialmenu

A camada radial do AI Core chama estes. Eles são tipados como `AiRadialClientExports` em `@aifivem/shared`.

| Export | O que faz |
| --- | --- |
| `AddItem(item: RadialItem & { onSelect?: () => void }): void` | Adiciona ou substitui um item do recurso que chama. `onSelect` é aceito como nome antigo de `onPressed`. `parent` o coloca em um submenu. |
| `RemoveItem(id: string, parent?: string): void` | Remove um item (de dentro de `parent` quando informado). |
| `Refresh(): void` | Lê de novo todos os `canShow` de um menu aberto. |

Os itens, submenus e estados de item de um recurso são removidos quando esse recurso para.

## APIs que ele responde

O ai-radialmenu faz `provide` de dois outros menus, então os nomes de exports deles chegam a ele:

- **qb-radialmenu**: `AddOption(data, id?)` retorna o id com que o item é guardado; `RemoveOption(id)`. Campos do item `title`, `icon` (`fas fa-x` é aceito), `items`, `action` (uma função) ou `type` + `event` (`client`, `server`, `command`, `qbcommand`), `shouldClose = false` mantém o menu aberto.
- **tgiann-radialmenu-target**: `AddMenuItem(item | items, parentId?)`, `RemoveMenuItem(id, parentId?)`, `ClearMenuItems()`, `RegisterSubMenu({ id, items })`, `RefreshMenu()`, `DisableMenu(state)`, `IsMenuDisabled()`, `OpenMenu()`, `CloseMenu()`, `IsMenuOpen()`, `HasMenuItem(id)`, `SetMenuItemHidden(id, state)`, `IsMenuItemHidden(id)`, `UpdateMenuItem(id, { label?, icon? })`, `ResetMenuItem(id)`. Campos do item `label` (um texto, ou `{ en, tr }` escolhido pela convar `ai:locale`), `canInteract(args)`, `onSelect(args)`, `event` + `type` + `args`, `command`, `export { resource, name, args }`, `menu`, `shouldClose`, `whileDead`.

Não respondidos: o `GetCurrentMenuId` do tgiann-radialmenu-target, suas configurações e exports do servidor, e seus eventos locais (`menuOpened`, `itemSelected`). A API de target dele é respondida pelo [ai-target](/pt/docs/scripts/essentials/ai-target).

## Eventos

Nenhum para outros scripts. As mensagens NUI do menu (`open`, `update`, `close`) e os callbacks (`select`, `close`) são internos.
