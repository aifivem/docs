ai-radialmenu est le menu rond qui s’ouvre sur **F3**. Il contient quelques actions intégrées et chaque entrée qu’ajoutent les autres scripts : le menu police pour les agents, le temps de prison pour les détenus, les actions de véhicule en conduisant, et ainsi de suite. Chaque entrée ne s’affiche que lorsqu’elle a du sens (en service, dans un véhicule, en tenant un objet).

## Ce qu’il fait en jeu

- **Entrées intégrées.** **Inventory** (ouvre l’inventaire), **HUD settings** (ouvre les réglages propres au HUD qui tourne, affiché uniquement quand le HUD a un menu de réglages), **Keys** (l’écran des touches d’AI Core : un clavier avec chaque touche qui fait quelque chose et les assignations propres au joueur), et une catégorie **Vehicle** dans un véhicule.
- **Catégorie véhicule.** **Engine on / off**, **Trunk** et **Hood** pour le conducteur. L’entrée moteur ne démarre jamais une voiture dont le joueur n’a pas la clé. Les autres scripts ajoutent ici leurs propres entrées de véhicule (clés, sièges, portières).
- **Entrées d’autres scripts.** Ajoutées et retirées en direct, et disparues quand ce script s’arrête.
- **Sous-menus.** Une catégorie ouvre sa propre roue. Survoler une catégorie affiche ses entrées sous forme de petites icônes autour d’elle.
- **Pages.** Dix entrées par page. Les touches **1** à **9** et **0** choisissent une entrée ; les flèches, la molette ou le sélecteur de pages changent de page.
- **Revenir en arrière.** **Retour arrière** ou un clic droit revient d’un niveau ; le bouton central revient en arrière ou ferme ; **Échap**, la touche d’ouverture à nouveau, ou un clic en dehors des cartes le ferme.
- **À terre.** Quand le joueur est mort ou à terre, seules les entrées prévues pour cet état s’affichent. S’il n’y en a aucune, la roue ne s’ouvre pas.

## Installation

La recipe txAdmin d’AI Core l’installe. À la main : placez le dossier dans `resources/[ai]/` et ajoutez `ensure ai-radialmenu` à `server.cfg` après `ensure ai-core`. Il nécessite OneSync et ai-core. Il n’a pas de table de base de données.

Ne faites pas tourner qb-radialmenu ou tgiann-radialmenu-target à côté : les deux roues se disputeraient la touche. AI Core les signale dans la console et refuse les joueurs tant que les deux tournent.

## Réglages du panneau

Aucun. ai-radialmenu n’a pas d’onglet dans le panneau d’administration : les entrées viennent des scripts, et la touche se règle dans l’onglet **Keybinds**.

## Commandes

Aucune.

## Raccourcis clavier

| Touche par défaut | Ce qu’elle fait | Nom dans les réglages de GTA |
| --- | --- | --- |
| F3 | Ouvre le menu radial (appuyer à nouveau pour fermer) | Open the radial menu |

La touche s’affiche aussi dans les aides de touches du HUD sous le nom « Menu ». Changez la valeur par défaut pour tout le monde dans l’onglet **Keybinds** du panneau ; chaque joueur peut changer la sienne dans les réglages des touches de GTA.

## Fonctionne avec d’autres scripts

- **qb-radialmenu** (`provide`) : les scripts qui appellent `exports['qb-radialmenu']:AddOption(...)` / `RemoveOption(...)` ajoutent leurs entrées à cette roue.
- **tgiann-radialmenu-target** (`provide`) : ses exports de menu client (`AddMenuItem`, `RegisterSubMenu`, `DisableMenu`, ...) fonctionnent sur cette roue.
- **Le radial d’ox_lib** ne peut pas être pris en charge : les entrées des scripts écrits pour `lib.addRadialItem` s’affichent dans la roue propre à ox_lib (touche Z par défaut) si ox_lib tourne.
- **Vous pouvez le remplacer.** Tous les scripts `ai-*` ajoutent leurs entrées via AI Core, qui les remet au premier menu radial qui tourne : ai-radialmenu, tgiann-radialmenu-target, qb-radialmenu, tgiann-radialmenu, codem-supreme-radialmenu ou ox_lib. Avec une autre roue, certaines fonctionnalités manquent (par exemple qb-radialmenu n’a pas de conditions, donc une entrée s’affiche toujours). Voir [Compatibilité](/fr/docs/compatibility).

## Limites connues

- Une entrée indisponible au moment où elle est choisie (le joueur a quitté le véhicule, a quitté son service) est refusée avec « That is not available right now ».
- Les entrées de qb-radialmenu n’ont pas de conditions propres : elles s’affichent toujours.
- Le `ClearMenuItems` de tgiann-radialmenu-target n’efface ici que les entrées du script appelant (l’original efface celles de tout le monde).
