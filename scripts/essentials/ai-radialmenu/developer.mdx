<Callout type="info">
Add your items through AI Core, not through ai-radialmenu: lib `radial.add(item)` in TypeScript or `aiLib.radial.add(item)` in Lua. AI Core keeps the items, hands them to whichever radial menu the server runs, gives them again to a radial that restarts, and drops them when your resource stops. Calling ai-radialmenu directly ties your script to one wheel.
</Callout>

## Adding an item (recommended way)

### radial.add

Adds an item to the wheel, or replaces the item with the same `id`.

**Side:** Client · **Waits:** no

```ts title="Signature"
radial.add(item: RadialItem): void
```

```lua title="Lua"
aiLib.radial.add(item)
```

#### Parameters

<TypeTable
  type={{
    item: { type: 'RadialItem', description: 'The item. Fields below.', required: true },
  }}
/>

#### RadialItem

<TypeTable
  type={{
    id: { type: 'string', description: 'Unique id. Adding the same id again replaces the item.', required: true },
    label: { type: 'string', description: 'Text on the card, already translated (`Locale("...")`).', required: true },
    icon: { type: 'string', description: 'A Font Awesome solid icon name without `fa-` (`car`, `key`, `handcuffs`), or an image url.' },
    parent: { type: 'string', description: 'The item this one goes into: `"vehicle"` (`RADIAL_VEHICLE` from `@aifivem/shared`, the built-in vehicle category) or the id of another item. Left out: the main wheel.' },
    items: { type: 'RadialItem[]', description: 'Sub items. The card then opens a sub wheel instead of running `onPressed`. A category with no visible sub item hides itself.' },
    canShow: { type: '() => boolean', description: 'The item shows only while this returns true. Read each time the wheel opens and on `radial.refresh()`. A function that throws hides the item.' },
    onPressed: { type: '() => void', description: 'Runs in your resource when the player picks the item. The wheel checks `canShow` again first and refuses with a notification when it no longer holds.' },
    keepOpen: { type: 'boolean', description: 'Keeps the wheel open after the press and refreshes it (doors, extras).', default: 'false' },
    whileDead: { type: 'boolean', description: 'Keeps the item while the player is down. Every other item hides then.', default: 'false' },
  }}
/>

#### Returns

Nothing.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { radial, notify, onPlayerData, getPlayerData } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import Locale from "common/locale";

// A police category on the main wheel, shown only on duty.
radial.add({
  id: "police",
  label: Locale("RADIAL_POLICE"),
  icon: "shield-halved",
  canShow: () => getPlayerData("duty") === "police",
  items: [
    { id: "police_cuff", label: Locale("RADIAL_CUFF"), icon: "handcuffs", onPressed: () => emit("myscript:cuffNearest") },
  ],
});

// An item inside the built-in vehicle category.
radial.add({
  id: "myscript_windows",
  label: Locale("RADIAL_WINDOWS"),
  icon: "car-side",
  parent: RADIAL_VEHICLE,
  keepOpen: true,
  onPressed: () => notify(Locale("WINDOWS_TOGGLED"), "info"),
});

// Duty changed: read every canShow of an open wheel again.
onPlayerData("duty", () => radial.refresh());
```
</Tab>
<Tab value="Lua">
```lua
-- fxmanifest.lua: shared_script '@ai-lib/init.lua'

local L = aiLib.locale()

local function onDutyPolice()
    return aiLib.playerData.get('duty') == 'police'
end

aiLib.radial.add({
    id = 'police',
    label = L('RADIAL_POLICE'),
    icon = 'shield-halved',
    canShow = onDutyPolice,
    items = {
        { id = 'police_cuff', label = L('RADIAL_CUFF'), icon = 'handcuffs',
          onPressed = function() TriggerEvent('myscript:cuffNearest') end },
    },
})

aiLib.radial.add({
    id = 'myscript_windows',
    label = L('RADIAL_WINDOWS'),
    icon = 'car-side',
    parent = 'vehicle',
    keepOpen = true,
    onPressed = function() aiLib.notify(L('WINDOWS_TOGGLED'), 'info') end,
})

aiLib.playerData.onChange('duty', function() aiLib.radial.refresh() end)
```
</Tab>
</Tabs>

<Callout type="warn">
Add your items once, when your resource starts. Do not add them again when the radial menu restarts: AI Core does that for you. `canShow` runs on every open, so keep it cheap (read cached data, no server calls).
</Callout>

### radial.remove

Removes one of your items by id. **Side:** Client · **Waits:** no.

```ts title="Signature"
radial.remove(id: string): void
```

```lua title="Lua"
aiLib.radial.remove('myscript_windows')
```

### radial.refresh

Reads every `canShow` of an open wheel again. Call it after the data your `canShow` reads has changed while the wheel may be open. **Side:** Client · **Waits:** no.

```ts title="Signature"
radial.refresh(): void
```

```lua title="Lua"
aiLib.radial.refresh()
```

## ai-radialmenu's own client exports

AI Core's radial layer calls these. They are typed `AiRadialClientExports` in `@aifivem/shared`.

| Export | What it does |
| --- | --- |
| `AddItem(item: RadialItem & { onSelect?: () => void }): void` | Adds or replaces an item owned by the calling resource. `onSelect` is accepted as an older name of `onPressed`. `parent` puts it into a sub menu. |
| `RemoveItem(id: string, parent?: string): void` | Removes an item (from under `parent` when given). |
| `Refresh(): void` | Reads every `canShow` of an open wheel again. |

Items, sub menus and item states of a resource are removed when that resource stops.

## APIs it answers

ai-radialmenu `provide`s two other wheels, so their export names reach it:

- **qb-radialmenu**: `AddOption(data, id?)` returns the id the item is kept under; `RemoveOption(id)`. Item fields `title`, `icon` (`fas fa-x` accepted), `items`, `action` (a function) or `type` + `event` (`client`, `server`, `command`, `qbcommand`), `shouldClose = false` keeps the wheel open.
- **tgiann-radialmenu-target**: `AddMenuItem(item | items, parentId?)`, `RemoveMenuItem(id, parentId?)`, `ClearMenuItems()`, `RegisterSubMenu({ id, items })`, `RefreshMenu()`, `DisableMenu(state)`, `IsMenuDisabled()`, `OpenMenu()`, `CloseMenu()`, `IsMenuOpen()`, `HasMenuItem(id)`, `SetMenuItemHidden(id, state)`, `IsMenuItemHidden(id)`, `UpdateMenuItem(id, { label?, icon? })`, `ResetMenuItem(id)`. Item fields `label` (a text, or `{ en, tr }` picked by the `ai:locale` convar), `canInteract(args)`, `onSelect(args)`, `event` + `type` + `args`, `command`, `export { resource, name, args }`, `menu`, `shouldClose`, `whileDead`.

Not answered: tgiann-radialmenu-target's `GetCurrentMenuId`, its settings and server exports, and its local events (`menuOpened`, `itemSelected`). Its target API is answered by [ai-target](/docs/scripts/essentials/ai-target).

## Events

None for other scripts. The wheel's NUI messages (`open`, `update`, `close`) and callbacks (`select`, `close`) are internal.
