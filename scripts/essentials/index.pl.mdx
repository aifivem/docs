To skrypty, których serwer roleplay używa od pierwszego dnia. [ai-core](/pl/docs/scripts/essentials/ai-core) jest wymagany: potrzebuje go każdy inny skrypt `ai-*`. [ai-mysql](/pl/docs/scripts/essentials/ai-mysql) i [ai-lib](/pl/docs/scripts/essentials/ai-lib) są potrzebne prawie wszystkiemu. Każdy z pozostałych można zastąpić skryptem zewnętrznym tego samego rodzaju (innym ekwipunkiem, HUD-em, skryptem głosu lub ubrań), bo inne skrypty docierają do nich przez AI Core.

| Skrypt | Co robi | Zastępuje |
| --- | --- | --- |
| [ai-core](/pl/docs/scripts/essentials/ai-core) | Framework: gracze, postacie, ekran postaci, pieniądze, prace i gangi, uprawnienia, panel administratora i most frameworków. | es_extended, qb-core, qbx_core, vrp, zasoby UI ESX i QB |
| [ai-mysql](/pl/docs/scripts/essentials/ai-mysql) | Silnik bazy danych dla skryptów zewnętrznych. | oxmysql, mysql-async, ghmattimysql |
| [ai-lib](/pl/docs/scripts/essentials/ai-lib) | Powiadomienia, pasek postępu, podpowiedzi, menu, okna wprowadzania i minigry dla każdego skryptu; funkcje pomocnicze AI Core dla zasobów Lua i JavaScript. | |
| [ai-loading](/pl/docs/scripts/essentials/ai-loading) | Ekran ładowania. | |
| [ai-appearance](/pl/docs/scripts/essentials/ai-appearance) | Kreator postaci, sklepy z ubraniami i fryzjerzy. | |
| [ai-inventory](/pl/docs/scripts/essentials/ai-inventory) | Ekwipunek z siatką, przedmioty na ziemi, schowki, bagażniki, sklepy, wytwarzanie, broń. | ox_inventory, qb-inventory |
| [ai-hud](/pl/docs/scripts/essentials/ai-hud) | HUD i potrzeby (głód, pragnienie, stres). | |
| [ai-chat](/pl/docs/scripts/essentials/ai-chat) | Czat z kanałami i podpowiedziami komend. | chat |
| [ai-voice](/pl/docs/scripts/essentials/ai-voice) | Głos zbliżeniowy, radio i rozmowy telefoniczne. | pma-voice, mumble-voip, tokovoip |
| [ai-radialmenu](/pl/docs/scripts/essentials/ai-radialmenu) | Menu radialne (F3). | qb-radialmenu, tgiann-radialmenu-target |
| [ai-target](/pl/docs/scripts/essentials/ai-target) | Oko targetu. | ox_target |
| [ai-scoreboard](/pl/docs/scripts/essentials/ai-scoreboard) | Gracze online i liczby osób na służbie (Home). | |
| [ai-weathersync](/pl/docs/scripts/essentials/ai-weathersync) | Czas i pogoda, takie same dla wszystkich. | qb-weathersync |

## Kolejność uruchamiania

`server.cfg` uruchamia je w tej kolejności (przepis robi to za ciebie): `ai-mysql`, potem `ai-core`, potem pozostałe. Skrypt, który „zastępuje” inny, liczy się jako ten skrypt dla każdego innego zasobu: nie instaluj obok niego oryginału.
