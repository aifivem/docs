<Callout type="info">
Não chame o ai-appearance nem leia a tabela dele a partir do seu script. Use a camada de aparência do AI Core: o `appearance` da lib (servidor `appearance.get(charId)`, cliente `appearance.apply(ped, look)`, `appearance.read(ped)`, `appearance.openMenu(...)`, `appearance.wearOutfit(outfit)`, `appearance.reloadSkin()`), ou `aiLib.appearance` em Lua. Ela funciona com todo script de roupas que o AI Core suporta, então o dono pode substituir o ai-appearance. Veja a [referência da lib](/pt/docs/developers/api/lib-client).
</Callout>

## Exports do cliente

Tipados como `AiAppearanceClientExports` em `@aifivem/shared`. O adaptador de aparência do AI Core os chama.

### ApplyAppearance

Coloca uma aparência do ai-appearance em um ped.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
ApplyAppearance(ped: number, appearance: unknown): boolean
```

```lua title="Lua"
local ok = exports['ai-appearance']:ApplyAppearance(ped, look)
```

#### Parâmetros

<TypeTable
  type={{
    ped: { type: 'number', description: 'Handle do ped. Ele já precisa ter o modelo da aparência (crie-o com esse modelo antes).', required: true },
    appearance: { type: 'Appearance', description: 'O JSON de aparência próprio do ai-appearance (`version: 1`), como guardado em `ai_appearance_characters.data`. Trate-o como opaco.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando a aparência foi aplicada. `false` quando a aparência é inválida ou o modelo do ped não é o modelo da aparência.

### GetPedAppearance

Lê a aparência que o jogador local está usando.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
GetPedAppearance(ped: number): unknown
```

#### Retorno

A `Appearance` do jogador local, ou `null` para qualquer outro ped.

### WearOutfit

Coloca uma roupa de emprego (uniforme) no jogador local. Só as peças listadas mudam, e a roupa nunca é salva como a aparência própria do jogador.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
WearOutfit(outfit: JobOutfit): void
```

```lua title="Lua"
exports['ai-appearance']:WearOutfit({ components = { { id = 11, collection = '', index = 55, texture = 0 } }, props = {} })
```

#### JobOutfit

<TypeTable
  type={{
    components: { type: 'OutfitPiece[]', description: 'Componentes de roupa (ids de componente do GTA 0-11: 4 pernas, 6 sapatos, 8 camiseta de baixo, 11 tronco...).', required: true },
    props: { type: 'OutfitPiece[]', description: 'Props (ids de prop do GTA: 0 chapéu, 1 óculos, 2 orelhas, 6 relógio, 7 pulseira).', required: true },
  }}
/>

#### OutfitPiece

<TypeTable
  type={{
    id: { type: 'number', description: 'O id do componente ou do prop.', required: true },
    collection: { type: 'string', description: 'O nome da coleção de roupas; `""` para o jogo base.', required: true },
    index: { type: 'number', description: 'O índice do drawable dentro daquela coleção (0-1023). Para um prop, -1 o tira.', required: true },
    texture: { type: 'number', description: 'A textura (variante de cor) do drawable.', required: true },
  }}
/>

#### Retorno

Nada.

### ReloadSkin

Coloca a aparência salva de volta no jogador local (tira uma roupa de emprego). **Lado:** Cliente · **Espera:** não.

```ts title="Signature"
ReloadSkin(): void
```

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance } from "@aifivem/lib/client";
import type { JobOutfit } from "@aifivem/shared";

// Pelo AI Core: funciona com o ai-appearance e os outros scripts de roupas suportados.
const uniform: JobOutfit = {
  components: [
    { id: 11, collection: "", index: 55, texture: 0 },
    { id: 4, collection: "", index: 35, texture: 0 },
  ],
  props: [{ id: 0, collection: "", index: 46, texture: 0 }],
};

RegisterCommand("uniform", () => appearance.wearOutfit(uniform), false);
RegisterCommand("ownclothes", () => appearance.reloadSkin(), false);
```
</Tab>
<Tab value="Lua">
```lua
-- fxmanifest.lua: shared_script '@ai-lib/init.lua'
local uniform = {
    components = {
        { id = 11, collection = '', index = 55, texture = 0 },
        { id = 4, collection = '', index = 35, texture = 0 },
    },
    props = { { id = 0, collection = '', index = 46, texture = 0 } },
}

RegisterCommand('uniform', function() aiLib.appearance.wearOutfit(uniform) end, false)
RegisterCommand('ownclothes', function() aiLib.appearance.reloadSkin() end, false)
```
</Tab>
</Tabs>

<Callout type="warn">
As peças de roupa são endereçadas pelo nome da coleção e pelo índice dentro dela, não pelo número de drawable global do GTA. O jogo base é a coleção `""`. Pelo AI Core, `appearance.wearOutfit` e `reloadSkin` respondem `false` quando o script de roupas rodando não suporta roupas de emprego.
</Callout>

## Eventos

| Evento | Lado | Argumentos | O que é |
| --- | --- | --- | --- |
| `ai-core:client:characterPortrait` | Cliente (local) | `charId: number, url: string` | O ai-appearance envia o retrato de cada cartão (`https://nui-img/...`) para a tela de personagens do AI Core. |

O ai-appearance escuta o evento de servidor `characterScreen (src, charIds)` do AI Core para saber quais retratos fazer, e o `onCharacter` da lib para vestir um personagem carregado ou abrir o criador.

## Banco de dados

Tabela `ai_appearance_characters`: `char_id` (= `ai_core_characters.id`) e `data` (o JSON `Appearance`). Só o ai-appearance a escreve. O adaptador do AI Core a lê para `GetCharacterAppearance`.
