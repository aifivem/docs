<Callout type="info">
No llames a ai-appearance ni leas su tabla desde tu script. Usa la capa de apariencia de AI Core: `appearance` de la lib (servidor `appearance.get(charId)`, cliente `appearance.apply(ped, look)`, `appearance.read(ped)`, `appearance.openMenu(...)`, `appearance.wearOutfit(outfit)`, `appearance.reloadSkin()`), o `aiLib.appearance` en Lua. Funciona con cualquier script de ropa que AI Core soporte, así que el dueño puede reemplazar ai-appearance. Mira la [referencia de la lib](/es/docs/developers/api/lib-client).
</Callout>

## Exports de cliente

Tipados como `AiAppearanceClientExports` en `@aicore-fivem/shared`. Los llama el adaptador de apariencia de AI Core.

### ApplyAppearance

Pone un aspecto de ai-appearance en un ped.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
ApplyAppearance(ped: number, appearance: unknown): boolean
```

```lua title="Lua"
local ok = exports['ai-appearance']:ApplyAppearance(ped, look)
```

#### Parámetros

<TypeTable
  type={{
    ped: { type: 'number', description: 'Handle del ped. Ya debe tener el modelo del aspecto (créalo primero con ese modelo).', required: true },
    appearance: { type: 'Appearance', description: 'El JSON de aspecto propio de ai-appearance (`version: 1`), tal como se guarda en `ai_appearance_characters.data`. Trátalo como opaco.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando se aplicó el aspecto. `false` cuando el aspecto no es válido o el modelo del ped no es el modelo del aspecto.

### GetPedAppearance

Lee el aspecto que lleva el jugador local.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
GetPedAppearance(ped: number): unknown
```

#### Devuelve

El `Appearance` del jugador local, o `null` para cualquier otro ped.

### WearOutfit

Pone un uniforme de trabajo al jugador local. Solo cambian las piezas indicadas, y el uniforme nunca se guarda como aspecto propio del jugador.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
WearOutfit(outfit: JobOutfit): void
```

```lua title="Lua"
exports['ai-appearance']:WearOutfit({ components = { { id = 11, collection = '', index = 55, texture = 0 } }, props = {} })
```

#### JobOutfit

<TypeTable
  type={{

    props: { type: 'OutfitPiece[]', description: 'Props (ids de prop de GTA: 0 sombrero, 1 gafas, 2 orejas, 6 reloj, 7 pulsera).', required: true },
  }}
/>

#### OutfitPiece

<TypeTable
  type={{
    id: { type: 'number', description: 'El id del componente o del prop.', required: true },
    collection: { type: 'string', description: 'El nombre de la colección de ropa; `""` para el juego base.', required: true },
    index: { type: 'number', description: 'El índice del drawable dentro de esa colección (0-1023). Para un prop, -1 lo quita.', required: true },
    texture: { type: 'number', description: 'La textura (variante de color) del drawable.', required: true },
  }}
/>

#### Devuelve

Nada.

### ReloadSkin

Vuelve a poner el aspecto guardado al jugador local (quita un uniforme de trabajo). **Lado:** Cliente · **Espera:** no.

```ts title="Firma"
ReloadSkin(): void
```

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance } from "@aicore-fivem/lib/client";
import type { JobOutfit } from "@aicore-fivem/shared";

// A través de AI Core: funciona con ai-appearance y con los demás scripts de ropa soportados.
const uniform: JobOutfit = {
  components: [
    { id: 11, collection: "", index: 55, texture: 0 },
    { id: 4, collection: "", index: 35, texture: 0 },
  ],
  props: [{ id: 0, collection: "", index: 46, texture: 0 }],
};

RegisterCommand("uniform", () => appearance.wearOutfit(uniform), false);
RegisterCommand("ownclothes", () => appearance.reloadSkin(), false);
```
</Tab>
<Tab value="Lua">
```lua
-- fxmanifest.lua: shared_script '@ai-lib/init.lua'
local uniform = {
    components = {
        { id = 11, collection = '', index = 55, texture = 0 },
        { id = 4, collection = '', index = 35, texture = 0 },
    },
    props = { { id = 0, collection = '', index = 46, texture = 0 } },
}

RegisterCommand('uniform', function() aiLib.appearance.wearOutfit(uniform) end, false)
RegisterCommand('ownclothes', function() aiLib.appearance.reloadSkin() end, false)
```
</Tab>
</Tabs>

<Callout type="warn">
Las piezas del uniforme se indican por nombre de colección y el índice dentro de ella, no por el número de drawable global de GTA. El juego base es la colección `""`. A través de AI Core, `appearance.wearOutfit` y `reloadSkin` responden `false` cuando el script de ropa en uso no soporta uniformes de trabajo.
</Callout>

## Eventos

| Evento | Lado | Argumentos | Qué es |
| --- | --- | --- | --- |
| `ai-core:client:characterPortrait` | Cliente (local) | `charId: number, url: string` | ai-appearance envía el retrato de cada tarjeta (`https://nui-img/...`) a la pantalla de personajes de AI Core. |

ai-appearance escucha el evento de servidor de AI Core `characterScreen (src, charIds)` para saber qué retratos hacer, y `onCharacter` de la lib para vestir a un personaje cargado o abrir el creador.

## Base de datos

Tabla `ai_appearance_characters`: `char_id` (= `ai_core_characters.id`) y `data` (el JSON de `Appearance`). Solo ai-appearance la escribe. El adaptador de AI Core la lee para `GetCharacterAppearance`.
