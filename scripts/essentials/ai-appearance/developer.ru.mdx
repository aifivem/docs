<Callout type="info">
Не вызывайте ai-appearance и не читайте его таблицу из своего скрипта. Используйте слой внешности AI Core: `appearance` из lib (на сервере `appearance.get(charId)`, на клиенте `appearance.apply(ped, look)`, `appearance.read(ped)`, `appearance.openMenu(...)`, `appearance.wearOutfit(outfit)`, `appearance.reloadSkin()`) или `aiLib.appearance` в Lua. Он работает с каждым скриптом одежды, который поддерживает AI Core, поэтому владелец может заменить ai-appearance. См. [справочник lib](/ru/docs/developers/api/lib-client).
</Callout>

## Клиентские экспорты

Типизированы как `AiAppearanceClientExports` в `@aicore-fivem/shared`. Их вызывает адаптер внешности AI Core.

### ApplyAppearance

Надевает внешность ai-appearance на педа.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
ApplyAppearance(ped: number, appearance: unknown): boolean
```

```lua title="Lua"
local ok = exports['ai-appearance']:ApplyAppearance(ped, look)
```

#### Параметры

<TypeTable
  type={{
    ped: { type: 'number', description: 'Хэндл педа. У него уже должна быть модель этой внешности (сначала создайте его с этой моделью).', required: true },
    appearance: { type: 'Appearance', description: 'Собственный JSON внешности ai-appearance (`version: 1`), как он хранится в `ai_appearance_characters.data`. Считайте его непрозрачным.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, если внешность применена. `false`, если внешность неверна или модель педа не совпадает с моделью внешности.

### GetPedAppearance

Читает внешность, которую носит локальный игрок.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
GetPedAppearance(ped: number): unknown
```

#### Возвращает

`Appearance` локального игрока или `null` для любого другого педа.

### WearOutfit

Надевает на локального игрока рабочую форму (униформу). Меняются только перечисленные части, и форма никогда не сохраняется как собственная внешность игрока.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
WearOutfit(outfit: JobOutfit): void
```

```lua title="Lua"
exports['ai-appearance']:WearOutfit({ components = { { id = 11, collection = '', index = 55, texture = 0 } }, props = {} })
```

### ReloadSkin

Возвращает на локального игрока сохранённую внешность (снимает рабочую форму). **Сторона:** клиент · **Ожидание:** нет.

```ts title="Сигнатура"
ReloadSkin(): void
```

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance } from "@aicore-fivem/lib/client";
import type { JobOutfit } from "@aicore-fivem/shared";

// Через AI Core: работает с ai-appearance и другими поддерживаемыми скриптами одежды.
const uniform: JobOutfit = {
  components: [
    { id: 11, collection: "", index: 55, texture: 0 },
    { id: 4, collection: "", index: 35, texture: 0 },
  ],
  props: [{ id: 0, collection: "", index: 46, texture: 0 }],
};

RegisterCommand("uniform", () => appearance.wearOutfit(uniform), false);
RegisterCommand("ownclothes", () => appearance.reloadSkin(), false);
```
</Tab>
<Tab value="Lua">
```lua
-- fxmanifest.lua: shared_script '@ai-lib/init.lua'
local uniform = {
    components = {
        { id = 11, collection = '', index = 55, texture = 0 },
        { id = 4, collection = '', index = 35, texture = 0 },
    },
    props = { { id = 0, collection = '', index = 46, texture = 0 } },
}

RegisterCommand('uniform', function() aiLib.appearance.wearOutfit(uniform) end, false)
RegisterCommand('ownclothes', function() aiLib.appearance.reloadSkin() end, false)
```
</Tab>
</Tabs>

<Callout type="warn">
Части формы задаются названием коллекции и индексом внутри неё, а не глобальным номером drawable в GTA. Базовая игра имеет коллекцию `""`. Через AI Core `appearance.wearOutfit` и `reloadSkin` отвечают `false`, когда запущенный скрипт одежды не поддерживает рабочие формы.
</Callout>

## События

| Событие | Сторона | Аргументы | Что это |
| --- | --- | --- | --- |
| `ai-core:client:characterPortrait` | Клиент (локальное) | `charId: number, url: string` | ai-appearance отправляет портрет каждой карточки (`https://nui-img/...`) на экран персонажей AI Core. |

ai-appearance слушает серверное событие AI Core `characterScreen (src, charIds)`, чтобы знать, какие портреты делать, и `onCharacter` из lib, чтобы одеть загруженного персонажа или запустить редактор.

## База данных

Таблица `ai_appearance_characters`: `char_id` (= `ai_core_characters.id`) и `data` (JSON `Appearance`). Пишет в неё только ai-appearance. Адаптер AI Core читает её для `GetCharacterAppearance`.
