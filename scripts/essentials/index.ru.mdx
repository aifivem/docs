Это скрипты, которые ролевой сервер запускает с первого дня. [ai-core](/ru/docs/scripts/essentials/ai-core) обязателен: он нужен каждому другому скрипту `ai-*`. [ai-mysql](/ru/docs/scripts/essentials/ai-mysql) и [ai-lib](/ru/docs/scripts/essentials/ai-lib) нужны почти всему. Каждый из остальных можно заменить сторонним скриптом того же типа (другим инвентарём, HUD, голосом или скриптом одежды), потому что остальные скрипты обращаются к ним через AI Core.

| Скрипт | Что делает | Заменяет |
| --- | --- | --- |
| [ai-core](/ru/docs/scripts/essentials/ai-core) | Фреймворк: игроки, персонажи, экран персонажей, деньги, работы и банды, права, админ-панель и мост фреймворков. | es_extended, qb-core, qbx_core, vrp, ресурсы интерфейса ESX и QB |
| [ai-mysql](/ru/docs/scripts/essentials/ai-mysql) | Движок базы данных для сторонних скриптов. | oxmysql, mysql-async, ghmattimysql |
| [ai-lib](/ru/docs/scripts/essentials/ai-lib) | Уведомления, полоса прогресса, подсказки, меню, диалоги ввода и мини-игры для каждого скрипта; вспомогательные функции AI Core для ресурсов на Lua и JavaScript. | |
| [ai-loading](/ru/docs/scripts/essentials/ai-loading) | Экран загрузки. | |
| [ai-appearance](/ru/docs/scripts/essentials/ai-appearance) | Редактор персонажа, магазины одежды и парикмахерские. | |
| [ai-inventory](/ru/docs/scripts/essentials/ai-inventory) | Инвентарь-сетка, предметы на земле, тайники, багажники, магазины, крафт, оружие. | ox_inventory, qb-inventory |
| [ai-hud](/ru/docs/scripts/essentials/ai-hud) | HUD и потребности (голод, жажда, стресс). | |
| [ai-chat](/ru/docs/scripts/essentials/ai-chat) | Чат с каналами и подсказками команд. | chat |
| [ai-voice](/ru/docs/scripts/essentials/ai-voice) | Голос по близости, рация и телефонные звонки. | pma-voice, mumble-voip, tokovoip |
| [ai-radialmenu](/ru/docs/scripts/essentials/ai-radialmenu) | Радиальное меню (F3). | qb-radialmenu, tgiann-radialmenu-target |
| [ai-target](/ru/docs/scripts/essentials/ai-target) | Глаз взаимодействия (target). | ox_target |
| [ai-scoreboard](/ru/docs/scripts/essentials/ai-scoreboard) | Игроки онлайн и число людей на дежурстве (Home). | |
| [ai-weathersync](/ru/docs/scripts/essentials/ai-weathersync) | Время и погода, одинаковые для всех. | qb-weathersync |

## Порядок запуска

`server.cfg` запускает их в таком порядке (рецепт делает это за вас): `ai-mysql`, затем `ai-core`, затем остальные. Скрипт, который «заменяет» другой, считается этим скриптом для всех остальных ресурсов: не устанавливайте оригинал рядом с ним.
