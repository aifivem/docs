<Callout type="info">
Для своих мест, NPC и опций на моделях используйте точки взаимодействия AI Core: `Points` из lib в TypeScript или `aiLib.Points` в Lua (см. [справочник lib](/ru/docs/developers/api/lib-client)). Точка показывается как подсказка или как маркер target, как выбрал владелец, на любом запущенном скрипте target, и в обоих случаях выполняется тот же `onPressed`. Вызывайте API ниже, только когда переносите скрипт, написанный для ox_target.
</Callout>

## Экспорты

Каждый экспорт **клиентский**, отвечает и под `exports['ai-target']`, и под `exports.ox_target` (ai-target делает `provide` для ox_target) и не ждёт. Опции принадлежат ресурсу, который их добавил, и удаляются, когда он останавливается.

### TargetOption

Формат опции, который принимает каждый экспорт `add*`, одна опция или список. Опция без `label` пропускается.

### addBoxZone

Добавляет зону в форме параллелепипеда с опциями. `addSphereZone` и `addPolyZone` работают так же с другими формами.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
addBoxZone(data: { coords: Vec3; size?: Vec3; rotation?: number; name?: string; options: TargetOption | TargetOption[] }): number
addSphereZone(data: { coords: Vec3; radius?: number; name?: string; options: TargetOption | TargetOption[] }): number
addPolyZone(data: { points: Vec3[]; thickness?: number; name?: string; options: TargetOption | TargetOption[] }): number
```

```lua title="Lua"
local id = exports.ox_target:addBoxZone({ coords = vec3(x, y, z), size = vec3(2, 2, 2), rotation = 0, options = { ... } })
```

#### Параметры

<TypeTable
  type={{

    size: { type: 'Vec3', description: 'Размер параллелепипеда в метрах (только box).', default: '{ x: 2, y: 2, z: 2 }' },
    rotation: { type: 'number', description: 'Направление параллелепипеда в градусах (только box).', default: '0' },
    radius: { type: 'number', description: 'Радиус сферы в метрах (только sphere).', default: '2' },
    points: { type: 'Vec3[]', description: 'Углы многоугольника, не меньше 3 (только poly). Высота равна среднему их `z`.', required: true },
    thickness: { type: 'number', description: 'Высота многоугольника в метрах с центром на среднем `z` (только poly).', default: '4' },

    options: { type: 'TargetOption | TargetOption[]', description: 'Опции на зоне.', required: true },
  }}
/>

#### Возвращает

`number`: id зоны. `0`, если координаты отсутствуют или некорректны (в лог пишется предупреждение).

  if (name === GetCurrentResourceName()) callExport("ox_target", "removeZone", zone);
});

<Callout type="info">
Зоны ресурса удаляются, когда этот ресурс останавливается, поэтому обработчик остановки выше необязателен. Удаляйте зону сами, когда место исчезает, а ваш ресурс продолжает работать.
</Callout>

### removeZone

Удаляет зону. **Сторона:** клиент · **Ожидание:** нет.

```ts title="Сигнатура"
removeZone(id: number | string): void
```

`id` является номером, который вернул `add*Zone`, или `name` зоны.

### zoneExists

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
zoneExists(id: number | string): boolean
```

Возвращает `true`, пока существует зона с этим номером или именем.

### addModel

Ставит опции на каждую сущность этих моделей (двери модели, банкоматы, мусорные контейнеры).

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
addModel(models: string | number | Array<string | number>, options: TargetOption | TargetOption[]): void
removeModel(models: string | number | Array<string | number>, names?: string | string[]): void
```

```lua title="Lua"
exports.ox_target:addModel({ 'prop_atm_01', 'prop_atm_02' }, { { name = 'atm', label = 'Use ATM', icon = 'credit-card', onSelect = openAtm } })
```

#### Параметры

<TypeTable
  type={{
    models: { type: 'string | number | Array<string | number>', description: 'Имена моделей или хэши.', required: true },
    options: { type: 'TargetOption | TargetOption[]', description: 'Опции, которые нужно добавить.', required: true },
    names: { type: 'string | string[]', description: 'Только `removeModel`: имена опций, которые нужно удалить. Если не указано: все опции на этих моделях.' },
  }}
/>

#### Возвращает

Ничего.

### addEntity и addLocalEntity

`addEntity` ставит опции на сетевые сущности по **network id** (транспорт или педы, созданные сервером). `addLocalEntity` ставит их на сущности по **хэндлу** (пед или проп, созданный вашим клиентом). У каждого есть двойник `remove*`, который принимает те же id и необязательные имена опций.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
addEntity(netIds: number | number[], options: TargetOption | TargetOption[]): void
removeEntity(netIds: number | number[], names?: string | string[]): void
addLocalEntity(entities: number | number[], options: TargetOption | TargetOption[]): void
removeLocalEntity(entities: number | number[], names?: string | string[]): void
```

### Глобальные опции по типу

Опции на каждом педе, транспорте, объекте или игроке.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
addGlobalPed(options: TargetOption | TargetOption[]): void
addGlobalVehicle(options: TargetOption | TargetOption[]): void
addGlobalObject(options: TargetOption | TargetOption[]): void
addGlobalPlayer(options: TargetOption | TargetOption[]): void
removeGlobalPed(names?: string | string[]): void   // и removeGlobalVehicle, removeGlobalObject, removeGlobalPlayer
```

```lua title="Lua"
exports.ox_target:addGlobalVehicle({
    { name = 'myscript_wash', label = 'Wash vehicle', icon = 'soap', distance = 2.0,
      canInteract = function(entity) return GetVehicleDirtLevel(entity) > 5.0 end,
      onSelect = function(data) TriggerServerEvent('myscript:wash', VehToNet(data.entity)) end },
})
```

<Callout type="warn">
`addGlobalOption` (опция ни на чём) не предоставляется. Он пишет предупреждение в лог и ничего не делает. Помещайте такие действия в радиальное меню (`radial` из lib).
</Callout>

### disableTargeting

Выключает маркеры (`true`) или снова включает их (`false`) для этого игрока. **Сторона:** клиент · **Ожидание:** нет.

```ts title="Сигнатура"
disableTargeting(state: boolean): void
```

### isActive

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
isActive(): boolean
```

Возвращает `true`, пока рядом с игроком есть хотя бы один маркер.

### HandleInteract

Собственный экспорт ai-target (не из ox_target). Клавиша взаимодействия AI Core спрашивает его первым: он выполняет опцию в фокусе.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
HandleInteract(): boolean
```

Возвращает `true`, если опция в фокусе была использована (или открылось её меню), `false`, если в фокусе ничего нет, и тогда клавиша переходит к подсказкам. Типизирован в `AiTargetClientExports`. Вызывать его вам не нужно.
