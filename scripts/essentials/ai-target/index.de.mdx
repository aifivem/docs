ai-target setzt kleine Marker auf die Personen, Objekte, Fahrzeuge und Orte, mit denen ein Spieler interagieren kann. Der Spieler schaut einen an, drückt die Interaktionstaste (**E**), und die Aktion läuft. Hat ein Punkt mehrere Aktionen, öffnet sich ein kleines Menü zur Auswahl.

## Was es im Spiel macht

- **Marker nahe der Kamera.** Jeder Interaktionspunkt in Reichweite zeigt einen Marker, schon kurz bevor er in Reichweite ist, sodass Spieler sehen, wo sie etwas tun können.
- **Fokus.** Der Marker, den der Spieler anschaut, ist im Fokus und zeigt seine Aktion.
- **Eine Taste.** Dieselbe Interaktionstaste wie bei den Hinweisen (**E** von ai-lib) benutzt den fokussierten Marker.
- **Mehrere Optionen.** Ein Punkt mit mehr als einer Aktion zeigt „N options“ und öffnet ein kleines Menü.
- **Job-Sperren.** Eine Option kann auf Jobs oder Gangs (und einen Mindestrang) beschränkt werden. Andere Spieler sehen sie nicht.

## Prompt oder Target: Der Betreiber entscheidet

Jedes `ai-*`-Skript erstellt seine Orte (Shops, Lager, NPCs, Türen) über die Interaktionspunkte von AI Core. Der Betreiber wählt, wie sie aussehen, für alle Skripte auf einmal, im Tab **General** von AI Core (Karte **Interaction**, **Interaction style**):

- **Prompt and key** (Standard): eine Box rechts auf dem Bildschirm und die Interaktionstaste, wenn man nah ist.
- **Target eye**: Die Punkte werden zu Target-Markern. Das braucht ein Target-Skript wie ai-target; ohne eines wird der Prompt genutzt.

Ist **Prompt and key** gewählt, läuft ai-target trotzdem, aber nur Skripte, die die API von ox_target selbst aufrufen (Drittanbieter-Skripte), setzen Marker darauf.

## Installation

Das txAdmin-Rezept von AI Core installiert es. Von Hand: Lege den Ordner in `resources/[ai]/` und füge `ensure ai-target` in der `server.cfg` nach `ensure ai-core` ein. Es braucht ai-core. Es hat keine Datenbanktabelle.

Betreibe ox_target nicht daneben (ai-target beantwortet den Namen von ox_target). Stelle dann im Tab General **Interaction style** auf **Target eye**, wenn du jedes `ai-*`-Skript darauf haben willst.

## Panel-Einstellungen

Keine eigenen. Die einzige Einstellung ist **Interaction style** von AI Core (siehe oben).

## Befehle

Keine.

## Tastenbelegungen

ai-target hat keine eigene Taste. Es nutzt die Interaktionstaste von ai-lib:

| Standardtaste | Was sie macht | Name in den GTA-Einstellungen |
| --- | --- | --- |
| E | Benutzt den fokussierten Marker (oder den Hinweis auf dem Bildschirm) | Interact with the prompt on screen |

## Zusammenspiel mit anderen Skripten

- **Ersetzt ox_target** (`provide 'ox_target'`). Skripte, die `exports.ox_target:addBoxZone(...)`, `addModel`, `addEntity`, `addGlobalVehicle` und die anderen Exports von ox_target aufrufen, setzen ihre Optionen auf ai-target.
- **Du kannst es ersetzen.** Die Interaktionspunkte von AI Core funktionieren auch mit tgiann-radialmenu-target, tgiann-target, sleepless_interact, ox_target, qb-target und interact (darktrovx). Entferne ai-target und starte eines davon; das erste, das in dieser Reihenfolge läuft, wird genutzt. Siehe [Kompatibilität](/de/docs/compatibility).

## Bekannte Grenzen

- Die **globalen Optionen** von ox_target (`addGlobalOption`, Optionen, die an nichts hängen) werden nicht angeboten: Sie gehören in ein Radialmenü. Ein Skript, das es aufruft, bekommt eine Warnung in der Konsole.
- Die Reichweite einer Option beträgt höchstens 50 m (Standard 2.5 m).
