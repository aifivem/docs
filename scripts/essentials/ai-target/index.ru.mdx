ai-target ставит маленькие маркеры на людей, объекты, транспорт и места, с которыми игрок может взаимодействовать. Игрок смотрит на один из них, нажимает клавишу взаимодействия (**E**), и действие выполняется. Когда у точки несколько действий, открывается маленькое меню для выбора.

## Что он делает в игре

- **Маркеры рядом с камерой.** Каждая точка взаимодействия в пределах досягаемости показывает маркер, немного раньше, чем до неё можно дотянуться, поэтому игроки видят, где можно что-то сделать.
- **Фокус.** Маркер, на который смотрит игрок, находится в фокусе и показывает своё действие.
- **Одна клавиша.** Та же клавиша взаимодействия, что и для подсказок (**E** из ai-lib), использует маркер в фокусе.
- **Несколько опций.** Точка с несколькими действиями показывает "N options" и открывает маленькое меню.
- **Ограничения по работе.** Опцию можно ограничить работами или бандами (и минимальным рангом). Другие игроки её не видят.

## Prompt или target: выбирает владелец

Каждый скрипт `ai-*` создаёт свои места (магазины, тайники, NPC, двери) через точки взаимодействия AI Core. Владелец выбирает, как они выглядят, сразу для всех скриптов, во вкладке **General** из AI Core (карточка **Interaction**, **Interaction style**):

- **Prompt and key** (по умолчанию): окошко справа на экране и клавиша взаимодействия вблизи.
- **Target eye**: точки становятся маркерами target. Для этого нужен скрипт target, например ai-target; без него используется подсказка.

Если выбрано **Prompt and key**, ai-target всё равно работает, но маркеры на нём ставят только скрипты, которые сами вызывают API ox_target (сторонние скрипты).

## Установка

Его устанавливает рецепт AI Core для txAdmin. Вручную: положите папку в `resources/[ai]/` и добавьте `ensure ai-target` в `server.cfg` после `ensure ai-core`. Ему нужен ai-core. Таблицы в базе данных у него нет.

Не запускайте рядом с ним ox_target (ai-target отвечает на имя ox_target). Затем установите **Interaction style** в **Target eye** во вкладке General, если хотите, чтобы каждый скрипт `ai-*` работал через него.

## Настройки панели

Собственных нет. Единственная настройка находится в AI Core: **Interaction style** (см. выше).

## Команды

Нет.

## Привязки клавиш

У ai-target нет своей клавиши. Он использует клавишу взаимодействия ai-lib:

| Клавиша по умолчанию | Что делает | Название в настройках GTA |
| --- | --- | --- |
| E | Использует маркер в фокусе (или подсказку на экране) | Interact with the prompt on screen |

## Работа с другими скриптами

- **Заменяет ox_target** (`provide 'ox_target'`). Скрипты, которые вызывают `exports.ox_target:addBoxZone(...)`, `addModel`, `addEntity`, `addGlobalVehicle` и другие экспорты ox_target, ставят свои опции на ai-target.
- **Его можно заменить.** Точки взаимодействия AI Core также работают с tgiann-radialmenu-target, tgiann-target, sleepless_interact, ox_target, qb-target и interact (darktrovx). Удалите ai-target и запустите один из них; используется первый запущенный в этом порядке. См. [Совместимость](/ru/docs/compatibility).

## Известные ограничения

- **Глобальные опции** ox_target (`addGlobalOption`, опции, которые ни на чём не висят) не предоставляются: им место в радиальном меню. Скрипт, который его вызывает, получает предупреждение в консоли.
- Дальность опции не больше 50 м (по умолчанию 2,5 м).
