ai-loading hat **keine Exports, Events oder State Bags**. Es ist eine FiveM-`loadscreen`-Seite mit einem kleinen Serverteil.

## Wie die Daten die Seite erreichen

Ein Ladebildschirm kann keine NUI-Nachrichten von einem Client-Skript empfangen (es läuft noch kein Client-Skript). ai-loading nutzt den einzigen Kanal, den es gibt, die Übergabe beim Verbinden:

1. Wenn sich ein Spieler verbindet, beantwortet der Server von ai-loading `playerConnecting` mit `deferrals.handover({ aiLoading: view })`.
2. Die Seite liest beim Öffnen `window.nuiHandoverData.aiLoading`.

Übergaben mehrerer Ressourcen werden von FiveM zusammengeführt, sodass deine eigene Ladebildschirm-Ressource einen eigenen Schlüssel neben `aiLoading` hinzufügen kann.

## Schließen

Das Manifest von ai-loading enthält `loadscreen_manual_shutdown 'yes'`. Der Charakterbildschirm von AI Core schließt den Ladebildschirm (`ShutdownLoadingScreenNui`), sobald seine Szene steht. Wenn du ai-loading durch deinen eigenen Ladebildschirm ersetzt, nutze dieselbe Manifestzeile, sonst schließt das Spiel deinen Bildschirm, sobald die Karte geladen ist, und Spieler sehen vor dem Charakterbildschirm die leere Welt.
