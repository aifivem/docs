ai-loading is the screen players see between pressing **Connect** and the character screen. It shows your server's name, subtitle and tagline, a background picture, how far the game has loaded, and short tips one after another.

## What it does in the game

- **Your brand.** The name, subtitle and tagline come from AI Core's **General** tab (**Server name** card), the same ones the character screen shows. You set them once.
- **Loading progress.** A bar that follows the game's own loading stages. It never goes back when the game starts a new stage.
- **Tips.** Your lines, one after another, each for a few seconds.
- **No empty world.** The screen stays until the character screen's scene is ready, so players never see the map loading behind it.

## Installation

The AI Core txAdmin recipe installs it. By hand: put the folder in `resources/[ai]/` and add `ensure ai-loading` to `server.cfg` after `ensure ai-core`. It needs OneSync and ai-core. It has no client script and no database table.

Run only one loading screen: remove qb-loading or any other loading screen resource.

## Panel settings

Open the admin panel (**F10**) and pick **Loading screen**. Everything is on one tab.

**Look**: the server name, subtitle and tagline come from ai-core's General settings.

| Setting | What it changes | Values | Default |
| --- | --- | --- | --- |
| Background | The picture behind the loading screen. | Same as the character screen / City skyline / Night drive | Same as the character screen |

"Same as the character screen" uses the **Background** picked in AI Core's **General** tab.

**Tips**: short lines shown one after another while players wait.

| Setting | What it changes | Values | Default |
| --- | --- | --- | --- |
| Tips | The lines, in order. Press **Add tip** for a new one. | up to 30 tips, 1 to 160 characters each | 3 example tips |
| Time per tip | Seconds each tip stays before the next one. | 3 to 60 s | 7 |

A change reaches players the next time they connect: the loading screen gets its data once, when the player connects.

## Commands

None.

## Keybinds

None.

## Works with other scripts

It replaces qb-loading and other loading screens. Nothing else depends on it: remove it and FiveM's default loading screen shows instead.

## Known limits

- The pictures ship inside the resource, because nothing else is downloaded yet while a loading screen shows. Only the built-in backgrounds can be picked.
- Check the example tips: one of them names a key ("Press F1 for the radial menu"), while the radial menu opens on **F3** by default. Edit it to match your server.
