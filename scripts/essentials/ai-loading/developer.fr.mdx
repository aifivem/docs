ai-loading n’a **ni export, ni event, ni state bag**. C’est une page `loadscreen` de FiveM avec une petite partie serveur.

## Comment les données atteignent la page

Un écran de chargement ne peut pas recevoir de messages NUI d’un script client (aucun script client ne tourne encore). ai-loading utilise le seul canal qui existe, la passation de connexion :

1. Quand un joueur se connecte, le serveur d’ai-loading répond à `playerConnecting` avec `deferrals.handover({ aiLoading: view })`.
2. La page lit `window.nuiHandoverData.aiLoading` à son ouverture.

Les passations de plusieurs ressources sont fusionnées par FiveM, donc votre propre ressource d’écran de chargement peut ajouter sa propre clé à côté de `aiLoading`.

## Fermeture

Le manifeste d’ai-loading contient `loadscreen_manual_shutdown 'yes'`. L’écran des personnages d’AI Core ferme l’écran de chargement (`ShutdownLoadingScreenNui`) une fois sa scène en place. Si vous remplacez ai-loading par votre propre écran de chargement, utilisez la même ligne de manifeste, sinon le jeu ferme votre écran dès que la carte est chargée et les joueurs voient le monde vide avant l’écran des personnages.
