Estes são os scripts que um servidor de roleplay roda desde o primeiro dia. O [ai-core](/pt/docs/scripts/essentials/ai-core) é obrigatório: todo outro script `ai-*` precisa dele. O [ai-mysql](/pt/docs/scripts/essentials/ai-mysql) e o [ai-lib](/pt/docs/scripts/essentials/ai-lib) são necessários para quase tudo. Cada um dos outros pode ser substituído por um script de terceiros do mesmo tipo (outro inventário, HUD, voz ou script de roupas), porque os outros scripts chegam a eles através do AI Core.

| Script | O que faz | Substitui |
| --- | --- | --- |
| [ai-core](/pt/docs/scripts/essentials/ai-core) | O framework: jogadores, personagens, a tela de personagens, dinheiro, empregos e gangues, permissões, o painel de administração e a ponte de frameworks. | es_extended, qb-core, qbx_core, vrp, recursos de UI do ESX e do QB |
| [ai-mysql](/pt/docs/scripts/essentials/ai-mysql) | O motor de banco de dados para scripts de terceiros. | oxmysql, mysql-async, ghmattimysql |
| [ai-lib](/pt/docs/scripts/essentials/ai-lib) | Notificações, barra de progresso, avisos, menus, caixas de entrada e minigames para todo script; os helpers do AI Core para recursos em Lua e JavaScript. | |
| [ai-loading](/pt/docs/scripts/essentials/ai-loading) | A tela de carregamento. | |
| [ai-appearance](/pt/docs/scripts/essentials/ai-appearance) | Criador de personagem, lojas de roupas e barbearias. | |
| [ai-inventory](/pt/docs/scripts/essentials/ai-inventory) | Inventário em grade, drops, baús, porta-malas, lojas, crafting, armas. | ox_inventory, qb-inventory |
| [ai-hud](/pt/docs/scripts/essentials/ai-hud) | O HUD e as necessidades (fome, sede, estresse). | |
| [ai-chat](/pt/docs/scripts/essentials/ai-chat) | Chat com canais e sugestões de comandos. | chat |
| [ai-voice](/pt/docs/scripts/essentials/ai-voice) | Voz por proximidade, rádio e chamadas telefônicas. | pma-voice, mumble-voip, tokovoip |
| [ai-radialmenu](/pt/docs/scripts/essentials/ai-radialmenu) | O menu radial (F3). | qb-radialmenu, tgiann-radialmenu-target |
| [ai-target](/pt/docs/scripts/essentials/ai-target) | O target. | ox_target |
| [ai-scoreboard](/pt/docs/scripts/essentials/ai-scoreboard) | Jogadores online e contagens de quem está em serviço (Home). | |
| [ai-weathersync](/pt/docs/scripts/essentials/ai-weathersync) | Hora e clima, iguais para todos. | qb-weathersync |

## Ordem de inicialização

O `server.cfg` os inicia nesta ordem (a receita faz isso por você): `ai-mysql`, depois `ai-core`, depois os outros. Um script que "substitui" outro conta como aquele script para todos os outros recursos: não instale o original junto com ele.
