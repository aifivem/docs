ai-inventory является инвентарём-сеткой: каждый предмет занимает несколько ячеек (телефон 1x1, винтовка 4x2), и его можно повернуть при перетаскивании. Он хранит предметы игрока, землю, тайники, багажники и бардачки транспорта, магазины и верстаки для крафта, а также оружие как предметы.

## Что он делает в игре

- **Сетка.** У каждого инвентаря одинаковое число столбцов; различаются только строки и предел веса. У предметов есть размер в ячейках и вес; инвентарь отказывает в том, что не помещается или слишком тяжело.
- **Экран** (**F2**): одежда персонажа в двух столбцах вокруг персонажа, пять быстрых слотов, сетка игрока и второй инвентарь (земля, багажник, тайник, магазин, верстак) справа. Щелчок по вещи снимает её или надевает обратно.
- **Быстрые слоты.** Пять отдельных слотов (не ячейки сетки). Клавиши от **1** до **5** используют их; **TAB** показывает их панелью внизу.
- **Использование предметов.** Двойной щелчок или меню предмета. Еда и напитки проигрывают анимацию, восполняют голод и жажду ([ai-hud](/ru/docs/scripts/essentials/ai-hud)) и расходуются. Сервер проверяет, что предмет всё ещё на месте после анимации.
- **Передать, выбросить, разделить.** Меню предмета передаёт ближайшему игроку, выбрасывает на землю или делит стак.
- **Предметы на земле.** Выброшенные предметы лежат в сумке на земле. Если выбросить рядом со своей сумкой, они добавятся в неё. Сумки исчезают через несколько минут без прикосновения.
- **Багажники и бардачки.** **F2** у задней части транспорта открывает его багажник (если он не заперт); внутри транспорта его бардачок. Багажник личного транспорта остаётся с транспортом, какой бы номер на нём ни был; багажник любого другого транспорта временный.
- **Тайники.** Хранилища в фиксированных местах, общие или по одному на персонажа, открытые для всех или для некоторых работ и банд.
- **Магазины.** Места с товарами и ценами, блипом на карте и необязательным NPC, оплата сначала наличными, затем с банка (как задано).
- **Верстаки для крафта.** Рецепты, которые за несколько секунд превращают материалы в предметы.
- **Оружие.** Оружие является предметами с серийным номером. Патроны являются предметом; **R** перезаряжает из него. Обвесы (фонарик, глушитель...) являются предметами, которые ставятся на оружие в руках. Колесо оружия GTA по умолчанию отключено: оружие берётся из быстрых слотов.
- **Редкость.** Предметы могут относиться к редкости, цвет которой окрашивает их ячейку.
- **Оружие из других источников.** Оружие, которое выдал не ai-inventory, у игрока забирается.

## Установка

Его устанавливает рецепт AI Core для txAdmin. Вручную: положите папку в `resources/[ai]/` и добавьте `ensure ai-inventory` в `server.cfg` после `ensure ai-core`. Ему нужны ai-core и база данных:

```ini title="env.cfg"
add_convar_permission ai-inventory read mysql_connection_string
```

Таблица `ai_inventory_inventories` создаётся при первом запуске. Картинки предметов кладутся в папку ресурса `dist/web/images` (картинки ox_inventory поставляются вместе с ним).

Удалите ox_inventory и qb-inventory: ai-inventory отвечает на их имена.

## Настройки панели

Откройте админ-панель (**F10**) и выберите **Inventory**.

### Вкладка Items

Каждый предмет, который существует в игре. Каждый предмет является одной записью; его ключ (`water`, `lockpick`) является именем предмета, которое используют скрипты. Скрипт поставляется с 242 предметами (взяты из списков ox_inventory).

**Item** (предмет): название, которое видят игроки, и тип предмета.

| Настройка | Что меняет | Значения | По умолчанию для нового предмета |
| --- | --- | --- | --- |
| Name | Название, которое видят игроки. | до 48 символов | |
| Description | Строка под названием. | до 240 символов | |
| Kind | **Item**, **Weapon** (берётся в руки при использовании), **Ammo** (перезаряжает оружие в руках), **Attachment** (ставится на оружие в руках). | Item / Weapon / Ammo / Attachment | Item |
| Rarity | Окрашивает ячейку предмета цветом редкости (вкладка Rarities). Пусто: обычная ячейка. | редкость | нет |
| Picture | Имя файла в папке картинок (`water.png`) или полная ссылка `https`. Пусто показывает иконку. | до 200 символов | |
| Other names | Имена, которые другие скрипты используют для этого предмета (например, `pistol_ammo`), чтобы они продолжали работать. | до 30 имён | |

**Size and weight** (размер и вес): сколько ячеек занимает предмет и сколько он весит.

| Настройка | Что меняет | Значения | По умолчанию |
| --- | --- | --- | --- |
| Width | Ячейки слева направо. Игроки могут повернуть предмет при перетаскивании. | от 1 до 8 ячеек | 1 |
| Height | Ячейки сверху вниз. | от 1 до 8 ячеек | 1 |
| Weight | Граммы на единицу (1000 г = 1 кг). | от 0 до 1,000,000 г | 100 |
| Stack size | Наибольшее число единиц в одном стаке. 1 делает каждую единицу отдельной, для предметов со своими данными. | от 1 до 100,000 | 10 |

**Using** (использование): что происходит, когда игрок использует предмет.

| Настройка | Что меняет | Значения | По умолчанию |
| --- | --- | --- | --- |
| Can be used | Выкл.: использование ничего не делает, если этот предмет не обрабатывает какой-нибудь скрипт. | вкл. / выкл. | выкл. |
| Used up per use | Сколько единиц убирается при каждом использовании. 0 оставляет предмет. | от 0 до 1000 | 0 |
| Close the inventory | Закрывает экран инвентаря, когда предмет используют. | вкл. / выкл. | выкл. |
| Animation | Проигрывается во время использования. | None / Eat / Drink / Bandage / Put on armour | None |
| Use time | Сколько длится анимация, прежде чем предмет подействует. | от 0 до 60,000 мс | |
| Hunger | Прибавляется к голоду игрока при использовании (минус уменьшает). Нужен HUD, который отслеживает потребности. | от -100 до 100 | |
| Thirst | Прибавляется к жажде. | от -100 до 100 | |
| Stress | Прибавляется к стрессу. | от -100 до 100 | |

**Weapon** (оружие): только для оружия и обвесов.

| Настройка | Что меняет | Значения | По умолчанию |
| --- | --- | --- | --- |
| Ammo item | Имя предмета, которым заряжается оружие (например, `ammo-9`). | имя предмета | |
| Thrown | Гранаты и подобное: количество в стаке является боезапасом. | вкл. / выкл. | выкл. |
| Attachment hashes | Названия компонентов GTA, которыми может быть этот обвес (`COMPONENT_AT_PI_FLSH`); используется первый, который подходит оружию в руках. | до 20 названий | |

Удаление предмета: у игроков, у которых он есть, остаётся стак, который никто не может использовать.

### Вкладка Rarities

Цветовые группы, к которым относятся предметы. В комплекте: Common, Uncommon, Rare, Epic, Legendary, Medical, Special.

| Настройка | Что меняет | Значения |
| --- | --- | --- |
| Name | Название редкости. | до 32 символов |
| Colour | Им окрашивается ячейка каждого предмета этой редкости. | цвет |

Удаление редкости: её предметы теряют свой цвет.

### Вкладка Shops

Места, где игроки покупают предметы. Скрипт поставляется с 45 магазинами (24/7, LTD, Rob's Liquor, хозяйственные магазины, Ammu-Nation и другие, плюс рабочие магазины для полиции и EMS).

**Shop** (магазин): где находится магазин и кто может в нём покупать.

| Настройка | Что меняет | Значения | По умолчанию для нового магазина |
| --- | --- | --- | --- |
| Shop name | Название, которое видят игроки. | до 48 символов | |
| Place | Встаньте там, где игроки должны его открывать, и используйте свою позицию. | точка | |
| Reach | Насколько близко должен быть игрок, чтобы открыть его. | от 0.5 до 30 м | 2 |
| Jobs | Пользоваться могут только участники этих работ. Оставьте работы и банды пустыми, чтобы было доступно всем. | названия работ | пусто |
| Gangs | Участники этих банд тоже могут пользоваться. | названия банд | пусто |
| Only on duty | Участники работы должны быть на дежурстве в этой работе. | вкл. / выкл. | выкл. |
| Map blip | Показывает магазин на карте. | вкл. / выкл. | вкл. |
| Blip look | Картинка, цвет и размер блипа (когда блип включён). | спрайт, цвет, размер | |
| Paid from | Денежные счета, которые проверяются по порядку. | до 5 счетов | cash, bank |

**Products** (товары): предметы, которые продаёт магазин, и их цена за единицу. До 100 строк, каждая из них **Item** и **Price** (от 0 до 100,000,000 $).

**NPC**: продавец, который стоит у магазина. **Model** (пусто, чтобы его не было, виден в пределах 50 м), **What it does** (анимация ожидания), **Where it stands** (точка на полу и направление; без неё он стоит в точке магазина).

## Команды

Собственных нет. Администраторы выдают и забирают предметы инструментами предметов из [ai-admin](/ru/docs/scripts/world/ai-admin).

## Привязки клавиш

| Клавиша по умолчанию | Что делает | Название в настройках GTA |
| --- | --- | --- |
| F2 | Открывает инвентарь (с землёй, багажником или бардачком рядом с вами) или закрывает его | Open the inventory |
| TAB | Показывает или скрывает панель быстрых слотов | Show / hide the quick slots bar |
| 1–5 | Использует предмет из этого быстрого слота | Use the item in quick slot 1 (to 5) |
| R | Перезаряжает оружие в руках из предмета-патронов | Reload the weapon |

На экране: перетаскивайте, чтобы переместить, поворачивайте предмет при перетаскивании, двойной щелчок для использования, правый щелчок для меню предмета, **Escape** или **F2** для закрытия.

## Работа с другими скриптами

- **Заменяет ox_inventory** (`provide`, API ox_inventory 2.44) **и qb-inventory** (`provide`, API 2.0): их экспорты отвечают, поэтому скрипты ox и QB выдают, забирают и проверяют предметы здесь. Что поддерживается, а что нет, см. на [странице разработчика](/ru/docs/scripts/essentials/ai-inventory/developer).
- **Слой инвентаря AI Core.** Каждый скрипт `ai-*` и мост ESX / QB выдают и забирают предметы через AI Core, который вызывает ai-inventory.
- **Его можно заменить.** В AI Core есть адаптеры для других инвентарей (tgiann-inventory, codem-inventory, core_inventory, origen_inventory, jaksam_inventory и другие), у каждого свои ограничения. Поддерживаемый инвентарь делает ai-inventory ненужным: AI Core сообщит в консоли, что его нужно удалить. См. [Совместимость](/ru/docs/compatibility).

## Известные ограничения

- Одно использование за раз на игрока.
- Новая сумка на земле ограничена одной в секунду на игрока, настройкой панели **Bags per player** и 50 на область карты. Результаты крафта и предметы, выброшенные скриптами, эти ограничения обходят.
- Предметы нельзя выбросить, находясь в транспорте.
- Хуки ox_inventory, `RegisterShop` в формате ox и конфискация не поддерживаются (магазины берутся из панели или из собственного `RegisterShop` ai-inventory).
