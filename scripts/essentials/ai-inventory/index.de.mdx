ai-inventory ist ein Raster-Inventar: Jedes Item belegt eine Anzahl von Zellen (ein Telefon 1x1, ein Gewehr 4x2) und kann beim Ziehen gedreht werden. Es enthält die Items des Spielers, den Boden, Lager, Kofferräume und Handschuhfächer von Fahrzeugen, Shops und Werkbänke sowie Waffen als Items.

## Was es im Spiel macht

- **Das Raster.** Jedes Inventar hat dieselbe Anzahl von Spalten; nur die Zeilen und das Gewichtslimit unterscheiden sich. Items haben eine Größe in Zellen und ein Gewicht; das Inventar lehnt ab, was nicht passt oder zu schwer ist.
- **Der Bildschirm** (**F2**): die Kleidung des Charakters in zwei Spalten um den Charakter herum, die fünf Schnellplätze, das Raster des Spielers und rechts das zweite Inventar (Boden, Kofferraum, Lager, Shop, Werkbank). Ein Klick auf ein Kleidungsstück zieht es aus oder wieder an.
- **Schnellplätze.** Fünf eigene Plätze (keine Rasterzellen). Die Tasten **1** bis **5** benutzen sie; **TAB** zeigt sie als Leiste unten an.
- **Items benutzen.** Doppelklick oder das Item-Menü. Essen und Trinken spielen eine Animation ab, füllen Hunger und Durst ([ai-hud](/de/docs/scripts/essentials/ai-hud)) und werden verbraucht. Der Server prüft nach der Animation, ob das Item noch da ist.
- **Geben, ablegen, teilen.** Das Item-Menü gibt an den nächsten Spieler, legt auf den Boden ab oder teilt einen Stapel.
- **Drops auf dem Boden.** Abgelegte Items liegen in einer Tasche auf dem Boden. Ablegen neben deiner eigenen Tasche fügt sie dieser hinzu. Taschen verschwinden nach einigen unberührten Minuten.
- **Kofferräume und Handschuhfächer.** **F2** am Heck eines Fahrzeugs öffnet seinen Kofferraum (wenn aufgeschlossen); im Fahrzeug sein Handschuhfach. Der Kofferraum eines Fahrzeugs im Besitz bleibt beim Fahrzeug, egal welches Kennzeichen es trägt; der Kofferraum jedes anderen Fahrzeugs ist vorübergehend.
- **Lager.** Stauraum an festen Orten, gemeinsam oder einer pro Charakter, offen für alle oder für bestimmte Jobs und Gangs.
- **Shops.** Orte mit Produkten und Preisen, einem Karten-Blip und einem optionalen NPC, bezahlt mit Bargeld, dann Bank (je nach Einstellung).
- **Werkbänke.** Rezepte, die Materialien in einigen Sekunden in Items verwandeln.
- **Waffen.** Waffen sind Items mit einer Seriennummer. Munition ist ein Item; **R** lädt daraus nach. Aufsätze (Taschenlampe, Schalldämpfer...) sind Items, die an die gehaltene Waffe kommen. Das Waffenrad von GTA ist standardmäßig aus: Waffen kommen aus den Schnellplätzen.
- **Seltenheiten.** Items können zu einer Seltenheit gehören, deren Farbe ihre Box färbt.
- **Waffen von anderswo.** Eine Waffe, die nicht von ai-inventory vergeben wurde, wird dem Spieler abgenommen.

## Installation

Das txAdmin-Rezept von AI Core installiert es. Von Hand: Lege den Ordner in `resources/[ai]/` und füge `ensure ai-inventory` in der `server.cfg` nach `ensure ai-core` ein. Es braucht ai-core und die Datenbank:

```ini title="env.cfg"
add_convar_permission ai-inventory read mysql_connection_string
```

Die Tabelle `ai_inventory_inventories` wird beim ersten Start angelegt. Item-Bilder kommen in den Ordner `dist/web/images` der Ressource (die Bilder von ox_inventory werden mitgeliefert).

Entferne ox_inventory und qb-inventory: ai-inventory beantwortet ihre Namen.

## Panel-Einstellungen

Öffne das Admin-Panel (**F10**) und wähle **Inventory**.

### Tab Items

Jedes Item, das im Spiel existiert. Jedes Item ist ein Datensatz; sein Schlüssel (`water`, `lockpick`) ist der Item-Name, den Skripte nutzen. Das Skript kommt mit 242 Items (aus den Listen von ox_inventory übernommen).

**Item**: der Name, den Spieler sehen, und welche Art von Item es ist.

| Einstellung | Was sie ändert | Werte | Standard für ein neues Item |
| --- | --- | --- | --- |
| Name | Der Name, den Spieler sehen. | bis zu 48 Zeichen | |
| Description | Eine Zeile unter dem Namen. | bis zu 240 Zeichen | |
| Kind | **Item**, **Weapon** (wird beim Benutzen gehalten), **Ammo** (lädt die gehaltene Waffe nach), **Attachment** (kommt an die gehaltene Waffe). | Item / Weapon / Ammo / Attachment | Item |
| Rarity | Färbt die Box des Items mit der Farbe einer Seltenheit (Tab Rarities). Leer: eine einfache Box. | eine Seltenheit | keine |
| Picture | Dateiname im Bilderordner (`water.png`) oder ein vollständiger `https`-Link. Leer zeigt ein Symbol. | bis zu 200 Zeichen | |
| Other names | Namen, die andere Skripte für dieses Item nutzen (zum Beispiel `pistol_ammo`), damit sie weiter funktionieren. | bis zu 30 Namen | |

**Size and weight** (Größe und Gewicht): wie viele Zellen das Item belegt und wie schwer es ist.

| Einstellung | Was sie ändert | Werte | Standard |
| --- | --- | --- | --- |
| Width | Zellen von links nach rechts. Spieler können ein Item beim Ziehen drehen. | 1 bis 8 Zellen | 1 |
| Height | Zellen von oben nach unten. | 1 bis 8 Zellen | 1 |
| Weight | Gramm pro Einheit (1000 g = 1 kg). | 0 bis 1.000.000 g | 100 |
| Stack size | Höchstzahl an Einheiten in einem Stapel. 1 macht jede Einheit einzeln, für Items mit eigenen Daten. | 1 bis 100.000 | 10 |

**Using** (Benutzen): was passiert, wenn ein Spieler das Item benutzt.

| Einstellung | Was sie ändert | Werte | Standard |
| --- | --- | --- | --- |
| Can be used | Aus: Benutzen tut nichts, es sei denn, ein Skript behandelt dieses Item. | an / aus | aus |
| Used up per use | Einheiten, die bei jeder Benutzung entfernt werden. 0 behält es. | 0 bis 1000 | 0 |
| Close the inventory | Schließt den Inventarbildschirm, wenn das Item benutzt wird. | an / aus | aus |
| Animation | Wird beim Benutzen abgespielt. | None / Eat / Drink / Bandage / Put on armour | None |
| Use time | Wie lange die Animation läuft, bevor das Item wirkt. | 0 bis 60.000 ms | |
| Hunger | Wird beim Benutzen zum Hunger des Spielers addiert (ein Minus senkt ihn). Braucht ein HUD, das Bedürfnisse verfolgt. | -100 bis 100 | |
| Thirst | Wird zum Durst addiert. | -100 bis 100 | |
| Stress | Wird zum Stress addiert. | -100 bis 100 | |

**Weapon** (Waffe): nur für Waffen und Aufsätze.

| Einstellung | Was sie ändert | Werte | Standard |
| --- | --- | --- | --- |
| Ammo item | Item-Name, den die Waffe lädt (zum Beispiel `ammo-9`). | ein Item-Name | |
| Thrown | Granaten und Ähnliches: Die Stapelanzahl ist die Munition. | an / aus | aus |
| Attachment hashes | GTA-Komponentennamen, die dieser Aufsatz sein kann (`COMPONENT_AT_PI_FLSH`); der erste, den die gehaltene Waffe annimmt, wird genutzt. | bis zu 20 Namen | |

Ein Item löschen: Spieler, die es haben, behalten einen Stapel, den niemand benutzen kann.

### Tab Rarities

Farbgruppen, zu denen Items gehören. Mitgeliefert: Common, Uncommon, Rare, Epic, Legendary, Medical, Special.

| Einstellung | Was sie ändert | Werte |
| --- | --- | --- |
| Name | Der Name der Seltenheit. | bis zu 32 Zeichen |
| Colour | Die Box jedes Items dieser Seltenheit wird damit gefärbt. | eine Farbe |

| Reach | Wie nah ein Spieler sein muss, um ihn zu öffnen. | 0.5 bis 30 m | 2 |

| Only on duty | Job-Mitglieder müssen in diesem Job im Dienst sein. | an / aus | aus |

## Befehle

Keine eigenen. Admins geben und nehmen Items mit den Item-Werkzeugen von [ai-admin](/de/docs/scripts/world/ai-admin).

## Tastenbelegungen

| Standardtaste | Was sie macht | Name in den GTA-Einstellungen |
| --- | --- | --- |
| F2 | Öffnet das Inventar (mit dem Boden, Kofferraum oder Handschuhfach neben dir) oder schließt es | Open the inventory |
| TAB | Zeigt oder verbirgt die Schnellleiste | Show / hide the quick slots bar |
| 1 bis 5 | Benutzt das Item in diesem Schnellplatz | Use the item in quick slot 1 (to 5) |
| R | Lädt die gehaltene Waffe aus einem Munitions-Item nach | Reload the weapon |

Im Bildschirm: Ziehen zum Bewegen, das Item beim Ziehen drehen, Doppelklick zum Benutzen, Rechtsklick für das Item-Menü, **Escape** oder **F2** zum Schließen.

## Zusammenspiel mit anderen Skripten

- **Ersetzt ox_inventory** (`provide`, API von ox_inventory 2.44) **und qb-inventory** (`provide`, API 2.0): Ihre Exports antworten, sodass ox- und QB-Skripte hier Items geben, nehmen und prüfen. Was beantwortet wird und was nicht, steht auf der [Entwicklerseite](/de/docs/scripts/essentials/ai-inventory/developer).
- **Der Inventar-Layer von AI Core.** Jedes `ai-*`-Skript und die ESX- / QB-Brücke geben und nehmen Items über AI Core, das ai-inventory aufruft.
- **Du kannst es ersetzen.** AI Core hat Adapter für andere Inventare (tgiann-inventory, codem-inventory, core_inventory, origen_inventory, jaksam_inventory und mehr), jedes mit eigenen Grenzen. Ein unterstütztes Inventar macht ai-inventory unnötig: AI Core sagt dir in der Konsole, dass du es entfernen sollst. Siehe [Kompatibilität](/de/docs/compatibility).

## Bekannte Grenzen

- Eine Benutzung gleichzeitig pro Spieler.
- Eine neue Tasche auf dem Boden ist auf eine pro Sekunde pro Spieler, die Panel-Einstellung **Bags per player** und 50 pro Kartenbereich begrenzt. Crafting-Ergebnisse und Drops von Skripten umgehen diese Grenzen.
- Items können nicht aus einem Fahrzeug heraus abgelegt werden.
- Die Hooks von ox_inventory, `RegisterShop` in der Form von ox und Beschlagnahme werden nicht beantwortet (Shops kommen aus dem Panel oder aus dem eigenen `RegisterShop` von ai-inventory).
