Estos son los scripts que un servidor de roleplay usa desde el primer día. [ai-core](/es/docs/scripts/essentials/ai-core) es obligatorio: todos los demás scripts `ai-*` lo necesitan. [ai-mysql](/es/docs/scripts/essentials/ai-mysql) y [ai-lib](/es/docs/scripts/essentials/ai-lib) los necesita casi todo. Cada uno de los demás puede reemplazarse por un script de terceros del mismo tipo (otro inventario, HUD, voz o script de ropa), porque los demás scripts llegan a ellos a través de AI Core.

| Script | Qué hace | Sustituye a |
| --- | --- | --- |
| [ai-core](/es/docs/scripts/essentials/ai-core) | El framework: jugadores, personajes, la pantalla de personajes, dinero, trabajos y bandas, permisos, el panel de administración y el puente de frameworks. | es_extended, qb-core, qbx_core, vrp, recursos de interfaz de ESX y QB |
| [ai-mysql](/es/docs/scripts/essentials/ai-mysql) | El motor de base de datos para scripts de terceros. | oxmysql, mysql-async, ghmattimysql |
| [ai-lib](/es/docs/scripts/essentials/ai-lib) | Notificaciones, barra de progreso, avisos, menús, cuadros de entrada y minijuegos para todos los scripts; las utilidades de AI Core para recursos en Lua y JavaScript. | |
| [ai-loading](/es/docs/scripts/essentials/ai-loading) | La pantalla de carga. | |
| [ai-appearance](/es/docs/scripts/essentials/ai-appearance) | Creador de personajes, tiendas de ropa y barberías. | |
| [ai-inventory](/es/docs/scripts/essentials/ai-inventory) | Inventario en cuadrícula, objetos en el suelo, alijos, maleteros, tiendas, fabricación, armas. | ox_inventory, qb-inventory |
| [ai-hud](/es/docs/scripts/essentials/ai-hud) | El HUD y las necesidades (hambre, sed, estrés). | |
| [ai-chat](/es/docs/scripts/essentials/ai-chat) | Chat con canales y sugerencias de comandos. | chat |
| [ai-voice](/es/docs/scripts/essentials/ai-voice) | Voz por proximidad, radio y llamadas telefónicas. | pma-voice, mumble-voip, tokovoip |
| [ai-radialmenu](/es/docs/scripts/essentials/ai-radialmenu) | El menú radial (F3). | qb-radialmenu, tgiann-radialmenu-target |
| [ai-target](/es/docs/scripts/essentials/ai-target) | El ojo de interacción (target). | ox_target |
| [ai-scoreboard](/es/docs/scripts/essentials/ai-scoreboard) | Jugadores conectados y recuento de quién está de servicio (Home). | |
| [ai-weathersync](/es/docs/scripts/essentials/ai-weathersync) | Hora y clima, los mismos para todos. | qb-weathersync |

## Orden de inicio

`server.cfg` los inicia en este orden (la receta lo hace por ti): `ai-mysql`, después `ai-core` y después los demás. Un script que "sustituye a" otro cuenta como ese script para todos los demás recursos: no instales el original a su lado.
