<Callout type="info">
Twoje własne skrypty nie powinny wywoływać ai-weathersync bezpośrednio. Zamiast tego używaj warstwy czasu i pogody AI Core: `world` z biblioteki w TypeScript (`world.setWeather`, `world.setTime`...) lub `aiLib.world` w Lua, opisanej w [dokumentacji biblioteki](/pl/docs/developers/api/lib-server). Ta warstwa działa z każdym skryptem pogody, którego używa serwer, więc właściciel może zastąpić ai-weathersync bez psucia twojego skryptu. Poniższe eksporty są dla skryptów napisanych dla qb-weathersync i do szczególnych przypadków.
</Callout>

## Eksporty

Każdy eksport działa **po stronie serwera** i odpowiada pod dwiema nazwami: `exports['ai-weathersync']` i `exports['qb-weathersync']` (ai-weathersync robi `provide` dla qb-weathersync). Żaden z nich nie czeka. Nie są typowane w `@aifivem/shared`; z TypeScript wywołuj je przez `callExport("ai-weathersync", name, ...args)` z biblioteki.

Zmiany wprowadzone przez `setBlackout`, `setTimeFreeze` i `setDynamicWeather` trwają, dopóki właściciel nie zmieni tego ustawienia w panelu lub zasób się nie zrestartuje.

### setWeather

Od razu zmienia pogodę w świecie. Nie dotyka regionów pogodowych.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
setWeather(type: string): boolean
```

```lua title="Lua"
local ok = exports['ai-weathersync']:setWeather('RAIN')
```

#### Parametry

<TypeTable
  type={{
    type: { type: 'string', description: 'Nazwa pogody GTA: EXTRASUNNY, CLEAR, NEUTRAL, SMOG, FOGGY, OVERCAST, CLOUDS, CLEARING, RAIN, THUNDER, SNOW, BLIZZARD, SNOWLIGHT, XMAS lub HALLOWEEN. Małe litery są akceptowane.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy pogoda się zmieniła. `false`, gdy `type` nie jest znaną nazwą pogody.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

// Burza na wydarzenie; cykl pogody z panelu toczy się dalej od tego miejsca.
const ok = callExport("ai-weathersync", "setWeather", "THUNDER") === true;
if (!ok) console.log("unknown weather");
```
</Tab>
<Tab value="Lua">
```lua
local ok = exports['ai-weathersync']:setWeather('THUNDER')
if not ok then print('unknown weather') end
```
</Tab>
</Tabs>

<Callout type="warn">
Przy włączonym **Changing weather** następna zmiana i tak przychodzi według timera z panelu, od pozycji nowej pogody na liście (albo od pierwszego wpisu, gdy nowej pogody nie ma na liście).
</Callout>

### setTime

Ustawia zegar świata. Zegar biegnie dalej z prędkością z panelu od nowej godziny.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
setTime(hour: number, minute?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-weathersync']:setTime(22, 30)
```

#### Parametry

<TypeTable
  type={{
    hour: { type: 'number', description: 'Godzina dnia, 0-23. Części dziesiętne są ucinane, wartości powyżej 23 zawijają się (24 = 0).', required: true },
    minute: { type: 'number', description: 'Minuta, 0-59. Części dziesiętne są ucinane.', default: '0' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy zegar został ustawiony. `false`, gdy `hour` nie jest liczbą.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

callExport("ai-weathersync", "setTime", 22, 30);
```
</Tab>
<Tab value="Lua">
```lua
exports['ai-weathersync']:setTime(22, 30)
```
</Tab>
</Tabs>

### Gettery

Każdy odczytuje bieżący stan i nie czeka.

| Eksport | Zwraca |
| --- | --- |
| `getWeatherState(): string` | Nazwa bieżącej pogody w świecie, na przykład `"CLEAR"`. Regiony nie są uwzględniane. |
| `getTime(): { hour: number, minute: number }` | Bieżący czas gry. W Lua tabela z `hour` i `minute`. |
| `getBlackoutState(): boolean` | Czy blackout jest włączony (wartość z eksportu, w przeciwnym razie z panelu). |
| `getTimeFreezeState(): boolean` | Czy zegar jest zatrzymany. |
| `getDynamicWeather(): boolean` | Czy pogoda zmienia się sama. |

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

const time = callExport("ai-weathersync", "getTime") as { hour: number; minute: number };
const weather = callExport("ai-weathersync", "getWeatherState") as string;
console.log(`It is ${time.hour}:${String(time.minute).padStart(2, "0")}, weather ${weather}`);
```
</Tab>
<Tab value="Lua">
```lua
local time = exports['ai-weathersync']:getTime()
local weather = exports['ai-weathersync']:getWeatherState()
print(('It is %d:%02d, weather %s'):format(time.hour, time.minute, weather))
```
</Tab>
</Tabs>

<Callout type="warn">
`getTime` odpowiada tabelą (`{ hour, minute }`), a oryginalny qb-weathersync odpowiada dwiema wartościami (`hour, minute`). Skrypt Lua napisany dla qb-weathersync, który robi `local h, m = exports['qb-weathersync']:getTime()`, dostaje tabelę w `h`. Własny eksport `GetTime` AI Core i `world.getTime()` z biblioteki czytają oba kształty i zawsze odpowiadają `{ hour, minute }`.
</Callout>

## Klucze GlobalState

ai-weathersync publikuje swój stan jako GlobalState, zapisywany przez serwer tylko wtedy, gdy coś się zmienia. Czytaj je; nigdy ich nie zapisuj.

| Klucz | Wartość | Kiedy się zmienia |
| --- | --- | --- |
| `ai:clock` | `{ base: number, at: number, scale: number, frozen: boolean }`: minuta gry w ciągu dnia (`base`, 0-1439) w czasie serwera `at` (ms, `Date.now()`), przesuwająca się o `scale` minut gry na prawdziwą minutę albo stojąca w miejscu, gdy `frozen`. | Zmiana w panelu, `setTime`, `setTimeFreeze`. |
| `ai:weather` | `{ type: string, blackout: boolean }`: pogoda i blackout w świecie. | Każda zmiana pogody i `setBlackout`. |
| `ai:rweather:<regionId>` | `string`: bieżąca pogoda jednego regionu. Usuwany, gdy region zostanie usunięty. | Według własnego timera regionu. |

Czas nie jest wysyłany co minutę: każdy klient wylicza go z `ai:clock` i własnego zegara (przesunięcie pobierane raz z serwera).

## Zdarzenia

ai-weathersync nie ma zdarzeń dla innych skryptów. Aby wstrzymać synchronizację na kliencie (wnętrze, przerywnik), używaj eksportów klienta AI Core `PauseWorldSync` / `ResumeWorldSync` lub `world.pauseSync(reason)` / `resumeSync(reason)` z biblioteki (zobacz [eksporty klienta ai-core](/pl/docs/developers/api/core-client)). ai-weathersync nasłuchuje tylko wstrzymania z AI Core.
