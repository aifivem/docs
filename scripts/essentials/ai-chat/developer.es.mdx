ai-chat responde a la API del recurso `chat` de FiveM, así que escribes el código de chat de la forma estándar de FiveM. Los exports responden bajo `exports['ai-chat']` y `exports.chat`.

## ChatMessage

La forma de mensaje que reciben todos los exports y eventos.

## Exports de servidor

### addMessage

Envía una línea de chat a un jugador, a varios jugadores o a todos.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
addMessage(target: number | number[], message: ChatMessage): void
```

```lua title="Lua"
exports.chat:addMessage(source, { args = { 'Bank', 'Your salary arrived.' }, color = { 61, 247, 158 } })
```

#### Parámetros

<TypeTable
  type={{
    target: { type: 'number | number[]', description: 'Un id de servidor, una lista de ids de servidor, o `-1` para todos.', required: true },
    message: { type: 'ChatMessage', description: 'La línea que mostrar.', required: true },
  }}
/>

#### Devuelve

Nada. Un mensaje sin una lista `args` válida se descarta.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aicore-fivem/lib/server";

function announce(text: string): void {
  callExport("chat", "addMessage", -1, { args: ["City", text], color: [61, 247, 158], multiline: true });
}
announce("The bank closes in 10 minutes.");
```
</Tab>
<Tab value="Lua">
```lua
local function announce(text)
    exports.chat:addMessage(-1, { args = { 'City', text }, color = { 61, 247, 158 }, multiline = true })
end
announce('The bank closes in 10 minutes.')
```
</Tab>
</Tabs>

### registerMessageHook

Ejecuta tu función para cada mensaje que envía un jugador, antes de entregarlo. El hook puede cambiar el mensaje, cambiar quién lo recibe o cancelarlo. Los hooks se quitan cuando tu recurso se detiene.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
registerMessageHook(hook: (source: number, message: ChatMessage, ref: HookRef) => void): void
```

#### HookRef

<TypeTable
  type={{
    updateMessage: { type: '(change: Partial<ChatMessage>) => void', description: 'Une `change` al mensaje.' },
    cancel: { type: '() => void', description: 'Descarta el mensaje: nadie lo recibe.' },
    setRouting: { type: '(target: number | number[]) => void', description: 'Lo envía en su lugar a estos ids de servidor (`-1` para todos).' },
  }}
/>

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aicore-fivem/lib/server";

callExport("chat", "registerMessageHook", (source: number, message: { args: string[] }, ref: { cancel(): void }) => {
  const text = message.args[message.args.length - 1] ?? "";
  if (/discord\.gg\//i.test(text)) ref.cancel();
});
```
</Tab>
<Tab value="Lua">
```lua
exports.chat:registerMessageHook(function(source, message, ref)
    local text = message.args[#message.args] or ''
    if text:lower():find('discord%.gg/') then ref.cancel() end
end)
```
</Tab>
</Tabs>

### registerMode

Añade un canal desde un script (los modos de chat de FiveM). Su callback decide quién recibe cada mensaje, como un hook de mensajes. El modo se quita cuando tu recurso se detiene.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
registerMode(data: { name: string; displayName?: string; color?: string; cb?: (source: number, message: ChatMessage, ref: HookRef) => void }): void
```

<TypeTable
  type={{
    name: { type: 'string', description: 'Id del modo.', required: true },
    displayName: { type: 'string', description: 'Texto mostrado para el modo.', default: 'name' },
    color: { type: 'string', description: 'Color CSS del modo.', default: '"#ffffff"' },
    cb: { type: '(source, message, ref) => void', description: 'Enruta cada mensaje del modo (`ref.setRouting`, `ref.cancel`).' },
  }}
/>

## Exports de cliente

| Export | Qué hace |
| --- | --- |
| `addMessage(message: ChatMessage \| string): void` | Muestra una línea solo en el chat de este jugador. |
| `addSuggestion(name: string, help: string, params?: { name: string, help: string }[]): void` | Añade una sugerencia de comando para este jugador. |

## Eventos

### chatMessage (server)

Se dispara en el servidor para cada mensaje que envía un jugador, antes de la entrega. Cancélalo (`CancelEvent()`) para descartar el mensaje.

**Lado:** Servidor (evento local)

| Argumento | Tipo | Qué es |
| --- | --- | --- |
| `source` | `number` | El id de servidor de quien envía. |
| `author` | `string` | El autor mostrado (el nombre del personaje). |
| `text` | `string` | El texto del mensaje. |

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
on("chatMessage", (source: number, author: string, text: string) => {
  console.log(`[chat] ${author} (${source}): ${text}`);
});
```
</Tab>
<Tab value="Lua">
```lua
AddEventHandler('chatMessage', function(source, author, text)
    print(('[chat] %s (%d): %s'):format(author, source, text))
end)
```
</Tab>
</Tabs>

### Eventos de cliente que escucha ai-chat

Envíalos desde el servidor (`TriggerClientEvent`) o desde un script de cliente (`TriggerEvent`).

| Evento | Argumentos | Qué hace |
| --- | --- | --- |
| `chat:addMessage` | `message: ChatMessage \| string` | Muestra una línea. |
| `chatMessage` | `author: string, color: [r, g, b], text: string` | Muestra una línea (estilo antiguo). |
| `chat:addSuggestion` | `name: string, help: string, params?: { name, help }[]` | Añade una sugerencia. |
| `chat:addSuggestions` | `suggestions: { name, help, params? }[]` | Añade varias sugerencias. |
| `chat:removeSuggestion` | `name: string` | Quita una sugerencia. |
| `chat:addMode` / `chat:removeMode` | `mode` / `name` | Añade o quita un modo de script en este cliente. |
| `chat:clear` | ninguno | Vacía el chat de este jugador. |

<Callout type="warn">
`chat:addTemplate` se ignora: las plantillas (HTML) nunca se dibujan. Los mensajes que escriben los jugadores no se envían por `_chat:messageEntered`; escucha `chatMessage` en el servidor.
</Callout>
