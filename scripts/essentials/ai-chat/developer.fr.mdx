ai-chat répond à l’API de la ressource `chat` de FiveM, donc vous écrivez votre code de chat de la façon standard de FiveM. Les exports répondent sous `exports['ai-chat']` comme sous `exports.chat`.

## ChatMessage

La forme de message que prennent chaque export et chaque event.

## Exports serveur

### addMessage

Envoie une ligne de chat à un joueur, à plusieurs joueurs ou à tout le monde.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
addMessage(target: number | number[], message: ChatMessage): void
```

```lua title="Lua"
exports.chat:addMessage(source, { args = { 'Bank', 'Your salary arrived.' }, color = { 61, 247, 158 } })
```

#### Paramètres

<TypeTable
  type={{
    target: { type: 'number | number[]', description: 'Un id serveur, une liste d’id serveur, ou `-1` pour tout le monde.', required: true },
    message: { type: 'ChatMessage', description: 'La ligne à afficher.', required: true },
  }}
/>

#### Retour

Rien. Un message sans liste `args` valide est ignoré.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aicore-fivem/lib/server";

function announce(text: string): void {
  callExport("chat", "addMessage", -1, { args: ["City", text], color: [61, 247, 158], multiline: true });
}
announce("The bank closes in 10 minutes.");
```
</Tab>
<Tab value="Lua">
```lua
local function announce(text)
    exports.chat:addMessage(-1, { args = { 'City', text }, color = { 61, 247, 158 }, multiline = true })
end
announce('The bank closes in 10 minutes.')
```
</Tab>
</Tabs>

### registerMessageHook

Exécute votre fonction pour chaque message qu’envoie un joueur, avant sa livraison. Le hook peut modifier le message, changer qui le reçoit, ou l’annuler. Les hooks sont retirés quand votre ressource s’arrête.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
registerMessageHook(hook: (source: number, message: ChatMessage, ref: HookRef) => void): void
```

#### HookRef

<TypeTable
  type={{
    updateMessage: { type: '(change: Partial<ChatMessage>) => void', description: 'Fusionne `change` dans le message.' },
    cancel: { type: '() => void', description: 'Abandonne le message : personne ne le reçoit.' },
    setRouting: { type: '(target: number | number[]) => void', description: 'L’envoie plutôt à ces id serveur (`-1` pour tout le monde).' },
  }}
/>

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aicore-fivem/lib/server";

callExport("chat", "registerMessageHook", (source: number, message: { args: string[] }, ref: { cancel(): void }) => {
  const text = message.args[message.args.length - 1] ?? "";
  if (/discord\.gg\//i.test(text)) ref.cancel();
});
```
</Tab>
<Tab value="Lua">
```lua
exports.chat:registerMessageHook(function(source, message, ref)
    local text = message.args[#message.args] or ''
    if text:lower():find('discord%.gg/') then ref.cancel() end
end)
```
</Tab>
</Tabs>

### registerMode

Ajoute un canal depuis un script (les modes de chat de FiveM). Son callback décide qui reçoit chaque message, comme un hook de message. Le mode est retiré quand votre ressource s’arrête.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
registerMode(data: { name: string; displayName?: string; color?: string; cb?: (source: number, message: ChatMessage, ref: HookRef) => void }): void
```

<TypeTable
  type={{
    name: { type: 'string', description: 'Id du mode.', required: true },
    displayName: { type: 'string', description: 'Texte affiché pour le mode.', default: 'name' },
    color: { type: 'string', description: 'Couleur CSS du mode.', default: '"#ffffff"' },
    cb: { type: '(source, message, ref) => void', description: 'Achemine chaque message du mode (`ref.setRouting`, `ref.cancel`).' },
  }}
/>

## Exports client

| Export | Ce qu’il fait |
| --- | --- |
| `addMessage(message: ChatMessage \| string): void` | Affiche une ligne uniquement dans le chat de ce joueur. |
| `addSuggestion(name: string, help: string, params?: { name: string, help: string }[]): void` | Ajoute une suggestion de commande pour ce joueur. |

## Events

### chatMessage (serveur)

Se déclenche sur le serveur pour chaque message qu’envoie un joueur, avant sa livraison. Annulez-le (`CancelEvent()`) pour abandonner le message.

**Côté :** serveur (event local)

| Argument | Type | Ce que c’est |
| --- | --- | --- |
| `source` | `number` | L’id serveur de l’expéditeur. |
| `author` | `string` | L’auteur affiché (le nom du personnage). |
| `text` | `string` | Le texte du message. |

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
on("chatMessage", (source: number, author: string, text: string) => {
  console.log(`[chat] ${author} (${source}): ${text}`);
});
```
</Tab>
<Tab value="Lua">
```lua
AddEventHandler('chatMessage', function(source, author, text)
    print(('[chat] %s (%d): %s'):format(author, source, text))
end)
```
</Tab>
</Tabs>

### Events client qu’écoute ai-chat

Envoyez-les depuis le serveur (`TriggerClientEvent`) ou depuis un script client (`TriggerEvent`).

| Event | Arguments | Ce qu’il fait |
| --- | --- | --- |
| `chat:addMessage` | `message: ChatMessage \| string` | Affiche une ligne. |
| `chatMessage` | `author: string, color: [r, g, b], text: string` | Affiche une ligne (ancien style). |
| `chat:addSuggestion` | `name: string, help: string, params?: { name, help }[]` | Ajoute une suggestion. |
| `chat:addSuggestions` | `suggestions: { name, help, params? }[]` | Ajoute plusieurs suggestions. |
| `chat:removeSuggestion` | `name: string` | Retire une suggestion. |
| `chat:addMode` / `chat:removeMode` | `mode` / `name` | Ajoute ou retire un mode de script sur ce client. |
| `chat:clear` | aucun | Vide le chat de ce joueur. |

<Callout type="warn">
`chat:addTemplate` est ignoré : les modèles (HTML) ne sont jamais rendus. Les messages tapés par les joueurs ne passent pas par `_chat:messageEntered` ; écoutez `chatMessage` sur le serveur.
</Callout>
