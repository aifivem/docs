O ai-chat responde à API do recurso `chat` do FiveM, então você escreve código de chat do jeito padrão do FiveM. Os exports respondem tanto em `exports['ai-chat']` quanto em `exports.chat`.

## ChatMessage

## Exports do servidor

### addMessage

Envia uma linha de chat para um jogador, vários jogadores ou todos.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
addMessage(target: number | number[], message: ChatMessage): void
```

```lua title="Lua"
exports.chat:addMessage(source, { args = { 'Bank', 'Your salary arrived.' }, color = { 61, 247, 158 } })
```

#### Parâmetros

<TypeTable
  type={{
    target: { type: 'number | number[]', description: 'Um id do servidor, uma lista de ids do servidor, ou `-1` para todos.', required: true },
    message: { type: 'ChatMessage', description: 'A linha a mostrar.', required: true },
  }}
/>

#### Retorno

Nada. Uma mensagem sem uma lista `args` válida é descartada.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aicore-fivem/lib/server";

function announce(text: string): void {
  callExport("chat", "addMessage", -1, { args: ["City", text], color: [61, 247, 158], multiline: true });
}
announce("The bank closes in 10 minutes.");
```
</Tab>
<Tab value="Lua">
```lua
local function announce(text)
    exports.chat:addMessage(-1, { args = { 'City', text }, color = { 61, 247, 158 }, multiline = true })
end
announce('The bank closes in 10 minutes.')
```
</Tab>
</Tabs>

### registerMessageHook

Roda sua função para toda mensagem que um jogador envia, antes de ela ser entregue. O hook pode mudar a mensagem, mudar quem a recebe, ou cancelá-la. Os hooks são removidos quando seu recurso para.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
registerMessageHook(hook: (source: number, message: ChatMessage, ref: HookRef) => void): void
```

#### HookRef

<TypeTable
  type={{
    updateMessage: { type: '(change: Partial<ChatMessage>) => void', description: 'Mescla `change` na mensagem.' },
    cancel: { type: '() => void', description: 'Descarta a mensagem: ninguém a recebe.' },
    setRouting: { type: '(target: number | number[]) => void', description: 'Envia para estes ids do servidor no lugar (`-1` para todos).' },
  }}
/>

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aicore-fivem/lib/server";

callExport("chat", "registerMessageHook", (source: number, message: { args: string[] }, ref: { cancel(): void }) => {
  const text = message.args[message.args.length - 1] ?? "";
  if (/discord\.gg\//i.test(text)) ref.cancel();
});
```
</Tab>
<Tab value="Lua">
```lua
exports.chat:registerMessageHook(function(source, message, ref)
    local text = message.args[#message.args] or ''
    if text:lower():find('discord%.gg/') then ref.cancel() end
end)
```
</Tab>
</Tabs>

### registerMode

Adiciona um canal a partir de um script (os modos de chat do FiveM). O callback dele decide quem recebe cada mensagem, como um hook de mensagem. O modo é removido quando seu recurso para.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
registerMode(data: { name: string; displayName?: string; color?: string; cb?: (source: number, message: ChatMessage, ref: HookRef) => void }): void
```

<TypeTable
  type={{
    name: { type: 'string', description: 'Id do modo.', required: true },
    displayName: { type: 'string', description: 'Texto mostrado para o modo.', default: 'name' },
    color: { type: 'string', description: 'Cor CSS do modo.', default: '"#ffffff"' },
    cb: { type: '(source, message, ref) => void', description: 'Direciona cada mensagem do modo (`ref.setRouting`, `ref.cancel`).' },
  }}
/>

## Exports do cliente

| Export | O que faz |
| --- | --- |
| `addMessage(message: ChatMessage \| string): void` | Mostra uma linha só no chat deste jogador. |
| `addSuggestion(name: string, help: string, params?: { name: string, help: string }[]): void` | Adiciona uma sugestão de comando para este jogador. |

## Eventos

### chatMessage (server)

Disparado no servidor para toda mensagem que um jogador envia, antes da entrega. Cancele-o (`CancelEvent()`) para descartar a mensagem.

**Lado:** Servidor (evento local)

| Argumento | Tipo | O que é |
| --- | --- | --- |
| `source` | `number` | O id do servidor de quem envia. |
| `author` | `string` | O autor mostrado (o nome do personagem). |
| `text` | `string` | O texto da mensagem. |

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
on("chatMessage", (source: number, author: string, text: string) => {
  console.log(`[chat] ${author} (${source}): ${text}`);
});
```
</Tab>
<Tab value="Lua">
```lua
AddEventHandler('chatMessage', function(source, author, text)
    print(('[chat] %s (%d): %s'):format(author, source, text))
end)
```
</Tab>
</Tabs>

### Eventos de cliente que o ai-chat escuta

Envie-os a partir do servidor (`TriggerClientEvent`) ou de um script de cliente (`TriggerEvent`).

| Evento | Argumentos | O que faz |
| --- | --- | --- |
| `chat:addMessage` | `message: ChatMessage \| string` | Mostra uma linha. |
| `chatMessage` | `author: string, color: [r, g, b], text: string` | Mostra uma linha (estilo antigo). |
| `chat:addSuggestion` | `name: string, help: string, params?: { name, help }[]` | Adiciona uma sugestão. |
| `chat:addSuggestions` | `suggestions: { name, help, params? }[]` | Adiciona várias sugestões. |
| `chat:removeSuggestion` | `name: string` | Remove uma sugestão. |
| `chat:addMode` / `chat:removeMode` | `mode` / `name` | Adiciona ou remove um modo de script neste cliente. |
| `chat:clear` | nenhum | Esvazia o chat deste jogador. |

<Callout type="warn">
`chat:addTemplate` é ignorado: templates (HTML) nunca são desenhados. Mensagens digitadas por jogadores não são enviadas por `_chat:messageEntered`; escute `chatMessage` no servidor.
</Callout>
