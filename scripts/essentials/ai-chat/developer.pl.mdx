ai-chat odpowiada na API zasobu `chat` z FiveM, więc kod czatu piszesz standardowo, jak w FiveM. Eksporty odpowiadają zarówno pod `exports['ai-chat']`, jak i `exports.chat`.

## ChatMessage

## Eksporty serwera

### addMessage

Wysyła linię czatu do jednego gracza, kilku graczy lub wszystkich.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
addMessage(target: number | number[], message: ChatMessage): void
```

```lua title="Lua"
exports.chat:addMessage(source, { args = { 'Bank', 'Your salary arrived.' }, color = { 61, 247, 158 } })
```

#### Parametry

<TypeTable
  type={{
    target: { type: 'number | number[]', description: 'ID gracza na serwerze, lista takich ID albo `-1` dla wszystkich.', required: true },
    message: { type: 'ChatMessage', description: 'Linia do pokazania.', required: true },
  }}
/>

#### Zwraca

Nic. Wiadomość bez prawidłowej listy `args` jest odrzucana.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

function announce(text: string): void {
  callExport("chat", "addMessage", -1, { args: ["City", text], color: [61, 247, 158], multiline: true });
}
announce("The bank closes in 10 minutes.");
```
</Tab>
<Tab value="Lua">
```lua
local function announce(text)
    exports.chat:addMessage(-1, { args = { 'City', text }, color = { 61, 247, 158 }, multiline = true })
end
announce('The bank closes in 10 minutes.')
```
</Tab>
</Tabs>

### registerMessageHook

Uruchamia twoją funkcję dla każdej wiadomości wysłanej przez gracza, zanim zostanie dostarczona. Hook może zmienić wiadomość, zmienić odbiorców albo ją anulować. Hooki są usuwane, gdy twój zasób się zatrzymuje.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
registerMessageHook(hook: (source: number, message: ChatMessage, ref: HookRef) => void): void
```

#### HookRef

<TypeTable
  type={{
    updateMessage: { type: '(change: Partial<ChatMessage>) => void', description: 'Scala `change` z wiadomością.' },
    cancel: { type: '() => void', description: 'Odrzuca wiadomość: nikt jej nie dostaje.' },
    setRouting: { type: '(target: number | number[]) => void', description: 'Wysyła ją zamiast tego do tych ID graczy (`-1` dla wszystkich).' },
  }}
/>

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

callExport("chat", "registerMessageHook", (source: number, message: { args: string[] }, ref: { cancel(): void }) => {
  const text = message.args[message.args.length - 1] ?? "";
  if (/discord\.gg\//i.test(text)) ref.cancel();
});
```
</Tab>
<Tab value="Lua">
```lua
exports.chat:registerMessageHook(function(source, message, ref)
    local text = message.args[#message.args] or ''
    if text:lower():find('discord%.gg/') then ref.cancel() end
end)
```
</Tab>
</Tabs>

### registerMode

Dodaje kanał ze skryptu (tryby czatu FiveM). Jego callback decyduje, kto dostaje każdą wiadomość, jak hook wiadomości. Tryb jest usuwany, gdy twój zasób się zatrzymuje.

**Strona:** serwer · **Czeka:** nie

```ts title="Sygnatura"
registerMode(data: { name: string; displayName?: string; color?: string; cb?: (source: number, message: ChatMessage, ref: HookRef) => void }): void
```

## Eksporty klienta

| Eksport | Co robi |
| --- | --- |
| `addMessage(message: ChatMessage \| string): void` | Pokazuje linię tylko na czacie tego gracza. |
| `addSuggestion(name: string, help: string, params?: { name: string, help: string }[]): void` | Dodaje podpowiedź komendy dla tego gracza. |

## Zdarzenia

### chatMessage (server)

Wywoływane na serwerze dla każdej wiadomości wysłanej przez gracza, przed dostarczeniem. Anuluj je (`CancelEvent()`), aby odrzucić wiadomość.

**Strona:** serwer (zdarzenie lokalne)

| Argument | Typ | Co to jest |
| --- | --- | --- |
| `source` | `number` | ID nadawcy na serwerze. |
| `author` | `string` | Pokazywany autor (imię postaci). |
| `text` | `string` | Tekst wiadomości. |

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
on("chatMessage", (source: number, author: string, text: string) => {
  console.log(`[chat] ${author} (${source}): ${text}`);
});
```
</Tab>
<Tab value="Lua">
```lua
AddEventHandler('chatMessage', function(source, author, text)
    print(('[chat] %s (%d): %s'):format(author, source, text))
end)
```
</Tab>
</Tabs>

### Zdarzenia klienta, których nasłuchuje ai-chat

Wysyłaj je z serwera (`TriggerClientEvent`) lub ze skryptu klienta (`TriggerEvent`).

| Zdarzenie | Argumenty | Co robi |
| --- | --- | --- |
| `chat:addMessage` | `message: ChatMessage \| string` | Pokazuje linię. |
| `chatMessage` | `author: string, color: [r, g, b], text: string` | Pokazuje linię (stary styl). |
| `chat:addSuggestion` | `name: string, help: string, params?: { name, help }[]` | Dodaje jedną podpowiedź. |
| `chat:addSuggestions` | `suggestions: { name, help, params? }[]` | Dodaje kilka podpowiedzi. |
| `chat:removeSuggestion` | `name: string` | Usuwa podpowiedź. |
| `chat:addMode` / `chat:removeMode` | `mode` / `name` | Dodaje lub usuwa tryb skryptu na tym kliencie. |
| `chat:clear` | brak | Czyści czat tego gracza. |

<Callout type="warn">
`chat:addTemplate` jest ignorowane: szablony (HTML) nigdy nie są rysowane. Wiadomości wpisywane przez graczy nie są wysyłane przez `_chat:messageEntered`; nasłuchuj `chatMessage` na serwerze.
</Callout>
