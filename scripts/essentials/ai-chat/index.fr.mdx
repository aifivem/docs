ai-chat est la boîte de chat. Les joueurs écrivent dans les canaux que vous réglez dans le panneau (tout le monde, les joueurs à proximité, un métier), exécutent des commandes avec des suggestions limitées aux commandes qu’ils peuvent utiliser, et montrent des actions au-dessus de leur tête avec `/me`.

## Ce qu’il fait en jeu

- **Canaux.** Chaque canal a un nom, une couleur et une portée : tout le serveur, ou seulement les joueurs à quelques mètres. Un canal peut être limité à des métiers et des gangs. Les joueurs ne voient que les canaux qu’ils peuvent utiliser.
- **Changer de canal.** **Tab** parcourt les canaux (et le mode Command, ci-dessous). Le chat s’ouvre sur le premier canal.
- **Commandes.** Une ligne qui commence par `/` exécute une commande dans n’importe quel canal. Les suggestions ne listent que les commandes que le joueur a le droit d’utiliser, avec leurs arguments.
- **Commandes sans /** (facultatif) : la saisie s’ouvre en mode Command, où la commande se tape sans la barre oblique.
- **Historique.** **Haut** et **Bas** parcourent les lignes que vous avez envoyées, tant que la saisie est vide.
- **Couleurs.** Les codes couleur GTA `^0` à `^9` fonctionnent. Le HTML venant des scripts n’est jamais rendu.
- **Disparition.** Le chat s’estompe quelques secondes après le dernier message tant qu’il est fermé.
- **Les noms des auteurs** sont les noms des personnages.
- Les messages ne sont pas stockés. Ils vont dans le canal de logs `messages` via AI Core.

## Installation

La recipe txAdmin d’AI Core l’installe. À la main : placez le dossier dans `resources/[ai]/` et ajoutez `ensure ai-chat` à `server.cfg` après `ensure ai-core`. Il nécessite ai-core. Il n’a pas de table de base de données.

Retirez la ressource `chat` propre à FiveM et gardez `set resources_useSystemChat false` dans votre cfg : ai-chat fournit `chat`.

## Réglages du panneau

Ouvrez le panneau d’administration (**F10**) et choisissez **Chat**.

### Onglet Channels

Où les joueurs écrivent. Chaque canal est un enregistrement ; appuyez sur **New channel** pour en ajouter un.

| Réglage | Ce qu’il change | Valeurs | Défaut pour un nouveau canal |
| --- | --- | --- | --- |
| Name | L’étiquette du canal affichée avant l’auteur. | 1 à 24 caractères | |
| Colour | Couleur de l’étiquette du canal et de l’auteur, au format `#RRGGBB`. | une couleur hexadécimale | `#36ff9f` |
| Range | Seuls les joueurs aussi proches de l’auteur le lisent. 0 signifie tout le serveur. | 0 à 1000 m | 0 |
| Jobs | Seuls les membres de ces métiers peuvent l’utiliser. Laissez les métiers et les gangs vides pour tout le monde. | noms de métiers | vide |
| Gangs | Les membres de ces gangs peuvent aussi l’utiliser. | noms de gangs | vide |
| Only on duty | Les membres d’un métier doivent être en service dans ce métier. | activé / désactivé | désactivé |
| Order | Le plus petit vient en premier ; le premier canal est celui où s’ouvre le chat. | 0 à 100 | 10 |

Canaux livrés avec le script :

| Canal | Portée | Qui | Ordre |
| --- | --- | --- | --- |
| Local | 20 m | tout le monde | 0 |
| OOC | tout le serveur | tout le monde | 1 |
| Police | tout le serveur | le métier `police` | 2 |

### Onglet Settings

**Messages** : les règles de chaque message.

| Réglage | Ce qu’il change | Valeurs | Défaut |
| --- | --- | --- | --- |
| Longest message | Les messages plus longs sont coupés. | 16 à 1000 caractères | 256 |
| Stays on screen | Secondes pendant lesquelles les messages restent visibles après un nouveau message tant que le chat est fermé. | 2 à 60 s | 8 |
| Messages kept | Combien de messages chaque joueur garde pour remonter l’historique. | 20 à 500 | 100 |
| Join and leave messages | Prévient tout le monde quand un joueur arrive ou part. | activé / désactivé | désactivé |
| Commands without / | La saisie s’ouvre en mode Command : les joueurs tapent une commande sans la barre oblique. Tab parcourt Command et les canaux ; une ligne qui commence par `/` s’exécute toujours comme une commande dans n’importe quel canal. | activé / désactivé | activé |

## Commandes

| Commande | Arguments | Qui | Ce qu’elle fait |
| --- | --- | --- | --- |
| `/ooc` | `<message>` | tout le monde | Une ligne hors personnage (`OOC \| <nom FiveM>`) pour vous et les joueurs à moins de 20 m. |
| `/me` | `<message>` | tout le monde | Affiche une action au-dessus de votre tête (« allume une cigarette ») pendant 7 secondes, pour vous et les joueurs à moins de 20 m. Jusqu’à 120 caractères. |

## Raccourcis clavier

| Touche par défaut | Ce qu’elle fait | Nom dans les réglages de GTA |
| --- | --- | --- |
| T | Ouvre la saisie du chat | Open the chat |

Dans le chat ouvert : **Tab** change de canal, **Haut** / **Bas** parcourent les lignes envoyées ou les suggestions, **Entrée** envoie (ou prend la suggestion choisie), **Échap** ferme.

## Fonctionne avec d’autres scripts

- **Remplace la ressource `chat` de FiveM** (`provide 'chat'`). Chaque script qui envoie `chat:addMessage`, `chatMessage`, ajoute des suggestions ou appelle `exports.chat:addMessage` fonctionne sans modification.
- Les commandes créées avec la lib d’AI Core (`addCommand`) envoient leur propre aide et leurs arguments comme suggestions.

## Limites connues

- `chat:addTemplate` est ignoré et les modèles HTML ne sont pas rendus : le message affiche son texte brut.
- Les scripts qui écoutent l’event interne `_chat:messageEntered` de FiveM ne voient rien. Utilisez plutôt l’event serveur `chatMessage`.
- Le `setSeObject` des hooks de messages et le filtrage ACE des modes de script ne sont pas pris en charge.
