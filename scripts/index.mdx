AI Core comes with around forty `ai-*` scripts. Together they make a full roleplay server: characters, money, an inventory, a HUD, vehicles, jobs, police, crime and housing. You do not have to use all of them.

## How the scripts fit together

- **Each script is its own resource.** It has its own folder in `resources/[ai]/` and its own `ensure` line in `server.cfg`. Remove the line and the script is gone.
- **Every setting is in the admin panel.** Each script adds its own tabs to the [admin panel](/docs/admin-panel) (press **F10** in the game). You never edit a config file.
- **Scripts talk through AI Core.** When a robbery gives an item, it asks AI Core, and AI Core hands the item to the inventory you run. The robbery script does not know whether that is ai-inventory or another inventory. This is why you can replace almost any `ai-*` script with a third-party script of the same kind (see [Compatibility](/docs/compatibility)).
- **Third-party scripts keep working.** Many `ai-*` scripts also answer the exports of the well-known script they replace. For example, ai-inventory answers `exports.ox_inventory:AddItem(...)`, so a script written for ox_inventory runs unchanged. Each script's page lists what it stands in for.

## How the categories work

The scripts are grouped by what they are for. Each category has an overview page, and each script has its own folder with two pages:

- **The script page** is for server owners: what the script does in the game, how to install it, every panel setting, its commands and keys, and which third-party scripts it works with.
- **The developer page** is for people writing scripts: its exports, events and state bags, with types and examples in TypeScript and Lua.

| Category | What is in it |
| --- | --- |
| [Essentials](/docs/scripts/essentials) | The framework and the scripts every server needs: database, shared UI, loading screen, clothing, inventory, HUD, chat, voice, radial menu, target eye, scoreboard, time and weather. |
| [Vehicles](/docs/scripts/vehicles) | Owned vehicles, keys, fuel, garages, shops, used car lots, rental, mechanics and emergency lights. |
| [Jobs and services](/docs/scripts/jobs) | Work routes, police, police alerts, prison, death and EMS, banking, boss menus and the city hall. |
| [Crime and racing](/docs/scripts/crime) | Robberies, drugs, pawnshops, scrapyards and street races. |
| [World and tools](/docs/scripts/world) | Housing, door locks, many small features, sleeping bodies, character size and admin tools. |

## Default keys

Each player can change every key in GTA's own settings (**Settings > Key Bindings > FiveM**). The owner changes the starting key for everyone in the admin panel (**Keybinds** tab); a player who already changed a key keeps their own.

| Key | Action | Script |
| --- | --- | --- |
| F10 | Admin panel (admins only) | ai-core |
| F9 | Admin quick menu (admins only) | ai-admin |
| F3 | Radial menu | ai-radialmenu |
| F2 | Inventory | ai-inventory |
| TAB | Quick slots bar | ai-inventory |
| 1 to 5 | Use the item in that quick slot | ai-inventory |
| R | Reload the weapon | ai-inventory |
| T | Chat | ai-chat |
| F6 | Police menu (on duty) | ai-police |
| E | Interact with the prompt on screen | ai-lib |
| Backspace | Cancel the running action | ai-lib |
| U | Lock or unlock the vehicle | ai-vehiclekeys |
| M | Engine on / off | ai-vehiclekeys |
| K | Seatbelt | ai-smallresources |
| F11 | Voice range | ai-voice |
| Left Alt | Talk on the radio | ai-voice |
| Home | Scoreboard | ai-scoreboard |

Each script's page lists all of its keys.
