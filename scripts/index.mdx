## Default keys

Every key can be changed by each player in GTA's key settings, and its default by the owner in the admin panel (**Keybinds**).

| Key | Action |
| --- | --- |
| F10 | Admin panel (admins) |
| F9 | Admin quick menu (admins) |
| F1 | Radial menu |
| F2 | Inventory |
| F6 | Police menu (on duty) |
| E | Interact with the prompt on screen |
| Home (hold) | Scoreboard |
| Backspace | Cancel the running action |
