O AI Core vem com cerca de quarenta scripts `ai-*`. Juntos eles formam um servidor de roleplay completo: personagens, dinheiro, um inventário, um HUD, veículos, empregos, polícia, crime e moradia. Você não precisa usar todos.

## Como os scripts se encaixam

- **Cada script é seu próprio recurso.** Ele tem sua própria pasta em `resources/[ai]/` e sua própria linha `ensure` no `server.cfg`. Remova a linha e o script some.
- **Toda configuração fica no painel de administração.** Cada script adiciona suas próprias abas ao [painel de administração](/pt/docs/admin-panel) (aperte **F10** no jogo). Você nunca edita um arquivo de config.
- **Os scripts conversam através do AI Core.** Quando um roubo dá um item, ele pede ao AI Core, e o AI Core entrega o item ao inventário que você usa. O script de roubo não sabe se é o ai-inventory ou outro inventário. É por isso que você pode substituir quase qualquer script `ai-*` por um script de terceiros do mesmo tipo (veja [Compatibilidade](/pt/docs/compatibility)).
- **Scripts de terceiros continuam funcionando.** Muitos scripts `ai-*` também respondem aos exports do script conhecido que substituem. Por exemplo, o ai-inventory responde a `exports.ox_inventory:AddItem(...)`, então um script escrito para o ox_inventory roda sem alterações. A página de cada script lista o que ele substitui.

## Como funcionam as categorias

Os scripts são agrupados pelo que fazem. Cada categoria tem uma página de visão geral, e cada script tem sua própria pasta com duas páginas:

- **A página do script** é para donos de servidor: o que o script faz no jogo, como instalá-lo, cada configuração do painel, seus comandos e teclas, e com quais scripts de terceiros ele funciona.
- **A página para desenvolvedores** é para quem escreve scripts: seus exports, eventos e state bags, com tipos e exemplos em TypeScript e Lua.

| Categoria | O que tem nela |
| --- | --- |
| [Essenciais](/pt/docs/scripts/essentials) | O framework e os scripts que todo servidor precisa: banco de dados, UI compartilhada, tela de carregamento, roupas, inventário, HUD, chat, voz, menu radial, target, placar, hora e clima. |
| [Veículos](/pt/docs/scripts/vehicles) | Veículos próprios, chaves, combustível, garagens, lojas, pátios de carros usados, aluguel, mecânicos e luzes de emergência. |
| [Empregos e serviços](/pt/docs/scripts/jobs) | Rotas de trabalho, polícia, alertas da polícia, prisão, morte e EMS, banco, menus do chefe e a prefeitura. |
| [Crime e corridas](/pt/docs/scripts/crime) | Roubos, drogas, casas de penhores, ferros-velhos e corridas de rua. |
| [Mundo e ferramentas](/pt/docs/scripts/world) | Moradia, trancas de portas, muitos recursos pequenos, corpos dormindo, tamanho do personagem e ferramentas de administração. |

## Teclas padrão

Cada jogador pode trocar qualquer tecla nas próprias configurações do GTA (**Settings > Key Bindings > FiveM**). O dono troca a tecla inicial de todos no painel de administração (aba **Keybinds**); um jogador que já trocou uma tecla mantém a sua.

| Tecla | Ação | Script |
| --- | --- | --- |
| F10 | Painel de administração (só administradores) | ai-core |
| F9 | Menu rápido de administração (só administradores) | ai-admin |
| F3 | Menu radial | ai-radialmenu |
| F2 | Inventário | ai-inventory |
| TAB | Barra de atalhos rápidos | ai-inventory |
| 1 a 5 | Usa o item daquele atalho rápido | ai-inventory |
| R | Recarrega a arma | ai-inventory |
| T | Chat | ai-chat |
| F6 | Menu da polícia (em serviço) | ai-police |
| E | Interage com o aviso na tela | ai-lib |
| Backspace | Cancela a ação em andamento | ai-lib |
| U | Tranca ou destranca o veículo | ai-vehiclekeys |
| M | Liga / desliga o motor | ai-vehiclekeys |
| K | Cinto de segurança | ai-smallresources |
| F11 | Alcance da voz | ai-voice |
| Alt esquerdo | Fala no rádio | ai-voice |
| Home | Placar | ai-scoreboard |

A página de cada script lista todas as suas teclas.
