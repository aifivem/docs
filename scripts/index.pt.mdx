O AI Core vem com cerca de quarenta scripts `ai-*`. Cada um é seu próprio repositório, é configurado no [painel de administração](/pt/docs/admin-panel) e fala com os outros só através do AI Core, então você pode remover qualquer um deles ou substituí-lo por um script de terceiros.

## Teclas padrão

Cada tecla pode ser alterada por cada jogador nas configurações de teclas do GTA, e seu padrão pelo dono no painel de administração (**Keybinds**).

| Tecla | Ação |
| --- | --- |
| F10 | Painel de administração (administradores) |
| F9 | Menu rápido de administração (administradores) |
| F1 | Menu radial |
| F2 | Inventário |
| F6 | Menu da polícia (em serviço) |
| E | Interagir com o aviso na tela |
| Home (segurar) | Placar |
| Backspace | Cancelar a ação em andamento |
