<Callout type="info">
Para prender a partir do seu script, use `prison.jail`, `prison.release` e `prison.timeLeft` da lib (TypeScript) ou `aiLib.prison.*` (Lua). Eles passam pela camada de prisão do AI Core e chegam a qualquer script de prisão que estiver rodando (ai-prison, qb-prison, rcore_prison, xt-prison, tgiann-policejob). Os exports mais abaixo são o que essa camada chama enquanto o ai-prison roda.
</Callout>

## Funções da lib (recomendado)

### prison.jail

Manda um jogador carregado para a prisão por alguns minutos. Com o ai-prison: o jogador vai para uma cela, os itens são retirados (interruptor no painel), a pena é cortada para **Longest sentence**, e um registro `jail` é escrito no MDT.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
prison.jail(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local ok = aiLib.prison.jail(source, minutes, by)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id do servidor do jogador a prender. Precisa de um personagem carregado.', required: true },
    minutes: { type: 'number', description: 'Duração da pena em minutos. O ai-prison arredonda para baixo, aumenta para pelo menos 1 e corta para a Longest sentence do painel.', required: true },
    by: { type: 'number', description: 'Id do servidor de quem o mandou (o policial), para o log e o registro do MDT. 0 = ninguém.', default: '0' },
  }}
/>

#### Retorno

`true` quando o script de prisão aceitou a pena. `false` quando nenhum script de prisão está rodando ou o jogador não tem um personagem carregado.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, prison } from "@aicore-fivem/lib/server";

// /judge <id> <minutes>: para jogadores com o principal de juiz.
addCommand(
  "judge",
  {
    help: "Sentence a player",
    restricted: "ai.job.judge",
    params: [
      { name: "id", type: "playerId" },
      { name: "minutes", type: "number" },
    ] as const,
  },
  (source, { id, minutes }) => {
    if (!prison.jail(id, minutes, source))
      notify(source, "No prison is running", "error");
  },
);
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
aiLib.addCommand('judge', {
  help = 'Sentence a player',
  restricted = 'ai.job.judge',
  params = {
    { name = 'id', type = 'playerId' },
    { name = 'minutes', type = 'number' },
  },
}, function(source, args)
  if not aiLib.prison.jail(args.id, args.minutes, source) then
    aiLib.notify(source, 'No prison is running', 'error')
  end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Prender um jogador que já está preso **define** a pena com a nova duração (não soma). Com o tgiann-policejob como script de prisão, os minutos são somados.
</Callout>

### prison.release

Solta um jogador preso agora. Com o ai-prison: ele vai para o ponto de soltura e recebe de volta os itens retirados.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
prison.release(source: number): boolean
```

```lua title="Lua"
local ok = aiLib.prison.release(source)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id do servidor do jogador preso.', required: true },
  }}
/>

#### Retorno

`true` quando o jogador estava preso e agora está livre. `false` quando ele não estava preso ou nenhum script de prisão está rodando.

### prison.timeLeft

Minutos de pena restantes.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
prison.timeLeft(source: number): number
```

```lua title="Lua"
local minutes = aiLib.prison.timeLeft(source)
```

#### Retorno

Os minutos restantes, `0` quando o jogador está livre ou nenhum script de prisão está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory, notify, prison } from "@aicore-fivem/lib/server";

inventory.registerUsableItem("phone", (source: number) => {
  if (prison.timeLeft(source) > 0) {
    notify(source, "No phones in prison", "error");
    return;
  }
  // ... abre o celular
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.inventory.registerUsableItem('phone', function(source)
  if aiLib.prison.timeLeft(source) > 0 then
    aiLib.notify(source, 'No phones in prison', 'error')
    return
  end
  -- ... abre o celular
end)
```
</Tab>
</Tabs>

## Exports do servidor

A camada de prisão chama estes enquanto o ai-prison roda. Eles não são tipados em `@aicore-fivem/shared`: em TypeScript chame-os com `callExport("ai-prison", name, ...args)`. Cada export também responde com seu equivalente em minúsculas (`jailPlayer`).

### JailPlayer

```ts title="Signature"
JailPlayer(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-prison']:JailPlayer(source, minutes, by)
```

Mesmo comportamento e valor de retorno que `prison.jail`. Responde `false` quando `source` ou `minutes` não é um número.

### ReleasePlayer

```ts title="Signature"
ReleasePlayer(source: number): boolean
```

```lua title="Lua"
local ok = exports['ai-prison']:ReleasePlayer(source)
```

`true` quando o jogador estava preso e agora foi solto; `false` caso contrário.

### GetJailTime

```ts title="Signature"
GetJailTime(source: number): number
```

```lua title="Lua"
local minutes = exports['ai-prison']:GetJailTime(source)
```

Minutos restantes, `0` quando livre.

## Metadata de personagem

O ai-prison mantém seu estado na metadata de personagem do ai-core (leia com `GetMeta(source, key)` nos exports do ai-core, ou `PlayerData.metadata` pela ponte QB).

| Chave | Tipo | O que guarda |
| --- | --- | --- |
| `injail` | `number` | Minutos restantes (a chave do QBCore). Escrever um número acima de 0 a partir de outro script começa uma pena; escrever 0 solta. |
| `jailitems` | `{ name: string; count: number; metadata?: object }[] \| null` | Os itens retirados no portão, devolvidos na soltura. |
| `ai:jailLeftAt` | `number \| null` | Momento (ms desde 1970) em que o jogador saiu enquanto preso, definido só quando **Count time offline** está ligado. |

<Callout type="warn">
Prefira `prison.jail` a escrever `injail`: ele funciona com todo script de prisão, enquanto `injail` só é lido pelo ai-prison e por prisões no estilo QB.
</Callout>

## Eventos e callbacks privados

O contrato próprio do script (`resource/common/prison.ts`). Eles podem mudar entre versões: não os dispare nem os escute a partir de outros recursos.

| Nome | Direção | O que carrega |
| --- | --- | --- |
| `ai-prison:client:state` | servidor -> jogador preso | `(minutes)`: minutos restantes, 0 quando livre (no carregamento, a cada minuto, na soltura). |
| `ai-prison:client:move` | servidor -> jogador preso | `(point)`: teleporta para uma cela, de volta para dentro depois de uma fuga, ou para fora na soltura. |
| `ai-prison:workStart` | callback do cliente | `(taskId)`: trabalha em um ponto; o servidor roda a barra de progresso, depois desconta minutos. |
| `ai-prison:canteen` | callback do cliente | `()`: uma refeição da cantina. |
