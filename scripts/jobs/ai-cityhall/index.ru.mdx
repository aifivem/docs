ai-cityhall отвечает за стойку мэрии. В центре занятости игроки берут общественную работу (такси, дальнобойщик, мусоровоз...) с её начальным рангом. У стойки документов они покупают удостоверение личности или водительские права. Использование документа показывает карточку с фото владельца на экране у всех, кто стоит рядом с ним.

## Что он делает в игре

- **Стойка.** Подойдите к стойке мэрии и откройте меню (меню ai-lib): **Job center** и **Documents**.
- **Центр занятости.** Показывает общественные работы из панели с их названиями из ai-core. Выбор одной выставляет игроку работу с рангом из панели. Работы, которых нет в ai-core, пропускаются.
- **Документы.** Купите предмет-документ по его цене, оплата со счетов из панели по порядку. Предмет содержит имя и фамилию владельца, дату рождения, пол, национальность и citizen id.
- **Показ документа.** Использование предмета проигрывает короткую анимацию показа и выводит карточку на экран у всех в пределах 3 м, включая владельца, на время из панели. Предмет остаётся у вас. Фото является лицом владельца, которое создаётся на ходу в игре каждого зрителя; у карточки, которую показывает не её владелец, фото нет.

## Установка

Устанавливается рецептом AI Core. Вручную: `ensure ai-cityhall` после `ensure ai-core`. Нужен `ai-core`.

Документами являются предметы `id_card` и `driver_license` (в ai-inventory они есть в списке предметов по умолчанию). С другим инвентарём добавьте эти предметы как уникальные (не складываемые в стак). Предмет-документ, добавленный в панели, работает сразу.

## Настройки панели

Админ-панель > **City hall**. Значения по умолчанию берутся из `data/halls.json` и `data/settings.json`.

### Вкладка City halls

Одна запись на мэрию. По умолчанию: одна City Hall с NPC `a_m_m_hasjew_01`.

| Настройка | Что меняет | Единица | По умолчанию для новой мэрии |
| --- | --- | --- | --- |
| Name | Название мэрии, показывается на блипе. 1-48 символов. | | City Hall |
| Counter | Где игроки открывают меню. Встаньте у стойки и используйте свою позицию. | | 0, 0, 0 |
| Reach | Насколько близко игрок должен быть к стойке. 1-20. | м | 2.5 |
| Map blip | Показывает мэрию на карте. | | вкл. |
| Blip look | Спрайт, цвет и размер (показывается, когда включено **Map blip**). | | спрайт 419, цвет 0, размер 0.7 |

У каждой мэрии также есть карточка **NPC**: **Model** (пусто означает без NPC), **What it does** (анимация ожидания) и **Where it stands**.

### Вкладка Offers

Этот файл остаётся на сервере; игроки получают предложение, когда открывают стойку.

**Job center** (центр занятости): общественные работы и ранг, с которого начинает новый участник.

| Настройка | Что меняет | По умолчанию |
| --- | --- | --- |
| Jobs | До 30 строк, каждая из них **Job** (её название в ai-core) и **Grade** (0-50), с которого начинает игрок. | trucker, taxi, tow, reporter, garbage, bus, hotdog, все с рангом 0 |

**Documents** (документы): предметы, которые игроки здесь покупают.

| Настройка | Что меняет | Единица | По умолчанию |
| --- | --- | --- | --- |
| Documents | До 20 строк, каждая из них **Item** и **Price** (0-1,000,000). | $ | `id_card` $50, `driver_license` $250 |
| Paid from | Денежные счета, которые проверяются по порядку. До 5. | | cash, bank |
| Shown document stays | Сколько секунд документ остаётся на экранах игроков, которым его показали (все в пределах 3 м и владелец). 2-60. | с | 8 |

## Команды

Нет.

## Привязки клавиш

Нет. Стойка использует **Interaction style** из ai-core (подсказка с **E** или опция target).

## Что он заменяет

Нет `fxProvide`. Он выполняет работу qb-cityhall (список работ по умолчанию взят из qb-cityhall) и qbx_idcard (поля предмета-документа взяты из qbx_idcard), без их экспортов и событий.

## Известные ограничения

- Документ, удалённый из панели, остаётся зарегистрированным как используемый предмет до следующего перезапуска; его использование ничего не делает.
- Сохранённое фото Qbox не используется: фото создаётся на ходу из лица владельца.
- Канал логов: `cityhall`.
