ai-banking ist der Bankbildschirm von AI Core. In einer Bankfiliale zahlen Spieler ein, heben ab, überweisen Geld an andere Spieler und lesen ihren Transaktionsverlauf; Chefs verwalten außerdem das Konto ihres Jobs. Geldautomaten zahlen aus und überweisen. ai-banking hält kein eigenes Geld: Jedes Guthaben ist das von ai-core, sodass das Geld überall dasselbe ist.

## Was es im Spiel macht

- **Bankfiliale.** Geh zur Theke einer Filiale und öffne die Bank. Tabs: die Karte und das Guthaben, Konten, Aktivität und die Formulare zum Einzahlen, Abheben und Überweisen.
- **Geldautomat.** Benutze ein beliebiges Geldautomaten-Prop (die Modelle im Panel). Geldautomaten heben nur ab und überweisen, innerhalb der Geldautomaten-Limits.
- **Überweisungen.** An einen Spieler, der online ist, per Server-ID oder Citizen-ID. Die Überweisungsgebühr aus dem Panel (ein Prozentsatz) zahlt der Absender zusätzlich.
- **Verlauf.** Jede Geldänderung des Kontos, die neueste zuerst, aus dem Hauptbuch von ai-core gelesen, Seite für Seite.
- **Firmenkonten.** Ein Spieler, dessen Job-Rang ein Chefrang ist, sieht das Konto `bank` dieses Jobs und kann ein- und auszahlen. Jeder Chef mit offenem Bildschirm sieht Änderungen sofort.

## Installation

Wird vom Rezept von AI Core installiert. Von Hand: `ensure ai-banking` nach `ensure ai-core`. Es braucht `ai-core`.

Es liest die Konto- und Transaktionstabellen von ai-core und braucht daher eine eigene Datenbank-Berechtigungszeile in der `env.cfg`:

```ini title="env.cfg"
add_convar_permission ai-banking read mysql_connection_string
```

Das Rezept fügt diese Zeile hinzu. Im Panel von ai-core wählt **General > Bank** das Bankskript; `auto` nutzt zuerst ai-banking.

## Panel-Einstellungen

Admin-Panel > **Banking**. Die Standardwerte kommen aus `data/banks.json` und `data/settings.json`.

### Tab Banks

Ein Datensatz pro Filiale. Standard: sechs Fleeca-Filialen, Pacific Standard und Blaine County Savings (Paleto Bay).

| Einstellung | Was sie ändert | Einheit | Standard für eine neue Bank |
| --- | --- | --- | --- |
| Name | Der Name der Filiale, am Blip angezeigt. 1-48 Zeichen. | | Fleeca Bank |
| Counter | Wo Spieler die Bank öffnen. Stell dich an die Theke und nutze deine Position. | | 0, 0, 0 |
| Reach | Wie nah der Spieler an der Theke sein muss. 1-20. | m | 3 |
| Map blip | Zeigt die Filiale auf der Karte. | | an |
| Blip look | Sprite, Farbe und Größe (angezeigt, wenn **Map blip** an ist). | | Sprite 108, Farbe 2, Größe 0.7 |

Jede Filiale hat außerdem eine Karte **NPC**: **Model** (leer bedeutet kein NPC), **What it does** (Leerlaufanimation) und **Where it stands**.

### Tab Rules

Geldautomaten zahlen aus und überweisen; Einzahlungen und Firmenkonten brauchen eine Bank.

| Einstellung | Was sie ändert | Einheit | Standard |
| --- | --- | --- | --- |
| ATM models | Welt-Props, die als Geldautomaten funktionieren. Bis zu 20 Modellnamen. | | `prop_atm_01`, `prop_atm_02`, `prop_atm_03`, `prop_fleeca_atm` |
| ATM limit per action | Höchstbetrag, den eine Abhebung oder Überweisung am Geldautomaten bewegt. Bankfilialen haben kein Limit. 0-10.000.000. | $ | 5.000 |
| ATM limit per day | Höchstbetrag, den ein Charakter in 24 Stunden an Geldautomaten abhebt und überweist. Im Speicher gezählt: Ein Neustart von ai-banking startet jede Zählung neu. 0-100.000.000. | $ | 20.000 |
| Transfer fee | Prozentsatz, der auf Überweisungen an andere Spieler aufgeschlagen wird (0 = kostenlos). 0-50, in Schritten von 0.5. | % | 0 |

## Befehle

Keine.

## Tastenbelegungen

Keine. Filialen und Geldautomaten nutzen den **Interaction style** von ai-core: einen Hinweis mit **E** oder eine Target-Option.

## Was es ersetzt

`fxProvide`: **qb-banking** und **Renewed-Banking**. Skripte, die ihre Firmengeld-Exports nutzen, erreichen ai-banking:

- `exports['qb-banking']:GetAccountBalance(job)`, `AddMoney(job, amount, reason)`, `RemoveMoney(job, amount, reason)`
- `exports['Renewed-Banking']:getAccountMoney(job)`, `addAccountMoney(job, amount, reason)`, `removeAccountMoney(job, amount, reason)`

Das Konto ist ein Job-Name; das Geld ist das Job-Konto `bank` von ai-core.

## Andere Bankskripte

Der Bank-Layer von AI Core unterstützt auch tgiann-bank, Renewed-Banking, qb-banking, okokBankingV2, fd_banking, wasabi_banking, kartik-banking und tgg-banking. Wähle eines im Panel von ai-core (**General > Bank**) und stoppe ai-banking. Siehe [Kompatibilität](/de/docs/compatibility).

## Bekannte Grenzen

- Überweisungen gehen nur an Spieler, die online sind, weil ai-core das Geld von Online-Charakteren im Speicher hält.
- Der Server kann Geldautomaten-Props nicht sehen: Er vertraut der Geldautomaten-Position, die das Spiel des Spielers sendet, und prüft, dass der Spieler innerhalb von 3 m davon bleibt. Deshalb haben Geldautomaten eigene Limits; Filialen haben keine.
- Log-Kanäle: `transfers` und `society`.
