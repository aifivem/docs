<Callout type="info">
O ai-banking não guarda dinheiro próprio. Em código novo, mova o dinheiro de empregos e gangues com os exports de dinheiro compartilhado do ai-core (`GetSharedMoney`, `AddSharedMoney`, `RemoveSharedMoney`) ou com o `money.transfer` da lib, e abra a tela do banco com o `banking.open(source)` da lib. Eles funcionam com todo script de banco. Os exports abaixo existem para que scripts QBCore escritos para o qb-banking ou o Renewed-Banking continuem funcionando.
</Callout>

## Funções da lib (recomendado)

### banking.open

Abre a tela do script de banco ativo para um jogador.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
banking.open(source: number): boolean
```

```lua title="Lua"
local ok = aiLib.banking.open(source)
```

#### Retorno

`true` quando a tela abriu. `false` quando o script de banco não pode ser aberto de fora, ou nenhum está rodando.

<Callout type="warn">
Nem todo script de banco pode ser aberto a partir de outro recurso. Verifique o que `banking.open` responde antes de dizer qualquer coisa ao jogador.
</Callout>

### money.transfer

Move dinheiro entre duas contas em uma única transação do banco de dados, escrevendo as duas linhas de registro. Usado pelo ai-banking em todo depósito, saque e transferência.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
money.transfer(from: MoneyRef, to: MoneyRef, amount: number, reason?: string, fee?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:TransferMoney(from, to, amount, reason, fee)
```

#### Parâmetros

<TypeTable
  type={{
    from: { type: 'MoneyRef', description: 'A conta de onde o dinheiro sai: o `{ source, account }` de um jogador ou o `{ owner, id, account }` de um emprego / gangue.', required: true },
    to: { type: 'MoneyRef', description: 'A conta para onde o dinheiro vai, no mesmo formato.', required: true },
    amount: { type: 'number', description: 'Valor em $.', required: true },
    reason: { type: 'string', description: 'Motivo de registro mostrado no histórico.' },
    fee: { type: 'number', description: 'Valor extra que `from` paga por cima (não é somado a `to`).' },
  }}
/>

#### MoneyRef

<TypeTable
  type={{
    source: { type: 'number', description: 'Formato de jogador: o id do servidor do jogador.' },
    owner: { type: '"job" | "gang"', description: 'Formato compartilhado: de quem é a conta.' },
    id: { type: 'string', description: 'Formato compartilhado: o nome do emprego ou gangue.' },
    account: { type: 'string', description: 'O nome da conta (`cash`, `bank`...).', required: true },
  }}
/>

#### Retorno

`true` quando o dinheiro se moveu. `false` quando falta uma conta, as duas são a mesma, ou `from` não consegue pagar.

#### Exemplo

Um chefe paga um bônus da conta do emprego para o banco de um membro:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money, notify } from "@aifivem/lib/server";

function payBonus(boss: number, member: number, amount: number): void {
  const ok = money.transfer(
    { owner: "job", id: "police", account: "bank" },
    { source: member, account: "bank" },
    amount,
    "bonus",
  );
  notify(boss, ok ? "Bonus paid" : "The job account cannot pay", ok ? "success" : "error");
}
```
</Tab>
<Tab value="Lua">
```lua
local function payBonus(boss, member, amount)
  local ok = exports['ai-core']:TransferMoney(
    { owner = 'job', id = 'police', account = 'bank' },
    { source = member, account = 'bank' },
    amount, 'bonus')
  aiLib.notify(boss, ok and 'Bonus paid' or 'The job account cannot pay', ok and 'success' or 'error')
end
```
</Tab>
</Tabs>

## Exports do servidor

Os três agem sobre a conta `bank` do ai-core de um **emprego** (o nome da conta é o nome do emprego). Eles também respondem como `exports['qb-banking']:<mesmo nome>`, e como `getAccountMoney`, `addAccountMoney` e `removeAccountMoney` do Renewed-Banking. Eles não são tipados em `@aifivem/shared`: em TypeScript use `callExport("ai-banking", name, ...args)`. Cada export também responde com seu equivalente em minúsculas (`getAccountBalance`).

### GetAccountBalance

O saldo da sociedade de um emprego.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
GetAccountBalance(job: string): number
```

```lua title="Lua"
local balance = exports['ai-banking']:GetAccountBalance('police')
-- o mesmo: exports['qb-banking']:GetAccountBalance('police')
-- o mesmo: exports['Renewed-Banking']:getAccountMoney('police')
```

#### Parâmetros

<TypeTable
  type={{
    job: { type: 'string', description: 'O nome do emprego (`police`).', required: true },
  }}
/>

#### Retorno

O saldo em $. `0` quando o emprego não tem conta ou `job` não é um texto.

### AddMoney

Adiciona dinheiro à conta da sociedade de um emprego. Todo chefe com a tela do banco aberta vê o novo saldo.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
AddMoney(job: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = exports['ai-banking']:AddMoney('police', 500, 'fine')
-- o mesmo: exports['Renewed-Banking']:addAccountMoney('police', 500, 'fine')
```

#### Parâmetros

<TypeTable
  type={{
    job: { type: 'string', description: 'O nome do emprego.', required: true },
    amount: { type: 'number', description: 'Valor em $, acima de 0.', required: true },
    reason: { type: 'string', description: 'Motivo de registro mostrado no histórico.', default: '"script"' },
  }}
/>

#### Retorno

`true` quando o dinheiro foi adicionado. `false` quando `job` não é um texto, `amount` não está acima de 0, ou o ai-core recusou (não existe essa conta de emprego).

### RemoveMoney

Tira dinheiro da conta da sociedade de um emprego.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
RemoveMoney(job: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = exports['ai-banking']:RemoveMoney('mechanic', 1200, 'parts')
```

#### Parâmetros

<TypeTable
  type={{
    job: { type: 'string', description: 'O nome do emprego.', required: true },
    amount: { type: 'number', description: 'Valor em $, acima de 0.', required: true },
    reason: { type: 'string', description: 'Motivo de registro mostrado no histórico.', default: '"script"' },
  }}
/>

#### Retorno

`true` quando o dinheiro foi retirado. `false` quando a conta não consegue pagar, não existe, ou os argumentos estão errados.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callExport } from "@aifivem/lib/server";

// Um script de mecânico compra peças com a conta do emprego.
function buyParts(cost: number): boolean {
  return callExport("ai-banking", "RemoveMoney", "mechanic", cost, "parts") === true;
}
```
</Tab>
<Tab value="Lua">
```lua
local function buyParts(cost)
  return exports['ai-banking']:RemoveMoney('mechanic', cost, 'parts') == true
end
```
</Tab>
</Tabs>

<Callout type="warn">
Esses exports só alcançam contas de **empregos**. Para uma conta de gangue use o `AddSharedMoney('gang', name, 'bank', amount, reason)` do ai-core e seus parentes. O dinheiro alterado diretamente pelos exports do ai-core é o mesmo dinheiro, mas as telas de banco abertas só se atualizam na hora para mudanças feitas pelo ai-banking.
</Callout>

## Callbacks privados

As chamadas da tela do banco (`resource/common/bank.ts`): abrir, páginas do histórico, depositar, sacar, transferir e fechar. O servidor verifica a posição da agência ou do caixa eletrônico a cada chamada. Elas podem mudar entre versões: não as chame a partir de outros recursos.
