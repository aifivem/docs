<Callout type="info">
Чтобы отправить вызов полиции из своего скрипта, вызывайте `dispatch.alert(alert)` из lib (TypeScript) или `aiLib.dispatch.alert(alert)` (Lua). Он идёт через слой диспетчера AI Core и попадает в ту систему оповещений, которую использует сервер: ai-policealert или поддерживаемый сторонний скрипт оповещений. Никогда не вызывайте экспорт ai-policealert напрямую.
</Callout>

## dispatch.alert

Отправляет один вызов полиции (или другой работе) через AI Core. Его получают участники `jobs` на дежурстве; без `jobs` его получают собственные полицейские работы системы оповещений (для ai-policealert: **Alert jobs** из панели).

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local sent = aiLib.dispatch.alert(alert) -- boolean
```

#### Возвращает

`true`, если система оповещений приняла вызов. `false`, если ни одна система оповещений не запущена или вызов некорректен (нет `title`).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, onClientCallback } from "@aicore-fivem/lib/server";
import { Locale } from "./locale"; // переведённые тексты вашего ресурса

// Клиент сообщает, что начал взламывать банкомат; сервер вызывает полицию в позицию игрока.
onClientCallback("myscript:breakAtm", (source) => {
  const sent = dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_ATM_TITLE"),
    message: Locale("ALERT_ATM_MESSAGE"),
    source, // coords берутся от этого игрока
    icon: "money-bill",
    priority: "high",
  });
  if (!sent) console.log("no alert system is running");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">

RegisterNetEvent('myscript:breakAtm', function()

<Callout type="warn">
Тексты показываются так, как вы их отправили: переводите их до вызова. Поля, не перечисленные выше, отбрасываются. Не отправляйте вызов на каждое повторяющееся действие: например, ai-police оставляет один вызов о стрельбе на 150 м каждые 30 с.
</Callout>

## Серверный экспорт

### DispatchAlert

Собственная точка входа ai-policealert. Её вызывает только слой диспетчера AI Core, пока ai-policealert является активной системой оповещений; скрипты используют `dispatch.alert` выше. Типизирован как `AiPoliceAlertServerExports` в `@aicore-fivem/shared`.

**Сторона:** сервер · **Ожидание:** нет

```ts title="Сигнатура"
DispatchAlert(alert: DispatchAlert): void
```

```lua title="Lua"
exports['ai-policealert']:DispatchAlert(alert)
```

#### Параметры

<TypeTable
  type={{
    alert: { type: 'DispatchAlert', description: 'Те же поля, что и выше. Проверяются ещё раз: вызов без заголовка отбрасывается.', required: true },
  }}
/>

#### Возвращает

Ничего. Прямой вызов пропускает выбор системы оповещений AI Core, а `coords` не заполняется из `source` (AI Core делает это перед вызовом экспорта).

## Приватные события

Собственный контракт скрипта между сервером и клиентом (`resource/common/alerts.ts`). Они могут меняться между версиями: не вызывайте и не слушайте их из других ресурсов.

| Имя | Направление | Что передаёт |
| --- | --- | --- |
| `ai-policealert:client:alerts` | server -> officer | Текущие вызовы работы, на дежурстве в которой офицер (полный список; пустой список очищает карточки). |
| `ai-policealert:client:alert` | server -> officer | Один новый вызов. |
