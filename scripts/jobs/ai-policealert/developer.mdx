<Callout type="info">
To send a police alert from your script, call the lib's `dispatch.alert(alert)` (TypeScript) or `aiLib.dispatch.alert(alert)` (Lua). It goes through AI Core's dispatch layer and reaches whichever alert system the server uses: ai-policealert, or a supported third-party alert script. Never call ai-policealert's export directly.
</Callout>

## dispatch.alert

Sends one police (or other job) alert through AI Core. On-duty members of `jobs` get it; without `jobs` the alert system's own police jobs do (for ai-policealert: the panel's **Alert jobs**).

**Side:** Server · **Waits:** no

```ts title="Signature"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local sent = aiLib.dispatch.alert(alert) -- boolean
```

#### Parameters

<TypeTable
  type={{
    alert: { type: 'DispatchAlert', description: 'What the alert says, where it points and who gets it. Fields below.', required: true },
  }}
/>

#### DispatchAlert

<TypeTable
  type={{
    title: { type: 'string', description: 'The headline ("Shots fired"). Pass a translated text. Cut at 80 characters.', required: true },
    code: { type: 'string', description: 'Radio code shown before the title ("10-71"). Cut at 12 characters.' },
    message: { type: 'string', description: 'One more line (the shop\'s name).' },
    coords: { type: '{ x: number; y: number; z: number }', description: 'Where it happened. Without it, the position of the `source` player; without both, the alert has no map point.' },
    jobs: { type: 'string[]', description: 'Jobs whose on-duty members get it (up to 10). Default: the alert system\'s police jobs.' },
    source: { type: 'number', description: 'Server id of the player the alert is about (shooter, robber). Alert systems that describe the suspect (vehicle, gender) read this player.' },
    blip: { type: '{ sprite: number; color?: number; scale?: number }', description: 'GTA blip sprite, colour and size. Default: the alert system\'s (ai-policealert: the panel\'s Alert blip).' },
    duration: { type: 'number', description: 'Seconds the alert stays (card, blip, waypoint key). Default: the alert system\'s own (ai-policealert: Alert time).' },
    icon: { type: 'string', description: 'Font Awesome solid icon name without `fa-` ("gun").', default: '"triangle-exclamation" (ai-policealert)' },
    priority: { type: '"normal" | "high"', description: '`high` makes the card stand out (blinks, flashing blip).', default: '"normal"' },
  }}
/>

#### Returns

`true` when an alert system took the alert. `false` when no alert system runs or the alert is invalid (no `title`).

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, onClientCallback } from "@aifivem/lib/server";
import { Locale } from "./locale"; // your resource's translated texts

// A client says it started breaking into an ATM; the server alerts the police at the player's position.
onClientCallback("myscript:breakAtm", (source) => {
  const sent = dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_ATM_TITLE"),
    message: Locale("ALERT_ATM_MESSAGE"),
    source, // coords come from this player
    icon: "money-bill",
    priority: "high",
  });
  if (!sent) console.log("no alert system is running");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
RegisterNetEvent('myscript:breakAtm', function()
  local source = source
  local sent = aiLib.dispatch.alert({
    code = '10-90',
    title = 'ATM break-in',
    message = 'Someone is breaking into an ATM',
    source = source,
    icon = 'money-bill',
    priority = 'high',
  })
  if not sent then print('no alert system is running') end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Texts are shown as you send them: translate them before the call. Fields not listed above are dropped. Do not send an alert for every repeated action: ai-police, for example, keeps one shot alert per 150 m every 30 s.
</Callout>

## Server export

### DispatchAlert

ai-policealert's own entry point. Only AI Core's dispatch layer calls it while ai-policealert is the active alert system; scripts use `dispatch.alert` above. Typed as `AiPoliceAlertServerExports` in `@aifivem/shared`.

**Side:** Server · **Waits:** no

```ts title="Signature"
DispatchAlert(alert: DispatchAlert): void
```

```lua title="Lua"
exports['ai-policealert']:DispatchAlert(alert)
```

#### Parameters

<TypeTable
  type={{
    alert: { type: 'DispatchAlert', description: 'The same fields as above. Checked again: an alert without a title is dropped.', required: true },
  }}
/>

#### Returns

Nothing. Calling it directly skips AI Core's choice of alert system, and `coords` is not filled from `source` (AI Core does that before it calls the export).

## Private events

The script's own server-client contract (`resource/common/alerts.ts`). They may change between versions: do not trigger or listen to them from other resources.

| Name | Direction | What it carries |
| --- | --- | --- |
| `ai-policealert:client:alerts` | server -> officer | The live alerts of the officer's duty job (a full list; an empty list clears the cards). |
| `ai-policealert:client:alert` | server -> officer | One new alert. |
