<Callout type="info">
Script’inden bir polis ihbarı göndermek için lib’in `dispatch.alert(alert)` (TypeScript) ya da `aiLib.dispatch.alert(alert)` (Lua) fonksiyonunu çağır. AI Core’un ihbar katmanından geçer ve sunucu hangi ihbar sistemini kullanıyorsa ona ulaşır: ai-policealert ya da desteklenen bir üçüncü parti ihbar script’i. ai-policealert’in export’unu asla doğrudan çağırma.
</Callout>

## dispatch.alert

AI Core üzerinden bir polis (ya da başka bir meslek) ihbarı gönderir. `jobs` mesleklerinin mesaideki üyeleri alır; `jobs` yoksa ihbar sisteminin kendi polis meslekleri alır (ai-policealert için: paneldeki **Alert jobs**).

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local sent = aiLib.dispatch.alert(alert) -- boolean
```

#### Dönüş değeri

Bir ihbar sistemi ihbarı aldıysa `true`. Hiçbir ihbar sistemi çalışmıyorsa ya da ihbar geçersizse (`title` yoksa) `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, onClientCallback } from "@aifivem/lib/server";
import { Locale } from "./locale"; // resource’unun çevrilmiş metinleri

// Bir client bir ATM’yi kırmaya başladığını söyler; server oyuncunun konumunda polisi uyarır.
onClientCallback("myscript:breakAtm", (source) => {
  const sent = dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_ATM_TITLE"),
    message: Locale("ALERT_ATM_MESSAGE"),
    source, // coords bu oyuncudan gelir
    icon: "money-bill",
    priority: "high",
  });
  if (!sent) console.log("no alert system is running");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
RegisterNetEvent('myscript:breakAtm', function()
  local source = source
  local sent = aiLib.dispatch.alert({
    code = '10-90',
    title = 'ATM break-in',
    message = 'Someone is breaking into an ATM',
    source = source,
    icon = 'money-bill',
    priority = 'high',
  })
  if not sent then print('no alert system is running') end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Metinler gönderdiğin gibi gösterilir: çağrıdan önce çevir. Yukarıda listelenmeyen alanlar atılır. Tekrarlanan her eylem için ihbar gönderme: örneğin ai-police her 150 m için 30 sn’de bir silah sesi ihbarı tutar.
</Callout>

## Server export’u

### DispatchAlert

ai-policealert’in kendi giriş noktası. Onu sadece ai-policealert etkin ihbar sistemiyken AI Core’un ihbar katmanı çağırır; script’ler yukarıdaki `dispatch.alert` fonksiyonunu kullanır. `@aifivem/shared` içinde `AiPoliceAlertServerExports` olarak tiplidir.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
DispatchAlert(alert: DispatchAlert): void
```

```lua title="Lua"
exports['ai-policealert']:DispatchAlert(alert)
```

#### Parametreler

<TypeTable
  type={{
    alert: { type: 'DispatchAlert', description: 'Yukarıdakiyle aynı alanlar. Tekrar kontrol edilir: başlığı olmayan bir ihbar atılır.', required: true },
  }}
/>

#### Dönüş değeri

Hiçbir şey. Doğrudan çağırmak AI Core’un ihbar sistemi seçimini atlar ve `coords` alanı `source` değerinden doldurulmaz (AI Core bunu export’u çağırmadan önce yapar).

## Özel event’ler

Script’in kendi server-client sözleşmesi (`resource/common/alerts.ts`). Sürümler arasında değişebilirler: başka resource’lardan tetikleme ya da dinleme.

| Ad | Yön | Ne taşır |
| --- | --- | --- |
| `ai-policealert:client:alerts` | server -> memur | Memurun mesaideki mesleğinin canlı ihbarları (tam liste; boş liste kartları temizler). |
| `ai-policealert:client:alert` | server -> memur | Yeni bir ihbar. |
