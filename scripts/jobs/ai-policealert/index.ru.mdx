ai-policealert показывает вызовы полиции офицерам на дежурстве: карточку на экране, блип на карте и клавишу, которая ставит метку к самому новому вызову. Каждый скрипт, который отправляет вызов полиции (ограбления, стрельба, продажа наркотиков, побеги из тюрьмы, уличные гонки), отправляет его через AI Core, а AI Core передаёт его ai-policealert, пока тот является активной системой оповещений. Его можно заменить другим скриптом оповещений, не трогая ни один другой скрипт.

## Что он делает в игре

- **Карточка вызова.** Выезжает карточка с радиокодом вызова, заголовком, дополнительной строкой, улицей и районом и полосой, которая убывает, пока карточка остаётся. Вызовы с высоким приоритетом (вооружённое ограбление, офицер ранен) мигают красным. Одновременно показывается не больше четырёх карточек, самая новая сверху.
- **Блип.** Каждый вызов с позицией получает блип на карте на время вызова. Блипы с высоким приоритетом мигают.
- **Клавиша метки.** Нажмите **J**, чтобы поставить метку к самому новому текущему вызову.
- **Звук.** Когда приходит карточка, звучит звук (переключатель в панели).
- **Кто получает.** Участники на дежурстве тех работ, которые указаны в вызове. Вызов, в котором работы не указаны, идёт к **Alert jobs** из панели.
- **Заступление на дежурство.** Офицер, который заступает на дежурство, сразу получает текущие вызовы своей работы. Уход с дежурства или смена персонажа очищает карточки.

## Установка

Устанавливается рецептом AI Core. Вручную: `ensure ai-policealert` после `ensure ai-core`. Нужен `ai-core`.

В панели ai-core **General > Police alerts** выбирает систему оповещений. `auto` использует первый запущенный поддерживаемый скрипт оповещений; ai-policealert идёт последним в этом порядке, поэтому установленный сторонний скрипт оповещений побеждает. Выберите там **ai-policealert**, чтобы использовать его принудительно.

Для проверки: администратор ai-core вводит в игре `aicore_alert` (или `aicore_alert high`). Это отправляет тестовый вызов в позицию администратора через активную систему оповещений.

## Настройки панели

Админ-панель > **Police alerts** > вкладка **Alerts**. Эти настройки используются, только пока ai-policealert является системой оповещений, в которую AI Core отправляет вызовы. Значения по умолчанию берутся из `data/settings.json`.

| Настройка | Что меняет | Единица | По умолчанию |
| --- | --- | --- | --- |
| Alert jobs | Участники этих работ на дежурстве получают вызовы, в которых не указаны собственные работы. До 10. | | police |
| Alert time | Сколько остаются блип вызова и клавиша метки, если вызов не задаёт своё время. 10-600. | с | 60 |
| Card time | Сколько карточка вызова остаётся на экране. 2-60. | с | 8 |
| Live alerts per officer | Наибольшее число вызовов, которые офицер одновременно держит на карте; новый заменяет самый старый. 5-100. | | 30 |
| Sound | Когда приходит карточка, звучит звук. | | вкл. |
| Alert blip | Блип на карте для вызова, скрипт которого не задаёт свой блип. Вызовы с высоким приоритетом мигают. | | спрайт 60, цвет 1 (красный), размер 0.8 |

## Команды

Собственных нет. `aicore_alert [high]` (ai-core, только администраторы) отправляет тестовый вызов.

## Привязки клавиш

Каждый игрок может изменить их в настройках клавиш GTA (раздел FiveM); владелец меняет значения по умолчанию в админ-панели (**Keybinds**).

| Клавиша по умолчанию | Что делает |
| --- | --- |
| J | Поставить метку к самому новому вызову полиции (`police_alert_waypoint`). |

## Что он заменяет

Нет `fxProvide`. Скрипты QBCore / Qbox, которые отправляют `police:server:policeAlert` (ограбления qb, ключи от транспорта и другие), продолжают работать: AI Core отвечает на это событие и передаёт вызов активной системе оповещений.

## Другие скрипты оповещений

Слой диспетчера AI Core также поддерживает tgiann-policealert, ps-dispatch, cd_dispatch, rcore_dispatch, core_dispatch, linden_outlawalert, lb-tablet, wasabi_mdt, origen_police, kartik-mdt, tk_dispatch, codem-dispatch, aty_dispatch, redutzu-mdt, emergencydispatch, tgiann-mdt и tgiann-policejob. Установите один из них и оставьте **Police alerts** на `auto` (или выберите его), и вызовы каждого скрипта ai-* пойдут туда. См. [Совместимость](/ru/docs/compatibility).

## Известные ограничения

- Вызовы живут только в памяти. После перезапуска ai-policealert показывать нечего, пока не придут новые вызовы.
- Сервер хранит не больше 1,000 текущих вызовов по всем работам; самый старый уходит первым.
- Названия улицы и района читаются в игре каждого офицера по позиции вызова.
