<Callout type="info">
Para enviar um alerta da polícia a partir do seu script, chame o `dispatch.alert(alert)` da lib (TypeScript) ou `aiLib.dispatch.alert(alert)` (Lua). Ele passa pela camada de dispatch do AI Core e chega a qualquer sistema de alertas que o servidor usa: o ai-policealert, ou um script de alerta de terceiros suportado. Nunca chame o export do ai-policealert diretamente.
</Callout>

## dispatch.alert

Envia um alerta da polícia (ou de outro emprego) através do AI Core. Os membros em serviço de `jobs` o recebem; sem `jobs`, quem recebe são os empregos de polícia do próprio sistema de alertas (para o ai-policealert: os **Alert jobs** do painel).

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local sent = aiLib.dispatch.alert(alert) -- boolean
```

    priority: { type: '"normal" | "high"', description: '`high` faz o cartão se destacar (pisca, blip piscando).', default: '"normal"' },
  }}
/>

#### Retorno

`true` quando um sistema de alertas aceitou o alerta. `false` quando nenhum sistema de alertas está rodando ou o alerta é inválido (sem `title`).

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, onClientCallback } from "@aifivem/lib/server";
import { Locale } from "./locale"; // os textos traduzidos do seu recurso

// Um cliente diz que começou a arrombar um caixa eletrônico; o servidor alerta a polícia na posição do jogador.
onClientCallback("myscript:breakAtm", (source) => {
  const sent = dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_ATM_TITLE"),
    message: Locale("ALERT_ATM_MESSAGE"),
    source, // as coords vêm deste jogador
    icon: "money-bill",
    priority: "high",
  });
  if (!sent) console.log("no alert system is running");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
RegisterNetEvent('myscript:breakAtm', function()
  local source = source
  local sent = aiLib.dispatch.alert({
    code = '10-90',
    title = 'ATM break-in',
    message = 'Someone is breaking into an ATM',
    source = source,
    icon = 'money-bill',
    priority = 'high',
  })
  if not sent then print('no alert system is running') end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Os textos são mostrados como você os envia: traduza-os antes da chamada. Campos não listados acima são descartados. Não envie um alerta para cada ação repetida: o ai-police, por exemplo, mantém um alerta de disparos por 150 m a cada 30 s.
</Callout>

## Export do servidor

### DispatchAlert

O ponto de entrada próprio do ai-policealert. Só a camada de dispatch do AI Core o chama enquanto o ai-policealert é o sistema de alertas ativo; os scripts usam o `dispatch.alert` acima. Tipado como `AiPoliceAlertServerExports` em `@aifivem/shared`.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
DispatchAlert(alert: DispatchAlert): void
```

```lua title="Lua"
exports['ai-policealert']:DispatchAlert(alert)
```

#### Parâmetros

<TypeTable
  type={{
    alert: { type: 'DispatchAlert', description: 'Os mesmos campos de cima. Verificados de novo: um alerta sem título é descartado.', required: true },
  }}
/>

#### Retorno

Nada. Chamá-lo diretamente pula a escolha de sistema de alertas do AI Core, e `coords` não é preenchido a partir de `source` (o AI Core faz isso antes de chamar o export).

## Eventos privados

O contrato servidor-cliente próprio do script (`resource/common/alerts.ts`). Eles podem mudar entre versões: não os dispare nem os escute a partir de outros recursos.

| Nome | Direção | O que carrega |
| --- | --- | --- |
| `ai-policealert:client:alerts` | servidor -> policial | Os alertas ativos do emprego em serviço do policial (uma lista completa; uma lista vazia limpa os cartões). |
| `ai-policealert:client:alert` | servidor -> policial | Um novo alerta. |
