<Callout type="info">
Um aus deinem Skript einen Polizeialarm zu senden, rufe `dispatch.alert(alert)` der Lib (TypeScript) oder `aiLib.dispatch.alert(alert)` (Lua) auf. Er läuft über den Dispatch-Layer von AI Core und erreicht das Alarmsystem, das der Server gerade nutzt: ai-policealert oder ein unterstütztes Drittanbieter-Alarmskript. Rufe den Export von ai-policealert nie direkt auf.
</Callout>

## dispatch.alert

Sendet einen Polizei- (oder anderen Job-)Alarm über AI Core. Mitglieder im Dienst von `jobs` bekommen ihn; ohne `jobs` bekommen ihn die eigenen Polizeijobs des Alarmsystems (bei ai-policealert: die **Alert jobs** aus dem Panel).

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local sent = aiLib.dispatch.alert(alert) -- boolean
```

#### Parameter

  type={{

/>

#### Rückgabewert

`true`, wenn ein Alarmsystem den Alarm angenommen hat. `false`, wenn kein Alarmsystem läuft oder der Alarm ungültig ist (kein `title`).

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, onClientCallback } from "@aifivem/lib/server";
import { Locale } from "./locale"; // die übersetzten Texte deiner Ressource

// Ein Client meldet, dass er begonnen hat, einen Geldautomaten aufzubrechen; der Server alarmiert die Polizei an der Position des Spielers.
onClientCallback("myscript:breakAtm", (source) => {
  const sent = dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_ATM_TITLE"),
    message: Locale("ALERT_ATM_MESSAGE"),
    source, // Koordinaten kommen von diesem Spieler
    icon: "money-bill",
    priority: "high",
  });
  if (!sent) console.log("no alert system is running");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
RegisterNetEvent('myscript:breakAtm', function()
  local source = source
  local sent = aiLib.dispatch.alert({
    code = '10-90',
    title = 'ATM break-in',
    message = 'Someone is breaking into an ATM',
    source = source,
    icon = 'money-bill',
    priority = 'high',
  })
  if not sent then print('no alert system is running') end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Texte werden so angezeigt, wie du sie sendest: Übersetze sie vor dem Aufruf. Nicht oben aufgeführte Felder werden verworfen. Sende nicht bei jeder wiederholten Aktion einen Alarm: ai-police zum Beispiel behält einen Schussalarm pro 150 m alle 30 s.
</Callout>

## Server-Export

### DispatchAlert

Der eigene Einstiegspunkt von ai-policealert. Nur der Dispatch-Layer von AI Core ruft ihn auf, solange ai-policealert das aktive Alarmsystem ist; Skripte nutzen `dispatch.alert` oben. Typisiert als `AiPoliceAlertServerExports` in `@aifivem/shared`.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
DispatchAlert(alert: DispatchAlert): void
```

```lua title="Lua"
exports['ai-policealert']:DispatchAlert(alert)
```

#### Parameter

<TypeTable
  type={{
    alert: { type: 'DispatchAlert', description: 'Dieselben Felder wie oben. Wird erneut geprüft: Ein Alarm ohne Titel wird verworfen.', required: true },
  }}
/>

#### Rückgabewert

Nichts. Ein direkter Aufruf umgeht die Wahl des Alarmsystems durch AI Core, und `coords` wird nicht aus `source` gefüllt (das macht AI Core, bevor es den Export aufruft).

## Private Events

Der eigene Server-Client-Vertrag des Skripts (`resource/common/alerts.ts`). Sie können sich zwischen Versionen ändern: Löse sie nicht aus anderen Ressourcen aus und höre nicht darauf.

| Name | Richtung | Was es überträgt |
| --- | --- | --- |
| `ai-policealert:client:alerts` | Server -> Beamter | Die aktiven Alarme des Dienstjobs des Beamten (eine vollständige Liste; eine leere Liste löscht die Karten). |
| `ai-policealert:client:alert` | Server -> Beamter | Ein neuer Alarm. |
