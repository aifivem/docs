ai-death решает, что происходит, когда персонаж теряет сознание. Игрок лежит в анимации смерти и ждёт медика. После таймера он может очнуться в ближайшей больнице за плату. Медики на дежурстве реанимируют на месте аптечкой, а больницы предлагают платное лечение, пока на дежурстве мало медиков.

## Что он делает в игре

- **Потеря сознания.** Игрок лежит в анимации смерти (обмякший на сиденье транспорта, ragdoll в воде, ничего, пока его несут). Он всё ещё может осматриваться, писать в чат, говорить через push to talk и открывать меню паузы; всё остальное управление отключено. Экран без сознания показывает обратный отсчёт.
- **Переподключение.** Игрок, который выходит без сознания, возвращается без сознания. Состояние без сознания хранится в персонаже (`isdead`, ключ, который использует QBCore).
- **Вызов врача.** Без сознания нажмите **G**, чтобы отправить сигнал бедствия медикам. Между двумя вызовами есть ожидание (панель). Экран без сознания показывает, сколько медиков свободно.
- **Возрождение.** Когда обратный отсчёт заканчивается, экран без сознания предлагает больницу. Игрок очнётся в точке пробуждения ближайшей больницы. Сбор больницы списывается со счетов из панели по порядку; игрок, который не может заплатить, проходит бесплатно. Когда включено **Lose items**, инвентарь очищается.
- **Реанимация медиком.** Медик на дежурстве, который использует `medikit`, реанимирует ближайшего игрока без сознания в пределах 3 м там, где тот лежит. Когда **Revive fee** больше 0, реанимированный игрок получает счёт от работы медика (оплачивается позже). Любой другой, кто использует `medikit`, лечит себя.
- **Лечение через регистратуру.** В точке регистрации больницы игрок платит цену лечения и полностью исцеляется. Это работает, только пока на дежурстве не больше **Medics for check-in** медиков.
- **Восстановление здоровья.** GTA медленно возвращает здоровье, если вас какое-то время не ранят. ai-death по умолчанию это отключает (переключатель в панели).
- **Блипы больниц.** Каждая больница может показывать блип на карте.

## Установка

Устанавливается рецептом AI Core. Вручную: `ensure ai-death` после `ensure ai-core`. Нужны `ai-core` и OneSync.

- Предмет аптечки называется `medikit`. Убедитесь, что он есть в списке предметов вашего инвентаря. ai-death регистрирует его как используемый в любом запущенном инвентаре.
- Добавьте свою работу медиков (по умолчанию `ambulance`) в ai-core (админ-панель, **Jobs**) и укажите её в **Medic jobs**.
- AI Core использует первый запущенный поддерживаемый скрипт смерти (см. ниже).

## Настройки панели

Админ-панель > **Death and hospitals**. Значения по умолчанию берутся из `data/settings.json` и `data/hospitals.json`.

### Вкладка Rules

**Respawn** (возрождение): персонаж без сознания ждёт медика; по истечении времени он может очнуться в ближайшей больнице.

| Настройка | Что меняет | Единица | По умолчанию |
| --- | --- | --- | --- |
| Wait before respawn | Сколько секунд игрок без сознания ждёт, прежде чем появится вариант больницы. 0-3600. | с | 300 |
| Hospital fee | Списывается при пробуждении в больнице; игроки, которые не могут заплатить, проходят бесплатно. 0-1,000,000. | $ | 1,000 |
| Lose items | Пробуждение в больнице очищает инвентарь. | | выкл. |
| Health refills by itself | GTA медленно возвращает здоровье (до половины), если вас какое-то время не ранят. Выкл.: здоровье дают только лечение, медики и предметы. | | выкл. |
| Paid from | Денежные счета, которые проверяются по порядку для сбора больницы и лечения. До 5. | | bank, cash |

**Medics** (медики): медики на дежурстве реанимируют игроков без сознания аптечкой; игроки без сознания вызывают их с экрана без сознания.

| Настройка | Что меняет | Единица | По умолчанию |
| --- | --- | --- | --- |
| Medic jobs | Участники этих работ на дежурстве реанимируют аптечкой и получают вызовы врача. До 10. | | ambulance |
| Treatment price | Лечение через регистратуру полностью исцеляет за эту цену. 0-1,000,000. | $ | 250 |
| Medics for check-in | Регистратура работает, только пока на дежурстве не больше стольких медиков. 0-100. | | 2 |
| Revive fee | Реанимация аптечкой медика отправляет реанимированному игроку счёт от работы медика; счёт работы получает деньги, когда он платит. 0 = бесплатно. 0-1,000,000. | $ | 0 |
| Doctor call wait | Сколько секунд игрок без сознания ждёт между двумя вызовами врача. 10-3600. | с | 60 |

### Вкладка Hospitals

Одна запись на больницу. По умолчанию: Pillbox Medical, Sandy Shores Medical, Paleto Bay Medical.

| Настройка | Что меняет | По умолчанию для новой больницы |
| --- | --- | --- |
| Name | Название больницы, показывается на блипе. 1-48 символов. | пусто |
| Wake-up spot | Где игроки просыпаются, лицом в вашу сторону. | 0, 0, 0 |
| Check-in | Где игроки платят за лечение. | 0, 0, 0 |
| Map blip | Показывает больницу на карте. | вкл. |
| Blip look | Спрайт, цвет и размер (показывается, когда включено **Map blip**). | спрайт 61, цвет 1, размер 0.7 |

## Команды

Нет. Инструменты администратора реанимируют и лечат через медицинский слой AI Core, который вызывает ai-death.

## Привязки клавиш

Каждый игрок может изменить их в настройках клавиш GTA (раздел FiveM); владелец меняет значения по умолчанию в админ-панели (**Keybinds**).

| Клавиша по умолчанию | Что делает |
| --- | --- |
| G | Вызвать врача без сознания (`death_distress`). Экран без сознания показывает назначенную клавишу. |

Вариант больницы в конце обратного отсчёта и точки регистрации используют подсказки ai-core (по умолчанию **E**).

## Что он заменяет

Нет `fxProvide`. Он отвечает на `exports.qbx_medical:Revive` и `exports.qbx_medical:IsDead`, а клиентское событие `hospital:client:Revive` (его отправляют скрипты QB и админ-меню) реанимирует игрока. Состояние без сознания использует ключ метаданных QBCore `isdead`.

## Другие скрипты смерти

Медицинский слой AI Core также поддерживает qbx_medical, ars_ambulancejob, qb-ambulancejob, esx_ambulancejob, tgiann-ambulance, wasabi_ambulance (v1 и v2), osp_ambulance и brutal_ambulancejob. Остановите ai-death и запустите один из них: реанимация администратором и каждый скрипт ai-* продолжат работать. Вызовы врача идут через слой EMS AI Core, который также доходит до tgiann-policealert и wasabi_ambulance_v2. См. [Совместимость](/ru/docs/compatibility).

## Известные ограничения

- Обратный отсчёт идёт по часам игры игрока; сервер ещё раз проверяет время перед возрождением.
- Отклонённый счёт за реанимацию записывается в лог как предупреждение; реанимация всё равно засчитывается.
- Каналы логов: `deaths`, `revives` и `distress`.
