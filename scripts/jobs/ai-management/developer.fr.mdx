ai-management n’a **aucun export, event ni state bag** pour les autres scripts. Tout ce qu’il change appartient à ai-core :

| Ce que fait le patron | Ce que détient ai-core | À lire ou modifier avec |
| --- | --- | --- |
| Recruter, changer de grade, licencier | L’appartenance du joueur à un métier ou à un gang | Les exports de métiers et de gangs d’ai-core ([exports serveur d’ai-core](/fr/docs/developers/api/core-server)) |
| Déposer, retirer | Le compte partagé `bank` du métier ou du gang | `GetSharedMoney`, `AddSharedMoney`, `RemoveSharedMoney`, ou le `money.transfer` de la lib |

Qui compte comme patron, c’est l’indicateur `boss` sur un grade dans les définitions de métiers et de gangs d’ai-core (`definitions.job(name)` / `definitions.gang(name)` de la lib).

## Exemple

Afficher le solde du compte d’un métier, le même nombre que montre le menu de patron :

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// /jobbalance police (administrateurs d’ai-core)
addCommand(
  "jobbalance",
  { help: "Show a job account", restricted: true, params: [{ name: "job", type: "string" }] as const },
  (source, { job }) => {
    const balance = core.GetSharedMoney("job", job, "bank");
    const text = balance === null ? "No such job account" : `${job}: $${balance}`;
    if (source > 0) notify(source, text, "info");
    else console.log(text);
  },
);
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua : shared_script '@ai-lib/init.lua')
aiLib.addCommand('jobbalance', {
  help = 'Show a job account',
  restricted = true,
  params = { { name = 'job', type = 'string' } },
}, function(source, args)
  local balance = exports['ai-core']:GetSharedMoney('job', args.job, 'bank')
  local text = balance and ('%s: $%d'):format(args.job, balance) or 'No such job account'
  if source > 0 then aiLib.notify(source, text, 'info') else print(text) end
end)
```
</Tab>
</Tabs>

## Callbacks privés

Les appels du menu de patron (`resource/common/boss.ts`) : ouvrir le menu, recruter, régler un grade, licencier, déposer et retirer. Le serveur vérifie le grade de patron et la distance à chaque appel. Ils peuvent changer d’une version à l’autre : ne les appelez pas depuis d’autres ressources.
