ai-management **nie ma eksportów, zdarzeń ani state bagów** dla innych skryptów. Wszystko, co zmienia, należy do ai-core:

| Co robi szef | Co przechowuje ai-core | Odczyt lub zmiana przez |
| --- | --- | --- |
| Zatrudnianie, zmiana stopnia, zwalnianie | Członkostwo gracza w pracy lub gangu | Eksporty prac i gangów ai-core ([eksporty serwera ai-core](/pl/docs/developers/api/core-server)) |
| Wpłata, wypłata | Wspólne konto `bank` pracy lub gangu | `GetSharedMoney`, `AddSharedMoney`, `RemoveSharedMoney` lub `money.transfer` z biblioteki |

To, kto liczy się jako szef, określa flaga `boss` na stopniu w definicjach prac i gangów ai-core (`definitions.job(name)` / `definitions.gang(name)` z biblioteki).

## Przykład

Pokaż saldo konta pracy, tę samą liczbę, którą pokazuje menu szefa:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// /jobbalance police (administratorzy ai-core)
addCommand(
  "jobbalance",
  { help: "Show a job account", restricted: true, params: [{ name: "job", type: "string" }] as const },
  (source, { job }) => {
    const balance = core.GetSharedMoney("job", job, "bank");
    const text = balance === null ? "No such job account" : `${job}: $${balance}`;
    if (source > 0) notify(source, text, "info");
    else console.log(text);
  },
);
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
aiLib.addCommand('jobbalance', {
  help = 'Show a job account',
  restricted = true,
  params = { { name = 'job', type = 'string' } },
}, function(source, args)
  local balance = exports['ai-core']:GetSharedMoney('job', args.job, 'bank')
  local text = balance and ('%s: $%d'):format(args.job, balance) or 'No such job account'
  if source > 0 then aiLib.notify(source, text, 'info') else print(text) end
end)
```
</Tab>
</Tabs>

## Prywatne callbacki

Wywołania menu szefa (`resource/common/boss.ts`): otwarcie menu, zatrudnienie, ustawienie stopnia, zwolnienie, wpłata i wypłata. Serwer sprawdza stopień szefa i odległość przy każdym wywołaniu. Mogą się zmieniać między wersjami: nie wywołuj ich z innych zasobów.
