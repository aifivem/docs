O ai-management **não tem exports, eventos nem state bags** para outros scripts. Tudo o que ele muda pertence ao ai-core:

| O que o chefe faz | O que o ai-core guarda | Leia ou altere com |
| --- | --- | --- |
| Contratar, mudar cargo, demitir | A associação do jogador ao emprego ou gangue | Os exports de emprego e gangue do ai-core ([exports do servidor do ai-core](/pt/docs/developers/api/core-server)) |
| Depositar, sacar | A conta compartilhada `bank` do emprego ou gangue | `GetSharedMoney`, `AddSharedMoney`, `RemoveSharedMoney`, ou o `money.transfer` da lib |

Quem conta como chefe é a flag `boss` de um cargo nas definições de empregos e gangues do ai-core (`definitions.job(name)` / `definitions.gang(name)` da lib).

## Exemplo

Mostra o saldo da conta de um emprego, o mesmo número que o menu do chefe mostra:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// /jobbalance police (administradores do ai-core)
addCommand(
  "jobbalance",
  { help: "Show a job account", restricted: true, params: [{ name: "job", type: "string" }] as const },
  (source, { job }) => {
    const balance = core.GetSharedMoney("job", job, "bank");
    const text = balance === null ? "No such job account" : `${job}: $${balance}`;
    if (source > 0) notify(source, text, "info");
    else console.log(text);
  },
);
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
aiLib.addCommand('jobbalance', {
  help = 'Show a job account',
  restricted = true,
  params = { { name = 'job', type = 'string' } },
}, function(source, args)
  local balance = exports['ai-core']:GetSharedMoney('job', args.job, 'bank')
  local text = balance and ('%s: $%d'):format(args.job, balance) or 'No such job account'
  if source > 0 then aiLib.notify(source, text, 'info') else print(text) end
end)
```
</Tab>
</Tabs>

## Callbacks privados

As chamadas do menu do chefe (`resource/common/boss.ts`): abrir o menu, contratar, definir um cargo, demitir, depositar e sacar. O servidor verifica o cargo de chefe e a distância a cada chamada. Elas podem mudar entre versões: não as chame a partir de outros recursos.
