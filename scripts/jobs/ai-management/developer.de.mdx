ai-management hat **keine Exports, Events oder State Bags** für andere Skripte. Alles, was es ändert, gehört ai-core:

| Was der Chef tut | Was ai-core hält | Lesen oder ändern mit |
| --- | --- | --- |
| Einstellen, Rang ändern, entlassen | Die Job- oder Gang-Mitgliedschaft des Spielers | Die Job- und Gang-Exports von ai-core ([Server-Exports von ai-core](/de/docs/developers/api/core-server)) |
| Einzahlen, abheben | Das gemeinsame Konto `bank` des Jobs oder der Gang | `GetSharedMoney`, `AddSharedMoney`, `RemoveSharedMoney` oder `money.transfer` der Lib |

Wer als Chef gilt, ist das Flag `boss` an einem Rang in den Job- und Gang-Definitionen von ai-core (`definitions.job(name)` / `definitions.gang(name)` der Lib).

## Beispiel

Das Kontoguthaben eines Jobs anzeigen, dieselbe Zahl, die das Chefmenü zeigt:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// /jobbalance police (Admins von ai-core)
addCommand(
  "jobbalance",
  { help: "Show a job account", restricted: true, params: [{ name: "job", type: "string" }] as const },
  (source, { job }) => {
    const balance = core.GetSharedMoney("job", job, "bank");
    const text = balance === null ? "No such job account" : `${job}: $${balance}`;
    if (source > 0) notify(source, text, "info");
    else console.log(text);
  },
);
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
aiLib.addCommand('jobbalance', {
  help = 'Show a job account',
  restricted = true,
  params = { { name = 'job', type = 'string' } },
}, function(source, args)
  local balance = exports['ai-core']:GetSharedMoney('job', args.job, 'bank')
  local text = balance and ('%s: $%d'):format(args.job, balance) or 'No such job account'
  if source > 0 then aiLib.notify(source, text, 'info') else print(text) end
end)
```
</Tab>
</Tabs>

## Private Callbacks

Die Aufrufe des Chefmenüs (`resource/common/boss.ts`): das Menü öffnen, einstellen, einen Rang setzen, entlassen, einzahlen und abheben. Der Server prüft bei jedem Aufruf den Chefrang und die Entfernung. Sie können sich zwischen Versionen ändern: Rufe sie nicht aus anderen Ressourcen auf.
