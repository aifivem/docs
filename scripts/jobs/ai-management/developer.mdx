ai-management has **no exports, events or state bags** for other scripts. Everything it changes belongs to ai-core:

| What the boss does | What ai-core holds | Read or change it with |
| --- | --- | --- |
| Hire, change grade, fire | The player's job or gang membership | ai-core's job and gang exports ([ai-core server exports](/docs/developers/api/core-server)) |
| Deposit, withdraw | The job's or gang's `bank` shared account | `GetSharedMoney`, `AddSharedMoney`, `RemoveSharedMoney`, or the lib's `money.transfer` |

Who counts as a boss is the `boss` flag on a grade in ai-core's job and gang definitions (lib `definitions.job(name)` / `definitions.gang(name)`).

## Example

Show a job's account balance, the same number the boss menu shows:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// /jobbalance police (ai-core admins)
addCommand(
  "jobbalance",
  { help: "Show a job account", restricted: true, params: [{ name: "job", type: "string" }] as const },
  (source, { job }) => {
    const balance = core.GetSharedMoney("job", job, "bank");
    const text = balance === null ? "No such job account" : `${job}: $${balance}`;
    if (source > 0) notify(source, text, "info");
    else console.log(text);
  },
);
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
aiLib.addCommand('jobbalance', {
  help = 'Show a job account',
  restricted = true,
  params = { { name = 'job', type = 'string' } },
}, function(source, args)
  local balance = exports['ai-core']:GetSharedMoney('job', args.job, 'bank')
  local text = balance and ('%s: $%d'):format(args.job, balance) or 'No such job account'
  if source > 0 then aiLib.notify(source, text, 'info') else print(text) end
end)
```
</Tab>
</Tabs>

## Private callbacks

The boss menu's calls (`resource/common/boss.ts`): open the menu, hire, set a grade, fire, deposit and withdraw. The server checks the boss grade and the distance on every call. They may change between versions: do not call them from other resources.
