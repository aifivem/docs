ai-management’ın diğer script’ler için **hiç export’u, event’i ya da state bag’i yoktur**. Değiştirdiği her şey ai-core’a aittir:

| Patronun yaptığı | ai-core’un tuttuğu | Okumak ya da değiştirmek için |
| --- | --- | --- |
| İşe alma, kademe değiştirme, kovma | Oyuncunun meslek ya da çete üyeliği | ai-core’un meslek ve çete export’ları ([ai-core server export’ları](/tr/docs/developers/api/core-server)) |
| Para yatırma, çekme | Mesleğin ya da çetenin ortak `bank` hesabı | `GetSharedMoney`, `AddSharedMoney`, `RemoveSharedMoney` ya da lib’in `money.transfer` fonksiyonu |

Kimin patron sayıldığını ai-core’un meslek ve çete tanımlarındaki bir kademenin `boss` bayrağı belirler (lib `definitions.job(name)` / `definitions.gang(name)`).

## Örnek

Bir mesleğin hesap bakiyesini göster, patron menüsünün gösterdiği sayının aynısı:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// /jobbalance police (ai-core adminleri)
addCommand(
  "jobbalance",
  { help: "Show a job account", restricted: true, params: [{ name: "job", type: "string" }] as const },
  (source, { job }) => {
    const balance = core.GetSharedMoney("job", job, "bank");
    const text = balance === null ? "No such job account" : `${job}: $${balance}`;
    if (source > 0) notify(source, text, "info");
    else console.log(text);
  },
);
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
aiLib.addCommand('jobbalance', {
  help = 'Show a job account',
  restricted = true,
  params = { { name = 'job', type = 'string' } },
}, function(source, args)
  local balance = exports['ai-core']:GetSharedMoney('job', args.job, 'bank')
  local text = balance and ('%s: $%d'):format(args.job, balance) or 'No such job account'
  if source > 0 then aiLib.notify(source, text, 'info') else print(text) end
end)
```
</Tab>
</Tabs>

## Özel callback’ler

Patron menüsünün çağrıları (`resource/common/boss.ts`): menüyü açma, işe alma, kademe ayarlama, kovma, para yatırma ve çekme. Server her çağrıda patron kademesini ve mesafeyi kontrol eder. Sürümler arasında değişebilirler: başka resource’lardan çağırma.
