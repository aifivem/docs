ai-management **no tiene exports, eventos ni state bags** para otros scripts. Todo lo que cambia pertenece a ai-core:

| Lo que hace el jefe | Lo que guarda ai-core | Léelo o cámbialo con |
| --- | --- | --- |
| Contratar, cambiar rango, despedir | La pertenencia del jugador a un trabajo o banda | Los exports de trabajos y bandas de ai-core ([exports de servidor de ai-core](/es/docs/developers/api/core-server)) |
| Ingresar, retirar | La cuenta compartida `bank` del trabajo o banda | `GetSharedMoney`, `AddSharedMoney`, `RemoveSharedMoney`, o `money.transfer` de la lib |

Quién cuenta como jefe es el flag `boss` de un rango en las definiciones de trabajos y bandas de ai-core (`definitions.job(name)` / `definitions.gang(name)` de la lib).

## Ejemplo

Mostrar el saldo de la cuenta de un trabajo, el mismo número que muestra el menú de jefe:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// /jobbalance police (administradores de ai-core)
addCommand(
  "jobbalance",
  { help: "Show a job account", restricted: true, params: [{ name: "job", type: "string" }] as const },
  (source, { job }) => {
    const balance = core.GetSharedMoney("job", job, "bank");
    const text = balance === null ? "No such job account" : `${job}: $${balance}`;
    if (source > 0) notify(source, text, "info");
    else console.log(text);
  },
);
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
aiLib.addCommand('jobbalance', {
  help = 'Show a job account',
  restricted = true,
  params = { { name = 'job', type = 'string' } },
}, function(source, args)
  local balance = exports['ai-core']:GetSharedMoney('job', args.job, 'bank')
  local text = balance and ('%s: $%d'):format(args.job, balance) or 'No such job account'
  if source > 0 then aiLib.notify(source, text, 'info') else print(text) end
end)
```
</Tab>
</Tabs>

## Callbacks privados

Las llamadas del menú de jefe (`resource/common/boss.ts`): abrir el menú, contratar, fijar un rango, despedir, ingresar y retirar. El servidor comprueba el rango de jefe y la distancia en cada llamada. Pueden cambiar entre versiones: no las llames desde otros recursos.
