У ai-management **нет экспортов, событий и state bags** для других скриптов. Всё, что он меняет, принадлежит ai-core:

| Что делает босс | Что хранит ai-core | Чем читать или менять |
| --- | --- | --- |
| Нанять, изменить ранг, уволить | Членство игрока в работе или банде | Экспорты работ и банд ai-core ([серверные экспорты ai-core](/ru/docs/developers/api/core-server)) |
| Пополнить, снять | Общий счёт `bank` работы или банды | `GetSharedMoney`, `AddSharedMoney`, `RemoveSharedMoney` или `money.transfer` из lib |

Кто считается боссом, определяет флаг `boss` у ранга в определениях работ и банд ai-core (`definitions.job(name)` / `definitions.gang(name)` из lib).

## Пример

Показать баланс счёта работы, то же число, что показывает меню босса:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// /jobbalance police (администраторы ai-core)
addCommand(
  "jobbalance",
  { help: "Show a job account", restricted: true, params: [{ name: "job", type: "string" }] as const },
  (source, { job }) => {
    const balance = core.GetSharedMoney("job", job, "bank");
    const text = balance === null ? "No such job account" : `${job}: $${balance}`;
    if (source > 0) notify(source, text, "info");
    else console.log(text);
  },
);
```
</Tab>
<Tab value="Lua">
```lua
-- server.lua (fxmanifest.lua: shared_script '@ai-lib/init.lua')
aiLib.addCommand('jobbalance', {
  help = 'Show a job account',
  restricted = true,
  params = { { name = 'job', type = 'string' } },
}, function(source, args)
  local balance = exports['ai-core']:GetSharedMoney('job', args.job, 'bank')
  local text = balance and ('%s: $%d'):format(args.job, balance) or 'No such job account'
  if source > 0 then aiLib.notify(source, text, 'info') else print(text) end
end)
```
</Tab>
</Tabs>

## Приватные колбэки

Вызовы меню босса (`resource/common/boss.ts`): открыть меню, нанять, выставить ранг, уволить, пополнить и снять. Сервер при каждом вызове проверяет ранг босса и расстояние. Они могут меняться между версиями: не вызывайте их из других ресурсов.
