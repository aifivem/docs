These scripts give players work and run the city's services. Jobs, ranks and salaries themselves are set in [ai-core](/docs/scripts/essentials/ai-core) (admin panel, **Jobs**); the scripts below add what a job does in the game. Police alerts, prison, deaths and banking go through AI Core, so each of these scripts can be replaced by a third-party script of the same kind.

| Script | What it does |
| --- | --- |
| [ai-jobs](/docs/scripts/jobs/ai-jobs) | Work routes: taxi, bus, trucker, garbage, tow, gathering jobs and a hot dog stand. |
| [ai-police](/docs/scripts/jobs/ai-police) | Police job menu: cuffs, escort, search, fines, prison, impound. |
| [ai-policealert](/docs/scripts/jobs/ai-policealert) | Police alert cards with a blip and a waypoint key. |
| [ai-prison](/docs/scripts/jobs/ai-prison) | Jail sentences, prison work, the canteen and escapes. |
| [ai-death](/docs/scripts/jobs/ai-death) | Death, respawn at hospitals and revives by medics. |
| [ai-banking](/docs/scripts/jobs/ai-banking) | Banks, ATMs, transfers and society accounts. |
| [ai-management](/docs/scripts/jobs/ai-management) | Boss menu of jobs and gangs. |
| [ai-cityhall](/docs/scripts/jobs/ai-cityhall) | Job center and documents (ID card, driver license). |
