## Клавиши по умолчанию

Каждый игрок может изменить любую клавишу в настройках управления GTA, а владелец сервера может изменить её значение по умолчанию в админ-панели (**Keybinds**).

| Клавиша | Действие |
| --- | --- |
| F10 | Админ-панель (администраторы) |
| F9 | Быстрое меню администратора (администраторы) |
| F1 | Радиальное меню |
| F2 | Инвентарь |
| F6 | Меню полиции (на дежурстве) |
| E | Взаимодействие с подсказкой на экране |
| Home (удерживать) | Список игроков |
| Backspace | Отмена текущего действия |
