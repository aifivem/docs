AI Core поставляется примерно с сорока скриптами `ai-*`. Вместе они составляют полноценный ролевой сервер: персонажи, деньги, инвентарь, HUD, транспорт, работы, полиция, криминал и жильё. Использовать их все не обязательно.

## Как скрипты работают вместе

- **Каждый скрипт является отдельным ресурсом.** У него своя папка в `resources/[ai]/` и своя строка `ensure` в `server.cfg`. Удалите строку, и скрипта больше нет.
- **Каждая настройка находится в админ-панели.** Каждый скрипт добавляет свои вкладки в [админ-панель](/ru/docs/admin-panel) (нажмите **F10** в игре). Конфиг-файлы вы никогда не правите.
- **Скрипты общаются через AI Core.** Когда ограбление выдаёт предмет, оно просит об этом AI Core, а AI Core передаёт предмет тому инвентарю, который у вас стоит. Скрипт ограблений не знает, ai-inventory это или другой инвентарь. Поэтому почти любой скрипт `ai-*` можно заменить сторонним скриптом того же типа (см. [Совместимость](/ru/docs/compatibility)).
- **Сторонние скрипты продолжают работать.** Многие скрипты `ai-*` также отвечают на экспорты известного скрипта, который они заменяют. Например, ai-inventory отвечает на `exports.ox_inventory:AddItem(...)`, поэтому скрипт, написанный для ox_inventory, работает без изменений. На странице каждого скрипта указано, что он заменяет.

## Как устроены категории

Скрипты сгруппированы по назначению. У каждой категории есть обзорная страница, а у каждого скрипта своя папка с двумя страницами:

- **Страница скрипта** предназначена для владельцев серверов: что скрипт делает в игре, как его установить, каждая настройка панели, его команды и клавиши и с какими сторонними скриптами он работает.
- **Страница разработчика** предназначена для тех, кто пишет скрипты: его экспорты, события и state bags, с типами и примерами на TypeScript и Lua.

| Категория | Что в ней |
| --- | --- |
| [Основное](/ru/docs/scripts/essentials) | Фреймворк и скрипты, которые нужны каждому серверу: база данных, общий интерфейс, экран загрузки, одежда, инвентарь, HUD, чат, голос, радиальное меню, глаз взаимодействия, список игроков, время и погода. |
| [Транспорт](/ru/docs/scripts/vehicles) | Личный транспорт, ключи, топливо, гаражи, автосалоны, площадки подержанных машин, аренда, механики и спецсигналы. |
| [Работы и службы](/ru/docs/scripts/jobs) | Рабочие маршруты, полиция, вызовы полиции, тюрьма, смерть и EMS, банки, меню босса и мэрия. |
| [Криминал и гонки](/ru/docs/scripts/crime) | Ограбления, наркотики, ломбарды, свалки и уличные гонки. |
| [Мир и инструменты](/ru/docs/scripts/world) | Жильё, замки дверей, много мелких функций, спящие тела, размер персонажа и инструменты администратора. |

## Клавиши по умолчанию

Каждый игрок может изменить любую клавишу в собственных настройках GTA (**Settings > Key Bindings > FiveM**). Владелец меняет начальную клавишу для всех в админ-панели (вкладка **Keybinds**); игрок, который уже изменил клавишу, сохраняет свою.

| Клавиша | Действие | Скрипт |
| --- | --- | --- |
| F10 | Админ-панель (только администраторы) | ai-core |
| F9 | Быстрое меню администратора (только администраторы) | ai-admin |
| F3 | Радиальное меню | ai-radialmenu |
| F2 | Инвентарь | ai-inventory |
| TAB | Панель быстрых слотов | ai-inventory |
| 1–5 | Использовать предмет из этого быстрого слота | ai-inventory |
| R | Перезарядить оружие | ai-inventory |
| T | Чат | ai-chat |
| F6 | Меню полиции (на дежурстве) | ai-police |
| E | Взаимодействие с подсказкой на экране | ai-lib |
| Backspace | Отмена текущего действия | ai-lib |
| U | Закрыть или открыть транспорт | ai-vehiclekeys |
| M | Двигатель вкл. / выкл. | ai-vehiclekeys |
| K | Ремень безопасности | ai-smallresources |
| F11 | Дальность голоса | ai-voice |
| Левый Alt | Говорить по рации | ai-voice |
| Home | Список игроков | ai-scoreboard |

На странице каждого скрипта перечислены все его клавиши.
