ai-drugs gibt Spielern zwei Wege, mit Drogen Geld zu verdienen: Verkauf an Fremde auf der Straße und Anbau von Cannabis. Der Server entscheidet über jeden Verkauf (Preis, Ablehnung, Polizeialarm), und Pflanzen werden in der Datenbank gespeichert, sodass sie über Neustarts hinweg weiterwachsen.

## Was es im Spiel macht

### Straßenverkauf

1. Öffne das Radialmenü und wähle **Sell drugs**, um nach Käufern zu suchen. Wähle es erneut, um aufzuhören.
2. Während du verkaufst, kommt ein Fremder aus der Nähe auf dich zu. Ein Hinweis **Sell to the stranger** erscheint, wenn er neben dir steht.
3. Der Server wählt eine Droge, die du trägst, aus der Liste des Panels, eine Anzahl und einen Preis in der Spanne dieser Droge. Der Käufer kann ablehnen (**Refuse chance**). Das Geld geht auf das Geldkonto aus dem Panel.
4. Ein Verkauf kann die Polizei alarmieren (**Police alert chance**). Niemand kauft, solange weniger als **Police needed** Beamte im Dienst sind.

Ein Spieler kann nicht öfter verkaufen als **Time between sales**, und derselbe Fremde kauft 10 Minuten lang nicht erneut.

### Cannabispflanzen

1. Benutze draußen einen `weed_seed`, um eine Cannabispflanze zu pflanzen. Pflanzen dürfen nicht innerhalb von 2 m voneinander stehen, und ein Charakter kann höchstens **Plants per character** Pflanzen haben.
2. Die Pflanze wächst über **Growing time**: ein junges Prop, ab 40 % ein wachsendes Prop, am Ende ein erntereifes Prop. Der Hinweis zeigt das Wachstum in Prozent.
3. Jeder kann eine reife Pflanze ernten: ein Fortschrittsbalken, dann eine zufällige Anzahl `weed_bud` zwischen **Buds from** und **Buds up to**.
4. Polizei im Dienst kann eine wachsende Pflanze zerstören.
5. Eine reife Pflanze, die niemand erntet, verschwindet nach **Rots after**.

## Installation

Wird vom Rezept von AI Core installiert. Von Hand: `ensure ai-drugs` nach `ensure ai-core`. Es braucht `ai-core` und OneSync.

- Es speichert Pflanzen in seiner eigenen Tabelle `ai_drugs_plants`, die beim Start angelegt wird. Es braucht seine Datenbank-Berechtigungszeile in der `env.cfg`:

```ini title="env.cfg"
add_convar_permission ai-drugs read mysql_connection_string
```

- Von den Standardwerten genutzte Items: `weed_seed` (benutzbar), `weed_bud`, `coke_baggy`, `meth_baggy`. ai-inventory hat sie; bei einem anderen Inventar fügst du sie hinzu oder änderst das Panel.
- Der Eintrag **Sell drugs** erscheint in jedem Radialmenü, das AI Core unterstützt.

## Panel-Einstellungen

Admin-Panel > **Drugs**. Die Standardwerte kommen aus `data/settings.json` und `data/plants.json`. Die Einstellungen **Street sales** und **Weed plants** bleiben auf dem Server.

### Tab Street sales

Spieler verkaufen an Fremde, nachdem sie den Verkauf im Radialmenü eingeschaltet haben.

| Einstellung | Was sie ändert | Einheit | Standard |
| --- | --- | --- | --- |
| Drugs | Bis zu 30 Zeilen, jede mit einem **Item** und **Price from** und **Price up to** (0-1.000.000). Ein Verkauf wird zwischen beiden bepreist. | $ | `weed_bud` $40-80, `coke_baggy` $90-160, `meth_baggy` $120-200 |
| Time between sales | Ein Spieler kann nicht öfter verkaufen als dies. 1-600. | s | 10 |
| Refuse chance | Chance, dass ein Käufer „Not interested“ sagt. 0-100. | % | 20 |
| Police alert chance | Chance, dass ein Verkauf die Polizei im Dienst alarmiert. 0-100. | % | 20 |
| Police needed | Beamte im Dienst, die nötig sind, bevor jemand kauft. 0-32. | | 0 |
| Police jobs | Mitglieder im Dienst gelten als Polizei und können Pflanzen zerstören. Bis zu 10. | | police |
| Money account | Das Geld aus Verkäufen geht auf dieses Konto. | | cash |

### Tab Weed plants

Jeder kann eine reife Pflanze ernten; die Polizei zerstört wachsende.

| Einstellung | Was sie ändert | Einheit | Standard |
| --- | --- | --- | --- |
| Growing time | Wie lange eine Pflanze braucht, bis sie reif ist. 1-10.080. | min | 60 |
| Rots after | Eine reife Pflanze, die niemand erntet, verschwindet nach dieser Zeit. 1-10.080. | min | 120 |
| Plants per character | Wie viele Pflanzen ein Charakter gleichzeitig haben kann. 0-100. | | 5 |
| Buds from | Wenigste Blüten pro Ernte. 1-100. | | 3 |
| Buds up to | Meiste Blüten pro Ernte. 1-100. | | 8 |
| Seed item | Dieses Item zu benutzen pflanzt eine Cannabispflanze. Ein neues Item funktioniert sofort. | | weed_seed |
| Harvest item | Eine reife Pflanze gibt dieses Item. | | weed_bud |

### Tab Plant look

Die Props, die Spieler sehen, während eine Pflanze wächst.

| Einstellung | Was sie ändert | Einheit | Standard |
| --- | --- | --- | --- |
| Young plant | Prop bis 40 % Wachstum. | | `bkr_prop_weed_01_small_01c` |
| Growing plant | Prop ab 40 %. | | `bkr_prop_weed_med_01a` |
| Ready plant | Prop, wenn sie geerntet werden kann. | | `bkr_prop_weed_lrg_01a` |
| Draw distance | Pflanzen, die weiter entfernt sind, haben kein Prop. 20-300. | m | 100 |

## Befehle

Keine.

## Tastenbelegungen

Keine. Der Verkauf startet aus dem Radialmenü (**Sell drugs**). Käufer und Pflanzen nutzen Hinweise (standardmäßig **E**).

## Was es ersetzt

Kein `fxProvide`. Es beantwortet nicht die Exports oder Events eines anderen Drogenskripts.

## Kompatible Skripte

Items laufen über den Inventar-Layer von AI Core, Polizeialarme über den Dispatch-Layer, der Verkaufsschalter über den Radial-Layer. Jedes Inventar, Alarmskript und Radialmenü, das AI Core unterstützt, funktioniert (siehe [Kompatibilität](/de/docs/compatibility)).

## Bekannte Grenzen

- Nur Cannabis wächst; Kokain und Meth werden verkauft, nicht hergestellt.
- Wachstum hängt nur von der Zeit ab: Es gibt kein Wasser und keinen Dünger.
- Log-Kanal: `drugs`.
