ai-robberies lets players rob store registers and safes, bank lockers behind vault doors, jewelry vitrines and houses, and hit an armored truck. Each place has its own police requirement, cooldown and alert chance; each target has its tool, time, minigame and reward. The server checks every step.

## What it does in the game

- **Places and targets.** A *place* is a store, bank, jewelry store or house. A *target* is one thing to rob there: a register, safe, locker, vitrine, door, house door or search spot. Each target is an interaction point (**Rob**, or **Emptied** while it waits for its cooldown).
- **Robbing a target.**
  1. The server checks the police on duty (the place's **Police needed**), the cooldown, the tool in the player's inventory, and that nobody else is working on the target.
  2. A minigame plays (lockpick or skill check, by kind or as set on the target). A lost game frees the target; a broken lockpick uses up one of the target's tool.
  3. A progress bar runs while the player faces the target and stays within 2.5 m.
  4. The server checks again, then pays the money into the panel's money account and gives the reward item.
- **Kinds.**
  - **Register**, **Safe**, **Locker**: pay money and items.
  - **Vitrine**: needs a weapon in hand.
  - **Door**: opens a door until the place's cooldown ends instead of paying (an ai-doorlock door, or a vault object that swings open on every player's game).
  - **House door (break in)**: takes the robber inside the house's interior. Other targets of the house (search spots) work only for players inside it.
  - **Search spot**: a place to search inside a house.
- **Cooldown.** A robbed target stays empty for its place's cooldown. An opened door stays open as long.
- **Police alert.** The first robbery of a visit may alert the police (the place's **Alert chance**), once per cooldown. The alert points to the place's alert point.
- **Houses.** Each occupied house is a private world (a routing bucket): only robbers of that house are inside. A player who leaves the server inside a house comes back at its door.
- **Armored truck.** At the job giver a robber pays the job price. A guarded truck parks at a random spawn. Guards attack players who come within 40 m. Plant the charge item on the rear doors, wait for the fuse, then loot the cash. An unrobbed truck goes away after its lifetime.

## Installation

Installed by the AI Core recipe. By hand: `ensure ai-robberies` after `ensure ai-core`. It needs `ai-core` and OneSync.

- Items used by the defaults: tools `lockpick`, `drill`, `electronickit`, `c4`; loot `rolex`, `goldchain`, `diamond_ring`. ai-inventory has them in its default item list; with another inventory, add them or change the targets.
- Bank vault doors: targets with a **Doorlock door** id need ai-doorlock with that door. Without one, the vault object set on the target swings.
- Police alerts go to the police alert script AI Core uses.

The defaults copy QBCore's robbery scripts: 21 stores (registers and a safe each), 6 Fleeca banks, Paleto Bay and Pacific Standard (vault doors and lockers), Vangelico (20 vitrines), 81 houses with search spots, and the armored truck. That is about 870 targets.

## Panel settings

Admin panel > **Robberies**. Defaults come from `data/places.json`, `data/targets.json` and `data/settings.json`.

### Places tab

| Setting | What it changes | Unit | Default for a new place |
| --- | --- | --- | --- |
| Name | The place's name, shown on the alert and blip. 1-48 characters. | | empty |
| Alert point | Where the police alert points to. | | 0, 0, 0 |
| Police needed | On-duty officers needed before anything here can be robbed. 0-32. | | 0 |
| Cooldown | How long a robbed target stays empty (and an opened door open). 1-1440. | min | 30 |
| Alert chance | Chance that the first robbery of a visit alerts the police (once per cooldown). 0-100. | % | 100 |
| Show on the map | Shows the place with the **Place blip** look (Settings tab). | | off |
| Interior point (House card) | Set an interior to make this place a house: where robbers appear inside (and leave from). Leave at 0, 0, 0 for places that are not houses. | | 0, 0, 0 |

Default values by place type:

| Places | Police needed | Cooldown | Alert chance |
| --- | --- | --- | --- |
| Stores (`store_1` to `store_21`) | 0 | 30 min | 70 % |
| Banks (`bank_1` to `bank_6`, `paleto`, `pacific`) | 2 | 60 min | 100 % |
| Vangelico (`vangelico`) | 2 | 45 min | 100 % |
| Houses (`house_1` to `house_81`) | 0 | 60 min | 30 % |

Deleting a place stops its targets until they name another place.

## Commands

None.

## Keybinds

None. Targets and the job giver use ai-core's **Interaction style** (prompt with **E**, or a target option).

## What it stands in for

No `fxProvide`. The defaults copy qb-storerobbery, qb-bankrobbery, qb-jewelery, qb-houserobbery and qb-truckrobbery, but it does not answer their exports or events.

## Compatible scripts

Tools and loot go through AI Core's inventory layer, police alerts through the dispatch layer, the truck through AI Core's vehicle spawning. Any inventory and alert script AI Core supports works (see [Compatibility](/docs/compatibility)).

## Known limits

- Robbed targets and opened doors reset when the resource restarts.
- The minigame result comes from the player's game; the server still runs the progress bar and every check after it.
- Log channel: `robberies`.
