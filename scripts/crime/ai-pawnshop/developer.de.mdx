ai-pawnshop hat **keine Exports, Events oder State Bags** für andere Skripte. Läden und Plätze sind Panel-Daten, und Items und Geld laufen über AI Core.

## Geld

Verkäufe in der Pfandleihe gehen auf das **Money account** aus dem Panel mit dem Buchungsgrund `pawn:<shopId>` (zum Beispiel `pawn:pawn_vinewood`).

## Welche Fahrzeuge ein Schrottplatz annimmt

Ein Platz nimmt nur Weltfahrzeuge an. Er lehnt ab:

- vom Server erstellte Fahrzeuge (Populationstyp 7, „mission“): Mietwagen, Job- und Dienstfahrzeuge, von einer Garage gespawnte Autos im Besitz, den Geldtransporter und jedes Fahrzeug, das dein eigenes Skript auf dem Server spawnt;
- in ai-vehicles registrierte Fahrzeuge (ein Kennzeichen im Besitz).

Ein vom Server mit `spawnVehicle` der Lib gespawntes Fahrzeug kann also nie verschrottet werden, was Arbeitsfahrzeuge und Mietwagen ohne zusätzlichen Code schützt.

## Eine Pfandleihe aus deinem Skript beliefern

Ein Laden kauft alle Items an, die unter **What it buys** aufgeführt sind. Damit Spieler die Beute deines Skripts verkaufen können, gib ihnen ein Item und füge es im Panel der Liste eines Ladens hinzu; auf der Seite von ai-pawnshop ist kein Code nötig.

## Private Callbacks

Der eigene Vertrag des Skripts (`resource/common/pawn.ts`). Der Server prüft bei jedem Aufruf die Entfernung, den Bestand und die Abklingzeit. Sie können sich zwischen Versionen ändern: Rufe sie nicht aus anderen Ressourcen auf.

| Name | Richtung | Was es überträgt |
| --- | --- | --- |
| `ai-pawnshop:offers` | Client-Callback | `(shopId)`: antwortet mit `{ ok, offers }`, was dieser Laden ankauft, das der Spieler trägt. |
| `ai-pawnshop:sell` | Client-Callback | `(shopId, item, count)`: Items verkaufen. |
| `ai-pawnshop:scrapStart` | Client-Callback | `(yardId, netId)`: beginnen, ein Fahrzeug zu zerlegen; der Server lässt den Fortschrittsbalken laufen und zahlt. |
