AI Core est livré avec une quarantaine de scripts `ai-*`. Ensemble, ils forment un serveur roleplay complet : personnages, argent, inventaire, HUD, véhicules, métiers, police, crime et logement. Vous n’êtes pas obligé de tous les utiliser.

## Comment les scripts s’articulent

- **Chaque script est sa propre ressource.** Il a son propre dossier dans `resources/[ai]/` et sa propre ligne `ensure` dans `server.cfg`. Retirez la ligne et le script disparaît.
- **Chaque réglage se trouve dans le panneau d’administration.** Chaque script ajoute ses propres onglets au [panneau d’administration](/fr/docs/admin-panel) (appuyez sur **F10** en jeu). Vous ne modifiez jamais de fichier de config.
- **Les scripts communiquent à travers AI Core.** Quand un braquage donne un objet, il le demande à AI Core, et AI Core remet l’objet à l’inventaire que vous utilisez. Le script de braquage ne sait pas s’il s’agit d’ai-inventory ou d’un autre inventaire. C’est pourquoi vous pouvez remplacer presque n’importe quel script `ai-*` par un script tiers du même type (voir [Compatibilité](/fr/docs/compatibility)).
- **Les scripts tiers continuent de fonctionner.** Beaucoup de scripts `ai-*` répondent aussi aux exports du script connu qu’ils remplacent. Par exemple, ai-inventory répond à `exports.ox_inventory:AddItem(...)`, donc un script écrit pour ox_inventory fonctionne sans modification. La page de chaque script indique ce qu’il remplace.

## Comment fonctionnent les catégories

Les scripts sont regroupés selon leur usage. Chaque catégorie a une page de présentation, et chaque script a son propre dossier avec deux pages :

- **La page du script** s’adresse aux propriétaires de serveur : ce que fait le script en jeu, comment l’installer, chaque réglage du panneau, ses commandes et ses touches, et les scripts tiers avec lesquels il fonctionne.
- **La page développeur** s’adresse à ceux qui écrivent des scripts : ses exports, events et state bags, avec les types et des exemples en TypeScript et en Lua.

| Catégorie | Ce qu’elle contient |
| --- | --- |
| [Essentiels](/fr/docs/scripts/essentials) | Le framework et les scripts dont chaque serveur a besoin : base de données, interface partagée, écran de chargement, vêtements, inventaire, HUD, chat, voix, menu radial, œil de ciblage, tableau des joueurs, heure et météo. |
| [Véhicules](/fr/docs/scripts/vehicles) | Véhicules possédés, clés, carburant, garages, concessions, parcs d’occasion, location, mécaniciens et gyrophares. |
| [Métiers et services](/fr/docs/scripts/jobs) | Tournées de travail, police, alertes police, prison, mort et EMS, banque, menus de patron et mairie. |
| [Crime et courses](/fr/docs/scripts/crime) | Braquages, drogues, prêteurs sur gages, casses automobiles et courses de rue. |
| [Monde et outils](/fr/docs/scripts/world) | Logement, serrures de portes, nombreuses petites fonctionnalités, corps endormis, taille des personnages et outils d’administration. |

## Touches par défaut

Chaque joueur peut changer chaque touche dans les réglages de GTA (**Settings > Key Bindings > FiveM**). Le propriétaire change la touche de départ pour tout le monde dans le panneau d’administration (onglet **Keybinds**) ; un joueur qui a déjà changé une touche garde la sienne.

| Touche | Action | Script |
| --- | --- | --- |
| F10 | Panneau d’administration (administrateurs uniquement) | ai-core |
| F9 | Menu rapide d’administration (administrateurs uniquement) | ai-admin |
| F3 | Menu radial | ai-radialmenu |
| F2 | Inventaire | ai-inventory |
| TAB | Barre d’emplacements rapides | ai-inventory |
| 1 à 5 | Utiliser l’objet de cet emplacement rapide | ai-inventory |
| R | Recharger l’arme | ai-inventory |
| T | Chat | ai-chat |
| F6 | Menu police (en service) | ai-police |
| E | Interagir avec l’invite à l’écran | ai-lib |
| Retour arrière | Annuler l’action en cours | ai-lib |
| U | Verrouiller ou déverrouiller le véhicule | ai-vehiclekeys |
| M | Moteur allumé / éteint | ai-vehiclekeys |
| K | Ceinture de sécurité | ai-smallresources |
| F11 | Portée de la voix | ai-voice |
| Alt gauche | Parler à la radio | ai-voice |
| Origine (Home) | Tableau des joueurs | ai-scoreboard |

La page de chaque script liste toutes ses touches.
