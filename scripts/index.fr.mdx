## Touches par défaut

Chaque joueur peut changer chaque touche dans les réglages de touches de GTA, et le propriétaire peut changer sa valeur par défaut dans le panneau d’administration (**Keybinds**).

| Touche | Action |
| --- | --- |
| F10 | Panneau d’administration (administrateurs) |
| F9 | Menu rapide d’administration (administrateurs) |
| F1 | Menu radial |
| F2 | Inventaire |
| F6 | Menu police (en service) |
| E | Interagir avec le prompt à l’écran |
| Home (maintenir) | Liste des joueurs |
| Backspace | Annuler l’action en cours |
