AI Core kommt mit rund vierzig `ai-*`-Skripten. Zusammen ergeben sie einen vollständigen Roleplay-Server: Charaktere, Geld, ein Inventar, ein HUD, Fahrzeuge, Jobs, Polizei, Kriminalität und Wohnen. Du musst nicht alle davon nutzen.

## Wie die Skripte zusammenspielen

- **Jedes Skript ist eine eigene Ressource.** Es hat einen eigenen Ordner in `resources/[ai]/` und eine eigene `ensure`-Zeile in der `server.cfg`. Entfernst du die Zeile, ist das Skript weg.
- **Jede Einstellung steht im Admin-Panel.** Jedes Skript fügt dem [Admin-Panel](/de/docs/admin-panel) eigene Tabs hinzu (im Spiel **F10** drücken). Du bearbeitest nie eine Config-Datei.
- **Skripte sprechen über AI Core miteinander.** Wenn ein Überfall ein Item vergibt, fragt er AI Core, und AI Core gibt das Item an das Inventar weiter, das du nutzt. Das Überfallskript weiß nicht, ob das ai-inventory oder ein anderes Inventar ist. Deshalb kannst du fast jedes `ai-*`-Skript durch ein Drittanbieter-Skript derselben Art ersetzen (siehe [Kompatibilität](/de/docs/compatibility)).
- **Drittanbieter-Skripte funktionieren weiter.** Viele `ai-*`-Skripte beantworten auch die Exports des bekannten Skripts, das sie ersetzen. ai-inventory beantwortet zum Beispiel `exports.ox_inventory:AddItem(...)`, sodass ein für ox_inventory geschriebenes Skript unverändert läuft. Die Seite jedes Skripts listet auf, was es ersetzt.

## Wie die Kategorien funktionieren

Die Skripte sind nach ihrem Zweck gruppiert. Jede Kategorie hat eine Übersichtsseite, und jedes Skript hat einen eigenen Ordner mit zwei Seiten:

- **Die Skriptseite** ist für Serverbetreiber: was das Skript im Spiel macht, wie du es installierst, jede Panel-Einstellung, seine Befehle und Tasten und mit welchen Drittanbieter-Skripten es funktioniert.
- **Die Entwicklerseite** ist für Leute, die Skripte schreiben: seine Exports, Events und State Bags, mit Typen und Beispielen in TypeScript und Lua.

| Kategorie | Was drin ist |
| --- | --- |
| [Grundlagen](/de/docs/scripts/essentials) | Das Framework und die Skripte, die jeder Server braucht: Datenbank, gemeinsame UI, Ladebildschirm, Kleidung, Inventar, HUD, Chat, Sprachchat, Radialmenü, Target-Auge, Scoreboard, Zeit und Wetter. |
| [Fahrzeuge](/de/docs/scripts/vehicles) | Fahrzeuge im Besitz, Schlüssel, Sprit, Garagen, Händler, Gebrauchtwagenplätze, Vermietung, Mechaniker und Blaulicht. |
| [Jobs und Dienste](/de/docs/scripts/jobs) | Arbeitsrouten, Polizei, Polizeialarme, Gefängnis, Tod und EMS, Banken, Chefmenüs und das Rathaus. |
| [Kriminalität und Rennen](/de/docs/scripts/crime) | Überfälle, Drogen, Pfandleihen, Schrottplätze und Straßenrennen. |
| [Welt und Werkzeuge](/de/docs/scripts/world) | Wohnen, Türschlösser, viele kleine Funktionen, schlafende Körper, Charaktergröße und Admin-Werkzeuge. |

## Standardtasten

Jeder Spieler kann jede Taste in den Einstellungen von GTA ändern (**Settings > Key Bindings > FiveM**). Der Betreiber ändert die Starttaste für alle im Admin-Panel (Tab **Keybinds**); ein Spieler, der eine Taste schon geändert hat, behält seine eigene.

| Taste | Aktion | Skript |
| --- | --- | --- |
| F10 | Admin-Panel (nur Admins) | ai-core |
| F9 | Admin-Schnellmenü (nur Admins) | ai-admin |
| F3 | Radialmenü | ai-radialmenu |
| F2 | Inventar | ai-inventory |
| TAB | Schnellleiste | ai-inventory |
| 1 bis 5 | Das Item in diesem Schnellplatz benutzen | ai-inventory |
| R | Die Waffe nachladen | ai-inventory |
| T | Chat | ai-chat |
| F6 | Polizeimenü (im Dienst) | ai-police |
| E | Mit der Aufforderung auf dem Bildschirm interagieren | ai-lib |
| Rücktaste | Die laufende Aktion abbrechen | ai-lib |
| U | Fahrzeug ab- oder aufschließen | ai-vehiclekeys |
| M | Motor an / aus | ai-vehiclekeys |
| K | Sicherheitsgurt | ai-smallresources |
| F11 | Sprachreichweite | ai-voice |
| Linke Alt | Über Funk sprechen | ai-voice |
| Pos1 | Scoreboard | ai-scoreboard |

Die Seite jedes Skripts listet alle seine Tasten auf.
