## Standardtasten

Jede Taste kann jeder Spieler in den Tasteneinstellungen von GTA ändern, und ihre Standardbelegung der Betreiber im Admin-Panel (**Keybinds**).

| Taste | Aktion |
| --- | --- |
| F10 | Admin-Panel (Admins) |
| F9 | Admin-Schnellmenü (Admins) |
| F1 | Radialmenü |
| F2 | Inventar |
| F6 | Polizeimenü (im Dienst) |
| E | Mit der Aufforderung auf dem Bildschirm interagieren |
| Pos1 (halten) | Scoreboard |
| Rücktaste | Die laufende Aktion abbrechen |
