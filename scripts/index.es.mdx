AI Core viene con unos cuarenta scripts `ai-*`. Juntos forman un servidor de roleplay completo: personajes, dinero, un inventario, un HUD, vehículos, trabajos, policía, crimen y viviendas. No tienes que usarlos todos.

## Cómo encajan los scripts

- **Cada script es su propio recurso.** Tiene su propia carpeta en `resources/[ai]/` y su propia línea `ensure` en `server.cfg`. Quita la línea y el script desaparece.
- **Todos los ajustes están en el panel de administración.** Cada script añade sus propias pestañas al [panel de administración](/es/docs/admin-panel) (pulsa **F10** en el juego). Nunca editas un archivo de configuración.
- **Los scripts se hablan a través de AI Core.** Cuando un robo da un objeto, se lo pide a AI Core, y AI Core entrega el objeto al inventario que uses. El script de robos no sabe si es ai-inventory u otro inventario. Por eso puedes reemplazar casi cualquier script `ai-*` por un script de terceros del mismo tipo (mira [Compatibilidad](/es/docs/compatibility)).
- **Los scripts de terceros siguen funcionando.** Muchos scripts `ai-*` también responden a los exports del script conocido al que reemplazan. Por ejemplo, ai-inventory responde a `exports.ox_inventory:AddItem(...)`, así que un script escrito para ox_inventory funciona sin cambios. La página de cada script indica a qué sustituye.

## Cómo funcionan las categorías

Los scripts se agrupan según para qué sirven. Cada categoría tiene una página de resumen, y cada script tiene su propia carpeta con dos páginas:

- **La página del script** es para los dueños de servidores: qué hace el script en el juego, cómo instalarlo, cada ajuste del panel, sus comandos y teclas, y con qué scripts de terceros funciona.
- **La página para desarrolladores** es para quien escribe scripts: sus exports, eventos y state bags, con tipos y ejemplos en TypeScript y Lua.

| Categoría | Qué contiene |
| --- | --- |
| [Esenciales](/es/docs/scripts/essentials) | El framework y los scripts que necesita cualquier servidor: base de datos, interfaz compartida, pantalla de carga, ropa, inventario, HUD, chat, voz, menú radial, ojo de interacción, marcador de jugadores, hora y clima. |
| [Vehículos](/es/docs/scripts/vehicles) | Vehículos en propiedad, llaves, combustible, garajes, concesionarios, compraventa de usados, alquiler, mecánicos y luces de emergencia. |
| [Trabajos y servicios](/es/docs/scripts/jobs) | Rutas de trabajo, policía, alertas policiales, prisión, muerte y EMS, banca, menús de jefe y el ayuntamiento. |
| [Crimen y carreras](/es/docs/scripts/crime) | Robos, drogas, casas de empeño, desguaces y carreras callejeras. |
| [Mundo y herramientas](/es/docs/scripts/world) | Viviendas, cerraduras de puertas, muchas funciones pequeñas, cuerpos dormidos, tamaño del personaje y herramientas de administración. |

## Teclas por defecto

Cada jugador puede cambiar cualquier tecla en los ajustes de GTA (**Settings > Key Bindings > FiveM**). El dueño cambia la tecla inicial para todos en el panel de administración (pestaña **Keybinds**); un jugador que ya cambió una tecla conserva la suya.

| Tecla | Acción | Script |
| --- | --- | --- |
| F10 | Panel de administración (solo administradores) | ai-core |
| F9 | Menú rápido de administración (solo administradores) | ai-admin |
| F3 | Menú radial | ai-radialmenu |
| F2 | Inventario | ai-inventory |
| TAB | Barra de accesos rápidos | ai-inventory |
| 1 a 5 | Usar el objeto de esa ranura rápida | ai-inventory |
| R | Recargar el arma | ai-inventory |
| T | Chat | ai-chat |
| F6 | Menú de policía (de servicio) | ai-police |
| E | Interactuar con el aviso en pantalla | ai-lib |
| Backspace | Cancelar la acción en curso | ai-lib |
| U | Cerrar o abrir el vehículo | ai-vehiclekeys |
| M | Encender / apagar el motor | ai-vehiclekeys |
| K | Cinturón | ai-smallresources |
| F11 | Alcance de voz | ai-voice |
| Alt izquierdo | Hablar por la radio | ai-voice |
| Home | Marcador de jugadores | ai-scoreboard |

La página de cada script indica todas sus teclas.
