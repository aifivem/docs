## Domyślne klawisze

Każdy gracz może zmienić każdy klawisz w ustawieniach klawiszy GTA, a właściciel jego wartość domyślną w panelu administratora (**Keybinds**).

| Klawisz | Akcja |
| --- | --- |
| F10 | Panel administratora (administratorzy) |
| F9 | Szybkie menu administratora (administratorzy) |
| F1 | Menu radialne |
| F2 | Ekwipunek |
| F6 | Menu policji (na służbie) |
| E | Interakcja z podpowiedzią na ekranie |
| Home (przytrzymaj) | Tablica wyników |
| Backspace | Anulowanie trwającej akcji |
