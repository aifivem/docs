AI Core zawiera około czterdziestu skryptów `ai-*`. Razem tworzą pełny serwer roleplay: postacie, pieniądze, ekwipunek, HUD, pojazdy, prace, policję, przestępczość i nieruchomości. Nie musisz używać ich wszystkich.

## Jak skrypty do siebie pasują

- **Każdy skrypt to osobny zasób.** Ma własny folder w `resources/[ai]/` i własną linię `ensure` w `server.cfg`. Usuń linię, a skryptu nie będzie.
- **Każde ustawienie jest w panelu administratora.** Każdy skrypt dodaje własne zakładki do [panelu administratora](/pl/docs/admin-panel) (naciśnij **F10** w grze). Nigdy nie edytujesz pliku konfiguracyjnego.
- **Skrypty komunikują się przez AI Core.** Gdy napad daje przedmiot, prosi o to AI Core, a AI Core przekazuje przedmiot do ekwipunku, którego używasz. Skrypt napadów nie wie, czy to ai-inventory, czy inny ekwipunek. Dlatego możesz zastąpić prawie każdy skrypt `ai-*` skryptem zewnętrznym tego samego rodzaju (zobacz [Zgodność](/pl/docs/compatibility)).
- **Skrypty zewnętrzne działają dalej.** Wiele skryptów `ai-*` odpowiada też na eksporty znanego skryptu, który zastępują. Na przykład ai-inventory odpowiada na `exports.ox_inventory:AddItem(...)`, więc skrypt napisany dla ox_inventory działa bez zmian. Strona każdego skryptu podaje, co zastępuje.

## Jak działają kategorie

Skrypty są pogrupowane według przeznaczenia. Każda kategoria ma stronę przeglądu, a każdy skrypt ma własny folder z dwiema stronami:

- **Strona skryptu** jest dla właścicieli serwerów: co skrypt robi w grze, jak go zainstalować, każde ustawienie w panelu, jego komendy i klawisze oraz z jakimi skryptami zewnętrznymi współpracuje.
- **Strona dla deweloperów** jest dla osób piszących skrypty: jego eksporty, zdarzenia i state bagi, z typami i przykładami w TypeScript i Lua.

| Kategoria | Co zawiera |
| --- | --- |
| [Podstawy](/pl/docs/scripts/essentials) | Framework i skrypty, których potrzebuje każdy serwer: baza danych, wspólne UI, ekran ładowania, ubrania, ekwipunek, HUD, czat, głos, menu radialne, oko targetu, tablica wyników, czas i pogoda. |
| [Pojazdy](/pl/docs/scripts/vehicles) | Posiadane pojazdy, klucze, paliwo, garaże, salony, komisy używanych aut, wypożyczalnia, mechanicy i światła uprzywilejowane. |
| [Prace i służby](/pl/docs/scripts/jobs) | Trasy pracy, policja, alerty policyjne, więzienie, śmierć i EMS, bankowość, menu szefa i ratusz. |
| [Przestępczość i wyścigi](/pl/docs/scripts/crime) | Napady, narkotyki, lombardy, złomowiska i wyścigi uliczne. |
| [Świat i narzędzia](/pl/docs/scripts/world) | Nieruchomości, zamki drzwi, wiele drobnych funkcji, śpiące ciała, rozmiar postaci i narzędzia administratora. |

## Domyślne klawisze

Każdy gracz może zmienić każdy klawisz we własnych ustawieniach GTA (**Settings > Key Bindings > FiveM**). Właściciel zmienia klawisz początkowy dla wszystkich w panelu administratora (zakładka **Keybinds**); gracz, który już zmienił klawisz, zachowuje własny.

| Klawisz | Akcja | Skrypt |
| --- | --- | --- |
| F10 | Panel administratora (tylko administratorzy) | ai-core |
| F9 | Szybkie menu administratora (tylko administratorzy) | ai-admin |
| F3 | Menu radialne | ai-radialmenu |
| F2 | Ekwipunek | ai-inventory |
| TAB | Pasek szybkich slotów | ai-inventory |
| od 1 do 5 | Użyj przedmiotu z danego szybkiego slotu | ai-inventory |
| R | Przeładuj broń | ai-inventory |
| T | Czat | ai-chat |
| F6 | Menu policji (na służbie) | ai-police |
| E | Interakcja z podpowiedzią na ekranie | ai-lib |
| Backspace | Anuluj trwającą czynność | ai-lib |
| U | Zamknij lub otwórz pojazd | ai-vehiclekeys |
| M | Silnik wł. / wył. | ai-vehiclekeys |
| K | Pasy | ai-smallresources |
| F11 | Zasięg głosu | ai-voice |
| Lewy Alt | Mów przez radio | ai-voice |
| Home | Tablica wyników | ai-scoreboard |

Strona każdego skryptu wymienia wszystkie jego klawisze.
