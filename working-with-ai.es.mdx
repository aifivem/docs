AI Core está hecho para que alguien que no sabe programar pueda pedirle a una IA que cambie un script o escriba uno nuevo, y obtenga un resultado que encaje.

Abre la carpeta de datos de tu servidor en Claude Code (u otro agente de programación: lee `AGENTS.md`) y pide lo que quieras con tus propias palabras. La IA encuentra:

| Archivo | Qué contiene |
| --- | --- |
| `CLAUDE.md` | Objetivos, estructura, decisiones, el proceso de compilación y comprobación. |
| `.claude/rules/` | Reglas por tema que se cargan cuando se editan los archivos correspondientes. |
| `.claude/skills/aicore-fivem`, `aicore-ui`, `aicore-mysql` | Conocimiento del motor de FiveM, de NUI y de SQL. |
| `resources/[ai]/<script>/CLAUDE.md` | Qué hace cada script y por qué. |
| `docs/compat/` | Las interfaces de los frameworks y notas sobre scripts de terceros. |

<Callout type="warn">
Aun así, se recomienda probar el código generado antes de ponerlo en un servidor en producción.
</Callout>

## ¿Necesito IA?

No. Desarrollar con ayuda de la IA es opcional. AI Core funciona como un framework de FiveM normal y no necesita ningún servicio de IA para funcionar.
