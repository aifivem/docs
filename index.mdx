**AI Core** is a free, open-source FiveM framework built from the ground up with **TypeScript**, designed to make server development easier, smarter and more accessible to everyone.

Inspired by ESX and QBCore, AI Core combines an AI-friendly architecture, cross-framework compatibility, automatic resource integration and in-game management tools. Whether you are an experienced developer or have never written a line of code, you can build your server your way.

## Why AI Core

<Cards>
  <Card title="Built for AI development">
    Dedicated AI instructions, development guidelines and one consistent TypeScript architecture.
  </Card>
  <Card title="ESX & QBCore compatibility">
    Designed to run existing ESX and QBCore scripts, including paid third-party resources.
  </Card>
  <Card title="Automatic script integration">
    Detects supported installed scripts and adapts related systems.
  </Card>
  <Card title="Manage everything in-game">
    Framework settings live in an in-game admin panel, not in config files.
  </Card>
</Cards>
