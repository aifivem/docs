**AI Core** is a free, open-source FiveM framework built from the ground up with **TypeScript**, designed to make server development easier, smarter and more accessible to everyone.

Inspired by ESX, QBCore and Qbox, AI Core combines an AI-friendly architecture, cross-framework compatibility, automatic resource integration and in-game management tools. It ships with around forty `ai-*` scripts that cover a full roleplay server, from the character screen to jobs, vehicles, housing and crime. Whether you are an experienced developer or have never written a line of code, you can build your server your way.

## Why AI Core

<Cards>
  <Card title="Built for AI development">
    Dedicated AI instructions, development guidelines and one consistent TypeScript architecture.
  </Card>
  <Card title="ESX, QBCore, Qbox and vRP compatibility">
    Existing ESX, QBCore, Qbox and vRP scripts run unchanged, including paid third-party resources.
  </Card>
  <Card title="Automatic script integration">
    Detects supported inventories, key systems, phones, dispatch, clothing and more, and adapts to them.
  </Card>
  <Card title="Manage everything in-game">
    Every setting of every script lives in one in-game admin panel, not in config files.
  </Card>
  <Card title="Server-authoritative">
    Strict FiveM security settings, every client request checked on the server.
  </Card>
  <Card title="Built for scale">
    Every system is planned for thousands of players and millions of records, and measured.
  </Card>
</Cards>
