**AI Core** ist ein kostenloses Open-Source-FiveM-Framework, von Grund auf in **TypeScript** geschrieben, damit Serverentwicklung für alle einfacher, klüger und zugänglicher wird.

Inspiriert von ESX, QBCore und Qbox verbindet AI Core eine KI-freundliche Architektur, Framework-übergreifende Kompatibilität, automatische Integration von Ressourcen und Verwaltungswerkzeuge im Spiel. Es kommt mit rund vierzig `ai-*`-Skripten, die einen kompletten Roleplay-Server abdecken, vom Charakterbildschirm bis zu Jobs, Fahrzeugen, Häusern und Kriminalität. Ob du ein erfahrener Entwickler bist oder noch nie eine Zeile Code geschrieben hast: Du baust deinen Server auf deine Art.

## Warum AI Core

<Cards>
  <Card title="Für KI-Entwicklung gebaut">
    Eigene KI-Anweisungen, Entwicklungsregeln und eine einheitliche TypeScript-Architektur.
  </Card>
  <Card title="ESX-, QBCore-, Qbox- und vRP-kompatibel">
    Vorhandene ESX-, QBCore-, Qbox- und vRP-Skripte laufen unverändert, auch kostenpflichtige Ressourcen von Drittanbietern.
  </Card>
  <Card title="Automatische Skriptintegration">
    Erkennt unterstützte Inventare, Schlüsselsysteme, Handys, Dispatch, Kleidung und mehr und passt sich ihnen an.
  </Card>
  <Card title="Alles im Spiel verwalten">
    Jede Einstellung jedes Skripts steht in einem Admin-Panel im Spiel, nicht in Config-Dateien.
  </Card>
  <Card title="Der Server entscheidet">
    Strenge FiveM-Sicherheitseinstellungen, jede Client-Anfrage wird auf dem Server geprüft.
  </Card>
  <Card title="Für Skalierung gebaut">
    Jedes System ist für Tausende Spieler und Millionen Datensätze geplant und gemessen.
  </Card>
</Cards>
