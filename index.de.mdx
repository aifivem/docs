**AI Core** ist ein kostenloses Open-Source-FiveM-Framework, von Grund auf in **TypeScript** geschrieben, damit Serverentwicklung einfacher, klüger und für alle zugänglich wird.

Inspiriert von ESX, QBCore und Qbox verbindet AI Core eine KI-freundliche Architektur, Framework-übergreifende Kompatibilität, automatische Integration von Ressourcen und Verwaltung im Spiel. Rund vierzig `ai-*`-Skripte decken einen kompletten Roleplay-Server ab, vom Charakterbildschirm bis zu Jobs, Fahrzeugen, Häusern und Kriminalität.

## Warum AI Core

<Cards>
  <Card title="Für KI-Entwicklung gebaut">
    Eigene KI-Anweisungen, Entwicklungsregeln und eine einheitliche TypeScript-Architektur.
  </Card>
  <Card title="ESX-, QBCore- und Qbox-kompatibel">
    Vorhandene ESX-, QBCore- und Qbox-Skripte laufen unverändert, auch kostenpflichtige.
  </Card>
  <Card title="Automatische Integration">
    Erkennt unterstützte Inventare, Schlüsselsysteme, Handys, Dispatch, Kleidung und mehr.
  </Card>
  <Card title="Alles im Spiel verwalten">
    Jede Einstellung jedes Skripts steht in einem Admin-Panel im Spiel, nicht in Config-Dateien.
  </Card>
  <Card title="Server entscheidet">
    Strenge FiveM-Sicherheitseinstellungen, jede Client-Anfrage wird auf dem Server geprüft.
  </Card>
  <Card title="Für große Server">
    Jedes System ist für Tausende Spieler und Millionen Datensätze geplant und gemessen.
  </Card>
</Cards>
