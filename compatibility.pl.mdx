Prawie każdy skrypt FiveM jest napisany dla ESX, QBCore lub Qbox, więc ich uruchamianie to główny cel. AI Core nie dołącza żadnych skryptów zewnętrznych i nie faworyzuje żadnego dostawcy: instalujesz własne.

## Trzy warstwy

<Steps>
<Step>

### Most frameworków

AI Core udostępnia `es_extended`, `qb-core` i `qbx_core` i odpowiada na ich eksporty, obiekty core, obiekty graczy, callbacki, zdarzenia i dołączane pliki (`@qb-core/shared/locale.lua`, `@es_extended/imports.lua`, `@qbx_core/modules/playerdata.lua`), więc skrypty napisane dla ESX, QBCore lub Qbox widzą AI Core jako swój framework i działają bez zmian. Ich menu, podpowiedzi tekstowe, paski postępu i okna wprowadzania są rysowane własnym UI AI Core.

</Step>
<Step>

### Warstwy integracji

AI Core i skrypty `ai-*` potrzebują rzeczy, które dostarczają inne skrypty. Każda kategoria ma jeden interfejs, a każdy obsługiwany skrypt to jeden adapter. AI Core wykrywa zainstalowany skrypt przy starcie oraz gdy skrypty się uruchamiają lub zatrzymują; panel administratora może nadpisać ten wybór.

| Kategoria | Przykłady |
| --- | --- |
| Ekwipunek | ai-inventory, ox_inventory, qb-inventory, tgiann-inventory i inne |
| Klucze pojazdów | ai-vehiclekeys, qbx_vehiclekeys i inne |
| Dispatch (alerty policyjne) | ai-policealert i skrypty alertów |
| Telefon | tgiann-phone, lb-phone |
| Ubrania | ai-appearance, tgiann-clothing |
| Śmierć | ai-death |
| Pogoda i czas | ai-weathersync, qb-weathersync, Renewed-Weathersync, cd_easytime |
| Więzienie | ai-prison, qb-prison |
| Menu radialne | ai-radialmenu, qb-radialmenu, ox_lib |

</Step>
<Step>

### Zamienniki

Kilka skryptów `ai-*` odpowiada na API skryptu, który zastępuje, więc skrypty zewnętrzne działają z nimi bez adaptera: ai-mysql zastępuje oxmysql (także mysql-async i ghmattimysql), ai-inventory zastępuje ox_inventory i qb-inventory, ai-target ox_target, ai-voice pma-voice, ai-chat chat, a ai-vehicles i ai-vehiclekeys skrypty pojazdów Qbox.

</Step>
</Steps>

Na liście [zgodnych skryptów](/pl/scripts) zobaczysz, z czym AI Core integruje się dziś.

## Zastępowanie skryptu ai-*

Jeśli zainstalujesz płatny skrypt, który zastępuje jeden ze skryptów `ai-*` (na przykład inny ekwipunek), AI Core powie ci, który folder usunąć, i nie wpuszcza graczy, dopóki działają oba, więc dwa skrypty nigdy nie walczą o to samo zadanie.

## Dodawanie skryptu

Obsługa nowego skryptu to jedno małe, powtarzalne zadanie: skopiuj szablon adaptera danej kategorii, uzupełnij jego wywołania, dodaj jedną linię do rejestru. Możesz poprosić o to swoje AI.
