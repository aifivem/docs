AI Core опирается на труд сообщества FiveM с открытым кодом. Его мост фреймворков отвечает на API ESX, QBCore и Qbox, его lib покрывает то, что даёт ox_lib, а многие скрипты `ai-*` написаны по мотивам открытых скриптов ниже: их функций, мест по умолчанию (стойки, NPC, точки, камеры), значений настроек и, где позволяет лицензия, их кода. Спасибо всем, кто их создал и поделился ими.

AI Core выпущен под GNU GPL v3 (`LICENSE` в каждом репозитории), что сохраняет его совместимость с проектами под GPL и LGPL, на которых он учился. Каждый проект сохраняет свои авторские права; названия ниже являются товарными знаками их владельцев и используются только для описания совместимости.

## Фреймворки

| Проект | Авторы | Лицензия | Что AI Core из него берёт |
| --- | --- | --- | --- |
| [ESX Legacy](https://github.com/esx-framework/esx_core) | ESX Framework | GPL-3.0 | API моста `es_extended` (xPlayer, события, колбэки), модель работ и счетов |
| [QBCore](https://github.com/qbcore-framework/qb-core) | QBCore Framework | GPL-3.0 | API моста `qb-core` (объект Player, метаданные, события, команды), общие предметы, работы, банды, места по умолчанию |
| [Qbox](https://github.com/Qbox-project/qbx_core) | Qbox Project | GPL-3.0 | API моста `qbx_core`, идеи нескольких работ и групп, многие скрипты qbx_* из списка ниже |
| [ox_core](https://github.com/overextended/ox_core) | Overextended | LGPL-3.0 | Модель данных и идеи дизайна, где решает сервер |
| [ND Core](https://github.com/ND-Framework/ND_Core) | ND Framework | GPL-3.0 | Сравнение фреймворков |
| [vRP](https://github.com/ImagicTheCat/vRP) | ImagicTheCat | MIT | Сравнение фреймворков |
