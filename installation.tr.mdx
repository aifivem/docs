## Gereksinimler

| Bağımlılık | Sürüm | Neden |
| --- | --- | --- |
| FXServer (artifact) | 38039 veya daha yenisi önerilir | Yeni sürümlerde sunucu oyuncu ölümlerini kendisi görür. Eski sürümler de çalışır. |
| [Bun](https://bun.sh) | güncel | Paketleri kurar ve TypeScript resource’larını derler. |
| MariaDB | güncel | Veritabanı. |

## Kurulum adımları

<Steps>
<Step>

### Sunucu klasörünü al

[ai-core](https://github.com/aifivem/ai-core) reposunu sunucu veri klasörü olarak kullanacağın klasöre klonla.

</Step>
<Step>

### Gizli bilgileri ayarla

`env.example.cfg` dosyasını `env.cfg` olarak kopyala, lisans anahtarını ve veritabanı bağlantısını gir, ardından veritabanını oluştur.

</Step>
<Step>

### Paketleri kur ve derle

```bash
bun install
bun run build
```

</Step>
<Step>

### Sunucuyu başlat

FXServer’ı (txAdmin) bu klasörü sunucu veri klasörü olarak göstererek başlat.

</Step>
</Steps>

## Klasör yapısı

| Yol | Ne |
| --- | --- |
| `server.cfg`, `security.cfg`, `misc.cfg`, `permission.cfg` | Sunucu ayarları. Gizli bilgiler `env.cfg` dosyasına gider. |
| `resources/[ai]/` | AI Core resource’ları, her `ai-*` klasörü ayrı bir git reposu. |
| `resources/[standalone]/` | Üçüncü parti resource’lar. |
| `packages/` | `@aicore-fivem/*` npm paketleri. |
| `template/` | Yeni resource şablonu: `bun run new <isim> "<açıklama>"`. |
