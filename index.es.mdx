**AI Core** es un framework de FiveM gratuito y de código abierto, construido desde cero con **TypeScript**, pensado para que el desarrollo de servidores sea más fácil, más inteligente y más accesible para todos.

Inspirado en ESX, QBCore y Qbox, AI Core combina una arquitectura pensada para la IA, compatibilidad entre frameworks, integración automática de recursos y herramientas de gestión dentro del juego. Viene con unos cuarenta scripts `ai-*` que cubren un servidor de roleplay completo, desde la pantalla de personajes hasta trabajos, vehículos, viviendas y crimen. Tanto si eres un desarrollador con experiencia como si nunca has escrito una línea de código, puedes construir tu servidor a tu manera.

## Por qué AI Core

<Cards>
  <Card title="Hecho para desarrollar con IA">
    Instrucciones dedicadas para la IA, guías de desarrollo y una única arquitectura TypeScript coherente.
  </Card>
  <Card title="Compatible con ESX, QBCore, Qbox y vRP">
    Los scripts existentes de ESX, QBCore, Qbox y vRP funcionan sin cambios, incluidos los recursos de pago de terceros.
  </Card>
  <Card title="Integración automática de scripts">
    Detecta los inventarios, sistemas de llaves, teléfonos, dispatch, ropa y más que son compatibles, y se adapta a ellos.
  </Card>
  <Card title="Gestiona todo desde el juego">
    Cada ajuste de cada script está en un único panel de administración dentro del juego, no en archivos de configuración.
  </Card>
  <Card title="El servidor decide">
    Ajustes de seguridad de FiveM estrictos; cada petición del cliente se comprueba en el servidor.
  </Card>
  <Card title="Pensado para escalar">
    Cada sistema se diseña para miles de jugadores y millones de registros, y se mide.
  </Card>
</Cards>
