**AI Core** es un framework de FiveM gratuito y de código abierto, escrito desde cero en **TypeScript**, para que crear servidores sea más fácil, más inteligente y accesible para todos.

Inspirado en ESX, QBCore y Qbox, AI Core une una arquitectura pensada para la IA, compatibilidad entre frameworks, integración automática de recursos y gestión dentro del juego. Unos cuarenta scripts `ai-*` cubren un servidor de roleplay completo, desde la pantalla de personajes hasta trabajos, vehículos, viviendas y crimen.

## Por qué AI Core

<Cards>
  <Card title="Hecho para desarrollar con IA">
    Instrucciones para IA, reglas de desarrollo y una arquitectura TypeScript coherente.
  </Card>
  <Card title="Compatible con ESX, QBCore y Qbox">
    Los scripts existentes de ESX, QBCore y Qbox funcionan sin cambios, incluidos los de pago.
  </Card>
  <Card title="Integración automática">
    Detecta inventarios, sistemas de llaves, teléfonos, dispatch, ropa y más, y se adapta.
  </Card>
  <Card title="Todo desde el juego">
    Cada ajuste de cada script está en un panel de administración dentro del juego, no en archivos de configuración.
  </Card>
  <Card title="El servidor decide">
    Ajustes de seguridad de FiveM estrictos; cada petición del cliente se comprueba en el servidor.
  </Card>
  <Card title="Pensado para escalar">
    Cada sistema se diseña para miles de jugadores y millones de registros, y se mide.
  </Card>
</Cards>
