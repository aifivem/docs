## Requirements

| Dependency | Version | Why |
| --- | --- | --- |
| FXServer (artifact) | 38039 or newer recommended | Newer builds let the server see player deaths itself. Older builds still run. |
| [Bun](https://bun.sh) | latest | Installs packages and builds the TypeScript resources. |
| MariaDB | latest | The database. |

## Setup

<Steps>
<Step>

### Get the server data folder

Clone [ai-core](https://github.com/aifivem/ai-core) into the folder you will use as your server data folder.

</Step>
<Step>

### Configure secrets

Copy `env.example.cfg` to `env.cfg`, fill in your license key and the database connection, then create the database.

</Step>
<Step>

### Install and build

```bash
bun install
bun run build
```

</Step>
<Step>

### Start the server

Start FXServer (txAdmin) with this folder as the server data folder.

</Step>
</Steps>

## Layout

| Path | What |
| --- | --- |
| `server.cfg`, `security.cfg`, `misc.cfg`, `permission.cfg` | Server config. Secrets go into `env.cfg`. |
| `resources/[ai]/` | AI Core resources, each `ai-*` folder its own git repo. |
| `resources/[standalone]/` | Third-party resources. |
| `packages/` | The `@aicore-fivem/*` npm packages. |
| `template/` | Template for new resources: `bun run new <name> "<description>"`. |
