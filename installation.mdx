## Requirements

| Dependency | Version | Why |
| --- | --- | --- |
| FXServer (artifact) with txAdmin | 38039 or newer | ai-core needs it: the server sees player deaths itself. |
| MariaDB (or MySQL) | latest | The database. AI Core creates its own tables. |
| [Bun](https://bun.sh) | latest | Only to change or build scripts. Every script ships with its build, so running a server needs no build tools. |

## Install with txAdmin (recommended)

<Steps>
<Step>

### Start txAdmin

Download the latest FXServer artifact and start it: txAdmin opens in your browser. Follow the [official guide](https://docs.fivem.net/docs/server-manual/setting-up-a-server-txadmin/) up to the deployment step.

</Step>
<Step>

### Use the AI Core recipe

Choose **Popular Recipes > Remote URL Template** and paste:

```text
https://raw.githubusercontent.com/aifivem/aicore-server/main/recipe/ai-core.yaml
```

</Step>
<Step>

### Fill in the details

Enter your server name, your license key from [portal.cfx.re](https://portal.cfx.re/) and the database. The recipe writes `server.cfg` and `env.cfg`, connects the database and downloads every `ai-*` script. There is no SQL file to import: AI Core and the scripts create and update their own tables at the first start.

</Step>
<Step>

### Make yourself an admin

Join the server. A welcome card shows the line that makes you an admin: add it to `permission.cfg` and restart. Then press **F10** to open the [admin panel](/docs/admin-panel); its setup guide walks you through the first settings.

</Step>
</Steps>

<Callout>
The server list name, description, tags, language, banners and Discord link are set at [portal.cfx.re/servers](https://portal.cfx.re/servers), not in `server.cfg`.
</Callout>

## Install by hand

<Steps>
<Step>

### Get the server folder

Download the server folder (the cfg files, `recipe/`, `tools/`, `template/`) and put each `ai-*` script into `resources/[ai]/`.

</Step>
<Step>

### Configure secrets

Copy `env.example.cfg` to `env.cfg`, fill in your license key and the database connection, then create the database.

</Step>
<Step>

### Start the server

Start FXServer (txAdmin) with this folder as the server data folder.

</Step>
</Steps>

## Layout

| Path | What |
| --- | --- |
| `server.cfg` | The resource list and config includes. |
| `env.cfg` | License, slots, endpoints, database, RCON. Machine-specific, never in git. |
| `security.cfg` | Strict FiveM security settings. Never loosen them: every script is written for them. |
| `permission.cfg` | Admins and ACE permissions. |
| `misc.cfg` | Language and other shared convars. |
| `resources/[ai]/` | The AI Core scripts, each `ai-*` folder its own git repository. |
| `resources/[standalone]/` | Third-party resources you add. |
| `packages/` | The `@aicore-fivem/*` packages (developers). |
| `template/` | Template for new scripts: `bun run new <name> "<description>"`. |
