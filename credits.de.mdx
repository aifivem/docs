AI Core baut auf der Arbeit der Open-Source-FiveM-Community auf. Seine Framework-Brücke beantwortet die APIs von ESX, QBCore und Qbox, seine Lib deckt ab, was ox_lib bietet, und viele `ai-*`-Skripte entstanden beim Lesen der Open-Source-Skripte unten: ihre Funktionen, Standardorte (Theken, NPCs, Punkte, Kameras), Konfigurationswerte und, wo die Lizenz es erlaubt, ihr Code. Danke an alle, die sie gebaut und geteilt haben.

AI Core steht unter der GNU GPL v3 (`LICENSE` in jedem Repository), was es mit den GPL- und LGPL-Projekten verträglich hält, von denen es gelernt hat. Jedes Projekt behält sein eigenes Urheberrecht; die Namen unten sind Marken ihrer Inhaber und dienen nur dazu, die Kompatibilität zu beschreiben.

## Frameworks

| Projekt | Autoren | Lizenz | Was AI Core davon übernimmt |
| --- | --- | --- | --- |
| [ESX Legacy](https://github.com/esx-framework/esx_core) | ESX Framework | GPL-3.0 | API der `es_extended`-Brücke (xPlayer, Events, Callbacks), Job- und Kontenmodell |
| [QBCore](https://github.com/qbcore-framework/qb-core) | QBCore Framework | GPL-3.0 | API der `qb-core`-Brücke (Player-Objekt, Metadaten, Events, Befehle), gemeinsame Items, Jobs, Gangs, Standardorte |
| [Qbox](https://github.com/Qbox-project/qbx_core) | Qbox Project | GPL-3.0 | API der `qbx_core`-Brücke, Ideen zu Multi-Job und Gruppen, viele unten genannte qbx_*-Skripte |
| [ox_core](https://github.com/overextended/ox_core) | Overextended | LGPL-3.0 | Datenmodell und Ideen für ein serverautoritatives Design |
| [ND Core](https://github.com/ND-Framework/ND_Core) | ND Framework | GPL-3.0 | Framework-Vergleich |
| [vRP](https://github.com/ImagicTheCat/vRP) | ImagicTheCat | MIT | Framework-Vergleich |
