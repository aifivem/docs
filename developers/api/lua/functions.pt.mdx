Todo membro do `aiLib`, a partir do `init.lua` do ai-lib. A maioria é o equivalente de uma função TypeScript e está documentada na página dessa função, com a chamada Lua no bloco de assinatura e uma aba de exemplo em Lua. **Espera** significa que a chamada pausa até a resposta chegar: chame dentro de uma thread (veja [Funções que esperam](/pt/docs/developers/api/lua#funções-que-esperam)).

Os métodos de uma classe (`points:add(...)`, `job:set(...)`) são listados junto com a classe.
