Каждый член `aiLib` из `init.lua` в ai-lib. Большинство из них являются аналогами функций TypeScript и описаны на странице этой функции: вызов на Lua есть в блоке сигнатуры, а пример на Lua на отдельной вкладке. **Ждёт** означает, что вызов приостанавливается до прихода ответа: вызывайте его внутри потока (см. [Функции, которые ждут](/ru/docs/developers/api/lua#функции-которые-ждут)).

Методы класса (`points:add(...)`, `job:set(...)`) перечислены вместе со своим классом.
