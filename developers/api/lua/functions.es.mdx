Cada miembro de `aiLib`, a partir del `init.lua` de ai-lib. La mayoría son el equivalente de una función de TypeScript y se documentan en la página de esa función, con la llamada Lua en el bloque de firma y una pestaña de ejemplo Lua. **Espera** significa que la llamada se pausa hasta que llega la respuesta: llámala dentro de un hilo (consulta [Funciones que esperan](/es/docs/developers/api/lua#funciones-que-esperan)).

Los métodos de una clase (`points:add(...)`, `job:set(...)`) se listan con su clase.
