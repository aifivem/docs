Jedes Mitglied von `aiLib`, aus der `init.lua` von ai-lib. Die meisten sind der Zwilling einer TypeScript-Funktion und werden auf der Seite dieser Funktion dokumentiert, mit dem Lua-Aufruf im Signaturblock und einem Lua-Beispieltab. **Wartet** bedeutet, dass der Aufruf anhält, bis die Antwort kommt: Rufe ihn innerhalb eines Threads auf (siehe [Funktionen, die warten](/de/docs/developers/api/lua#funktionen-die-warten)).

Methoden einer Klasse (`points:add(...)`, `job:set(...)`) werden mit ihrer Klasse aufgeführt.
