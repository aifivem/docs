Większość funkcji `aiLib` to odpowiednik w Lua funkcji TypeScript i jest opisana obok niej, w zakładce Lua (zobacz [Każda funkcja aiLib](/pl/docs/developers/api/lua/functions)). Te z tej strony mają w Lua inną nazwę, kształt albo zachowanie, więc są opisane tutaj.

## Klient: dane gracza

### aiLib.playerData.get

Ostatnia wartość, którą ai-core wysłał dla jednego klucza danych lokalnego gracza. Gdy od startu twojego zasobu nic nie przyszło, pyta ai-core raz (`GetPlayerData`) i zachowuje odpowiedź.

**Strona:** Klient · **Czeka:** nie

```lua title="Lua"
local value = aiLib.playerData.get(key)
```

**TypeScript:** te same dane przez `getPlayerData(key)` (zobacz [Członkostwo i dane gracza](/pl/docs/developers/api/lib-client/membership)).

#### Parametry

<TypeTable
  type={{
    key: { type: "'character' | 'money' | 'jobs' | 'duty' | 'job' | 'gangs' | 'activeGang' | 'metadata'", description: 'Klucz z [AiPlayerData](/pl/docs/developers/api/types#aiplayerdata).', required: true },
  }}
/>

#### Zwracana wartość

Wartość: tabela dla `character`, `money` (`{ cash = 500, bank = 5000 }`), `jobs`, `job`, `gangs` i `metadata`; string albo `nil` dla `duty` i `activeGang`. `nil`, dopóki żadna postać nie jest wczytana albo ai-core nie działa.

#### Przykład

```lua title="client.lua"
RegisterCommand('cash', function()
    local money = aiLib.playerData.get('money') or {}
    aiLib.notify(('Cash: $%s'):format(aiLib.numbers.groupDigits(money.cash or 0)), 'info')
end, false)
```

### aiLib.playerData.onChange

Uruchamia funkcję za każdym razem, gdy ai-core wypycha nową wartość jednego klucza lokalnego gracza (zmiana pracy, pieniądze, wejście na służbę). Dla `money` i `metadata` ai-core wysyła tylko zmienione wpisy; aiLib je scala, więc twój handler zawsze dostaje całą tabelę.

**Strona:** Klient · **Czeka:** nie

```lua title="Lua"
aiLib.playerData.onChange(key, function(value) end)
```

**TypeScript:** `onPlayerData(key, handler)` (zobacz [Członkostwo i dane gracza](/pl/docs/developers/api/lib-client/membership)).

#### Parametry

<TypeTable
  type={{
    key: { type: 'string', description: 'Klucz z `AiPlayerData` (zobacz `get` wyżej).', required: true },
    handler: { type: 'fun(value: any)', description: 'Dostaje nową wartość. Działa po każdym wypchnięciu, także gdy postać się wczytuje.', required: true },
  }}
/>

#### Zwracana wartość

Nic. Nie da się usunąć handlera; znika razem z twoim zasobem.

#### Przykład

```lua title="client.lua"
aiLib.playerData.onChange('duty', function(job)
    if job == 'police' then
        aiLib.notify('You are now on duty', 'success')
    end
end)
```

## Serwer: gracze online

`aiLib.online` czyta wczytanych graczy przez eksporty ai-core, jedno wywołanie eksportu na odczyt. Jest przeznaczone do sprawdzeń w chwili akcji (komenda, callback), nie do każdego ticku. `online` w TypeScript trzyma lokalne lustro z większą liczbą czytników i innymi kształtami wyników (zobacz [Gracze](/pl/docs/developers/api/lib-server/players)).

### aiLib.online.character

Wczytana postać gracza.

**Strona:** Serwer · **Czeka:** nie

```lua title="Lua"
local character = aiLib.online.character(src)
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'integer', description: 'Id serwerowe gracza.', required: true },
  }}
/>

#### Zwracana wartość

Tabela [CharacterInfo](/pl/docs/developers/api/types#characterinfo) (`id`, `citizenid`, `firstname`, `lastname`, `birthdate`, `sex`, `nationality`...) albo `nil`, gdy gracz nie ma wczytanej postaci.

#### Przykład

```lua title="server.lua"
aiLib.addCommand('whoami', { help = 'Shows your character id' }, function(source)
    local character = aiLib.online.character(source)
    if not character then return end
    aiLib.notify(source, ('Character #%d (%s)'):format(character.id, character.citizenid), 'info')
end)
```

### aiLib.online.name

"Imię Nazwisko" postaci, w przeciwnym razie nazwa gracza w FiveM.

**Strona:** Serwer · **Czeka:** nie

```lua title="Lua"
local name = aiLib.online.name(src, fallback)
```

**TypeScript:** `online.name(source, { fallback })` przyjmuje tabelę opcji zamiast wartości logicznej.

#### Parametry

<TypeTable
  type={{
    src: { type: 'integer', description: 'Id serwerowe gracza.', required: true },
    fallback: { type: 'boolean', description: '`false`: odpowiedz `""` zamiast nazwy z FiveM, gdy żadna postać nie jest wczytana.', default: 'true' },
  }}
/>

#### Zwracana wartość

`string`: imię i nazwisko postaci, w przeciwnym razie nazwa z FiveM (albo `""` przy `fallback = false` lub gdy gracza już nie ma).

#### Przykład

```lua title="server.lua"
print(('%s opened the shop'):format(aiLib.online.name(source)))
```

### aiLib.online.jobs

Każda praca gracza, na służbie czy nie.

**Strona:** Serwer · **Czeka:** nie

```lua title="Lua"
local jobs = aiLib.online.jobs(src)
```

**TypeScript:** `online.jobs(source)` zwraca tylko **nazwy** prac; Lua zwraca tabele członkostwa.

#### Parametry

<TypeTable
  type={{
    src: { type: 'integer', description: 'Id serwerowe gracza.', required: true },
  }}
/>

#### Zwracana wartość

Lista tabel [JobMembership](/pl/docs/developers/api/types#jobmembership) (`{ job = 'police', grade = 2 }`). Pusta lista, gdy gracz nie ma żadnej pracy albo postaci.

#### Przykład

```lua title="server.lua"
for _, membership in ipairs(aiLib.online.jobs(source)) do
    print(membership.job, membership.grade)
end
```

### aiLib.online.gangs

Każdy gang gracza.

**Strona:** Serwer · **Czeka:** nie

```lua title="Lua"
local gangs = aiLib.online.gangs(src)
```

**TypeScript:** `online.gangs(source)` zwraca tylko nazwy gangów.

#### Parametry

<TypeTable
  type={{
    src: { type: 'integer', description: 'Id serwerowe gracza.', required: true },
  }}
/>

#### Zwracana wartość

Lista tabel [GangMembership](/pl/docs/developers/api/types#gangmembership) (`{ gang = 'ballas', grade = 0 }`) albo pusta lista.

#### Przykład

```lua title="server.lua"
local inAGang = #aiLib.online.gangs(source) > 0
```

### aiLib.online.jobGrade

Stopień gracza w jednej pracy.

**Strona:** Serwer · **Czeka:** nie

```lua title="Lua"
local grade = aiLib.online.jobGrade(src, job)
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'integer', description: 'Id serwerowe gracza.', required: true },
    job: { type: 'string', description: 'Nazwa pracy (`"police"`).', required: true },
  }}
/>

#### Zwracana wartość

`integer` (0 = najniższy stopień) albo `nil`, gdy gracz nie ma tej pracy.

#### Przykład

```lua title="server.lua"
local grade = aiLib.online.jobGrade(source, 'police')
if not grade or grade < 2 then return aiLib.fail('NOT_ALLOWED') end
```

### aiLib.online.gangGrade

Stopień gracza w jednym gangu.

**Strona:** Serwer · **Czeka:** nie

```lua title="Lua"
local grade = aiLib.online.gangGrade(src, gang)
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'integer', description: 'Id serwerowe gracza.', required: true },
    gang: { type: 'string', description: 'Nazwa gangu (`"ballas"`).', required: true },
  }}
/>

#### Zwracana wartość

`integer` albo `nil`, gdy gracz nie należy do tego gangu.

#### Przykład

### aiLib.online.dutyJob

Praca, w której gracz jest na służbie.

**Strona:** Serwer · **Czeka:** nie

```lua title="Lua"
local job = aiLib.online.dutyJob(src)
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'integer', description: 'Id serwerowe gracza.', required: true },
  }}
/>

#### Zwracana wartość

Nazwa pracy albo `nil`, gdy jest poza służbą.

#### Przykład

```lua title="server.lua"
if aiLib.online.dutyJob(source) ~= 'police' then return aiLib.fail('NOT_ON_DUTY') end
```

### aiLib.online.sources

Id serwerowe każdego gracza z wczytaną postacią.

**Strona:** Serwer · **Czeka:** nie

```lua title="Lua"
local players = aiLib.online.sources()
```

#### Zwracana wartość

Lista id serwerowych (pusta, gdy nikt nie jest wczytany albo ai-core nie działa).

#### Przykład

```lua title="server.lua"
for _, src in ipairs(aiLib.online.sources()) do
    if aiLib.online.dutyJob(src) == 'police' then
        aiLib.notify(src, 'Robbery in progress', 'warning')
    end
end
```

<Callout type="warn">
Każde wywołanie to wywołanie eksportu ai-core. W pętli po wszystkich graczach odczytaj to, czego potrzebujesz, raz na gracza i nigdy nie uruchamiaj tego co klatkę. Dla "ilu jest na służbie" czytaj stan globalny `ai:duty:<job>` (`GlobalState['ai:duty:police']`).
</Callout>

## Serwer: uprawnienia

### aiLib.isAdmin

Czy gracz jest administratorem ai-core (ACE `ai.admin`) albo ma podane przez ciebie ACE.

**Strona:** Serwer · **Czeka:** nie

```lua title="Lua"
local allowed = aiLib.isAdmin(src, ace)
```

**TypeScript:** `isAdmin(ace?)` jest tam za to **strażnikiem** dla `onClientCallback` / `onClientEvent` (zobacz [Wejście z klienta](/pl/docs/developers/api/lib-server/client-input)). W Lua zabezpiecz callback jego opcją `ace` albo wywołaj `aiLib.isAdmin` sam.

#### Parametry

<TypeTable
  type={{
    src: { type: 'integer', description: 'Id serwerowe gracza. `0` (konsola serwera) nigdy nie jest tu administratorem.', required: true },
    ace: { type: 'string', description: 'ACE do sprawdzenia.', default: "'ai.admin'" },
  }}
/>

#### Zwracana wartość

`true`, gdy gracz ma to ACE, w przeciwnym razie `false`.

#### Przykład

```lua title="server.lua"
RegisterCommand('fixall', function(source)
    if not aiLib.isAdmin(source) then return end
    -- tu praca tylko dla administratora
end, false)
```

## Klient: tabela menu

### aiLib.menu

Okna dialogowe są w jednej tabeli. Nazwy najwyższego poziomu to te same funkcje, zostawione dla krótkich wywołań:

| W `aiLib.menu` | To samo co | Czeka | Odpowiada |
| --- | --- | --- | --- |
| `menu.show(request, listeners?)` | (tylko tutaj) | tak | `id` wybranej pozycji, `'__back'` dla powrotu z podmenu albo `nil` po zamknięciu. |
| `menu.input(request)` | `aiLib.input(request)` | tak | Tabela wartości według `name` pola albo `nil` po zamknięciu. |
| `menu.itemPicker(request)` | `aiLib.itemPicker(request)` | tak | Lista `{ name, count }` albo `nil`. Tylko narzędzia administratora. |
| `menu.skillCheck(difficulty, keys?)` | `aiLib.skillCheck(difficulty, keys?)` | tak | `true`, gdy trafiono każdy etap. |
| `menu.lockpick(options?)` | `aiLib.lockpick(options?)` | tak | `'opened'`, `'broken'` albo `'cancelled'`. |

Kształty żądań to [MenuRequest](/pl/docs/developers/api/types#menurequest), [InputRequest](/pl/docs/developers/api/types#inputrequest), [ItemPickerRequest](/pl/docs/developers/api/types#itempickerrequest) i [SkillDifficulty](/pl/docs/developers/api/types#skilldifficulty). Każda opcja i listener są opisane przy odpowiednikach TypeScript na stronie [Wspólne UI](/pl/docs/developers/api/lib-client/ui).

```lua title="client.lua"
RegisterCommand('fine', function()
    local values = aiLib.input({
        title = 'Write a fine',
        confirm = 'Send',
        fields = {
            { name = 'amount', label = 'Amount', type = 'number', min = 1, max = 10000 },
            { name = 'reason', label = 'Reason', type = 'text', maxLength = 80 },
        },
    })
    if values then aiLib.callAction('mypolice:fine', { values.amount, values.reason }, { fallback = 'FINE_FAILED' }) end
end, false)
```
