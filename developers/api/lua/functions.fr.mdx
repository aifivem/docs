Tous les membres d’`aiLib`, tirés du `init.lua` d’ai-lib. La plupart sont l’équivalent d’une fonction TypeScript et sont documentés sur la page de cette fonction, avec l’appel Lua dans le bloc de signature et un onglet d’exemple Lua. **Attend** signifie que l’appel se met en pause jusqu’à l’arrivée de la réponse : appelez-le dans un thread (voir [Fonctions qui attendent](/fr/docs/developers/api/lua#fonctions-qui-attendent)).

Les méthodes d’une classe (`points:add(...)`, `job:set(...)`) sont listées avec leur classe.
