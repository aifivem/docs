Typisiert als `AiCoreClientExports` in `@aicore-fivem/shared` (`exports.ts`).

```ts title="TypeScript"
import { resourceExport } from "@aicore-fivem/lib/client";
const core = resourceExport("ai-core");
```

Für die meisten gibt es einen einfacheren Lib-Helfer (in der letzten Spalte); Lua-Ressourcen haben dieselben Helfer auf `aiLib`.

## Spieler

| Export | Was | Lib |
| --- | --- | --- |
| `GetPlayerData(): AiPlayerData \| null` | Die Daten des lokalen Spielers: Charakter, Geld, Jobs, Dienst, Job, Gangs, aktive Gang, Metadaten. | `getPlayerData`, `onPlayerData` |
| `IsPlayerLoaded(): boolean` | Ob ein Charakter geladen ist. | |
| `IsDead(): boolean` | Der lokale Spieler ist am Boden, in welchem Todesskript auch immer. | `medical.isDead` |
| `GetDefinitions(file: "jobs" \| "gangs"): Record<string, unknown> \| null` | Job- oder Gang-Definitionen, wie die Panel-Datei sie hält. | |

```lua title="Lua"
local data = exports['ai-core']:GetPlayerData()
if data and data.duty == 'police' then
  -- on duty
end
```

## HUD

| Export | Was | Lib |
| --- | --- | --- |
| `HideHud(reason: string): void` | Blendet jedes HUD aus, solange ein Grund besteht (die Gründe einer gestoppten Ressource gehen mit ihr). | `hud.hide` |
| `ShowHud(reason: string): void` | Entfernt einen Grund. | `hud.show` |
| `IsHudVisible(): boolean` | Ob HUDs gerade sichtbar sind. | `hud.visible` |
| `OpenHudSettings(): boolean` | Öffnet die eigenen Einstellungen des laufenden HUDs; false ohne. | |
| `HasHudSettings(): boolean` | Ob das laufende HUD Einstellungen hat. | |

```ts title="TypeScript"
core.HideHud("photo-mode");
// ...
core.ShowHud("photo-mode");
```

```lua title="Lua"
exports['ai-core']:HideHud('photo-mode')
exports['ai-core']:ShowHud('photo-mode')
```

## Tastenbelegungen und Tastenhinweise

| Export | Was | Lib |
| --- | --- | --- |
| `GetKeybindKey(name: string): string \| null` | Die Taste, mit der ein Lib-`Keybind` registriert wurde; null bis zur Registrierung. | `Keybind.currentKey` |
| `ShowKeyHint(id: string, hint: KeyHintRequest): void` | Zeigt einen Tastenhinweis (`label`, `keybind?`, `key?`, `icon?`), bis er ausgeblendet wird. | `keyHints.show` |
| `HideKeyHint(id: string): void` | Blendet ihn aus. | `keyHints.hide` |
| `GetKeyHints(): KeyHintView[]` | Die Hinweise, die HUDs gerade zeigen (`id`, `key`, `label`, `icon?`). | |
| `OpenKeyboard(): void` | Öffnet den Tastenbildschirm: jede Taste mit einer Aktion. | |

```lua title="Lua"
exports['ai-core']:ShowKeyHint('noclip_speed', { label = 'Speed', key = 'SHIFT', icon = 'gauge' })
```

## Radialmenü

Einträge erreichen das laufende Radialmenü; ai-core entfernt sie, wenn die hinzufügende Ressource stoppt.

| Export | Was | Lib |
| --- | --- | --- |
| `AddRadialItem(item: RadialItem): void` | Fügt einen Eintrag hinzu oder ersetzt ihn (`id`, `label`, `icon?`, `parent?`, `items?`, `canShow?`, `onPressed?`, `keepOpen?`, `whileDead?`). | `radial.add` |
| `RemoveRadialItem(id: string): void` | Entfernt einen Eintrag. | `radial.remove` |
| `RefreshRadial(): void` | Liest jedes `canShow` eines offenen Rads erneut. | `radial.refresh` |

```lua title="Lua"
exports['ai-core']:AddRadialItem({
  id = 'myscript_engine', label = 'Engine', icon = 'power-off', parent = 'vehicle',
  canShow = function() return IsPedInAnyVehicle(PlayerPedId(), false) end,
  onPressed = function() ExecuteCommand('engine') end,
})
```

## Gesten

| Export | Was | Lib |
| --- | --- | --- |
| `GetGestureProvider(): string \| null` | Das Emote-Skript, das Hände hoch und Zeigen beantwortet. | `gestures.provider` |
| `IsHandsUp(): boolean` | Der lokale Spieler hat die Hände oben. | `gestures.isHandsUp` |
| `IsPointing(): boolean` | Der lokale Spieler zeigt. | `gestures.isPointing` |

## Aussehen

| Export | Was | Lib |
| --- | --- | --- |
| `ApplyAppearance(ped: number, look: CharacterAppearance): boolean` | Legt ein Aussehen aus `GetCharacterAppearance` über das aktive Kleidungsskript auf einen Ped desselben Modells. | `appearance.apply` |
| `GetPedAppearance(ped: number): CharacterAppearance \| null` | Das Aussehen, das ein Ped gerade trägt. | `appearance.read` |

Menüs, Eingabedialoge, Benachrichtigungen, Prompts, Fortschrittsbalken und Minispiele gehören zu ai-lib, nicht zu ai-core: siehe [Skript-Exports](/de/docs/developers/api/scripts#ai-lib).
