Всё, что может вызвать другой скрипт: экспорты ai-core, события, которые он отправляет, и вспомогательные функции `@aifivem/lib` (собственные экспорты каждого скрипта ai-* описаны на его странице в разделе «Скрипты»). Каждая сигнатура на этих страницах взята из исходников (`@aifivem/shared` `exports.ts`, JSDoc библиотеки, вызовы экспортов в каждом скрипте).

## Выберите правильный путь

| Вы пишете | Используйте |
| --- | --- |
| Скрипт ai-* или любой ресурс на TypeScript | `@aifivem/lib`: `inventory`, `vehicleKeys`, `online`, `medical`... Библиотека сама вызывает ai-core. |
| Ресурс на Lua | `aiLib` из ai-lib (`shared_script '@ai-lib/init.lua'`) или экспорты ai-core напрямую. |
| Скрипт для ESX / QB / Qbox / vRP | Ничего нового: мост отвечает на собственный API фреймворка. См. [Слои и мост](/ru/docs/developers/layers). |

Предметы, ключи от транспорта, оповещения, телефон, погода, тюрьма, одежда и смерти всегда идут через ai-core, а не через экспорты конкретного скрипта: ai-core передаёт вызов тому скрипту, который сервер использует для этой задачи.

## Вызов экспорта

```ts
import { resourceExport } from "@aifivem/lib/server";

// Один типизированный хэндл на ресурс, в начале файла.
const core = resourceExport("ai-core");

const cash = core.GetMoney(source, "cash");
```

```lua
local cash = exports['ai-core']:GetMoney(source, 'cash')
```

- Типы: `resourceExport` берёт их из `CitizenExports` в `@aifivem/shared`. Ресурс, который может быть не запущен, использует `optionalExport("x")` (null, пока он остановлен).
- Имена: каждый экспорт отвечает и с изменённым регистром первой буквы (`GetMoney` и `getMoney`).
- Экспорты синхронные и возвращают небольшие значения. Если значению нужно время (сохранённая внешность), экспорт принимает callback: promise не пересекает границу ресурса.
- Горячие пути следят за событиями ai-core, а не вызывают экспорты в цикле (так работает зеркало `online` в библиотеке).
