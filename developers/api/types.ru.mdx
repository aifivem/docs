Страницы API пишут типы по имени (`Vec3`, `ActionResult`, `InventoryRef`...). Эта страница объясняет каждый из них один раз: его поля, что означает каждое поле, и пример значения.

Откуда берётся тип:

| Пакет | Импорт | Типы |
| --- | --- | --- |
| `@aifivem/shared` | `import type { AiPlayerData } from "@aifivem/shared";` | Всё на этой странице, если заголовок не говорит иное. |
| `@aifivem/lib/shared` | `import type { Vec3 } from "@aifivem/lib/shared";` | `Vec3`, `Vec4`, `AccessRule`, `BlipStyle`, `ZoneShape`, `VehicleProps`, `VehicleSetup`, `PlacePed`. |
| `@aifivem/lib/client` | `import type { ProgressOptions } from "@aifivem/lib/client";` | `ProgressOptions`. |
| `@aifivem/lib/server` | `import type { ProgressForOptions } from "@aifivem/lib/server";` | `ProgressForOptions`. |

<Callout type="info">
В Lua нет типов во время выполнения. Таблица Lua с теми же ключами - это то же значение: `{ x = 1.0, y = 2.0, z = 3.0 }` - это `Vec3`. Массивы - это списки Lua (`{ 'police', 'sheriff' }`), `null` - это `nil`. О векторах см. [Библиотека для Lua](/ru/docs/developers/api/lua).
</Callout>

## Позиции

### Vec3

Точка в мире, в метрах. В GTA `x` - восток, `y` - север, `z` - вверх.

<TypeTable
  type={{
    x: { type: 'number', description: 'Позиция с запада на восток в метрах.', required: true },
    y: { type: 'number', description: 'Позиция с севера на юг в метрах.', required: true },
    z: { type: 'number', description: 'Высота в метрах.', required: true },
  }}
/>

```ts title="Пример"
const counter: Vec3 = { x: 25.7, y: -1347.3, z: 29.5 };
```

```lua title="Lua"
local counter = vector3(25.7, -1347.3, 29.5) -- или { x = 25.7, y = -1347.3, z = 29.5 }
```

### Vec4

Точка с направлением: где стоит пед или появляется транспорт и куда он обращён. Поля панели `vec4` и инструмент точки в панели хранят именно эту форму.

<TypeTable
  type={{
    x: { type: 'number', description: 'Позиция с запада на восток в метрах.', required: true },
    y: { type: 'number', description: 'Позиция с севера на юг в метрах.', required: true },
    z: { type: 'number', description: 'Высота в метрах.', required: true },
    heading: { type: 'number', description: "Направление в градусах, 0-360 (как в GTA: 0 = север, против часовой стрелки).", required: true },
  }}
/>

```ts title="Пример"
const spawn: Vec4 = { x: -42.1, y: -1098.4, z: 26.4, heading: 158.0 };
```

<Callout type="info">
В Lua `vector4` называет направление `w`. Функции чтения библиотеки ([readVec4](/ru/docs/developers/api/lib-shared/input#readvec4)) принимают и `heading`, и `w`.
</Callout>

### ZoneShape

Область в мире. Используется клиентскими `Zones` и серверными проверками областей ([геометрия зон](/ru/docs/developers/api/lib-shared/zones)). Это одна из трёх форм, выбираемая по `type`.

**Sphere** (шар вокруг точки):

<TypeTable
  type={{
    type: { type: '"sphere"', description: 'Выбирает эту форму.', required: true },
    center: { type: 'Vec3', description: 'Центр шара.', required: true, typeDescription: '{ x, y, z }' },
    radius: { type: 'number', description: 'Радиус в метрах.', required: true },
  }}
/>

**Cylinder** (круг на земле, уходящий вверх и вниз):

<TypeTable
  type={{
    type: { type: '"cylinder"', description: 'Выбирает эту форму.', required: true },
    center: { type: 'Vec3', description: 'Центр круга.', required: true },
    radius: { type: 'number', description: 'Радиус в плоскости земли, в метрах.', required: true },
    height: { type: 'number', description: 'Насколько зона уходит вверх и вниз от `center.z`, в метрах (общая высота вдвое больше).', required: true },
  }}
/>

**Poly** (многоугольник на земле между двумя высотами):

<TypeTable
  type={{
    type: { type: '"poly"', description: 'Выбирает эту форму.', required: true },
    points: { type: 'Array<{ x: number; y: number }>', description: 'Углы на земле по порядку вокруг области. Не менее 3.', required: true },
    minZ: { type: 'number', description: 'Наименьшая высота внутри зоны.', required: true },
    maxZ: { type: 'number', description: 'Наибольшая высота внутри зоны.', required: true },
  }}
/>

```ts title="Пример"
const yard: ZoneShape = { type: "sphere", center: { x: 440.1, y: -981.2, z: 30.7 }, radius: 25 };
const lot: ZoneShape = {
  type: "poly",
  points: [ { x: 210, y: -810 }, { x: 240, y: -800 }, { x: 230, y: -770 }, { x: 200, y: -780 } ],
  minZ: 28,
  maxZ: 36,
};
```

## Результаты

### ActionResult

Что каждое серверное действие отвечает клиенту: либо успех, либо языковой ключ, который клиент показывает как причину. В ветке успеха могут идти дополнительные поля (`ActionResult<{ id: number }>`). Само новое состояние никогда не передаётся в ответе: оно приходит дельтой.

**Успех:**

<TypeTable
  type={{
    ok: { type: 'true', description: 'Действие выполнено.', required: true },
    '...T': { type: 'T', description: 'Дополнительные поля `ActionResult<T>` (например, id новой записи).' },
  }}
/>

**Отказ:**

<TypeTable
  type={{
    ok: { type: 'false', description: 'Действие отклонено.', required: true },
    error: { type: 'string', description: 'Языковой ключ из `locales/*.json` ресурса (`"NOT_ENOUGH_MONEY"`). Клиент переводит и показывает его.', required: true },
  }}
/>

```ts title="Пример"
const done: ActionResult = { ok: true };
const created: ActionResult<{ id: number }> = { ok: true, id: 42 };
const refused: ActionResult = { ok: false, error: "NOT_ENOUGH_MONEY" };
```

```lua title="Lua"
return { ok = true }
return aiLib.fail('NOT_ENOUGH_MONEY') -- { ok = false, error = 'NOT_ENOUGH_MONEY' }
```

Собирайте отказы через [fail](/ru/docs/developers/api/lib-shared/input#fail); читайте ответы через [isActionOk](/ru/docs/developers/api/lib-shared/input#isactionok) и [replyError](/ru/docs/developers/api/lib-shared/input#replyerror).

## Деньги

### Имена счетов

Деньги лежат на именованных счетах. Какие существуют, задаёт список **Accounts** в панели; ai-core поставляется с такими:

| Имя | Подпись | Начальная сумма |
| --- | --- | --- |
| `cash` | Cash | 500 |
| `bank` | Bank | 5000 |
| `black_money` | Dirty money | 0 |
| `crypto` | Crypto | 0 |

Владелец сервера может добавлять, переименовывать или удалять счета в панели, поэтому читайте список экспортом `GetAccountTypes`, а не полагайтесь на него. Когда список пуст, ai-core оставляет единственный счёт `cash`.

```ts title="Пример"
core.AddMoney(source, "bank", 250, "Paycheck");
```

## Инвентарь

### InventoryRef

С каким инвентарём работает вызов.

| Значение | Означает |
| --- | --- |
| `number` | Серверный id игрока: собственный инвентарь этого игрока. |
| `string` | Любой другой инвентарь по его id: имя тайника, id багажника или бардачка. |

```ts title="Пример"
inventory.addItem(source, "water", 2);          // игрок
inventory.addItem("police_evidence", "phone", 1); // тайник
```

### ItemMetadata

Свободные данные, хранящиеся на одной стопке предметов (`Record<string, unknown>`): серийный номер, прочность, заметка. Каждый инвентарь сам показывает некоторые ключи (`label`, `description`, `image` в большинстве из них).

```ts title="Пример"
const metadata: ItemMetadata = { serial: "AB-1029", durability: 100 };
```

<Callout type="warn">
Держите метаданные небольшими и безопасными для JSON (строки, числа, boolean, простые объекты и массивы). Две стопки с разными метаданными никогда не складываются вместе.
</Callout>

### KeyPurpose

Почему игрок получает ключ от транспорта. Скрипты ключей обрабатывают каждый вариант по-своему. Всё неизвестное считается `"temporary"`.

| Значение | Используйте, когда |
| --- | --- |
| `"purchase"` | Игрок теперь владеет транспортом (автосалон, выдача админом): новый ключ, старые копии перестают работать. |
| `"garage"` | Личный транспорт выходит со стоянки: у владельца ключ уже есть. |
| `"job"` | Рабочий транспорт на смену. |
| `"rental"` | Арендованный транспорт на время аренды. |
| `"temporary"` | Всё остальное кратковременное (спавн админом, тест-драйв, транспорт для ограбления). По умолчанию. |

### LookupSource

Список значений, из которого выбирает поле панели. `lookup` на текстовом поле или поле имён заставляет сервер отклонять всё остальное, а панель предлагать этот список.

| --- | --- |

| `"gang"` | Банды из списка Gangs панели. |
| `"account"` | Денежные счета. |
| `"resource"` | Запущенные ресурсы. |
| `"player"` | Игроки в сети, по citizen id. |
| `"vehicle"` | Все модели транспорта, которые есть в игре админа, включая аддоны. Сервер никогда не отклоняет (он не может перечислить модели). |

## Мост vRP

### VrpConfig

Сопоставление прав vRP из панели (`data/vrp.json`) в том виде, в каком его читает мост vRP в ai-core (серверный экспорт `GetVrpConfig`; локальное событие `ai-core:vrp:config` несёт ту же форму после изменения).
