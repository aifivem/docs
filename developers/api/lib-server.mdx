The server entry also re-exports the `/fivem` helpers: see [Lib: shared and fivem](/docs/developers/api/lib-shared). The last column names the Lua twin on `aiLib` ([Lib for Lua](/docs/developers/api/lua)).

## Client input

Every client request goes through the gate: real player check, rate limit, guards, an argument parser, optionally one call at a time.

| Helper | What | Lua |
| --- | --- | --- |
| `onClientCallback(name, handler, options?)` / `onClientCallback(name, { args, guards?, rate?, lock? }, handler)` | Answers `triggerServerCallback`; `args` turns raw values into checked ones (null refuses). | `onClientCallback` (options `rate`, `lock`, `ace`) |
| `onClientEvent(name, handler, options?)` / `onClientEvent(name, { args, ... }, handler)` | A net event from a client, through the same gate. | `onClientEvent` |
| `triggerClientCallback(name, source, args = [], timeoutMs?): Promise<unknown>` | Asks a client (`onServerCallback` there). | `triggerClientCallback` |
| `isAdmin(ace?)`, `hasCharacter()`, `near(point \| (source) => point, metres)` | Guards for `guards: [...]`. | `isAdmin(source, ace?)` |
| `eventSource(): number` | The player who sent the event (read before the first `await`). | |
| `isOnline(source): boolean` | Whether the player is connected. | |
| `progressFor(source, { label, duration, anim?, scenario?, face?, allowVehicle?, canCancel?, freeze?, disable?, minRatio? }): Promise<boolean>` | A timed action the server checks: ai-lib's bar on the player's client, true only when it ran out there and enough time passed here. | `progressFor` (waits) |
| `minigameFor(source, { game, difficulty?, rounds?, keys?, pins?, picks?, minMs? }): Promise<"won" \| "lost" \| "broken">` | A skill check or lockpick a server flow needs; a win sooner than `minMs` counts as lost. | `minigameFor` (waits) |
| `new PendingActions({ minRatio? })`: `start(source, data, ms)`, `take(source, token)`, `peek`, `cancel` | Dialogs the server waits for: a token, freed on drop. | |

```ts title="TypeScript"
onClientCallback(
  "repair",
  { args: oneArg(readId), guards: [hasCharacter()], lock: true },
  async (source, netId) => {
    if (!inventory.hasItem(source, "repairkit")) return fail("NO_KIT");
    if (!(await progressFor(source, { label: t("REPAIRING"), duration: 8000 })))
      return fail("CANCELLED");
    inventory.removeItem(source, "repairkit");
    return { ok: true };
  },
);
```

```lua title="Lua"
aiLib.onClientCallback('repair', function(source, netId)
  if not aiLib.inventory.hasItem(source, 'repairkit') then return aiLib.fail('NO_KIT') end
  if not aiLib.progressFor(source, { label = 'Repairing', duration = 8000 }) then
    return aiLib.fail('CANCELLED')
  end
  aiLib.inventory.removeItem(source, 'repairkit', 1)
  return { ok = true }
end, { lock = true })
```

## Commands, panel, data

| Helper | What | Lua |
| --- | --- | --- |
| `addCommand(name \| [name, ...aliases], { help, params, restricted }, (source, args, raw) => ...)` | A command: parsed params, ACE checked, listed in the panel. | `addCommand` |
| `new AdminPanel(schema)`: `get`, `onChange`, `view`, `records`, `onAction`, `rule` | A script's panel store: schema, validation, save, deltas. | |
| `new DataFile(resource, name, log)` | Panel content in `data/*.json` with atomic writes. | |
| `createDatabaseTables(resource, file): Promise<void>` | Installs `sql/main.sql`. | |
| `new WriteQueue(onError)`: `push(label, task)`, `idle()` | Database writes one after another. | |
| `new AreaStream({ event, view, cellSize?, range?, chunk?, alsoTo?, extra? })` | World objects streamed to the players around them: a snapshot, then only changes. | |
| `EntityState`, `PlayerState`, `GlobalKey`, `GlobalGroup` (with `set`) | State bags; the server classes write. | |

```ts title="TypeScript"
addCommand(
  "heal",
  {
    help: t("CMD_HEAL"),
    params: [{ name: "id", type: "playerId", optional: true }],
    restricted: true,
  },
  (source, args) => medical.heal(args.id ?? source),
);
```
