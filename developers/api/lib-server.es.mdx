```ts title="TypeScript"
import { onClientCallback, inventory, online, fail } from "@aicore-fivem/lib/server";
```

La entrada de servidor también reexporta las utilidades de `/fivem`: ver [Lib: shared y fivem](/es/docs/developers/api/lib-shared). La última columna nombra la gemela en Lua de `aiLib` ([Lib para Lua](/es/docs/developers/api/lua)).

## Entrada del cliente

Cada petición del cliente pasa por la puerta: comprobación de jugador real, límite de frecuencia, guardas, un parser de argumentos y, si se pide, una llamada a la vez.

| Utilidad | Qué | Lua |
| --- | --- | --- |
| `onClientCallback(name, handler, options?)` / `onClientCallback(name, { args, guards?, rate?, lock? }, handler)` | Responde a `triggerServerCallback`; `args` convierte los valores crudos en valores comprobados (null rechaza). | `onClientCallback` (opciones `rate`, `lock`, `ace`) |
| `onClientEvent(name, handler, options?)` / `onClientEvent(name, { args, ... }, handler)` | Un evento de red de un cliente, por la misma puerta. | `onClientEvent` |
| `triggerClientCallback(name, source, args = [], timeoutMs?): Promise<unknown>` | Pregunta a un cliente (allí `onServerCallback`). | `triggerClientCallback` |
| `isAdmin(ace?)`, `hasCharacter()`, `near(point \| (source) => point, metres)` | Guardas para `guards: [...]`. | `isAdmin(source, ace?)` |
| `eventSource(): number` | El jugador que envió el evento (léelo antes del primer `await`). | |
| `isOnline(source): boolean` | Si el jugador está conectado. | |
| `progressFor(source, { label, duration, anim?, scenario?, face?, allowVehicle?, canCancel?, freeze?, disable?, minRatio? }): Promise<boolean>` | Una acción temporizada que comprueba el servidor: la barra de ai-lib en el cliente del jugador, true solo cuando terminó allí y pasó tiempo suficiente aquí. | `progressFor` (espera) |
| `minigameFor(source, { game, difficulty?, rounds?, keys?, pins?, picks?, minMs? }): Promise<"won" \| "lost" \| "broken">` | Una prueba de habilidad o cerradura que necesita un flujo del servidor; una victoria antes de `minMs` cuenta como derrota. | `minigameFor` (espera) |
| `new PendingActions({ minRatio? })`: `start(source, data, ms)`, `take(source, token)`, `peek`, `cancel` | Diálogos que espera el servidor: un token, liberado al desconectarse. | |

```ts title="TypeScript"
onClientCallback(
  "repair",
  { args: oneArg(readId), guards: [hasCharacter()], lock: true },
  async (source, netId) => {
    if (!inventory.hasItem(source, "repairkit")) return fail("NO_KIT");
    if (!(await progressFor(source, { label: t("REPAIRING"), duration: 8000 })))
      return fail("CANCELLED");
    inventory.removeItem(source, "repairkit");
    return { ok: true };
  },
);
```

```lua title="Lua"
aiLib.onClientCallback('repair', function(source, netId)
  if not aiLib.inventory.hasItem(source, 'repairkit') then return aiLib.fail('NO_KIT') end
  if not aiLib.progressFor(source, { label = 'Repairing', duration = 8000 }) then
    return aiLib.fail('CANCELLED')
  end
  aiLib.inventory.removeItem(source, 'repairkit', 1)
  return { ok = true }
end, { lock = true })
```

| `online.allows(source, rule: AccessRule): boolean` | Si el jugador puede usar un lugar. | |

| `coordsOf(source)`, `entityCoords(entity)`, `isNear(source, point, metres)` | Posiciones. | |

| `new Cooldowns()`, `new KeyedCooldowns()`: `ready`, `start`, `take(key, ms)`, `left`, `clear` | Tiempos de espera por jugador, o por cualquier clave (id de personaje, puerta). | |

| `new RateLimit(count, windowMs)`: `take(source)`, `release(source)` | Un límite de ráfagas por jugador. | `RateLimit.new(count, windowMs)` |
| `new KeyWatchers()`: `watch(source, key)`, `stop`, `of(key)`, `keyOf(source)` | Jugadores que reciben los deltas de una clave (una pantalla abierta). | |

## Comandos, panel, datos

| Utilidad | Qué | Lua |
| --- | --- | --- |
| `addCommand(name \| [name, ...aliases], { help, params, restricted }, (source, args, raw) => ...)` | Un comando: parámetros validados, comprobado con ACE, listado en el panel. | `addCommand` |
| `new AdminPanel(schema)`: `get`, `onChange`, `view`, `records`, `onAction`, `rule` | El almacén del panel de un script: esquema, validación, guardado, deltas. | |
| `new DataFile(resource, name, log)` | Contenido del panel en `data/*.json` con escrituras atómicas. | |
| `createDatabaseTables(resource, file): Promise<void>` | Instala `sql/main.sql`. | |
| `new WriteQueue(onError)`: `push(label, task)`, `idle()` | Escrituras en la base de datos una tras otra. | |
| `new AreaStream({ event, view, cellSize?, range?, chunk?, alsoTo?, extra? })` | Objetos del mundo transmitidos a los jugadores cercanos: una instantánea, luego solo los cambios. | |
| `EntityState`, `PlayerState`, `GlobalKey`, `GlobalGroup` (con `set`) | State bags; las clases del servidor escriben. | |

```ts title="TypeScript"
addCommand(
  "heal",
  {
    help: t("CMD_HEAL"),
    params: [{ name: "id", type: "playerId", optional: true }],
    restricted: true,
  },
  (source, args) => medical.heal(args.id ?? source),
);
```
