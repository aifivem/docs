API sayfaları tipleri adıyla yazar (`Vec3`, `ActionResult`, `InventoryRef`...). Bu sayfa her birini bir kez açıklar: alanlarını, her alanın ne anlama geldiğini ve örnek bir değeri.

Bir tipin nereden geldiği:

| Paket | Import | Tipler |
| --- | --- | --- |
| `@aifivem/shared` | `import type { AiPlayerData } from "@aifivem/shared";` | Başlık başka bir şey söylemedikçe bu sayfadaki her şey. |
| `@aifivem/lib/shared` | `import type { Vec3 } from "@aifivem/lib/shared";` | `Vec3`, `Vec4`, `AccessRule`, `BlipStyle`, `ZoneShape`, `VehicleProps`, `VehicleSetup`, `PlacePed`. |
| `@aifivem/lib/client` | `import type { ProgressOptions } from "@aifivem/lib/client";` | `ProgressOptions`. |
| `@aifivem/lib/server` | `import type { ProgressForOptions } from "@aifivem/lib/server";` | `ProgressForOptions`. |

<Callout type="info">
Lua’da çalışma anında tip yoktur. Aynı anahtarlara sahip bir Lua tablosu aynı değerdir: `{ x = 1.0, y = 2.0, z = 3.0 }` bir `Vec3`’tür. Diziler Lua listeleridir (`{ 'police', 'sheriff' }`), `null` ise `nil`’dir. Vektörler için bkz. [Lua için lib](/tr/docs/developers/api/lua).
</Callout>

## Konumlar

### Vec3

Dünyada bir nokta, metre cinsinden. GTA’da `x` doğu, `y` kuzey, `z` yukarıdır.

<TypeTable
  type={{
    x: { type: 'number', description: 'Doğu-batı konumu, metre.', required: true },
    y: { type: 'number', description: 'Kuzey-güney konumu, metre.', required: true },
    z: { type: 'number', description: 'Yükseklik, metre.', required: true },
  }}
/>

```ts title="Örnek"
const counter: Vec3 = { x: 25.7, y: -1347.3, z: 29.5 };
```

```lua title="Lua"
local counter = vector3(25.7, -1347.3, 29.5) -- ya da { x = 25.7, y = -1347.3, z = 29.5 }
```

### Vec4

Yönü olan bir nokta: bir ped’in durduğu ya da bir aracın doğduğu yer ve hangi yöne baktığı. Panelin `vec4` alanları ve panelin nokta aracı bu şekli kaydeder.

<TypeTable
  type={{
    x: { type: 'number', description: 'Doğu-batı konumu, metre.', required: true },
    y: { type: 'number', description: 'Kuzey-güney konumu, metre.', required: true },
    z: { type: 'number', description: 'Yükseklik, metre.', required: true },
    heading: { type: 'number', description: 'Derece cinsinden yön, 0-360 (GTA’nınki: 0 = kuzey, saat yönünün tersine).', required: true },
  }}
/>

```ts title="Örnek"
const spawn: Vec4 = { x: -42.1, y: -1098.4, z: 26.4, heading: 158.0 };
```

<Callout type="info">

</Callout>

**Cylinder** (yerde yukarı ve aşağı uzanan bir daire):

/>

**Poly** (iki yükseklik arasında yerde bir çokgen):

<TypeTable
  type={{

## Sonuçlar

### ActionResult

Her server aksiyonunun client’a verdiği cevap: ya başarı ya da client’ın sebep olarak gösterdiği bir dil anahtarı. Başarı dalında ek alanlar taşınabilir (`ActionResult<{ id: number }>`). Yeni durumun kendisi asla cevapta gitmez: delta olarak gelir.

**Başarı:**

<TypeTable
  type={{
    ok: { type: 'true', description: 'Aksiyon çalıştı.', required: true },
    '...T': { type: 'T', description: '`ActionResult<T>`’nin ek alanları (örneğin yeni kaydın id’si).' },
  }}
/>

**Ret:**

<TypeTable
  type={{
    ok: { type: 'false', description: 'Aksiyon reddedildi.', required: true },
    error: { type: 'string', description: 'Resource’un `locales/*.json` dosyasından bir dil anahtarı (`"NOT_ENOUGH_MONEY"`). Client onu çevirip gösterir.', required: true },
  }}
/>

```ts title="Örnek"
const done: ActionResult = { ok: true };
const created: ActionResult<{ id: number }> = { ok: true, id: 42 };
const refused: ActionResult = { ok: false, error: "NOT_ENOUGH_MONEY" };
```

```lua title="Lua"
return { ok = true }
return aiLib.fail('NOT_ENOUGH_MONEY') -- { ok = false, error = 'NOT_ENOUGH_MONEY' }
```

Retleri [fail](/tr/docs/developers/api/lib-shared/input#fail) ile kur; cevapları [isActionOk](/tr/docs/developers/api/lib-shared/input#isactionok) ve [replyError](/tr/docs/developers/api/lib-shared/input#replyerror) ile oku.

## Para

### Hesap isimleri

Para isimli hesaplarda durur. Hangilerinin var olduğunu panelin **Accounts** listesi belirler; ai-core bunlarla gelir:

| Ad | Etiket | Başlangıç miktarı |
| --- | --- | --- |
| `cash` | Cash | 500 |
| `bank` | Bank | 5000 |
| `black_money` | Dirty money | 0 |
| `crypto` | Crypto | 0 |

Sunucu sahibi panelde hesap ekleyebilir, yeniden adlandırabilir ya da silebilir; bu yüzden listeyi varsaymak yerine `GetAccountTypes` export’uyla oku. Liste boşken ai-core tek bir `cash` hesabı tutar.

```ts title="Örnek"
core.AddMoney(source, "bank", 250, "Paycheck");
```

## Envanter

### InventoryRef

Bir çağrının hangi envanter üzerinde çalıştığı.

| Değer | Anlamı |
| --- | --- |
| `number` | Bir oyuncunun server id’si: o oyuncunun kendi envanteri. |
| `string` | id’siyle başka herhangi bir envanter: bir stash adı, bagaj ya da torpido id’si. |

```ts title="Örnek"
inventory.addItem(source, "water", 2);          // bir oyuncu
inventory.addItem("police_evidence", "phone", 1); // bir stash
```

### ItemMetadata

Tek bir eşya yığınında saklanan serbest veri (`Record<string, unknown>`): seri numarası, dayanıklılık, bir not. Her envanter bazı anahtarları kendisi gösterir (çoğunda `label`, `description`, `image`).

```ts title="Örnek"
const metadata: ItemMetadata = { serial: "AB-1029", durability: 100 };
```

<Callout type="warn">
Metadata’yı küçük ve JSON uyumlu tut (string’ler, sayılar, boolean’lar, düz nesneler ve diziler). Farklı metadata’ya sahip iki yığın asla üst üste binmez.
</Callout>

### UsableItemHandler

`(source: number, item: UsedItem) => unknown`: bir oyuncu eşyayı kullandığında çalışır. `false` döndürmek, kullanılan eşyayı kendisi alan envanterlerde eşyayı yerinde tutar (ai-inventory eşyanın `consume` miktarını alır); diğer envanterler kendi eşya ayarlarına uyar.

```ts title="Örnek"
const onUse: UsableItemHandler = (source, item) => {
  if (item.metadata.durability === 0) return false; // yerinde tut
  return true;
};
```
