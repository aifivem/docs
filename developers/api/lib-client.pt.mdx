```ts title="TypeScript"
import { Points, notify, progress, cache } from "@aicore-fivem/lib/client";
```

A entrada de cliente também reexporta os helpers de `/fivem` (`every`, `ByResource`, `Reasons`, `caller`, `onStop`, `plateOf`, os helpers de exports e de idioma, as classes de state bags): veja [Lib: shared e fivem](/pt/docs/developers/api/lib-shared). A última coluna dá o gêmeo em Lua no `aiLib` ([Lib para Lua](/pt/docs/developers/api/lua)).

## Falando com o servidor

| Helper | O quê | Lua |
| --- | --- | --- |
| `triggerServerCallback(name, args = [], timeoutMs?): Promise<unknown>` | Pergunta ao servidor (`onClientCallback` lá); valide a resposta. | `triggerServerCallback` |
| `onServerCallback(name, handler: (...args) => unknown): void` | Responde ao `triggerClientCallback` do servidor. | `onServerCallback` |
| `onServerEvent(name, handler)` / `onServerEvent(name, { args }, handler)` | Um evento de rede do servidor; emits que não vieram do servidor são descartados. `args` valida os dados. | `onServerEvent` |
| `fromServer(): boolean` | Se o evento em tratamento veio do servidor. | |
| `callAction(name, args = [], { fallback, timeout?, silent? })` | Executa uma ação no servidor, mostra a recusa traduzida sozinho e resolve a resposta ok ou null. | `callAction` |
| `isActionOk(reply)`, `replyError(reply, fallback)` | Leem um `ActionResult` à mão. | |

```ts title="TypeScript"
const reply = await callAction("buy", [itemId], { fallback: "BUY_FAILED" });
if (reply) notify(t("BOUGHT"), "success");
```

| `player.freeze(state: boolean)` | Congela o ped. | `player.freeze` |
| `player.teleport(to: { x, y, z? }, { heading?, ground?, fade?, keepVehicle? }): Promise<void>` | Teleporte atrás de um fade com carregamento de colisão; sem `z` cai no chão. | `player.teleport` |
| `player.playAnim(dict, clip, options?): Promise<void>`, `player.stopAnim()` | Toca ou para uma animação. | `player.playAnim`, `player.stopAnim` |

| `playerPed(serverId): number` | O ped de um jogador pelo id de servidor, 0 fora do scope. | `playerPed` |
| `nearestPlayer(metres, { from?, filter? }): number \| null` | O id de servidor do outro jogador mais próximo. | `nearestPlayer` |

## Locais e o mundo

| Helper | O quê | Lua |
| --- | --- | --- |
| `new Points()` | Todo local que um jogador usa: prompt ou target (escolha do dono), NPC, blip. | `Points.new()` |
| `points.add(id, { coords, label, icon?, radius?, height?, canShow?, onPressed, onEnter?, onExit?, ped?, blip?, world?, promptOnly?, preferTarget? })` | Adiciona um ponto; `label` pode ser uma função. | `points:add` |
| `points.addModel(id, { models, label, icon?, radius?, canShow?(entity), onPressed(entity), vehicles?, inVehicle? })` | Um ponto em todo objeto de certos modelos (caixas eletrônicos, cadeiras). | `points:addModel` |
| `points.addVehicle(id, { label, icon?, radius?, canShow?(vehicle), onPressed(vehicle) })` | Um ponto em todo veículo em rede. | `points:addVehicle` |
| `points.remove(id)`, `clear()`, `refresh(id?)`, `isInside(id)` | Gerenciam os pontos; `refresh` lê `canShow` de novo. | |
| `new Zones()`: `add(id, options)`, `remove`, `clear`, `isInside`, `size` | Áreas sem interação. | `Zones.new()` |
| `new LocalPed({ model, coords, ... })`: `entity`, `remove` | Um ped que só este cliente vê, criado perto do jogador. | `LocalPed.new()` |
| `new Blips()`: `add(id, options)`, `get`, `remove`, `clear`; `createBlip(options)` | Blips com nome. | `Blips.new()`, `Blips.create()` |
| `showPrompt(id, text, at?)`, `hidePrompt(id)`, `onPromptPressed(handler)` | O prompt do ai-lib à mão (`Points` o usa). | `showPrompt`, `hidePrompt`, `onPromptPressed` |
| `new AdminWorld(files)`: `get`, `onChange`, `view`, `records` | A cópia no cliente dos arquivos de painel `sync: "all"` de um script. | |

```ts title="TypeScript"
const points = new Points();
points.add("shop", {
  coords: { x: 25.7, y: -1347.3, z: 29.5 },
  label: t("OPEN_SHOP"),
  icon: "basket-shopping",
  blip: { sprite: 52, color: 2, scale: 0.8, label: t("SHOP") },
  onPressed: () => openShop(),
});
```

| `lockpick({ difficulty?, pins?, picks? }): Promise<"opened" \| "broken" \| "cancelled">` | Minigame de lockpick. | `lockpick` |
| `new NuiScreen(name, { cursor?, onClose?, closeCallback? })`: `open`, `close`, `send`, `on`, `isOpen` | Uma NUI de tela cheia: foco, HUDs escondidos, mensagem de fechamento, callbacks. | |
| `hud.hide(reason)`, `hud.show(reason)`, `hud.visible()`, `hud.onChange(fn)` | Escondem os HUDs em volta de uma interface de tela cheia. | `hud` |

| `radial.add(item)`, `radial.remove(id)`, `radial.refresh()` | Itens no menu radial que estiver rodando. | `radial` |
| `controls.disable(reason, controls, group?)`, `controls.enable(reason)`, `controls.disableAll(reason, except?)` | Controles desativados, uma única tarefa por frame. | `controls` |
| `new Keybind({ name, description, defaultKey, defaultMapper, hint?, icon?, hintLabel?, onPressed, onReleased })` | Uma tecla reconfigurável; o painel pode definir o padrão. `isPressed()`, `currentKey()`, `disable(state)`. | `Keybind.new()` |

```ts title="TypeScript"
const done = await progress({
  label: t("REPAIRING"),
  duration: 8000,
  anim: { dict: "mini@repair", clip: "fixing_a_player" },
  canCancel: true,
});
```
