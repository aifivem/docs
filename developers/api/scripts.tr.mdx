ai-* script’leri ortak bir iş için birbirini çağırmaz: eşyalar, anahtarlar, ihbarlar, hapis, sağlık, görünümler, radyal öğeler ve hava ai-core (lib) üzerinden gider; aşağıdaki export’ları ai-core çağırır. Bunları sadece o script’e özgü bir şey için kendin çağır. `@aicore-fivem/shared` içinde tipli olanlar `resourceExport("ai-...")` ile, diğerleri `callExport(resource, name, ...args)` ya da düz bir `exports[...]` çağrısıyla çalışır.

Bir script başka bir script’in yerini tutuyorsa (`provide`), o script’in export adları da cevap verir; `exports.ox_inventory:AddItem(...)` ai-inventory’ye ulaşır.

## ai-lib

Ortak oyuncu arayüzü. Client export’ları, `AiLibClientExports` olarak tipli; lib’in `notify`, `progress`, `showPrompt`, `menu`, `input`, `skillCheck` ve `lockpick`’i senin yerine çağırır.

| Export | Ne |
| --- | --- |
| `Notify(notification: Notification): void` | Bir bildirim kartı (`text`, `title?`, `kind`, `duration?`). |
| `ShowProgress(label: string, duration: number): void` | İlerleme çubuğunu `duration` ms gösterir (eylemi çağıran yürütür). |
| `HideProgress(): void` | Gizler. |
| `ShowPrompt(id: string, text: string, at?: { x, y, z }): void` | Çağıranın istemini gösterir ya da günceller; `at` onu bir dünya noktasının üstüne çizer. |
| `HidePrompt(id: string): void` | Bir istemi gizler. |
| `OpenMenu(requestId: number, request: MenuRequest): void` | Bir menü; seçim `MENU_EVENTS.menuResult` olarak gelir. |
| `OpenInput(requestId: number, request: InputRequest): void` | Bir giriş diyaloğu; değerler `MENU_EVENTS.inputResult` olarak gelir. |
| `OpenMinigame(requestId: number, request: MinigameRequest): void` | Beceri kontrolü ya da maymuncuk; sonuç `MENU_EVENTS.menuResult` olarak gelir. |
| `CloseDialog(): void` | Çağıranın açık menüsünü ya da giriş diyaloğunu kapatır (null ile cevaplanır). |

Bir `Notification` ile sunucu olayı `ai-lib:client:notify` (`LIB_UI.notifyEvent`) o oyuncunun ekranında bir kart gösterir.

## ai-inventory

Sunucu export’ları (kendi): diğer ai-* script’leri bunlara ai-core’un envanter katmanı üzerinden ulaşır.

| Export | Ne |
| --- | --- |
| `AddItem(inv: number \| string, item: string, count: number, metadata?, slot?): boolean` | Eşya ekler. |
| `RemoveItem(inv: number \| string, item: string, count: number, metadata?, slot?): boolean` | Eşya alır. |
| `GetItemCount(inv: number \| string, item: string, metadata?): number` | Kaç tane. |
| `GetItems(inv: number \| string): { name, label, count, slot, metadata }[]` | Etiketiyle her yığın. |
| `CanCarryItem(inv: number \| string, item: string, count: number, metadata?): boolean` | Sığar mı. |
| `RegisterUsableItem(name: string, handler: (source, item) => unknown): void` | `handler` false dönerse eşya kalır; yoksa `consume` miktarı alınır. |
| `RegisterStash(name: string, label: string, slots: number, maxWeight: number, jobs?: string[], personal?: boolean): void` | Bir depo. |
| `OpenInventory(source: number, inv: number \| string): boolean` | Bir envanteri oyuncunun ekranında açar. |
| `ClearInventory(inv: number \| string): void` | Boşaltır. |
| `Items(name?: string): unknown` | Bir eşya tanımı (ox biçimi) ya da hepsi. |
| `GetWeight(inv: number \| string): { weight, maxWeight } \| null` | Taşınan ağırlık ve sınır, gram. |

Client export’ları: `OpenInventory(type, data)`, `CloseInventory()`, `OpenSelf()` (yer, bagaj ya da torpido gözüyle kendi envanteri), `GetItemCount(item)`, `HasItem(items: string \| string[] \| Record<string, number>, amount?)`, `GetPlayerItems()`.

Sunucu yerel olayı `ai-inventory:usedItem (source, name, slot, metadata, status)`.

### ox_inventory API’si

ai-inventory `ox_inventory`’yi `provide` eder ve export’larını cevaplar (ox_inventory 2.44). Envanterler ox’taki gibi adlandırılır: bir oyuncu source’u, bir depo adı, kişisel depolar için `{ id, owner }`, bagajlar için bir plaka.

- Sunucu: `AddItem` (`success, response` döner, `cb` çağırır), `RemoveItem`, `GetItem`, `GetItemCount`, `Search` (`count` / `slots`), `CanCarryItem`, `CanCarryWeight`, `CanCarryAmount`, `GetInventory`, `GetInventoryItems`, `GetSlot`, `GetSlotWithItem`, `GetSlotsWithItem`, `GetSlotIdWithItem`, `GetSlotIdsWithItem`, `GetEmptySlot`, `SetMetadata`, `SetDurability`, `SetMaxWeight`, `RegisterStash`, `ClearInventory`, `Items`, `ItemList`, `forceOpenInventory` (depo, oyuncu, mağaza), `CreateTemporaryStash`, `CustomDrop`, `RemoveInventory`, `SwapSlots`.
- Client: `openInventory`, `closeInventory`, `Search`, `GetItemCount`, `GetPlayerItems`, `GetPlayerWeight`, `GetPlayerMaxWeight`, `Items`, `useSlot`, `getCurrentWeapon` / `GetCurrentWeapon`; `displayMetadata`, `weaponWheel`, `setStashTarget` kabul edilir ve bir şey yapmaz.
- Cevaplanmayanlar: hook’lar (`registerHook`, `removeHooks`), `UpdateVehicle`, `ConfiscateInventory` / `ReturnInventory`, `GetContainerFromSlot`, `RegisterShop` (mağazalar panelden gelir).

### qb-inventory API’si

ai-inventory `qb-inventory`’yi `provide` eder (2.0 API). Dönen eşyalar iki biçimi de taşır: `count` / `metadata` ve `amount` / `info`.

- Sunucu: `AddItem(identifier, item, amount, slot, info)`, `RemoveItem`, `HasItem` (ad, liste ya da `{ name = amount }`), `GetItemCount`, `GetItemByName`, `GetItemsByName`, `GetItemBySlot`, `CanAddItem`, `GetFreeWeight`, `GetSlots`, `ClearInventory`, `SetItemData`, `CreateInventory`, `OpenInventory`, `OpenInventoryById`, `RemoveInventory`, `CloseInventory`.
- Client: `HasItem`, `CloseInventory`.
- Cevaplanmayanlar: hook’lar ve dinleyiciler, `CreateShop` / `OpenShop`, `SetInventory`, `GetInventory`, `SaveInventory`, `LoadInventory`, `UseItem`, `GetFirstSlotByItem`, `GetSlotsByItem`, `GetTotalWeight`.
