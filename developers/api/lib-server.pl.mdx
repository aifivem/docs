## Wejście z klienta

Każde żądanie klienta przechodzi przez bramkę: sprawdzenie prawdziwego gracza, limit częstotliwości, warunki, parser argumentów, opcjonalnie jedno wywołanie naraz.

| Funkcja | Co | Lua |
| --- | --- | --- |
| `onClientCallback(name, handler, options?)` / `onClientCallback(name, { args, guards?, rate?, lock? }, handler)` | Odpowiada na `triggerServerCallback`; `args` zamienia surowe wartości w sprawdzone (null odmawia). | `onClientCallback` (opcje `rate`, `lock`, `ace`) |
| `onClientEvent(name, handler, options?)` / `onClientEvent(name, { args, ... }, handler)` | Zdarzenie sieciowe od klienta przez tę samą bramkę. | `onClientEvent` |
| `triggerClientCallback(name, source, args = [], timeoutMs?): Promise<unknown>` | Pyta klienta (tam `onServerCallback`). | `triggerClientCallback` |
| `isAdmin(ace?)`, `hasCharacter()`, `near(point \| (source) => point, metres)` | Warunki dla `guards: [...]`. | `isAdmin(source, ace?)` |
| `eventSource(): number` | Gracz, który wysłał zdarzenie (czytaj przed pierwszym `await`). | |
| `isOnline(source): boolean` | Czy gracz jest połączony. | |
| `progressFor(source, { label, duration, anim?, scenario?, face?, allowVehicle?, canCancel?, freeze?, disable?, minRatio? }): Promise<boolean>` | Akcja z czasem sprawdzana przez serwer: pasek ai-lib na kliencie gracza, true tylko gdy tam dobiegł końca, a tutaj minęło dość czasu. | `progressFor` (czeka) |
| `minigameFor(source, { game, difficulty?, rounds?, keys?, pins?, picks?, minMs? }): Promise<"won" \| "lost" \| "broken">` | Test umiejętności lub wytrych potrzebny w przebiegu serwera; wygrana szybsza niż `minMs` liczy się jako przegrana. | `minigameFor` (czeka) |
| `new PendingActions({ minRatio? })`: `start(source, data, ms)`, `take(source, token)`, `peek`, `cancel` | Okna dialogowe, na które czeka serwer: token, zwalniany po wyjściu gracza. | |

```ts title="TypeScript"
onClientCallback(
  "repair",
  { args: oneArg(readId), guards: [hasCharacter()], lock: true },
  async (source, netId) => {
    if (!inventory.hasItem(source, "repairkit")) return fail("NO_KIT");
    if (!(await progressFor(source, { label: t("REPAIRING"), duration: 8000 })))
      return fail("CANCELLED");
    inventory.removeItem(source, "repairkit");
    return { ok: true };
  },
);
```

```lua title="Lua"
aiLib.onClientCallback('repair', function(source, netId)
  if not aiLib.inventory.hasItem(source, 'repairkit') then return aiLib.fail('NO_KIT') end
  if not aiLib.progressFor(source, { label = 'Repairing', duration = 8000 }) then
    return aiLib.fail('CANCELLED')
  end
  aiLib.inventory.removeItem(source, 'repairkit', 1)
  return { ok = true }
end, { lock = true })
```
