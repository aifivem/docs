Sunucu girişi `/fivem` yardımcılarını da yeniden dışa aktarır: bkz. [Lib: shared ve fivem](/tr/docs/developers/api/lib-shared). Son sütun `aiLib` üzerindeki Lua karşılığını verir ([Lua için lib](/tr/docs/developers/api/lua)).

## Client girdisi

Her client isteği kapıdan geçer: gerçek oyuncu kontrolü, hız sınırı, koruyucular, bir argüman ayrıştırıcı, isteğe bağlı olarak aynı anda tek çağrı.

| Yardımcı | Ne | Lua |
| --- | --- | --- |
| `onClientCallback(name, handler, options?)` / `onClientCallback(name, { args, guards?, rate?, lock? }, handler)` | `triggerServerCallback`’i cevaplar; `args` ham değerleri kontrol edilmiş değerlere çevirir (null reddeder). | `onClientCallback` (seçenekler `rate`, `lock`, `ace`) |
| `onClientEvent(name, handler, options?)` / `onClientEvent(name, { args, ... }, handler)` | Bir client’tan net olayı, aynı kapıdan. | `onClientEvent` |
| `triggerClientCallback(name, source, args = [], timeoutMs?): Promise<unknown>` | Bir client’a sorar (orada `onServerCallback`). | `triggerClientCallback` |
| `isAdmin(ace?)`, `hasCharacter()`, `near(point \| (source) => point, metres)` | `guards: [...]` için koruyucular. | `isAdmin(source, ace?)` |
| `eventSource(): number` | Olayı gönderen oyuncu (ilk `await`’ten önce oku). | |
| `isOnline(source): boolean` | Oyuncu bağlı mı. | |
| `progressFor(source, { label, duration, anim?, scenario?, face?, allowVehicle?, canCancel?, freeze?, disable?, minRatio? }): Promise<boolean>` | Sunucunun kontrol ettiği süreli eylem: oyuncunun client’ında ai-lib’in çubuğu; sadece orada bittiğinde ve burada yeterli süre geçtiğinde true. | `progressFor` (bekler) |
| `minigameFor(source, { game, difficulty?, rounds?, keys?, pins?, picks?, minMs? }): Promise<"won" \| "lost" \| "broken">` | Sunucu akışının istediği beceri kontrolü ya da maymuncuk; `minMs`’ten erken bir kazanç kayıp sayılır. | `minigameFor` (bekler) |
| `new PendingActions({ minRatio? })`: `start(source, data, ms)`, `take(source, token)`, `peek`, `cancel` | Sunucunun beklediği diyaloglar: bir token, oyuncu çıkınca temizlenir. | |

```ts title="TypeScript"
onClientCallback(
  "repair",
  { args: oneArg(readId), guards: [hasCharacter()], lock: true },
  async (source, netId) => {
    if (!inventory.hasItem(source, "repairkit")) return fail("NO_KIT");
    if (!(await progressFor(source, { label: t("REPAIRING"), duration: 8000 })))
      return fail("CANCELLED");
    inventory.removeItem(source, "repairkit");
    return { ok: true };
  },
);
```

```lua title="Lua"
aiLib.onClientCallback('repair', function(source, netId)
  if not aiLib.inventory.hasItem(source, 'repairkit') then return aiLib.fail('NO_KIT') end
  if not aiLib.progressFor(source, { label = 'Repairing', duration = 8000 }) then
    return aiLib.fail('CANCELLED')
  end
  aiLib.inventory.removeItem(source, 'repairkit', 1)
  return { ok = true }
end, { lock = true })
```

## Komutlar, panel, veri

| Yardımcı | Ne | Lua |
| --- | --- | --- |
| `addCommand(name \| [name, ...aliases], { help, params, restricted }, (source, args, raw) => ...)` | Bir komut: ayrıştırılmış parametreler, ACE kontrolü, panelde listelenir. | `addCommand` |
| `new AdminPanel(schema)`: `get`, `onChange`, `view`, `records`, `onAction`, `rule` | Bir script’in panel deposu: şema, doğrulama, kayıt, değişiklikler. | |
| `new DataFile(resource, name, log)` | `data/*.json` içindeki panel içeriği, atomik yazmalarla. | |
| `createDatabaseTables(resource, file): Promise<void>` | `sql/main.sql`’i kurar. | |
| `new WriteQueue(onError)`: `push(label, task)`, `idle()` | Veritabanı yazmaları sırayla. | |
| `new AreaStream({ event, view, cellSize?, range?, chunk?, alsoTo?, extra? })` | Dünyadaki nesneler çevredeki oyunculara akar: bir anlık görüntü, sonra sadece değişenler. | |
| `EntityState`, `PlayerState`, `GlobalKey`, `GlobalGroup` (`set` ile) | State bag’ler; sunucu sınıfları yazar. | |

```ts title="TypeScript"
addCommand(
  "heal",
  {
    help: t("CMD_HEAL"),
    params: [{ name: "id", type: "playerId", optional: true }],
    restricted: true,
  },
  (source, args) => medical.heal(args.id ?? source),
);
```
