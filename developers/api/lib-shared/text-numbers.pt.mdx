Pequenos helpers para o que os jogadores leem (dinheiro, pesos, textos traduzidos), sorteios aleatórios e contagens regressivas que seguem o relógio do servidor.

```ts title="TypeScript"
import { formatText, round, groupDigits, formatWeight, stripGameText, randomInt, pickRandom, rollChance, ServerClock } from "@aifivem/lib/shared";
```

## Texto

### formatText

Preenche os placeholders `{0}`, `{1}`... de um texto com valores por posição. Uma tradução pode mover ou repetir um placeholder (`"{1} paid {0}"`), por isso os valores vão por número, não por ordem.

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
formatText(template: string, args: ReadonlyArray<string | number>): string
```

```lua title="Lua"
local text = aiLib.formatText(template, ...) -- valores como argumentos separados
```

#### Parâmetros

<TypeTable
  type={{
    template: { type: 'string', description: 'Texto com placeholders `{0}`, `{1}`...', required: true },
    args: { type: 'ReadonlyArray<string | number>', description: 'TypeScript: os valores em um array, `{0}` é `args[0]`. Lua: os valores como argumentos separados depois de `template`.', required: true },
  }}
/>

#### Retorno

`string`: o texto com todo placeholder que tem valor preenchido. Um placeholder sem valor fica como está (`{2}`).

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { formatText } from "@aifivem/lib/shared";

formatText("You paid ${0} for {1} items", [250, 3]); // "You paid $250 for 3 items"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.formatText('You paid ${0} for {1} items', 250, 3) -- "You paid $250 for 3 items"
```
</Tab>
</Tabs>

<Callout type="info">
Você raramente o chama: os helpers de idioma (`createLocale`, `aiLib.locale`, `LangTexts`) já preenchem os placeholders. Veja [Idioma](/pt/docs/developers/api/lib-shared/locale).
</Callout>

### stripGameText

Deixa simples um texto vindo de outro script: remove tags HTML, códigos de cor e de entrada do GTA (`~r~`, `~INPUT_PICKUP~`) e `&nbsp;`, junta sequências de espaços e corta as pontas. Use antes de mostrar o texto de outro script na sua própria UI.

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
stripGameText(text: unknown): string
```

```lua title="Lua"
local plain = aiLib.stripGameText(text)
```

#### Parâmetros

<TypeTable
  type={{
    text: { type: 'unknown', description: 'Qualquer valor. O que não é string é convertido em texto primeiro.', required: true },
  }}
/>

#### Retorno

`string`: o texto simples. `""` para `null` / `undefined` (Lua: `nil`).

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { stripGameText } from "@aifivem/lib/shared";

stripGameText("Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~"); // "Press to open the shop"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.stripGameText('Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~') -- "Press to open the shop"
```
</Tab>
</Tabs>

## Números

### round

Arredonda um número para uma quantidade de casas decimais.

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
round(value: number, decimals?: number): number
```

```lua title="Lua"
local rounded = aiLib.numbers.round(value, decimals)
```

#### Parâmetros

<TypeTable
  type={{
    value: { type: 'number', description: 'O número a arredondar.', required: true },
    decimals: { type: 'number', description: 'Casas decimais a manter.', default: '0' },
  }}
/>

#### Retorno

`number`: o valor arredondado.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { round } from "@aifivem/lib/shared";

round(12.345, 1); // 12.3
round(12.5);      // 13
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.round(12.345, 1) -- 12.3
aiLib.numbers.round(12.5)      -- 13
```
</Tab>
</Tabs>

### groupDigits

Escreve um número com um separador a cada três dígitos: `1234567` vira `1,234,567`. Mantém o sinal e os decimais. Use para todo valor em dinheiro que os jogadores veem.

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
groupDigits(value: number | string, separator?: string): string
```

```lua title="Lua"
local text = aiLib.numbers.groupDigits(value, separator)
```

#### Parâmetros

<TypeTable
  type={{
    value: { type: 'number | string', description: 'O número, ou um número já escrito como texto.', required: true },
    separator: { type: 'string', description: 'Texto colocado entre os grupos (`"."` ou `" "` para outros idiomas).', default: '","' },
  }}
/>

#### Retorno

`string`: o número agrupado.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groupDigits } from "@aifivem/lib/shared";

groupDigits(1234567);        // "1,234,567"
groupDigits(-9876.5);        // "-9,876.5"
groupDigits(1500000, ".");   // "1.500.000"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.groupDigits(1234567)      -- "1,234,567"
aiLib.numbers.groupDigits(1500000, '.') -- "1.500.000"
```
</Tab>
</Tabs>

### formatWeight

Escreve um peso em gramas do jeito que os jogadores leem: abaixo de 1 kg em gramas, a partir de 1 kg em quilos com uma casa decimal (quilos inteiros a partir de 100 kg), dígitos agrupados.

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
formatWeight(grams: number): string
```

**Lua:** sem equivalente.

#### Parâmetros

<TypeTable
  type={{
    grams: { type: 'number', description: 'Peso em gramas.', required: true },
  }}
/>

#### Retorno

`string`: `"750 g"`, `"1.5 kg"`, `"1,250 kg"`.

#### Exemplo

```ts
import { formatWeight } from "@aifivem/lib/shared";

formatWeight(750);      // "750 g"
formatWeight(1500);     // "1.5 kg"
formatWeight(1250000);  // "1,250 kg"
```

## Aleatório

### randomInt

Um número inteiro aleatório de `min` a `max`, os dois incluídos.

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
randomInt(min: number, max: number): number
```

**Lua:** sem equivalente; use `math.random(min, max)`.

#### Parâmetros

<TypeTable
  type={{
    min: { type: 'number', description: 'Menor resultado possível (um número inteiro).', required: true },
    max: { type: 'number', description: 'Maior resultado possível (um número inteiro).', required: true },
  }}
/>

#### Retorno

`number`: um número inteiro entre `min` e `max`.

#### Exemplo

```ts
import { randomInt } from "@aifivem/lib/shared";

const payout = randomInt(150, 300); // 150, 151, ... ou 300
```

### pickRandom

Um item aleatório de uma lista.

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
pickRandom<T>(list: readonly T[]): T | undefined
```

**Lua:** sem equivalente; use `list[math.random(#list)]`.

#### Parâmetros

<TypeTable
  type={{
    list: { type: 'readonly T[]', description: 'Os itens entre os quais escolher.', required: true },
  }}
/>

#### Retorno

Um item, ou `undefined` quando a lista está vazia.

#### Exemplo

```ts
import { pickRandom } from "@aifivem/lib/shared";

const loot = pickRandom(["goldbar", "rolex", "diamond"]) ?? "goldbar";
```

### rollChance

`true` com uma chance de `percent` em 100.

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
rollChance(percent: number): boolean
```

**Lua:** sem equivalente; use `math.random() * 100 < percent`.

#### Parâmetros

<TypeTable
  type={{
    percent: { type: 'number', description: 'Chance de 0 (nunca) a 100 (sempre).', required: true },
  }}
/>

#### Retorno

`true` cerca de `percent` vezes em 100.

#### Exemplo

```ts title="resource/server/index.ts"
import { inventory } from "@aifivem/lib/server";
import { rollChance } from "@aifivem/lib/shared";

function useLockpick(source: number, slot: number): void {
  if (rollChance(25)) inventory.removeItem(source, "lockpick", 1, undefined, slot); // quebra 1 em cada 4 vezes
}
```

<Callout type="warn">
Faça o sorteio no servidor para qualquer coisa que dá itens ou dinheiro. Um sorteio no cliente pode ser forçado por um trapaceiro.
</Callout>

## Tempo

### ServerClock

O relógio do servidor em um cliente, para contagens regressivas que não dependem do relógio do próprio cliente. É exportado de `@aifivem/lib/shared` e não tem equivalente em Lua. A referência completa (`sync`, `now`, `toLocal`, exemplo de contagem regressiva) está em [Câmera e tempo: ServerClock](/pt/docs/developers/api/lib-client/camera-and-timing#new-serverclock).
