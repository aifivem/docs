Małe funkcje pomocnicze do tego, co czytają gracze (pieniądze, wagi, przetłumaczone teksty), losowania i odliczania zgodnego z zegarem serwera.

```ts title="TypeScript"
import { formatText, round, groupDigits, formatWeight, stripGameText, randomInt, pickRandom, rollChance, ServerClock } from "@aifivem/lib/shared";
```

## Tekst

### formatText

Wypełnia w tekście miejsca `{0}`, `{1}`... wartościami według pozycji. Tłumaczenie może przesunąć albo powtórzyć miejsce (`"{1} paid {0}"`), dlatego wartości idą według numeru, a nie według kolejności.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
formatText(template: string, args: ReadonlyArray<string | number>): string
```

```lua title="Lua"
local text = aiLib.formatText(template, ...) -- wartości jako osobne argumenty
```

#### Parametry

<TypeTable
  type={{
    template: { type: 'string', description: 'Tekst z miejscami `{0}`, `{1}`...', required: true },
    args: { type: 'ReadonlyArray<string | number>', description: 'TypeScript: wartości w jednej tablicy, `{0}` to `args[0]`. Lua: wartości jako osobne argumenty po `template`.', required: true },
  }}
/>

#### Zwracana wartość

`string`: tekst z wypełnionym każdym miejscem, które ma wartość. Miejsce bez wartości zostaje bez zmian (`{2}`).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { formatText } from "@aifivem/lib/shared";

formatText("You paid ${0} for {1} items", [250, 3]); // "You paid $250 for 3 items"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.formatText('You paid ${0} for {1} items', 250, 3) -- "You paid $250 for 3 items"
```
</Tab>
</Tabs>

<Callout type="info">
Rzadko wywołujesz ją sam: funkcje tłumaczeń (`createLocale`, `aiLib.locale`, `LangTexts`) już wypełniają miejsca. Zobacz [Tłumaczenia](/pl/docs/developers/api/lib-shared/locale).
</Callout>

### stripGameText

Zamienia tekst z innego skryptu w zwykły tekst: usuwa tagi HTML, kody kolorów i klawiszy GTA (`~r~`, `~INPUT_PICKUP~`) oraz `&nbsp;`, zwija ciągi spacji i przycina. Używaj jej, zanim pokażesz tekst innego skryptu we własnym UI.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
stripGameText(text: unknown): string
```

```lua title="Lua"
local plain = aiLib.stripGameText(text)
```

#### Parametry

<TypeTable
  type={{
    text: { type: 'unknown', description: 'Dowolna wartość. Wartości niebędące stringami są najpierw zamieniane w tekst.', required: true },
  }}
/>

#### Zwracana wartość

`string`: zwykły tekst. `""` dla `null` / `undefined` (Lua: `nil`).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { stripGameText } from "@aifivem/lib/shared";

stripGameText("Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~"); // "Press to open the shop"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.stripGameText('Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~') -- "Press to open the shop"
```
</Tab>
</Tabs>

## Liczby

### round

Zaokrągla liczbę do podanej liczby miejsc po przecinku.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
round(value: number, decimals?: number): number
```

```lua title="Lua"
local rounded = aiLib.numbers.round(value, decimals)
```

#### Parametry

<TypeTable
  type={{
    value: { type: 'number', description: 'Liczba do zaokrąglenia.', required: true },
    decimals: { type: 'number', description: 'Ile miejsc po przecinku zachować.', default: '0' },
  }}
/>

#### Zwracana wartość

`number`: zaokrąglona wartość.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { round } from "@aifivem/lib/shared";

round(12.345, 1); // 12.3
round(12.5);      // 13
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.round(12.345, 1) -- 12.3
aiLib.numbers.round(12.5)      -- 13
```
</Tab>
</Tabs>

### groupDigits

Zapisuje liczbę z separatorem co trzy cyfry: `1234567` staje się `1,234,567`. Zachowuje znak i część dziesiętną. Używaj jej dla każdej kwoty pieniędzy, którą widzą gracze.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
groupDigits(value: number | string, separator?: string): string
```

```lua title="Lua"
local text = aiLib.numbers.groupDigits(value, separator)
```

#### Parametry

<TypeTable
  type={{
    value: { type: 'number | string', description: 'Liczba albo liczba już zapisana jako tekst.', required: true },
    separator: { type: 'string', description: 'Tekst wstawiany między grupy (`"."` albo `" "` dla innych języków).', default: '","' },
  }}
/>

#### Zwracana wartość

`string`: liczba z pogrupowanymi cyframi.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groupDigits } from "@aifivem/lib/shared";

groupDigits(1234567);        // "1,234,567"
groupDigits(-9876.5);        // "-9,876.5"
groupDigits(1500000, ".");   // "1.500.000"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.groupDigits(1234567)      -- "1,234,567"
aiLib.numbers.groupDigits(1500000, '.') -- "1.500.000"
```
</Tab>
</Tabs>

### formatWeight

Zapisuje wagę w gramach tak, jak czytają ją gracze: poniżej 1 kg w gramach, od 1 kg w kilogramach z jednym miejscem po przecinku (pełne kilogramy od 100 kg), cyfry pogrupowane.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
formatWeight(grams: number): string
```

**Lua:** brak odpowiednika.

#### Parametry

<TypeTable
  type={{
    grams: { type: 'number', description: 'Waga w gramach.', required: true },
  }}
/>

#### Zwracana wartość

`string`: `"750 g"`, `"1.5 kg"`, `"1,250 kg"`.

#### Przykład

```ts
import { formatWeight } from "@aifivem/lib/shared";

formatWeight(750);      // "750 g"
formatWeight(1500);     // "1.5 kg"
formatWeight(1250000);  // "1,250 kg"
```

## Losowanie

### randomInt

Losowa liczba całkowita od `min` do `max`, obie włącznie.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
randomInt(min: number, max: number): number
```

**Lua:** brak odpowiednika; użyj `math.random(min, max)`.

#### Parametry

<TypeTable
  type={{
    min: { type: 'number', description: 'Najniższy możliwy wynik (liczba całkowita).', required: true },
    max: { type: 'number', description: 'Najwyższy możliwy wynik (liczba całkowita).', required: true },
  }}
/>

#### Zwracana wartość

`number`: liczba całkowita od `min` do `max`.

#### Przykład

```ts
import { randomInt } from "@aifivem/lib/shared";

const payout = randomInt(150, 300); // 150, 151, ... albo 300
```

### pickRandom

Jeden losowy element listy.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
pickRandom<T>(list: readonly T[]): T | undefined
```

**Lua:** brak odpowiednika; użyj `list[math.random(#list)]`.

#### Parametry

<TypeTable
  type={{
    list: { type: 'readonly T[]', description: 'Elementy do wyboru.', required: true },
  }}
/>

#### Zwracana wartość

Jeden element albo `undefined`, gdy lista jest pusta.

#### Przykład

```ts
import { pickRandom } from "@aifivem/lib/shared";

const loot = pickRandom(["goldbar", "rolex", "diamond"]) ?? "goldbar";
```

### rollChance

`true` z szansą `percent` na 100.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
rollChance(percent: number): boolean
```

**Lua:** brak odpowiednika; użyj `math.random() * 100 < percent`.

#### Parametry

<TypeTable
  type={{
    percent: { type: 'number', description: 'Szansa od 0 (nigdy) do 100 (zawsze).', required: true },
  }}
/>

#### Zwracana wartość

`true` mniej więcej `percent` razy na 100.

#### Przykład

```ts title="resource/server/index.ts"
import { inventory } from "@aifivem/lib/server";
import { rollChance } from "@aifivem/lib/shared";

function useLockpick(source: number, slot: number): void {
  if (rollChance(25)) inventory.removeItem(source, "lockpick", 1, undefined, slot); // psuje się 1 raz na 4
}
```

<Callout type="warn">
Losuj na serwerze wszystko, co daje przedmioty albo pieniądze. Losowanie na kliencie może wymusić oszust.
</Callout>

## Czas

### ServerClock

Zegar serwera na kliencie, do odliczań, które nie zależą od własnego zegara klienta. Jest eksportowany z `@aifivem/lib/shared` i nie ma odpowiednika w Lua. Jego pełny opis (`sync`, `now`, `toLocal`, przykład odliczania) jest na stronie [Kamera i czas: ServerClock](/pl/docs/developers/api/lib-client/camera-and-timing#new-serverclock).
