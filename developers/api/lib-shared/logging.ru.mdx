Эти помощники пишут в **консоль** (F8 на клиенте, консоль сервера или txAdmin на сервере). Для логов, которые владелец сервера читает в Discord, Fivemanage или FiveM Stats, используйте `aiLog` (см. [Логи](/ru/docs/developers/api/lib-server/logs)).

```ts title="TypeScript"
import { createLogger, logSafe, previewJson } from "@aicore-fivem/lib/shared";
```

### createLogger

Возвращает логгер, строки которого начинаются с `[your-resource]`, поэтому в консоли сервера видно, откуда пришла каждая строка. Предупреждения жёлтые, ошибки красные.

**Сторона:** Клиент, сервер и NUI · **Ждёт:** нет

```ts title="Сигнатура"
createLogger(resource: string): Logger
```

**Lua:** аналога нет; используйте `print(('[%s] %s'):format(GetCurrentResourceName(), message))`.

#### Параметры

<TypeTable
  type={{
    resource: { type: 'string', description: 'Имя перед каждой строкой, обычно `GetCurrentResourceName()`.', required: true },
  }}
/>

#### Возвращает

`Logger`:

<TypeTable
  type={{
    'info(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'Обычная строка (`console.log`).' },
    'warn(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'Жёлтая строка (`console.warn`).' },
    'error(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'Красная строка (`console.error`). Передайте ошибку как деталь, чтобы вывести её стек.' },
  }}
/>

#### Пример

```ts title="resource/server/index.ts"
import { createLogger } from "@aicore-fivem/lib/shared";

const log = createLogger(GetCurrentResourceName());

log.info("loaded 12 shops");               // [my-shop] загружено 12 магазинов
log.warn("shop legion has no ped model");  // жёлтая
try {
  JSON.parse("{");
} catch (error) {
  log.error("could not read shops.json", error); // красная, с ошибкой
}
```

### logSafe

Делает текст, отправленный клиентом, безопасным для консоли сервера: одна строка (переносы становятся ` | `), без управляющих символов, без цветовых кодов `^1`, урезано до `max` символов. Используйте всегда, когда строка лога содержит текст игрока (имя, сообщение, заметку).

**Сторона:** Клиент, сервер и NUI · **Ждёт:** нет

```ts title="Сигнатура"
logSafe(text: string, max: number): string
```

**Lua:** аналога нет.

#### Параметры

<TypeTable
  type={{
    text: { type: 'string', description: 'Недоверенный текст.', required: true },
    max: { type: 'number', description: 'Сколько символов максимум сохраняется.', required: true },
  }}
/>

#### Возвращает

`string`: очищенный текст.

#### Пример

```ts
import { logSafe } from "@aicore-fivem/lib/shared";

logSafe("^1fake error\nsecond line", 100); // "fake error | second line"
```

<Callout type="warn">
Без этого игрок может написать в чат сообщение с цветовыми кодами `^1` и переносами строк, которое в вашей консоли выглядит как настоящая ошибка сервера.
</Callout>

### previewJson

Короткий JSON-подобный текст любого недоверенного значения, урезанный до `max` символов и построенный **без** предварительной сериализации всего значения (враждебные данные могут весить мегабайты). Вложенность глубже 4 уровней показывается как `[...]` / `{...}`. Используйте, чтобы вывести то, что прислал клиент, когда вы ему отказываете.

**Сторона:** Клиент, сервер и NUI · **Ждёт:** нет

```ts title="Сигнатура"
previewJson(value: unknown, max: number): string
```

**Lua:** аналога нет.

#### Параметры

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Что угодно: сырые аргументы отклонённого вызова.', required: true },
    max: { type: 'number', description: 'Сколько символов максимум в результате.', required: true },
  }}
/>

#### Возвращает

`string`: предпросмотр, не более `max` символов. Ключи объектов урезаются до 50 символов.

#### Пример

```ts title="resource/server/index.ts"
import { onClientEvent } from "@aicore-fivem/lib/server";
import { createLogger, logSafe, previewJson } from "@aicore-fivem/lib/shared";

const log = createLogger(GetCurrentResourceName());

onClientEvent("my-shop:rate", (source) => {
  log.info(`${logSafe(GetPlayerName(String(source)) ?? "?", 32)} opened the rating`);
});

function refuse(source: number, raw: unknown[]): void {
  log.warn(`refused input from ${source}: ${previewJson(raw, 200)}`);
}
```
