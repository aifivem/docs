## Periodic work

### every

Runs a function every `ms` milliseconds (`0` = every frame) from your resource's single scheduler. Use it instead of `setInterval`, `setTick` or a `CreateThread` loop with `Wait`: all jobs of a resource share one tick, and that tick exists only while at least one job is switched on, so an idle resource costs nothing in resmon.

**Side:** Client and server · **Waits:** no

```ts title="Signature"
every(ms: number, fn: () => unknown, options?: EveryOptions): Job
```

```lua title="Lua"
local job = aiLib.every(ms, fn, options) -- job:set(active), job:stop(), job.running
```

#### Parameters

<TypeTable
  type={{
    ms: { type: 'number', description: 'Interval in milliseconds. `0` runs it every frame. Fractions are rounded down, negatives count as 0.', required: true },
    fn: { type: '() => unknown', description: 'The work. It may return a promise; a throw or a rejected promise is logged and the job keeps running.', required: true },
    options: { type: 'EveryOptions', description: 'Fields below.' },
  }}
/>

#### EveryOptions

<TypeTable
  type={{
    active: { type: 'boolean', description: '`false` creates the job switched off. Switch it on later with `job.set(true)`.', default: 'true' },
    name: { type: 'string', description: 'Name in the error log.', default: "the function’s name (TS), 'anonymous' (Lua)" },
  }}
/>

#### Returns

`Job`: a handle to switch the job on and off.

<TypeTable
  type={{
    running: { type: 'boolean (read only)', description: '`true` while the job is switched on.' },
    'set(active)': { type: '(active: boolean) => void', description: 'Switches the job on or off. Switched on, the first run comes one interval later (next frame for 0). Lua: `job:set(true)`.' },
    'stop()': { type: '() => void', description: 'Switches the job off for good: `set(true)` does nothing afterwards. Lua: `job:stop()`.' },
  }}
/>

#### Example

A per-frame job that runs only while it has something to do:

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { every, cache, onCache } from "@aifivem/lib/client";

// Hides the crosshair every frame, but only while a weapon is in hand.
const hideCrosshair = every(0, () => HideHudComponentThisFrame(14), {
  active: cache.weapon !== false,
  name: "hide crosshair",
});

onCache("weapon", (weapon) => hideCrosshair.set(weapon !== false));
```
</Tab>
<Tab value="Lua">
```lua
-- Hides the crosshair every frame, but only while a weapon is in hand.
local hideCrosshair = aiLib.every(0, function()
    HideHudComponentThisFrame(14)
end, { active = aiLib.cache.weapon ~= false, name = 'hide crosshair' })

aiLib.cache.onChange('weapon', function(weapon)
    hideCrosshair:set(weapon ~= false)
end)
```
</Tab>
</Tabs>

<Callout type="warn">
A job must never wait: no `Wait` in Lua, no long `await` chain that you expect to finish before the next run in TypeScript. In Lua a `Wait` inside a job holds every other job of the resource; start a thread from the job for that. A failing job is logged at most once every 10 seconds (the errors in between are counted into the next line).
</Callout>

## Waiting

### sleep

Waits `ms` milliseconds.

**Side:** Client, server and NUI · **Waits:** yes (Promise)

```ts title="Signature"
sleep(ms: number): Promise<void>
```

**Lua:** no twin; use `Wait(ms)` inside a thread.

#### Parameters

<TypeTable
  type={{
    ms: { type: 'number', description: 'Milliseconds to wait.', required: true },
  }}
/>

#### Returns

`Promise<void>` that resolves after `ms` milliseconds.

#### Example

```ts
import { sleep } from "@aifivem/lib/shared";
import { fadeOut, fadeIn } from "@aifivem/lib/client";

async function blink(): Promise<void> {
  await fadeOut(300);
  await sleep(1000);
  await fadeIn(300);
}
```

### waitFor

Checks a condition until it gives a value, then returns that value. Use it to wait for something the game does on its own time: an entity to exist, a model to load, a value to arrive.

**Side:** Client, server and NUI · **Waits:** yes (Promise in TypeScript, yields the thread in Lua)

```ts title="Signature"
waitFor<T>(check: () => T | undefined, timeoutMs?: number | false, intervalMs?: number): Promise<T>
```

```lua title="Lua"
local value = aiLib.waitFor(check, timeout, interval) -- value, or nil after the timeout; call inside a thread
```

#### Parameters

<TypeTable
  type={{
    check: { type: '() => T | undefined', description: 'Runs on every check. Return the value you wait for, or `undefined` (Lua: `nil`) to keep waiting. To wait for a true condition, return `cond || undefined` (Lua: `cond or nil`).', required: true },
    timeoutMs: { type: 'number | false', description: 'Give up after this many milliseconds. `false` waits forever.', default: '10000' },
    intervalMs: { type: 'number', description: 'Milliseconds between checks. `0` checks every tick.', default: '0' },
  }}
/>

#### Returns

TypeScript: `Promise<T>` that resolves with the first value `check` returned that was not `undefined`. It **rejects** with `Error("waitFor timed out after <ms> ms")` after the timeout.

Lua: the value, or `nil` after the timeout (it does not throw).

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { waitFor } from "@aifivem/lib/shared";

async function vehicleFromNet(netId: number): Promise<number | null> {
  try {
    return await waitFor(() => {
      const vehicle = NetworkGetEntityFromNetworkId(netId);
      return DoesEntityExist(vehicle) ? vehicle : undefined;
    }, 5000);
  } catch {
    return null; // not streamed in within 5 seconds
  }
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local vehicle = aiLib.waitFor(function()
        local entity = NetworkGetEntityFromNetworkId(netId)
        return DoesEntityExist(entity) and entity or nil
    end, 5000)
    if not vehicle then return end -- not streamed in within 5 seconds
    SetVehicleEngineOn(vehicle, true, true, false)
end)
```
</Tab>
</Tabs>

<Callout type="warn">
In TypeScript, always handle the rejection (`try` / `catch` or `.catch()`), or pass `false` as the timeout. In Lua, `waitFor` only works inside a thread.
</Callout>

## Resource lifecycle

### onStop

Runs a function when your resource stops (on the side the code runs on). Use it to delete what natives created and nothing else removes: entities you spawned, cameras, a NUI focus.

**Side:** Client and server · **Waits:** no

```ts title="Signature"
onStop(fn: () => void): void
```

**Lua:** no twin; use `AddEventHandler('onResourceStop', function(name) if name == GetCurrentResourceName() then ... end end)`.

#### Parameters

<TypeTable
  type={{
    fn: { type: '() => void', description: 'Runs once, when this resource stops.', required: true },
  }}
/>

#### Returns

`void`.

#### Example

```ts title="resource/server/index.ts"
import { onStop } from "@aifivem/lib/server";

const spawned = new Set<number>();

onStop(() => {
  for (const entity of spawned) if (DoesEntityExist(entity)) DeleteEntity(entity);
});
```

<Callout type="info">
All `onStop`, `ByResource` and `Reasons` of a resource share one stop listener, so adding many costs nothing extra.
</Callout>

### caller

The name of the resource that called the export now running. Inside your own code (not in an export call) it is your resource's name.

**Side:** Client and server · **Waits:** no

```ts title="Signature"
caller(): string
```

**Lua:** no twin; use `GetInvokingResource() or GetCurrentResourceName()`.

#### Returns

`string`: the calling resource's name, or this resource's name when no other resource is calling.

#### Example

```ts title="resource/server/index.ts"
import { registerExport, caller } from "@aifivem/lib/server";

registerExport("Ping", () => {
  console.log(`${caller()} asked for a ping`);
  return true;
});
```

### ByResource

A map whose entries belong to the resource that set them. When that resource stops, its entries are removed at once (and `onDrop` runs for each). Use it for things other resources register through your exports: hooks, prompts, items, menu entries.

**Side:** Client and server · **Waits:** no

```ts title="Signature"
new ByResource<K, V>(options?: { onDrop?: (resource: string, key: K, value: V) => void })
```

**Lua:** no twin.

#### Parameters

<TypeTable
  type={{
    'options.onDrop': { type: '(resource: string, key: K, value: V) => void', description: 'Runs for each entry removed because its resource stopped (not for `delete`).' },
  }}
/>

#### Methods

<TypeTable
  type={{
    'set(key, value, owner?)': { type: '(key: K, value: V, owner?: string) => void', description: 'Stores the entry under `owner` (default: `caller()`, the resource calling your export). Setting a key another resource owns moves it to the new owner.' },
    'get(key)': { type: '(key: K) => V | undefined', description: 'The entry, `undefined` when there is none.' },
    'ownerOf(key)': { type: '(key: K) => string | undefined', description: 'The resource that owns the entry.' },
    'delete(key)': { type: '(key: K) => boolean', description: 'Removes the entry. `false` when there was none.' },
    'values()': { type: '() => Generator<V>', description: 'Every value.' },
    'entries()': { type: '() => Generator<[K, V]>', description: 'Every key and value.' },
    size: { type: 'number (read only)', description: 'Number of entries.' },
    'dropResource(resource)': { type: '(resource: string) => void', description: 'Removes every entry of a resource now (`onDrop` per entry). Called for you when a resource stops.' },
  }}
/>

#### Example

```ts title="resource/server/index.ts"
import { ByResource, registerExport } from "@aifivem/lib/server";
import { readText } from "@aifivem/lib/shared";

type Hook = (source: number, text: string) => boolean;
const hooks = new ByResource<string, Hook>({
  onDrop: (resource, id) => console.log(`${resource} stopped: hook ${id} removed`),
});

// Another resource: exports["my-chat"].AddHook("swear-filter", (source, text) => ...)
registerExport("AddHook", (id: unknown, hook: unknown) => {
  const name = readText(id, 64);
  if (name === null || typeof hook !== "function") return false;
  hooks.set(name, hook as Hook); // owner = the resource calling AddHook
  return true;
});

export function allowed(source: number, text: string): boolean {
  for (const hook of hooks.values()) if (!hook(source, text)) return false;
  return true;
}
```

### Reasons

A switch that is on while at least one reason is set. Each resource sets its own named reasons, and a stopping resource's reasons are cleared. Use it for "hide the HUD", "pause the sync", "block the menu": several scripts can ask at once, and the state only flips back when the last one lets go.

**Side:** Client and server · **Waits:** no

```ts title="Signature"
new Reasons()
```

**Lua:** no twin.

#### Methods

<TypeTable
  type={{
    any: { type: 'boolean (read only)', description: '`true` while at least one reason of any resource is set.' },
    'set(reason, on, owner?)': { type: '(reason: string, on: boolean, owner?: string) => void', description: 'Sets (`on = true`) or clears a reason of `owner` (default: `caller()`).' },
    'has(reason, owner?)': { type: '(reason: string, owner?: string) => boolean', description: 'Whether that reason of `owner` (default: `caller()`) is set.' },
    'onChange(handler)': { type: '(handler: (any: boolean) => void) => void', description: 'Runs when `any` flips (from off to on, or on to off). Not on every `set`.' },
  }}
/>

#### Example

```ts title="resource/client/index.ts"
import { Reasons, registerExport } from "@aifivem/lib/client";
import { readText } from "@aifivem/lib/shared";

const hidden = new Reasons();
hidden.onChange((any) => SendNUIMessage({ action: "visible", value: !any }));

// Other resources: exports["my-hud"].Hide("cutscene") and exports["my-hud"].Show("cutscene")
registerExport("Hide", (reason: unknown) => {
  const name = readText(reason, 64);
  if (name !== null) hidden.set(name, true);
});
registerExport("Show", (reason: unknown) => {
  const name = readText(reason, 64);
  if (name !== null) hidden.set(name, false);
});
```
