State bag, FiveM’in server’dan ona ihtiyaç duyan client’lara kopyaladığı bir değerdir: bir aracın yakıtı (`Entity(vehicle).state.fuel`), bir oyuncunun yerde olup olmadığı (`Player(id).state.dead`), server genelinde bir bayrak (`GlobalState["ai:pvp"]`).

Bir bag’i doğrudan okumak yavaştır: her okuma proxy’ler kurar, birkaç native çağırır ve değeri yeniden çözer. Bu sınıflar **anahtar başına tek bir değişiklik handler’ı** ve her değerin bir kopyasını bellekte tutar; bu yüzden bir okuma bir map aramasıdır. Birden fazla okuduğun her bag için bunları kullan.

```ts title="Client dosyası: salt okunur sürümler (get, onChange)"
import { EntityState, PlayerState, GlobalKey, GlobalGroup, stateNumber, stateBoolean, stateString } from "@aicore-fivem/lib/client";
```

```ts title="Server dosyası: aynı sınıflar artı set(...)"
import { EntityState, PlayerState, GlobalKey, GlobalGroup, stateNumber, stateBoolean, stateString } from "@aicore-fivem/lib/server";
```

Sınıflar `@aicore-fivem/lib/fivem` üzerinde değildir: onları client ya da server girişinden import et. State bag’leri yalnızca server yazar (`sv_stateBagStrictMode`); bir client server’a bir callback ile sorar ve değeri server ayarlar. Server’ın `set` metotları [Lib: server, State bag’ler](/tr/docs/developers/api/lib-server/state-bags) sayfasındadır.

**Lua:** bunların hiçbirinin Lua karşılığı yok. Lua bag’leri kendisi okur (`Entity(vehicle).state.fuel`, `Player(id).state.dead`, `GlobalState['ai:pvp']`) ve `AddStateBagChangeHandler` ile dinler.

ai-core’un ve `ai-*` script’lerinin kullandığı anahtarlar [Olaylar ve durum](/tr/docs/developers/api/events) sayfasında listelenir.

## Ayrıştırıcılar

Her sınıf bir ayrıştırıcı (parser) alır: ham replike değeri senin tipine çeviren ya da geçerli bir değer değilse `undefined` döndüren bir fonksiyon. Tipi `StateParse<T> = (value: unknown) => T | undefined`’dir. Temizlenmiş bir bag (`null`) her zaman `undefined` olarak okunur; ayrıştırıcı onu hiç görmez.

### stateNumber

Sonlu bir sayıyı kabul eder; başka her şey (metin, `NaN`, `Infinity`) `undefined` olarak okunur.

**Taraf:** Client ve server · **Bekler:** hayır

```ts title="Signature"
stateNumber: StateParse<number>
```

#### Örnek

```ts
import { EntityState, stateNumber } from "@aicore-fivem/lib/client";

const fuel = new EntityState("fuel", stateNumber); // 0-100, yakıt script’i tarafından ayarlanır
```

### stateBoolean

`true` ya da `false`’u kabul eder; başka her şey `undefined` olarak okunur.

**Taraf:** Client ve server · **Bekler:** hayır

```ts title="Signature"
stateBoolean: StateParse<boolean>
```

#### Örnek

```ts
import { PlayerState, stateBoolean } from "@aicore-fivem/lib/client";

const dead = new PlayerState("dead", stateBoolean); // yerdeyken true (ai-death)
```

### stateString

Bir string’i kabul eder; başka her şey `undefined` olarak okunur.

**Taraf:** Client ve server · **Bekler:** hayır

```ts title="Signature"
stateString: StateParse<string>
```

#### Örnek

```ts
import { GlobalKey, stateString } from "@aicore-fivem/lib/client";

const inventoryScript = new GlobalKey("ai:inventory", stateString); // aktif envanterin resource adı
```

<Callout type="info">
Bir nesne değeri için, her alanı kontrol eden ve hatalı bir değer için `undefined` döndüren kendi ayrıştırıcını yaz:

```ts
import { PlayerState, type StateParse } from "@aicore-fivem/lib/client";

type Proximity = { index: number; distance: number; mode: string };
const proximity: StateParse<Proximity> = (v) => {
  if (typeof v !== "object" || v === null) return undefined;
  const { index, distance, mode } = v as Record<string, unknown>;
  return typeof index === "number" && typeof distance === "number" && typeof mode === "string"
    ? { index, distance, mode }
    : undefined;
};
const voiceRange = new PlayerState("proximity", proximity); // pma-voice’un menzili, ai-voice tarafından yazılır
```
</Callout>

## Sınıflar

### EntityState

Ağa bağlı her entity için entity state bag’lerinin tek bir anahtarı (`fuel`, `ai:owned`...). Değerler network id’ye göre tutulur; bir okuma entity handle’ını alır.

**Taraf:** Client ve server · **Bekler:** hayır

```ts title="Signature"
new EntityState<T>(key: string, parse: StateParse<T>)
```

#### Parametreler

<TypeTable
  type={{
    key: { type: 'string', description: 'Bag anahtarı (`"fuel"`).', required: true },
    parse: { type: 'StateParse<T>', description: 'Ham değeri `T`’ye çevirir ya da hatalı bir değer için `undefined`. Yukarıdaki Ayrıştırıcılar’a bak.', required: true },
  }}
/>

#### Metotlar

<TypeTable
  type={{
    'get(entity)': { type: '(entity: number) => T | undefined', description: 'Bir entity handle’ı üzerindeki değer. Değeri yoksa, ağa bağlı değilse ya da `entity` 0 ise `undefined`.' },
    'getByNetId(netId)': { type: '(netId: number) => T | undefined', description: 'Bu tarafın bildiği kadarıyla network id’ye göre değer (bag okuması yok).' },
    'onChange(listener)': { type: '(listener: (netId: number, value: T | undefined, old: T | undefined) => void) => () => void', description: 'Bir değer değiştikten sonra çalışır; yeni değer zaten okunabilir. Dinleyiciyi kaldıran bir fonksiyon döndürür.' },
    key: { type: 'string (read only)', description: 'Bag anahtarı.' },
  }}
/>

#### Örnek

```ts title="resource/client/index.ts"
import { EntityState, stateNumber, cache, every } from "@aicore-fivem/lib/client";

const fuel = new EntityState("fuel", stateNumber);

every(1000, () => {
  if (cache.vehicle === false) return;
  SendNUIMessage({ action: "fuel", value: fuel.get(cache.vehicle) ?? 100 });
});
```

<Callout type="info">
Bellek kendiliğinden küçük kalır: server bir entity’yi silindiğinde unutur ve bir client 30 saniyede bir menzilinden çıkan entity’leri atar. Yeni bir entity tarafından yeniden kullanılan bir network id tekrar okunur.
</Callout>

### PlayerState

Server id’ye göre oyuncu state bag’lerinin tek bir anahtarı (`dead`, `cuffed`, pma-voice’un `proximity`’si...).

**Taraf:** Client ve server · **Bekler:** hayır

```ts title="Signature"
new PlayerState<T>(key: string, parse: StateParse<T>)
```

#### Parametreler

<TypeTable
  type={{
    key: { type: 'string', description: 'Bag anahtarı (`"dead"`).', required: true },
    parse: { type: 'StateParse<T>', description: 'Ham değeri `T`’ye çevirir.', required: true },
  }}
/>

#### Metotlar

<TypeTable
  type={{
    'get(serverId)': { type: '(serverId: number) => T | undefined', description: 'Server id’ye göre bir oyuncunun değeri (client’ta yerel oyuncu: `cache.serverId`). Yoksa `undefined`.' },
    'onChange(listener)': { type: '(listener: (serverId: number, value: T | undefined, old: T | undefined) => void) => () => void', description: 'Bir değer değiştikten sonra çalışır. Dinleyiciyi kaldıran bir fonksiyon döndürür.' },
    key: { type: 'string (read only)', description: 'Bag anahtarı.' },
  }}
/>

#### Örnek

```ts title="resource/server/index.ts"
import { PlayerState, stateBoolean, onClientCallback } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const dead = new PlayerState("dead", stateBoolean);
const cuffed = new PlayerState("cuffed", stateBoolean);

onClientCallback("my-shop:open", (source) => {
  if (dead.get(source) || cuffed.get(source)) return fail("CANNOT_NOW");
  return { ok: true };
});
```

<Callout type="info">
Server’da oyundan çıkan bir oyuncu, resource’unun her `PlayerState`’inde unutulur (paylaşılan tek bir `playerDropped` dinleyicisi).
</Callout>

### GlobalKey

Tek bir `GlobalState` anahtarı: her oyuncunun ihtiyaç duyduğu bir değer (PvP anahtarı, aktif envanter). Açılışta bir kez okunur, sonra değişiklik handler’ı tarafından güncel tutulur.

**Taraf:** Client ve server · **Bekler:** hayır

```ts title="Signature"
new GlobalKey<T>(key: string, parse: StateParse<T>)
```

#### Parametreler

<TypeTable
  type={{
    key: { type: 'string', description: '`GlobalState` anahtarı (`"ai:pvp"`).', required: true },
    parse: { type: 'StateParse<T>', description: 'Ham değeri `T`’ye çevirir.', required: true },
  }}
/>

#### Metotlar

<TypeTable
  type={{
    'get()': { type: '() => T | undefined', description: 'Güncel değer; ayarlanmamışsa `undefined`.' },
    'onChange(listener)': { type: '(listener: (id: "global", value: T | undefined, old: T | undefined) => void) => () => void', description: 'Değer değiştikten sonra çalışır. İlk argüman her zaman `"global"`’dır.' },
    key: { type: 'string (read only)', description: 'Anahtar.' },
  }}
/>

#### Örnek

```ts title="resource/client/index.ts"
import { GlobalKey, stateBoolean } from "@aicore-fivem/lib/client";

const pvp = new GlobalKey("ai:pvp", stateBoolean);

pvp.onChange((_id, on) => SendNUIMessage({ action: "pvp", value: on === true }));
```

### GlobalGroup

Aynı ön eki paylaşan birçok `GlobalState` anahtarı (`ai:duty:police`, `ai:duty:ambulance`), ön ekten sonraki kısma göre okunur. Bir resource’un tüm grupları tek bir handler paylaşır.

**Taraf:** Client ve server · **Bekler:** hayır

```ts title="Signature"
new GlobalGroup<T>(prefix: string, parse: StateParse<T>)
```

#### Parametreler

<TypeTable
  type={{
    prefix: { type: 'string', description: 'Anahtarların ortak başlangıcı (`"ai:duty:"`).', required: true },
    parse: { type: 'StateParse<T>', description: 'Her ham değeri `T`’ye çevirir.', required: true },
  }}
/>

#### Metotlar

<TypeTable
  type={{
    'get(id)': { type: '(id: string) => T | undefined', description: '`<prefix><id>`’nin değeri; ayarlanmamışsa `undefined`.' },
    'ids()': { type: '() => IterableIterator<string>', description: 'Değeri olan her id.' },
    'onChange(listener)': { type: '(listener: (id: string, value: T | undefined, old: T | undefined) => void) => () => void', description: 'Grubun bir anahtarı değiştikten sonra, ön ekten sonraki id ile çalışır.' },
    prefix: { type: 'string (read only)', description: 'Ön ek.' },
  }}
/>

#### Örnek

ai-core meslek başına kaç oyuncunun görevde olduğunu `ai:duty:<job>` altında yayınlar:

```ts title="resource/client/index.ts"
import { GlobalGroup, stateNumber } from "@aicore-fivem/lib/client";

const onDuty = new GlobalGroup("ai:duty:", stateNumber);

function policeOnline(): number {
  return onDuty.get("police") ?? 0;
}
```

<Callout type="warn">
Her sınıfı anahtar başına bir kez, bir dosyanın en üstünde oluştur; asla sık çalışan bir fonksiyonun içinde değil: her örnek bir değişiklik handler’ı ekler. `GlobalState` her oyuncuya gönderilir; bu yüzden oraya yalnızca her oyuncunun ihtiyaç duyduğu değerleri koy.
</Callout>
