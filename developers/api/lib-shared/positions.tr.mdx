Düz nesneler olarak yazılmış noktalar üzerinde matematik ([Vec3](/tr/docs/developers/api/types#vec3): metre cinsinden `{ x, y, z }`). Native’e ihtiyaç duymazlar; bu yüzden aynı kod server’da, client’ta ve bir NUI sayfasında çalışır.

```ts title="TypeScript"
import { distance, flatDistance, headingTo, nearestOf, gridCell, cellKey } from "@aifivem/lib/shared";
```

<Callout type="info">
Lua’da vektör matematiği yerleşiktir: `#(a - b)` iki `vector3` arasındaki mesafe, `#(a.xy - b.xy)` zemindeki mesafedir. Yalnızca `headingTo`’nun bir Lua karşılığı vardır (`aiLib.numbers.headingTo`).
</Callout>

### distance

İki nokta arasındaki düz mesafe, metre cinsinden.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
distance(a: Vec3, b: Vec3): number
```

**Lua:** karşılığı yok; iki `vector3` ile `#(a - b)` kullan.

#### Parametreler

<TypeTable
  type={{
    a: { type: 'Vec3', description: 'Birinci nokta.', required: true },
    b: { type: 'Vec3', description: 'İkinci nokta.', required: true },
  }}
/>

#### Dönüş değeri

`number`: metre, 0 ya da daha büyük.

#### Örnek

```ts title="resource/server/index.ts"
import { coordsOf } from "@aifivem/lib/server";
import { distance } from "@aifivem/lib/shared";

const counter = { x: 25.7, y: -1347.3, z: 29.5 };

function nearCounter(source: number): boolean {
  return distance(coordsOf(source), counter) <= 3;
}
```

### flatDistance

Yüksekliği yok sayarak (yalnızca `x` ve `y`) zemin düzlemindeki mesafe, metre cinsinden. Yüksekliğin önemli olmadığı alanlar için kullan (eğimli bir otopark, bir blip yarıçapı).

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
flatDistance(a: { x: number; y: number }, b: { x: number; y: number }): number
```

**Lua:** karşılığı yok; `#(a.xy - b.xy)` kullan.

#### Parametreler

<TypeTable
  type={{
    a: { type: '{ x: number; y: number }', description: 'Birinci nokta (bir `Vec3` de çalışır).', required: true },
    b: { type: '{ x: number; y: number }', description: 'İkinci nokta.', required: true },
  }}
/>

#### Dönüş değeri

`number`: zemin düzleminde metre.

#### Örnek

```ts
import { flatDistance } from "@aifivem/lib/shared";

flatDistance({ x: 0, y: 0, z: 0 }, { x: 3, y: 4, z: 50 }); // 5
```

### headingTo

Bir noktadan diğerine bakan heading, GTA’nın kuralıyla: 0-360 derece, 0 = kuzey, saat yönünün tersine. Bir ped’i ya da kamerayı bir şeye doğru çevirmek için kullan.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
headingTo(from: { x: number; y: number }, to: { x: number; y: number }): number
```

```lua title="Lua"
local heading = aiLib.numbers.headingTo(from, to) -- vector3’ler ya da { x, y } tabloları
```

#### Parametreler

<TypeTable
  type={{
    from: { type: '{ x: number; y: number }', description: 'Ped’in ya da kameranın durduğu yer.', required: true },
    to: { type: '{ x: number; y: number }', description: 'Neye bakması gerektiği.', required: true },
  }}
/>

#### Dönüş değeri

`number`: 0’dan 360’a kadar (360 hariç) bir heading.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { cache, player } from "@aifivem/lib/client";
import { headingTo } from "@aifivem/lib/shared";

const counter = { x: 25.7, y: -1347.3, z: 29.5 };
SetEntityHeading(cache.ped, headingTo(player.coords(), counter));
```
</Tab>
<Tab value="Lua">
```lua
local counter = vector3(25.7, -1347.3, 29.5)
SetEntityHeading(aiLib.cache.ped, aiLib.numbers.headingTo(aiLib.player.coords(), counter))
```
</Tab>
</Tabs>

### nearestOf

Bir listenin bir noktaya en yakın öğesi (3D mesafe), isteğe bağlı bir menzil içinde. Her listede çalışır: bir öğenin konumunun nasıl okunacağını sen söylersin.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
nearestOf<T>(items: Iterable<T>, point: Vec3, pos: (item: T) => Vec3, max?: number): T | undefined
```

**Lua:** karşılığı yok.

#### Parametreler

<TypeTable
  type={{
    items: { type: 'Iterable<T>', description: 'Adaylar (bir dizi, `map.values()`...).', required: true },
    point: { type: 'Vec3', description: 'Ölçümün başladığı nokta.', required: true },
    pos: { type: '(item: T) => Vec3', description: 'Bir öğenin konumunu okur.', required: true },
    max: { type: 'number', description: 'Bir öğenin olabileceği en uzak mesafe, metre cinsinden.', default: 'Infinity' },
  }}
/>

#### Dönüş değeri

En yakın öğe ya da liste boşsa veya her öğe `max`’tan uzaktaysa `undefined`.

#### Örnek

```ts title="resource/server/index.ts"
import { coordsOf } from "@aifivem/lib/server";
import { nearestOf, type Vec3 } from "@aifivem/lib/shared";

const atms: Array<{ id: string; coords: Vec3 }> = [
  { id: "legion", coords: { x: 147.4, y: -1035.8, z: 29.3 } },
  { id: "pillbox", coords: { x: 296.2, y: -591.6, z: 43.3 } },
];

function atmNear(source: number) {
  return nearestOf(atms, coordsOf(source), (atm) => atm.coords, 2);
}
```

### gridCell

`size` metrelik karelerden oluşan bir ızgarada bir noktanın düştüğü tam sayı ızgara hücresi. Lib’in alan yayını (server’da `AreaStream`, client’ta `AreaFollower`) bunu kullanır; böylece iki taraf bir noktanın hangi hücrede olduğu konusunda anlaşır. Hücreler artı ya da eksi 16.000’e sıkıştırılır.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
gridCell(x: number, y: number, size: number): { cx: number; cy: number }
```

**Lua:** karşılığı yok.

#### Parametreler

<TypeTable
  type={{
    x: { type: 'number', description: 'Noktanın x’i, metre cinsinden.', required: true },
    y: { type: 'number', description: 'Noktanın y’si, metre cinsinden.', required: true },
    size: { type: 'number', description: 'Metre cinsinden hücre boyutu.', required: true },
  }}
/>

#### Dönüş değeri

`{ cx, cy }`: hücrenin sütunu ve satırı.

#### Örnek

```ts
import { gridCell, cellKey } from "@aifivem/lib/shared";

const { cx, cy } = gridCell(147.4, -1035.8, 100); // { cx: 1, cy: -11 }
const key = cellKey(cx, cy);
```

### cellKey

Bir ızgara hücresi için, hızlı bir `Map` anahtarı olacak kadar küçük (2^30’un altında) tek bir sayı.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
cellKey(cx: number, cy: number): number
```

**Lua:** karşılığı yok.

#### Parametreler

<TypeTable
  type={{
    cx: { type: 'number', description: '`gridCell`’den hücre sütunu.', required: true },
    cy: { type: 'number', description: '`gridCell`’den hücre satırı.', required: true },
  }}
/>

#### Dönüş değeri

`number`: her tarafta aynı hücre için aynı sayı.

#### Örnek

```ts
import { gridCell, cellKey } from "@aifivem/lib/shared";

const byCell = new Map<number, string[]>();

function addSign(id: string, x: number, y: number): void {
  const { cx, cy } = gridCell(x, y, 100);
  const key = cellKey(cx, cy);
  byCell.set(key, [...(byCell.get(key) ?? []), id]);
}
```
