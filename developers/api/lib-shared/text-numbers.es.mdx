Pequeñas utilidades para lo que leen los jugadores (dinero, pesos, textos traducidos), tiradas aleatorias y cuentas atrás que coinciden con el reloj del servidor.

```ts title="TypeScript"
import { formatText, round, groupDigits, formatWeight, stripGameText, randomInt, pickRandom, rollChance, ServerClock } from "@aicore-fivem/lib/shared";
```

## Texto

### formatText

Rellena los marcadores `{0}`, `{1}`... de un texto con valores por posición. Una traducción puede mover o repetir un marcador (`"{1} paid {0}"`), por eso los valores van por número, no por orden.

**Lado:** Cliente, servidor y NUI · **Espera:** no

```ts title="Firma"
formatText(template: string, args: ReadonlyArray<string | number>): string
```

```lua title="Lua"
local text = aiLib.formatText(template, ...) -- valores como argumentos separados
```

#### Parámetros

<TypeTable
  type={{
    template: { type: 'string', description: 'Texto con marcadores `{0}`, `{1}`...', required: true },
    args: { type: 'ReadonlyArray<string | number>', description: 'TypeScript: los valores en un array, `{0}` es `args[0]`. Lua: los valores como argumentos separados después de `template`.', required: true },
  }}
/>

#### Devuelve

`string`: el texto con cada marcador que tiene valor rellenado. Un marcador sin valor se queda como está (`{2}`).

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { formatText } from "@aicore-fivem/lib/shared";

formatText("You paid ${0} for {1} items", [250, 3]); // "You paid $250 for 3 items"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.formatText('You paid ${0} for {1} items', 250, 3) -- "You paid $250 for 3 items"
```
</Tab>
</Tabs>

<Callout type="info">
Rara vez lo llamas tú mismo: las utilidades de idioma (`createLocale`, `aiLib.locale`, `LangTexts`) ya rellenan los marcadores. Consulta [Idioma](/es/docs/developers/api/lib-shared/locale).
</Callout>

### stripGameText

Convierte en texto plano el texto de otro script: quita las etiquetas HTML, los códigos de color y de entrada de GTA (`~r~`, `~INPUT_PICKUP~`) y `&nbsp;`, junta los espacios repetidos y recorta. Úsalo antes de mostrar el texto de otro script en tu propia interfaz.

**Lado:** Cliente, servidor y NUI · **Espera:** no

```ts title="Firma"
stripGameText(text: unknown): string
```

```lua title="Lua"
local plain = aiLib.stripGameText(text)
```

#### Parámetros

<TypeTable
  type={{
    text: { type: 'unknown', description: 'Cualquier valor. Lo que no es string se convierte primero en texto.', required: true },
  }}
/>

#### Devuelve

`string`: el texto plano. `""` para `null` / `undefined` (Lua: `nil`).

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { stripGameText } from "@aicore-fivem/lib/shared";

stripGameText("Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~"); // "Press to open the shop"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.stripGameText('Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~') -- "Press to open the shop"
```
</Tab>
</Tabs>

## Números

### round

Redondea un número a una cantidad de decimales.

**Lado:** Cliente, servidor y NUI · **Espera:** no

```ts title="Firma"
round(value: number, decimals?: number): number
```

```lua title="Lua"
local rounded = aiLib.numbers.round(value, decimals)
```

#### Parámetros

<TypeTable
  type={{
    value: { type: 'number', description: 'El número que se redondea.', required: true },
    decimals: { type: 'number', description: 'Decimales que se conservan.', default: '0' },
  }}
/>

#### Devuelve

`number`: el valor redondeado.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { round } from "@aicore-fivem/lib/shared";

round(12.345, 1); // 12.3
round(12.5);      // 13
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.round(12.345, 1) -- 12.3
aiLib.numbers.round(12.5)      -- 13
```
</Tab>
</Tabs>

### groupDigits

Escribe un número con un separador cada tres dígitos: `1234567` pasa a ser `1,234,567`. Conserva el signo y los decimales. Úsalo para cada cantidad de dinero que ven los jugadores.

**Lado:** Cliente, servidor y NUI · **Espera:** no

```ts title="Firma"
groupDigits(value: number | string, separator?: string): string
```

```lua title="Lua"
local text = aiLib.numbers.groupDigits(value, separator)
```

#### Parámetros

<TypeTable
  type={{
    value: { type: 'number | string', description: 'El número, o un número ya escrito como texto.', required: true },
    separator: { type: 'string', description: 'Texto que se pone entre los grupos (`"."` o `" "` para otros idiomas).', default: '","' },
  }}
/>

#### Devuelve

`string`: el número agrupado.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groupDigits } from "@aicore-fivem/lib/shared";

groupDigits(1234567);        // "1,234,567"
groupDigits(-9876.5);        // "-9,876.5"
groupDigits(1500000, ".");   // "1.500.000"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.groupDigits(1234567)      -- "1,234,567"
aiLib.numbers.groupDigits(1500000, '.') -- "1.500.000"
```
</Tab>
</Tabs>

### formatWeight

Escribe un peso en gramos como lo leen los jugadores: por debajo de 1 kg en gramos, desde 1 kg en kilogramos con un decimal (kilogramos enteros desde 100 kg), con los dígitos agrupados.

**Lado:** Cliente, servidor y NUI · **Espera:** no

```ts title="Firma"
formatWeight(grams: number): string
```

**Lua:** sin equivalente.

#### Parámetros

<TypeTable
  type={{
    grams: { type: 'number', description: 'Peso en gramos.', required: true },
  }}
/>

#### Devuelve

`string`: `"750 g"`, `"1.5 kg"`, `"1,250 kg"`.

#### Ejemplo

```ts
import { formatWeight } from "@aicore-fivem/lib/shared";

formatWeight(750);      // "750 g"
formatWeight(1500);     // "1.5 kg"
formatWeight(1250000);  // "1,250 kg"
```

## Aleatorio

### randomInt

Un número entero aleatorio de `min` a `max`, ambos incluidos.

**Lado:** Cliente, servidor y NUI · **Espera:** no

```ts title="Firma"
randomInt(min: number, max: number): number
```

**Lua:** sin equivalente; usa `math.random(min, max)`.

#### Parámetros

<TypeTable
  type={{
    min: { type: 'number', description: 'Resultado más bajo posible (un número entero).', required: true },
    max: { type: 'number', description: 'Resultado más alto posible (un número entero).', required: true },
  }}
/>

#### Devuelve

`number`: un número entero entre `min` y `max`.

#### Ejemplo

```ts
import { randomInt } from "@aicore-fivem/lib/shared";

const payout = randomInt(150, 300); // 150, 151, ... o 300
```

### pickRandom

Un elemento aleatorio de una lista.

**Lado:** Cliente, servidor y NUI · **Espera:** no

```ts title="Firma"
pickRandom<T>(list: readonly T[]): T | undefined
```

**Lua:** sin equivalente; usa `list[math.random(#list)]`.

#### Parámetros

<TypeTable
  type={{
    list: { type: 'readonly T[]', description: 'Los elementos entre los que elegir.', required: true },
  }}
/>

#### Devuelve

Un elemento, o `undefined` cuando la lista está vacía.

#### Ejemplo

```ts
import { pickRandom } from "@aicore-fivem/lib/shared";

const loot = pickRandom(["goldbar", "rolex", "diamond"]) ?? "goldbar";
```

### rollChance

`true` con una probabilidad de `percent` sobre 100.

**Lado:** Cliente, servidor y NUI · **Espera:** no

```ts title="Firma"
rollChance(percent: number): boolean
```

**Lua:** sin equivalente; usa `math.random() * 100 < percent`.

#### Parámetros

<TypeTable
  type={{
    percent: { type: 'number', description: 'Probabilidad de 0 (nunca) a 100 (siempre).', required: true },
  }}
/>

#### Devuelve

`true` aproximadamente `percent` veces de cada 100.

#### Ejemplo

```ts title="resource/server/index.ts"
import { inventory } from "@aicore-fivem/lib/server";
import { rollChance } from "@aicore-fivem/lib/shared";

function useLockpick(source: number, slot: number): void {
  if (rollChance(25)) inventory.removeItem(source, "lockpick", 1, undefined, slot); // se rompe 1 de cada 4 veces
}
```

<Callout type="warn">
Haz la tirada en el servidor para todo lo que dé objetos o dinero. Un tramposo puede forzar una tirada en el cliente.
</Callout>

## Tiempo

### ServerClock

El reloj del servidor en un cliente, para cuentas atrás que no dependen del propio reloj del cliente. Se exporta desde `@aicore-fivem/lib/shared` y no tiene equivalente en Lua. Su referencia completa (`sync`, `now`, `toLocal`, ejemplo de cuenta atrás) está en [Cámara y temporización: ServerClock](/es/docs/developers/api/lib-client/camera-and-timing#new-serverclock).
