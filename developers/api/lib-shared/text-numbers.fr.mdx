De petits utilitaires pour ce que lisent les joueurs (argent, poids, textes traduits), les tirages aléatoires et les comptes à rebours alignés sur l’horloge du serveur.

```ts title="TypeScript"
import { formatText, round, groupDigits, formatWeight, stripGameText, randomInt, pickRandom, rollChance, ServerClock } from "@aifivem/lib/shared";
```

## Texte

### formatText

Remplit les emplacements `{0}`, `{1}`... d’un texte avec des valeurs selon leur position. Une traduction peut déplacer ou répéter un emplacement (`"{1} paid {0}"`), c’est pourquoi les valeurs sont désignées par numéro et non par ordre.

**Côté :** client, serveur et NUI · **Attend :** non

```ts title="Signature"
formatText(template: string, args: ReadonlyArray<string | number>): string
```

```lua title="Lua"
local text = aiLib.formatText(template, ...) -- les valeurs en arguments séparés
```

#### Paramètres

<TypeTable
  type={{
    template: { type: 'string', description: 'Texte avec des emplacements `{0}`, `{1}`...', required: true },
    args: { type: 'ReadonlyArray<string | number>', description: 'TypeScript : les valeurs dans un seul tableau, `{0}` est `args[0]`. Lua : les valeurs en arguments séparés après `template`.', required: true },
  }}
/>

#### Retour

`string` : le texte avec chaque emplacement qui a une valeur rempli. Un emplacement sans valeur reste tel quel (`{2}`).

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { formatText } from "@aifivem/lib/shared";

formatText("You paid ${0} for {1} items", [250, 3]); // "You paid $250 for 3 items"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.formatText('You paid ${0} for {1} items', 250, 3) -- "You paid $250 for 3 items"
```
</Tab>
</Tabs>

<Callout type="info">
Vous l’appelez rarement vous-même : les utilitaires de langue (`createLocale`, `aiLib.locale`, `LangTexts`) remplissent déjà les emplacements. Voir [Langue](/fr/docs/developers/api/lib-shared/locale).
</Callout>

### stripGameText

Rend brut un texte venant d’un autre script : retire les balises HTML, les codes de couleur et de touche de GTA (`~r~`, `~INPUT_PICKUP~`) et `&nbsp;`, réduit les suites d’espaces et supprime les espaces au début et à la fin. Utilisez-le avant d’afficher le texte d’un autre script dans votre propre interface.

**Côté :** client, serveur et NUI · **Attend :** non

```ts title="Signature"
stripGameText(text: unknown): string
```

```lua title="Lua"
local plain = aiLib.stripGameText(text)
```

#### Paramètres

<TypeTable
  type={{
    text: { type: 'unknown', description: 'N’importe quelle valeur. Ce qui n’est pas une chaîne est d’abord converti en texte.', required: true },
  }}
/>

#### Retour

`string` : le texte brut. `""` pour `null` / `undefined` (Lua : `nil`).

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { stripGameText } from "@aifivem/lib/shared";

stripGameText("Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~"); // "Press to open the shop"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.stripGameText('Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~') -- "Press to open the shop"
```
</Tab>
</Tabs>

## Nombres

### round

Arrondit un nombre à un nombre de décimales.

**Côté :** client, serveur et NUI · **Attend :** non

```ts title="Signature"
round(value: number, decimals?: number): number
```

```lua title="Lua"
local rounded = aiLib.numbers.round(value, decimals)
```

#### Paramètres

<TypeTable
  type={{
    value: { type: 'number', description: 'Le nombre à arrondir.', required: true },
    decimals: { type: 'number', description: 'Nombre de décimales à garder.', default: '0' },
  }}
/>

#### Retour

`number` : la valeur arrondie.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { round } from "@aifivem/lib/shared";

round(12.345, 1); // 12.3
round(12.5);      // 13
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.round(12.345, 1) -- 12.3
aiLib.numbers.round(12.5)      -- 13
```
</Tab>
</Tabs>

### groupDigits

Écrit un nombre avec un séparateur tous les trois chiffres : `1234567` devient `1,234,567`. Garde le signe et les décimales. Utilisez-le pour chaque montant d’argent que voient les joueurs.

**Côté :** client, serveur et NUI · **Attend :** non

```ts title="Signature"
groupDigits(value: number | string, separator?: string): string
```

```lua title="Lua"
local text = aiLib.numbers.groupDigits(value, separator)
```

#### Paramètres

<TypeTable
  type={{
    value: { type: 'number | string', description: 'Le nombre, ou un nombre déjà écrit sous forme de texte.', required: true },
    separator: { type: 'string', description: 'Texte placé entre les groupes (`"."` ou `" "` pour d’autres langues).', default: '","' },
  }}
/>

#### Retour

`string` : le nombre groupé.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groupDigits } from "@aifivem/lib/shared";

groupDigits(1234567);        // "1,234,567"
groupDigits(-9876.5);        // "-9,876.5"
groupDigits(1500000, ".");   // "1.500.000"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.groupDigits(1234567)      -- "1,234,567"
aiLib.numbers.groupDigits(1500000, '.') -- "1.500.000"
```
</Tab>
</Tabs>

### formatWeight

Écrit un poids en grammes comme les joueurs le lisent : sous 1 kg en grammes, à partir de 1 kg en kilogrammes avec une décimale (kilogrammes entiers à partir de 100 kg), chiffres groupés.

**Côté :** client, serveur et NUI · **Attend :** non

```ts title="Signature"
formatWeight(grams: number): string
```

**Lua :** pas d’équivalent.

#### Paramètres

<TypeTable
  type={{
    grams: { type: 'number', description: 'Poids en grammes.', required: true },
  }}
/>

#### Retour

`string` : `"750 g"`, `"1.5 kg"`, `"1,250 kg"`.

#### Exemple

```ts
import { formatWeight } from "@aifivem/lib/shared";

formatWeight(750);      // "750 g"
formatWeight(1500);     // "1.5 kg"
formatWeight(1250000);  // "1,250 kg"
```

## Aléatoire

### randomInt

Un nombre entier aléatoire de `min` à `max`, tous deux inclus.

**Côté :** client, serveur et NUI · **Attend :** non

```ts title="Signature"
randomInt(min: number, max: number): number
```

**Lua :** pas d’équivalent ; utilisez `math.random(min, max)`.

#### Paramètres

<TypeTable
  type={{
    min: { type: 'number', description: 'Plus petit résultat possible (un nombre entier).', required: true },
    max: { type: 'number', description: 'Plus grand résultat possible (un nombre entier).', required: true },
  }}
/>

#### Retour

`number` : un nombre entier entre `min` et `max`.

#### Exemple

```ts
import { randomInt } from "@aifivem/lib/shared";

const payout = randomInt(150, 300); // 150, 151, ... ou 300
```

### pickRandom

Un élément aléatoire d’une liste.

**Côté :** client, serveur et NUI · **Attend :** non

```ts title="Signature"
pickRandom<T>(list: readonly T[]): T | undefined
```

**Lua :** pas d’équivalent ; utilisez `list[math.random(#list)]`.

#### Paramètres

<TypeTable
  type={{
    list: { type: 'readonly T[]', description: 'Les éléments parmi lesquels choisir.', required: true },
  }}
/>

#### Retour

Un élément, ou `undefined` quand la liste est vide.

#### Exemple

```ts
import { pickRandom } from "@aifivem/lib/shared";

const loot = pickRandom(["goldbar", "rolex", "diamond"]) ?? "goldbar";
```

### rollChance

`true` avec une probabilité de `percent` sur 100.

**Côté :** client, serveur et NUI · **Attend :** non

```ts title="Signature"
rollChance(percent: number): boolean
```

**Lua :** pas d’équivalent ; utilisez `math.random() * 100 < percent`.

#### Paramètres

<TypeTable
  type={{
    percent: { type: 'number', description: 'Probabilité de 0 (jamais) à 100 (toujours).', required: true },
  }}
/>

#### Retour

`true` environ `percent` fois sur 100.

#### Exemple

```ts title="resource/server/index.ts"
import { inventory } from "@aifivem/lib/server";
import { rollChance } from "@aifivem/lib/shared";

function useLockpick(source: number, slot: number): void {
  if (rollChance(25)) inventory.removeItem(source, "lockpick", 1, undefined, slot); // se casse 1 fois sur 4
}
```

<Callout type="warn">
Faites le tirage sur le serveur pour tout ce qui donne des objets ou de l’argent. Un tirage sur le client peut être forcé par un tricheur.
</Callout>

## Temps

### ServerClock

L’horloge du serveur sur un client, pour des comptes à rebours qui ne dépendent pas de l’horloge propre du client. Elle est exportée depuis `@aifivem/lib/shared` et n’a pas d’équivalent Lua. Sa référence complète (`sync`, `now`, `toLocal`, exemple de compte à rebours) se trouve sur [Caméra et timing : ServerClock](/fr/docs/developers/api/lib-client/camera-and-timing#new-serverclock).
