Ustawienia twojego skryptu są w plikach `data/*.json`, które właściciel serwera edytuje w panelu administratora ai-core (zobacz [Panel administratora](/pl/docs/developers/api/lib-server/admin-panel)). Panel sprawdza wartości względem twojego `schema.ts`, ale plik i tak może być stary, edytowany ręcznie albo nie mieć jakiegoś pola. Czytniki z tej strony **nigdy nie odrzucają**: brakująca albo zła wartość daje podaną przez ciebie wartość zastępczą, więc skrypt zawsze startuje.

Dla wartości wysyłanych przez klienta użyj zamiast tego ścisłych czytników ze strony [Akcje i wejście z klienta](/pl/docs/developers/api/lib-shared/input): one odrzucają złą wartość.

```ts title="TypeScript"
import { num, int, bool, str, record, vec4, spec, readRecords, withoutSchemaKey } from "@aicore-fivem/lib/shared";
```

**Lua:** żadna z nich nie ma odpowiednika w Lua (panel administratora i jego pliki danych są tylko dla TypeScript).

## Czytniki wartości

### num

Skończona liczba ograniczona do `[min, max]`, w przeciwnym razie wartość zastępcza.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
num(value: unknown, fallback: number, min?: number, max?: number): number
```

#### Parametry

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Surowa wartość z pliku.', required: true },
    fallback: { type: 'number', description: 'Używana, gdy `value` nie jest skończoną liczbą.', required: true },
    min: { type: 'number', description: 'Mniejsza liczba jest podnoszona do tej.', default: '-Infinity' },
    max: { type: 'number', description: 'Większa liczba jest obniżana do tej.', default: 'Infinity' },
  }}
/>

#### Zwracana wartość

`number`: wartość ograniczona do zakresu albo `fallback` (nieograniczony).

#### Przykład

```ts
import { num } from "@aicore-fivem/lib/shared";

num(25, 2.5, 1, 20);      // 20 (ograniczone)
num("big", 2.5, 1, 20);   // 2.5 (wartość zastępcza)
```

### int

Jak `num`, potem zaokrąglona do liczby całkowitej.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
int(value: unknown, fallback: number, min?: number, max?: number): number
```

#### Parametry

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Surowa wartość z pliku.', required: true },
    fallback: { type: 'number', description: 'Używana, gdy `value` nie jest skończoną liczbą.', required: true },
    min: { type: 'number', description: 'Najniższy wynik.', default: '-Infinity' },
    max: { type: 'number', description: 'Najwyższy wynik.', default: 'Infinity' },

#### Zwracana wartość

`number`: liczba całkowita (wartość zastępcza też jest zaokrąglana).

#### Przykład


#### Parametry

<TypeTable
  type={{

### str

Przycięty, niepusty string skrócony do `max` znaków, w przeciwnym razie wartość zastępcza.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"

```

#### Parametry

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Surowa wartość z pliku.', required: true },
    fallback: { type: 'string', description: 'Używana, gdy `value` nie jest stringiem albo jest pusty po przycięciu.', required: true },

#### Zwracana wartość

`string`.

### record

Wartość jako zwykły obiekt albo pusty obiekt `{}`. Używaj go przed odczytem pól wartości, której może brakować.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
record(value: unknown): Record<string, unknown>
```

#### Parametry

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Dowolna wartość.', required: true },
  }}
/>

#### Zwracana wartość

Sama `value`, gdy jest zwykłym obiektem, w przeciwnym razie nowy `{}` (także dla tablic i `null`).

#### Przykład

```ts
import { num, record } from "@aicore-fivem/lib/shared";

function readCoords(raw: unknown) {
  const c = record(raw); // {}, gdy brakuje pola
  return { x: num(c.x, 0), y: num(c.y, 0), z: num(c.z, 0) };
}
```

### vec4

Pozycja z kierunkiem; każde brakujące albo złe pole pochodzi z wartości zastępczej.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"

```

#### Parametry

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Surowa wartość (`{ x, y, z, heading }`).', required: true },
    fallback: { type: 'Vec4', description: 'Skąd pochodzi każde brakujące pole.', required: true, typeDescription: '{ x, y, z, heading }' },
  }}
/>

#### Zwracana wartość

Nowy [Vec4](/pl/docs/developers/api/types#vec4).

#### Przykład

```ts

```

## Funkcje schematu

### spec

Konstruktory pól liczbowych w `schema.ts` twojego panelu, żebyś nie pisał ręcznie tego samego obiektu `DataSpec`.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
spec.int(min: number, max: number, optional?: boolean): DataSpec
spec.num(min: number, max: number, optional?: boolean): DataSpec
```

#### Parametry

<TypeTable
  type={{
    min: { type: 'number', description: 'Najniższa wartość akceptowana przez panel.', required: true },
    max: { type: 'number', description: 'Najwyższa wartość akceptowana przez panel.', required: true },
    optional: { type: 'boolean', description: '`true`: pole można zostawić puste.', default: 'false' },
  }}
/>

#### Zwracana wartość

`DataSpec`: `{ type: "number", min, max }`, plus `integer: true` dla `spec.int` i `optional: true` na żądanie.

#### Przykład

```ts title="resource/server/schema.ts"
import { spec } from "@aicore-fivem/lib/shared";
import type { PanelSchema } from "@aicore-fivem/shared";

export const schema: PanelSchema = {
  title: "ADMIN_TITLE",
  icon: "store",
  files: {
    settings: {
      kind: "settings",
      sync: "admin",
      sections: {
        prices: { type: "object", fields: { water: spec.int(0, 1_000_000), tax: spec.num(0, 0.5) } },
      },
    },
  },
  tabs: [], // układ panelu (karty i pola), zobacz Panel administratora
};
```

### withoutSchemaKey

Usuwa klucz `"$schema"` z zawartości pliku danych. Klucz jest tam tylko po to, żeby edytory kodu mogły sprawdzić plik; twój czytnik nie powinien go widzieć.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
withoutSchemaKey(value: unknown): unknown
```

#### Parametry

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Sparsowany plik danych.', required: true },
  }}
/>

#### Zwracana wartość

Kopia bez `$schema`, gdy wartość jest obiektem, który go ma; w przeciwnym razie `value` bez zmian.

#### Przykład

```ts
import { withoutSchemaKey } from "@aicore-fivem/lib/shared";

withoutSchemaKey({ $schema: "./schemas/shops.schema.json", legion: { label: "Legion" } });
// { legion: { label: "Legion" } }
```

## Pliki rekordów

Plik **rekordów** trzyma wiele wpisów według klucza (`{ "legion": {...}, "pillbox": {...} }`): sklepy, garaże, ratusze. Każdy wpis jest czytany przez twoją własną funkcję czytnika (`RecordReader<T> = (key: string, raw: Record<string, unknown>) => T | null`), zbudowaną z czytników wartości wyżej.

### readRecords

Czyta cały plik rekordów raz do `Map`, jeden wpis na klucz, przez twój czytnik. Wpisy, które nie są obiektami albo dla których twój czytnik zwraca `null`, są pomijane.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
readRecords<T>(raw: unknown, readOne: RecordReader<T>): Map<string, T>
```

#### Parametry

<TypeTable
  type={{
    raw: { type: 'unknown', description: 'Sparsowany plik (`{ key: record }`). Cokolwiek innego daje pustą mapę.', required: true },
    readOne: { type: '(key: string, raw: Record<string, unknown>) => T | null', description: 'Czyta jeden wpis. Zwróć `null`, żeby go pominąć.', required: true },
  }}
/>

#### Zwracana wartość

`Map<string, T>`: sparsowane wpisy według klucza.

#### Przykład

```ts
import { readRecords, str, num, record } from "@aicore-fivem/lib/shared";

type Shop = { label: string; x: number; y: number; z: number };

const readShop = (key: string, v: Record<string, unknown>): Shop => {
  const c = record(v.coords);
  return { label: str(v.label, key, 48), x: num(c.x, 0), y: num(c.y, 0), z: num(c.z, 0) };
};

const shops = readRecords({ legion: { label: "Legion", coords: { x: 25.7, y: -1347.3, z: 29.5 } } }, readShop);
shops.get("legion"); // { label: "Legion", x: 25.7, y: -1347.3, z: 29.5 }
```

<Callout type="info">
Dla pliku panelu wybieraj raczej `panel.records(file, readOne)` (serwerowy `AdminPanel`) albo `world.records(file, readOne)` (kliencki `AdminWorld`): zwracają mapę, która pozostaje aktualna podczas edycji przez właściciela i parsuje tylko zmieniony wpis.
</Callout>

### RecordObjects

Utrzymuje obiekty świata z pliku rekordów (punkty, blipy, pedy, strefy) zgodne z panelem, po jednym wpisie: edytowany wpis przebudowuje tylko własne obiekty. Jest eksportowany z `@aicore-fivem/lib/shared` i nie ma odpowiednika w Lua. Jego pełny opis (konstruktor, funkcja `build`, `rebuild`, `rebuildAll`, przykład) jest na stronie [Punkty interakcji: RecordObjects](/pl/docs/developers/api/lib-client/points#new-recordobjects).
