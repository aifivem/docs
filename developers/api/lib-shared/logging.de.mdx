Diese Helfer schreiben in die **Konsole** (F8 auf einem Client, die Server-Konsole oder txAdmin auf dem Server). Für Logs, die der Serverbetreiber in Discord, Fivemanage oder FiveM Stats liest, nutze stattdessen `aiLog` (siehe [Logs](/de/docs/developers/api/lib-server/logs)).

```ts title="TypeScript"
import { createLogger, logSafe, previewJson } from "@aicore-fivem/lib/shared";
```

### createLogger

Gibt einen Logger zurück, dessen Zeilen mit `[your-resource]` beginnen, damit die Server-Konsole zeigt, woher jede Zeile kommt. Warnungen sind gelb, Fehler rot.

**Seite:** Client, Server und NUI · **Wartet:** nein

```ts title="Signatur"
createLogger(resource: string): Logger
```

**Lua:** kein Zwilling; nutze `print(('[%s] %s'):format(GetCurrentResourceName(), message))`.

#### Parameter

<TypeTable
  type={{
    resource: { type: 'string', description: 'Der Name vor jeder Zeile, meist `GetCurrentResourceName()`.', required: true },
  }}
/>

#### Rückgabewert

`Logger`:

<TypeTable
  type={{
    'info(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'Eine normale Zeile (`console.log`).' },
    'warn(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'Eine gelbe Zeile (`console.warn`).' },
    'error(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'Eine rote Zeile (`console.error`). Übergib den Fehler als Detail, um seinen Stack auszugeben.' },
  }}
/>

#### Beispiel

```ts title="resource/server/index.ts"
import { createLogger } from "@aicore-fivem/lib/shared";

const log = createLogger(GetCurrentResourceName());

log.info("loaded 12 shops");               // [my-shop] loaded 12 shops
log.warn("shop legion has no ped model");  // gelb
try {
  JSON.parse("{");
} catch (error) {
  log.error("could not read shops.json", error); // rot, mit dem Fehler
}
```

### logSafe

Macht Text, den ein Client gesendet hat, sicher für die Server-Konsole: eine Zeile (Zeilenumbrüche werden zu ` | `), keine Steuerzeichen, keine `^1`-Farbcodes, auf `max` Zeichen gekürzt. Nutze es immer, wenn eine Log-Zeile Text eines Spielers enthält (einen Namen, eine Nachricht, eine Notiz).

**Seite:** Client, Server und NUI · **Wartet:** nein

```ts title="Signatur"
logSafe(text: string, max: number): string
```

**Lua:** kein Zwilling.

#### Parameter

<TypeTable
  type={{
    text: { type: 'string', description: 'Der nicht vertrauenswürdige Text.', required: true },
    max: { type: 'number', description: 'Höchstzahl behaltener Zeichen.', required: true },
  }}
/>

#### Rückgabewert

`string`: der bereinigte Text.

#### Beispiel

```ts
import { logSafe } from "@aicore-fivem/lib/shared";

logSafe("^1fake error\nsecond line", 100); // "fake error | second line"
```

<Callout type="warn">
Ohne es kann ein Spieler eine Chatnachricht mit `^1`-Farbcodes und Zeilenumbrüchen schreiben, die in deiner Konsole wie ein echter Server-Fehler aussieht.
</Callout>

### previewJson

Ein kurzer JSON-ähnlicher Text eines beliebigen nicht vertrauenswürdigen Werts, bei `max` Zeichen abgeschnitten, gebaut, **ohne** zuerst den ganzen Wert zu serialisieren (eine feindliche Nutzlast kann Megabytes groß sein). Verschachtelung tiefer als 4 Ebenen erscheint als `[...]` / `{...}`. Nutze es, um auszugeben, was ein Client gesendet hat, wenn du es ablehnst.

**Seite:** Client, Server und NUI · **Wartet:** nein

```ts title="Signatur"
previewJson(value: unknown, max: number): string
```

**Lua:** kein Zwilling.

#### Parameter

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Alles Mögliche: die rohen Argumente eines abgelehnten Aufrufs.', required: true },
    max: { type: 'number', description: 'Höchstzahl an Zeichen im Ergebnis.', required: true },
  }}
/>

#### Rückgabewert

`string`: die Vorschau, höchstens `max` Zeichen. Objektschlüssel werden auf 50 Zeichen gekürzt.

#### Beispiel

```ts title="resource/server/index.ts"
import { onClientEvent } from "@aicore-fivem/lib/server";
import { createLogger, logSafe, previewJson } from "@aicore-fivem/lib/shared";

const log = createLogger(GetCurrentResourceName());

onClientEvent("my-shop:rate", (source) => {
  log.info(`${logSafe(GetPlayerName(String(source)) ?? "?", 32)} opened the rating`);
});

function refuse(source: number, raw: unknown[]): void {
  log.warn(`refused input from ${source}: ${previewJson(raw, 200)}`);
}
```
