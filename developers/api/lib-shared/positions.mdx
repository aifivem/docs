Math on points written as plain objects ([Vec3](/docs/developers/api/types#vec3): `{ x, y, z }` in metres). They need no natives, so the same code runs on the server, the client and in a NUI page.

```ts title="TypeScript"
import { distance, flatDistance, headingTo, nearestOf, gridCell, cellKey } from "@aicore-fivem/lib/shared";
```

<Callout type="info">
Lua has vector math built in: `#(a - b)` is the distance between two `vector3`s, `#(a.xy - b.xy)` the distance on the ground. Only `headingTo` has a Lua twin (`aiLib.numbers.headingTo`).
</Callout>

### distance

The straight distance between two points, in metres.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
distance(a: Vec3, b: Vec3): number
```

**Lua:** no twin; use `#(a - b)` with two `vector3`s.

#### Parameters

<TypeTable
  type={{
    a: { type: 'Vec3', description: 'First point.', required: true },
    b: { type: 'Vec3', description: 'Second point.', required: true },
  }}
/>

#### Returns

`number`: metres, 0 or more.

#### Example

```ts title="resource/server/index.ts"
import { coordsOf } from "@aicore-fivem/lib/server";
import { distance } from "@aicore-fivem/lib/shared";

const counter = { x: 25.7, y: -1347.3, z: 29.5 };

function nearCounter(source: number): boolean {
  return distance(coordsOf(source), counter) <= 3;
}
```

### flatDistance

The distance on the ground plane, ignoring height (only `x` and `y`), in metres. Use it for areas where height does not matter (a parking lot on a slope, a blip radius).

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
flatDistance(a: { x: number; y: number }, b: { x: number; y: number }): number
```

**Lua:** no twin; use `#(a.xy - b.xy)`.

#### Parameters

<TypeTable
  type={{
    a: { type: '{ x: number; y: number }', description: 'First point (a `Vec3` works too).', required: true },
    b: { type: '{ x: number; y: number }', description: 'Second point.', required: true },
  }}
/>

#### Returns

`number`: metres on the ground plane.

#### Example

```ts
import { flatDistance } from "@aicore-fivem/lib/shared";

flatDistance({ x: 0, y: 0, z: 0 }, { x: 3, y: 4, z: 50 }); // 5
```

### headingTo

The heading that faces from one point towards another, in GTA's convention: 0-360 degrees, 0 = north, counter-clockwise. Use it to turn a ped or a camera toward something.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
headingTo(from: { x: number; y: number }, to: { x: number; y: number }): number
```

```lua title="Lua"
local heading = aiLib.numbers.headingTo(from, to) -- vector3s or { x, y } tables
```

#### Parameters

<TypeTable
  type={{
    from: { type: '{ x: number; y: number }', description: 'Where the ped or camera stands.', required: true },
    to: { type: '{ x: number; y: number }', description: 'What it should face.', required: true },
  }}
/>

#### Returns

`number`: a heading from 0 up to (not including) 360.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { cache, player } from "@aicore-fivem/lib/client";
import { headingTo } from "@aicore-fivem/lib/shared";

const counter = { x: 25.7, y: -1347.3, z: 29.5 };
SetEntityHeading(cache.ped, headingTo(player.coords(), counter));
```
</Tab>
<Tab value="Lua">
```lua
local counter = vector3(25.7, -1347.3, 29.5)
SetEntityHeading(aiLib.cache.ped, aiLib.numbers.headingTo(aiLib.player.coords(), counter))
```
</Tab>
</Tabs>

### nearestOf

The item of a list nearest to a point (3D distance), within an optional range. Works for any list: you tell it how to read an item's position.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
nearestOf<T>(items: Iterable<T>, point: Vec3, pos: (item: T) => Vec3, max?: number): T | undefined
```

**Lua:** no twin.

#### Parameters

<TypeTable
  type={{
    items: { type: 'Iterable<T>', description: 'The candidates (an array, `map.values()`...).', required: true },
    point: { type: 'Vec3', description: 'The point to measure from.', required: true },
    pos: { type: '(item: T) => Vec3', description: 'Reads the position of one item.', required: true },
    max: { type: 'number', description: 'Farthest distance in metres an item may be.', default: 'Infinity' },
  }}
/>

#### Returns

The nearest item, or `undefined` when the list is empty or every item is farther than `max`.

#### Example

```ts title="resource/server/index.ts"
import { coordsOf } from "@aicore-fivem/lib/server";
import { nearestOf, type Vec3 } from "@aicore-fivem/lib/shared";

const atms: Array<{ id: string; coords: Vec3 }> = [
  { id: "legion", coords: { x: 147.4, y: -1035.8, z: 29.3 } },
  { id: "pillbox", coords: { x: 296.2, y: -591.6, z: 43.3 } },
];

function atmNear(source: number) {
  return nearestOf(atms, coordsOf(source), (atm) => atm.coords, 2);
}
```

### gridCell

The integer grid cell a point falls in, on a grid of `size`-metre squares. The lib's area streaming (`AreaStream` on the server, `AreaFollower` on the client) uses it, so both sides agree on which cell a point is in. Cells are clamped to plus or minus 16,000.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
gridCell(x: number, y: number, size: number): { cx: number; cy: number }
```

**Lua:** no twin.

#### Parameters

<TypeTable
  type={{
    x: { type: 'number', description: 'Point x in metres.', required: true },
    y: { type: 'number', description: 'Point y in metres.', required: true },
    size: { type: 'number', description: 'Cell size in metres.', required: true },
  }}
/>

#### Returns

`{ cx, cy }`: the cell's column and row.

#### Example

```ts
import { gridCell, cellKey } from "@aicore-fivem/lib/shared";

const { cx, cy } = gridCell(147.4, -1035.8, 100); // { cx: 1, cy: -11 }
const key = cellKey(cx, cy);
```

### cellKey

One number for a grid cell, small enough to be a fast `Map` key (below 2^30).

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
cellKey(cx: number, cy: number): number
```

**Lua:** no twin.

#### Parameters

<TypeTable
  type={{
    cx: { type: 'number', description: 'Cell column from `gridCell`.', required: true },
    cy: { type: 'number', description: 'Cell row from `gridCell`.', required: true },
  }}
/>

#### Returns

`number`: the same number for the same cell, on every side.

#### Example

```ts
import { gridCell, cellKey } from "@aicore-fivem/lib/shared";

const byCell = new Map<number, string[]>();

function addSign(id: string, x: number, y: number): void {
  const { cx, cy } = gridCell(x, y, 100);
  const key = cellKey(cx, cy);
  byCell.set(key, [...(byCell.get(key) ?? []), id]);
}
```
