Небольшие помощники для того, что читают игроки (деньги, вес, переведённые тексты), для случайных бросков и для обратных отсчётов, совпадающих с часами сервера.

```ts title="TypeScript"
import { formatText, round, groupDigits, formatWeight, stripGameText, randomInt, pickRandom, rollChance, ServerClock } from "@aifivem/lib/shared";
```

## Текст

### formatText

Подставляет в текст значения на места плейсхолдеров `{0}`, `{1}`... по позиции. Перевод может переставить или повторить плейсхолдер (`"{1} paid {0}"`), поэтому значения идут по номеру, а не по порядку.

**Сторона:** Клиент, сервер и NUI · **Ждёт:** нет

```ts title="Сигнатура"
formatText(template: string, args: ReadonlyArray<string | number>): string
```

```lua title="Lua"
local text = aiLib.formatText(template, ...) -- значения отдельными аргументами
```

#### Параметры

<TypeTable
  type={{
    template: { type: 'string', description: 'Текст с плейсхолдерами `{0}`, `{1}`...', required: true },
    args: { type: 'ReadonlyArray<string | number>', description: 'TypeScript: значения в одном массиве, `{0}` это `args[0]`. Lua: значения отдельными аргументами после `template`.', required: true },
  }}
/>

#### Возвращает

`string`: текст, в котором заполнен каждый плейсхолдер, для которого есть значение. Плейсхолдер без значения остаётся как есть (`{2}`).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { formatText } from "@aifivem/lib/shared";

formatText("You paid ${0} for {1} items", [250, 3]); // "You paid $250 for 3 items" (Вы заплатили $250 за 3 предмета)
```
</Tab>
<Tab value="Lua">
```lua
aiLib.formatText('You paid ${0} for {1} items', 250, 3) -- "You paid $250 for 3 items" (Вы заплатили $250 за 3 предмета)
```
</Tab>
</Tabs>

<Callout type="info">
Вызывать её самому приходится редко: помощники локализации (`createLocale`, `aiLib.locale`, `LangTexts`) уже заполняют плейсхолдеры. См. [Локализация](/ru/docs/developers/api/lib-shared/locale).
</Callout>

### stripGameText

Делает текст из другого скрипта простым: удаляет HTML-теги, цветовые коды GTA и коды ввода (`~r~`, `~INPUT_PICKUP~`) и `&nbsp;`, схлопывает повторяющиеся пробелы и обрезает края. Используйте перед тем, как показать текст другого скрипта в своём интерфейсе.

**Сторона:** Клиент, сервер и NUI · **Ждёт:** нет

```ts title="Сигнатура"
stripGameText(text: unknown): string
```

```lua title="Lua"
local plain = aiLib.stripGameText(text)
```

#### Параметры

<TypeTable
  type={{
    text: { type: 'unknown', description: 'Любое значение. Не строки сначала превращаются в текст.', required: true },
  }}
/>

#### Возвращает

`string`: простой текст. `""` для `null` / `undefined` (Lua: `nil`).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { stripGameText } from "@aifivem/lib/shared";

stripGameText("Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~"); // "Press to open the shop" (Нажмите, чтобы открыть магазин)
```
</Tab>
<Tab value="Lua">
```lua
aiLib.stripGameText('Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~') -- "Press to open the shop" (Нажмите, чтобы открыть магазин)
```
</Tab>
</Tabs>

## Числа

### round

Округляет число до заданного количества знаков после запятой.

**Сторона:** Клиент, сервер и NUI · **Ждёт:** нет

```ts title="Сигнатура"
round(value: number, decimals?: number): number
```

```lua title="Lua"
local rounded = aiLib.numbers.round(value, decimals)
```

#### Параметры

<TypeTable
  type={{
    value: { type: 'number', description: 'Число для округления.', required: true },
    decimals: { type: 'number', description: 'Сколько знаков после запятой оставить.', default: '0' },
  }}
/>

#### Возвращает

`number`: округлённое значение.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { round } from "@aifivem/lib/shared";

round(12.345, 1); // 12.3
round(12.5);      // 13
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.round(12.345, 1) -- 12.3
aiLib.numbers.round(12.5)      -- 13
```
</Tab>
</Tabs>

### groupDigits

Записывает число с разделителем через каждые три цифры: `1234567` становится `1,234,567`. Сохраняет знак и дробную часть. Используйте для каждой суммы денег, которую видят игроки.

**Сторона:** Клиент, сервер и NUI · **Ждёт:** нет

```ts title="Сигнатура"
groupDigits(value: number | string, separator?: string): string
```

```lua title="Lua"
local text = aiLib.numbers.groupDigits(value, separator)
```

#### Параметры

<TypeTable
  type={{
    value: { type: 'number | string', description: 'Число или число, уже записанное текстом.', required: true },
    separator: { type: 'string', description: 'Текст между группами (`"."` или `" "` для других языков).', default: '","' },
  }}
/>

#### Возвращает

`string`: число, разбитое на группы.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groupDigits } from "@aifivem/lib/shared";

groupDigits(1234567);        // "1,234,567"
groupDigits(-9876.5);        // "-9,876.5"
groupDigits(1500000, ".");   // "1.500.000"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.groupDigits(1234567)      -- "1,234,567"
aiLib.numbers.groupDigits(1500000, '.') -- "1.500.000"
```
</Tab>
</Tabs>

### formatWeight

Записывает вес в граммах так, как его читают игроки: меньше 1 кг в граммах, от 1 кг в килограммах с одним знаком после запятой (целые килограммы от 100 кг), цифры разбиты на группы.

**Сторона:** Клиент, сервер и NUI · **Ждёт:** нет

```ts title="Сигнатура"
formatWeight(grams: number): string
```

**Lua:** аналога нет.

#### Параметры

<TypeTable
  type={{
    grams: { type: 'number', description: 'Вес в граммах.', required: true },
  }}
/>

#### Возвращает

`string`: `"750 g"`, `"1.5 kg"`, `"1,250 kg"`.

#### Пример

```ts
import { formatWeight } from "@aifivem/lib/shared";

formatWeight(750);      // "750 g"
formatWeight(1500);     // "1.5 kg"
formatWeight(1250000);  // "1,250 kg"
```

## Случайность

### randomInt

Случайное целое число от `min` до `max`, оба включительно.

**Сторона:** Клиент, сервер и NUI · **Ждёт:** нет

```ts title="Сигнатура"
randomInt(min: number, max: number): number
```

**Lua:** аналога нет; используйте `math.random(min, max)`.

#### Параметры

<TypeTable
  type={{
    min: { type: 'number', description: 'Наименьший возможный результат (целое число).', required: true },
    max: { type: 'number', description: 'Наибольший возможный результат (целое число).', required: true },
  }}
/>

#### Возвращает

`number`: целое число от `min` до `max`.

#### Пример

```ts
import { randomInt } from "@aifivem/lib/shared";

const payout = randomInt(150, 300); // 150, 151, ... или 300
```

### pickRandom

Один случайный элемент списка.

**Сторона:** Клиент, сервер и NUI · **Ждёт:** нет

```ts title="Сигнатура"
pickRandom<T>(list: readonly T[]): T | undefined
```

**Lua:** аналога нет; используйте `list[math.random(#list)]`.

#### Параметры

<TypeTable
  type={{
    list: { type: 'readonly T[]', description: 'Элементы, из которых выбирать.', required: true },
  }}
/>

#### Возвращает

Один элемент или `undefined`, если список пуст.

#### Пример

```ts
import { pickRandom } from "@aifivem/lib/shared";

const loot = pickRandom(["goldbar", "rolex", "diamond"]) ?? "goldbar";
```

### rollChance

`true` с шансом `percent` из 100.

**Сторона:** Клиент, сервер и NUI · **Ждёт:** нет

```ts title="Сигнатура"
rollChance(percent: number): boolean
```

**Lua:** аналога нет; используйте `math.random() * 100 < percent`.

#### Параметры

<TypeTable
  type={{
    percent: { type: 'number', description: 'Шанс от 0 (никогда) до 100 (всегда).', required: true },
  }}
/>

#### Возвращает

`true` примерно `percent` раз из 100.

#### Пример

```ts title="resource/server/index.ts"
import { inventory } from "@aifivem/lib/server";
import { rollChance } from "@aifivem/lib/shared";

function useLockpick(source: number, slot: number): void {
  if (rollChance(25)) inventory.removeItem(source, "lockpick", 1, undefined, slot); // ломается в 1 случае из 4
}
```

<Callout type="warn">
Бросайте на сервере для всего, что даёт предметы или деньги. Бросок на клиенте читер может подделать.
</Callout>

## Время

### ServerClock

Часы сервера на клиенте, для обратных отсчётов, которые не зависят от собственных часов клиента. Экспортируется из `@aifivem/lib/shared` и не имеет Lua-аналога. Полный справочник (`sync`, `now`, `toLocal`, пример обратного отсчёта) находится на странице [Камера и время: ServerClock](/ru/docs/developers/api/lib-client/camera-and-timing#new-serverclock).
