Script’inin ayarları, sunucu sahibinin ai-core’un admin panelinde düzenlediği `data/*.json` dosyalarında durur (bkz. [Admin paneli](/tr/docs/developers/api/lib-server/admin-panel)). Panel değerleri `schema.ts`’ine göre kontrol eder, ama bir dosya yine de eski, elle düzenlenmiş ya da bir alanı eksik olabilir. Bu sayfadaki okuyucular **asla reddetmez**: eksik ya da yanlış bir değer verdiğin yedeği verir; böylece script her zaman başlar.

Bir client’ın gönderdiği değerler için bunun yerine [Aksiyonlar ve client girdisi](/tr/docs/developers/api/lib-shared/input) sayfasındaki katı okuyucuları kullan: onlar hatalı bir değeri reddeder.

```ts title="TypeScript"
import { num, int, bool, str, record, vec4, spec, readRecords, withoutSchemaKey } from "@aicore-fivem/lib/shared";
```

**Lua:** bunların hiçbirinin Lua karşılığı yok (admin paneli ve veri dosyaları yalnızca TypeScript’tir).

## Değer okuyucular

### num

`[min, max]` aralığına sıkıştırılmış sonlu bir sayı, yoksa yedek.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
num(value: unknown, fallback: number, min?: number, max?: number): number
```

#### Parametreler

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Dosyadan gelen ham değer.', required: true },
    fallback: { type: 'number', description: '`value` sonlu bir sayı değilse kullanılır.', required: true },
    min: { type: 'number', description: 'Daha küçük bir sayı buna yükseltilir.', default: '-Infinity' },
    max: { type: 'number', description: 'Daha büyük bir sayı buna düşürülür.', default: 'Infinity' },
  }}
/>

#### Dönüş değeri

`number`: aralığa sıkıştırılmış değer ya da `fallback` (sıkıştırılmaz).

#### Örnek

```ts
import { num } from "@aicore-fivem/lib/shared";

num(25, 2.5, 1, 20);      // 20 (sıkıştırıldı)
num("big", 2.5, 1, 20);   // 2.5 (yedek)
```

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
int(value: unknown, fallback: number, min?: number, max?: number): number
```

#### Parametreler

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Dosyadan gelen ham değer.', required: true },
    fallback: { type: 'number', description: '`value` sonlu bir sayı değilse kullanılır.', required: true },
    min: { type: 'number', description: 'En düşük sonuç.', default: '-Infinity' },
    max: { type: 'number', description: 'En yüksek sonuç.', default: 'Infinity' },

#### Dönüş değeri

#### Örnek

### record

Düz bir nesne olarak değer ya da boş bir nesne `{}`. Eksik olabilecek bir değerin alanlarını okumadan önce kullan.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
record(value: unknown): Record<string, unknown>
```

#### Parametreler

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Herhangi bir değer.', required: true },
  }}
/>

#### Dönüş değeri

Düz bir nesneyse `value`’nun kendisi, aksi halde yeni bir `{}` (diziler ve `null` için de).

#### Örnek

```ts
import { num, record } from "@aicore-fivem/lib/shared";

function readCoords(raw: unknown) {
  const c = record(raw); // alan eksikse {}
  return { x: num(c.x, 0), y: num(c.y, 0), z: num(c.z, 0) };
}
```

### vec4

Heading’li bir konum; eksik ya da yanlış her alan yedekten gelir.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
vec4(value: unknown, fallback: Vec4): Vec4
```

#### Parametreler

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Ham değer (`{ x, y, z, heading }`).', required: true },
    fallback: { type: 'Vec4', description: 'Eksik her alanın geldiği yer.', required: true, typeDescription: '{ x, y, z, heading }' },
  }}
/>

#### Dönüş değeri

Yeni bir [Vec4](/tr/docs/developers/api/types#vec4).

#### Örnek

```ts
import { vec4 } from "@aicore-fivem/lib/shared";

vec4({ x: 10, y: 20, z: 30 }, { x: 0, y: 0, z: 0, heading: 90 }); // { x: 10, y: 20, z: 30, heading: 90 }
```

## Şema yardımcıları

### spec

Panel `schema.ts`’indeki sayı alanları için kurucular; böylece aynı `DataSpec` nesnesini elle yazmazsın.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
spec.int(min: number, max: number, optional?: boolean): DataSpec
spec.num(min: number, max: number, optional?: boolean): DataSpec
```

#### Parametreler

<TypeTable
  type={{
    min: { type: 'number', description: 'Panelin kabul ettiği en düşük değer.', required: true },
    max: { type: 'number', description: 'Panelin kabul ettiği en yüksek değer.', required: true },
    optional: { type: 'boolean', description: '`true`: alan boş bırakılabilir.', default: 'false' },
  }}
/>

#### Dönüş değeri

`DataSpec`: `{ type: "number", min, max }`, artı `spec.int` için `integer: true` ve istendiğinde `optional: true`.

#### Örnek

```ts title="resource/server/schema.ts"
import { spec } from "@aicore-fivem/lib/shared";
import type { PanelSchema } from "@aicore-fivem/shared";

export const schema: PanelSchema = {
  title: "ADMIN_TITLE",
  icon: "store",
  files: {
    settings: {
      kind: "settings",
      sync: "admin",
      sections: {
        prices: { type: "object", fields: { water: spec.int(0, 1_000_000), tax: spec.num(0, 0.5) } },
      },
    },
  },
  tabs: [], // panel düzeni (kartlar ve alanlar), bkz. Admin paneli
};
```

### withoutSchemaKey

Bir veri dosyasının içeriğinden `"$schema"` anahtarını kaldırır. Anahtar yalnızca kod editörlerinin dosyayı kontrol edebilmesi için oradadır; okuyucun onu görmemelidir.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
withoutSchemaKey(value: unknown): unknown
```

#### Parametreler

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Ayrıştırılmış bir veri dosyası.', required: true },
  }}
/>

#### Dönüş değeri

Değer onu içeren bir nesneyse `$schema` olmadan bir kopya; aksi halde `value` değişmeden.

#### Örnek

```ts
import { withoutSchemaKey } from "@aicore-fivem/lib/shared";

withoutSchemaKey({ $schema: "./schemas/shops.schema.json", legion: { label: "Legion" } });
// { legion: { label: "Legion" } }
```

## Records dosyaları

Bir **records** dosyası anahtara göre çok sayıda girdi tutar (`{ "legion": {...}, "pillbox": {...} }`): marketler, garajlar, belediye binaları. Her girdi, yukarıdaki değer okuyucularıyla kurulan kendi okuyucu fonksiyonunla okunur (`RecordReader<T> = (key: string, raw: Record<string, unknown>) => T | null`).

### readRecords

Bütün bir records dosyasını okuyucun aracılığıyla bir kez, anahtar başına bir girdi olacak şekilde bir `Map`’e okur. Nesne olmayan ya da okuyucunun `null` döndürdüğü girdiler dışarıda bırakılır.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
readRecords<T>(raw: unknown, readOne: RecordReader<T>): Map<string, T>
```

#### Parametreler

<TypeTable
  type={{
    raw: { type: 'unknown', description: 'Ayrıştırılmış dosya (`{ key: record }`). Başka her şey boş bir map verir.', required: true },
    readOne: { type: '(key: string, raw: Record<string, unknown>) => T | null', description: 'Tek bir girdiyi okur. Onu dışarıda bırakmak için `null` döndür.', required: true },
  }}
/>

#### Dönüş değeri

`Map<string, T>`: anahtara göre ayrıştırılmış girdiler.

#### Örnek

```ts
import { readRecords, str, num, record } from "@aicore-fivem/lib/shared";

type Shop = { label: string; x: number; y: number; z: number };

const readShop = (key: string, v: Record<string, unknown>): Shop => {
  const c = record(v.coords);
  return { label: str(v.label, key, 48), x: num(c.x, 0), y: num(c.y, 0), z: num(c.z, 0) };
};

const shops = readRecords({ legion: { label: "Legion", coords: { x: 25.7, y: -1347.3, z: 29.5 } } }, readShop);
shops.get("legion"); // { label: "Legion", x: 25.7, y: -1347.3, z: 29.5 }
```

<Callout type="info">
Bir panel dosyası için `panel.records(file, readOne)` (server `AdminPanel`) ya da `world.records(file, readOne)` (client `AdminWorld`) tercih et: sahip düzenlerken güncel kalan ve yalnızca değişen girdiyi ayrıştıran bir map döndürürler.
</Callout>

### RecordObjects

Bir records dosyasının dünya nesnelerini (noktalar, blip’ler, ped’ler, bölgeler) her seferinde bir girdi olacak şekilde panelle uyumlu tutar: düzenlenen bir girdi yalnızca kendi nesnelerini yeniden kurar. `@aicore-fivem/lib/shared`’dan export edilir ve Lua karşılığı yoktur. Tam başvurusu (constructor, `build` fonksiyonu, `rebuild`, `rebuildAll`, örnek) [Etkileşim noktaları: RecordObjects](/tr/docs/developers/api/lib-client/points#new-recordobjects) sayfasındadır.
