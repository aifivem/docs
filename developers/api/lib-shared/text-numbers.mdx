Small helpers for what players read (money, weights, translated texts), random rolls, and countdowns that match the server's clock.

```ts title="TypeScript"
import { formatText, round, groupDigits, formatWeight, stripGameText, randomInt, pickRandom, rollChance, ServerClock } from "@aifivem/lib/shared";
```

## Text

### formatText

Fills `{0}`, `{1}`... placeholders in a text with values by position. A translation may move or repeat a placeholder (`"{1} paid {0}"`), which is why the values go by number, not by order.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
formatText(template: string, args: ReadonlyArray<string | number>): string
```

```lua title="Lua"
local text = aiLib.formatText(template, ...) -- values as separate arguments
```

#### Parameters

<TypeTable
  type={{
    template: { type: 'string', description: 'Text with `{0}`, `{1}`... placeholders.', required: true },
    args: { type: 'ReadonlyArray<string | number>', description: 'TypeScript: the values in one array, `{0}` is `args[0]`. Lua: the values as separate arguments after `template`.', required: true },
  }}
/>

#### Returns

`string`: the text with every placeholder that has a value filled in. A placeholder without a value stays as it is (`{2}`).

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { formatText } from "@aifivem/lib/shared";

formatText("You paid ${0} for {1} items", [250, 3]); // "You paid $250 for 3 items"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.formatText('You paid ${0} for {1} items', 250, 3) -- "You paid $250 for 3 items"
```
</Tab>
</Tabs>

<Callout type="info">
You rarely call it yourself: the locale helpers (`createLocale`, `aiLib.locale`, `LangTexts`) already fill placeholders. See [Locale](/docs/developers/api/lib-shared/locale).
</Callout>

### stripGameText

Makes text from another script plain: removes HTML tags, GTA colour and input codes (`~r~`, `~INPUT_PICKUP~`) and `&nbsp;`, folds runs of spaces and trims. Use it before you show another script's text in your own UI.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
stripGameText(text: unknown): string
```

```lua title="Lua"
local plain = aiLib.stripGameText(text)
```

#### Parameters

<TypeTable
  type={{
    text: { type: 'unknown', description: 'Any value. Non-strings are turned into text first.', required: true },
  }}
/>

#### Returns

`string`: the plain text. `""` for `null` / `undefined` (Lua: `nil`).

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { stripGameText } from "@aifivem/lib/shared";

stripGameText("Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~"); // "Press to open the shop"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.stripGameText('Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~') -- "Press to open the shop"
```
</Tab>
</Tabs>

## Numbers

### round

Rounds a number to a number of decimal places.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
round(value: number, decimals?: number): number
```

```lua title="Lua"
local rounded = aiLib.numbers.round(value, decimals)
```

#### Parameters

<TypeTable
  type={{
    value: { type: 'number', description: 'The number to round.', required: true },
    decimals: { type: 'number', description: 'Decimal places to keep.', default: '0' },
  }}
/>

#### Returns

`number`: the rounded value.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { round } from "@aifivem/lib/shared";

round(12.345, 1); // 12.3
round(12.5);      // 13
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.round(12.345, 1) -- 12.3
aiLib.numbers.round(12.5)      -- 13
```
</Tab>
</Tabs>

### groupDigits

Writes a number with a separator every three digits: `1234567` becomes `1,234,567`. Keeps the sign and the decimals. Use it for every amount of money players see.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
groupDigits(value: number | string, separator?: string): string
```

```lua title="Lua"
local text = aiLib.numbers.groupDigits(value, separator)
```

#### Parameters

<TypeTable
  type={{
    value: { type: 'number | string', description: 'The number, or a number already written as text.', required: true },
    separator: { type: 'string', description: 'Text put between groups (`"."` or `" "` for other languages).', default: '","' },
  }}
/>

#### Returns

`string`: the grouped number.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groupDigits } from "@aifivem/lib/shared";

groupDigits(1234567);        // "1,234,567"
groupDigits(-9876.5);        // "-9,876.5"
groupDigits(1500000, ".");   // "1.500.000"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.groupDigits(1234567)      -- "1,234,567"
aiLib.numbers.groupDigits(1500000, '.') -- "1.500.000"
```
</Tab>
</Tabs>

### formatWeight

Writes a weight in grams the way players read it: under 1 kg in grams, from 1 kg in kilograms with one decimal (whole kilograms from 100 kg), digits grouped.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
formatWeight(grams: number): string
```

**Lua:** no twin.

#### Parameters

<TypeTable
  type={{
    grams: { type: 'number', description: 'Weight in grams.', required: true },
  }}
/>

#### Returns

`string`: `"750 g"`, `"1.5 kg"`, `"1,250 kg"`.

#### Example

```ts
import { formatWeight } from "@aifivem/lib/shared";

formatWeight(750);      // "750 g"
formatWeight(1500);     // "1.5 kg"
formatWeight(1250000);  // "1,250 kg"
```

## Random

### randomInt

A random whole number from `min` to `max`, both included.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
randomInt(min: number, max: number): number
```

**Lua:** no twin; use `math.random(min, max)`.

#### Parameters

<TypeTable
  type={{
    min: { type: 'number', description: 'Lowest possible result (a whole number).', required: true },
    max: { type: 'number', description: 'Highest possible result (a whole number).', required: true },
  }}
/>

#### Returns

`number`: a whole number between `min` and `max`.

#### Example

```ts
import { randomInt } from "@aifivem/lib/shared";

const payout = randomInt(150, 300); // 150, 151, ... or 300
```

### pickRandom

One random item of a list.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
pickRandom<T>(list: readonly T[]): T | undefined
```

**Lua:** no twin; use `list[math.random(#list)]`.

#### Parameters

<TypeTable
  type={{
    list: { type: 'readonly T[]', description: 'The items to pick from.', required: true },
  }}
/>

#### Returns

One item, or `undefined` when the list is empty.

#### Example

```ts
import { pickRandom } from "@aifivem/lib/shared";

const loot = pickRandom(["goldbar", "rolex", "diamond"]) ?? "goldbar";
```

### rollChance

`true` with a chance of `percent` out of 100.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
rollChance(percent: number): boolean
```

**Lua:** no twin; use `math.random() * 100 < percent`.

#### Parameters

<TypeTable
  type={{
    percent: { type: 'number', description: 'Chance from 0 (never) to 100 (always).', required: true },
  }}
/>

#### Returns

`true` about `percent` times out of 100.

#### Example

```ts title="resource/server/index.ts"
import { inventory } from "@aifivem/lib/server";
import { rollChance } from "@aifivem/lib/shared";

function useLockpick(source: number, slot: number): void {
  if (rollChance(25)) inventory.removeItem(source, "lockpick", 1, undefined, slot); // breaks 1 in 4 times
}
```

<Callout type="warn">
Roll on the server for anything that gives items or money. A roll on the client can be forced by a cheater.
</Callout>

## Time

### ServerClock

The server's clock on a client, for countdowns that do not depend on the client's own clock. It is exported from `@aifivem/lib/shared` and has no Lua twin. Its full reference (`sync`, `now`, `toLocal`, countdown example) is on [Camera and timing: ServerClock](/docs/developers/api/lib-client/camera-and-timing#new-serverclock).
