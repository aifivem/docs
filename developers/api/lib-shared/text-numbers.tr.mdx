Oyuncuların okudukları (para, ağırlıklar, çevrilmiş metinler), rastgele zarlar ve server’ın saatiyle uyumlu geri sayımlar için küçük yardımcılar.

```ts title="TypeScript"
import { formatText, round, groupDigits, formatWeight, stripGameText, randomInt, pickRandom, rollChance, ServerClock } from "@aifivem/lib/shared";
```

## Metin

### formatText

Bir metindeki `{0}`, `{1}`... yer tutucularını konuma göre değerlerle doldurur. Bir çeviri bir yer tutucuyu taşıyabilir ya da tekrarlayabilir (`"{1} paid {0}"`); değerlerin sıraya göre değil numaraya göre gitmesinin sebebi budur.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
formatText(template: string, args: ReadonlyArray<string | number>): string
```

```lua title="Lua"
local text = aiLib.formatText(template, ...) -- değerler ayrı argümanlar olarak
```

#### Parametreler

<TypeTable
  type={{
    template: { type: 'string', description: '`{0}`, `{1}`... yer tutuculu metin.', required: true },
    args: { type: 'ReadonlyArray<string | number>', description: 'TypeScript: değerler tek bir dizide, `{0}` `args[0]`’dır. Lua: değerler `template`’ten sonra ayrı argümanlar olarak.', required: true },
  }}
/>

#### Dönüş değeri

`string`: değeri olan her yer tutucusu doldurulmuş metin. Değeri olmayan bir yer tutucu olduğu gibi kalır (`{2}`).

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { formatText } from "@aifivem/lib/shared";

formatText("You paid ${0} for {1} items", [250, 3]); // "You paid $250 for 3 items"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.formatText('You paid ${0} for {1} items', 250, 3) -- "You paid $250 for 3 items"
```
</Tab>
</Tabs>

<Callout type="info">
Onu nadiren kendin çağırırsın: dil yardımcıları (`createLocale`, `aiLib.locale`, `LangTexts`) yer tutucuları zaten doldurur. Bkz. [Dil](/tr/docs/developers/api/lib-shared/locale).
</Callout>

### stripGameText

Başka bir script’ten gelen metni düz hale getirir: HTML etiketlerini, GTA renk ve girdi kodlarını (`~r~`, `~INPUT_PICKUP~`) ve `&nbsp;`’yi kaldırır, art arda boşlukları birleştirir ve kırpar. Başka bir script’in metnini kendi arayüzünde göstermeden önce kullan.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
stripGameText(text: unknown): string
```

```lua title="Lua"
local plain = aiLib.stripGameText(text)
```

#### Parametreler

<TypeTable
  type={{
    text: { type: 'unknown', description: 'Herhangi bir değer. String olmayanlar önce metne çevrilir.', required: true },
  }}
/>

#### Dönüş değeri

`string`: düz metin. `null` / `undefined` için `""` (Lua: `nil`).

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { stripGameText } from "@aifivem/lib/shared";

stripGameText("Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~"); // "Press to open the shop"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.stripGameText('Press ~INPUT_CONTEXT~ to <b>open</b>  the ~g~shop~s~') -- "Press to open the shop"
```
</Tab>
</Tabs>

## Sayılar

### round

Bir sayıyı belirli sayıda ondalık basamağa yuvarlar.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
round(value: number, decimals?: number): number
```

```lua title="Lua"
local rounded = aiLib.numbers.round(value, decimals)
```

#### Parametreler

<TypeTable
  type={{
    value: { type: 'number', description: 'Yuvarlanacak sayı.', required: true },
    decimals: { type: 'number', description: 'Tutulacak ondalık basamak.', default: '0' },
  }}
/>

#### Dönüş değeri

`number`: yuvarlanmış değer.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { round } from "@aifivem/lib/shared";

round(12.345, 1); // 12.3
round(12.5);      // 13
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.round(12.345, 1) -- 12.3
aiLib.numbers.round(12.5)      -- 13
```
</Tab>
</Tabs>

### groupDigits

Bir sayıyı her üç basamakta bir ayırıcıyla yazar: `1234567`, `1,234,567` olur. İşareti ve ondalıkları korur. Oyuncuların gördüğü her para miktarı için kullan.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
groupDigits(value: number | string, separator?: string): string
```

```lua title="Lua"
local text = aiLib.numbers.groupDigits(value, separator)
```

#### Parametreler

<TypeTable
  type={{
    value: { type: 'number | string', description: 'Sayı ya da zaten metin olarak yazılmış bir sayı.', required: true },
    separator: { type: 'string', description: 'Gruplar arasına konan metin (diğer diller için `"."` ya da `" "`).', default: '","' },
  }}
/>

#### Dönüş değeri

`string`: gruplanmış sayı.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groupDigits } from "@aifivem/lib/shared";

groupDigits(1234567);        // "1,234,567"
groupDigits(-9876.5);        // "-9,876.5"
groupDigits(1500000, ".");   // "1.500.000"
```
</Tab>
<Tab value="Lua">
```lua
aiLib.numbers.groupDigits(1234567)      -- "1,234,567"
aiLib.numbers.groupDigits(1500000, '.') -- "1.500.000"
```
</Tab>
</Tabs>

### formatWeight

Gram cinsinden bir ağırlığı oyuncuların okuduğu şekilde yazar: 1 kg’ın altında gram, 1 kg’dan itibaren tek ondalıklı kilogram (100 kg’dan itibaren tam kilogram), basamaklar gruplanmış.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
formatWeight(grams: number): string
```

**Lua:** karşılığı yok.

#### Parametreler

<TypeTable
  type={{
    grams: { type: 'number', description: 'Gram cinsinden ağırlık.', required: true },
  }}
/>

#### Dönüş değeri

`string`: `"750 g"`, `"1.5 kg"`, `"1,250 kg"`.

#### Örnek

```ts
import { formatWeight } from "@aifivem/lib/shared";

formatWeight(750);      // "750 g"
formatWeight(1500);     // "1.5 kg"
formatWeight(1250000);  // "1,250 kg"
```

## Rastgele

### randomInt

`min` ile `max` arasında (ikisi de dahil) rastgele bir tam sayı.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
randomInt(min: number, max: number): number
```

**Lua:** karşılığı yok; `math.random(min, max)` kullan.

#### Parametreler

<TypeTable
  type={{
    min: { type: 'number', description: 'Mümkün olan en düşük sonuç (bir tam sayı).', required: true },
    max: { type: 'number', description: 'Mümkün olan en yüksek sonuç (bir tam sayı).', required: true },
  }}
/>

#### Dönüş değeri

`number`: `min` ile `max` arasında bir tam sayı.

#### Örnek

```ts
import { randomInt } from "@aifivem/lib/shared";

const payout = randomInt(150, 300); // 150, 151, ... ya da 300
```

### pickRandom

Bir listeden rastgele bir öğe.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
pickRandom<T>(list: readonly T[]): T | undefined
```

**Lua:** karşılığı yok; `list[math.random(#list)]` kullan.

#### Parametreler

<TypeTable
  type={{
    list: { type: 'readonly T[]', description: 'Seçilecek öğeler.', required: true },
  }}
/>

#### Dönüş değeri

Bir öğe ya da liste boşsa `undefined`.

#### Örnek

```ts
import { pickRandom } from "@aifivem/lib/shared";

const loot = pickRandom(["goldbar", "rolex", "diamond"]) ?? "goldbar";
```

### rollChance

100’de `percent` ihtimalle `true`.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
rollChance(percent: number): boolean
```

**Lua:** karşılığı yok; `math.random() * 100 < percent` kullan.

#### Parametreler

<TypeTable
  type={{
    percent: { type: 'number', description: '0 (asla) ile 100 (her zaman) arası ihtimal.', required: true },
  }}
/>

#### Dönüş değeri

100’de yaklaşık `percent` kez `true`.

#### Örnek

```ts title="resource/server/index.ts"
import { inventory } from "@aifivem/lib/server";
import { rollChance } from "@aifivem/lib/shared";

function useLockpick(source: number, slot: number): void {
  if (rollChance(25)) inventory.removeItem(source, "lockpick", 1, undefined, slot); // 4’te 1 kırılır
}
```

<Callout type="warn">
Eşya ya da para veren her şey için zarı server’da at. Client’taki bir zar bir hileci tarafından zorlanabilir.
</Callout>

## Zaman

### ServerClock

Client’ın kendi saatine bağlı olmayan geri sayımlar için, server’ın saati client’ta. `@aifivem/lib/shared`’dan export edilir ve Lua karşılığı yoktur. Tam başvurusu (`sync`, `now`, `toLocal`, geri sayım örneği) [Kamera ve zamanlama: ServerClock](/tr/docs/developers/api/lib-client/camera-and-timing#new-serverclock) sayfasındadır.
