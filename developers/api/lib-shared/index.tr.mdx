Lib’in iki parçası client’ta ve server’da aynı şekilde çalışır:

| Giriş | Ne içerir | Nerede kullanabilirsin |
| --- | --- | --- |
| `@aicore-fivem/lib/shared` | Hiçbir zaman FiveM native’i çağırmayan düz yardımcılar: reddetmeler, girdi okuyucular, sayı ve metin biçimlendirme, vektör matematiği, bölge geometrisi, panel verisi okuyucuları, bir NUI sayfasının dil metinleri. | Client, server, `resource/common/` ve NUI (React) kodu. |
| `@aicore-fivem/lib/fivem` | İki tarafta da var olan native’leri çağıran yardımcılar: resource’lar arası export’lar, zamanlayıcı, resource durdurma işleme, dil dosyası yükleyicisi. | Client, server ve `resource/common/`. NUI kodunda değil. |

Client ve server girişleri `/fivem`’deki her şeyi yeniden export eder; bu yüzden bir client ya da server dosyasında bu yardımcıları `@aicore-fivem/lib/client` ya da `@aicore-fivem/lib/server`’dan da import edebilirsin. `/fivem`’i yalnızca iki tarafın da paketlediği `resource/common/` dosyalarında kullan.

```ts title="TypeScript"
import { fail, readInt, groupDigits } from "@aicore-fivem/lib/shared";
import { resourceExport, every, createLocale } from "@aicore-fivem/lib/fivem";
```

## Lua

Bu yardımcıların yalnızca birkaçının `aiLib` üzerinde bir Lua karşılığı vardır (onu `shared_script '@ai-lib/init.lua'` ile yükle, bkz. [Lua için lib](/tr/docs/developers/api/lua)): `every`, `waitFor`, `formatText`, `locale`, `fail`, `numbers.round`, `numbers.groupDigits`, `numbers.headingTo` ve `stripGameText`. Her girdi, varsa Lua çağrısını gösterir, yoksa bunu belirtir. Geri kalanı için Lua’nın kendi araçları vardır: vektör matematiği (mesafe için `#(a - b)`), state bag’ler için `Entity(e).state`, export’lar için `exports['name']:Fn()`.
