Duas partes da lib funcionam tanto no cliente quanto no servidor:

| Entrada | O que contém | Onde você pode usar |
| --- | --- | --- |
| `@aifivem/lib/shared` | Helpers simples que nunca chamam uma native do FiveM: recusas, leitores de entrada, formatação de números e textos, matemática de vetores, geometria de zonas, leitores de dados do painel, os textos de idioma de uma página NUI. | Código de cliente, de servidor, de `resource/common/` e de NUI (React). |
| `@aifivem/lib/fivem` | Helpers que chamam natives existentes nos dois lados: exports entre recursos, o agendador, o tratamento da parada do recurso, o carregador do arquivo de idioma. | Cliente, servidor e `resource/common/`. Não em código de NUI. |

As entradas de cliente e de servidor reexportam tudo de `/fivem`, então em um arquivo de cliente ou de servidor você também pode importar esses helpers de `@aifivem/lib/client` ou `@aifivem/lib/server`. Use `/fivem` só em arquivos de `resource/common/` que os dois lados empacotam.

```ts title="TypeScript"
import { fail, readInt, groupDigits } from "@aifivem/lib/shared";
import { resourceExport, every, createLocale } from "@aifivem/lib/fivem";
```

## Lua

Só alguns destes helpers têm um equivalente em Lua no `aiLib` (carregue-o com `shared_script '@ai-lib/init.lua'`, veja [Lib para Lua](/pt/docs/developers/api/lua)): `every`, `waitFor`, `formatText`, `locale`, `fail`, `numbers.round`, `numbers.groupDigits`, `numbers.headingTo` e `stripGameText`. Cada entrada mostra a chamada Lua quando existe, e informa quando não existe. Lua tem as próprias ferramentas para o resto: matemática de vetores (`#(a - b)` para uma distância), `Entity(e).state` para state bags, `exports['name']:Fn()` para exports.
