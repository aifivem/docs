Your script's settings live in `data/*.json` files the server owner edits in ai-core's admin panel (see [Admin panel](/docs/developers/api/lib-server/admin-panel)). The panel checks values against your `schema.ts`, but a file can still be old, hand-edited or missing a field. The readers on this page **never refuse**: a missing or wrong value gives the fallback you pass, so the script always starts.

For values a client sends, use the strict readers on [Actions and client input](/docs/developers/api/lib-shared/input) instead: those refuse a bad value.

```ts title="TypeScript"
import { num, int, bool, str, record, vec4, spec, readRecords, withoutSchemaKey } from "@aifivem/lib/shared";
```

**Lua:** none of these have a Lua twin (the admin panel and its data files are TypeScript only).

## Value readers

### num

A finite number clamped to `[min, max]`, else the fallback.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
num(value: unknown, fallback: number, min?: number, max?: number): number
```

#### Parameters

<TypeTable
  type={{
    value: { type: 'unknown', description: 'The raw value from the file.', required: true },
    fallback: { type: 'number', description: 'Used when `value` is not a finite number.', required: true },
    min: { type: 'number', description: 'A smaller number is raised to this.', default: '-Infinity' },
    max: { type: 'number', description: 'A larger number is lowered to this.', default: 'Infinity' },
  }}
/>

#### Returns

`number`: the value clamped into the range, or `fallback` (not clamped).

#### Example

```ts
import { num } from "@aifivem/lib/shared";

num(25, 2.5, 1, 20);      // 20 (clamped)
num("big", 2.5, 1, 20);   // 2.5 (fallback)
```

### int

Like `num`, then rounded to a whole number.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
int(value: unknown, fallback: number, min?: number, max?: number): number
```

#### Parameters

<TypeTable
  type={{
    value: { type: 'unknown', description: 'The raw value from the file.', required: true },
    fallback: { type: 'number', description: 'Used when `value` is not a finite number.', required: true },
    min: { type: 'number', description: 'Lowest result.', default: '-Infinity' },
    max: { type: 'number', description: 'Highest result.', default: 'Infinity' },
  }}
/>

#### Returns

`number`: a whole number (the fallback is rounded too).

#### Example

```ts
import { int } from "@aifivem/lib/shared";

int(12.6, 10, 0, 100); // 13
int(null, 10, 0, 100); // 10
```

### bool

A boolean, else the fallback.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
bool(value: unknown, fallback: boolean): boolean
```

#### Parameters

<TypeTable
  type={{
    value: { type: 'unknown', description: 'The raw value from the file.', required: true },
    fallback: { type: 'boolean', description: 'Used when `value` is not `true` or `false`.', required: true },
  }}
/>

`boolean`.

#### Example

### str

A trimmed, non-empty string cut to `max` characters, else the fallback.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
str(value: unknown, fallback: string, max?: number): string
```

#### Parameters

<TypeTable
  type={{
    value: { type: 'unknown', description: 'The raw value from the file.', required: true },
    fallback: { type: 'string', description: 'Used when `value` is not a string or is empty after trimming.', required: true },
    max: { type: 'number', description: 'Most characters kept.', default: '64' },
  }}
/>

#### Returns

`string`.

#### Example

```ts
import { str } from "@aifivem/lib/shared";

str("  City Hall ", "Hall", 48); // "City Hall"
str("", "Hall", 48);             // "Hall"
```

### record

The value as a plain object, or an empty object `{}`. Use it before reading fields of a value that may be missing.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
record(value: unknown): Record<string, unknown>
```

#### Parameters

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Any value.', required: true },
  }}
/>

#### Returns

`value` itself when it is a plain object, otherwise a new `{}` (also for arrays and `null`).

#### Example

```ts
import { num, record } from "@aifivem/lib/shared";

function readCoords(raw: unknown) {
  const c = record(raw); // {} when the field is missing
  return { x: num(c.x, 0), y: num(c.y, 0), z: num(c.z, 0) };
}
```

### vec4

A position with heading; each missing or wrong field comes from the fallback.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
vec4(value: unknown, fallback: Vec4): Vec4
```

#### Parameters

<TypeTable
  type={{
    value: { type: 'unknown', description: 'The raw value (`{ x, y, z, heading }`).', required: true },
    fallback: { type: 'Vec4', description: 'Where each missing field comes from.', required: true, typeDescription: '{ x, y, z, heading }' },
  }}
/>

#### Returns

A new [Vec4](/docs/developers/api/types#vec4).

#### Example

```ts
import { vec4 } from "@aifivem/lib/shared";

vec4({ x: 10, y: 20, z: 30 }, { x: 0, y: 0, z: 0, heading: 90 }); // { x: 10, y: 20, z: 30, heading: 90 }
```

## Schema helpers

### spec

Builders for number fields in your panel `schema.ts`, so you do not write the same `DataSpec` object by hand.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
spec.int(min: number, max: number, optional?: boolean): DataSpec
spec.num(min: number, max: number, optional?: boolean): DataSpec
```

#### Parameters

<TypeTable
  type={{
    min: { type: 'number', description: 'Lowest value the panel accepts.', required: true },
    max: { type: 'number', description: 'Highest value the panel accepts.', required: true },
    optional: { type: 'boolean', description: '`true`: the field may be left empty.', default: 'false' },
  }}
/>

#### Returns

`DataSpec`: `{ type: "number", min, max }`, plus `integer: true` for `spec.int` and `optional: true` when asked.

#### Example

```ts title="resource/server/schema.ts"
import { spec } from "@aifivem/lib/shared";
import type { PanelSchema } from "@aifivem/shared";

export const schema: PanelSchema = {
  title: "ADMIN_TITLE",
  icon: "store",
  files: {
    settings: {
      kind: "settings",
      sync: "admin",
      sections: {
        prices: { type: "object", fields: { water: spec.int(0, 1_000_000), tax: spec.num(0, 0.5) } },
      },
    },
  },
  tabs: [], // the panel layout (cards and fields), see Admin panel
};
```

### withoutSchemaKey

Removes the `"$schema"` key from a data file's content. The key is only there so code editors can check the file; your reader should not see it.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
withoutSchemaKey(value: unknown): unknown
```

#### Parameters

<TypeTable
  type={{
    value: { type: 'unknown', description: 'A parsed data file.', required: true },
  }}
/>

#### Returns

A copy without `$schema` when the value is an object that has it; otherwise `value` unchanged.

#### Example

```ts
import { withoutSchemaKey } from "@aifivem/lib/shared";

withoutSchemaKey({ $schema: "./schemas/shops.schema.json", legion: { label: "Legion" } });
// { legion: { label: "Legion" } }
```

## Records files

A **records** file holds many entries by key (`{ "legion": {...}, "pillbox": {...} }`): shops, garages, city halls. Each entry is read by your own reader function (`RecordReader<T> = (key: string, raw: Record<string, unknown>) => T | null`), built from the value readers above.

### readRecords

Reads a whole records file once into a `Map`, one entry per key, through your reader. Entries that are not objects, or for which your reader returns `null`, are left out.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
readRecords<T>(raw: unknown, readOne: RecordReader<T>): Map<string, T>
```

#### Parameters

<TypeTable
  type={{
    raw: { type: 'unknown', description: 'The parsed file (`{ key: record }`). Anything else gives an empty map.', required: true },
    readOne: { type: '(key: string, raw: Record<string, unknown>) => T | null', description: 'Reads one entry. Return `null` to leave it out.', required: true },
  }}
/>

#### Returns

`Map<string, T>`: the parsed entries by key.

#### Example

```ts
import { readRecords, str, num, record } from "@aifivem/lib/shared";

type Shop = { label: string; x: number; y: number; z: number };

const readShop = (key: string, v: Record<string, unknown>): Shop => {
  const c = record(v.coords);
  return { label: str(v.label, key, 48), x: num(c.x, 0), y: num(c.y, 0), z: num(c.z, 0) };
};

const shops = readRecords({ legion: { label: "Legion", coords: { x: 25.7, y: -1347.3, z: 29.5 } } }, readShop);
shops.get("legion"); // { label: "Legion", x: 25.7, y: -1347.3, z: 29.5 }
```

<Callout type="info">
For a panel file, prefer `panel.records(file, readOne)` (server `AdminPanel`) or `world.records(file, readOne)` (client `AdminWorld`): they return a map that stays current while the owner edits, parsing only the changed entry.
</Callout>

### RecordObjects

Keeps the world objects of a records file (points, blips, peds, zones) in step with the panel, one entry at a time: an edited entry rebuilds only its own objects. It is exported from `@aifivem/lib/shared` and has no Lua twin. Its full reference (constructor, `build` function, `rebuild`, `rebuildAll`, example) is on [Interaction points: RecordObjects](/docs/developers/api/lib-client/points#new-recordobjects).
