## Placas

O GTA completa as placas até 8 caracteres com espaços (`"  AI 1  "`). Todo script que guarda dados por placa (chaves, combustível, garagens) usa a placa **sem espaços nas pontas e em maiúsculas** como chave, para que o mesmo veículo combine em todo lugar.

### plateOf

A placa de um veículo como as chaves a usam: lida da entidade, sem espaços nas pontas, em maiúsculas.

**Lado:** Cliente e servidor · **Espera:** não

```ts title="Signature"
plateOf(vehicle: number): string
```

**Lua:** sem equivalente; use `GetVehicleNumberPlateText(vehicle):match('^%s*(.-)%s*$'):upper()`.

#### Parâmetros

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Handle da entidade do veículo (no servidor: uma entidade do servidor).', required: true },
  }}
/>

#### Retorno

`string`: a placa, sem espaços nas pontas e em maiúsculas.

#### Exemplo

```ts title="resource/server/index.ts"
import { plateOf, vehicleOf } from "@aicore-fivem/lib/server";

function plateOfPlayerVehicle(source: number): string | null {
  const vehicle = vehicleOf(source);
  return vehicle === 0 ? null : plateOf(vehicle);
}
```

### normalizePlate

O mesmo corte de espaços e maiúsculas para uma placa que você já tem como texto (digitada por um jogador, guardada em um banco de dados, enviada por outro script).

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
normalizePlate(plate: string): string
```

**Lua:** sem equivalente; use `plate:match('^%s*(.-)%s*$'):upper()`.

#### Parâmetros

<TypeTable
  type={{
    plate: { type: 'string', description: 'Texto da placa em qualquer forma.', required: true },
  }}
/>

#### Retorno

`string`: sem espaços nas pontas, em maiúsculas.

#### Exemplo

```ts
import { normalizePlate } from "@aicore-fivem/lib/shared";

normalizePlate("  ai 123 "); // "AI 123"
```

## Spawn

### vehicleTypeOfClass

Transforma uma classe de veículo do GTA (`GetVehicleClassFromName`) no tipo de que `CreateVehicleServerSetter` precisa: `"bike"`, `"boat"`, `"heli"`, `"plane"`, `"train"` ou `"automobile"`. O `spawnVehicle` da lib faz isso para você; use só quando você mesmo chama `CreateVehicleServerSetter`.

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
vehicleTypeOfClass(vehicleClass: number): string
```

**Lua:** sem equivalente.

#### Parâmetros

<TypeTable
  type={{
    vehicleClass: { type: 'number', description: 'Classe de veículo do GTA 0-22. As classes 8 (motos) e 13 (bicicletas) são bikes, 14 barcos, 15 helicópteros, 16 aviões, 21 trens.', required: true },
  }}
/>

#### Retorno

`string`: o tipo de spawn. Toda classe não listada acima é `"automobile"`.

#### Exemplo

```ts title="resource/client/index.ts"
import { vehicleTypeOfClass } from "@aicore-fivem/lib/shared";

const type = vehicleTypeOfClass(GetVehicleClassFromName("frogger")); // "heli"
```

<Callout type="info">
`GetVehicleClassFromName` é uma native de cliente. O servidor descobre o tipo de um modelo a partir de um cliente (o `spawnVehicle` da lib pergunta ao cliente do ai-core por você).
</Callout>

## Visuais a partir de dados não confiáveis

### toVehicleProps

Verifica props de veículo guardadas ou recebidas e retorna um objeto [VehicleProps](/pt/docs/developers/api/types#vehicleprops) limpo, ou `null` quando os dados não estão nesse formato. Partes opcionais ausentes recebem padrões (mods de fábrica, sem livery, vida cheia); campos desconhecidos são descartados; a placa é cortada em 8 caracteres.

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
toVehicleProps(value: unknown): VehicleProps | null
```

**Lua:** sem equivalente.

#### Parâmetros

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Props vindas do banco de dados, de um state bag, de uma chamada de export ou de um cliente.', required: true },
  }}
/>

#### Retorno

`VehicleProps`, ou `null` quando `value` não é um objeto, `v` não é `1`, `model` ou `plate` está ausente, ou um de `colors`, `extraColors`, `neonColor`, `tyreSmoke`, `mods`, `extras`, `neon` está ausente ou com o tamanho errado.

#### Exemplo

```ts title="resource/server/index.ts"
import { optionalExport } from "@aicore-fivem/lib/server";
import { toVehicleProps } from "@aicore-fivem/lib/shared";

function storedColors(vehicleId: number): [number, number] | null {
  const vehicle = optionalExport("ai-vehicles")?.GetVehicle(vehicleId);
  const props = toVehicleProps(vehicle?.props);
  return props ? props.colors : null;
}
```

### toVehicleSetup

Verifica um [VehicleSetup](/pt/docs/developers/api/types#vehiclesetup) recebido campo por campo: campos errados são descartados, os certos mantidos. Use em uma configuração que vem de um cliente ou de outro recurso antes de passá-la para `spawnVehicle`.

**Lado:** Cliente, servidor e NUI · **Espera:** não

```ts title="Signature"
toVehicleSetup(value: unknown): VehicleSetup | null
```

**Lua:** sem equivalente.

#### Parâmetros

<TypeTable
  type={{
    value: { type: 'unknown', description: 'A configuração a verificar.', required: true },
  }}
/>

#### Retorno

`VehicleSetup` só com os campos válidos (cores 0-255, `livery` 0-100, `windowTint` 0-6, `dirt` 0-15; `maxed` e `engineOn` só quando exatamente `true`). `null` quando `value` não é um objeto.

#### Exemplo

```ts
import { toVehicleSetup } from "@aicore-fivem/lib/shared";

toVehicleSetup({ colors: [27, 27], windowTint: 9, maxed: "yes" });
// { colors: [27, 27], windowTint: undefined, maxed: undefined, ... }: os campos inválidos são descartados
```

<Callout type="warn">
Um cliente nunca deve escolher `maxed: true` ou uma cor livre para um veículo pelo qual paga: verifique no servidor o preço do que a configuração contém.
</Callout>
