Obliczenia na punktach zapisanych jako zwykłe obiekty ([Vec3](/pl/docs/developers/api/types#vec3): `{ x, y, z }` w metrach). Nie potrzebują natywek, więc ten sam kod działa na serwerze, na kliencie i na stronie NUI.

```ts title="TypeScript"
import { distance, flatDistance, headingTo, nearestOf, gridCell, cellKey } from "@aifivem/lib/shared";
```

<Callout type="info">
Lua ma wbudowaną matematykę wektorów: `#(a - b)` to odległość między dwoma `vector3`, `#(a.xy - b.xy)` to odległość po ziemi. Tylko `headingTo` ma odpowiednik w Lua (`aiLib.numbers.headingTo`).
</Callout>

### distance

Odległość w linii prostej między dwoma punktami, w metrach.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
distance(a: Vec3, b: Vec3): number
```

**Lua:** brak odpowiednika; użyj `#(a - b)` z dwoma `vector3`.

#### Parametry

<TypeTable
  type={{
    a: { type: 'Vec3', description: 'Pierwszy punkt.', required: true },
    b: { type: 'Vec3', description: 'Drugi punkt.', required: true },
  }}
/>

#### Zwracana wartość

`number`: metry, 0 lub więcej.

#### Przykład

```ts title="resource/server/index.ts"
import { coordsOf } from "@aifivem/lib/server";
import { distance } from "@aifivem/lib/shared";

const counter = { x: 25.7, y: -1347.3, z: 29.5 };

function nearCounter(source: number): boolean {
  return distance(coordsOf(source), counter) <= 3;
}
```

### flatDistance

Odległość na płaszczyźnie ziemi, z pominięciem wysokości (tylko `x` i `y`), w metrach. Używaj jej dla obszarów, w których wysokość nie ma znaczenia (parking na zboczu, promień blipa).

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
flatDistance(a: { x: number; y: number }, b: { x: number; y: number }): number
```

**Lua:** brak odpowiednika; użyj `#(a.xy - b.xy)`.

#### Parametry

<TypeTable
  type={{
    a: { type: '{ x: number; y: number }', description: 'Pierwszy punkt (`Vec3` też działa).', required: true },
    b: { type: '{ x: number; y: number }', description: 'Drugi punkt.', required: true },
  }}
/>

#### Zwracana wartość

`number`: metry na płaszczyźnie ziemi.

#### Przykład

```ts
import { flatDistance } from "@aifivem/lib/shared";

flatDistance({ x: 0, y: 0, z: 0 }, { x: 3, y: 4, z: 50 }); // 5
```

### headingTo

Kierunek, który patrzy z jednego punktu na drugi, w konwencji GTA: 0-360 stopni, 0 = północ, przeciwnie do ruchu wskazówek zegara. Używaj go, żeby obrócić peda albo kamerę w stronę czegoś.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
headingTo(from: { x: number; y: number }, to: { x: number; y: number }): number
```

```lua title="Lua"
local heading = aiLib.numbers.headingTo(from, to) -- vector3 albo tabele { x, y }
```

#### Parametry

<TypeTable
  type={{
    from: { type: '{ x: number; y: number }', description: 'Gdzie stoi ped albo kamera.', required: true },
    to: { type: '{ x: number; y: number }', description: 'W co ma patrzeć.', required: true },
  }}
/>

#### Zwracana wartość

`number`: kierunek od 0 do 360 (bez 360).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { cache, player } from "@aifivem/lib/client";
import { headingTo } from "@aifivem/lib/shared";

const counter = { x: 25.7, y: -1347.3, z: 29.5 };
SetEntityHeading(cache.ped, headingTo(player.coords(), counter));
```
</Tab>
<Tab value="Lua">
```lua
local counter = vector3(25.7, -1347.3, 29.5)
SetEntityHeading(aiLib.cache.ped, aiLib.numbers.headingTo(aiLib.player.coords(), counter))
```
</Tab>
</Tabs>

### nearestOf

Element listy najbliższy punktowi (odległość 3D), w opcjonalnym zasięgu. Działa dla każdej listy: mówisz, jak odczytać pozycję elementu.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
nearestOf<T>(items: Iterable<T>, point: Vec3, pos: (item: T) => Vec3, max?: number): T | undefined
```

**Lua:** brak odpowiednika.

#### Parametry

<TypeTable
  type={{
    items: { type: 'Iterable<T>', description: 'Kandydaci (tablica, `map.values()`...).', required: true },
    point: { type: 'Vec3', description: 'Punkt, od którego się mierzy.', required: true },
    pos: { type: '(item: T) => Vec3', description: 'Odczytuje pozycję jednego elementu.', required: true },
    max: { type: 'number', description: 'Największa odległość w metrach, na jakiej może być element.', default: 'Infinity' },
  }}
/>

#### Zwracana wartość

Najbliższy element albo `undefined`, gdy lista jest pusta albo każdy element jest dalej niż `max`.

#### Przykład

```ts title="resource/server/index.ts"
import { coordsOf } from "@aifivem/lib/server";
import { nearestOf, type Vec3 } from "@aifivem/lib/shared";

const atms: Array<{ id: string; coords: Vec3 }> = [
  { id: "legion", coords: { x: 147.4, y: -1035.8, z: 29.3 } },
  { id: "pillbox", coords: { x: 296.2, y: -591.6, z: 43.3 } },
];

function atmNear(source: number) {
  return nearestOf(atms, coordsOf(source), (atm) => atm.coords, 2);
}
```

### gridCell

Całkowitoliczbowa komórka siatki, w którą wpada punkt, na siatce kwadratów o boku `size` metrów. Strumieniowanie obszarów liba (`AreaStream` na serwerze, `AreaFollower` na kliencie) jej używa, więc obie strony zgadzają się, w której komórce jest punkt. Komórki są ograniczone do plus minus 16 000.

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
gridCell(x: number, y: number, size: number): { cx: number; cy: number }
```

**Lua:** brak odpowiednika.

#### Parametry

<TypeTable
  type={{
    x: { type: 'number', description: 'x punktu w metrach.', required: true },
    y: { type: 'number', description: 'y punktu w metrach.', required: true },
    size: { type: 'number', description: 'Rozmiar komórki w metrach.', required: true },
  }}
/>

#### Zwracana wartość

`{ cx, cy }`: kolumna i wiersz komórki.

#### Przykład

```ts
import { gridCell, cellKey } from "@aifivem/lib/shared";

const { cx, cy } = gridCell(147.4, -1035.8, 100); // { cx: 1, cy: -11 }
const key = cellKey(cx, cy);
```

### cellKey

Jedna liczba dla komórki siatki, na tyle mała, żeby była szybkim kluczem `Map` (poniżej 2^30).

**Strona:** Klient, serwer i NUI · **Czeka:** nie

```ts title="Sygnatura"
cellKey(cx: number, cy: number): number
```

**Lua:** brak odpowiednika.

#### Parametry

<TypeTable
  type={{
    cx: { type: 'number', description: 'Kolumna komórki z `gridCell`.', required: true },
    cy: { type: 'number', description: 'Wiersz komórki z `gridCell`.', required: true },
  }}
/>

#### Zwracana wartość

`number`: ta sama liczba dla tej samej komórki, po każdej stronie.

#### Przykład

```ts
import { gridCell, cellKey } from "@aifivem/lib/shared";

const byCell = new Map<number, string[]>();

function addSign(id: string, x: number, y: number): void {
  const { cx, cy } = gridCell(x, y, 100);
  const key = cellKey(cx, cy);
  byCell.set(key, [...(byCell.get(key) ?? []), id]);
}
```
