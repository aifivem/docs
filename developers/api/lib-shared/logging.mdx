These helpers write to the **console** (F8 on a client, the server console or txAdmin on the server). For logs the server owner reads in Discord, Fivemanage or FiveM Stats, use `aiLog` instead (see [Logs](/docs/developers/api/lib-server/logs)).

```ts title="TypeScript"
import { createLogger, logSafe, previewJson } from "@aifivem/lib/shared";
```

### createLogger

Returns a logger whose lines start with `[your-resource]`, so the server console shows where each line came from. Warnings are yellow, errors red.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
createLogger(resource: string): Logger
```

**Lua:** no twin; use `print(('[%s] %s'):format(GetCurrentResourceName(), message))`.

#### Parameters

<TypeTable
  type={{
    resource: { type: 'string', description: 'The name in front of every line, usually `GetCurrentResourceName()`.', required: true },
  }}
/>

#### Returns

`Logger`:

<TypeTable
  type={{
    'info(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'A normal line (`console.log`).' },
    'warn(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'A yellow line (`console.warn`).' },
    'error(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'A red line (`console.error`). Pass the error as a detail to print its stack.' },
  }}
/>

#### Example

```ts title="resource/server/index.ts"
import { createLogger } from "@aifivem/lib/shared";

const log = createLogger(GetCurrentResourceName());

log.info("loaded 12 shops");               // [my-shop] loaded 12 shops
log.warn("shop legion has no ped model");  // yellow
try {
  JSON.parse("{");
} catch (error) {
  log.error("could not read shops.json", error); // red, with the error
}
```

### logSafe

Makes text a client sent safe for the server console: one line (line breaks become ` | `), no control characters, no `^1` colour codes, cut to `max` characters. Use it whenever a log line contains a player's text (a name, a message, a note).

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
logSafe(text: string, max: number): string
```

**Lua:** no twin.

#### Parameters

<TypeTable
  type={{
    text: { type: 'string', description: 'The untrusted text.', required: true },
    max: { type: 'number', description: 'Most characters kept.', required: true },
  }}
/>

#### Returns

`string`: the cleaned text.

#### Example

```ts
import { logSafe } from "@aifivem/lib/shared";

logSafe("^1fake error\nsecond line", 100); // "fake error | second line"
```

<Callout type="warn">
Without it, a player can write a chat message with `^1` colour codes and line breaks that looks like a real server error in your console.
</Callout>

### previewJson

A short JSON-like text of any untrusted value, cut at `max` characters, built **without** serializing the whole value first (a hostile payload can be megabytes). Nesting deeper than 4 levels shows as `[...]` / `{...}`. Use it to print what a client sent when you refuse it.

**Side:** Client, server and NUI · **Waits:** no

```ts title="Signature"
previewJson(value: unknown, max: number): string
```

**Lua:** no twin.

#### Parameters

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Anything: the raw arguments of a refused call.', required: true },
    max: { type: 'number', description: 'Most characters in the result.', required: true },
  }}
/>

#### Returns

`string`: the preview, at most `max` characters. Object keys are cut to 50 characters.

#### Example

```ts title="resource/server/index.ts"
import { onClientEvent } from "@aifivem/lib/server";
import { createLogger, logSafe, previewJson } from "@aifivem/lib/shared";

const log = createLogger(GetCurrentResourceName());

onClientEvent("my-shop:rate", (source) => {
  log.info(`${logSafe(GetPlayerName(String(source)) ?? "?", 32)} opened the rating`);
});

function refuse(source: number, raw: unknown[]): void {
  log.warn(`refused input from ${source}: ${previewJson(raw, 200)}`);
}
```
