Bu yardımcılar **konsola** yazar (client’ta F8, server’da server konsolu ya da txAdmin). Sunucu sahibinin Discord’da, Fivemanage’da ya da FiveM Stats’te okuduğu loglar için bunun yerine `aiLog` kullan (bkz. [Loglar](/tr/docs/developers/api/lib-server/logs)).

```ts title="TypeScript"
import { createLogger, logSafe, previewJson } from "@aifivem/lib/shared";
```

### createLogger

Satırları `[your-resource]` ile başlayan bir logger döndürür; böylece server konsolu her satırın nereden geldiğini gösterir. Uyarılar sarı, hatalar kırmızıdır.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
createLogger(resource: string): Logger
```

**Lua:** karşılığı yok; `print(('[%s] %s'):format(GetCurrentResourceName(), message))` kullan.

#### Parametreler

<TypeTable
  type={{
    resource: { type: 'string', description: 'Her satırın önündeki ad, genellikle `GetCurrentResourceName()`.', required: true },
  }}
/>

#### Dönüş değeri

`Logger`:

<TypeTable
  type={{
    'info(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'Normal bir satır (`console.log`).' },
    'warn(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'Sarı bir satır (`console.warn`).' },
    'error(message, ...details)': { type: '(message: string, ...details: unknown[]) => void', description: 'Kırmızı bir satır (`console.error`). Stack’ini yazdırmak için hatayı bir detay olarak geçir.' },
  }}
/>

#### Örnek

```ts title="resource/server/index.ts"
import { createLogger } from "@aifivem/lib/shared";

const log = createLogger(GetCurrentResourceName());

log.info("loaded 12 shops");               // [my-shop] loaded 12 shops
log.warn("shop legion has no ped model");  // sarı
try {
  JSON.parse("{");
} catch (error) {
  log.error("could not read shops.json", error); // kırmızı, hatayla birlikte
}
```

### logSafe

Bir client’ın gönderdiği metni server konsolu için güvenli hale getirir: tek satır (satır sonları ` | ` olur), kontrol karakterleri yok, `^1` renk kodları yok, `max` karaktere kesilir. Bir log satırı bir oyuncunun metnini (bir ad, bir mesaj, bir not) içerdiğinde her zaman kullan.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
logSafe(text: string, max: number): string
```

**Lua:** karşılığı yok.

#### Parametreler

<TypeTable
  type={{
    text: { type: 'string', description: 'Güvenilmeyen metin.', required: true },
    max: { type: 'number', description: 'Tutulan en fazla karakter.', required: true },
  }}
/>

#### Dönüş değeri

`string`: temizlenmiş metin.

#### Örnek

```ts
import { logSafe } from "@aifivem/lib/shared";

logSafe("^1fake error\nsecond line", 100); // "fake error | second line"
```

<Callout type="warn">
Bu olmadan bir oyuncu, `^1` renk kodları ve satır sonlarıyla konsolunda gerçek bir server hatası gibi görünen bir sohbet mesajı yazabilir.
</Callout>

### previewJson

Güvenilmeyen herhangi bir değerin, `max` karakterde kesilen kısa, JSON benzeri bir metni; önce değerin tamamı serileştirilmeden kurulur (düşmanca bir payload megabaytlarca olabilir). 4 seviyeden derin iç içe yapılar `[...]` / `{...}` olarak gösterilir. Bir client’ın gönderdiğini reddettiğinde onu yazdırmak için kullan.

**Taraf:** Client, server ve NUI · **Bekler:** hayır

```ts title="Signature"
previewJson(value: unknown, max: number): string
```

**Lua:** karşılığı yok.

#### Parametreler

<TypeTable
  type={{
    value: { type: 'unknown', description: 'Herhangi bir şey: reddedilen bir çağrının ham argümanları.', required: true },
    max: { type: 'number', description: 'Sonuçtaki en fazla karakter.', required: true },
  }}
/>

#### Dönüş değeri

`string`: önizleme, en fazla `max` karakter. Nesne anahtarları 50 karaktere kesilir.

#### Örnek

```ts title="resource/server/index.ts"
import { onClientEvent } from "@aifivem/lib/server";
import { createLogger, logSafe, previewJson } from "@aifivem/lib/shared";

const log = createLogger(GetCurrentResourceName());

onClientEvent("my-shop:rate", (source) => {
  log.info(`${logSafe(GetPlayerName(String(source)) ?? "?", 32)} opened the rating`);
});

function refuse(source: number, raw: unknown[]): void {
  log.warn(`refused input from ${source}: ${previewJson(raw, 200)}`);
}
```
