ai-lib rysuje jedno wspólne UI za każdy zasób: karty powiadomień, pasek postępu, prompty "naciśnij E", menu, okna wejścia i minigry. Twój skrypt tylko o nie prosi, więc każdy skrypt na serwerze wygląda tak samo, a ty nie piszesz do nich żadnego NUI. Wybierak przedmiotów rysuje ai-core.

Teksty, które podajesz, są pokazywane tak, jak są: najpierw je przetłumacz (`Locale("KEY")` w TypeScript, `t('KEY')` w Lua).

## Powiadomienia

### notify

Pokazuje kartę powiadomienia na ekranie tego gracza.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
notify(text: string, kind?: NotificationKind, duration?: number): void
```

```lua title="Lua"
aiLib.notify(text, kind, duration)
```

#### Parametry

<TypeTable
  type={{
    text: { type: 'string', description: 'Wiadomość, już przetłumaczona.', required: true },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'Kolor i ikona karty.', default: '"info"' },
    duration: { type: 'number', description: 'Milisekundy na ekranie.', default: '4000' },
  }}
/>

Typ kind to [`NotificationKind`](/pl/docs/developers/api/types#notificationkind). Żeby powiadomić gracza z serwera, użyj serwerowego `notify(source, text, kind)`.

#### Zwracana wartość

`void`.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, notify } from "@aifivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();

notify(Locale("WELCOME"));
notify(Locale("NO_MONEY"), "error");
notify(Locale("SAVED"), "success", 2000);
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()

aiLib.notify(t('WELCOME'))
aiLib.notify(t('NO_MONEY'), 'error')
aiLib.notify(t('SAVED'), 'success', 2000)
```
</Tab>
</Tabs>

## Pasek postępu

### progress

Wykonuje akcję z czasem z paskiem postępu ai-lib i opcjonalną animacją albo scenariuszem i czeka, aż się skończy. Kończy się wcześniej (anulowana), gdy gracz zginie, wsiądzie do pojazdu, naciśnie klawisz anulowania ai-lib (domyślnie `Backspace`, tylko z `canCancel`) albo twój skrypt wywoła `cancelProgress()`. Jeden pasek na zasób naraz.

**Strona:** Klient · **Czeka:** tak (Promise w TypeScript, w Lua wstrzymuje wątek)

```ts title="Sygnatura"
progress(options: ProgressOptions): Promise<boolean>
```

```lua title="Lua"
local finished = aiLib.progress(options) -- boolean, wywołuj wewnątrz wątku
```

#### Parametry

<TypeTable
  type={{
    options: { type: 'ProgressOptions', description: 'Co pokazuje pasek i co gracz może robić. Pola poniżej.', required: true },
  }}
/>

#### ProgressOptions

<TypeTable
  type={{
    label: { type: 'string', description: 'Tekst na pasku, już przetłumaczony.', required: true },
    duration: { type: 'number', description: 'Jak długo trwa pasek, w milisekundach.', required: true },
    anim: { type: '{ dict: string; clip: string; flag?: number }', description: 'Animacja odtwarzana przez cały czas (flag domyślnie 49: górna część ciała, pętla, można się ruszać). Zatrzymywana na końcu.' },
    scenario: { type: 'string', description: 'Scenariusz odtwarzany w miejscu (WORLD_HUMAN_HAMMERING), gdy nie ma anim. Czyszczony na końcu.' },
    face: { type: 'Vec3', description: 'Gracz najpierw obraca się w stronę tego punktu (dystrybutor, lada, pojazd), co trwa 600 ms, tylko pieszo. Tylko TypeScript.' },
    canCancel: { type: 'boolean', description: 'Gracz może anulować klawiszem anulowania ai-lib.', default: 'false' },
    allowVehicle: { type: 'boolean', description: 'Bycie w pojeździe go nie anuluje. Bez tego bycie w pojeździe przy dowolnym sprawdzeniu (także na starcie) anuluje.', default: 'false' },
    whileDead: { type: 'boolean', description: 'Trwa dalej, gdy gracz zostanie powalony. Domyślnie powalenie, w dowolnym skrypcie śmierci, anuluje.', default: 'false' },
    freeze: { type: 'boolean', description: 'Trzyma gracza w miejscu w czasie trwania.', default: 'false' },
    disable: { type: '{ move?: boolean; car?: boolean; mouse?: boolean; combat?: boolean }', description: 'Sterowanie zablokowane w czasie trwania: move = chodzenie (sterowanie 30, 31, 36, 21, 44), car = jazda (63, 64, 71, 72, 75), mouse = rozglądanie się (1, 2, 106), combat = walka (24, 25, 37, 47, 58, 140-143, 257, 263, 264).' },
  }}
/>

#### Zwracana wartość

`Promise<boolean>`: `true`, gdy pasek dobiegł końca; `false`, gdy został anulowany, albo od razu, gdy inny pasek twojego zasobu jeszcze trwa. Lua zwraca tę samą wartość logiczną.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, createLocale, nearestVehicle, notify, progress } from "@aifivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();

export async function repair(): Promise<void> {
  const vehicle = nearestVehicle(4, { notOwn: true });
  if (!vehicle) return notify(Locale("NO_VEHICLE"), "error");
  const [x = 0, y = 0, z = 0] = GetEntityCoords(vehicle, false);
  const done = await progress({
    label: Locale("REPAIRING"),
    duration: 8000,
    face: { x, y, z },
    anim: { dict: "mini@repair", clip: "fixing_a_player" },
    canCancel: true,
    disable: { move: true, combat: true },
  });
  if (!done) return notify(Locale("CANCELLED"), "error");
  await callAction("mymech:repair", [NetworkGetNetworkIdFromEntity(vehicle)], { fallback: "REPAIR_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()

local function repair()
    CreateThread(function()
        local vehicle = aiLib.nearestVehicle(4.0, { notOwn = true })
        if vehicle == 0 then return aiLib.notify(t('NO_VEHICLE'), 'error') end
        local done = aiLib.progress({
            label = t('REPAIRING'),
            duration = 8000,
            anim = { dict = 'mini@repair', clip = 'fixing_a_player' },
            canCancel = true,
            disable = { move = true, combat = true },
        })
        if not done then return aiLib.notify(t('CANCELLED'), 'error') end
        aiLib.callAction('mymech:repair', { NetworkGetNetworkIdFromEntity(vehicle) }, { fallback = 'REPAIR_FAILED' })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Wynik to słowo klienta: oszust może pominąć pasek. Gdy serwer płaci za akcję (przedmioty, pieniądze, naprawa), uruchom pasek z serwera przez `progressFor(source, options)` ([Wejście z klienta](/pl/docs/developers/api/lib-server/client-input)): odpowiada `true` tylko wtedy, gdy na serwerze też minęło dość czasu.
</Callout>

### cancelProgress

Anuluje trwający pasek twojego zasobu, niezależnie od tego, czy gracz może go anulować. Wywołanie `progress` rozwiązuje się wtedy `false`. Nic się nie dzieje, gdy żaden pasek nie trwa.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
cancelProgress(): void
```

```lua title="Lua"
aiLib.progress.cancel()
```

#### Zwracana wartość

`void`.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { cancelProgress, onServerEvent } from "@aifivem/lib/client";

// Serwer mówi, że cel został okradziony przez kogoś innego.
onServerEvent("myrob:taken", () => cancelProgress());
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onServerEvent('myrob:taken', function() aiLib.progress.cancel() end)
```
</Tab>
</Tabs>

### isProgressRunning

Czy pasek twojego zasobu trwa teraz.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
isProgressRunning(): boolean
```

```lua title="Lua"
local running = aiLib.progress.isRunning()
```

#### Zwracana wartość

`boolean`: `true`, dopóki trwa pasek twojego zasobu. Paski innych zasobów się nie liczą.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { isProgressRunning, menu } from "@aifivem/lib/client";

export async function openMenu(): Promise<void> {
  if (isProgressRunning()) return; // zajęty
  await menu({ title: "Actions", items: [{ id: "a", label: "Action" }] });
}
```
</Tab>
<Tab value="Lua">
```lua
if aiLib.progress.isRunning() then return end
```
</Tab>
</Tabs>

## Menu i okna dialogowe

### menu

Pokazuje menu ai-lib i czeka na wybór gracza. Strzałki przesuwają, Enter wybiera. Pozycje z `checked` to wiersze-przełączniki, które przełączają się w miejscu bez zamykania menu. W podmenu (`back: true`) krótkie Escape rozwiązuje się `MENU_BACK`, żebyś mógł otworzyć poprzednie menu; przytrzymanie Escape zamyka.

**Strona:** Klient · **Czeka:** tak (Promise w TypeScript, w Lua wstrzymuje wątek)

```ts title="Sygnatura"
menu(request: MenuRequest, listeners?: ((item: string) => void) | MenuListeners): Promise<string | null>
```

```lua title="Lua"
local picked = aiLib.menu.show(request, listeners) -- string albo nil, wywołuj wewnątrz wątku
```

    listeners: { type: '((item: string) => void) | MenuListeners', description: 'Funkcja to onHover. Albo obiekt z onHover i onToggle. Lua: tylko obiekt.' },

#### MenuRequest

<TypeTable

/>

#### MenuItem

  type={{

    label: { type: 'string', description: 'Tekst wiersza, już przetłumaczony.', required: true },
    icon: { type: 'string', description: 'Nazwa ikony solid z Font Awesome bez fa- (car, key). Nazwy, których brakuje w mapie ikon ai-lib, pokazują kropkę.' },
    description: { type: 'string', description: 'Dodatkowy tekst pokazywany z wierszem.' },
    disabled: { type: 'boolean', description: 'Wiersza nie można wybrać.', default: 'false' },

  }}
/>

#### Zwracana wartość

`Promise<string | null>`: id wybranej pozycji; `"__back"` (`MENU_BACK` z `@aifivem/shared`) po krótkim Escape w podmenu; `null`, gdy gracz zamknął menu. Lua zwraca to samo, `nil` przy zamknięciu.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, createLocale, menu } from "@aifivem/lib/client";
import { MENU_BACK } from "@aifivem/shared";

const Locale = createLocale<typeof import("../../locales/en.json")>();
let engineOn = true;

export async function vehicleMenu(vehicle: number): Promise<void> {
  const pick = await menu({
    title: Locale("VEHICLE"),
    items: [
      { id: "doors", label: Locale("DOORS"), icon: "door-open" },
      { id: "engine", label: Locale("ENGINE"), icon: "power-off", checked: engineOn },
    ],
  }, {
    onToggle: (item, checked) => {
      if (item !== "engine") return;
      engineOn = checked;
      SetVehicleEngineOn(vehicle, checked, false, true);
    },
  });
  if (pick === "doors") await doorsMenu(vehicle);
}

async function doorsMenu(vehicle: number): Promise<void> {
  const pick = await menu({
    title: Locale("DOORS"),
    back: true,
    items: [0, 1, 2, 3].map((door) => ({ id: String(door), label: Locale("DOOR", door + 1) })),
  });
  if (pick === MENU_BACK) return vehicleMenu(vehicle);
  if (pick !== null) SetVehicleDoorOpen(vehicle, Number(pick), false, false);
}
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()

local function openShop()

        local pick = aiLib.menu.show({
            title = t('SHOP'),

            onHover = function(item) print('looking at', item) end,

end
```
</Tab>

### itemPicker

Narzędzia administratora: pokazuje wybierak przedmiotów ai-core. Wymienia każdy przedmiot aktywnego ekwipunku z obrazkiem i wyszukiwaniem; kliknięcia wypełniają listę po prawej (1 na kliknięcie, 10 z Ctrl, 100 z Shift), która zatrzymuje się na limicie wagi celu. Lista przedmiotów jest wysyłana tylko administratorom.

**Strona:** Klient · **Czeka:** tak (Promise w TypeScript, w Lua wstrzymuje wątek)

```ts title="Sygnatura"
itemPicker(request: ItemPickerRequest): Promise<PickedItem[] | null>
```

```lua title="Lua"
local list = aiLib.itemPicker(request) -- tabela albo nil, wywołuj wewnątrz wątku
```

#### Parametry

<TypeTable
  type={{
    request: { type: 'ItemPickerRequest', description: 'Pola poniżej.', required: true },
  }}
/>

#### ItemPickerRequest

<TypeTable
  type={{
    title: { type: 'string', description: 'Tytuł wybieraka, już przetłumaczony.', required: true },
    target: { type: 'number', description: 'Id serwerowe gracza, który dostaje przedmioty: jego wolna waga ogranicza listę.', default: 'administrator, który wybiera' },
  }}
/>

#### Zwracana wartość

`Promise<PickedItem[] | null>`: lista, którą wziął administrator, każdy wiersz `{ name: string; count: number }` (count to liczba całkowita powyżej 0); `null`, gdy wybierak został zamknięty. Lua zwraca listę albo `nil`. Typy to [`ItemPickerRequest`](/pl/docs/developers/api/types#itempickerrequest) i [`PickedItem`](/pl/docs/developers/api/types#pickeditem).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, itemPicker } from "@aifivem/lib/client";

export async function giveItems(target: number): Promise<void> {
  const list = await itemPicker({ title: "Give items", target });
  if (!list || list.length === 0) return;
  await callAction("myadmin:give", [target, list], { fallback: "GIVE_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local function giveItems(target)
    CreateThread(function()
        local list = aiLib.itemPicker({ title = 'Give items', target = target })
        if not list or #list == 0 then return end
        aiLib.callAction('myadmin:give', { target, list }, { fallback = 'GIVE_FAILED' })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Przedmioty daje twój handler serwera: sprawdź, czy wywołujący jest administratorem (strażnik `isAdmin`), i ponownie sprawdź każdą nazwę i ilość. Wybierak nigdy nic sam nie daje.
</Callout>

## Prompty ręcznie

[Punkty](/pl/docs/developers/api/lib-client/points) pokazują i ukrywają prompty za ciebie. Używaj tych funkcji tylko dla promptu, który nie jest związany z miejscem.

Uruchamia handler, gdy gracz naciśnie klawisz interakcji (domyślnie `E`), gdy jeden z promptów twojego zasobu jest na wierzchu.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
onPromptPressed(handler: (id: string) => void): void
```

```lua title="Lua"
aiLib.onPromptPressed(function(id) end)
```

#### Parametry

<TypeTable
  type={{
    handler: { type: '(id: string) => void', description: 'Dostaje id promptu, który był na wierzchu. Działa dla każdego promptu twojego zasobu, także tych z Points: sprawdź id.', required: true },
  }}

`void`.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

## Minigry

### skillCheck

Test umiejętności ai-lib: wskazówka obiega pierścień raz na etap, a gracz naciska pokazany klawisz, gdy jest ona na zielonym łuku. Ma typowy kształt testu umiejętności FiveM (`"easy" | "medium" | "hard"` albo `{ areaSize, speedMultiplier }`), więc kod napisany dla testu umiejętności ox_lib działa tak samo.

**Strona:** Klient · **Czeka:** tak (Promise w TypeScript, w Lua wstrzymuje wątek)

```ts title="Sygnatura"
skillCheck(difficulty: SkillDifficulty | SkillDifficulty[], keys?: string[]): Promise<boolean>
```

```lua title="Lua"
local passed = aiLib.skillCheck(difficulty, keys) -- boolean, wywołuj wewnątrz wątku
```

#### Parametry

<TypeTable
  type={{
    difficulty: { type: 'SkillDifficulty | SkillDifficulty[]', description: 'Jeden etap albo lista etapów rozgrywanych jeden po drugim (najwyżej 20).', required: true },
    keys: { type: 'string[]', description: 'Klawisze, o które może prosić etap: pojedyncze litery albo cyfry. Każdy etap pokazuje jeden z nich.', default: '["e"]' },
  }}
/>

#### SkillDifficulty

[`SkillDifficulty`](/pl/docs/developers/api/types#skilldifficulty) to jedno z:

<TypeTable
  type={{
    '"easy"': { type: 'string', description: 'Zielony łuk 50 stopni, wskazówka 0.6 obrotu na sekundę.' },
    '"medium"': { type: 'string', description: 'Zielony łuk 40 stopni, 0.85 obrotu na sekundę.' },
    '"hard"': { type: 'string', description: 'Zielony łuk 25 stopni, 1 obrót na sekundę.' },
    '{ areaSize, speedMultiplier }': { type: '{ areaSize: number; speedMultiplier: number }', description: 'Twój własny etap: areaSize to zielony łuk w stopniach (5-180), speedMultiplier mnoży szybkość easy (0.2-5).' },
  }}
/>

#### Zwracana wartość

`Promise<boolean>`: `true`, gdy trafiono każdy etap; `false` przy chybieniu, złym klawiszu albo Escape.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

```ts
  await callAction("mykeys:hotwire", [netId, passed], { fallback: "HOTWIRE_FAILED" });

```

### lockpick

Wytrych ai-lib: gracz przesuwa wytrych klawiszami A / D (albo strzałkami) i przytrzymuje W, żeby obrócić zamek. Zamek obraca się tym dalej, im bliżej wytrych jest ukrytego dobrego punktu; forsowanie zużywa wytrych.

**Strona:** Klient · **Czeka:** tak (Promise w TypeScript, w Lua wstrzymuje wątek)

```ts title="Sygnatura"
lockpick(options?: LockpickOptions): Promise<LockpickResult>
```

```lua title="Lua"
local result = aiLib.lockpick(options) -- 'opened' | 'broken' | 'cancelled', wywołuj wewnątrz wątku
```

#### Parametry

<TypeTable
  type={{
    options: { type: 'LockpickOptions', description: 'Pola poniżej.', default: '{}' },
  }}
/>

#### LockpickOptions

<TypeTable
  type={{
    difficulty: { type: '"easy" | "medium" | "hard"', description: 'Szerokość dobrego punktu każdej zapadki: easy 18, medium 11, hard 6 stopni.', default: '"medium"' },
    pins: { type: 'number', description: 'Zapadki do obrócenia jedna po drugiej (1-6).', default: '1' },
    picks: { type: 'number', description: 'Ile wytrychów gracz może złamać, zanim gra skończy się jako broken (1-10).', default: '1' },
  }}
/>

#### Zwracana wartość

`Promise<LockpickResult>` ([`LockpickResult`](/pl/docs/developers/api/types#lockpickresult)): `"opened"`, gdy obróciła się każda zapadka; `"broken"`, gdy złamał się ostatni wytrych (zabierz przedmiot wytrycha); `"cancelled"`, gdy gracz nacisnął Escape.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, lockpick } from "@aifivem/lib/client";

export async function pickDoor(doorId: string): Promise<void> {
  const result = await lockpick({ difficulty: "hard", pins: 3, picks: 2 });
  if (result === "cancelled") return;
  await callAction("mydoors:picked", [doorId, result], { fallback: "PICK_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua

        if result == 'cancelled' then return end
        aiLib.callAction('mydoors:picked', { doorId, result }, { fallback = 'PICK_FAILED' })
    end)
end
```
