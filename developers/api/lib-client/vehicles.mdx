Finding vehicles near the player, turning network ids from the server into local entities, and reading or applying a vehicle's look. Spawning a vehicle is server-only (`spawnVehicle` on [Vehicles](/docs/developers/api/lib-server/vehicles)); a local showroom car is [`PreviewVehicle`](/docs/developers/api/lib-client/world-objects#new-previewvehicle).

## Finding vehicles

### nearestVehicle

The closest vehicle within a distance of the local player. The vehicle the player sits in wins first, unless `notOwn`. Use `filter` to skip vehicles that do not fit, so the trunk the player stands behind wins over a closer car next to it.

**Side:** Client · **Waits:** no

```ts title="Signature"
nearestVehicle(metres: number, options?: { networked?: boolean; notOwn?: boolean; filter?: (vehicle: number) => boolean }): number
```

```lua title="Lua"
local vehicle = aiLib.nearestVehicle(metres, options) -- 0 when none
```

#### Parameters

<TypeTable
  type={{
    metres: { type: 'number', description: 'The search radius, in metres.', required: true },
    options: { type: '{ networked?, notOwn?, filter? }', description: 'Fields below.', default: '{}' },
  }}
/>

#### Options

<TypeTable
  type={{
    networked: { type: 'boolean', description: 'Skip local-only vehicles (showroom previews, props). false includes them.', default: 'true' },
    notOwn: { type: 'boolean', description: 'Skip the vehicle the player sits in.', default: 'false' },
    filter: { type: '(vehicle: number) => boolean', description: 'Skips vehicles it returns false for. Also applied to the vehicle the player sits in.' },
  }}
/>

#### Returns

`number`: the vehicle handle, or `0` when none is within `metres`.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, nearestVehicle, notify } from "@aifivem/lib/client";

export async function impound(): Promise<void> {
  const vehicle = nearestVehicle(5, { notOwn: true, filter: (v) => GetPedInVehicleSeat(v, -1) === 0 });
  if (!vehicle) return notify("No empty vehicle near", "error");
  await callAction("mypolice:impound", [NetworkGetNetworkIdFromEntity(vehicle)], { fallback: "IMPOUND_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local function impound()
    CreateThread(function()
        local vehicle = aiLib.nearestVehicle(5.0, {
            notOwn = true,
            filter = function(v) return GetPedInVehicleSeat(v, -1) == 0 end,
        })
        if vehicle == 0 then return aiLib.notify('No empty vehicle near', 'error') end
        aiLib.callAction('mypolice:impound', { NetworkGetNetworkIdFromEntity(vehicle) }, { fallback = 'IMPOUND_FAILED' })
    end)
end
```
</Tab>
</Tabs>

<Callout type="info">
It walks every vehicle the client knows, so call it on a key press or an action, not every frame. Send the vehicle to the server as a network id; the server turns it back with `vehicleFromNet` or `vehicleNearPlayer` and checks the distance.
</Callout>

### drivenVehicle

The vehicle the local player drives (sits in the driver seat).

**Side:** Client · **Waits:** no

```ts title="Signature"
drivenVehicle(): number | false
```

No Lua twin: `aiLib.cache.seat == -1 and aiLib.cache.vehicle`.

#### Returns

`number | false`: the vehicle handle when the player is the driver, `false` on foot or as a passenger.

#### Example

```ts
import { drivenVehicle, notify } from "@aifivem/lib/client";

RegisterCommand(
  "flip",
  () => {
    const vehicle = drivenVehicle();
    if (vehicle === false) return notify("You must drive a vehicle", "error");
    SetVehicleOnGroundProperly(vehicle);
  },
  false,
);
```

## Entities from network ids

The server sends entities as network ids. On a client the entity may not exist yet (the player is far, or it was just created).

### waitForEntity

Waits until the entity of a network id exists on this client and returns it.

**Side:** Client · **Waits:** yes (Promise in TypeScript, yields the thread in Lua)

```ts title="Signature"
waitForEntity(netId: number, timeoutMs?: number): Promise<number>
```

```lua title="Lua"
local entity = aiLib.waitForEntity(netId, timeout) -- call inside a thread
```

#### Parameters

<TypeTable
  type={{
    netId: { type: 'number', description: 'The network id the server sent.', required: true },
    timeoutMs: { type: 'number', description: 'How long to wait, in milliseconds. Lua names it timeout.', default: '5000' },
  }}
/>

#### Returns

`Promise<number>`: the local entity handle, or `0` after the timeout. It never rejects.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onServerEvent, waitForEntity } from "@aifivem/lib/client";
import { readId } from "@aifivem/lib/shared";

// The server spawned a job vehicle and sends its net id.
onServerEvent(
  "myjob:vehicle",
  { args: ([id]) => { const netId = readId(id); return netId === null ? null : [netId]; } },
  async (netId) => {
    const vehicle = await waitForEntity(netId);
    if (vehicle) SetVehicleFuelLevel(vehicle, 100);
  },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onServerEvent('myjob:vehicle', function(netId)
    if type(netId) ~= 'number' then return end
    local vehicle = aiLib.waitForEntity(netId)
    if vehicle ~= 0 then SetVehicleFuelLevel(vehicle, 100.0) end
end)
```
</Tab>
</Tabs>

### entityFromNetId

The local entity of a network id right now, without waiting. Optionally checks the entity type.

**Side:** Client · **Waits:** no

```ts title="Signature"
entityFromNetId(netId: number, type?: 1 | 2 | 3): number
```

No Lua twin: `NetworkDoesEntityExistWithNetworkId(netId) and NetToEnt(netId) or 0`.

#### Parameters

<TypeTable
  type={{
    netId: { type: 'number', description: 'The network id the server sent.', required: true },
    type: { type: '1 | 2 | 3', description: 'Only accept this entity type: 1 ped, 2 vehicle, 3 object. Any type when left out.' },
  }}
/>

#### Returns

`number`: the entity handle, or `0` when it is not on this client or not of `type`.

#### Example

```ts
import { entityFromNetId, EntityState, stateBoolean } from "@aifivem/lib/client";

const sirens = new EntityState("sirensMuted", stateBoolean);

sirens.onChange((netId, muted) => {
  const vehicle = entityFromNetId(netId, 2);
  if (vehicle) SetVehicleHasMutedSirens(vehicle, muted === true);
});
```

## Vehicle look

### getVehicleProps

Reads every property of a vehicle this client can see: plate, colours, mods, extras, neon, damage. Store the result to put the same look back later.

**Side:** Client · **Waits:** no

```ts title="Signature"
getVehicleProps(vehicle: number): VehicleProps
```

No Lua twin.

#### Parameters

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'A vehicle handle.', required: true },
  }}
/>

#### Returns

[`VehicleProps`](/docs/developers/api/types#vehicleprops): `v` (format version 1), `model`, `plate` (trimmed), `plateIndex`, `colors`, `extraColors`, `customPrimary`, `customSecondary` (RGB or `null`), `wheelType`, `windowTint`, `livery`, `mods` (by mod type 0-49; toggle mods 17-22 as 1 or 0), `xenonColor`, `neon` (four booleans), `neonColor`, `tyreSmoke`, `extras` (by extra id), `dirt`, `engineHealth`, `bodyHealth`.

#### Example

```ts
import { callAction, drivenVehicle, getVehicleProps } from "@aifivem/lib/client";

export async function saveLook(): Promise<void> {
  const vehicle = drivenVehicle();
  if (vehicle === false) return;
  await callAction("mygarage:saveProps", [NetworkGetNetworkIdFromEntity(vehicle), getVehicleProps(vehicle)], { fallback: "SAVE_FAILED" });
}
```

<Callout type="warn">
The props come from the player's client: the server must parse and check them (`toVehicleProps` from `@aifivem/lib/shared`) before storing.
</Callout>

### setVehicleProps

Applies stored properties to a vehicle. Only works on a vehicle this client controls; other players get the look through the network.

**Side:** Client · **Waits:** no

```ts title="Signature"
setVehicleProps(vehicle: number, props: VehicleProps): void
```

No Lua twin.

#### Parameters

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'A vehicle this client controls (the driver or the creator).', required: true },
    props: { type: 'VehicleProps', description: 'Properties read by getVehicleProps and stored.', required: true },
  }}
/>

#### Returns

`void`.

#### Example

```ts
import { onServerEvent, setVehicleProps, waitForEntity } from "@aifivem/lib/client";
import { readId, toVehicleProps } from "@aifivem/lib/shared";

onServerEvent(
  "mygarage:look",
  {
    args: ([id, raw]) => {
      const netId = readId(id);
      const props = toVehicleProps(raw);
      return netId === null || props === null ? null : [netId, props];
    },
  },
  async (netId, props) => {
    const vehicle = await waitForEntity(netId);
    if (vehicle && NetworkHasControlOfEntity(vehicle)) setVehicleProps(vehicle, props);
  },
);
```

<Callout type="info">
A vehicle spawned with `spawnVehicle({ props })` gets its look applied by ai-core on the owner client already. You need `setVehicleProps` only for your own flows.
</Callout>

### setVehicleSetup

Applies a spawn setup to a fresh vehicle: maxed performance, colours, livery, tint, dirt, engine on. Only works on a vehicle this client controls.

**Side:** Client · **Waits:** no

```ts title="Signature"
setVehicleSetup(vehicle: number, setup: VehicleSetup): void
```

No Lua twin.

#### Parameters

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'A vehicle this client controls.', required: true },
    setup: { type: 'VehicleSetup', description: 'Fields below. Fields left out stay as they are.', required: true },
  }}
/>

#### VehicleSetup

<TypeTable
  type={{
    maxed: { type: 'boolean', description: 'Engine, brakes, transmission, suspension and armour at their top level, turbo and xenons on.' },
    colors: { type: '[number, number]', description: 'GTA colour indexes: primary, secondary.' },
    primary: { type: '[number, number, number]', description: 'Custom primary colour, RGB 0-255.' },
    secondary: { type: '[number, number, number]', description: 'Custom secondary colour, RGB 0-255.' },
    livery: { type: 'number', description: 'Livery index.' },
    windowTint: { type: 'number', description: 'Window tint index.' },
    dirt: { type: 'number', description: 'Dirt level: 0 clean to 15.' },
    engineOn: { type: 'boolean', description: 'Start the engine.' },
  }}
/>

The type is [`VehicleSetup`](/docs/developers/api/types#vehiclesetup).

#### Returns

`void`.

#### Example

```ts
import { PreviewVehicle, setVehicleSetup } from "@aifivem/lib/client";

const preview = new PreviewVehicle();

export function showMaxed(model: string): Promise<number> {
  return preview.show(model, { x: -44.4, y: -1097.1, z: 26.4, heading: 120 }, (vehicle) =>
    setVehicleSetup(vehicle, { maxed: true, primary: [20, 200, 120], windowTint: 1 }),
  );
}
```
