---
title: Zonas
description: Zones - áreas con callbacks de entrada y salida (esfera, cilindro, polígono), comprobadas a su propio intervalo, nunca en cada frame.
icon: Shapes
---

Una **zona** es un área que ejecuta código cuando el jugador entra o sale de ella: entrar en un distrito, un área con límite de velocidad, un marcador que solo se dibuja de cerca. Cuando el jugador debe *hacer* algo en el lugar (pulsar una tecla, elegir una opción de target), usa un [punto](/es/docs/developers/api/lib-client/points) en su lugar: es una zona con el prompt, el target, el ped y el blip ya conectados.

En TypeScript, cada zona la comprueba el único comprobador de ai-lib para todos los recursos (las zonas se colocan en una cuadrícula de 64 m, así que un millón de zonas cuesta lo mismo que unas pocas). Tu recurso comprueba sus propias zonas solo mientras ai-lib no está en marcha. En Lua, cada recurso ejecuta una tarea del planificador para sus zonas.

### new Zones

Crea un grupo de zonas. Crea un grupo por funcionalidad, al principio del archivo.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
new Zones()
```

```lua title="Lua"
local zones = aiLib.Zones.new()
```

#### Devuelve

Un grupo `Zones` con los métodos de abajo.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { Zones } from "@aicore-fivem/lib/client";

const zones = new Zones();
```
</Tab>
<Tab value="Lua">
```lua
local zones = aiLib.Zones.new()
```
</Tab>
</Tabs>

### zones.add

Añade una zona, o reemplaza la zona con el mismo id. Cuando el jugador estaba dentro de la zona reemplazada, primero se ejecuta su `onExit`.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
zones.add(id: string, options: ZoneOptions): void
```

```lua title="Lua"
zones:add(id, options)
```

#### Parámetros

<TypeTable
  type={{
    id: { type: 'string', description: 'Único dentro de este grupo. El mismo id reemplaza la zona anterior.', required: true },
    options: { type: 'ZoneOptions', description: 'La forma y los callbacks. Campos abajo.', required: true },
  }}
/>

#### ZoneOptions

<TypeTable
  type={{
    shape: { type: 'ZoneShape', description: 'El área: una esfera, un cilindro o un polígono. Formas abajo.', required: true },
    interval: { type: 'number', description: 'Cada cuánto se comprueba la zona, en milisegundos (al menos 50). Una tienda necesita unos 500, un disparador rápido unos 100.', default: '500' },
    onEnter: { type: '() => void', description: 'El jugador entró. Un error lanzado se registra en el log.' },
    onExit: { type: '() => void', description: 'El jugador salió, o la zona se eliminó o se reemplazó mientras el jugador estaba dentro.' },
  }}
/>

#### ZoneShape

[`ZoneShape`](/es/docs/developers/api/types#zoneshape) es uno de tres objetos, elegido por `type`:

<TypeTable
  type={{
    '"sphere"': { type: '{ type: "sphere"; center: Vec3; radius: number }', description: 'Una bola de radius metros alrededor de center.' },
    '"cylinder"': { type: '{ type: "cylinder"; center: Vec3; radius: number; height: number }', description: 'Un círculo de radius metros en el suelo, height metros hacia arriba y hacia abajo desde center (habitaciones, plantas).' },
    '"poly"': { type: '{ type: "poly"; points: Array<{ x: number; y: number }>; minZ: number; maxZ: number }', description: 'Un polígono en el suelo (los puntos en orden alrededor del borde) entre dos alturas.' },
  }}
/>

En Lua, `center` puede ser un `vector3` y los puntos tablas `{ x = ..., y = ... }`.

#### Devuelve

`void`.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, notify, Zones } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const zones = new Zones();

zones.add("safezone", {
  shape: { type: "cylinder", center: { x: 298.6, y: -584.5, z: 43.3 }, radius: 60, height: 30 },
  onEnter: () => notify(Locale("SAFEZONE_IN"), "info"),
  onExit: () => notify(Locale("SAFEZONE_OUT"), "info"),
});

zones.add("yard", {
  shape: {
    type: "poly",
    points: [
      { x: 1700.1, y: 2560.4 },
      { x: 1780.6, y: 2560.4 },
      { x: 1780.6, y: 2620.2 },
      { x: 1700.1, y: 2620.2 },
    ],
    minZ: 40,
    maxZ: 60,
  },
  interval: 1000,
  onEnter: () => SetPedMoveRateOverride(PlayerPedId(), 0.8),
});
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()
local zones = aiLib.Zones.new()

zones:add('safezone', {
    shape = { type = 'cylinder', center = vector3(298.6, -584.5, 43.3), radius = 60.0, height = 30.0 },
    onEnter = function() aiLib.notify(t('SAFEZONE_IN'), 'info') end,
    onExit = function() aiLib.notify(t('SAFEZONE_OUT'), 'info') end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Una zona dibujada en tu panel de administración con el widget `zone` da esquinas; conviértelas en un polígono con `polyFromCorners(corners, height)` de `@aicore-fivem/lib/shared`. El servidor puede probar las mismas formas con `zoneContains(shape, x, y, z)`.
</Callout>

### zones.clear

Elimina todas las zonas del grupo; `onExit` se ejecuta para aquellas en las que está el jugador.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
zones.clear(): void
```

```lua title="Lua"
zones:clear()
```

#### Devuelve

`void`.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
onServerEvent("myscript:eventOver", () => zones.clear());
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onServerEvent('myscript:eventOver', function() zones:clear() end)
```
</Tab>
</Tabs>

### zones.isInside

Si el jugador está dentro de una zona, según su última comprobación.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
zones.isInside(id: string): boolean
```

```lua title="Lua"
local inside = zones:isInside(id)
```

#### Parámetros

<TypeTable
  type={{
    id: { type: 'string', description: 'El id dado a add.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` mientras está dentro; `false` fuera o para un id desconocido. Refleja la última comprobación, así que puede tener hasta `interval` ms de antigüedad.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
if (zones.isInside("safezone")) return notify(Locale("NO_WEAPONS_HERE"), "error");
```
</Tab>
<Tab value="Lua">
```lua
if zones:isInside('safezone') then return aiLib.notify(t('NO_WEAPONS_HERE'), 'error') end
```
</Tab>
</Tabs>

### zones.size

Cuántas zonas tiene el grupo.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
zones.size: number // propiedad de solo lectura
```

Sin equivalente en Lua.

#### Devuelve

`number`: el número de zonas de este grupo.

#### Ejemplo

```ts
console.log(`${zones.size} zones loaded`);
```
