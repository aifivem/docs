**Nokta**, oyuncunun kullandığı herhangi bir yerdir: bir market tezgahı, bir kapı, bir NPC, bir iade noktası, her ATM, her arabanın bagajı. Onu bir kez tanımlarsın (nerede, hangi metin, ne olur) ve lib onu sunucu sahibinin seçtiği şekilde çizer.

## Prompt ya da target

Sahip etkileşim stilini ai-core’un admin panelinde (**Interaction**) seçer. Her iki durumda da aynı `onPressed` çalışır; bu yüzden script’in hangisinin açık olduğunu hiç umursamaz.

| Stil | Oyuncunun gördüğü |
| --- | --- |
| **Prompt** | Oyuncu noktanın yarıçapı içinde durduğu sürece ekranın sağ tarafında bir "E’ye bas" kutusu. Tuş, ai-lib’de yeniden atanabilir tek bir keybind’dır (varsayılan `E`); bu yüzden hiçbir şey her karede tuşları yoklamaz. |
| **Target** | Noktadaki, NPC’deki, nesnedeki ya da araçtaki target gözünde bir seçenek. Lib’in adaptörü olduğu target script’lerinden birinin çalışmasını gerektirir. Birden fazlası çalışıyorsa bu sıradaki ilki kazanır: `ai-target`, `tgiann-radialmenu-target`, `tgiann-target`, `sleepless_interact`, `ox_target`, `qb-target`, `interact`. |

Sahip target’ı seçtiyse ama hiçbir target script’i çalışmıyorsa her nokta bir prompt olur. Bir nokta sahibin seçimini geçersiz kılabilir: `promptOnly` prompt’u korur (araçtan yapılan şeyler: yakıt pompaları, oto yıkamalar), `preferTarget` bir target script’i çalıştığında her zaman target seçeneği kullanır (koltuklar). Bir target script’i başladığında ya da durduğunda veya sahip stili değiştirdiğinde her nokta kendiliğinden geçiş yapar.

<Callout type="info">
Resource’unun aynı anda yalnızca bir nokta aksiyonu çalışır. `onPressed` bir promise döndürdüğünde, resource’unun diğer noktaları o sonuçlanana kadar basmaları yok sayar; böylece kendi `busy` bayrağına hiç ihtiyacın olmaz. Oyuncu ayrıca basma anında `canShow`’dan da geçmelidir.
</Callout>

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { callAction, createLocale, hasJob, onMembershipChange, Points } from "@aifivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const points = new Points();

// Bir dükkân sahibi ve harita blip’i olan bir market tezgahı.
points.add("shop", {
  coords: { x: 25.7, y: -1347.3, z: 29.5 },
  label: Locale("OPEN_SHOP"),
  icon: "basket-shopping",
  ped: { model: "mp_m_shopkeep_01", coords: { x: 24.5, y: -1346.6, z: 29.5, heading: 270 } },
  blip: { sprite: 52, color: 2, label: Locale("SHOP") },
  onPressed: () => callAction("myshop:open", [], { fallback: "SHOP_FAILED" }),
});

// Yalnızca polisin açabildiği bir depo; metin bir durumu takip eder.
let locked = true;
points.add("evidence", {
  coords: { x: 474.9, y: -996.4, z: 26.3 },
  label: () => (locked ? Locale("UNLOCK") : Locale("LOCK")),
  icon: "box-archive",
  canShow: () => hasJob(["police"], 2),
  onPressed: async () => {
    const reply = await callAction("myscript:toggle", [], { fallback: "TOGGLE_FAILED" });
    if (reply) locked = !locked;
    points.refresh("evidence");
  },
});

// canShow mesleği okur: meslekler, görev durumu ya da çeteler değiştiğinde tekrar kontrol et.
onMembershipChange(() => points.refresh());
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local t = aiLib.locale()
local points = aiLib.Points.new()

points:add('shop', {
    coords = vector3(25.7, -1347.3, 29.5),
    label = t('OPEN_SHOP'),
    icon = 'basket-shopping',
    ped = { model = 'mp_m_shopkeep_01', coords = vector4(24.5, -1346.6, 29.5, 270.0) },
    blip = { sprite = 52, color = 2, label = t('SHOP') },
    onPressed = function()
        CreateThread(function()
            aiLib.callAction('myshop:open', {}, { fallback = 'SHOP_FAILED' })
        end)
    end,
})

local function isPolice()
    for _, m in ipairs(aiLib.playerData.get('jobs') or {}) do
        if m.job == 'police' and m.grade >= 2 then return true end
    end
    return false
end

points:add('evidence', {
    coords = vector3(474.9, -996.4, 26.3),
    label = t('OPEN_EVIDENCE'),
    icon = 'box-archive',
    canShow = isPolice,
    onPressed = function() TriggerServerEvent('myscript:openEvidence') end,
})

aiLib.playerData.onChange('jobs', function() points:refresh() end)
```
</Tab>
</Tabs>

</Callout>

### points.refresh

`canShow`’u ve fonksiyon etiketlerini yeniden okur. Okudukları bir şey değiştiğinde çağır: meslek, görev durumu, bir araç, server’ın gönderdiği bir durum. Prompt’lar hemen güncellenir; target seçenekleri `canShow`’u göz açıldığında okur ve değişen bir etiket yeniden konur.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
points.refresh(id?: string): void
```

```lua title="Lua"
points:refresh() -- grubun tüm noktaları
```

#### Parametreler

<TypeTable
  type={{
    id: { type: 'string', description: 'Yalnızca bu nokta (yüzlercesi arasında soyulmuş bir kasa). Verilmezse grubun tüm noktaları. Yalnızca TypeScript: Lua her zaman tüm grubu yeniler.' },
  }}
/>

#### Dönüş değeri

`void`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { EntityState, onCache, onMembershipChange, Points, stateBoolean } from "@aifivem/lib/client";

const robbed = new EntityState("robbed", stateBoolean);

onMembershipChange(() => points.refresh());
// Bir kasa değişti: yalnızca onun noktasını yenile.

```

</Callout>

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
points.isInside(id: string): boolean
```

Lua karşılığı yok.

#### Parametreler

<TypeTable
  type={{

  }}

#### Dönüş değeri

`boolean`: oyuncu içerideyken `true`; dışarıdayken ya da bilinmeyen bir id veya model noktası için `false`.

if (points.isInside("garage")) notify(Locale("PARK_HERE"), "info");

### points.restyle

**Taraf:** Client · **Bekler:** hayır

## Panel kayıtlarından noktalar

Noktaların çoğu script’inin admin panelindeki bir records dosyasından gelir (marketler, garajlar, kiralama tezgahları). Dosyayı client’ta [`AdminWorld`](#new-adminworld) ile yansıt, sonra her kaydın noktalarını [`RecordObjects`](#new-recordobjects) ile kur: düzenlenen bir kayıt yalnızca kendi noktalarını yeniden kurar, silinen bir kayıt onları kaldırır.

### new RecordObjects

Bir records dosyasının dünya nesnelerini (noktalar, blip’ler, ped’ler, bölgeler) her seferinde bir kayıt olacak şekilde dosyayla uyumlu tutar. `build(key, record)` bir kaydın nesnelerini yapar ve onları nasıl kaldıracağını döndürür. Constructor’ında her kaydı kurar.

**Taraf:** Client ve server (`@aifivem/lib/shared`’dan) · **Bekler:** hayır

```ts title="Signature"
new RecordObjects<T>(
  source: RecordSource,
  file: string,
  records: RecordReader<T> | ReadonlyMap<string, T>,
  build: (key: string, record: T) => (() => void) | void,
)
```

Lua karşılığı yok.

#### Parametreler

  type={{
    source: { type: 'RecordSource', description: 'Dosyanın bulunduğu yer: client’ta bir AdminWorld (server’da bir AdminPanel).', required: true },
    file: { type: 'string', description: 'data/ ve .json olmadan records dosyasının adı (locations).', required: true },
    records: { type: 'RecordReader<T> | ReadonlyMap<string, T>', description: 'Bir kaydı ayrıştıran bir okuyucu (key, raw) => T | null (null onu dışarıda bırakır) ya da aynı dosyadan zaten tuttuğun bir records görünümü (world.records(file, readOne)); böylece her düzenleme bir kez ayrıştırılır.', required: true },
    build: { type: '(key: string, record: T) => (() => void) | void', description: 'Bir kaydın nesnelerini yapar ve onları kaldıran bir fonksiyon döndürür.', required: true },

/>

#### Üyeler

<TypeTable
  type={{
    records: { type: 'ReadonlyMap<string, T>', description: 'Anahtara göre ayrıştırılmış kayıtlar, her zaman güncel. Bir kaydı yakalamak yerine onPressed içinde ara.' },
    'rebuild(key)': { type: '(key: string) => void', description: 'Bir kaydı kaldırır ve yeniden kurar (kayıt yoksa o da gider). Bir düzenlemede kendiliğinden çağrılır.' },
    'rebuildAll()': { type: '() => void', description: 'Her kaydı kaldırır ve yeniden kurar. Her kaydın okuduğu bir ayar değiştiğinde çağır (bir blip stili, bir yarıçap).' },
  }}
/>

#### Örnek

```ts title="resource/client/index.ts"
import { AdminWorld, callAction, createLocale, Points } from "@aifivem/lib/client";
import { readVec3, RecordObjects, str } from "@aifivem/lib/shared";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const world = new AdminWorld(["settings", "shops"]);
const points = new Points();

interface Shop { label: string; coords: { x: number; y: number; z: number } }
const readShop = (_key: string, raw: Record<string, unknown>): Shop | null => {
  const coords = readVec3(raw.coords);
  return coords ? { label: str(raw.label, "Shop"), coords } : null;
};

const shops = new RecordObjects(world, "shops", readShop, (id, shop) => {
  points.add(id, {
    coords: shop.coords,
    label: Locale("OPEN_SHOP", shop.label),
    onPressed: () => callAction("myshop:open", [id], { fallback: "SHOP_FAILED" }),
  });
  return () => points.remove(id);
});

// Her marketin okuduğu bir ayar değişti: hepsini yeniden kur.
world.onChange("settings", () => shops.rebuildAll());
```

<Callout type="warn">
`RecordObjects` constructor’ında kurar. Onu `build`’in okuduğu her şeyden sonra oluştur ve `build` içinde `record` argümanını kullan: `RecordObjects`’i tutan bir sınıf alanı o ilk kurulum sırasında henüz atanmamıştır.
</Callout>

### new AdminWorld

Script’inin dünya panel dosyalarının (şeması `sync: "all"` diyen dosyalar, bkz. [Admin paneli](/tr/docs/developers/api/lib-server/admin-panel)) client kopyası. FiveM’in açılışta önbelleğe aldığı kopyayı okur, o zamandan beri değişen kayıtlar için server’a bir kez sorar, sonra canlı değişiklikleri takip eder. Asla yoklama yapmaz.

**Taraf:** Client · **Bekler:** hayır (`ready` promise’i açılıştan beri olan değişikliklerin ne zaman geldiğini söyler)

```ts title="Signature"
new AdminWorld(files: string[])
```

Lua karşılığı yok.

#### Parametreler

  }}
/>

#### Üyeler

<TypeTable
  type={{

    'records(file, readOne)': { type: '<T>(file: string, readOne: RecordReader<T>) => ReadonlyMap<string, T>', description: 'Kayıt kayıt ayrıştırılan bir records dosyası (readOne birini dışarıda bırakmak için null döndürür). Bir düzenleme yalnızca değişen kaydı ayrıştırır.' },
  }}
/>

#### Örnek

```ts
import { AdminWorld } from "@aifivem/lib/client";
import { num, record } from "@aifivem/lib/shared";

const world = new AdminWorld(["settings"]);
const settings = world.view("settings", (raw) => ({
  radius: num(record(raw).radius, 2),
}));

world.onChange("settings", () => console.log("new radius", settings.value.radius));
```
