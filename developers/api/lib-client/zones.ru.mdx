**Зона** это область, которая выполняет код, когда игрок входит в неё или выходит из неё: вход в район, область ограничения скорости, маркер, который рисуется только поблизости. Когда игрок должен что-то *сделать* в этом месте (нажать клавишу, выбрать опцию target), используйте [точку](/ru/docs/developers/api/lib-client/points): это зона с уже подключёнными подсказкой, target, педом и блипом.

В TypeScript каждую зону проверяет единая проверка ai-lib для всех ресурсов (зоны лежат в сетке по 64 м, поэтому миллион зон стоит столько же, сколько несколько). Ваш ресурс проверяет свои зоны сам, только пока ai-lib не запущен. В Lua каждый ресурс запускает одну задачу планировщика для своих зон.

### new Zones

Создаёт группу зон. Создайте одну группу на функцию в начале файла.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
new Zones()
```

```lua title="Lua"
local zones = aiLib.Zones.new()
```

#### Возвращает

Группа `Zones` с методами ниже.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { Zones } from "@aifivem/lib/client";

const zones = new Zones();
```
</Tab>
<Tab value="Lua">
```lua
local zones = aiLib.Zones.new()
```
</Tab>
</Tabs>

### zones.add

Добавляет зону или заменяет зону с тем же id. Если в заменяемой зоне был игрок, сначала выполняется её `onExit`.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
zones.add(id: string, options: ZoneOptions): void
```

```lua title="Lua"
zones:add(id, options)
```

#### Параметры

<TypeTable
  type={{
    id: { type: 'string', description: 'Уникален внутри этой группы. Тот же id заменяет старую зону.', required: true },
    options: { type: 'ZoneOptions', description: 'Форма и колбэки. Поля ниже.', required: true },
  }}
/>

#### ZoneOptions

<TypeTable
  type={{
    shape: { type: 'ZoneShape', description: 'Область: сфера, цилиндр или полигон. Формы ниже.', required: true },
    interval: { type: 'number', description: 'Как часто проверяется зона, в миллисекундах (не меньше 50). Магазину нужно около 500, быстрому триггеру около 100.', default: '500' },
    onEnter: { type: '() => void', description: 'Игрок вошёл внутрь. Выброшенная ошибка логируется.' },
    onExit: { type: '() => void', description: 'Игрок вышел, или зона была удалена или заменена, пока игрок был внутри.' },
  }}
/>

#### ZoneShape

[`ZoneShape`](/ru/docs/developers/api/types#zoneshape) это один из трёх объектов, выбираемый по `type`:

<TypeTable
  type={{
    '"sphere"': { type: '{ type: "sphere"; center: Vec3; radius: number }', description: 'Шар радиусом radius метров вокруг center.' },
    '"cylinder"': { type: '{ type: "cylinder"; center: Vec3; radius: number; height: number }', description: 'Круг радиусом radius метров на земле, на height метров вверх и вниз от center (комнаты, этажи).' },
    '"poly"': { type: '{ type: "poly"; points: Array<{ x: number; y: number }>; minZ: number; maxZ: number }', description: 'Полигон на земле (точки по порядку вдоль края) между двумя высотами.' },
  }}
/>

В Lua `center` может быть `vector3`, а точки таблицами `{ x = ..., y = ... }`.

#### Возвращает

`void`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, notify, Zones } from "@aifivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const zones = new Zones();

zones.add("safezone", {
  shape: { type: "cylinder", center: { x: 298.6, y: -584.5, z: 43.3 }, radius: 60, height: 30 },
  onEnter: () => notify(Locale("SAFEZONE_IN"), "info"),
  onExit: () => notify(Locale("SAFEZONE_OUT"), "info"),
});

zones.add("yard", {
  shape: {
    type: "poly",
    points: [
      { x: 1700.1, y: 2560.4 },
      { x: 1780.6, y: 2560.4 },
      { x: 1780.6, y: 2620.2 },
      { x: 1700.1, y: 2620.2 },
    ],
    minZ: 40,
    maxZ: 60,
  },
  interval: 1000,
  onEnter: () => SetPedMoveRateOverride(PlayerPedId(), 0.8),
});
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()
local zones = aiLib.Zones.new()

zones:add('safezone', {
    shape = { type = 'cylinder', center = vector3(298.6, -584.5, 43.3), radius = 60.0, height = 30.0 },
    onEnter = function() aiLib.notify(t('SAFEZONE_IN'), 'info') end,
    onExit = function() aiLib.notify(t('SAFEZONE_OUT'), 'info') end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Зона, нарисованная в вашей админ-панели виджетом `zone`, даёт углы; превратите их в полигон через `polyFromCorners(corners, height)` из `@aifivem/lib/shared`. Сервер может проверить те же формы через `zoneContains(shape, x, y, z)`.
</Callout>

### zones.remove

Удаляет одну зону. Если игрок был внутри, выполняется `onExit`. Неизвестный id ничего не делает.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
zones.remove(id: string): void
```

```lua title="Lua"
zones:remove(id)
```

#### Параметры

<TypeTable
  type={{
    id: { type: 'string', description: 'Id, переданный в add.', required: true },
  }}
/>

#### Возвращает

`void`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
zones.remove("safezone");
```
</Tab>
<Tab value="Lua">
```lua
zones:remove('safezone')
```
</Tab>
</Tabs>

### zones.clear

Удаляет все зоны группы; `onExit` выполняется для тех, в которых находится игрок.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
zones.clear(): void
```

```lua title="Lua"
zones:clear()
```

#### Возвращает

`void`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
onServerEvent("myscript:eventOver", () => zones.clear());
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onServerEvent('myscript:eventOver', function() zones:clear() end)
```
</Tab>
</Tabs>

### zones.isInside

Находится ли игрок внутри зоны, по результату её последней проверки.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
zones.isInside(id: string): boolean
```

```lua title="Lua"
local inside = zones:isInside(id)
```

#### Параметры

<TypeTable
  type={{
    id: { type: 'string', description: 'Id, переданный в add.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, пока внутри; `false` снаружи или для неизвестного id. Отражает последнюю проверку, поэтому может устареть до `interval` мс.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
if (zones.isInside("safezone")) return notify(Locale("NO_WEAPONS_HERE"), "error");
```
</Tab>
<Tab value="Lua">
```lua
if zones:isInside('safezone') then return aiLib.notify(t('NO_WEAPONS_HERE'), 'error') end
```
</Tab>
</Tabs>

### zones.size

Сколько зон содержит группа.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
zones.size: number // свойство только для чтения
```

Lua-аналога нет.

#### Возвращает

`number`: количество зон в этой группе.

#### Пример

```ts
console.log(`${zones.size} zones loaded`);
```
