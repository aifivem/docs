ai-lib zeichnet eine gemeinsame UI für jede Ressource: Benachrichtigungskarten, den Fortschrittsbalken, die „Drücke E“-Prompts, Menüs, Eingabedialoge und Minispiele. Dein Skript fordert sie nur an, daher sieht jedes Skript auf dem Server gleich aus, und du schreibst dafür keine NUI. Die Item-Auswahl zeichnet ai-core.

Texte, die du übergibst, werden so angezeigt, wie sie sind: Übersetze sie zuerst (`Locale("KEY")` in TypeScript, `t('KEY')` in Lua).

## Benachrichtigungen

### notify

Zeigt eine Benachrichtigungskarte auf dem Bildschirm dieses Spielers.

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
notify(text: string, kind?: NotificationKind, duration?: number): void
```

```lua title="Lua"
aiLib.notify(text, kind, duration)
```

#### Parameter

<TypeTable
  type={{
    text: { type: 'string', description: 'Die Nachricht, bereits übersetzt.', required: true },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'Farbe und Icon der Karte.', default: '"info"' },
    duration: { type: 'number', description: 'Millisekunden auf dem Bildschirm.', default: '4000' },
  }}
/>

Der Typ von kind ist [`NotificationKind`](/de/docs/developers/api/types#notificationkind). Um einen Spieler vom Server aus zu benachrichtigen, nutze das Server-`notify(source, text, kind)`.

#### Rückgabewert

`void`.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

const Locale = createLocale<typeof import("../../locales/en.json")>();

notify(Locale("NO_MONEY"), "error");
notify(Locale("SAVED"), "success", 2000);
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()

aiLib.notify(t('WELCOME'))
aiLib.notify(t('NO_MONEY'), 'error')
aiLib.notify(t('SAVED'), 'success', 2000)
```
</Tab>
</Tabs>

## Fortschrittsbalken

### progress

Führt eine zeitgesteuerte Aktion mit dem Fortschrittsbalken von ai-lib und einer optionalen Animation oder einem Szenario aus und wartet, bis sie endet. Sie endet vorzeitig (abgebrochen), wenn der Spieler stirbt, in ein Fahrzeug steigt, die Abbruchtaste von ai-lib drückt (Standard `Backspace`, nur mit `canCancel`) oder dein Skript `cancelProgress()` aufruft. Ein Fortschritt pro Ressource zur Zeit.

**Seite:** Client · **Wartet:** ja (Promise in TypeScript, hält in Lua den Thread an)

```ts title="Signatur"
progress(options: ProgressOptions): Promise<boolean>
```

```lua title="Lua"
local finished = aiLib.progress(options) -- boolean, innerhalb eines Threads aufrufen
```

#### Parameter

<TypeTable
  type={{
    options: { type: 'ProgressOptions', description: 'Was der Balken zeigt und was der Spieler tun darf. Felder unten.', required: true },
  }}
/>

#### ProgressOptions

<TypeTable
  type={{
    label: { type: 'string', description: 'Text auf dem Balken, bereits übersetzt.', required: true },
    duration: { type: 'number', description: 'Wie lange der Balken läuft, in Millisekunden.', required: true },
    anim: { type: '{ dict: string; clip: string; flag?: number }', description: 'Eine Animation, die für die Dauer abgespielt wird (flag Standard 49: Oberkörper, Schleife, kann sich bewegen). Am Ende gestoppt.' },
    scenario: { type: 'string', description: 'Ein Szenario, das an Ort und Stelle abgespielt wird (WORLD_HUMAN_HAMMERING), wenn es keine anim gibt. Am Ende beendet.' },
    face: { type: 'Vec3', description: 'Der Spieler dreht sich zuerst zu diesem Punkt (eine Zapfsäule, eine Theke, ein Fahrzeug), dauert 600 ms, nur zu Fuß. Nur TypeScript.' },
    canCancel: { type: 'boolean', description: 'Der Spieler darf mit der Abbruchtaste von ai-lib abbrechen.', default: 'false' },
    allowVehicle: { type: 'boolean', description: 'In einem Fahrzeug zu sein bricht nicht ab. Ohne es bricht ein Fahrzeug bei jeder Prüfung ab (auch beim Start).', default: 'false' },
    whileDead: { type: 'boolean', description: 'Läuft weiter, wenn der Spieler zu Boden geht. Standardmäßig bricht das Zu-Boden-Gehen ab, in jedem Death-Skript.', default: 'false' },
    freeze: { type: 'boolean', description: 'Hält den Spieler fest, solange es läuft.', default: 'false' },
    disable: { type: '{ move?: boolean; car?: boolean; mouse?: boolean; combat?: boolean }', description: 'Steuerungen, die gesperrt sind, solange es läuft: move = gehen (Controls 30, 31, 36, 21, 44), car = fahren (63, 64, 71, 72, 75), mouse = umsehen (1, 2, 106), combat = kämpfen (24, 25, 37, 47, 58, 140-143, 257, 263, 264).' },
  }}
/>

#### Rückgabewert

`Promise<boolean>`: `true`, wenn der Balken abgelaufen ist; `false`, wenn er abgebrochen wurde, oder sofort, wenn noch ein anderer Fortschritt deiner Ressource läuft. Lua gibt denselben Boolean zurück.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, createLocale, nearestVehicle, notify, progress } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();

export async function repair(): Promise<void> {
  const vehicle = nearestVehicle(4, { notOwn: true });
  if (!vehicle) return notify(Locale("NO_VEHICLE"), "error");
  const [x = 0, y = 0, z = 0] = GetEntityCoords(vehicle, false);
  const done = await progress({
    label: Locale("REPAIRING"),
    duration: 8000,
    face: { x, y, z },
    anim: { dict: "mini@repair", clip: "fixing_a_player" },
    canCancel: true,
    disable: { move: true, combat: true },
  });
  if (!done) return notify(Locale("CANCELLED"), "error");
  await callAction("mymech:repair", [NetworkGetNetworkIdFromEntity(vehicle)], { fallback: "REPAIR_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()

local function repair()
    CreateThread(function()
        local vehicle = aiLib.nearestVehicle(4.0, { notOwn = true })
        if vehicle == 0 then return aiLib.notify(t('NO_VEHICLE'), 'error') end
        local done = aiLib.progress({
            label = t('REPAIRING'),
            duration = 8000,
            anim = { dict = 'mini@repair', clip = 'fixing_a_player' },
            canCancel = true,
            disable = { move = true, combat = true },
        })
        if not done then return aiLib.notify(t('CANCELLED'), 'error') end
        aiLib.callAction('mymech:repair', { NetworkGetNetworkIdFromEntity(vehicle) }, { fallback = 'REPAIR_FAILED' })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Das Ergebnis ist das Wort des Clients: Ein Cheater kann den Balken überspringen. Wenn der Server für die Aktion bezahlt (Items, Geld, eine Reparatur), starte den Balken vom Server mit `progressFor(source, options)` ([Client-Eingaben](/de/docs/developers/api/lib-server/client-input)): Es antwortet nur mit `true`, wenn auch auf dem Server genug Zeit vergangen ist.
</Callout>

### cancelProgress

Bricht den laufenden Fortschritt deiner Ressource ab, egal ob der Spieler ihn abbrechen darf. Der `progress`-Aufruf wird dann mit `false` erfüllt. Es passiert nichts, wenn kein Fortschritt läuft.

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
cancelProgress(): void
```

```lua title="Lua"
aiLib.progress.cancel()
```

#### Rückgabewert

`void`.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { cancelProgress, onServerEvent } from "@aicore-fivem/lib/client";

// Der Server sagt, das Ziel wurde von jemand anderem ausgeraubt.
onServerEvent("myrob:taken", () => cancelProgress());
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onServerEvent('myrob:taken', function() aiLib.progress.cancel() end)
```
</Tab>
</Tabs>

## Menüs und Dialoge

### menu

Zeigt das Menü von ai-lib und wartet auf die Wahl des Spielers. Pfeiltasten bewegen, Enter wählt. Einträge mit `checked` sind Schalterzeilen, die an Ort und Stelle umschalten, ohne das Menü zu schließen. In einem Untermenü (`back: true`) ergibt ein kurzes Escape `MENU_BACK`, damit du das vorherige Menü öffnen kannst; Escape gedrückt halten schließt.

**Seite:** Client · **Wartet:** ja (Promise in TypeScript, hält in Lua den Thread an)


```lua title="Lua"
local picked = aiLib.menu.show(request, listeners) -- string oder nil, innerhalb eines Threads aufrufen
```

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, createLocale, menu } from "@aicore-fivem/lib/client";
import { MENU_BACK } from "@aicore-fivem/shared";

const Locale = createLocale<typeof import("../../locales/en.json")>();
let engineOn = true;

export async function vehicleMenu(vehicle: number): Promise<void> {
  const pick = await menu({
    title: Locale("VEHICLE"),
    items: [
      { id: "doors", label: Locale("DOORS"), icon: "door-open" },
      { id: "engine", label: Locale("ENGINE"), icon: "power-off", checked: engineOn },
    ],
  }, {
    onToggle: (item, checked) => {
      if (item !== "engine") return;
      engineOn = checked;
      SetVehicleEngineOn(vehicle, checked, false, true);
    },
  });
  if (pick === "doors") await doorsMenu(vehicle);
}

async function doorsMenu(vehicle: number): Promise<void> {
  const pick = await menu({
    title: Locale("DOORS"),
    back: true,
    items: [0, 1, 2, 3].map((door) => ({ id: String(door), label: Locale("DOOR", door + 1) })),
  });
  if (pick === MENU_BACK) return vehicleMenu(vehicle);
  if (pick !== null) SetVehicleDoorOpen(vehicle, Number(pick), false, false);
}
```
</Tab>
<Tab value="Lua">

### itemPicker

Admin-Werkzeuge: zeigt die Item-Auswahl von ai-core. Sie listet jedes Item des aktiven Inventars mit Bild und einer Suche; Klicks füllen eine Liste rechts (1 pro Klick, 10 mit Strg, 100 mit Shift), die am Gewichtslimit des Ziels stoppt. Die Item-Liste wird nur an Admins gesendet.

**Seite:** Client · **Wartet:** ja (Promise in TypeScript, hält in Lua den Thread an)

```ts title="Signatur"
itemPicker(request: ItemPickerRequest): Promise<PickedItem[] | null>
```

```lua title="Lua"
local list = aiLib.itemPicker(request) -- table oder nil, innerhalb eines Threads aufrufen
```

#### Parameter

<TypeTable
  type={{
    request: { type: 'ItemPickerRequest', description: 'Felder unten.', required: true },
  }}
/>

#### ItemPickerRequest

<TypeTable
  type={{
    title: { type: 'string', description: 'Der Titel der Auswahl, bereits übersetzt.', required: true },
    target: { type: 'number', description: 'Server-ID des Spielers, der die Items bekommt: Sein freies Gewicht begrenzt die Liste.', default: 'der Admin, der auswählt' },
  }}
/>

#### Rückgabewert

`Promise<PickedItem[] | null>`: die Liste, die der Admin genommen hat, jede Zeile `{ name: string; count: number }` (count eine ganze Zahl über 0); `null`, wenn die Auswahl geschlossen wurde. Lua gibt die Liste oder `nil` zurück. Die Typen sind [`ItemPickerRequest`](/de/docs/developers/api/types#itempickerrequest) und [`PickedItem`](/de/docs/developers/api/types#pickeditem).

<Tabs items={['TypeScript', 'Lua']}>

```ts

export async function giveItems(target: number): Promise<void> {
  const list = await itemPicker({ title: "Give items", target });
  if (!list || list.length === 0) return;
  await callAction("myadmin:give", [target, list], { fallback: "GIVE_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua

    CreateThread(function()
        local list = aiLib.itemPicker({ title = 'Give items', target = target })

end
```
</Tab>

<Callout type="warn">

</Callout>

## Minispiele

### skillCheck

Der Skill-Check von ai-lib: Eine Nadel läuft pro Stufe einmal um einen Ring, und der Spieler drückt die angezeigte Taste, während sie im grünen Bogen ist. Er hat die übliche FiveM-Skill-Check-Form (`"easy" | "medium" | "hard"` oder `{ areaSize, speedMultiplier }`), daher funktioniert Code, der für den Skill-Check von ox_lib geschrieben wurde, genauso.

**Seite:** Client · **Wartet:** ja (Promise in TypeScript, hält in Lua den Thread an)

```ts title="Signatur"
skillCheck(difficulty: SkillDifficulty | SkillDifficulty[], keys?: string[]): Promise<boolean>
```

```lua title="Lua"
local passed = aiLib.skillCheck(difficulty, keys) -- boolean, innerhalb eines Threads aufrufen
```

#### Parameter

<TypeTable
  type={{
    difficulty: { type: 'SkillDifficulty | SkillDifficulty[]', description: 'Eine Stufe oder eine Liste von Stufen, die nacheinander gespielt werden (höchstens 20).', required: true },
    keys: { type: 'string[]', description: 'Tasten, die eine Stufe verlangen kann: einzelne Buchstaben oder Ziffern. Jede Stufe zeigt eine davon.', default: '["e"]' },
  }}
/>

#### SkillDifficulty

[`SkillDifficulty`](/de/docs/developers/api/types#skilldifficulty) ist eines von:

<TypeTable
  type={{
    '"easy"': { type: 'string', description: 'Grüner Bogen 50 Grad, Nadel 0.6 Umdrehungen pro Sekunde.' },
    '"medium"': { type: 'string', description: 'Grüner Bogen 40 Grad, 0.85 Umdrehungen pro Sekunde.' },
    '"hard"': { type: 'string', description: 'Grüner Bogen 25 Grad, 1 Umdrehung pro Sekunde.' },
    '{ areaSize, speedMultiplier }': { type: '{ areaSize: number; speedMultiplier: number }', description: 'Deine eigene Stufe: areaSize ist der grüne Bogen in Grad (5-180), speedMultiplier multipliziert die easy-Geschwindigkeit (0.2-5).' },
  }}
/>

#### Rückgabewert

`Promise<boolean>`: `true`, wenn jede Stufe getroffen wurde; `false` bei einem Fehlschlag, einer falschen Taste oder Escape.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

```ts
  await callAction("mykeys:hotwire", [netId, passed], { fallback: "HOTWIRE_FAILED" });
}
```

### lockpick

Das Schlossknacken von ai-lib: Der Spieler bewegt den Dietrich mit A / D (oder den Pfeiltasten) und hält W, um das Schloss zu drehen. Das Schloss dreht sich umso weiter, je näher der Dietrich am versteckten Sweet Spot ist; Gewalt nutzt den Dietrich ab.

**Seite:** Client · **Wartet:** ja (Promise in TypeScript, hält in Lua den Thread an)

```ts title="Signatur"
lockpick(options?: LockpickOptions): Promise<LockpickResult>
```

```lua title="Lua"
local result = aiLib.lockpick(options) -- 'opened' | 'broken' | 'cancelled', innerhalb eines Threads aufrufen
```

#### Parameter

<TypeTable
  type={{
    options: { type: 'LockpickOptions', description: 'Felder unten.', default: '{}' },
  }}
/>

#### LockpickOptions

<TypeTable
  type={{
    difficulty: { type: '"easy" | "medium" | "hard"', description: 'Breite des Sweet Spots jedes Stifts: easy 18, medium 11, hard 6 Grad.', default: '"medium"' },
    pins: { type: 'number', description: 'Stifte, die nacheinander gedreht werden (1-6).', default: '1' },
    picks: { type: 'number', description: 'Dietriche, die der Spieler zerbrechen darf, bevor es als broken fehlschlägt (1-10).', default: '1' },
  }}
/>

#### Rückgabewert

`Promise<LockpickResult>` ([`LockpickResult`](/de/docs/developers/api/types#lockpickresult)): `"opened"`, wenn jeder Stift gedreht wurde; `"broken"`, wenn der letzte Dietrich zerbrochen ist (nimm das Dietrich-Item weg); `"cancelled"`, wenn der Spieler Escape gedrückt hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, lockpick } from "@aicore-fivem/lib/client";

export async function pickDoor(doorId: string): Promise<void> {
  const result = await lockpick({ difficulty: "hard", pins: 3, picks: 2 });
  if (result === "cancelled") return;
  await callAction("mydoors:picked", [doorId, result], { fallback: "PICK_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua

    end)
```
