Jede Taste, auf die ein Skript hört, ist ein `Keybind`: Der Spieler kann sie in den GTA-Einstellungen ändern (**Settings > Key Bindings > FiveM**, Einstellungen > Tastenbelegung > FiveM), der Serverbetreiber kann ihren Standard im Admin-Panel von ai-core ändern (Tab **Keybinds**), und nichts fragt Tasten in jedem Frame ab.

### new Keybind

Registriert eine neu belegbare Taste. Die Standardtaste kommt aus dem Admin-Panel von ai-core, wenn der Betreiber dort eine gesetzt hat, sonst aus `defaultKey`. Die Lib registriert die Tastenbelegung, sobald ai-core geantwortet hat (ein Hin und Zurück beim Start); ohne ai-core nutzt sie sofort `defaultKey`.

**Seite:** Client · **Wartet:** nein (die Registrierung wird im Hintergrund abgeschlossen)

```ts title="Signatur"
new Keybind(options: KeybindOptions)
```

```lua title="Lua"
local key = aiLib.Keybind.new(options)
```

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { createLocale, Keybind, NuiScreen } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const screen = new NuiScreen("tablet");

const openKey = new Keybind({
  name: "mytablet_open",
  description: Locale("KEYBIND_OPEN_TABLET"),
  defaultKey: "F5",
  hint: "foot",
  icon: "tablet-screen-button",
  hintLabel: Locale("HINT_TABLET"),
  onPressed: () => {
    if (screen.isOpen) return;
    // Der Seite sagen, welche Taste sie wieder schließt.
    screen.open({ action: "open", data: { closeKey: openKey.currentKey } });
  },
});

// Solange gefesselt, bewirkt die Taste nichts.
export const setCuffed = (cuffed: boolean): void => openKey.disable(cuffed);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local t = aiLib.locale()

local openKey = aiLib.Keybind.new({
    name = 'mytablet_open',
    description = t('KEYBIND_OPEN_TABLET'),
    defaultKey = 'F5',
    hint = 'foot',
    icon = 'tablet-screen-button',
    hintLabel = t('HINT_TABLET'),
    onPressed = function()
        SetNuiFocus(true, true)
        SendNUIMessage({ action = 'open' })
    end,
})

local function setCuffed(cuffed)
    openKey:disable(cuffed)
end
```
</Tab>

<Callout type="info">
Der Belegungsbefehl trägt die Taste: `+<name>_<key>` (`+mytablet_open_F5`). Wenn der Betreiber den Standard im Panel ändert, bekommt die neue Taste ihre eigene Belegung, die jeder Spieler erhält, und die alte reagiert nicht mehr. FiveM behält alte Belegungen und die eigene Belegung jedes Spielers pro Befehl, deshalb ist die Taste Teil des Namens. Eine andere Ressource, die die Taste dieses Keybinds braucht, fragt den Client-Export `GetKeybindKey(name)` von ai-core.
</Callout>

<Callout type="warn">
Halte `name` stabil: Eine Umbenennung erzeugt ein neues Keybind, und jeder Spieler verliert die Taste, die er dem alten zugewiesen hat. Erstelle nie zwei Keybinds mit demselben Namen, auch nicht in verschiedenen Ressourcen.
</Callout>
