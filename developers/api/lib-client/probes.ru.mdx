Вопросы к игре о мире (что перед игроком, на какой высоте земля, как называется эта улица) и загрузчики, которые нужны каждой модели, анимации и эффекту перед использованием.

## Замеры

### raycast

Замер по линии с ответом в том же кадре: во что первым попадает линия от `from` до `to`. Используйте для «на что смотрит игрок», размещения объектов на земле или проверки прямой видимости.

**Сторона:** Клиент · **Ждёт:** нет (блокирует кадр, пока проверка не завершится)

```ts title="Сигнатура"
raycast(from: Vec3, to: Vec3, options?: RaycastOptions): RayHit | null
```

```lua title="Lua"
local hit = aiLib.raycast(from, to, options) -- таблица или nil; from / to это vector3
```

#### Параметры

<TypeTable
  type={{
    from: { type: 'Vec3', description: 'Начало линии. Lua: vector3.', required: true },
    to: { type: 'Vec3', description: 'Конец линии. Lua: vector3.', required: true },
    options: { type: 'RaycastOptions', description: 'Поля ниже.', default: '{}' },
  }}
/>

#### RaycastOptions

<TypeTable
  type={{
    flags: { type: 'number', description: 'Что проверяет замер, в сумме: 1 карта, 2 транспорт, 4 педы, 8 ragdoll, 16 объекты.', default: '1 | 2 | 16 (19)' },
    ignore: { type: 'number', description: 'Сущность, сквозь которую проходит замер.', default: 'локальный пед' },
    options: { type: 'number', description: 'Биты опций замера: 1 игнорировать стекло, 2 игнорировать прозрачное, 4 игнорировать объекты без коллизии.', default: '7' },
  }}
/>

#### Возвращает

`RayHit | null`: `{ coords, normal, entity }` для первого попадания или `null` (`nil`), если линия ни во что не попала.

<TypeTable
  type={{
    coords: { type: 'Vec3', description: 'Точка попадания. Lua: vector3.' },
    normal: { type: 'Vec3', description: 'Нормаль поверхности в точке попадания (куда обращена поверхность). Lua: vector3.' },
    entity: { type: 'number', description: 'Сущность, в которую попали, 0 для карты.' },
  }}
/>

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { raycast } from "@aicore-fivem/lib/client";

/** What the camera looks at within 10 m. */
export function lookedAt(): number {
  const [cx = 0, cy = 0, cz = 0] = GetGameplayCamCoord();
  const [rx = 0, , rz = 0] = GetGameplayCamRot(2);
  const pitch = (rx * Math.PI) / 180;
  const yaw = (rz * Math.PI) / 180;
  const dir = { x: -Math.sin(yaw) * Math.cos(pitch), y: Math.cos(yaw) * Math.cos(pitch), z: Math.sin(pitch) };
  const hit = raycast(
    { x: cx, y: cy, z: cz },
    { x: cx + dir.x * 10, y: cy + dir.y * 10, z: cz + dir.z * 10 },
    { flags: 2 | 4 | 16 },
  );
  return hit?.entity ?? 0;
}
```
</Tab>
<Tab value="Lua">
```lua
local function lookedAt()
    local cam = GetGameplayCamCoord()
    local rot = GetGameplayCamRot(2)
    local pitch, yaw = math.rad(rot.x), math.rad(rot.z)
    local dir = vector3(-math.sin(yaw) * math.cos(pitch), math.cos(yaw) * math.cos(pitch), math.sin(pitch))
    local hit = aiLib.raycast(cam, cam + dir * 10.0, { flags = 2 | 4 | 16 })
    return hit and hit.entity or 0
end
```
</Tab>
</Tabs>

<Callout type="warn">
Это синхронный замер: делайте не больше одного-двух за кадр.
</Callout>

### groundZ

Высота земли под точкой, замер вниз от `z`.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
groundZ(x: number, y: number, z?: number): number | null
```

```lua title="Lua"
local ground = aiLib.groundZ(x, y, z) -- number или nil
```

#### Параметры

<TypeTable
  type={{
    x: { type: 'number', description: 'X в мире.', required: true },
    y: { type: 'number', description: 'Y в мире.', required: true },
    z: { type: 'number', description: 'Высота, с которой начинается замер вниз.', default: '1000' },
  }}
/>

#### Возвращает

`number | null`: высота земли или `null` (`nil`), пока коллизия там не загружена (область далеко от игрока).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groundZ, player } from "@aicore-fivem/lib/client";

const { x, y, z } = player.coords();
const ground = groundZ(x, y, z + 2);
if (ground !== null) console.log(`ground is ${(z - ground).toFixed(2)} m below`);
```
</Tab>
<Tab value="Lua">
```lua
local c = aiLib.player.coords()
local ground = aiLib.groundZ(c.x, c.y, c.z + 2.0)
if ground then print(('ground is %.2f m below'):format(c.z - ground)) end
```
</Tab>
</Tabs>

<Callout type="info">
Чтобы переместить игрока на неизвестную землю, используйте `player.teleport` без `z`: он ждёт коллизию на каждой высоте.
</Callout>

### pedHeadshot

Делает снимок лица педа и ждёт, пока игра его отрисует. Используйте имя текстуры на странице NUI как `https://nui-img/<txd>/<txd>`.

**Сторона:** Клиент · **Ждёт:** да (Promise в TypeScript, в Lua приостанавливает поток)

```ts title="Сигнатура"
pedHeadshot(ped: number, transparent?: boolean, timeoutMs?: number): Promise<{ handle: number; txd: string } | null>
```

```lua title="Lua"
local handle, txd = aiLib.pedHeadshot(ped, transparent, timeout) -- вызывайте внутри потока
```

#### Параметры

<TypeTable
  type={{
    ped: { type: 'number', description: 'Пед, которого нужно сфотографировать.', required: true },
    transparent: { type: 'boolean', description: 'Прозрачный фон вместо стандартного.', default: 'false' },
    timeoutMs: { type: 'number', description: 'Сколько ждать отрисовки, в миллисекундах. В Lua называется timeout.', default: '5000' },
  }}
/>

#### Возвращает

`Promise<{ handle: number; txd: string } | null>`: хэндл снимка и имя его текстуры; `null`, если педа не существует или отрисовка заняла больше тайм-аута. Lua возвращает `handle, txd` или `nil`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { cache, pedHeadshot } from "@aicore-fivem/lib/client";

export async function sendMugshot(): Promise<void> {
  const shot = await pedHeadshot(cache.ped, true);
  if (!shot) return;
  SendNUIMessage({ action: "photo", data: `https://nui-img/${shot.txd}/${shot.txd}` });
  setTimeout(() => UnregisterPedheadshot(shot.handle), 10_000);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local handle, txd = aiLib.pedHeadshot(aiLib.cache.ped, true)
    if not handle then return end
    SendNUIMessage({ action = 'photo', data = ('https://nui-img/%s/%s'):format(txd, txd) })
    Wait(10000)
    UnregisterPedheadshot(handle)
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Вызовите `UnregisterPedheadshot(handle)`, как только снимок больше не показывается.
</Callout>

### onShot

Запускает обработчик в том кадре, когда локальный пед стреляет (стресс, оповещения о выстрелах, гильзы). Одна покадровая проверка на ваш ресурс, включена только пока в руках оружие.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
onShot(handler: (weapon: number) => void): () => void
```

```lua title="Lua"
aiLib.onShot(function(weapon) end) -- ничего не возвращает
```

#### Параметры

<TypeTable
  type={{
    handler: { type: '(weapon: number) => void', description: 'Получает хэш оружия, из которого выстрелили. Выполняется внутри кадра: делайте его дешёвым.', required: true },
  }}
/>

#### Возвращает

TypeScript: `() => void`, функция, которая удаляет обработчик. Lua ничего не возвращает (обработчик остаётся).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onShot } from "@aicore-fivem/lib/client";

let lastAlert = 0;
onShot(() => {
  if (GetGameTimer() - lastAlert < 30_000) return; // одно оповещение за 30 с
  lastAlert = GetGameTimer();
  emitNet("mypolice:shots");
});
```
</Tab>
<Tab value="Lua">
```lua
local lastAlert = 0
aiLib.onShot(function()
    if GetGameTimer() - lastAlert < 30000 then return end
    lastAlert = GetGameTimer()
    TriggerServerEvent('mypolice:shots')
end)
```
</Tab>
</Tabs>

## Загрузка игровых ресурсов

Модели, анимации, эффекты и текстуры нужно загрузить перед использованием. Каждый загрузчик запрашивает ресурс и ждёт его готовности. Освобождайте его, когда закончите, как сказано в каждой записи.

### requestModel

Загружает модель (пед, транспорт, объект) и возвращает её хэш.

**Сторона:** Клиент · **Ждёт:** да (Promise в TypeScript, в Lua приостанавливает поток)

```ts title="Сигнатура"
requestModel(model: string | number, timeoutMs?: number): Promise<number>
```

```lua title="Lua"
local hash = aiLib.requestModel(model, timeout) -- integer или nil, вызывайте внутри потока
```

#### Параметры

<TypeTable
  type={{
    model: { type: 'string | number', description: 'Имя или хэш модели.', required: true },
    timeoutMs: { type: 'number', description: 'Сколько ждать, в миллисекундах. В Lua называется timeout.', default: '10000' },
  }}
/>

#### Возвращает

`Promise<number>`: хэш модели после загрузки. Он **отклоняется**, если модели нет в файлах игры или она не загрузилась вовремя. Lua возвращает хэш или `nil` в обоих случаях.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { requestModel } from "@aicore-fivem/lib/client";

export async function placeCone(x: number, y: number, z: number): Promise<number> {
  const hash = await requestModel("prop_roadcone02a");
  const cone = CreateObject(hash, x, y, z, false, false, false);
  SetModelAsNoLongerNeeded(hash);
  PlaceObjectOnGroundProperly(cone);
  return cone;
}
```
</Tab>
<Tab value="Lua">
```lua
local function placeCone(x, y, z)
    local hash = aiLib.requestModel('prop_roadcone02a')
    if not hash then return 0 end
    local cone = CreateObject(hash, x, y, z, false, false, false)
    SetModelAsNoLongerNeeded(hash)
    PlaceObjectOnGroundProperly(cone)
    return cone
end
```
</Tab>
</Tabs>

<Callout type="info">
Вызовите `SetModelAsNoLongerNeeded(hash)`, как только сущность создана.
</Callout>

CreateThread(function()
    local dict = aiLib.requestAnimDict('anim@amb@nightclub@dancers@crowddance_facedj@')

</Tab>
</Tabs>

<Callout type="info">
Вызовите `RemoveAnimDict(dict)`, когда анимация больше не проигрывается. `player.playAnim` загружает и освобождает словарь за вас.
</Callout>

### requestWeaponAsset

Загружает модель и ресурсы оружия и возвращает его хэш.

**Сторона:** Клиент · **Ждёт:** да (Promise в TypeScript, в Lua приостанавливает поток)

```ts title="Сигнатура"
requestWeaponAsset(weapon: string | number, timeoutMs?: number): Promise<number>
```

```lua title="Lua"
local hash = aiLib.requestWeaponAsset(weapon, timeout) -- integer или nil, вызывайте внутри потока
```

#### Параметры

<TypeTable
  type={{
    weapon: { type: 'string | number', description: 'Имя оружия (WEAPON_PISTOL) или хэш.', required: true },
    timeoutMs: { type: 'number', description: 'Сколько ждать, в миллисекундах. В Lua называется timeout.', default: '10000' },
  }}
/>

#### Возвращает

`Promise<number>`: хэш оружия после загрузки. Он **отклоняется**, если оружие не загрузилось вовремя. Lua возвращает хэш или `nil`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { player, requestWeaponAsset } from "@aicore-fivem/lib/client";

export async function showcasePistol(): Promise<number> {
  const hash = await requestWeaponAsset("WEAPON_PISTOL");
  const { x, y, z } = player.coords();
  const object = CreateWeaponObject(hash, 0, x, y, z + 1, true, 1, 0);
  RemoveWeaponAsset(hash);
  return object;
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local hash = aiLib.requestWeaponAsset('WEAPON_PISTOL')
    if not hash then return end
    local c = aiLib.player.coords()
    CreateWeaponObject(hash, 0, c.x, c.y, c.z + 1.0, true, 1.0, 0)
    RemoveWeaponAsset(hash)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Вызовите `RemoveWeaponAsset(hash)`, когда закончите.
</Callout>
