**Bölge** (zone), oyuncu içine girdiğinde ya da çıktığında kod çalıştıran bir alandır: bir semte girmek, bir hız sınırı alanı, yalnızca yakındayken çizilen bir marker. Oyuncunun o yerde bir şey *yapması* gerekiyorsa (bir tuşa basmak, bir target seçeneği seçmek) bunun yerine bir [nokta](/tr/docs/developers/api/lib-client/points) kullan: prompt’u, target’ı, ped’i ve blip’i zaten bağlanmış bir bölgedir.

TypeScript’te her bölge, tüm resource’lar için ai-lib’in tek denetleyicisi tarafından kontrol edilir (bölgeler 64 m’lik bir ızgarada durur; bu yüzden bir milyon bölge birkaç bölgeyle aynı maliyettedir). Resource’un kendi bölgelerini yalnızca ai-lib çalışmıyorken kendisi kontrol eder. Lua’da her resource bölgeleri için tek bir zamanlayıcı görevi çalıştırır.

### new Zones

Bir bölge grubu oluşturur. Dosyanın en üstünde, özellik başına bir grup oluştur.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
new Zones()
```

```lua title="Lua"
local zones = aiLib.Zones.new()
```

#### Dönüş değeri

Aşağıdaki metotlara sahip bir `Zones` grubu.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { Zones } from "@aifivem/lib/client";

const zones = new Zones();
```
</Tab>
<Tab value="Lua">
```lua
local zones = aiLib.Zones.new()
```
</Tab>
</Tabs>

### zones.add

Bir bölge ekler ya da aynı id’ye sahip bölgenin yerine geçer. Yerine geçilen bölgenin içinde oyuncu varsa önce onun `onExit`’i çalışır.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
zones.add(id: string, options: ZoneOptions): void
```

```lua title="Lua"
zones:add(id, options)
```

#### Parametreler

<TypeTable
  type={{
    id: { type: 'string', description: 'Bu grup içinde benzersiz. Aynı id eski bölgenin yerine geçer.', required: true },
    options: { type: 'ZoneOptions', description: 'Şekil ve callback’ler. Alanlar aşağıda.', required: true },
  }}
/>

#### ZoneOptions

<TypeTable
  type={{
    shape: { type: 'ZoneShape', description: 'Alan: bir küre, bir silindir ya da bir çokgen. Şekiller aşağıda.', required: true },
    interval: { type: 'number', description: 'Bölgenin ne sıklıkla kontrol edildiği, milisaniye cinsinden (en az 50). Bir market yaklaşık 500’e, hızlı bir tetikleyici yaklaşık 100’e ihtiyaç duyar.', default: '500' },
    onEnter: { type: '() => void', description: 'Oyuncu içeri girdi. Fırlatılan bir hata loglanır.' },
    onExit: { type: '() => void', description: 'Oyuncu çıktı ya da oyuncu içerideyken bölge kaldırıldı veya yerine başkası geçti.' },
  }}
/>

#### ZoneShape

[`ZoneShape`](/tr/docs/developers/api/types#zoneshape), `type`’a göre seçilen üç nesneden biridir:

<TypeTable
  type={{
    '"sphere"': { type: '{ type: "sphere"; center: Vec3; radius: number }', description: 'center etrafında radius metrelik bir küre.' },
    '"cylinder"': { type: '{ type: "cylinder"; center: Vec3; radius: number; height: number }', description: 'Zeminde radius metrelik bir daire; center’dan height metre yukarı ve aşağı (odalar, katlar).' },
    '"poly"': { type: '{ type: "poly"; points: Array<{ x: number; y: number }>; minZ: number; maxZ: number }', description: 'İki yükseklik arasında bir zemin çokgeni (kenar boyunca sırayla noktalar).' },
  }}
/>

Lua’da `center` bir `vector3`, noktalar da `{ x = ..., y = ... }` tabloları olabilir.

#### Dönüş değeri

`void`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, notify, Zones } from "@aifivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const zones = new Zones();

zones.add("safezone", {
  shape: { type: "cylinder", center: { x: 298.6, y: -584.5, z: 43.3 }, radius: 60, height: 30 },
  onEnter: () => notify(Locale("SAFEZONE_IN"), "info"),
  onExit: () => notify(Locale("SAFEZONE_OUT"), "info"),
});

zones.add("yard", {
  shape: {
    type: "poly",
    points: [
      { x: 1700.1, y: 2560.4 },
      { x: 1780.6, y: 2560.4 },
      { x: 1780.6, y: 2620.2 },
      { x: 1700.1, y: 2620.2 },
    ],
    minZ: 40,
    maxZ: 60,
  },
  interval: 1000,
  onEnter: () => SetPedMoveRateOverride(PlayerPedId(), 0.8),
});
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()
local zones = aiLib.Zones.new()

zones:add('safezone', {
    shape = { type = 'cylinder', center = vector3(298.6, -584.5, 43.3), radius = 60.0, height = 30.0 },
    onEnter = function() aiLib.notify(t('SAFEZONE_IN'), 'info') end,
    onExit = function() aiLib.notify(t('SAFEZONE_OUT'), 'info') end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Admin panelinde `zone` widget’ıyla çizilen bir bölge köşeler verir; onları `@aifivem/lib/shared`’daki `polyFromCorners(corners, height)` ile bir çokgene çevir. Server aynı şekilleri `zoneContains(shape, x, y, z)` ile test edebilir.
</Callout>

### zones.remove

Tek bir bölgeyi kaldırır. Oyuncu içerideyse `onExit` çalışır. Bilinmeyen bir id hiçbir şey yapmaz.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
zones.remove(id: string): void
```

```lua title="Lua"
zones:remove(id)
```

#### Parametreler

<TypeTable
  type={{
    id: { type: 'string', description: 'add’e verilen id.', required: true },
  }}
/>

#### Dönüş değeri

`void`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
zones.remove("safezone");
```
</Tab>
<Tab value="Lua">
```lua
zones:remove('safezone')
```
</Tab>
</Tabs>

### zones.clear

Grubun tüm bölgelerini kaldırır; oyuncunun içinde olduğu bölgeler için `onExit` çalışır.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
zones.clear(): void
```

```lua title="Lua"
zones:clear()
```

#### Dönüş değeri

`void`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
onServerEvent("myscript:eventOver", () => zones.clear());
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onServerEvent('myscript:eventOver', function() zones:clear() end)
```
</Tab>
</Tabs>

### zones.isInside

Son kontrole göre oyuncunun bir bölgenin içinde olup olmadığı.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
zones.isInside(id: string): boolean
```

```lua title="Lua"
local inside = zones:isInside(id)
```

#### Parametreler

<TypeTable
  type={{
    id: { type: 'string', description: 'add’e verilen id.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: içerideyken `true`; dışarıdayken ya da bilinmeyen bir id için `false`. Son kontrolü yansıtır; bu yüzden en fazla `interval` ms eski olabilir.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
if (zones.isInside("safezone")) return notify(Locale("NO_WEAPONS_HERE"), "error");
```
</Tab>
<Tab value="Lua">
```lua
if zones:isInside('safezone') then return aiLib.notify(t('NO_WEAPONS_HERE'), 'error') end
```
</Tab>
</Tabs>

### zones.size

Grubun kaç bölge tuttuğu.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
zones.size: number // salt okunur özellik
```

Lua karşılığı yok.

#### Dönüş değeri

`number`: bu gruptaki bölge sayısı.

#### Örnek

```ts
console.log(`${zones.size} zones loaded`);
```
