Bir script’in dinlediği her tuş bir `Keybind`’dır: oyuncu onu GTA ayarlarında (**Settings > Key Bindings > FiveM**) değiştirebilir, sunucu sahibi varsayılanını ai-core’un admin panelinde (**Keybinds** sekmesi) değiştirebilir ve hiçbir şey her karede tuşları yoklamaz.

### new Keybind

Yeniden atanabilir bir tuş kaydeder. Varsayılan tuş, sahip orada bir tane ayarladıysa ai-core’un admin panelinden, yoksa `defaultKey`’den gelir. Lib, tuş eşlemesini ai-core cevap verdikten sonra (açılışta tek bir gidiş dönüş) kaydeder; ai-core yoksa hemen `defaultKey`’i kullanır.

**Taraf:** Client · **Bekler:** hayır (kayıt arka planda biter)

```ts title="Signature"
new Keybind(options: KeybindOptions)
```

```lua title="Lua"
local key = aiLib.Keybind.new(options)
```

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { createLocale, Keybind, NuiScreen } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const screen = new NuiScreen("tablet");

const openKey = new Keybind({
  name: "mytablet_open",
  description: Locale("KEYBIND_OPEN_TABLET"),
  defaultKey: "F5",
  hint: "foot",
  icon: "tablet-screen-button",
  hintLabel: Locale("HINT_TABLET"),
  onPressed: () => {
    if (screen.isOpen) return;
    // Sayfaya onu hangi tuşun tekrar kapattığını söyle.
    screen.open({ action: "open", data: { closeKey: openKey.currentKey } });
  },
});

// Kelepçeliyken tuş hiçbir şey yapmaz.
export const setCuffed = (cuffed: boolean): void => openKey.disable(cuffed);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local t = aiLib.locale()

local openKey = aiLib.Keybind.new({
    name = 'mytablet_open',
    description = t('KEYBIND_OPEN_TABLET'),
    defaultKey = 'F5',
    hint = 'foot',
    icon = 'tablet-screen-button',
    hintLabel = t('HINT_TABLET'),
    onPressed = function()
        SetNuiFocus(true, true)
        SendNUIMessage({ action = 'open' })
    end,
})

local function setCuffed(cuffed)
    openKey:disable(cuffed)
end
```
</Tab>
</Tabs>

<Callout type="info">
Eşleme komutu tuşu taşır: `+<name>_<key>` (`+mytablet_open_F5`). Sahip panelde varsayılanı değiştirdiğinde yeni tuş, her oyuncunun aldığı kendi eşlemesini alır ve eskisi çalışmayı bırakır. FiveM eski eşlemeleri ve her oyuncunun kendi atamasını komut başına tutar; tuşun adın parçası olmasının sebebi budur. Bu keybind’in tuşuna ihtiyaç duyan başka bir resource, ai-core’un `GetKeybindKey(name)` client export’una sorar.
</Callout>

<Callout type="warn">
`name`’i sabit tut: onu yeniden adlandırmak yeni bir keybind oluşturur ve her oyuncu eskisine atadığı tuşu kaybeder. Farklı resource’larda bile olsa asla aynı ada sahip iki keybind oluşturma.
</Callout>
