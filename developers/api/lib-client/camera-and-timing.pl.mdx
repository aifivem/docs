Kamera skryptowa dla salonów i scen, zadanie co klatkę, które włączasz tylko wtedy, gdy jest potrzebne, kliencka połowa strumieniowania obszarów serwera i zegar serwera do odliczań. Praca okresowa w ogóle to `every(ms, fn)` (zobacz [Lib: shared i fivem](/pl/docs/developers/api/lib-shared)); nigdy `setInterval` ani gołe `setTick`.

## ScriptCamera

### new ScriptCamera

Kamera skryptowa: widok salonu sklepu, edytor, scena, lornetka. `start` ją tworzy i pokazuje, pozostałe metody ją przesuwają i zmieniają, `stop` płynnie wraca do kamery gry i ją niszczy. Kamera, która nadal działa, gdy twój zasób się zatrzymuje, jest od razu oddawana, więc gracz nigdy w niej nie utknie.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
new ScriptCamera(type?: string)
```

Brak odpowiednika w Lua: zasoby Lua używają `CreateCam`, `RenderScriptCams` i `DestroyCam`.

```ts

const camera = new ScriptCamera();

}

  camera.glideTo({ x: -47.5, y: -1093.8, z: 27.2 }, { pointAt: CAR, fov: 45 }, 1200);
}

export function closeShowroom(): void {
  camera.stop(800);
}
```

### camera.glideTo

**Strona:** Klient · **Czeka:** nie


## TickLoop

### new TickLoop

Zadanie co klatkę (`every(0, fn)` w jedynym harmonogramie twojego zasobu), które jest wyłączone, dopóki go nie włączysz. Używaj go do wszystkiego, co musi działać co klatkę tylko czasami: rysowanie markera w pobliżu, podgląd stawiania, blokada strzelania przy celowaniu w przyjaciela.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
new TickLoop(onFrame: () => void, name?: string)
```

Brak odpowiednika w Lua: `aiLib.every(0, fn, { active = false, name = name })` i `job:set(active)`.

#### Parametry

<TypeTable

    name: { type: 'string', description: 'Nazwa pokazywana w logach błędów.' },
  }}
/>

#### Składowe

<TypeTable

  }}

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

  DrawLightWithRange(SPOT.x, SPOT.y, SPOT.z + 2, 61, 247, 158, 8, 4);

  shape: { type: "sphere", center: SPOT, radius: 25 },
  onEnter: () => light.set(true),
  onExit: () => light.set(false),
```

<Callout type="info">
Każde zadanie twojego zasobu działa z jednego `setTick`, który istnieje tylko wtedy, gdy jakieś zadanie jest włączone. Utwórz pętlę raz na górze pliku i ją przełączaj, zamiast tworzyć nową przy każdym starcie.
</Callout>

## AreaFollower

### new AreaFollower

Kliencka połowa serwerowego `AreaStream` ([Strumieniowanie obszarów](/pl/docs/developers/api/lib-server/area-stream)): mówi serwerowi, w której komórce siatki stoi gracz, za każdym razem, gdy się zmieni (sprawdzane co 2 sekundy po uruchomieniu), więc serwer wysyła tylko obiekty świata (zrzuty, rośliny, postawione propy) wokół gracza. Utwórz jeden na górze pliku.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
new AreaFollower(event: string, cellSize?: number)
```

Brak odpowiednika w Lua.

#### Parametry

<TypeTable
  type={{
    event: { type: 'string', description: 'Zdarzenie sieciowe, którego słucha serwer; dostaje (cx, cy), współrzędne komórki.', required: true },
    cellSize: { type: 'number', description: 'Rozmiar komórki w metrach. Musi się zgadzać z cellSize strumienia serwera.', default: '64' },
  }}
/>

#### Składowe

<TypeTable
  type={{
    'start()': { type: '() => void', description: 'Wysyła bieżącą komórkę teraz i przy każdej zmianie.' },
    'stop()': { type: '() => void', description: 'Przestaje zgłaszać.' },
  }}
/>

#### Przykład

```ts title="resource/client/index.ts"
import { AreaFollower, onServerEvent } from "@aicore-fivem/lib/client";

const follower = new AreaFollower("myplants:cell");
follower.start();

const plants = new Map<number, unknown>();

// Strumień wysyła (reset, puts, removes): jedna migawka z reset true, potem tylko zmiany.
onServerEvent(
  "myplants:area",
  {
    args: ([reset, puts, removes]) =>
      typeof reset === "boolean" && Array.isArray(puts) && Array.isArray(removes)
        ? ([reset, puts, removes] as const)
        : null,
  },
  (reset, puts, removes) => {
    if (reset) plants.clear();
    for (const plant of puts as Array<{ id?: unknown } | null>)
      if (typeof plant?.id === "number") plants.set(plant.id, plant);
    for (const id of removes) if (typeof id === "number") plants.delete(id);
  },
);
```

<Callout type="warn">
Serwer sprawdza zgłoszoną komórkę względem prawdziwej pozycji gracza (`followReported` przyjmuje tylko komórki w odległości jednej komórki od peda), więc oszust nie może poprosić o odległy obszar.
</Callout>

## ServerClock

### new ServerClock

Zegar serwera na kliencie. Zegary klienta i serwera mogą się różnić, więc odliczanie do czasu serwera (cooldown napadu, koniec aukcji) trzeba najpierw zamienić na czas lokalny. Wywołuj `sync` z `Date.now()` serwera, gdy tylko przyjdzie migawka albo wiadomość startowa.

**Strona:** Klient (z `@aicore-fivem/lib/shared`) · **Czeka:** nie

```ts title="Sygnatura"
new ServerClock()
```

Brak odpowiednika w Lua.

#### Składowe

<TypeTable
  type={{
    'sync(serverNow)': { type: '(serverNow: number) => void', description: 'Bierze przesunięcie z właśnie otrzymanego Date.now() serwera.' },
    'now()': { type: '() => number', description: 'Date.now() serwera w tej chwili.' },
    'toLocal(serverTime)': { type: '(serverTime: number) => number', description: 'Czas serwera jako lokalny czas Date.now(), do odliczań na lokalnym zegarze.' },
  }}
/>

#### Przykład

```ts title="resource/client/index.ts"
import { every, onServerEvent } from "@aicore-fivem/lib/client";
import { ServerClock } from "@aicore-fivem/lib/shared";

const clock = new ServerClock();
let endsAt = 0; // czas lokalny

onServerEvent(
  "myauction:state",
  { args: ([now, ends]) => (typeof now === "number" && typeof ends === "number" ? [now, ends] : null) },
  (now, ends) => {
    clock.sync(now);
    endsAt = clock.toLocal(ends);
  },
);

every(1000, () => {
  const left = Math.max(0, Math.round((endsAt - Date.now()) / 1000));
  SendNUIMessage({ action: "countdown", data: left });
});
```

<Callout type="info">
Serwer wysyła czas końca raz; klient odlicza na własnym zegarze. Nigdy nie wysyłaj pozostałego czasu co sekundę.
</Callout>
