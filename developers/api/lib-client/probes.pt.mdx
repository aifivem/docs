## Sondagens

### raycast

Uma sondagem por linha respondida no mesmo frame: o que a linha de `from` até `to` atinge primeiro. Use para "para onde o jogador está olhando", colocar objetos no chão ou linha de visão.

**Lado:** Cliente · **Espera:** não (bloqueia o frame até o teste terminar)

```ts title="Signature"
raycast(from: Vec3, to: Vec3, options?: RaycastOptions): RayHit | null
```

```lua title="Lua"
local hit = aiLib.raycast(from, to, options) -- table ou nil; from / to são vector3
```

#### Parâmetros

<TypeTable
  type={{
    from: { type: 'Vec3', description: 'Início da linha. Lua: um vector3.', required: true },
    to: { type: 'Vec3', description: 'Fim da linha. Lua: um vector3.', required: true },
    options: { type: 'RaycastOptions', description: 'Campos abaixo.', default: '{}' },
  }}
/>

#### RaycastOptions

<TypeTable
  type={{
    flags: { type: 'number', description: 'O que a sondagem testa, somado: 1 mapa, 2 veículos, 4 peds, 8 ragdolls, 16 objetos.', default: '1 | 2 | 16 (19)' },
    ignore: { type: 'number', description: 'Uma entidade que a sondagem atravessa.', default: 'o ped local' },
    options: { type: 'number', description: 'Bits de opção da sondagem: 1 ignora vidro, 2 ignora o que é transparente, 4 ignora o que não tem colisão.', default: '7' },
  }}
/>

#### Retorno

`RayHit | null`: `{ coords, normal, entity }` para o primeiro acerto, ou `null` (`nil`) quando a linha não atinge nada.

<TypeTable
  type={{
    coords: { type: 'Vec3', description: 'O ponto de acerto. Lua: um vector3.' },
    normal: { type: 'Vec3', description: 'A normal da superfície no ponto de acerto (para onde a superfície está virada). Lua: um vector3.' },
    entity: { type: 'number', description: 'A entidade atingida, 0 para o mapa.' },
  }}
/>

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { raycast } from "@aicore-fivem/lib/client";

/** What the camera looks at within 10 m. */
export function lookedAt(): number {
  const [cx = 0, cy = 0, cz = 0] = GetGameplayCamCoord();
  const [rx = 0, , rz = 0] = GetGameplayCamRot(2);
  const pitch = (rx * Math.PI) / 180;
  const yaw = (rz * Math.PI) / 180;
  const dir = { x: -Math.sin(yaw) * Math.cos(pitch), y: Math.cos(yaw) * Math.cos(pitch), z: Math.sin(pitch) };
  const hit = raycast(
    { x: cx, y: cy, z: cz },
    { x: cx + dir.x * 10, y: cy + dir.y * 10, z: cz + dir.z * 10 },
    { flags: 2 | 4 | 16 },
  );
  return hit?.entity ?? 0;
}
```
</Tab>
<Tab value="Lua">
```lua
local function lookedAt()
    local cam = GetGameplayCamCoord()
    local rot = GetGameplayCamRot(2)
    local pitch, yaw = math.rad(rot.x), math.rad(rot.z)
    local dir = vector3(-math.sin(yaw) * math.cos(pitch), math.cos(yaw) * math.cos(pitch), math.sin(pitch))
    local hit = aiLib.raycast(cam, cam + dir * 10.0, { flags = 2 | 4 | 16 })
    return hit and hit.entity or 0
end
```
</Tab>
</Tabs>

<Callout type="warn">
É uma sondagem síncrona: limite a uma ou duas por frame.
</Callout>

### groundZ

A altura do chão sob um ponto, sondando para baixo a partir de `z`.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
groundZ(x: number, y: number, z?: number): number | null
```

```lua title="Lua"
local ground = aiLib.groundZ(x, y, z) -- number ou nil
```

#### Parâmetros

<TypeTable
  type={{
    x: { type: 'number', description: 'X no mundo.', required: true },
    y: { type: 'number', description: 'Y no mundo.', required: true },
    z: { type: 'number', description: 'Altura de onde a sondagem começa, descendo.', default: '1000' },
  }}
/>

#### Retorno

`number | null`: a altura do chão, ou `null` (`nil`) enquanto a colisão ali não está carregada (a área está longe do jogador).

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groundZ, player } from "@aicore-fivem/lib/client";

const { x, y, z } = player.coords();
const ground = groundZ(x, y, z + 2);
if (ground !== null) console.log(`ground is ${(z - ground).toFixed(2)} m below`);
```
</Tab>
<Tab value="Lua">
```lua
local c = aiLib.player.coords()
local ground = aiLib.groundZ(c.x, c.y, c.z + 2.0)
if ground then print(('ground is %.2f m below'):format(c.z - ground)) end
```
</Tab>
</Tabs>

<Callout type="info">
Para mover o jogador para um chão desconhecido, use `player.teleport` sem `z`: ele espera a colisão em cada altura.
</Callout>

### pedHeadshot

Tira uma foto de rosto (headshot) de um ped e espera até o jogo renderizá-la. Use o nome da textura em uma página NUI como `https://nui-img/<txd>/<txd>`.

**Lado:** Cliente · **Espera:** sim (Promise em TypeScript, pausa a thread em Lua)

```ts title="Signature"
pedHeadshot(ped: number, transparent?: boolean, timeoutMs?: number): Promise<{ handle: number; txd: string } | null>
```

```lua title="Lua"
local handle, txd = aiLib.pedHeadshot(ped, transparent, timeout) -- chame dentro de uma thread
```

#### Parâmetros

<TypeTable
  type={{
    ped: { type: 'number', description: 'O ped a fotografar.', required: true },
    transparent: { type: 'boolean', description: 'Um fundo transparente em vez do padrão.', default: 'false' },
    timeoutMs: { type: 'number', description: 'Quanto tempo esperar pela renderização, em milissegundos. Em Lua se chama timeout.', default: '5000' },
  }}
/>

#### Retorno

`Promise<{ handle: number; txd: string } | null>`: o handle do headshot e o nome da textura; `null` quando o ped não existe ou a renderização demorou mais que o timeout. Lua retorna `handle, txd`, ou `nil`.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { cache, pedHeadshot } from "@aicore-fivem/lib/client";

export async function sendMugshot(): Promise<void> {
  const shot = await pedHeadshot(cache.ped, true);
  if (!shot) return;
  SendNUIMessage({ action: "photo", data: `https://nui-img/${shot.txd}/${shot.txd}` });
  setTimeout(() => UnregisterPedheadshot(shot.handle), 10_000);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local handle, txd = aiLib.pedHeadshot(aiLib.cache.ped, true)
    if not handle then return end
    SendNUIMessage({ action = 'photo', data = ('https://nui-img/%s/%s'):format(txd, txd) })
    Wait(10000)
    UnregisterPedheadshot(handle)
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Chame `UnregisterPedheadshot(handle)` assim que a imagem não for mais mostrada.
</Callout>

### onShot

Roda um handler no frame em que o ped local dispara um tiro (estresse, alertas de tiro, cápsulas). Uma verificação por frame para o seu recurso, ligada só enquanto há uma arma na mão.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
onShot(handler: (weapon: number) => void): () => void
```

```lua title="Lua"
aiLib.onShot(function(weapon) end) -- não retorna nada
```

#### Parâmetros

<TypeTable
  type={{
    handler: { type: '(weapon: number) => void', description: 'Recebe o hash da arma que disparou. Roda dentro do frame: mantenha-o leve.', required: true },
  }}
/>

#### Retorno

TypeScript: `() => void`, uma função que remove o handler. Lua não retorna nada (o handler fica).

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onShot } from "@aicore-fivem/lib/client";

let lastAlert = 0;
onShot(() => {
  if (GetGameTimer() - lastAlert < 30_000) return; // um alerta a cada 30 s
  lastAlert = GetGameTimer();
  emitNet("mypolice:shots");
});
```
</Tab>
<Tab value="Lua">
```lua
local lastAlert = 0
aiLib.onShot(function()
    if GetGameTimer() - lastAlert < 30000 then return end
    lastAlert = GetGameTimer()
    TriggerServerEvent('mypolice:shots')
end)
```
</Tab>
</Tabs>

## Carregando assets do jogo

Modelos, animações, efeitos e texturas precisam ser carregados antes do uso. Cada carregador pede o asset e espera até ele ficar pronto. Libere-o quando terminar, como cada entrada indica.

### requestModel

Carrega um modelo (ped, veículo, objeto) e dá o hash dele.

**Lado:** Cliente · **Espera:** sim (Promise em TypeScript, pausa a thread em Lua)

```ts title="Signature"
requestModel(model: string | number, timeoutMs?: number): Promise<number>
```

```lua title="Lua"
local hash = aiLib.requestModel(model, timeout) -- integer ou nil, chame dentro de uma thread
```

#### Parâmetros

<TypeTable
  type={{
    model: { type: 'string | number', description: 'Nome ou hash do modelo.', required: true },
    timeoutMs: { type: 'number', description: 'Quanto tempo esperar, em milissegundos. Em Lua se chama timeout.', default: '10000' },
  }}
/>

#### Retorno

`Promise<number>`: o hash do modelo depois de carregado. Ela **rejeita** quando o modelo não existe nos arquivos do jogo ou não carrega a tempo. Lua retorna o hash, ou `nil` nos dois casos.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { requestModel } from "@aicore-fivem/lib/client";

export async function placeCone(x: number, y: number, z: number): Promise<number> {
  const hash = await requestModel("prop_roadcone02a");
  const cone = CreateObject(hash, x, y, z, false, false, false);
  SetModelAsNoLongerNeeded(hash);
  PlaceObjectOnGroundProperly(cone);
  return cone;
}
```
</Tab>
<Tab value="Lua">
```lua
local function placeCone(x, y, z)
    local hash = aiLib.requestModel('prop_roadcone02a')
    if not hash then return 0 end
    local cone = CreateObject(hash, x, y, z, false, false, false)
    SetModelAsNoLongerNeeded(hash)
    PlaceObjectOnGroundProperly(cone)
    return cone
end
```
</Tab>
</Tabs>

<Callout type="info">
Chame `SetModelAsNoLongerNeeded(hash)` assim que a entidade for criada.
</Callout>
