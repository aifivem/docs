Bu nesneler asla belirli bir script ile konuşmaz. **ai-core**’a sorarlar ve ai-core, sunucunun o iş için çalıştırdığı script hangisiyse ona iletir: ai-death ya da başka bir ölüm script’i, ai-appearance ya da tgiann-clothing, desteklenen herhangi bir emote ya da radyal script’i. Sahip birini değiştirdiğinde script’in çalışmaya devam eder. Katmanların nasıl çalıştığı [Katmanlar ve köprü](/tr/docs/developers/layers) sayfasındadır.

O türden hiçbir script çalışmıyorken çağrılar, her girdinin söylediği gibi `false`, `null` ya da oyunun kendi değeriyle cevap verir.

## medical

### medical.isDead

Hangi ölüm script’i çalışıyorsa, yerel oyuncunun yerde (ölü ya da son nefeste) olup olmadığı. Ölüm script’leri yerdeki bir ped’i canlandırmak için canlı tutar; bu yüzden tek başına `IsEntityDead` onları kaçırır. İlk çağrıdan sonra bir bellek okuması.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
medical.isDead(): boolean
```

Lua karşılığı yok: `exports['ai-core']:IsDead()` çağır ve yerel `ai-core:client:dead` (`dead`) event’ini dinle.

#### Dönüş değeri

`boolean`: ai-core’un medical katmanı oyuncunun yerde olduğunu söylüyorsa ya da ped oyun için ölüyse `true`.

#### Örnek

```ts
import { medical, notify } from "@aicore-fivem/lib/client";

RegisterCommand(
  "phone",
  () => {
    if (medical.isDead()) return notify("You cannot use the phone now", "error");
    SetNuiFocus(true, true);
  },
  false,
);
```

### medical.onChange

Yerel oyuncu yere düştüğünde ya da ayağa kalktığında bir handler çalıştırır.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
medical.onChange(fn: (dead: boolean) => void): void
```

Lua karşılığı yok: `AddEventHandler('ai-core:client:dead', function(dead) end)`.

#### Parametreler

<TypeTable
  type={{
    fn: { type: '(dead: boolean) => void', description: 'Oyuncu yere düştüğünde true, ayağa kalktığında false alır.', required: true },
  }}
/>

#### Dönüş değeri

`void`.

#### Örnek

```ts
import { medical, Points } from "@aicore-fivem/lib/client";

const points = new Points();
medical.onChange(() => points.refresh()); // canShow’u medical.isDead()’i okuyan noktalar
```

## appearance

Hangi kıyafet script’i çalışıyorsa, ai-core’un görünüm katmanı üzerinden ped’lerin görünümleri.

### appearance.apply

Kayıtlı bir görünümü, görünümün modelindeki bir ped’e giydirir. Görünümü server’da `appearance.get(charId)` ile al, ped’i `look.model` ile oluştur, sonra uygula. Oyuncunun kendi ped’inde kıyafetlerini değiştirir.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
appearance.apply(ped: number, look: CharacterAppearance): boolean
```

```lua title="Lua"
local ok = aiLib.appearance.apply(ped, look)
```

#### Parametreler

<TypeTable
  type={{
    ped: { type: 'number', description: 'Giydirilecek ped. Modeli look.model olmalıdır.', required: true },
    look: { type: 'CharacterAppearance', description: '{ model: number; data: unknown }: model hash’i ve kıyafet script’inin kendi verisi. data’yı opak kabul et.', required: true },
  }}
/>

Tipi [`CharacterAppearance`](/tr/docs/developers/api/types#characterappearance)’dır.

#### Dönüş değeri

`boolean`: ped yok olduysa, model farklıysa ya da hiçbir kıyafet script’i çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, LocalPed, triggerServerCallback } from "@aicore-fivem/lib/client";
import type { CharacterAppearance } from "@aicore-fivem/shared";

// Bir karakterin, onun gibi giyinmiş uyuyan bir kopyası.
export async function showSleeper(charId: number): Promise<void> {
  const look = (await triggerServerCallback("mysleep:look", [charId]).catch(() => null)) as CharacterAppearance | null;
  if (!look) return;
  new LocalPed({
    model: look.model,
    coords: { x: 151.2, y: -1004.6, z: 29.4, heading: 90 },
    onSpawn: (ped) => appearance.apply(ped, look),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local function showSleeper(charId)
    CreateThread(function()
        local look = aiLib.triggerServerCallback('mysleep:look', { charId })
        if type(look) ~= 'table' then return end
        aiLib.LocalPed.new({
            model = look.model,
            coords = vector4(151.2, -1004.6, 29.4, 90.0),
            onSpawn = function(ped) aiLib.appearance.apply(ped, look) end,
        })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Server’ın gönderdiğini tip dönüşümü yapmadan önce kontrol et. `look.model`’den başka bir modelle oluşturulan bir ped görünümü alamaz: `apply` `false` cevabını verir.
</Callout>

## fuel

### fuel.get

Bir aracın yakıt seviyesi. Server, hangi yakıt script’i çalışırsa çalışsın her araç için bir `fuel` state bag’i tutar; bu yüzden bu bir bellek okumasıdır; o bag yoksa oyunun depo seviyesidir.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
fuel.get(vehicle: number): number
```

Lua karşılığı yok: `Entity(vehicle).state.fuel`’i oku. Yakıt ayarlamak yalnızca server’dadır ([Araçlar](/tr/docs/developers/api/lib-server/vehicles) sayfasındaki `fuel.set`).

#### Parametreler

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Bu client’ın bildiği bir araç.', required: true },
  }}
/>

#### Dönüş değeri

`number`: 0-100.

#### Örnek

```ts
import { cache, every, fuel } from "@aicore-fivem/lib/client";

every(1000, () => {
  if (cache.vehicle !== false) SendNUIMessage({ action: "fuel", data: Math.round(fuel.get(cache.vehicle)) });
});
```

### inventory.hasItem

Oyuncunun bir eşyadan en az `count` tane tutup tutmadığı. Oyuncunun yalnızca yapabildiklerini görmesi için `canShow` içinde kullan; server tekrar kontrol eder.

**Taraf:** Client · **Bekler:** hayır
