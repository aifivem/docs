Eine geskriptete Kamera für Ausstellungsräume und Szenen, ein Job pro Frame, den du nur einschaltest, solange er gebraucht wird, die Client-Hälfte des Bereichs-Streamings des Servers und die Server-Uhr für Countdowns. Periodische Arbeit allgemein ist `every(ms, fn)` (siehe [Lib: Shared und fivem](/de/docs/developers/api/lib-shared)); nie `setInterval` oder ein nacktes `setTick`.

## ScriptCamera

### new ScriptCamera

Eine geskriptete Kamera: die Ausstellungsansicht eines Shops, ein Editor, eine Szene, ein Fernglas. `start` erstellt und zeigt sie, die anderen Methoden bewegen und verändern sie, `stop` blendet weich zur Spielkamera zurück und zerstört sie. Eine Kamera, die noch läuft, wenn deine Ressource stoppt, wird sofort zurückgegeben, sodass der Spieler nie darin festhängt.

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
new ScriptCamera(type?: string)
```

Kein Lua-Zwilling: Lua-Ressourcen nutzen `CreateCam`, `RenderScriptCams` und `DestroyCam`.

#### Mitglieder

<TypeTable
  type={{

#### Beispiel

```ts
import { ScriptCamera } from "@aicore-fivem/lib/client";

const camera = new ScriptCamera();
const CAR = { x: -44.4, y: -1097.1, z: 26.4 };

export function openShowroom(): void {
  camera.start({ x: -40.2, y: -1100.5, z: 27.6 }, { pointAt: CAR, fov: 50 }, 800);
}

export function frontView(): void {
  camera.glideTo({ x: -47.5, y: -1093.8, z: 27.2 }, { pointAt: CAR, fov: 45 }, 1200);
}

export function closeShowroom(): void {
  camera.stop(800);
}
```

### camera.glideTo

Blendet zu einer neuen Einstellung über: Eine zweite Kamera am neuen Ort übernimmt von dieser, und die alte wird nach der Überblendung zerstört. Wackeln und Unschärfe werden übernommen. Startet die Kamera, wenn sie gestoppt ist (oder wenn `ms` 0 ist).

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
camera.glideTo(at: Vec3, view: CameraView, ms: number): void
```

#### Parameter

<TypeTable

## TickLoop

### new TickLoop

Ein Job pro Frame (`every(0, fn)` auf dem einen Scheduler deiner Ressource), der aus ist, bis du ihn einschaltest. Nutze ihn für alles, was nur manchmal in jedem Frame laufen muss: einen Marker in der Nähe zeichnen, eine Platzierungsvorschau, deaktiviertes Schießen beim Zielen auf einen Freund.

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
new TickLoop(onFrame: () => void, name?: string)
```

Kein Lua-Zwilling: `aiLib.every(0, fn, { active = false, name = name })` und `job:set(active)`.

#### Parameter

<TypeTable
  type={{
    onFrame: { type: '() => void', description: 'Läuft in jedem Frame, solange die Schleife an ist. Ein geworfener Fehler wird geloggt (höchstens einmal pro 10 s), und die Schleife läuft weiter.', required: true },
    name: { type: 'string', description: 'Ein Name, der in Fehler-Logs angezeigt wird.' },
  }}
/>

#### Mitglieder

<TypeTable
  type={{
    running: { type: 'boolean', description: 'Schreibgeschützte Eigenschaft: ob die Schleife an ist.' },
    'set(active)': { type: '(active: boolean) => void', description: 'Schaltet die Schleife ein (true) oder aus (false).' },
  }}
/>

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { TickLoop, Zones } from "@aicore-fivem/lib/client";

const SPOT = { x: 215.8, y: -810.1, z: 30.7 };
const light = new TickLoop(() => {
  DrawLightWithRange(SPOT.x, SPOT.y, SPOT.z + 2, 61, 247, 158, 8, 4);
}, "garageLight");

const zones = new Zones();
zones.add("garage", {
  shape: { type: "sphere", center: SPOT, radius: 25 },
  onEnter: () => light.set(true),
  onExit: () => light.set(false),
});
```
</Tab>
<Tab value="Lua">
```lua
local SPOT = vector3(215.8, -810.1, 30.7)
local light = aiLib.every(0, function()
    DrawLightWithRange(SPOT.x, SPOT.y, SPOT.z + 2.0, 61, 247, 158, 8.0, 4.0)
end, { active = false, name = 'garageLight' })

local zones = aiLib.Zones.new()
zones:add('garage', {
    shape = { type = 'sphere', center = SPOT, radius = 25.0 },
    onEnter = function() light:set(true) end,
    onExit = function() light:set(false) end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Jeder Job deiner Ressource läuft aus einem `setTick`, das nur existiert, solange ein Job an ist. Erstelle die Schleife einmal am Anfang der Datei und schalte sie, statt pro Start eine neue zu erstellen.
</Callout>

## AreaFollower

### new AreaFollower

Die Client-Hälfte eines Server-`AreaStream` ([Bereichs-Streaming](/de/docs/developers/api/lib-server/area-stream)): Sie meldet dem Server, in welcher Rasterzelle der Spieler steht, sobald sie sich ändert (alle 2 Sekunden geprüft, solange gestartet), sodass der Server nur die Weltobjekte (Drops, Pflanzen, platzierte Props) um den Spieler sendet. Erstelle eine am Anfang der Datei.

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
new AreaFollower(event: string, cellSize?: number)
```

Kein Lua-Zwilling.

#### Parameter

<TypeTable
  type={{
    event: { type: 'string', description: 'Das Net-Event, auf das der Server hört; es bekommt (cx, cy), die Zellkoordinaten.', required: true },
    cellSize: { type: 'number', description: 'Zellgröße in Metern. Muss zur cellSize des Server-Streams passen.', default: '64' },
  }}
/>

#### Mitglieder

<TypeTable
  type={{
    'start()': { type: '() => void', description: 'Sendet die aktuelle Zelle jetzt und bei jeder Änderung.' },
    'stop()': { type: '() => void', description: 'Beendet das Melden.' },
  }}
/>

#### Beispiel

```ts title="resource/client/index.ts"
import { AreaFollower, onServerEvent } from "@aicore-fivem/lib/client";

const follower = new AreaFollower("myplants:cell");
follower.start();

const plants = new Map<number, unknown>();

// Der Stream sendet (reset, puts, removes): einen Snapshot mit reset true, danach nur Änderungen.
onServerEvent(
  "myplants:area",
  {
    args: ([reset, puts, removes]) =>
      typeof reset === "boolean" && Array.isArray(puts) && Array.isArray(removes)
        ? ([reset, puts, removes] as const)
        : null,
  },
  (reset, puts, removes) => {
    if (reset) plants.clear();
    for (const plant of puts as Array<{ id?: unknown } | null>)
      if (typeof plant?.id === "number") plants.set(plant.id, plant);
    for (const id of removes) if (typeof id === "number") plants.delete(id);
  },
);
```

<Callout type="warn">
Der Server prüft eine gemeldete Zelle gegen die echte Position des Spielers (`followReported` akzeptiert nur Zellen innerhalb einer Zelle um den Ped), sodass ein Cheater keinen weit entfernten Bereich anfordern kann.
</Callout>

## ServerClock

### new ServerClock

Die Server-Uhr auf einem Client. Client- und Server-Uhr können sich unterscheiden, daher muss ein Countdown bis zu einer Serverzeit (ein Raub-Cooldown, das Ende einer Auktion) zuerst in lokale Zeit umgerechnet werden. Rufe `sync` mit dem `Date.now()` des Servers auf, sobald ein Snapshot oder eine Startnachricht ankommt.

**Seite:** Client (aus `@aicore-fivem/lib/shared`) · **Wartet:** nein

```ts title="Signatur"
new ServerClock()
```

Kein Lua-Zwilling.

#### Mitglieder

<TypeTable
  type={{
    'sync(serverNow)': { type: '(serverNow: number) => void', description: 'Nimmt den Versatz aus dem gerade empfangenen Date.now() des Servers.' },
    'now()': { type: '() => number', description: 'Das Date.now() des Servers genau jetzt.' },
    'toLocal(serverTime)': { type: '(serverTime: number) => number', description: 'Eine Serverzeit als lokale Date.now()-Zeit, für Countdowns auf der lokalen Uhr.' },
  }}
/>

#### Beispiel

```ts title="resource/client/index.ts"
import { every, onServerEvent } from "@aicore-fivem/lib/client";
import { ServerClock } from "@aicore-fivem/lib/shared";

const clock = new ServerClock();
let endsAt = 0; // lokale Zeit

onServerEvent(
  "myauction:state",
  { args: ([now, ends]) => (typeof now === "number" && typeof ends === "number" ? [now, ends] : null) },
  (now, ends) => {
    clock.sync(now);
    endsAt = clock.toLocal(ends);
  },
);

every(1000, () => {
  const left = Math.max(0, Math.round((endsAt - Date.now()) / 1000));
  SendNUIMessage({ action: "countdown", data: left });
});
```

<Callout type="info">
Der Server sendet die Endzeit einmal; der Client zählt auf seiner eigenen Uhr herunter. Sende nie jede Sekunde die verbleibende Zeit.
</Callout>
