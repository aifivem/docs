icon: Layers

Estes objetos nunca falam com um script específico. Eles perguntam ao **ai-core**, e o ai-core encaminha para qualquer script que o servidor roda para aquela tarefa: ai-death ou outro script de morte, ai-appearance ou tgiann-clothing, qualquer script de emotes ou radial suportado. Seu script continua funcionando quando o dono troca um deles. Como as camadas funcionam está em [Camadas e a ponte](/pt/docs/developers/layers).

Quando nenhum script desse tipo está rodando, as chamadas respondem `false`, `null` ou o próprio valor do jogo, como cada entrada indica.

## medical

### medical.isDead

Se o jogador local está caído (morto ou em last stand), em qualquer script de morte rodando. Scripts de morte mantêm um ped caído vivo para animá-lo, então `IsEntityDead` sozinho não os detecta. Uma leitura em memória depois da primeira chamada.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
medical.isDead(): boolean
```

Sem equivalente em Lua: chame `exports['ai-core']:IsDead()` e escute o evento local `ai-core:client:dead` (`dead`).

#### Retorno

`boolean`: `true` quando a camada médica do ai-core diz que o jogador está caído, ou o ped está morto para o jogo.

#### Exemplo

```ts
import { medical, notify } from "@aifivem/lib/client";

RegisterCommand(
  "phone",
  () => {
    if (medical.isDead()) return notify("You cannot use the phone now", "error");
    SetNuiFocus(true, true);
  },
  false,
);
```

### medical.onChange

Roda um handler quando o jogador local cai ou se levanta.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
medical.onChange(fn: (dead: boolean) => void): void
```

Sem equivalente em Lua: `AddEventHandler('ai-core:client:dead', function(dead) end)`.

#### Parâmetros

<TypeTable
  type={{
    fn: { type: '(dead: boolean) => void', description: 'Recebe true quando o jogador caiu, false quando se levantou.', required: true },
  }}
/>

#### Retorno

`void`.

#### Exemplo

```ts
import { medical, Points } from "@aifivem/lib/client";

const points = new Points();
medical.onChange(() => points.refresh()); // pontos cujo canShow lê medical.isDead()
```

## appearance

Visuais em peds pela camada de aparência do ai-core, qualquer que seja o script de roupas rodando.

### appearance.apply

Coloca um visual salvo em um ped do modelo desse visual. Pegue o visual no servidor com `appearance.get(charId)`, crie o ped com `look.model` e depois aplique. No próprio ped do jogador, troca as roupas dele.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
appearance.apply(ped: number, look: CharacterAppearance): boolean
```

```lua title="Lua"
local ok = aiLib.appearance.apply(ped, look)
```

#### Parâmetros

<TypeTable
  type={{
    ped: { type: 'number', description: 'O ped a vestir. O modelo dele precisa ser look.model.', required: true },
    look: { type: 'CharacterAppearance', description: '{ model: number; data: unknown }: o hash do modelo e os dados próprios do script de roupas. Trate data como opaco.', required: true },
  }}
/>

O tipo é [`CharacterAppearance`](/pt/docs/developers/api/types#characterappearance).

#### Retorno

`boolean`: `false` quando o ped sumiu, o modelo é diferente ou nenhum script de roupas está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, LocalPed, triggerServerCallback } from "@aifivem/lib/client";
import type { CharacterAppearance } from "@aifivem/shared";

// Uma cópia dormindo de um personagem, vestida como ele.
export async function showSleeper(charId: number): Promise<void> {
  const look = (await triggerServerCallback("mysleep:look", [charId]).catch(() => null)) as CharacterAppearance | null;
  if (!look) return;
  new LocalPed({
    model: look.model,
    coords: { x: 151.2, y: -1004.6, z: 29.4, heading: 90 },
    onSpawn: (ped) => appearance.apply(ped, look),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local function showSleeper(charId)
    CreateThread(function()
        local look = aiLib.triggerServerCallback('mysleep:look', { charId })
        if type(look) ~= 'table' then return end
        aiLib.LocalPed.new({
            model = look.model,
            coords = vector4(151.2, -1004.6, 29.4, 90.0),
            onSpawn = function(ped) aiLib.appearance.apply(ped, look) end,
        })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Verifique o que o servidor envia antes de fazer o cast. Um ped criado com outro modelo que não `look.model` não consegue receber o visual: `apply` responde `false`.
</Callout>

</Tab>

## fuel

### fuel.get

O nível de combustível de um veículo. O servidor mantém um state bag `fuel` para todo veículo, qualquer que seja o script de combustível rodando, então isto é uma leitura em memória; sem esse bag é o nível do tanque do jogo.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
fuel.get(vehicle: number): number
```

Sem equivalente em Lua: leia `Entity(vehicle).state.fuel`. Definir o combustível é só no servidor (`fuel.set` em [Veículos](/pt/docs/developers/api/lib-server/vehicles)).

#### Parâmetros

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Um veículo que este cliente conhece.', required: true },
  }}
/>

#### Retorno

`number`: 0-100.

#### Exemplo

```ts
import { cache, every, fuel } from "@aifivem/lib/client";

every(1000, () => {
  if (cache.vehicle !== false) SendNUIMessage({ action: "fuel", data: Math.round(fuel.get(cache.vehicle)) });
});
```

Remove um motivo de pausa; a sincronização volta a rodar quando não sobra nenhum motivo.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
world.resumeSync(reason: string): void
```

```lua title="Lua"
aiLib.world.resumeSync(reason)
```

#### Parâmetros

<TypeTable
  type={{
    reason: { type: 'string', description: 'O motivo passado para pauseSync.', required: true },
  }}
/>

#### Retorno

`void`. Veja o exemplo de [`world.pauseSync`](#worldpausesync).

## inventory

O inventário do jogador local pela camada de inventário do ai-core: o inventário que o servidor escolheu responde. Dar e tirar itens é só no servidor ([Itens](/pt/docs/developers/api/lib-server/items)).

### inventory.openInventory

Abre a tela do próprio inventário do jogador.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
inventory.openInventory(): void
```

```lua title="Lua"
aiLib.inventory.openInventory()
```

#### Retorno

`void`.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aifivem/lib/client";

RegisterCommand("bag", () => inventory.openInventory(), false);
```
</Tab>
<Tab value="Lua">
```lua
RegisterCommand('bag', function() aiLib.inventory.openInventory() end, false)
```
</Tab>
</Tabs>

### inventory.hasItem

Se o jogador tem pelo menos `count` de um item. Use em `canShow` para que o jogador só veja o que pode fazer; o servidor verifica de novo.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
inventory.hasItem(item: string, count?: number): boolean
```

```lua title="Lua"
local has = aiLib.inventory.hasItem(item, count)
```

#### Parâmetros

<TypeTable
  type={{
    item: { type: 'string', description: 'O nome do item (lockpick).', required: true },
    count: { type: 'number', description: 'Quantos são necessários.', default: '1' },
  }}
/>

#### Retorno

`boolean`: `true` quando o jogador tem o suficiente.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory, Points } from "@aifivem/lib/client";

const points = new Points();
points.addVehicle("lockpick", {
  label: "Lockpick",
  icon: "unlock",
  canShow: (vehicle) => GetVehicleDoorLockStatus(vehicle) >= 2 && inventory.hasItem("lockpick"),
  onPressed: (vehicle) => emitNet("mykeys:lockpick", NetworkGetNetworkIdFromEntity(vehicle)),
});
```
</Tab>
<Tab value="Lua">
```lua
local points = aiLib.Points.new()
points:addVehicle('lockpick', {
    label = 'Lockpick',
    icon = 'unlock',
    canShow = function(vehicle)
        return GetVehicleDoorLockStatus(vehicle) >= 2 and aiLib.inventory.hasItem('lockpick')
    end,
    onPressed = function(vehicle) TriggerServerEvent('mykeys:lockpick', NetworkGetNetworkIdFromEntity(vehicle)) end,
})
```
</Tab>
</Tabs>

### inventory.currentWeapon

O item de arma na mão do jogador: nome, rótulo e imagem.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
inventory.currentWeapon(): HeldWeapon | null
```

```lua title="Lua"
local weapon = aiLib.inventory.currentWeapon() -- table ou nil
```

#### Retorno

[`HeldWeapon`](/pt/docs/developers/api/types#heldweapon) `{ name: string; label: string; image?: string }` (`name` como `WEAPON_PISTOL`, `image` uma url `nui://` quando o inventário tem uma), ou `null` (`nil`) quando a mão está vazia.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory, onCache } from "@aifivem/lib/client";

// Leia quando a arma muda, nunca a cada frame.
onCache("weapon", () => SendNUIMessage({ action: "weapon", data: inventory.currentWeapon() }));
```
</Tab>
<Tab value="Lua">
```lua
aiLib.cache.onChange('weapon', function()
    SendNUIMessage({ action = 'weapon', data = aiLib.inventory.currentWeapon() })
end)
```
</Tab>
</Tabs>
