Una cámara con script para exposiciones y escenas, una tarea por frame que activas solo mientras hace falta, la mitad de cliente del streaming por áreas del servidor y el reloj del servidor para cuentas atrás. El trabajo periódico en general es `every(ms, fn)` (consulta [Lib: compartido y fivem](/es/docs/developers/api/lib-shared)); nunca `setInterval` ni un `setTick` a secas.

## ScriptCamera

### new ScriptCamera

Una cámara con script: la vista de exposición de una tienda, un editor, una escena, unos prismáticos. `start` la crea y la muestra, los demás métodos la mueven y la cambian, `stop` vuelve suavemente a la cámara del juego y la destruye. Una cámara que sigue en marcha cuando tu recurso se detiene se devuelve al momento, así que el jugador nunca se queda atrapado en ella.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
new ScriptCamera(type?: string)
```

Sin equivalente en Lua: los recursos Lua usan `CreateCam`, `RenderScriptCams` y `DestroyCam`.

#### Miembros

<TypeTable
  type={{

#### Ejemplo

```ts
import { ScriptCamera } from "@aicore-fivem/lib/client";

const camera = new ScriptCamera();
const CAR = { x: -44.4, y: -1097.1, z: 26.4 };

export function openShowroom(): void {
  camera.start({ x: -40.2, y: -1100.5, z: 27.6 }, { pointAt: CAR, fov: 50 }, 800);
}

export function frontView(): void {
  camera.glideTo({ x: -47.5, y: -1093.8, z: 27.2 }, { pointAt: CAR, fov: 45 }, 1200);
}

export function closeShowroom(): void {
  camera.stop(800);
}
```

### camera.glideTo

Hace una transición a un nuevo plano: una segunda cámara en el nuevo lugar toma el relevo de esta, y la antigua se destruye después de la transición. La vibración y el desenfoque se mantienen. Inicia la cámara cuando está detenida (o cuando `ms` es 0).

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
camera.glideTo(at: Vec3, view: CameraView, ms: number): void
```

#### Parámetros

<TypeTable
  type={{

    view: { type: 'CameraView', description: 'La nueva mirada.', required: true },
    ms: { type: 'number', description: 'Duración de la transición en milisegundos.', required: true },
  }}
/>

#### Devuelve

`void`. Consulta el ejemplo de la clase.

## TickLoop

### new TickLoop

Una tarea por frame (`every(0, fn)` en el único planificador de tu recurso) que está apagada hasta que la enciendes. Úsala para todo lo que deba ejecutarse en cada frame solo a veces: dibujar un marcador mientras estás cerca, una vista previa de colocación, desactivar el disparo mientras apuntas a un amigo.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
new TickLoop(onFrame: () => void, name?: string)
```

Sin equivalente en Lua: `aiLib.every(0, fn, { active = false, name = name })` y `job:set(active)`.

#### Parámetros

<TypeTable
  type={{
    onFrame: { type: '() => void', description: 'Se ejecuta en cada frame mientras el bucle está encendido. Un error lanzado se registra en el log (como máximo una vez cada 10 s) y el bucle sigue en marcha.', required: true },
    name: { type: 'string', description: 'Un nombre que se muestra en los logs de errores.' },
  }}
/>

#### Miembros

<TypeTable
  type={{
    running: { type: 'boolean', description: 'Propiedad de solo lectura: si el bucle está encendido.' },
    'set(active)': { type: '(active: boolean) => void', description: 'Enciende (true) o apaga (false) el bucle.' },
  }}
/>

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { TickLoop, Zones } from "@aicore-fivem/lib/client";

const SPOT = { x: 215.8, y: -810.1, z: 30.7 };
const light = new TickLoop(() => {
  DrawLightWithRange(SPOT.x, SPOT.y, SPOT.z + 2, 61, 247, 158, 8, 4);
}, "garageLight");

const zones = new Zones();
zones.add("garage", {
  shape: { type: "sphere", center: SPOT, radius: 25 },
  onEnter: () => light.set(true),
  onExit: () => light.set(false),
});
```
</Tab>
<Tab value="Lua">
```lua
local SPOT = vector3(215.8, -810.1, 30.7)
local light = aiLib.every(0, function()
    DrawLightWithRange(SPOT.x, SPOT.y, SPOT.z + 2.0, 61, 247, 158, 8.0, 4.0)
end, { active = false, name = 'garageLight' })

local zones = aiLib.Zones.new()
zones:add('garage', {
    shape = { type = 'sphere', center = SPOT, radius = 25.0 },
    onEnter = function() light:set(true) end,
    onExit = function() light:set(false) end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Cada tarea de tu recurso se ejecuta desde un único `setTick` que solo existe mientras hay una tarea encendida. Crea el bucle una vez al principio del archivo y conmútalo, en lugar de crear uno nuevo en cada inicio.
</Callout>

## AreaFollower

### new AreaFollower

La mitad de cliente de un `AreaStream` de servidor ([Streaming por áreas](/es/docs/developers/api/lib-server/area-stream)): indica al servidor en qué celda de la cuadrícula está el jugador cada vez que cambia (se comprueba cada 2 segundos mientras está iniciado), para que el servidor envíe solo los objetos del mundo (objetos tirados, plantas, props colocados) alrededor del jugador. Crea uno al principio del archivo.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
new AreaFollower(event: string, cellSize?: number)
```

Sin equivalente en Lua.

#### Parámetros

<TypeTable
  type={{
    event: { type: 'string', description: 'El evento de red que escucha el servidor; recibe (cx, cy), las coordenadas de la celda.', required: true },
    cellSize: { type: 'number', description: 'Tamaño de celda en metros. Debe coincidir con el cellSize del stream del servidor.', default: '64' },
  }}
/>

#### Miembros

<TypeTable
  type={{
    'start()': { type: '() => void', description: 'Envía la celda actual ahora y en cada cambio.' },
    'stop()': { type: '() => void', description: 'Deja de informar.' },
  }}
/>

#### Ejemplo

```ts title="resource/client/index.ts"
import { AreaFollower, onServerEvent } from "@aicore-fivem/lib/client";

const follower = new AreaFollower("myplants:cell");
follower.start();

const plants = new Map<number, unknown>();

// El stream envía (reset, puts, removes): un snapshot con reset en true y después solo cambios.
onServerEvent(
  "myplants:area",
  {
    args: ([reset, puts, removes]) =>
      typeof reset === "boolean" && Array.isArray(puts) && Array.isArray(removes)
        ? ([reset, puts, removes] as const)
        : null,
  },
  (reset, puts, removes) => {
    if (reset) plants.clear();
    for (const plant of puts as Array<{ id?: unknown } | null>)
      if (typeof plant?.id === "number") plants.set(plant.id, plant);
    for (const id of removes) if (typeof id === "number") plants.delete(id);
  },
);
```

<Callout type="warn">
El servidor comprueba una celda informada contra la posición real del jugador (`followReported` solo acepta celdas a una celda como máximo del ped), así que un tramposo no puede pedir un área lejana.
</Callout>

## ServerClock

### new ServerClock

El reloj del servidor en un cliente. Los relojes del cliente y del servidor pueden diferir, así que una cuenta atrás hacia una hora del servidor (el cooldown de un robo, el final de una subasta) debe convertirse primero a hora local. Llama a `sync` con el `Date.now()` del servidor cada vez que llegue un snapshot o un mensaje de inicio.

**Lado:** Cliente (desde `@aicore-fivem/lib/shared`) · **Espera:** no

```ts title="Firma"
new ServerClock()
```

Sin equivalente en Lua.

#### Miembros

<TypeTable
  type={{
    'sync(serverNow)': { type: '(serverNow: number) => void', description: 'Toma el desfase a partir del Date.now() del servidor recién recibido.' },
    'now()': { type: '() => number', description: 'El Date.now() del servidor ahora mismo.' },
    'toLocal(serverTime)': { type: '(serverTime: number) => number', description: 'Una hora del servidor como hora Date.now() local, para cuentas atrás con el reloj local.' },
  }}
/>

#### Ejemplo

```ts title="resource/client/index.ts"
import { every, onServerEvent } from "@aicore-fivem/lib/client";
import { ServerClock } from "@aicore-fivem/lib/shared";

const clock = new ServerClock();
let endsAt = 0; // hora local

onServerEvent(
  "myauction:state",
  { args: ([now, ends]) => (typeof now === "number" && typeof ends === "number" ? [now, ends] : null) },
  (now, ends) => {
    clock.sync(now);
    endsAt = clock.toLocal(ends);
  },
);

every(1000, () => {
  const left = Math.max(0, Math.round((endsAt - Date.now()) / 1000));
  SendNUIMessage({ action: "countdown", data: left });
});
```

<Callout type="info">
El servidor envía la hora de fin una vez; el cliente cuenta hacia atrás con su propio reloj. Nunca envíes el tiempo restante cada segundo.
</Callout>
