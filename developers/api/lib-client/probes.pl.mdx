Pytania do gry o świat (co jest przed graczem, jak wysoko jest ziemia, jak nazywa się ta ulica) i loadery, których każdy model, animacja i efekt potrzebuje przed użyciem.

## Sondy

### raycast

Sonda liniowa z odpowiedzią w tej samej klatce: w co najpierw trafia linia od `from` do `to`. Używaj jej do "na co patrzy gracz", stawiania obiektów na ziemi albo linii wzroku.

**Strona:** Klient · **Czeka:** nie (blokuje klatkę, aż test się skończy)

```ts title="Sygnatura"
raycast(from: Vec3, to: Vec3, options?: RaycastOptions): RayHit | null
```

```lua title="Lua"
local hit = aiLib.raycast(from, to, options) -- tabela albo nil; from / to to vector3
```

#### Parametry

<TypeTable
  type={{
    from: { type: 'Vec3', description: 'Początek linii. Lua: vector3.', required: true },
    to: { type: 'Vec3', description: 'Koniec linii. Lua: vector3.', required: true },
    options: { type: 'RaycastOptions', description: 'Pola poniżej.', default: '{}' },
  }}
/>

#### RaycastOptions

<TypeTable
  type={{
    flags: { type: 'number', description: 'Co testuje sonda, zsumowane: 1 mapa, 2 pojazdy, 4 pedy, 8 ragdolle, 16 obiekty.', default: '1 | 2 | 16 (19)' },
    ignore: { type: 'number', description: 'Encja, przez którą sonda przechodzi.', default: 'lokalny ped' },
    options: { type: 'number', description: 'Bity opcji sondy: 1 ignoruj szkło, 2 ignoruj przezroczyste, 4 ignoruj bez kolizji.', default: '7' },
  }}
/>

#### Zwracana wartość

`RayHit | null`: `{ coords, normal, entity }` dla pierwszego trafienia albo `null` (`nil`), gdy linia w nic nie trafia.

<TypeTable
  type={{
    coords: { type: 'Vec3', description: 'Punkt trafienia. Lua: vector3.' },
    normal: { type: 'Vec3', description: 'Normalna powierzchni w punkcie trafienia (w którą stronę zwrócona jest powierzchnia). Lua: vector3.' },
    entity: { type: 'number', description: 'Trafiona encja, 0 dla mapy.' },
  }}
/>

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { raycast } from "@aifivem/lib/client";

/** What the camera looks at within 10 m. */
export function lookedAt(): number {
  const [cx = 0, cy = 0, cz = 0] = GetGameplayCamCoord();
  const [rx = 0, , rz = 0] = GetGameplayCamRot(2);
  const pitch = (rx * Math.PI) / 180;
  const yaw = (rz * Math.PI) / 180;
  const dir = { x: -Math.sin(yaw) * Math.cos(pitch), y: Math.cos(yaw) * Math.cos(pitch), z: Math.sin(pitch) };
  const hit = raycast(
    { x: cx, y: cy, z: cz },
    { x: cx + dir.x * 10, y: cy + dir.y * 10, z: cz + dir.z * 10 },
    { flags: 2 | 4 | 16 },
  );
  return hit?.entity ?? 0;
}
```
</Tab>
<Tab value="Lua">
```lua
local function lookedAt()
    local cam = GetGameplayCamCoord()
    local rot = GetGameplayCamRot(2)
    local pitch, yaw = math.rad(rot.x), math.rad(rot.z)
    local dir = vector3(-math.sin(yaw) * math.cos(pitch), math.cos(yaw) * math.cos(pitch), math.sin(pitch))
    local hit = aiLib.raycast(cam, cam + dir * 10.0, { flags = 2 | 4 | 16 })
    return hit and hit.entity or 0
end
```
</Tab>
</Tabs>

<Callout type="warn">
To synchroniczna sonda: ogranicz się do jednej albo dwóch na klatkę.
</Callout>

### groundZ

Wysokość ziemi pod punktem, sondując w dół od `z`.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
groundZ(x: number, y: number, z?: number): number | null
```

```lua title="Lua"
local ground = aiLib.groundZ(x, y, z) -- liczba albo nil
```

#### Parametry

<TypeTable
  type={{
    x: { type: 'number', description: 'x w świecie.', required: true },
    y: { type: 'number', description: 'y w świecie.', required: true },
    z: { type: 'number', description: 'Wysokość, od której zaczyna się sonda, idąc w dół.', default: '1000' },
  }}
/>

#### Zwracana wartość

`number | null`: wysokość ziemi albo `null` (`nil`), dopóki kolizja tam nie jest wczytana (obszar jest daleko od gracza).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groundZ, player } from "@aifivem/lib/client";

const { x, y, z } = player.coords();
const ground = groundZ(x, y, z + 2);
if (ground !== null) console.log(`ground is ${(z - ground).toFixed(2)} m below`);
```
</Tab>
<Tab value="Lua">
```lua
local c = aiLib.player.coords()
local ground = aiLib.groundZ(c.x, c.y, c.z + 2.0)
if ground then print(('ground is %.2f m below'):format(c.z - ground)) end
```
</Tab>
</Tabs>

<Callout type="info">
Żeby przenieść gracza na nieznaną ziemię, użyj `player.teleport` bez `z`: czeka na kolizję na każdej wysokości.
</Callout>

### pedHeadshot

Robi zdjęcie głowy peda i czeka, aż gra je wyrenderuje. Używaj nazwy tekstury na stronie NUI jako `https://nui-img/<txd>/<txd>`.

**Strona:** Klient · **Czeka:** tak (Promise w TypeScript, w Lua wstrzymuje wątek)

```ts title="Sygnatura"
pedHeadshot(ped: number, transparent?: boolean, timeoutMs?: number): Promise<{ handle: number; txd: string } | null>
```

```lua title="Lua"
local handle, txd = aiLib.pedHeadshot(ped, transparent, timeout) -- wywołuj wewnątrz wątku
```

#### Parametry

<TypeTable
  type={{
    ped: { type: 'number', description: 'Ped do sfotografowania.', required: true },
    transparent: { type: 'boolean', description: 'Przezroczyste tło zamiast domyślnego.', default: 'false' },
    timeoutMs: { type: 'number', description: 'Jak długo czekać na render, w milisekundach. W Lua nazywa się timeout.', default: '5000' },
  }}
/>

#### Zwracana wartość

`Promise<{ handle: number; txd: string } | null>`: uchwyt zdjęcia i nazwa jego tekstury; `null`, gdy ped nie istnieje albo render trwał dłużej niż limit czasu. Lua zwraca `handle, txd` albo `nil`.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { cache, pedHeadshot } from "@aifivem/lib/client";

export async function sendMugshot(): Promise<void> {
  const shot = await pedHeadshot(cache.ped, true);
  if (!shot) return;
  SendNUIMessage({ action: "photo", data: `https://nui-img/${shot.txd}/${shot.txd}` });
  setTimeout(() => UnregisterPedheadshot(shot.handle), 10_000);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local handle, txd = aiLib.pedHeadshot(aiLib.cache.ped, true)
    if not handle then return end
    SendNUIMessage({ action = 'photo', data = ('https://nui-img/%s/%s'):format(txd, txd) })
    Wait(10000)
    UnregisterPedheadshot(handle)
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Wywołaj `UnregisterPedheadshot(handle)`, gdy zdjęcie nie jest już pokazywane.
</Callout>

### onShot

Uruchamia handler w klatce, w której lokalny ped oddaje strzał (stres, alerty o strzałach, łuski). Jedno sprawdzenie co klatkę na twój zasób, włączone tylko wtedy, gdy broń jest w ręku.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
onShot(handler: (weapon: number) => void): () => void
```

```lua title="Lua"
aiLib.onShot(function(weapon) end) -- nic nie zwraca
```

#### Parametry

<TypeTable
  type={{
    handler: { type: '(weapon: number) => void', description: 'Dostaje hash broni, która wystrzeliła. Działa wewnątrz klatki: niech będzie tani.', required: true },
  }}
/>

#### Zwracana wartość

TypeScript: `() => void`, funkcja, która usuwa handler. Lua nic nie zwraca (handler zostaje).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onShot } from "@aifivem/lib/client";

let lastAlert = 0;
onShot(() => {
  if (GetGameTimer() - lastAlert < 30_000) return; // jeden alert na 30 s
  lastAlert = GetGameTimer();
  emitNet("mypolice:shots");
});
```
</Tab>
<Tab value="Lua">
```lua
local lastAlert = 0
aiLib.onShot(function()
    if GetGameTimer() - lastAlert < 30000 then return end
    lastAlert = GetGameTimer()
    TriggerServerEvent('mypolice:shots')
end)
```
</Tab>
</Tabs>

## Wczytywanie zasobów gry

Modele, animacje, efekty i tekstury muszą być wczytane przed użyciem. Każdy loader prosi o zasób i czeka, aż będzie gotowy. Zwolnij go, gdy skończysz, jak mówi każdy wpis.

### requestModel

Wczytuje model (ped, pojazd, obiekt) i podaje jego hash.

**Strona:** Klient · **Czeka:** tak (Promise w TypeScript, w Lua wstrzymuje wątek)

```ts title="Sygnatura"
requestModel(model: string | number, timeoutMs?: number): Promise<number>
```

```lua title="Lua"
local hash = aiLib.requestModel(model, timeout) -- integer albo nil, wywołuj wewnątrz wątku
```

#### Parametry

<TypeTable
  type={{
    model: { type: 'string | number', description: 'Nazwa albo hash modelu.', required: true },
    timeoutMs: { type: 'number', description: 'Jak długo czekać, w milisekundach. W Lua nazywa się timeout.', default: '10000' },
  }}
/>

#### Zwracana wartość

`Promise<number>`: hash modelu po wczytaniu. **Odrzuca się**, gdy model nie istnieje w plikach gry albo nie wczyta się na czas. Lua zwraca hash albo `nil` w obu przypadkach.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { requestModel } from "@aifivem/lib/client";

export async function placeCone(x: number, y: number, z: number): Promise<number> {
  const hash = await requestModel("prop_roadcone02a");
  const cone = CreateObject(hash, x, y, z, false, false, false);
  SetModelAsNoLongerNeeded(hash);
  PlaceObjectOnGroundProperly(cone);
  return cone;
}
```
</Tab>
<Tab value="Lua">
```lua
local function placeCone(x, y, z)
    local hash = aiLib.requestModel('prop_roadcone02a')
    if not hash then return 0 end
    local cone = CreateObject(hash, x, y, z, false, false, false)
    SetModelAsNoLongerNeeded(hash)
    PlaceObjectOnGroundProperly(cone)
    return cone
end
```
</Tab>
</Tabs>

<Callout type="info">
Wywołaj `SetModelAsNoLongerNeeded(hash)`, gdy encja zostanie utworzona.
</Callout>
