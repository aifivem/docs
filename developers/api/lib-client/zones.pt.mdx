---
title: Zonas
description: Zones - áreas com callbacks de entrada e saída (esfera, cilindro, polígono), verificadas no próprio intervalo, nunca a cada frame.
icon: Shapes
---

Uma **zona** é uma área que roda código quando o jogador entra ou sai dela: entrar em um bairro, uma área com limite de velocidade, um marcador que só é desenhado por perto. Quando o jogador deve *fazer* algo no lugar (apertar uma tecla, escolher uma opção de target), use um [ponto](/pt/docs/developers/api/lib-client/points): é uma zona com o prompt, o target, o ped e o blip já conectados.

Em TypeScript toda zona é verificada pelo único verificador do ai-lib para todos os recursos (as zonas ficam em uma grade de 64 m, então um milhão de zonas custa o mesmo que algumas). Seu recurso verifica as próprias zonas só enquanto o ai-lib não está rodando. Em Lua cada recurso roda um job do agendador para as suas zonas.

### new Zones

Cria um grupo de zonas. Faça um grupo por funcionalidade no topo do arquivo.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
new Zones()
```

```lua title="Lua"
local zones = aiLib.Zones.new()
```

#### Retorno

Um grupo `Zones` com os métodos abaixo.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { Zones } from "@aicore-fivem/lib/client";

const zones = new Zones();
```
</Tab>
<Tab value="Lua">
```lua
local zones = aiLib.Zones.new()
```
</Tab>
</Tabs>

### zones.add

Adiciona uma zona, ou substitui a zona com o mesmo id. Quando a zona substituída tinha o jogador dentro, o `onExit` dela roda primeiro.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
zones.add(id: string, options: ZoneOptions): void
```

```lua title="Lua"
zones:add(id, options)
```

#### Parâmetros

<TypeTable
  type={{
    id: { type: 'string', description: 'Único dentro deste grupo. O mesmo id substitui a zona antiga.', required: true },
    options: { type: 'ZoneOptions', description: 'A forma e os callbacks. Campos abaixo.', required: true },
  }}
/>

#### ZoneOptions

<TypeTable
  type={{
    shape: { type: 'ZoneShape', description: 'A área: uma esfera, um cilindro ou um polígono. Formas abaixo.', required: true },
    interval: { type: 'number', description: 'Com que frequência a zona é verificada, em milissegundos (pelo menos 50). Uma loja precisa de cerca de 500, um gatilho rápido de cerca de 100.', default: '500' },
    onEnter: { type: '() => void', description: 'O jogador entrou. Um erro lançado é registrado em log.' },
    onExit: { type: '() => void', description: 'O jogador saiu, ou a zona foi removida ou substituída enquanto o jogador estava dentro.' },
  }}
/>

#### ZoneShape

[`ZoneShape`](/pt/docs/developers/api/types#zoneshape) é um de três objetos, escolhido por `type`:

<TypeTable
  type={{
    '"sphere"': { type: '{ type: "sphere"; center: Vec3; radius: number }', description: 'Uma bola de radius metros ao redor de center.' },
    '"cylinder"': { type: '{ type: "cylinder"; center: Vec3; radius: number; height: number }', description: 'Um círculo de radius metros no chão, com height metros para cima e para baixo a partir de center (salas, andares).' },
    '"poly"': { type: '{ type: "poly"; points: Array<{ x: number; y: number }>; minZ: number; maxZ: number }', description: 'Um polígono no chão (os pontos em ordem ao redor da borda) entre duas alturas.' },
  }}
/>

Em Lua, `center` pode ser um `vector3` e os pontos tabelas `{ x = ..., y = ... }`.

#### Retorno

`void`.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, notify, Zones } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const zones = new Zones();

zones.add("safezone", {
  shape: { type: "cylinder", center: { x: 298.6, y: -584.5, z: 43.3 }, radius: 60, height: 30 },
  onEnter: () => notify(Locale("SAFEZONE_IN"), "info"),
  onExit: () => notify(Locale("SAFEZONE_OUT"), "info"),
});

zones.add("yard", {
  shape: {
    type: "poly",
    points: [
      { x: 1700.1, y: 2560.4 },
      { x: 1780.6, y: 2560.4 },
      { x: 1780.6, y: 2620.2 },
      { x: 1700.1, y: 2620.2 },
    ],
    minZ: 40,
    maxZ: 60,
  },
  interval: 1000,
  onEnter: () => SetPedMoveRateOverride(PlayerPedId(), 0.8),
});
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()
local zones = aiLib.Zones.new()

zones:add('safezone', {
    shape = { type = 'cylinder', center = vector3(298.6, -584.5, 43.3), radius = 60.0, height = 30.0 },
    onEnter = function() aiLib.notify(t('SAFEZONE_IN'), 'info') end,
    onExit = function() aiLib.notify(t('SAFEZONE_OUT'), 'info') end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Uma zona desenhada no seu painel de administração com o widget `zone` dá cantos; transforme-os em um polígono com `polyFromCorners(corners, height)` de `@aicore-fivem/lib/shared`. O servidor pode testar as mesmas formas com `zoneContains(shape, x, y, z)`.
</Callout>

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
zones.remove(id: string): void
```

```lua title="Lua"

```

<TypeTable

`void`.

### zones.clear

Remove todas as zonas do grupo; `onExit` roda para as que têm o jogador dentro.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
zones.clear(): void
```

```lua title="Lua"
zones:clear()
```

#### Retorno

`void`.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>

```ts
onServerEvent("myscript:eventOver", () => zones.clear());
```
</Tab>
<Tab value="Lua">
```lua

```
</Tab>
</Tabs>

### zones.isInside

Se o jogador está dentro de uma zona, segundo a última verificação dela.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
zones.isInside(id: string): boolean
```

```lua title="Lua"
local inside = zones:isInside(id)
```

#### Parâmetros

<TypeTable
  type={{
    id: { type: 'string', description: 'O id passado para add.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` enquanto dentro; `false` fora ou para um id desconhecido. Reflete a última verificação, então pode ter até `interval` ms de atraso.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
if (zones.isInside("safezone")) return notify(Locale("NO_WEAPONS_HERE"), "error");
```
</Tab>
<Tab value="Lua">
```lua
if zones:isInside('safezone') then return aiLib.notify(t('NO_WEAPONS_HERE'), 'error') end
```
</Tab>
</Tabs>

### zones.size

Quantas zonas o grupo tem.

**Lado:** Cliente · **Espera:** não

```ts title="Signature"
zones.size: number // propriedade somente leitura
```

Sem equivalente em Lua.

#### Retorno

`number`: a contagem de zonas neste grupo.

#### Exemplo

```ts
console.log(`${zones.size} zones loaded`);
```
