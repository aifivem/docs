## Sondes

### raycast

Une sonde linéaire qui répond dans la même frame : ce que la ligne de `from` à `to` touche en premier. Utilisez-la pour « ce que le joueur regarde », pour poser des objets au sol ou pour la ligne de vue.

**Côté :** client · **Attend :** non (elle bloque la frame jusqu’à la fin du test)

```ts title="Signature"
raycast(from: Vec3, to: Vec3, options?: RaycastOptions): RayHit | null
```

```lua title="Lua"
local hit = aiLib.raycast(from, to, options) -- table ou nil ; from / to sont des vector3
```

#### Paramètres

<TypeTable
  type={{
    from: { type: 'Vec3', description: 'Début de la ligne. Lua : un vector3.', required: true },
    to: { type: 'Vec3', description: 'Fin de la ligne. Lua : un vector3.', required: true },
    options: { type: 'RaycastOptions', description: 'Champs ci-dessous.', default: '{}' },
  }}
/>

#### RaycastOptions

<TypeTable
  type={{
    flags: { type: 'number', description: 'Ce que la sonde teste, valeurs additionnées : 1 carte, 2 véhicules, 4 peds, 8 ragdolls, 16 objets.', default: '1 | 2 | 16 (19)' },
    ignore: { type: 'number', description: 'Une entité que la sonde traverse.', default: 'le ped local' },
    options: { type: 'number', description: 'Bits d’option de la sonde : 1 ignore le verre, 2 ignore ce qui est transparent, 4 ignore ce qui n’a pas de collision.', default: '7' },
  }}
/>

#### Retour

`RayHit | null` : `{ coords, normal, entity }` pour le premier impact, ou `null` (`nil`) quand la ligne ne touche rien.

<TypeTable
  type={{
    coords: { type: 'Vec3', description: 'Le point d’impact. Lua : un vector3.' },
    normal: { type: 'Vec3', description: 'La normale de la surface au point d’impact (la direction vers laquelle la surface est tournée). Lua : un vector3.' },
    entity: { type: 'number', description: 'L’entité touchée, 0 pour la carte.' },
  }}
/>

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { raycast } from "@aifivem/lib/client";

/** Ce que la caméra regarde dans un rayon de 10 m. */
export function lookedAt(): number {
  const [cx = 0, cy = 0, cz = 0] = GetGameplayCamCoord();
  const [rx = 0, , rz = 0] = GetGameplayCamRot(2);
  const pitch = (rx * Math.PI) / 180;
  const yaw = (rz * Math.PI) / 180;
  const dir = { x: -Math.sin(yaw) * Math.cos(pitch), y: Math.cos(yaw) * Math.cos(pitch), z: Math.sin(pitch) };
  const hit = raycast(
    { x: cx, y: cy, z: cz },
    { x: cx + dir.x * 10, y: cy + dir.y * 10, z: cz + dir.z * 10 },
    { flags: 2 | 4 | 16 },
  );
  return hit?.entity ?? 0;
}
```
</Tab>
<Tab value="Lua">
```lua
local function lookedAt()
    local cam = GetGameplayCamCoord()
    local rot = GetGameplayCamRot(2)
    local pitch, yaw = math.rad(rot.x), math.rad(rot.z)
    local dir = vector3(-math.sin(yaw) * math.cos(pitch), math.cos(yaw) * math.cos(pitch), math.sin(pitch))
    local hit = aiLib.raycast(cam, cam + dir * 10.0, { flags = 2 | 4 | 16 })
    return hit and hit.entity or 0
end
```
</Tab>
</Tabs>

<Callout type="warn">
C’est une sonde synchrone : limitez-vous à une ou deux par frame.
</Callout>

### groundZ

La hauteur du sol sous un point, en sondant vers le bas depuis `z`.

**Côté :** client · **Attend :** non

```ts title="Signature"
groundZ(x: number, y: number, z?: number): number | null
```

```lua title="Lua"
local ground = aiLib.groundZ(x, y, z) -- nombre ou nil
```

#### Paramètres

<TypeTable
  type={{
    x: { type: 'number', description: 'x dans le monde.', required: true },
    y: { type: 'number', description: 'y dans le monde.', required: true },
    z: { type: 'number', description: 'Hauteur d’où part la sonde, vers le bas.', default: '1000' },
  }}
/>

#### Retour

`number | null` : la hauteur du sol, ou `null` (`nil`) tant que la collision à cet endroit n’est pas chargée (la zone est loin du joueur).

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groundZ, player } from "@aifivem/lib/client";

const { x, y, z } = player.coords();
const ground = groundZ(x, y, z + 2);
if (ground !== null) console.log(`ground is ${(z - ground).toFixed(2)} m below`);
```
</Tab>
<Tab value="Lua">
```lua
local c = aiLib.player.coords()
local ground = aiLib.groundZ(c.x, c.y, c.z + 2.0)
if ground then print(('ground is %.2f m below'):format(c.z - ground)) end
```
</Tab>
</Tabs>

<Callout type="info">
Pour déplacer le joueur sur un sol inconnu, utilisez `player.teleport` sans `z` : il attend la collision à chaque hauteur.
</Callout>

### pedHeadshot

Prend une photo du visage d’un ped et attend que le jeu l’ait rendue. Utilisez le nom de texture dans une page NUI sous la forme `https://nui-img/<txd>/<txd>`.

**Côté :** client · **Attend :** oui (Promise en TypeScript, cède la main (yield) du thread en Lua)

```ts title="Signature"
pedHeadshot(ped: number, transparent?: boolean, timeoutMs?: number): Promise<{ handle: number; txd: string } | null>
```

```lua title="Lua"
local handle, txd = aiLib.pedHeadshot(ped, transparent, timeout) -- à appeler dans un thread
```

#### Paramètres

<TypeTable
  type={{
    ped: { type: 'number', description: 'Le ped à photographier.', required: true },
    transparent: { type: 'boolean', description: 'Un fond transparent au lieu du fond par défaut.', default: 'false' },
    timeoutMs: { type: 'number', description: 'Durée d’attente du rendu, en millisecondes. Lua le nomme timeout.', default: '5000' },
  }}
/>

#### Retour

`Promise<{ handle: number; txd: string } | null>` : le handle de la photo et son nom de texture ; `null` quand le ped n’existe pas ou que le rendu a pris plus de temps que le délai. Lua renvoie `handle, txd`, ou `nil`.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { cache, pedHeadshot } from "@aifivem/lib/client";

export async function sendMugshot(): Promise<void> {
  const shot = await pedHeadshot(cache.ped, true);
  if (!shot) return;
  SendNUIMessage({ action: "photo", data: `https://nui-img/${shot.txd}/${shot.txd}` });
  setTimeout(() => UnregisterPedheadshot(shot.handle), 10_000);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local handle, txd = aiLib.pedHeadshot(aiLib.cache.ped, true)
    if not handle then return end
    SendNUIMessage({ action = 'photo', data = ('https://nui-img/%s/%s'):format(txd, txd) })
    Wait(10000)
    UnregisterPedheadshot(handle)
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Appelez `UnregisterPedheadshot(handle)` dès que la photo n’est plus affichée.
</Callout>

### onShot

Exécute un gestionnaire dans la frame où le ped local tire (stress, alertes de tirs, douilles). Une seule vérification par frame pour votre ressource, active uniquement quand une arme est en main.

**Côté :** client · **Attend :** non

```ts title="Signature"
onShot(handler: (weapon: number) => void): () => void
```

```lua title="Lua"
aiLib.onShot(function(weapon) end) -- ne renvoie rien
```

#### Paramètres

<TypeTable
  type={{
    handler: { type: '(weapon: number) => void', description: 'Reçoit le hash de l’arme qui a tiré. Il s’exécute dans la frame : gardez-le léger.', required: true },
  }}
/>

#### Retour

TypeScript : `() => void`, une fonction qui retire le gestionnaire. Lua ne renvoie rien (le gestionnaire reste).

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onShot } from "@aifivem/lib/client";

let lastAlert = 0;
onShot(() => {
  if (GetGameTimer() - lastAlert < 30_000) return; // une alerte toutes les 30 s
  lastAlert = GetGameTimer();
  emitNet("mypolice:shots");
});
```
</Tab>
<Tab value="Lua">
```lua
local lastAlert = 0
aiLib.onShot(function()
    if GetGameTimer() - lastAlert < 30000 then return end
    lastAlert = GetGameTimer()
    TriggerServerEvent('mypolice:shots')
end)
```
</Tab>
</Tabs>

## Charger les assets du jeu

Les modèles, animations, effets et textures doivent être chargés avant usage. Chaque chargeur demande l’asset et attend qu’il soit prêt. Libérez-le quand vous avez terminé, comme l’indique chaque entrée.

### requestModel

Charge un modèle (ped, véhicule, objet) et donne son hash.

**Côté :** client · **Attend :** oui (Promise en TypeScript, cède la main (yield) du thread en Lua)

```ts title="Signature"
requestModel(model: string | number, timeoutMs?: number): Promise<number>
```

```lua title="Lua"
local hash = aiLib.requestModel(model, timeout) -- entier ou nil, à appeler dans un thread
```

#### Paramètres

<TypeTable
  type={{
    model: { type: 'string | number', description: 'Nom ou hash du modèle.', required: true },
    timeoutMs: { type: 'number', description: 'Durée d’attente, en millisecondes. Lua le nomme timeout.', default: '10000' },
  }}
/>

#### Retour

`Promise<number>` : le hash du modèle une fois chargé. Elle est **rejetée** quand le modèle n’existe pas dans les fichiers du jeu ou ne se charge pas à temps. Lua renvoie le hash, ou `nil` dans les deux cas.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { requestModel } from "@aifivem/lib/client";

export async function placeCone(x: number, y: number, z: number): Promise<number> {
  const hash = await requestModel("prop_roadcone02a");
  const cone = CreateObject(hash, x, y, z, false, false, false);
  SetModelAsNoLongerNeeded(hash);
  PlaceObjectOnGroundProperly(cone);
  return cone;
}
```
</Tab>
<Tab value="Lua">
```lua
local function placeCone(x, y, z)
    local hash = aiLib.requestModel('prop_roadcone02a')
    if not hash then return 0 end
    local cone = CreateObject(hash, x, y, z, false, false, false)
    SetModelAsNoLongerNeeded(hash)
    PlaceObjectOnGroundProperly(cone)
    return cone
end
```
</Tab>
</Tabs>

<Callout type="info">
Appelez `SetModelAsNoLongerNeeded(hash)` une fois l’entité créée.
</Callout>
