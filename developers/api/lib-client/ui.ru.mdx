ai-lib рисует один общий интерфейс для всех ресурсов: карточки уведомлений, полосу прогресса, подсказки «нажмите E», меню, диалоги ввода и мини-игры. Ваш скрипт только запрашивает их, поэтому все скрипты на сервере выглядят одинаково, а вы не пишете для них NUI. Выбор предметов рисует ai-core.

Переданные вами тексты показываются как есть: сначала переведите их (`Locale("KEY")` в TypeScript, `t('KEY')` в Lua).

## Уведомления

### notify

Показывает карточку уведомления на экране этого игрока.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
notify(text: string, kind?: NotificationKind, duration?: number): void
```

```lua title="Lua"
aiLib.notify(text, kind, duration)
```

#### Параметры

<TypeTable
  type={{
    text: { type: 'string', description: 'Сообщение, уже переведённое.', required: true },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'Цвет и иконка карточки.', default: '"info"' },
    duration: { type: 'number', description: 'Сколько миллисекунд на экране.', default: '4000' },
  }}
/>

Тип вида: [`NotificationKind`](/ru/docs/developers/api/types#notificationkind). Чтобы уведомить игрока с сервера, используйте серверный `notify(source, text, kind)`.

#### Возвращает

`void`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, notify } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();

notify(Locale("WELCOME"));
notify(Locale("NO_MONEY"), "error");
notify(Locale("SAVED"), "success", 2000);
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()

aiLib.notify(t('WELCOME'))
aiLib.notify(t('NO_MONEY'), 'error')
aiLib.notify(t('SAVED'), 'success', 2000)
```
</Tab>
</Tabs>

## Полоса прогресса

### progress

Выполняет действие с таймером с полосой прогресса ai-lib и необязательной анимацией или сценарием и ждёт его окончания. Оно заканчивается досрочно (отменяется), когда игрок умирает, садится в транспорт, нажимает клавишу отмены ai-lib (по умолчанию `Backspace`, только с `canCancel`) или ваш скрипт вызывает `cancelProgress()`. Одновременно одна полоса прогресса на ресурс.

**Сторона:** Клиент · **Ждёт:** да (Promise в TypeScript, в Lua приостанавливает поток)

```ts title="Сигнатура"
progress(options: ProgressOptions): Promise<boolean>
```

```lua title="Lua"
local finished = aiLib.progress(options) -- boolean, вызывайте внутри потока
```

#### Параметры

/>

#### ProgressOptions

#### Возвращает

`Promise<boolean>`: `true`, если полоса дошла до конца; `false`, если она отменена, или сразу, если ещё идёт другая полоса вашего ресурса. Lua возвращает то же булево значение.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, createLocale, nearestVehicle, notify, progress } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();

export async function repair(): Promise<void> {
  const vehicle = nearestVehicle(4, { notOwn: true });
  if (!vehicle) return notify(Locale("NO_VEHICLE"), "error");
  const [x = 0, y = 0, z = 0] = GetEntityCoords(vehicle, false);
  const done = await progress({
    label: Locale("REPAIRING"),
    duration: 8000,
    face: { x, y, z },
    anim: { dict: "mini@repair", clip: "fixing_a_player" },
    canCancel: true,
    disable: { move: true, combat: true },
  });
  if (!done) return notify(Locale("CANCELLED"), "error");
  await callAction("mymech:repair", [NetworkGetNetworkIdFromEntity(vehicle)], { fallback: "REPAIR_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()

local function repair()
    CreateThread(function()
        local vehicle = aiLib.nearestVehicle(4.0, { notOwn = true })
        if vehicle == 0 then return aiLib.notify(t('NO_VEHICLE'), 'error') end
        local done = aiLib.progress({
            label = t('REPAIRING'),
            duration = 8000,
            anim = { dict = 'mini@repair', clip = 'fixing_a_player' },
            canCancel = true,
            disable = { move = true, combat = true },
        })
        if not done then return aiLib.notify(t('CANCELLED'), 'error') end
        aiLib.callAction('mymech:repair', { NetworkGetNetworkIdFromEntity(vehicle) }, { fallback = 'REPAIR_FAILED' })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Результат это слово клиента: читер может пропустить полосу. Когда сервер платит за действие (предметы, деньги, ремонт), запускайте полосу с сервера через `progressFor(source, options)` ([Ввод от клиента](/ru/docs/developers/api/lib-server/client-input)): он отвечает `true`, только если достаточно времени прошло и на сервере.
</Callout>

### cancelProgress

Отменяет идущую полосу прогресса вашего ресурса, независимо от того, может ли её отменить игрок. Вызов `progress` тогда выполняется с `false`. Ничего не происходит, если полоса не идёт.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
cancelProgress(): void
```

```lua title="Lua"
aiLib.progress.cancel()
```

#### Возвращает

`void`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { cancelProgress, onServerEvent } from "@aicore-fivem/lib/client";

// Сервер сообщает, что цель ограбил кто-то другой.
onServerEvent("myrob:taken", () => cancelProgress());
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onServerEvent('myrob:taken', function() aiLib.progress.cancel() end)
```
</Tab>
</Tabs>

### isProgressRunning

Идёт ли сейчас полоса прогресса вашего ресурса.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
isProgressRunning(): boolean
```

```lua title="Lua"
local running = aiLib.progress.isRunning()
```

#### Возвращает

`boolean`: `true`, пока идёт полоса вашего ресурса. Полосы других ресурсов не учитываются.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { isProgressRunning, menu } from "@aicore-fivem/lib/client";

export async function openMenu(): Promise<void> {
  if (isProgressRunning()) return; // занято
  await menu({ title: "Actions", items: [{ id: "a", label: "Action" }] });
}
```
</Tab>
<Tab value="Lua">
```lua
if aiLib.progress.isRunning() then return end
```
</Tab>
</Tabs>

## Меню и диалоги

### menu

Показывает меню ai-lib и ждёт выбора игрока. Стрелки перемещают, Enter выбирает. Пункты с `checked` это строки-переключатели, которые переключаются на месте, не закрывая меню. В подменю (`back: true`) короткое нажатие Escape выполняется с `MENU_BACK`, чтобы вы могли открыть предыдущее меню; удержание Escape закрывает.

**Сторона:** Клиент · **Ждёт:** да (Promise в TypeScript, в Lua приостанавливает поток)

```ts title="Сигнатура"
menu(request: MenuRequest, listeners?: ((item: string) => void) | MenuListeners): Promise<string | null>
```

```lua title="Lua"
local picked = aiLib.menu.show(request, listeners) -- string или nil, вызывайте внутри потока
```

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, createLocale, menu } from "@aicore-fivem/lib/client";
import { MENU_BACK } from "@aicore-fivem/shared";

const Locale = createLocale<typeof import("../../locales/en.json")>();
let engineOn = true;

export async function vehicleMenu(vehicle: number): Promise<void> {
  const pick = await menu({
    title: Locale("VEHICLE"),
    items: [
      { id: "doors", label: Locale("DOORS"), icon: "door-open" },
      { id: "engine", label: Locale("ENGINE"), icon: "power-off", checked: engineOn },
    ],
  }, {
    onToggle: (item, checked) => {
      if (item !== "engine") return;
      engineOn = checked;
      SetVehicleEngineOn(vehicle, checked, false, true);
    },
  });
  if (pick === "doors") await doorsMenu(vehicle);
}

async function doorsMenu(vehicle: number): Promise<void> {
  const pick = await menu({
    title: Locale("DOORS"),
    back: true,
    items: [0, 1, 2, 3].map((door) => ({ id: String(door), label: Locale("DOOR", door + 1) })),
  });
  if (pick === MENU_BACK) return vehicleMenu(vehicle);
  if (pick !== null) SetVehicleDoorOpen(vehicle, Number(pick), false, false);
}
```
</Tab>
<Tab value="Lua">

### itemPicker

Инструменты администратора: показывает выбор предметов ai-core. Он перечисляет все предметы активного инвентаря с картинкой и поиском; клики заполняют список справа (1 за клик, 10 с Ctrl, 100 с Shift), который останавливается на пределе веса получателя. Список предметов отправляется только администраторам.

**Сторона:** Клиент · **Ждёт:** да (Promise в TypeScript, в Lua приостанавливает поток)

```ts title="Сигнатура"
itemPicker(request: ItemPickerRequest): Promise<PickedItem[] | null>
```

```lua title="Lua"
local list = aiLib.itemPicker(request) -- таблица или nil, вызывайте внутри потока
```

#### Параметры

<TypeTable
  type={{
    request: { type: 'ItemPickerRequest', description: 'Поля ниже.', required: true },
  }}
/>

#### ItemPickerRequest

<TypeTable
  type={{
    title: { type: 'string', description: 'Заголовок выбора, уже переведённый.', required: true },
    target: { type: 'number', description: 'Серверный id игрока, который получит предметы: его свободный вес ограничивает список.', default: 'администратор, который выбирает' },
  }}
/>

#### Возвращает

`Promise<PickedItem[] | null>`: список, который взял администратор, каждая строка `{ name: string; count: number }` (count это целое число больше 0); `null`, если выбор закрыли. Lua возвращает список или `nil`. Типы: [`ItemPickerRequest`](/ru/docs/developers/api/types#itempickerrequest) и [`PickedItem`](/ru/docs/developers/api/types#pickeditem).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, itemPicker } from "@aicore-fivem/lib/client";

export async function giveItems(target: number): Promise<void> {
  const list = await itemPicker({ title: "Give items", target });
  if (!list || list.length === 0) return;
  await callAction("myadmin:give", [target, list], { fallback: "GIVE_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local function giveItems(target)
    CreateThread(function()
        local list = aiLib.itemPicker({ title = 'Give items', target = target })
        if not list or #list == 0 then return end
        aiLib.callAction('myadmin:give', { target, list }, { fallback = 'GIVE_FAILED' })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Предметы выдаёт ваш серверный обработчик: проверьте, что вызывающий является администратором (guard-условие `isAdmin`), и снова проверьте каждое название и количество. Сам выбор никогда ничего не выдаёт.
</Callout>

## Подсказки вручную

[Точки](/ru/docs/developers/api/lib-client/points) показывают и скрывают подсказки за вас. Используйте эти функции только для подсказки, которая не привязана к месту.

### showPrompt

Показывает одну из подсказок вашего ресурса (или меняет её текст): окно «нажмите E» справа на экране. С `at` подсказка вместо этого парит над точкой в мире или местом на сущности.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
showPrompt(id: string, text: string, at?: PromptAnchor): void
```

```lua title="Lua"
aiLib.showPrompt(id, text) -- в Lua нет привязки к миру
```

#### Параметры

<TypeTable
  type={{
    id: { type: 'string', description: 'Ваш собственный id этой подсказки. Id привязаны к ресурсу: два ресурса никогда не конфликтуют.', required: true },
    text: { type: 'string', description: 'Текст подсказки, уже переведённый.', required: true },
    at: { type: 'PromptAnchor', description: 'Рисовать её в мире: точка { x, y, z } или { anchors: [{ entity, offset }] } места на сущностях. Только TypeScript. См. PromptAnchor на странице точек.' },
  }}
/>

#### Возвращает

`void`.

#### Пример

См. [`onPromptPressed`](#onpromptpressed).

### hidePrompt

Скрывает одну из подсказок вашего ресурса. Id, который не показан, ничего не делает.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
hidePrompt(id: string): void
```

```lua title="Lua"
aiLib.hidePrompt(id)
```

#### Параметры

<TypeTable
  type={{
    id: { type: 'string', description: 'Id, переданный в showPrompt.', required: true },
  }}
/>

#### Возвращает

`void`.

### onPromptPressed

Запускает обработчик, когда игрок нажимает клавишу взаимодействия (по умолчанию `E`), пока сверху находится одна из подсказок вашего ресурса.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
onPromptPressed(handler: (id: string) => void): void
```

```lua title="Lua"
aiLib.onPromptPressed(function(id) end)
```

#### Параметры

<TypeTable
  type={{
    handler: { type: '(id: string) => void', description: 'Получает id подсказки, которая была сверху. Выполняется для каждой подсказки вашего ресурса, включая подсказки Points: проверяйте id.', required: true },
  }}
/>

#### Возвращает

`void`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, hidePrompt, onCache, onPromptPressed, showPrompt } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();

// «Нажмите E, чтобы высадить», пока сидите на пассажирском месте.
onCache("seat", (seat) => {
  if (seat === 0) showPrompt("eject", Locale("EJECT"));
  else hidePrompt("eject");
});

onPromptPressed((id) => {
  if (id !== "eject") return;
  TaskLeaveVehicle(PlayerPedId(), GetVehiclePedIsIn(PlayerPedId(), false), 4160);
});
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()

aiLib.cache.onChange('seat', function(seat)
    if seat == 0 then aiLib.showPrompt('eject', t('EJECT')) else aiLib.hidePrompt('eject') end
end)

aiLib.onPromptPressed(function(id)
    if id ~= 'eject' then return end
    TaskLeaveVehicle(PlayerPedId(), GetVehiclePedIsIn(PlayerPedId(), false), 4160)
end)
```
</Tab>

## Мини-игры

### skillCheck

Проверка навыка ai-lib: стрелка проходит по кольцу один раз за этап, и игрок нажимает показанную клавишу, пока она на зелёной дуге. У неё распространённая в FiveM форма проверки навыка (`"easy" | "medium" | "hard"` или `{ areaSize, speedMultiplier }`), поэтому код, написанный для проверки навыка ox_lib, работает так же.

**Сторона:** Клиент · **Ждёт:** да (Promise в TypeScript, в Lua приостанавливает поток)

```ts title="Сигнатура"
skillCheck(difficulty: SkillDifficulty | SkillDifficulty[], keys?: string[]): Promise<boolean>
```

```lua title="Lua"
local passed = aiLib.skillCheck(difficulty, keys) -- boolean, вызывайте внутри потока
```

#### Параметры

<TypeTable
  type={{
    difficulty: { type: 'SkillDifficulty | SkillDifficulty[]', description: 'Один этап или список этапов, которые проходятся один за другим (не более 20).', required: true },
    keys: { type: 'string[]', description: 'Клавиши, которые может запросить этап: отдельные буквы или цифры. Каждый этап показывает одну из них.', default: '["e"]' },
  }}
/>

#### SkillDifficulty

[`SkillDifficulty`](/ru/docs/developers/api/types#skilldifficulty) это одно из:

<TypeTable
  type={{
    '"easy"': { type: 'string', description: 'Зелёная дуга 50 градусов, стрелка 0.6 оборота в секунду.' },
    '"medium"': { type: 'string', description: 'Зелёная дуга 40 градусов, 0.85 оборота в секунду.' },
    '"hard"': { type: 'string', description: 'Зелёная дуга 25 градусов, 1 оборот в секунду.' },
    '{ areaSize, speedMultiplier }': { type: '{ areaSize: number; speedMultiplier: number }', description: 'Ваш собственный этап: areaSize это зелёная дуга в градусах (5-180), speedMultiplier умножает скорость easy (0.2-5).' },
  }}
/>

#### Возвращает

`Promise<boolean>`: `true`, если пройдены все этапы; `false` при промахе, неверной клавише или Escape.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, skillCheck } from "@aicore-fivem/lib/client";

export async function hotwire(netId: number): Promise<void> {
  const passed = await skillCheck(["easy", "easy", "medium", { areaSize: 30, speedMultiplier: 1.5 }], ["w", "a", "s", "d"]);
  await callAction("mykeys:hotwire", [netId, passed], { fallback: "HOTWIRE_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local function hotwire(netId)
    CreateThread(function()
        local passed = aiLib.skillCheck({ 'easy', 'easy', 'medium' }, { 'w', 'a', 's', 'd' })
        aiLib.callAction('mykeys:hotwire', { netId, passed }, { fallback = 'HOTWIRE_FAILED' })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Результат это слово клиента. Когда мини-игра приносит выгоду (машина, ограбление), запускайте её с сервера через `minigameFor(source, { game: "skillCheck", ... })`, который также отклоняет победу быстрее реальной игры ([Ввод от клиента](/ru/docs/developers/api/lib-server/client-input)).
</Callout>

### lockpick

Взлом отмычкой ai-lib: игрок двигает отмычку клавишами A / D (или стрелками) и удерживает W, чтобы повернуть замок. Замок поворачивается тем дальше, чем ближе отмычка к скрытой зоне срабатывания; если давить силой, отмычка изнашивается.

**Сторона:** Клиент · **Ждёт:** да (Promise в TypeScript, в Lua приостанавливает поток)

```ts title="Сигнатура"
lockpick(options?: LockpickOptions): Promise<LockpickResult>
```

```lua title="Lua"
local result = aiLib.lockpick(options) -- 'opened' | 'broken' | 'cancelled', вызывайте внутри потока
```

#### Параметры

<TypeTable
  type={{
    options: { type: 'LockpickOptions', description: 'Поля ниже.', default: '{}' },
  }}
/>

#### LockpickOptions

<TypeTable
  type={{
    difficulty: { type: '"easy" | "medium" | "hard"', description: 'Ширина зоны срабатывания каждого штифта: easy 18, medium 11, hard 6 градусов.', default: '"medium"' },
    pins: { type: 'number', description: 'Штифты, которые нужно повернуть один за другим (1-6).', default: '1' },
    picks: { type: 'number', description: 'Сколько отмычек игрок может сломать, прежде чем взлом провалится как broken (1-10).', default: '1' },
  }}
/>

#### Возвращает

`Promise<LockpickResult>` ([`LockpickResult`](/ru/docs/developers/api/types#lockpickresult)): `"opened"`, если повернулись все штифты; `"broken"`, если сломалась последняя отмычка (заберите предмет отмычки); `"cancelled"`, если игрок нажал Escape.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, lockpick } from "@aicore-fivem/lib/client";

export async function pickDoor(doorId: string): Promise<void> {
  const result = await lockpick({ difficulty: "hard", pins: 3, picks: 2 });
  if (result === "cancelled") return;
  await callAction("mydoors:picked", [doorId, result], { fallback: "PICK_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local function pickDoor(doorId)
    CreateThread(function()
        local result = aiLib.lockpick({ difficulty = 'hard', pins = 3, picks = 2 })
        if result == 'cancelled' then return end
        aiLib.callAction('mydoors:picked', { doorId, result }, { fallback = 'PICK_FAILED' })
    end)
end
```
</Tab>
</Tabs>
