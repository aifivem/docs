---
title: Strefy
description: Zones - obszary z callbackami wejścia i wyjścia (kula, walec, wielokąt), sprawdzane we własnym odstępie, nigdy co klatkę.
icon: Shapes
---

**Strefa** to obszar, który uruchamia kod, gdy gracz do niego wchodzi albo go opuszcza: wjazd do dzielnicy, obszar z ograniczeniem prędkości, marker rysowany tylko w pobliżu. Gdy gracz ma w tym miejscu coś *zrobić* (nacisnąć klawisz, wybrać opcję targetu), użyj zamiast tego [punktu](/pl/docs/developers/api/lib-client/points): to strefa z już podłączonym promptem, targetem, pedem i blipem.

W TypeScript każdą strefę sprawdza jeden mechanizm ai-lib za wszystkie zasoby (strefy leżą w siatce 64 m, więc milion stref kosztuje tyle samo co kilka). Twój zasób sprawdza własne strefy tylko wtedy, gdy ai-lib nie działa. W Lua każdy zasób uruchamia jedno zadanie harmonogramu dla swoich stref.

### new Zones

Tworzy grupę stref. Zrób jedną grupę na funkcję na górze pliku.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
new Zones()
```

```lua title="Lua"
local zones = aiLib.Zones.new()
```

#### Zwracana wartość

Grupa `Zones` z metodami poniżej.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { Zones } from "@aicore-fivem/lib/client";

const zones = new Zones();
```
</Tab>
<Tab value="Lua">
```lua
local zones = aiLib.Zones.new()
```
</Tab>
</Tabs>

### zones.add

Dodaje strefę albo zastępuje strefę o tym samym id. Gdy gracz był wewnątrz zastępowanej strefy, najpierw działa jej `onExit`.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
zones.add(id: string, options: ZoneOptions): void
```

```lua title="Lua"
zones:add(id, options)
```

#### Parametry

<TypeTable
  type={{
    id: { type: 'string', description: 'Unikalne w tej grupie. To samo id zastępuje starą strefę.', required: true },
    options: { type: 'ZoneOptions', description: 'Kształt i callbacki. Pola poniżej.', required: true },
  }}
/>

#### ZoneOptions

<TypeTable
  type={{
    shape: { type: 'ZoneShape', description: 'Obszar: kula, walec albo wielokąt. Kształty poniżej.', required: true },
    interval: { type: 'number', description: 'Jak często strefa jest sprawdzana, w milisekundach (co najmniej 50). Sklep potrzebuje około 500, szybki wyzwalacz około 100.', default: '500' },
    onEnter: { type: '() => void', description: 'Gracz wszedł do środka. Rzucony błąd jest logowany.' },
    onExit: { type: '() => void', description: 'Gracz wyszedł albo strefa została usunięta lub zastąpiona, gdy gracz był w środku.' },
  }}
/>

#### ZoneShape

[`ZoneShape`](/pl/docs/developers/api/types#zoneshape) to jeden z trzech obiektów, wybierany przez `type`:

<TypeTable
  type={{
    '"sphere"': { type: '{ type: "sphere"; center: Vec3; radius: number }', description: 'Kula o promieniu radius metrów wokół center.' },
    '"cylinder"': { type: '{ type: "cylinder"; center: Vec3; radius: number; height: number }', description: 'Koło o promieniu radius metrów na ziemi, height metrów w górę i w dół od center (pokoje, piętra).' },
    '"poly"': { type: '{ type: "poly"; points: Array<{ x: number; y: number }>; minZ: number; maxZ: number }', description: 'Wielokąt na ziemi (punkty po kolei wokół krawędzi) między dwiema wysokościami.' },
  }}
/>

W Lua `center` może być `vector3`, a punkty tabelami `{ x = ..., y = ... }`.

#### Zwracana wartość

`void`.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, notify, Zones } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const zones = new Zones();

zones.add("safezone", {
  shape: { type: "cylinder", center: { x: 298.6, y: -584.5, z: 43.3 }, radius: 60, height: 30 },
  onEnter: () => notify(Locale("SAFEZONE_IN"), "info"),
  onExit: () => notify(Locale("SAFEZONE_OUT"), "info"),
});

zones.add("yard", {
  shape: {
    type: "poly",
    points: [
      { x: 1700.1, y: 2560.4 },
      { x: 1780.6, y: 2560.4 },
      { x: 1780.6, y: 2620.2 },
      { x: 1700.1, y: 2620.2 },
    ],
    minZ: 40,
    maxZ: 60,
  },
  interval: 1000,
  onEnter: () => SetPedMoveRateOverride(PlayerPedId(), 0.8),
});
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()
local zones = aiLib.Zones.new()

zones:add('safezone', {
    shape = { type = 'cylinder', center = vector3(298.6, -584.5, 43.3), radius = 60.0, height = 30.0 },
    onEnter = function() aiLib.notify(t('SAFEZONE_IN'), 'info') end,
    onExit = function() aiLib.notify(t('SAFEZONE_OUT'), 'info') end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Strefa narysowana w twoim panelu administratora widżetem `zone` daje narożniki; zamień je w wielokąt przez `polyFromCorners(corners, height)` z `@aicore-fivem/lib/shared`. Serwer może sprawdzać te same kształty przez `zoneContains(shape, x, y, z)`.
</Callout>

### zones.isInside

Czy gracz jest w strefie, według jej ostatniego sprawdzenia.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
zones.isInside(id: string): boolean
```

```lua title="Lua"
local inside = zones:isInside(id)
```

#### Parametry

<TypeTable
  type={{
    id: { type: 'string', description: 'Id podane w add.', required: true },
  }}
/>

#### Zwracana wartość

`boolean`: `true`, dopóki jest w środku; `false` na zewnątrz albo dla nieznanego id. Odzwierciedla ostatnie sprawdzenie, więc może być stare do `interval` ms.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
if (zones.isInside("safezone")) return notify(Locale("NO_WEAPONS_HERE"), "error");
```
</Tab>
<Tab value="Lua">
```lua
if zones:isInside('safezone') then return aiLib.notify(t('NO_WEAPONS_HERE'), 'error') end
```
</Tab>
</Tabs>

### zones.size

Ile stref ma grupa.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
zones.size: number // właściwość tylko do odczytu
```

Brak odpowiednika w Lua.

#### Zwracana wartość

`number`: liczba stref w tej grupie.

#### Przykład

```ts
console.log(`${zones.size} zones loaded`);
```
