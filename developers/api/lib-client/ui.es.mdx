ai-lib dibuja una única interfaz compartida para todos los recursos: tarjetas de notificación, la barra de progreso, los prompts de "pulsa E", menús, diálogos de entrada y minijuegos. Tu script solo los pide, así que todos los scripts del servidor se ven igual y no escribes NUI para estas cosas. El selector de objetos lo dibuja ai-core.

Los textos que pasas se muestran tal cual: tradúcelos primero (`Locale("KEY")` en TypeScript, `t('KEY')` en Lua).

## Notificaciones

### notify

Muestra una tarjeta de notificación en la pantalla de este jugador.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
notify(text: string, kind?: NotificationKind, duration?: number): void
```

```lua title="Lua"
aiLib.notify(text, kind, duration)
```

#### Parámetros

<TypeTable
  type={{
    text: { type: 'string', description: 'El mensaje, ya traducido.', required: true },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'El color y el icono de la tarjeta.', default: '"info"' },
    duration: { type: 'number', description: 'Milisegundos en pantalla.', default: '4000' },
  }}
/>

El tipo de kind es [`NotificationKind`](/es/docs/developers/api/types#notificationkind). Para notificar a un jugador desde el servidor, usa `notify(source, text, kind)` del servidor.

#### Devuelve

`void`.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, notify } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();

notify(Locale("WELCOME"));
notify(Locale("NO_MONEY"), "error");
notify(Locale("SAVED"), "success", 2000);
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()

aiLib.notify(t('NO_MONEY'), 'error')
aiLib.notify(t('SAVED'), 'success', 2000)
```
</Tab>
</Tabs>

## Barra de progreso

### progress

Ejecuta una acción temporizada con la barra de progreso de ai-lib y una animación o un escenario opcional, y espera hasta que termine. Termina antes (cancelada) cuando el jugador muere, se sube a un vehículo, pulsa la tecla de cancelar de ai-lib (por defecto `Backspace`, solo con `canCancel`) o tu script llama a `cancelProgress()`. Un progreso por recurso a la vez.

**Lado:** Cliente · **Espera:** sí (Promise en TypeScript, cede el hilo en Lua)

```ts title="Firma"
progress(options: ProgressOptions): Promise<boolean>
```

```lua title="Lua"
local finished = aiLib.progress(options) -- boolean, llamar dentro de un hilo
```

#### Parámetros

<TypeTable
  type={{
    options: { type: 'ProgressOptions', description: 'Qué muestra la barra y qué puede hacer el jugador. Campos abajo.', required: true },
  }}
/>

#### ProgressOptions

<TypeTable
  type={{
    label: { type: 'string', description: 'Texto de la barra, ya traducido.', required: true },
    duration: { type: 'number', description: 'Cuánto dura la barra, en milisegundos.', required: true },
    anim: { type: '{ dict: string; clip: string; flag?: number }', description: 'Una animación que se reproduce durante todo el tiempo (flag por defecto 49: parte superior del cuerpo, en bucle, puede moverse). Se detiene al final.' },
    scenario: { type: 'string', description: 'Un escenario que se reproduce en el sitio (WORLD_HUMAN_HAMMERING) cuando no hay anim. Se limpia al final.' },
    face: { type: 'Vec3', description: 'El jugador se gira primero hacia este punto (un surtidor, un mostrador, un vehículo), en 600 ms, solo a pie. Solo TypeScript.' },
    canCancel: { type: 'boolean', description: 'El jugador puede cancelar con la tecla de cancelar de ai-lib.', default: 'false' },
    allowVehicle: { type: 'boolean', description: 'Estar en un vehículo no lo cancela. Sin esto, estar en un vehículo en cualquier comprobación (también al empezar) lo cancela.', default: 'false' },
    whileDead: { type: 'boolean', description: 'Sigue en marcha cuando el jugador cae derribado. Por defecto, caer derribado, en cualquier script de muerte, lo cancela.', default: 'false' },
    freeze: { type: 'boolean', description: 'Mantiene al jugador en el sitio mientras está en marcha.', default: 'false' },
    disable: { type: '{ move?: boolean; car?: boolean; mouse?: boolean; combat?: boolean }', description: 'Controles bloqueados mientras está en marcha: move = caminar (controles 30, 31, 36, 21, 44), car = conducir (63, 64, 71, 72, 75), mouse = mirar alrededor (1, 2, 106), combat = pelear (24, 25, 37, 47, 58, 140-143, 257, 263, 264).' },
  }}
/>

#### Devuelve

`Promise<boolean>`: `true` cuando la barra terminó; `false` cuando se canceló, o al momento cuando otro progreso de tu recurso sigue en marcha. Lua devuelve el mismo booleano.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, createLocale, nearestVehicle, notify, progress } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();

export async function repair(): Promise<void> {
  const vehicle = nearestVehicle(4, { notOwn: true });
  if (!vehicle) return notify(Locale("NO_VEHICLE"), "error");
  const [x = 0, y = 0, z = 0] = GetEntityCoords(vehicle, false);
  const done = await progress({
    label: Locale("REPAIRING"),
    duration: 8000,
    face: { x, y, z },
    anim: { dict: "mini@repair", clip: "fixing_a_player" },
    canCancel: true,
    disable: { move: true, combat: true },
  });
  if (!done) return notify(Locale("CANCELLED"), "error");
  await callAction("mymech:repair", [NetworkGetNetworkIdFromEntity(vehicle)], { fallback: "REPAIR_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()

local function repair()
    CreateThread(function()
        local vehicle = aiLib.nearestVehicle(4.0, { notOwn = true })
        if vehicle == 0 then return aiLib.notify(t('NO_VEHICLE'), 'error') end
        local done = aiLib.progress({
            label = t('REPAIRING'),
            duration = 8000,
            anim = { dict = 'mini@repair', clip = 'fixing_a_player' },
            canCancel = true,
            disable = { move = true, combat = true },
        })
        if not done then return aiLib.notify(t('CANCELLED'), 'error') end
        aiLib.callAction('mymech:repair', { NetworkGetNetworkIdFromEntity(vehicle) }, { fallback = 'REPAIR_FAILED' })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
El resultado es la palabra del cliente: un tramposo puede saltarse la barra. Cuando el servidor paga por la acción (objetos, dinero, una reparación), ejecuta la barra desde el servidor con `progressFor(source, options)` ([Entrada del cliente](/es/docs/developers/api/lib-server/client-input)): solo responde `true` cuando también pasó suficiente tiempo en el servidor.
</Callout>

### cancelProgress

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
cancelProgress(): void
```

```lua title="Lua"

```

#### Devuelve

`void`.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

```

## Menús y diálogos

### menu

Muestra el menú de ai-lib y espera a que el jugador elija. Las flechas mueven, Enter elige. Las entradas con `checked` son filas de interruptor que cambian en el sitio sin cerrar el menú. En un submenú (`back: true`), un Escape corto resuelve `MENU_BACK` para que puedas abrir el menú anterior; mantener Escape lo cierra.

**Lado:** Cliente · **Espera:** sí (Promise en TypeScript, cede el hilo en Lua)

```ts title="Firma"
menu(request: MenuRequest, listeners?: ((item: string) => void) | MenuListeners): Promise<string | null>
```

```lua title="Lua"
local picked = aiLib.menu.show(request, listeners) -- string o nil, llamar dentro de un hilo
```

/>

#### MenuRequest

<TypeTable

    items: { type: 'MenuItem[]', description: 'Las filas, en orden. Campos abajo.', required: true },
    back: { type: 'boolean', description: 'Esto es un submenú: un Escape corto resuelve MENU_BACK ("__back"), mantener Escape cierra.', default: 'false' },

#### MenuItem

<TypeTable
  type={{
    id: { type: 'string', description: 'Con qué se resuelve menu cuando se elige esta fila.', required: true },
    label: { type: 'string', description: 'El texto de la fila, ya traducido.', required: true },
    icon: { type: 'string', description: 'Nombre de icono sólido de Font Awesome sin fa- (car, key). Los nombres que faltan en el mapa de iconos de ai-lib muestran un punto.' },
    description: { type: 'string', description: 'Texto extra que se muestra con la fila.' },

#### MenuListeners

<TypeTable
  type={{
    onHover: { type: '(item: string) => void', description: 'El id de la fila bajo el puntero o el foco del teclado. Úsalo para vistas previas en vivo (un color en el coche).' },

#### Devuelve

`Promise<string | null>`: el id de la entrada elegida; `"__back"` (`MENU_BACK` de `@aicore-fivem/shared`) tras un Escape corto en un submenú; `null` cuando el jugador cerró el menú. Lua devuelve lo mismo, `nil` para cerrado.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, createLocale, menu } from "@aicore-fivem/lib/client";
import { MENU_BACK } from "@aicore-fivem/shared";

const Locale = createLocale<typeof import("../../locales/en.json")>();
let engineOn = true;

export async function vehicleMenu(vehicle: number): Promise<void> {
  const pick = await menu({
    title: Locale("VEHICLE"),
    items: [
      { id: "doors", label: Locale("DOORS"), icon: "door-open" },
      { id: "engine", label: Locale("ENGINE"), icon: "power-off", checked: engineOn },
    ],
  }, {
    onToggle: (item, checked) => {
      if (item !== "engine") return;
      engineOn = checked;
      SetVehicleEngineOn(vehicle, checked, false, true);
    },
  });
  if (pick === "doors") await doorsMenu(vehicle);
}

async function doorsMenu(vehicle: number): Promise<void> {
  const pick = await menu({
    title: Locale("DOORS"),
    back: true,
    items: [0, 1, 2, 3].map((door) => ({ id: String(door), label: Locale("DOOR", door + 1) })),
  });
  if (pick === MENU_BACK) return vehicleMenu(vehicle);
  if (pick !== null) SetVehicleDoorOpen(vehicle, Number(pick), false, false);
}
```
</Tab>
<Tab value="Lua">

### itemPicker

Herramientas de admin: muestra el selector de objetos de ai-core. Lista todos los objetos del inventario activo con su imagen y un buscador; los clics rellenan una lista a la derecha (1 por clic, 10 con Ctrl, 100 con Shift) que se detiene en el límite de peso del destinatario. La lista de objetos solo se envía a los admins.

**Lado:** Cliente · **Espera:** sí (Promise en TypeScript, cede el hilo en Lua)

```ts title="Firma"
itemPicker(request: ItemPickerRequest): Promise<PickedItem[] | null>
```

```lua title="Lua"
local list = aiLib.itemPicker(request) -- table o nil, llamar dentro de un hilo
```

#### Parámetros

<TypeTable
  type={{
    request: { type: 'ItemPickerRequest', description: 'Campos abajo.', required: true },
  }}
/>

#### ItemPickerRequest

<TypeTable
  type={{
    title: { type: 'string', description: 'El título del selector, ya traducido.', required: true },
    target: { type: 'number', description: 'Id de servidor del jugador que recibe los objetos: su peso libre limita la lista.', default: 'el admin que elige' },
  }}
/>

#### Devuelve

`Promise<PickedItem[] | null>`: la lista que tomó el admin, cada fila `{ name: string; count: number }` (count un número entero mayor que 0); `null` cuando se cerró el selector. Lua devuelve la lista o `nil`. Los tipos son [`ItemPickerRequest`](/es/docs/developers/api/types#itempickerrequest) y [`PickedItem`](/es/docs/developers/api/types#pickeditem).

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, itemPicker } from "@aicore-fivem/lib/client";

export async function giveItems(target: number): Promise<void> {
  const list = await itemPicker({ title: "Give items", target });
  if (!list || list.length === 0) return;
  await callAction("myadmin:give", [target, list], { fallback: "GIVE_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local function giveItems(target)
    CreateThread(function()
        local list = aiLib.itemPicker({ title = 'Give items', target = target })
        if not list or #list == 0 then return end
        aiLib.callAction('myadmin:give', { target, list }, { fallback = 'GIVE_FAILED' })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Tu handler de servidor da los objetos: comprueba que quien llama es admin (guarda `isAdmin`) y comprueba de nuevo cada nombre y cantidad. El selector nunca da nada por sí mismo.
</Callout>

## Minijuegos

### skillCheck

La prueba de habilidad de ai-lib: una aguja recorre un anillo una vez por fase, y el jugador pulsa la tecla mostrada mientras está en el arco verde. Tiene la forma habitual de prueba de habilidad de FiveM (`"easy" | "medium" | "hard"` o `{ areaSize, speedMultiplier }`), así que el código escrito para la prueba de habilidad de ox_lib funciona igual.

**Lado:** Cliente · **Espera:** sí (Promise en TypeScript, cede el hilo en Lua)

```ts title="Firma"
skillCheck(difficulty: SkillDifficulty | SkillDifficulty[], keys?: string[]): Promise<boolean>
```

```lua title="Lua"
local passed = aiLib.skillCheck(difficulty, keys) -- boolean, llamar dentro de un hilo
```

#### Parámetros

<TypeTable
  type={{
    difficulty: { type: 'SkillDifficulty | SkillDifficulty[]', description: 'Una fase, o una lista de fases jugadas una tras otra (como máximo 20).', required: true },
    keys: { type: 'string[]', description: 'Teclas que puede pedir una fase: letras o dígitos sueltos. Cada fase muestra una de ellas.', default: '["e"]' },
  }}
/>

#### SkillDifficulty

[`SkillDifficulty`](/es/docs/developers/api/types#skilldifficulty) es uno de:

<TypeTable
  type={{
    '"easy"': { type: 'string', description: 'Arco verde de 50 grados, aguja a 0.6 vueltas por segundo.' },
    '"medium"': { type: 'string', description: 'Arco verde de 40 grados, 0.85 vueltas por segundo.' },
    '"hard"': { type: 'string', description: 'Arco verde de 25 grados, 1 vuelta por segundo.' },
    '{ areaSize, speedMultiplier }': { type: '{ areaSize: number; speedMultiplier: number }', description: 'Tu propia fase: areaSize es el arco verde en grados (5-180), speedMultiplier multiplica la velocidad de easy (0.2-5).' },
  }}
/>

#### Devuelve

`Promise<boolean>`: `true` cuando se acertaron todas las fases; `false` con un fallo, una tecla incorrecta o Escape.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, skillCheck } from "@aicore-fivem/lib/client";

export async function hotwire(netId: number): Promise<void> {
  const passed = await skillCheck(["easy", "easy", "medium", { areaSize: 30, speedMultiplier: 1.5 }], ["w", "a", "s", "d"]);
  await callAction("mykeys:hotwire", [netId, passed], { fallback: "HOTWIRE_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local function hotwire(netId)
    CreateThread(function()
        local passed = aiLib.skillCheck({ 'easy', 'easy', 'medium' }, { 'w', 'a', 's', 'd' })
        aiLib.callAction('mykeys:hotwire', { netId, passed }, { fallback = 'HOTWIRE_FAILED' })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
El resultado es la palabra del cliente. Cuando el minijuego paga (un coche, un robo), juégalo desde el servidor con `minigameFor(source, { game: "skillCheck", ... })`, que además rechaza una victoria más rápida que una partida real ([Entrada del cliente](/es/docs/developers/api/lib-server/client-input)).
</Callout>

### lockpick

La ganzúa de ai-lib: el jugador mueve la ganzúa con A / D (o las flechas) y mantiene W para girar la cerradura. La cerradura gira más cuanto más cerca está la ganzúa del punto justo oculto; forzarla desgasta la ganzúa.

**Lado:** Cliente · **Espera:** sí (Promise en TypeScript, cede el hilo en Lua)

```ts title="Firma"
lockpick(options?: LockpickOptions): Promise<LockpickResult>
```

```lua title="Lua"
local result = aiLib.lockpick(options) -- 'opened' | 'broken' | 'cancelled', llamar dentro de un hilo
```

#### Parámetros

<TypeTable
  type={{
    options: { type: 'LockpickOptions', description: 'Campos abajo.', default: '{}' },
  }}
/>

#### LockpickOptions

<TypeTable
  type={{
    difficulty: { type: '"easy" | "medium" | "hard"', description: 'Anchura del punto justo de cada pin: easy 18, medium 11, hard 6 grados.', default: '"medium"' },
    pins: { type: 'number', description: 'Pines que se giran uno tras otro (1-6).', default: '1' },
    picks: { type: 'number', description: 'Ganzúas que el jugador puede romper antes de fallar como broken (1-10).', default: '1' },
  }}
/>

#### Devuelve

`Promise<LockpickResult>` ([`LockpickResult`](/es/docs/developers/api/types#lockpickresult)): `"opened"` cuando giraron todos los pines; `"broken"` cuando se rompió la última ganzúa (quita el objeto de ganzúa); `"cancelled"` cuando el jugador pulsó Escape.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { callAction, lockpick } from "@aicore-fivem/lib/client";

export async function pickDoor(doorId: string): Promise<void> {
  const result = await lockpick({ difficulty: "hard", pins: 3, picks: 2 });
  if (result === "cancelled") return;
  await callAction("mydoors:picked", [doorId, result], { fallback: "PICK_FAILED" });
}
```
</Tab>
<Tab value="Lua">
```lua
local function pickDoor(doorId)
    CreateThread(function()
        local result = aiLib.lockpick({ difficulty = 'hard', pins = 3, picks = 2 })
        if result == 'cancelled' then return end
        aiLib.callAction('mydoors:picked', { doorId, result }, { fallback = 'PICK_FAILED' })
    end)
end
```
</Tab>
</Tabs>
