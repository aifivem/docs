---
title: Layers through ai-core
description: medical, appearance, gestures, seatbelt, fuel, mdt, radial, world and inventory - client calls that reach whatever death, clothing, emote, belt, fuel, MDT, radial, weather or inventory script the server runs.
icon: Layers
---

These objects never talk to a specific script. They ask **ai-core**, and ai-core forwards to whichever script the server runs for that job: ai-death or another death script, ai-appearance or tgiann-clothing, any supported emote or radial script. Your script keeps working when the owner swaps one. How the layers work is on [Layers and the bridge](/docs/developers/layers).

When no script of that kind runs, the calls answer `false`, `null` or the game's own value, as each entry says.

## medical

### medical.isDead

Whether the local player is down (dead or in last stand), in whatever death script runs. Death scripts keep a downed ped alive to animate it, so `IsEntityDead` alone misses them. A memory read after the first call.

**Side:** Client · **Waits:** no

```ts title="Signature"
medical.isDead(): boolean
```

No Lua twin: call `exports['ai-core']:IsDead()` and listen to the local event `ai-core:client:dead` (`dead`).

#### Returns

`boolean`: `true` when ai-core's medical layer says the player is down, or the ped is dead for the game.

#### Example

```ts
import { medical, notify } from "@aicore-fivem/lib/client";

RegisterCommand(
  "phone",
  () => {
    if (medical.isDead()) return notify("You cannot use the phone now", "error");
    SetNuiFocus(true, true);
  },
  false,
);
```

### medical.onChange

Runs a handler when the local player goes down or gets up.

**Side:** Client · **Waits:** no

```ts title="Signature"
medical.onChange(fn: (dead: boolean) => void): void
```

No Lua twin: `AddEventHandler('ai-core:client:dead', function(dead) end)`.

#### Parameters

<TypeTable
  type={{
    fn: { type: '(dead: boolean) => void', description: 'Gets true when the player went down, false when they got up.', required: true },
  }}
/>

#### Returns

`void`.

#### Example

```ts
import { medical, Points } from "@aicore-fivem/lib/client";

const points = new Points();
medical.onChange(() => points.refresh()); // points whose canShow reads medical.isDead()
```

## appearance

Looks on peds through ai-core's appearance layer, whatever clothing script runs.

### appearance.apply

Puts a stored look on a ped of the look's model. Get the look on the server with `appearance.get(charId)`, create the ped with `look.model`, then apply. On the player's own ped it changes their clothes.

**Side:** Client · **Waits:** no

```ts title="Signature"
appearance.apply(ped: number, look: CharacterAppearance): boolean
```

```lua title="Lua"
local ok = aiLib.appearance.apply(ped, look)
```

#### Parameters

<TypeTable
  type={{
    ped: { type: 'number', description: 'The ped to dress. Its model must be look.model.', required: true },
    look: { type: 'CharacterAppearance', description: '{ model: number; data: unknown }: the model hash and the clothing script own data. Treat data as opaque.', required: true },
  }}
/>

The type is [`CharacterAppearance`](/docs/developers/api/types#characterappearance).

#### Returns

`boolean`: `false` when the ped is gone, the model differs, or no clothing script runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, LocalPed, triggerServerCallback } from "@aicore-fivem/lib/client";
import type { CharacterAppearance } from "@aicore-fivem/shared";

// A sleeping copy of a character, dressed like them.
export async function showSleeper(charId: number): Promise<void> {
  const look = (await triggerServerCallback("mysleep:look", [charId]).catch(() => null)) as CharacterAppearance | null;
  if (!look) return;
  new LocalPed({
    model: look.model,
    coords: { x: 151.2, y: -1004.6, z: 29.4, heading: 90 },
    onSpawn: (ped) => appearance.apply(ped, look),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local function showSleeper(charId)
    CreateThread(function()
        local look = aiLib.triggerServerCallback('mysleep:look', { charId })
        if type(look) ~= 'table' then return end
        aiLib.LocalPed.new({
            model = look.model,
            coords = vector4(151.2, -1004.6, 29.4, 90.0),
            onSpawn = function(ped) aiLib.appearance.apply(ped, look) end,
        })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Check what the server sends before you cast it. A ped created with another model than `look.model` cannot take the look: `apply` answers `false`.
</Callout>

## fuel

### fuel.get

A vehicle's fuel level. The server keeps a `fuel` state bag for every vehicle whatever fuel script runs, so this is a memory read; without that bag it is the game's tank level.

**Side:** Client · **Waits:** no

```ts title="Signature"
fuel.get(vehicle: number): number
```

No Lua twin: read `Entity(vehicle).state.fuel`. Setting fuel is server-only (`fuel.set` on [Vehicles](/docs/developers/api/lib-server/vehicles)).

#### Parameters

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'A vehicle this client knows.', required: true },
  }}
/>

#### Returns

`number`: 0-100.

#### Example

```ts
import { cache, every, fuel } from "@aicore-fivem/lib/client";

every(1000, () => {
  if (cache.vehicle !== false) SendNUIMessage({ action: "fuel", data: Math.round(fuel.get(cache.vehicle)) });
});
```

### inventory.currentWeapon

The weapon item in the player's hand: its name, label and picture.

**Side:** Client · **Waits:** no

```ts title="Signature"
inventory.currentWeapon(): HeldWeapon | null
```

```lua title="Lua"
local weapon = aiLib.inventory.currentWeapon() -- table or nil
```

#### Returns

[`HeldWeapon`](/docs/developers/api/types#heldweapon) `{ name: string; label: string; image?: string }` (`name` like `WEAPON_PISTOL`, `image` a `nui://` url when the inventory has one), or `null` (`nil`) when the hand is empty.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory, onCache } from "@aicore-fivem/lib/client";

// Read it when the weapon changes, never every frame.
onCache("weapon", () => SendNUIMessage({ action: "weapon", data: inventory.currentWeapon() }));
```
</Tab>
<Tab value="Lua">
```lua
aiLib.cache.onChange('weapon', function()
    SendNUIMessage({ action = 'weapon', data = aiLib.inventory.currentWeapon() })
end)
```
