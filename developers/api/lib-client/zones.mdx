---
title: Zones
description: Zones - areas with enter and exit callbacks (sphere, cylinder, polygon), checked at their own interval, never every frame.
icon: Shapes
---

A **zone** is an area that runs code when the player enters or leaves it: entering a district, a speed limit area, a marker that draws only nearby. When the player should *do* something at the place (press a key, pick a target option), use a [point](/docs/developers/api/lib-client/points) instead: it is a zone with the prompt, target, ped and blip already wired.

In TypeScript every zone is checked by ai-lib's one checker for all resources (zones sit in a 64 m grid, so a million zones cost the same as a few). Your resource checks its own zones only while ai-lib is not running. In Lua each resource runs one scheduler job for its zones.

### new Zones

Creates a group of zones. Make one group per feature at the top of the file.

**Side:** Client · **Waits:** no

```ts title="Signature"
new Zones()
```

```lua title="Lua"
local zones = aiLib.Zones.new()
```

#### Returns

A `Zones` group with the methods below.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { Zones } from "@aicore-fivem/lib/client";

const zones = new Zones();
```
</Tab>
<Tab value="Lua">
```lua
local zones = aiLib.Zones.new()
```
</Tab>
</Tabs>

### zones.add

Adds a zone, or replaces the zone with the same id. When the replaced zone had the player inside, its `onExit` runs first.

**Side:** Client · **Waits:** no

```ts title="Signature"
zones.add(id: string, options: ZoneOptions): void
```

```lua title="Lua"
zones:add(id, options)
```

#### Parameters

<TypeTable
  type={{
    id: { type: 'string', description: 'Unique within this group. The same id replaces the old zone.', required: true },
    options: { type: 'ZoneOptions', description: 'The shape and the callbacks. Fields below.', required: true },
  }}
/>

#### ZoneOptions

<TypeTable
  type={{
    shape: { type: 'ZoneShape', description: 'The area: a sphere, a cylinder or a polygon. Shapes below.', required: true },
    interval: { type: 'number', description: 'How often the zone is checked, in milliseconds (at least 50). A shop needs about 500, a fast trigger about 100.', default: '500' },
    onEnter: { type: '() => void', description: 'The player came inside. A thrown error is logged.' },
    onExit: { type: '() => void', description: 'The player left, or the zone was removed or replaced while the player was inside.' },
  }}
/>

#### ZoneShape

[`ZoneShape`](/docs/developers/api/types#zoneshape) is one of three objects, picked by `type`:

<TypeTable
  type={{
    '"sphere"': { type: '{ type: "sphere"; center: Vec3; radius: number }', description: 'A ball of radius metres around center.' },
    '"cylinder"': { type: '{ type: "cylinder"; center: Vec3; radius: number; height: number }', description: 'A circle of radius metres on the ground, height metres up and down from center (rooms, floors).' },
    '"poly"': { type: '{ type: "poly"; points: Array<{ x: number; y: number }>; minZ: number; maxZ: number }', description: 'A ground polygon (the points in order around the edge) between two heights.' },
  }}
/>

In Lua, `center` may be a `vector3` and the points `{ x = ..., y = ... }` tables.

#### Returns

`void`.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, notify, Zones } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const zones = new Zones();

zones.add("safezone", {
  shape: { type: "cylinder", center: { x: 298.6, y: -584.5, z: 43.3 }, radius: 60, height: 30 },
  onEnter: () => notify(Locale("SAFEZONE_IN"), "info"),
  onExit: () => notify(Locale("SAFEZONE_OUT"), "info"),
});

zones.add("yard", {
  shape: {
    type: "poly",
    points: [
      { x: 1700.1, y: 2560.4 },
      { x: 1780.6, y: 2560.4 },
      { x: 1780.6, y: 2620.2 },
      { x: 1700.1, y: 2620.2 },
    ],
    minZ: 40,
    maxZ: 60,
  },
  interval: 1000,
  onEnter: () => SetPedMoveRateOverride(PlayerPedId(), 0.8),
});
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()
local zones = aiLib.Zones.new()

zones:add('safezone', {
    shape = { type = 'cylinder', center = vector3(298.6, -584.5, 43.3), radius = 60.0, height = 30.0 },
    onEnter = function() aiLib.notify(t('SAFEZONE_IN'), 'info') end,
    onExit = function() aiLib.notify(t('SAFEZONE_OUT'), 'info') end,
})
```
</Tab>
</Tabs>

<Callout type="info">
A zone drawn in your admin panel with the `zone` widget gives corners; turn them into a polygon with `polyFromCorners(corners, height)` from `@aicore-fivem/lib/shared`. The server can test the same shapes with `zoneContains(shape, x, y, z)`.
</Callout>

### zones.remove

**Side:** Client · **Waits:** no


```lua title="Lua"
zones:remove(id)
```

#### Parameters

<TypeTable

### zones.clear

Removes every zone of the group; `onExit` runs for the ones the player is in.

**Side:** Client · **Waits:** no

```ts title="Signature"
zones.clear(): void
```

```lua title="Lua"
zones:clear()
```

#### Returns

`void`.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
onServerEvent("myscript:eventOver", () => zones.clear());
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onServerEvent('myscript:eventOver', function() zones:clear() end)
```
</Tab>
</Tabs>

### zones.isInside

Whether the player is inside a zone, as of its last check.

**Side:** Client · **Waits:** no

```ts title="Signature"
zones.isInside(id: string): boolean
```

```lua title="Lua"
local inside = zones:isInside(id)
```

#### Parameters

<TypeTable
  type={{
    id: { type: 'string', description: 'The id given to add.', required: true },
  }}
/>

#### Returns

`boolean`: `true` while inside; `false` outside or for an unknown id. It reflects the last check, so it can be up to `interval` ms old.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
if (zones.isInside("safezone")) return notify(Locale("NO_WEAPONS_HERE"), "error");
```
</Tab>
<Tab value="Lua">
```lua
if zones:isInside('safezone') then return aiLib.notify(t('NO_WEAPONS_HERE'), 'error') end
```
</Tab>
</Tabs>

### zones.size

How many zones the group holds.

**Side:** Client · **Waits:** no

```ts title="Signature"
zones.size: number // read-only property
```

No Lua twin.

#### Returns

`number`: the count of zones in this group.

#### Example

```ts
console.log(`${zones.size} zones loaded`);
```
