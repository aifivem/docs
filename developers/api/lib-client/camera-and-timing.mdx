A scripted camera for showrooms and scenes, a per-frame job you switch on only while it is needed, the client half of the server's area streaming, and the server's clock for countdowns. Periodic work in general is `every(ms, fn)` (see [Lib: shared and fivem](/docs/developers/api/lib-shared)); never `setInterval` or a bare `setTick`.

## ScriptCamera

### new ScriptCamera

A scripted camera: a shop's showroom view, an editor, a scene, binoculars. `start` creates and shows it, the other methods move and change it, `stop` eases back to the game camera and destroys it. A camera still running when your resource stops is given back at once, so the player is never stuck in it.

**Side:** Client · **Waits:** no

```ts title="Signature"
new ScriptCamera(type?: string)
```

No Lua twin: Lua resources use `CreateCam`, `RenderScriptCams` and `DestroyCam`.

#### Parameters

<TypeTable
  type={{
    type: { type: 'string', description: 'The game camera name. DEFAULT_SCRIPTED_FLY_CAMERA for a hand-held view.', default: '"DEFAULT_SCRIPTED_CAMERA"' },
  }}
/>

#### CameraView

Where a camera looks, used by `start`, `move` and `glideTo`:

<TypeTable
  type={{
    pointAt: { type: 'Vec3', description: 'A point the camera keeps looking at.' },
    rotation: { type: 'Vec3', description: 'A fixed rotation in degrees, when there is no pointAt.' },
    fov: { type: 'number', description: 'Field of view in degrees.' },
  }}
/>

#### Members

<TypeTable
  type={{
    active: { type: 'boolean', description: 'Read-only property: whether the camera exists (started and not stopped).' },
    cam: { type: 'number', description: 'Read-only property: the game camera handle (0 while stopped), for natives the class does not wrap.' },
  }}
/>

#### Example

```ts
import { ScriptCamera } from "@aifivem/lib/client";

const camera = new ScriptCamera();
const CAR = { x: -44.4, y: -1097.1, z: 26.4 };

export function openShowroom(): void {
  camera.start({ x: -40.2, y: -1100.5, z: 27.6 }, { pointAt: CAR, fov: 50 }, 800);
}

export function frontView(): void {
  camera.glideTo({ x: -47.5, y: -1093.8, z: 27.2 }, { pointAt: CAR, fov: 45 }, 1200);
}

export function closeShowroom(): void {
  camera.stop(800);
}
```

### camera.glideTo

**Side:** Client · **Waits:** no


## TickLoop

### new TickLoop

A per-frame job (`every(0, fn)` on your resource's one scheduler) that is off until you switch it on. Use it for anything that must run every frame only sometimes: drawing a marker while near, a placement preview, disabled firing while aiming at a friend.

**Side:** Client · **Waits:** no

```ts title="Signature"
new TickLoop(onFrame: () => void, name?: string)
```

No Lua twin: `aiLib.every(0, fn, { active = false, name = name })` and `job:set(active)`.

#### Parameters

<TypeTable
  type={{
    onFrame: { type: '() => void', description: 'Runs every frame while the loop is on. A thrown error is logged (at most once per 10 s) and the loop keeps running.', required: true },
    name: { type: 'string', description: 'A name shown in error logs.' },
  }}
/>

#### Members

<TypeTable
  type={{
    running: { type: 'boolean', description: 'Read-only property: whether the loop is on.' },
    'set(active)': { type: '(active: boolean) => void', description: 'Switches the loop on (true) or off (false).' },
  }}
/>

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { TickLoop, Zones } from "@aifivem/lib/client";

const SPOT = { x: 215.8, y: -810.1, z: 30.7 };
const light = new TickLoop(() => {
  DrawLightWithRange(SPOT.x, SPOT.y, SPOT.z + 2, 61, 247, 158, 8, 4);
}, "garageLight");

const zones = new Zones();
zones.add("garage", {
  shape: { type: "sphere", center: SPOT, radius: 25 },
  onEnter: () => light.set(true),
  onExit: () => light.set(false),
});
```
</Tab>
<Tab value="Lua">
```lua
local SPOT = vector3(215.8, -810.1, 30.7)
local light = aiLib.every(0, function()
    DrawLightWithRange(SPOT.x, SPOT.y, SPOT.z + 2.0, 61, 247, 158, 8.0, 4.0)
end, { active = false, name = 'garageLight' })

local zones = aiLib.Zones.new()
zones:add('garage', {
    shape = { type = 'sphere', center = SPOT, radius = 25.0 },
    onEnter = function() light:set(true) end,
    onExit = function() light:set(false) end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Every job of your resource runs from one `setTick` that exists only while a job is on. Create the loop once at the top of the file and switch it, instead of creating a new one per start.
</Callout>

## AreaFollower

### new AreaFollower

The client half of a server `AreaStream` ([Area streaming](/docs/developers/api/lib-server/area-stream)): it tells the server which grid cell the player stands in whenever it changes (checked every 2 seconds while started), so the server sends only the world objects (drops, plants, placed props) around the player. Create one at the top of the file.

**Side:** Client · **Waits:** no

```ts title="Signature"
new AreaFollower(event: string, cellSize?: number)
```

No Lua twin.

#### Parameters

<TypeTable
  type={{
    event: { type: 'string', description: 'The net event the server listens to; it gets (cx, cy), the cell coordinates.', required: true },
    cellSize: { type: 'number', description: 'Cell size in metres. Must match the server stream cellSize.', default: '64' },
  }}
/>

#### Members

<TypeTable
  type={{
    'start()': { type: '() => void', description: 'Sends the current cell now and on every change.' },
    'stop()': { type: '() => void', description: 'Stops reporting.' },
  }}
/>

#### Example

```ts title="resource/client/index.ts"
import { AreaFollower, onServerEvent } from "@aifivem/lib/client";

const follower = new AreaFollower("myplants:cell");
follower.start();

const plants = new Map<number, unknown>();

// The stream sends (reset, puts, removes): one snapshot with reset true, then only changes.
onServerEvent(
  "myplants:area",
  {
    args: ([reset, puts, removes]) =>
      typeof reset === "boolean" && Array.isArray(puts) && Array.isArray(removes)
        ? ([reset, puts, removes] as const)
        : null,
  },
  (reset, puts, removes) => {
    if (reset) plants.clear();
    for (const plant of puts as Array<{ id?: unknown } | null>)
      if (typeof plant?.id === "number") plants.set(plant.id, plant);
    for (const id of removes) if (typeof id === "number") plants.delete(id);
  },
);
```

<Callout type="warn">
The server checks a reported cell against the player's real position (`followReported` accepts only cells within one cell of the ped), so a cheater cannot ask for a far area.
</Callout>

## ServerClock

### new ServerClock

The server's clock on a client. Client and server clocks can differ, so a countdown to a server time (a robbery cooldown, an auction end) must be turned into local time first. Call `sync` with the server's `Date.now()` whenever a snapshot or start message arrives.

**Side:** Client (from `@aifivem/lib/shared`) · **Waits:** no

```ts title="Signature"
new ServerClock()
```

No Lua twin.

#### Members

<TypeTable
  type={{
    'sync(serverNow)': { type: '(serverNow: number) => void', description: 'Takes the offset from the server Date.now() just received.' },
    'now()': { type: '() => number', description: 'The server Date.now() right now.' },
    'toLocal(serverTime)': { type: '(serverTime: number) => number', description: 'A server time as a local Date.now() time, for countdowns on the local clock.' },
  }}
/>

#### Example

```ts title="resource/client/index.ts"
import { every, onServerEvent } from "@aifivem/lib/client";
import { ServerClock } from "@aifivem/lib/shared";

const clock = new ServerClock();
let endsAt = 0; // local time

onServerEvent(
  "myauction:state",
  { args: ([now, ends]) => (typeof now === "number" && typeof ends === "number" ? [now, ends] : null) },
  (now, ends) => {
    clock.sync(now);
    endsAt = clock.toLocal(ends);
  },
);

every(1000, () => {
  const left = Math.max(0, Math.round((endsAt - Date.now()) / 1000));
  SendNUIMessage({ action: "countdown", data: left });
});
```

<Callout type="info">
The server sends the end time once; the client counts down on its own clock. Never send the remaining time every second.
</Callout>
