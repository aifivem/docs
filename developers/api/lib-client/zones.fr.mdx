---
title: Zones
description: "Zones : des zones avec des callbacks d’entrée et de sortie (sphère, cylindre, polygone), vérifiées à leur propre intervalle, jamais à chaque frame."
icon: Shapes
---

Une **zone** est une zone qui exécute du code quand le joueur y entre ou en sort : entrer dans un quartier, une zone de limitation de vitesse, un marqueur qui ne se dessine qu’à proximité. Quand le joueur doit *faire* quelque chose à cet endroit (appuyer sur une touche, choisir une option de ciblage), utilisez plutôt un [point](/fr/docs/developers/api/lib-client/points) : c’est une zone avec l’invite, le ciblage, le ped et le blip déjà câblés.

En TypeScript, chaque zone est vérifiée par l’unique vérificateur d’ai-lib pour toutes les ressources (les zones sont rangées dans une grille de 64 m, si bien qu’un million de zones coûte autant que quelques-unes). Votre ressource ne vérifie ses propres zones que lorsque ai-lib ne tourne pas. En Lua, chaque ressource exécute une tâche du planificateur pour ses zones.

### new Zones

Crée un groupe de zones. Créez un groupe par fonctionnalité en haut du fichier.

**Côté :** client · **Attend :** non

```ts title="Signature"
new Zones()
```

```lua title="Lua"
local zones = aiLib.Zones.new()
```

#### Retour

Un groupe `Zones` avec les méthodes ci-dessous.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { Zones } from "@aicore-fivem/lib/client";

const zones = new Zones();
```
</Tab>
<Tab value="Lua">
```lua
local zones = aiLib.Zones.new()
```
</Tab>
</Tabs>

### zones.add

Ajoute une zone, ou remplace la zone portant le même id. Quand le joueur se trouvait dans la zone remplacée, son `onExit` s’exécute d’abord.

**Côté :** client · **Attend :** non

```ts title="Signature"
zones.add(id: string, options: ZoneOptions): void
```

```lua title="Lua"
zones:add(id, options)
```

#### Paramètres

<TypeTable
  type={{
    id: { type: 'string', description: 'Unique dans ce groupe. Le même id remplace l’ancienne zone.', required: true },
    options: { type: 'ZoneOptions', description: 'La forme et les callbacks. Champs ci-dessous.', required: true },
  }}
/>

#### ZoneOptions

<TypeTable
  type={{
    shape: { type: 'ZoneShape', description: 'La zone : une sphère, un cylindre ou un polygone. Formes ci-dessous.', required: true },
    interval: { type: 'number', description: 'La fréquence de vérification de la zone, en millisecondes (au moins 50). Une boutique a besoin d’environ 500, un déclencheur rapide d’environ 100.', default: '500' },
    onEnter: { type: '() => void', description: 'Le joueur est entré. Une erreur levée est journalisée.' },
    onExit: { type: '() => void', description: 'Le joueur est sorti, ou la zone a été retirée ou remplacée alors que le joueur s’y trouvait.' },
  }}
/>

#### ZoneShape

[`ZoneShape`](/fr/docs/developers/api/types#zoneshape) est l’un de trois objets, choisi par `type` :

<TypeTable
  type={{
    '"sphere"': { type: '{ type: "sphere"; center: Vec3; radius: number }', description: 'Une boule de radius mètres autour de center.' },
    '"cylinder"': { type: '{ type: "cylinder"; center: Vec3; radius: number; height: number }', description: 'Un cercle de radius mètres au sol, height mètres vers le haut et vers le bas depuis center (pièces, étages).' },
    '"poly"': { type: '{ type: "poly"; points: Array<{ x: number; y: number }>; minZ: number; maxZ: number }', description: 'Un polygone au sol (les points dans l’ordre le long du bord) entre deux hauteurs.' },
  }}
/>

En Lua, `center` peut être un `vector3` et les points des tables `{ x = ..., y = ... }`.

#### Retour

`void`.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, notify, Zones } from "@aicore-fivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const zones = new Zones();

zones.add("safezone", {
  shape: { type: "cylinder", center: { x: 298.6, y: -584.5, z: 43.3 }, radius: 60, height: 30 },
  onEnter: () => notify(Locale("SAFEZONE_IN"), "info"),
  onExit: () => notify(Locale("SAFEZONE_OUT"), "info"),
});

zones.add("yard", {
  shape: {
    type: "poly",
    points: [
      { x: 1700.1, y: 2560.4 },
      { x: 1780.6, y: 2560.4 },
      { x: 1780.6, y: 2620.2 },
      { x: 1700.1, y: 2620.2 },
    ],
    minZ: 40,
    maxZ: 60,
  },
  interval: 1000,
  onEnter: () => SetPedMoveRateOverride(PlayerPedId(), 0.8),
});
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()
local zones = aiLib.Zones.new()

zones:add('safezone', {
    shape = { type = 'cylinder', center = vector3(298.6, -584.5, 43.3), radius = 60.0, height = 30.0 },
    onEnter = function() aiLib.notify(t('SAFEZONE_IN'), 'info') end,
    onExit = function() aiLib.notify(t('SAFEZONE_OUT'), 'info') end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Une zone dessinée dans votre panneau d’administration avec le widget `zone` donne des coins ; transformez-les en polygone avec `polyFromCorners(corners, height)` depuis `@aicore-fivem/lib/shared`. Le serveur peut tester les mêmes formes avec `zoneContains(shape, x, y, z)`.
</Callout>

### zones.isInside

Indique si le joueur est dans une zone, d’après sa dernière vérification.

**Côté :** client · **Attend :** non

```ts title="Signature"
zones.isInside(id: string): boolean
```

```lua title="Lua"
local inside = zones:isInside(id)
```

#### Paramètres

<TypeTable
  type={{
    id: { type: 'string', description: 'L’id passé à add.', required: true },
  }}
/>

#### Retour

`boolean` : `true` tant que le joueur est à l’intérieur ; `false` à l’extérieur ou pour un id inconnu. La valeur reflète la dernière vérification, elle peut donc dater de jusqu’à `interval` ms.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
if (zones.isInside("safezone")) return notify(Locale("NO_WEAPONS_HERE"), "error");
```
</Tab>
<Tab value="Lua">
```lua
if zones:isInside('safezone') then return aiLib.notify(t('NO_WEAPONS_HERE'), 'error') end
```
</Tab>
</Tabs>

### zones.size

Le nombre de zones que contient le groupe.

**Côté :** client · **Attend :** non

```ts title="Signature"
zones.size: number // propriété en lecture seule
```

Pas d’équivalent Lua.

#### Retour

`number` : le nombre de zones de ce groupe.

#### Exemple

```ts
console.log(`${zones.size} zones loaded`);
```
