Wszystko o graczu siedzącym przy tym komputerze. Czytaj wartości z `cache` zamiast wywoływać `PlayerPedId()` w pętlach: ai-core trzyma jednego obserwatora dla wszystkich zasobów i wypycha zmiany, więc żaden skrypt ich nie odpytuje.

### cache

Najczęściej czytane wartości lokalnego gracza, utrzymywane aktualne przez jednego obserwatora ai-core. Jak `cache` w ox_lib: czytaj `cache.ped` zamiast wywoływać `PlayerPedId()` i `cache.vehicle` zamiast `GetVehiclePedIsIn` co klatkę. Odczyt klucza to zwykły odczyt z pamięci, bezpieczny w pętlach i kodzie co klatkę.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
const cache: PlayerCache // tylko do odczytu
```

```lua title="Lua"
local ped = aiLib.cache.ped
```

#### Klucze

<TypeTable
  type={{
    ped: { type: 'number', description: 'Uchwyt lokalnego peda. Zmienia się, gdy zmienia się model (nowa postać, zmiana modelu ubrania); powie ci o tym onCache("ped").' },
    playerId: { type: 'number', description: 'Indeks lokalnego gracza (PlayerId()), używany przez natywki, które przyjmują gracza.' },
    serverId: { type: 'number', description: 'Id serwerowe lokalnego gracza (source, które widzi serwer).' },
    vehicle: { type: 'number | false', description: 'Pojazd, w którym siedzi gracz, false pieszo.' },
    seat: { type: 'number | false', description: 'Miejsce w pojeździe: -1 kierowca, 0 przedni pasażer, 1 i wyżej tylne miejsca. false pieszo.' },
    weapon: { type: 'number | false', description: 'Hash broni w ręku, false bez broni.' },
  }}
/>

Typ to [`PlayerCache`](/pl/docs/developers/api/types#playercache).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { cache, every } from "@aicore-fivem/lib/client";

// Prędkość pokazywana w czasie jazdy, czytana z cache co 200 ms.
every(200, () => {
  if (cache.vehicle === false || cache.seat !== -1) return;
  const kmh = GetEntitySpeed(cache.vehicle) * 3.6;
  SendNUIMessage({ action: "speed", data: Math.round(kmh) });
});
```
</Tab>
<Tab value="Lua">
```lua
local cache = aiLib.cache

aiLib.every(200, function()
    if not cache.vehicle or cache.seat ~= -1 then return end
    local kmh = GetEntitySpeed(cache.vehicle) * 3.6
    SendNUIMessage({ action = 'speed', data = math.floor(kmh + 0.5) })
end)
```
</Tab>
</Tabs>

<Callout type="warn">
`cache.ped` spóźnia się za zmianą modelu do 100 ms. Zaraz po zmianie modelu (`SetPlayerModel`) wywołaj raz `PlayerPedId()`. Akcje `player` niżej już czytają peda na świeżo.
</Callout>

### onCache

Uruchamia handler za każdym razem, gdy zmieni się jedna zapamiętana wartość: gracz wsiadł do pojazdu albo z niego wysiadł, zmienił miejsce, wyjął albo schował broń lub dostał nowego peda. Używaj go zamiast sprawdzać wartość na timerze.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
onCache<K extends keyof PlayerCache>(key: K, handler: (value: PlayerCache[K], old: PlayerCache[K]) => void): void
```

```lua title="Lua"
aiLib.cache.onChange(key, function(value, old) end)
```

#### Parametry

<TypeTable
  type={{
    key: { type: '"ped" | "playerId" | "serverId" | "vehicle" | "seat" | "weapon"', description: 'Klucz cache do obserwowania.', required: true },
    handler: { type: '(value, old) => void', description: 'Dostaje nową wartość i poprzednią. Działa raz na zmianę, gdy cache już trzyma nową wartość.', required: true },
  }}
/>

#### Zwracana wartość

`void`. Nie da się usunąć handlera; trzymaj jeden na funkcję na górze pliku.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onCache, inventory, Points } from "@aicore-fivem/lib/client";

const points = new Points();

// Punkty, których canShow czyta cache.vehicle, są sprawdzane ponownie.
onCache("vehicle", () => points.refresh());

// Przedmiot broni w ręku, czytany tylko przy zmianie broni.
onCache("weapon", (weapon) => {
  const item = weapon === false ? null : inventory.currentWeapon();
  SendNUIMessage({ action: "weapon", data: item });
});
```
</Tab>
<Tab value="Lua">
```lua
local points = aiLib.Points.new()

aiLib.cache.onChange('vehicle', function()
    points:refresh()
end)

aiLib.cache.onChange('weapon', function(weapon)
    local item = weapon and aiLib.inventory.currentWeapon() or nil
    SendNUIMessage({ action = 'weapon', data = item })
end)
```
</Tab>
</Tabs>

### readPlayerState

Czyta pojazd, miejsce i broń peda w tej chwili, bez cache. Używa jej obserwator ai-core; potrzebujesz jej tylko dla peda, który nie jest lokalny, albo żeby ręcznie porównać z cache.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
readPlayerState(ped: number): { vehicle: number | false; seat: number | false; weapon: number | false }
```

Brak odpowiednika w Lua.

#### Parametry

<TypeTable
  type={{
    ped: { type: 'number', description: 'Dowolny uchwyt peda.', required: true },
  }}
/>

#### Zwracana wartość

Obiekt z `vehicle` (uchwyt pojazdu, `false` pieszo), `seat` (-1 kierowca i wyżej, `false` pieszo) i `weapon` (hash w ręku, `false` bez broni).

#### Przykład

```ts
import { playerPed, readPlayerState } from "@aicore-fivem/lib/client";

const ped = playerPed(12);
if (ped !== 0 && readPlayerState(ped).seat === -1) console.log("player 12 is driving");
```

### readWeapon

Broń w ręku peda w tej chwili, `false` bez broni.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
readWeapon(ped: number): number | false
```

Brak odpowiednika w Lua.

#### Parametry

<TypeTable
  type={{
    ped: { type: 'number', description: 'Dowolny uchwyt peda.', required: true },
  }}
/>

#### Zwracana wartość

`number | false`: hash broni albo `false`, gdy ped trzyma `WEAPON_UNARMED`.

#### Przykład

```ts

const id = nearestPlayer(5);
if (id !== null && readWeapon(playerPed(id)) !== false) console.log("the player next to you is armed");
```

## player

Jeden obiekt dla lokalnego peda: gdzie jest, przemieszczanie, animacje. Odczyty używają `cache.ped`; akcje czytają peda na świeżo, więc działają też zaraz po zmianie modelu.

### player.ped

Uchwyt lokalnego peda (ta sama wartość co `cache.ped`).

**Strona:** Klient · **Czeka:** nie


#### Zwracana wartość

`number`: uchwyt peda.

### player.teleport

Przenosi gracza i czeka, aż świat wokół nowego miejsca się wczyta, za czarnym wygaszeniem ekranu. Bez `z` (albo z `ground: "find"`) szuka ziemi pod x i y: używaj tego dla punktu nawigacji na mapie.

**Strona:** Klient · **Czeka:** tak (Promise w TypeScript, w Lua wstrzymuje wątek)

```ts title="Sygnatura"
player.teleport(to: { x: number; y: number; z?: number }, options?: TeleportOptions): Promise<void>
```

```lua title="Lua"
aiLib.player.teleport(to, options) -- wywołuj wewnątrz wątku
```

#### Parametry

<TypeTable
  type={{
    to: { type: '{ x: number; y: number; z?: number }', description: 'Dokąd iść. Pomiń z, żeby wylądować na ziemi pod x / y. Lua przyjmuje też vector3.', required: true },
    options: { type: 'TeleportOptions', description: 'Kierunek, obsługa ziemi, wygaszenie, pojazd. Pola poniżej.', default: '{}' },
  }}
/>

#### TeleportOptions

<TypeTable
  type={{
    heading: { type: 'number', description: 'Kierunek, w którym patrzeć po przeniesieniu, w stopniach. Bez zmian, gdy pominięty.' },
    ground: { type: 'boolean | "find"', description: 'true: z to podłoga (punkt wybrany w panelu) i stopy na niej stoją. false: z to korzeń peda, tak jak daje go player.coords(). "find": szukaj ziemi pod x / y i ignoruj z.', default: 'true' },
    fade: { type: 'boolean', description: 'Wygaś ekran do czerni przed przeniesieniem i rozjaśnij po nim.', default: 'true' },
    keepVehicle: { type: 'boolean', description: 'Zabierz ze sobą pojazd, w którym siedzi gracz.', default: 'false' },
  }}
/>

#### Zwracana wartość

`Promise<void>`, który się rozwiązuje, gdy gracz stoi w nowym miejscu i kolizja tam się wczytała (albo po 5 sekundach bez niej). Lua nic nie zwraca.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { notify, player, waypoint } from "@aicore-fivem/lib/client";

RegisterCommand(
  "tpm",
  async () => {
    const target = waypoint();
    if (!target) return notify("Set a waypoint first", "error");
    await player.teleport(target, { keepVehicle: true }); // bez z: ląduje na ziemi
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua
RegisterCommand('tpm', function()
    local target = aiLib.waypoint()
    if not target then return aiLib.notify('Set a waypoint first', 'error') end
    aiLib.player.teleport(target, { keepVehicle = true })
end, false)
```
</Tab>
</Tabs>

<Callout type="info">
Wyszukiwanie ziemi w TypeScript stawia zamrożonego peda na rosnących wysokościach, na każdej czeka na kolizję i pomija powierzchnie wewnątrz wnętrz MLO albo IPL, więc nigdy nie ląduje na dachu ani w budynku nad ulicą. Wersja Lua bierze pierwszą znalezioną ziemię i czeka na kolizję najwyżej 3 sekundy.
</Callout>

### playerPed

Ped gracza według id serwerowego. Dla lokalnego gracza zwraca `cache.ped`; dla innego gracza zwraca 0, gdy ten gracz nie jest na tyle blisko, żeby był strumieniowany do tego klienta.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
playerPed(serverId: number): number
```

```lua title="Lua"
local ped = aiLib.playerPed(serverId)
```

#### Parametry

<TypeTable
  type={{
    serverId: { type: 'number', description: 'Id serwerowe gracza (source, którego używa serwer).', required: true },
  }}
/>

#### Zwracana wartość

`number`: uchwyt peda albo `0`, gdy gracz nie jest w zasięgu tego klienta.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onServerEvent, playerPed } from "@aicore-fivem/lib/client";

// Serwer mówi wszystkim w pobliżu, że gracz został skuty.
onServerEvent(
  "myscript:cuffed",
  { args: ([id]) => (typeof id === "number" ? [id] : null) },
  (id) => {
    const ped = playerPed(id);
    if (ped !== 0) SetEnableHandcuffs(ped, true);
  },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onServerEvent('myscript:cuffed', function(id)
    local ped = aiLib.playerPed(id)
    if ped ~= 0 then SetEnableHandcuffs(ped, true) end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Nigdy nie używaj ręcznie `GetPlayerPed(-1)` ani `GetPlayerPed(GetPlayerFromServerId(id))`: nieznane id daje -1, a `GetPlayerPed(-1)` to lokalny ped, więc akcja trafia w złego gracza.
</Callout>

### nearestPlayer

Najbliższy inny gracz w danej odległości, jako id serwerowe. Przechodzi tylko po graczach strumieniowanych do tego klienta. Używaj go, żeby wybrać cel akcji dawania, przeszukania, skucia albo powalenia, potem wyślij to id do serwera, który ponownie sprawdzi odległość.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
nearestPlayer(metres: number, options?: { from?: Vec3; filter?: (serverId: number, ped: number) => boolean }): number | null
```

```lua title="Lua"
local serverId = aiLib.nearestPlayer(metres, options) -- integer albo nil
```

#### Parametry

<TypeTable
  type={{
    metres: { type: 'number', description: 'Promień wyszukiwania, w metrach.', required: true },
    options: { type: '{ from?, filter? }', description: 'Opcjonalne. Pola poniżej.', default: '{}' },

#### Zwracana wartość

`number | null`: id serwerowe najbliższego gracza, który przeszedł `filter`, albo `null` (`nil` w Lua), gdy nikogo nie ma w odległości `metres`. Lokalny gracz nigdy nie jest zwracany.
