Эти объекты никогда не общаются с конкретным скриптом. Они спрашивают **ai-core**, а ai-core передаёт вызов тому скрипту, который сервер использует для этой задачи: ai-death или другому скрипту смерти, ai-appearance или tgiann-clothing, любому поддерживаемому скрипту эмоций или радиального меню. Ваш скрипт продолжает работать, когда владелец меняет один из них. Как работают слои, описано на странице [Слои и мост](/ru/docs/developers/layers).

Когда скрипт такого вида не запущен, вызовы отвечают `false`, `null` или собственным значением игры, как сказано в каждой записи.

## medical

### medical.isDead

Лежит ли локальный игрок без сознания (мёртв или в last stand) в том скрипте смерти, который запущен. Скрипты смерти держат упавшего педа живым, чтобы анимировать его, поэтому одного `IsEntityDead` недостаточно. После первого вызова это чтение из памяти.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
medical.isDead(): boolean
```

Lua-аналога нет: вызывайте `exports['ai-core']:IsDead()` и слушайте локальное событие `ai-core:client:dead` (`dead`).

#### Возвращает

`boolean`: `true`, если медицинский слой ai-core говорит, что игрок без сознания, или пед мёртв с точки зрения игры.

#### Пример

```ts
import { medical, notify } from "@aicore-fivem/lib/client";

RegisterCommand(
  "phone",
  () => {
    if (medical.isDead()) return notify("You cannot use the phone now", "error");
    SetNuiFocus(true, true);
  },
  false,
);
```

### medical.onChange

Запускает обработчик, когда локальный игрок падает без сознания или встаёт.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
medical.onChange(fn: (dead: boolean) => void): void
```

Lua-аналога нет: `AddEventHandler('ai-core:client:dead', function(dead) end)`.

#### Параметры

<TypeTable
  type={{
    fn: { type: '(dead: boolean) => void', description: 'Получает true, когда игрок упал, false, когда встал.', required: true },
  }}
/>

#### Возвращает

`void`.

#### Пример

```ts
import { medical, Points } from "@aicore-fivem/lib/client";

const points = new Points();
medical.onChange(() => points.refresh()); // точки, canShow которых читает medical.isDead()
```

## appearance

Внешность педов через слой внешности ai-core, какой бы скрипт одежды ни был запущен.

### appearance.apply

Надевает сохранённую внешность на педа модели этой внешности. Получите внешность на сервере через `appearance.get(charId)`, создайте педа с `look.model`, затем примените. На собственном педе игрока это меняет его одежду.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
appearance.apply(ped: number, look: CharacterAppearance): boolean
```

```lua title="Lua"
local ok = aiLib.appearance.apply(ped, look)
```

#### Параметры

<TypeTable
  type={{
    ped: { type: 'number', description: 'Пед, которого нужно одеть. Его модель должна быть look.model.', required: true },
    look: { type: 'CharacterAppearance', description: '{ model: number; data: unknown }: хэш модели и собственные данные скрипта одежды. Считайте data непрозрачными.', required: true },
  }}
/>

Тип: [`CharacterAppearance`](/ru/docs/developers/api/types#characterappearance).

#### Возвращает

`boolean`: `false`, если педа нет, модель отличается или не запущен скрипт одежды.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, LocalPed, triggerServerCallback } from "@aicore-fivem/lib/client";
import type { CharacterAppearance } from "@aicore-fivem/shared";

// Спящая копия персонажа, одетая как он.
export async function showSleeper(charId: number): Promise<void> {
  const look = (await triggerServerCallback("mysleep:look", [charId]).catch(() => null)) as CharacterAppearance | null;
  if (!look) return;
  new LocalPed({
    model: look.model,
    coords: { x: 151.2, y: -1004.6, z: 29.4, heading: 90 },
    onSpawn: (ped) => appearance.apply(ped, look),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local function showSleeper(charId)
    CreateThread(function()
        local look = aiLib.triggerServerCallback('mysleep:look', { charId })
        if type(look) ~= 'table' then return end
        aiLib.LocalPed.new({
            model = look.model,
            coords = vector4(151.2, -1004.6, 29.4, 90.0),
            onSpawn = function(ped) aiLib.appearance.apply(ped, look) end,
        })
    end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Проверяйте то, что присылает сервер, прежде чем приводить тип. Пед, созданный с моделью, отличной от `look.model`, не может принять внешность: `apply` отвечает `false`.
</Callout>

## fuel

### fuel.get

Уровень топлива транспорта. Сервер держит state bag `fuel` для каждого транспорта, какой бы скрипт топлива ни был запущен, поэтому это чтение из памяти; без этого bag это уровень бака в игре.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
fuel.get(vehicle: number): number
```

Lua-аналога нет: читайте `Entity(vehicle).state.fuel`. Задать топливо можно только на сервере (`fuel.set` на странице [Транспорт](/ru/docs/developers/api/lib-server/vehicles)).

#### Параметры

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Транспорт, который знает этот клиент.', required: true },
  }}
/>

#### Возвращает

`number`: 0-100.

#### Пример

```ts
import { cache, every, fuel } from "@aicore-fivem/lib/client";

every(1000, () => {
  if (cache.vehicle !== false) SendNUIMessage({ action: "fuel", data: Math.round(fuel.get(cache.vehicle)) });
});
```

```ts
import { RADIAL_VEHICLE } from "@aicore-fivem/shared";

const Locale = createLocale<typeof import("../../locales/en.json")>();

radial.add({
  id: "myscript:engine",
  label: Locale("ENGINE"),
  icon: "power-off",
  parent: RADIAL_VEHICLE,
  keepOpen: true,
  canShow: () => cache.seat === -1,
  onPressed: () => {
    if (cache.vehicle === false) return;
    SetVehicleEngineOn(cache.vehicle, !GetIsVehicleEngineRunning(cache.vehicle), false, true);
  },
});

radial.add({
  id: "myscript:police",
  label: Locale("POLICE"),
  icon: "shield-halved",
  canShow: () => hasJob(["police"]),
  items: [
    { id: "myscript:cuff", label: Locale("CUFF"), icon: "handcuffs", onPressed: () => emitNet("mypolice:cuff") },
  ],
});
```

## world

Синхронизация погоды и времени того скрипта погоды, который запущен, приостановленная, пока действует причина.

### world.pauseSync

Приостанавливает синхронизацию погоды и времени по причине: внутри интерьера, во время сцены или пока ваш скрипт задаёт собственную погоду.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
world.pauseSync(reason: string): void
```

```lua title="Lua"
aiLib.world.pauseSync(reason)
```

#### Параметры

<TypeTable
  type={{
    reason: { type: 'string', description: 'Почему (apartment, cutscene). Синхронизация остаётся на паузе, пока действует любая причина любого ресурса.', required: true },
  }}
/>

#### Возвращает

`void`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { world } from "@aicore-fivem/lib/client";

export function enterApartment(): void {
  world.pauseSync("apartment");
  NetworkOverrideClockTime(12, 0, 0);

export function leaveApartment(): void {
  world.resumeSync("apartment");
}
```
</Tab>

```lua
    SetWeatherTypeNowPersist('EXTRASUNNY')

    aiLib.world.resumeSync('apartment')
end
```
</Tab>
</Tabs>

### inventory.hasItem

Есть ли у игрока не меньше `count` единиц предмета. Используйте в `canShow`, чтобы игрок видел только то, что может сделать; сервер проверит снова.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
inventory.hasItem(item: string, count?: number): boolean
```

```lua title="Lua"
local has = aiLib.inventory.hasItem(item, count)
```

#### Параметры

<TypeTable
  type={{
    item: { type: 'string', description: 'Название предмета (lockpick).', required: true },
    count: { type: 'number', description: 'Сколько нужно.', default: '1' },
  }}
/>

#### Возвращает

`boolean`: `true`, если у игрока достаточно.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

```ts
const points = new Points();
points.addVehicle("lockpick", {
  label: "Lockpick",
  icon: "unlock",
  canShow: (vehicle) => GetVehicleDoorLockStatus(vehicle) >= 2 && inventory.hasItem("lockpick"),
  onPressed: (vehicle) => emitNet("mykeys:lockpick", NetworkGetNetworkIdFromEntity(vehicle)),
});
```
</Tab>
<Tab value="Lua">

### inventory.currentWeapon

Предмет оружия в руке игрока: его название, подпись и картинка.

**Сторона:** Клиент · **Ждёт:** нет

```ts title="Сигнатура"
inventory.currentWeapon(): HeldWeapon | null
```

```lua title="Lua"
local weapon = aiLib.inventory.currentWeapon() -- таблица или nil
```

#### Возвращает

[`HeldWeapon`](/ru/docs/developers/api/types#heldweapon) `{ name: string; label: string; image?: string }` (`name` вида `WEAPON_PISTOL`, `image` это URL `nui://`, если он есть у инвентаря) или `null` (`nil`), если рука пуста.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory, onCache } from "@aicore-fivem/lib/client";

// Читайте при смене оружия, никогда не каждый кадр.
onCache("weapon", () => SendNUIMessage({ action: "weapon", data: inventory.currentWeapon() }));
```
</Tab>
<Tab value="Lua">
```lua
aiLib.cache.onChange('weapon', function()
    SendNUIMessage({ action = 'weapon', data = aiLib.inventory.currentWeapon() })
end)
```
</Tab>
</Tabs>
