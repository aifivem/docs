## Sorgular

### raycast

Aynı karede cevaplanan bir çizgi sorgusu: `from`’dan `to`’ya çizginin ilk çarptığı şey. "Oyuncu neye bakıyor", nesneleri zemine yerleştirmek ya da görüş hattı için kullan.

**Taraf:** Client · **Bekler:** hayır (test bitene kadar kareyi bloklar)

```ts title="Signature"
raycast(from: Vec3, to: Vec3, options?: RaycastOptions): RayHit | null
```

```lua title="Lua"
local hit = aiLib.raycast(from, to, options) -- table ya da nil; from / to vector3’tür
```

#### Parametreler

<TypeTable
  type={{
    from: { type: 'Vec3', description: 'Çizginin başlangıcı. Lua: bir vector3.', required: true },
    to: { type: 'Vec3', description: 'Çizginin sonu. Lua: bir vector3.', required: true },
    options: { type: 'RaycastOptions', description: 'Alanlar aşağıda.', default: '{}' },
  }}
/>

#### RaycastOptions

<TypeTable
  type={{
    flags: { type: 'number', description: 'Sorgunun neyi test ettiği, toplanarak: 1 harita, 2 araçlar, 4 ped’ler, 8 ragdoll’lar, 16 nesneler.', default: '1 | 2 | 16 (19)' },
    ignore: { type: 'number', description: 'Sorgunun içinden geçtiği bir entity.', default: 'yerel ped' },
    options: { type: 'number', description: 'Sorgu seçenek bitleri: 1 camı yok say, 2 saydamı yok say, 4 çarpışmasızı yok say.', default: '7' },
  }}
/>

#### Dönüş değeri

`RayHit | null`: ilk çarpma için `{ coords, normal, entity }` ya da çizgi hiçbir şeye çarpmazsa `null` (`nil`).

<TypeTable
  type={{
    coords: { type: 'Vec3', description: 'Çarpma noktası. Lua: bir vector3.' },
    normal: { type: 'Vec3', description: 'Çarpma noktasındaki yüzey normali (yüzeyin hangi yöne baktığı). Lua: bir vector3.' },
    entity: { type: 'number', description: 'Çarpılan entity, harita için 0.' },
  }}
/>

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { raycast } from "@aifivem/lib/client";

/** Kameranın 10 m içinde baktığı şey. */
export function lookedAt(): number {
  const [cx = 0, cy = 0, cz = 0] = GetGameplayCamCoord();
  const [rx = 0, , rz = 0] = GetGameplayCamRot(2);
  const pitch = (rx * Math.PI) / 180;
  const yaw = (rz * Math.PI) / 180;
  const dir = { x: -Math.sin(yaw) * Math.cos(pitch), y: Math.cos(yaw) * Math.cos(pitch), z: Math.sin(pitch) };
  const hit = raycast(
    { x: cx, y: cy, z: cz },
    { x: cx + dir.x * 10, y: cy + dir.y * 10, z: cz + dir.z * 10 },
    { flags: 2 | 4 | 16 },
  );
  return hit?.entity ?? 0;
}
```
</Tab>
<Tab value="Lua">
```lua
local function lookedAt()
    local cam = GetGameplayCamCoord()
    local rot = GetGameplayCamRot(2)
    local pitch, yaw = math.rad(rot.x), math.rad(rot.z)
    local dir = vector3(-math.sin(yaw) * math.cos(pitch), math.cos(yaw) * math.cos(pitch), math.sin(pitch))
    local hit = aiLib.raycast(cam, cam + dir * 10.0, { flags = 2 | 4 | 16 })
    return hit and hit.entity or 0
end
```
</Tab>
</Tabs>

<Callout type="warn">
Senkron bir sorgudur: kare başına bir ya da iki tane ile sınırlı tut.
</Callout>

### groundZ

Bir noktanın altındaki zemin yüksekliği; `z`’den aşağı doğru sorgulanır.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
groundZ(x: number, y: number, z?: number): number | null
```

```lua title="Lua"
local ground = aiLib.groundZ(x, y, z) -- number ya da nil
```

#### Parametreler

<TypeTable
  type={{
    x: { type: 'number', description: 'Dünya x’i.', required: true },
    y: { type: 'number', description: 'Dünya y’si.', required: true },
    z: { type: 'number', description: 'Sorgunun aşağı doğru başladığı yükseklik.', default: '1000' },
  }}
/>

#### Dönüş değeri

`number | null`: zemin yüksekliği ya da oradaki çarpışma yüklenmemişken (alan oyuncudan uzaktadır) `null` (`nil`).

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { groundZ, player } from "@aifivem/lib/client";

const { x, y, z } = player.coords();
const ground = groundZ(x, y, z + 2);
if (ground !== null) console.log(`ground is ${(z - ground).toFixed(2)} m below`);
```
</Tab>
<Tab value="Lua">
```lua
local c = aiLib.player.coords()
local ground = aiLib.groundZ(c.x, c.y, c.z + 2.0)
if ground then print(('ground is %.2f m below'):format(c.z - ground)) end
```
</Tab>
</Tabs>

<Callout type="info">
Oyuncuyu bilinmeyen bir zemine taşımak için `z` olmadan `player.teleport` kullan: her yükseklikte çarpışmayı bekler.
</Callout>

### pedHeadshot

Bir ped’in vesikalık fotoğrafını çeker ve oyun onu çizene kadar bekler. Doku adını bir NUI sayfasında `https://nui-img/<txd>/<txd>` olarak kullan.

**Taraf:** Client · **Bekler:** evet (TypeScript’te Promise, Lua’da thread’i yield eder)

```ts title="Signature"
pedHeadshot(ped: number, transparent?: boolean, timeoutMs?: number): Promise<{ handle: number; txd: string } | null>
```

```lua title="Lua"
local handle, txd = aiLib.pedHeadshot(ped, transparent, timeout) -- bir thread içinde çağır
```

#### Parametreler

<TypeTable
  type={{
    ped: { type: 'number', description: 'Fotoğrafı çekilecek ped.', required: true },
    transparent: { type: 'boolean', description: 'Varsayılan arka plan yerine saydam bir arka plan.', default: 'false' },
    timeoutMs: { type: 'number', description: 'Çizim için ne kadar bekleneceği, milisaniye cinsinden. Lua’da adı timeout.', default: '5000' },
  }}
/>

#### Dönüş değeri

`Promise<{ handle: number; txd: string } | null>`: vesikalık handle’ı ve doku adı; ped yoksa ya da çizim zaman aşımından uzun sürdüyse `null`. Lua `handle, txd` ya da `nil` döndürür.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { cache, pedHeadshot } from "@aifivem/lib/client";

export async function sendMugshot(): Promise<void> {
  const shot = await pedHeadshot(cache.ped, true);
  if (!shot) return;
  SendNUIMessage({ action: "photo", data: `https://nui-img/${shot.txd}/${shot.txd}` });
  setTimeout(() => UnregisterPedheadshot(shot.handle), 10_000);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local handle, txd = aiLib.pedHeadshot(aiLib.cache.ped, true)
    if not handle then return end
    SendNUIMessage({ action = 'photo', data = ('https://nui-img/%s/%s'):format(txd, txd) })
    Wait(10000)
    UnregisterPedheadshot(handle)
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Fotoğraf artık gösterilmediğinde `UnregisterPedheadshot(handle)` çağır.
</Callout>

### onShot

Yerel ped’in ateş ettiği karede bir handler çalıştırır (stres, ateş ihbarları, kovanlar). Resource’un için tek bir kare başı kontrol; yalnızca elde silah varken açık.

**Taraf:** Client · **Bekler:** hayır

```ts title="Signature"
onShot(handler: (weapon: number) => void): () => void
```

```lua title="Lua"
aiLib.onShot(function(weapon) end) -- hiçbir şey döndürmez
```

#### Parametreler

<TypeTable
  type={{
    handler: { type: '(weapon: number) => void', description: 'Ateş eden silahın hash’ini alır. Kare içinde çalışır: hafif tut.', required: true },
  }}
/>

#### Dönüş değeri

TypeScript: `() => void`, handler’ı kaldıran bir fonksiyon. Lua hiçbir şey döndürmez (handler kalır).

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onShot } from "@aifivem/lib/client";

let lastAlert = 0;
onShot(() => {
  if (GetGameTimer() - lastAlert < 30_000) return; // 30 sn’de bir ihbar
  lastAlert = GetGameTimer();
  emitNet("mypolice:shots");
});
```
</Tab>
<Tab value="Lua">
```lua
local lastAlert = 0
aiLib.onShot(function()
    if GetGameTimer() - lastAlert < 30000 then return end
    lastAlert = GetGameTimer()
    TriggerServerEvent('mypolice:shots')
end)
```
</Tab>
</Tabs>

## Oyun varlıklarını yüklemek

Modeller, animasyonlar, efektler ve dokular kullanılmadan önce yüklenmelidir. Her yükleyici varlığı ister ve hazır olana kadar bekler. İşin bitince, her girdinin söylediği gibi onu serbest bırak.

### requestModel

Bir modeli (ped, araç, nesne) yükler ve hash’ini verir.

**Taraf:** Client · **Bekler:** evet (TypeScript’te Promise, Lua’da thread’i yield eder)

```ts title="Signature"
requestModel(model: string | number, timeoutMs?: number): Promise<number>
```

```lua title="Lua"
local hash = aiLib.requestModel(model, timeout) -- integer ya da nil, bir thread içinde çağır
```

#### Parametreler

<TypeTable
  type={{
    model: { type: 'string | number', description: 'Model adı ya da hash’i.', required: true },
    timeoutMs: { type: 'number', description: 'Ne kadar bekleneceği, milisaniye cinsinden. Lua’da adı timeout.', default: '10000' },
  }}
/>

#### Dönüş değeri

`Promise<number>`: yüklendiğinde model hash’i. Model oyun dosyalarında yoksa ya da zamanında yüklenmezse **reddedilir**. Lua hash’i ya da iki durumda da `nil` döndürür.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { requestModel } from "@aifivem/lib/client";

export async function placeCone(x: number, y: number, z: number): Promise<number> {
  const hash = await requestModel("prop_roadcone02a");
  const cone = CreateObject(hash, x, y, z, false, false, false);
  SetModelAsNoLongerNeeded(hash);
  PlaceObjectOnGroundProperly(cone);
  return cone;
}
```
</Tab>
<Tab value="Lua">
```lua
local function placeCone(x, y, z)
    local hash = aiLib.requestModel('prop_roadcone02a')
    if not hash then return 0 end
    local cone = CreateObject(hash, x, y, z, false, false, false)
    SetModelAsNoLongerNeeded(hash)
    PlaceObjectOnGroundProperly(cone)
    return cone
end
```
</Tab>
</Tabs>

<Callout type="info">
Entity oluşturulduktan sonra `SetModelAsNoLongerNeeded(hash)` çağır.
</Callout>
