Un **point** est tout endroit qu’un joueur utilise : un comptoir de boutique, une porte, un PNJ, un lieu de restitution, chaque distributeur, le coffre de chaque voiture. Vous le décrivez une fois (où, quel texte, ce qui se passe) et la lib le dessine de la manière choisie par le propriétaire du serveur.

## Invite ou ciblage

Le propriétaire choisit le style d’interaction dans le panneau d’administration d’ai-core (**Interaction**). Le même `onPressed` s’exécute dans les deux cas, votre script n’a donc jamais à se soucier du style actif.

| Style | Ce que voit le joueur |
| --- | --- |
| **Prompt** (invite) | Une boîte « appuyez sur E » sur le côté droit de l’écran tant que le joueur se trouve dans le rayon du point. La touche est un unique raccourci clavier réassignable dans ai-lib (`E` par défaut), si bien que rien ne scrute les touches à chaque frame. |
| **Target** (ciblage) | Une option dans l’œil de ciblage sur l’emplacement, le PNJ, l’objet ou le véhicule. Il faut qu’un des scripts de ciblage pour lesquels la lib a un adaptateur tourne. Quand plusieurs tournent, le premier dans cet ordre l’emporte : `ai-target`, `tgiann-radialmenu-target`, `tgiann-target`, `sleepless_interact`, `ox_target`, `qb-target`, `interact`. |

Quand le propriétaire a choisi le ciblage mais qu’aucun script de ciblage ne tourne, chaque point est une invite. Un point peut passer outre le choix du propriétaire : `promptOnly` garde une invite (actions faites depuis un véhicule : pompes à essence, stations de lavage), `preferTarget` utilise une option de ciblage dès qu’un script de ciblage tourne (sièges). Quand un script de ciblage démarre ou s’arrête, ou que le propriétaire change de style, chaque point bascule de lui-même.

<Callout type="info">
Une seule action de point de votre ressource s’exécute à la fois. Quand `onPressed` renvoie une promesse, les autres points de votre ressource ignorent les appuis jusqu’à ce qu’elle soit réglée, vous n’avez donc jamais besoin de votre propre drapeau `busy`. Le joueur doit aussi passer `canShow` au moment de l’appui.
</Callout>

### points.refresh

Relit `canShow` et les libellés sous forme de fonction. Appelez-la quand une chose qu’ils lisent a changé : le métier, le service, un véhicule, un état envoyé par le serveur. Les invites se mettent à jour immédiatement ; les options de ciblage lisent `canShow` quand l’œil s’ouvre, et un libellé modifié est réappliqué.

**Côté :** client · **Attend :** non

```ts title="Signature"

```


<TypeTable

## Points à partir des enregistrements du panneau

La plupart des points viennent d’un fichier d’enregistrements du panneau d’administration de votre script (boutiques, garages, comptoirs de location). Reflétez le fichier sur le client avec [`AdminWorld`](#new-adminworld), puis construisez les points de chaque enregistrement avec [`RecordObjects`](#new-recordobjects) : un enregistrement modifié ne reconstruit que ses propres points, un enregistrement supprimé les retire.

### new RecordObjects

Garde les objets du monde d’un fichier d’enregistrements (points, blips, peds, zones) synchronisés avec le fichier, un enregistrement à la fois. `build(key, record)` crée les objets d’un enregistrement et renvoie la manière de les retirer. Il construit chaque enregistrement dans son constructeur.

**Côté :** client et serveur (depuis `@aicore-fivem/lib/shared`) · **Attend :** non

```ts title="Signature"
new RecordObjects<T>(
  source: RecordSource,
  file: string,
  records: RecordReader<T> | ReadonlyMap<string, T>,
  build: (key: string, record: T) => (() => void) | void,
)
```

Pas d’équivalent Lua.

<TypeTable
  type={{
    records: { type: 'ReadonlyMap<string, T>', description: 'Les enregistrements analysés par clé, toujours à jour. Cherchez un enregistrement dans onPressed au lieu de le capturer.' },

#### Exemple

```ts title="resource/client/index.ts"
import { AdminWorld, callAction, createLocale, Points } from "@aicore-fivem/lib/client";
import { readVec3, RecordObjects, str } from "@aicore-fivem/lib/shared";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const world = new AdminWorld(["settings", "shops"]);
const points = new Points();

interface Shop { label: string; coords: { x: number; y: number; z: number } }
const readShop = (_key: string, raw: Record<string, unknown>): Shop | null => {
  const coords = readVec3(raw.coords);
  return coords ? { label: str(raw.label, "Shop"), coords } : null;
};

const shops = new RecordObjects(world, "shops", readShop, (id, shop) => {
  points.add(id, {
    coords: shop.coords,
    label: Locale("OPEN_SHOP", shop.label),
    onPressed: () => callAction("myshop:open", [id], { fallback: "SHOP_FAILED" }),
  });
  return () => points.remove(id);
});

// Un réglage lu par toutes les boutiques a changé : les reconstruire toutes.
world.onChange("settings", () => shops.rebuildAll());
```

<Callout type="warn">
`RecordObjects` construit dans son constructeur. Créez-le après tout ce que `build` lit, et dans `build` utilisez l’argument `record` : un champ de classe qui contient le `RecordObjects` n’est pas encore assigné pendant cette première construction.
</Callout>

### new AdminWorld

La copie client des fichiers de monde du panneau de votre script (les fichiers dont le schéma indique `sync: "all"`, voir [Panneau d’administration](/fr/docs/developers/api/lib-server/admin-panel)). Elle lit la copie que FiveM a mise en cache au démarrage, demande une seule fois au serveur les enregistrements modifiés depuis, puis suit les changements en direct. Elle n’interroge jamais en boucle.

**Côté :** client · **Attend :** non (la promesse `ready` indique quand les changements depuis le démarrage sont arrivés)

```ts title="Signature"
new AdminWorld(files: string[])
```

Pas d’équivalent Lua.

  }}
/>

#### Exemple

```ts
import { AdminWorld } from "@aicore-fivem/lib/client";
import { num, record } from "@aicore-fivem/lib/shared";

const world = new AdminWorld(["settings"]);
const settings = world.view("settings", (raw) => ({
  radius: num(record(raw).radius, 2),
}));

world.onChange("settings", () => console.log("new radius", settings.value.radius));
```
