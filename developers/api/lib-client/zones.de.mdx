title: Zonen
description: "Zones - Bereiche mit Betreten- und Verlassen-Callbacks (Kugel, Zylinder, Polygon), in ihrem eigenen Intervall geprüft, nie in jedem Frame."
icon: Shapes
---

Eine **Zone** ist ein Bereich, der Code ausführt, wenn der Spieler ihn betritt oder verlässt: ein Viertel betreten, ein Bereich mit Tempolimit, ein Marker, der nur in der Nähe gezeichnet wird. Wenn der Spieler an dem Ort etwas *tun* soll (eine Taste drücken, eine Target-Option wählen), nutze stattdessen einen [Punkt](/de/docs/developers/api/lib-client/points): Er ist eine Zone, bei der Prompt, Target, Ped und Blip schon verdrahtet sind.

In TypeScript wird jede Zone von dem einen Prüfer von ai-lib für alle Ressourcen geprüft (Zonen liegen in einem 64-m-Raster, daher kostet eine Million Zonen so viel wie ein paar). Deine Ressource prüft ihre eigenen Zonen nur, solange ai-lib nicht läuft. In Lua führt jede Ressource einen Scheduler-Job für ihre Zonen aus.

### new Zones

Erstellt eine Gruppe von Zonen. Erstelle eine Gruppe pro Feature am Anfang der Datei.

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
new Zones()
```

```lua title="Lua"
local zones = aiLib.Zones.new()
```

#### Rückgabewert

Eine `Zones`-Gruppe mit den Methoden unten.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { Zones } from "@aifivem/lib/client";

const zones = new Zones();
```
</Tab>
<Tab value="Lua">
```lua
local zones = aiLib.Zones.new()
```
</Tab>
</Tabs>

### zones.add

Fügt eine Zone hinzu oder ersetzt die Zone mit derselben ID. Wenn der Spieler in der ersetzten Zone war, läuft zuerst ihr `onExit`.

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
zones.add(id: string, options: ZoneOptions): void
```

```lua title="Lua"
zones:add(id, options)
```

#### Parameter

<TypeTable
  type={{
    id: { type: 'string', description: 'Eindeutig innerhalb dieser Gruppe. Dieselbe ID ersetzt die alte Zone.', required: true },
    options: { type: 'ZoneOptions', description: 'Die Form und die Callbacks. Felder unten.', required: true },
  }}
/>

#### ZoneOptions

<TypeTable
  type={{
    shape: { type: 'ZoneShape', description: 'Der Bereich: eine Kugel, ein Zylinder oder ein Polygon. Formen unten.', required: true },
    interval: { type: 'number', description: 'Wie oft die Zone geprüft wird, in Millisekunden (mindestens 50). Ein Shop braucht etwa 500, ein schneller Auslöser etwa 100.', default: '500' },
    onEnter: { type: '() => void', description: 'Der Spieler ist hineingekommen. Ein geworfener Fehler wird geloggt.' },
    onExit: { type: '() => void', description: 'Der Spieler ist gegangen, oder die Zone wurde entfernt oder ersetzt, während der Spieler drin war.' },
  }}
/>

#### ZoneShape

[`ZoneShape`](/de/docs/developers/api/types#zoneshape) ist eines von drei Objekten, gewählt nach `type`:

<TypeTable
  type={{
    '"sphere"': { type: '{ type: "sphere"; center: Vec3; radius: number }', description: 'Eine Kugel mit radius Metern um center.' },
    '"cylinder"': { type: '{ type: "cylinder"; center: Vec3; radius: number; height: number }', description: 'Ein Kreis mit radius Metern auf dem Boden, height Meter nach oben und unten von center (Räume, Stockwerke).' },
    '"poly"': { type: '{ type: "poly"; points: Array<{ x: number; y: number }>; minZ: number; maxZ: number }', description: 'Ein Bodenpolygon (die Punkte der Reihe nach um den Rand) zwischen zwei Höhen.' },
  }}
/>

In Lua darf `center` ein `vector3` sein und die Punkte Tabellen `{ x = ..., y = ... }`.

#### Rückgabewert

`void`.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { createLocale, notify, Zones } from "@aifivem/lib/client";

const Locale = createLocale<typeof import("../../locales/en.json")>();
const zones = new Zones();

zones.add("safezone", {
  shape: { type: "cylinder", center: { x: 298.6, y: -584.5, z: 43.3 }, radius: 60, height: 30 },
  onEnter: () => notify(Locale("SAFEZONE_IN"), "info"),
  onExit: () => notify(Locale("SAFEZONE_OUT"), "info"),
});

zones.add("yard", {
  shape: {
    type: "poly",
    points: [
      { x: 1700.1, y: 2560.4 },
      { x: 1780.6, y: 2560.4 },
      { x: 1780.6, y: 2620.2 },
      { x: 1700.1, y: 2620.2 },
    ],
    minZ: 40,
    maxZ: 60,
  },
  interval: 1000,
  onEnter: () => SetPedMoveRateOverride(PlayerPedId(), 0.8),
});
```
</Tab>
<Tab value="Lua">
```lua
local t = aiLib.locale()
local zones = aiLib.Zones.new()

zones:add('safezone', {
    shape = { type = 'cylinder', center = vector3(298.6, -584.5, 43.3), radius = 60.0, height = 30.0 },
    onEnter = function() aiLib.notify(t('SAFEZONE_IN'), 'info') end,
    onExit = function() aiLib.notify(t('SAFEZONE_OUT'), 'info') end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Eine Zone, die in deinem Admin-Panel mit dem `zone`-Widget gezeichnet wird, liefert Ecken; mache daraus mit `polyFromCorners(corners, height)` aus `@aifivem/lib/shared` ein Polygon. Der Server kann dieselben Formen mit `zoneContains(shape, x, y, z)` testen.
</Callout>

### zones.isInside

Ob der Spieler in einer Zone ist, Stand ihrer letzten Prüfung.

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
zones.isInside(id: string): boolean
```

```lua title="Lua"
local inside = zones:isInside(id)
```

#### Parameter

<TypeTable
  type={{
    id: { type: 'string', description: 'Die an add übergebene ID.', required: true },
  }}
/>

#### Rückgabewert

`boolean`: `true`, solange drin; `false` draußen oder bei einer unbekannten ID. Es spiegelt die letzte Prüfung wider, kann also bis zu `interval` ms alt sein.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
if (zones.isInside("safezone")) return notify(Locale("NO_WEAPONS_HERE"), "error");
```
</Tab>
<Tab value="Lua">
```lua
if zones:isInside('safezone') then return aiLib.notify(t('NO_WEAPONS_HERE'), 'error') end
```
</Tab>
</Tabs>

### zones.size

Wie viele Zonen die Gruppe enthält.

**Seite:** Client · **Wartet:** nein

```ts title="Signatur"
zones.size: number // schreibgeschützte Eigenschaft
```

Kein Lua-Zwilling.

#### Rückgabewert

`number`: die Anzahl der Zonen in dieser Gruppe.

#### Beispiel

```ts
console.log(`${zones.size} zones loaded`);
```
