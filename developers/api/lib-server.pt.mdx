A entrada de servidor também reexporta os helpers de `/fivem`: veja [Lib: shared e fivem](/pt/docs/developers/api/lib-shared). A última coluna dá o gêmeo em Lua no `aiLib` ([Lib para Lua](/pt/docs/developers/api/lua)).

## Entrada do cliente

Todo pedido do cliente passa pelo portão: verificação de jogador real, limite de taxa, guards, um parser de argumentos e, opcionalmente, uma chamada por vez.

| Helper | O quê | Lua |
| --- | --- | --- |
| `onClientCallback(name, handler, options?)` / `onClientCallback(name, { args, guards?, rate?, lock? }, handler)` | Responde a `triggerServerCallback`; `args` transforma valores crus em valores verificados (null recusa). | `onClientCallback` (opções `rate`, `lock`, `ace`) |
| `onClientEvent(name, handler, options?)` / `onClientEvent(name, { args, ... }, handler)` | Um evento de rede de um cliente, pelo mesmo portão. | `onClientEvent` |
| `triggerClientCallback(name, source, args = [], timeoutMs?): Promise<unknown>` | Pergunta a um cliente (`onServerCallback` lá). | `triggerClientCallback` |
| `isAdmin(ace?)`, `hasCharacter()`, `near(point \| (source) => point, metres)` | Guards para `guards: [...]`. | `isAdmin(source, ace?)` |
| `eventSource(): number` | O jogador que enviou o evento (leia antes do primeiro `await`). | |
| `isOnline(source): boolean` | Se o jogador está conectado. | |
| `progressFor(source, { label, duration, anim?, scenario?, face?, allowVehicle?, canCancel?, freeze?, disable?, minRatio? }): Promise<boolean>` | Uma ação cronometrada que o servidor confere: a barra do ai-lib no cliente do jogador, true só quando terminou lá e passou tempo suficiente aqui. | `progressFor` (aguarda) |
| `minigameFor(source, { game, difficulty?, rounds?, keys?, pins?, picks?, minMs? }): Promise<"won" \| "lost" \| "broken">` | Um skill check ou lockpick de que um fluxo do servidor precisa; uma vitória antes de `minMs` conta como derrota. | `minigameFor` (aguarda) |
| `new PendingActions({ minRatio? })`: `start(source, data, ms)`, `take(source, token)`, `peek`, `cancel` | Diálogos que o servidor aguarda: um token, liberado quando o jogador sai. | |

```ts title="TypeScript"
onClientCallback(
  "repair",
  { args: oneArg(readId), guards: [hasCharacter()], lock: true },
  async (source, netId) => {
    if (!inventory.hasItem(source, "repairkit")) return fail("NO_KIT");
    if (!(await progressFor(source, { label: t("REPAIRING"), duration: 8000 })))
      return fail("CANCELLED");
    inventory.removeItem(source, "repairkit");
    return { ok: true };
  },
);
```

```lua title="Lua"
aiLib.onClientCallback('repair', function(source, netId)
  if not aiLib.inventory.hasItem(source, 'repairkit') then return aiLib.fail('NO_KIT') end
  if not aiLib.progressFor(source, { label = 'Repairing', duration = 8000 }) then
    return aiLib.fail('CANCELLED')
  end
  aiLib.inventory.removeItem(source, 'repairkit', 1)
  return { ok = true }
end, { lock = true })
```

## Comandos, painel, dados

| Helper | O quê | Lua |
| --- | --- | --- |
| `addCommand(name \| [name, ...aliases], { help, params, restricted }, (source, args, raw) => ...)` | Um comando: parâmetros validados, conferido por ACE, listado no painel. | `addCommand` |
| `new AdminPanel(schema)`: `get`, `onChange`, `view`, `records`, `onAction`, `rule` | O armazenamento do painel de um script: schema, validação, salvamento, deltas. | |
| `new DataFile(resource, name, log)` | Conteúdo do painel em `data/*.json` com escritas atômicas. | |
| `createDatabaseTables(resource, file): Promise<void>` | Instala `sql/main.sql`. | |
| `new WriteQueue(onError)`: `push(label, task)`, `idle()` | Escritas no banco de dados uma após a outra. | |
| `new AreaStream({ event, view, cellSize?, range?, chunk?, alsoTo?, extra? })` | Objetos do mundo transmitidos aos jogadores em volta: um snapshot, depois só as mudanças. | |
| `EntityState`, `PlayerState`, `GlobalKey`, `GlobalGroup` (com `set`) | State bags; as classes do servidor escrevem. | |

```ts title="TypeScript"
addCommand(
  "heal",
  {
    help: t("CMD_HEAL"),
    params: [{ name: "id", type: "playerId", optional: true }],
    restricted: true,
  },
  (source, args) => medical.heal(args.id ?? source),
);
```
