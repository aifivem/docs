## phone

Телефон игрока через ai-core: отвечает первый запущенный скрипт телефона (tgiann-phone, lb-phone...). Без скрипта телефона каждый вызов отвечает `null` или `false`. Lua-аналоги в `aiLib.phone` имеют те же имена и тот же порядок аргументов.

### phone.number

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
phone.number(source: number): string | null
```

```lua title="Lua"
local number = aiLib.phone.number(source)
```

**Возвращает** номер телефона игрока или `null` (в Lua `nil`), если номера нет или не запущен скрипт телефона.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const number = phone.number(source);
if (!number) return fail("NO_PHONE_NUMBER");
```
</Tab>
<Tab value="Lua">
```lua
local number = aiLib.phone.number(source)
if not number then return aiLib.fail('NO_PHONE_NUMBER') end
```
</Tab>
</Tabs>

### phone.sourceOf

Игрок онлайн, которому принадлежит номер телефона.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
phone.sourceOf(number: string): number | null
```

```lua title="Lua"
local source = aiLib.phone.sourceOf(number)
```

**Возвращает** серверный id или `null` (в Lua `nil`), если ни у кого онлайн нет этого номера.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const owner = phone.sourceOf("555-0101");
if (owner !== null) notify(owner, "Your phone is ringing");
```
</Tab>
<Tab value="Lua">
```lua
local owner = aiLib.phone.sourceOf('555-0101')
if owner then aiLib.notify(owner, 'Your phone is ringing') end
```
</Tab>
</Tabs>

### phone.hasPhone

Есть ли у игрока с собой телефон.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
phone.hasPhone(source: number): boolean
```

```lua title="Lua"

```

**Возвращает** `true`, если есть; `false`, если нет или нет скрипта телефона.

<Tabs items={['TypeScript', 'Lua']}>

</Tab>
<Tab value="Lua">
```lua

```
</Tab>
</Tabs>

## appearance

Сохранённая внешность персонажей через слой внешности ai-core, какой бы скрипт одежды ни был запущен (ai-appearance, tgiann-clothing).

### appearance.get

Сохранённая внешность персонажа, загружен он или нет. Используйте, чтобы одеть педа, который заменяет персонажа (спящее тело, манекен): передайте результат без изменений в клиентский `appearance.apply` ([Lib: клиент](/ru/docs/developers/api/lib-client)).

**Сторона:** Сервер · **Ждёт:** да (Promise в TypeScript, в Lua приостанавливает поток)

```ts title="Сигнатура"
appearance.get(charId: number): Promise<CharacterAppearance | null>
```

```lua title="Lua"
local look = aiLib.appearance.get(charId) -- { model, data } или nil, вызывайте внутри потока
```

<TypeTable
  type={{
    charId: { type: "number", description: "Id персонажа (`CharacterInfo.id`).", required: true },
  }}
/>

#### Возвращает

`Promise<CharacterAppearance | null>`: [`CharacterAppearance`](/ru/docs/developers/api/types#characterappearance) это `{ model, data }` (хэш модели педа и собственные данные внешности скрипта одежды). `null`, если внешности нет, не запущен скрипт одежды или ai-core остановлен.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, online, playersNear } from "@aifivem/lib/server";

async function sendLook(source: number) {
  const charId = online.charId(source);
  if (charId === undefined) return;
  const look = await appearance.get(charId);
  if (!look) return;
  // Внешность нужна только игрокам рядом с этим персонажем.
  for (const other of playersNear(source, 100)) emitNet("my-sleepers:look", other, source, look);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local character = aiLib.online.character(source)
    if not character then return end
    local look = aiLib.appearance.get(character.id)
    if look then TriggerClientEvent('my-sleepers:look', source, look) end
end)
```
</Tab>
</Tabs>

### appearance.provider

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
appearance.provider(): string | null
```

```lua title="Lua"
local name = aiLib.appearance.provider()
```

**Возвращает** скрипт одежды, который отвечает, или `null` (в Lua `nil`), если никакой не запущен.

```ts
console.log(`looks through ${appearance.provider() ?? "nothing"}`);
```
