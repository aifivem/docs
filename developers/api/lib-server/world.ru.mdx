## world

Время и погода через ai-core, какой бы скрипт погоды ни был запущен (Renewed-Weathersync, av_weather, cd_easytime, qb-weathersync). Пока никакой не запущен, чтение отвечает `null`, а изменения отвечают `false`.

### world.getWeather

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
world.getWeather(): string | null
```

```lua title="Lua"
local weather = aiLib.world.getWeather()
```

**Возвращает** текущий тип погоды так, как его сообщает скрипт погоды (`CLEAR`, `RAIN`...), или `null`, пока никакой не запущен.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const raining = ["RAIN", "THUNDER"].includes(world.getWeather() ?? "");
```
</Tab>
<Tab value="Lua">
```lua
local weather = aiLib.world.getWeather()
local raining = weather == 'RAIN' or weather == 'THUNDER'
```
</Tab>
</Tabs>

### world.setWeather

Задаёт погоду.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
world.setWeather(type: Weather): boolean
```

```lua title="Lua"
local ok = aiLib.world.setWeather(weather)
```

<TypeTable
  type={{
    type: { type: "Weather", typeDescriptionLink: "/ru/docs/developers/api/types#weather", description: "Одно из `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Значение от клиента или из панели сначала проверьте через `isWeather` (`@aifivem/shared`).", required: true },
  }}
/>

**Возвращает** `true`, если задано, `false`, пока не запущен скрипт погоды или значение не является строкой.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, world } from "@aifivem/lib/server";
import { isWeather } from "@aifivem/shared";

addCommand("weather", { restricted: true, params: [{ name: "type", type: "string" }] }, (_source, { type }) => {
  const upper = type.toUpperCase();
  if (isWeather(upper)) world.setWeather(upper);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { restricted = true, params = { { name = 'type', type = 'string' } } }, function(_, args)
    aiLib.world.setWeather(args.type:upper())
end)
```
</Tab>
</Tabs>

## buckets

Routing buckets (отдельные миры: интерьер квартиры, инстанс) из распределителя ai-core, поэтому два скрипта никогда не получат один и тот же. Никогда не выбирайте номера buckets сами (`1000 + n`). Lua-аналога нет: вызывайте экспорты ai-core `AcquireBucket(tag)` / `ReleaseBucket(id)`.

### buckets.acquire

Берёт свободный bucket для этого ресурса. В нём нет населения (ни фоновых педов, ни машин) и действует строгая блокировка сущностей.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
buckets.acquire(tag: string): number
```

<TypeTable
  type={{
    tag: { type: "string", description: "Имя для логов (`property:12`).", required: true },
  }}
/>

**Возвращает** id bucket.

```ts
import { buckets } from "@aifivem/lib/server";

const bucket = buckets.acquire(`property:${propertyId}`);
SetPlayerRoutingBucket(String(source), bucket);
```

### buckets.release

Возвращает bucket, когда из него вышли игроки.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
buckets.release(id: number): boolean
```

**Возвращает** `true`, если освобождён. Каждый bucket остановленного ресурса возвращается сам.

```ts
SetPlayerRoutingBucket(String(source), 0);
buckets.release(bucket);
```

## doors

Замки дверей через слой замков ai-core, по собственному id двери в скрипте замков. Lua-аналога нет: вызывайте экспорты ai-core `SetDoorLocked`, `IsDoorLocked`.

### doors.setLocked

Запирает или отпирает дверь.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
doors.setLocked(id: string, locked: boolean, by?: number): boolean
```

<TypeTable
  type={{
    id: { type: "string", description: "Собственный id двери в скрипте замков (id двери в панели ai-doorlock).", required: true },
    locked: { type: "boolean", description: "`true` запирает, `false` отпирает.", required: true },
    by: { type: "number", description: "Серверный id действующего игрока. Он нужен скриптам дверей без серверного API.", required: false },
  }}
/>

**Возвращает** `true`, если скрипт дверей принял вызов, иначе `false`.

```ts
if (outcome === "won") doors.setLocked("bank_vault", false, source);
```

### doors.isLocked

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
doors.isLocked(id: string): boolean | null
```

**Возвращает** `true` или `false` либо `null`, если неизвестно (нет скрипта замков, нет такой двери или скрипт не может сказать это на сервере).

```ts
if (doors.isLocked("bank_vault") === false) return fail("ALREADY_OPEN");
```

### doors.provider

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
doors.provider(): string | null
```

**Возвращает** скрипт замков, который отвечает, или `null`, если никакой не запущен.

```ts
console.log(`doors through ${doors.provider() ?? "nothing"}`);
```

## characters

Сохранённые персонажи через ai-core. Загруженные персонажи идут через `online` и экспорты игроков ai-core.

### characters.setOfflinePosition

Перемещает точку появления сохранённого (не загруженного) персонажа, например спящего тела, которое унесли. ai-core записывает её, как только персонажа не удерживает сохранение при загрузке или выгрузке.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
characters.setOfflinePosition(charId: number, position: { x: number; y: number; z: number; heading?: number }): boolean
```

Lua-аналога нет: вызывайте экспорт ai-core `SetOfflinePosition(charId, position)`.

<TypeTable
  type={{
    charId: { type: "number", description: "Id персонажа (`CharacterInfo.id`).", required: true },
    position: { type: "{ x: number; y: number; z: number; heading?: number }", description: "Новая точка появления; направление в градусах.", required: true },
  }}
/>

**Возвращает** `true`, если принято. `false`, если персонаж загружен или значения неверные.

```ts
characters.setOfflinePosition(sleeperCharId, { x: 340.2, y: -1396.7, z: 32.5, heading: 50 });
```
