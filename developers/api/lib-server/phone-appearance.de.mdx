## phone

Das Handy des Spielers über ai-core: Das erste laufende Handy-Skript (tgiann-phone, lb-phone...) antwortet. Ohne Handy-Skript antwortet jeder Aufruf mit `null` oder `false`. Die Lua-Zwillinge auf `aiLib.phone` haben dieselben Namen und dieselbe Argumentreihenfolge.

### phone.number

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
phone.number(source: number): string | null
```

```lua title="Lua"
local number = aiLib.phone.number(source)
```

**Rückgabewert:** die Telefonnummer des Spielers, oder `null` (Lua `nil`), wenn er keine hat oder kein Handy-Skript läuft.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const number = phone.number(source);
if (!number) return fail("NO_PHONE_NUMBER");
```
</Tab>
<Tab value="Lua">
```lua
local number = aiLib.phone.number(source)
if not number then return aiLib.fail('NO_PHONE_NUMBER') end
```
</Tab>
</Tabs>

### phone.sourceOf

Der Online-Spieler, dem eine Telefonnummer gehört.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
phone.sourceOf(number: string): number | null
```

```lua title="Lua"
local source = aiLib.phone.sourceOf(number)
```

**Rückgabewert:** die Server-ID, oder `null` (Lua `nil`), wenn niemand online diese Nummer hat.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const owner = phone.sourceOf("555-0101");
if (owner !== null) notify(owner, "Your phone is ringing");
```
</Tab>
<Tab value="Lua">
```lua
local owner = aiLib.phone.sourceOf('555-0101')
if owner then aiLib.notify(owner, 'Your phone is ringing') end
```
</Tab>
</Tabs>

## appearance

Das gespeicherte Aussehen von Charakteren über die Aussehens-Ebene von ai-core, egal welches Kleidungs-Skript läuft (ai-appearance, tgiann-clothing).

### appearance.get

Das gespeicherte Aussehen eines Charakters, geladen oder nicht. Nutze es, um einen Ped einzukleiden, der für einen Charakter steht (ein schlafender Körper, eine Schaufensterpuppe): Gib das Ergebnis unverändert an `appearance.apply` des Clients weiter ([Lib: Client](/de/docs/developers/api/lib-client)).

**Seite:** Server · **Wartet:** ja (Promise in TypeScript, hält in Lua den Thread an)

```ts title="Signatur"
appearance.get(charId: number): Promise<CharacterAppearance | null>
```

```lua title="Lua"
local look = aiLib.appearance.get(charId) -- { model, data } oder nil, innerhalb eines Threads aufrufen
```

<TypeTable
  type={{
    charId: { type: "number", description: "Die Charakter-ID (`CharacterInfo.id`).", required: true },
  }}
/>

#### Rückgabewert

`Promise<CharacterAppearance | null>`: [`CharacterAppearance`](/de/docs/developers/api/types#characterappearance) ist `{ model, data }` (der Hash des Ped-Modells und die eigenen Aussehensdaten des Kleidungs-Skripts). `null`, wenn der Charakter keins hat, kein Kleidungs-Skript läuft oder ai-core gestoppt ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, online, playersNear } from "@aicore-fivem/lib/server";

async function sendLook(source: number) {
  const charId = online.charId(source);
  if (charId === undefined) return;
  const look = await appearance.get(charId);
  if (!look) return;
  // Nur die Spieler in der Nähe dieses Charakters brauchen das Aussehen.
  for (const other of playersNear(source, 100)) emitNet("my-sleepers:look", other, source, look);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local character = aiLib.online.character(source)
    if not character then return end
    local look = aiLib.appearance.get(character.id)
    if look then TriggerClientEvent('my-sleepers:look', source, look) end
end)
```
</Tab>
</Tabs>

### appearance.provider

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
appearance.provider(): string | null
```

```lua title="Lua"
local name = aiLib.appearance.provider()
```

**Rückgabewert:** das Kleidungs-Skript, das antwortet, oder `null` (Lua `nil`), wenn keins läuft.

console.log(`looks through ${appearance.provider() ?? "nothing"}`);
