```ts title="TypeScript"
import { aiLog, aiLogChannels } from "@aicore-fivem/lib/server";
```

Votre script ne publie jamais lui-même sur Discord ou un service de journaux. Il envoie un journal à ai-core sur un **canal** (un nom comme `purchase`) ; le propriétaire du serveur décide dans le panneau d’administration d’ai-core où va chaque canal. Les URL de webhook et les clés d’API restent dans le panneau, jamais dans votre code.

### aiLog

Envoie une ligne de journal via le système de journaux d’ai-core.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
aiLog(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
aiLib.aiLog(channel, message, options)
```

#### Paramètres

<TypeTable
  type={{
    channel: { type: "string", description: "Le nom du canal (`purchase`, `admin`). Décrivez vos canaux une fois avec `aiLogChannels`.", required: true },
    message: { type: "string", description: "Ce qui s’est passé. Passez les joueurs en `source` / `target` au lieu d’écrire leurs noms dans le texte.", required: true },
    options: { type: "LogOptions", typeDescriptionLink: "/fr/docs/developers/api/types#logoptions", description: "Niveau, joueurs et valeurs supplémentaires. Champs ci-dessous.", required: false },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: "Gravité.", required: false },
    source: { type: "number", description: "Id serveur du joueur qui a agi. Son nom, son personnage et ses identifiants sont ajoutés.", required: false },
    target: { type: "number", description: "Id serveur du joueur qui a subi l’action.", required: false },
    metadata: { type: "Record<string, unknown>", description: "Champs supplémentaires (montants, noms d’objets, coordonnées).", required: false },
  }}
/>

#### Retour

`void`. En TypeScript, ne fait rien tant qu’ai-core ne tourne pas ; l’équivalent Lua affiche alors `[channel] message` dans la console.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { aiLog } from "@aicore-fivem/lib/server";

aiLog("purchase", `bought ${count}x ${item} for $${price}`, {
  source,
  metadata: { item, count, price },
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.aiLog('purchase', ('bought %dx %s for $%d'):format(count, item, price), {
    source = source,
    metadata = { item = item, count = count, price = price },
})
```
</Tab>
</Tabs>

### aiLogChannels

Décrit les canaux de journaux de votre ressource : le nom du dataset utilisé par Fivemanage et FiveM Stats, et si un canal est actif. Appelez-la une fois au démarrage de votre script.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
aiLogChannels(channels: Record<string, LogChannel>): void
```

Pas d’équivalent Lua : appelez l’export d’ai-core `exports['ai-core']:LogChannels(channels)`.

#### Paramètres

<TypeTable
  type={{
    channels: { type: "Record<string, LogChannel>", typeDescriptionLink: "/fr/docs/developers/api/types#logchannel", description: "Une entrée par nom de canal. Chaque `LogChannel` a `dataset?` (dataset Fivemanage / FiveM Stats, par défaut le nom de la ressource) et `active?` (`false` désactive le canal).", required: true },
  }}
/>

#### Retour

`void`. Ne fait rien tant qu’ai-core ne tourne pas.

#### Exemple

```ts
import { aiLogChannels } from "@aicore-fivem/lib/server";

aiLogChannels({
  purchase: { dataset: "shops" },
  debug: { active: false },
});
```
