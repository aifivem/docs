## phone

El teléfono del jugador a través de ai-core: responde el primer script de teléfono que esté en marcha (tgiann-phone, lb-phone...). Sin script de teléfono, cada llamada responde `null` o `false`. Los equivalentes en Lua en `aiLib.phone` tienen los mismos nombres y el mismo orden de argumentos.

### phone.number

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
phone.number(source: number): string | null
```

```lua title="Lua"
local number = aiLib.phone.number(source)
```

**Devuelve** el número de teléfono del jugador, o `null` (`nil` en Lua) cuando no tiene ninguno o no hay script de teléfono en marcha.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const number = phone.number(source);
if (!number) return fail("NO_PHONE_NUMBER");
```
</Tab>
<Tab value="Lua">
```lua
local number = aiLib.phone.number(source)
if not number then return aiLib.fail('NO_PHONE_NUMBER') end
```
</Tab>
</Tabs>

### phone.sourceOf

El jugador en línea que tiene un número de teléfono.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
phone.sourceOf(number: string): number | null
```

```lua title="Lua"
local source = aiLib.phone.sourceOf(number)
```

**Devuelve** el id de servidor, o `null` (`nil` en Lua) cuando nadie en línea tiene ese número.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const owner = phone.sourceOf("555-0101");
if (owner !== null) notify(owner, "Your phone is ringing");
```
</Tab>
<Tab value="Lua">
```lua
local owner = aiLib.phone.sourceOf('555-0101')
if owner then aiLib.notify(owner, 'Your phone is ringing') end
```
</Tab>
</Tabs>

### phone.hasPhone

Si el jugador lleva un teléfono.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
phone.hasPhone(source: number): boolean
```

```lua title="Lua"
local has = aiLib.phone.hasPhone(source)
```

**Devuelve** `true` cuando tiene uno; `false` si no lo tiene o no hay script de teléfono.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

```
</Tab>
<Tab value="Lua">
```lua

```
</Tab>
</Tabs>

## appearance

El aspecto guardado de los personajes a través de la capa de apariencia de ai-core, sea cual sea el script de ropa que funcione (ai-appearance, tgiann-clothing).

### appearance.get

El aspecto guardado de un personaje, esté cargado o no. Úsalo para vestir un ped que representa a un personaje (un cuerpo dormido, un maniquí): pasa el resultado sin cambios a `appearance.apply` del cliente ([Lib: cliente](/es/docs/developers/api/lib-client)).

**Lado:** Servidor · **Espera:** sí (Promise en TypeScript, cede el hilo en Lua)

```ts title="Firma"
appearance.get(charId: number): Promise<CharacterAppearance | null>
```

```lua title="Lua"
local look = aiLib.appearance.get(charId) -- { model, data } o nil, llamar dentro de un hilo
```

<TypeTable
  type={{
    charId: { type: "number", description: "El id del personaje (`CharacterInfo.id`).", required: true },
  }}
/>

#### Devuelve

`Promise<CharacterAppearance | null>`: [`CharacterAppearance`](/es/docs/developers/api/types#characterappearance) es `{ model, data }` (el hash del modelo del ped y los datos de aspecto propios del script de ropa). `null` cuando el personaje no tiene ninguno, no hay script de ropa en marcha o ai-core está detenido.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, online, playersNear } from "@aifivem/lib/server";

async function sendLook(source: number) {
  const charId = online.charId(source);
  if (charId === undefined) return;
  const look = await appearance.get(charId);
  if (!look) return;
  // Solo los jugadores cerca de este personaje necesitan el aspecto.
  for (const other of playersNear(source, 100)) emitNet("my-sleepers:look", other, source, look);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local character = aiLib.online.character(source)
    if not character then return end
    local look = aiLib.appearance.get(character.id)
    if look then TriggerClientEvent('my-sleepers:look', source, look) end
end)
```
</Tab>
</Tabs>

### appearance.provider

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
appearance.provider(): string | null
```

```lua title="Lua"
local name = aiLib.appearance.provider()
```

**Devuelve** el script de ropa que responde, o `null` (`nil` en Lua) cuando no hay ninguno en marcha.

```ts
console.log(`looks through ${appearance.provider() ?? "nothing"}`);
```
