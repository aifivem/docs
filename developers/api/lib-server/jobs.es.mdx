```ts title="TypeScript"
import { dispatch, prison, mdt, ems, medical, stress, needs, definitions, isPrimeTime } from "@aicore-fivem/lib/server";
```

Cada objeto de esta página pasa por una de las capas de ai-core: responde el script que usa el servidor para esa tarea (un sistema de alertas, una prisión, un MDT, un script de muerte, un HUD). Tu script sigue funcionando cuando el dueño lo cambia. Mientras no haya un script así en marcha, las llamadas fallan en silencio (`false`, `0`, `null`).

## dispatch

### dispatch.alert

Envía una alerta a la policía (o a otro trabajo). El sistema de alertas la muestra a los miembros de servicio de `jobs`, por defecto los trabajos de policía.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

<TypeTable
  type={{
    title: { type: "string", description: "El titular, traducido (`Shots fired`).", required: true },
    code: { type: "string", description: "Código de radio que se muestra antes del título (`10-71`).", required: false },
    message: { type: "string", description: "Una línea más (el nombre de la tienda).", required: false },
    coords: { type: "{ x: number; y: number; z: number }", description: "Dónde pasó. Sin él, la posición del jugador `source`; sin ninguno de los dos, no hay punto en el mapa.", required: false },
    jobs: { type: "string[]", description: "Trabajos cuyos miembros de servicio la reciben.", default: "los trabajos de policía del sistema de alertas" },
    source: { type: "number", description: "El jugador al que se refiere la alerta (tirador, ladrón). Los sistemas que describen al sospechoso (vehículo, género) leen a este jugador.", required: false },
    blip: { type: "{ sprite: number; color?: number; scale?: number }", description: "Blip del mapa: un sprite y un color de blip de GTA.", default: "los del sistema de alertas" },
    duration: { type: "number", description: "Segundos que dura la alerta (tarjeta, blip, tecla de ruta).", default: "los del sistema de alertas" },
    icon: { type: "string", description: "Nombre de icono sólido de Font Awesome sin `fa-` (`gun`).", required: false },
    priority: { type: '"normal" | "high"', description: "`high` hace que la tarjeta destaque (robo a mano armada, agente herido).", default: '"normal"' },
  }}
/>

El tipo es [`DispatchAlert`](/es/docs/developers/api/types#dispatchalert).

#### Devuelve

`boolean`: `true` cuando se envió. `false` cuando no hay sistema de alertas en marcha o la alerta no es válida.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, coordsOf, createLocale } from "@aicore-fivem/lib/server";

const Locale = createLocale();

function storeRobbed(source: number, store: string) {
  dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

local function storeRobbed(source, store)
    local c = GetEntityCoords(GetPlayerPed(source))
    aiLib.dispatch.alert({
        code = '10-90',
        title = Locale('ALERT_STORE_ROBBERY'),
        message = store,
        coords = { x = c.x, y = c.y, z = c.z },
        source = source,
        icon = 'store',
        priority = 'high',
    })
end
```
</Tab>
</Tabs>

## prison

Condenas de prisión a través de ai-core, sea cual sea el script de prisión que funcione.

### prison.jail

Envía a prisión a un jugador cargado.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
prison.jail(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local ok = aiLib.prison.jail(source, minutes, by)
```

<TypeTable
  type={{
    source: { type: "number", description: "Id de servidor del jugador que se encarcela.", required: true },
    minutes: { type: "number", description: "Duración de la condena en minutos.", required: true },
    by: { type: "number", description: "Id de servidor de quien lo envió (para el log). 0 significa el servidor.", default: "0" },
  }}
/>

**Devuelve** `true` cuando se encarceló, `false` mientras no haya prisión en marcha.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

```
</Tab>
<Tab value="Lua">
```lua
if not aiLib.prison.jail(target, 15, officer) then return aiLib.fail('NO_PRISON') end
```
</Tab>
</Tabs>

## mdt

Registros policiales del MDT (multas, órdenes de búsqueda, arrestos, cárcel) a través de la capa de MDT de ai-core. No se escribe nada mientras no haya MDT en marcha.

### mdt.record

Escribe un registro en el MDT policial.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
mdt.record(record: MdtRecord): boolean
```

```lua title="Lua"
local ok = aiLib.mdt.record(record)
```

#### MdtRecord

<TypeTable
  type={{
    kind: { type: '"fine" | "warrant" | "arrest" | "jail"', description: "El tipo de registro.", required: true },
    target: { type: "number", description: "Id de servidor del jugador al que se refiere el registro.", required: true },
    by: { type: "number", description: "Id de servidor del agente que lo escribe.", required: false },
    title: { type: "string", description: "Qué pasó, traducido (`Armed robbery`).", required: true },
    amount: { type: "number", description: "El importe de una multa en dólares.", required: false },
    minutes: { type: "number", description: "Una condena de cárcel en minutos.", required: false },
  }}
/>

El tipo es [`MdtRecord`](/es/docs/developers/api/types#mdtrecord).

**Devuelve** `true` cuando se escribió, `false` cuando no hay MDT en marcha o este no acepta ese tipo de registro.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

</Tab>
<Tab value="Lua">
```lua

    aiLib.mdt.record({ kind = 'jail', target = target, by = officer, title = 'Armed robbery', minutes = 20 })
end
```
</Tab>
</Tabs>

## ems

Médicos a través de la capa de EMS de ai-core: el recuento y las llamadas de auxilio propios de un script de EMS, o si no, los recuentos de servicio y las alertas de ai-core.

### ems.available

Cuántos médicos están libres para atender una llamada.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
ems.available(jobs: string[]): number
```

```lua title="Lua"
local count = aiLib.ems.available(jobs)
```

<TypeTable
  type={{
    jobs: { type: "string[]", description: "Los nombres de trabajos de EMS que se cuentan (`[\"ambulance\"]`).", required: true },
  }}
/>

**Devuelve** el número de médicos de servicio en `jobs`, dejando fuera a los ocupados cuando un script de dispatch los conoce.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Deja a los jugadores reaparecer en el hospital solo cuando ningún médico puede venir.
const canRespawn = ems.available(["ambulance"]) === 0;
```
</Tab>
<Tab value="Lua">
```lua
local canRespawn = aiLib.ems.available({ 'ambulance' }) == 0
```
</Tab>
</Tabs>

## medical

Revivir, curar y el estado de derribado a través de la capa médica de ai-core, sea cual sea el script de muerte o de ambulancia que funcione. Sin equivalente en Lua: llama a los exports de ai-core `RevivePlayer`, `HealPlayer`, `IsPlayerDead`.

### medical.revive

Levanta a un jugador derribado donde está tendido.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
medical.revive(source: number): boolean
```

**Devuelve** `true` cuando se revivió, `false` cuando no está derribado o no hay script de muerte en marcha.

```ts
if (!medical.revive(target)) return fail("NOT_DOWN");
```

### medical.heal

Da la salud completa a un jugador que no está derribado.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
medical.heal(source: number): boolean
```

**Devuelve** `true` cuando se curó, `false` cuando no hay script de muerte en marcha.

```ts
medical.heal(source);
```

### medical.isDead

Si el jugador está derribado.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
medical.isDead(source: number): boolean
```

**Devuelve** `true` cuando está derribado; `false` sin script de muerte. Úsalo en lugar de leer la salud del ped.

```ts
if (medical.isDead(source)) return fail("YOU_ARE_DOWN");
```

### medical.provider

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
medical.provider(): string | null
```

**Devuelve** el script de muerte que responde (`ai-death`...), o `null` cuando no hay ninguno en marcha.

```ts
console.log(`deaths through ${medical.provider() ?? "nothing"}`);
```

## needs

### needs.refill

Llena por completo el hambre y la sed (revivir de admin, hospital), a través del HUD que las lleva, o de los metadatos del personaje de ai-core si no hay ninguno.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
needs.refill(source: number): boolean
```

Sin equivalente en Lua: llama al export de ai-core `RefillNeeds(source)`.

**Devuelve** `true` cuando se rellenaron, `false` cuando el jugador no tiene personaje.

```ts
if (medical.revive(target)) needs.refill(target);
```

## Definiciones de trabajos y bandas

### definitions.job

La definición de un trabajo tal como está en el panel de ai-core. Cada una se lee una vez de ai-core y se guarda hasta que el panel la cambia, así que una lectura es una consulta en memoria.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
definitions.job(name: string): JobDefinition | null
```

Sin equivalente en Lua: llama al export de ai-core `GetJobDefinition(name)`.

**Devuelve** [`JobDefinition`](/es/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`), o `null` cuando no existe ese trabajo.

```ts
const label = definitions.job("police")?.label ?? "police";
```

### definitions.gang

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
definitions.gang(name: string): GangDefinition | null
```

Sin equivalente en Lua: llama al export de ai-core `GetGangDefinition(name)`.

**Devuelve** [`GangDefinition`](/es/docs/developers/api/types#gangdefinition) (`label`, `grades`), o `null`.

```ts
const gang = definitions.gang("ballas");
if (!gang) return fail("UNKNOWN_GANG");
```

## Horas punta

### isPrimeTime

Si es hora punta para un trabajo, según el ajuste de horas punta de ai-core. Las horas vienen de tgiann-policealert mientras está en marcha, o si no, de las horas fijadas en el panel de ai-core.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
isPrimeTime(job?: string): boolean
```

Sin equivalente en Lua: llama al export de ai-core `IsPrimeTime(job)`.

<TypeTable
  type={{
    job: { type: "string", description: "Trabajo cuyas horas punta se comprueban. Sin él, las horas por defecto.", required: false },
  }}
/>

**Devuelve** `true` durante las horas punta.

```ts
if (!isPrimeTime("police")) return fail("BANK_CLOSED_FOR_HEISTS");
```
