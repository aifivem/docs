```ts title="TypeScript"
import { jobs, dispatch, prison, mdt, ems, medical, stress, needs, definitions, isPrimeTime } from "@aifivem/lib/server";
```

`jobs` y `definitions` son ai-core en sí: los trabajos y bandas de un personaje, y las definiciones de trabajos del servidor. Todo lo demás de aquí pasa por una de las capas de ai-core, donde responde el script que el servidor usa para esa tarea (un sistema de avisos, una cárcel, un MDT, un script de muerte, un HUD). Tu script sigue funcionando cuando el propietario lo cambia. Mientras no corra ninguno, esas llamadas fallan en silencio (`false`, `0`, `null`).

## jobs

`jobs` son los trabajos y bandas propios de un jugador cargado a través de ai-core: un personaje puede tener varios trabajos, está de servicio en uno como máximo, y actúa por una banda a la vez. Leer **muchos** jugadores a la vez es el espejo de la lib ([`online`](/es/docs/developers/api/lib-server/players#onlinejobs)); cambiar un personaje **no conectado** es [`characters`](/es/docs/developers/api/lib-server/characters#characterssetjob-and-charactersremovejob).

### jobs.current

El trabajo que los demás scripts ven como "el" trabajo de un jugador: el que tiene de servicio, si no el último en el que estuvo de servicio, si no el primero que tiene, si no el trabajo de desempleado.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
jobs.current(source: number): JobMembership | null
```

```lua title="Lua"
local current = aiLib.jobs.current(source)
```

#### Devuelve

Un [JobMembership](/es/docs/developers/api/types#jobmembership) (`{ job, grade }`), o `null` cuando el jugador no tiene personaje cargado.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs } from "@aifivem/lib/server";

export function isOfficer(source: number): boolean {
  return jobs.current(source)?.job === "police";
}
```
</Tab>
<Tab value="Lua">
```lua
local current = aiLib.jobs.current(source)
local officer = current and current.job == 'police'
```
</Tab>
</Tabs>

**Lado:** Servidor · **Espera:** no

### jobs.duty and jobs.setDuty

En qué trabajo está de servicio el jugador, y entrar o salir de servicio. Muchos scripts comprueban el servicio en vez de la pertenencia: un agente fuera de servicio es un civil.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
jobs.duty(source: number): string | null
jobs.setDuty(source: number, job: string | null): boolean
```

```lua title="Lua"
local onDutyIn = aiLib.jobs.duty(source)
local ok = aiLib.jobs.setDuty(source, job)
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador.', required: true },
    job: { type: 'string | null', description: 'Un trabajo que el jugador tiene, para entrar de servicio en él. `null` (en Lua `nil`) sale de servicio.', required: true },
  }}
/>

#### Devuelve

`jobs.duty`: el nombre del trabajo, o `null` fuera de servicio (o sin personaje). `jobs.setDuty`: `true` cuando el cambio se hizo, `false` para un trabajo que el jugador no tiene.

### jobs.set

Añade un trabajo al jugador, o cambia el grado de uno que ya tiene. Se aplican las reglas del panel: cuántos trabajos puede tener un personaje y si se permite un segundo.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
jobs.set(source: number, job: string, grade: number): boolean
```

```lua title="Lua"
local ok = aiLib.jobs.set(source, job, grade)
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador.', required: true },
    job: { type: 'string', description: 'El nombre del trabajo tal como está en el panel (o en una definición de script).', required: true },
    grade: { type: 'number', description: 'El grado en ese trabajo, desde 0. Un grado que el trabajo no tiene se rechaza.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el jugador tiene después ese trabajo en ese grado. `false` sin personaje cargado, con un trabajo desconocido, un grado desconocido, o al topar con el límite de trabajos del panel.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs, notify } from "@aifivem/lib/server";

export function hire(source: number, job: string): void {
  if (!jobs.set(source, job, 0)) return notify(source, "No se pudo contratar", "error");
  notify(source, `Bienvenido a ${job}`, "success");
}
```
</Tab>
<Tab value="Lua">
```lua
if aiLib.jobs.set(source, 'mechanic', 0) then
    aiLib.notify(source, 'Bienvenido a mechanic', 'success')
end
```
</Tab>
</Tabs>

## dispatch

### dispatch.alert

Envía una alerta a la policía (o a otro trabajo). El sistema de alertas la muestra a los miembros de servicio de `jobs`, por defecto los trabajos de policía.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"

```

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

<TypeTable
  type={{
    title: { type: "string", description: "El titular, traducido (`Shots fired`).", required: true },
    code: { type: "string", description: "Código de radio que se muestra antes del título (`10-71`).", required: false },
    message: { type: "string", description: "Una línea más (el nombre de la tienda).", required: false },
    coords: { type: "{ x: number; y: number; z: number }", description: "Dónde pasó. Sin él, la posición del jugador `source`; sin ninguno de los dos, no hay punto en el mapa.", required: false },

    source: { type: "number", description: "El jugador al que se refiere la alerta (tirador, ladrón). Los sistemas que describen al sospechoso (vehículo, género) leen a este jugador.", required: false },
    blip: { type: "{ sprite: number; color?: number; scale?: number }", description: "Blip del mapa: un sprite y un color de blip de GTA.", default: "los del sistema de alertas" },
    duration: { type: "number", description: "Segundos que dura la alerta (tarjeta, blip, tecla de ruta).", default: "los del sistema de alertas" },
    icon: { type: "string", description: "Nombre de icono sólido de Font Awesome sin `fa-` (`gun`).", required: false },

  }}
/>

El tipo es [`DispatchAlert`](/es/docs/developers/api/types#dispatchalert).

#### Devuelve

`boolean`: `true` cuando se envió. `false` cuando no hay sistema de alertas en marcha o la alerta no es válida.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, coordsOf, createLocale } from "@aifivem/lib/server";

const Locale = createLocale();

function storeRobbed(source: number, store: string) {
  dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

local function storeRobbed(source, store)
    local c = GetEntityCoords(GetPlayerPed(source))
    aiLib.dispatch.alert({
        code = '10-90',
        title = Locale('ALERT_STORE_ROBBERY'),
        message = store,
        coords = { x = c.x, y = c.y, z = c.z },
        source = source,
        icon = 'store',
        priority = 'high',
    })
end
```
</Tab>
</Tabs>

## medical

**Lado:** Servidor · **Espera:** no

medical.revive(source: number): boolean

## Definiciones de trabajos y bandas

**Devuelve** [`JobDefinition`](/es/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`), o `null` cuando no existe ese trabajo.

```ts
const label = definitions.job("police")?.label ?? "police";
```

```ts
const gang = definitions.gang("ballas");
if (!gang) return fail("UNKNOWN_GANG");
```

### definitions.registerJob and definitions.removeJob

Un trabajo que trae tu script sin que el propietario lo añada en el panel: un trabajo del resource que llama, que desaparece cuando el resource para y nunca se escribe en el archivo del panel.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
definitions.registerJob(name: string, definition: JobDefinition): CharacterResult
definitions.removeJob(name: string): boolean
```

```lua title="Lua"
local result = aiLib.definitions.registerJob(name, definition)
local ok = aiLib.definitions.removeJob(name)
```

#### Parámetros

<TypeTable
  type={{
    name: { type: 'string', description: 'El nombre de trabajo que usa tu script (`"my-garbagejob"`).', required: true },
    definition: { type: 'JobDefinition', typeDescriptionLink: '/es/docs/developers/api/types#jobdefinition', description: 'El trabajo en sí: `label`, `type`, `defaultDuty`, `listed`, y sus `grades` (cada uno con `label`, `salary`, `boss`).', required: true },
  }}
/>

#### Devuelve

`registerJob` responde [ActionResult](/es/docs/developers/api/types#actionresult): `{ ok: true }`, o `{ ok: false, error }` con una clave de idioma cuando el panel ya tiene un trabajo con ese nombre o otro resource lo registró - el panel del propietario siempre gana. `removeJob` responde `true` solo para un trabajo que registró este resource.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { definitions } from "@aifivem/lib/server";

// Una vez al arrancar: el trabajo existe mientras este resource corra.
const result = definitions.registerJob("garbage", {
  label: "Garbage",
  type: "job",
  defaultDuty: true,
  grades: [{ label: "Driver", salary: 60, boss: false }],
});
if (!result.ok) console.log(`trabajo no registrado: ${result.error}`);
```
</Tab>
<Tab value="Lua">
```lua
local result = aiLib.definitions.registerJob('garbage', {
    label = 'Garbage',
    type = 'job',
    defaultDuty = true,
    grades = { { label = 'Driver', salary = 60, boss = false } },
})
if not result.ok then print(('trabajo no registrado: %s'):format(result.error)) end
```
</Tab>
</Tabs>

<Callout type="info">
Un trabajo que el propietario del servidor deba poder editar pertenece al panel, no aquí. Registra uno cuando el trabajo es parte de tu script y no significa nada sin él.
</Callout>

## Horas punta

### isPrimeTime

Si es hora punta para un trabajo, según el ajuste de horas punta de ai-core. Las horas vienen de tgiann-policealert mientras está en marcha, o si no, de las horas fijadas en el panel de ai-core.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
isPrimeTime(job?: string): boolean
```

Sin equivalente en Lua: llama al export de ai-core `IsPrimeTime(job)`.

<TypeTable
  type={{
    job: { type: "string", description: "Trabajo cuyas horas punta se comprueban. Sin él, las horas por defecto.", required: false },
  }}
/>

**Devuelve** `true` durante las horas punta.

```ts
if (!isPrimeTime("police")) return fail("BANK_CLOSED_FOR_HEISTS");
```
