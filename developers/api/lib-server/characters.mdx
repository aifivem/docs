```ts title="TypeScript"
import { characters } from "@aifivem/lib/server";
```

```lua title="Lua"
-- aiLib.characters, after shared_script '@ai-lib/init.lua'
```

`characters` is the lib's door to [ai-core's stored-character exports](/docs/developers/api/core-server/stored-characters). It exists because those exports answer through a callback: the lib turns each one into a **Promise** in TypeScript and into a **plain wait** in Lua, so your code reads top to bottom.

- A character is named by its **character id** (`charId`, a number). From a citizenid, use [`characters.idOf`](#charactersidof).
- A loaded character answers from memory (live money, live memberships); a stored one is read from the database while ai-core holds it, so it cannot load in the middle of a write.
- Every write answers [ActionResult](/docs/developers/api/types#actionresult): `{ ok: true }`, or `{ ok: false, error }` with an ai-core lang key.
- Every function here **waits**. In Lua that means calling it from a thread; see [Functions that wait](/docs/developers/api/lua#functions-that-wait).

<Callout type="info">
For the player an action is about, the shorter path is often ai-core directly: [GetCharacter](/docs/developers/api/core-server/characters#getcharacter), [money](/docs/developers/api/lib-server/money#moneyget), [jobs](/docs/developers/api/lib-server/jobs#jobsset). Use `characters` when the target may be offline, or when you need a whole character at once.
</Callout>

## characters

### characters.idOf

The character id behind a citizenid.

**Side:** Server · **Waits:** yes

```ts title="Signature"
characters.idOf(citizenid: string): Promise<number | null>
```

No Lua twin: call ai-core's export [GetCharIdByCitizenId](/docs/developers/api/core-server/stored-characters#getcharidbycitizenid) and wait for its callback.

#### Parameters

<TypeTable
  type={{
    citizenid: { type: 'string', description: 'The citizen id text.', required: true },
  }}
/>

#### Returns

`Promise<number | null>`: the character id, or `null` when no character has that citizenid or it was deleted.

#### Example

```ts
import { characters } from "@aifivem/lib/server";

/** A fine that works whether the driver is online or not. */
export async function fine(citizenid: string, amount: number): Promise<boolean> {
  const charId = await characters.idOf(citizenid);
  if (charId === null) return false;
  return (await characters.removeMoney(charId, "bank", amount, "Speeding fine")).ok;
}
```

### characters.get

One character with everything ai-core keeps about it: info, money per account, jobs, gangs, metadata, stored position, last save, and the server id when it is loaded.

**Side:** Server · **Waits:** yes

```ts title="Signature"
characters.get(charId: number): Promise<OfflineCharacter | null>
```

```lua title="Lua"
local character = aiLib.characters.get(charId) -- table or nil
```

#### Parameters

<TypeTable
  type={{
    charId: { type: 'number', description: 'The character id.', required: true },
  }}
/>

#### Returns

An [OfflineCharacter](/docs/developers/api/types#offlinecharacter), or `null` / `nil` when the id is unknown or the character was deleted.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { characters } from "@aifivem/lib/server";

export async function bankOf(charId: number): Promise<number> {
  const c = await characters.get(charId);
  return c?.money.bank ?? 0;
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local c = aiLib.characters.get(12)
    if not c then return end
    print(('%s %s, bank %d'):format(c.info.firstname, c.info.lastname, c.money.bank or 0))
end)
```
</Tab>
</Tabs>

### characters.search

Characters by a typed text, loaded or not: name prefixes (`"jane doe"` too), citizenid, fivem / license / discord id. 25 a page, newest first.

**Side:** Server · **Waits:** yes

```ts title="Signature"
characters.search(text: string, cursor?: number): Promise<CharacterSearchPage>
```

```lua title="Lua"
local page = aiLib.characters.search(text, cursor)
```

#### Parameters

<TypeTable
  type={{
    text: { type: 'string', description: 'What was typed. An empty text answers the newest characters, so a browse screen needs no term.', required: true },
    cursor: { type: 'number', description: 'The `next` of the page you just read. Leave it out for the first page.' },
  }}
/>

#### Returns

A [CharacterSearchPage](/docs/developers/api/types#charactersearchpage): `characters` (up to 25) and `next` (`null` on the last page). On an error it answers an empty page, never `null`.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { characters, onClientCallback } from "@aifivem/lib/server";
import { oneArg, readText } from "@aifivem/lib/shared";

onClientCallback(
  "myscript:people",
  { args: oneArg((v) => readText(v, 64)), rate: { count: 10, windowMs: 10_000 } },
  async (_source, text) => ({ ok: true, ...(await characters.search(text)) }),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:people', function(source, text)
    if type(text) ~= 'string' then return aiLib.fail('CORE_ERR_ARGS') end
    local page = aiLib.characters.search(text)
    return { ok = true, characters = page.characters, next = page.next }
end, { rate = { count = 10, windowMs = 10000 } })
```
</Tab>
</Tabs>

### characters.jobMembers and characters.gangMembers

Everyone who holds a job, or is in a gang, loaded or not - a page at a time, with their grade and their server id when they are connected.

**Side:** Server · **Waits:** yes

```ts title="Signature"
characters.jobMembers(job: string, after?: number, limit?: number): Promise<MembersPage>
characters.gangMembers(gang: string, after?: number, limit?: number): Promise<MembersPage>
```

```lua title="Lua"
local page = aiLib.characters.jobMembers(job, after, limit)
local page = aiLib.characters.gangMembers(gang, after, limit)
```

#### Parameters

<TypeTable
  type={{
    job: { type: 'string', description: 'The job name (`gangMembers` takes a gang name).', required: true },
    after: { type: 'number', description: 'The `next` of the page you just read. Leave it out for the first page.' },
    limit: { type: 'number', description: 'Members per page, 1-500.', default: '100' },
  }}
/>

#### Returns

A [MembersPage](/docs/developers/api/types#memberspage): `members` and `next` (`null` on the last page).

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { characters } from "@aifivem/lib/server";

/** The whole roster of a job, page by page. */
export async function roster(job: string) {
  const all = [];
  let after: number | undefined;
  do {
    const page = await characters.jobMembers(job, after);
    all.push(...page.members);
    after = page.next ?? undefined;
  } while (after !== undefined);
  return all;
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local all, after = {}, nil
    repeat
        local page = aiLib.characters.jobMembers('police', after)
        for _, m in ipairs(page.members) do all[#all + 1] = m end
        after = page.next
    until not after
    print(('police: %d members'):format(#all))
end)
```
</Tab>
</Tabs>

<Callout type="info">
Counting the players who are **connected** in a job is not this: that is the lib's mirror, [`online.jobMembers`](/docs/developers/api/lib-server/players#onlinejobmembers) (no export call, no database read).
</Callout>

### characters.hasJobMember

**Side:** Server · **Waits:** yes

```

```

#### Returns

### characters.addMoney, characters.removeMoney and characters.setMoney

Money of a character, loaded or not, with a ledger row. A loaded character goes through its live wallet, so the player sees the change at once.

**Side:** Server · **Waits:** yes

```ts title="Signature"
characters.addMoney(charId: number, account: string, amount: number, reason?: string): Promise<CharacterResult>
characters.removeMoney(charId: number, account: string, amount: number, reason?: string): Promise<CharacterResult>
characters.setMoney(charId: number, account: string, amount: number, reason?: string): Promise<CharacterResult>
```

```lua title="Lua"
local result = aiLib.characters.addMoney(charId, account, amount, reason)
local result = aiLib.characters.removeMoney(charId, account, amount, reason)
local result = aiLib.characters.setMoney(charId, account, amount, reason)
```

#### Parameters

<TypeTable
  type={{
    charId: { type: 'number', description: 'The character id.', required: true },
    account: { type: 'string', description: 'Account name from the panel (`cash`, `bank`...). See [Account names](/docs/developers/api/types#account-names).', required: true },
    amount: { type: 'number', description: 'Whole dollars, above 0 for add and remove. `setMoney` takes the new balance (0 allowed).', required: true },
    reason: { type: 'string', description: 'What the ledger row says.', default: 'the calling resource name' },
  }}
/>

#### Returns

`{ ok: true }`, or `{ ok: false, error }` with a lang key: unknown character, unknown account, a fractional or negative amount, or a balance that cannot pay (`removeMoney`, unless the account type may go below zero).

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { characters } from "@aifivem/lib/server";

export async function payOut(charId: number, amount: number): Promise<boolean> {
  const result = await characters.addMoney(charId, "bank", amount, "Vehicle sold");
  if (!result.ok) console.log(`payout refused: ${result.error}`);
  return result.ok;
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local result = aiLib.characters.addMoney(12, 'bank', 2500, 'Vehicle sold')
    if not result.ok then print(('refused: %s'):format(result.error)) end
end)
```
</Tab>
</Tabs>

<Callout type="info">
Moving money between two accounts is one call and one transaction: [`money.transfer`](/docs/developers/api/lib-server/money#moneytransfer). A stored character's ledger is [`money.history`](/docs/developers/api/lib-server/money#moneyhistory) with `{ owner: "character", id, account }`.
</Callout>

### characters.setJob and characters.removeJob

Hires, regrades or fires a character, online or not. The panel's job rules apply, and the unemployed job is never stored: removing the last job is what makes a character unemployed.

**Side:** Server · **Waits:** yes

```ts title="Signature"
characters.setJob(charId: number, job: string, grade: number): Promise<CharacterResult>
characters.removeJob(charId: number, job: string): Promise<CharacterResult>
```

```lua title="Lua"
local result = aiLib.characters.setJob(charId, job, grade)
local result = aiLib.characters.removeJob(charId, job)
```

#### Parameters

<TypeTable
  type={{
    charId: { type: 'number', description: 'The character id.', required: true },
    job: { type: 'string', description: 'The job name as the panel (or a script definition) has it.', required: true },
    grade: { type: 'number', description: 'The grade in that job, from 0. A grade the job does not have is refused.', required: true },
  }}
/>

#### Returns

`{ ok: true }`, or `{ ok: false, error }`: unknown character, unknown job, unknown grade, or the panel's limit on how many jobs a character may hold.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { characters } from "@aifivem/lib/server";

/** Fire a member whether they are online or not. */
export async function fire(charId: number, job: string): Promise<boolean> {
  return (await characters.removeJob(charId, job)).ok;
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    print(aiLib.characters.removeJob(12, 'police').ok and 'fired' or 'refused')
end)
```
</Tab>
</Tabs>

<TypeTable
  type={{

### characters.save

Writes a connected player's position and metadata now and waits for their queued writes.

**Side:** Server · **Waits:** yes

```ts title="Signature"
characters.save(source: number): Promise<boolean>
```

```lua title="Lua"
local ok = aiLib.characters.save(source)
```

#### Returns

`true` once everything is written, `false` when the player has no loaded character. ai-core saves by itself (periodically, on unload, on shutdown): use this only when the write must have happened before your next step.
