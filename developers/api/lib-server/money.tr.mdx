```ts title="TypeScript"
import { money, banking, billing } from "@aifivem/lib/server";
```

`money`, sunucudaki her bakiyedir: yüklü bir oyuncunun hesapları, bir mesleğin ya da çetenin ortak hesabı, parayı tek transaction'da taşıyan bir transfer ve defter. **Bağlı olmayan** bir karakter [`characters`](/tr/docs/developers/api/lib-server/characters#charactersaddmoney-charactersremovemoney-and-characterssetmoney) ile yapılır. `banking` ve `billing`, sunucunun banka ve fatura script'leri için katmanlardır.

## money

### money.get

Yüklü bir oyuncunun tek bir hesaptaki bakiyesi.

**Taraf:** Server · **Bekler:** hayır

```ts title="İmza"
money.get(source: number, account: string): number | null
```

```lua title="Lua"
local balance = aiLib.money.get(source, account)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    account: { type: 'string', description: 'Paneldeki hesap adı (`cash`, `bank`...). Bkz. [Hesap adları](/tr/docs/developers/api/types#hesap-isimleri).', required: true },
  }}
/>

#### Dönüş değeri

`number | null`: bakiye ya da oyuncunun yüklü karakteri yoksa / hesap tipi yoksa `null`. Kayıtlı bir karakterin bakiyeleri [`characters.get`](/tr/docs/developers/api/lib-server/characters#charactersget) ile gelir.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money, notify } from "@aifivem/lib/server";

export function tellBalance(source: number): void {
  const bank = money.get(source, "bank");
  notify(source, bank === null ? "Karakter yok" : `Banka: $${bank}`, bank === null ? "error" : "inform");
}
```
</Tab>
<Tab value="Lua">
```lua
local bank = aiLib.money.get(source, 'bank')
aiLib.notify(source, bank and ('Banka: $%d'):format(bank) or 'Karakter yok', bank and 'inform' or 'error')
```
</Tab>
</Tabs>

### money.add, money.remove and money.set

Yüklü bir oyuncunun tek bir hesabını defter satırıyla değiştirir. Bir ödül, bir fiyat, script'inin ödediği bir maaş için çağrılar bunlardır.

**Taraf:** Server · **Bekler:** hayır

```ts title="İmza"
money.add(source: number, account: string, amount: number, reason?: string): boolean
money.remove(source: number, account: string, amount: number, reason?: string): boolean
money.set(source: number, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = aiLib.money.add(source, account, amount, reason)
local ok = aiLib.money.remove(source, account, amount, reason)
local ok = aiLib.money.set(source, account, amount, reason)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    account: { type: 'string', description: 'Paneldeki hesap adı.', required: true },
    amount: { type: 'number', description: 'Tam sayı dolar; `add` ve `remove` için 0’dan büyük. `set` yeni bakiyeyi alır (0 olabilir).', required: true },
    reason: { type: 'string', description: 'Defter satırında ne yazacağı (`"shop:tools"`).', default: 'çağıran resource adı' },
  }}
/>

#### Dönüş değeri

`boolean`: değişiklik yapıldıysa `true`. Oyuncunun yüklü karakteri yoksa, hesap yoksa, miktar 0’dan büyük tam sayı değilse ya da - `remove` için - bakiye ödemeye yetmiyorsa (hesap tipi sıfırın altına inemiyorsa) `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money, onClientCallback } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

onClientCallback("myshop:buyTools", { lock: true }, (source) => {
  if (!money.remove(source, "cash", 150, "shop:tools")) return fail("NOT_ENOUGH_CASH");
  // eşyayı burada ver
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myshop:buyTools', function(source)
    if not aiLib.money.remove(source, 'cash', 150, 'shop:tools') then return aiLib.fail('NOT_ENOUGH_CASH') end
    return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="warn">
Bir oyuncudan diğerine ödeme **bir `remove` artı bir `add` değildir**: ortada bir hata para yaratır ya da yok eder. Tek bir veritabanı transaction'ı olan [`money.transfer`](#moneytransfer) kullan.
</Callout>

### money.sharedGet

Bir mesleğin ya da çetenin hesabındaki bakiye - `bank`, diğer framework'lerin society parası dediği şeydir.

**Taraf:** Server · **Bekler:** hayır

```ts title="İmza"
money.sharedGet(type: "job" | "gang", id: string, account: string): number | null
```

```lua title="Lua"
local balance = aiLib.money.sharedGet(type, id, account)
```

#### Parametreler

<TypeTable
  type={{
    type: { type: '"job" | "gang"', description: 'Hesabın kime ait olduğu.', required: true },
    id: { type: 'string', description: 'Meslek ya da çete adı (`"mechanic"`).', required: true },
    account: { type: 'string', description: 'Hesap adı; `bank` society parasıdır.', required: true },
  }}
/>

#### Dönüş değeri

`number | null`: bakiye ya da o meslek / çetede böyle bir hesap yoksa `null` (bilinmeyen bir meslek ya da sunucuda olmayan bir hesap tipi).

### money.sharedAdd and money.sharedRemove

Bir mesleğin ya da çetenin hesabını defter satırıyla değiştirir - bir şirketin geliri ve gideri.

**Taraf:** Server · **Bekler:** hayır

```ts title="İmza"
money.sharedAdd(type: "job" | "gang", id: string, account: string, amount: number, reason?: string): boolean
money.sharedRemove(type: "job" | "gang", id: string, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = aiLib.money.sharedAdd(type, id, account, amount, reason)
local ok = aiLib.money.sharedRemove(type, id, account, amount, reason)
```

#### Dönüş değeri

`boolean`: değişiklik yapıldıysa `true`; bilinmeyen meslek ya da çete, olmayan hesap, hatalı miktar veya ödemeye yetmeyen hesap için `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money } from "@aifivem/lib/server";

/** Tamirci dükkânının kazandığı bir şehir sözleşmesi ve parçalar için ödediği ücret. */
export function contractDone(job: string, pay: number, parts: number): boolean {
  if (!money.sharedAdd("job", job, "bank", pay, "city contract")) return false;
  return money.sharedRemove("job", job, "bank", parts, "parts");
}
```
</Tab>
<Tab value="Lua">
```lua
local ok = aiLib.money.sharedAdd('job', 'mechanic', 'bank', 500, 'repair')
```
</Tab>
</Tabs>

### money.transfer

Parayı tek bir veritabanı transaction’ında, iki tarafta da bir defter satırıyla bir hesaptan diğerine taşır. Paranın yarı yolda ortaya çıkmaması ya da kaybolmaması gereken her şey için kullan: başka bir oyuncuya ödeme, bir mesleğin prim ödemesi, bir ücret.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
money.transfer(from: MoneyRef, to: MoneyRef, amount: number, reason?: string, fee?: number): boolean
```

```lua title="Lua"
local ok = aiLib.money.transfer(from, to, amount, reason, fee)
```

#### Parametreler

<TypeTable
  type={{
    from: { type: "MoneyRef", typeDescriptionLink: "/tr/docs/developers/api/types#moneyref", description: "Ödeyen hesap: bir oyuncunun `{ source, account }`’u (`account`: `cash`, `bank`...) ya da bir mesleğin / çetenin `{ owner: \"job\" | \"gang\", id, account }`’u.", required: true },
    to: { type: "MoneyRef", typeDescriptionLink: "/tr/docs/developers/api/types#moneyref", description: "Alan hesap, aynı biçimde.", required: true },
    amount: { type: "number", description: "`to`’nun ne kadar aldığı: 1 ya da daha büyük bir tam sayı.", required: true },
    reason: { type: "string", description: "İki defter satırına da yazılır (`rent:apartment_3`).", required: false },
    fee: { type: "number", description: "`from`’un ayrıca ödediği ek tam miktar. Ekonomiden çıkar (kimse almaz).", default: "0" },
  }}
/>

#### Dönüş değeri

`boolean`: iki satır da yazıldıysa `true`. Bir miktar tam sayı değilse, bir hesap yoksa, ikisi aynıysa ya da `from` `amount` artı `fee`’yi ödeyemiyorsa `false`.

#### Örnek

```ts
import { onClientCallback, money, nearestPlayerTo, notify } from "@aifivem/lib/server";
import { fail, oneArg, readInt } from "@aifivem/lib/shared";

onClientCallback("my-cash:give", { args: oneArg((v) => readInt(v, 1, 100_000)), lock: true }, (source, amount) => {
  const target = nearestPlayerTo(source, 2);
  if (target === null) return fail("NOBODY_NEAR");
  if (!money.transfer({ source, account: "cash" }, { source: target, account: "cash" }, amount, "give:cash"))
    return fail("NOT_ENOUGH_CASH");
  notify(target, `You received $${amount}`, "success");
  return { ok: true };
});
```

### money.history

Bir hesabın defter satırları, en yeni başta: ne hareket etti, sonraki bakiye, sebep, kim yaptı ve ne zaman. Bir oyuncunun hesabı, bir mesleğin / çetenin hesabı ve kayıtlı bir karakterin hesabı için çalışır.

**Taraf:** Server · **Bekler:** evet

```ts title="İmza"
money.history(account: LedgerRef, query?: LedgerQuery): Promise<LedgerPage>
```

```lua title="Lua"
local page = aiLib.money.history(account, query)
```

#### Parametreler

<TypeTable
  type={{
    account: { type: 'LedgerRef', typeDescriptionLink: '/tr/docs/developers/api/types#ledgerref', description: 'Kimin defteri: `{ source, account }`, `{ owner: "job" | "gang", id, account }` ya da `{ owner: "character", id, account }` ile kayıtlı bir karakter (`id`, karakter id’si metin olarak).', required: true },
    query: { type: 'LedgerQuery', typeDescriptionLink: '/tr/docs/developers/api/types#ledgerquery', description: 'Hangi satırlar: `before` (yeni okuduğun sayfanın `next` değeri), `since` (unix saniye), `limit` (1-200, varsayılan 50).' },
  }}
/>

#### Dönüş değeri

Bir [LedgerPage](/tr/docs/developers/api/types#ledgerpage): `rows` ve `before` olarak göndereceğin `next` (son sayfada `null`). ai-core bir satırı değişiklikten bir an sonra yazar, yani en yeni satır bakiyenin birkaç milisaniye gerisinde olabilir.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money } from "@aifivem/lib/server";

/** Kayıtlı bir karakterin son 20 banka satırı. */
export async function statement(charId: number) {
  const page = await money.history({ owner: "character", id: String(charId), account: "bank" }, { limit: 20 });
  return page.rows.map((r) => `${r.at}: ${r.amount} (${r.reason})`);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local page = aiLib.money.history({ source = source, account = 'bank' }, { limit = 20 })
    for _, row in ipairs(page.rows) do
        print(('%d: %d (%s)'):format(row.at, row.amount, row.reason))
    end
end)
```
</Tab>
</Tabs>

## banking

`banking`, ai-core’un bankacılık katmanı üzerinden banka script’iyle konuşur. Meslek parasının kendisi her zaman `money` ya da ai-core’un export’ları üzerinden hareket eder.

### banking.open

Banka script’inin ekranını bir oyuncu için açar.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
banking.open(source: number): boolean
```

```lua title="Lua"
local ok = aiLib.banking.open(source)
```

**Dönüş değeri**: açıldıysa `true`. Script dışarıdan açılamıyorsa ya da hiçbiri çalışmıyorsa `false`.

<Tabs items={['TypeScript', 'Lua']}>

aiLib.onClientCallback('my-atm:open', function(source)

</Tab>

**Dönüş değeri**: bakiye ya da hiçbiri çalışmıyorsa veya script bakiye tutmuyorsa `null` (Lua’da `nil`).

## billing

`billing`, faturaları hangi fatura script’i çalışıyorsa onun üzerinden gönderir; hiçbiri yoksa ai-core’un kendi faturaları kullanılır (oyuncu ekrandaki bir listeden öder, para o ödediğinde hareket eder). Metinler zaten çevrilmiş haldedir.

### billing.send

Bir meslekten (cezalar, hizmet ücretleri) ya da bir oyuncudan fatura gönderir.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
billing.send(bill: BillRequest): boolean
```

```lua title="Lua"
local ok = aiLib.billing.send(bill)
```

#### BillRequest

<TypeTable
  type={{
    to: { type: "number", description: "Faturayı alan oyuncunun server id’si. `to` ya da `toCitizenid` ver.", required: false },
    toCitizenid: { type: "string", description: "Faturayı alan karakter, citizen id ile, çevrimiçi ya da çevrimdışı. Çevrimdışı bir karakter faturayı yalnızca ai-core’un kendi faturalarından alır; bir fatura script’i oyuncunun çevrimiçi olmasını gerektirir.", required: false },
    amount: { type: "number", description: "Tam dolar.", required: true },
    label: { type: "string", description: "Neyin karşılığı olduğu (`Speeding`).", required: true },
    from: { type: "number", description: "Faturayı kesen oyuncunun (memur, tamirci) server id’si. `job` olmayan bir fatura bu oyuncuya ödenir.", required: false },
    job: { type: "string", description: "Ödemeyi hesabına alan meslek. Bu olmadan fatura kişiseldir ve `from` zorunludur.", required: false },
  }}
/>

#### Dönüş değeri

`boolean`: gönderildiyse `true`, geçersizse ya da reddedildiyse `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { billing, nearestPlayerTo, online } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

function fine(officer: number, amount: number) {
  if (!online.onDutyIn(officer, ["police"])) return fail("NOT_ON_DUTY");
  const target = nearestPlayerTo(officer, 3);
  if (target === null) return fail("NOBODY_NEAR");
  return billing.send({ to: target, amount, label: "Speeding", from: officer, job: "police" })
    ? { ok: true }
    : fail("BILL_FAILED");
}
```
</Tab>
<Tab value="Lua">
```lua
local function fine(officer, amount)
    if aiLib.online.dutyJob(officer) ~= 'police' then return aiLib.fail('NOT_ON_DUTY') end
    local target = aiLib.nearestPlayerTo(officer, 3.0)
    if not target then return aiLib.fail('NOBODY_NEAR') end
    if not aiLib.billing.send({ to = target, amount = amount, label = 'Speeding', from = officer, job = 'police' }) then
        return aiLib.fail('BILL_FAILED')
    end
    return { ok = true }
end
```
</Tab>
</Tabs>

### billing.unpaid

Oyuncunun açık faturaları.

**Taraf:** Server · **Bekler:** evet (TypeScript’te Promise, Lua’da thread’i yield eder)

```ts title="Signature"
billing.unpaid(source: number): Promise<UnpaidBill[] | null>
```

```lua title="Lua"
local bills = aiLib.billing.unpaid(source) -- table[] ya da nil, bir thread içinde çağır
```

**Dönüş değeri**: [`UnpaidBill[]`](/tr/docs/developers/api/types#unpaidbill) (`id`, `label`, hâlâ borçlu olunan `amount`, `sender`) ya da fatura script’i onları listeleyemiyorsa `null`.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const bills = await billing.unpaid(source);
const owed = bills?.reduce((sum, bill) => sum + bill.amount, 0) ?? 0;
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local bills = aiLib.billing.unpaid(source) or {}
    local owed = 0
    for _, bill in ipairs(bills) do owed = owed + bill.amount end
    print(owed)
end)
```
</Tab>
</Tabs>
