## phone

ai-core üzerinden oyuncunun telefonu: çalışan ilk telefon script’i (tgiann-phone, lb-phone...) cevap verir. Telefon script’i yoksa her çağrı `null` ya da `false` cevabını verir. `aiLib.phone` üzerindeki Lua karşılıkları aynı adlara ve argüman sırasına sahiptir.

### phone.number

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
phone.number(source: number): string | null
```

```lua title="Lua"
local number = aiLib.phone.number(source)
```

**Dönüş değeri**: oyuncunun telefon numarası ya da numarası yoksa veya hiçbir telefon script’i çalışmıyorsa `null` (Lua’da `nil`).

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const number = phone.number(source);
if (!number) return fail("NO_PHONE_NUMBER");
```
</Tab>
<Tab value="Lua">
```lua
local number = aiLib.phone.number(source)
if not number then return aiLib.fail('NO_PHONE_NUMBER') end
```
</Tab>
</Tabs>

### phone.sourceOf

Bir telefon numarasının sahibi olan çevrimiçi oyuncu.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
phone.sourceOf(number: string): number | null
```

```lua title="Lua"
local source = aiLib.phone.sourceOf(number)
```

**Dönüş değeri**: server id ya da çevrimiçi kimse o numaraya sahip değilse `null` (Lua’da `nil`).

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const owner = phone.sourceOf("555-0101");
if (owner !== null) notify(owner, "Your phone is ringing");
```
</Tab>
<Tab value="Lua">
```lua
local owner = aiLib.phone.sourceOf('555-0101')
if owner then aiLib.notify(owner, 'Your phone is ringing') end
```
</Tab>
</Tabs>

## appearance

Hangi kıyafet script’i çalışıyorsa (ai-appearance, tgiann-clothing) ai-core’un görünüm katmanı üzerinden karakterlerin kayıtlı görünümleri.

### appearance.get

Yüklü olsun ya da olmasın bir karakterin kayıtlı görünümü. Bir karakterin yerine duran bir ped’i (uyuyan bir beden, bir manken) giydirmek için kullan: sonucu değiştirmeden client’ın `appearance.apply` fonksiyonuna ver ([Lib: client](/tr/docs/developers/api/lib-client)).

**Taraf:** Server · **Bekler:** evet (TypeScript’te Promise, Lua’da thread’i yield eder)

```ts title="Signature"
appearance.get(charId: number): Promise<CharacterAppearance | null>
```

```lua title="Lua"
local look = aiLib.appearance.get(charId) -- { model, data } ya da nil, bir thread içinde çağır
```

<TypeTable
  type={{
    charId: { type: "number", description: "Karakter id’si (`CharacterInfo.id`).", required: true },
  }}
/>

#### Dönüş değeri

`Promise<CharacterAppearance | null>`: [`CharacterAppearance`](/tr/docs/developers/api/types#characterappearance), `{ model, data }`’dır (ped model hash’i ve kıyafet script’inin kendi görünüm verisi). Karakterin görünümü yoksa, hiçbir kıyafet script’i çalışmıyorsa ya da ai-core durmuşsa `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, online, playersNear } from "@aicore-fivem/lib/server";

async function sendLook(source: number) {
  const charId = online.charId(source);
  if (charId === undefined) return;
  const look = await appearance.get(charId);
  if (!look) return;
  // Görünüme yalnızca bu karakterin yakınındaki oyuncuların ihtiyacı var.
  for (const other of playersNear(source, 100)) emitNet("my-sleepers:look", other, source, look);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local character = aiLib.online.character(source)
    if not character then return end
    local look = aiLib.appearance.get(character.id)
    if look then TriggerClientEvent('my-sleepers:look', source, look) end
end)
```
</Tab>
</Tabs>

```ts title="Signature"
appearance.provider(): string | null
```

```lua title="Lua"
local name = aiLib.appearance.provider()
```
