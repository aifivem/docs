## world

Hora y clima a través de ai-core, sea cual sea el script de clima que funcione (Renewed-Weathersync, av_weather, cd_easytime, qb-weathersync). Mientras no haya ninguno en marcha, las lecturas responden `null` y los cambios responden `false`.

### world.getWeather

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
world.getWeather(): string | null
```

```lua title="Lua"
local weather = aiLib.world.getWeather()
```

**Devuelve** el tipo de clima actual tal como lo informa el script de clima (`CLEAR`, `RAIN`...), o `null` mientras no haya ninguno en marcha.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const raining = ["RAIN", "THUNDER"].includes(world.getWeather() ?? "");
```
</Tab>
<Tab value="Lua">
```lua
local weather = aiLib.world.getWeather()
local raining = weather == 'RAIN' or weather == 'THUNDER'
```
</Tab>
</Tabs>

### world.setWeather

Fija el clima.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
world.setWeather(type: Weather): boolean
```

```lua title="Lua"
local ok = aiLib.world.setWeather(weather)
```

<TypeTable
  type={{
    type: { type: "Weather", typeDescriptionLink: "/es/docs/developers/api/types#weather", description: "Uno de `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Comprueba antes con `isWeather` (`@aifivem/shared`) un valor que venga de un cliente o del panel.", required: true },
  }}
/>

**Devuelve** `true` cuando se fijó, `false` mientras no haya script de clima en marcha o el valor no sea un string.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, world } from "@aifivem/lib/server";
import { isWeather } from "@aifivem/shared";

addCommand("weather", { restricted: true, params: [{ name: "type", type: "string" }] }, (_source, { type }) => {
  const upper = type.toUpperCase();
  if (isWeather(upper)) world.setWeather(upper);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { restricted = true, params = { { name = 'type', type = 'string' } } }, function(_, args)
    aiLib.world.setWeather(args.type:upper())
end)
```
</Tab>
</Tabs>

## buckets

Routing buckets (mundos separados: el interior de un apartamento, una instancia) del asignador de ai-core, para que dos scripts nunca compartan uno. Nunca elijas los números de bucket tú mismo (`1000 + n`). Sin equivalente en Lua: llama a los exports de ai-core `AcquireBucket(tag)` / `ReleaseBucket(id)`.

### buckets.acquire

Toma un bucket libre para este recurso. No tiene población (ni peds ni coches ambientales) y tiene bloqueo estricto de entidades.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
buckets.acquire(tag: string): number
```

<TypeTable
  type={{
    tag: { type: "string", description: "Un nombre para los logs (`property:12`).", required: true },
  }}
/>

**Devuelve** el id del bucket.

```ts
import { buckets } from "@aifivem/lib/server";

const bucket = buckets.acquire(`property:${propertyId}`);
SetPlayerRoutingBucket(String(source), bucket);
```

### buckets.release

Devuelve un bucket una vez que sus jugadores han salido.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
buckets.release(id: number): boolean
```

**Devuelve** `true` cuando se liberó. Cada bucket de un recurso detenido se devuelve solo.

```ts
SetPlayerRoutingBucket(String(source), 0);
buckets.release(bucket);
```

## doors

Cerraduras de puertas a través de la capa de cerraduras de ai-core, por el id de puerta propio del script de cerraduras. Sin equivalente en Lua: llama a los exports de ai-core `SetDoorLocked`, `IsDoorLocked`.

### doors.setLocked

Cierra o abre una puerta.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
doors.setLocked(id: string, locked: boolean, by?: number): boolean
```

<TypeTable
  type={{
    id: { type: "string", description: "El id de puerta propio del script de cerraduras (el id de puerta en el panel de ai-doorlock).", required: true },
    locked: { type: "boolean", description: "`true` cierra, `false` abre.", required: true },
    by: { type: "number", description: "Id de servidor del jugador que actúa. Los scripts de puertas sin API de servidor lo necesitan.", required: false },
  }}
/>

**Devuelve** `true` cuando un script de puertas lo aceptó, `false` en caso contrario.

```ts
if (outcome === "won") doors.setLocked("bank_vault", false, source);
```

### doors.isLocked

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
doors.isLocked(id: string): boolean | null
```

**Devuelve** `true` o `false`, o `null` cuando se desconoce (sin script de cerraduras, sin esa puerta, o el script no puede saberlo en el servidor).

```ts
if (doors.isLocked("bank_vault") === false) return fail("ALREADY_OPEN");
```

### doors.provider

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
doors.provider(): string | null
```

**Devuelve** el script de cerraduras que responde, o `null` cuando no hay ninguno en marcha.

```ts
console.log(`doors through ${doors.provider() ?? "nothing"}`);
```

## characters

Personajes guardados a través de ai-core. Los personajes cargados pasan por `online` y los exports de jugador de ai-core.

### characters.setOfflinePosition

Mueve el punto de aparición de un personaje guardado (no cargado), por ejemplo un cuerpo dormido que alguien se llevó. ai-core lo escribe cuando ningún guardado de carga o descarga retiene al personaje.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
characters.setOfflinePosition(charId: number, position: { x: number; y: number; z: number; heading?: number }): boolean
```

Sin equivalente en Lua: llama al export de ai-core `SetOfflinePosition(charId, position)`.

<TypeTable
  type={{
    charId: { type: "number", description: "El id del personaje (`CharacterInfo.id`).", required: true },
    position: { type: "{ x: number; y: number; z: number; heading?: number }", description: "El nuevo punto de aparición; el heading en grados.", required: true },
  }}
/>

**Devuelve** `true` cuando se aceptó. `false` cuando el personaje está cargado o los valores son incorrectos.

```ts
characters.setOfflinePosition(sleeperCharId, { x: 340.2, y: -1396.7, z: 32.5, heading: 50 });
```
