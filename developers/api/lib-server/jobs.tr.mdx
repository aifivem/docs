```ts title="TypeScript"
import { dispatch, prison, mdt, ems, medical, stress, needs, definitions, isPrimeTime } from "@aicore-fivem/lib/server";
```

Buradaki her nesne ai-core’un katmanlarından biri üzerinden gider: sunucunun o iş için çalıştırdığı script (bir ihbar sistemi, bir hapishane, bir MDT, bir ölüm script’i, bir HUD) cevap verir. Sahip onu değiştirdiğinde script’in çalışmaya devam eder. Böyle bir script çalışmıyorken çağrılar sessizce başarısız olur (`false`, `0`, `null`).

## dispatch

### dispatch.alert

Bir polis (ya da başka bir meslek) ihbarı gönderir. İhbar sistemi onu `jobs`’un görevdeki üyelerine gösterir; varsayılan polis meslekleridir.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

<TypeTable
  type={{
    title: { type: "string", description: "Başlık, çevrilmiş (`Shots fired`).", required: true },
    code: { type: "string", description: "Başlıktan önce gösterilen telsiz kodu (`10-71`).", required: false },
    message: { type: "string", description: "Bir satır daha (marketin adı).", required: false },
    coords: { type: "{ x: number; y: number; z: number }", description: "Olayın yeri. Bu olmadan `source` oyuncusunun konumu; ikisi de yoksa haritada nokta olmaz.", required: false },
    jobs: { type: "string[]", description: "Görevdeki üyeleri ihbarı alan meslekler.", default: "ihbar sisteminin polis meslekleri" },
    source: { type: "number", description: "İhbarın konusu olan oyuncu (ateş eden, soyguncu). Şüpheliyi tarif eden sistemler (araç, cinsiyet) bu oyuncuyu okur.", required: false },
    blip: { type: "{ sprite: number; color?: number; scale?: number }", description: "Harita blip’i: bir GTA blip sprite’ı ve rengi.", default: "ihbar sisteminin kendi değeri" },
    duration: { type: "number", description: "İhbarın kaldığı saniye (kart, blip, waypoint tuşu).", default: "ihbar sisteminin kendi değeri" },
    icon: { type: "string", description: "`fa-` olmadan Font Awesome solid ikon adı (`gun`).", required: false },
    priority: { type: '"normal" | "high"', description: "`high` kartı öne çıkarır (silahlı soygun, yaralı memur).", default: '"normal"' },
  }}
/>

Tipi [`DispatchAlert`](/tr/docs/developers/api/types#dispatchalert)’tir.

#### Dönüş değeri

`boolean`: gönderildiyse `true`. Hiçbir ihbar sistemi çalışmıyorsa ya da ihbar geçersizse `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, coordsOf, createLocale } from "@aicore-fivem/lib/server";

const Locale = createLocale();

function storeRobbed(source: number, store: string) {
  dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

local function storeRobbed(source, store)
    local c = GetEntityCoords(GetPlayerPed(source))
    aiLib.dispatch.alert({
        code = '10-90',
        title = Locale('ALERT_STORE_ROBBERY'),
        message = store,
        coords = { x = c.x, y = c.y, z = c.z },
        source = source,
        icon = 'store',
        priority = 'high',
    })
end
```
</Tab>
</Tabs>


## mdt

**Taraf:** Server · **Bekler:** hayır


```lua title="Lua"
local ok = aiLib.mdt.record(record)
```

#### MdtRecord

## ems

ai-core’un EMS katmanı üzerinden sağlıkçılar: bir EMS script’inin kendi sayımı ve yardım çağrıları, yoksa ai-core’un görev sayımları ve ihbarları.

### ems.available

Bir çağrıyı almaya müsait kaç sağlıkçı olduğu.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
ems.available(jobs: string[]): number
```

```lua title="Lua"
local count = aiLib.ems.available(jobs)
```

<TypeTable
  type={{
    jobs: { type: "string[]", description: "Sayılacak EMS meslek adları (`[\"ambulance\"]`).", required: true },
  }}
/>

**Dönüş değeri**: `jobs` içinde görevdeki sağlıkçı sayısı; bir dispatch script’i meşgul olanları biliyorsa onlar dışarıda bırakılır.

## medical

Hangi ölüm ya da ambulans script’i çalışıyorsa ai-core’un medical katmanı üzerinden canlandırma, iyileştirme ve yerde olma durumu. Lua karşılığı yok: ai-core’un `RevivePlayer`, `HealPlayer`, `IsPlayerDead` export’larını çağır.

### medical.revive

Yerdeki bir oyuncuyu yattığı yerde ayağa kaldırır.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
medical.revive(source: number): boolean
```

**Dönüş değeri**: canlandırıldıysa `true`; yerde değilse ya da hiçbir ölüm script’i çalışmıyorsa `false`.

```ts
if (!medical.revive(target)) return fail("NOT_DOWN");
```

### medical.heal

Yerde olmayan bir oyuncuya tam can verir.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
medical.heal(source: number): boolean
```

**Dönüş değeri**: iyileştirildiyse `true`, hiçbir ölüm script’i çalışmıyorsa `false`.

```ts
medical.heal(source);
```

### medical.isDead

Oyuncunun yerde olup olmadığı.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
medical.isDead(source: number): boolean
```

**Dönüş değeri**: yerdeyse `true`; ölüm script’i yoksa `false`. Ped’in canını okumak yerine bunu kullan.

```ts
if (medical.isDead(source)) return fail("YOU_ARE_DOWN");
```

### medical.provider

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
medical.provider(): string | null
```

**Dönüş değeri**: cevap veren ölüm script’i (`ai-death`...) ya da hiçbiri çalışmıyorsa `null`.

```ts
console.log(`deaths through ${medical.provider() ?? "nothing"}`);
```

## needs

### needs.refill

Açlığı ve susuzluğu, onları tutan HUD üzerinden ya da HUD yoksa ai-core’un karakter metadata’sı üzerinden tamamen doldurur (admin canlandırması, hastane).

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
needs.refill(source: number): boolean
```

Lua karşılığı yok: ai-core’un `RefillNeeds(source)` export’unu çağır.

```ts
if (medical.revive(target)) needs.refill(target);
```

## Meslek ve çete tanımları

### definitions.job

ai-core’un panelinde ayarlandığı haliyle bir mesleğin tanımı. Her biri ai-core’dan bir kez okunur ve panel onu değiştirene kadar tutulur; bu yüzden bir okuma bellekten bakmaktır.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
definitions.job(name: string): JobDefinition | null
```

Lua karşılığı yok: ai-core’un `GetJobDefinition(name)` export’unu çağır.

**Dönüş değeri**: [`JobDefinition`](/tr/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`) ya da böyle bir meslek yoksa `null`.

```ts
const label = definitions.job("police")?.label ?? "police";
```

### definitions.gang

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
definitions.gang(name: string): GangDefinition | null
```

Lua karşılığı yok: ai-core’un `GetGangDefinition(name)` export’unu çağır.

**Dönüş değeri**: [`GangDefinition`](/tr/docs/developers/api/types#gangdefinition) (`label`, `grades`) ya da `null`.

```ts
const gang = definitions.gang("ballas");
if (!gang) return fail("UNKNOWN_GANG");
```

## Prime time

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
isPrimeTime(job?: string): boolean
```

Lua karşılığı yok: ai-core’un `IsPrimeTime(job)` export’unu çağır.

<TypeTable
  type={{
    job: { type: "string", description: "Prime time’ı kontrol edilecek meslek. Bu olmadan varsayılan saatler.", required: false },
  }}
/>

**Dönüş değeri**: prime time sırasında `true`.

```ts
if (!isPrimeTime("police")) return fail("BANK_CLOSED_FOR_HEISTS");
```
