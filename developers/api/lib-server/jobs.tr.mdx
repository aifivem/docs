`jobs` ve `definitions` ai-core'un kendisidir: bir karakterin meslekleri ve çeteleri ile sunucunun meslek tanımları. Buradaki geri kalan her şey ai-core'un katmanlarından biri üzerinden gider; o işi sunucuda hangi script yapıyorsa (bir ihbar sistemi, bir hapishane, bir MDT, bir ölüm script'i, bir HUD) o cevap verir. Sahibi onu değiştirdiğinde script'in çalışmaya devam eder. Böyle bir script çalışmıyorken o çağrılar sessizce başarısız olur (`false`, `0`, `null`).

## jobs

`jobs`, yüklü bir oyuncunun ai-core üzerinden kendi meslekleri ve çeteleridir: bir karakter birkaç meslek tutabilir, en çok birinde görevdedir ve bir seferde bir çete adına hareket eder. **Çok** oyuncuyu birden okumak lib'in aynasıdır ([`online`](/tr/docs/developers/api/lib-server/players#onlinejobs)); **bağlı olmayan** bir karakteri değiştirmek [`characters`](/tr/docs/developers/api/lib-server/characters#characterssetjob-and-charactersremovejob) ile olur.

### jobs.current

Diğer script'lerin bir oyuncunun "mesleği" olarak gördüğü meslek: görevde olduğu meslek, yoksa en son görevde olduğu, yoksa tuttuğu ilk meslek, yoksa işsizlik mesleği.

**Taraf:** Server · **Bekler:** hayır

```ts title="İmza"
jobs.current(source: number): JobMembership | null
```

```lua title="Lua"
local current = aiLib.jobs.current(source)
```

#### Dönüş değeri

Bir [JobMembership](/tr/docs/developers/api/types#jobmembership) (`{ job, grade }`) ya da oyuncunun yüklü karakteri yoksa `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs } from "@aifivem/lib/server";

export function isOfficer(source: number): boolean {
  return jobs.current(source)?.job === "police";
}
```
</Tab>
<Tab value="Lua">
```lua
local current = aiLib.jobs.current(source)
local officer = current and current.job == 'police'
```
</Tab>
</Tabs>

**Taraf:** Server · **Bekler:** hayır

### jobs.duty and jobs.setDuty

Oyuncunun hangi meslekte görevde olduğu ve göreve girip çıkması. Çok script üyelik yerine görev durumunu kontrol eder: görevde olmayan bir polis sivildir.

**Taraf:** Server · **Bekler:** hayır

```ts title="İmza"
jobs.duty(source: number): string | null
jobs.setDuty(source: number, job: string | null): boolean
```

```lua title="Lua"
local onDutyIn = aiLib.jobs.duty(source)
local ok = aiLib.jobs.setDuty(source, job)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    job: { type: 'string | null', description: 'Oyuncunun tuttuğu bir meslek; o meslekte göreve girmek için. `null` (Lua’da `nil`) görevden çıkarır.', required: true },
  }}
/>

#### Dönüş değeri

`jobs.duty`: meslek adı ya da görevde değilse (veya karakter yoksa) `null`. `jobs.setDuty`: değişiklik yapıldıysa `true`, oyuncunun tutmadığı bir meslek için `false`.

### jobs.set

Oyuncuya bir meslek ekler ya da tuttuğu bir mesleğin derecesini değiştirir. Panelin kuralları geçerlidir: bir karakterin kaç meslek tutabileceği ve ikinci bir mesleğe hiç izin verilip verilmediği.

**Taraf:** Server · **Bekler:** hayır

```ts title="İmza"
jobs.set(source: number, job: string, grade: number): boolean
```

```lua title="Lua"
local ok = aiLib.jobs.set(source, job, grade)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    job: { type: 'string', description: 'Panelde (ya da bir script tanımında) olduğu gibi meslek adı.', required: true },
    grade: { type: 'number', description: 'O meslekteki derece, 0’dan başlar. Mesleğin sahip olmadığı derece reddedilir.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: sonrasında oyuncu o mesleği o derecede tutuyorsa `true`. Yüklü karakter yoksa, meslek bilinmiyorsa, derece yoksa ya da panelin meslek sınırı aşılıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs, notify } from "@aifivem/lib/server";

export function hire(source: number, job: string): void {
  if (!jobs.set(source, job, 0)) return notify(source, "İşe alınamadı", "error");
  notify(source, `${job} ekibine hoş geldin`, "success");
}
```
</Tab>
<Tab value="Lua">
```lua
if aiLib.jobs.set(source, 'mechanic', 0) then
    aiLib.notify(source, 'mechanic ekibine hoş geldin', 'success')
end
```
</Tab>
</Tabs>

## dispatch

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"

```

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

    code: { type: "string", description: "Başlıktan önce gösterilen telsiz kodu (`10-71`).", required: false },
    message: { type: "string", description: "Bir satır daha (marketin adı).", required: false },

`boolean`: gönderildiyse `true`. Hiçbir ihbar sistemi çalışmıyorsa ya da ihbar geçersizse `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>

const Locale = createLocale();

function storeRobbed(source: number, store: string) {
  dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```

<Tab value="Lua">

local Locale = aiLib.locale()

local function storeRobbed(source, store)
    local c = GetEntityCoords(GetPlayerPed(source))
    aiLib.dispatch.alert({
        code = '10-90',
        title = Locale('ALERT_STORE_ROBBERY'),
        message = store,
        coords = { x = c.x, y = c.y, z = c.z },
        source = source,
        icon = 'store',
        priority = 'high',
    })
end
```
</Tab>
</Tabs>

### definitions.registerJob and definitions.removeJob

Sahibinin panele eklemesine gerek kalmadan script'inin getirdiği bir meslek: çağıran resource'a ait olur, resource durduğunda gider ve panelin dosyasına asla yazılmaz.

**Taraf:** Server · **Bekler:** hayır

```ts title="İmza"
definitions.registerJob(name: string, definition: JobDefinition): CharacterResult
definitions.removeJob(name: string): boolean
```

```lua title="Lua"
local result = aiLib.definitions.registerJob(name, definition)
local ok = aiLib.definitions.removeJob(name)
```

#### Parametreler

<TypeTable
  type={{
    name: { type: 'string', description: 'Script’inin kullandığı meslek adı (`"my-garbagejob"`).', required: true },
    definition: { type: 'JobDefinition', typeDescriptionLink: '/tr/docs/developers/api/types#jobdefinition', description: 'Mesleğin kendisi: `label`, `type`, `defaultDuty`, `listed` ve `grades` (her biri `label`, `salary`, `boss` ile).', required: true },
  }}
/>

#### Dönüş değeri

`registerJob` [ActionResult](/tr/docs/developers/api/types#actionresult) döner: `{ ok: true }` ya da panelde o adda bir meslek varsa / başka bir resource onu kaydettiyse bir dil anahtarıyla `{ ok: false, error }` - sunucu sahibinin paneli her zaman kazanır. `removeJob` yalnızca bu resource'un kaydettiği bir meslek için `true` döner.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { definitions } from "@aifivem/lib/server";

// Başlangıçta bir kez: meslek bu resource çalıştığı sürece var olur.
const result = definitions.registerJob("garbage", {
  label: "Garbage",
  type: "job",
  defaultDuty: true,
  grades: [{ label: "Driver", salary: 60, boss: false }],
});
if (!result.ok) console.log(`meslek kaydedilmedi: ${result.error}`);
```
</Tab>
<Tab value="Lua">
```lua
local result = aiLib.definitions.registerJob('garbage', {
    label = 'Garbage',
    type = 'job',
    defaultDuty = true,
    grades = { { label = 'Driver', salary = 60, boss = false } },
})
if not result.ok then print(('meslek kaydedilmedi: %s'):format(result.error)) end
```
</Tab>
</Tabs>

<Callout type="info">
Sunucu sahibinin düzenleyebilmesi gereken bir meslek buraya değil panele aittir. Meslek script'inin bir parçasıysa ve onsuz bir anlamı yoksa burada kaydet.
</Callout>
