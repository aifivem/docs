```ts title="TypeScript"
import { aiLog, aiLogChannels } from "@aifivem/lib/server";
```

Seu script nunca publica no Discord nem em um serviço de logs por conta própria. Ele envia um log ao ai-core em um **canal** (um nome como `purchase`); o dono do servidor decide no painel de administração do ai-core para onde cada canal vai. URLs de webhook e chaves de API ficam no painel, nunca no seu código.

### aiLog

Envia uma linha de log pelo sistema de logs do ai-core.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
aiLog(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
aiLib.aiLog(channel, message, options)
```

#### Parâmetros

<TypeTable
  type={{
    channel: { type: "string", description: "O nome do canal (`purchase`, `admin`). Descreva seus canais uma vez com `aiLogChannels`.", required: true },
    message: { type: "string", description: "O que aconteceu. Passe os jogadores como `source` / `target` em vez de escrever nomes no texto.", required: true },
    options: { type: "LogOptions", typeDescriptionLink: "/pt/docs/developers/api/types#logoptions", description: "Nível, jogadores e valores extras. Campos abaixo.", required: false },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: "Gravidade.", required: false },
    source: { type: "number", description: "Id de servidor do jogador que fez a ação. O nome, o personagem e os identificadores dele são adicionados.", required: false },
    target: { type: "number", description: "Id de servidor do jogador que sofreu a ação.", required: false },
    metadata: { type: "Record<string, unknown>", description: "Campos extras (valores, nomes de itens, coordenadas).", required: false },
  }}
/>

#### Retorno

`void`. Em TypeScript não faz nada enquanto o ai-core não está rodando; o equivalente em Lua imprime `[channel] message` no console em vez disso.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { aiLog } from "@aifivem/lib/server";

aiLog("purchase", `bought ${count}x ${item} for $${price}`, {
  source,
  metadata: { item, count, price },
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.aiLog('purchase', ('bought %dx %s for $%d'):format(count, item, price), {
    source = source,
    metadata = { item = item, count = count, price = price },
})
```
</Tab>
</Tabs>

### aiLogChannels

Descreve os canais de log do seu recurso: o nome do dataset usado pelo Fivemanage e pelo FiveM Stats, e se um canal está ativo. Chame uma vez quando o script iniciar.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
aiLogChannels(channels: Record<string, LogChannel>): void
```

Sem equivalente em Lua: chame o export do ai-core `exports['ai-core']:LogChannels(channels)`.

#### Parâmetros

<TypeTable
  type={{
    channels: { type: "Record<string, LogChannel>", typeDescriptionLink: "/pt/docs/developers/api/types#logchannel", description: "Uma entrada por nome de canal. Cada `LogChannel` tem `dataset?` (dataset do Fivemanage / FiveM Stats, por padrão o nome do recurso) e `active?` (`false` desativa o canal).", required: true },
  }}
/>

#### Retorno

`void`. Não faz nada enquanto o ai-core não está rodando.

#### Exemplo

```ts
import { aiLogChannels } from "@aifivem/lib/server";

aiLogChannels({
  purchase: { dataset: "shops" },
  debug: { active: false },
});
```
