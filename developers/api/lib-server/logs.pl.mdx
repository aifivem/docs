```ts title="TypeScript"
import { aiLog, aiLogChannels } from "@aicore-fivem/lib/server";
```

Twój skrypt nigdy sam nie publikuje na Discordzie ani w usłudze logów. Wysyła log do ai-core na **kanale** (nazwa jak `purchase`); właściciel serwera decyduje w panelu administratora ai-core, dokąd trafia każdy kanał. Adresy webhooków i klucze API zostają w panelu, nigdy w twoim kodzie.

### aiLog

Wysyła jedną linię logu przez system logów ai-core.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
aiLog(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
aiLib.aiLog(channel, message, options)
```

#### Parametry

<TypeTable
  type={{
    channel: { type: "string", description: "Nazwa kanału (`purchase`, `admin`). Opisz swoje kanały raz przez `aiLogChannels`.", required: true },
    message: { type: "string", description: "Co się stało. Podawaj graczy jako `source` / `target` zamiast wpisywać nazwy do tekstu.", required: true },
    options: { type: "LogOptions", typeDescriptionLink: "/pl/docs/developers/api/types#logoptions", description: "Poziom, gracze i dodatkowe wartości. Pola poniżej.", required: false },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: "Ważność.", required: false },
    source: { type: "number", description: "Id serwerowe gracza, który to zrobił. Dodawane są jego nazwa, postać i identyfikatory.", required: false },
    target: { type: "number", description: "Id serwerowe gracza, któremu to zrobiono.", required: false },
    metadata: { type: "Record<string, unknown>", description: "Dodatkowe pola (kwoty, nazwy przedmiotów, współrzędne).", required: false },
  }}
/>

#### Zwracana wartość

`void`. W TypeScript nic nie robi, dopóki ai-core nie działa; odpowiednik w Lua wypisuje wtedy `[channel] message` w konsoli.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { aiLog } from "@aicore-fivem/lib/server";

aiLog("purchase", `bought ${count}x ${item} for $${price}`, {
  source,
  metadata: { item, count, price },
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.aiLog('purchase', ('bought %dx %s for $%d'):format(count, item, price), {
    source = source,
    metadata = { item = item, count = count, price = price },
})
```
</Tab>
</Tabs>

### aiLogChannels

Opisuje kanały logów twojego zasobu: nazwę zbioru danych używaną przez Fivemanage i FiveM Stats oraz czy kanał jest włączony. Wywołaj ją raz, gdy twój skrypt startuje.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
aiLogChannels(channels: Record<string, LogChannel>): void
```

Brak odpowiednika w Lua: wywołaj eksport ai-core `exports['ai-core']:LogChannels(channels)`.

#### Parametry

<TypeTable
  type={{
    channels: { type: "Record<string, LogChannel>", typeDescriptionLink: "/pl/docs/developers/api/types#logchannel", description: "Jeden wpis na nazwę kanału. Każdy `LogChannel` ma `dataset?` (zbiór danych Fivemanage / FiveM Stats, domyślnie nazwa zasobu) i `active?` (`false` wyłącza kanał).", required: true },
  }}
/>

#### Zwracana wartość

`void`. Nic nie robi, dopóki ai-core nie działa.

#### Przykład

```ts
import { aiLogChannels } from "@aicore-fivem/lib/server";

aiLogChannels({
  purchase: { dataset: "shops" },
  debug: { active: false },
});
```
