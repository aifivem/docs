## Spawn

### spawnVehicle

Cria um veículo em rede no servidor e o configura em uma chamada: placa, combustível, visual, tranca, routing bucket, chaves para o propósito certo, um motorista e passageiros. Use para todo veículo de script (veículos de emprego, aluguéis, veículos de garagem, spawns de admin).

**Lado:** Servidor · **Espera:** sim (Promise em TypeScript, pausa a thread em Lua)

```ts title="Signature"
spawnVehicle(options: SpawnVehicleOptions): Promise<number | null>
```

```lua title="Lua"
local vehicle = aiLib.spawnVehicle(options) -- entidade ou nil, chame dentro de uma thread
```

  }}

    bags: { type: "Record<string, unknown>", description: "Valores de state bag replicados definidos logo depois da criação.", required: false },
  }}
/>

#### Retorno

`Promise<number | null>`: o handle da entidade do veículo. `null` quando o modelo não existe (o cliente `asker` disse isso), a entidade não foi criada em 5 segundos ou o tipo é desconhecido.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, spawnVehicle, hasCharacter, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const DEPOT = { x: 895.4, y: -179.3, z: 74.7 };

onClientCallback(
  "my-taxi:start",
  async (source) => {
    const vehicle = await spawnVehicle({
      model: "taxi",
      coords: { x: 899.1, y: -180.6, z: 73.8, heading: 238 },
      asker: source,
      keysTo: source,
      purpose: "job",
      driver: source,
      fuel: 100,
      setup: { dirt: 0 },
    });
    if (!vehicle) return fail("SPAWN_FAILED");
    return { ok: true, netId: NetworkGetNetworkIdFromEntity(vehicle) };
  },
  { guards: [hasCharacter(), near(DEPOT, 5)], lock: true },
);
```
</Tab>
<Tab value="Lua">
```lua
local DEPOT = vector3(895.4, -179.3, 74.7)

aiLib.onClientCallback('my-taxi:start', function(source)
    if #(GetEntityCoords(GetPlayerPed(source)) - DEPOT) > 5.0 then return aiLib.fail('TOO_FAR') end
    local vehicle = aiLib.spawnVehicle({
        model = 'taxi',
        coords = vector4(899.1, -180.6, 73.8, 238.0),
        asker = source,
        keysTo = source,
        purpose = 'job',
        driver = source,
        fuel = 100,
    })
    if not vehicle then return aiLib.fail('SPAWN_FAILED') end
    return { ok = true, netId = NetworkGetNetworkIdFromEntity(vehicle) }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
As chaves esperam (até 3 segundos) até o servidor ler a placa: antes da primeira sincronização do cliente dono, o servidor lê uma placa vazia. Os jogadores colocados nos bancos são colocados de novo por até 2 segundos até sentarem. Em TypeScript, o tipo de um modelo vindo de um cliente serve só para aquele jogador até o cliente de um segundo jogador dar a mesma resposta; o equivalente em Lua guarda a primeira resposta que recebe.
</Callout>

### vehicleType

O tipo de spawn de um modelo, perguntado ao cliente de um jogador. Use para verificar se um modelo existe antes de cobrar o dinheiro.

**Lado:** Servidor · **Espera:** sim (Promise)

```ts title="Signature"
vehicleType(model: string, asker: number): Promise<string | null>
```

Sem equivalente em Lua: `aiLib.spawnVehicle` com `asker` faz essa verificação e retorna `nil` para um modelo desconhecido.

<TypeTable
  type={{
    model: { type: "string", description: "Nome de spawn do modelo.", required: true },
    asker: { type: "number", description: "Id de servidor do jogador cujo cliente responde.", required: true },
  }}
/>

#### Retorno

`Promise<string | null>`: `automobile`, `bike`, `boat`, `heli`, `plane`, `submarine`, `trailer` ou `train`; `null` quando o jogo não tem esse veículo ou o cliente não deu uma resposta válida. Uma resposta passa a valer para todos assim que os clientes de dois jogadores diferentes concordaram com ela, então um cliente modificado só consegue quebrar os próprios spawns.

#### Exemplo

```ts
import { onClientCallback, vehicleType } from "@aicore-fivem/lib/server";
import { fail, oneArg, readText } from "@aicore-fivem/lib/shared";

onClientCallback("my-dealer:buy", { args: oneArg((v) => readText(v, 32)), lock: true }, async (source, model) => {
  if (!(await vehicleType(model, source))) return fail("UNKNOWN_MODEL");
  // cobra o dinheiro, depois spawnVehicle(...)
  return { ok: true };
});
```

### randomPlate

Uma placa aleatória como as do próprio jogo (dois dígitos, três letras, três dígitos), ou o seu prefixo seguido de dígitos.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
randomPlate(prefix?: string): string
```

Sem equivalente em Lua (`aiLib.spawnVehicle` define uma placa aleatória quando você não passa nenhuma).

<TypeTable
  type={{
    prefix: { type: "string", description: "Texto com que a placa começa; o resto é preenchido com dígitos até 8 caracteres. Mais de 8 é cortado.", required: false },
  }}
/>

**Retorno** uma placa de 8 caracteres (`42ABC123`, ou `TAXI1234` para `randomPlate("TAXI")`). Ela não é verificada quanto à unicidade: verifique a sua própria tabela antes de guardá-la.

```ts
const plate = randomPlate("RENT");
```

## Encontrando veículos

### nearestVehicleTo

O veículo mais próximo, a até `metres` de um jogador, que passa no seu filtro. O veículo em que o jogador está sentado vence primeiro.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
nearestVehicleTo(source: number, metres: number, filter?: (vehicle: number) => boolean): number
```

```lua title="Lua"
local vehicle = aiLib.nearestVehicleTo(source, metres, filter) -- entidade ou 0
```

<TypeTable
  type={{
    source: { type: "number", description: "Id de servidor do jogador.", required: true },
    metres: { type: "number", description: "Raio de busca em metros.", required: true },
    filter: { type: "(vehicle: number) => boolean", description: "Pula os veículos para os quais ele responde `false` (portas trancadas, um modelo).", required: false },
  }}
/>

**Retorno** a entidade do veículo, ou `0` quando não há nenhum.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const vehicle = nearestVehicleTo(source, 5);
if (!vehicle) return fail("NO_VEHICLE");
```
</Tab>
<Tab value="Lua">
```lua
local vehicle = aiLib.nearestVehicleTo(source, 5.0)
if vehicle == 0 then return aiLib.fail('NO_VEHICLE') end
```
</Tab>
</Tabs>

<Callout type="warn">
Ele percorre todos os veículos do servidor: use para comandos e ações (com limite de taxa), nunca em um tick.
</Callout>

### nearestVehicleAt

O veículo mais próximo a até `metres` de um ponto. Use para verificar se um local de spawn está livre.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
nearestVehicleAt(point: { x: number; y: number; z: number }, metres: number, filter?: (vehicle: number) => boolean): number
```

Sem equivalente em Lua.

**Retorno** a entidade do veículo, ou `0` quando não há nenhum. Percorre todos os veículos, como `nearestVehicleTo`.

```ts
const SPOT = { x: 899.1, y: -180.6, z: 73.8 };
if (nearestVehicleAt(SPOT, 3)) return fail("SPOT_BLOCKED");
```

## Entidades a partir da entrada do cliente

Um cliente envia um network id, nunca um handle de entidade. Estes helpers transformam um net id na entidade viva do servidor e a verificam, então você nunca chama `NetworkGetEntityFromNetworkId` + `DoesEntityExist` + `GetEntityType` à mão.

### entityFromNet

A entidade viva por trás do network id de um cliente.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
entityFromNet(netId: unknown, type?: 1 | 2 | 3): number
```

Sem equivalente em Lua (Lua tem `vehicleFromNet`).

<TypeTable
  type={{
    netId: { type: "unknown", description: "O valor bruto vindo do cliente.", required: true },
    type: { type: "1 | 2 | 3", description: "Tipo de entidade exigido: 1 ped, 2 veículo, 3 objeto. Qualquer tipo quando omitido.", required: false },
  }}
/>

**Retorno** a entidade, ou `0` quando o valor não é um número inteiro positivo, não está em rede, sumiu ou é de outro tipo.

```ts
const prop = entityFromNet(rawNetId, 3);
if (!prop) return fail("NOT_FOUND");
```

### pedFromNet

`entityFromNet(netId, 1)`: o ped vivo, ou `0`.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
pedFromNet(netId: unknown): number
```

```ts
const ped = pedFromNet(rawNetId);
```

### vehicleNearPlayer

O veículo por trás do network id de um cliente, mas só quando o jogador está perto dele (ou no banco do motorista).

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
vehicleNearPlayer(source: number, netId: unknown, options?: { metres?: number; driver?: boolean }): number
```

```lua title="Lua"
local vehicle = aiLib.vehicleNearPlayer(source, netId, options) -- entidade ou 0
```

<TypeTable
  type={{

## Combustível

`fuel` lê e define o combustível de um veículo (0 a 100) pela camada de combustível do ai-core, qualquer que seja o script de combustível rodando. Sem equivalente em Lua no servidor: chame os exports do ai-core `GetVehicleFuel` / `SetVehicleFuel`.

### fuel.get

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
fuel.get(vehicle: number): number | null
```

**Retorno** o nível de uma entidade de veículo do servidor (0 a 100), ou `null` quando ela não tem.

```ts
const level = fuel.get(vehicle) ?? 0;
```

### fuel.set

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
fuel.set(vehicle: number, level: number): boolean
```

<TypeTable
  type={{
    vehicle: { type: "number", description: "Entidade de veículo do servidor.", required: true },
    level: { type: "number", description: "Novo nível, limitado a 0-100.", required: true },
  }}
/>

**Retorno** `true` quando definido, `false` para um veículo errado.

```ts
fuel.set(vehicle, 100);
```

### fuel.provider

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
fuel.provider(): string | null
```

**Retorno** o nome do recurso do script de combustível que responde (`ai-fuel`, `ox_fuel`, `LegacyFuel`...), ou `null` quando nenhum está rodando.

```ts
console.log(`fuel through ${fuel.provider() ?? "nothing"}`);
```

## Garagens

`garages` passa pela camada de garagens do ai-core, qualquer que seja o script de garagem rodando; cada script responde só o que expõe. Sem equivalente em Lua.

### garages.impound

Manda um veículo para o pátio de apreensão, ou abre o formulário de apreensão do script de garagem para `by`.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
garages.impound(vehicle: number, by?: number): boolean
```

<TypeTable
  type={{
    vehicle: { type: "number", description: "Entidade de veículo do servidor.", required: true },
    by: { type: "number", description: "Id de servidor do jogador que faz a apreensão (scripts com formulário o abrem para este jogador).", required: false },
  }}
/>

**Retorno** `true` quando o script de garagem o aceitou. `false` quando nada o aceitou: apague o veículo você mesmo.

```ts
if (!garages.impound(vehicle, source)) DeleteEntity(vehicle);
```

### garages.store

Guarda um veículo em uma garagem.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
garages.store(vehicle: number, garage?: string | null, by?: number): boolean
```

<TypeTable
  type={{
    vehicle: { type: "number", description: "Entidade de veículo do servidor.", required: true },
    garage: { type: "string | null", description: "O id de garagem do próprio script de garagem.", default: "null" },
    by: { type: "number", description: "Id de servidor do jogador que o guarda.", required: false },
  }}
/>

**Retorno** `true` quando guardado, `false` quando nada o aceitou.

```ts
if (!garages.store(vehicle, "legion", source)) return fail("STORE_FAILED");
```

### garages.open

Abre o menu de garagem do script de garagem para um jogador.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
garages.open(source: number, garage?: string | null): boolean
```

**Retorno** `true` quando aberto, `false` quando o script não tem esse menu.

```ts
garages.open(source, "pillbox");
```

### garages.stored

Os veículos de um jogador nas garagens ou no pátio de apreensão.

**Lado:** Servidor · **Espera:** sim (Promise)

```ts title="Signature"
garages.stored(source: number): Promise<GaragedVehicle[] | null>
```

**Retorno** [`GaragedVehicle[]`](/pt/docs/developers/api/types#garagedvehicle) (`plate`, `model`, `garage`, `impounded`), ou `null` quando o script não consegue informar ou o ai-core está parado.

```ts
const list = await garages.stored(source);
const impounded = list?.filter((v) => v.impounded).length ?? 0;
```

### garages.provider

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
garages.provider(): string | null
```

**Retorno** o script de garagem que responde, ou `null` quando nenhum está rodando.

```ts
if (!garages.provider()) console.warn("no garage script runs");
```
