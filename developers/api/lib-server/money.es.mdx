```ts title="TypeScript"
import { money, banking, billing } from "@aifivem/lib/server";
```

`money` es todo saldo del servidor: las cuentas de un jugador cargado, la cuenta compartida de un trabajo o una banda, una transferencia que mueve el dinero en una sola transacción, y el registro. Un personaje que **no** está conectado se maneja con [`characters`](/es/docs/developers/api/lib-server/characters#charactersaddmoney-charactersremovemoney-and-characterssetmoney). `banking` y `billing` son las capas para los scripts de banco y de facturas del servidor.

## money

### money.get

El saldo de un jugador cargado en una cuenta.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
money.get(source: number, account: string): number | null
```

```lua title="Lua"
local balance = aiLib.money.get(source, account)
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador.', required: true },
    account: { type: 'string', description: 'Nombre de cuenta del panel (`cash`, `bank`...). Ver [Nombres de cuenta](/es/docs/developers/api/types#nombres-de-cuenta).', required: true },
  }}
/>

#### Devuelve

`number | null`: el saldo, o `null` cuando el jugador no tiene personaje cargado o el tipo de cuenta no existe. Los saldos de un personaje guardado vienen de [`characters.get`](/es/docs/developers/api/lib-server/characters#charactersget).

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money, notify } from "@aifivem/lib/server";

export function tellBalance(source: number): void {
  const bank = money.get(source, "bank");
  notify(source, bank === null ? "Sin personaje" : `Banco: $${bank}`, bank === null ? "error" : "inform");
}
```
</Tab>
<Tab value="Lua">
```lua
local bank = aiLib.money.get(source, 'bank')
aiLib.notify(source, bank and ('Banco: $%d'):format(bank) or 'Sin personaje', bank and 'inform' or 'error')
```
</Tab>
</Tabs>

### money.add, money.remove and money.set

Cambia una cuenta de un jugador cargado, con una fila de registro. Son las llamadas para una recompensa, un precio, un sueldo que paga tu script.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
money.add(source: number, account: string, amount: number, reason?: string): boolean
money.remove(source: number, account: string, amount: number, reason?: string): boolean
money.set(source: number, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = aiLib.money.add(source, account, amount, reason)
local ok = aiLib.money.remove(source, account, amount, reason)
local ok = aiLib.money.set(source, account, amount, reason)
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador.', required: true },
    account: { type: 'string', description: 'Nombre de cuenta del panel.', required: true },
    amount: { type: 'number', description: 'Dólares enteros, mayores que 0 para `add` y `remove`. `set` toma el nuevo saldo (0 permitido).', required: true },
    reason: { type: 'string', description: 'Lo que dice la fila del registro (`"shop:tools"`).', default: 'el nombre del resource que llama' },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el cambio se hizo. `false` cuando el jugador no tiene personaje cargado, la cuenta no existe, la cantidad no es un entero mayor que 0, o - en `remove` - el saldo no puede pagar (salvo que el tipo de cuenta permita bajar de cero).

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money, onClientCallback } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

onClientCallback("myshop:buyTools", { lock: true }, (source) => {
  if (!money.remove(source, "cash", 150, "shop:tools")) return fail("NOT_ENOUGH_CASH");
  // entrega el objeto aquí
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myshop:buyTools', function(source)
    if not aiLib.money.remove(source, 'cash', 150, 'shop:tools') then return aiLib.fail('NOT_ENOUGH_CASH') end
    return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="warn">
Que un jugador pague a otro **no** es un `remove` más un `add`: un fallo a medio camino haría aparecer o desaparecer dinero. Usa [`money.transfer`](#moneytransfer), que es una sola transacción.
</Callout>

### money.sharedGet

El saldo de la cuenta de un trabajo o una banda - `bank` es lo que otros frameworks llaman dinero de sociedad.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
money.sharedGet(type: "job" | "gang", id: string, account: string): number | null
```

```lua title="Lua"
local balance = aiLib.money.sharedGet(type, id, account)
```

#### Parámetros

<TypeTable
  type={{
    type: { type: '"job" | "gang"', description: 'De quién es la cuenta.', required: true },
    id: { type: 'string', description: 'El nombre del trabajo o de la banda (`"mechanic"`).', required: true },
    account: { type: 'string', description: 'Nombre de cuenta; `bank` es el dinero de sociedad.', required: true },
  }}
/>

#### Devuelve

`number | null`: el saldo, o `null` cuando ese trabajo o banda no tiene esa cuenta (un trabajo desconocido, o un tipo de cuenta que el servidor no tiene).

### money.sharedAdd and money.sharedRemove

Cambia la cuenta de un trabajo o una banda, con una fila de registro - los ingresos y los costes de una empresa.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
money.sharedAdd(type: "job" | "gang", id: string, account: string, amount: number, reason?: string): boolean
money.sharedRemove(type: "job" | "gang", id: string, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = aiLib.money.sharedAdd(type, id, account, amount, reason)
local ok = aiLib.money.sharedRemove(type, id, account, amount, reason)
```

#### Devuelve

`boolean`: `true` cuando el cambio se hizo, `false` para un trabajo o banda desconocidos, una cuenta que falta, una cantidad errónea, o una cuenta que no puede pagar.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money } from "@aifivem/lib/server";

/** Un contrato de la ciudad que gana el taller, y lo que paga por las piezas. */
export function contractDone(job: string, pay: number, parts: number): boolean {
  if (!money.sharedAdd("job", job, "bank", pay, "city contract")) return false;
  return money.sharedRemove("job", job, "bank", parts, "parts");
}
```
</Tab>
<Tab value="Lua">
```lua
local ok = aiLib.money.sharedAdd('job', 'mechanic', 'bank', 500, 'repair')
```
</Tab>
</Tabs>

### money.transfer

Mueve dinero de una cuenta a otra en una sola transacción de base de datos, con una fila de registro contable en ambos lados. Úsalo para todo aquello en que el dinero no deba aparecer ni desaparecer a medias: pagar a otro jugador, un trabajo que paga una prima, una comisión.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
money.transfer(from: MoneyRef, to: MoneyRef, amount: number, reason?: string, fee?: number): boolean
```

```lua title="Lua"
local ok = aiLib.money.transfer(from, to, amount, reason, fee)
```

#### Parámetros

<TypeTable
  type={{
    from: { type: "MoneyRef", typeDescriptionLink: "/es/docs/developers/api/types#moneyref", description: "La cuenta que paga: la `{ source, account }` de un jugador (`account`: `cash`, `bank`...) o la `{ owner: \"job\" | \"gang\", id, account }` de un trabajo o una banda.", required: true },
    to: { type: "MoneyRef", typeDescriptionLink: "/es/docs/developers/api/types#moneyref", description: "La cuenta que recibe, con la misma forma.", required: true },
    amount: { type: "number", description: "Cuánto recibe `to`: un número entero, 1 o más.", required: true },
    reason: { type: "string", description: "Se escribe en ambas filas del registro (`rent:apartment_3`).", required: false },
    fee: { type: "number", description: "Cantidad entera extra que `from` también paga. Sale de la economía (nadie la recibe).", default: "0" },
  }}
/>

#### Devuelve

`boolean`: `true` cuando se escribieron ambas filas. `false` cuando una cantidad no es un número entero, falta una cuenta, ambas son la misma, o `from` no puede pagar `amount` más `fee`.

#### Ejemplo

```ts
import { onClientCallback, money, nearestPlayerTo, notify } from "@aifivem/lib/server";
import { fail, oneArg, readInt } from "@aifivem/lib/shared";

onClientCallback("my-cash:give", { args: oneArg((v) => readInt(v, 1, 100_000)), lock: true }, (source, amount) => {
  const target = nearestPlayerTo(source, 2);
  if (target === null) return fail("NOBODY_NEAR");
  if (!money.transfer({ source, account: "cash" }, { source: target, account: "cash" }, amount, "give:cash"))
    return fail("NOT_ENOUGH_CASH");
  notify(target, `You received $${amount}`, "success");
  return { ok: true };
});
```

### money.history

Las filas del registro de una cuenta, las más nuevas primero: qué se movió, el saldo después, el motivo, quién lo hizo y cuándo. Funciona para la cuenta de un jugador, la de un trabajo o banda, y la de un personaje guardado.

**Lado:** Servidor · **Espera:** sí

```ts title="Firma"
money.history(account: LedgerRef, query?: LedgerQuery): Promise<LedgerPage>
```

```lua title="Lua"
local page = aiLib.money.history(account, query)
```

#### Parámetros

<TypeTable
  type={{
    account: { type: 'LedgerRef', typeDescriptionLink: '/es/docs/developers/api/types#ledgerref', description: 'El registro de quién: `{ source, account }`, `{ owner: "job" | "gang", id, account }`, o un personaje guardado con `{ owner: "character", id, account }` (`id` es el id del personaje como texto).', required: true },
    query: { type: 'LedgerQuery', typeDescriptionLink: '/es/docs/developers/api/types#ledgerquery', description: 'Qué filas: `before` (el `next` de la página que acabas de leer), `since` (segundos unix), `limit` (1-200, por defecto 50).' },
  }}
/>

#### Devuelve

Una [LedgerPage](/es/docs/developers/api/types#ledgerpage): `rows` y el `next` que pasas como `before` (`null` en la última página). ai-core escribe una fila un momento después del cambio, así que la más nueva puede ir unos milisegundos detrás del saldo.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money } from "@aifivem/lib/server";

/** Las últimas 20 filas de banco de un personaje guardado. */
export async function statement(charId: number) {
  const page = await money.history({ owner: "character", id: String(charId), account: "bank" }, { limit: 20 });
  return page.rows.map((r) => `${r.at}: ${r.amount} (${r.reason})`);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local page = aiLib.money.history({ source = source, account = 'bank' }, { limit = 20 })
    for _, row in ipairs(page.rows) do
        print(('%d: %d (%s)'):format(row.at, row.amount, row.reason))
    end
end)
```
</Tab>
</Tabs>

## banking

`banking` habla con el script de banca a través de la capa de banca de ai-core. El dinero de los trabajos en sí siempre se mueve mediante `money` o los exports de ai-core.

### banking.open

Abre la pantalla del script de banca para un jugador.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
banking.open(source: number): boolean
```

```lua title="Lua"
local ok = aiLib.banking.open(source)
```

**Devuelve** `true` cuando se abrió. `false` cuando el script no puede abrirse desde fuera o no hay ninguno en marcha.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
onClientCallback("my-atm:open", (source) => (banking.open(source) ? { ok: true } : fail("BANK_UNAVAILABLE")));
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('my-atm:open', function(source)
    if not aiLib.banking.open(source) then return aiLib.fail('BANK_UNAVAILABLE') end
    return { ok = true }
end)
```
</Tab>
</Tabs>

```ts title="Firma"

```


**Devuelve** el saldo, o `null` (`nil` en Lua) cuando no hay ninguno en marcha o el script no lleva ninguno.

## billing

`billing` envía facturas a través del script de facturación que funcione; sin ninguno, las facturas propias de ai-core (el jugador paga desde una lista en pantalla y el dinero se mueve cuando paga). Los textos ya están traducidos.

### billing.send

Envía una factura desde un trabajo (multas, tarifas de servicio) o desde un jugador.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
billing.send(bill: BillRequest): boolean
```

```lua title="Lua"
local ok = aiLib.billing.send(bill)
```

#### BillRequest

<TypeTable
  type={{
    to: { type: "number", description: "Id de servidor del jugador que la recibe. Indica `to` o `toCitizenid`.", required: false },
    toCitizenid: { type: "string", description: "El personaje que la recibe, por citizen id, en línea o desconectado. Un personaje desconectado solo la recibe con las facturas propias de ai-core; un script de facturación necesita al jugador en línea.", required: false },
    amount: { type: "number", description: "Dólares enteros.", required: true },
    label: { type: "string", description: "Para qué es (`Speeding`).", required: true },
    from: { type: "number", description: "Id de servidor del jugador que la emite (agente, mecánico). Una factura sin `job` le paga a este jugador.", required: false },
    job: { type: "string", description: "El trabajo cuya cuenta recibe el pago. Sin él, la factura es personal y `from` es obligatorio.", required: false },
  }}
/>

#### Devuelve

`boolean`: `true` cuando se envió, `false` cuando no es válida o se rechazó.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { billing, nearestPlayerTo, online } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

function fine(officer: number, amount: number) {
  if (!online.onDutyIn(officer, ["police"])) return fail("NOT_ON_DUTY");
  const target = nearestPlayerTo(officer, 3);
  if (target === null) return fail("NOBODY_NEAR");
  return billing.send({ to: target, amount, label: "Speeding", from: officer, job: "police" })
    ? { ok: true }
    : fail("BILL_FAILED");
}
```
</Tab>
<Tab value="Lua">
```lua
local function fine(officer, amount)
    if aiLib.online.dutyJob(officer) ~= 'police' then return aiLib.fail('NOT_ON_DUTY') end
    local target = aiLib.nearestPlayerTo(officer, 3.0)
    if not target then return aiLib.fail('NOBODY_NEAR') end
    if not aiLib.billing.send({ to = target, amount = amount, label = 'Speeding', from = officer, job = 'police' }) then
        return aiLib.fail('BILL_FAILED')
    end
    return { ok = true }
end
```
</Tab>
</Tabs>

### billing.unpaid

Las facturas abiertas del jugador.

**Lado:** Servidor · **Espera:** sí (Promise en TypeScript, cede el hilo en Lua)

```ts title="Firma"
billing.unpaid(source: number): Promise<UnpaidBill[] | null>
```

```lua title="Lua"
local bills = aiLib.billing.unpaid(source) -- table[] o nil, llamar dentro de un hilo
```

**Devuelve** [`UnpaidBill[]`](/es/docs/developers/api/types#unpaidbill) (`id`, `label`, `amount` aún adeudado, `sender`), o `null` cuando el script de facturación no puede listarlas.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const bills = await billing.unpaid(source);
const owed = bills?.reduce((sum, bill) => sum + bill.amount, 0) ?? 0;
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local bills = aiLib.billing.unpaid(source) or {}
    local owed = 0
    for _, bill in ipairs(bills) do owed = owed + bill.amount end
    print(owed)
end)
```
</Tab>
</Tabs>
