## phone

Le téléphone du joueur via ai-core : le premier script de téléphone qui tourne (tgiann-phone, lb-phone...) répond. Sans script de téléphone, chaque appel répond `null` ou `false`. Les équivalents Lua sur `aiLib.phone` ont les mêmes noms et le même ordre d’arguments.

### phone.number

**Côté :** serveur · **Attend :** non

```ts title="Signature"
phone.number(source: number): string | null
```

```lua title="Lua"
local number = aiLib.phone.number(source)
```

**Retour** le numéro de téléphone du joueur, ou `null` (Lua `nil`) quand il n’en a pas ou qu’aucun script de téléphone ne tourne.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const number = phone.number(source);
if (!number) return fail("NO_PHONE_NUMBER");
```
</Tab>
<Tab value="Lua">
```lua
local number = aiLib.phone.number(source)
if not number then return aiLib.fail('NO_PHONE_NUMBER') end
```
</Tab>
</Tabs>

### phone.sourceOf

Le joueur en ligne à qui appartient un numéro de téléphone.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
phone.sourceOf(number: string): number | null
```

```lua title="Lua"
local source = aiLib.phone.sourceOf(number)
```

**Retour** l’id serveur, ou `null` (Lua `nil`) quand personne en ligne n’a ce numéro.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const owner = phone.sourceOf("555-0101");
if (owner !== null) notify(owner, "Your phone is ringing");
```
</Tab>
<Tab value="Lua">
```lua
local owner = aiLib.phone.sourceOf('555-0101')
if owner then aiLib.notify(owner, 'Your phone is ringing') end
```
</Tab>
</Tabs>

## appearance

L’apparence enregistrée des personnages via la couche apparence d’ai-core, quel que soit le script de vêtements qui tourne (ai-appearance, tgiann-clothing).

### appearance.get

L’apparence enregistrée d’un personnage, chargé ou non. Utilisez-la pour habiller un ped qui représente un personnage (un corps endormi, un mannequin) : transmettez le résultat tel quel à `appearance.apply` côté client ([Lib : client](/fr/docs/developers/api/lib-client)).

**Côté :** serveur · **Attend :** oui (Promise en TypeScript, cède la main (yield) dans le thread en Lua)

```ts title="Signature"
appearance.get(charId: number): Promise<CharacterAppearance | null>
```

```lua title="Lua"
local look = aiLib.appearance.get(charId) -- { model, data } ou nil, à appeler dans un thread
```

<TypeTable
  type={{
    charId: { type: "number", description: "L’id du personnage (`CharacterInfo.id`).", required: true },
  }}
/>

#### Retour

`Promise<CharacterAppearance | null>` : [`CharacterAppearance`](/fr/docs/developers/api/types#characterappearance) est `{ model, data }` (le hash du modèle du ped et les données d’apparence propres au script de vêtements). `null` quand le personnage n’en a pas, qu’aucun script de vêtements ne tourne, ou qu’ai-core est arrêté.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, online, playersNear } from "@aicore-fivem/lib/server";

async function sendLook(source: number) {
  const charId = online.charId(source);
  if (charId === undefined) return;
  const look = await appearance.get(charId);
  if (!look) return;
  // Seuls les joueurs proches de ce personnage ont besoin de l’apparence.
  for (const other of playersNear(source, 100)) emitNet("my-sleepers:look", other, source, look);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local character = aiLib.online.character(source)
    if not character then return end
    local look = aiLib.appearance.get(character.id)
    if look then TriggerClientEvent('my-sleepers:look', source, look) end
end)
```
</Tab>
</Tabs>

### appearance.provider

**Côté :** serveur · **Attend :** non

```ts title="Signature"
appearance.provider(): string | null
```

```lua title="Lua"
local name = aiLib.appearance.provider()
```

**Retour** le script de vêtements qui répond, ou `null` (Lua `nil`) quand aucun ne tourne.

```ts
console.log(`looks through ${appearance.provider() ?? "nothing"}`);
```
