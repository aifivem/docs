title: Предметы
description: "inventory: выдача, изъятие и подсчёт предметов, хранилища, магазины и используемые предметы через тот инвентарь, который запущен на сервере."
icon: Package
---

```ts title="TypeScript"
import { inventory } from "@aicore-fivem/lib/server";
```

`inventory` отправляет каждый вызов, связанный с предметами, через слой инвентаря ai-core: отвечает инвентарь, запущенный на сервере (ai-inventory или другой, выбранный владельцем в панели ai-core). Ваш скрипт никогда не вызывает собственные экспорты инвентаря, поэтому продолжает работать, когда владелец меняет инвентарь.

**Аргумент инвентаря** (`inv`, тип [`InventoryRef`](/ru/docs/developers/api/types#inventoryref)) это серверный id игрока (число) или id другого инвентаря (строка: имя хранилища, номер транспорта).

**Количества** это целые числа от 1 и выше; дробь округляется вниз, `0` или отрицательное количество приводит к неудаче вызова.

<Callout type="info">
Пока не запущен ни один инвентарь, вызовы тихо завершаются неудачей: `false`, `0`, пустой список или `null`. Lua-аналоги в `aiLib.inventory` имеют те же имена и тот же порядок аргументов.
</Callout>

### inventory.addItem

Выдаёт предметы в инвентарь.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
inventory.addItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = aiLib.inventory.addItem(inv, item, count, metadata, slot)
```

#### Параметры

<TypeTable
  type={{
    inv: { type: "InventoryRef", typeDescriptionLink: "/ru/docs/developers/api/types#inventoryref", description: "Серверный id игрока либо имя хранилища или номер.", required: true },
    item: { type: "string", description: "Название предмета так, как его знает инвентарь (`water`).", required: true },
    count: { type: "number", description: "Сколько.", default: "1" },
    metadata: { type: "ItemMetadata", typeDescriptionLink: "/ru/docs/developers/api/types#itemmetadata", description: "Дополнительные данные, хранящиеся в стаке (`{ serial: \"A1\" }`). Стаки с разными метаданными не объединяются.", required: false },
    slot: { type: "number", description: "Положить в этот слот (1 и выше), если инвентарь это поддерживает.", required: false },
  }}
/>

#### Возвращает

`boolean`: `true`, если выдано. `false`, если не помещается, предмета не существует, аргумент неверный или не запущен инвентарь.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

if (!inventory.addItem(source, "phone", 1, { number: "555-0101" })) return fail("INVENTORY_FULL");
```
</Tab>
<Tab value="Lua">
```lua
if not aiLib.inventory.addItem(source, 'phone', 1, { number = '555-0101' }) then
    return aiLib.fail('INVENTORY_FULL')
end
```
</Tab>
</Tabs>

<Callout type="warn">
Когда вы что-то берёте взамен (деньги, другой предмет), сначала проверьте `canCarryItem`: забирайте только после того, как `addItem` ответил `true`, иначе верните обратно.
</Callout>

```ts title="Сигнатура"

```

```lua title="Lua"
local ok = aiLib.inventory.openInventory(source, inv)
```

<TypeTable
  type={{
    source: { type: "number", description: "Серверный id игрока, который его видит.", required: true },
    inv: { type: "InventoryRef", typeDescriptionLink: "/ru/docs/developers/api/types#inventoryref", description: "Имя хранилища, номер или серверный id другого игрока.", required: true },

/>

#### Возвращает

`boolean`: `true`, если инвентарь его открыл.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, near, online, inventory } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const ARMORY = { x: 452.3, y: -980.0, z: 30.7 };

onClientCallback(
  "my-police:armory",
  (source) => {
    if (!online.onDutyIn(source, ["police"])) return fail("NOT_ON_DUTY");
    return { ok: inventory.openInventory(source, "police_armory") };
  },
  { guards: [near(ARMORY, 3)] },
);
```
</Tab>
<Tab value="Lua">
```lua
local ARMORY = vector3(452.3, -980.0, 30.7)

aiLib.onClientCallback('my-police:armory', function(source)
    if aiLib.online.dutyJob(source) ~= 'police' then return aiLib.fail('NOT_ON_DUTY') end
    if #(GetEntityCoords(GetPlayerPed(source)) - ARMORY) > 3.0 then return aiLib.fail('TOO_FAR') end
    return { ok = aiLib.inventory.openInventory(source, 'police_armory') }
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Здесь не проверяются ни расстояние, ни доступ: проверьте расстояние, работу и владение перед вызовом.

### inventory.registerUsableItem

Запускает ваш обработчик, когда игрок использует предмет. ai-core хранит обработчик для инвентарей, которые запустятся позже, и при перезапусках инвентаря, поэтому регистрируйте один раз при запуске скрипта.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
inventory.registerUsableItem(name: string, handler: UsableItemHandler): void
```

```lua title="Lua"
aiLib.inventory.registerUsableItem(name, handler) -- handler(source, item)
```

#### Параметры

<TypeTable
  type={{
    name: { type: "string", description: "Название предмета.", required: true },
    handler: { type: "(source: number, item: UsedItem) => unknown", typeDescriptionLink: "/ru/docs/developers/api/types#usableitemhandler", description: "Получает игрока и использованный стак `{ name, slot, count, metadata }` (тип `UsedItem`). Возврат `false` оставляет предмет в инвентарях, которые сами забирают использованный предмет (ai-inventory: количество `consume` предмета); другие инвентари следуют своим настройкам предметов.", required: true },
  }}
/>

Использованный стак это [`UsedItem`](/ru/docs/developers/api/types#useditem).

<Callout type="warn">
Инвентари, которые сами забирают использованный предмет (ai-inventory), забирают его, как только обработчик вернёт что угодно, кроме `false`. Если ваш обработчик ждёт (полоса прогресса) и сам удаляет предмет, сразу возвращайте `false`, иначе предмет заберут дважды.
</Callout>

#### Возвращает

`void`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory, progressFor, medical, createLocale } from "@aicore-fivem/lib/server";

const Locale = createLocale();

async function bandage(source: number) {
  const done = await progressFor(source, { label: Locale("BANDAGING"), duration: 4000, canCancel: true });
  if (done && inventory.removeItem(source, "bandage")) medical.heal(source);
}

inventory.registerUsableItem("bandage", (source) => {
  void bandage(source);
  return false; // пока оставляем предмет: bandage() заберёт его после полосы
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.inventory.registerUsableItem('bandage', function(source, item)
    CreateThread(function()
        local done = aiLib.progressFor(source, { label = Locale('BANDAGING'), duration = 4000, canCancel = true })
        if done and aiLib.inventory.removeItem(source, 'bandage', 1) then
            exports['ai-core']:HealPlayer(source)
        end
    end)
    return false -- пока оставляем предмет: поток заберёт его после полосы
end)
```
</Tab>
</Tabs>
