```ts title="TypeScript"
import { money, banking, billing } from "@aifivem/lib/server";
```

`money` - это любой баланс на сервере: счета загруженного игрока, общий счёт работы или банды, перевод, который двигает деньги одной транзакцией, и журнал. Персонаж, который **не** подключён, идёт через [`characters`](/ru/docs/developers/api/lib-server/characters#charactersaddmoney-charactersremovemoney-and-characterssetmoney). `banking` и `billing` - слои для банковского и счётного скриптов сервера.

## money

### money.get

Баланс загруженного игрока на одном счёте.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
money.get(source: number, account: string): number | null
```

```lua title="Lua"
local balance = aiLib.money.get(source, account)
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
    account: { type: 'string', description: 'Имя счёта из панели (`cash`, `bank`...). См. [Имена счетов](/ru/docs/developers/api/types#имена-счетов).', required: true },
  }}
/>

#### Возвращает

`number | null`: баланс или `null`, если у игрока нет загруженного персонажа либо такого типа счёта не существует. Балансы сохранённого персонажа берутся из [`characters.get`](/ru/docs/developers/api/lib-server/characters#charactersget).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money, notify } from "@aifivem/lib/server";

export function tellBalance(source: number): void {
  const bank = money.get(source, "bank");
  notify(source, bank === null ? "Нет персонажа" : `Банк: $${bank}`, bank === null ? "error" : "inform");
}
```
</Tab>
<Tab value="Lua">
```lua
local bank = aiLib.money.get(source, 'bank')
aiLib.notify(source, bank and ('Банк: $%d'):format(bank) or 'Нет персонажа', bank and 'inform' or 'error')
```
</Tab>
</Tabs>

### money.add, money.remove and money.set

Меняет один счёт загруженного игрока, со строкой журнала. Это вызовы для награды, цены, зарплаты, которую платит ваш скрипт.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
money.add(source: number, account: string, amount: number, reason?: string): boolean
money.remove(source: number, account: string, amount: number, reason?: string): boolean
money.set(source: number, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = aiLib.money.add(source, account, amount, reason)
local ok = aiLib.money.remove(source, account, amount, reason)
local ok = aiLib.money.set(source, account, amount, reason)
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
    account: { type: 'string', description: 'Имя счёта из панели.', required: true },
    amount: { type: 'number', description: 'Целые доллары, больше 0 для `add` и `remove`. `set` принимает новый баланс (0 допустим).', required: true },
    reason: { type: 'string', description: 'Что будет в строке журнала (`"shop:tools"`).', default: 'имя вызывающего ресурса' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда изменение прошло. `false`, если у игрока нет загруженного персонажа, счёта не существует, сумма не целая больше 0, либо - у `remove` - баланс не может заплатить (если тип счёта не разрешает уходить ниже нуля).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money, onClientCallback } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

onClientCallback("myshop:buyTools", { lock: true }, (source) => {
  if (!money.remove(source, "cash", 150, "shop:tools")) return fail("NOT_ENOUGH_CASH");
  // здесь выдайте предмет
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myshop:buyTools', function(source)
    if not aiLib.money.remove(source, 'cash', 150, 'shop:tools') then return aiLib.fail('NOT_ENOUGH_CASH') end
    return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="warn">
Оплата одного игрока другому - это **не** `remove` плюс `add`: сбой на середине создал бы или уничтожил деньги. Берите [`money.transfer`](#moneytransfer), это одна транзакция базы.
</Callout>

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
money.sharedGet(type: "job" | "gang", id: string, account: string): number | null
```

```lua title="Lua"
local balance = aiLib.money.sharedGet(type, id, account)
```

#### Параметры

<TypeTable
  type={{
    type: { type: '"job" | "gang"', description: 'Чей это счёт.', required: true },
    id: { type: 'string', description: 'Название работы или банды (`"mechanic"`).', required: true },
    account: { type: 'string', description: 'Имя счёта; `bank` - это деньги организации.', required: true },

### money.sharedAdd and money.sharedRemove

Меняет счёт работы или банды, со строкой журнала - доходы и расходы компании.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
money.sharedAdd(type: "job" | "gang", id: string, account: string, amount: number, reason?: string): boolean
money.sharedRemove(type: "job" | "gang", id: string, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = aiLib.money.sharedAdd(type, id, account, amount, reason)
local ok = aiLib.money.sharedRemove(type, id, account, amount, reason)
```

#### Возвращает

`boolean`: `true`, когда изменение прошло, `false` при неизвестной работе или банде, отсутствующем счёте, неверной сумме либо счёте, который не может заплатить.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money } from "@aifivem/lib/server";

/** Городской контракт, который зарабатывает мастерская, и плата за запчасти. */
export function contractDone(job: string, pay: number, parts: number): boolean {
  if (!money.sharedAdd("job", job, "bank", pay, "city contract")) return false;
  return money.sharedRemove("job", job, "bank", parts, "parts");
}
```
</Tab>
<Tab value="Lua">
```lua
local ok = aiLib.money.sharedAdd('job', 'mechanic', 'bank', 500, 'repair')
```
</Tab>
</Tabs>

### money.transfer

Переводит деньги с одного счёта на другой в одной транзакции базы данных, с записью в журнале на обеих сторонах. Используйте для всего, где деньги не должны появиться или исчезнуть на полпути: оплата другому игроку, премия от работы, сбор.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
money.transfer(from: MoneyRef, to: MoneyRef, amount: number, reason?: string, fee?: number): boolean
```

```lua title="Lua"
local ok = aiLib.money.transfer(from, to, amount, reason, fee)
```

#### Параметры

<TypeTable
  type={{
    from: { type: "MoneyRef", typeDescriptionLink: "/ru/docs/developers/api/types#moneyref", description: "Счёт плательщика: `{ source, account }` игрока (`account`: `cash`, `bank`...) или `{ owner: \"job\" | \"gang\", id, account }` работы / банды.", required: true },
    to: { type: "MoneyRef", typeDescriptionLink: "/ru/docs/developers/api/types#moneyref", description: "Счёт получателя, та же форма.", required: true },
    amount: { type: "number", description: "Сколько получает `to`: целое число, 1 или больше.", required: true },
    reason: { type: "string", description: "Записывается в обе строки журнала (`rent:apartment_3`).", required: false },
    fee: { type: "number", description: "Дополнительная целая сумма, которую также платит `from`. Она уходит из экономики (никто её не получает).", default: "0" },
  }}
/>

#### Возвращает

`boolean`: `true`, если обе строки записаны. `false`, если сумма не является целым числом, счёт отсутствует, оба счёта совпадают или `from` не может заплатить `amount` плюс `fee`.

#### Пример

```ts
import { onClientCallback, money, nearestPlayerTo, notify } from "@aifivem/lib/server";
import { fail, oneArg, readInt } from "@aifivem/lib/shared";

onClientCallback("my-cash:give", { args: oneArg((v) => readInt(v, 1, 100_000)), lock: true }, (source, amount) => {
  const target = nearestPlayerTo(source, 2);
  if (target === null) return fail("NOBODY_NEAR");
  if (!money.transfer({ source, account: "cash" }, { source: target, account: "cash" }, amount, "give:cash"))
    return fail("NOT_ENOUGH_CASH");
  notify(target, `You received $${amount}`, "success");
  return { ok: true };
});
```

### money.history

Строки журнала счёта, самые новые первыми: что сдвинулось, баланс после, причина, кто это сделал и когда. Работает для счёта игрока, счёта работы или банды и счёта сохранённого персонажа.

**Сторона:** Сервер · **Ждёт:** да

```ts title="Сигнатура"
money.history(account: LedgerRef, query?: LedgerQuery): Promise<LedgerPage>
```

```lua title="Lua"
local page = aiLib.money.history(account, query)
```

#### Параметры

<TypeTable
  type={{
    account: { type: 'LedgerRef', typeDescriptionLink: '/ru/docs/developers/api/types#ledgerref', description: 'Чей журнал: `{ source, account }`, `{ owner: "job" | "gang", id, account }` или сохранённый персонаж через `{ owner: "character", id, account }` (`id` - id персонажа текстом).', required: true },
    query: { type: 'LedgerQuery', typeDescriptionLink: '/ru/docs/developers/api/types#ledgerquery', description: 'Какие строки: `before` (`next` страницы, которую вы только что прочитали), `since` (unix-секунды), `limit` (1-200, по умолчанию 50).' },
  }}
/>

#### Возвращает

[LedgerPage](/ru/docs/developers/api/types#ledgerpage): `rows` и `next`, который вы передаёте как `before` (`null` на последней странице). ai-core пишет строку через мгновение после изменения, так что самая новая может отставать от баланса на несколько миллисекунд.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money } from "@aifivem/lib/server";

/** Последние 20 банковских строк сохранённого персонажа. */
export async function statement(charId: number) {
  const page = await money.history({ owner: "character", id: String(charId), account: "bank" }, { limit: 20 });
  return page.rows.map((r) => `${r.at}: ${r.amount} (${r.reason})`);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local page = aiLib.money.history({ source = source, account = 'bank' }, { limit = 20 })
    for _, row in ipairs(page.rows) do
        print(('%d: %d (%s)'):format(row.at, row.amount, row.reason))
    end
end)
```
</Tab>
</Tabs>

## billing

`billing` отправляет счета через тот скрипт счетов, который запущен; без него используются собственные счета ai-core (игрок платит из списка на экране, деньги перемещаются при оплате). Тексты уже переведены.

### billing.send

Отправляет счёт от работы (штрафы, плата за услуги) или от игрока.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
billing.send(bill: BillRequest): boolean
```

```lua title="Lua"
local ok = aiLib.billing.send(bill)
```

#### BillRequest

<TypeTable
  type={{
    to: { type: "number", description: "Серверный id игрока, который его получает. Укажите `to` или `toCitizenid`.", required: false },
    toCitizenid: { type: "string", description: "Персонаж, который его получает, по citizen id, онлайн или офлайн. Офлайн-персонаж получает его только через собственные счета ai-core; скрипту счетов нужен игрок онлайн.", required: false },
    amount: { type: "number", description: "Целые доллары.", required: true },
    label: { type: "string", description: "За что счёт (`Speeding`).", required: true },
    from: { type: "number", description: "Серверный id игрока, выставившего счёт (полицейский, механик). Счёт без `job` оплачивается этому игроку.", required: false },
    job: { type: "string", description: "Работа, на счёт которой поступает платёж. Без неё счёт личный, и `from` обязателен.", required: false },
  }}
/>

#### Возвращает

`boolean`: `true`, если отправлен, `false`, если неверный или отклонён.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { billing, nearestPlayerTo, online } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

function fine(officer: number, amount: number) {
  if (!online.onDutyIn(officer, ["police"])) return fail("NOT_ON_DUTY");
  const target = nearestPlayerTo(officer, 3);
  if (target === null) return fail("NOBODY_NEAR");
  return billing.send({ to: target, amount, label: "Speeding", from: officer, job: "police" })
    ? { ok: true }
    : fail("BILL_FAILED");
}
```
</Tab>
<Tab value="Lua">
```lua
local function fine(officer, amount)
    if aiLib.online.dutyJob(officer) ~= 'police' then return aiLib.fail('NOT_ON_DUTY') end
    local target = aiLib.nearestPlayerTo(officer, 3.0)
    if not target then return aiLib.fail('NOBODY_NEAR') end
    if not aiLib.billing.send({ to = target, amount = amount, label = 'Speeding', from = officer, job = 'police' }) then
        return aiLib.fail('BILL_FAILED')
    end
    return { ok = true }
end
```
</Tab>
</Tabs>

### billing.unpaid

Неоплаченные счета игрока.

**Сторона:** Сервер · **Ждёт:** да (Promise в TypeScript, в Lua приостанавливает поток)

```ts title="Сигнатура"
billing.unpaid(source: number): Promise<UnpaidBill[] | null>
```

```lua title="Lua"
local bills = aiLib.billing.unpaid(source) -- table[] или nil, вызывайте внутри потока
```

**Возвращает** [`UnpaidBill[]`](/ru/docs/developers/api/types#unpaidbill) (`id`, `label`, ещё не оплаченная `amount`, `sender`) или `null`, если скрипт счетов не умеет их перечислять.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const bills = await billing.unpaid(source);
const owed = bills?.reduce((sum, bill) => sum + bill.amount, 0) ?? 0;
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local bills = aiLib.billing.unpaid(source) or {}
    local owed = 0
    for _, bill in ipairs(bills) do owed = owed + bill.amount end
    print(owed)
end)
```
</Tab>
</Tabs>
