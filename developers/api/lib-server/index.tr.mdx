Server lib’i, her `ai-*` server script’inin aynı kodu yeniden yazmak yerine kullandığı yardımcıların bütünüdür: client’lara güvenli cevap vermek, komutlar, oyuncular, eşyalar, araçlar, para, loglar ve admin paneli. Başka bir sisteme dokunan yardımcıların çoğu (envanter, anahtarlar, telefon, hapis...) **ai-core** üzerinden gider; böylece sunucu sahibi envanter ya da telefon script’ini değiştirdiğinde senin script’in çalışmaya devam eder.

## TypeScript

`resource/server/` altındaki dosyalarda `@aifivem/lib/server`’dan import et. Her tarafta çalışan yardımcılar (reddetmeler, girdi okuyucular, matematik) `@aifivem/lib/shared`’dan gelir.

```ts title="resource/server/index.ts"
import { onClientCallback, inventory, notify } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";
```

ai-core şablonundan yapılan her resource pakete zaten bağlıdır (`package.json` içinde `"@aifivem/lib": "workspace:*"`); build onu `dist/server.js` içine paketler.

## Lua

Lua resource’ları aynı yardımcıları `ai-lib` resource’undan gelen global `aiLib` tablosunda bulur. `fxmanifest.lua` dosyana iki satır ekle:

```lua title="fxmanifest.lua"
dependency 'ai-lib'
shared_script '@ai-lib/init.lua'
```

Sonra herhangi bir server dosyasında `aiLib.<name>` çağır. Her modül ilk kullandığında yüklenir ve senin resource’unun içinde çalışır; bu yüzden kaydettiğin komutlar ve callback’ler senin resource’una aittir ve o durduğunda kaldırılır.

```lua title="server.lua"
aiLib.addCommand('hello', { help = 'Says hello' }, function(source)
    aiLib.notify(source, 'Hello!', 'success')
end)
```

<Callout type="warn">
**Bekler** olarak işaretli Lua fonksiyonları (`progressFor`, `minigameFor`, `spawnVehicle`, `triggerClientCallback`, `billing.unpaid`, `appearance.get`) cevap gelene kadar kodu duraklatır. Yalnızca bir thread içinde çalışırlar. `aiLib.onClientCallback` ve `aiLib.onClientEvent` handler’ları zaten bir thread içinde çalışır; başka her yerde çağrıyı `CreateThread(function() ... end)` ile sar.
</Callout>

Her TypeScript yardımcısının bir Lua karşılığı yoktur. Karşılığı olmayan her girdi bunu belirtir. Lua’da eksik olanlar: `PendingActions`, `PlayerMap`, `Cooldowns`, `KeyedCooldowns`, `SourceLock`, `KeyWatchers`, konum yardımcıları, `AreaStream`, state bag sınıfları, `AdminPanel`, `DataFile` ve veritabanı yardımcıları (Lua resource’ları SQL için ai-mysql’in oxmysql API’sini kullanır).

## Client ile paylaşılan yardımcılar

Server girişi `/fivem` yardımcılarını da yeniden export eder; bu yüzden onları `@aifivem/lib/server`’dan da import edebilirsin. Bunlar [Lib: shared ve fivem](/tr/docs/developers/api/lib-shared) sayfasında bir kez belgelenir:

`registerExport`, `resourceExport`, `optionalExport`, `callExport`, `provideExport`, `isResourceStarted`, `createLocale`, `loadLocaleTexts`, `LOCALE_CONVAR`, `ByResource`, `caller`, `onStop`, `plateOf`, `Reasons`, `every` (`EveryOptions` ve `Job` tipleriyle), `stateBoolean`, `stateNumber`, `stateString` (tip `StateParse`).

Server girişinden export edilen `EntityState`, `PlayerState`, `GlobalKey` ve `GlobalGroup` state bag sınıfları server sürümleridir: `set` eklerler. Bkz. [State bag’ler](/tr/docs/developers/api/lib-server/state-bags).

## Yalnızca ai-core’un kullandığı iki yardımcı

`sendPlayerData(source, key, value)` ve `patchPlayerData(source, key, patch)`, bir oyuncunun verisinin (`AiPlayerData`) tek bir değerini o oyuncunun client’ına gönderir. Bunları ai-core çağırır; senin script’inin onlara hiç ihtiyacı olmaz. Oyuncu verisini client’ta `getPlayerData` ile oku ([Lib: client](/tr/docs/developers/api/lib-client)).
