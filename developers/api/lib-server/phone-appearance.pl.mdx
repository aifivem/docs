## phone

Telefon gracza przez ai-core: odpowiada pierwszy działający skrypt telefonu (tgiann-phone, lb-phone...). Bez skryptu telefonu każde wywołanie odpowiada `null` albo `false`. Odpowiedniki w Lua w `aiLib.phone` mają te same nazwy i kolejność argumentów.

### phone.number

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
phone.number(source: number): string | null
```

```lua title="Lua"
local number = aiLib.phone.number(source)
```

**Zwraca** numer telefonu gracza albo `null` (Lua `nil`), gdy go nie ma albo nie działa żaden skrypt telefonu.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const number = phone.number(source);
if (!number) return fail("NO_PHONE_NUMBER");
```
</Tab>
<Tab value="Lua">
```lua
local number = aiLib.phone.number(source)
if not number then return aiLib.fail('NO_PHONE_NUMBER') end
```
</Tab>
</Tabs>

### phone.sourceOf

Gracz online, który jest właścicielem numeru telefonu.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
phone.sourceOf(number: string): number | null
```

```lua title="Lua"
local source = aiLib.phone.sourceOf(number)
```

**Zwraca** id serwerowe albo `null` (Lua `nil`), gdy nikt online nie ma tego numeru.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

if (owner !== null) notify(owner, "Your phone is ringing");
```
</Tab>
<Tab value="Lua">
```lua
local owner = aiLib.phone.sourceOf('555-0101')
if owner then aiLib.notify(owner, 'Your phone is ringing') end
```
</Tab>
</Tabs>

### phone.hasPhone


## appearance

Zapisany wygląd postaci przez warstwę wyglądu ai-core, niezależnie od tego, jaki skrypt ubrań działa (ai-appearance, tgiann-clothing).

### appearance.get

Zapisany wygląd postaci, wczytanej czy nie. Używaj go, żeby ubrać peda, który zastępuje postać (śpiące ciało, manekin): przekaż wynik bez zmian do `appearance.apply` klienta ([Lib: klient](/pl/docs/developers/api/lib-client)).

**Strona:** Serwer · **Czeka:** tak (Promise w TypeScript, w Lua wstrzymuje wątek)

```ts title="Sygnatura"
appearance.get(charId: number): Promise<CharacterAppearance | null>
```

```lua title="Lua"
local look = aiLib.appearance.get(charId) -- { model, data } albo nil, wywołuj wewnątrz wątku
```

<TypeTable
  type={{
    charId: { type: "number", description: "Id postaci (`CharacterInfo.id`).", required: true },
  }}
/>

#### Zwracana wartość

`Promise<CharacterAppearance | null>`: [`CharacterAppearance`](/pl/docs/developers/api/types#characterappearance) to `{ model, data }` (hash modelu peda i własne dane wyglądu skryptu ubrań). `null`, gdy postać go nie ma, nie działa żaden skrypt ubrań albo ai-core jest zatrzymany.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, online, playersNear } from "@aicore-fivem/lib/server";

async function sendLook(source: number) {
  const charId = online.charId(source);
  if (charId === undefined) return;
  const look = await appearance.get(charId);
  if (!look) return;
  // Wygląd potrzebny jest tylko graczom w pobliżu tej postaci.
  for (const other of playersNear(source, 100)) emitNet("my-sleepers:look", other, source, look);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local character = aiLib.online.character(source)
    if not character then return end
    local look = aiLib.appearance.get(character.id)
    if look then TriggerClientEvent('my-sleepers:look', source, look) end
end)
```
</Tab>
</Tabs>

### appearance.provider

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
appearance.provider(): string | null
```

```lua title="Lua"
local name = aiLib.appearance.provider()
```

**Zwraca** skrypt ubrań, który odpowiada, albo `null` (Lua `nil`), gdy żaden nie działa.

```ts
console.log(`looks through ${appearance.provider() ?? "nothing"}`);
```
