```ts title="TypeScript"
import { jobs, dispatch, prison, mdt, ems, medical, stress, needs, definitions, isPrimeTime } from "@aifivem/lib/server";
```

`jobs` and `definitions` are ai-core itself: the jobs and gangs of a character, and the job definitions of the server. Everything else here goes through one of ai-core's layers, where the script the server runs for that job (an alert system, a prison, an MDT, a death script, a HUD) answers. Your script keeps working when the owner swaps it. While no such script runs, those calls fail quietly (`false`, `0`, `null`).

## jobs

`jobs` is a loaded player's own jobs and gangs through ai-core: a character may hold several jobs, is on duty in at most one, and acts for one gang at a time. Reading **many** players at once is the lib's mirror [`online`](/docs/developers/api/lib-server/players#onlinejobs); changing a character who is **not** connected is [`characters`](/docs/developers/api/lib-server/characters#characterssetjob-and-charactersremovejob).

### jobs.current

The job other scripts see as "the" job of a player: the one they are on duty in, else the last one they were on duty in, else the first they hold, else the unemployed job.

**Side:** Server · **Waits:** no

```ts title="Signature"
jobs.current(source: number): JobMembership | null
```

```lua title="Lua"
local current = aiLib.jobs.current(source)
```

#### Returns

A [JobMembership](/docs/developers/api/types#jobmembership) (`{ job, grade }`), or `null` when the player has no loaded character.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs } from "@aifivem/lib/server";

export function isOfficer(source: number): boolean {
  return jobs.current(source)?.job === "police";
}
```
</Tab>
<Tab value="Lua">
```lua
local current = aiLib.jobs.current(source)
local officer = current and current.job == 'police'
```
</Tab>
</Tabs>

### jobs.duty and jobs.setDuty

Which job the player is on duty in, and going on or off duty. Many scripts check duty rather than membership: an officer off duty is a civilian.

**Side:** Server · **Waits:** no

```ts title="Signature"
jobs.duty(source: number): string | null
jobs.setDuty(source: number, job: string | null): boolean
```

```lua title="Lua"
local onDutyIn = aiLib.jobs.duty(source)
local ok = aiLib.jobs.setDuty(source, job)
```

#### Parameters

<TypeTable
  type={{
    source: { type: 'number', description: 'Server id of the player.', required: true },
    job: { type: 'string | null', description: 'A job the player holds, to go on duty in it. `null` (Lua `nil`) goes off duty.', required: true },
  }}
/>

#### Returns

`jobs.duty`: the job name, or `null` when off duty (or no character). `jobs.setDuty`: `true` when the change was made, `false` for a job the player does not hold.

### jobs.set

Adds a job to the player, or regrades a job they already hold. The panel's rules apply: how many jobs a character may hold and whether a second one is allowed at all.

**Side:** Server · **Waits:** no

```ts title="Signature"
jobs.set(source: number, job: string, grade: number): boolean
```

```lua title="Lua"
local ok = aiLib.jobs.set(source, job, grade)
```

#### Parameters

<TypeTable
  type={{
    source: { type: 'number', description: 'Server id of the player.', required: true },
    job: { type: 'string', description: 'The job name as the panel (or a script definition) has it.', required: true },
    grade: { type: 'number', description: 'The grade in that job, from 0. A grade the job does not have is refused.', required: true },
  }}
/>

#### Returns

`boolean`: `true` when the player holds the job at that grade afterwards. `false` for no loaded character, an unknown job, an unknown grade, or the panel's job limit.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs, notify } from "@aifivem/lib/server";

export function hire(source: number, job: string): void {
  if (!jobs.set(source, job, 0)) return notify(source, "Could not hire you", "error");
  notify(source, `Welcome to ${job}`, "success");
}
```
</Tab>
<Tab value="Lua">
```lua
if aiLib.jobs.set(source, 'mechanic', 0) then
    aiLib.notify(source, 'Welcome to mechanic', 'success')
end
```
</Tab>
</Tabs>

## dispatch

### dispatch.alert

Sends a police (or other job) alert. The alert system shows it to the on-duty members of `jobs`, default the police jobs.

**Side:** Server · **Waits:** no

```ts title="Signature"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

<TypeTable
  type={{
    title: { type: "string", description: "The headline, translated (`Shots fired`).", required: true },
    code: { type: "string", description: "Radio code shown before the title (`10-71`).", required: false },
    message: { type: "string", description: "One more line (the shop name).", required: false },
    coords: { type: "{ x: number; y: number; z: number }", description: "Where it happened. Without it, the `source` player’s position; without both, no map point.", required: false },
    jobs: { type: "string[]", description: "Jobs whose on-duty members get it.", default: "the alert system’s police jobs" },
    source: { type: "number", description: "The player the alert is about (shooter, robber). Systems that describe the suspect (vehicle, gender) read this player.", required: false },
    blip: { type: "{ sprite: number; color?: number; scale?: number }", description: "Map blip: a GTA blip sprite and colour.", default: "the alert system’s" },
    duration: { type: "number", description: "Seconds the alert stays (card, blip, waypoint key).", default: "the alert system’s" },
    icon: { type: "string", description: "Font Awesome solid icon name without `fa-` (`gun`).", required: false },
    priority: { type: '"normal" | "high"', description: "`high` makes the card stand out (armed robbery, officer down).", default: '"normal"' },
  }}
/>

The type is [`DispatchAlert`](/docs/developers/api/types#dispatchalert).

#### Returns

`boolean`: `true` when sent. `false` when no alert system runs or the alert is invalid.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, coordsOf, createLocale } from "@aifivem/lib/server";

const Locale = createLocale();

function storeRobbed(source: number, store: string) {
  dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

local function storeRobbed(source, store)
    local c = GetEntityCoords(GetPlayerPed(source))
    aiLib.dispatch.alert({
        code = '10-90',
        title = Locale('ALERT_STORE_ROBBERY'),
        message = store,
        coords = { x = c.x, y = c.y, z = c.z },
        source = source,
        icon = 'store',
        priority = 'high',
    })
end
```
</Tab>
</Tabs>

**Returns** [`JobDefinition`](/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`), or `null` when no such job exists.

```ts
const label = definitions.job("police")?.label ?? "police";
```

### definitions.gang

**Side:** Server · **Waits:** no

```ts title="Signature"
definitions.gang(name: string): GangDefinition | null
```


### definitions.registerJob and definitions.removeJob

A job your script brings with it, without the owner adding it in the panel: a job of the calling resource, gone when the resource stops and never written to the panel's file.

**Side:** Server · **Waits:** no

```ts title="Signature"
definitions.registerJob(name: string, definition: JobDefinition): CharacterResult
definitions.removeJob(name: string): boolean
```

```lua title="Lua"
local result = aiLib.definitions.registerJob(name, definition)
local ok = aiLib.definitions.removeJob(name)
```

#### Parameters

<TypeTable
  type={{
    name: { type: 'string', description: 'The job name your script uses (`"my-garbagejob"`).', required: true },
    definition: { type: 'JobDefinition', typeDescriptionLink: '/docs/developers/api/types#jobdefinition', description: 'The job itself: `label`, `type`, `defaultDuty`, `listed`, and its `grades` (each with `label`, `salary`, `boss`).', required: true },
  }}
/>

#### Returns

`registerJob` answers [ActionResult](/docs/developers/api/types#actionresult): `{ ok: true }`, or `{ ok: false, error }` with a lang key when the panel already has a job of that name or another resource registered it - the owner's panel always wins. `removeJob` answers `true` only for a job this resource registered.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { definitions } from "@aifivem/lib/server";

// Once at start: the job exists while this resource runs.
const result = definitions.registerJob("garbage", {
  label: "Garbage",
  type: "job",
  defaultDuty: true,
  grades: [{ label: "Driver", salary: 60, boss: false }],
});
if (!result.ok) console.log(`job not registered: ${result.error}`);
```
</Tab>
<Tab value="Lua">
```lua
local result = aiLib.definitions.registerJob('garbage', {
    label = 'Garbage',
    type = 'job',
    defaultDuty = true,
    grades = { { label = 'Driver', salary = 60, boss = false } },
})
if not result.ok then print(('job not registered: %s'):format(result.error)) end
```
</Tab>
</Tabs>

<Callout type="info">
A job the server owner should be able to edit belongs in the panel, not here. Register one when the job is part of your script and means nothing without it.
</Callout>

## Prime time

**Side:** Server · **Waits:** no

```ts title="Signature"
isPrimeTime(job?: string): boolean
```

No Lua twin: call ai-core's export `IsPrimeTime(job)`.

<TypeTable
  type={{
    job: { type: "string", description: "Job whose prime time to check. Without it, the default hours.", required: false },
  }}
/>

**Returns** `true` during prime time.

