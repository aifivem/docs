Each object here goes through one of ai-core's layers: the script the server runs for that job (an alert system, a prison, an MDT, a death script, a HUD) answers. Your script keeps working when the owner swaps it. While no such script runs, calls fail quietly (`false`, `0`, `null`).

## dispatch

### dispatch.alert

Sends a police (or other job) alert. The alert system shows it to the on-duty members of `jobs`, default the police jobs.

**Side:** Server · **Waits:** no

```ts title="Signature"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

<TypeTable
  type={{
    title: { type: "string", description: "The headline, translated (`Shots fired`).", required: true },
    code: { type: "string", description: "Radio code shown before the title (`10-71`).", required: false },
    message: { type: "string", description: "One more line (the shop name).", required: false },
    coords: { type: "{ x: number; y: number; z: number }", description: "Where it happened. Without it, the `source` player’s position; without both, no map point.", required: false },
    jobs: { type: "string[]", description: "Jobs whose on-duty members get it.", default: "the alert system’s police jobs" },
    source: { type: "number", description: "The player the alert is about (shooter, robber). Systems that describe the suspect (vehicle, gender) read this player.", required: false },
    blip: { type: "{ sprite: number; color?: number; scale?: number }", description: "Map blip: a GTA blip sprite and colour.", default: "the alert system’s" },
    duration: { type: "number", description: "Seconds the alert stays (card, blip, waypoint key).", default: "the alert system’s" },
    icon: { type: "string", description: "Font Awesome solid icon name without `fa-` (`gun`).", required: false },
    priority: { type: '"normal" | "high"', description: "`high` makes the card stand out (armed robbery, officer down).", default: '"normal"' },
  }}
/>

The type is [`DispatchAlert`](/docs/developers/api/types#dispatchalert).

#### Returns

`boolean`: `true` when sent. `false` when no alert system runs or the alert is invalid.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, coordsOf, createLocale } from "@aicore-fivem/lib/server";

const Locale = createLocale();

function storeRobbed(source: number, store: string) {
  dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

local function storeRobbed(source, store)
    local c = GetEntityCoords(GetPlayerPed(source))
    aiLib.dispatch.alert({
        code = '10-90',
        title = Locale('ALERT_STORE_ROBBERY'),
        message = store,
        coords = { x = c.x, y = c.y, z = c.z },
        source = source,
        icon = 'store',
        priority = 'high',
    })
end
```
</Tab>
</Tabs>

## prison

Jail sentences through ai-core, whatever prison script runs.

### prison.jail

Sends a loaded player to prison.

**Side:** Server · **Waits:** no

```ts title="Signature"
prison.jail(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local ok = aiLib.prison.jail(source, minutes, by)
```

<TypeTable
  type={{
    source: { type: "number", description: "Server id of the player to jail.", required: true },
    minutes: { type: "number", description: "Sentence length in minutes.", required: true },
    by: { type: "number", description: "Server id of who sent them (for the log). 0 means the server.", default: "0" },
  }}
/>

**Returns** `true` when jailed, `false` while no prison runs.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

```
</Tab>
<Tab value="Lua">
```lua
if not aiLib.prison.jail(target, 15, officer) then return aiLib.fail('NO_PRISON') end
```
</Tab>
</Tabs>

## mdt

Police MDT records (fines, warrants, arrests, jail) through ai-core's MDT layer. Nothing is written while no MDT runs.

### mdt.record

Writes a record into the police MDT.

**Side:** Server · **Waits:** no

```ts title="Signature"
mdt.record(record: MdtRecord): boolean
```

```lua title="Lua"
local ok = aiLib.mdt.record(record)
```

#### MdtRecord

<TypeTable
  type={{
    kind: { type: '"fine" | "warrant" | "arrest" | "jail"', description: "The kind of record.", required: true },
    target: { type: "number", description: "Server id of the player the record is about.", required: true },
    by: { type: "number", description: "Server id of the officer who writes it.", required: false },
    title: { type: "string", description: "What happened, translated (`Armed robbery`).", required: true },
    amount: { type: "number", description: "A fine’s amount in dollars.", required: false },
    minutes: { type: "number", description: "A jail sentence in minutes.", required: false },
  }}
/>

The type is [`MdtRecord`](/docs/developers/api/types#mdtrecord).

**Returns** `true` when written, `false` when no MDT runs or it takes no such record.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
if (prison.jail(target, 20, officer)) mdt.record({ kind: "jail", target, by: officer, title: "Armed robbery", minutes: 20 });
```
</Tab>
<Tab value="Lua">
```lua
if aiLib.prison.jail(target, 20, officer) then
    aiLib.mdt.record({ kind = 'jail', target = target, by = officer, title = 'Armed robbery', minutes = 20 })
end
```
</Tab>
</Tabs>

### mdt.provider

**Side:** Server · **Waits:** no

```ts title="Signature"
mdt.provider(): string | null
```

```lua title="Lua"
local name = aiLib.mdt.provider()
```

**Returns** the MDT that records go to, or `null`.

```ts
if (!mdt.provider()) console.log("no MDT: records are skipped");
```

## ems

Medics through ai-core's EMS layer: an EMS script's own count and distress calls, else ai-core's duty counts and alerts.

### ems.available

How many medics are free to take a call.

**Side:** Server · **Waits:** no

```ts title="Signature"
ems.available(jobs: string[]): number
```

```lua title="Lua"
local count = aiLib.ems.available(jobs)
```

<TypeTable
  type={{
    jobs: { type: "string[]", description: "The EMS job names to count (`[\"ambulance\"]`).", required: true },
  }}
/>

**Returns** the number of medics on duty in `jobs`, leaving out busy ones when a dispatch script knows them.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
// Let players respawn at the hospital only when no medic can come.
const canRespawn = ems.available(["ambulance"]) === 0;
```
</Tab>
<Tab value="Lua">
```lua
local canRespawn = aiLib.ems.available({ 'ambulance' }) == 0
```
</Tab>
</Tabs>

## medical

Revive, heal and the down state through ai-core's medical layer, whatever death or ambulance script runs. No Lua twin: call ai-core's exports `RevivePlayer`, `HealPlayer`, `IsPlayerDead`.

### medical.revive

Gets a downed player up where they lie.

**Side:** Server · **Waits:** no

```ts title="Signature"
medical.revive(source: number): boolean
```

**Returns** `true` when revived, `false` when not down or no death script runs.

```ts
if (!medical.revive(target)) return fail("NOT_DOWN");
```

### medical.heal

Gives full health to a player who is not down.

**Side:** Server · **Waits:** no

```ts title="Signature"
medical.heal(source: number): boolean
```

**Returns** `true` when healed, `false` when no death script runs.

```ts
medical.heal(source);
```

### medical.isDead

Whether the player is down.

**Side:** Server · **Waits:** no

```ts title="Signature"
medical.isDead(source: number): boolean
```

**Returns** `true` when down; `false` without a death script. Use it instead of reading the ped's health.

```ts
if (medical.isDead(source)) return fail("YOU_ARE_DOWN");
```

### medical.provider

**Side:** Server · **Waits:** no

```ts title="Signature"
medical.provider(): string | null
```

**Returns** the death script that answers (`ai-death`...), or `null` when none runs.

```ts
console.log(`deaths through ${medical.provider() ?? "nothing"}`);
```

## needs

### needs.refill

Fills hunger and thirst to full (admin revive, hospital), through the HUD that keeps them, or ai-core's character metadata without one.

**Side:** Server · **Waits:** no

```ts title="Signature"
needs.refill(source: number): boolean
```

No Lua twin: call ai-core's export `RefillNeeds(source)`.

```ts
if (medical.revive(target)) needs.refill(target);
```

## Job and gang definitions

### definitions.job

A job's definition as set in ai-core's panel. Each one is read once from ai-core and kept until the panel changes it, so a read is a memory lookup.

**Side:** Server · **Waits:** no

```ts title="Signature"
definitions.job(name: string): JobDefinition | null
```

No Lua twin: call ai-core's export `GetJobDefinition(name)`.

**Returns** [`JobDefinition`](/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`), or `null` when no such job exists.

```ts
const label = definitions.job("police")?.label ?? "police";
```

### definitions.gang

**Side:** Server · **Waits:** no

```ts title="Signature"
definitions.gang(name: string): GangDefinition | null
```

No Lua twin: call ai-core's export `GetGangDefinition(name)`.

**Returns** [`GangDefinition`](/docs/developers/api/types#gangdefinition) (`label`, `grades`), or `null`.

```ts
const gang = definitions.gang("ballas");
if (!gang) return fail("UNKNOWN_GANG");
```

## Prime time

### isPrimeTime

Whether it is prime time for a job, from ai-core's prime time setting. The hours come from tgiann-policealert while it runs, else from the hours set in ai-core's panel.

**Side:** Server · **Waits:** no

```ts title="Signature"
isPrimeTime(job?: string): boolean
```

No Lua twin: call ai-core's export `IsPrimeTime(job)`.

<TypeTable
  type={{
    job: { type: "string", description: "Job whose prime time to check. Without it, the default hours.", required: false },
  }}
/>

**Returns** `true` during prime time.

```ts
if (!isPrimeTime("police")) return fail("BANK_CLOSED_FOR_HEISTS");
```
