---
title: Logs
description: "aiLog and aiLogChannels: send logs through ai-core to the console, Discord, Fivemanage or FiveM Stats, whatever the owner turns on in the panel."
icon: ScrollText
---

```ts title="TypeScript"
import { aiLog, aiLogChannels } from "@aifivem/lib/server";
```

Your script never posts to Discord or a log service itself. It sends a log to ai-core on a **channel** (a name like `purchase`); the server owner decides in ai-core's admin panel where each channel goes. Webhook urls and API keys stay in the panel, never in your code.

### aiLog

Sends one log line through ai-core's log system.

**Side:** Server · **Waits:** no

```ts title="Signature"
aiLog(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
aiLib.aiLog(channel, message, options)
```

#### Parameters

<TypeTable
  type={{
    channel: { type: "string", description: "The channel name (`purchase`, `admin`). Describe your channels once with `aiLogChannels`.", required: true },
    message: { type: "string", description: "What happened. Pass the players as `source` / `target` instead of writing names into the text.", required: true },
    options: { type: "LogOptions", typeDescriptionLink: "/docs/developers/api/types#logoptions", description: "Level, players and extra values. Fields below.", required: false },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: "Severity.", required: false },
    source: { type: "number", description: "Server id of the player who did it. Their name, character and identifiers are added.", required: false },
    target: { type: "number", description: "Server id of the player it was done to.", required: false },
    metadata: { type: "Record<string, unknown>", description: "Extra fields (amounts, item names, coordinates).", required: false },
  }}
/>

#### Returns

`void`. In TypeScript it does nothing while ai-core is not running; the Lua twin prints `[channel] message` to the console instead.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { aiLog } from "@aifivem/lib/server";

aiLog("purchase", `bought ${count}x ${item} for $${price}`, {
  source,
  metadata: { item, count, price },
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.aiLog('purchase', ('bought %dx %s for $%d'):format(count, item, price), {
    source = source,
    metadata = { item = item, count = count, price = price },
})
```
</Tab>
</Tabs>

### aiLogChannels

Describes your resource's log channels: the dataset name used by Fivemanage and FiveM Stats, and whether a channel is on. Call it once when your script starts.

**Side:** Server · **Waits:** no

```ts title="Signature"
aiLogChannels(channels: Record<string, LogChannel>): void
```

No Lua twin: call ai-core's export `exports['ai-core']:LogChannels(channels)`.

#### Parameters

<TypeTable
  type={{
    channels: { type: "Record<string, LogChannel>", typeDescriptionLink: "/docs/developers/api/types#logchannel", description: "One entry per channel name. Each `LogChannel` has `dataset?` (Fivemanage / FiveM Stats dataset, default the resource name) and `active?` (`false` turns the channel off).", required: true },
  }}
/>

#### Returns

`void`. Does nothing while ai-core is not running.

#### Example

```ts
import { aiLogChannels } from "@aifivem/lib/server";

aiLogChannels({
  purchase: { dataset: "shops" },
  debug: { active: false },
});
```
