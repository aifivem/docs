## Spawnowanie

### spawnVehicle

Tworzy pojazd sieciowy na serwerze i konfiguruje go w jednym wywołaniu: tablica, paliwo, wygląd, zamek, routing bucket, klucze do właściwego celu, kierowca i pasażerowie. Używaj go dla każdego pojazdu skryptu (pojazdy pracy, wypożyczenia, pojazdy z garażu, spawny administratora).

**Strona:** Serwer · **Czeka:** tak (Promise w TypeScript, w Lua wstrzymuje wątek)

```ts title="Sygnatura"
spawnVehicle(options: SpawnVehicleOptions): Promise<number | null>
```

```lua title="Lua"
local vehicle = aiLib.spawnVehicle(options) -- encja albo nil, wywołuj wewnątrz wątku
```

#### Zwracana wartość

`Promise<number | null>`: uchwyt encji pojazdu. `null`, gdy model nie istnieje (tak powiedział klient `asker`), encja nie została utworzona w ciągu 5 sekund albo typ jest nieznany.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, spawnVehicle, hasCharacter, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const DEPOT = { x: 895.4, y: -179.3, z: 74.7 };

onClientCallback(
  "my-taxi:start",
  async (source) => {
    const vehicle = await spawnVehicle({
      model: "taxi",
      coords: { x: 899.1, y: -180.6, z: 73.8, heading: 238 },
      asker: source,
      keysTo: source,
      purpose: "job",
      driver: source,
      fuel: 100,
      setup: { dirt: 0 },
    });
    if (!vehicle) return fail("SPAWN_FAILED");
    return { ok: true, netId: NetworkGetNetworkIdFromEntity(vehicle) };
  },
  { guards: [hasCharacter(), near(DEPOT, 5)], lock: true },
);
```
</Tab>


<Callout type="info">
Klucze czekają (do 3 sekund), aż serwer odczyta tablicę: przed pierwszą synchronizacją klienta właściciela serwer czyta pustą tablicę. Sadzani gracze są wsadzani ponownie przez maksymalnie 2 sekundy, aż usiądą. W TypeScript typ modelu od jednego klienta służy tylko temu graczowi, dopóki klient drugiego gracza nie poda tej samej odpowiedzi; odpowiednik w Lua zachowuje pierwszą odpowiedź, jaką dostanie.
</Callout>

### vehicleType

Typ spawnu modelu, zapytany od klienta gracza. Używaj go, żeby sprawdzić, czy model istnieje, zanim weźmiesz pieniądze.

**Strona:** Serwer · **Czeka:** tak (Promise)

```ts title="Sygnatura"
vehicleType(model: string, asker: number): Promise<string | null>
```

Brak odpowiednika w Lua: `aiLib.spawnVehicle` z `asker` to sprawdza i zwraca `nil` dla nieznanego modelu.

<TypeTable
  type={{
    model: { type: "string", description: "Nazwa spawnu modelu.", required: true },
    asker: { type: "number", description: "Id serwerowe gracza, którego klient odpowiada.", required: true },
  }}
/>

#### Zwracana wartość

`Promise<string | null>`: `automobile`, `bike`, `boat`, `heli`, `plane`, `submarine`, `trailer` albo `train`; `null`, gdy gra nie ma takiego pojazdu albo klient nie dał poprawnej odpowiedzi. Odpowiedź jest zachowywana dla wszystkich, gdy zgodzą się co do niej klienty dwóch różnych graczy, więc jeden zmodyfikowany klient może zepsuć tylko własne spawny.

#### Przykład

```ts
import { onClientCallback, vehicleType } from "@aifivem/lib/server";
import { fail, oneArg, readText } from "@aifivem/lib/shared";

onClientCallback("my-dealer:buy", { args: oneArg((v) => readText(v, 32)), lock: true }, async (source, model) => {
  if (!(await vehicleType(model, source))) return fail("UNKNOWN_MODEL");
  // weź pieniądze, potem spawnVehicle(...)
  return { ok: true };
});
```

### randomPlate

Losowa tablica jak w samej grze (dwie cyfry, trzy litery, trzy cyfry) albo twój prefiks i po nim cyfry.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
randomPlate(prefix?: string): string
```

Brak odpowiednika w Lua (`aiLib.spawnVehicle` ustawia losową tablicę, gdy żadnej nie podasz).

<TypeTable
  type={{
    prefix: { type: "string", description: "Tekst, od którego zaczyna się tablica; reszta jest wypełniana cyframi do 8 znaków. Dłuższy niż 8 jest skracany.", required: false },
  }}
/>

**Zwraca** 8-znakową tablicę (`42ABC123` albo `TAXI1234` dla `randomPlate("TAXI")`). Nie jest sprawdzana pod kątem unikalności: sprawdź własną tabelę, zanim ją zapiszesz.

```ts
const plate = randomPlate("RENT");
```

### nearestVehicleTo

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
nearestVehicleTo(source: number, metres: number, filter?: (vehicle: number) => boolean): number
```


### nearestVehicleAt

Najbliższy pojazd w odległości `metres` od punktu. Używaj jej, żeby sprawdzić, czy miejsce spawnu jest wolne.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
nearestVehicleAt(point: { x: number; y: number; z: number }, metres: number, filter?: (vehicle: number) => boolean): number
```

Brak odpowiednika w Lua.

**Zwraca** encję pojazdu albo `0`, gdy nie ma żadnego. Przechodzi po każdym pojeździe, jak `nearestVehicleTo`.

```ts
const SPOT = { x: 899.1, y: -180.6, z: 73.8 };
if (nearestVehicleAt(SPOT, 3)) return fail("SPOT_BLOCKED");
```

## Paliwo

`fuel` czyta i ustawia paliwo pojazdu (od 0 do 100) przez warstwę paliwa ai-core, niezależnie od tego, jaki skrypt paliwa działa. Brak odpowiednika w Lua na serwerze: wywołaj eksporty ai-core `GetVehicleFuel` / `SetVehicleFuel`.

### fuel.get

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
fuel.get(vehicle: number): number | null
```

**Zwraca** poziom encji pojazdu serwerowego (od 0 do 100) albo `null`, gdy go nie ma.

```ts
const level = fuel.get(vehicle) ?? 0;
```

### fuel.set

**Strona:** Serwer · **Czeka:** nie


  }}
/>

**Zwraca** `true`, gdy ustawiono, `false` dla złego pojazdu.

### fuel.provider

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
fuel.provider(): string | null
```

## Garaże

`garages` przechodzi przez warstwę garaży ai-core, niezależnie od tego, jaki skrypt garaży działa; każdy skrypt odpowiada tylko na to, co udostępnia. Brak odpowiednika w Lua.
