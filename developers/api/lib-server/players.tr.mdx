**Oyuncu**, server id’si (`source`) olan bağlı bir client’tır. **Karakter** ise oynadığı kişidir; karakter ekranındaki bir oyuncunun yüklü karakteri yoktur. Oyuncuların ve karakterlerin sahibi ai-core’dur; bu yardımcılar onları okur.

## online

`online`, resource’unun ai-core’un yüklü oyuncularından tuttuğu kopyadır: karakterler, rütbeleriyle meslek ve çete üyelikleri, meslek ve çete başına üye listeleri ve görev durumu. İlk kullanımda ai-core’u bir kez okur, sonra ai-core’un event’lerini takip eder; bu yüzden bir okuma bellekten bakmaktır. Sık çalışan yollarda (her sohbet mesajı, her ihbar) ai-core’un export’larını çağırmak yerine bunu kullan.

Lua’da `aiLib.online` her çağrıda ai-core’un export’larına sorar: aksiyonlar için uygundur, her tick için değil. `character`, `name`, `jobs`, `gangs`, `jobGrade`, `gangGrade`, `dutyJob` ve `sources` vardır; geri kalanının Lua karşılığı yoktur.

### online.sources

Yüklü karakteri olan her oyuncunun server id’si.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
online.sources(): IterableIterator<number>
```

```lua title="Lua"
local list = aiLib.online.sources() -- integer[]
```

#### Dönüş değeri

`IterableIterator<number>` (Lua: bir dizi). Karakter ekranındaki oyuncular içinde değildir.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { online, notify } from "@aicore-fivem/lib/server";

for (const source of online.sources()) notify(source, "Server restart in 5 minutes", "warning", 10_000);
```
</Tab>
<Tab value="Lua">
```lua
for _, source in ipairs(aiLib.online.sources()) do
    aiLib.notify(source, 'Server restart in 5 minutes', 'warning', 10000)
end
```
</Tab>
</Tabs>

### online.allows

Oyuncunun bir erişim kuralıyla (meslekler, çeteler, minimum rütbeler, görevde olma) kilitlenmiş bir yeri kullanıp kullanamayacağı. Client’ın `allows`’u aynı kuralı kullanır; böylece oyuncunun gördüğü, server’ın kullanmasına izin verdiğiyle aynıdır.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
online.allows(source: number, rule: AccessRule): boolean
```

Lua karşılığı yok.

<TypeTable
  type={{
    source: { type: "number", description: "Oyuncunun server id’si.", required: true },
    rule: { type: "AccessRule", typeDescriptionLink: "/tr/docs/developers/api/types#accessrule", description: "`{ jobs, gangs, grades, onDuty }`, bir panel kaydından `readAccess(record)` ile okunur. İki liste de boş: herkes.", required: true },
  }}
/>

**Dönüş değeri**: listeler boşsa, oyuncu `gangs`’ten birinde minimum rütbesindeyse ya da `jobs`’tan birinde minimum rütbesindeyse (ve `onDuty` ayarlıysa o meslekte görevdeyse) `true`.

```ts
import { online } from "@aicore-fivem/lib/server";
import { readAccess, fail } from "@aicore-fivem/lib/shared";

const rule = readAccess(stashRecord); // { jobs: ["police"], gangs: [], grades: { police: 2 }, onDuty: true }
if (!online.allows(source, rule)) return fail("NO_ACCESS");
```

## Karakter yaşam döngüsü

### onCharacter

Bir karakter dünyaya girdiğinde ve ayrıldığında kodunu çalıştırır. Resource’un (yeniden) başladığında dünyada zaten olan karakterleri de yeniden oynatır ve oyundan çıkmaları kapsar; bu yüzden yanında bir `playerDropped` handler’ına ihtiyacın olmaz.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
onCharacter(handlers: CharacterHandlers): void
```

```lua title="Lua"
aiLib.onCharacter({ loaded = function(source, character) end, unloaded = function(source, charId, reason) end })
```

#### CharacterHandlers

<TypeTable
  type={{
    loaded: { type: "(source: number, character: CharacterInfo) => void | Promise<void>", typeDescriptionLink: "/tr/docs/developers/api/types#characterinfo", description: "Bir karakter dünyaya girdi. Ayrıca `onCharacter`’ı çağırdıktan sonraki tick’te, resource’un başlamadan önce yüklenmiş her karakter için bir kez çalışır. Fırlatılan bir hata ya da reddetme loglanır.", required: false },
    unloaded: { type: '(source: number, charId: number, reason: "dropped" | "switch") => void', description: "Karakter ayrıldı: çıkış yapma ya da karakter değiştirme için `switch`, oyuncunun bağlantısı koptuğunda `dropped`. Her `loaded` tam olarak bir `unloaded` alır.", required: false },
  }}
/>

#### Dönüş değeri

`void`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onCharacter, PlayerMap } from "@aicore-fivem/lib/server";

const playtime = new PlayerMap<{ charId: number; since: number }>();

onCharacter({
  loaded(source, character) {
    playtime.set(source, { charId: character.id, since: Date.now() });
  },
  unloaded(source, charId, reason) {
    const entry = playtime.get(source);
    if (entry) console.log(`character ${charId} played ${Date.now() - entry.since} ms (${reason})`);
    playtime.delete(source);
  },
});
```
</Tab>
<Tab value="Lua">
```lua
local since = {}

aiLib.onCharacter({
    loaded = function(source, character)
        since[source] = os.time()
    end,
    unloaded = function(source, charId, reason)
        print(('character %d played %ds (%s)'):format(charId, os.time() - (since[source] or os.time()), reason))
        since[source] = nil
    end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Onu bir server dosyasının en üst seviyesinde bir kez çağır. Yukarıdaki PlayerMap oyundan çıkışta kendiliğinden boşalır; bir çıkış için `unloaded` handler’ı yine önce çalışır, böylece veriyi orada kaydedebilirsin.
</Callout>

## Oyuncularla konuşmak

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
notify(source: number, text: string, kind?: NotificationKind, duration?: number): void
```

```lua title="Lua"
aiLib.notify(source, text, kind, duration)
```

#### Parametreler

<Tabs items={['TypeScript', 'Lua']}>

### isOnline

Bir oyuncunun hâlâ bağlı olup olmadığı. Uzun bir `await`’ten sonra bir şey vermeden önce kontrol et.

**Taraf:** Server · **Bekler:** hayır

```

await new Promise((resolve) => setTimeout(resolve, 60_000));

```

## Yakındaki oyuncular

## Oyuncu başına depolar

Bunların hiçbirinin Lua karşılığı yok: bir Lua tablosu kullan ve onu `playerDropped`’ta temizle. Her depoyu modül seviyesinde bir kez oluştur, asla bir handler içinde değil.

### PlayerMap

Oyuncu server id’siyle anahtarlanan ve oyuncu oyundan çıktığında kendini boşaltan bir `Map`. Oyuncu başına tuttuğun her şey için kullan (açık bir ekran, seçili bir eşya).

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
new PlayerMap<V>(options?: { onDrop?: (source: number, value: V) => void })
```

<TypeTable
  type={{
    "options.onDrop": { type: "(source: number, value: V) => void", description: "Oyundan çıkan bir oyuncunun girdisi kaldırıldıktan sonra son değeriyle çalışır (bir aksiyonu bitir, bir şey kaydet).", required: false },
  }}
/>

Bir JavaScript `Map`’inin tüm metotlarına sahiptir (`get`, `set`, `has`, `delete`, `size`, iterasyon).

```ts
import { PlayerMap } from "@aicore-fivem/lib/server";

const carrying = new PlayerMap<string>({
  onDrop: (source, item) => console.log(`${source} left while carrying ${item}`),
});
carrying.set(source, "box");
```

### Cooldowns

Oyun saatine göre oyuncu başına cooldown’lar; oyuncu oyundan çıktığında serbest bırakılır.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
new Cooldowns()
ready(source: number): boolean
start(source: number, ms: number): void
take(source: number, ms: number): boolean
left(source: number): number
clear(source: number): void
```

| Metot | Ne yapar | Dönüş değeri |
| --- | --- | --- |
| `ready(source)` | Oyuncu için çalışan bir cooldown yok. | `boolean` |
| `start(source, ms)` | Oyuncunun cooldown’ını `ms` milisaniye için başlatır (ya da yeniden başlatır). | `void` |
| `take(source, ms)` | Hazırsa cooldown’ı başlatır. | başladıysa `true`, biri hâlâ çalışıyorken `false` |
| `left(source)` | Kalan milisaniye. | `number`, hazırsa `0` |
| `clear(source)` | Oyuncunun cooldown’ını bitirir. | `void` |

```ts
import { onClientCallback, Cooldowns } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const searchCooldown = new Cooldowns();

onClientCallback("my-bins:search", (source) => {
  if (!searchCooldown.take(source, 30_000)) return fail("WAIT");
  return { ok: true };
});
```

<Callout type="warn">
Bir oyuncu yeniden bağlanarak bir `Cooldowns` girdisini sıfırlayabilir. Yeniden bağlanmadan sonra da kalması gereken bir cooldown, `online.charId(source)` ile anahtarlanan `KeyedCooldowns` kullanır.
</Callout>

### KeyedCooldowns

Bir bağlantıdan uzun yaşayan herhangi bir anahtara göre cooldown’lar: bir karakter id’si, bir entity, bir kapı id’si. Süresi dolan girdiler map büyüdükçe temizlenir.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
new KeyedCooldowns<K = number>()
ready(key: K): boolean
start(key: K, ms: number): void
take(key: K, ms: number): boolean
left(key: K): number
clear(key: K): void
```

`Cooldowns` ile aynı metotlar, `key`’e göre. `ms` 0 ya da daha az olan bir `start` cooldown’ı bitirir.

```ts
import { KeyedCooldowns, online } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const robbed = new KeyedCooldowns<string>(); // market id’sine göre
const perCharacter = new KeyedCooldowns(); // karakter id’sine göre

function canRob(source: number, store: string) {
  const charId = online.charId(source);
  if (charId === undefined) return fail("NO_CHARACTER");
  if (!robbed.ready(store)) return fail("STORE_EMPTY");
  if (!perCharacter.take(charId, 15 * 60_000)) return fail("WAIT");
  robbed.start(store, 30 * 60_000);
  return { ok: true };
}
```

### SourceLock

Birkaç callback genelinde oyuncu başına çalışan tek bir aksiyon. Bir callback’in kendi `lock: true`’su yalnızca o callback’i kapsar; birbirini dışlaması gereken iki aksiyon (aynı aracı listelemek ve satmak) tek bir `SourceLock` paylaşır.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
new SourceLock()
run<T, B>(source: number, busy: B, task: () => Promise<T>): Promise<T | B>
release(source: number): void
```

<TypeTable
  type={{
    source: { type: "number", description: "Oyuncunun server id’si.", required: true },
    busy: { type: "B", description: "Oyuncunun zaten çalışan bir görevi varsa `run`’ın döndürdüğü (`fail(\"BUSY\")`).", required: true },
    task: { type: "() => Promise<T>", description: "Aksiyon. Kilit, görev sonuçlandığında, hata fırlatsa bile serbest bırakılır.", required: true },
  }}
/>

**Dönüş değeri** (`run`): görevin sonucu ya da `busy`. `release(source)` oyuncuyu serbest bırakır; onu `playerDropped`’tan çağır (hâlâ çalışan bir görev, sonuçlanana kadar kendi girdisini tutar).

```ts
import { onClientCallback, SourceLock } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const dealer = new SourceLock();
on("playerDropped", () => dealer.release(Number(globalThis.source)));

onClientCallback("my-dealer:list", (source) => dealer.run(source, fail("BUSY"), async () => ({ ok: true })));
onClientCallback("my-dealer:sell", (source) => dealer.run(source, fail("BUSY"), async () => ({ ok: true })));
```

### RateLimit

Oyuncu başına bir patlama sınırı: herhangi bir `windowMs` içinde en fazla `count` aksiyon. Kapı zaten her girdiye hız sınırı uygular; bunu tek bir aksiyon için ek, daha yavaş bir sınır olarak kullan.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
new RateLimit(count: number, windowMs: number)
take(source: number): boolean
release(source: number): void
```

```lua title="Lua"
local limit = aiLib.RateLimit.new(count, windowMs)
local allowed = limit:take(source)
limit:release(source)
```

<TypeTable
  type={{
    count: { type: "number", description: "Pencere başına izin verilen aksiyon sayısı.", required: true },
    windowMs: { type: "number", description: "Milisaniye cinsinden pencere uzunluğu (kayan pencere).", required: true },
  }}
/>

**Dönüş değeri** (`take`): `true` ve bir aksiyonu sayar ya da oyuncu sınırı aşmışsa `false` (sayılmaz). `release(source)` oyuncuyu unutur; onu `playerDropped`’tan çağır.

### KeyWatchers

Tek bir anahtarın canlı değişikliklerini alan oyuncular (bir otoparkın arabaları, açık bir karakter sayfası). Oyuncu başına bir anahtar: yeni bir anahtarı izlemek eskisini bırakır. Oyundan çıkışta serbest bırakılır; her işlem sabit zamanlıdır.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
new KeyWatchers<K>()
watch(source: number, key: K): void
stop(source: number): void
of(key: K): ReadonlySet<number> | undefined
keyOf(source: number): K | undefined
```

| Metot | Ne yapar | Dönüş değeri |
| --- | --- | --- |
| `watch(source, key)` | Oyuncu `key`’i izler ve öncekini izlemeyi bırakır. | `void` |
| `stop(source)` | Oyuncu izlemeyi bırakır. | `void` |
| `of(key)` | `key`’i izleyen oyuncular. | bir set ya da kimse izlemiyorsa `undefined` |
| `keyOf(source)` | Oyuncunun izlediği anahtar. | anahtar ya da `undefined` |

```ts
import { onClientCallback, onClientEvent, KeyWatchers } from "@aicore-fivem/lib/server";
import { oneArg, readText } from "@aicore-fivem/lib/shared";

const lots = new KeyWatchers<string>();

onClientCallback("my-lot:open", { args: oneArg((v) => readText(v, 32)) }, (source, lot) => {
  lots.watch(source, lot);
  return { ok: true, cars: [] }; // snapshot
});
onClientEvent("my-lot:close", (source) => lots.stop(source));

function carChanged(lot: string, car: unknown) {
  for (const source of lots.of(lot) ?? []) emitNet("my-lot:car", source, car); // delta
}
```
