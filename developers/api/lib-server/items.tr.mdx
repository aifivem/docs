```ts title="TypeScript"
import { inventory } from "@aicore-fivem/lib/server";
```

`inventory` her eşya çağrısını ai-core’un envanter katmanı üzerinden gönderir: sunucunun çalıştırdığı envanter (ai-inventory ya da sahibin ai-core panelinde seçtiği başka bir envanter) cevap verir. Script’in hiçbir zaman bir envanterin kendi export’larını çağırmaz; böylece sahip envanteri değiştirdiğinde çalışmaya devam eder.

**Envanter argümanı** (`inv`, tip [`InventoryRef`](/tr/docs/developers/api/types#inventoryref)) bir oyuncunun server id’si (bir sayı) ya da başka bir envanterin id’sidir (bir string: bir stash adı, bir plaka).

**Miktarlar** 1 ya da daha büyük tam sayılardır; kesirli bir sayı aşağı yuvarlanır, `0` ya da negatif bir miktar çağrının başarısız olmasına yol açar.

<Callout type="info">
Hiçbir envanter çalışmıyorken çağrılar sessizce başarısız olur: `false`, `0`, boş bir liste ya da `null`. `aiLib.inventory` üzerindeki Lua karşılıkları aynı adlara ve argüman sırasına sahiptir.
</Callout>

### inventory.addItem

Bir envantere eşya verir.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
inventory.addItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = aiLib.inventory.addItem(inv, item, count, metadata, slot)
```

#### Parametreler

<TypeTable
  type={{
    inv: { type: "InventoryRef", typeDescriptionLink: "/tr/docs/developers/api/types#inventoryref", description: "Oyuncunun server id’si ya da bir stash adı veya plaka.", required: true },
    item: { type: "string", description: "Envanterin bildiği haliyle eşya adı (`water`).", required: true },
    count: { type: "number", description: "Kaç tane.", default: "1" },
    metadata: { type: "ItemMetadata", typeDescriptionLink: "/tr/docs/developers/api/types#itemmetadata", description: "Yığında saklanan ek veri (`{ serial: \"A1\" }`). Metadata’sı farklı yığınlar birleşmez.", required: false },
    slot: { type: "number", description: "Envanter destekliyorsa onları bu slota koy (1 ya da daha büyük).", required: false },
  }}
/>

#### Dönüş değeri

`boolean`: verildiyse `true`. Sığmıyorlarsa, eşya yoksa, bir argüman yanlışsa ya da hiçbir envanter çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

if (!inventory.addItem(source, "phone", 1, { number: "555-0101" })) return fail("INVENTORY_FULL");
```
</Tab>
<Tab value="Lua">
```lua
if not aiLib.inventory.addItem(source, 'phone', 1, { number = '555-0101' }) then
    return aiLib.fail('INVENTORY_FULL')
end
```
</Tab>
</Tabs>

<Callout type="warn">
Karşılığında bir şey alıyorsan (para, başka bir eşya) önce `canCarryItem`’ı kontrol et: onu yalnızca `addItem` `true` cevabını verdikten sonra al ya da geri ver.
</Callout>

### inventory.openInventory

Bir stash’i ya da başka bir oyuncunun envanterini bir oyuncunun ekranında açar.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
inventory.openInventory(source: number, inv: InventoryRef): boolean
```

```lua title="Lua"
local ok = aiLib.inventory.openInventory(source, inv)
```

<TypeTable
  type={{
    source: { type: "number", description: "Envanteri gören oyuncunun server id’si.", required: true },
    inv: { type: "InventoryRef", typeDescriptionLink: "/tr/docs/developers/api/types#inventoryref", description: "Stash adı, plaka ya da başka bir oyuncunun server id’si.", required: true },
  }}
/>

#### Dönüş değeri

`boolean`: envanter onu açtıysa `true`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, near, online, inventory } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const ARMORY = { x: 452.3, y: -980.0, z: 30.7 };

onClientCallback(
  "my-police:armory",
  (source) => {
    if (!online.onDutyIn(source, ["police"])) return fail("NOT_ON_DUTY");
    return { ok: inventory.openInventory(source, "police_armory") };
  },
  { guards: [near(ARMORY, 3)] },
);
```
</Tab>
<Tab value="Lua">
```lua
local ARMORY = vector3(452.3, -980.0, 30.7)

aiLib.onClientCallback('my-police:armory', function(source)
    if aiLib.online.dutyJob(source) ~= 'police' then return aiLib.fail('NOT_ON_DUTY') end
    if #(GetEntityCoords(GetPlayerPed(source)) - ARMORY) > 3.0 then return aiLib.fail('TOO_FAR') end
    return { ok = aiLib.inventory.openInventory(source, 'police_armory') }
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Burada hiçbir mesafe ya da erişim kontrolü yapılmaz: çağırmadan önce mesafeyi, mesleği ve sahipliği kontrol et.
</Callout>

### inventory.registerUsableItem

Bir oyuncu bir eşyayı kullandığında handler’ını çalıştırır. ai-core handler’ı sonradan başlayan envanterler için ve envanter yeniden başlatmalarında tutar; bu yüzden script’in başladığında bir kez kaydet.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
inventory.registerUsableItem(name: string, handler: UsableItemHandler): void
```

```lua title="Lua"
aiLib.inventory.registerUsableItem(name, handler) -- handler(source, item)
```

#### Parametreler

<TypeTable
  type={{
    name: { type: "string", description: "Eşya adı.", required: true },
    handler: { type: "(source: number, item: UsedItem) => unknown", typeDescriptionLink: "/tr/docs/developers/api/types#usableitemhandler", description: "Oyuncuyu ve kullanılan yığını `{ name, slot, count, metadata }` (tip `UsedItem`) alır. `false` döndürmek, kullanılan eşyayı kendisi alan envanterlerde (ai-inventory: eşyanın `consume` miktarı) eşyayı yerinde tutar; diğer envanterler kendi eşya ayarlarına uyar.", required: true },
  }}
/>

Kullanılan yığın bir [`UsedItem`](/tr/docs/developers/api/types#useditem)’dır.

<Callout type="warn">
Kullanılan eşyayı kendisi alan envanterler (ai-inventory), handler `false` dışında herhangi bir şey döndürür döndürmez eşyayı alır. Handler’ın bekliyorsa (bir ilerleme çubuğu) ve eşyayı kendisi kaldırıyorsa hemen `false` döndür; yoksa eşya iki kez alınır.
</Callout>

#### Dönüş değeri

`void`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory, progressFor, medical, createLocale } from "@aicore-fivem/lib/server";

const Locale = createLocale();

async function bandage(source: number) {
  const done = await progressFor(source, { label: Locale("BANDAGING"), duration: 4000, canCancel: true });
  if (done && inventory.removeItem(source, "bandage")) medical.heal(source);
}

inventory.registerUsableItem("bandage", (source) => {
  void bandage(source);
  return false; // eşyayı şimdilik tut: bandage() onu çubuktan sonra alır
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.inventory.registerUsableItem('bandage', function(source, item)
    CreateThread(function()
        local done = aiLib.progressFor(source, { label = Locale('BANDAGING'), duration = 4000, canCancel = true })
        if done and aiLib.inventory.removeItem(source, 'bandage', 1) then
            exports['ai-core']:HealPlayer(source)
        end
    end)
    return false -- eşyayı şimdilik tut: thread onu çubuktan sonra alır
end)
```
</Tab>
</Tabs>
