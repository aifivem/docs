---
title: Objetos
description: "inventory: dar, quitar y contar objetos, almacenes, tiendas y objetos usables a través del inventario que use el servidor."
icon: Package
---

```ts title="TypeScript"
import { inventory } from "@aifivem/lib/server";
```

`inventory` envía cada llamada de objetos a través de la capa de inventario de ai-core: responde el inventario que usa el servidor (ai-inventory, u otro que el dueño elija en el panel de ai-core). Tu script nunca llama a los exports propios de un inventario, así que sigue funcionando cuando el dueño cambia de inventario.

**El argumento de inventario** (`inv`, tipo [`InventoryRef`](/es/docs/developers/api/types#inventoryref)) es el id de servidor de un jugador (un número) o el id de otro inventario (un string: el nombre de un almacén, una matrícula).

**Las cantidades** son números enteros de 1 o más; una fracción se redondea hacia abajo, y `0` o una cantidad negativa hace que la llamada falle.

<Callout type="info">
Mientras no haya inventario en marcha, las llamadas fallan en silencio: `false`, `0`, una lista vacía o `null`. Los equivalentes en Lua en `aiLib.inventory` tienen los mismos nombres y el mismo orden de argumentos.
</Callout>

### inventory.addItem

Da objetos a un inventario.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
inventory.addItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = aiLib.inventory.addItem(inv, item, count, metadata, slot)
```

#### Parámetros

<TypeTable
  type={{
    inv: { type: "InventoryRef", typeDescriptionLink: "/es/docs/developers/api/types#inventoryref", description: "Id de servidor del jugador, o el nombre de un almacén o una matrícula.", required: true },
    item: { type: "string", description: "Nombre del objeto tal como lo conoce el inventario (`water`).", required: true },
    count: { type: "number", description: "Cuántos.", default: "1" },
    metadata: { type: "ItemMetadata", typeDescriptionLink: "/es/docs/developers/api/types#itemmetadata", description: "Datos extra guardados en la pila (`{ serial: \"A1\" }`). Las pilas con metadatos distintos no se juntan.", required: false },
    slot: { type: "number", description: "Ponerlos en este slot (1 o más) cuando el inventario lo admite.", required: false },
  }}
/>

#### Devuelve

`boolean`: `true` cuando se dieron. `false` cuando no caben, el objeto no existe, un argumento es incorrecto o no hay inventario en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

if (!inventory.addItem(source, "phone", 1, { number: "555-0101" })) return fail("INVENTORY_FULL");
```
</Tab>
<Tab value="Lua">
```lua
if not aiLib.inventory.addItem(source, 'phone', 1, { number = '555-0101' }) then
    return aiLib.fail('INVENTORY_FULL')
end
```
</Tab>
</Tabs>

<Callout type="warn">
Comprueba primero `canCarryItem` cuando quitas algo a cambio (dinero, otro objeto): quítalo solo después de que `addItem` respondiera `true`, o devuélvelo.
</Callout>

### inventory.removeItem

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
inventory.removeItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = aiLib.inventory.removeItem(inv, item, count, metadata, slot)
```

#### Parámetros

<TypeTable
  type={{
    inv: { type: "InventoryRef", typeDescriptionLink: "/es/docs/developers/api/types#inventoryref", description: "Id de servidor del jugador, o el nombre de un almacén o una matrícula.", required: true },
    item: { type: "string", description: "Nombre del objeto.", required: true },
    count: { type: "number", description: "Cuántos.", default: "1" },
    metadata: { type: "ItemMetadata", typeDescriptionLink: "/es/docs/developers/api/types#itemmetadata", description: "Quitar solo de las pilas con estos metadatos.", required: false },

`boolean`: `true` cuando se quitaron. `false` cuando no hay suficientes, un argumento es incorrecto o no hay inventario en marcha.

### inventory.openInventory

Abre un almacén o el inventario de otro jugador en la pantalla de un jugador.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
inventory.openInventory(source: number, inv: InventoryRef): boolean
```

```lua title="Lua"
local ok = aiLib.inventory.openInventory(source, inv)
```

<TypeTable
  type={{
    source: { type: "number", description: "Id de servidor del jugador que lo ve.", required: true },
    inv: { type: "InventoryRef", typeDescriptionLink: "/es/docs/developers/api/types#inventoryref", description: "Nombre del almacén, matrícula o el id de servidor de otro jugador.", required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el inventario lo abrió.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, near, online, inventory } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const ARMORY = { x: 452.3, y: -980.0, z: 30.7 };

onClientCallback(
  "my-police:armory",
  (source) => {
    if (!online.onDutyIn(source, ["police"])) return fail("NOT_ON_DUTY");
    return { ok: inventory.openInventory(source, "police_armory") };
  },
  { guards: [near(ARMORY, 3)] },
);
```
</Tab>
<Tab value="Lua">
```lua
local ARMORY = vector3(452.3, -980.0, 30.7)

aiLib.onClientCallback('my-police:armory', function(source)
    if aiLib.online.dutyJob(source) ~= 'police' then return aiLib.fail('NOT_ON_DUTY') end
    if #(GetEntityCoords(GetPlayerPed(source)) - ARMORY) > 3.0 then return aiLib.fail('TOO_FAR') end
    return { ok = aiLib.inventory.openInventory(source, 'police_armory') }
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Aquí no se comprueba ni la distancia ni el acceso: comprueba la distancia, el trabajo y la propiedad antes de llamarlo.
</Callout>

### inventory.registerUsableItem

Ejecuta tu handler cuando un jugador usa un objeto. ai-core guarda el handler para los inventarios que arranquen más tarde y a través de los reinicios del inventario, así que regístralo una vez cuando tu script arranque.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
inventory.registerUsableItem(name: string, handler: UsableItemHandler): void
```

```lua title="Lua"
aiLib.inventory.registerUsableItem(name, handler) -- handler(source, item)
```

#### Parámetros

<TypeTable
  type={{
    name: { type: "string", description: "Nombre del objeto.", required: true },
    handler: { type: "(source: number, item: UsedItem) => unknown", typeDescriptionLink: "/es/docs/developers/api/types#usableitemhandler", description: "Recibe al jugador y la pila usada `{ name, slot, count, metadata }` (tipo `UsedItem`). Devolver `false` conserva el objeto en los inventarios que quitan ellos mismos un objeto usado (ai-inventory: la cantidad `consume` del objeto); los demás inventarios siguen sus propios ajustes de objeto.", required: true },
  }}
/>

La pila usada es un [`UsedItem`](/es/docs/developers/api/types#useditem).

<Callout type="warn">
Los inventarios que quitan ellos mismos un objeto usado (ai-inventory) lo quitan en cuanto el handler devuelve cualquier cosa que no sea `false`. Cuando tu handler espera (una barra de progreso) y quita el objeto por sí mismo, devuelve `false` enseguida, o el objeto se quita dos veces.
</Callout>

#### Devuelve

`void`.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory, progressFor, medical, createLocale } from "@aifivem/lib/server";

const Locale = createLocale();

async function bandage(source: number) {
  const done = await progressFor(source, { label: Locale("BANDAGING"), duration: 4000, canCancel: true });
  if (done && inventory.removeItem(source, "bandage")) medical.heal(source);
}

inventory.registerUsableItem("bandage", (source) => {
  void bandage(source);
  return false; // conservar el objeto ahora: bandage() lo quita después de la barra
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.inventory.registerUsableItem('bandage', function(source, item)
    CreateThread(function()
        local done = aiLib.progressFor(source, { label = Locale('BANDAGING'), duration = 4000, canCancel = true })
        if done and aiLib.inventory.removeItem(source, 'bandage', 1) then
            exports['ai-core']:HealPlayer(source)
        end
    end)
    return false -- conservar el objeto ahora: el hilo lo quita después de la barra
end)
```
</Tab>
</Tabs>
