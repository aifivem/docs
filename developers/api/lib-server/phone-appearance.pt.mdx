## phone

O celular do jogador pelo ai-core: o primeiro script de celular que estiver rodando (tgiann-phone, lb-phone...) responde. Sem um script de celular, toda chamada responde `null` ou `false`. Os equivalentes em Lua em `aiLib.phone` têm os mesmos nomes e a mesma ordem de argumentos.

### phone.number

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
phone.number(source: number): string | null
```

```lua title="Lua"
local number = aiLib.phone.number(source)
```

**Retorno** o número de celular do jogador, ou `null` (`nil` em Lua) quando ele não tem um ou nenhum script de celular está rodando.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const number = phone.number(source);
if (!number) return fail("NO_PHONE_NUMBER");
```
</Tab>
<Tab value="Lua">
```lua
local number = aiLib.phone.number(source)
if not number then return aiLib.fail('NO_PHONE_NUMBER') end
```
</Tab>
</Tabs>

### phone.sourceOf

O jogador online dono de um número de celular.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
phone.sourceOf(number: string): number | null
```

```lua title="Lua"
local source = aiLib.phone.sourceOf(number)
```

**Retorno** o id de servidor, ou `null` (`nil` em Lua) quando ninguém online tem esse número.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const owner = phone.sourceOf("555-0101");
if (owner !== null) notify(owner, "Your phone is ringing");
```
</Tab>
<Tab value="Lua">
```lua
local owner = aiLib.phone.sourceOf('555-0101')
if owner then aiLib.notify(owner, 'Your phone is ringing') end
```
</Tab>
</Tabs>

### phone.hasPhone

Se o jogador carrega um celular.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
phone.hasPhone(source: number): boolean
```

```lua title="Lua"
local has = aiLib.phone.hasPhone(source)
```

**Retorno** `true` quando ele tem um; `false` sem celular, ou sem um script de celular.

<Tabs items={['TypeScript', 'Lua']}>

```
</Tab>

```
</Tab>
</Tabs>

## appearance

O visual salvo dos personagens pela camada de aparência do ai-core, qualquer que seja o script de roupas rodando (ai-appearance, tgiann-clothing).

### appearance.get

O visual salvo de um personagem, carregado ou não. Use para vestir um ped que representa um personagem (um corpo dormindo, um manequim): passe o resultado sem mudanças para o `appearance.apply` do cliente ([Lib: cliente](/pt/docs/developers/api/lib-client)).

**Lado:** Servidor · **Espera:** sim (Promise em TypeScript, pausa a thread em Lua)

```ts title="Signature"
appearance.get(charId: number): Promise<CharacterAppearance | null>
```

```lua title="Lua"
local look = aiLib.appearance.get(charId) -- { model, data } ou nil, chame dentro de uma thread
```

<TypeTable
  type={{
    charId: { type: "number", description: "O id do personagem (`CharacterInfo.id`).", required: true },
  }}
/>

#### Retorno

`Promise<CharacterAppearance | null>`: [`CharacterAppearance`](/pt/docs/developers/api/types#characterappearance) é `{ model, data }` (o hash do modelo do ped e os dados de visual próprios do script de roupas). `null` quando o personagem não tem um, nenhum script de roupas está rodando ou o ai-core está parado.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, online, playersNear } from "@aifivem/lib/server";

async function sendLook(source: number) {
  const charId = online.charId(source);
  if (charId === undefined) return;
  const look = await appearance.get(charId);
  if (!look) return;
  // Só os jogadores perto deste personagem precisam do visual.
  for (const other of playersNear(source, 100)) emitNet("my-sleepers:look", other, source, look);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local character = aiLib.online.character(source)
    if not character then return end
    local look = aiLib.appearance.get(character.id)
    if look then TriggerClientEvent('my-sleepers:look', source, look) end
end)
```
</Tab>
</Tabs>

### appearance.provider

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
appearance.provider(): string | null
```

```lua title="Lua"
local name = aiLib.appearance.provider()
```

**Retorno** o script de roupas que responde, ou `null` (`nil` em Lua) quando nenhum está rodando.

```ts
console.log(`looks through ${appearance.provider() ?? "nothing"}`);
```
