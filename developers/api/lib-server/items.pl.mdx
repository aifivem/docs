```ts title="TypeScript"
import { inventory } from "@aicore-fivem/lib/server";
```

`inventory` wysyła każde wywołanie przedmiotów przez warstwę ekwipunku ai-core: odpowiada ekwipunek, którego używa serwer (ai-inventory albo inny wybrany przez właściciela w panelu ai-core). Twój skrypt nigdy nie wywołuje własnych eksportów ekwipunku, więc działa dalej, gdy właściciel zmieni ekwipunek.

**Argument ekwipunku** (`inv`, typ [`InventoryRef`](/pl/docs/developers/api/types#inventoryref)) to id serwerowe gracza (liczba) albo id innego ekwipunku (string: nazwa schowka, tablica rejestracyjna).

**Ilości** to liczby całkowite od 1 w górę; ułamek jest zaokrąglany w dół, `0` albo ujemna ilość sprawia, że wywołanie się nie udaje.

<Callout type="info">
Dopóki nie działa żaden ekwipunek, wywołania po cichu się nie udają: `false`, `0`, pusta lista albo `null`. Odpowiedniki w Lua w `aiLib.inventory` mają te same nazwy i kolejność argumentów.
</Callout>

### inventory.addItem

Daje przedmioty do ekwipunku.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
inventory.addItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = aiLib.inventory.addItem(inv, item, count, metadata, slot)
```

#### Parametry

<TypeTable
  type={{
    inv: { type: "InventoryRef", typeDescriptionLink: "/pl/docs/developers/api/types#inventoryref", description: "Id serwerowe gracza albo nazwa schowka lub tablica.", required: true },
    item: { type: "string", description: "Nazwa przedmiotu tak, jak zna ją ekwipunek (`water`).", required: true },
    count: { type: "number", description: "Ile.", default: "1" },
    metadata: { type: "ItemMetadata", typeDescriptionLink: "/pl/docs/developers/api/types#itemmetadata", description: "Dodatkowe dane zapisane na stosie (`{ serial: \"A1\" }`). Stosy z różnymi metadanymi się nie łączą.", required: false },
    slot: { type: "number", description: "Włóż je do tego slotu (od 1), gdy ekwipunek to obsługuje.", required: false },
  }}
/>

#### Zwracana wartość

`boolean`: `true`, gdy dano. `false`, gdy się nie mieszczą, przedmiot nie istnieje, argument jest zły albo nie działa żaden ekwipunek.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

if (!inventory.addItem(source, "phone", 1, { number: "555-0101" })) return fail("INVENTORY_FULL");
```
</Tab>
<Tab value="Lua">
```lua
if not aiLib.inventory.addItem(source, 'phone', 1, { number = '555-0101' }) then
    return aiLib.fail('INVENTORY_FULL')
end
```
</Tab>
</Tabs>

<Callout type="warn">
Najpierw sprawdź `canCarryItem`, gdy coś zabierasz w zamian (pieniądze, inny przedmiot): zabierz to dopiero wtedy, gdy `addItem` odpowiedział `true`, albo to oddaj.
</Callout>

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, near, online, inventory } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const ARMORY = { x: 452.3, y: -980.0, z: 30.7 };

onClientCallback(
  "my-police:armory",
  (source) => {
    if (!online.onDutyIn(source, ["police"])) return fail("NOT_ON_DUTY");
    return { ok: inventory.openInventory(source, "police_armory") };
  },
  { guards: [near(ARMORY, 3)] },
);
```
</Tab>

```lua

aiLib.onClientCallback('my-police:armory', function(source)
    if aiLib.online.dutyJob(source) ~= 'police' then return aiLib.fail('NOT_ON_DUTY') end
    if #(GetEntityCoords(GetPlayerPed(source)) - ARMORY) > 3.0 then return aiLib.fail('TOO_FAR') end
    return { ok = aiLib.inventory.openInventory(source, 'police_armory') }
end)
```
</Tab>
</Tabs>

### inventory.registerUsableItem

Uruchamia twój handler, gdy gracz używa przedmiotu. ai-core trzyma handler dla ekwipunków, które startują później, i przez restarty ekwipunku, więc zarejestruj go raz, gdy twój skrypt startuje.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
inventory.registerUsableItem(name: string, handler: UsableItemHandler): void
```

```lua title="Lua"
aiLib.inventory.registerUsableItem(name, handler) -- handler(source, item)
```

#### Parametry

<TypeTable
  type={{
    name: { type: "string", description: "Nazwa przedmiotu.", required: true },
    handler: { type: "(source: number, item: UsedItem) => unknown", typeDescriptionLink: "/pl/docs/developers/api/types#usableitemhandler", description: "Dostaje gracza i użyty stos `{ name, slot, count, metadata }` (typ `UsedItem`). Zwrócenie `false` zostawia przedmiot w ekwipunkach, które same zabierają użyty przedmiot (ai-inventory: ilość `consume` przedmiotu); inne ekwipunki stosują własne ustawienia przedmiotu.", required: true },
  }}
/>

Użyty stos to [`UsedItem`](/pl/docs/developers/api/types#useditem).

<Callout type="warn">
Ekwipunki, które same zabierają użyty przedmiot (ai-inventory), zabierają go, gdy tylko handler zwróci cokolwiek innego niż `false`. Gdy twój handler czeka (pasek postępu) i sam usuwa przedmiot, od razu zwróć `false`, bo inaczej przedmiot zostanie zabrany dwa razy.
</Callout>

#### Zwracana wartość

`void`.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory, progressFor, medical, createLocale } from "@aicore-fivem/lib/server";

const Locale = createLocale();

async function bandage(source: number) {
  const done = await progressFor(source, { label: Locale("BANDAGING"), duration: 4000, canCancel: true });
  if (done && inventory.removeItem(source, "bandage")) medical.heal(source);
}

inventory.registerUsableItem("bandage", (source) => {
  void bandage(source);
  return false; // na razie zostaw przedmiot: bandage() zabiera go po pasku
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.inventory.registerUsableItem('bandage', function(source, item)
    CreateThread(function()
        local done = aiLib.progressFor(source, { label = Locale('BANDAGING'), duration = 4000, canCancel = true })
        if done and aiLib.inventory.removeItem(source, 'bandage', 1) then
            exports['ai-core']:HealPlayer(source)
        end
    end)
    return false -- na razie zostaw przedmiot: wątek zabiera go po pasku
end)
```
</Tab>
</Tabs>
