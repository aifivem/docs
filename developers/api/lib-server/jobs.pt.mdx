```ts title="TypeScript"
import { jobs, dispatch, prison, mdt, ems, medical, stress, needs, definitions, isPrimeTime } from "@aifivem/lib/server";
```

O `jobs` e o `definitions` são o próprio ai-core: os empregos e gangues de uma personagem, e as definições de empregos do servidor. Tudo o mais aqui passa por uma das camadas do ai-core, onde responde o script que o servidor usa para essa tarefa (um sistema de alertas, uma prisão, um MDT, um script de morte, um HUD). O seu script continua a funcionar quando o proprietário o troca. Enquanto nenhum desses scripts correr, essas chamadas falham em silêncio (`false`, `0`, `null`).

## jobs

`jobs` são os empregos e gangues próprios de um jogador carregado através do ai-core: uma personagem pode ter vários empregos, está de serviço em no máximo um, e age por uma gangue de cada vez. Ler **muitos** jogadores de uma vez é o espelho da lib ([`online`](/pt/docs/developers/api/lib-server/players#onlinejobs)); alterar uma personagem **não ligada** é [`characters`](/pt/docs/developers/api/lib-server/characters#characterssetjob-and-charactersremovejob).

### jobs.current

O emprego que os outros scripts veem como "o" emprego de um jogador: aquele em que está de serviço, senão o último em que esteve, senão o primeiro que tem, senão o emprego de desempregado.

**Lado:** Servidor · **Espera:** não

```ts title="Assinatura"
jobs.current(source: number): JobMembership | null
```

```lua title="Lua"
local current = aiLib.jobs.current(source)
```

#### Retorno

Um [JobMembership](/pt/docs/developers/api/types#jobmembership) (`{ job, grade }`), ou `null` quando o jogador não tem personagem carregada.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs } from "@aifivem/lib/server";

export function isOfficer(source: number): boolean {
  return jobs.current(source)?.job === "police";
}
```
</Tab>
<Tab value="Lua">
```lua
local current = aiLib.jobs.current(source)
local officer = current and current.job == 'police'
```
</Tab>
</Tabs>

### jobs.duty and jobs.setDuty

Em que emprego o jogador está de serviço, e entrar ou sair de serviço. Muitos scripts verificam o serviço em vez da pertença: um agente fora de serviço é um civil.

**Lado:** Servidor · **Espera:** não

```ts title="Assinatura"
jobs.duty(source: number): string | null
jobs.setDuty(source: number, job: string | null): boolean
```

```lua title="Lua"
local onDutyIn = aiLib.jobs.duty(source)
local ok = aiLib.jobs.setDuty(source, job)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do jogador.', required: true },
    job: { type: 'string | null', description: 'Um emprego que o jogador tem, para entrar de serviço nele. `null` (em Lua `nil`) sai de serviço.', required: true },
  }}
/>

#### Retorno

`jobs.duty`: o nome do emprego, ou `null` fora de serviço (ou sem personagem). `jobs.setDuty`: `true` quando a alteração foi feita, `false` para um emprego que o jogador não tem.

### jobs.set

Acrescenta um emprego ao jogador, ou altera o grau de um que já tem. Aplicam-se as regras do painel: quantos empregos uma personagem pode ter e se um segundo é permitido.

**Lado:** Servidor · **Espera:** não

```ts title="Assinatura"
jobs.set(source: number, job: string, grade: number): boolean
```

```lua title="Lua"
local ok = aiLib.jobs.set(source, job, grade)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do jogador.', required: true },
    job: { type: 'string', description: 'O nome do emprego tal como está no painel (ou numa definição de script).', required: true },
    grade: { type: 'number', description: 'O grau nesse emprego, a partir de 0. Um grau que o emprego não tem é recusado.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o jogador fica com esse emprego nesse grau. `false` sem personagem carregada, com um emprego desconhecido, um grau desconhecido, ou ao bater no limite de empregos do painel.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs, notify } from "@aifivem/lib/server";

export function hire(source: number, job: string): void {
  if (!jobs.set(source, job, 0)) return notify(source, "Não foi possível contratar", "error");
  notify(source, `Bem-vindo a ${job}`, "success");
}
```
</Tab>
<Tab value="Lua">
```lua
if aiLib.jobs.set(source, 'mechanic', 0) then
    aiLib.notify(source, 'Bem-vindo a mechanic', 'success')
end
```
</Tab>
</Tabs>

### jobs.remove

Retira um emprego. Uma personagem sem empregos conta como desempregada: o emprego de desempregado nunca é guardado.

**Lado:** Servidor · **Espera:** não

```ts title="Assinatura"
jobs.remove(source: number, job: string): boolean
```

```lua title="Lua"

```

#### Retorno

`boolean`: `true` quando o emprego foi retirado, `false` quando o jogador não o tinha (ou não tem personagem carregada).


`string`: o nome do emprego segundo o painel.

```ts title="Assinatura"
jobs.onDutyCount(job: string): number
```


### jobs.activeGang and jobs.setActiveGang

Uma personagem pode estar em várias gangues mas age por uma de cada vez: essa é a gangue ativa, e é a que um script de território ou de droga deve ler.

**Lado:** Servidor · **Espera:** não

```ts title="Assinatura"
jobs.activeGang(source: number): string | null
jobs.setActiveGang(source: number, gang: string | null): boolean
```

```lua title="Lua"

```

#### Retorno

`jobs.activeGang`: o nome da gangue, ou `null` se nenhuma está ativa. `jobs.setActiveGang`: `true` quando a alteração foi feita, `false` para uma gangue em que o jogador não está (`null` limpa-a).

### jobs.setGang and jobs.removeGang

Acrescenta, muda o grau ou retira uma gangue do jogador.

**Lado:** Servidor · **Espera:** não


```lua title="Lua"

```

#### Retorno

`boolean`, como nas chamadas de emprego: `false` sem personagem carregada, com uma gangue desconhecida ou um grau desconhecido.

## dispatch

**Lado:** Servidor · **Espera:** não

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

```ts
    title: Locale("ALERT_STORE_ROBBERY"),
```

```lua
        message = store,

        source = source,
        icon = 'store',
        priority = 'high',

end
```

## medical

Reviver, curar e o estado de caído pela camada médica do ai-core, qualquer que seja o script de morte ou de ambulância rodando. Sem equivalente em Lua: chame os exports do ai-core `RevivePlayer`, `HealPlayer`, `IsPlayerDead`.

### medical.revive

Levanta um jogador caído onde ele está.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
medical.revive(source: number): boolean
```

**Retorno** `true` quando revivido, `false` quando não está caído ou nenhum script de morte está rodando.

```ts
if (!medical.revive(target)) return fail("NOT_DOWN");
```

### medical.heal

Dá vida cheia a um jogador que não está caído.

**Lado:** Servidor · **Espera:** não

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
medical.isDead(source: number): boolean
```

**Retorno** `true` quando caído; `false` sem um script de morte. Use em vez de ler a vida do ped.

**Lado:** Servidor · **Espera:** não

## Definições de empregos e gangues

### definitions.job

A definição de um emprego como configurada no painel do ai-core. Cada uma é lida uma vez do ai-core e mantida até o painel mudá-la, então uma leitura é uma consulta em memória.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
definitions.job(name: string): JobDefinition | null
```

```lua title="Lua"
local definition = aiLib.definitions.job(name)
```

**Retorno** [`JobDefinition`](/pt/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`), ou `null` quando esse emprego não existe.

```ts
const label = definitions.job("police")?.label ?? "police";
```

### definitions.gang

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
definitions.gang(name: string): GangDefinition | null
```

```lua title="Lua"
local definition = aiLib.definitions.gang(name)
```

**Retorno** [`GangDefinition`](/pt/docs/developers/api/types#gangdefinition) (`label`, `grades`), ou `null`.

```ts
const gang = definitions.gang("ballas");
if (!gang) return fail("UNKNOWN_GANG");
```

### definitions.registerJob and definitions.removeJob

Um emprego que o seu script traz sem o proprietário o acrescentar no painel: um emprego do resource que chama, que desaparece quando o resource para e nunca é escrito no ficheiro do painel.

**Lado:** Servidor · **Espera:** não

```ts title="Assinatura"
definitions.registerJob(name: string, definition: JobDefinition): CharacterResult
definitions.removeJob(name: string): boolean
```

```lua title="Lua"
local result = aiLib.definitions.registerJob(name, definition)
local ok = aiLib.definitions.removeJob(name)
```

#### Parâmetros

<TypeTable
  type={{
    name: { type: 'string', description: 'O nome de emprego que o seu script usa (`"my-garbagejob"`).', required: true },
    definition: { type: 'JobDefinition', typeDescriptionLink: '/pt/docs/developers/api/types#jobdefinition', description: 'O emprego em si: `label`, `type`, `defaultDuty`, `listed`, e os seus `grades` (cada um com `label`, `salary`, `boss`).', required: true },
  }}
/>

#### Retorno

O `registerJob` responde [ActionResult](/pt/docs/developers/api/types#actionresult): `{ ok: true }`, ou `{ ok: false, error }` com uma chave de idioma quando o painel já tem um emprego com esse nome ou outro resource o registou - o painel do proprietário ganha sempre. O `removeJob` responde `true` só para um emprego que este resource registou.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { definitions } from "@aifivem/lib/server";

// Uma vez no arranque: o emprego existe enquanto este resource correr.
const result = definitions.registerJob("garbage", {
  label: "Garbage",
  type: "job",
  defaultDuty: true,
  grades: [{ label: "Driver", salary: 60, boss: false }],
});
if (!result.ok) console.log(`emprego não registado: ${result.error}`);
```
</Tab>
<Tab value="Lua">
```lua
local result = aiLib.definitions.registerJob('garbage', {
    label = 'Garbage',
    type = 'job',
    defaultDuty = true,
    grades = { { label = 'Driver', salary = 60, boss = false } },
})
if not result.ok then print(('emprego não registado: %s'):format(result.error)) end
```
</Tab>
</Tabs>

<Callout type="info">
Um emprego que o proprietário do servidor deva poder editar pertence ao painel, não aqui. Registe um quando o emprego faz parte do seu script e não significa nada sem ele.
</Callout>

## Horário nobre

### isPrimeTime

Se é horário nobre para um emprego, pela configuração de horário nobre do ai-core. As horas vêm do tgiann-policealert enquanto ele está rodando, senão das horas definidas no painel do ai-core.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
isPrimeTime(job?: string): boolean
```

Sem equivalente em Lua: chame o export do ai-core `IsPrimeTime(job)`.

<TypeTable
  type={{
    job: { type: "string", description: "Emprego cujo horário nobre verificar. Sem ele, as horas padrão.", required: false },
  }}
/>

**Retorno** `true` durante o horário nobre.

```ts
if (!isPrimeTime("police")) return fail("BANK_CLOSED_FOR_HEISTS");
```
