```ts title="TypeScript"
import { dispatch, prison, mdt, ems, medical, stress, needs, definitions, isPrimeTime } from "@aicore-fivem/lib/server";
```

Cada objeto aqui passa por uma das camadas do ai-core: o script que o servidor roda para aquela tarefa (um sistema de alertas, uma prisão, um MDT, um script de morte, um HUD) responde. Seu script continua funcionando quando o dono o troca. Enquanto nenhum script desses está rodando, as chamadas falham em silêncio (`false`, `0`, `null`).

## dispatch

### dispatch.alert

Envia um alerta da polícia (ou de outro emprego). O sistema de alertas o mostra aos membros em serviço de `jobs`, por padrão os empregos de polícia.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

<TypeTable
  type={{
    title: { type: "string", description: "O título, traduzido (`Shots fired`).", required: true },
    code: { type: "string", description: "Código de rádio mostrado antes do título (`10-71`).", required: false },
    message: { type: "string", description: "Mais uma linha (o nome da loja).", required: false },
    coords: { type: "{ x: number; y: number; z: number }", description: "Onde aconteceu. Sem isso, a posição do jogador `source`; sem os dois, nenhum ponto no mapa.", required: false },
    jobs: { type: "string[]", description: "Empregos cujos membros em serviço o recebem.", default: "os empregos de polícia do sistema de alertas" },
    source: { type: "number", description: "O jogador de quem o alerta trata (atirador, ladrão). Sistemas que descrevem o suspeito (veículo, gênero) leem este jogador.", required: false },
    blip: { type: "{ sprite: number; color?: number; scale?: number }", description: "Blip no mapa: um sprite e uma cor de blip do GTA.", default: "o do sistema de alertas" },
    duration: { type: "number", description: "Segundos que o alerta fica (card, blip, tecla de waypoint).", default: "o do sistema de alertas" },
    icon: { type: "string", description: "Nome do ícone Font Awesome solid sem `fa-` (`gun`).", required: false },
    priority: { type: '"normal" | "high"', description: "`high` faz o card se destacar (assalto à mão armada, policial ferido).", default: '"normal"' },
  }}
/>

O tipo é [`DispatchAlert`](/pt/docs/developers/api/types#dispatchalert).

#### Retorno

`boolean`: `true` quando enviado. `false` quando nenhum sistema de alertas está rodando ou o alerta é inválido.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, coordsOf, createLocale } from "@aicore-fivem/lib/server";

const Locale = createLocale();

function storeRobbed(source: number, store: string) {
  dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

local function storeRobbed(source, store)
    local c = GetEntityCoords(GetPlayerPed(source))
    aiLib.dispatch.alert({
        code = '10-90',
        title = Locale('ALERT_STORE_ROBBERY'),
        message = store,
        coords = { x = c.x, y = c.y, z = c.z },
        source = source,
        icon = 'store',
        priority = 'high',
    })
end
```
</Tab>
</Tabs>

## prison

Penas de prisão pelo ai-core, qualquer que seja o script de prisão rodando.

### prison.jail

Manda um jogador carregado para a prisão.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
prison.jail(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local ok = aiLib.prison.jail(source, minutes, by)
```

<TypeTable
  type={{
    source: { type: "number", description: "Id de servidor do jogador a prender.", required: true },
    minutes: { type: "number", description: "Duração da pena em minutos.", required: true },
    by: { type: "number", description: "Id de servidor de quem o mandou (para o log). 0 significa o servidor.", default: "0" },
  }}
/>

**Retorno** `true` quando preso, `false` enquanto nenhuma prisão está rodando.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

```
</Tab>
<Tab value="Lua">
```lua
if not aiLib.prison.jail(target, 15, officer) then return aiLib.fail('NO_PRISON') end
```
</Tab>
</Tabs>

## mdt

Registros do MDT da polícia (multas, mandados, prisões, cadeia) pela camada de MDT do ai-core. Nada é escrito enquanto nenhum MDT está rodando.

### mdt.record

Escreve um registro no MDT da polícia.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
mdt.record(record: MdtRecord): boolean
```

```lua title="Lua"
local ok = aiLib.mdt.record(record)
```

#### MdtRecord

<TypeTable
  type={{
    kind: { type: '"fine" | "warrant" | "arrest" | "jail"', description: "O tipo de registro.", required: true },
    target: { type: "number", description: "Id de servidor do jogador de quem o registro trata.", required: true },
    by: { type: "number", description: "Id de servidor do policial que o escreve.", required: false },
    title: { type: "string", description: "O que aconteceu, traduzido (`Armed robbery`).", required: true },
    amount: { type: "number", description: "O valor de uma multa em dólares.", required: false },
    minutes: { type: "number", description: "Uma pena de prisão em minutos.", required: false },
  }}
/>

O tipo é [`MdtRecord`](/pt/docs/developers/api/types#mdtrecord).

**Retorno** `true` quando escrito, `false` quando nenhum MDT está rodando ou ele não aceita esse tipo de registro.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

## ems

Médicos pela camada de EMS do ai-core: a contagem e os chamados de socorro próprios de um script de EMS, senão as contagens de serviço e os alertas do ai-core.

### ems.available

Quantos médicos estão livres para atender um chamado.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
ems.available(jobs: string[]): number
```

```lua title="Lua"
local count = aiLib.ems.available(jobs)
```

<TypeTable
  type={{
    jobs: { type: "string[]", description: "Os nomes dos empregos de EMS a contar (`[\"ambulance\"]`).", required: true },
  }}
/>

**Retorno** o número de médicos em serviço em `jobs`, deixando de fora os ocupados quando um script de dispatch os conhece.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

const canRespawn = ems.available(["ambulance"]) === 0;
```
</Tab>
<Tab value="Lua">
```lua
local canRespawn = aiLib.ems.available({ 'ambulance' }) == 0
```
</Tab>
</Tabs>

## medical

Reviver, curar e o estado de caído pela camada médica do ai-core, qualquer que seja o script de morte ou de ambulância rodando. Sem equivalente em Lua: chame os exports do ai-core `RevivePlayer`, `HealPlayer`, `IsPlayerDead`.

### medical.revive

Levanta um jogador caído onde ele está.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
medical.revive(source: number): boolean
```

**Retorno** `true` quando revivido, `false` quando não está caído ou nenhum script de morte está rodando.

```ts
if (!medical.revive(target)) return fail("NOT_DOWN");
```

### medical.heal

Dá vida cheia a um jogador que não está caído.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
medical.heal(source: number): boolean
```

**Retorno** `true` quando curado, `false` quando nenhum script de morte está rodando.

```ts
medical.heal(source);
```

### medical.isDead

Se o jogador está caído.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
medical.isDead(source: number): boolean
```

**Retorno** `true` quando caído; `false` sem um script de morte. Use em vez de ler a vida do ped.

```ts
if (medical.isDead(source)) return fail("YOU_ARE_DOWN");
```

### medical.provider

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
medical.provider(): string | null
```

**Retorno** o script de morte que responde (`ai-death`...), ou `null` quando nenhum está rodando.

```ts
console.log(`deaths through ${medical.provider() ?? "nothing"}`);
```

## needs

### needs.refill

Enche a fome e a sede ao máximo (revive de admin, hospital), pelo HUD que as guarda, ou pela metadata de personagem do ai-core quando não há um.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
needs.refill(source: number): boolean
```

Sem equivalente em Lua: chame o export do ai-core `RefillNeeds(source)`.

**Retorno** `true` quando reabastecido, `false` quando o jogador não tem personagem.

```ts
if (medical.revive(target)) needs.refill(target);
```

## Definições de empregos e gangues

### definitions.job

A definição de um emprego como configurada no painel do ai-core. Cada uma é lida uma vez do ai-core e mantida até o painel mudá-la, então uma leitura é uma consulta em memória.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
definitions.job(name: string): JobDefinition | null
```

Sem equivalente em Lua: chame o export do ai-core `GetJobDefinition(name)`.

**Retorno** [`JobDefinition`](/pt/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`), ou `null` quando esse emprego não existe.

```ts
const label = definitions.job("police")?.label ?? "police";
```

### definitions.gang

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
definitions.gang(name: string): GangDefinition | null
```

Sem equivalente em Lua: chame o export do ai-core `GetGangDefinition(name)`.

**Retorno** [`GangDefinition`](/pt/docs/developers/api/types#gangdefinition) (`label`, `grades`), ou `null`.

```ts
const gang = definitions.gang("ballas");
if (!gang) return fail("UNKNOWN_GANG");
```

## Horário nobre

### isPrimeTime

Se é horário nobre para um emprego, pela configuração de horário nobre do ai-core. As horas vêm do tgiann-policealert enquanto ele está rodando, senão das horas definidas no painel do ai-core.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
isPrimeTime(job?: string): boolean
```

Sem equivalente em Lua: chame o export do ai-core `IsPrimeTime(job)`.

<TypeTable
  type={{
    job: { type: "string", description: "Emprego cujo horário nobre verificar. Sem ele, as horas padrão.", required: false },
  }}
/>

**Retorno** `true` durante o horário nobre.

```ts
if (!isPrimeTime("police")) return fail("BANK_CLOSED_FOR_HEISTS");
```
