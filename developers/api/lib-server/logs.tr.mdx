```ts title="TypeScript"
import { aiLog, aiLogChannels } from "@aicore-fivem/lib/server";
```

Script’in hiçbir zaman Discord’a ya da bir log servisine kendisi göndermez. Bir log’u ai-core’a bir **kanal** üzerinden (`purchase` gibi bir ad) gönderir; her kanalın nereye gideceğine sunucu sahibi ai-core’un admin panelinde karar verir. Webhook url’leri ve API anahtarları panelde kalır, asla senin kodunda değil.

### aiLog

ai-core’un log sistemi üzerinden tek bir log satırı gönderir.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
aiLog(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
aiLib.aiLog(channel, message, options)
```

#### Parametreler

<TypeTable
  type={{
    channel: { type: "string", description: "Kanal adı (`purchase`, `admin`). Kanallarını `aiLogChannels` ile bir kez tanımla.", required: true },
    message: { type: "string", description: "Ne olduğu. Adları metne yazmak yerine oyuncuları `source` / `target` olarak geçir.", required: true },
    options: { type: "LogOptions", typeDescriptionLink: "/tr/docs/developers/api/types#logoptions", description: "Seviye, oyuncular ve ek değerler. Alanlar aşağıda.", required: false },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: "Önem derecesi.", required: false },
    source: { type: "number", description: "Bunu yapan oyuncunun server id’si. Adı, karakteri ve identifier’ları eklenir.", required: false },
    target: { type: "number", description: "Bunun yapıldığı oyuncunun server id’si.", required: false },
    metadata: { type: "Record<string, unknown>", description: "Ek alanlar (miktarlar, eşya adları, koordinatlar).", required: false },
  }}
/>

#### Dönüş değeri

`void`. TypeScript’te ai-core çalışmıyorken hiçbir şey yapmaz; Lua karşılığı bunun yerine konsola `[channel] message` yazdırır.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { aiLog } from "@aicore-fivem/lib/server";

aiLog("purchase", `bought ${count}x ${item} for $${price}`, {
  source,
  metadata: { item, count, price },
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.aiLog('purchase', ('bought %dx %s for $%d'):format(count, item, price), {
    source = source,
    metadata = { item = item, count = count, price = price },
})
```
</Tab>
</Tabs>

### aiLogChannels

Resource’unun log kanallarını tanımlar: Fivemanage ve FiveM Stats’in kullandığı dataset adı ve bir kanalın açık olup olmadığı. Script’in başladığında bir kez çağır.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
aiLogChannels(channels: Record<string, LogChannel>): void
```

Lua karşılığı yok: ai-core’un `exports['ai-core']:LogChannels(channels)` export’unu çağır.

#### Parametreler

<TypeTable
  type={{
    channels: { type: "Record<string, LogChannel>", typeDescriptionLink: "/tr/docs/developers/api/types#logchannel", description: "Kanal adı başına bir girdi. Her `LogChannel`’da `dataset?` (Fivemanage / FiveM Stats dataset’i, varsayılan resource adı) ve `active?` (`false` kanalı kapatır) bulunur.", required: true },
  }}
/>

#### Dönüş değeri

`void`. ai-core çalışmıyorken hiçbir şey yapmaz.

#### Örnek

```ts
import { aiLogChannels } from "@aicore-fivem/lib/server";

aiLogChannels({
  purchase: { dataset: "shops" },
  debug: { active: false },
});
```
