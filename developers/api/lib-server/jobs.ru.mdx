```ts title="TypeScript"
import { jobs, dispatch, prison, mdt, ems, medical, stress, needs, definitions, isPrimeTime } from "@aifivem/lib/server";
```

`jobs` и `definitions` - это сам ai-core: работы и банды персонажа и определения работ сервера. Всё остальное здесь идёт через один из слоёв ai-core, где отвечает скрипт, который сервер держит для этой задачи (система вызовов, тюрьма, MDT, скрипт смерти, HUD). Ваш скрипт продолжит работать, когда владелец его заменит. Пока такого скрипта нет, эти вызовы тихо не срабатывают (`false`, `0`, `null`).

## jobs

`jobs` - это собственные работы и банды загруженного игрока через ai-core: у персонажа может быть несколько работ, на смене он не больше чем в одной, и действует за одну банду. Читать **многих** игроков сразу - это зеркало библиотеки ([`online`](/ru/docs/developers/api/lib-server/players#onlinejobs)); менять персонажа, который **не** подключён, - это [`characters`](/ru/docs/developers/api/lib-server/characters#characterssetjob-and-charactersremovejob).

### jobs.current

Работа, которую другие скрипты видят как «ту» работу игрока: та, на смене которой он есть, иначе последняя, где он был на смене, иначе первая, что у него есть, иначе работа безработного.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
jobs.current(source: number): JobMembership | null
```

```lua title="Lua"
local current = aiLib.jobs.current(source)
```

#### Возвращает

[JobMembership](/ru/docs/developers/api/types#jobmembership) (`{ job, grade }`) или `null`, когда у игрока нет загруженного персонажа.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs } from "@aifivem/lib/server";

export function isOfficer(source: number): boolean {
  return jobs.current(source)?.job === "police";
}
```
</Tab>
<Tab value="Lua">
```lua
local current = aiLib.jobs.current(source)
local officer = current and current.job == 'police'
```
</Tab>
</Tabs>

### jobs.list

Каждая работа, которая есть у игрока.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
jobs.list(source: number): JobMembership[]
```

```lua title="Lua"

```

#### Возвращает

Массив [JobMembership](/ru/docs/developers/api/types#jobmembership). Пустой, когда у игрока нет загруженного персонажа или нет ни одной работы.

### jobs.duty and jobs.setDuty

В какой работе игрок на смене, и выход на смену или с неё. Многие скрипты проверяют смену, а не принадлежность: офицер не на смене - гражданский.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
jobs.duty(source: number): string | null
jobs.setDuty(source: number, job: string | null): boolean
```

```lua title="Lua"
local onDutyIn = aiLib.jobs.duty(source)
local ok = aiLib.jobs.setDuty(source, job)
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
    job: { type: 'string | null', description: 'Работа, которая есть у игрока, чтобы выйти в ней на смену. `null` (в Lua `nil`) снимает со смены.', required: true },
  }}
/>

#### Возвращает

`jobs.duty`: название работы или `null` вне смены (либо без персонажа). `jobs.setDuty`: `true`, когда изменение прошло, `false` для работы, которой у игрока нет.

### jobs.set

Добавляет игроку работу или меняет грейд работы, которая у него уже есть. Действуют правила панели: сколько работ может быть у персонажа и разрешена ли вторая вообще.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
jobs.set(source: number, job: string, grade: number): boolean
```

```lua title="Lua"
local ok = aiLib.jobs.set(source, job, grade)
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
    job: { type: 'string', description: 'Название работы как в панели (или в определении из скрипта).', required: true },
    grade: { type: 'number', description: 'Грейд в этой работе, с 0. Грейд, которого у работы нет, отклоняется.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, когда после этого у игрока есть эта работа в этом грейде. `false` без загруженного персонажа, при неизвестной работе, неизвестном грейде либо лимите работ из панели.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs, notify } from "@aifivem/lib/server";

export function hire(source: number, job: string): void {
  if (!jobs.set(source, job, 0)) return notify(source, "Не удалось принять на работу", "error");
  notify(source, `Добро пожаловать в ${job}`, "success");
}
```
</Tab>
<Tab value="Lua">
```lua
if aiLib.jobs.set(source, 'mechanic', 0) then
    aiLib.notify(source, 'Добро пожаловать в mechanic', 'success')
end
```
</Tab>
</Tabs>

### jobs.remove

Забирает работу. Персонаж без работ считается безработным: сама работа безработного никогда не сохраняется.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
jobs.remove(source: number, job: string): boolean
```

```lua title="Lua"
local ok = aiLib.jobs.remove(source, job)
```

#### Возвращает

`boolean`: `true`, когда работа забрана, `false`, когда у игрока её не было (либо нет загруженного персонажа).

### jobs.unemployed

Название работы, которая есть у персонажа без работы, как задано в панели. Никогда не считайте, что это `"unemployed"`: сервер может назвать её как угодно.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
jobs.unemployed(): string
```

```lua title="Lua"
local name = aiLib.jobs.unemployed()
```

#### Возвращает

`string`: название работы из панели.

### jobs.onDutyCount

Сколько игроков сейчас на смене в работе - число, которое обычно нужно диспетчеру или проверке на входе.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
jobs.onDutyCount(job: string): number
```

```lua title="Lua"
local count = aiLib.jobs.onDutyCount(job)
```

#### Возвращает

`number`: сколько подключённых игроков на смене в этой работе, 0 если никого.

### jobs.gangs

### jobs.activeGang and jobs.setActiveGang

Персонаж может быть в нескольких бандах, но действует за одну: это активная банда, и именно её должен читать скрипт территорий или наркотиков.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
jobs.activeGang(source: number): string | null
jobs.setActiveGang(source: number, gang: string | null): boolean
```

```lua title="Lua"
local active = aiLib.jobs.activeGang(source)
local ok = aiLib.jobs.setActiveGang(source, gang)
```

#### Возвращает

`jobs.activeGang`: название банды или `null`, если активной нет. `jobs.setActiveGang`: `true`, когда изменение прошло, `false` для банды, в которой игрока нет (`null` очищает её).

### jobs.setGang and jobs.removeGang

Добавляет, меняет грейд или забирает банду игрока.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
jobs.setGang(source: number, gang: string, grade: number): boolean
jobs.removeGang(source: number, gang: string): boolean
```

```lua title="Lua"
local ok = aiLib.jobs.setGang(source, gang, grade)
local ok = aiLib.jobs.removeGang(source, gang)
```

#### Возвращает

`boolean`, как и у работ: `false` без загруженного персонажа, при неизвестной банде или неизвестном грейде.

## dispatch

### dispatch.alert

Отправляет оповещение полиции (или другой работе). Система оповещений показывает его членам `jobs` на дежурстве, по умолчанию полицейским работам.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

<TypeTable
  type={{
    title: { type: "string", description: "Заголовок, переведённый (`Shots fired`).", required: true },
    code: { type: "string", description: "Радиокод, показываемый перед заголовком (`10-71`).", required: false },
    message: { type: "string", description: "Ещё одна строка (название магазина).", required: false },
    coords: { type: "{ x: number; y: number; z: number }", description: "Где это произошло. Без него берётся позиция игрока `source`; без обоих точки на карте нет.", required: false },
    jobs: { type: "string[]", description: "Работы, члены которых на дежурстве получают оповещение.", default: "полицейские работы системы оповещений" },
    source: { type: "number", description: "Игрок, о котором оповещение (стрелок, грабитель). Системы, которые описывают подозреваемого (транспорт, пол), читают этого игрока.", required: false },
    blip: { type: "{ sprite: number; color?: number; scale?: number }", description: "Блип на карте: спрайт и цвет блипа GTA.", default: "из системы оповещений" },
    duration: { type: "number", description: "Сколько секунд держится оповещение (карточка, блип, клавиша маршрута).", default: "из системы оповещений" },
    icon: { type: "string", description: "Имя сплошной иконки Font Awesome без `fa-` (`gun`).", required: false },
    priority: { type: '"normal" | "high"', description: "`high` выделяет карточку (вооружённое ограбление, ранен офицер).", default: '"normal"' },
  }}
/>

Тип: [`DispatchAlert`](/ru/docs/developers/api/types#dispatchalert).

#### Возвращает

`boolean`: `true`, если отправлено. `false`, если не запущена система оповещений или оповещение неверное.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>

```ts
  dispatch.alert({

    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```

## medical

Реанимация, лечение и состояние без сознания через медицинский слой ai-core, какой бы скрипт смерти или скорой помощи ни был запущен. Lua-аналога нет: вызывайте экспорты ai-core `RevivePlayer`, `HealPlayer`, `IsPlayerDead`.

### medical.revive

Поднимает игрока без сознания там, где он лежит.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
medical.revive(source: number): boolean
```

**Возвращает** `true`, если реанимирован, `false`, если игрок не без сознания или не запущен скрипт смерти.

```ts
if (!medical.revive(target)) return fail("NOT_DOWN");
```

### medical.heal

Полностью восстанавливает здоровье игроку, который не лежит без сознания.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
medical.heal(source: number): boolean
```

**Возвращает** `true`, если вылечен, `false`, если не запущен скрипт смерти.

```ts
medical.heal(source);
```

### medical.isDead

Лежит ли игрок без сознания.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
medical.isDead(source: number): boolean
```

**Возвращает** `true`, если без сознания; `false` без скрипта смерти. Используйте вместо чтения здоровья педа.

```ts
if (medical.isDead(source)) return fail("YOU_ARE_DOWN");
```

### medical.provider

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
medical.provider(): string | null
```

**Возвращает** скрипт смерти, который отвечает (`ai-death`...), или `null`, если никакой не запущен.

```ts
console.log(`deaths through ${medical.provider() ?? "nothing"}`);
```

## Определения работ и банд

### definitions.job

Определение работы так, как оно задано в панели ai-core. Каждое читается из ai-core один раз и хранится, пока панель его не изменит, поэтому чтение сводится к поиску в памяти.

**Сторона:** Сервер · **Ждёт:** нет

**Возвращает** [`JobDefinition`](/ru/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`) или `null`, если такой работы нет.

```ts
const label = definitions.job("police")?.label ?? "police";
```

### definitions.registerJob and definitions.removeJob

Работа, которую приносит ваш скрипт, без добавления владельцем в панель: работа вызывающего ресурса, исчезает, когда ресурс останавливается, и никогда не пишется в файл панели.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
definitions.registerJob(name: string, definition: JobDefinition): CharacterResult
definitions.removeJob(name: string): boolean
```

```lua title="Lua"
local result = aiLib.definitions.registerJob(name, definition)
local ok = aiLib.definitions.removeJob(name)
```

#### Параметры

<TypeTable
  type={{
    name: { type: 'string', description: 'Название работы, которое использует ваш скрипт (`"my-garbagejob"`).', required: true },
    definition: { type: 'JobDefinition', typeDescriptionLink: '/ru/docs/developers/api/types#jobdefinition', description: 'Сама работа: `label`, `type`, `defaultDuty`, `listed` и её `grades` (каждый с `label`, `salary`, `boss`).', required: true },
  }}
/>

#### Возвращает

`registerJob` отвечает [ActionResult](/ru/docs/developers/api/types#actionresult): `{ ok: true }` или `{ ok: false, error }` с языковым ключом, когда в панели уже есть работа с таким названием либо её зарегистрировал другой ресурс - панель владельца всегда выигрывает. `removeJob` отвечает `true` только для работы, которую зарегистрировал этот ресурс.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { definitions } from "@aifivem/lib/server";

// Один раз при запуске: работа существует, пока работает этот ресурс.
const result = definitions.registerJob("garbage", {
  label: "Garbage",
  type: "job",
  defaultDuty: true,
  grades: [{ label: "Driver", salary: 60, boss: false }],
});
if (!result.ok) console.log(`работа не зарегистрирована: ${result.error}`);
```
</Tab>
<Tab value="Lua">
```lua
local result = aiLib.definitions.registerJob('garbage', {
    label = 'Garbage',
    type = 'job',
    defaultDuty = true,
    grades = { { label = 'Driver', salary = 60, boss = false } },
})
if not result.ok then print(('работа не зарегистрирована: %s'):format(result.error)) end
```
</Tab>
</Tabs>

<Callout type="info">
Работа, которую владелец сервера должен уметь править, относится к панели, а не сюда. Регистрируйте её, когда работа - часть вашего скрипта и без него ничего не значит.
</Callout>

```ts title="Сигнатура"

```

Lua-аналога нет: вызывайте экспорт ai-core `IsPrimeTime(job)`.

  type={{
