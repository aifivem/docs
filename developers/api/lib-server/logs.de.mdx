```ts title="TypeScript"
import { aiLog, aiLogChannels } from "@aicore-fivem/lib/server";
```

Dein Skript postet nie selbst an Discord oder einen Log-Dienst. Es sendet einen Log über einen **Kanal** (ein Name wie `purchase`) an ai-core; der Serverbetreiber legt im Admin-Panel von ai-core fest, wohin jeder Kanal geht. Webhook-URLs und API-Schlüssel bleiben im Panel, nie in deinem Code.

### aiLog

Sendet eine Log-Zeile über das Log-System von ai-core.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
aiLog(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
aiLib.aiLog(channel, message, options)
```

#### Parameter

<TypeTable
  type={{
    channel: { type: "string", description: "Der Kanalname (`purchase`, `admin`). Beschreibe deine Kanäle einmal mit `aiLogChannels`.", required: true },
    message: { type: "string", description: "Was passiert ist. Übergib die Spieler als `source` / `target`, statt Namen in den Text zu schreiben.", required: true },
    options: { type: "LogOptions", typeDescriptionLink: "/de/docs/developers/api/types#logoptions", description: "Stufe, Spieler und zusätzliche Werte. Felder unten.", required: false },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: "Schweregrad.", required: false },
    source: { type: "number", description: "Server-ID des Spielers, der es getan hat. Sein Name, sein Charakter und seine Identifier werden hinzugefügt.", required: false },
    target: { type: "number", description: "Server-ID des Spielers, an dem es getan wurde.", required: false },
    metadata: { type: "Record<string, unknown>", description: "Zusätzliche Felder (Beträge, Item-Namen, Koordinaten).", required: false },
  }}
/>

#### Rückgabewert

`void`. In TypeScript tut es nichts, solange ai-core nicht läuft; der Lua-Zwilling gibt stattdessen `[channel] message` in der Konsole aus.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { aiLog } from "@aicore-fivem/lib/server";

aiLog("purchase", `bought ${count}x ${item} for $${price}`, {
  source,
  metadata: { item, count, price },
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.aiLog('purchase', ('bought %dx %s for $%d'):format(count, item, price), {
    source = source,
    metadata = { item = item, count = count, price = price },
})
```
</Tab>
</Tabs>

### aiLogChannels

Beschreibt die Log-Kanäle deiner Ressource: den Dataset-Namen, den Fivemanage und FiveM Stats nutzen, und ob ein Kanal eingeschaltet ist. Rufe es einmal beim Start deines Skripts auf.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
aiLogChannels(channels: Record<string, LogChannel>): void
```

Kein Lua-Zwilling: Rufe den Export von ai-core auf, `exports['ai-core']:LogChannels(channels)`.

#### Parameter

<TypeTable
  type={{
    channels: { type: "Record<string, LogChannel>", typeDescriptionLink: "/de/docs/developers/api/types#logchannel", description: "Ein Eintrag pro Kanalname. Jeder `LogChannel` hat `dataset?` (Dataset für Fivemanage / FiveM Stats, Standard ist der Ressourcenname) und `active?` (`false` schaltet den Kanal aus).", required: true },
  }}
/>

#### Rückgabewert

`void`. Tut nichts, solange ai-core nicht läuft.

#### Beispiel

```ts
import { aiLogChannels } from "@aicore-fivem/lib/server";

aiLogChannels({
  purchase: { dataset: "shops" },
  debug: { active: false },
});
```
