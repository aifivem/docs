icon: Package

```ts title="TypeScript"
import { inventory } from "@aicore-fivem/lib/server";
```

`inventory` envia toda chamada de item pela camada de inventário do ai-core: o inventário que o servidor roda (ai-inventory, ou outro que o dono escolhe no painel do ai-core) responde. Seu script nunca chama os exports próprios de um inventário, então continua funcionando quando o dono troca de inventário.

**O argumento de inventário** (`inv`, tipo [`InventoryRef`](/pt/docs/developers/api/types#inventoryref)) é o id de servidor de um jogador (um número) ou o id de outro inventário (uma string: o nome de um baú, uma placa).

**Quantidades** são números inteiros de 1 ou mais; uma fração é arredondada para baixo, e `0` ou uma quantidade negativa faz a chamada falhar.

<Callout type="info">
Enquanto nenhum inventário está rodando, as chamadas falham em silêncio: `false`, `0`, uma lista vazia ou `null`. Os equivalentes em Lua em `aiLib.inventory` têm os mesmos nomes e a mesma ordem de argumentos.
</Callout>

### inventory.addItem

Dá itens a um inventário.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
inventory.addItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = aiLib.inventory.addItem(inv, item, count, metadata, slot)
```

#### Parâmetros

<TypeTable
  type={{
    inv: { type: "InventoryRef", typeDescriptionLink: "/pt/docs/developers/api/types#inventoryref", description: "Id de servidor do jogador, ou o nome de um baú ou uma placa.", required: true },
    item: { type: "string", description: "Nome do item como o inventário o conhece (`water`).", required: true },
    count: { type: "number", description: "Quantos.", default: "1" },
    metadata: { type: "ItemMetadata", typeDescriptionLink: "/pt/docs/developers/api/types#itemmetadata", description: "Dados extras guardados na pilha (`{ serial: \"A1\" }`). Pilhas com metadata diferente não se juntam.", required: false },
    slot: { type: "number", description: "Coloca-os neste slot (1 ou mais) quando o inventário suporta isso.", required: false },
  }}
/>

#### Retorno

`boolean`: `true` quando dados. `false` quando não cabem, o item não existe, um argumento está errado ou nenhum inventário está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

if (!inventory.addItem(source, "phone", 1, { number: "555-0101" })) return fail("INVENTORY_FULL");
```
</Tab>
<Tab value="Lua">
```lua
if not aiLib.inventory.addItem(source, 'phone', 1, { number = '555-0101' }) then
    return aiLib.fail('INVENTORY_FULL')
end
```
</Tab>
</Tabs>

<Callout type="warn">
Verifique `canCarryItem` antes quando você recebe algo em troca (dinheiro, outro item): tire-o só depois que `addItem` respondeu `true`, ou devolva-o.
</Callout>

### inventory.openInventory

Abre um baú ou o inventário de outro jogador na tela de um jogador.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
inventory.openInventory(source: number, inv: InventoryRef): boolean
```

```lua title="Lua"
local ok = aiLib.inventory.openInventory(source, inv)
```

<TypeTable
  type={{
    source: { type: "number", description: "Id de servidor do jogador que o vê.", required: true },
    inv: { type: "InventoryRef", typeDescriptionLink: "/pt/docs/developers/api/types#inventoryref", description: "Nome do baú, placa, ou o id de servidor de outro jogador.", required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o inventário o abriu.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, near, online, inventory } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const ARMORY = { x: 452.3, y: -980.0, z: 30.7 };

onClientCallback(
  "my-police:armory",
  (source) => {
    if (!online.onDutyIn(source, ["police"])) return fail("NOT_ON_DUTY");
    return { ok: inventory.openInventory(source, "police_armory") };
  },
  { guards: [near(ARMORY, 3)] },
);
```
</Tab>
<Tab value="Lua">
```lua
local ARMORY = vector3(452.3, -980.0, 30.7)

aiLib.onClientCallback('my-police:armory', function(source)
    if aiLib.online.dutyJob(source) ~= 'police' then return aiLib.fail('NOT_ON_DUTY') end
    if #(GetEntityCoords(GetPlayerPed(source)) - ARMORY) > 3.0 then return aiLib.fail('TOO_FAR') end
    return { ok = aiLib.inventory.openInventory(source, 'police_armory') }
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Nenhuma verificação de distância ou de acesso acontece aqui: verifique distância, emprego e posse antes de chamá-lo.
</Callout>

### inventory.registerUsableItem

Roda o seu handler quando um jogador usa um item. O ai-core guarda o handler para inventários que iniciarem depois e entre reinícios do inventário, então registre uma vez quando o script iniciar.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
inventory.registerUsableItem(name: string, handler: UsableItemHandler): void
```

```lua title="Lua"
aiLib.inventory.registerUsableItem(name, handler) -- handler(source, item)
```

#### Parâmetros

<TypeTable
  type={{
    name: { type: "string", description: "Nome do item.", required: true },
    handler: { type: "(source: number, item: UsedItem) => unknown", typeDescriptionLink: "/pt/docs/developers/api/types#usableitemhandler", description: "Recebe o jogador e a pilha usada `{ name, slot, count, metadata }` (tipo `UsedItem`). Retornar `false` mantém o item nos inventários que tiram o item usado por conta própria (ai-inventory: a quantidade `consume` do item); outros inventários seguem as próprias configurações de item.", required: true },
  }}
/>

A pilha usada é um [`UsedItem`](/pt/docs/developers/api/types#useditem).

<Callout type="warn">
Inventários que tiram o item usado por conta própria (ai-inventory) o tiram assim que o handler retorna qualquer coisa diferente de `false`. Quando o seu handler espera (uma barra de progresso) e remove o item ele mesmo, retorne `false` na hora, senão o item é tirado duas vezes.
</Callout>

#### Retorno

`void`.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory, progressFor, medical, createLocale } from "@aicore-fivem/lib/server";

const Locale = createLocale();

async function bandage(source: number) {
  const done = await progressFor(source, { label: Locale("BANDAGING"), duration: 4000, canCancel: true });
  if (done && inventory.removeItem(source, "bandage")) medical.heal(source);
}

inventory.registerUsableItem("bandage", (source) => {
  void bandage(source);
  return false; // mantém o item agora: bandage() o tira depois da barra
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.inventory.registerUsableItem('bandage', function(source, item)
    CreateThread(function()
        local done = aiLib.progressFor(source, { label = Locale('BANDAGING'), duration = 4000, canCancel = true })
        if done and aiLib.inventory.removeItem(source, 'bandage', 1) then
            exports['ai-core']:HealPlayer(source)
        end
    end)
    return false -- mantém o item agora: a thread o tira depois da barra
end)
```
</Tab>
</Tabs>
