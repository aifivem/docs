## phone

The player's phone through ai-core: the first phone script that runs (tgiann-phone, lb-phone...) answers. Without a phone script every call answers `null` or `false`. The Lua twins on `aiLib.phone` have the same names and argument order.

### phone.number

**Side:** Server · **Waits:** no

```ts title="Signature"
phone.number(source: number): string | null
```

```lua title="Lua"
local number = aiLib.phone.number(source)
```

**Returns** the player's phone number, or `null` (Lua `nil`) when they have none or no phone script runs.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const number = phone.number(source);
if (!number) return fail("NO_PHONE_NUMBER");
```
</Tab>
<Tab value="Lua">
```lua
local number = aiLib.phone.number(source)
if not number then return aiLib.fail('NO_PHONE_NUMBER') end
```
</Tab>
</Tabs>

### phone.sourceOf

The online player who owns a phone number.

**Side:** Server · **Waits:** no

```ts title="Signature"
phone.sourceOf(number: string): number | null
```

```lua title="Lua"
local source = aiLib.phone.sourceOf(number)
```

**Returns** the server id, or `null` (Lua `nil`) when nobody online has that number.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const owner = phone.sourceOf("555-0101");
if (owner !== null) notify(owner, "Your phone is ringing");
```
</Tab>
<Tab value="Lua">
```lua
local owner = aiLib.phone.sourceOf('555-0101')
if owner then aiLib.notify(owner, 'Your phone is ringing') end
```
</Tab>
</Tabs>

## appearance

Characters' stored looks through ai-core's appearance layer, whatever clothing script runs (ai-appearance, tgiann-clothing).

### appearance.get

A character's stored look, loaded or not. Use it to dress a ped that stands in for a character (a sleeping body, a mannequin): hand the result unchanged to the client's `appearance.apply` ([Lib: client](/docs/developers/api/lib-client)).

**Side:** Server · **Waits:** yes (Promise in TypeScript, yields the thread in Lua)

```ts title="Signature"
appearance.get(charId: number): Promise<CharacterAppearance | null>
```

```lua title="Lua"
local look = aiLib.appearance.get(charId) -- { model, data } or nil, call inside a thread
```

<TypeTable
  type={{
    charId: { type: "number", description: "The character id (`CharacterInfo.id`).", required: true },
  }}
/>

#### Returns

`Promise<CharacterAppearance | null>`: [`CharacterAppearance`](/docs/developers/api/types#characterappearance) is `{ model, data }` (the ped model hash and the clothing script's own look data). `null` when the character has none, no clothing script runs, or ai-core is stopped.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { appearance, online, playersNear } from "@aifivem/lib/server";

async function sendLook(source: number) {
  const charId = online.charId(source);
  if (charId === undefined) return;
  const look = await appearance.get(charId);
  if (!look) return;
  // Only the players near this character need the look.
  for (const other of playersNear(source, 100)) emitNet("my-sleepers:look", other, source, look);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local character = aiLib.online.character(source)
    if not character then return end
    local look = aiLib.appearance.get(character.id)
    if look then TriggerClientEvent('my-sleepers:look', source, look) end
end)
```
</Tab>
</Tabs>

### appearance.provider

**Side:** Server · **Waits:** no

```ts title="Signature"
appearance.provider(): string | null
```

```lua title="Lua"
local name = aiLib.appearance.provider()
```

**Returns** the clothing script that answers, or `null` (Lua `nil`) when none runs.

```ts
console.log(`looks through ${appearance.provider() ?? "nothing"}`);
```
