## world

Hangi hava script’i çalışıyorsa (Renewed-Weathersync, av_weather, cd_easytime, qb-weathersync) ai-core üzerinden saat ve hava. Hiçbiri çalışmıyorken okumalar `null`, değişiklikler `false` cevabını verir.

### world.getWeather

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
world.getWeather(): string | null
```

```lua title="Lua"
local weather = aiLib.world.getWeather()
```

**Dönüş değeri**: hava script’inin bildirdiği haliyle güncel hava tipi (`CLEAR`, `RAIN`...) ya da hiçbiri çalışmıyorken `null`.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const raining = ["RAIN", "THUNDER"].includes(world.getWeather() ?? "");
```
</Tab>
<Tab value="Lua">
```lua
local weather = aiLib.world.getWeather()
local raining = weather == 'RAIN' or weather == 'THUNDER'
```
</Tab>
</Tabs>

### world.setWeather

Havayı ayarlar.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
world.setWeather(type: Weather): boolean
```

```lua title="Lua"
local ok = aiLib.world.setWeather(weather)
```

<TypeTable
  type={{
    type: { type: "Weather", typeDescriptionLink: "/tr/docs/developers/api/types#weather", description: "`EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN` değerlerinden biri. Bir client’tan ya da panelden gelen değeri önce `isWeather` (`@aicore-fivem/shared`) ile kontrol et.", required: true },
  }}
/>

**Dönüş değeri**: ayarlandıysa `true`; hiçbir hava script’i çalışmıyorken ya da değer bir string değilse `false`.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, world } from "@aicore-fivem/lib/server";
import { isWeather } from "@aicore-fivem/shared";

addCommand("weather", { restricted: true, params: [{ name: "type", type: "string" }] }, (_source, { type }) => {
  const upper = type.toUpperCase();
  if (isWeather(upper)) world.setWeather(upper);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { restricted = true, params = { { name = 'type', type = 'string' } } }, function(_, args)
    aiLib.world.setWeather(args.type:upper())
end)
```
</Tab>
</Tabs>

## buckets

ai-core’un dağıtıcısından routing bucket’lar (ayrı dünyalar: bir daire içi, bir instance); böylece iki script asla aynı bucket’ı paylaşmaz. Bucket numaralarını asla kendin seçme (`1000 + n`). Lua karşılığı yok: ai-core’un `AcquireBucket(tag)` / `ReleaseBucket(id)` export’larını çağır.

### buckets.acquire

Bu resource için boş bir bucket alır. Bucket’ta nüfus yoktur (çevredeki ped’ler ve arabalar yok) ve katı entity kilidi (lockdown) vardır.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
buckets.acquire(tag: string): number
```

<TypeTable
  type={{
    tag: { type: "string", description: "Loglar için bir ad (`property:12`).", required: true },
  }}
/>

**Dönüş değeri**: bucket id’si.

```ts
import { buckets } from "@aicore-fivem/lib/server";

const bucket = buckets.acquire(`property:${propertyId}`);
SetPlayerRoutingBucket(String(source), bucket);
```

### buckets.release

İçindeki oyuncular çıktıktan sonra bir bucket’ı geri verir.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
buckets.release(id: number): boolean
```

**Dönüş değeri**: serbest bırakıldıysa `true`. Duran bir resource’un her bucket’ı kendiliğinden geri döner.

```ts
SetPlayerRoutingBucket(String(source), 0);
buckets.release(bucket);
```

## doors

Kapı kilidi script’inin kendi kapı id’siyle, ai-core’un kapı kilidi katmanı üzerinden kapı kilitleri. Lua karşılığı yok: ai-core’un `SetDoorLocked`, `IsDoorLocked` export’larını çağır.

### doors.setLocked

Bir kapıyı kilitler ya da kilidini açar.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
doors.setLocked(id: string, locked: boolean, by?: number): boolean
```

<TypeTable
  type={{
    id: { type: "string", description: "Kapı kilidi script’inin kendi kapı id’si (ai-doorlock panelindeki kapı id’si).", required: true },
    locked: { type: "boolean", description: "`true` kilitler, `false` kilidi açar.", required: true },
    by: { type: "number", description: "İşlemi yapan oyuncunun server id’si. Server API’si olmayan kapı script’leri buna ihtiyaç duyar.", required: false },
  }}
/>

**Dönüş değeri**: bir kapı script’i isteği aldıysa `true`, değilse `false`.

```ts
if (outcome === "won") doors.setLocked("bank_vault", false, source);
```

### doors.isLocked

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
doors.isLocked(id: string): boolean | null
```

**Dönüş değeri**: `true` ya da `false`, bilinmiyorsa `null` (kapı kilidi yok, böyle bir kapı yok ya da script server’da bunu söyleyemiyor).

```ts
if (doors.isLocked("bank_vault") === false) return fail("ALREADY_OPEN");
```

### doors.provider

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
doors.provider(): string | null
```

**Dönüş değeri**: cevap veren kapı kilidi script’i ya da hiçbiri çalışmıyorsa `null`.

```ts
console.log(`doors through ${doors.provider() ?? "nothing"}`);
```

## characters

ai-core üzerinden kayıtlı karakterler. Yüklü karakterler `online` ve ai-core’un oyuncu export’ları üzerinden gider.

### characters.setOfflinePosition

Kayıtlı (yüklü olmayan) bir karakterin doğma noktasını taşır; örneğin başka yere taşınmış uyuyan bir beden. ai-core bunu, karakteri tutan bir yükleme ya da çıkış kaydı kalmadığında yazar.

**Taraf:** Server · **Bekler:** hayır

```ts title="Signature"
characters.setOfflinePosition(charId: number, position: { x: number; y: number; z: number; heading?: number }): boolean
```

Lua karşılığı yok: ai-core’un `SetOfflinePosition(charId, position)` export’unu çağır.

<TypeTable
  type={{
    charId: { type: "number", description: "Karakter id’si (`CharacterInfo.id`).", required: true },
    position: { type: "{ x: number; y: number; z: number; heading?: number }", description: "Yeni doğma noktası; heading derece cinsinden.", required: true },
  }}
/>

**Dönüş değeri**: kabul edildiyse `true`. Karakter yüklüyse ya da değerler yanlışsa `false`.

```ts
characters.setOfflinePosition(sleeperCharId, { x: 340.2, y: -1396.7, z: 32.5, heading: 50 });
```
