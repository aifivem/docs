```ts title="TypeScript"
import { aiLog, aiLogChannels } from "@aicore-fivem/lib/server";
```

Ваш скрипт никогда сам не отправляет сообщения в Discord или сервис логов. Он отправляет лог в ai-core по **каналу** (имя вроде `purchase`); владелец сервера решает в админ-панели ai-core, куда идёт каждый канал. URL вебхуков и API-ключи остаются в панели и никогда не попадают в ваш код.

### aiLog

Отправляет одну строку лога через систему логов ai-core.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
aiLog(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
aiLib.aiLog(channel, message, options)
```

#### Параметры

<TypeTable
  type={{
    channel: { type: "string", description: "Имя канала (`purchase`, `admin`). Опишите свои каналы один раз через `aiLogChannels`.", required: true },
    message: { type: "string", description: "Что произошло. Передавайте игроков как `source` / `target`, а не вписывайте имена в текст.", required: true },
    options: { type: "LogOptions", typeDescriptionLink: "/ru/docs/developers/api/types#logoptions", description: "Уровень, игроки и дополнительные значения. Поля ниже.", required: false },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: "Важность.", required: false },
    source: { type: "number", description: "Серверный id игрока, который это сделал. Добавляются его имя, персонаж и идентификаторы.", required: false },
    target: { type: "number", description: "Серверный id игрока, с которым это сделали.", required: false },
    metadata: { type: "Record<string, unknown>", description: "Дополнительные поля (суммы, названия предметов, координаты).", required: false },
  }}
/>

#### Возвращает

`void`. В TypeScript ничего не делает, пока ai-core не запущен; Lua-аналог вместо этого выводит `[channel] message` в консоль.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { aiLog } from "@aicore-fivem/lib/server";

aiLog("purchase", `bought ${count}x ${item} for $${price}`, {
  source,
  metadata: { item, count, price },
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.aiLog('purchase', ('bought %dx %s for $%d'):format(count, item, price), {
    source = source,
    metadata = { item = item, count = count, price = price },
})
```
</Tab>
</Tabs>

### aiLogChannels

Описывает каналы логов вашего ресурса: имя набора данных, которое используют Fivemanage и FiveM Stats, и включён ли канал. Вызовите один раз при запуске скрипта.

**Сторона:** Сервер · **Ждёт:** нет

```ts title="Сигнатура"
aiLogChannels(channels: Record<string, LogChannel>): void
```

Lua-аналога нет: вызывайте экспорт ai-core `exports['ai-core']:LogChannels(channels)`.

#### Параметры

<TypeTable
  type={{
    channels: { type: "Record<string, LogChannel>", typeDescriptionLink: "/ru/docs/developers/api/types#logchannel", description: "Одна запись на имя канала. У каждого `LogChannel` есть `dataset?` (набор данных Fivemanage / FiveM Stats, по умолчанию имя ресурса) и `active?` (`false` выключает канал).", required: true },
  }}
/>

#### Возвращает

`void`. Ничего не делает, пока ai-core не запущен.

#### Пример

```ts
import { aiLogChannels } from "@aicore-fivem/lib/server";

aiLogChannels({
  purchase: { dataset: "shops" },
  debug: { active: false },
});
```
