## world

Hora e clima pelo ai-core, qualquer que seja o script de clima rodando (Renewed-Weathersync, av_weather, cd_easytime, qb-weathersync). Enquanto nenhum está rodando, as leituras respondem `null` e as mudanças respondem `false`.

### world.getWeather

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
world.getWeather(): string | null
```

```lua title="Lua"
local weather = aiLib.world.getWeather()
```

**Retorno** o tipo de clima atual como o script de clima o informa (`CLEAR`, `RAIN`...), ou `null` enquanto nenhum está rodando.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const raining = ["RAIN", "THUNDER"].includes(world.getWeather() ?? "");
```
</Tab>
<Tab value="Lua">
```lua
local weather = aiLib.world.getWeather()
local raining = weather == 'RAIN' or weather == 'THUNDER'
```
</Tab>
</Tabs>

### world.setWeather

Define o clima.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
world.setWeather(type: Weather): boolean
```

```lua title="Lua"
local ok = aiLib.world.setWeather(weather)
```

<TypeTable
  type={{
    type: { type: "Weather", typeDescriptionLink: "/pt/docs/developers/api/types#weather", description: "Um de `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Verifique antes um valor vindo de um cliente ou do painel com `isWeather` (`@aifivem/shared`).", required: true },
  }}
/>

**Retorno** `true` quando definido, `false` enquanto nenhum script de clima está rodando ou o valor não é uma string.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, world } from "@aifivem/lib/server";
import { isWeather } from "@aifivem/shared";

addCommand("weather", { restricted: true, params: [{ name: "type", type: "string" }] }, (_source, { type }) => {
  const upper = type.toUpperCase();
  if (isWeather(upper)) world.setWeather(upper);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { restricted = true, params = { { name = 'type', type = 'string' } } }, function(_, args)
    aiLib.world.setWeather(args.type:upper())
end)
```
</Tab>
</Tabs>

## buckets

Routing buckets (mundos separados: o interior de um apartamento, uma instância) do alocador do ai-core, para que dois scripts nunca compartilhem um. Nunca escolha números de bucket você mesmo (`1000 + n`). Sem equivalente em Lua: chame os exports do ai-core `AcquireBucket(tag)` / `ReleaseBucket(id)`.

### buckets.acquire

Pega um bucket livre para este recurso. Ele não tem população (sem peds e carros ambientes) e tem lockdown estrito de entidades.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
buckets.acquire(tag: string): number
```

<TypeTable
  type={{
    tag: { type: "string", description: "Um nome para os logs (`property:12`).", required: true },
  }}
/>

**Retorno** o id do bucket.

```ts
import { buckets } from "@aifivem/lib/server";

const bucket = buckets.acquire(`property:${propertyId}`);
SetPlayerRoutingBucket(String(source), bucket);
```

### buckets.release

Devolve um bucket quando os jogadores dele já saíram.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
buckets.release(id: number): boolean
```

**Retorno** `true` quando liberado. Todo bucket de um recurso parado volta sozinho.

```ts
SetPlayerRoutingBucket(String(source), 0);
buckets.release(bucket);
```

## doors

Trancas de portas pela camada de trancas do ai-core, pelo id de porta do próprio script de trancas. Sem equivalente em Lua: chame os exports do ai-core `SetDoorLocked`, `IsDoorLocked`.

### doors.setLocked

Tranca ou destranca uma porta.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
doors.setLocked(id: string, locked: boolean, by?: number): boolean
```

<TypeTable
  type={{
    id: { type: "string", description: "O id de porta do próprio script de trancas (o id da porta no painel do ai-doorlock).", required: true },
    locked: { type: "boolean", description: "`true` tranca, `false` destranca.", required: true },
    by: { type: "number", description: "Id de servidor do jogador que age. Scripts de porta sem uma API de servidor precisam dele.", required: false },
  }}
/>

**Retorno** `true` quando um script de portas a aceitou, `false` caso contrário.

```ts
if (outcome === "won") doors.setLocked("bank_vault", false, source);
```

### doors.isLocked

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
doors.isLocked(id: string): boolean | null
```

**Retorno** `true` ou `false`, ou `null` quando desconhecido (sem tranca de portas, porta inexistente, ou o script não consegue informar no servidor).

```ts
if (doors.isLocked("bank_vault") === false) return fail("ALREADY_OPEN");
```

### doors.provider

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
doors.provider(): string | null
```

**Retorno** o script de trancas que responde, ou `null` quando nenhum está rodando.

```ts
console.log(`doors through ${doors.provider() ?? "nothing"}`);
```

## characters

Personagens salvos pelo ai-core. Personagens carregados passam por `online` e pelos exports de jogador do ai-core.

### characters.setOfflinePosition

Move o ponto de spawn de um personagem salvo (não carregado), por exemplo um corpo dormindo que foi carregado para longe. O ai-core o escreve assim que nenhum salvamento de carga ou descarga segura o personagem.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
characters.setOfflinePosition(charId: number, position: { x: number; y: number; z: number; heading?: number }): boolean
```

Sem equivalente em Lua: chame o export do ai-core `SetOfflinePosition(charId, position)`.

<TypeTable
  type={{
    charId: { type: "number", description: "O id do personagem (`CharacterInfo.id`).", required: true },
    position: { type: "{ x: number; y: number; z: number; heading?: number }", description: "O novo ponto de spawn; heading em graus.", required: true },
  }}
/>

**Retorno** `true` quando aceito. `false` quando o personagem está carregado ou os valores estão errados.

```ts
characters.setOfflinePosition(sleeperCharId, { x: 340.2, y: -1396.7, z: 32.5, heading: 50 });
```
