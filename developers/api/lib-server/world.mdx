## world

Time and weather through ai-core, whatever weather script runs (Renewed-Weathersync, av_weather, cd_easytime, qb-weathersync). While none runs, reads answer `null` and changes answer `false`.

### world.getWeather

**Side:** Server · **Waits:** no

```ts title="Signature"
world.getWeather(): string | null
```

```lua title="Lua"
local weather = aiLib.world.getWeather()
```

**Returns** the current weather type as the weather script reports it (`CLEAR`, `RAIN`...), or `null` while none runs.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const raining = ["RAIN", "THUNDER"].includes(world.getWeather() ?? "");
```
</Tab>
<Tab value="Lua">
```lua
local weather = aiLib.world.getWeather()
local raining = weather == 'RAIN' or weather == 'THUNDER'
```
</Tab>
</Tabs>

### world.setWeather

Sets the weather.

**Side:** Server · **Waits:** no

```ts title="Signature"
world.setWeather(type: Weather): boolean
```

```lua title="Lua"
local ok = aiLib.world.setWeather(weather)
```

<TypeTable
  type={{
    type: { type: "Weather", typeDescriptionLink: "/docs/developers/api/types#weather", description: "One of `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Check a value from a client or the panel with `isWeather` (`@aifivem/shared`) first.", required: true },
  }}
/>

**Returns** `true` when set, `false` while no weather script runs or the value is not a string.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, world } from "@aifivem/lib/server";
import { isWeather } from "@aifivem/shared";

addCommand("weather", { restricted: true, params: [{ name: "type", type: "string" }] }, (_source, { type }) => {
  const upper = type.toUpperCase();
  if (isWeather(upper)) world.setWeather(upper);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { restricted = true, params = { { name = 'type', type = 'string' } } }, function(_, args)
    aiLib.world.setWeather(args.type:upper())
end)
```
</Tab>
</Tabs>

## buckets

Routing buckets (separate worlds: an apartment interior, an instance) from ai-core's allocator, so no two scripts ever share one. Never pick bucket numbers yourself (`1000 + n`). No Lua twin: call ai-core's exports `AcquireBucket(tag)` / `ReleaseBucket(id)`.

### buckets.acquire

Takes a free bucket for this resource. It has no population (no ambient peds and cars) and strict entity lockdown.

**Side:** Server · **Waits:** no

```ts title="Signature"
buckets.acquire(tag: string): number
```

<TypeTable
  type={{
    tag: { type: "string", description: "A name for logs (`property:12`).", required: true },
  }}
/>

**Returns** the bucket id.

```ts
import { buckets } from "@aifivem/lib/server";

const bucket = buckets.acquire(`property:${propertyId}`);
SetPlayerRoutingBucket(String(source), bucket);
```

### buckets.release

Gives a bucket back once its players are out.

**Side:** Server · **Waits:** no

```ts title="Signature"
buckets.release(id: number): boolean
```

**Returns** `true` when released. Every bucket of a stopped resource goes back by itself.

```ts
SetPlayerRoutingBucket(String(source), 0);
buckets.release(bucket);
```

## doors

Door locks through ai-core's door lock layer, by the door lock script's own door id. No Lua twin: call ai-core's exports `SetDoorLocked`, `IsDoorLocked`.

### doors.setLocked

Locks or unlocks a door.

**Side:** Server · **Waits:** no

```ts title="Signature"
doors.setLocked(id: string, locked: boolean, by?: number): boolean
```

<TypeTable
  type={{
    id: { type: "string", description: "The door lock script’s own door id (the door id in ai-doorlock’s panel).", required: true },
    locked: { type: "boolean", description: "`true` locks, `false` unlocks.", required: true },
    by: { type: "number", description: "Server id of the player acting. Door scripts without a server API need one.", required: false },
  }}
/>

**Returns** `true` when a door script took it, `false` otherwise.

```ts
if (outcome === "won") doors.setLocked("bank_vault", false, source);
```

### doors.isLocked

**Side:** Server · **Waits:** no

```ts title="Signature"
doors.isLocked(id: string): boolean | null
```

**Returns** `true` or `false`, or `null` when unknown (no door lock, no such door, or the script cannot tell on the server).

```ts
if (doors.isLocked("bank_vault") === false) return fail("ALREADY_OPEN");
```

### doors.provider

**Side:** Server · **Waits:** no

```ts title="Signature"
doors.provider(): string | null
```

**Returns** the door lock script that answers, or `null` when none runs.

```ts
console.log(`doors through ${doors.provider() ?? "nothing"}`);
```

## characters

Stored characters through ai-core. Loaded characters go through `online` and ai-core's player exports.

### characters.setOfflinePosition

Moves a stored (not loaded) character's spawn point, for example a sleeping body that was carried away. ai-core writes it once no load or unload save holds the character.

**Side:** Server · **Waits:** no

```ts title="Signature"
characters.setOfflinePosition(charId: number, position: { x: number; y: number; z: number; heading?: number }): boolean
```

No Lua twin: call ai-core's export `SetOfflinePosition(charId, position)`.

<TypeTable
  type={{
    charId: { type: "number", description: "The character id (`CharacterInfo.id`).", required: true },
    position: { type: "{ x: number; y: number; z: number; heading?: number }", description: "The new spawn point; heading in degrees.", required: true },
  }}
/>

**Returns** `true` when accepted. `false` when the character is loaded or the values are wrong.

```ts
characters.setOfflinePosition(sleeperCharId, { x: 340.2, y: -1396.7, z: 32.5, heading: 50 });
```
