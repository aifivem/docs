## world

Zeit und Wetter über ai-core, egal welches Wetter-Skript läuft (Renewed-Weathersync, av_weather, cd_easytime, qb-weathersync). Solange keins läuft, antworten Lesezugriffe mit `null` und Änderungen mit `false`.

### world.getWeather

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
world.getWeather(): string | null
```

```lua title="Lua"
local weather = aiLib.world.getWeather()
```

**Rückgabewert:** der aktuelle Wettertyp, wie ihn das Wetter-Skript meldet (`CLEAR`, `RAIN`...), oder `null`, solange keins läuft.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const raining = ["RAIN", "THUNDER"].includes(world.getWeather() ?? "");
```
</Tab>
<Tab value="Lua">
```lua
local weather = aiLib.world.getWeather()
local raining = weather == 'RAIN' or weather == 'THUNDER'
```
</Tab>
</Tabs>

### world.setWeather

Setzt das Wetter.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
world.setWeather(type: Weather): boolean
```

```lua title="Lua"
local ok = aiLib.world.setWeather(weather)
```

<TypeTable
  type={{
    type: { type: "Weather", typeDescriptionLink: "/de/docs/developers/api/types#weather", description: "Einer von `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Prüfe einen Wert von einem Client oder aus dem Panel zuerst mit `isWeather` (`@aicore-fivem/shared`).", required: true },
  }}
/>

**Rückgabewert:** `true`, wenn gesetzt, `false`, solange kein Wetter-Skript läuft oder der Wert kein String ist.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, world } from "@aicore-fivem/lib/server";
import { isWeather } from "@aicore-fivem/shared";

addCommand("weather", { restricted: true, params: [{ name: "type", type: "string" }] }, (_source, { type }) => {
  const upper = type.toUpperCase();
  if (isWeather(upper)) world.setWeather(upper);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { restricted = true, params = { { name = 'type', type = 'string' } } }, function(_, args)
    aiLib.world.setWeather(args.type:upper())
end)
```
</Tab>
</Tabs>

## buckets

Routing-Buckets (getrennte Welten: ein Wohnungsinterieur, eine Instanz) aus dem Allokator von ai-core, damit sich nie zwei Skripte einen teilen. Wähle Bucket-Nummern nie selbst (`1000 + n`). Kein Lua-Zwilling: Rufe die Exports `AcquireBucket(tag)` / `ReleaseBucket(id)` von ai-core auf.

### buckets.acquire

Nimmt einen freien Bucket für diese Ressource. Er hat keine Bevölkerung (keine Umgebungs-Peds und -Autos) und striktes Entity-Lockdown.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
buckets.acquire(tag: string): number
```

<TypeTable
  type={{
    tag: { type: "string", description: "Ein Name für Logs (`property:12`).", required: true },
  }}
/>

**Rückgabewert:** die Bucket-ID.

```ts
import { buckets } from "@aicore-fivem/lib/server";

const bucket = buckets.acquire(`property:${propertyId}`);
SetPlayerRoutingBucket(String(source), bucket);
```

### buckets.release

Gibt einen Bucket zurück, sobald seine Spieler draußen sind.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
buckets.release(id: number): boolean
```

**Rückgabewert:** `true`, wenn freigegeben. Jeder Bucket einer gestoppten Ressource geht von selbst zurück.

```ts
SetPlayerRoutingBucket(String(source), 0);
buckets.release(bucket);
```

## doors

Türschlösser über die Türschloss-Ebene von ai-core, nach der eigenen Tür-ID des Türschloss-Skripts. Kein Lua-Zwilling: Rufe die Exports `SetDoorLocked`, `IsDoorLocked` von ai-core auf.

### doors.setLocked

Schließt eine Tür ab oder auf.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
doors.setLocked(id: string, locked: boolean, by?: number): boolean
```

<TypeTable
  type={{
    id: { type: "string", description: "Die eigene Tür-ID des Türschloss-Skripts (die Tür-ID im Panel von ai-doorlock).", required: true },
    locked: { type: "boolean", description: "`true` schließt ab, `false` schließt auf.", required: true },
    by: { type: "number", description: "Server-ID des handelnden Spielers. Tür-Skripte ohne Server-API brauchen sie.", required: false },
  }}
/>

**Rückgabewert:** `true`, wenn ein Tür-Skript es übernommen hat, sonst `false`.

```ts
if (outcome === "won") doors.setLocked("bank_vault", false, source);
```

### doors.isLocked

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
doors.isLocked(id: string): boolean | null
```

**Rückgabewert:** `true` oder `false`, oder `null`, wenn unbekannt (kein Türschloss, keine solche Tür, oder das Skript kann es auf dem Server nicht sagen).

```ts
if (doors.isLocked("bank_vault") === false) return fail("ALREADY_OPEN");
```

### doors.provider

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
doors.provider(): string | null
```

**Rückgabewert:** das Türschloss-Skript, das antwortet, oder `null`, wenn keins läuft.

```ts
console.log(`doors through ${doors.provider() ?? "nothing"}`);
```

## characters

Gespeicherte Charaktere über ai-core. Geladene Charaktere laufen über `online` und die Spieler-Exports von ai-core.

### characters.setOfflinePosition

Verschiebt den Spawnpunkt eines gespeicherten (nicht geladenen) Charakters, zum Beispiel eines schlafenden Körpers, der weggetragen wurde. ai-core schreibt ihn, sobald kein Lade- oder Entlade-Speichervorgang den Charakter hält.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
characters.setOfflinePosition(charId: number, position: { x: number; y: number; z: number; heading?: number }): boolean
```

Kein Lua-Zwilling: Rufe den Export `SetOfflinePosition(charId, position)` von ai-core auf.

<TypeTable
  type={{
    charId: { type: "number", description: "Die Charakter-ID (`CharacterInfo.id`).", required: true },
    position: { type: "{ x: number; y: number; z: number; heading?: number }", description: "Der neue Spawnpunkt; Heading in Grad.", required: true },
  }}
/>

**Rückgabewert:** `true`, wenn akzeptiert. `false`, wenn der Charakter geladen ist oder die Werte falsch sind.

```ts
characters.setOfflinePosition(sleeperCharId, { x: 340.2, y: -1396.7, z: 32.5, heading: 50 });
```
