Um **jogador** é um cliente conectado com um id de servidor (`source`). Um **personagem** é a pessoa que ele interpreta; um jogador na tela de personagens não tem personagem carregado. O ai-core é dono dos jogadores e personagens; estes helpers os leem.

## online

`online` é a cópia, no seu recurso, dos jogadores carregados do ai-core: personagens, vínculos com empregos e gangues com cargos, listas de membros por emprego e gangue, e serviço. Ele lê o ai-core uma vez no primeiro uso e depois acompanha os eventos do ai-core, então uma leitura é uma consulta em memória. Use em caminhos quentes (cada mensagem de chat, cada alerta) em vez de chamar os exports do ai-core.

Em Lua, `aiLib.online` consulta os exports do ai-core a cada chamada: bom para ações, não para todo tick. Ele tem `character`, `name`, `jobs`, `gangs`, `jobGrade`, `gangGrade`, `dutyJob` e `sources`; o resto não tem equivalente em Lua.

### online.sources

Os ids de servidor de todos os jogadores com um personagem carregado.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
online.sources(): IterableIterator<number>
```

```lua title="Lua"
local list = aiLib.online.sources() -- integer[]
```

#### Retorno

`IterableIterator<number>` (Lua: um array). Jogadores na tela de personagens não estão nele.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>

### online.charId

O id do personagem carregado do jogador (o id no banco de dados, estável entre reconexões).

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
online.charId(source: number): number | undefined
```

Sem equivalente em Lua: `(aiLib.online.character(source) or {}).id`.

**Retorno** o id do personagem, ou `undefined` quando nenhum está carregado. Indexe por este id, não por `source`, os dados que precisam sobreviver a uma reconexão (cooldowns, posse).

```ts
const charId = online.charId(source);
if (charId === undefined) return fail("NO_CHARACTER");
```

### online.allows

Se o jogador pode usar um lugar travado por uma regra de acesso (empregos, gangues, cargos mínimos, em serviço). O `allows` do cliente usa a mesma regra, então o que um jogador vê é o que o servidor o deixa usar.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
online.allows(source: number, rule: AccessRule): boolean
```

Sem equivalente em Lua.

<TypeTable
  type={{
    source: { type: "number", description: "Id de servidor do jogador.", required: true },
    rule: { type: "AccessRule", typeDescriptionLink: "/pt/docs/developers/api/types#accessrule", description: "`{ jobs, gangs, grades, onDuty }`, lido de um registro do painel com `readAccess(record)`. As duas listas vazias: todos.", required: true },
  }}
/>

**Retorno** `true` quando as listas estão vazias, o jogador está em uma das `gangs` no cargo mínimo dela, ou em um dos `jobs` no cargo mínimo dele (e em serviço nele quando `onDuty` está definido).

```ts
import { online } from "@aifivem/lib/server";
import { readAccess, fail } from "@aifivem/lib/shared";

const rule = readAccess(stashRecord); // { jobs: ["police"], gangs: [], grades: { police: 2 }, onDuty: true }
if (!online.allows(source, rule)) return fail("NO_ACCESS");
```

## Ciclo de vida do personagem

### onCharacter

Roda o seu código quando um personagem entra no mundo e quando sai. Também repete os personagens que já estão no mundo quando o seu recurso (re)inicia, e cobre as saídas, então você não precisa de um handler de `playerDropped` ao lado dele.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
onCharacter(handlers: CharacterHandlers): void
```

```lua title="Lua"
aiLib.onCharacter({ loaded = function(source, character) end, unloaded = function(source, charId, reason) end })
```

#### CharacterHandlers

<TypeTable
  type={{
    loaded: { type: "(source: number, character: CharacterInfo) => void | Promise<void>", typeDescriptionLink: "/pt/docs/developers/api/types#characterinfo", description: "Um personagem entrou no mundo. Também roda uma vez, no tick seguinte à chamada de `onCharacter`, para cada personagem carregado antes de o seu recurso iniciar. Um erro lançado ou uma rejeição é registrado em log.", required: false },
    unloaded: { type: '(source: number, charId: number, reason: "dropped" | "switch") => void', description: "O personagem saiu: `switch` para logout ou troca de personagem, `dropped` quando o jogador desconectou. Todo `loaded` recebe exatamente um `unloaded`.", required: false },
  }}
/>

#### Retorno

`void`.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onCharacter, PlayerMap } from "@aifivem/lib/server";

const playtime = new PlayerMap<{ charId: number; since: number }>();

onCharacter({
  loaded(source, character) {
    playtime.set(source, { charId: character.id, since: Date.now() });
  },
  unloaded(source, charId, reason) {
    const entry = playtime.get(source);
    if (entry) console.log(`character ${charId} played ${Date.now() - entry.since} ms (${reason})`);
    playtime.delete(source);
  },
});
```
</Tab>
<Tab value="Lua">
```lua
local since = {}

aiLib.onCharacter({
    loaded = function(source, character)
        since[source] = os.time()
    end,
    unloaded = function(source, charId, reason)
        print(('character %d played %ds (%s)'):format(charId, os.time() - (since[source] or os.time()), reason))
        since[source] = nil
    end,
})
```
</Tab>
</Tabs>

<Callout type="info">
Chame uma vez no nível superior de um arquivo de servidor. O PlayerMap acima é esvaziado sozinho na saída; o handler de `unloaded` ainda roda primeiro em uma saída, então você pode salvar dados ali.
</Callout>

### isOnline

Se um jogador ainda está conectado. Verifique depois de um `await` longo antes de dar qualquer coisa.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
isOnline(source: number): boolean
```

Sem equivalente em Lua: `GetPlayerName(source) ~= nil`.

**Retorno** `true` enquanto o jogador está conectado.

```ts
await new Promise((resolve) => setTimeout(resolve, 60_000));
if (!isOnline(source)) return;
```

## Jogadores próximos

Estes perguntam ao ai-core quais jogadores estão no escopo OneSync uns dos outros (cerca de 424 metros) e medem só esses poucos, em vez de percorrer todos os jogadores do servidor. Um raio maior que cerca de 424 m não encontra ninguém mais longe.

### playersNear

Os jogadores a até `radius` metros de um jogador.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
playersNear(source: number, radius: number): number[]
```

```lua title="Lua"
local list = aiLib.playersNear(source, radius) -- integer[]
```

<TypeTable
  type={{

**Retorno** um array de ids de servidor. O TypeScript inclui o próprio `source`; **o Lua o deixa de fora**.

## Stores por jogador

Nenhum destes tem equivalente em Lua: use uma tabela Lua e limpe-a em `playerDropped`. Crie cada store uma vez no nível do módulo, nunca dentro de um handler.

### PlayerMap

Um `Map` indexado pelo id de servidor do jogador que se esvazia sozinho quando o jogador sai. Use para tudo o que você guarda por jogador (uma tela aberta, um item selecionado).

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
new PlayerMap<V>(options?: { onDrop?: (source: number, value: V) => void })
```

<TypeTable
  type={{
    "options.onDrop": { type: "(source: number, value: V) => void", description: "Roda depois que a entrada de um jogador que saiu foi removida, com o último valor dela (terminar uma ação, salvar algo).", required: false },
  }}
/>

Ele tem todos os métodos de um `Map` do JavaScript (`get`, `set`, `has`, `delete`, `size`, iteração).

```ts
import { PlayerMap } from "@aifivem/lib/server";

const carrying = new PlayerMap<string>({
  onDrop: (source, item) => console.log(`${source} left while carrying ${item}`),
});
carrying.set(source, "box");
```

### Cooldowns

Cooldowns por jogador no relógio do jogo, liberados quando o jogador sai.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
new Cooldowns()
ready(source: number): boolean
start(source: number, ms: number): void
take(source: number, ms: number): boolean
left(source: number): number
clear(source: number): void
```

| Método | O que faz | Retorno |
| --- | --- | --- |
| `ready(source)` | Nenhum cooldown está rodando para o jogador. | `boolean` |
| `start(source, ms)` | Inicia (ou reinicia) o cooldown do jogador por `ms` milissegundos. | `void` |
| `take(source, ms)` | Inicia o cooldown quando ele está pronto. | `true` quando iniciado, `false` enquanto um ainda roda |
| `left(source)` | Milissegundos restantes. | `number`, `0` quando pronto |
| `clear(source)` | Encerra o cooldown do jogador. | `void` |

```ts
import { onClientCallback, Cooldowns } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const searchCooldown = new Cooldowns();

onClientCallback("my-bins:search", (source) => {
  if (!searchCooldown.take(source, 30_000)) return fail("WAIT");
  return { ok: true };
});
```

<Callout type="warn">
Um jogador pode reconectar para zerar uma entrada de `Cooldowns`. Um cooldown que precisa sobreviver a uma reconexão usa `KeyedCooldowns` indexado por `online.charId(source)`.
</Callout>

### KeyedCooldowns

Cooldowns por qualquer chave que dura mais que uma conexão: um id de personagem, uma entidade, um id de porta. Entradas expiradas são limpas conforme o mapa cresce.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
new KeyedCooldowns<K = number>()
ready(key: K): boolean
start(key: K, ms: number): void
take(key: K, ms: number): boolean
left(key: K): number
clear(key: K): void
```

Os mesmos métodos de `Cooldowns`, por `key`. `start` com `ms` de 0 ou menos encerra o cooldown.

```ts
import { KeyedCooldowns, online } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const robbed = new KeyedCooldowns<string>(); // por id de loja
const perCharacter = new KeyedCooldowns(); // por id de personagem

function canRob(source: number, store: string) {
  const charId = online.charId(source);
  if (charId === undefined) return fail("NO_CHARACTER");
  if (!robbed.ready(store)) return fail("STORE_EMPTY");
  if (!perCharacter.take(charId, 15 * 60_000)) return fail("WAIT");
  robbed.start(store, 30 * 60_000);
  return { ok: true };
}
```

### SourceLock

Uma ação em andamento por jogador entre vários callbacks. O próprio `lock: true` de um callback cobre só aquele callback; duas ações que precisam se excluir (listar e vender o mesmo veículo) compartilham um `SourceLock`.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
new SourceLock()
run<T, B>(source: number, busy: B, task: () => Promise<T>): Promise<T | B>
release(source: number): void
```

<TypeTable
  type={{
    source: { type: "number", description: "Id de servidor do jogador.", required: true },
    busy: { type: "B", description: "O que `run` retorna quando o jogador já tem uma tarefa rodando (`fail(\"BUSY\")`).", required: true },
    task: { type: "() => Promise<T>", description: "A ação. O lock é liberado quando ela termina, mesmo quando lança um erro.", required: true },
  }}
/>

**Retorno** (`run`) o resultado da tarefa, ou `busy`. `release(source)` libera o jogador; chame a partir de `playerDropped` (uma tarefa ainda rodando mantém a própria entrada até terminar).

```ts
import { onClientCallback, SourceLock } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const dealer = new SourceLock();
on("playerDropped", () => dealer.release(Number(globalThis.source)));

onClientCallback("my-dealer:list", (source) => dealer.run(source, fail("BUSY"), async () => ({ ok: true })));
onClientCallback("my-dealer:sell", (source) => dealer.run(source, fail("BUSY"), async () => ({ ok: true })));
```

### RateLimit

Um limite de rajada por jogador: no máximo `count` ações dentro de qualquer `windowMs`. O portão já limita a taxa de toda entrada; use isto para um limite extra, mais lento, em uma ação.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
new RateLimit(count: number, windowMs: number)
take(source: number): boolean
release(source: number): void
```

```lua title="Lua"
local limit = aiLib.RateLimit.new(count, windowMs)
local allowed = limit:take(source)
limit:release(source)
```

<TypeTable
  type={{
    count: { type: "number", description: "Ações permitidas por janela.", required: true },
    windowMs: { type: "number", description: "Duração da janela em milissegundos (uma janela deslizante).", required: true },
  }}
/>

**Retorno** (`take`) `true` e conta uma ação, ou `false` quando o jogador passou do limite (não contada). `release(source)` esquece o jogador; chame a partir de `playerDropped`.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, RateLimit } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const reports = new RateLimit(3, 60_000);
on("playerDropped", () => reports.release(Number(globalThis.source)));

onClientCallback("my-report:send", (source) => {
  if (!reports.take(source)) return fail("TOO_MANY_REPORTS");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local reports = aiLib.RateLimit.new(3, 60000)
AddEventHandler('playerDropped', function() reports:release(source) end)

aiLib.onClientCallback('my-report:send', function(source)
    if not reports:take(source) then return aiLib.fail('TOO_MANY_REPORTS') end
    return { ok = true }
end)
```
</Tab>
</Tabs>

### KeyWatchers

Os jogadores que recebem as mudanças ao vivo de uma chave (os carros de um estacionamento, uma ficha de personagem aberta). Uma chave por jogador: observar uma nova chave para a antiga. Liberado na saída; toda operação é de tempo constante.

**Lado:** Servidor · **Espera:** não

```ts title="Signature"
new KeyWatchers<K>()
watch(source: number, key: K): void
stop(source: number): void
of(key: K): ReadonlySet<number> | undefined
keyOf(source: number): K | undefined
```

| Método | O que faz | Retorno |
| --- | --- | --- |
| `watch(source, key)` | O jogador observa `key` e para de observar a anterior. | `void` |
| `stop(source)` | O jogador para de observar. | `void` |
| `of(key)` | Os jogadores que observam `key`. | um set, ou `undefined` quando ninguém observa |
| `keyOf(source)` | A chave que o jogador observa. | a chave, ou `undefined` |

```ts
import { onClientCallback, onClientEvent, KeyWatchers } from "@aifivem/lib/server";
import { oneArg, readText } from "@aifivem/lib/shared";

const lots = new KeyWatchers<string>();

onClientCallback("my-lot:open", { args: oneArg((v) => readText(v, 32)) }, (source, lot) => {
  lots.watch(source, lot);
  return { ok: true, cars: [] }; // o snapshot
});
onClientEvent("my-lot:close", (source) => lots.stop(source));

function carChanged(lot: string, car: unknown) {
  for (const source of lots.of(lot) ?? []) emitNet("my-lot:car", source, car); // o delta
}
```
