```ts title="TypeScript"
import { money, banking, billing } from "@aifivem/lib/server";
```

`money` to każdy stan konta na serwerze: konta wczytanego gracza, wspólne konto pracy albo gangu, przelew, który przenosi pieniądze w jednej transakcji, i księga. Postać, która **nie** jest połączona, idzie przez [`characters`](/pl/docs/developers/api/lib-server/characters#charactersaddmoney-charactersremovemoney-and-characterssetmoney). `banking` i `billing` to warstwy dla bankowego i rachunkowego skryptu serwera.

## money

### money.get

Stan konta wczytanego gracza na jednym koncie.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
money.get(source: number, account: string): number | null
```

```lua title="Lua"
local balance = aiLib.money.get(source, account)
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },
    account: { type: 'string', description: 'Nazwa konta z panelu (`cash`, `bank`...). Zobacz [Nazwy kont](/pl/docs/developers/api/types#nazwy-kont).', required: true },
  }}
/>

#### Zwraca

`number | null`: stan konta albo `null`, gdy gracz nie ma wczytanej postaci lub typ konta nie istnieje. Stany kont zapisanej postaci bierze się z [`characters.get`](/pl/docs/developers/api/lib-server/characters#charactersget).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money, notify } from "@aifivem/lib/server";

export function tellBalance(source: number): void {
  const bank = money.get(source, "bank");
  notify(source, bank === null ? "Brak postaci" : `Bank: $${bank}`, bank === null ? "error" : "inform");
}
```
</Tab>
<Tab value="Lua">
```lua
local bank = aiLib.money.get(source, 'bank')
aiLib.notify(source, bank and ('Bank: $%d'):format(bank) or 'Brak postaci', bank and 'inform' or 'error')
```
</Tab>
</Tabs>

### money.add, money.remove and money.set

Zmienia jedno konto wczytanego gracza, z wierszem księgi. To wywołania na nagrodę, cenę, pensję, którą płaci Twój skrypt.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
money.add(source: number, account: string, amount: number, reason?: string): boolean
money.remove(source: number, account: string, amount: number, reason?: string): boolean
money.set(source: number, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = aiLib.money.add(source, account, amount, reason)
local ok = aiLib.money.remove(source, account, amount, reason)
local ok = aiLib.money.set(source, account, amount, reason)
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },
    account: { type: 'string', description: 'Nazwa konta z panelu.', required: true },
    amount: { type: 'number', description: 'Całe dolary, powyżej 0 dla `add` i `remove`. `set` bierze nowy stan konta (0 dozwolone).', required: true },
    reason: { type: 'string', description: 'Co mówi wiersz księgi (`"shop:tools"`).', default: 'nazwa wołającego resource' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy zmiana się udała. `false`, gdy gracz nie ma wczytanej postaci, konto nie istnieje, kwota nie jest liczbą całkowitą powyżej 0, albo - przy `remove` - stan konta nie może zapłacić (chyba że typ konta może zejść poniżej zera).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money, onClientCallback } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

onClientCallback("myshop:buyTools", { lock: true }, (source) => {
  if (!money.remove(source, "cash", 150, "shop:tools")) return fail("NOT_ENOUGH_CASH");
  // tutaj wydaj przedmiot
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myshop:buyTools', function(source)
    if not aiLib.money.remove(source, 'cash', 150, 'shop:tools') then return aiLib.fail('NOT_ENOUGH_CASH') end
    return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="warn">
Zapłata jednego gracza drugiemu **nie** jest `remove` plus `add`: błąd w połowie stworzyłby albo zniszczył pieniądze. Użyj [`money.transfer`](#moneytransfer), to jedna transakcja bazy.
</Callout>

### money.sharedAdd and money.sharedRemove

Zmienia konto pracy albo gangu, z wierszem księgi - przychody i koszty firmy.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
money.sharedAdd(type: "job" | "gang", id: string, account: string, amount: number, reason?: string): boolean
money.sharedRemove(type: "job" | "gang", id: string, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = aiLib.money.sharedAdd(type, id, account, amount, reason)
local ok = aiLib.money.sharedRemove(type, id, account, amount, reason)
```

#### Zwraca

`boolean`: `true`, gdy zmiana się udała, `false` przy nieznanej pracy albo gangu, braku konta, błędnej kwocie albo koncie, które nie może zapłacić.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money } from "@aifivem/lib/server";

/** Kontrakt miasta, który zarabia warsztat, i opłata, którą płaci za części. */
export function contractDone(job: string, pay: number, parts: number): boolean {
  if (!money.sharedAdd("job", job, "bank", pay, "city contract")) return false;
  return money.sharedRemove("job", job, "bank", parts, "parts");
}
```
</Tab>
<Tab value="Lua">
```lua
local ok = aiLib.money.sharedAdd('job', 'mechanic', 'bank', 500, 'repair')
```
</Tab>
</Tabs>

### money.transfer

Przenosi pieniądze z jednego konta na drugie w jednej transakcji bazy danych, z wierszem w księdze po obu stronach. Używaj go dla wszystkiego, gdzie pieniądze nie mogą pojawić się ani zniknąć w połowie: płatność innemu graczowi, premia wypłacana przez pracę, opłata.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
money.transfer(from: MoneyRef, to: MoneyRef, amount: number, reason?: string, fee?: number): boolean
```

```lua title="Lua"
local ok = aiLib.money.transfer(from, to, amount, reason, fee)
```

#### Parametry

<TypeTable
  type={{
    from: { type: "MoneyRef", typeDescriptionLink: "/pl/docs/developers/api/types#moneyref", description: "Konto płacące: `{ source, account }` gracza (`account`: `cash`, `bank`...) albo `{ owner: \"job\" | \"gang\", id, account }` pracy lub gangu.", required: true },
    to: { type: "MoneyRef", typeDescriptionLink: "/pl/docs/developers/api/types#moneyref", description: "Konto odbierające, ten sam kształt.", required: true },
    amount: { type: "number", description: "Ile dostaje `to`: liczba całkowita, 1 lub więcej.", required: true },
    reason: { type: "string", description: "Zapisywane w obu wierszach księgi (`rent:apartment_3`).", required: false },
    fee: { type: "number", description: "Dodatkowa całkowita kwota, którą też płaci `from`. Opuszcza ekonomię (nikt jej nie dostaje).", default: "0" },
  }}
/>

#### Zwracana wartość

`boolean`: `true`, gdy oba wiersze zostały zapisane. `false`, gdy kwota nie jest liczbą całkowitą, brakuje konta, oba są tym samym kontem albo `from` nie może zapłacić `amount` plus `fee`.

#### Przykład

```ts
import { onClientCallback, money, nearestPlayerTo, notify } from "@aifivem/lib/server";
import { fail, oneArg, readInt } from "@aifivem/lib/shared";

onClientCallback("my-cash:give", { args: oneArg((v) => readInt(v, 1, 100_000)), lock: true }, (source, amount) => {
  const target = nearestPlayerTo(source, 2);
  if (target === null) return fail("NOBODY_NEAR");
  if (!money.transfer({ source, account: "cash" }, { source: target, account: "cash" }, amount, "give:cash"))
    return fail("NOT_ENOUGH_CASH");
  notify(target, `You received $${amount}`, "success");
  return { ok: true };
});
```

### money.history

Wiersze księgi konta, najnowsze pierwsze: co się ruszyło, stan konta po tym, powód, kto to zrobił i kiedy. Działa dla konta gracza, konta pracy albo gangu i konta zapisanej postaci.

**Strona:** Serwer · **Czeka:** tak

```ts title="Sygnatura"
money.history(account: LedgerRef, query?: LedgerQuery): Promise<LedgerPage>
```

```lua title="Lua"
local page = aiLib.money.history(account, query)
```

#### Parametry

<TypeTable
  type={{
    account: { type: 'LedgerRef', typeDescriptionLink: '/pl/docs/developers/api/types#ledgerref', description: 'Czyja księga: `{ source, account }`, `{ owner: "job" | "gang", id, account }` albo zapisana postać przez `{ owner: "character", id, account }` (`id` to id postaci jako tekst).', required: true },
    query: { type: 'LedgerQuery', typeDescriptionLink: '/pl/docs/developers/api/types#ledgerquery', description: 'Które wiersze: `before` (`next` strony, którą właśnie przeczytałeś), `since` (sekundy unix), `limit` (1-200, domyślnie 50).' },
  }}
/>

#### Zwraca

[LedgerPage](/pl/docs/developers/api/types#ledgerpage): `rows` i `next`, które podajesz jako `before` (`null` na ostatniej stronie). ai-core zapisuje wiersz chwilę po zmianie, więc najnowszy może być kilka milisekund za stanem konta.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { money } from "@aifivem/lib/server";

/** Ostatnie 20 wierszy bankowych zapisanej postaci. */
export async function statement(charId: number) {
  const page = await money.history({ owner: "character", id: String(charId), account: "bank" }, { limit: 20 });
  return page.rows.map((r) => `${r.at}: ${r.amount} (${r.reason})`);
}
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local page = aiLib.money.history({ source = source, account = 'bank' }, { limit = 20 })
    for _, row in ipairs(page.rows) do
        print(('%d: %d (%s)'):format(row.at, row.amount, row.reason))
    end
end)
```
</Tab>
</Tabs>

## banking

`banking` rozmawia ze skryptem bankowym przez warstwę bankowości ai-core. Same pieniądze pracy zawsze przechodzą przez `money` albo eksporty ai-core.

### banking.open

Otwiera ekran skryptu bankowego dla gracza.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
banking.open(source: number): boolean
```

```lua title="Lua"
local ok = aiLib.banking.open(source)
```

**Zwraca** `true`, gdy otwarto. `false`, gdy skryptu nie da się otworzyć z zewnątrz albo żaden nie działa.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

```lua
aiLib.onClientCallback('my-atm:open', function(source)

```
</Tab>
</Tabs>

## billing

`billing` wysyła rachunki przez dowolny skrypt rachunków, który działa; bez niego przez własne rachunki ai-core (gracz płaci z listy na ekranie, pieniądze przechodzą, gdy zapłaci). Teksty są już przetłumaczone.

### billing.send

Wysyła rachunek od pracy (mandaty, opłaty za usługi) albo od gracza.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
billing.send(bill: BillRequest): boolean
```

```lua title="Lua"
local ok = aiLib.billing.send(bill)
```

#### BillRequest

<TypeTable
  type={{
    to: { type: "number", description: "Id serwerowe gracza, który go dostaje. Podaj `to` albo `toCitizenid`.", required: false },
    toCitizenid: { type: "string", description: "Postać, która go dostaje, według citizen id, online albo offline. Postać offline dostaje go tylko z własnych rachunków ai-core; skrypt rachunków wymaga gracza online.", required: false },
    amount: { type: "number", description: "Całe dolary.", required: true },
    label: { type: "string", description: "Za co jest (`Speeding`).", required: true },
    from: { type: "number", description: "Id serwerowe gracza wystawiającego (policjant, mechanik). Rachunek bez `job` płaci temu graczowi.", required: false },
    job: { type: "string", description: "Praca, której konto dostaje płatność. Bez niej rachunek jest osobisty i `from` jest wymagane.", required: false },
  }}
/>

#### Zwracana wartość

`boolean`: `true`, gdy wysłano, `false`, gdy nieprawidłowy albo odrzucony.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { billing, nearestPlayerTo, online } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

function fine(officer: number, amount: number) {
  if (!online.onDutyIn(officer, ["police"])) return fail("NOT_ON_DUTY");
  const target = nearestPlayerTo(officer, 3);
  if (target === null) return fail("NOBODY_NEAR");
  return billing.send({ to: target, amount, label: "Speeding", from: officer, job: "police" })
    ? { ok: true }
    : fail("BILL_FAILED");
}
```
</Tab>
<Tab value="Lua">
```lua
local function fine(officer, amount)
    if aiLib.online.dutyJob(officer) ~= 'police' then return aiLib.fail('NOT_ON_DUTY') end
    local target = aiLib.nearestPlayerTo(officer, 3.0)
    if not target then return aiLib.fail('NOBODY_NEAR') end
    if not aiLib.billing.send({ to = target, amount = amount, label = 'Speeding', from = officer, job = 'police' }) then
        return aiLib.fail('BILL_FAILED')
    end
    return { ok = true }
end
```
</Tab>
</Tabs>

### billing.unpaid

Otwarte rachunki gracza.

**Strona:** Serwer · **Czeka:** tak (Promise w TypeScript, w Lua wstrzymuje wątek)

```ts title="Sygnatura"
billing.unpaid(source: number): Promise<UnpaidBill[] | null>
```

```lua title="Lua"
local bills = aiLib.billing.unpaid(source) -- table[] albo nil, wywołuj wewnątrz wątku
```

**Zwraca** [`UnpaidBill[]`](/pl/docs/developers/api/types#unpaidbill) (`id`, `label`, `amount` nadal do zapłaty, `sender`) albo `null`, gdy skrypt rachunków nie potrafi ich wymienić.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const bills = await billing.unpaid(source);
const owed = bills?.reduce((sum, bill) => sum + bill.amount, 0) ?? 0;
```
</Tab>
<Tab value="Lua">
```lua
CreateThread(function()
    local bills = aiLib.billing.unpaid(source) or {}
    local owed = 0
    for _, bill in ipairs(bills) do owed = owed + bill.amount end
    print(owed)
end)
```
</Tab>
</Tabs>
