import { dispatch, prison, mdt, ems, medical, stress, needs, definitions, isPrimeTime } from "@aifivem/lib/server";

Każdy obiekt tutaj przechodzi przez jedną z warstw ai-core: odpowiada skrypt, którego serwer używa do tego zadania (system alertów, więzienie, MDT, skrypt śmierci, HUD). Twój skrypt działa dalej, gdy właściciel go wymieni. Dopóki taki skrypt nie działa, wywołania po cichu się nie udają (`false`, `0`, `null`).

## dispatch

### dispatch.alert

Wysyła alert policyjny (albo innej pracy). System alertów pokazuje go członkom `jobs` na służbie, domyślnie pracom policyjnym.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

<TypeTable
  type={{
    title: { type: "string", description: "Nagłówek, przetłumaczony (`Shots fired`).", required: true },
    code: { type: "string", description: "Kod radiowy pokazywany przed tytułem (`10-71`).", required: false },
    message: { type: "string", description: "Jeszcze jedna linia (nazwa sklepu).", required: false },
    coords: { type: "{ x: number; y: number; z: number }", description: "Gdzie to się stało. Bez tego pozycja gracza `source`; bez obu brak punktu na mapie.", required: false },
    jobs: { type: "string[]", description: "Prace, których członkowie na służbie go dostają.", default: "prace policyjne systemu alertów" },
    source: { type: "number", description: "Gracz, którego dotyczy alert (strzelec, rabuś). Systemy, które opisują podejrzanego (pojazd, płeć), czytają tego gracza.", required: false },
    blip: { type: "{ sprite: number; color?: number; scale?: number }", description: "Blip na mapie: sprite i kolor blipa GTA.", default: "z systemu alertów" },
    duration: { type: "number", description: "Ile sekund alert zostaje (karta, blip, klawisz punktu nawigacji).", default: "z systemu alertów" },
    icon: { type: "string", description: "Nazwa ikony solid z Font Awesome bez `fa-` (`gun`).", required: false },
    priority: { type: '"normal" | "high"', description: "`high` wyróżnia kartę (napad z bronią, ranny policjant).", default: '"normal"' },
  }}
/>

Typ to [`DispatchAlert`](/pl/docs/developers/api/types#dispatchalert).

#### Zwracana wartość

`boolean`: `true`, gdy wysłano. `false`, gdy nie działa żaden system alertów albo alert jest nieprawidłowy.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, coordsOf, createLocale } from "@aifivem/lib/server";

const Locale = createLocale();

function storeRobbed(source: number, store: string) {
  dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

local function storeRobbed(source, store)
    local c = GetEntityCoords(GetPlayerPed(source))
    aiLib.dispatch.alert({
        code = '10-90',
        title = Locale('ALERT_STORE_ROBBERY'),
        message = store,
        coords = { x = c.x, y = c.y, z = c.z },
        source = source,
        icon = 'store',
        priority = 'high',
    })
end
```
</Tab>
</Tabs>

## medical

Wskrzeszanie, leczenie i stan powalenia przez warstwę medyczną ai-core, niezależnie od tego, jaki skrypt śmierci albo karetki działa. Brak odpowiednika w Lua: wywołaj eksporty ai-core `RevivePlayer`, `HealPlayer`, `IsPlayerDead`.

### medical.revive

Stawia powalonego gracza na nogi tam, gdzie leży.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
medical.revive(source: number): boolean
```

**Zwraca** `true`, gdy wskrzeszono, `false`, gdy nie jest powalony albo nie działa żaden skrypt śmierci.

```ts
if (!medical.revive(target)) return fail("NOT_DOWN");
```

### medical.heal

Daje pełne zdrowie graczowi, który nie jest powalony.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
medical.heal(source: number): boolean
```

**Zwraca** `true`, gdy wyleczono, `false`, gdy nie działa żaden skrypt śmierci.

```ts
medical.heal(source);
```

### medical.isDead

Czy gracz jest powalony.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
medical.isDead(source: number): boolean
```

**Zwraca** `true`, gdy jest powalony; `false` bez skryptu śmierci. Używaj go zamiast czytać zdrowie peda.

```ts
if (medical.isDead(source)) return fail("YOU_ARE_DOWN");
```

### medical.provider

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
medical.provider(): string | null
```

**Zwraca** skrypt śmierci, który odpowiada (`ai-death`...), albo `null`, gdy żaden nie działa.

```ts
console.log(`deaths through ${medical.provider() ?? "nothing"}`);
```

## needs

### needs.refill

Wypełnia głód i pragnienie do pełna (wskrzeszenie przez administratora, szpital) przez HUD, który je prowadzi, a bez niego przez metadane postaci w ai-core.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
needs.refill(source: number): boolean
```

Brak odpowiednika w Lua: wywołaj eksport ai-core `RefillNeeds(source)`.

**Zwraca** `true`, gdy wypełniono, `false`, gdy gracz nie ma postaci.

```ts
if (medical.revive(target)) needs.refill(target);
```

## Definicje prac i gangów

### definitions.job

Definicja pracy ustawiona w panelu ai-core. Każda jest czytana raz z ai-core i trzymana, dopóki panel jej nie zmieni, więc odczyt to wyszukanie w pamięci.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
definitions.job(name: string): JobDefinition | null
```

Brak odpowiednika w Lua: wywołaj eksport ai-core `GetJobDefinition(name)`.

**Zwraca** [`JobDefinition`](/pl/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`) albo `null`, gdy taka praca nie istnieje.

```ts
const label = definitions.job("police")?.label ?? "police";
```

### definitions.gang

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
definitions.gang(name: string): GangDefinition | null
```

Brak odpowiednika w Lua: wywołaj eksport ai-core `GetGangDefinition(name)`.

**Zwraca** [`GangDefinition`](/pl/docs/developers/api/types#gangdefinition) (`label`, `grades`) albo `null`.

```ts
const gang = definitions.gang("ballas");
if (!gang) return fail("UNKNOWN_GANG");
```

## Prime time

### isPrimeTime

Czy dla pracy trwa prime time, według ustawienia prime time w ai-core. Godziny pochodzą z tgiann-policealert, gdy działa, a w przeciwnym razie z godzin ustawionych w panelu ai-core.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
isPrimeTime(job?: string): boolean
```

Brak odpowiednika w Lua: wywołaj eksport ai-core `IsPrimeTime(job)`.

<TypeTable
  type={{
    job: { type: "string", description: "Praca, dla której sprawdzić prime time. Bez niej domyślne godziny.", required: false },
  }}
/>

**Zwraca** `true` w czasie prime time.

```ts
if (!isPrimeTime("police")) return fail("BANK_CLOSED_FOR_HEISTS");
```
