`jobs` i `definitions` to samo ai-core: prace i gangi postaci oraz definicje prac serwera. Wszystko inne tutaj idzie przez jedną z warstw ai-core, gdzie odpowiada skrypt, który serwer ma do tego zadania (system zgłoszeń, więzienie, MDT, skrypt śmierci, HUD). Twój skrypt działa dalej, gdy właściciel go wymieni. Dopóki żaden taki skrypt nie działa, te wywołania cicho zawodzą (`false`, `0`, `null`).

## jobs

`jobs` to własne prace i gangi wczytanego gracza przez ai-core: postać może mieć kilka prac, jest na służbie w co najwyżej jednej i działa dla jednego gangu naraz. Czytanie **wielu** graczy naraz to lustro liba ([`online`](/pl/docs/developers/api/lib-server/players#onlinejobs)); zmiana postaci, która **nie** jest połączona, to [`characters`](/pl/docs/developers/api/lib-server/characters#characterssetjob-and-charactersremovejob).

### jobs.current

Praca, którą inne skrypty widzą jako "tę" pracę gracza: ta, w której jest na służbie, inaczej ostatnia, w której był, inaczej pierwsza, którą ma, inaczej praca bezrobotnego.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
jobs.current(source: number): JobMembership | null
```

```lua title="Lua"
local current = aiLib.jobs.current(source)
```

#### Zwraca

[JobMembership](/pl/docs/developers/api/types#jobmembership) (`{ job, grade }`) albo `null`, gdy gracz nie ma wczytanej postaci.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs } from "@aifivem/lib/server";

export function isOfficer(source: number): boolean {
  return jobs.current(source)?.job === "police";
}
```
</Tab>
<Tab value="Lua">
```lua
local current = aiLib.jobs.current(source)
local officer = current and current.job == 'police'
```
</Tab>
</Tabs>

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"

jobs.setDuty(source: number, job: string | null): boolean
```

```lua title="Lua"

```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },

#### Zwraca

`jobs.duty`: nazwa pracy albo `null` po służbie (lub bez postaci). `jobs.setDuty`: `true`, gdy zmiana się udała, `false` przy pracy, której gracz nie ma.

### jobs.set

Dodaje graczowi pracę albo zmienia stopień pracy, którą już ma. Obowiązują reguły panelu: ile prac może mieć postać i czy druga jest w ogóle dozwolona.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
jobs.set(source: number, job: string, grade: number): boolean
```

```lua title="Lua"
local ok = aiLib.jobs.set(source, job, grade)
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },
    job: { type: 'string', description: 'Nazwa pracy jak w panelu (albo w definicji ze skryptu).', required: true },
    grade: { type: 'number', description: 'Stopień w tej pracy, od 0. Stopień, którego praca nie ma, jest odrzucany.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy gracz ma potem tę pracę w tym stopniu. `false` bez wczytanej postaci, przy nieznanej pracy, nieznanym stopniu albo limicie prac z panelu.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs, notify } from "@aifivem/lib/server";

export function hire(source: number, job: string): void {
  if (!jobs.set(source, job, 0)) return notify(source, "Nie udało się zatrudnić", "error");
  notify(source, `Witaj w ${job}`, "success");
}
```
</Tab>
<Tab value="Lua">
```lua
if aiLib.jobs.set(source, 'mechanic', 0) then
    aiLib.notify(source, 'Witaj w mechanic', 'success')
end
```
</Tab>
</Tabs>

**Strona:** Serwer · **Czeka:** nie


```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

    code: { type: "string", description: "Kod radiowy pokazywany przed tytułem (`10-71`).", required: false },
    message: { type: "string", description: "Jeszcze jedna linia (nazwa sklepu).", required: false },
    coords: { type: "{ x: number; y: number; z: number }", description: "Gdzie to się stało. Bez tego pozycja gracza `source`; bez obu brak punktu na mapie.", required: false },

    blip: { type: "{ sprite: number; color?: number; scale?: number }", description: "Blip na mapie: sprite i kolor blipa GTA.", default: "z systemu alertów" },

  }}

#### Zwracana wartość

`boolean`: `true`, gdy wysłano. `false`, gdy nie działa żaden system alertów albo alert jest nieprawidłowy.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

```ts
import { dispatch, coordsOf, createLocale } from "@aifivem/lib/server";

function storeRobbed(source: number, store: string) {
  dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

local function storeRobbed(source, store)
    local c = GetEntityCoords(GetPlayerPed(source))
    aiLib.dispatch.alert({
        code = '10-90',
        title = Locale('ALERT_STORE_ROBBERY'),
        message = store,
        coords = { x = c.x, y = c.y, z = c.z },
        source = source,
        icon = 'store',
        priority = 'high',
    })
end
```
</Tab>
</Tabs>

## Definicje prac i gangów

### definitions.job

Definicja pracy ustawiona w panelu ai-core. Każda jest czytana raz z ai-core i trzymana, dopóki panel jej nie zmieni, więc odczyt to wyszukanie w pamięci.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
definitions.job(name: string): JobDefinition | null
```

```lua title="Lua"
local definition = aiLib.definitions.job(name)
```

**Zwraca** [`JobDefinition`](/pl/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`) albo `null`, gdy taka praca nie istnieje.

```ts
const label = definitions.job("police")?.label ?? "police";
```

```ts title="Sygnatura"
definitions.gang(name: string): GangDefinition | null
```

### definitions.registerJob and definitions.removeJob

Praca, którą przynosi Twój skrypt, bez dodawania jej przez właściciela w panelu: praca wołającego resource, znika gdy resource się zatrzyma i nigdy nie jest zapisywana do pliku panelu.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
definitions.registerJob(name: string, definition: JobDefinition): CharacterResult
definitions.removeJob(name: string): boolean
```

```lua title="Lua"
local result = aiLib.definitions.registerJob(name, definition)
local ok = aiLib.definitions.removeJob(name)
```

#### Parametry

<TypeTable
  type={{
    name: { type: 'string', description: 'Nazwa pracy, której używa Twój skrypt (`"my-garbagejob"`).', required: true },
    definition: { type: 'JobDefinition', typeDescriptionLink: '/pl/docs/developers/api/types#jobdefinition', description: 'Sama praca: `label`, `type`, `defaultDuty`, `listed` i jej `grades` (każdy z `label`, `salary`, `boss`).', required: true },
  }}
/>

#### Zwraca

`registerJob` odpowiada [ActionResult](/pl/docs/developers/api/types#actionresult): `{ ok: true }` albo `{ ok: false, error }` z kluczem językowym, gdy panel ma już pracę o tej nazwie albo zarejestrował ją inny resource - panel właściciela zawsze wygrywa. `removeJob` odpowiada `true` tylko dla pracy, którą zarejestrował ten resource.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { definitions } from "@aifivem/lib/server";

// Raz przy starcie: praca istnieje, dopóki ten resource działa.
const result = definitions.registerJob("garbage", {
  label: "Garbage",
  type: "job",
  defaultDuty: true,
  grades: [{ label: "Driver", salary: 60, boss: false }],
});
if (!result.ok) console.log(`praca nie zarejestrowana: ${result.error}`);
```
</Tab>
<Tab value="Lua">
```lua
local result = aiLib.definitions.registerJob('garbage', {
    label = 'Garbage',
    type = 'job',
    defaultDuty = true,
    grades = { { label = 'Driver', salary = 60, boss = false } },
})
if not result.ok then print(('praca nie zarejestrowana: %s'):format(result.error)) end
```
</Tab>
</Tabs>

<Callout type="info">
Praca, którą właściciel serwera ma móc edytować, należy do panelu, nie tutaj. Rejestruj wtedy, gdy praca jest częścią Twojego skryptu i bez niego nic nie znaczy.
</Callout>

## Prime time

### isPrimeTime

Czy dla pracy trwa prime time, według ustawienia prime time w ai-core. Godziny pochodzą z tgiann-policealert, gdy działa, a w przeciwnym razie z godzin ustawionych w panelu ai-core.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
isPrimeTime(job?: string): boolean
```

Brak odpowiednika w Lua: wywołaj eksport ai-core `IsPrimeTime(job)`.

<TypeTable
  type={{
    job: { type: "string", description: "Praca, dla której sprawdzić prime time. Bez niej domyślne godziny.", required: false },
  }}
/>

```ts
if (!isPrimeTime("police")) return fail("BANK_CLOSED_FOR_HEISTS");
```
