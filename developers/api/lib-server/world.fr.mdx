## world

L’heure et la météo via ai-core, quel que soit le script météo qui tourne (Renewed-Weathersync, av_weather, cd_easytime, qb-weathersync). Tant qu’aucun ne tourne, les lectures répondent `null` et les changements répondent `false`.

### world.getWeather

**Côté :** serveur · **Attend :** non

```ts title="Signature"
world.getWeather(): string | null
```

```lua title="Lua"
local weather = aiLib.world.getWeather()
```

**Retour** le type de météo actuel tel que le script météo le rapporte (`CLEAR`, `RAIN`...), ou `null` tant qu’aucun ne tourne.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const raining = ["RAIN", "THUNDER"].includes(world.getWeather() ?? "");
```
</Tab>
<Tab value="Lua">
```lua
local weather = aiLib.world.getWeather()
local raining = weather == 'RAIN' or weather == 'THUNDER'
```
</Tab>
</Tabs>

### world.setWeather

Change la météo.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
world.setWeather(type: Weather): boolean
```

```lua title="Lua"
local ok = aiLib.world.setWeather(weather)
```

<TypeTable
  type={{
    type: { type: "Weather", typeDescriptionLink: "/fr/docs/developers/api/types#weather", description: "Une valeur parmi `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Vérifiez d’abord une valeur venant d’un client ou du panneau avec `isWeather` (`@aicore-fivem/shared`).", required: true },
  }}
/>

**Retour** `true` quand elle est appliquée, `false` tant qu’aucun script météo ne tourne ou si la valeur n’est pas une chaîne.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, world } from "@aicore-fivem/lib/server";
import { isWeather } from "@aicore-fivem/shared";

addCommand("weather", { restricted: true, params: [{ name: "type", type: "string" }] }, (_source, { type }) => {
  const upper = type.toUpperCase();
  if (isWeather(upper)) world.setWeather(upper);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { restricted = true, params = { { name = 'type', type = 'string' } } }, function(_, args)
    aiLib.world.setWeather(args.type:upper())
end)
```
</Tab>
</Tabs>

## buckets

Les routing buckets (des mondes séparés : l’intérieur d’un appartement, une instance) de l’allocateur d’ai-core, pour que deux scripts n’en partagent jamais un. Ne choisissez jamais vous-même les numéros de bucket (`1000 + n`). Pas d’équivalent Lua : appelez les exports d’ai-core `AcquireBucket(tag)` / `ReleaseBucket(id)`.

### buckets.acquire

Prend un bucket libre pour cette ressource. Il n’a aucune population (pas de peds ni de voitures ambiants) et un verrouillage strict des entités.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
buckets.acquire(tag: string): number
```

<TypeTable
  type={{
    tag: { type: "string", description: "Un nom pour les journaux (`property:12`).", required: true },
  }}
/>

**Retour** l’id du bucket.

```ts
import { buckets } from "@aicore-fivem/lib/server";

const bucket = buckets.acquire(`property:${propertyId}`);
SetPlayerRoutingBucket(String(source), bucket);
```

### buckets.release

Rend un bucket une fois ses joueurs sortis.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
buckets.release(id: number): boolean
```

**Retour** `true` quand il est rendu. Tous les buckets d’une ressource arrêtée sont rendus d’eux-mêmes.

```ts
SetPlayerRoutingBucket(String(source), 0);
buckets.release(bucket);
```

## doors

Le verrouillage des portes via la couche de verrouillage de portes d’ai-core, par l’id de porte propre au script de verrouillage. Pas d’équivalent Lua : appelez les exports d’ai-core `SetDoorLocked`, `IsDoorLocked`.

### doors.setLocked

Verrouille ou déverrouille une porte.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
doors.setLocked(id: string, locked: boolean, by?: number): boolean
```

<TypeTable
  type={{
    id: { type: "string", description: "L’id de porte propre au script de verrouillage (l’id de la porte dans le panneau d’ai-doorlock).", required: true },
    locked: { type: "boolean", description: "`true` verrouille, `false` déverrouille.", required: true },
    by: { type: "number", description: "Id serveur du joueur qui agit. Les scripts de portes sans API serveur en ont besoin.", required: false },
  }}
/>

**Retour** `true` quand un script de portes l’a pris en compte, `false` sinon.

```ts
if (outcome === "won") doors.setLocked("bank_vault", false, source);
```

### doors.isLocked

**Côté :** serveur · **Attend :** non

```ts title="Signature"
doors.isLocked(id: string): boolean | null
```

**Retour** `true` ou `false`, ou `null` quand c’est inconnu (pas de verrouillage de portes, porte inexistante, ou le script ne peut pas le dire côté serveur).

```ts
if (doors.isLocked("bank_vault") === false) return fail("ALREADY_OPEN");
```

### doors.provider

**Côté :** serveur · **Attend :** non

```ts title="Signature"
doors.provider(): string | null
```

**Retour** le script de verrouillage de portes qui répond, ou `null` quand aucun ne tourne.

```ts
console.log(`doors through ${doors.provider() ?? "nothing"}`);
```

## characters

Les personnages enregistrés via ai-core. Les personnages chargés passent par `online` et les exports joueur d’ai-core.

### characters.setOfflinePosition

Déplace le point d’apparition d’un personnage enregistré (non chargé), par exemple un corps endormi qui a été emporté. ai-core l’écrit dès qu’aucune sauvegarde de chargement ou de déchargement ne retient le personnage.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
characters.setOfflinePosition(charId: number, position: { x: number; y: number; z: number; heading?: number }): boolean
```

Pas d’équivalent Lua : appelez l’export d’ai-core `SetOfflinePosition(charId, position)`.

<TypeTable
  type={{
    charId: { type: "number", description: "L’id du personnage (`CharacterInfo.id`).", required: true },
    position: { type: "{ x: number; y: number; z: number; heading?: number }", description: "Le nouveau point d’apparition ; cap en degrés.", required: true },
  }}
/>

**Retour** `true` quand c’est accepté. `false` quand le personnage est chargé ou que les valeurs sont incorrectes.

```ts
characters.setOfflinePosition(sleeperCharId, { x: 340.2, y: -1396.7, z: 32.5, heading: 50 });
```
