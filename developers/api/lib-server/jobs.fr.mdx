```ts title="TypeScript"
import { dispatch, prison, mdt, ems, medical, stress, needs, definitions, isPrimeTime } from "@aicore-fivem/lib/server";
```

Chaque objet ici passe par l’une des couches d’ai-core : le script que le serveur utilise pour ce rôle (un système d’alertes, une prison, un MDT, un script de mort, un HUD) répond. Votre script continue de fonctionner quand le propriétaire du serveur le remplace. Tant qu’aucun script de ce type ne tourne, les appels échouent en silence (`false`, `0`, `null`).

## dispatch

### dispatch.alert

Envoie une alerte police (ou d’un autre métier). Le système d’alertes l’affiche aux membres en service de `jobs`, par défaut les métiers de police.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

<TypeTable
  type={{
    title: { type: "string", description: "Le titre, traduit (`Shots fired`).", required: true },
    code: { type: "string", description: "Code radio affiché avant le titre (`10-71`).", required: false },
    message: { type: "string", description: "Une ligne de plus (le nom du magasin).", required: false },
    coords: { type: "{ x: number; y: number; z: number }", description: "Où cela s’est passé. Sans lui, la position du joueur `source` ; sans les deux, aucun point sur la carte.", required: false },
    jobs: { type: "string[]", description: "Les métiers dont les membres en service la reçoivent.", default: "les métiers de police du système d’alertes" },
    source: { type: "number", description: "Le joueur concerné par l’alerte (tireur, braqueur). Les systèmes qui décrivent le suspect (véhicule, sexe) lisent ce joueur.", required: false },
    blip: { type: "{ sprite: number; color?: number; scale?: number }", description: "Blip sur la carte : un sprite de blip GTA et une couleur.", default: "celui du système d’alertes" },
    duration: { type: "number", description: "Secondes pendant lesquelles l’alerte reste (carte, blip, touche de point de passage).", default: "celle du système d’alertes" },
    icon: { type: "string", description: "Nom d’icône Font Awesome solid sans `fa-` (`gun`).", required: false },
    priority: { type: '"normal" | "high"', description: "`high` fait ressortir la carte (braquage à main armée, agent à terre).", default: '"normal"' },
  }}
/>

Le type est [`DispatchAlert`](/fr/docs/developers/api/types#dispatchalert).

#### Retour

`boolean` : `true` quand elle est envoyée. `false` quand aucun système d’alertes ne tourne ou que l’alerte est invalide.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, coordsOf, createLocale } from "@aicore-fivem/lib/server";

const Locale = createLocale();

function storeRobbed(source: number, store: string) {
  dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

local function storeRobbed(source, store)
    local c = GetEntityCoords(GetPlayerPed(source))
    aiLib.dispatch.alert({
        code = '10-90',
        title = Locale('ALERT_STORE_ROBBERY'),
        message = store,
        coords = { x = c.x, y = c.y, z = c.z },
        source = source,
        icon = 'store',
        priority = 'high',
    })
end
```
</Tab>
</Tabs>

## prison

Les peines de prison via ai-core, quel que soit le script de prison qui tourne.

### prison.jail

Envoie un joueur chargé en prison.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
prison.jail(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local ok = aiLib.prison.jail(source, minutes, by)
```

<TypeTable
  type={{
    source: { type: "number", description: "Id serveur du joueur à emprisonner.", required: true },
    minutes: { type: "number", description: "Durée de la peine en minutes.", required: true },

</Tabs>

## mdt

Les dossiers du MDT de police (amendes, mandats, arrestations, prison) via la couche MDT d’ai-core. Rien n’est écrit tant qu’aucun MDT ne tourne.

### mdt.record

Écrit un dossier dans le MDT de police.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
mdt.record(record: MdtRecord): boolean
```

```lua title="Lua"
local ok = aiLib.mdt.record(record)
```

#### MdtRecord

<TypeTable
  type={{
    kind: { type: '"fine" | "warrant" | "arrest" | "jail"', description: "Le type de dossier.", required: true },
    target: { type: "number", description: "Id serveur du joueur concerné par le dossier.", required: true },
    by: { type: "number", description: "Id serveur de l’agent qui l’écrit.", required: false },
    title: { type: "string", description: "Ce qui s’est passé, traduit (`Armed robbery`).", required: true },
    amount: { type: "number", description: "Le montant d’une amende en dollars.", required: false },
    minutes: { type: "number", description: "Une peine de prison en minutes.", required: false },
  }}
/>

Le type est [`MdtRecord`](/fr/docs/developers/api/types#mdtrecord).

**Retour** `true` quand il est écrit, `false` quand aucun MDT ne tourne ou qu’il n’accepte pas ce type de dossier.

<Tabs items={['TypeScript', 'Lua']}>

## ems

Les médecins via la couche EMS d’ai-core : le décompte et les appels de détresse propres à un script EMS, sinon les décomptes de service et les alertes d’ai-core.

### ems.available

Combien de médecins sont libres pour prendre un appel.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
ems.available(jobs: string[]): number
```

```lua title="Lua"
local count = aiLib.ems.available(jobs)
```

<TypeTable
  type={{
    jobs: { type: "string[]", description: "Les noms des métiers EMS à compter (`[\"ambulance\"]`).", required: true },
  }}
/>

**Retour** le nombre de médecins en service dans `jobs`, sans compter ceux qui sont occupés quand un script de dispatch les connaît.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

<Tab value="Lua">

</Tab>
</Tabs>

## medical

La réanimation, les soins et l’état à terre via la couche médicale d’ai-core, quel que soit le script de mort ou d’ambulance qui tourne. Pas d’équivalent Lua : appelez les exports d’ai-core `RevivePlayer`, `HealPlayer`, `IsPlayerDead`.

### medical.revive

Relève un joueur à terre là où il se trouve.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
medical.revive(source: number): boolean
```

**Retour** `true` quand il est réanimé, `false` quand il n’est pas à terre ou qu’aucun script de mort ne tourne.

```ts
if (!medical.revive(target)) return fail("NOT_DOWN");
```

### medical.heal

Rend toute sa santé à un joueur qui n’est pas à terre.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
medical.heal(source: number): boolean
```

**Retour** `true` quand il est soigné, `false` quand aucun script de mort ne tourne.

```ts
medical.heal(source);
```

### medical.isDead

Indique si le joueur est à terre.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
medical.isDead(source: number): boolean
```

**Retour** `true` quand il est à terre ; `false` sans script de mort. Utilisez-la au lieu de lire la santé du ped.

```ts
if (medical.isDead(source)) return fail("YOU_ARE_DOWN");
```

### medical.provider

**Côté :** serveur · **Attend :** non

```ts title="Signature"
medical.provider(): string | null
```

**Retour** le script de mort qui répond (`ai-death`...), ou `null` quand aucun ne tourne.

```ts
console.log(`deaths through ${medical.provider() ?? "nothing"}`);
```

## needs

### needs.refill

Remplit entièrement la faim et la soif (réanimation par un admin, hôpital), via le HUD qui les gère, ou sans HUD via les métadonnées du personnage dans ai-core.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
needs.refill(source: number): boolean
```

Pas d’équivalent Lua : appelez l’export d’ai-core `RefillNeeds(source)`.

**Retour** `true` quand elles sont remplies, `false` quand le joueur n’a pas de personnage.

```ts
if (medical.revive(target)) needs.refill(target);
```

## Définitions des métiers et des gangs

### definitions.job

La définition d’un métier telle que réglée dans le panneau d’ai-core. Chacune est lue une fois depuis ai-core et gardée jusqu’à ce que le panneau la modifie, donc une lecture est une simple recherche en mémoire.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
definitions.job(name: string): JobDefinition | null
```

Pas d’équivalent Lua : appelez l’export d’ai-core `GetJobDefinition(name)`.

**Retour** [`JobDefinition`](/fr/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`), ou `null` quand ce métier n’existe pas.

```ts
const label = definitions.job("police")?.label ?? "police";
```

### definitions.gang

**Côté :** serveur · **Attend :** non

```ts title="Signature"
definitions.gang(name: string): GangDefinition | null
```

Pas d’équivalent Lua : appelez l’export d’ai-core `GetGangDefinition(name)`.

**Retour** [`GangDefinition`](/fr/docs/developers/api/types#gangdefinition) (`label`, `grades`), ou `null`.

```ts
const gang = definitions.gang("ballas");
if (!gang) return fail("UNKNOWN_GANG");
```

## Heures de pointe

### isPrimeTime

Indique si c’est l’heure de pointe pour un métier, d’après le réglage d’heures de pointe d’ai-core. Les heures viennent de tgiann-policealert tant qu’il tourne, sinon des heures réglées dans le panneau d’ai-core.

**Côté :** serveur · **Attend :** non

```ts title="Signature"
isPrimeTime(job?: string): boolean
```

Pas d’équivalent Lua : appelez l’export d’ai-core `IsPrimeTime(job)`.

<TypeTable
  type={{
    job: { type: "string", description: "Le métier dont il faut vérifier l’heure de pointe. Sans lui, les heures par défaut.", required: false },
  }}
/>

**Retour** `true` pendant l’heure de pointe.

```ts
if (!isPrimeTime("police")) return fail("BANK_CLOSED_FOR_HEISTS");
```
