```ts title="TypeScript"
import { jobs, dispatch, prison, mdt, ems, medical, stress, needs, definitions, isPrimeTime } from "@aifivem/lib/server";
```

`jobs` und `definitions` sind ai-core selbst: die Jobs und Gangs eines Charakters und die Job-Definitionen des Servers. Alles andere hier geht über einen von ai-cores Layern, wo das Script antwortet, das der Server für diese Aufgabe fährt (ein Alarmsystem, ein Gefängnis, ein MDT, ein Death-Script, ein HUD). Dein Script läuft weiter, wenn der Besitzer es tauscht. Solange kein solches Script läuft, scheitern diese Aufrufe still (`false`, `0`, `null`).

## jobs

`jobs` sind die eigenen Jobs und Gangs eines geladenen Spielers über ai-core: ein Charakter kann mehrere Jobs halten, ist in höchstens einem im Dienst und handelt für eine Gang zur Zeit. **Viele** Spieler auf einmal zu lesen ist der Spiegel der Lib ([`online`](/de/docs/developers/api/lib-server/players#onlinejobs)); einen Charakter zu ändern, der **nicht** verbunden ist, ist [`characters`](/de/docs/developers/api/lib-server/characters#characterssetjob-and-charactersremovejob).

### jobs.current

Der Job, den andere Scripts als "den" Job eines Spielers sehen: der, in dem er im Dienst ist, sonst der, in dem er zuletzt im Dienst war, sonst der erste, den er hält, sonst der Arbeitslosen-Job.

**Seite:** Server · **Wartet:** nein

```ts title="Signature"
jobs.current(source: number): JobMembership | null
```

```lua title="Lua"
local current = aiLib.jobs.current(source)
```

#### Rückgabe

Ein [JobMembership](/de/docs/developers/api/types#jobmembership) (`{ job, grade }`), oder `null`, wenn der Spieler keinen geladenen Charakter hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs } from "@aifivem/lib/server";

export function isOfficer(source: number): boolean {
  return jobs.current(source)?.job === "police";
}
```
</Tab>
<Tab value="Lua">
```lua
local current = aiLib.jobs.current(source)
local officer = current and current.job == 'police'
```
</Tab>
</Tabs>

### jobs.duty and jobs.setDuty

In welchem Job der Spieler im Dienst ist, und in den Dienst gehen oder aus ihm heraus. Viele Scripts prüfen den Dienst statt der Mitgliedschaft: ein Beamter außer Dienst ist ein Zivilist.

**Seite:** Server · **Wartet:** nein

```ts title="Signature"
jobs.duty(source: number): string | null
jobs.setDuty(source: number, job: string | null): boolean
```

```lua title="Lua"
local onDutyIn = aiLib.jobs.duty(source)
local ok = aiLib.jobs.setDuty(source, job)
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers.', required: true },
    job: { type: 'string | null', description: 'Ein Job, den der Spieler hält, um darin in den Dienst zu gehen. `null` (Lua `nil`) geht außer Dienst.', required: true },
  }}
/>

#### Rückgabe

`jobs.duty`: der Jobname, oder `null`, wenn außer Dienst (oder kein Charakter). `jobs.setDuty`: `true`, wenn die Änderung gemacht wurde, `false` bei einem Job, den der Spieler nicht hält.

### jobs.set

Gibt dem Spieler einen Job oder ändert den Grade eines Jobs, den er schon hält. Die Regeln des Panels gelten: wie viele Jobs ein Charakter halten darf und ob ein zweiter überhaupt erlaubt ist.

**Seite:** Server · **Wartet:** nein

```ts title="Signature"
jobs.set(source: number, job: string, grade: number): boolean
```

```lua title="Lua"
local ok = aiLib.jobs.set(source, job, grade)
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers.', required: true },
    job: { type: 'string', description: 'Der Jobname wie im Panel (oder in einer Script-Definition).', required: true },
    grade: { type: 'number', description: 'Der Grade in diesem Job, ab 0. Ein Grade, den der Job nicht hat, wird abgelehnt.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn der Spieler den Job danach in diesem Grade hält. `false` ohne geladenen Charakter, bei einem unbekannten Job, einem unbekannten Grade, oder beim Joblimit des Panels.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs, notify } from "@aifivem/lib/server";

export function hire(source: number, job: string): void {
  if (!jobs.set(source, job, 0)) return notify(source, "Einstellung nicht möglich", "error");
  notify(source, `Willkommen bei ${job}`, "success");
}
```
</Tab>
<Tab value="Lua">
```lua
if aiLib.jobs.set(source, 'mechanic', 0) then
    aiLib.notify(source, 'Willkommen bei mechanic', 'success')
end
```
</Tab>
</Tabs>

## medical

Wiederbeleben, Heilen und der Bewusstlos-Zustand über die Medical-Ebene von ai-core, egal welches Death- oder Ambulance-Skript läuft. Kein Lua-Zwilling: Rufe die Exports `RevivePlayer`, `HealPlayer`, `IsPlayerDead` von ai-core auf.

### medical.revive

Bringt einen bewusstlosen Spieler dort wieder auf die Beine, wo er liegt.

**Seite:** Server · **Wartet:** nein

medical.revive(source: number): boolean
```

**Rückgabewert:** `true`, wenn wiederbelebt, `false`, wenn nicht bewusstlos oder kein Death-Skript läuft.

## Job- und Gang-Definitionen

### definitions.job

```

```lua title="Lua"

```

**Rückgabewert:** [`JobDefinition`](/de/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`), oder `null`, wenn es keinen solchen Job gibt.

```ts
const label = definitions.job("police")?.label ?? "police";
```

### definitions.registerJob and definitions.removeJob

Ein Job, den dein Script mitbringt, ohne dass der Besitzer ihn im Panel anlegt: ein Job der aufrufenden Resource, weg wenn die Resource stoppt, und nie in die Panel-Datei geschrieben.

**Seite:** Server · **Wartet:** nein

```ts title="Signature"
definitions.registerJob(name: string, definition: JobDefinition): CharacterResult
definitions.removeJob(name: string): boolean
```

```lua title="Lua"
local result = aiLib.definitions.registerJob(name, definition)
local ok = aiLib.definitions.removeJob(name)
```

#### Parameter

<TypeTable
  type={{
    name: { type: 'string', description: 'Der Jobname, den dein Script benutzt (`"my-garbagejob"`).', required: true },
    definition: { type: 'JobDefinition', typeDescriptionLink: '/de/docs/developers/api/types#jobdefinition', description: 'Der Job selbst: `label`, `type`, `defaultDuty`, `listed`, und seine `grades` (jeder mit `label`, `salary`, `boss`).', required: true },
  }}
/>

#### Rückgabe

`registerJob` antwortet [ActionResult](/de/docs/developers/api/types#actionresult): `{ ok: true }`, oder `{ ok: false, error }` mit einem Lang-Key, wenn das Panel schon einen Job dieses Namens hat oder eine andere Resource ihn registriert hat - das Panel des Besitzers gewinnt immer. `removeJob` antwortet nur bei einem Job `true`, den diese Resource registriert hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { definitions } from "@aifivem/lib/server";

// Einmal beim Start: der Job existiert, solange diese Resource läuft.
const result = definitions.registerJob("garbage", {
  label: "Garbage",
  type: "job",
  defaultDuty: true,
  grades: [{ label: "Driver", salary: 60, boss: false }],
});
if (!result.ok) console.log(`Job nicht registriert: ${result.error}`);
```
</Tab>
<Tab value="Lua">
```lua
local result = aiLib.definitions.registerJob('garbage', {
    label = 'Garbage',
    type = 'job',
    defaultDuty = true,
    grades = { { label = 'Driver', salary = 60, boss = false } },
})
if not result.ok then print(('Job nicht registriert: %s'):format(result.error)) end
```
</Tab>
</Tabs>

<Callout type="info">
Ein Job, den der Serverbesitzer bearbeiten können soll, gehört ins Panel, nicht hierher. Registriere einen, wenn der Job Teil deines Scripts ist und ohne es nichts bedeutet.
</Callout>

## Prime Time

### isPrimeTime

Ob für einen Job gerade Prime Time ist, nach der Prime-Time-Einstellung von ai-core. Die Uhrzeiten kommen von tgiann-policealert, solange es läuft, sonst aus den Uhrzeiten im Panel von ai-core.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
isPrimeTime(job?: string): boolean
```

Kein Lua-Zwilling: Rufe den Export `IsPrimeTime(job)` von ai-core auf.

<TypeTable
  type={{
    job: { type: "string", description: "Job, dessen Prime Time geprüft wird. Ohne Angabe die Standard-Uhrzeiten.", required: false },
  }}
/>

**Rückgabewert:** `true` während der Prime Time.

```ts
if (!isPrimeTime("police")) return fail("BANK_CLOSED_FOR_HEISTS");
```
