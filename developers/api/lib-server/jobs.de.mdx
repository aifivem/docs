```ts title="TypeScript"
import { dispatch, prison, mdt, ems, medical, stress, needs, definitions, isPrimeTime } from "@aifivem/lib/server";
```

Jedes Objekt hier läuft über eine der Ebenen von ai-core: Das Skript, das der Server für diese Aufgabe betreibt (ein Alarmsystem, ein Gefängnis, ein MDT, ein Death-Skript, ein HUD), antwortet. Dein Skript funktioniert weiter, wenn der Betreiber es austauscht. Solange kein solches Skript läuft, schlagen Aufrufe still fehl (`false`, `0`, `null`).

## dispatch

### dispatch.alert

Sendet einen Alarm an die Polizei (oder einen anderen Job). Das Alarmsystem zeigt ihn den Mitgliedern von `jobs` im Dienst, standardmäßig den Polizei-Jobs.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
dispatch.alert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local ok = aiLib.dispatch.alert(alert)
```

#### DispatchAlert

<TypeTable
  type={{
    title: { type: "string", description: "Die Überschrift, übersetzt (`Shots fired`).", required: true },
    code: { type: "string", description: "Funkcode, der vor dem Titel angezeigt wird (`10-71`).", required: false },
    message: { type: "string", description: "Eine weitere Zeile (der Name des Ladens).", required: false },
    coords: { type: "{ x: number; y: number; z: number }", description: "Wo es passiert ist. Ohne Angabe die Position des Spielers `source`; ohne beides kein Kartenpunkt.", required: false },
    jobs: { type: "string[]", description: "Jobs, deren Mitglieder im Dienst ihn bekommen.", default: "die Polizei-Jobs des Alarmsystems" },
    source: { type: "number", description: "Der Spieler, um den es im Alarm geht (Schütze, Räuber). Systeme, die den Verdächtigen beschreiben (Fahrzeug, Geschlecht), lesen diesen Spieler.", required: false },
    blip: { type: "{ sprite: number; color?: number; scale?: number }", description: "Karten-Blip: ein GTA-Blip-Sprite und eine Farbe.", default: "die des Alarmsystems" },
    duration: { type: "number", description: "Sekunden, die der Alarm bleibt (Karte, Blip, Wegpunkt-Taste).", default: "die des Alarmsystems" },
    icon: { type: "string", description: "Name eines Font-Awesome-Solid-Icons ohne `fa-` (`gun`).", required: false },
    priority: { type: '"normal" | "high"', description: "`high` hebt die Karte hervor (bewaffneter Raub, Beamter am Boden).", default: '"normal"' },
  }}
/>

Der Typ ist [`DispatchAlert`](/de/docs/developers/api/types#dispatchalert).

#### Rückgabewert

`boolean`: `true`, wenn gesendet. `false`, wenn kein Alarmsystem läuft oder der Alarm ungültig ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { dispatch, coordsOf, createLocale } from "@aifivem/lib/server";

const Locale = createLocale();

function storeRobbed(source: number, store: string) {
  dispatch.alert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: store,
    coords: coordsOf(source),
    source,
    icon: "store",
    priority: "high",
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

local function storeRobbed(source, store)
    local c = GetEntityCoords(GetPlayerPed(source))
    aiLib.dispatch.alert({
        code = '10-90',
        title = Locale('ALERT_STORE_ROBBERY'),
        message = store,
        coords = { x = c.x, y = c.y, z = c.z },
        source = source,
        icon = 'store',
        priority = 'high',
    })
end
```
</Tab>
</Tabs>

## prison

Haftstrafen über ai-core, egal welches Gefängnis-Skript läuft.

### prison.jail

Schickt einen geladenen Spieler ins Gefängnis.

**Seite:** Server · **Wartet:** nein



## mdt

### mdt.record

Schreibt einen Eintrag ins Polizei-MDT.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
mdt.record(record: MdtRecord): boolean
```

```lua title="Lua"
local ok = aiLib.mdt.record(record)
```

#### MdtRecord

**Seite:** Server · **Wartet:** nein



## medical

Wiederbeleben, Heilen und der Bewusstlos-Zustand über die Medical-Ebene von ai-core, egal welches Death- oder Ambulance-Skript läuft. Kein Lua-Zwilling: Rufe die Exports `RevivePlayer`, `HealPlayer`, `IsPlayerDead` von ai-core auf.

### medical.revive

Bringt einen bewusstlosen Spieler dort wieder auf die Beine, wo er liegt.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
medical.revive(source: number): boolean
```

**Rückgabewert:** `true`, wenn wiederbelebt, `false`, wenn nicht bewusstlos oder kein Death-Skript läuft.

```ts
if (!medical.revive(target)) return fail("NOT_DOWN");
```

### medical.heal

Gibt einem Spieler, der nicht bewusstlos ist, volle Gesundheit.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
medical.heal(source: number): boolean
```

**Rückgabewert:** `true`, wenn geheilt, `false`, wenn kein Death-Skript läuft.

```ts
medical.heal(source);
```

### medical.isDead

Ob der Spieler bewusstlos ist.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
medical.isDead(source: number): boolean
```

**Rückgabewert:** `true`, wenn bewusstlos; `false` ohne Death-Skript. Nutze es, statt die Gesundheit des Peds zu lesen.

```ts
if (medical.isDead(source)) return fail("YOU_ARE_DOWN");
```

### medical.provider

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
medical.provider(): string | null
```

**Rückgabewert:** das Death-Skript, das antwortet (`ai-death`...), oder `null`, wenn keins läuft.

```ts
console.log(`deaths through ${medical.provider() ?? "nothing"}`);
```

## needs

### needs.refill

Füllt Hunger und Durst ganz auf (Admin-Revive, Krankenhaus), über das HUD, das sie führt, oder ohne eines über die Charakter-Metadaten von ai-core.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
needs.refill(source: number): boolean
```

Kein Lua-Zwilling: Rufe den Export `RefillNeeds(source)` von ai-core auf.

**Rückgabewert:** `true`, wenn aufgefüllt, `false`, wenn der Spieler keinen Charakter hat.

```ts
if (medical.revive(target)) needs.refill(target);
```

## Job- und Gang-Definitionen

### definitions.job

Die Definition eines Jobs, wie sie im Panel von ai-core eingestellt ist. Jede wird einmal aus ai-core gelesen und behalten, bis das Panel sie ändert, daher ist ein Lesezugriff ein Nachschlagen im Speicher.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
definitions.job(name: string): JobDefinition | null
```

Kein Lua-Zwilling: Rufe den Export `GetJobDefinition(name)` von ai-core auf.

**Rückgabewert:** [`JobDefinition`](/de/docs/developers/api/types#jobdefinition) (`label`, `type`, `defaultDuty`, `listed?`, `grades`), oder `null`, wenn es keinen solchen Job gibt.

```ts
const label = definitions.job("police")?.label ?? "police";
```

### definitions.gang

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
definitions.gang(name: string): GangDefinition | null
```

Kein Lua-Zwilling: Rufe den Export `GetGangDefinition(name)` von ai-core auf.

**Rückgabewert:** [`GangDefinition`](/de/docs/developers/api/types#gangdefinition) (`label`, `grades`), oder `null`.

```ts
const gang = definitions.gang("ballas");
if (!gang) return fail("UNKNOWN_GANG");
```

## Prime Time

### isPrimeTime

Ob für einen Job gerade Prime Time ist, nach der Prime-Time-Einstellung von ai-core. Die Uhrzeiten kommen von tgiann-policealert, solange es läuft, sonst aus den Uhrzeiten im Panel von ai-core.

**Seite:** Server · **Wartet:** nein

```ts title="Signatur"
isPrimeTime(job?: string): boolean
```

Kein Lua-Zwilling: Rufe den Export `IsPrimeTime(job)` von ai-core auf.

<TypeTable
  type={{
    job: { type: "string", description: "Job, dessen Prime Time geprüft wird. Ohne Angabe die Standard-Uhrzeiten.", required: false },
  }}
/>

**Rückgabewert:** `true` während der Prime Time.

```ts
if (!isPrimeTime("police")) return fail("BANK_CLOSED_FOR_HEISTS");
```
