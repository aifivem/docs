---
title: Items
description: "inventory: give, take and count items, stashes, shops and usable items through whatever inventory the server runs."
icon: Package
---

```ts title="TypeScript"
import { inventory } from "@aifivem/lib/server";
```

`inventory` sends every item call through ai-core's inventory layer: the inventory the server runs (ai-inventory, or another the owner picks in ai-core's panel) answers. Your script never calls an inventory's own exports, so it keeps working when the owner changes inventory.

**The inventory argument** (`inv`, type [`InventoryRef`](/docs/developers/api/types#inventoryref)) is a player's server id (a number) or another inventory's id (a string: a stash name, a plate).

**Counts** are whole numbers of 1 or more; a fraction is rounded down, `0` or a negative count makes the call fail.

<Callout type="info">
While no inventory runs, calls fail quietly: `false`, `0`, an empty list or `null`. The Lua twins on `aiLib.inventory` have the same names and argument order.
</Callout>

### inventory.addItem

Gives items to an inventory.

**Side:** Server · **Waits:** no

```ts title="Signature"
inventory.addItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = aiLib.inventory.addItem(inv, item, count, metadata, slot)
```

#### Parameters

<TypeTable
  type={{
    inv: { type: "InventoryRef", typeDescriptionLink: "/docs/developers/api/types#inventoryref", description: "Player server id, or a stash name or plate.", required: true },
    item: { type: "string", description: "Item name as the inventory knows it (`water`).", required: true },
    count: { type: "number", description: "How many.", default: "1" },
    metadata: { type: "ItemMetadata", typeDescriptionLink: "/docs/developers/api/types#itemmetadata", description: "Extra data stored on the stack (`{ serial: \"A1\" }`). Stacks with different metadata do not merge.", required: false },
    slot: { type: "number", description: "Put them in this slot (1 or more) when the inventory supports it.", required: false },
  }}
/>

#### Returns

`boolean`: `true` when given. `false` when they do not fit, the item does not exist, an argument is wrong or no inventory runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

if (!inventory.addItem(source, "phone", 1, { number: "555-0101" })) return fail("INVENTORY_FULL");
```
</Tab>
<Tab value="Lua">
```lua
if not aiLib.inventory.addItem(source, 'phone', 1, { number = '555-0101' }) then
    return aiLib.fail('INVENTORY_FULL')
end
```
</Tab>
</Tabs>

<Callout type="warn">
Check `canCarryItem` first when you take something in exchange (money, another item): take it only after `addItem` answered `true`, or give it back.
</Callout>

### inventory.openInventory

Opens a stash or another player's inventory on a player's screen.

**Side:** Server · **Waits:** no

```ts title="Signature"
inventory.openInventory(source: number, inv: InventoryRef): boolean
```

```lua title="Lua"
local ok = aiLib.inventory.openInventory(source, inv)
```

<TypeTable
  type={{
    source: { type: "number", description: "Server id of the player who sees it.", required: true },
    inv: { type: "InventoryRef", typeDescriptionLink: "/docs/developers/api/types#inventoryref", description: "Stash name, plate, or another player’s server id.", required: true },
  }}
/>

#### Returns

`boolean`: `true` when the inventory opened it.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, near, online, inventory } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const ARMORY = { x: 452.3, y: -980.0, z: 30.7 };

onClientCallback(
  "my-police:armory",
  (source) => {
    if (!online.onDutyIn(source, ["police"])) return fail("NOT_ON_DUTY");
    return { ok: inventory.openInventory(source, "police_armory") };
  },
  { guards: [near(ARMORY, 3)] },
);
```
</Tab>
<Tab value="Lua">
```lua
local ARMORY = vector3(452.3, -980.0, 30.7)

aiLib.onClientCallback('my-police:armory', function(source)
    if aiLib.online.dutyJob(source) ~= 'police' then return aiLib.fail('NOT_ON_DUTY') end
    if #(GetEntityCoords(GetPlayerPed(source)) - ARMORY) > 3.0 then return aiLib.fail('TOO_FAR') end
    return { ok = aiLib.inventory.openInventory(source, 'police_armory') }
end)
```
</Tab>
</Tabs>

<Callout type="warn">
No range or access check happens here: check distance, job and ownership before you call it.
</Callout>

### inventory.registerUsableItem

Runs your handler when a player uses an item. ai-core keeps the handler for inventories that start later and across inventory restarts, so register once when your script starts.

**Side:** Server · **Waits:** no

```ts title="Signature"
inventory.registerUsableItem(name: string, handler: UsableItemHandler): void
```

```lua title="Lua"
aiLib.inventory.registerUsableItem(name, handler) -- handler(source, item)
```

#### Parameters

<TypeTable
  type={{
    name: { type: "string", description: "Item name.", required: true },
    handler: { type: "(source: number, item: UsedItem) => unknown", typeDescriptionLink: "/docs/developers/api/types#usableitemhandler", description: "Gets the player and the used stack `{ name, slot, count, metadata }` (type `UsedItem`). Returning `false` keeps the item in inventories that take a used item themselves (ai-inventory: the item’s `consume` amount); other inventories follow their own item settings.", required: true },
  }}
/>

The used stack is a [`UsedItem`](/docs/developers/api/types#useditem).

<Callout type="warn">
Inventories that take a used item themselves (ai-inventory) take it as soon as the handler returns anything but `false`. When your handler waits (a progress bar) and removes the item itself, return `false` at once, or the item is taken twice.
</Callout>

#### Returns

`void`.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { inventory, progressFor, medical, createLocale } from "@aifivem/lib/server";

const Locale = createLocale();

async function bandage(source: number) {
  const done = await progressFor(source, { label: Locale("BANDAGING"), duration: 4000, canCancel: true });
  if (done && inventory.removeItem(source, "bandage")) medical.heal(source);
}

inventory.registerUsableItem("bandage", (source) => {
  void bandage(source);
  return false; // keep the item now: bandage() takes it after the bar
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.inventory.registerUsableItem('bandage', function(source, item)
    CreateThread(function()
        local done = aiLib.progressFor(source, { label = Locale('BANDAGING'), duration = 4000, canCancel = true })
        if done and aiLib.inventory.removeItem(source, 'bandage', 1) then
            exports['ai-core']:HealPlayer(source)
        end
    end)
    return false -- keep the item now: the thread takes it after the bar
end)
```
</Tab>
</Tabs>

### inventory.registerShop
