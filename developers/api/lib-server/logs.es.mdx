```ts title="TypeScript"
import { aiLog, aiLogChannels } from "@aifivem/lib/server";
```

Tu script nunca publica en Discord ni en un servicio de logs por sí mismo. Envía un log a ai-core en un **canal** (un nombre como `purchase`); el dueño del servidor decide en el panel de administración de ai-core adónde va cada canal. Las URL de webhook y las claves de API se quedan en el panel, nunca en tu código.

### aiLog

Envía una línea de log a través del sistema de logs de ai-core.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
aiLog(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
aiLib.aiLog(channel, message, options)
```

#### Parámetros

<TypeTable
  type={{
    channel: { type: "string", description: "El nombre del canal (`purchase`, `admin`). Describe tus canales una vez con `aiLogChannels`.", required: true },
    message: { type: "string", description: "Qué pasó. Pasa los jugadores como `source` / `target` en lugar de escribir nombres en el texto.", required: true },
    options: { type: "LogOptions", typeDescriptionLink: "/es/docs/developers/api/types#logoptions", description: "Nivel, jugadores y valores extra. Campos abajo.", required: false },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: "Gravedad.", required: false },
    source: { type: "number", description: "Id de servidor del jugador que lo hizo. Se añaden su nombre, su personaje y sus identificadores.", required: false },
    target: { type: "number", description: "Id de servidor del jugador al que se le hizo.", required: false },
    metadata: { type: "Record<string, unknown>", description: "Campos extra (cantidades, nombres de objetos, coordenadas).", required: false },
  }}
/>

#### Devuelve

`void`. En TypeScript no hace nada mientras ai-core no está en marcha; el equivalente en Lua imprime `[channel] message` en la consola en su lugar.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { aiLog } from "@aifivem/lib/server";

aiLog("purchase", `bought ${count}x ${item} for $${price}`, {
  source,
  metadata: { item, count, price },
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.aiLog('purchase', ('bought %dx %s for $%d'):format(count, item, price), {
    source = source,
    metadata = { item = item, count = count, price = price },
})
```
</Tab>
</Tabs>

### aiLogChannels

Describe los canales de log de tu recurso: el nombre del dataset que usan Fivemanage y FiveM Stats, y si un canal está activo. Llámalo una vez cuando tu script arranque.

**Lado:** Servidor · **Espera:** no

```ts title="Firma"
aiLogChannels(channels: Record<string, LogChannel>): void
```

Sin equivalente en Lua: llama al export de ai-core `exports['ai-core']:LogChannels(channels)`.

#### Parámetros

<TypeTable
  type={{
    channels: { type: "Record<string, LogChannel>", typeDescriptionLink: "/es/docs/developers/api/types#logchannel", description: "Una entrada por nombre de canal. Cada `LogChannel` tiene `dataset?` (dataset de Fivemanage / FiveM Stats, por defecto el nombre del recurso) y `active?` (`false` desactiva el canal).", required: true },
  }}
/>

#### Devuelve

`void`. No hace nada mientras ai-core no está en marcha.

#### Ejemplo

```ts
import { aiLogChannels } from "@aifivem/lib/server";

aiLogChannels({
  purchase: { dataset: "shops" },
  debug: { active: false },
});
```
