## world

Czas i pogoda przez ai-core, niezależnie od tego, jaki skrypt pogody działa (Renewed-Weathersync, av_weather, cd_easytime, qb-weathersync). Dopóki żaden nie działa, odczyty odpowiadają `null`, a zmiany `false`.

### world.getWeather

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
world.getWeather(): string | null
```

```lua title="Lua"
local weather = aiLib.world.getWeather()
```

**Zwraca** bieżący typ pogody tak, jak podaje go skrypt pogody (`CLEAR`, `RAIN`...), albo `null`, dopóki żaden nie działa.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
const raining = ["RAIN", "THUNDER"].includes(world.getWeather() ?? "");
```
</Tab>
<Tab value="Lua">
```lua
local weather = aiLib.world.getWeather()
local raining = weather == 'RAIN' or weather == 'THUNDER'
```
</Tab>
</Tabs>

### world.setWeather

Ustawia pogodę.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
world.setWeather(type: Weather): boolean
```

```lua title="Lua"
local ok = aiLib.world.setWeather(weather)
```

<TypeTable
  type={{
    type: { type: "Weather", typeDescriptionLink: "/pl/docs/developers/api/types#weather", description: "Jedno z `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Wartość od klienta albo z panelu najpierw sprawdź przez `isWeather` (`@aifivem/shared`).", required: true },
  }}
/>

**Zwraca** `true`, gdy ustawiono, `false`, dopóki nie działa żaden skrypt pogody albo wartość nie jest stringiem.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, world } from "@aifivem/lib/server";
import { isWeather } from "@aifivem/shared";

addCommand("weather", { restricted: true, params: [{ name: "type", type: "string" }] }, (_source, { type }) => {
  const upper = type.toUpperCase();
  if (isWeather(upper)) world.setWeather(upper);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { restricted = true, params = { { name = 'type', type = 'string' } } }, function(_, args)
    aiLib.world.setWeather(args.type:upper())
end)
```
</Tab>
</Tabs>

## buckets

Routing buckety (osobne światy: wnętrze mieszkania, instancja) z alokatora ai-core, więc żadne dwa skrypty nigdy nie dzielą jednego. Nigdy nie wybieraj numerów bucketów sam (`1000 + n`). Brak odpowiednika w Lua: wywołaj eksporty ai-core `AcquireBucket(tag)` / `ReleaseBucket(id)`.

### buckets.acquire

Bierze wolny bucket dla tego zasobu. Nie ma populacji (żadnych pedów i aut w tle) i ma ścisłą blokadę encji.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
buckets.acquire(tag: string): number
```

<TypeTable
  type={{
    tag: { type: "string", description: "Nazwa do logów (`property:12`).", required: true },
  }}
/>

**Zwraca** id bucketu.

```ts
import { buckets } from "@aifivem/lib/server";

const bucket = buckets.acquire(`property:${propertyId}`);
SetPlayerRoutingBucket(String(source), bucket);
```

### buckets.release

Oddaje bucket, gdy jego gracze już z niego wyszli.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
buckets.release(id: number): boolean
```

**Zwraca** `true`, gdy zwolniono. Każdy bucket zatrzymanego zasobu wraca sam.

```ts
SetPlayerRoutingBucket(String(source), 0);
buckets.release(bucket);
```

## doors

Zamki drzwi przez warstwę zamków drzwi ai-core, według własnego id drzwi skryptu zamków. Brak odpowiednika w Lua: wywołaj eksporty ai-core `SetDoorLocked`, `IsDoorLocked`.

### doors.setLocked

Zamyka albo otwiera drzwi.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
doors.setLocked(id: string, locked: boolean, by?: number): boolean
```

<TypeTable
  type={{
    id: { type: "string", description: "Własne id drzwi skryptu zamków (id drzwi w panelu ai-doorlock).", required: true },
    locked: { type: "boolean", description: "`true` zamyka, `false` otwiera.", required: true },
    by: { type: "number", description: "Id serwerowe działającego gracza. Skrypty drzwi bez API serwerowego go potrzebują.", required: false },
  }}
/>

**Zwraca** `true`, gdy skrypt drzwi to przyjął, w przeciwnym razie `false`.

```ts
if (outcome === "won") doors.setLocked("bank_vault", false, source);
```

### doors.isLocked

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
doors.isLocked(id: string): boolean | null
```

**Zwraca** `true` albo `false` lub `null`, gdy nie wiadomo (brak zamka drzwi, brak takich drzwi albo skrypt nie potrafi tego stwierdzić na serwerze).

```ts
if (doors.isLocked("bank_vault") === false) return fail("ALREADY_OPEN");
```

### doors.provider

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
doors.provider(): string | null
```

**Zwraca** skrypt zamków drzwi, który odpowiada, albo `null`, gdy żaden nie działa.

```ts
console.log(`doors through ${doors.provider() ?? "nothing"}`);
```

## characters

Zapisane postacie przez ai-core. Wczytane postacie przechodzą przez `online` i eksporty graczy ai-core.

### characters.setOfflinePosition

Przenosi punkt spawnu zapisanej (niewczytanej) postaci, na przykład śpiącego ciała, które zostało przeniesione. ai-core zapisuje go, gdy żaden zapis przy wczytaniu ani wyładowaniu nie trzyma postaci.

**Strona:** Serwer · **Czeka:** nie

```ts title="Sygnatura"
characters.setOfflinePosition(charId: number, position: { x: number; y: number; z: number; heading?: number }): boolean
```

Brak odpowiednika w Lua: wywołaj eksport ai-core `SetOfflinePosition(charId, position)`.

<TypeTable
  type={{
    charId: { type: "number", description: "Id postaci (`CharacterInfo.id`).", required: true },
    position: { type: "{ x: number; y: number; z: number; heading?: number }", description: "Nowy punkt spawnu; kierunek w stopniach.", required: true },
  }}
/>

**Zwraca** `true`, gdy przyjęto. `false`, gdy postać jest wczytana albo wartości są złe.

```ts
characters.setOfflinePosition(sleeperCharId, { x: 340.2, y: -1396.7, z: 32.5, heading: 50 });
```
