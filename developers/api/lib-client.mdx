```ts title="TypeScript"
import { Points, notify, progress, cache } from "@aicore-fivem/lib/client";
```

The client entry also re-exports the `/fivem` helpers (`every`, `ByResource`, `Reasons`, `caller`, `onStop`, `plateOf`, exports and locale helpers, state bag classes): see [Lib: shared and fivem](/docs/developers/api/lib-shared). The last column names the Lua twin on `aiLib` ([Lib for Lua](/docs/developers/api/lua)).

## Talking to the server

| Helper | What | Lua |
| --- | --- | --- |
| `triggerServerCallback(name, args = [], timeoutMs?): Promise<unknown>` | Asks the server (`onClientCallback` there); parse the answer. | `triggerServerCallback` |
| `onServerCallback(name, handler: (...args) => unknown): void` | Answers the server's `triggerClientCallback`. | `onServerCallback` |
| `onServerEvent(name, handler)` / `onServerEvent(name, { args }, handler)` | A net event from the server; emits that did not come from the server are dropped. `args` parses the payload. | `onServerEvent` |
| `fromServer(): boolean` | Whether the event being handled came from the server. | |
| `callAction(name, args = [], { fallback, timeout?, silent? })` | Runs a server action, shows the translated refusal itself, resolves the ok reply or null. | `callAction` |
| `isActionOk(reply)`, `replyError(reply, fallback)` | Read an `ActionResult` by hand. | |

```ts title="TypeScript"
const reply = await callAction("buy", [itemId], { fallback: "BUY_FAILED" });
if (reply) notify(t("BOUGHT"), "success");
```

| Helper | What | Lua |
| --- | --- | --- |
| `cache` | `ped`, `playerId`, `serverId`, `vehicle`, `seat`, `weapon` (`false` = none), kept by ai-core's one watcher. | `cache` |
| `onCache(key, handler: (value, old) => void): void` | Runs when a cached value changes. | `cache.onChange` |
| `readPlayerState(ped)`, `readWeapon(ped)` | A ped's vehicle, seat and weapon right now. | |
| `player.coords()`, `player.heading()`, `player.distanceTo(point)`, `player.ped()` | Position reads (from the cache). | `player` |
| `player.freeze(state: boolean)` | Freezes the ped. | `player.freeze` |
| `player.teleport(to: { x, y, z? }, { heading?, ground?, fade?, keepVehicle? }): Promise<void>` | Teleport behind a fade with collision loading; no `z` lands on the ground. | `player.teleport` |
| `player.playAnim(dict, clip, options?): Promise<void>`, `player.stopAnim()` | Plays or stops an animation. | `player.playAnim`, `player.stopAnim` |
| `player.holdAnim(dict, clip, { ...options, while? })` | Keeps an animation playing until `stop()` or `while()` is false. | |
| `fadeOut(ms = 300)`, `fadeIn(ms = 400)` | Screen fades; each resolves when done. | `fadeOut`, `fadeIn` |
| `getPlayerData(key)`, `onPlayerData(key, handler): () => void`, `seedPlayerData(data)` | ai-core's player data (`character`, `money`, `jobs`, `duty`, `job`, `gangs`, `activeGang`, `metadata`). | `playerData.get`, `playerData.onChange` |
| `hasJob(jobs, minGrade = 0)`, `inGang(gangs, minGrade = 0)`, `onDutyIn(jobs)` | Membership checks (an empty list = everyone). | |
| `onMembershipChange(fn)` | Jobs, duty or gangs changed. | |
| `allows(rule: AccessRule): boolean` | Whether the player may use a place (the server's `online.allows` decides the same). | |
| `playerPed(serverId): number` | A player's ped by server id, 0 out of scope. | `playerPed` |
| `nearestPlayer(metres, { from?, filter? }): number \| null` | The closest other player's server id. | `nearestPlayer` |

## Places and the world

| Helper | What | Lua |
| --- | --- | --- |
| `new Points()` | Every place a player uses: prompt or target (the owner's choice), NPC, blip. | `Points.new()` |
| `points.add(id, { coords, label, icon?, radius?, height?, canShow?, onPressed, onEnter?, onExit?, ped?, blip?, world?, promptOnly?, preferTarget? })` | Adds a point; `label` may be a function. | `points:add` |
| `points.addModel(id, { models, label, icon?, radius?, canShow?(entity), onPressed(entity), vehicles?, inVehicle? })` | A point on every object of some models (ATMs, chairs). | `points:addModel` |
| `points.addVehicle(id, { label, icon?, radius?, canShow?(vehicle), onPressed(vehicle) })` | A point on every networked vehicle. | `points:addVehicle` |
| `points.remove(id)`, `clear()`, `refresh(id?)`, `isInside(id)` | Manage points; `refresh` reads `canShow` again. | |
| `new Zones()`: `add(id, options)`, `remove`, `clear`, `isInside`, `size` | Areas without an interaction. | `Zones.new()` |
| `new LocalPed({ model, coords, ... })`: `entity`, `remove` | A ped only this client sees, created near the player. | `LocalPed.new()` |
| `new Blips()`: `add(id, options)`, `get`, `remove`, `clear`; `createBlip(options)` | Named blips. | `Blips.new()`, `Blips.create()` |
| `showPrompt(id, text, at?)`, `hidePrompt(id)`, `onPromptPressed(handler)` | ai-lib's prompt by hand (`Points` uses it). | `showPrompt`, `hidePrompt`, `onPromptPressed` |
| `new AdminWorld(files)`: `get`, `onChange`, `view`, `records` | The client copy of a script's `sync: "all"` panel files. | |

```ts title="TypeScript"
const points = new Points();
points.add("shop", {
  coords: { x: 25.7, y: -1347.3, z: 29.5 },
  label: t("OPEN_SHOP"),
  icon: "basket-shopping",
  blip: { sprite: 52, color: 2, scale: 0.8, label: t("SHOP") },
  onPressed: () => openShop(),
});
```

```ts title="TypeScript"
const done = await progress({
  label: t("REPAIRING"),

```
