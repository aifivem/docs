---
title: Radial menu
description: Add, remove and refresh items on whichever radial menu the server runs, with conditions, sub menus and press handlers.
icon: CircleDot
---

The radial menu is the wheel players open with a key to pick quick actions (vehicle doors, emotes, job actions). Scripts add their items to ai-core, and ai-core hands them to the radial menu the server runs: ai-radialmenu, or a supported third-party one (tgiann-radialmenu, qb-radialmenu, codem-supreme-radialmenu, ox_lib's radial).

ai-core keeps every item. When the radial menu restarts, or the server owner switches to another one, ai-core adds every item again by itself, so your script adds its items **once at start** and never has to watch the radial resource. Items are removed when the resource that added them stops.

### AddRadialItem

Adds an item to the radial menu, or replaces the item with the same id. The item's functions (`canShow`, `onPressed`) run inside your resource.

**Side:** Client · **Waits:** no

```ts title="Signature"
AddRadialItem(item: RadialItem): void
```

```lua title="Lua"
exports['ai-core']:AddRadialItem(item) -- or aiLib.radial.add(item)
```

#### RadialItem

See also [RadialItem](/docs/developers/api/types#radialitem).

<TypeTable
  type={{
    id: { type: 'string', description: 'Unique id (at most 64 characters). Adding the same id again replaces the item. Start it with your resource name (`"myscript_engine"`) so it never clashes with another script.', required: true },
    label: { type: 'string', description: 'The text on the card, already translated. Cut to 48 characters.', required: true },
    icon: { type: 'string', description: 'A Font Awesome solid icon name without `fa-` (`"car"`, `"key"`), or an image url.' },
    parent: { type: 'string', description: 'The id of the item this goes into: the built-in `"vehicle"` sub menu (constant `RADIAL_VEHICLE` in `@aifivem/shared`), or one of your own items. Left out: the main wheel.' },
    items: { type: 'RadialItem[]', description: 'Sub items: the card opens a sub menu with these. Each has its own `canShow` and `onPressed`. At most 4 levels deep.', typeDescriptionLink: '/docs/developers/api/types#radialitem' },
    canShow: { type: '() => boolean', description: 'The item shows only while this returns `true` (a job, duty, a vehicle, an item). Read each time the wheel opens, and on `RefreshRadial`. Left out: always shown.' },
    onPressed: { type: '() => void', description: 'Runs when the player picks the item.' },
    keepOpen: { type: 'boolean', description: '`true` keeps the wheel open after the press (doors, extras).', default: 'false' },
    whileDead: { type: 'boolean', description: '`true` keeps the item while the player is down. Every other item hides then.', default: 'false' },
  }}
/>

#### Returns

Nothing. An item without a text `id` or `label` is not added, and ai-core prints a warning naming your resource.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/radial.ts"
import { cache, radial } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import { Locale } from "common";

// Once at start: an engine switch in the vehicle sub menu, only for the driver.
radial.add({
  id: "myscript_engine",
  label: Locale("RADIAL_ENGINE"),
  icon: "power-off",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && cache.seat === -1,
  onPressed: () => {
    if (cache.vehicle === false) return;
    SetVehicleEngineOn(cache.vehicle, !GetIsVehicleEngineRunning(cache.vehicle), false, true);
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/radial.lua"
local Locale = aiLib.locale()

-- Once at start: an engine switch in the vehicle sub menu, only for the driver.
aiLib.radial.add({
  id = 'myscript_engine',
  label = Locale('RADIAL_ENGINE'),
  icon = 'power-off',
  parent = 'vehicle',
  canShow = function() return aiLib.cache.vehicle ~= false and aiLib.cache.seat == -1 end,
  onPressed = function()
    local vehicle = aiLib.cache.vehicle
    if not vehicle then return end
    SetVehicleEngineOn(vehicle, not GetIsVehicleEngineRunning(vehicle), false, true)
  end,
})
```
</Tab>
</Tabs>

<Callout type="warn">
`canShow` runs every time the wheel opens: keep it cheap (read `cache`, a local variable or `HasItem`), never call the server from it. Do not add the same items again when the radial menu restarts; ai-core already does that.
</Callout>

### RemoveRadialItem

Removes an item by its id.

**Side:** Client · **Waits:** no

```ts title="Signature"
RemoveRadialItem(id: string): void
```

```lua title="Lua"
exports['ai-core']:RemoveRadialItem(id) -- or aiLib.radial.remove(id)
```

#### Parameters

<TypeTable
  type={{
    id: { type: 'string', description: 'The id the item was added with. An unknown id does nothing.', required: true },
  }}
/>

#### Returns

Nothing.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/duty.ts"
import { onPlayerData, radial } from "@aifivem/lib/client";
import { Locale } from "common";

// A cuff action only while on duty as police.
onPlayerData("duty", (duty) => {
  if (duty === "police")
    radial.add({ id: "myscript_cuff", label: Locale("RADIAL_CUFF"), icon: "handcuffs", onPressed: () => ExecuteCommand("cuff") });
  else radial.remove("myscript_cuff");
});
```
</Tab>
<Tab value="Lua">
```lua title="client/duty.lua"
local Locale = aiLib.locale()

-- A cuff action only while on duty as police.
aiLib.playerData.onChange('duty', function(duty)
  if duty == 'police' then
    aiLib.radial.add({ id = 'myscript_cuff', label = Locale('RADIAL_CUFF'), icon = 'handcuffs', onPressed = function() ExecuteCommand('cuff') end })
  else
    aiLib.radial.remove('myscript_cuff')
  end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
The id is not checked against the resource that added it: removing `"myscript_cuff"` removes it whoever added it. Use ids that start with your resource name. For an item that comes and goes often, a `canShow` is simpler than adding and removing.
</Callout>

### RefreshRadial

Reads every `canShow` of an open wheel again, so items appear or disappear while the player looks at it. Call it after something a `canShow` reads has changed (the player got in a vehicle, went on duty).

**Side:** Client · **Waits:** no

```ts title="Signature"
RefreshRadial(): void
```

```lua title="Lua"
exports['ai-core']:RefreshRadial() -- or aiLib.radial.refresh()
```

#### Parameters

None.

#### Returns

Nothing. Without a running radial menu it does nothing.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/radial.ts"
import { onCache, radial } from "@aifivem/lib/client";

// Vehicle items depend on the seat: refresh when it changes.
onCache("seat", () => radial.refresh());
```
</Tab>
<Tab value="Lua">
```lua title="client/radial.lua"
-- Vehicle items depend on the seat: refresh when it changes.
aiLib.cache.onChange('seat', function() aiLib.radial.refresh() end)
```
</Tab>
</Tabs>
