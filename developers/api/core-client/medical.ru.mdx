Скрипты смерти оставляют педа лежащего игрока живым, чтобы анимировать его (лежит на земле, ползёт, last stand). Поэтому собственный `IsEntityDead` в GTA часто говорит «жив» про игрока, который лежит. **Медицинский слой** ai-core спрашивает скрипт смерти, который работает на сервере (ai-death, qbx_medical, ars_ambulancejob, qb-ambulancejob, esx_ambulancejob, tgiann-ambulance, wasabi_ambulance, osp_ambulance, brutal_ambulancejob), и даёт всем ресурсам один и тот же ответ.

### IsDead

Сообщает, лежит ли локальный игрок прямо сейчас, мёртв или в last stand, в том скрипте смерти, который работает. Используйте перед действием, которое лежащему игроку делать нельзя (открыть меню, использовать предмет, сесть в транспорт).

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
IsDead(): boolean
```

```lua title="Lua"
local down = exports['ai-core']:IsDead() -- boolean
```

#### Параметры

Нет.

#### Возвращает

`boolean`: `true`, пока игрок лежит в активном скрипте смерти. `false`, когда он на ногах или когда не работает ни один поддерживаемый скрипт смерти.

`medical.isDead()` из библиотеки (TypeScript) отвечает `true` и тогда, когда сама GTA считает педа мёртвым, что покрывает серверы без скрипта смерти. Он читает экспорт один раз, а затем следит за клиентским событием `ai-core:client:dead`, поэтому частые вызовы ничего не стоят. В Lua вспомогательной функции нет: вызывайте экспорт или следите за событием.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/phone.ts"
import { medical, notify } from "@aifivem/lib/client";
import { Locale } from "common";

RegisterCommand(
  "phone",
  () => {
    if (medical.isDead()) return notify(Locale("CANT_WHILE_DOWN"), "error");
    SetNuiFocus(true, true);
    SendNUIMessage({ action: "open" });
  },
  false,
);

// Закрыть телефон в тот момент, когда игрок падает.
medical.onChange((dead) => {
  if (!dead) return;
  SetNuiFocus(false, false);
  SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client/phone.lua"
local Locale = aiLib.locale()

-- Берётся из ai-core: прочитать один раз, затем следить за событием.
local down = exports['ai-core']:IsDead()

RegisterCommand('phone', function()
  if down then return aiLib.notify(Locale('CANT_WHILE_DOWN'), 'error') end
  SetNuiFocus(true, true)
  SendNUIMessage({ action = 'open' })
end, false)

-- Закрыть телефон в тот момент, когда игрок падает.
AddEventHandler('ai-core:client:dead', function(dead)
  down = dead
  if not dead then return end
  SetNuiFocus(false, false)
  SendNUIMessage({ action = 'close' })
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Это собственное состояние локального игрока, для того, что он видит. Серверные решения (реанимация, обыск тела, отказ в действии) проверяют серверные медицинские экспорты, а не ответ клиента.
</Callout>
