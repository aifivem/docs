Ręce w górze, wskazywanie i emotki pochodzą ze skryptu emotek. ai-core pyta ten, który działa, więc przeszukanie przez policję ("czy ma ręce w górze?") albo animacja pracy działa z każdym z nich.

Dwie listy są trzymane osobno, bo nie każdy skrypt robi obie rzeczy:

- **Gesty** (ręce w górze, wskazywanie): tgiann-emotes, codem-emotemenu, rpemotes (i rpemotes-reborn), 0r-animmenu, ai-smallresources. Odpowiada pierwszy działający w tej kolejności.
- **Emotki** (odtwarzanie po nazwie, zatrzymanie): tgiann-emotes, rpemotes (i rpemotes-reborn), scully_emotemenu, dpemotes. Odpowiada pierwszy działający w tej kolejności.

### IsHandsUp

Mówi, czy lokalny gracz ma ręce w górze, według skryptu emotek, który odpowiada na gesty.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
IsHandsUp(): boolean
```

```lua title="Lua"
local up = exports['ai-core']:IsHandsUp() -- albo aiLib.gestures.isHandsUp()
```

#### Parametry

Brak.

#### Zwraca

`boolean`: `true`, gdy ręce są w górze. `false`, gdy nie są albo gdy nie działa żaden skrypt gestów.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/rob.ts"
import { gestures, notify } from "@aicore-fivem/lib/client";
import { Locale } from "common";

RegisterCommand(
  "surrender_check",
  () => notify(Locale(gestures.isHandsUp() ? "HANDS_UP" : "HANDS_DOWN")),
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client/rob.lua"
local Locale = aiLib.locale()

RegisterCommand('surrender_check', function()
  aiLib.notify(Locale(aiLib.gestures.isHandsUp() and 'HANDS_UP' or 'HANDS_DOWN'))
end, false)
```
</Tab>
</Tabs>

<Callout type="info">
To czyta tylko **lokalnego** gracza. Aby wiedzieć, czy inny gracz ma ręce w górze (napad, przeszukanie), zapytaj serwer, który pyta klienta tego gracza.
</Callout>

### IsPointing

Mówi, czy lokalny gracz wskazuje, według skryptu emotek, który odpowiada na gesty.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
IsPointing(): boolean
```

```lua title="Lua"
local pointing = exports['ai-core']:IsPointing() -- albo aiLib.gestures.isPointing()
```

#### Parametry

Brak.

#### Zwraca

`boolean`: `true` podczas wskazywania. `false`, gdy nie wskazuje, gdy nie działa żaden skrypt gestów albo gdy działający nie umie tego stwierdzić (0r-animmenu nie ma sprawdzania wskazywania).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { gestures } from "@aicore-fivem/lib/client";

RegisterCommand("ispointing", () => console.log(gestures.isPointing()), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('ispointing', function() print(aiLib.gestures.isPointing()) end, false)
```
</Tab>
</Tabs>

### GetGestureProvider

Zwraca nazwę zasobu skryptu emotek, który odpowiada na ręce w górze i wskazywanie.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
GetGestureProvider(): string | null
```

```lua title="Lua"
local provider = exports['ai-core']:GetGestureProvider() -- albo aiLib.gestures.provider()
```

#### Parametry

Brak.

#### Zwraca

`string`: nazwa zasobu (`"tgiann-emotes"`). `null`, gdy nie działa żaden z obsługiwanych skryptów.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { gestures } from "@aicore-fivem/lib/client";

// Używaj własnego klawisza rąk w górze tylko wtedy, gdy żaden skrypt emotek go nie oferuje.
if (gestures.provider() === null) console.log("no gesture script, enabling my own hands-up key");
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
-- Używaj własnego klawisza rąk w górze tylko wtedy, gdy żaden skrypt emotek go nie oferuje.
if aiLib.gestures.provider() == nil then print('no gesture script, enabling my own hands-up key') end
```
</Tab>
</Tabs>

### PlayEmote

Odtwarza emotkę działającego skryptu emotek po jej nazwie komendy, czyli nazwie, którą gracze wpisują po `/e` (`"sit"`, `"notepad"`).

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
PlayEmote(name: string): boolean
```

```lua title="Lua"
local played = exports['ai-core']:PlayEmote(name) -- albo aiLib.gestures.playEmote(name)
```

#### Parametry

<TypeTable
  type={{
    name: { type: 'string', description: 'Nazwa komendy emotki: od 1 do 32 liter, cyfr, `_` lub `-`. Nazwy różnią się między skryptami emotek; używaj popularnych albo pozwól właścicielowi serwera ustawić nazwę.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy nazwa jest poprawna i skrypt emotek został poproszony o jej odtworzenie. `false` dla niepoprawnej nazwy albo gdy nie działa żaden skrypt emotek. `true` nie dowodzi, że emotka istnieje w tym skrypcie: nieznana nazwa po prostu niczego nie odtwarza.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/notes.ts"
import { gestures, progress } from "@aicore-fivem/lib/client";
import { Locale } from "common";

// Pisze notatkę z emotką notatnika, dopóki trwa pasek.
export async function writeNote(): Promise<boolean> {
  gestures.playEmote("notepad");
  const done = await progress({ label: Locale("WRITING"), duration: 5000, canCancel: true });
  gestures.cancelEmote();
  return done;
}
```
</Tab>
<Tab value="Lua">
```lua title="client/notes.lua"
local Locale = aiLib.locale()

-- Pisze notatkę z emotką notatnika, dopóki trwa pasek (wywołuj z wątku).
local function writeNote()
  aiLib.gestures.playEmote('notepad')
  local done = aiLib.progress({ label = Locale('WRITING'), duration = 5000, canCancel = true })
  aiLib.gestures.cancelEmote()
  return done
end
```
</Tab>
</Tabs>

### CancelEmote

Zatrzymuje emotkę, którą odtwarza lokalny gracz, w działającym skrypcie emotek. Używaj tego, gdy twój skrypt potrzebuje rąk gracza (skuwanie, powalenie, minigra).

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
CancelEmote(): boolean
```

```lua title="Lua"
local stopped = exports['ai-core']:CancelEmote() -- albo aiLib.gestures.cancelEmote()
```

#### Parametry

Brak.

#### Zwraca

`boolean`: `true`, gdy skrypt emotek został poproszony o zatrzymanie (także gdy nic nie było odtwarzane), `false`, gdy nie działa żaden skrypt emotek.

#### Przykład

Zobacz przykład [PlayEmote](#playemote).

### GetEmoteProvider

Zwraca nazwę zasobu skryptu emotek, który odtwarza emotki po nazwie.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
GetEmoteProvider(): string | null
```

```lua title="Lua"
local provider = exports['ai-core']:GetEmoteProvider() -- albo aiLib.gestures.emoteProvider()
```

#### Parametry

Brak.

#### Zwraca

`string`: nazwa zasobu (`"rpemotes"`). `null`, gdy nie działa żaden z obsługiwanych skryptów emotek.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { gestures, player } from "@aicore-fivem/lib/client";

// Preferuj skrypt emotek serwera, w przeciwnym razie zwykła animacja.
export function sitDown(): void {
  if (gestures.emoteProvider() !== null) gestures.playEmote("sit");
  else void player.playAnim("anim@amb@business@bgen@bgen_no_work@", "sit_phone_phoneputdown_idle_nowork");
}
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
-- Preferuj skrypt emotek serwera, w przeciwnym razie zwykła animacja (wywołuj z wątku).
local function sitDown()
  if aiLib.gestures.emoteProvider() ~= nil then
    aiLib.gestures.playEmote('sit')
  else
    aiLib.player.playAnim('anim@amb@business@bgen@bgen_no_work@', 'sit_phone_phoneputdown_idle_nowork')
  end
end
```
</Tab>
