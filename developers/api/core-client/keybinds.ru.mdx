ai-core отслеживает каждую клавишу, которую скрипты регистрируют через `Keybind` из библиотеки (TypeScript) или `aiLib.Keybind` (Lua). Благодаря этому вкладка Keybinds в админ-панели может менять клавишу скрипта по умолчанию, HUD могут показывать список подсказок клавиш слева на экране, а экран клавиш может показать каждую клавишу с действием.

**Подсказка клавиши** - это короткая строка в HUD: клавиша и что она делает (`E  Open trunk`). Привязки могут объявить её своей опцией `hint`. Скрипт также может показывать подсказки какое-то время через `ShowKeyHint`, например управление инструментом, пока он используется.

### GetKeybindKey

Возвращает клавишу, с которой был зарегистрирован `Keybind` библиотеки: клавишу, которую владелец сервера задал во вкладке Keybinds админ-панели, иначе собственную клавишу скрипта по умолчанию. Игрок всё ещё мог изменить её в настройках клавиш GTA; чтобы узнать клавишу, которую он действительно нажимает, читайте `Keybind.currentKey` у своей привязки.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
GetKeybindKey(name: string): string | null
```

```lua title="Lua"
local key = exports['ai-core']:GetKeybindKey(name) -- string или nil
```

#### Параметры

<TypeTable
  type={{
    name: { type: 'string', description: '`name` привязки в том виде, в каком скрипт передал его в `Keybind` (`"myscript_open"`).', required: true },
  }}
/>

#### Возвращает

`string`: клавиша в верхнем регистре (`"F5"`, `"E"`) или `""` для привязки без клавиши по умолчанию. `null`, пока ai-core не ответил по этой привязке (вскоре после старта её ресурса), и для имён, которые не зарегистрировал ни один запущенный ресурс.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { Keybind, resourceExport } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

const open = new Keybind({
  name: "myscript_open",
  description: Locale("KEY_OPEN"),
  defaultKey: "F5",
  onPressed: () => console.log("open"),
});

RegisterCommand(
  "myscript_keys",
  () => {
    console.log(`registered with: ${core.GetKeybindKey("myscript_open") ?? "not yet"}`);
    console.log(`the player presses: ${open.currentKey}`);
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

aiLib.Keybind.new({
  name = 'myscript_open',
  description = Locale('KEY_OPEN'),
  defaultKey = 'F5',
  onPressed = function() print('open') end,
})

RegisterCommand('myscript_keys', function()
  print(('registered with: %s'):format(exports['ai-core']:GetKeybindKey('myscript_open') or 'not yet'))
end, false)
```
</Tab>
</Tabs>

### ShowKeyHint

Показывает подсказку клавиши вашего ресурса в списке подсказок HUD, пока вы её не скроете. Используйте для клавиш, которые важны лишь какое-то время: управление инструментом, мини-игра, режим камеры. Клавиши, которые ваши привязки предлагают всегда, относятся к опции `hint` у `Keybind`.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
ShowKeyHint(id: string, hint: KeyHintRequest): void
```

```lua title="Lua"
exports['ai-core']:ShowKeyHint(id, hint) -- или aiLib.keyHints.show(id, hint)
```

#### Параметры

<TypeTable
  type={{
    id: { type: 'string', description: 'Ваше имя для этой подсказки (`"camera_zoom"`). Повторный показ того же id заменяет подсказку. Id свои у каждого ресурса, поэтому `camera_zoom` другого скрипта - это другая подсказка.', required: true },
    hint: { type: 'KeyHintRequest', description: 'Что показывает строка. Поля ниже.', required: true, typeDescriptionLink: '/ru/docs/developers/api/types#keyhintrequest' },
  }}
/>

#### KeyHintRequest

См. также [KeyHintRequest](/ru/docs/developers/api/types#keyhintrequest).

<TypeTable
  type={{
    label: { type: 'string', description: 'Что делает клавиша, уже переведено (`Locale("HINT_ZOOM")`). Обрезается до 60 символов.', required: true },
    keybind: { type: 'string', description: '`name` привязки: подсказка показывает клавишу, которую игрок сейчас на неё назначил, и следует за ней при переназначении. Важнее `key`.' },
    key: { type: 'string', description: 'Буквальный текст клавиши (`"SCROLL"`, `"SHIFT"`), когда за ней не стоит привязка. Обрезается до 16 символов.' },
    icon: { type: 'string', description: 'Имя иконки Font Awesome solid без `fa-` (`"magnifying-glass"`). HUD рисуют значок клавиши, если не знают её. Обрезается до 32 символов.' },
  }}
/>

#### Возвращает

Ничего. Подсказка без текстового `label` или с нестроковым `id` игнорируется. Подсказка, у которой клавиша ни во что не разрешается (ни `keybind`, ни `key` не дают клавиши), сохраняется, но не выводится в списке.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/camera.ts"
import { keyHints } from "@aicore-fivem/lib/client";
import { Locale } from "common";

export function startCamera(): void {
  keyHints.show("camera_zoom", { label: Locale("HINT_ZOOM"), key: "SCROLL", icon: "magnifying-glass" });
  keyHints.show("camera_exit", { label: Locale("HINT_EXIT"), keybind: "myscript_camera" });
}

export function stopCamera(): void {
  keyHints.hide("camera_zoom");
  keyHints.hide("camera_exit");
}
```
</Tab>
<Tab value="Lua">
```lua title="client/camera.lua"
local Locale = aiLib.locale()

local function startCamera()
  aiLib.keyHints.show('camera_zoom', { label = Locale('HINT_ZOOM'), key = 'SCROLL', icon = 'magnifying-glass' })
  aiLib.keyHints.show('camera_exit', { label = Locale('HINT_EXIT'), keybind = 'myscript_camera' })
end

local function stopCamera()
  aiLib.keyHints.hide('camera_zoom')
  aiLib.keyHints.hide('camera_exit')
end
```
</Tab>
</Tabs>

<Callout type="info">
Подсказки выводятся в том порядке, в котором скрипты их показали, после подсказок, объявленных привязками. Подсказки вашего ресурса удаляются, когда он останавливается.
</Callout>

### HideKeyHint

Скрывает одну подсказку клавиши, которую показал ваш ресурс.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
HideKeyHint(id: string): void
```

```lua title="Lua"
exports['ai-core']:HideKeyHint(id) -- или aiLib.keyHints.hide(id)
```

#### Параметры

<TypeTable
  type={{
    id: { type: 'string', description: 'Id, который вы передали в `ShowKeyHint`. Id, который ваш ресурс никогда не показывал, ничего не делает.', required: true },
  }}
/>

#### Возвращает

Ничего.

#### Пример

См. пример [ShowKeyHint](#showkeyhint).

### GetKeyHints

Возвращает строки подсказок клавиш, которые HUD должны показывать прямо сейчас: подсказки, объявленные привязками для текущей ситуации игрока (пешком или в транспорте, как владелец сервера задал их в панели), плюс подсказки, которые показывают скрипты. HUD читает это один раз при старте, а затем следит за клиентским событием `ai-core:client:keyHints`, которое несёт тот же список после каждого изменения.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
GetKeyHints(): KeyHintView[]
```

```lua title="Lua"
local hints = exports['ai-core']:GetKeyHints() -- массив { id, key, label, icon? }
```

#### Параметры

Нет.

#### Возвращает

[`KeyHintView[]`](/ru/docs/developers/api/types#keyhintview) в порядке отображения. Пустой массив, когда ни одна подсказка не подходит.

<TypeTable
  type={{
    id: { type: 'string', description: 'Имя привязки или `<resource>:<id>` для подсказки, которую показал скрипт.', required: true },
    key: { type: 'string', description: 'Клавиша, как игрок назначил её сейчас (`"E"`, `"F5"`).', required: true },
    label: { type: 'string', description: 'Что она делает, уже переведено.', required: true },
    icon: { type: 'string', description: 'Имя иконки Font Awesome solid без `fa-`; отсутствует, если не задано.' },
  }}
/>

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hints.ts"
import { resourceExport } from "@aicore-fivem/lib/client";
import { KEY_HINTS, type KeyHintView } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Список подсказок клавиш своего HUD.
function draw(hints: KeyHintView[]): void {
  SendNUIMessage({ action: "keyHints", data: hints });
}

draw(core.GetKeyHints());
on(KEY_HINTS.changedEvent, draw);
```
</Tab>
<Tab value="Lua">
```lua title="client/hints.lua"
-- Список подсказок клавиш своего HUD.
local function draw(hints)
  SendNUIMessage({ action = 'keyHints', data = hints })
end

draw(exports['ai-core']:GetKeyHints())
AddEventHandler('ai-core:client:keyHints', draw)
```
</Tab>
</Tabs>

### OpenKeyboard

Открывает экран клавиш ai-core: клавиатуру, на которой подсвечена каждая клавиша с действием, а под ней написано, что она делает. Клавиши показаны так, как игрок назначил их сейчас. Его открывает пункт Keys в радиальном меню; может любой скрипт. Пока он открыт, HUD скрыты.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
OpenKeyboard(): void
```

```lua title="Lua"
exports['ai-core']:OpenKeyboard()
```

#### Параметры

Нет.

#### Возвращает

Ничего. Вызов, когда экран уже открыт, ничего не делает. Игрок закрывает его на самом экране.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aicore-fivem/lib/client";

const core = resourceExport("ai-core");

RegisterCommand("keys", () => core.OpenKeyboard(), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('keys', function() exports['ai-core']:OpenKeyboard() end, false)
```
</Tab>
</Tabs>
