Когда ваш скрипт открывает полноэкранный интерфейс (магазин, телефон, фоторежим), HUD должен уйти с дороги. Эти экспорты скрывают и показывают тот HUD, который работает на сервере: ai-hud или сторонний HUD, известный ai-core (tgiann-lumihud, tgiann-hudv2, tgiann-modern-hud, tgiann-statushud, jg-hud, 0r-hud-v3, codem-supreme-hud, Codem-BlackHUDV2, wais-hudv6, qb-hud, ps-hud). Если известного HUD нет, ai-core скрывает и показывает мини-карту. qb-hud и ps-hud нельзя скрыть из другого скрипта: с ними следует только мини-карта.

Скрытие работает с **причинами**. Каждый ресурс скрывает HUD под выбранным им именем (`"shop"`, `"photo-mode"`). HUD остаются скрытыми, пока хотя бы один ресурс задал причину, поэтому два одновременно открытых экрана никогда не мешают друг другу: HUD возвращается только после закрытия обоих. Причины принадлежат ресурсу, который их задал, и удаляются, когда он останавливается.

### HideHud

Скрывает все HUD (и мини-карту, когда известный HUD не работает) под причиной вашего ресурса. Вызывайте, когда открывается ваш полноэкранный интерфейс.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
HideHud(reason: string): void
```

```lua title="Lua"
exports['ai-core']:HideHud(reason) -- или aiLib.hud.hide(reason)
```

#### Параметры

<TypeTable
  type={{
    reason: { type: 'string', description: 'Название причины скрытия (`"shop"`). Снять её может только ваш ресурс. Повторное скрытие под тем же именем ничего не меняет.', required: true },
  }}
/>

#### Возвращает

Ничего. `reason`, который не является строкой, игнорируется.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/shop.ts"
import { hud } from "@aicore-fivem/lib/client";

export function openShop(): void {
  hud.hide("shop"); // то же, что resourceExport("ai-core").HideHud("shop")
  SetNuiFocus(true, true);
  SendNUIMessage({ action: "open" });
}

RegisterNuiCallback("close", (_data: unknown, cb: (r: unknown) => void) => {
  SetNuiFocus(false, false);
  hud.show("shop");
  cb(true);
});
```
</Tab>
<Tab value="Lua">
```lua title="client/shop.lua"
local function openShop()
  aiLib.hud.hide('shop') -- то же, что exports['ai-core']:HideHud('shop')
  SetNuiFocus(true, true)
  SendNUIMessage({ action = 'open' })
end

RegisterNUICallback('close', function(_, cb)
  SetNuiFocus(false, false)
  aiLib.hud.show('shop')
  cb(true)
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Каждому `HideHud` нужен свой `ShowHud` с той же причиной. ai-core убирает за ресурсом, который остановился, но не за тем, который продолжает работать и забывает вызвать `ShowHud`: тогда HUD так и остаётся скрытым у этого игрока.
</Callout>

### ShowHud

Снимает одну причину скрытия вашего ресурса. HUD возвращаются, когда ни у одного ресурса не осталось причин.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
ShowHud(reason: string): void
```

```lua title="Lua"
exports['ai-core']:ShowHud(reason) -- или aiLib.hud.show(reason)
```

#### Параметры

<TypeTable
  type={{
    reason: { type: 'string', description: 'Имя, которое вы передали в `HideHud`. Имя, которое ваш ресурс никогда не задавал, ничего не делает; причина другого ресурса с тем же именем не затрагивается.', required: true },
  }}
/>

#### Возвращает

Ничего.

#### Пример

См. пример [HideHud](#hidehud).

### IsHudVisible

Сообщает, видны ли HUD прямо сейчас, то есть ни один ресурс не задал причину скрытия. Ресурс HUD использует это при старте; после этого он следит за клиентским событием `ai-core:client:hudVisible`.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
IsHudVisible(): boolean
```

```lua title="Lua"
local visible = exports['ai-core']:IsHudVisible() -- или aiLib.hud.visible()
```

#### Параметры

Нет.

#### Возвращает

`boolean`: `true`, когда не задано ни одной причины скрытия, `false`, пока задана хотя бы одна.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { hud } from "@aicore-fivem/lib/client";

// Свой HUD: стартовать в правильном состоянии, затем следить за каждым изменением.
function setVisible(visible: boolean): void {
  SendNUIMessage({ action: "visible", data: visible });
}

setVisible(hud.visible);
hud.onChange(setVisible);
```
</Tab>
<Tab value="Lua">
```lua title="client/hud.lua"
-- Свой HUD: стартовать в правильном состоянии, затем следить за каждым изменением.
local function setVisible(visible)
  SendNUIMessage({ action = 'visible', data = visible })
end

setVisible(aiLib.hud.visible())
AddEventHandler('ai-core:client:hudVisible', setVisible)
```
</Tab>
</Tabs>

### OpenHudSettings

Открывает собственный экран настроек запущенного HUD (например, `/hud` у ai-hud или tgiann-lumihud). Его использует пункт HUD в радиальном меню; может любой скрипт.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
OpenHudSettings(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenHudSettings() -- boolean
```

#### Параметры

Нет.

#### Возвращает

`boolean`: `true`, когда у запущенного HUD есть экран настроек и он получил запрос на открытие. `false`, когда известный HUD не работает или у запущенного нет экрана настроек.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify, resourceExport } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

RegisterCommand(
  "hudsettings",
  () => {
    if (!core.OpenHudSettings()) notify(Locale("NO_HUD_SETTINGS"), "error");
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

RegisterCommand('hudsettings', function()
  if not exports['ai-core']:OpenHudSettings() then
    aiLib.notify(Locale('NO_HUD_SETTINGS'), 'error')
  end
end, false)
```
</Tab>
</Tabs>

### HasHudSettings

Сообщает, есть ли у запущенного HUD экран настроек, чтобы можно было показать или скрыть кнопку «HUD settings».

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
HasHudSettings(): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasHudSettings() -- boolean
```

#### Параметры

Нет.

#### Возвращает

`boolean`: `true`, когда работает известный HUD и у него есть экран настроек, иначе `false`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/menu.ts"
import { radial, resourceExport } from "@aicore-fivem/lib/client";

const core = resourceExport("ai-core");

// Пункт радиального меню, который виден, только когда у HUD есть настройки для открытия.
radial.add({
  id: "myscript_hud",
  label: "HUD",
  icon: "sliders",
  canShow: () => core.HasHudSettings(),
  onPressed: () => void core.OpenHudSettings(),
});
```
</Tab>
<Tab value="Lua">
```lua title="client/menu.lua"
-- Пункт радиального меню, который виден, только когда у HUD есть настройки для открытия.
aiLib.radial.add({
  id = 'myscript_hud',
  label = 'HUD',
  icon = 'sliders',
  canShow = function() return exports['ai-core']:HasHudSettings() end,
  onPressed = function() exports['ai-core']:OpenHudSettings() end,
})
```
</Tab>
</Tabs>
