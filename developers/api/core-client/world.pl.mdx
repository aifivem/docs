Skrypt pogody (ai-weathersync albo zewnętrzny) trzyma każdego gracza na pogodzie i zegarze serwera. Gdy twój skrypt potrzebuje własnej pogody lub czasu na ekranie jednego gracza (ciemne wnętrze, kreator postaci, przerywnik), najpierw wstrzymaj synchronizację, w przeciwnym razie skrypt pogody chwilę później nadpisze twoje wartości.

Wstrzymywanie działa na **powodach**, jak w HUD: synchronizacja zostaje wstrzymana, dopóki ustawiony jest co najmniej jeden powód, i działa znowu, gdy ostatni zostanie wyczyszczony. Powody należą do zasobu, który je ustawił, i są usuwane, gdy się zatrzymuje. ai-core informuje skrypt pogody przez własne klienckie zdarzenie `ai-core:client:worldSync` oraz przez popularne zdarzenia wstrzymania, których nasłuchują zewnętrzne skrypty pogody (qb-weathersync, cd_easytime, vSync, av_weather). W drugą stronę, gdy skrypt sam wysyła jedno z tych zdarzeń, ai-core też liczy je jako powód, więc wznowienie jednego skryptu nigdy nie kończy wstrzymania innego.

### PauseWorldSync

Wstrzymuje synchronizację pogody i czasu w grze tego gracza pod powodem twojego zasobu.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
PauseWorldSync(reason: string): void
```

```lua title="Lua"
exports['ai-core']:PauseWorldSync(reason) -- albo aiLib.world.pauseSync(reason)
```

#### Parametry

<TypeTable
  type={{
    reason: { type: 'string', description: 'Nazwa tego, dlaczego ją wstrzymujesz (`"interior"`). Tylko twój zasób może ją wyczyścić. Ponowne wstrzymanie pod tą samą nazwą niczego nie zmienia.', required: true },
  }}
/>

#### Zwraca

Nic. `reason`, który nie jest stringiem, jest ignorowany.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/interior.ts"
import { world } from "@aicore-fivem/lib/client";

// Ciemna, bezchmurna noc we własnym wnętrzu, powrót do pogody serwera przy wyjściu.
export function enterInterior(): void {
  world.pauseSync("interior"); // to samo co resourceExport("ai-core").PauseWorldSync("interior")
  NetworkOverrideClockTime(23, 0, 0);
  SetWeatherTypeNowPersist("CLEAR");
}

export function leaveInterior(): void {
  NetworkClearClockTimeOverride();
  world.resumeSync("interior");
}
```
</Tab>
<Tab value="Lua">
```lua title="client/interior.lua"
-- Ciemna, bezchmurna noc we własnym wnętrzu, powrót do pogody serwera przy wyjściu.
local function enterInterior()
  aiLib.world.pauseSync('interior') -- to samo co exports['ai-core']:PauseWorldSync('interior')
  NetworkOverrideClockTime(23, 0, 0)
  SetWeatherTypeNowPersist('CLEAR')
end

local function leaveInterior()
  NetworkClearClockTimeOverride()
  aiLib.world.resumeSync('interior')
end
```
</Tab>
</Tabs>

<Callout type="warn">
Wstrzymanie tylko zatrzymuje synchronizację. Ustawienie własnej pogody i czasu oraz ich wyczyszczenie po skończeniu to zadanie twojego skryptu.
</Callout>

### ResumeWorldSync

Czyści jeden powód wstrzymania twojego zasobu. Synchronizacja działa znowu, a skrypt pogody przywraca pogodę i zegar serwera, gdy nie zostaje żaden powód.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
ResumeWorldSync(reason: string): void
```

```lua title="Lua"
exports['ai-core']:ResumeWorldSync(reason) -- albo aiLib.world.resumeSync(reason)
```

#### Parametry

<TypeTable
  type={{
    reason: { type: 'string', description: 'Nazwa, którą podałeś do `PauseWorldSync`. Nazwa, której twój zasób nigdy nie ustawił, nic nie robi.', required: true },
  }}
/>

#### Zwraca

Nic.

#### Przykład

Zobacz przykład [PauseWorldSync](#pauseworldsync).

### IsWorldSyncPaused

Mówi, czy synchronizacja jest teraz wstrzymana przez dowolny zasób lub zewnętrzne zdarzenie wstrzymania. Skrypt pogody, który startuje później, czyta to raz; potem śledzi klienckie zdarzenie `ai-core:client:worldSync`.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
IsWorldSyncPaused(): boolean
```

```lua title="Lua"
local paused = exports['ai-core']:IsWorldSyncPaused() -- boolean
```

#### Parametry

Brak.

#### Zwraca

`boolean`: `true`, dopóki ustawiony jest co najmniej jeden powód, `false`, gdy synchronizacja działa.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/weather.ts"
import { resourceExport } from "@aicore-fivem/lib/client";
import { CORE } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Własny skrypt pogody: przestań stosować pogodę serwera, dopóki synchronizacja jest wstrzymana.
let paused = core.IsWorldSyncPaused();
on(CORE.clientWorldSyncEvent, (value: boolean) => {
  paused = value;
});

export const shouldApplyWeather = (): boolean => !paused;
```
</Tab>
<Tab value="Lua">
```lua title="client/weather.lua"
-- Własny skrypt pogody: przestań stosować pogodę serwera, dopóki synchronizacja jest wstrzymana.
local paused = exports['ai-core']:IsWorldSyncPaused()
AddEventHandler('ai-core:client:worldSync', function(value) paused = value end)

function ShouldApplyWeather() return not paused end
```
</Tab>
</Tabs>
