ai-core suit chaque touche que les scripts enregistrent avec `Keybind` de la lib (TypeScript) ou `aiLib.Keybind` (Lua). C’est ainsi que l’onglet Keybinds du panneau d’administration peut changer la touche par défaut d’un script, que les HUD peuvent lister des aides de touches à gauche de l’écran, et que l’écran des touches peut montrer chaque touche associée à une action.

Une **aide de touche** est une courte ligne sur le HUD : une touche et ce qu’elle fait (`E  Open trunk`). Les raccourcis peuvent en déclarer une avec leur option `hint`. Un script peut aussi afficher des aides pendant un moment avec `ShowKeyHint`, par exemple les commandes d’un outil pendant son utilisation.

### GetKeybindKey

Renvoie la touche avec laquelle un `Keybind` de la lib a été enregistré : la touche que le propriétaire du serveur a définie dans l’onglet Keybinds du panneau d’administration, sinon la touche par défaut du script. Le joueur peut encore l’avoir changée dans les réglages de touches de GTA ; pour la touche qu’il presse vraiment, lisez plutôt `Keybind.currentKey` sur votre raccourci.

**Côté :** Client · **Attend :** non

```ts title="Signature"
GetKeybindKey(name: string): string | null
```

```lua title="Lua"
local key = exports['ai-core']:GetKeybindKey(name) -- string ou nil
```

#### Paramètres

<TypeTable
  type={{
    name: { type: 'string', description: 'Le `name` du raccourci tel que le script l’a passé à `Keybind` (`"myscript_open"`).', required: true },
  }}
/>

#### Retour

`string` : la touche en majuscules (`"F5"`, `"E"`), ou `""` pour un raccourci sans touche par défaut. `null` tant qu’ai-core n’a pas répondu à ce raccourci (peu après le démarrage de sa ressource) et pour les noms qu’aucune ressource en cours n’a enregistrés.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { Keybind, resourceExport } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

const open = new Keybind({
  name: "myscript_open",
  description: Locale("KEY_OPEN"),
  defaultKey: "F5",
  onPressed: () => console.log("open"),
});

RegisterCommand(
  "myscript_keys",
  () => {
    console.log(`registered with: ${core.GetKeybindKey("myscript_open") ?? "not yet"}`);
    console.log(`the player presses: ${open.currentKey}`);
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

aiLib.Keybind.new({
  name = 'myscript_open',
  description = Locale('KEY_OPEN'),
  defaultKey = 'F5',
  onPressed = function() print('open') end,
})

RegisterCommand('myscript_keys', function()
  print(('registered with: %s'):format(exports['ai-core']:GetKeybindKey('myscript_open') or 'not yet'))
end, false)
```
</Tab>
</Tabs>

### ShowKeyHint

Affiche une aide de touche de votre ressource dans la liste d’aides du HUD jusqu’à ce que vous la masquiez. Utilisez-la pour les touches qui ne comptent que pendant un moment : les commandes d’un outil, un mini-jeu, un mode caméra. Les touches que vos raccourcis offrent en permanence vont plutôt dans l’option `hint` du `Keybind`.

**Côté :** Client · **Attend :** non

```ts title="Signature"
ShowKeyHint(id: string, hint: KeyHintRequest): void
```

```lua title="Lua"
exports['ai-core']:ShowKeyHint(id, hint) -- ou aiLib.keyHints.show(id, hint)
```

#### Paramètres

<TypeTable
  type={{
    id: { type: 'string', description: 'Votre nom pour cette aide (`"camera_zoom"`). Afficher de nouveau le même id remplace l’aide. Les ids sont propres à chaque ressource, donc le `camera_zoom` d’un autre script est une aide différente.', required: true },
    hint: { type: 'KeyHintRequest', description: 'Ce qu’affiche la ligne. Champs ci-dessous.', required: true, typeDescriptionLink: '/fr/docs/developers/api/types#keyhintrequest' },
  }}
/>

#### KeyHintRequest

Voir aussi [KeyHintRequest](/fr/docs/developers/api/types#keyhintrequest).

<TypeTable
  type={{
    label: { type: 'string', description: 'Ce que fait la touche, déjà traduit (`Locale("HINT_ZOOM")`). Coupé à 60 caractères.', required: true },
    keybind: { type: 'string', description: 'Le `name` d’un raccourci : l’aide montre la touche que le joueur y a associée maintenant, et suit s’il la réassigne. L’emporte sur `key`.' },
    key: { type: 'string', description: 'Un texte de touche littéral (`"SCROLL"`, `"SHIFT"`) quand aucun raccourci n’est derrière. Coupé à 16 caractères.' },
    icon: { type: 'string', description: 'Un nom d’icône Font Awesome solid sans `fa-` (`"magnifying-glass"`). Les HUD dessinent une icône de touche quand ils ne la connaissent pas. Coupé à 32 caractères.' },
  }}
/>

#### Retour

Rien. Une aide sans texte `label`, ou un `id` qui n’est pas une chaîne, est ignorée. Une aide dont la touche ne se résout en rien (ni `keybind` ni `key` ne donne de touche) est gardée mais pas listée.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/camera.ts"
import { keyHints } from "@aicore-fivem/lib/client";
import { Locale } from "common";

export function startCamera(): void {
  keyHints.show("camera_zoom", { label: Locale("HINT_ZOOM"), key: "SCROLL", icon: "magnifying-glass" });
  keyHints.show("camera_exit", { label: Locale("HINT_EXIT"), keybind: "myscript_camera" });
}

export function stopCamera(): void {
  keyHints.hide("camera_zoom");
  keyHints.hide("camera_exit");
}
```
</Tab>
<Tab value="Lua">
```lua title="client/camera.lua"
local Locale = aiLib.locale()

local function startCamera()
  aiLib.keyHints.show('camera_zoom', { label = Locale('HINT_ZOOM'), key = 'SCROLL', icon = 'magnifying-glass' })
  aiLib.keyHints.show('camera_exit', { label = Locale('HINT_EXIT'), keybind = 'myscript_camera' })
end

local function stopCamera()
  aiLib.keyHints.hide('camera_zoom')
  aiLib.keyHints.hide('camera_exit')
end
```
</Tab>
</Tabs>

<Callout type="info">
Les aides sont listées dans l’ordre où les scripts les ont affichées, après les aides que déclarent les raccourcis. Les aides de votre ressource sont retirées quand elle s’arrête.
</Callout>

### GetKeyHints

Renvoie les lignes d’aide de touches que les HUD doivent afficher en ce moment : les aides que déclarent les raccourcis pour la situation du joueur (à pied ou en véhicule, comme le propriétaire du serveur les a réglées dans le panneau) plus les aides qu’affichent les scripts. Un HUD la lit une fois au démarrage puis suit l’événement client `ai-core:client:keyHints`, qui transporte la même liste après chaque changement.

**Côté :** Client · **Attend :** non

```ts title="Signature"
GetKeyHints(): KeyHintView[]
```

```lua title="Lua"
local hints = exports['ai-core']:GetKeyHints() -- tableau de { id, key, label, icon? }
```

#### Paramètres

Aucun.

#### Retour

[`KeyHintView[]`](/fr/docs/developers/api/types#keyhintview), dans l’ordre d’affichage. Un tableau vide quand aucune aide ne s’applique.

<TypeTable
  type={{
    id: { type: 'string', description: 'Le nom du raccourci, ou `<resource>:<id>` pour une aide qu’un script a affichée.', required: true },
    key: { type: 'string', description: 'La touche telle que le joueur l’a associée maintenant (`"E"`, `"F5"`).', required: true },
    label: { type: 'string', description: 'Ce qu’elle fait, déjà traduit.', required: true },
    icon: { type: 'string', description: 'Nom d’icône Font Awesome solid sans `fa-` ; absent quand aucun n’a été donné.' },
  }}
/>

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hints.ts"
import { resourceExport } from "@aicore-fivem/lib/client";
import { KEY_HINTS, type KeyHintView } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// La liste d’aides de touches d’un HUD personnalisé.
function draw(hints: KeyHintView[]): void {
  SendNUIMessage({ action: "keyHints", data: hints });
}

draw(core.GetKeyHints());
on(KEY_HINTS.changedEvent, draw);
```
</Tab>
<Tab value="Lua">
```lua title="client/hints.lua"
-- La liste d’aides de touches d’un HUD personnalisé.
local function draw(hints)
  SendNUIMessage({ action = 'keyHints', data = hints })
end

draw(exports['ai-core']:GetKeyHints())
AddEventHandler('ai-core:client:keyHints', draw)
```
</Tab>
</Tabs>

### OpenKeyboard

Ouvre l’écran des touches d’ai-core : un clavier où chaque touche qui a une action est colorée, avec ce que fait chaque touche en dessous. Les touches sont montrées telles que le joueur les a associées maintenant. L’entrée Keys du menu radial l’ouvre ; n’importe quel script le peut. Tant qu’il est ouvert, les HUD sont masqués.

**Côté :** Client · **Attend :** non

```ts title="Signature"
OpenKeyboard(): void
```

```lua title="Lua"
exports['ai-core']:OpenKeyboard()
```

#### Paramètres

Aucun.

#### Retour

Rien. L’appeler alors que l’écran est déjà ouvert ne fait rien. Le joueur le ferme dans l’écran.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aicore-fivem/lib/client";

const core = resourceExport("ai-core");

RegisterCommand("keys", () => core.OpenKeyboard(), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('keys', function() exports['ai-core']:OpenKeyboard() end, false)
```
</Tab>
</Tabs>
