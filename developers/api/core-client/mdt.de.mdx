Das MDT (Mobile Data Terminal) ist der Polizeicomputer: Akten, Haftbefehle, Berichte. Die **MDT-Ebene** von ai-core öffnet das, das der Server nutzt, sodass ein Radial-Eintrag, eine Taste oder ein Fahrzeug-Laptop in deinem Skript den richtigen Bildschirm öffnet. Unterstützte MDTs, die von einem anderen Skript geöffnet werden können: tgiann-mdt, ps-mdt, wasabi_mdt.

### OpenMdt

Öffnet den Bildschirm des aktiven MDT für den lokalen Spieler. Das MDT prüft den Job des Spielers selbst und weist einen Spieler ab, der es nicht nutzen darf.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
OpenMdt(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenMdt() -- oder aiLib.mdt.open()
```

#### Parameter

Keine.

#### Rückgabe

`boolean`: `true`, wenn das aktive MDT zum Öffnen aufgefordert wurde. `false`, wenn kein unterstütztes MDT läuft oder das laufende nicht von einem anderen Skript aus geöffnet werden kann. `true` bedeutet nicht, dass der Bildschirm angezeigt wurde: Das MDT kann den Job des Spielers trotzdem ablehnen.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/laptop.ts"
import { cache, getPlayerData, mdt, notify, radial } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import { Locale } from "common";

// Ein Laptop-Eintrag im Fahrzeug-Untermenü für Polizei im Dienst.
radial.add({
  id: "myscript_mdt",
  label: Locale("RADIAL_MDT"),
  icon: "laptop",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && getPlayerData("duty") === "police",
  onPressed: () => {
    if (!mdt.open()) notify(Locale("NO_MDT"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/laptop.lua"
local Locale = aiLib.locale()

-- Ein Laptop-Eintrag im Fahrzeug-Untermenü für Polizei im Dienst.
aiLib.radial.add({
  id = 'myscript_mdt',
  label = Locale('RADIAL_MDT'),
  icon = 'laptop',
  parent = 'vehicle',
  canShow = function()
    return aiLib.cache.vehicle ~= false and aiLib.playerData.get('duty') == 'police'
  end,
  onPressed = function()
    if not aiLib.mdt.open() then aiLib.notify(Locale('NO_MDT'), 'error') end
  end,
})
```
