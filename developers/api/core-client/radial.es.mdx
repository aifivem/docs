---
title: Menú radial
description: Añade, quita y refresca elementos en el menú radial que tenga el servidor, con condiciones, submenús y handlers de pulsación.
icon: CircleDot
---

El menú radial es la rueda que los jugadores abren con una tecla para elegir acciones rápidas (puertas del vehículo, emotes, acciones de trabajo). Los scripts añaden sus elementos a ai-core, y ai-core se los entrega al menú radial que tenga el servidor: ai-radialmenu, o uno de terceros compatible (tgiann-radialmenu, qb-radialmenu, codem-supreme-radialmenu, el radial de ox_lib).

ai-core guarda cada elemento. Cuando el menú radial se reinicia, o el dueño del servidor cambia a otro, ai-core vuelve a añadir cada elemento por sí mismo, así que tu script añade sus elementos **una vez al iniciar** y nunca tiene que vigilar el recurso radial. Los elementos se quitan cuando se detiene el recurso que los añadió.

### AddRadialItem

Añade un elemento al menú radial, o reemplaza el elemento con el mismo id. Las funciones del elemento (`canShow`, `onPressed`) se ejecutan dentro de tu recurso.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
AddRadialItem(item: RadialItem): void
```

```lua title="Lua"
exports['ai-core']:AddRadialItem(item) -- o aiLib.radial.add(item)
```

#### Devuelve

Nada. Un elemento sin un `id` o `label` de texto no se añade, y ai-core imprime un aviso que nombra a tu recurso.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/radial.ts"
import { cache, radial } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import { Locale } from "common";

// Una vez al iniciar: un interruptor del motor en el submenú de vehículo, solo para el conductor.
radial.add({
  id: "myscript_engine",
  label: Locale("RADIAL_ENGINE"),
  icon: "power-off",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && cache.seat === -1,
  onPressed: () => {
    if (cache.vehicle === false) return;
    SetVehicleEngineOn(cache.vehicle, !GetIsVehicleEngineRunning(cache.vehicle), false, true);
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/radial.lua"
local Locale = aiLib.locale()

-- Una vez al iniciar: un interruptor del motor en el submenú de vehículo, solo para el conductor.
aiLib.radial.add({
  id = 'myscript_engine',
  label = Locale('RADIAL_ENGINE'),
  icon = 'power-off',
  parent = 'vehicle',
  canShow = function() return aiLib.cache.vehicle ~= false and aiLib.cache.seat == -1 end,
  onPressed = function()
    local vehicle = aiLib.cache.vehicle
    if not vehicle then return end
    SetVehicleEngineOn(vehicle, not GetIsVehicleEngineRunning(vehicle), false, true)
  end,
})
```
</Tab>
</Tabs>

<Callout type="warn">
`canShow` se ejecuta cada vez que se abre la rueda: que sea barato (lee `cache`, una variable local o `HasItem`), nunca llames al servidor desde él. No vuelvas a añadir los mismos elementos cuando se reinicia el menú radial; ai-core ya lo hace.
</Callout>

### RemoveRadialItem

Quita un elemento por su id.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
RemoveRadialItem(id: string): void
```

```lua title="Lua"
exports['ai-core']:RemoveRadialItem(id) -- o aiLib.radial.remove(id)
```

#### Parámetros

<TypeTable
  type={{
    id: { type: 'string', description: 'El id con el que se añadió el elemento. Un id desconocido no hace nada.', required: true },
  }}
/>

#### Devuelve

Nada.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/duty.ts"
import { onPlayerData, radial } from "@aifivem/lib/client";
import { Locale } from "common";

// Una acción de esposar solo mientras se está de servicio como policía.
onPlayerData("duty", (duty) => {
  if (duty === "police")
    radial.add({ id: "myscript_cuff", label: Locale("RADIAL_CUFF"), icon: "handcuffs", onPressed: () => ExecuteCommand("cuff") });
  else radial.remove("myscript_cuff");
});
```
</Tab>
<Tab value="Lua">
```lua title="client/duty.lua"
local Locale = aiLib.locale()

-- Una acción de esposar solo mientras se está de servicio como policía.
aiLib.playerData.onChange('duty', function(duty)
  if duty == 'police' then
    aiLib.radial.add({ id = 'myscript_cuff', label = Locale('RADIAL_CUFF'), icon = 'handcuffs', onPressed = function() ExecuteCommand('cuff') end })
  else
    aiLib.radial.remove('myscript_cuff')
  end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
El id no se comprueba contra el recurso que lo añadió: quitar `"myscript_cuff"` lo quita sea quien sea quien lo añadió. Usa ids que empiecen con el nombre de tu recurso. Para un elemento que aparece y desaparece a menudo, un `canShow` es más sencillo que añadir y quitar.
</Callout>

### RefreshRadial

Vuelve a leer cada `canShow` de una rueda abierta, para que los elementos aparezcan o desaparezcan mientras el jugador la mira. Llámalo después de que cambie algo que lee un `canShow` (el jugador subió a un vehículo, entró de servicio).

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
RefreshRadial(): void
```

```lua title="Lua"
exports['ai-core']:RefreshRadial() -- o aiLib.radial.refresh()
```

#### Parámetros

Ninguno.

#### Devuelve

Nada. Sin un menú radial en marcha no hace nada.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/radial.ts"
import { onCache, radial } from "@aifivem/lib/client";

// Los elementos de vehículo dependen del asiento: refresca cuando cambia.
onCache("seat", () => radial.refresh());
```
</Tab>
<Tab value="Lua">
```lua title="client/radial.lua"
-- Los elementos de vehículo dependen del asiento: refresca cuando cambia.
aiLib.cache.onChange('seat', function() aiLib.radial.refresh() end)
```
</Tab>
</Tabs>
