O ai-core acompanha cada tecla que os scripts registram com o `Keybind` da lib (TypeScript) ou `aiLib.Keybind` (Lua). É assim que a aba Keybinds do painel de administração consegue mudar a tecla padrão de um script, que os HUDs conseguem listar dicas de teclas à esquerda da tela e que a tela de teclas consegue mostrar cada tecla que tem uma ação.

Uma **dica de tecla** é uma linha curta no HUD: uma tecla e o que ela faz (`E  Open trunk`). Keybinds podem declarar uma com a opção `hint`. Um script também pode mostrar dicas por um tempo com `ShowKeyHint`, por exemplo os controles de uma ferramenta enquanto ela está em uso.

### GetKeybindKey

Retorna a tecla com que um `Keybind` da lib foi registrado: a tecla que o dono do servidor definiu na aba Keybinds do painel de administração, senão a tecla padrão do próprio script. O jogador ainda pode tê-la mudado nas configurações de teclas do GTA; para a tecla que ele realmente aperta, leia `Keybind.currentKey` no seu keybind.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
GetKeybindKey(name: string): string | null
```

```lua title="Lua"
local key = exports['ai-core']:GetKeybindKey(name) -- string ou nil
```

#### Parâmetros

<TypeTable
  type={{
    name: { type: 'string', description: 'O `name` do keybind como o script o passou para `Keybind` (`"myscript_open"`).', required: true },
  }}
/>

#### Retorno

`string`: a tecla em maiúsculas (`"F5"`, `"E"`), ou `""` para um keybind sem tecla padrão. `null` até o ai-core responder àquele keybind (pouco depois de o recurso dele iniciar) e para nomes que nenhum recurso em execução registrou.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { Keybind, resourceExport } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

const open = new Keybind({
  name: "myscript_open",
  description: Locale("KEY_OPEN"),
  defaultKey: "F5",
  onPressed: () => console.log("open"),
});

RegisterCommand(
  "myscript_keys",
  () => {
    console.log(`registered with: ${core.GetKeybindKey("myscript_open") ?? "not yet"}`);
    console.log(`the player presses: ${open.currentKey}`);
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

aiLib.Keybind.new({
  name = 'myscript_open',
  description = Locale('KEY_OPEN'),
  defaultKey = 'F5',
  onPressed = function() print('open') end,
})

RegisterCommand('myscript_keys', function()
  print(('registered with: %s'):format(exports['ai-core']:GetKeybindKey('myscript_open') or 'not yet'))
end, false)
```
</Tab>
</Tabs>

### ShowKeyHint

Mostra uma dica de tecla do seu recurso na lista de dicas do HUD até você escondê-la. Use para teclas que só importam por um tempo: os controles de uma ferramenta, um minigame, um modo de câmera. Teclas que seus keybinds sempre oferecem ficam na opção `hint` do `Keybind`.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
ShowKeyHint(id: string, hint: KeyHintRequest): void
```

```lua title="Lua"
exports['ai-core']:ShowKeyHint(id, hint) -- ou aiLib.keyHints.show(id, hint)
```

#### Parâmetros

<TypeTable
  type={{
    id: { type: 'string', description: 'Seu nome para esta dica (`"camera_zoom"`). Mostrar o mesmo id de novo substitui a dica. Os ids são por recurso, então o `camera_zoom` de outro script é outra dica.', required: true },
    hint: { type: 'KeyHintRequest', description: 'O que a linha mostra. Campos abaixo.', required: true, typeDescriptionLink: '/docs/developers/api/types#keyhintrequest' },
  }}
/>

#### KeyHintRequest

Veja também [KeyHintRequest](/pt/docs/developers/api/types#keyhintrequest).

<TypeTable
  type={{
    label: { type: 'string', description: 'O que a tecla faz, já traduzido (`Locale("HINT_ZOOM")`). Cortado em 60 caracteres.', required: true },
    keybind: { type: 'string', description: 'O `name` de um keybind: a dica mostra a tecla que o jogador associou a ele agora e acompanha quando ele a troca. Tem prioridade sobre `key`.' },
    key: { type: 'string', description: 'Um texto de tecla literal (`"SCROLL"`, `"SHIFT"`) quando nenhum keybind está por trás. Cortado em 16 caracteres.' },
    icon: { type: 'string', description: 'Um nome de ícone Font Awesome solid sem `fa-` (`"magnifying-glass"`). Os HUDs desenham um ícone de tecla quando não o conhecem. Cortado em 32 caracteres.' },
  }}
/>

#### Retorno

Nada. Uma dica sem texto em `label`, ou um `id` que não é string, é ignorada. Uma dica cuja tecla não resolve para nada (nem `keybind` nem `key` dão uma tecla) é mantida, mas não listada.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/camera.ts"
import { keyHints } from "@aicore-fivem/lib/client";
import { Locale } from "common";

export function startCamera(): void {
  keyHints.show("camera_zoom", { label: Locale("HINT_ZOOM"), key: "SCROLL", icon: "magnifying-glass" });
  keyHints.show("camera_exit", { label: Locale("HINT_EXIT"), keybind: "myscript_camera" });
}

export function stopCamera(): void {
  keyHints.hide("camera_zoom");
  keyHints.hide("camera_exit");
}
```
</Tab>
<Tab value="Lua">
```lua title="client/camera.lua"
local Locale = aiLib.locale()

local function startCamera()
  aiLib.keyHints.show('camera_zoom', { label = Locale('HINT_ZOOM'), key = 'SCROLL', icon = 'magnifying-glass' })
  aiLib.keyHints.show('camera_exit', { label = Locale('HINT_EXIT'), keybind = 'myscript_camera' })
end

local function stopCamera()
  aiLib.keyHints.hide('camera_zoom')
  aiLib.keyHints.hide('camera_exit')
end
```
</Tab>
</Tabs>

<Callout type="info">
As dicas são listadas na ordem em que os scripts as mostraram, depois das dicas que os keybinds declaram. As dicas do seu recurso são removidas quando ele para.
</Callout>

### HideKeyHint

Esconde uma dica de tecla que seu recurso mostrou.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
HideKeyHint(id: string): void
```

```lua title="Lua"
exports['ai-core']:HideKeyHint(id) -- ou aiLib.keyHints.hide(id)
```

#### Parâmetros

<TypeTable
  type={{
    id: { type: 'string', description: 'O id que você passou para `ShowKeyHint`. Um id que seu recurso nunca mostrou não faz nada.', required: true },
  }}
/>

#### Retorno

Nada.

#### Exemplo

Veja o exemplo de [ShowKeyHint](#showkeyhint).

### GetKeyHints

Retorna as linhas de dicas de teclas que os HUDs devem mostrar agora: as dicas que os keybinds declaram para a situação do jogador (a pé ou num veículo, como o dono do servidor as definiu no painel) mais as dicas que os scripts mostram. Um HUD a lê uma vez ao iniciar e depois segue o evento de cliente `ai-core:client:keyHints`, que traz a mesma lista depois de cada mudança.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
GetKeyHints(): KeyHintView[]
```

```lua title="Lua"
local hints = exports['ai-core']:GetKeyHints() -- array de { id, key, label, icon? }
```

#### Parâmetros

Nenhum.

#### Retorno

[`KeyHintView[]`](/pt/docs/developers/api/types#keyhintview), na ordem de exibição. Um array vazio quando nenhuma dica se aplica.

<TypeTable
  type={{
    id: { type: 'string', description: 'O nome do keybind, ou `<resource>:<id>` para uma dica que um script mostrou.', required: true },
    key: { type: 'string', description: 'A tecla como o jogador a tem associada agora (`"E"`, `"F5"`).', required: true },
    label: { type: 'string', description: 'O que ela faz, já traduzido.', required: true },
    icon: { type: 'string', description: 'Nome do ícone Font Awesome solid sem `fa-`; ausente quando nenhum foi dado.' },
  }}
/>

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hints.ts"
import { resourceExport } from "@aicore-fivem/lib/client";
import { KEY_HINTS, type KeyHintView } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// A lista de dicas de teclas de um HUD próprio.
function draw(hints: KeyHintView[]): void {
  SendNUIMessage({ action: "keyHints", data: hints });
}

draw(core.GetKeyHints());
on(KEY_HINTS.changedEvent, draw);
```
</Tab>
<Tab value="Lua">
```lua title="client/hints.lua"
-- A lista de dicas de teclas de um HUD próprio.
local function draw(hints)
  SendNUIMessage({ action = 'keyHints', data = hints })
end

draw(exports['ai-core']:GetKeyHints())
AddEventHandler('ai-core:client:keyHints', draw)
```
</Tab>
</Tabs>

### OpenKeyboard

Abre a tela de teclas do ai-core: um teclado em que cada tecla com uma ação fica colorida, com o que cada tecla faz embaixo dela. As teclas aparecem como o jogador as tem associadas agora. A entrada Keys do menu radial a abre; qualquer script pode. Enquanto ela está aberta, os HUDs ficam escondidos.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
OpenKeyboard(): void
```

```lua title="Lua"
exports['ai-core']:OpenKeyboard()
```

#### Parâmetros

Nenhum.

#### Retorno

Nada. Chamar enquanto a tela já está aberta não faz nada. O jogador a fecha na própria tela.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aicore-fivem/lib/client";

const core = resourceExport("ai-core");

RegisterCommand("keys", () => core.OpenKeyboard(), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('keys', function() exports['ai-core']:OpenKeyboard() end, false)
```
</Tab>
</Tabs>
