Każdy skrypt `ai-*` pokazuje powiadomienia przez ai-lib (`notify` w libie, `aiLib.notify` w Lua). ai-lib rysuje własne karty, chyba że właściciel serwera wybrał inne UI powiadomień w panelu ai-core (tgiann-lumihud, okokNotify, ox_lib, mythic_notify, brutal_notify). Wtedy ai-lib przekazuje każdą kartę do ai-core, a ai-core tłumaczy ją na wywołanie tego UI.

**Nie wywołujesz tego sam.** Aby pokazać powiadomienie, użyj `notify(text, kind, duration)` z liba albo `aiLib.notify(text, kind, duration)`: wybierają właściwe UI. Ta strona istnieje, abyś wiedział, co robi eksport, gdy go zobaczysz.

### ExternalNotify

Pokazuje jedną kartę powiadomienia ai-lib w UI powiadomień wybranym w panelu. ai-lib wywołuje to dla każdej karty, dopóki wybrane jest zewnętrzne UI.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
ExternalNotify(notification: Notification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:ExternalNotify({ text = 'Saved', kind = 'success' }) -- boolean
```

#### Notification

<TypeTable
  type={{
    text: { type: 'string', description: 'Treść wiadomości, już przetłumaczona. Obcinana do 300 znaków.', required: true },
    title: { type: 'string', description: 'Opcjonalny tytuł, już przetłumaczony. Obcinany do 60 znaków.' },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'Styl karty. Wszystko inne liczy się jako `"info"`. Każde UI dostaje własne słowo na to (na przykład `inform` z ox_lib dla `info`).', required: true },
    duration: { type: 'number', description: 'Milisekundy na ekranie. UI, które potrzebują wartości, dostają 4000, gdy jest pominięta.' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy zewnętrzne UI zostało wybrane, działa i dostało kartę. `false`, gdy karta nie ma tekstu albo gdy żadne zewnętrzne UI nie jest wybrane lub nie działa: wtedy ai-lib sam rysuje kartę.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify } from "@aicore-fivem/lib/client";
import { Locale } from "common";

// Właściwy sposób powiadamiania: ai-lib wywołuje ExternalNotify za ciebie, gdy wybrane jest zewnętrzne UI.
RegisterCommand("saved", () => notify(Locale("SAVED"), "success", 3000), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

-- Właściwy sposób powiadamiania: ai-lib wywołuje ExternalNotify za ciebie, gdy wybrane jest zewnętrzne UI.
RegisterCommand('saved', function() aiLib.notify(Locale('SAVED'), 'success', 3000) end, false)
```
</Tab>
</Tabs>

<Callout type="info">
Nazwa zasobu wybranego UI jest w GlobalState `ai:notify` (nieustawiona, dopóki ai-lib rysuje własne karty). Zobacz [State bagi](/pl/docs/developers/api/events/state-bags).
</Callout>
