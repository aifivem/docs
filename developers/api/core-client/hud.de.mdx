title: HUD
description: Jedes HUD aus- und einblenden, solange deine Vollbild-UI offen ist, lesen, ob HUDs sichtbar sind, und die eigenen Einstellungen des laufenden HUD öffnen.
icon: Gauge
---

Wenn dein Skript eine Vollbild-UI öffnet (einen Shop, ein Handy, einen Fotomodus), sollte das HUD aus dem Weg gehen. Diese Exports blenden das HUD aus und ein, das der Server nutzt: ai-hud oder ein HUD eines Drittanbieters, das ai-core kennt (tgiann-lumihud, tgiann-hudv2, tgiann-modern-hud, tgiann-statushud, jg-hud, 0r-hud-v3, codem-supreme-hud, Codem-BlackHUDV2, wais-hudv6, qb-hud, ps-hud). Ohne bekanntes HUD blendet ai-core stattdessen die Minikarte aus und ein. qb-hud und ps-hud können von einem anderen Skript nicht ausgeblendet werden: Mit ihnen folgt nur die Minikarte.

Das Ausblenden arbeitet mit **Gründen**. Jede Ressource blendet das HUD unter einem Namen ihrer Wahl aus (`"shop"`, `"photo-mode"`). HUDs bleiben ausgeblendet, solange mindestens ein Grund von irgendeiner Ressource gesetzt ist, sodass zwei gleichzeitig offene Bildschirme nie gegeneinander arbeiten: Das HUD kommt erst zurück, wenn beide geschlossen sind. Gründe gehören der Ressource, die sie gesetzt hat, und werden entfernt, wenn sie stoppt.

### HideHud

Blendet jedes HUD (und die Minikarte, wenn kein bekanntes HUD läuft) unter einem Grund deiner Ressource aus. Rufe es auf, wenn deine Vollbild-UI sich öffnet.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
HideHud(reason: string): void
```

```lua title="Lua"
exports['ai-core']:HideHud(reason) -- oder aiLib.hud.hide(reason)
```

#### Parameter

<TypeTable
  type={{
    reason: { type: 'string', description: 'Ein Name dafür, warum du es ausblendest (`"shop"`). Nur deine Ressource kann ihn löschen. Erneutes Ausblenden unter demselben Namen ändert nichts.', required: true },
  }}
/>

#### Rückgabe

Nichts. Ein `reason`, der kein String ist, wird ignoriert.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/shop.ts"
import { hud } from "@aicore-fivem/lib/client";

export function openShop(): void {
  hud.hide("shop"); // dasselbe wie resourceExport("ai-core").HideHud("shop")
  SetNuiFocus(true, true);
  SendNUIMessage({ action: "open" });
}

RegisterNuiCallback("close", (_data: unknown, cb: (r: unknown) => void) => {
  SetNuiFocus(false, false);
  hud.show("shop");
  cb(true);
});
```
</Tab>
<Tab value="Lua">
```lua title="client/shop.lua"
local function openShop()
  aiLib.hud.hide('shop') -- dasselbe wie exports['ai-core']:HideHud('shop')
  SetNuiFocus(true, true)
  SendNUIMessage({ action = 'open' })
end

RegisterNUICallback('close', function(_, cb)
  SetNuiFocus(false, false)
  aiLib.hud.show('shop')
  cb(true)
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Jedes `HideHud` braucht sein `ShowHud` mit demselben Grund. ai-core räumt hinter einer Ressource auf, die stoppt, aber nicht hinter einer, die weiterläuft und vergisst, `ShowHud` aufzurufen: Das HUD bleibt dann für diesen Spieler ausgeblendet.
</Callout>

### ShowHud

Löscht einen Ausblende-Grund deiner Ressource. HUDs kommen zurück, wenn keine Ressource mehr einen Grund hat.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
ShowHud(reason: string): void
```

```lua title="Lua"
exports['ai-core']:ShowHud(reason) -- oder aiLib.hud.show(reason)
```

#### Parameter

<TypeTable
  type={{
    reason: { type: 'string', description: 'Der Name, den du an `HideHud` übergeben hast. Ein Name, den deine Ressource nie gesetzt hat, bewirkt nichts; der gleichnamige Grund einer anderen Ressource wird nicht berührt.', required: true },
  }}
/>

#### Rückgabe

Nichts.

#### Beispiel

Siehe das Beispiel zu [HideHud](#hidehud).

### IsHudVisible

Sagt, ob HUDs gerade sichtbar sind, also keine Ressource einen Ausblende-Grund gesetzt hat. Eine HUD-Ressource nutzt es beim Start; danach folgt sie dem Client-Event `ai-core:client:hudVisible`.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
IsHudVisible(): boolean
```

```lua title="Lua"
local visible = exports['ai-core']:IsHudVisible() -- oder aiLib.hud.visible()
```

#### Parameter

Keine.

#### Rückgabe

`boolean`: `true`, wenn kein Ausblende-Grund gesetzt ist, `false`, solange mindestens einer gesetzt ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { hud } from "@aicore-fivem/lib/client";

// Ein eigenes HUD: im richtigen Zustand starten, dann jeder Änderung folgen.
function setVisible(visible: boolean): void {
  SendNUIMessage({ action: "visible", data: visible });
}

setVisible(hud.visible);
hud.onChange(setVisible);
```
</Tab>
<Tab value="Lua">
```lua title="client/hud.lua"
-- Ein eigenes HUD: im richtigen Zustand starten, dann jeder Änderung folgen.
local function setVisible(visible)
  SendNUIMessage({ action = 'visible', data = visible })
end

setVisible(aiLib.hud.visible())
AddEventHandler('ai-core:client:hudVisible', setVisible)
```
</Tab>
</Tabs>

### OpenHudSettings

Öffnet den eigenen Einstellungsbildschirm des laufenden HUD (zum Beispiel `/hud` von ai-hud oder tgiann-lumihud). Der HUD-Eintrag des Radialmenüs nutzt es; jedes Skript kann es nutzen.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
OpenHudSettings(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenHudSettings() -- boolean
```

#### Parameter

Keine.

#### Rückgabe

`boolean`: `true`, wenn das laufende HUD einen Einstellungsbildschirm hat und dieser zum Öffnen aufgefordert wurde. `false`, wenn kein bekanntes HUD läuft oder das laufende keinen Einstellungsbildschirm hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify, resourceExport } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

RegisterCommand(
  "hudsettings",
  () => {
    if (!core.OpenHudSettings()) notify(Locale("NO_HUD_SETTINGS"), "error");
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

RegisterCommand('hudsettings', function()
  if not exports['ai-core']:OpenHudSettings() then
    aiLib.notify(Locale('NO_HUD_SETTINGS'), 'error')
  end
end, false)
```
</Tab>
</Tabs>

### HasHudSettings

Sagt, ob das laufende HUD einen Einstellungsbildschirm hat, damit du einen Button „HUD-Einstellungen“ ein- oder ausblenden kannst.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
HasHudSettings(): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasHudSettings() -- boolean
```

#### Parameter

Keine.

#### Rückgabe

`boolean`: `true`, wenn ein bekanntes HUD läuft und es einen Einstellungsbildschirm hat, sonst `false`.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/menu.ts"
import { radial, resourceExport } from "@aicore-fivem/lib/client";

const core = resourceExport("ai-core");

// Ein Radial-Eintrag, der nur erscheint, wenn das HUD Einstellungen zum Öffnen hat.
radial.add({
  id: "myscript_hud",
  label: "HUD",
  icon: "sliders",
  canShow: () => core.HasHudSettings(),
  onPressed: () => void core.OpenHudSettings(),
});
```
</Tab>
<Tab value="Lua">
```lua title="client/menu.lua"
-- Ein Radial-Eintrag, der nur erscheint, wenn das HUD Einstellungen zum Öffnen hat.
aiLib.radial.add({
  id = 'myscript_hud',
  label = 'HUD',
  icon = 'sliders',
  canShow = function() return exports['ai-core']:HasHudSettings() end,
  onPressed = function() exports['ai-core']:OpenHudSettings() end,
})
```
</Tab>
</Tabs>
