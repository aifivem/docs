title: Notifications

Every `ai-*` script shows notifications through ai-lib (`notify` in the lib, `aiLib.notify` in Lua). ai-lib draws its own cards, unless the server owner picked another notification UI in ai-core's panel (tgiann-lumihud, okokNotify, ox_lib, mythic_notify, brutal_notify). Then ai-lib hands each card to ai-core, and ai-core translates it into that UI's call.

**You do not call this yourself.** To show a notification, use the lib's `notify(text, kind, duration)` or `aiLib.notify(text, kind, duration)`: they pick the right UI. This page exists so you know what the export does when you see it.

### ExternalNotify

Shows one ai-lib notification card in the notification UI the panel picked. ai-lib calls it for every card while a third-party UI is picked.

**Side:** Client · **Waits:** no

```ts title="Signature"
ExternalNotify(notification: Notification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:ExternalNotify({ text = 'Saved', kind = 'success' }) -- boolean
```

#### Parameters

<TypeTable
  type={{
    notification: { type: 'Notification', description: 'The card. Fields below.', required: true, typeDescriptionLink: '/docs/developers/api/types#notification' },
  }}
/>

#### Notification

<TypeTable
  type={{
    text: { type: 'string', description: 'The message, already translated. Cut to 300 characters.', required: true },
    title: { type: 'string', description: 'An optional title, already translated. Cut to 60 characters.' },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'The card\'s style. Anything else counts as `"info"`. Each UI gets its own word for it (ox_lib\'s `inform` for `info`, for example).', required: true },
    duration: { type: 'number', description: 'Milliseconds on screen. UIs that need a value get 4000 when it is left out.' },
  }}
/>

#### Returns

`boolean`: `true` when a third-party UI was picked, runs, and got the card. `false` when the card has no text, or when no third-party UI is picked or running: then ai-lib draws the card itself.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify } from "@aicore-fivem/lib/client";
import { Locale } from "common";

// The right way to notify: ai-lib calls ExternalNotify for you when a third-party UI is picked.
RegisterCommand("saved", () => notify(Locale("SAVED"), "success", 3000), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

-- The right way to notify: ai-lib calls ExternalNotify for you when a third-party UI is picked.
RegisterCommand('saved', function() aiLib.notify(Locale('SAVED'), 'success', 3000) end, false)
```
</Tab>
</Tabs>

<Callout type="info">
The picked UI's resource name is in GlobalState `ai:notify` (unset while ai-lib draws its own cards). See [State bags](/docs/developers/api/events/state-bags).
</Callout>
