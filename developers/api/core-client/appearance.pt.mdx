Estes exports passam pela **camada de aparência** do ai-core: o script de roupas que o servidor roda (ai-appearance, tgiann-clothing, illenium-appearance, qb-clothing, crm-appearance, rcore_clothing, bl_appearance) faz o trabalho. Seu script nunca toca no formato próprio de um script de roupas, então continua funcionando quando o dono do servidor o troca.

Um **visual** ([`CharacterAppearance`](/pt/docs/developers/api/types#characterappearance)) é `{ model, data }`: o hash do modelo do ped e os dados próprios do script de roupas. Trate `data` como uma caixa fechada: pegue um visual do servidor (`appearance.get(charId)` na lib do servidor, `aiLib.appearance.get` em Lua) ou de `GetPedAppearance` e devolva-o sem alterações.

### ApplyAppearance

Aplica um visual num ped pelo script de roupas ativo. Use para vestir um ped local como um personagem (um lojista parecido com o dono, um corpo dormindo, uma foto) ou para recolocar um visual salvo no jogador.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
ApplyAppearance(ped: number, look: CharacterAppearance): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:ApplyAppearance(ped, look) -- ou aiLib.appearance.apply(ped, look)
```

#### Parâmetros

<TypeTable
  type={{
    ped: { type: 'number', description: 'O handle do ped. O modelo dele precisa ser o `model` do visual: crie o ped com `look.model`.', required: true },
    look: { type: 'CharacterAppearance', description: '`{ model, data }` exatamente como o servidor ou `GetPedAppearance` o entregou.', required: true, typeDescriptionLink: '/docs/developers/api/types#characterappearance' },
  }}
/>

#### Retorno

`boolean`: `true` quando o visual foi entregue ao script de roupas. `false` quando o ped não existe, o modelo dele difere de `look.model`, o visual não é uma tabela `{ model, data }` ou nenhum script de roupas está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { appearance, onClientCallback, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// O próprio visual salvo do jogador que pede.
onClientCallback("myscript:myLook", async (source) => {
  const character = core.GetCharacter(source);
  return character ? await appearance.get(character.id) : null;
});
```

```ts title="resource/client/index.ts"
import { appearance, requestModel, triggerServerCallback } from "@aicore-fivem/lib/client";
import { toCharacterAppearance } from "@aicore-fivem/shared";

// Uma cópia local do jogador parada num ponto, vestida como ele.
export async function spawnLookalike(x: number, y: number, z: number): Promise<number> {
  const look = toCharacterAppearance(await triggerServerCallback("myscript:myLook", []));
  if (!look) return 0;
  await requestModel(look.model);
  const ped = CreatePed(4, look.model, x, y, z, 0, false, false);
  SetModelAsNoLongerNeeded(look.model);
  appearance.apply(ped, look);
  return ped;
}
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
-- O próprio visual salvo do jogador que pede.
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  return character and aiLib.appearance.get(character.id) or nil
end)
```

```lua title="client.lua"
-- Uma cópia local do jogador parada num ponto, vestida como ele (chame de uma thread).
local function spawnLookalike(x, y, z)
  local look = aiLib.triggerServerCallback('myscript:myLook', {})
  if not look then return 0 end
  aiLib.requestModel(look.model)
  local ped = CreatePed(4, look.model, x, y, z, 0.0, false, false)
  SetModelAsNoLongerNeeded(look.model)
  aiLib.appearance.apply(ped, look)
  return ped
end
```
</Tab>
</Tabs>

<Callout type="warn">
No ped do próprio jogador, `ApplyAppearance` muda o que ele veste agora. Se essa mudança é salva é regra do script de roupas, não do ai-core. Para vestir o jogador com um uniforme que nunca é salvo, use [WearOutfit](#wearoutfit).
</Callout>

### GetPedAppearance

Retorna o visual que um ped veste agora, no mesmo formato `{ model, data }` que os visuais salvos do servidor usam.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
GetPedAppearance(ped: number): CharacterAppearance | null
```

```lua title="Lua"
local look = exports['ai-core']:GetPedAppearance(ped) -- ou aiLib.appearance.read(ped)
```

#### Parâmetros

<TypeTable
  type={{
    ped: { type: 'number', description: 'O handle do ped (`cache.ped` para o jogador local).', required: true },
  }}
/>

#### Retorno

[`CharacterAppearance`](/pt/docs/developers/api/types#characterappearance): `model` é o hash do modelo do ped, `data` os dados do script de roupas. `null` quando o ped não existe, nenhum script de roupas está rodando ou o script de roupas não consegue ler aquele ped (alguns só leem o ped do próprio jogador local).

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/photo.ts"
import { appearance, cache } from "@aicore-fivem/lib/client";

// Copia o que o jogador veste agora para outro ped do mesmo modelo.
export function copyPlayerLook(target: number): boolean {
  const look = appearance.read(cache.ped);
  return look !== null && appearance.apply(target, look);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/photo.lua"
-- Copia o que o jogador veste agora para outro ped do mesmo modelo.
local function copyPlayerLook(target)
  local look = aiLib.appearance.read(aiLib.cache.ped)
  return look ~= nil and aiLib.appearance.apply(target, look)
end
```
</Tab>
</Tabs>

### OpenClothingMenu

Abre um dos menus do script de roupas ativo para o jogador local: a loja de roupas, o barbeiro ou os outfits salvos. Use para os marcadores da sua própria loja ou um guarda-roupa numa casa.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
OpenClothingMenu(menu: ClothingMenu): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenClothingMenu(menu) -- ou aiLib.appearance.openMenu(menu)
```

#### Parâmetros

<TypeTable
  type={{
    menu: { type: '"clothing" | "barber" | "outfits"', description: '`clothing`: a loja de roupas. `barber`: cabelo, barba e maquiagem. `outfits`: os outfits salvos do jogador (um guarda-roupa).', required: true, typeDescriptionLink: '/docs/developers/api/types#clothingmenu' },
  }}
/>

#### Retorno

`boolean`: `true` quando o script de roupas abriu o menu. `false` para um `menu` desconhecido, quando nenhum script de roupas está rodando ou quando o que está rodando não tem esse menu.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/wardrobe.ts"
import { appearance, notify, Points } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const points = new Points();

// Um guarda-roupa num quarto de motel.
points.add("motel_wardrobe", {
  coords: { x: 151.3, y: -1001.2, z: -99.0 },
  label: Locale("WARDROBE"),
  onPressed: () => {
    if (!appearance.openMenu("outfits")) notify(Locale("NO_WARDROBE"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/wardrobe.lua"
local Locale = aiLib.locale()

RegisterCommand('wardrobe', function()
  if not aiLib.appearance.openMenu('outfits') then
    aiLib.notify(Locale('NO_WARDROBE'), 'error')
  end
end, false)
```
</Tab>
</Tabs>

### WearOutfit

Coloca um outfit de emprego (um uniforme) no jogador local até `ReloadSkin`. Só as peças que você lista mudam; o resto da roupa fica. O outfit nunca é salvo como o visual próprio do jogador.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
WearOutfit(outfit: JobOutfit): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:WearOutfit(outfit) -- ou aiLib.appearance.wearOutfit(outfit)
```

#### Parâmetros

<TypeTable
  type={{
    outfit: { type: 'JobOutfit', description: 'As peças a vestir. Campos abaixo.', required: true, typeDescriptionLink: '/docs/developers/api/types#joboutfit' },
  }}
/>

#### JobOutfit

<TypeTable
  type={{
    components: { type: 'OutfitPiece[]', description: 'Componentes de roupa (tronco, pernas, sapatos...): `id` 0-11.', required: true, typeDescriptionLink: '/docs/developers/api/types#outfitpiece' },
    props: { type: 'OutfitPiece[]', description: 'Props (chapéus, óculos, relógios...): `id` 0-13.', required: true, typeDescriptionLink: '/docs/developers/api/types#outfitpiece' },
  }}
/>

#### OutfitPiece

Veja também [OutfitPiece](/pt/docs/developers/api/types#outfitpiece).

<TypeTable
  type={{
    id: { type: 'number', description: 'O id do componente (0-11) ou do prop (0-13).', required: true },
    collection: { type: 'string', description: 'O nome da coleção de roupas (DLC) de onde vem a peça; `""` para o jogo base. No máximo 64 caracteres.', required: true },
    index: { type: 'number', description: 'O índice do drawable dentro dessa coleção (0-1023). Para um prop, `-1` tira o prop.', required: true },
    texture: { type: 'number', description: 'A textura (variação de cor). Um valor ausente ou negativo conta como 0.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o script de roupas vestiu o outfit. `false` quando nenhuma peça válida sobra depois da verificação, nenhum script de roupas está rodando ou o que está rodando não sabe vestir outfits. Peças inválidas (faixa de id errada, índice ruim) são descartadas uma a uma; as válidas ainda são vestidas.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/locker.ts"
import { appearance } from "@aicore-fivem/lib/client";
import type { JobOutfit } from "@aicore-fivem/shared";

// Um uniforme simples com peças do jogo base: camisa, calça, sapatos, sem chapéu.
const UNIFORM: JobOutfit = {
  components: [
    { id: 11, collection: "", index: 55, texture: 0 },
    { id: 4, collection: "", index: 35, texture: 0 },
    { id: 6, collection: "", index: 25, texture: 0 },
  ],
  props: [{ id: 0, collection: "", index: -1, texture: 0 }],
};

export const putOnUniform = (): boolean => appearance.wearOutfit(UNIFORM);
export const takeOffUniform = (): boolean => appearance.reloadSkin();
```
</Tab>
<Tab value="Lua">
```lua title="client/locker.lua"
-- Um uniforme simples com peças do jogo base: camisa, calça, sapatos, sem chapéu.
local UNIFORM = {
  components = {
    { id = 11, collection = '', index = 55, texture = 0 },
    { id = 4, collection = '', index = 35, texture = 0 },
    { id = 6, collection = '', index = 25, texture = 0 },
  },
  props = { { id = 0, collection = '', index = -1, texture = 0 } },
}

local function putOnUniform() return aiLib.appearance.wearOutfit(UNIFORM) end
local function takeOffUniform() return aiLib.appearance.reloadSkin() end
```
</Tab>
</Tabs>

<Callout type="info">
Os índices de drawable diferem entre os modelos freemode masculino e feminino: mantenha um outfit por modelo e escolha-o pelo modelo do jogador.
</Callout>

### ReloadSkin

Recoloca o visual salvo do jogador local. Use para tirar um outfit de emprego.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
ReloadSkin(): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:ReloadSkin() -- ou aiLib.appearance.reloadSkin()
```

#### Parâmetros

Nenhum.

#### Retorno

`boolean`: `true` quando o script de roupas recebeu o pedido de recarregar o visual. `false` quando nenhum script de roupas está rodando ou o que está rodando não sabe recarregar.

#### Exemplo

Veja o exemplo de [WearOutfit](#wearoutfit).
