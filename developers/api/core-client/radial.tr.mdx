Radyal menü, oyuncuların hızlı aksiyonlar seçmek için bir tuşla açtığı tekerlektir (araç kapıları, emote’lar, meslek aksiyonları). Script’ler öğelerini ai-core’a ekler, ai-core da onları sunucunun çalıştırdığı radyal menüye verir: ai-radialmenu ya da desteklenen üçüncü taraf biri (tgiann-radialmenu, qb-radialmenu, codem-supreme-radialmenu, ox_lib’in radyali).

ai-core her öğeyi tutar. Radyal menü yeniden başladığında ya da sunucu sahibi başka birine geçtiğinde ai-core her öğeyi kendiliğinden yeniden ekler, bu yüzden script’in öğelerini **açılışta bir kez** ekler ve radyal resource’u asla izlemek zorunda kalmaz. Öğeler onları ekleyen resource durduğunda kaldırılır.

### AddRadialItem

Radyal menüye bir öğe ekler ya da aynı id’ye sahip öğeyi değiştirir. Öğenin fonksiyonları (`canShow`, `onPressed`) senin resource’unun içinde çalışır.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
AddRadialItem(item: RadialItem): void
```

```lua title="Lua"
exports['ai-core']:AddRadialItem(item) -- ya da aiLib.radial.add(item)
```

#### Dönüş değeri

Hiçbir şey. Metin bir `id` ya da `label` olmayan bir öğe eklenmez ve ai-core resource’unun adını veren bir uyarı yazar.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/radial.ts"
import { cache, radial } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import { Locale } from "common";

// Açılışta bir kez: araç alt menüsünde yalnızca sürücü için bir motor anahtarı.
radial.add({
  id: "myscript_engine",
  label: Locale("RADIAL_ENGINE"),
  icon: "power-off",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && cache.seat === -1,
  onPressed: () => {
    if (cache.vehicle === false) return;
    SetVehicleEngineOn(cache.vehicle, !GetIsVehicleEngineRunning(cache.vehicle), false, true);
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/radial.lua"
local Locale = aiLib.locale()

-- Açılışta bir kez: araç alt menüsünde yalnızca sürücü için bir motor anahtarı.
aiLib.radial.add({
  id = 'myscript_engine',
  label = Locale('RADIAL_ENGINE'),
  icon = 'power-off',
  parent = 'vehicle',
  canShow = function() return aiLib.cache.vehicle ~= false and aiLib.cache.seat == -1 end,
  onPressed = function()
    local vehicle = aiLib.cache.vehicle
    if not vehicle then return end
    SetVehicleEngineOn(vehicle, not GetIsVehicleEngineRunning(vehicle), false, true)
  end,
})
```
</Tab>
</Tabs>

<Callout type="warn">
`canShow` tekerlek her açıldığında çalışır: ucuz tut (`cache`’i, yerel bir değişkeni ya da `HasItem`’ı oku), içinden asla server’ı çağırma. Radyal menü yeniden başladığında aynı öğeleri tekrar ekleme; ai-core bunu zaten yapar.
</Callout>

### RemoveRadialItem

Bir öğeyi id’sine göre kaldırır.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
RemoveRadialItem(id: string): void
```

```lua title="Lua"
exports['ai-core']:RemoveRadialItem(id) -- ya da aiLib.radial.remove(id)
```

#### Parametreler

<TypeTable
  type={{
    id: { type: 'string', description: 'Öğenin eklendiği id. Bilinmeyen bir id hiçbir şey yapmaz.', required: true },
  }}
/>

#### Dönüş değeri

Hiçbir şey.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/duty.ts"
import { onPlayerData, radial } from "@aifivem/lib/client";
import { Locale } from "common";

// Yalnızca polis olarak mesaideyken bir kelepçe aksiyonu.
onPlayerData("duty", (duty) => {
  if (duty === "police")
    radial.add({ id: "myscript_cuff", label: Locale("RADIAL_CUFF"), icon: "handcuffs", onPressed: () => ExecuteCommand("cuff") });
  else radial.remove("myscript_cuff");
});
```
</Tab>
<Tab value="Lua">
```lua title="client/duty.lua"
local Locale = aiLib.locale()

-- Yalnızca polis olarak mesaideyken bir kelepçe aksiyonu.
aiLib.playerData.onChange('duty', function(duty)
  if duty == 'police' then
    aiLib.radial.add({ id = 'myscript_cuff', label = Locale('RADIAL_CUFF'), icon = 'handcuffs', onPressed = function() ExecuteCommand('cuff') end })
  else
    aiLib.radial.remove('myscript_cuff')
  end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Id onu ekleyen resource’a göre kontrol edilmez: `"myscript_cuff"`’ı kaldırmak, kim eklediyse onu kaldırır. Resource adınla başlayan id’ler kullan. Sık gelip giden bir öğe için `canShow`, ekleyip kaldırmaktan daha basittir.
</Callout>

### RefreshRadial

Açık bir tekerleğin her `canShow`’unu yeniden okur, böylece oyuncu bakarken öğeler belirir ya da kaybolur. Bir `canShow`’un okuduğu bir şey değiştikten sonra çağır (oyuncu araca bindi, mesaiye girdi).

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
RefreshRadial(): void
```

```lua title="Lua"
exports['ai-core']:RefreshRadial() -- ya da aiLib.radial.refresh()
```

#### Parametreler

Yok.

#### Dönüş değeri

Hiçbir şey. Çalışan bir radyal menü yokken hiçbir şey yapmaz.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/radial.ts"
import { onCache, radial } from "@aifivem/lib/client";

// Araç öğeleri koltuğa bağlıdır: değiştiğinde yenile.
onCache("seat", () => radial.refresh());
```
</Tab>
<Tab value="Lua">
```lua title="client/radial.lua"
-- Araç öğeleri koltuğa bağlıdır: değiştiğinde yenile.
aiLib.cache.onChange('seat', function() aiLib.radial.refresh() end)
```
</Tab>
</Tabs>
