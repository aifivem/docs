The MDT (mobile data terminal) is the police computer: records, warrants, reports. ai-core's **MDT layer** opens the one the server runs, so a radial item, a key or a vehicle laptop in your script opens the right screen. Supported MDTs that can be opened from another script: tgiann-mdt, ps-mdt, wasabi_mdt.

### OpenMdt

Opens the active MDT's screen for the local player. The MDT checks the player's job itself and refuses a player who may not use it.

**Side:** Client · **Waits:** no

```ts title="Signature"
OpenMdt(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenMdt() -- or aiLib.mdt.open()
```

#### Parameters

None.

#### Returns

`boolean`: `true` when the active MDT was asked to open. `false` when no supported MDT runs, or the running one cannot be opened from another script. `true` does not mean the screen showed: the MDT may still refuse the player's job.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/laptop.ts"
import { cache, getPlayerData, mdt, notify, radial } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import { Locale } from "common";

// A laptop entry in the vehicle sub menu for on-duty police.
radial.add({
  id: "myscript_mdt",
  label: Locale("RADIAL_MDT"),
  icon: "laptop",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && getPlayerData("duty") === "police",
  onPressed: () => {
    if (!mdt.open()) notify(Locale("NO_MDT"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/laptop.lua"
local Locale = aiLib.locale()

-- A laptop entry in the vehicle sub menu for on-duty police.
aiLib.radial.add({
  id = 'myscript_mdt',
  label = Locale('RADIAL_MDT'),
  icon = 'laptop',
  parent = 'vehicle',
  canShow = function()
    return aiLib.cache.vehicle ~= false and aiLib.playerData.get('duty') == 'police'
  end,
  onPressed = function()
    if not aiLib.mdt.open() then aiLib.notify(Locale('NO_MDT'), 'error') end
  end,
})
```
