title: Gestos y emotes
description: Comprueba manos arriba y señalar, reproduce y detén emotes por nombre y mira qué script de emotes responde, sea cual sea el menú de emotes del servidor.
icon: Hand
---

Las manos arriba, señalar y los emotes vienen de un script de emotes. ai-core pregunta al que esté en marcha, así que un cacheo policial ("¿tiene las manos arriba?") o una animación de trabajo funciona con cualquiera de ellos.

Se mantienen dos listas separadas, porque no todos los scripts hacen ambas cosas:

- **Gestos** (manos arriba, señalar): tgiann-emotes, codem-emotemenu, rpemotes (y rpemotes-reborn), 0r-animmenu, ai-smallresources. Responde el primero que esté en marcha en este orden.
- **Emotes** (reproducir por nombre, detener): tgiann-emotes, rpemotes (y rpemotes-reborn), scully_emotemenu, dpemotes. Responde el primero que esté en marcha en este orden.

### IsHandsUp

Indica si el jugador local tiene las manos arriba, en el script de emotes que responda a los gestos.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
IsHandsUp(): boolean
```

```lua title="Lua"
local up = exports['ai-core']:IsHandsUp() -- o aiLib.gestures.isHandsUp()
```

#### Parámetros

Ninguno.

#### Devuelve

`boolean`: `true` mientras las manos están arriba. `false` cuando no lo están, o cuando no hay ningún script de gestos en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/rob.ts"
import { gestures, notify } from "@aicore-fivem/lib/client";
import { Locale } from "common";

RegisterCommand(
  "surrender_check",
  () => notify(Locale(gestures.isHandsUp() ? "HANDS_UP" : "HANDS_DOWN")),
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client/rob.lua"
local Locale = aiLib.locale()

RegisterCommand('surrender_check', function()
  aiLib.notify(Locale(aiLib.gestures.isHandsUp() and 'HANDS_UP' or 'HANDS_DOWN'))
end, false)
```
</Tab>
</Tabs>

<Callout type="info">
Esto solo lee al jugador **local**. Para saber si otro jugador tiene las manos arriba (un robo, un cacheo), pregunta al servidor, que pregunta al cliente de ese jugador.
</Callout>

### IsPointing

Indica si el jugador local está señalando, en el script de emotes que responda a los gestos.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
IsPointing(): boolean
```

```lua title="Lua"
local pointing = exports['ai-core']:IsPointing() -- o aiLib.gestures.isPointing()
```

#### Parámetros

Ninguno.

#### Devuelve

`boolean`: `true` mientras señala. `false` cuando no, cuando no hay ningún script de gestos en marcha o cuando el que está en marcha no puede saberlo (0r-animmenu no tiene comprobación de señalar).

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { gestures } from "@aicore-fivem/lib/client";

RegisterCommand("ispointing", () => console.log(gestures.isPointing()), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('ispointing', function() print(aiLib.gestures.isPointing()) end, false)
```
</Tab>
</Tabs>

### GetGestureProvider

Devuelve el nombre de recurso del script de emotes que responde a manos arriba y señalar.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
GetGestureProvider(): string | null
```

```lua title="Lua"
local provider = exports['ai-core']:GetGestureProvider() -- o aiLib.gestures.provider()
```

#### Parámetros

Ninguno.

#### Devuelve

`string`: el nombre del recurso (`"tgiann-emotes"`). `null` cuando no hay en marcha ninguno de los scripts compatibles.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { gestures } from "@aicore-fivem/lib/client";

// Usa tu propia tecla de manos arriba solo cuando ningún script de emotes ofrece una.
if (gestures.provider() === null) console.log("no gesture script, enabling my own hands-up key");
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
-- Usa tu propia tecla de manos arriba solo cuando ningún script de emotes ofrece una.
if aiLib.gestures.provider() == nil then print('no gesture script, enabling my own hands-up key') end
```
</Tab>
</Tabs>

### PlayEmote

Reproduce un emote del script de emotes en marcha por su nombre de comando, el nombre que los jugadores escriben después de `/e` (`"sit"`, `"notepad"`).

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
PlayEmote(name: string): boolean
```

```lua title="Lua"
local played = exports['ai-core']:PlayEmote(name) -- o aiLib.gestures.playEmote(name)
```

#### Parámetros

<TypeTable
  type={{
    name: { type: 'string', description: 'El nombre de comando del emote: de 1 a 32 letras, dígitos, `_` o `-`. Los nombres cambian entre scripts de emotes; usa nombres comunes o deja que el dueño del servidor ponga el nombre.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el nombre es válido y se pidió a un script de emotes que lo reproduzca. `false` para un nombre no válido o cuando no hay ningún script de emotes en marcha. `true` no demuestra que el emote exista en ese script: un nombre desconocido simplemente no reproduce nada.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/notes.ts"
import { gestures, progress } from "@aicore-fivem/lib/client";
import { Locale } from "common";

// Escribe una nota con el emote de libreta mientras corre la barra.
export async function writeNote(): Promise<boolean> {
  gestures.playEmote("notepad");
  const done = await progress({ label: Locale("WRITING"), duration: 5000, canCancel: true });
  gestures.cancelEmote();
  return done;
}
```
</Tab>
<Tab value="Lua">
```lua title="client/notes.lua"
local Locale = aiLib.locale()

-- Escribe una nota con el emote de libreta mientras corre la barra (llámalo desde un thread).
local function writeNote()
  aiLib.gestures.playEmote('notepad')
  local done = aiLib.progress({ label = Locale('WRITING'), duration = 5000, canCancel = true })
  aiLib.gestures.cancelEmote()
  return done
end
```
</Tab>
</Tabs>

### CancelEmote

Detiene el emote que está reproduciendo el jugador local, en el script de emotes en marcha. Úsalo cuando tu script necesite las manos del jugador (esposar, un derribo, un minijuego).

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
CancelEmote(): boolean
```

```lua title="Lua"
local stopped = exports['ai-core']:CancelEmote() -- o aiLib.gestures.cancelEmote()
```

#### Parámetros

Ninguno.

#### Devuelve

`boolean`: `true` cuando se pidió a un script de emotes que pare (también cuando no se reproducía nada), `false` cuando no hay ningún script de emotes en marcha.

#### Ejemplo

Consulta el ejemplo de [PlayEmote](#playemote).

### GetEmoteProvider

Devuelve el nombre de recurso del script de emotes que reproduce emotes por nombre.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
GetEmoteProvider(): string | null
```

```lua title="Lua"
local provider = exports['ai-core']:GetEmoteProvider() -- o aiLib.gestures.emoteProvider()
```

#### Parámetros

Ninguno.

#### Devuelve

`string`: el nombre del recurso (`"rpemotes"`). `null` cuando no hay en marcha ninguno de los scripts de emotes compatibles.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { gestures, player } from "@aicore-fivem/lib/client";

// Prefiere el script de emotes del servidor, si no, una animación simple.
export function sitDown(): void {
  if (gestures.emoteProvider() !== null) gestures.playEmote("sit");
  else void player.playAnim("anim@amb@business@bgen@bgen_no_work@", "sit_phone_phoneputdown_idle_nowork");
}
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
-- Prefiere el script de emotes del servidor, si no, una animación simple (llámalo desde un thread).
local function sitDown()
  if aiLib.gestures.emoteProvider() ~= nil then
    aiLib.gestures.playEmote('sit')
  else
    aiLib.player.playAnim('anim@amb@business@bgen@bgen_no_work@', 'sit_phone_phoneputdown_idle_nowork')
  end
end
```
</Tab>
</Tabs>
