---
title: Seat belt
description: Tell whether the local player wears a seat belt and which script answers, whatever seat belt script or HUD the server runs.
icon: ShieldCheck
---

A seat belt can come from ai-smallresources, from qbx_seatbelt, or from a HUD with its own belt (tgiann-lumihud, tgiann-hudv2, tgiann-modern-hud). ai-core reads whichever one runs; when several run, a HUD's own belt wins over ai-smallresources. Scripts that need the belt (an ejection on crash, a "buckle up" hint, a HUD icon) ask ai-core and work with any of them.

ai-core passes belt changes on as the client event `ai-core:client:seatbelt` (lib `seatbelt.onChange`), from the scripts that tell changes: ai-smallresources and qbx_seatbelt. For the HUD belts, read the state when you need it.

### GetSeatbelt

Tells whether the local player wears a seat belt right now. Read it when you need it (a crash, an action), not every frame.

**Side:** Client · **Waits:** no

```ts title="Signature"
GetSeatbelt(): boolean | null
```

```lua title="Lua"
local worn = exports['ai-core']:GetSeatbelt() -- or aiLib.seatbelt.isOn()
```

#### Parameters

None.

#### Returns

`boolean | null`: `true` when the belt is on, `false` when it is off. `null` (`nil` in Lua) when no supported seat belt script runs, or the running one gives no clear answer (for example outside a vehicle with a belt).

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/crash.ts"
import { cache, seatbelt } from "@aifivem/lib/client";

// Called by your crash detection: throw the driver out only without a belt.
export function onHardCrash(): void {
  if (cache.vehicle === false) return;
  if (seatbelt.isOn() === true) return; // null = no belt script: treat as no belt
  const [x, y, z] = GetEntityCoords(cache.ped, true);
  SetEntityCoords(cache.ped, x, y, z + 1.0, false, false, false, false);
  SetPedToRagdoll(cache.ped, 3000, 3000, 0, false, false, false);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/crash.lua"
-- Called by your crash detection: throw the driver out only without a belt.
local function onHardCrash()
  if not aiLib.cache.vehicle then return end
  if aiLib.seatbelt.isOn() == true then return end -- nil = no belt script: treat as no belt
  local ped = aiLib.cache.ped
  local coords = GetEntityCoords(ped)
  SetEntityCoords(ped, coords.x, coords.y, coords.z + 1.0, false, false, false, false)
  SetPedToRagdoll(ped, 3000, 3000, 0, false, false, false)
end
```
</Tab>

### GetSeatbeltProvider

Returns the resource name of the seat belt script ai-core reads.

**Side:** Client · **Waits:** no

```ts title="Signature"
GetSeatbeltProvider(): string | null
```

```lua title="Lua"
local provider = exports['ai-core']:GetSeatbeltProvider() -- or aiLib.seatbelt.provider()
```

#### Parameters

None.

#### Returns

`string`: the resource name (`"ai-smallresources"`, `"tgiann-lumihud"`). `null` when none of the supported scripts runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { seatbelt } from "@aifivem/lib/client";

// A HUD that draws a belt icon only when some script provides a belt.
const hasBelt = seatbelt.provider() !== null;
SendNUIMessage({ action: "beltIcon", data: hasBelt });
if (hasBelt) seatbelt.onChange((worn) => SendNUIMessage({ action: "belt", data: worn }));
```
</Tab>
<Tab value="Lua">
```lua title="client/hud.lua"
-- A HUD that draws a belt icon only when some script provides a belt.
local hasBelt = aiLib.seatbelt.provider() ~= nil
SendNUIMessage({ action = 'beltIcon', data = hasBelt })
if hasBelt then
  aiLib.seatbelt.onChange(function(worn) SendNUIMessage({ action = 'belt', data = worn }) end)
end
```
</Tab>
</Tabs>
