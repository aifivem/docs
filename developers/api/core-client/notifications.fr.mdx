Chaque script `ai-*` affiche ses notifications via ai-lib (`notify` dans la lib, `aiLib.notify` en Lua). ai-lib dessine ses propres cartes, sauf si le propriétaire du serveur a choisi une autre interface de notifications dans le panneau d’ai-core (tgiann-lumihud, okokNotify, ox_lib, mythic_notify, brutal_notify). Alors ai-lib confie chaque carte à ai-core, et ai-core la traduit en appel de cette interface.

**Vous ne l’appelez pas vous-même.** Pour afficher une notification, utilisez `notify(text, kind, duration)` de la lib ou `aiLib.notify(text, kind, duration)` : ils choisissent la bonne interface. Cette page existe pour que vous sachiez ce que fait l’export quand vous le voyez.

### ExternalNotify

Affiche une carte de notification d’ai-lib dans l’interface de notifications que le panneau a choisie. ai-lib l’appelle pour chaque carte tant qu’une interface tierce est choisie.

**Côté :** Client · **Attend :** non

```ts title="Signature"
ExternalNotify(notification: Notification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:ExternalNotify({ text = 'Saved', kind = 'success' }) -- boolean
```

#### Notification

<TypeTable
  type={{
    text: { type: 'string', description: 'Le message, déjà traduit. Coupé à 300 caractères.', required: true },
    title: { type: 'string', description: 'Un titre facultatif, déjà traduit. Coupé à 60 caractères.' },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'Le style de la carte. Toute autre valeur compte comme `"info"`. Chaque interface reçoit son propre mot pour cela (`inform` d’ox_lib pour `info`, par exemple).', required: true },
    duration: { type: 'number', description: 'Millisecondes à l’écran. Les interfaces qui ont besoin d’une valeur reçoivent 4000 quand elle est omise.' },
  }}
/>

#### Retour

`boolean` : `true` quand une interface tierce a été choisie, tourne et a reçu la carte. `false` quand la carte n’a pas de texte, ou quand aucune interface tierce n’est choisie ou ne tourne : ai-lib dessine alors la carte lui-même.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify } from "@aicore-fivem/lib/client";
import { Locale } from "common";

// La bonne façon de notifier : ai-lib appelle ExternalNotify pour vous quand une interface tierce est choisie.
RegisterCommand("saved", () => notify(Locale("SAVED"), "success", 3000), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

-- La bonne façon de notifier : ai-lib appelle ExternalNotify pour vous quand une interface tierce est choisie.
RegisterCommand('saved', function() aiLib.notify(Locale('SAVED'), 'success', 3000) end, false)
```
</Tab>
</Tabs>

<Callout type="info">
Le nom de ressource de l’interface choisie se trouve dans la clé GlobalState `ai:notify` (non définie tant qu’ai-lib dessine ses propres cartes). Voir [State bags](/fr/docs/developers/api/events/state-bags).
</Callout>
