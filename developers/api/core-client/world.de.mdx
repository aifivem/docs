Das Wetter-Skript (ai-weathersync oder eines eines Drittanbieters) hält jeden Spieler auf dem Wetter und der Uhr des Servers. Wenn dein Skript auf dem Bildschirm eines Spielers eigenes Wetter oder eine eigene Zeit braucht (ein dunkles Interior, ein Charakter-Editor, eine Zwischensequenz), halte zuerst die Synchronisierung an, sonst überschreibt das Wetter-Skript deine Werte einen Moment später.

Das Anhalten arbeitet mit **Gründen**, wie beim HUD: Die Synchronisierung bleibt angehalten, solange mindestens ein Grund gesetzt ist, und läuft wieder, wenn der letzte gelöscht ist. Gründe gehören der Ressource, die sie gesetzt hat, und werden entfernt, wenn sie stoppt. ai-core informiert das Wetter-Skript über sein eigenes Client-Event `ai-core:client:worldSync` und über die üblichen Pause-Events, auf die Wetter-Skripte von Drittanbietern hören (qb-weathersync, cd_easytime, vSync, av_weather). Umgekehrt zählt ai-core es ebenfalls als Grund, wenn ein Skript selbst eines dieser Events sendet, sodass das Fortsetzen eines Skripts nie die Pause eines anderen beendet.

### PauseWorldSync

Hält die Wetter- und Zeitsynchronisierung im Spiel dieses Spielers unter einem Grund deiner Ressource an.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
PauseWorldSync(reason: string): void
```

```lua title="Lua"
exports['ai-core']:PauseWorldSync(reason) -- oder aiLib.world.pauseSync(reason)
```

#### Parameter

<TypeTable
  type={{
    reason: { type: 'string', description: 'Ein Name dafür, warum du sie anhältst (`"interior"`). Nur deine Ressource kann ihn löschen. Erneutes Anhalten unter demselben Namen ändert nichts.', required: true },
  }}
/>

#### Rückgabe

Nichts. Ein `reason`, der kein String ist, wird ignoriert.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/interior.ts"
import { world } from "@aifivem/lib/client";

// Eine dunkle, klare Nacht in einem eigenen Interior, beim Verlassen zurück zum Wetter des Servers.
export function enterInterior(): void {
  world.pauseSync("interior"); // dasselbe wie resourceExport("ai-core").PauseWorldSync("interior")
  NetworkOverrideClockTime(23, 0, 0);
  SetWeatherTypeNowPersist("CLEAR");
}

export function leaveInterior(): void {
  NetworkClearClockTimeOverride();
  world.resumeSync("interior");
}
```
</Tab>
<Tab value="Lua">
```lua title="client/interior.lua"
-- Eine dunkle, klare Nacht in einem eigenen Interior, beim Verlassen zurück zum Wetter des Servers.
local function enterInterior()
  aiLib.world.pauseSync('interior') -- dasselbe wie exports['ai-core']:PauseWorldSync('interior')
  NetworkOverrideClockTime(23, 0, 0)
  SetWeatherTypeNowPersist('CLEAR')
end

local function leaveInterior()
  NetworkClearClockTimeOverride()
  aiLib.world.resumeSync('interior')
end
```
</Tab>
</Tabs>

<Callout type="warn">
Die Pause stoppt nur die Synchronisierung. Dein eigenes Wetter und deine eigene Zeit zu setzen und sie wieder zu löschen, wenn du fertig bist, ist Aufgabe deines Skripts.
</Callout>

### ResumeWorldSync

Löscht einen Pause-Grund deiner Ressource. Die Synchronisierung läuft wieder, und das Wetter-Skript stellt Wetter und Uhr des Servers wieder her, wenn kein Grund mehr übrig ist.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
ResumeWorldSync(reason: string): void
```

```lua title="Lua"
exports['ai-core']:ResumeWorldSync(reason) -- oder aiLib.world.resumeSync(reason)
```

#### Parameter

<TypeTable
  type={{
    reason: { type: 'string', description: 'Der Name, den du an `PauseWorldSync` übergeben hast. Ein Name, den deine Ressource nie gesetzt hat, bewirkt nichts.', required: true },
  }}
/>

#### Rückgabe

Nichts.

#### Beispiel

Siehe das Beispiel zu [PauseWorldSync](#pauseworldsync).

### IsWorldSyncPaused

Sagt, ob die Synchronisierung gerade von irgendeiner Ressource oder einem Pause-Event eines Drittanbieters angehalten ist. Ein Wetter-Skript, das später startet, liest es einmal; danach folgt es dem Client-Event `ai-core:client:worldSync`.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
IsWorldSyncPaused(): boolean
```

```lua title="Lua"
local paused = exports['ai-core']:IsWorldSyncPaused() -- boolean
```

#### Parameter

Keine.

#### Rückgabe

`boolean`: `true`, solange mindestens ein Grund gesetzt ist, `false`, wenn die Synchronisierung läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/weather.ts"
import { resourceExport } from "@aifivem/lib/client";
import { CORE } from "@aifivem/shared";

const core = resourceExport("ai-core");

// Ein eigenes Wetter-Skript: das Wetter des Servers nicht anwenden, solange angehalten.
let paused = core.IsWorldSyncPaused();
on(CORE.clientWorldSyncEvent, (value: boolean) => {
  paused = value;
});

export const shouldApplyWeather = (): boolean => !paused;
```
</Tab>
<Tab value="Lua">
```lua title="client/weather.lua"
-- Ein eigenes Wetter-Skript: das Wetter des Servers nicht anwenden, solange angehalten.
local paused = exports['ai-core']:IsWorldSyncPaused()
AddEventHandler('ai-core:client:worldSync', function(value) paused = value end)

function ShouldApplyWeather() return not paused end
```
</Tab>
</Tabs>
