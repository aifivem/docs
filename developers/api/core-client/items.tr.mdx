Bu export’lar ai-core’un **envanter katmanı** üzerinden gider: onları sunucu sahibinin seçtiği envanter cevaplar (ai-inventory ya da desteklenen üçüncü taraf bir envanter). Script’in asla belirli bir envanterin export’larını çağırmaz, bu yüzden envanter değiştiğinde çalışmaya devam eder. Hiçbir envanter çalışmıyorken kontroller `false` / `null` cevabı verir ve açma hiçbir şey yapmaz.

Client yalnızca okur ve açar. Eşya verme ve alma her zaman server’da olur (server’da lib `inventory` ya da ai-core’un server export’ları); orada server önce oyuncuyu kontrol eder.

### OpenInventory

Aktif envanterde oyuncunun kendi envanter ekranını açar (o envanterin çevresinde ne gösteriyorsa onunla: yer, bagaj, torpido).

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
OpenInventory(): void
```

```lua title="Lua"
exports['ai-core']:OpenInventory() -- ya da aiLib.inventory.openInventory()
```

#### Parametreler

Yok.

#### Dönüş değeri

Hiçbir şey. Aktif bir envanter yoksa hiçbir şey açılmaz.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { inventory } from "@aicore-fivem/lib/client";

RegisterCommand("bag", () => inventory.openInventory(), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('bag', function() aiLib.inventory.openInventory() end, false)
```
</Tab>
</Tabs>

### HasItem

Oyuncunun bir eşyadan en az belli sayıda tutup tutmadığını söyler. Server’dan bir şey yapmasını istemeden önce bir seçeneği (bir radyal öğe, bir target seçeneği) göstermek ya da gizlemek için kullan.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
HasItem(item: string, count?: number): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasItem(item, count) -- ya da aiLib.inventory.hasItem(item, count)
```

#### Parametreler

<TypeTable
  type={{
    item: { type: 'string', description: 'Envanterin bildiği haliyle eşya adı (`"lockpick"`).', required: true },
    count: { type: 'number', description: 'Oyuncunun kaç tane tutması gerektiği. Eksik, sıfır ya da negatif bir değer 1 sayılır.', default: '1' },
  }}
/>

#### Dönüş değeri

`boolean`: oyuncu en az `count` kadar tutuyorsa `true`. Daha az tutuyorsa, `item` string değilse ya da hiçbir envanter çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { inventory, notify, triggerServerCallback } from "@aicore-fivem/lib/client";
import { Locale } from "common";

RegisterCommand(
  "picklock",
  async () => {
    // Oyuncu için hızlı bir kontrol; server bir şey yapmadan önce eşyayı tekrar kontrol eder.
    if (!inventory.hasItem("lockpick")) return notify(Locale("NEED_LOCKPICK"), "error");
    await triggerServerCallback("myscript:picklock", []);
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

RegisterCommand('picklock', function()
  -- Oyuncu için hızlı bir kontrol; server bir şey yapmadan önce eşyayı tekrar kontrol eder.
  if not aiLib.inventory.hasItem('lockpick') then
    return aiLib.notify(Locale('NEED_LOCKPICK'), 'error')
  end
  CreateThread(function()
    aiLib.triggerServerCallback('myscript:picklock', {}) -- server’ın cevabını bekler
  end)
end, false)
```
</Tab>
</Tabs>

<Callout type="warn">
Bir client cevabı bir hileci tarafından sahtelenebilir. `HasItem`’ı oyuncunun gördükleri için kullan; server eşyayı kendisi kontrol edip çıkarmalıdır.
</Callout>

### GetCurrentWeapon

Aktif envanter üzerinden oyuncunun elinde tuttuğu silah eşyasını etiketi ve resmiyle döndürür.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
GetCurrentWeapon(): HeldWeapon | null
```

```lua title="Lua"
local weapon = exports['ai-core']:GetCurrentWeapon() -- { name, label, image? } ya da nil
```

#### Parametreler

Yok.

#### Dönüş değeri

Elde bir silah eşyası varken [`HeldWeapon`](/tr/docs/developers/api/types#heldweapon), eller boşken ya da hiçbir envanter çalışmıyorken `null`.

<TypeTable
  type={{
    name: { type: 'string', description: 'Eşya adı (`"WEAPON_PISTOL"`).', required: true },
    label: { type: 'string', description: 'Eşyanın görünen adı.', required: true },
    image: { type: 'string', description: 'Resim url’si (`nui://...`); envanterde yoksa bulunmaz.' },
  }}
/>

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/weapon.ts"
import { inventory, onCache } from "@aicore-fivem/lib/client";

// Her karede değil, eldeki silah değiştiğinde oku.
onCache("weapon", () => {
  const weapon = inventory.currentWeapon();
  SendNUIMessage({ action: "weapon", data: weapon });
});
```
</Tab>
<Tab value="Lua">
```lua title="client/weapon.lua"
-- Her karede değil, eldeki silah değiştiğinde oku.
aiLib.cache.onChange('weapon', function()
  local weapon = aiLib.inventory.currentWeapon()
  SendNUIMessage({ action = 'weapon', data = weapon })
end)
```
</Tab>
</Tabs>

### OpenItemPicker

ai-core’un eşya seçicisini açar: aktif envanterdeki her eşyanın resimleriyle aranabilir bir ızgarası; oyuncu burada eşya ve adetlerden bir liste kurar. Admin araçları için tasarlanmıştır (bir oyuncuya eşya vermek): eşya listesi server’dan gelir, server da onu yalnızca admin’lere gönderir. Oyuncunun aldığı liste sonra `ai-lib:client:menuResult` client event’i olarak gelir.

**Taraf:** Client · **Bekler:** hayır (cevap bir event olarak gelir; lib’in `itemPicker`’ı senin için bekler)

```ts title="İmza"
OpenItemPicker(requestId: number, request: ItemPickerRequest): void
```

```lua title="Lua"
local list = aiLib.itemPicker({ title = 'Give items', target = 12 }) -- bekler; bir thread içinde çağır
```

#### Parametreler

<TypeTable
  type={{
    requestId: { type: 'number', description: 'Bu istek için senin numaran. Hangi isteği cevapladığını bilmen için cevap event’inde geri gelir.', required: true },
    request: { type: 'ItemPickerRequest', description: 'Seçicinin başlığı ve eşyaların kimin envanteri için olduğu. Alanlar aşağıda.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#itempickerrequest' },
  }}
/>

#### ItemPickerRequest

Ayrıca bkz. [ItemPickerRequest](/tr/docs/developers/api/types#itempickerrequest).

<TypeTable
  type={{
    title: { type: 'string', description: 'Seçicinin üstündeki başlık, zaten çevrilmiş. 60 karaktere kesilir.', required: true },
    target: { type: 'number', description: 'Eşyaları alacak oyuncunun server id’si. Onun boş ağırlığı alınabilecekleri sınırlar. Verilmezse seçen admin.' },
  }}
/>

#### Dönüş değeri

Hemen hiçbir şey. Daha sonra ai-core `(resource, requestId, value)` ile `ai-lib:client:menuResult` tetikler: oyuncu aldıysa `value` bir [`PickedItem[]`](/tr/docs/developers/api/types#pickeditem) listesidir (`{ name, count }`), seçiciyi kapattıysa `null`’dır. Lib’in `itemPicker(request)`’i bu değerle `Promise<PickedItem[] | null>` döndürür, `aiLib.itemPicker(request)` ise listeyi ya da `nil` döndürür.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/admin.ts"
import { itemPicker, triggerServerCallback } from "@aicore-fivem/lib/client";
import { Locale } from "common";

// Admin aracı: bir oyuncu için eşya seç, server admin’i kontrol eder ve her eşyayı verir.
export async function giveItemsTo(target: number): Promise<void> {
  const list = await itemPicker({ title: Locale("GIVE_ITEMS"), target });
  if (!list || list.length === 0) return;
  await triggerServerCallback("myadmin:giveItems", [target, list]);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/admin.lua"
local Locale = aiLib.locale()

-- Admin aracı: bir oyuncu için eşya seç, server admin’i kontrol eder ve her eşyayı verir.
local function giveItemsTo(target)
  CreateThread(function()
    local list = aiLib.itemPicker({ title = Locale('GIVE_ITEMS'), target = target })
    if not list or #list == 0 then return end
    aiLib.triggerServerCallback('myadmin:giveItems', { target, list })
  end)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Seçici eşyaları yalnızca admin’lere (`ai.admin`) gösterir: başka herkes için ızgara boştur. Server oyuncu başına 2 saniyede en fazla iki açılışa cevap verir; çevrimiçi olmayan bir `target` seçen admin sayılır. Oyuncunun cevabı client verisidir: server’ın bir şey vermeden önce çağıranın admin olduğunu ve her eşyayı ve adedi kontrol etmelidir.
</Callout>
