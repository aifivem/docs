Todo script `ai-*` mostra notificações pelo ai-lib (`notify` na lib, `aiLib.notify` em Lua). O ai-lib desenha os próprios cards, a menos que o dono do servidor tenha escolhido outra UI de notificação no painel do ai-core (tgiann-lumihud, okokNotify, ox_lib, mythic_notify, brutal_notify). Aí o ai-lib entrega cada card ao ai-core, e o ai-core o traduz para a chamada daquela UI.

**Você não chama isto.** Para mostrar uma notificação, use `notify(text, kind, duration)` da lib ou `aiLib.notify(text, kind, duration)`: eles escolhem a UI certa. Esta página existe para você saber o que o export faz quando o vir.

### ExternalNotify

Mostra um card de notificação do ai-lib na UI de notificação que o painel escolheu. O ai-lib o chama para cada card enquanto uma UI de terceiros estiver escolhida.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
ExternalNotify(notification: Notification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:ExternalNotify({ text = 'Saved', kind = 'success' }) -- boolean
```

#### Notification

<TypeTable
  type={{
    text: { type: 'string', description: 'A mensagem, já traduzida. Cortada em 300 caracteres.', required: true },
    title: { type: 'string', description: 'Um título opcional, já traduzido. Cortado em 60 caracteres.' },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'O estilo do card. Qualquer outro valor conta como `"info"`. Cada UI recebe a própria palavra para ele (o `inform` do ox_lib para `info`, por exemplo).', required: true },
    duration: { type: 'number', description: 'Milissegundos na tela. UIs que precisam de um valor recebem 4000 quando ele é omitido.' },
  }}
/>

#### Retorno

`boolean`: `true` quando uma UI de terceiros foi escolhida, está rodando e recebeu o card. `false` quando o card não tem texto, ou quando nenhuma UI de terceiros está escolhida ou rodando: aí o ai-lib desenha o card ele mesmo.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify } from "@aicore-fivem/lib/client";
import { Locale } from "common";

// O jeito certo de notificar: o ai-lib chama ExternalNotify por você quando uma UI de terceiros está escolhida.
RegisterCommand("saved", () => notify(Locale("SAVED"), "success", 3000), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

-- O jeito certo de notificar: o ai-lib chama ExternalNotify por você quando uma UI de terceiros está escolhida.
RegisterCommand('saved', function() aiLib.notify(Locale('SAVED'), 'success', 3000) end, false)
```
</Tab>
</Tabs>

<Callout type="info">
O nome do recurso da UI escolhida fica no GlobalState `ai:notify` (sem valor enquanto o ai-lib desenha os próprios cards). Veja [State bags](/pt/docs/developers/api/events/state-bags).
</Callout>
