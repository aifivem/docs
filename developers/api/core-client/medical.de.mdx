---
title: Medizin
description: Feststellen, ob der lokale Spieler am Boden ist (tot oder im Last Stand), egal welches Tod-Skript der Server nutzt.
icon: HeartPulse
---

Tod-Skripte halten den Ped eines Spielers am Boden am Leben, um ihn animieren zu können (am Boden liegen, kriechen, Last Stand). Das bedeutet, dass GTAs eigenes `IsEntityDead` für einen Spieler am Boden oft „lebendig“ sagt. Die **Medizin-Ebene** von ai-core fragt das Tod-Skript, das der Server nutzt (ai-death, qbx_medical, ars_ambulancejob, qb-ambulancejob, esx_ambulancejob, tgiann-ambulance, wasabi_ambulance, osp_ambulance, brutal_ambulancejob), und gibt jeder Ressource dieselbe Antwort.

### IsDead

Sagt, ob der lokale Spieler gerade am Boden ist, tot oder im Last Stand, im laufenden Tod-Skript. Nutze es vor einer Aktion, die ein Spieler am Boden nicht ausführen darf (ein Menü öffnen, ein Item benutzen, in ein Fahrzeug steigen).

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
IsDead(): boolean
```

```lua title="Lua"
local down = exports['ai-core']:IsDead() -- boolean
```

#### Parameter

Keine.

#### Rückgabe

`boolean`: `true`, solange der Spieler im aktiven Tod-Skript am Boden ist. `false`, wenn er auf den Beinen ist oder kein unterstütztes Tod-Skript läuft.

`medical.isDead()` der Lib (TypeScript) antwortet auch `true`, wenn GTA selbst sagt, dass der Ped tot ist, was Server ohne Tod-Skript abdeckt. Es liest den Export einmal und folgt dann dem Client-Event `ai-core:client:dead`, sodass häufige Aufrufe nichts kosten. In Lua gibt es keinen Helfer: Rufe den Export auf oder folge dem Event.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/phone.ts"
import { medical, notify } from "@aifivem/lib/client";
import { Locale } from "common";

RegisterCommand(
  "phone",
  () => {
    if (medical.isDead()) return notify(Locale("CANT_WHILE_DOWN"), "error");
    SetNuiFocus(true, true);
    SendNUIMessage({ action: "open" });
  },
  false,
);

// Das Handy in dem Moment schließen, in dem der Spieler zu Boden geht.
medical.onChange((dead) => {
  if (!dead) return;
  SetNuiFocus(false, false);
  SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client/phone.lua"
local Locale = aiLib.locale()

-- Von ai-core übernommen: einmal lesen, dann dem Event folgen.
local down = exports['ai-core']:IsDead()

RegisterCommand('phone', function()
  if down then return aiLib.notify(Locale('CANT_WHILE_DOWN'), 'error') end
  SetNuiFocus(true, true)
  SendNUIMessage({ action = 'open' })
end, false)

-- Das Handy in dem Moment schließen, in dem der Spieler zu Boden geht.
AddEventHandler('ai-core:client:dead', function(dead)
  down = dead
  if not dead then return end
  SetNuiFocus(false, false)
  SendNUIMessage({ action = 'close' })
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Das ist der eigene Zustand des lokalen Spielers, für das, was er sieht. Serverentscheidungen (wiederbeleben, einen Körper plündern, eine Aktion verweigern) prüfen die Medizin-Exports des Servers, nie die Antwort eines Clients.
</Callout>
