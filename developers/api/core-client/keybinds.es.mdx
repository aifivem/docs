ai-core lleva la cuenta de cada tecla que los scripts registran con el `Keybind` de la lib (TypeScript) o `aiLib.Keybind` (Lua). Así es como la pestaña Keybinds del panel de administración puede cambiar la tecla por defecto de un script, como los HUD pueden listar ayudas de teclas a la izquierda de la pantalla y como la pantalla de teclas puede mostrar cada tecla que tiene una acción.

Una **ayuda de tecla** es una fila corta en el HUD: una tecla y lo que hace (`E  Abrir maletero`). Los keybinds pueden declarar una con su opción `hint`. Un script también puede mostrar ayudas durante un rato con `ShowKeyHint`, por ejemplo los controles de una herramienta mientras se usa.

### GetKeybindKey

Devuelve la tecla con la que se registró un `Keybind` de la lib: la tecla que el dueño del servidor puso en la pestaña Keybinds del panel de administración; si no, la tecla por defecto del propio script. El jugador aún puede haberla cambiado en los ajustes de teclas de GTA; para la tecla que pulsa de verdad, lee `Keybind.currentKey` en tu keybind.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
GetKeybindKey(name: string): string | null
```

```lua title="Lua"
local key = exports['ai-core']:GetKeybindKey(name) -- string o nil
```

#### Parámetros

<TypeTable
  type={{
    name: { type: 'string', description: 'El `name` del keybind tal como el script se lo pasó a `Keybind` (`"myscript_open"`).', required: true },
  }}
/>

#### Devuelve

`string`: la tecla en mayúsculas (`"F5"`, `"E"`), o `""` para un keybind sin tecla por defecto. `null` hasta que ai-core haya respondido por ese keybind (poco después de que se inicie su recurso) y para nombres que ningún recurso en marcha registró.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { Keybind, resourceExport } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

const open = new Keybind({
  name: "myscript_open",
  description: Locale("KEY_OPEN"),
  defaultKey: "F5",
  onPressed: () => console.log("open"),
});

RegisterCommand(
  "myscript_keys",
  () => {
    console.log(`registered with: ${core.GetKeybindKey("myscript_open") ?? "not yet"}`);
    console.log(`the player presses: ${open.currentKey}`);
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

aiLib.Keybind.new({
  name = 'myscript_open',
  description = Locale('KEY_OPEN'),
  defaultKey = 'F5',
  onPressed = function() print('open') end,
})

RegisterCommand('myscript_keys', function()
  print(('registered with: %s'):format(exports['ai-core']:GetKeybindKey('myscript_open') or 'not yet'))
end, false)
```
</Tab>
</Tabs>

### ShowKeyHint

Muestra una ayuda de tecla de tu recurso en la lista de ayudas de teclas del HUD hasta que la ocultes. Úsala para teclas que solo importan durante un rato: los controles de una herramienta, un minijuego, un modo de cámara. Las teclas que tus keybinds ofrecen siempre van en la opción `hint` del `Keybind`.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
ShowKeyHint(id: string, hint: KeyHintRequest): void
```

```lua title="Lua"
exports['ai-core']:ShowKeyHint(id, hint) -- o aiLib.keyHints.show(id, hint)
```

#### Parámetros

<TypeTable
  type={{
    id: { type: 'string', description: 'Tu nombre para esta ayuda (`"camera_zoom"`). Mostrar el mismo id otra vez reemplaza la ayuda. Los ids son por recurso, así que el `camera_zoom` de otro script es una ayuda distinta.', required: true },
    hint: { type: 'KeyHintRequest', description: 'Lo que muestra la fila. Campos abajo.', required: true, typeDescriptionLink: '/docs/developers/api/types#keyhintrequest' },
  }}
/>

#### KeyHintRequest

Consulta también [KeyHintRequest](/es/docs/developers/api/types#keyhintrequest).

<TypeTable
  type={{
    label: { type: 'string', description: 'Lo que hace la tecla, ya traducido (`Locale("HINT_ZOOM")`). Se corta a 60 caracteres.', required: true },
    keybind: { type: 'string', description: 'El `name` de un keybind: la ayuda muestra la tecla que el jugador tiene asignada ahora y la sigue cuando la reasigna. Tiene prioridad sobre `key`.' },
    key: { type: 'string', description: 'Un texto de tecla literal (`"SCROLL"`, `"SHIFT"`) cuando no hay ningún keybind detrás. Se corta a 16 caracteres.' },
    icon: { type: 'string', description: 'Un nombre de icono sólido de Font Awesome sin `fa-` (`"magnifying-glass"`). Los HUD dibujan un icono de tecla cuando no lo conocen. Se corta a 32 caracteres.' },
  }}
/>

#### Devuelve

Nada. Una ayuda sin un `label` de texto, o un `id` que no es una cadena, se ignora. Una ayuda cuya tecla no resuelve a nada (ni `keybind` ni `key` dan una tecla) se guarda pero no se lista.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/camera.ts"
import { keyHints } from "@aicore-fivem/lib/client";
import { Locale } from "common";

export function startCamera(): void {
  keyHints.show("camera_zoom", { label: Locale("HINT_ZOOM"), key: "SCROLL", icon: "magnifying-glass" });
  keyHints.show("camera_exit", { label: Locale("HINT_EXIT"), keybind: "myscript_camera" });
}

export function stopCamera(): void {
  keyHints.hide("camera_zoom");
  keyHints.hide("camera_exit");
}
```
</Tab>
<Tab value="Lua">
```lua title="client/camera.lua"
local Locale = aiLib.locale()

local function startCamera()
  aiLib.keyHints.show('camera_zoom', { label = Locale('HINT_ZOOM'), key = 'SCROLL', icon = 'magnifying-glass' })
  aiLib.keyHints.show('camera_exit', { label = Locale('HINT_EXIT'), keybind = 'myscript_camera' })
end

local function stopCamera()
  aiLib.keyHints.hide('camera_zoom')
  aiLib.keyHints.hide('camera_exit')
end
```
</Tab>
</Tabs>

<Callout type="info">
Las ayudas se listan en el orden en que los scripts las mostraron, después de las ayudas que declaran los keybinds. Las ayudas de tu recurso se quitan cuando se detiene.
</Callout>

### GetKeyHints

Devuelve las filas de ayudas de teclas que los HUD deberían mostrar ahora mismo: las ayudas que declaran los keybinds para la situación del jugador (a pie o en un vehículo, como lo haya puesto el dueño del servidor en el panel) más las ayudas que muestran los scripts. Un HUD lo lee una vez al iniciar y después sigue el evento de cliente `ai-core:client:keyHints`, que lleva la misma lista tras cada cambio.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
GetKeyHints(): KeyHintView[]
```

```lua title="Lua"
local hints = exports['ai-core']:GetKeyHints() -- array de { id, key, label, icon? }
```

#### Parámetros

Ninguno.

#### Devuelve

[`KeyHintView[]`](/es/docs/developers/api/types#keyhintview), en orden de visualización. Un array vacío cuando no aplica ninguna ayuda.

<TypeTable
  type={{
    id: { type: 'string', description: 'El nombre del keybind, o `<resource>:<id>` para una ayuda que mostró un script.', required: true },
    key: { type: 'string', description: 'La tecla tal como la tiene asignada ahora el jugador (`"E"`, `"F5"`).', required: true },
    label: { type: 'string', description: 'Lo que hace, ya traducido.', required: true },
    icon: { type: 'string', description: 'Nombre de icono sólido de Font Awesome sin `fa-`; ausente cuando no se dio ninguno.' },
  }}
/>

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hints.ts"
import { resourceExport } from "@aicore-fivem/lib/client";
import { KEY_HINTS, type KeyHintView } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// La lista de ayudas de teclas de un HUD propio.
function draw(hints: KeyHintView[]): void {
  SendNUIMessage({ action: "keyHints", data: hints });
}

draw(core.GetKeyHints());
on(KEY_HINTS.changedEvent, draw);
```
</Tab>
<Tab value="Lua">
```lua title="client/hints.lua"
-- La lista de ayudas de teclas de un HUD propio.
local function draw(hints)
  SendNUIMessage({ action = 'keyHints', data = hints })
end

draw(exports['ai-core']:GetKeyHints())
AddEventHandler('ai-core:client:keyHints', draw)
```
</Tab>
</Tabs>

### OpenKeyboard

Abre la pantalla de teclas de ai-core: un teclado donde cada tecla que tiene una acción aparece coloreada, con lo que hace cada tecla debajo. Las teclas se muestran tal como las tiene asignadas ahora el jugador. La entrada Keys del menú radial la abre; cualquier script puede hacerlo. Mientras está abierta, los HUD se ocultan.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
OpenKeyboard(): void
```

```lua title="Lua"
exports['ai-core']:OpenKeyboard()
```

#### Parámetros

Ninguno.

#### Devuelve

Nada. Llamarlo cuando la pantalla ya está abierta no hace nada. El jugador la cierra desde la propia pantalla.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aicore-fivem/lib/client";

const core = resourceExport("ai-core");

RegisterCommand("keys", () => core.OpenKeyboard(), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('keys', function() exports['ai-core']:OpenKeyboard() end, false)
```
</Tab>
</Tabs>
