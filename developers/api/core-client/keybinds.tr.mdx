ai-core, script’lerin lib’in `Keybind`’ı (TypeScript) ya da `aiLib.Keybind` (Lua) ile kaydettiği her tuşun kaydını tutar. Admin panelinin Keybinds sekmesi bir script’in varsayılan tuşunu bu sayede değiştirebilir, HUD’lar ekranın solunda tuş ipuçlarını bu sayede listeleyebilir, tuşlar ekranı da aksiyonu olan her tuşu bu sayede gösterebilir.

Bir **tuş ipucu** HUD’da kısa bir satırdır: bir tuş ve ne yaptığı (`E  Open trunk`). Keybind’lar `hint` seçenekleriyle bir tane bildirebilir. Bir script de `ShowKeyHint` ile bir süreliğine ipuçları gösterebilir, örneğin bir araç kullanımdayken kontrollerini.

### GetKeybindKey

Bir lib `Keybind`’ının kaydedildiği tuşu döndürür: sunucu sahibinin admin panelinin Keybinds sekmesinde ayarladığı tuş, yoksa script’in kendi varsayılan tuşu. Oyuncu bunu yine de GTA’nın tuş ayarlarında değiştirmiş olabilir; gerçekten bastığı tuş için bunun yerine keybind’ındaki `Keybind.currentKey`’i oku.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
GetKeybindKey(name: string): string | null
```

```lua title="Lua"
local key = exports['ai-core']:GetKeybindKey(name) -- string ya da nil
```

#### Parametreler

<TypeTable
  type={{
    name: { type: 'string', description: 'Script’in `Keybind`’a verdiği haliyle keybind’ın `name`’i (`"myscript_open"`).', required: true },
  }}
/>

#### Dönüş değeri

`string`: büyük harfle tuş (`"F5"`, `"E"`) ya da varsayılan tuşu olmayan bir keybind için `""`. ai-core o keybind’ı cevaplayana kadar (resource’u başladıktan kısa süre sonra) ve çalışan hiçbir resource’un kaydetmediği adlar için `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { Keybind, resourceExport } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

const open = new Keybind({
  name: "myscript_open",
  description: Locale("KEY_OPEN"),
  defaultKey: "F5",
  onPressed: () => console.log("open"),
});

RegisterCommand(
  "myscript_keys",
  () => {
    console.log(`registered with: ${core.GetKeybindKey("myscript_open") ?? "not yet"}`);
    console.log(`the player presses: ${open.currentKey}`);
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

aiLib.Keybind.new({
  name = 'myscript_open',
  description = Locale('KEY_OPEN'),
  defaultKey = 'F5',
  onPressed = function() print('open') end,
})

RegisterCommand('myscript_keys', function()
  print(('registered with: %s'):format(exports['ai-core']:GetKeybindKey('myscript_open') or 'not yet'))
end, false)
```
</Tab>
</Tabs>

### ShowKeyHint

Resource’unun bir tuş ipucunu sen gizleyene kadar HUD’ın tuş ipucu listesinde gösterir. Yalnızca bir süreliğine önemli olan tuşlar için kullan: bir aracın kontrolleri, bir mini oyun, bir kamera modu. Keybind’larının her zaman sunduğu tuşlar bunun yerine `Keybind`’ın `hint` seçeneğine aittir.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
ShowKeyHint(id: string, hint: KeyHintRequest): void
```

```lua title="Lua"
exports['ai-core']:ShowKeyHint(id, hint) -- ya da aiLib.keyHints.show(id, hint)
```

#### Parametreler

<TypeTable
  type={{
    id: { type: 'string', description: 'Bu ipucu için senin adın (`"camera_zoom"`). Aynı id’yi tekrar göstermek ipucunu değiştirir. Id’ler resource başınadır, bu yüzden başka bir script’in `camera_zoom`’u farklı bir ipucudur.', required: true },
    hint: { type: 'KeyHintRequest', description: 'Satırın ne gösterdiği. Alanlar aşağıda.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#keyhintrequest' },
  }}
/>

#### KeyHintRequest

Ayrıca bkz. [KeyHintRequest](/tr/docs/developers/api/types#keyhintrequest).

<TypeTable
  type={{
    label: { type: 'string', description: 'Tuşun ne yaptığı, zaten çevrilmiş (`Locale("HINT_ZOOM")`). 60 karaktere kesilir.', required: true },
    keybind: { type: 'string', description: 'Bir keybind’ın `name`’i: ipucu oyuncunun şu an ona atadığı tuşu gösterir ve yeniden atadığında izler. `key`’e üstün gelir.' },
    key: { type: 'string', description: 'Arkasında bir keybind olmadığında düz bir tuş metni (`"SCROLL"`, `"SHIFT"`). 16 karaktere kesilir.' },
    icon: { type: 'string', description: '`fa-` olmadan bir Font Awesome solid ikon adı (`"magnifying-glass"`). HUD’lar tanımadıklarında bir tuş ikonu çizer. 32 karaktere kesilir.' },
  }}
/>

#### Dönüş değeri

Hiçbir şey. Metin bir `label` olmayan bir ipucu ya da string olmayan bir `id` yok sayılır. Tuşu hiçbir şeye çözülmeyen (ne `keybind` ne `key` bir tuş vermeyen) bir ipucu tutulur ama listelenmez.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/camera.ts"
import { keyHints } from "@aicore-fivem/lib/client";
import { Locale } from "common";

export function startCamera(): void {
  keyHints.show("camera_zoom", { label: Locale("HINT_ZOOM"), key: "SCROLL", icon: "magnifying-glass" });
  keyHints.show("camera_exit", { label: Locale("HINT_EXIT"), keybind: "myscript_camera" });
}

export function stopCamera(): void {
  keyHints.hide("camera_zoom");
  keyHints.hide("camera_exit");
}
```
</Tab>
<Tab value="Lua">
```lua title="client/camera.lua"
local Locale = aiLib.locale()

local function startCamera()
  aiLib.keyHints.show('camera_zoom', { label = Locale('HINT_ZOOM'), key = 'SCROLL', icon = 'magnifying-glass' })
  aiLib.keyHints.show('camera_exit', { label = Locale('HINT_EXIT'), keybind = 'myscript_camera' })
end

local function stopCamera()
  aiLib.keyHints.hide('camera_zoom')
  aiLib.keyHints.hide('camera_exit')
end
```
</Tab>
</Tabs>

<Callout type="info">
İpuçları, keybind’ların bildirdiği ipuçlarından sonra, script’lerin gösterdiği sırayla listelenir. Resource’unun ipuçları o durduğunda kaldırılır.
</Callout>

### GetKeyHints

HUD’ların şu an göstermesi gereken tuş ipucu satırlarını döndürür: keybind’ların oyuncunun durumu için bildirdiği ipuçları (yaya ya da araçta, sunucu sahibinin panelde ayarladığı gibi) artı script’lerin gösterdiği ipuçları. Bir HUD bunu açılışta bir kez okur ve sonra her değişiklikten sonra aynı listeyi taşıyan `ai-core:client:keyHints` client event’ini izler.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
GetKeyHints(): KeyHintView[]
```

```lua title="Lua"
local hints = exports['ai-core']:GetKeyHints() -- { id, key, label, icon? } dizisi
```

#### Parametreler

Yok.

#### Dönüş değeri

[`KeyHintView[]`](/tr/docs/developers/api/types#keyhintview), gösterim sırasıyla. Hiçbir ipucu geçerli değilse boş dizi.

<TypeTable
  type={{
    id: { type: 'string', description: 'Keybind adı ya da bir script’in gösterdiği ipucu için `<resource>:<id>`.', required: true },
    key: { type: 'string', description: 'Oyuncunun şu an atadığı haliyle tuş (`"E"`, `"F5"`).', required: true },
    label: { type: 'string', description: 'Ne yaptığı, zaten çevrilmiş.', required: true },
    icon: { type: 'string', description: '`fa-` olmadan Font Awesome solid ikon adı; verilmediyse bulunmaz.' },
  }}
/>

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hints.ts"
import { resourceExport } from "@aicore-fivem/lib/client";
import { KEY_HINTS, type KeyHintView } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Özel bir HUD’ın tuş ipucu listesi.
function draw(hints: KeyHintView[]): void {
  SendNUIMessage({ action: "keyHints", data: hints });
}

draw(core.GetKeyHints());
on(KEY_HINTS.changedEvent, draw);
```
</Tab>
<Tab value="Lua">
```lua title="client/hints.lua"
-- Özel bir HUD’ın tuş ipucu listesi.
local function draw(hints)
  SendNUIMessage({ action = 'keyHints', data = hints })
end

draw(exports['ai-core']:GetKeyHints())
AddEventHandler('ai-core:client:keyHints', draw)
```
</Tab>
</Tabs>

### OpenKeyboard

ai-core’un tuşlar ekranını açar: aksiyonu olan her tuşun renklendirildiği, altında her tuşun ne yaptığının yazdığı bir klavye. Tuşlar oyuncunun şu an atadığı haliyle gösterilir. Radyal menünün Keys girişi onu açar; her script açabilir. Açıkken HUD’lar gizlenir.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
OpenKeyboard(): void
```

```lua title="Lua"
exports['ai-core']:OpenKeyboard()
```

#### Parametreler

Yok.

#### Dönüş değeri

Hiçbir şey. Ekran zaten açıkken çağırmak hiçbir şey yapmaz. Oyuncu onu ekranda kapatır.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aicore-fivem/lib/client";

const core = resourceExport("ai-core");

RegisterCommand("keys", () => core.OpenKeyboard(), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('keys', function() exports['ai-core']:OpenKeyboard() end, false)
```
</Tab>
</Tabs>
