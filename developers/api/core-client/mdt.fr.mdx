Le MDT (terminal de données mobile) est l’ordinateur de la police : casiers, mandats, rapports. La **couche MDT** d’ai-core ouvre celui qu’utilise le serveur, si bien qu’une entrée radiale, une touche ou un ordinateur de véhicule dans votre script ouvre le bon écran. MDT pris en charge qui peuvent être ouverts depuis un autre script : tgiann-mdt, ps-mdt, wasabi_mdt.

### OpenMdt

Ouvre l’écran du MDT actif pour le joueur local. Le MDT vérifie lui-même le métier du joueur et refuse un joueur qui n’a pas le droit de l’utiliser.

**Côté :** Client · **Attend :** non

```ts title="Signature"
OpenMdt(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenMdt() -- ou aiLib.mdt.open()
```

#### Paramètres

Aucun.

#### Retour

`boolean` : `true` quand on a demandé au MDT actif de s’ouvrir. `false` quand aucun MDT pris en charge ne tourne, ou que celui en cours ne peut pas être ouvert depuis un autre script. `true` ne signifie pas que l’écran s’est affiché : le MDT peut encore refuser le métier du joueur.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/laptop.ts"
import { cache, getPlayerData, mdt, notify, radial } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import { Locale } from "common";

// Une entrée ordinateur dans le sous-menu véhicule pour la police en service.
radial.add({
  id: "myscript_mdt",
  label: Locale("RADIAL_MDT"),
  icon: "laptop",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && getPlayerData("duty") === "police",
  onPressed: () => {
    if (!mdt.open()) notify(Locale("NO_MDT"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/laptop.lua"
local Locale = aiLib.locale()

-- Une entrée ordinateur dans le sous-menu véhicule pour la police en service.
aiLib.radial.add({
  id = 'myscript_mdt',
  label = Locale('RADIAL_MDT'),
  icon = 'laptop',
  parent = 'vehicle',
  canShow = function()
    return aiLib.cache.vehicle ~= false and aiLib.playerData.get('duty') == 'police'
  end,
  onPressed = function()
    if not aiLib.mdt.open() then aiLib.notify(Locale('NO_MDT'), 'error') end
  end,
})
```
