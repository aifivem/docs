Estos exports pasan por la **capa de apariencia** de ai-core: el script de ropa que tenga el servidor (ai-appearance, tgiann-clothing, illenium-appearance, qb-clothing, crm-appearance, rcore_clothing, bl_appearance) hace el trabajo. Tu script nunca toca el formato propio de un script de ropa, así que sigue funcionando cuando el dueño del servidor lo cambia.

Un **aspecto** ([`CharacterAppearance`](/es/docs/developers/api/types#characterappearance)) es `{ model, data }`: el hash del modelo de ped y los datos propios del script de ropa. Trata `data` como una caja cerrada: obtén un aspecto del servidor (`appearance.get(charId)` en la lib de servidor, `aiLib.appearance.get` en Lua) o de `GetPedAppearance`, y devuélvelo sin cambios.

### ApplyAppearance

Pone un aspecto en un ped a través del script de ropa activo. Úsalo para vestir un ped local como un personaje (un tendero que se parece al dueño, un cuerpo dormido, una foto) o para devolver al jugador un aspecto guardado.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
ApplyAppearance(ped: number, look: CharacterAppearance): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:ApplyAppearance(ped, look) -- o aiLib.appearance.apply(ped, look)
```

#### Parámetros

<TypeTable
  type={{
    ped: { type: 'number', description: 'El handle del ped. Su modelo debe ser el `model` del aspecto: crea el ped con `look.model`.', required: true },
    look: { type: 'CharacterAppearance', description: '`{ model, data }` tal cual lo dio el servidor o `GetPedAppearance`.', required: true, typeDescriptionLink: '/docs/developers/api/types#characterappearance' },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de ropa recibió el aspecto. `false` cuando el ped no existe, su modelo es distinto de `look.model`, el aspecto no es una tabla `{ model, data }` o no hay ningún script de ropa en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { appearance, onClientCallback, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// El aspecto guardado del propio jugador que lo pide.
onClientCallback("myscript:myLook", async (source) => {
  const character = core.GetCharacter(source);
  return character ? await appearance.get(character.id) : null;
});
```

```ts title="resource/client/index.ts"
import { appearance, requestModel, triggerServerCallback } from "@aicore-fivem/lib/client";
import { toCharacterAppearance } from "@aicore-fivem/shared";

// Una copia local del jugador de pie en un punto, vestida como él.
export async function spawnLookalike(x: number, y: number, z: number): Promise<number> {
  const look = toCharacterAppearance(await triggerServerCallback("myscript:myLook", []));
  if (!look) return 0;
  await requestModel(look.model);
  const ped = CreatePed(4, look.model, x, y, z, 0, false, false);
  SetModelAsNoLongerNeeded(look.model);
  appearance.apply(ped, look);
  return ped;
}
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
-- El aspecto guardado del propio jugador que lo pide.
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  return character and aiLib.appearance.get(character.id) or nil
end)
```

```lua title="client.lua"
-- Una copia local del jugador de pie en un punto, vestida como él (llámalo desde un thread).
local function spawnLookalike(x, y, z)
  local look = aiLib.triggerServerCallback('myscript:myLook', {})
  if not look then return 0 end
  aiLib.requestModel(look.model)
  local ped = CreatePed(4, look.model, x, y, z, 0.0, false, false)
  SetModelAsNoLongerNeeded(look.model)
  aiLib.appearance.apply(ped, look)
  return ped
end
```
</Tab>
</Tabs>

<Callout type="warn">
En el propio ped del jugador, `ApplyAppearance` cambia lo que lleva ahora. Si ese cambio se guarda lo decide el script de ropa, no ai-core. Para vestir al jugador con un uniforme que nunca se guarda, usa [WearOutfit](#wearoutfit).
</Callout>

### GetPedAppearance

Devuelve el aspecto que lleva un ped ahora mismo, en la misma forma `{ model, data }` que usan los aspectos guardados del servidor.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
GetPedAppearance(ped: number): CharacterAppearance | null
```

```lua title="Lua"
local look = exports['ai-core']:GetPedAppearance(ped) -- o aiLib.appearance.read(ped)
```

#### Parámetros

<TypeTable
  type={{
    ped: { type: 'number', description: 'El handle del ped (`cache.ped` para el jugador local).', required: true },
  }}
/>

#### Devuelve

[`CharacterAppearance`](/es/docs/developers/api/types#characterappearance): `model` es el hash del modelo del ped, `data` los datos del script de ropa. `null` cuando el ped no existe, no hay ningún script de ropa en marcha o el script de ropa no puede leer ese ped (algunos solo leen el ped del propio jugador local).

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/photo.ts"
import { appearance, cache } from "@aicore-fivem/lib/client";

// Copia lo que lleva ahora el jugador en otro ped del mismo modelo.
export function copyPlayerLook(target: number): boolean {
  const look = appearance.read(cache.ped);
  return look !== null && appearance.apply(target, look);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/photo.lua"
-- Copia lo que lleva ahora el jugador en otro ped del mismo modelo.
local function copyPlayerLook(target)
  local look = aiLib.appearance.read(aiLib.cache.ped)
  return look ~= nil and aiLib.appearance.apply(target, look)
end
```
</Tab>
</Tabs>

### OpenClothingMenu

Abre uno de los menús del script de ropa activo para el jugador local: la tienda de ropa, la barbería o sus conjuntos guardados. Úsalo para tus propios marcadores de tienda o un armario en una casa.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
OpenClothingMenu(menu: ClothingMenu): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenClothingMenu(menu) -- o aiLib.appearance.openMenu(menu)
```

#### Parámetros

<TypeTable
  type={{
    menu: { type: '"clothing" | "barber" | "outfits"', description: '`clothing`: la tienda de ropa. `barber`: pelo, barba y maquillaje. `outfits`: los conjuntos guardados del jugador (un armario).', required: true, typeDescriptionLink: '/docs/developers/api/types#clothingmenu' },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de ropa abrió el menú. `false` para un `menu` desconocido, cuando no hay ningún script de ropa en marcha o cuando el que está en marcha no tiene ese menú.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/wardrobe.ts"
import { appearance, notify, Points } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const points = new Points();

// Un armario en una habitación de motel.
points.add("motel_wardrobe", {
  coords: { x: 151.3, y: -1001.2, z: -99.0 },
  label: Locale("WARDROBE"),
  onPressed: () => {
    if (!appearance.openMenu("outfits")) notify(Locale("NO_WARDROBE"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/wardrobe.lua"
local Locale = aiLib.locale()

RegisterCommand('wardrobe', function()
  if not aiLib.appearance.openMenu('outfits') then
    aiLib.notify(Locale('NO_WARDROBE'), 'error')
  end
end, false)
```
</Tab>
</Tabs>

### WearOutfit

Pone un conjunto de trabajo (un uniforme) al jugador local hasta `ReloadSkin`. Solo cambian las piezas que indiques; el resto de su ropa se queda. El conjunto nunca se guarda como aspecto propio del jugador.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
WearOutfit(outfit: JobOutfit): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:WearOutfit(outfit) -- o aiLib.appearance.wearOutfit(outfit)
```

#### Parámetros

<TypeTable
  type={{
    outfit: { type: 'JobOutfit', description: 'Las piezas que se ponen. Campos abajo.', required: true, typeDescriptionLink: '/docs/developers/api/types#joboutfit' },
  }}
/>

#### JobOutfit

<TypeTable
  type={{
    components: { type: 'OutfitPiece[]', description: 'Componentes de ropa (torso, piernas, zapatos...): `id` 0-11.', required: true, typeDescriptionLink: '/docs/developers/api/types#outfitpiece' },
    props: { type: 'OutfitPiece[]', description: 'Props (sombreros, gafas, relojes...): `id` 0-13.', required: true, typeDescriptionLink: '/docs/developers/api/types#outfitpiece' },
  }}
/>

#### OutfitPiece

Consulta también [OutfitPiece](/es/docs/developers/api/types#outfitpiece).

<TypeTable
  type={{
    id: { type: 'number', description: 'El id de componente (0-11) o el id de prop (0-13).', required: true },
    collection: { type: 'string', description: 'El nombre de la colección de ropa (DLC) de la que viene la pieza; `""` para el juego base. Como mucho 64 caracteres.', required: true },
    index: { type: 'number', description: 'El índice de drawable dentro de esa colección (0-1023). En un prop, `-1` quita el prop.', required: true },
    texture: { type: 'number', description: 'La textura (variante de color). Un valor ausente o negativo cuenta como 0.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de ropa puso el conjunto. `false` cuando no queda ninguna pieza válida tras la comprobación, no hay ningún script de ropa en marcha o el que está en marcha no puede poner conjuntos. Las piezas no válidas (rango de id incorrecto, índice erróneo) se descartan una a una; las válidas se ponen igualmente.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/locker.ts"
import { appearance } from "@aicore-fivem/lib/client";
import type { JobOutfit } from "@aicore-fivem/shared";

// Un uniforme sencillo con piezas del juego base: camisa, pantalón, zapatos, sin sombrero.
const UNIFORM: JobOutfit = {
  components: [
    { id: 11, collection: "", index: 55, texture: 0 },
    { id: 4, collection: "", index: 35, texture: 0 },
    { id: 6, collection: "", index: 25, texture: 0 },
  ],
  props: [{ id: 0, collection: "", index: -1, texture: 0 }],
};

export const putOnUniform = (): boolean => appearance.wearOutfit(UNIFORM);
export const takeOffUniform = (): boolean => appearance.reloadSkin();
```
</Tab>
<Tab value="Lua">
```lua title="client/locker.lua"
-- Un uniforme sencillo con piezas del juego base: camisa, pantalón, zapatos, sin sombrero.
local UNIFORM = {
  components = {
    { id = 11, collection = '', index = 55, texture = 0 },
    { id = 4, collection = '', index = 35, texture = 0 },
    { id = 6, collection = '', index = 25, texture = 0 },
  },
  props = { { id = 0, collection = '', index = -1, texture = 0 } },
}

local function putOnUniform() return aiLib.appearance.wearOutfit(UNIFORM) end
local function takeOffUniform() return aiLib.appearance.reloadSkin() end
```
</Tab>
</Tabs>

<Callout type="info">
Los índices de drawable son distintos entre los modelos freemode masculino y femenino: ten un conjunto por modelo y elígelo según el modelo del jugador.
</Callout>

### ReloadSkin

Vuelve a poner el aspecto guardado del jugador local. Úsalo para quitar un conjunto de trabajo.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
ReloadSkin(): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:ReloadSkin() -- o aiLib.appearance.reloadSkin()
```

#### Parámetros

Ninguno.

#### Devuelve

`boolean`: `true` cuando se pidió al script de ropa que recargue el aspecto. `false` cuando no hay ningún script de ropa en marcha o el que está en marcha no puede recargar.

#### Ejemplo

Consulta el ejemplo de [WearOutfit](#wearoutfit).
