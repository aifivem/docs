Le menu radial est la roue que les joueurs ouvrent avec une touche pour choisir des actions rapides (portes du véhicule, emotes, actions de métier). Les scripts ajoutent leurs entrées à ai-core, et ai-core les transmet au menu radial qu’utilise le serveur : ai-radialmenu, ou un menu tiers pris en charge (tgiann-radialmenu, qb-radialmenu, codem-supreme-radialmenu, le radial d’ox_lib).

ai-core garde chaque entrée. Quand le menu radial redémarre, ou que le propriétaire du serveur passe à un autre, ai-core ajoute de nouveau chaque entrée tout seul ; votre script ajoute donc ses entrées **une fois au démarrage** et n’a jamais à surveiller la ressource radiale. Les entrées sont retirées quand la ressource qui les a ajoutées s’arrête.

### AddRadialItem

Ajoute une entrée au menu radial, ou remplace l’entrée de même id. Les fonctions de l’entrée (`canShow`, `onPressed`) s’exécutent dans votre ressource.

**Côté :** Client · **Attend :** non

```ts title="Signature"
AddRadialItem(item: RadialItem): void
```

```lua title="Lua"
exports['ai-core']:AddRadialItem(item) -- ou aiLib.radial.add(item)
```

#### Retour

Rien. Une entrée sans `id` ou `label` texte n’est pas ajoutée, et ai-core affiche un avertissement nommant votre ressource.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/radial.ts"
import { cache, radial } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import { Locale } from "common";

// Une fois au démarrage : un interrupteur moteur dans le sous-menu véhicule, seulement pour le conducteur.
radial.add({
  id: "myscript_engine",
  label: Locale("RADIAL_ENGINE"),
  icon: "power-off",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && cache.seat === -1,
  onPressed: () => {
    if (cache.vehicle === false) return;
    SetVehicleEngineOn(cache.vehicle, !GetIsVehicleEngineRunning(cache.vehicle), false, true);
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/radial.lua"
local Locale = aiLib.locale()

-- Une fois au démarrage : un interrupteur moteur dans le sous-menu véhicule, seulement pour le conducteur.
aiLib.radial.add({
  id = 'myscript_engine',
  label = Locale('RADIAL_ENGINE'),
  icon = 'power-off',
  parent = 'vehicle',
  canShow = function() return aiLib.cache.vehicle ~= false and aiLib.cache.seat == -1 end,
  onPressed = function()
    local vehicle = aiLib.cache.vehicle
    if not vehicle then return end
    SetVehicleEngineOn(vehicle, not GetIsVehicleEngineRunning(vehicle), false, true)
  end,
})
```
</Tab>
</Tabs>

<Callout type="warn">
`canShow` s’exécute à chaque ouverture de la roue : gardez-le léger (lisez `cache`, une variable locale ou `HasItem`), n’appelez jamais le serveur depuis lui. N’ajoutez pas de nouveau les mêmes entrées quand le menu radial redémarre ; ai-core le fait déjà.
</Callout>

### RemoveRadialItem

Retire une entrée par son id.

**Côté :** Client · **Attend :** non

```ts title="Signature"
RemoveRadialItem(id: string): void
```

```lua title="Lua"
exports['ai-core']:RemoveRadialItem(id) -- ou aiLib.radial.remove(id)
```

#### Paramètres

<TypeTable
  type={{
    id: { type: 'string', description: 'L’id avec lequel l’entrée a été ajoutée. Un id inconnu ne fait rien.', required: true },
  }}
/>

#### Retour

Rien.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/duty.ts"
import { onPlayerData, radial } from "@aifivem/lib/client";
import { Locale } from "common";

// Une action de menottage seulement en service comme policier.
onPlayerData("duty", (duty) => {
  if (duty === "police")
    radial.add({ id: "myscript_cuff", label: Locale("RADIAL_CUFF"), icon: "handcuffs", onPressed: () => ExecuteCommand("cuff") });
  else radial.remove("myscript_cuff");
});
```
</Tab>
<Tab value="Lua">
```lua title="client/duty.lua"
local Locale = aiLib.locale()

-- Une action de menottage seulement en service comme policier.
aiLib.playerData.onChange('duty', function(duty)
  if duty == 'police' then
    aiLib.radial.add({ id = 'myscript_cuff', label = Locale('RADIAL_CUFF'), icon = 'handcuffs', onPressed = function() ExecuteCommand('cuff') end })
  else
    aiLib.radial.remove('myscript_cuff')
  end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
L’id n’est pas vérifié par rapport à la ressource qui l’a ajouté : retirer `"myscript_cuff"` le retire, quel que soit qui l’a ajouté. Utilisez des ids qui commencent par le nom de votre ressource. Pour une entrée qui apparaît et disparaît souvent, un `canShow` est plus simple que d’ajouter et de retirer.
</Callout>

### RefreshRadial

Relit chaque `canShow` d’une roue ouverte, pour que les entrées apparaissent ou disparaissent pendant que le joueur la regarde. Appelez-le après un changement de ce que lit un `canShow` (le joueur est monté dans un véhicule, a pris son service).

**Côté :** Client · **Attend :** non

```ts title="Signature"
RefreshRadial(): void
```

```lua title="Lua"
exports['ai-core']:RefreshRadial() -- ou aiLib.radial.refresh()
```

#### Paramètres

Aucun.

#### Retour

Rien. Sans menu radial en cours, il ne fait rien.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/radial.ts"
import { onCache, radial } from "@aifivem/lib/client";

// Les entrées de véhicule dépendent du siège : rafraîchir quand il change.
onCache("seat", () => radial.refresh());
```
</Tab>
<Tab value="Lua">
```lua title="client/radial.lua"
-- Les entrées de véhicule dépendent du siège : rafraîchir quand il change.
aiLib.cache.onChange('seat', function() aiLib.radial.refresh() end)
```
</Tab>
</Tabs>
