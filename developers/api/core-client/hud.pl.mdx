Gdy twój skrypt otwiera pełnoekranowe UI (sklep, telefon, tryb zdjęć), HUD powinien zejść z drogi. Te eksporty ukrywają i pokazują HUD, którego używa serwer: ai-hud albo zewnętrzny HUD znany ai-core (tgiann-lumihud, tgiann-hudv2, tgiann-modern-hud, tgiann-statushud, jg-hud, 0r-hud-v3, codem-supreme-hud, Codem-BlackHUDV2, wais-hudv6, qb-hud, ps-hud). Bez znanego HUD ai-core zamiast tego ukrywa i pokazuje minimapę. qb-hud i ps-hud nie dają się ukryć przez inny skrypt: przy nich podąża tylko minimapa.

Ukrywanie działa na **powodach**. Każdy zasób ukrywa HUD pod wybraną przez siebie nazwą (`"shop"`, `"photo-mode"`). HUD zostaje ukryty, dopóki dowolny zasób ma ustawiony co najmniej jeden powód, więc dwa ekrany otwarte naraz nigdy ze sobą nie walczą: HUD wraca dopiero po zamknięciu obu. Powody należą do zasobu, który je ustawił, i są usuwane, gdy się zatrzymuje.

### HideHud

Ukrywa każdy HUD (i minimapę, gdy nie działa żaden znany HUD) pod powodem twojego zasobu. Wywołaj to, gdy otwiera się twoje pełnoekranowe UI.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
HideHud(reason: string): void
```

```lua title="Lua"
exports['ai-core']:HideHud(reason) -- albo aiLib.hud.hide(reason)
```

#### Parametry

<TypeTable
  type={{
    reason: { type: 'string', description: 'Nazwa tego, dlaczego go ukrywasz (`"shop"`). Tylko twój zasób może ją wyczyścić. Ponowne ukrycie pod tą samą nazwą niczego nie zmienia.', required: true },
  }}
/>

#### Zwraca

Nic. `reason`, który nie jest stringiem, jest ignorowany.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/shop.ts"
import { hud } from "@aifivem/lib/client";

export function openShop(): void {
  hud.hide("shop"); // to samo co resourceExport("ai-core").HideHud("shop")
  SetNuiFocus(true, true);
  SendNUIMessage({ action: "open" });
}

RegisterNuiCallback("close", (_data: unknown, cb: (r: unknown) => void) => {
  SetNuiFocus(false, false);
  hud.show("shop");
  cb(true);
});
```
</Tab>
<Tab value="Lua">
```lua title="client/shop.lua"
local function openShop()
  aiLib.hud.hide('shop') -- to samo co exports['ai-core']:HideHud('shop')
  SetNuiFocus(true, true)
  SendNUIMessage({ action = 'open' })
end

RegisterNUICallback('close', function(_, cb)
  SetNuiFocus(false, false)
  aiLib.hud.show('shop')
  cb(true)
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Każde `HideHud` potrzebuje swojego `ShowHud` z tym samym powodem. ai-core sprząta po zasobie, który się zatrzymuje, ale nie po takim, który dalej działa i zapomina wywołać `ShowHud`: wtedy HUD zostaje ukryty dla tego gracza.
</Callout>

### ShowHud

Czyści jeden powód ukrycia twojego zasobu. HUD wraca, gdy żaden zasób nie ma już powodu.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
ShowHud(reason: string): void
```

```lua title="Lua"
exports['ai-core']:ShowHud(reason) -- albo aiLib.hud.show(reason)
```

#### Parametry

<TypeTable
  type={{
    reason: { type: 'string', description: 'Nazwa, którą podałeś do `HideHud`. Nazwa, której twój zasób nigdy nie ustawił, nic nie robi; powód innego zasobu o tej samej nazwie nie jest ruszany.', required: true },
  }}
/>

#### Zwraca

Nic.

#### Przykład

Zobacz przykład [HideHud](#hidehud).

### IsHudVisible

Mówi, czy HUD jest teraz widoczny, czyli czy żaden zasób nie ma ustawionego powodu ukrycia. Zasób HUD używa tego przy starcie; potem śledzi klienckie zdarzenie `ai-core:client:hudVisible`.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
IsHudVisible(): boolean
```

```lua title="Lua"
local visible = exports['ai-core']:IsHudVisible() -- albo aiLib.hud.visible()
```

#### Parametry

Brak.

#### Zwraca

`boolean`: `true`, gdy nie ma ustawionego powodu ukrycia, `false`, dopóki jest co najmniej jeden.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { hud } from "@aifivem/lib/client";

// Własny HUD: zacznij we właściwym stanie, potem śledź każdą zmianę.
function setVisible(visible: boolean): void {
  SendNUIMessage({ action: "visible", data: visible });
}

setVisible(hud.visible);
hud.onChange(setVisible);
```
</Tab>
<Tab value="Lua">
```lua title="client/hud.lua"
-- Własny HUD: zacznij we właściwym stanie, potem śledź każdą zmianę.
local function setVisible(visible)
  SendNUIMessage({ action = 'visible', data = visible })
end

setVisible(aiLib.hud.visible())
AddEventHandler('ai-core:client:hudVisible', setVisible)
```
</Tab>
</Tabs>

### OpenHudSettings

Otwiera własny ekran ustawień działającego HUD (na przykład `/hud` z ai-hud lub tgiann-lumihud). Używa tego pozycja HUD w menu radialnym; może każdy skrypt.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
OpenHudSettings(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenHudSettings() -- boolean
```

#### Parametry

Brak.

#### Zwraca

`boolean`: `true`, gdy działający HUD ma ekran ustawień i został poproszony o jego otwarcie. `false`, gdy nie działa żaden znany HUD albo działający nie ma ekranu ustawień.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify, resourceExport } from "@aifivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

RegisterCommand(
  "hudsettings",
  () => {
    if (!core.OpenHudSettings()) notify(Locale("NO_HUD_SETTINGS"), "error");
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

RegisterCommand('hudsettings', function()
  if not exports['ai-core']:OpenHudSettings() then
    aiLib.notify(Locale('NO_HUD_SETTINGS'), 'error')
  end
end, false)
```
</Tab>
</Tabs>

### HasHudSettings

Mówi, czy działający HUD ma ekran ustawień, więc możesz pokazać lub ukryć przycisk "Ustawienia HUD".

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
HasHudSettings(): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasHudSettings() -- boolean
```

#### Parametry

Brak.

#### Zwraca

`boolean`: `true`, gdy działa znany HUD i ma ekran ustawień, w przeciwnym razie `false`.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/menu.ts"
import { radial, resourceExport } from "@aifivem/lib/client";

const core = resourceExport("ai-core");

// Element radialny widoczny tylko wtedy, gdy HUD ma ustawienia do otwarcia.
radial.add({
  id: "myscript_hud",
  label: "HUD",
  icon: "sliders",
  canShow: () => core.HasHudSettings(),
  onPressed: () => void core.OpenHudSettings(),
});
```
</Tab>
<Tab value="Lua">
```lua title="client/menu.lua"
-- Element radialny widoczny tylko wtedy, gdy HUD ma ustawienia do otwarcia.
aiLib.radial.add({
  id = 'myscript_hud',
  label = 'HUD',
  icon = 'sliders',
  canShow = function() return exports['ai-core']:HasHudSettings() end,
  onPressed = function() exports['ai-core']:OpenHudSettings() end,
})
```
</Tab>
</Tabs>
