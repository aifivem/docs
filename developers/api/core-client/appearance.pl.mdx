Te eksporty przechodzą przez **warstwę wyglądu** ai-core: pracę wykonuje skrypt ubrań, którego używa serwer (ai-appearance, tgiann-clothing, illenium-appearance, qb-clothing, crm-appearance, rcore_clothing, bl_appearance). Twój skrypt nigdy nie dotyka własnego formatu skryptu ubrań, więc działa dalej, gdy właściciel serwera go zmieni.

**Wygląd** ([`CharacterAppearance`](/pl/docs/developers/api/types#characterappearance)) to `{ model, data }`: hash modelu peda i własne dane skryptu ubrań. Traktuj `data` jak zamkniętą skrzynkę: pobierz wygląd z serwera (`appearance.get(charId)` w serwerowym libie, `aiLib.appearance.get` w Lua) lub z `GetPedAppearance` i oddaj go bez zmian.

### ApplyAppearance

Nakłada wygląd na peda przez aktywny skrypt ubrań. Używaj tego, aby ubrać lokalnego peda jak postać (sprzedawca wyglądający jak właściciel, śpiące ciało, zdjęcie) albo aby przywrócić graczowi zapisany wygląd.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
ApplyAppearance(ped: number, look: CharacterAppearance): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:ApplyAppearance(ped, look) -- albo aiLib.appearance.apply(ped, look)
```

#### Parametry

<TypeTable
  type={{
    ped: { type: 'number', description: 'Uchwyt peda. Jego model musi być `model` wyglądu: utwórz peda z `look.model`.', required: true },
    look: { type: 'CharacterAppearance', description: '`{ model, data }` dokładnie tak, jak podał to serwer lub `GetPedAppearance`.', required: true, typeDescriptionLink: '/pl/docs/developers/api/types#characterappearance' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt ubrań dostał wygląd. `false`, gdy ped nie istnieje, jego model różni się od `look.model`, wygląd nie jest tabelą `{ model, data }` albo nie działa żaden skrypt ubrań.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { appearance, onClientCallback, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Własny zapisany wygląd pytającego gracza.
onClientCallback("myscript:myLook", async (source) => {
  const character = core.GetCharacter(source);
  return character ? await appearance.get(character.id) : null;
});
```

```ts title="resource/client/index.ts"
import { appearance, requestModel, triggerServerCallback } from "@aifivem/lib/client";
import { toCharacterAppearance } from "@aifivem/shared";

// Lokalna kopia gracza stojąca w punkcie, ubrana jak on.
export async function spawnLookalike(x: number, y: number, z: number): Promise<number> {
  const look = toCharacterAppearance(await triggerServerCallback("myscript:myLook", []));
  if (!look) return 0;
  await requestModel(look.model);
  const ped = CreatePed(4, look.model, x, y, z, 0, false, false);
  SetModelAsNoLongerNeeded(look.model);
  appearance.apply(ped, look);
  return ped;
}
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
-- Własny zapisany wygląd pytającego gracza.
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  return character and aiLib.appearance.get(character.id) or nil
end)
```

```lua title="client.lua"
-- Lokalna kopia gracza stojąca w punkcie, ubrana jak on (wywołuj z wątku).
local function spawnLookalike(x, y, z)
  local look = aiLib.triggerServerCallback('myscript:myLook', {})
  if not look then return 0 end
  aiLib.requestModel(look.model)
  local ped = CreatePed(4, look.model, x, y, z, 0.0, false, false)
  SetModelAsNoLongerNeeded(look.model)
  aiLib.appearance.apply(ped, look)
  return ped
end
```
</Tab>
</Tabs>

<Callout type="warn">
Na własnym pedzie gracza `ApplyAppearance` zmienia to, co nosi teraz. Czy ta zmiana zostanie zapisana, to reguła skryptu ubrań, nie ai-core. Aby ubrać gracza w mundur, który nigdy nie jest zapisywany, użyj [WearOutfit](#wearoutfit).
</Callout>

### GetPedAppearance

Zwraca wygląd, który ped nosi w tej chwili, w tym samym kształcie `{ model, data }`, którego używają wyglądy zapisane na serwerze.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
GetPedAppearance(ped: number): CharacterAppearance | null
```

```lua title="Lua"
local look = exports['ai-core']:GetPedAppearance(ped) -- albo aiLib.appearance.read(ped)
```

#### Parametry

<TypeTable
  type={{
    ped: { type: 'number', description: 'Uchwyt peda (`cache.ped` dla lokalnego gracza).', required: true },
  }}
/>

#### Zwraca

[`CharacterAppearance`](/pl/docs/developers/api/types#characterappearance): `model` to hash modelu peda, `data` to dane skryptu ubrań. `null`, gdy ped nie istnieje, nie działa żaden skrypt ubrań albo skrypt ubrań nie umie odczytać tego peda (niektóre czytają tylko własnego peda lokalnego gracza).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/photo.ts"
import { appearance, cache } from "@aifivem/lib/client";

// Kopiuje to, co gracz teraz nosi, na innego peda tego samego modelu.
export function copyPlayerLook(target: number): boolean {
  const look = appearance.read(cache.ped);
  return look !== null && appearance.apply(target, look);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/photo.lua"
-- Kopiuje to, co gracz teraz nosi, na innego peda tego samego modelu.
local function copyPlayerLook(target)
  local look = aiLib.appearance.read(aiLib.cache.ped)
  return look ~= nil and aiLib.appearance.apply(target, look)
end
```
</Tab>
</Tabs>

### OpenClothingMenu

Otwiera dla lokalnego gracza jedno z menu aktywnego skryptu ubrań: sklep z ubraniami, fryzjera albo jego zapisane stroje. Używaj tego dla własnych znaczników sklepów albo szafy w domu.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
OpenClothingMenu(menu: ClothingMenu): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenClothingMenu(menu) -- albo aiLib.appearance.openMenu(menu)
```

#### Parametry

<TypeTable
  type={{
    menu: { type: '"clothing" | "barber" | "outfits"', description: '`clothing`: sklep z ubraniami. `barber`: włosy, broda i makijaż. `outfits`: zapisane stroje gracza (szafa).', required: true, typeDescriptionLink: '/pl/docs/developers/api/types#clothingmenu' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt ubrań otworzył menu. `false` dla nieznanego `menu`, gdy nie działa żaden skrypt ubrań albo działający nie ma takiego menu.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/wardrobe.ts"
import { appearance, notify, Points } from "@aifivem/lib/client";
import { Locale } from "common";

const points = new Points();

// Szafa w pokoju motelowym.
points.add("motel_wardrobe", {
  coords: { x: 151.3, y: -1001.2, z: -99.0 },
  label: Locale("WARDROBE"),
  onPressed: () => {
    if (!appearance.openMenu("outfits")) notify(Locale("NO_WARDROBE"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/wardrobe.lua"
local Locale = aiLib.locale()

RegisterCommand('wardrobe', function()
  if not aiLib.appearance.openMenu('outfits') then
    aiLib.notify(Locale('NO_WARDROBE'), 'error')
  end
end, false)
```
</Tab>
</Tabs>

### WearOutfit

Nakłada strój pracy (mundur) na lokalnego gracza do czasu `ReloadSkin`. Zmieniają się tylko części, które wymienisz; reszta ubrań zostaje. Strój nigdy nie jest zapisywany jako własny wygląd gracza.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
WearOutfit(outfit: JobOutfit): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:WearOutfit(outfit) -- albo aiLib.appearance.wearOutfit(outfit)
```

#### Parametry

<TypeTable
  type={{
    outfit: { type: 'JobOutfit', description: 'Części do założenia. Pola poniżej.', required: true, typeDescriptionLink: '/pl/docs/developers/api/types#joboutfit' },
  }}
/>

#### JobOutfit

<TypeTable
  type={{
    components: { type: 'OutfitPiece[]', description: 'Komponenty ubrań (tors, nogi, buty...): `id` 0-11.', required: true, typeDescriptionLink: '/pl/docs/developers/api/types#outfitpiece' },
    props: { type: 'OutfitPiece[]', description: 'Propy (czapki, okulary, zegarki...): `id` 0-13.', required: true, typeDescriptionLink: '/pl/docs/developers/api/types#outfitpiece' },
  }}
/>

#### OutfitPiece

Zobacz też [OutfitPiece](/pl/docs/developers/api/types#outfitpiece).

<TypeTable
  type={{
    id: { type: 'number', description: 'Id komponentu (0-11) lub id propa (0-13).', required: true },
    collection: { type: 'string', description: 'Nazwa kolekcji ubrań (DLC), z której pochodzi część; `""` dla podstawowej gry. Najwyżej 64 znaki.', required: true },
    index: { type: 'number', description: 'Indeks drawable w tej kolekcji (0-1023). Dla propa `-1` zdejmuje propa.', required: true },
    texture: { type: 'number', description: 'Tekstura (wariant koloru). Brakująca lub ujemna wartość liczy się jako 0.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt ubrań założył strój. `false`, gdy po sprawdzeniu nie została żadna poprawna część, nie działa żaden skrypt ubrań albo działający nie umie zakładać strojów. Niepoprawne części (zły zakres id, zły indeks) są odrzucane pojedynczo; poprawne i tak zostają założone.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/locker.ts"
import { appearance } from "@aifivem/lib/client";
import type { JobOutfit } from "@aifivem/shared";

// Prosty mundur z części podstawowej gry: koszula, spodnie, buty, bez czapki.
const UNIFORM: JobOutfit = {
  components: [
    { id: 11, collection: "", index: 55, texture: 0 },
    { id: 4, collection: "", index: 35, texture: 0 },
    { id: 6, collection: "", index: 25, texture: 0 },
  ],
  props: [{ id: 0, collection: "", index: -1, texture: 0 }],
};

export const putOnUniform = (): boolean => appearance.wearOutfit(UNIFORM);
export const takeOffUniform = (): boolean => appearance.reloadSkin();
```
</Tab>
<Tab value="Lua">
```lua title="client/locker.lua"
-- Prosty mundur z części podstawowej gry: koszula, spodnie, buty, bez czapki.
local UNIFORM = {
  components = {
    { id = 11, collection = '', index = 55, texture = 0 },
    { id = 4, collection = '', index = 35, texture = 0 },
    { id = 6, collection = '', index = 25, texture = 0 },
  },
  props = { { id = 0, collection = '', index = -1, texture = 0 } },
}

local function putOnUniform() return aiLib.appearance.wearOutfit(UNIFORM) end
local function takeOffUniform() return aiLib.appearance.reloadSkin() end
```
</Tab>
</Tabs>

<Callout type="info">
Indeksy drawable różnią się między męskim i żeńskim modelem freemode: trzymaj jeden strój na model i wybieraj go według modelu gracza.
</Callout>

### ReloadSkin

Przywraca lokalnemu graczowi jego zapisany wygląd. Używaj tego, aby zdjąć strój pracy.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
ReloadSkin(): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:ReloadSkin() -- albo aiLib.appearance.reloadSkin()
```

#### Parametry

Brak.

#### Zwraca

`boolean`: `true`, gdy skrypt ubrań został poproszony o ponowne wczytanie wyglądu. `false`, gdy nie działa żaden skrypt ubrań albo działający nie umie ponownie wczytać wyglądu.

#### Przykład

Zobacz przykład [WearOutfit](#wearoutfit).
