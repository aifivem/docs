MDT (mobil veri terminali) polis bilgisayarıdır: kayıtlar, arama kararları, raporlar. ai-core’un **MDT katmanı** sunucunun çalıştırdığını açar, böylece script’indeki bir radyal öğe, bir tuş ya da bir araç laptopu doğru ekranı açar. Başka bir script’ten açılabilen desteklenen MDT’ler: tgiann-mdt, ps-mdt, wasabi_mdt.

### OpenMdt

Yerel oyuncu için aktif MDT’nin ekranını açar. MDT oyuncunun mesleğini kendisi kontrol eder ve kullanamayacak bir oyuncuyu reddeder.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
OpenMdt(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenMdt() -- ya da aiLib.mdt.open()
```

#### Parametreler

Yok.

#### Dönüş değeri

`boolean`: aktif MDT’den açması istendiğinde `true`. Desteklenen bir MDT çalışmıyorsa ya da çalışan başka bir script’ten açılamıyorsa `false`. `true` ekranın göründüğü anlamına gelmez: MDT oyuncunun mesleğini yine de reddedebilir.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/laptop.ts"
import { cache, getPlayerData, mdt, notify, radial } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import { Locale } from "common";

// Mesaideki polis için araç alt menüsünde bir laptop girişi.
radial.add({
  id: "myscript_mdt",
  label: Locale("RADIAL_MDT"),
  icon: "laptop",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && getPlayerData("duty") === "police",
  onPressed: () => {
    if (!mdt.open()) notify(Locale("NO_MDT"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/laptop.lua"
local Locale = aiLib.locale()

-- Mesaideki polis için araç alt menüsünde bir laptop girişi.
aiLib.radial.add({
  id = 'myscript_mdt',
  label = Locale('RADIAL_MDT'),
  icon = 'laptop',
  parent = 'vehicle',
  canShow = function()
    return aiLib.cache.vehicle ~= false and aiLib.playerData.get('duty') == 'police'
  end,
  onPressed = function()
    if not aiLib.mdt.open() then aiLib.notify(Locale('NO_MDT'), 'error') end
  end,
})
```
