Erhobene Hände, Zeigen und Emotes kommen aus einem Emote-Skript. ai-core fragt das, das läuft, sodass eine Polizeidurchsuchung („sind seine Hände oben?“) oder eine Job-Animation mit jedem von ihnen funktioniert.

Zwei Listen werden getrennt geführt, weil nicht jedes Skript beides kann:

- **Gesten** (Hände hoch, Zeigen): tgiann-emotes, codem-emotemenu, rpemotes (und rpemotes-reborn), 0r-animmenu, ai-smallresources. Das erste, das in dieser Reihenfolge läuft, antwortet.
- **Emotes** (per Name abspielen, stoppen): tgiann-emotes, rpemotes (und rpemotes-reborn), scully_emotemenu, dpemotes. Das erste, das in dieser Reihenfolge läuft, antwortet.

### IsHandsUp

Sagt, ob der lokale Spieler die Hände oben hat, in dem Emote-Skript, das Gesten beantwortet.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
IsHandsUp(): boolean
```

```lua title="Lua"
local up = exports['ai-core']:IsHandsUp() -- oder aiLib.gestures.isHandsUp()
```

#### Parameter

Keine.

#### Rückgabe

`boolean`: `true`, solange die Hände oben sind. `false`, wenn nicht oder wenn kein Gesten-Skript läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/rob.ts"
import { gestures, notify } from "@aifivem/lib/client";
import { Locale } from "common";

RegisterCommand(
  "surrender_check",
  () => notify(Locale(gestures.isHandsUp() ? "HANDS_UP" : "HANDS_DOWN")),
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client/rob.lua"
local Locale = aiLib.locale()

RegisterCommand('surrender_check', function()
  aiLib.notify(Locale(aiLib.gestures.isHandsUp() and 'HANDS_UP' or 'HANDS_DOWN'))
end, false)
```
</Tab>
</Tabs>

<Callout type="info">
Das liest nur den **lokalen** Spieler. Um zu wissen, ob ein anderer Spieler die Hände oben hat (ein Überfall, eine Durchsuchung), frage den Server, der den Client dieses Spielers fragt.
</Callout>

### IsPointing

Sagt, ob der lokale Spieler zeigt, in dem Emote-Skript, das Gesten beantwortet.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
IsPointing(): boolean
```

```lua title="Lua"
local pointing = exports['ai-core']:IsPointing() -- oder aiLib.gestures.isPointing()
```

#### Parameter

Keine.

#### Rückgabe

`boolean`: `true`, solange er zeigt. `false`, wenn nicht, wenn kein Gesten-Skript läuft oder das laufende es nicht sagen kann (0r-animmenu hat keine Zeige-Prüfung).

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { gestures } from "@aifivem/lib/client";

RegisterCommand("ispointing", () => console.log(gestures.isPointing()), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('ispointing', function() print(aiLib.gestures.isPointing()) end, false)
```
</Tab>
</Tabs>

### GetGestureProvider

Gibt den Ressourcennamen des Emote-Skripts zurück, das erhobene Hände und Zeigen beantwortet.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
GetGestureProvider(): string | null
```

```lua title="Lua"
local provider = exports['ai-core']:GetGestureProvider() -- oder aiLib.gestures.provider()
```

#### Parameter

Keine.

#### Rückgabe

`string`: der Ressourcenname (`"tgiann-emotes"`). `null`, wenn keines der unterstützten Skripte läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { gestures } from "@aifivem/lib/client";

// Nutze deine eigene Hände-hoch-Taste nur, wenn kein Emote-Skript eine anbietet.
if (gestures.provider() === null) console.log("no gesture script, enabling my own hands-up key");
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
-- Nutze deine eigene Hände-hoch-Taste nur, wenn kein Emote-Skript eine anbietet.
if aiLib.gestures.provider() == nil then print('no gesture script, enabling my own hands-up key') end
```
</Tab>
</Tabs>

### PlayEmote

Spielt ein Emote des laufenden Emote-Skripts über seinen Befehlsnamen ab, den Namen, den Spieler nach `/e` tippen (`"sit"`, `"notepad"`).

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
PlayEmote(name: string): boolean
```

```lua title="Lua"
local played = exports['ai-core']:PlayEmote(name) -- oder aiLib.gestures.playEmote(name)
```

#### Parameter

<TypeTable
  type={{
    name: { type: 'string', description: 'Der Befehlsname des Emotes: 1 bis 32 Buchstaben, Ziffern, `_` oder `-`. Namen unterscheiden sich zwischen Emote-Skripten; nutze gängige oder lass den Serverbesitzer den Namen festlegen.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn der Name gültig ist und ein Emote-Skript aufgefordert wurde, es abzuspielen. `false` für einen ungültigen Namen oder wenn kein Emote-Skript läuft. `true` beweist nicht, dass das Emote in diesem Skript existiert: Ein unbekannter Name spielt einfach nichts ab.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/notes.ts"
import { gestures, progress } from "@aifivem/lib/client";
import { Locale } from "common";

// Schreibt eine Notiz mit dem Notizblock-Emote, während der Balken läuft.
export async function writeNote(): Promise<boolean> {
  gestures.playEmote("notepad");
  const done = await progress({ label: Locale("WRITING"), duration: 5000, canCancel: true });
  gestures.cancelEmote();
  return done;
}
```
</Tab>
<Tab value="Lua">
```lua title="client/notes.lua"
local Locale = aiLib.locale()

-- Schreibt eine Notiz mit dem Notizblock-Emote, während der Balken läuft (aus einem Thread aufrufen).
local function writeNote()
  aiLib.gestures.playEmote('notepad')
  local done = aiLib.progress({ label = Locale('WRITING'), duration = 5000, canCancel = true })
  aiLib.gestures.cancelEmote()
  return done
end
```
</Tab>
</Tabs>

### CancelEmote

Stoppt das Emote, das der lokale Spieler im laufenden Emote-Skript abspielt. Nutze es, wenn dein Skript die Hände des Spielers braucht (Fesseln, ein Niederschlag, ein Minispiel).

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
CancelEmote(): boolean
```

```lua title="Lua"
local stopped = exports['ai-core']:CancelEmote() -- oder aiLib.gestures.cancelEmote()
```

#### Parameter

Keine.

#### Rückgabe

`boolean`: `true`, wenn ein Emote-Skript zum Stoppen aufgefordert wurde (auch wenn nichts lief), `false`, wenn kein Emote-Skript läuft.

#### Beispiel

Siehe das Beispiel zu [PlayEmote](#playemote).

### GetEmoteProvider

Gibt den Ressourcennamen des Emote-Skripts zurück, das Emotes per Name abspielt.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
GetEmoteProvider(): string | null
```

```lua title="Lua"
local provider = exports['ai-core']:GetEmoteProvider() -- oder aiLib.gestures.emoteProvider()
```

#### Parameter

Keine.

#### Rückgabe

`string`: der Ressourcenname (`"rpemotes"`). `null`, wenn keines der unterstützten Emote-Skripte läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { gestures, player } from "@aifivem/lib/client";

// Bevorzuge das Emote-Skript des Servers, falle auf eine einfache Animation zurück.
export function sitDown(): void {
  if (gestures.emoteProvider() !== null) gestures.playEmote("sit");
  else void player.playAnim("anim@amb@business@bgen@bgen_no_work@", "sit_phone_phoneputdown_idle_nowork");
}
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
-- Bevorzuge das Emote-Skript des Servers, falle auf eine einfache Animation zurück (aus einem Thread aufrufen).
local function sitDown()
  if aiLib.gestures.emoteProvider() ~= nil then
    aiLib.gestures.playEmote('sit')
  else
    aiLib.player.playAnim('anim@amb@business@bgen@bgen_no_work@', 'sit_phone_phoneputdown_idle_nowork')
  end
end
```
</Tab>
</Tabs>
