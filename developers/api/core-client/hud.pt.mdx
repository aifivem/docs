Quando seu script abre uma UI de tela cheia (uma loja, um celular, um modo foto), o HUD deve sair do caminho. Estes exports escondem e mostram o HUD que o servidor roda: ai-hud, ou um HUD de terceiros que o ai-core conhece (tgiann-lumihud, tgiann-hudv2, tgiann-modern-hud, tgiann-statushud, jg-hud, 0r-hud-v3, codem-supreme-hud, Codem-BlackHUDV2, wais-hudv6, qb-hud, ps-hud). Sem nenhum HUD conhecido, o ai-core esconde e mostra o minimapa. O qb-hud e o ps-hud não podem ser escondidos por outro script: com eles só o minimapa acompanha.

Esconder funciona com **motivos**. Cada recurso esconde o HUD sob um nome de sua escolha (`"shop"`, `"photo-mode"`). Os HUDs ficam escondidos enquanto pelo menos um motivo estiver definido por qualquer recurso, então duas telas abertas ao mesmo tempo nunca brigam: o HUD só volta depois que as duas fecham. Os motivos pertencem ao recurso que os definiu e são removidos quando ele para.

### HideHud

Esconde todos os HUDs (e o minimapa quando nenhum HUD conhecido está rodando) sob um motivo do seu recurso. Chame quando sua UI de tela cheia abrir.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
HideHud(reason: string): void
```

```lua title="Lua"
exports['ai-core']:HideHud(reason) -- ou aiLib.hud.hide(reason)
```

#### Parâmetros

<TypeTable
  type={{
    reason: { type: 'string', description: 'Um nome para o motivo de esconder (`"shop"`). Só o seu recurso pode limpá-lo. Esconder de novo sob o mesmo nome não muda nada.', required: true },
  }}
/>

#### Retorno

Nada. Um `reason` que não é string é ignorado.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/shop.ts"
import { hud } from "@aifivem/lib/client";

export function openShop(): void {
  hud.hide("shop"); // o mesmo que resourceExport("ai-core").HideHud("shop")
  SetNuiFocus(true, true);
  SendNUIMessage({ action: "open" });
}

RegisterNuiCallback("close", (_data: unknown, cb: (r: unknown) => void) => {
  SetNuiFocus(false, false);
  hud.show("shop");
  cb(true);
});
```
</Tab>
<Tab value="Lua">
```lua title="client/shop.lua"
local function openShop()
  aiLib.hud.hide('shop') -- o mesmo que exports['ai-core']:HideHud('shop')
  SetNuiFocus(true, true)
  SendNUIMessage({ action = 'open' })
end

RegisterNUICallback('close', function(_, cb)
  SetNuiFocus(false, false)
  aiLib.hud.show('shop')
  cb(true)
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Cada `HideHud` precisa do seu `ShowHud` com o mesmo motivo. O ai-core limpa depois de um recurso que para, mas não depois de um que continua rodando e esquece de chamar `ShowHud`: o HUD então fica escondido para aquele jogador.
</Callout>

### ShowHud

Limpa um motivo de esconder do seu recurso. Os HUDs voltam quando nenhum recurso tem mais motivo.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
ShowHud(reason: string): void
```

```lua title="Lua"
exports['ai-core']:ShowHud(reason) -- ou aiLib.hud.show(reason)
```

#### Parâmetros

<TypeTable
  type={{
    reason: { type: 'string', description: 'O nome que você passou para `HideHud`. Um nome que seu recurso nunca definiu não faz nada; o motivo de outro recurso com o mesmo nome não é tocado.', required: true },
  }}
/>

#### Retorno

Nada.

#### Exemplo

Veja o exemplo de [HideHud](#hidehud).

### IsHudVisible

Diz se os HUDs aparecem agora, ou seja, se nenhum recurso tem um motivo de esconder definido. Um recurso de HUD usa isto ao iniciar; depois segue o evento de cliente `ai-core:client:hudVisible`.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
IsHudVisible(): boolean
```

```lua title="Lua"
local visible = exports['ai-core']:IsHudVisible() -- ou aiLib.hud.visible()
```

#### Parâmetros

Nenhum.

#### Retorno

`boolean`: `true` quando nenhum motivo de esconder está definido, `false` enquanto pelo menos um estiver.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { hud } from "@aifivem/lib/client";

// Um HUD próprio: começa no estado certo e depois segue cada mudança.
function setVisible(visible: boolean): void {
  SendNUIMessage({ action: "visible", data: visible });
}

setVisible(hud.visible);
hud.onChange(setVisible);
```
</Tab>
<Tab value="Lua">
```lua title="client/hud.lua"
-- Um HUD próprio: começa no estado certo e depois segue cada mudança.
local function setVisible(visible)
  SendNUIMessage({ action = 'visible', data = visible })
end

setVisible(aiLib.hud.visible())
AddEventHandler('ai-core:client:hudVisible', setVisible)
```
</Tab>
</Tabs>

### OpenHudSettings

Abre a tela de configurações do próprio HUD ativo (o `/hud` do ai-hud ou do tgiann-lumihud, por exemplo). A entrada de HUD do menu radial usa isto; qualquer script pode.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
OpenHudSettings(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenHudSettings() -- boolean
```

#### Parâmetros

Nenhum.

#### Retorno

`boolean`: `true` quando o HUD ativo tem uma tela de configurações e ela recebeu o pedido de abrir. `false` quando nenhum HUD conhecido está rodando ou o que está rodando não tem tela de configurações.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify, resourceExport } from "@aifivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

RegisterCommand(
  "hudsettings",
  () => {
    if (!core.OpenHudSettings()) notify(Locale("NO_HUD_SETTINGS"), "error");
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

RegisterCommand('hudsettings', function()
  if not exports['ai-core']:OpenHudSettings() then
    aiLib.notify(Locale('NO_HUD_SETTINGS'), 'error')
  end
end, false)
```
</Tab>
</Tabs>

### HasHudSettings

Diz se o HUD ativo tem uma tela de configurações, para você mostrar ou esconder um botão "HUD settings".

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
HasHudSettings(): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasHudSettings() -- boolean
```

#### Parâmetros

Nenhum.

#### Retorno

`boolean`: `true` quando um HUD conhecido está rodando e tem uma tela de configurações, `false` caso contrário.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/menu.ts"
import { radial, resourceExport } from "@aifivem/lib/client";

const core = resourceExport("ai-core");

// Um item radial que só aparece quando o HUD tem configurações para abrir.
radial.add({
  id: "myscript_hud",
  label: "HUD",
  icon: "sliders",
  canShow: () => core.HasHudSettings(),
  onPressed: () => void core.OpenHudSettings(),
});
```
</Tab>
<Tab value="Lua">
```lua title="client/menu.lua"
-- Um item radial que só aparece quando o HUD tem configurações para abrir.
aiLib.radial.add({
  id = 'myscript_hud',
  label = 'HUD',
  icon = 'sliders',
  canShow = function() return exports['ai-core']:HasHudSettings() end,
  onPressed = function() exports['ai-core']:OpenHudSettings() end,
})
```
</Tab>
</Tabs>
