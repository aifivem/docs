Cada script `ai-*` muestra notificaciones a través de ai-lib (`notify` en la lib, `aiLib.notify` en Lua). ai-lib dibuja sus propias tarjetas, salvo que el dueño del servidor haya elegido otra interfaz de notificaciones en el panel de ai-core (tgiann-lumihud, okokNotify, ox_lib, mythic_notify, brutal_notify). Entonces ai-lib entrega cada tarjeta a ai-core, y ai-core la traduce a la llamada de esa interfaz.

**No lo llamas tú.** Para mostrar una notificación, usa `notify(text, kind, duration)` de la lib o `aiLib.notify(text, kind, duration)`: eligen la interfaz correcta. Esta página existe para que sepas qué hace el export cuando lo veas.

### ExternalNotify

Muestra una tarjeta de notificación de ai-lib en la interfaz de notificaciones que eligió el panel. ai-lib lo llama para cada tarjeta mientras haya una interfaz de terceros elegida.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
ExternalNotify(notification: Notification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:ExternalNotify({ text = 'Saved', kind = 'success' }) -- boolean
```

#### Notification

<TypeTable
  type={{
    text: { type: 'string', description: 'El mensaje, ya traducido. Se corta a 300 caracteres.', required: true },
    title: { type: 'string', description: 'Un título opcional, ya traducido. Se corta a 60 caracteres.' },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'El estilo de la tarjeta. Cualquier otro valor cuenta como `"info"`. Cada interfaz recibe su propia palabra para él (el `inform` de ox_lib para `info`, por ejemplo).', required: true },
    duration: { type: 'number', description: 'Milisegundos en pantalla. Las interfaces que necesitan un valor reciben 4000 cuando se omite.' },
  }}
/>

#### Devuelve

`boolean`: `true` cuando hay una interfaz de terceros elegida, en marcha, y recibió la tarjeta. `false` cuando la tarjeta no tiene texto, o cuando no hay ninguna interfaz de terceros elegida o en marcha: entonces ai-lib dibuja la tarjeta por sí misma.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify } from "@aifivem/lib/client";
import { Locale } from "common";

// La forma correcta de notificar: ai-lib llama a ExternalNotify por ti cuando hay una interfaz de terceros elegida.
RegisterCommand("saved", () => notify(Locale("SAVED"), "success", 3000), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

-- La forma correcta de notificar: ai-lib llama a ExternalNotify por ti cuando hay una interfaz de terceros elegida.
RegisterCommand('saved', function() aiLib.notify(Locale('SAVED'), 'success', 3000) end, false)
```
</Tab>
</Tabs>

<Callout type="info">
El nombre de recurso de la interfaz elegida está en el GlobalState `ai:notify` (sin definir mientras ai-lib dibuja sus propias tarjetas). Consulta [State bags](/es/docs/developers/api/events/state-bags).
</Callout>
