El MDT (mobile data terminal) es el ordenador de la policía: registros, órdenes de búsqueda, informes. La **capa de MDT** de ai-core abre el que tenga el servidor, así que un elemento radial, una tecla o un portátil de vehículo en tu script abre la pantalla correcta. MDT compatibles que se pueden abrir desde otro script: tgiann-mdt, ps-mdt, wasabi_mdt.

### OpenMdt

Abre la pantalla del MDT activo para el jugador local. El MDT comprueba por sí mismo el trabajo del jugador y rechaza a un jugador que no puede usarlo.

**Lado:** Cliente · **Espera:** no

```ts title="Firma"
OpenMdt(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenMdt() -- o aiLib.mdt.open()
```

#### Parámetros

Ninguno.

#### Devuelve

`boolean`: `true` cuando se pidió al MDT activo que se abra. `false` cuando no hay ningún MDT compatible en marcha, o el que está en marcha no se puede abrir desde otro script. `true` no significa que se mostrara la pantalla: el MDT aún puede rechazar el trabajo del jugador.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/laptop.ts"
import { cache, getPlayerData, mdt, notify, radial } from "@aicore-fivem/lib/client";
import { RADIAL_VEHICLE } from "@aicore-fivem/shared";
import { Locale } from "common";

// Una entrada de portátil en el submenú de vehículo para la policía de servicio.
radial.add({
  id: "myscript_mdt",
  label: Locale("RADIAL_MDT"),
  icon: "laptop",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && getPlayerData("duty") === "police",
  onPressed: () => {
    if (!mdt.open()) notify(Locale("NO_MDT"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/laptop.lua"
local Locale = aiLib.locale()

-- Una entrada de portátil en el submenú de vehículo para la policía de servicio.
aiLib.radial.add({
  id = 'myscript_mdt',
  label = Locale('RADIAL_MDT'),
  icon = 'laptop',
  parent = 'vehicle',
  canShow = function()
    return aiLib.cache.vehicle ~= false and aiLib.playerData.get('duty') == 'police'
  end,
  onPressed = function()
    if not aiLib.mdt.open() then aiLib.notify(Locale('NO_MDT'), 'error') end
  end,
})
```
