ai-core śledzi każdy klawisz, który skrypty rejestrują przez `Keybind` liba (TypeScript) lub `aiLib.Keybind` (Lua). Dzięki temu karta Keybinds w panelu administratora może zmienić domyślny klawisz skryptu, HUD może wyświetlać podpowiedzi klawiszy po lewej stronie ekranu, a ekran klawiszy może pokazać każdy klawisz z akcją.

**Podpowiedź klawisza** to krótki wiersz na HUD: klawisz i to, co robi (`E  Otwórz bagażnik`). Skróty klawiszowe mogą ją zadeklarować opcją `hint`. Skrypt może też pokazywać podpowiedzi przez jakiś czas przez `ShowKeyHint`, na przykład sterowanie narzędzia, gdy jest w użyciu.

### GetKeybindKey

Zwraca klawisz, z którym zarejestrowano `Keybind` liba: klawisz ustawiony przez właściciela serwera w karcie Keybinds panelu administratora, w przeciwnym razie własny domyślny klawisz skryptu. Gracz mógł go jeszcze zmienić w ustawieniach klawiszy GTA; klawisz, który naprawdę naciska, odczytasz z `Keybind.currentKey` swojego skrótu.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
GetKeybindKey(name: string): string | null
```

```lua title="Lua"
local key = exports['ai-core']:GetKeybindKey(name) -- string lub nil
```

#### Parametry

<TypeTable
  type={{
    name: { type: 'string', description: '`name` skrótu tak, jak skrypt podał go do `Keybind` (`"myscript_open"`).', required: true },
  }}
/>

#### Zwraca

`string`: klawisz wielkimi literami (`"F5"`, `"E"`) albo `""` dla skrótu bez domyślnego klawisza. `null`, dopóki ai-core nie odpowiedział na ten skrót (krótko po starcie jego zasobu), i dla nazw, których nie zarejestrował żaden działający zasób.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { Keybind, resourceExport } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

const open = new Keybind({
  name: "myscript_open",
  description: Locale("KEY_OPEN"),
  defaultKey: "F5",
  onPressed: () => console.log("open"),
});

RegisterCommand(
  "myscript_keys",
  () => {
    console.log(`registered with: ${core.GetKeybindKey("myscript_open") ?? "not yet"}`);
    console.log(`the player presses: ${open.currentKey}`);
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

aiLib.Keybind.new({
  name = 'myscript_open',
  description = Locale('KEY_OPEN'),
  defaultKey = 'F5',
  onPressed = function() print('open') end,
})

RegisterCommand('myscript_keys', function()
  print(('registered with: %s'):format(exports['ai-core']:GetKeybindKey('myscript_open') or 'not yet'))
end, false)
```
</Tab>
</Tabs>

### ShowKeyHint

Pokazuje podpowiedź klawisza twojego zasobu na liście podpowiedzi HUD, dopóki jej nie ukryjesz. Używaj tego dla klawiszy ważnych tylko przez jakiś czas: sterowanie narzędzia, minigra, tryb kamery. Klawisze, które twoje skróty zawsze oferują, należą do opcji `hint` w `Keybind`.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
ShowKeyHint(id: string, hint: KeyHintRequest): void
```

```lua title="Lua"
exports['ai-core']:ShowKeyHint(id, hint) -- albo aiLib.keyHints.show(id, hint)
```

#### Parametry

<TypeTable
  type={{
    id: { type: 'string', description: 'Twoja nazwa tej podpowiedzi (`"camera_zoom"`). Ponowne pokazanie tego samego id zastępuje podpowiedź. Id są per zasób, więc `camera_zoom` innego skryptu to inna podpowiedź.', required: true },
    hint: { type: 'KeyHintRequest', description: 'Co pokazuje wiersz. Pola poniżej.', required: true, typeDescriptionLink: '/docs/developers/api/types#keyhintrequest' },
  }}
/>

#### KeyHintRequest

Zobacz też [KeyHintRequest](/pl/docs/developers/api/types#keyhintrequest).

<TypeTable
  type={{
    label: { type: 'string', description: 'Co robi klawisz, już przetłumaczone (`Locale("HINT_ZOOM")`). Obcinane do 60 znaków.', required: true },
    keybind: { type: 'string', description: '`name` skrótu klawiszowego: podpowiedź pokazuje klawisz, który gracz teraz do niego przypisał, i podąża za zmianą przypisania. Ma pierwszeństwo przed `key`.' },
    key: { type: 'string', description: 'Dosłowny tekst klawisza (`"SCROLL"`, `"SHIFT"`), gdy nie stoi za nim żaden skrót. Obcinany do 16 znaków.' },
    icon: { type: 'string', description: 'Nazwa ikony Font Awesome solid bez `fa-` (`"magnifying-glass"`). HUD rysuje ikonę klawisza, gdy jej nie zna. Obcinana do 32 znaków.' },
  }}
/>

#### Zwraca

Nic. Podpowiedź bez tekstowego `label` albo z `id`, które nie jest stringiem, jest ignorowana. Podpowiedź, której klawisz nie daje się ustalić (ani `keybind`, ani `key` nie daje klawisza), jest zachowana, ale nie wyświetlana.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/camera.ts"
import { keyHints } from "@aicore-fivem/lib/client";
import { Locale } from "common";

export function startCamera(): void {
  keyHints.show("camera_zoom", { label: Locale("HINT_ZOOM"), key: "SCROLL", icon: "magnifying-glass" });
  keyHints.show("camera_exit", { label: Locale("HINT_EXIT"), keybind: "myscript_camera" });
}

export function stopCamera(): void {
  keyHints.hide("camera_zoom");
  keyHints.hide("camera_exit");
}
```
</Tab>
<Tab value="Lua">
```lua title="client/camera.lua"
local Locale = aiLib.locale()

local function startCamera()
  aiLib.keyHints.show('camera_zoom', { label = Locale('HINT_ZOOM'), key = 'SCROLL', icon = 'magnifying-glass' })
  aiLib.keyHints.show('camera_exit', { label = Locale('HINT_EXIT'), keybind = 'myscript_camera' })
end

local function stopCamera()
  aiLib.keyHints.hide('camera_zoom')
  aiLib.keyHints.hide('camera_exit')
end
```
</Tab>
</Tabs>

<Callout type="info">
Podpowiedzi są wyświetlane w kolejności, w jakiej skrypty je pokazały, po podpowiedziach zadeklarowanych przez skróty. Podpowiedzi twojego zasobu są usuwane, gdy się zatrzymuje.
</Callout>

### HideKeyHint

Ukrywa jedną podpowiedź klawisza, którą pokazał twój zasób.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
HideKeyHint(id: string): void
```

```lua title="Lua"
exports['ai-core']:HideKeyHint(id) -- albo aiLib.keyHints.hide(id)
```

#### Parametry

<TypeTable
  type={{

  }}
/>

#### Zwraca

Nic.

### GetKeyHints

Zwraca wiersze podpowiedzi klawiszy, które HUD powinien teraz pokazać: podpowiedzi zadeklarowane przez skróty dla sytuacji gracza (pieszo lub w pojeździe, jak ustawił to właściciel serwera w panelu) oraz podpowiedzi pokazywane przez skrypty. HUD czyta to raz przy starcie, a potem śledzi klienckie zdarzenie `ai-core:client:keyHints`, które niesie tę samą listę po każdej zmianie.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
GetKeyHints(): KeyHintView[]
```

```lua title="Lua"
local hints = exports['ai-core']:GetKeyHints() -- tablica { id, key, label, icon? }
```

#### Parametry

Brak.

#### Zwraca

[`KeyHintView[]`](/pl/docs/developers/api/types#keyhintview), w kolejności wyświetlania. Pusta tablica, gdy żadna podpowiedź nie ma zastosowania.

<TypeTable
  type={{
    id: { type: 'string', description: 'Nazwa skrótu albo `<resource>:<id>` dla podpowiedzi pokazanej przez skrypt.', required: true },
    key: { type: 'string', description: 'Klawisz tak, jak gracz go teraz przypisał (`"E"`, `"F5"`).', required: true },
    label: { type: 'string', description: 'Co robi, już przetłumaczone.', required: true },
    icon: { type: 'string', description: 'Nazwa ikony Font Awesome solid bez `fa-`; nieobecna, gdy jej nie podano.' },
  }}
/>

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hints.ts"
import { resourceExport } from "@aicore-fivem/lib/client";
import { KEY_HINTS, type KeyHintView } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Lista podpowiedzi klawiszy własnego HUD.
function draw(hints: KeyHintView[]): void {
  SendNUIMessage({ action: "keyHints", data: hints });
}

draw(core.GetKeyHints());
on(KEY_HINTS.changedEvent, draw);
```
</Tab>
<Tab value="Lua">
```lua title="client/hints.lua"
-- Lista podpowiedzi klawiszy własnego HUD.
local function draw(hints)
  SendNUIMessage({ action = 'keyHints', data = hints })
end

draw(exports['ai-core']:GetKeyHints())
AddEventHandler('ai-core:client:keyHints', draw)
```
</Tab>
</Tabs>

### OpenKeyboard

Otwiera ekran klawiszy ai-core: klawiaturę, na której każdy klawisz z akcją jest pokolorowany, a pod nim widać, co robi. Klawisze są pokazane tak, jak gracz je teraz przypisał. Otwiera go pozycja Keys w menu radialnym; może każdy skrypt. Gdy jest otwarty, HUD jest ukryty.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
OpenKeyboard(): void
```

```lua title="Lua"
exports['ai-core']:OpenKeyboard()
```

#### Parametry

Brak.

#### Zwraca

Nic. Wywołanie, gdy ekran jest już otwarty, nic nie robi. Gracz zamyka go na ekranie.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aicore-fivem/lib/client";

const core = resourceExport("ai-core");

RegisterCommand("keys", () => core.OpenKeyboard(), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('keys', function() exports['ai-core']:OpenKeyboard() end, false)
```
</Tab>
</Tabs>
