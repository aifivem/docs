---
title: Médico
description: Saiba se o jogador local está caído (morto ou em last stand), seja qual for o script de morte do servidor.
icon: HeartPulse
---

Scripts de morte mantêm vivo o ped de um jogador caído para poder animá-lo (deitado no chão, rastejando, last stand). Isso significa que o próprio `IsEntityDead` do GTA muitas vezes diz "vivo" para um jogador que está caído. A **camada médica** do ai-core pergunta ao script de morte que o servidor roda (ai-death, qbx_medical, ars_ambulancejob, qb-ambulancejob, esx_ambulancejob, tgiann-ambulance, wasabi_ambulance, osp_ambulance, brutal_ambulancejob) e dá a mesma resposta a todos os recursos.

### IsDead

Diz se o jogador local está caído agora, morto ou em last stand, no script de morte que estiver rodando. Use antes de uma ação que um jogador caído não pode fazer (abrir um menu, usar um item, entrar num veículo).

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
IsDead(): boolean
```

```lua title="Lua"
local down = exports['ai-core']:IsDead() -- boolean
```

#### Parâmetros

Nenhum.

#### Retorno

`boolean`: `true` enquanto o jogador está caído no script de morte ativo. `false` quando está de pé, ou quando nenhum script de morte suportado está rodando.

O `medical.isDead()` da lib (TypeScript) responde `true` também quando o próprio GTA diz que o ped está morto, o que cobre servidores sem script de morte. Ele lê o export uma vez e depois segue o evento de cliente `ai-core:client:dead`, então chamá-lo com frequência não custa nada. Em Lua não há helper: chame o export ou siga o evento.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/phone.ts"
import { medical, notify } from "@aicore-fivem/lib/client";
import { Locale } from "common";

RegisterCommand(
  "phone",
  () => {
    if (medical.isDead()) return notify(Locale("CANT_WHILE_DOWN"), "error");
    SetNuiFocus(true, true);
    SendNUIMessage({ action: "open" });
  },
  false,
);

// Fecha o celular no momento em que o jogador cai.
medical.onChange((dead) => {
  if (!dead) return;
  SetNuiFocus(false, false);
  SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client/phone.lua"
local Locale = aiLib.locale()

-- Mantido a partir do ai-core: lê uma vez e depois segue o evento.
local down = exports['ai-core']:IsDead()

RegisterCommand('phone', function()
  if down then return aiLib.notify(Locale('CANT_WHILE_DOWN'), 'error') end
  SetNuiFocus(true, true)
  SendNUIMessage({ action = 'open' })
end, false)

-- Fecha o celular no momento em que o jogador cai.
AddEventHandler('ai-core:client:dead', function(dead)
  down = dead
  if not dead then return end
  SetNuiFocus(false, false)
  SendNUIMessage({ action = 'close' })
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Este é o estado do próprio jogador local, para o que ele vê. Decisões do servidor (reviver, saquear um corpo, recusar uma ação) verificam os exports médicos do servidor, nunca a resposta de um cliente.
</Callout>
