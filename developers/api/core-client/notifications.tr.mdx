Her `ai-*` script’i bildirimleri ai-lib üzerinden gösterir (lib’de `notify`, Lua’da `aiLib.notify`). ai-lib kendi kartlarını çizer, sunucu sahibi ai-core’un panelinde başka bir bildirim arayüzü seçmediyse (tgiann-lumihud, okokNotify, ox_lib, mythic_notify, brutal_notify). O durumda ai-lib her kartı ai-core’a verir, ai-core da onu o arayüzün çağrısına çevirir.

**Bunu kendin çağırmazsın.** Bir bildirim göstermek için lib’in `notify(text, kind, duration)`’ını ya da `aiLib.notify(text, kind, duration)`’ı kullan: doğru arayüzü onlar seçer. Bu sayfa, export’u gördüğünde ne yaptığını bilmen için var.

### ExternalNotify

Panelin seçtiği bildirim arayüzünde tek bir ai-lib bildirim kartı gösterir. Üçüncü taraf bir arayüz seçiliyken ai-lib her kart için bunu çağırır.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
ExternalNotify(notification: Notification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:ExternalNotify({ text = 'Saved', kind = 'success' }) -- boolean
```

/>

#### Dönüş değeri

`boolean`: üçüncü taraf bir arayüz seçiliyse, çalışıyorsa ve kartı aldıysa `true`. Kartta metin yoksa ya da hiçbir üçüncü taraf arayüz seçili değilse veya çalışmıyorsa `false`: o zaman kartı ai-lib kendisi çizer.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify } from "@aicore-fivem/lib/client";
import { Locale } from "common";

// Bildirim göstermenin doğru yolu: üçüncü taraf bir arayüz seçiliyken ai-lib ExternalNotify’ı senin için çağırır.
RegisterCommand("saved", () => notify(Locale("SAVED"), "success", 3000), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

-- Bildirim göstermenin doğru yolu: üçüncü taraf bir arayüz seçiliyken ai-lib ExternalNotify’ı senin için çağırır.
RegisterCommand('saved', function() aiLib.notify(Locale('SAVED'), 'success', 3000) end, false)
```
</Tab>
</Tabs>

<Callout type="info">
Seçilen arayüzün resource adı GlobalState `ai:notify` içindedir (ai-lib kendi kartlarını çizerken ayarlanmamıştır). Bkz. [State bag’ler](/tr/docs/developers/api/events/state-bags).
</Callout>
