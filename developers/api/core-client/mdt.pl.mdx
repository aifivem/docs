MDT (mobile data terminal) to policyjny komputer: kartoteki, nakazy, raporty. **Warstwa MDT** ai-core otwiera to, którego używa serwer, więc element radialny, klawisz albo laptop w pojeździe w twoim skrypcie otwiera właściwy ekran. Obsługiwane MDT, które da się otworzyć z innego skryptu: tgiann-mdt, ps-mdt, wasabi_mdt.

### OpenMdt

Otwiera ekran aktywnego MDT dla lokalnego gracza. MDT samo sprawdza pracę gracza i odmawia graczowi, który nie może go używać.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
OpenMdt(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenMdt() -- albo aiLib.mdt.open()
```

#### Parametry

Brak.

#### Zwraca

`boolean`: `true`, gdy aktywne MDT zostało poproszone o otwarcie. `false`, gdy nie działa żadne obsługiwane MDT albo działającego nie da się otworzyć z innego skryptu. `true` nie znaczy, że ekran się pokazał: MDT może jeszcze odmówić ze względu na pracę gracza.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/laptop.ts"
import { cache, getPlayerData, mdt, notify, radial } from "@aicore-fivem/lib/client";
import { RADIAL_VEHICLE } from "@aicore-fivem/shared";
import { Locale } from "common";

// Pozycja laptopa w podmenu pojazdu dla policji na służbie.
radial.add({
  id: "myscript_mdt",
  label: Locale("RADIAL_MDT"),
  icon: "laptop",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && getPlayerData("duty") === "police",
  onPressed: () => {
    if (!mdt.open()) notify(Locale("NO_MDT"), "error");
  },
});
```

<Tab value="Lua">
```lua title="client/laptop.lua"
local Locale = aiLib.locale()

-- Pozycja laptopa w podmenu pojazdu dla policji na służbie.
aiLib.radial.add({
  id = 'myscript_mdt',
  label = Locale('RADIAL_MDT'),
  icon = 'laptop',
  parent = 'vehicle',
  canShow = function()
    return aiLib.cache.vehicle ~= false and aiLib.playerData.get('duty') == 'police'
  end,
  onPressed = function()
    if not aiLib.mdt.open() then aiLib.notify(Locale('NO_MDT'), 'error') end
  end,
})
```
