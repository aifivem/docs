Death scripts keep a downed player's ped alive so they can animate it (lying on the ground, crawling, last stand). That means GTA's own `IsEntityDead` often says "alive" for a player who is down. ai-core's **medical layer** asks the death script the server runs (ai-death, qbx_medical, ars_ambulancejob, qb-ambulancejob, esx_ambulancejob, tgiann-ambulance, wasabi_ambulance, osp_ambulance, brutal_ambulancejob) and tells every resource the same answer.

### IsDead

Tells whether the local player is down right now, dead or in last stand, in whichever death script runs. Use it before an action a downed player must not do (opening a menu, using an item, entering a vehicle).

**Side:** Client · **Waits:** no

```ts title="Signature"
IsDead(): boolean
```

```lua title="Lua"
local down = exports['ai-core']:IsDead() -- boolean
```

#### Parameters

None.

#### Returns

`boolean`: `true` while the player is down in the active death script. `false` when they are up, or when no supported death script runs.

The lib's `medical.isDead()` (TypeScript) answers `true` also when GTA itself says the ped is dead, which covers servers without a death script. It reads the export once and then follows the client event `ai-core:client:dead`, so calling it often costs nothing. In Lua there is no helper: call the export, or follow the event.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/phone.ts"
import { medical, notify } from "@aicore-fivem/lib/client";
import { Locale } from "common";

RegisterCommand(
  "phone",
  () => {
    if (medical.isDead()) return notify(Locale("CANT_WHILE_DOWN"), "error");
    SetNuiFocus(true, true);
    SendNUIMessage({ action: "open" });
  },
  false,
);

// Close the phone the moment the player goes down.
medical.onChange((dead) => {
  if (!dead) return;
  SetNuiFocus(false, false);
  SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client/phone.lua"
local Locale = aiLib.locale()

-- Kept from ai-core: read once, then follow the event.
local down = exports['ai-core']:IsDead()

RegisterCommand('phone', function()
  if down then return aiLib.notify(Locale('CANT_WHILE_DOWN'), 'error') end
  SetNuiFocus(true, true)
  SendNUIMessage({ action = 'open' })
end, false)

-- Close the phone the moment the player goes down.
AddEventHandler('ai-core:client:dead', function(dead)
  down = dead
  if not dead then return end
  SetNuiFocus(false, false)
  SendNUIMessage({ action = 'close' })
end)
```
</Tab>
</Tabs>

<Callout type="warn">
This is the local player's own state, for what they see. Server decisions (reviving, looting a body, refusing an action) check the server's medical exports, never a client's answer.
</Callout>
