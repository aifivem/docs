Каждый скрипт `ai-*` показывает уведомления через ai-lib (`notify` в библиотеке, `aiLib.notify` в Lua). ai-lib рисует собственные карточки, если только владелец сервера не выбрал другой интерфейс уведомлений в панели ai-core (tgiann-lumihud, okokNotify, ox_lib, mythic_notify, brutal_notify). Тогда ai-lib передаёт каждую карточку в ai-core, а ai-core переводит её в вызов этого интерфейса.

**Сами вы это не вызываете.** Чтобы показать уведомление, используйте `notify(text, kind, duration)` из библиотеки или `aiLib.notify(text, kind, duration)`: они выбирают нужный интерфейс. Эта страница нужна, чтобы вы знали, что делает экспорт, когда встретите его.

### ExternalNotify

Показывает одну карточку уведомления ai-lib в интерфейсе уведомлений, выбранном в панели. ai-lib вызывает его для каждой карточки, пока выбран сторонний интерфейс.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
ExternalNotify(notification: Notification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:ExternalNotify({ text = 'Saved', kind = 'success' }) -- boolean
```

#### Notification

#### Возвращает

`boolean`: `true`, когда сторонний интерфейс выбран, работает и получил карточку. `false`, когда у карточки нет текста или когда сторонний интерфейс не выбран или не запущен: тогда ai-lib рисует карточку сам.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify } from "@aifivem/lib/client";
import { Locale } from "common";

// Правильный способ показать уведомление: ai-lib сам вызывает ExternalNotify, когда выбран сторонний интерфейс.
RegisterCommand("saved", () => notify(Locale("SAVED"), "success", 3000), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

-- Правильный способ показать уведомление: ai-lib сам вызывает ExternalNotify, когда выбран сторонний интерфейс.
RegisterCommand('saved', function() aiLib.notify(Locale('SAVED'), 'success', 3000) end, false)
```
</Tab>
</Tabs>

<Callout type="info">
Имя ресурса выбранного интерфейса хранится в GlobalState `ai:notify` (не задано, пока ai-lib рисует собственные карточки). См. [State bag](/ru/docs/developers/api/events/state-bags).
</Callout>
