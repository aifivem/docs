title: Keybinds and key hints
description: Read the key a lib Keybind was registered with, show and hide key hints on the HUD, read the hints HUDs show, and open the keys screen.
icon: Keyboard
---

ai-core keeps track of every key that scripts register with the lib's `Keybind` (TypeScript) or `aiLib.Keybind` (Lua). That is how the admin panel's Keybinds tab can change a script's default key, how HUDs can list key hints on the left of the screen, and how the keys screen can show every key with an action.

A **key hint** is a short row on the HUD: a key and what it does (`E  Open trunk`). Keybinds can declare one with their `hint` option. A script can also show hints for a while with `ShowKeyHint`, for example the controls of a tool while it is in use.

### GetKeybindKey

Returns the key a lib `Keybind` was registered with: the key the server owner set in the admin panel's Keybinds tab, else the script's own default key. The player may still have changed it in GTA's key settings; for the key they really press, read `Keybind.currentKey` on your keybind instead.

**Side:** Client · **Waits:** no

```ts title="Signature"
GetKeybindKey(name: string): string | null
```

```lua title="Lua"
local key = exports['ai-core']:GetKeybindKey(name) -- string or nil
```

#### Parameters

<TypeTable
  type={{
    name: { type: 'string', description: 'The keybind\'s `name` as the script passed it to `Keybind` (`"myscript_open"`).', required: true },
  }}
/>

#### Returns

`string`: the key in upper case (`"F5"`, `"E"`), or `""` for a keybind without a default key. `null` until ai-core answered that keybind (shortly after its resource starts) and for names no running resource registered.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { Keybind, resourceExport } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

const open = new Keybind({
  name: "myscript_open",
  description: Locale("KEY_OPEN"),
  defaultKey: "F5",
  onPressed: () => console.log("open"),
});

RegisterCommand(
  "myscript_keys",
  () => {
    console.log(`registered with: ${core.GetKeybindKey("myscript_open") ?? "not yet"}`);
    console.log(`the player presses: ${open.currentKey}`);
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

aiLib.Keybind.new({
  name = 'myscript_open',
  description = Locale('KEY_OPEN'),
  defaultKey = 'F5',
  onPressed = function() print('open') end,
})

RegisterCommand('myscript_keys', function()
  print(('registered with: %s'):format(exports['ai-core']:GetKeybindKey('myscript_open') or 'not yet'))
end, false)
```
</Tab>
</Tabs>

### ShowKeyHint

Shows a key hint of your resource on the HUD's key hint list until you hide it. Use it for keys that matter only for a while: a tool's controls, a minigame, a camera mode. Keys your keybinds always offer belong in the `hint` option of the `Keybind` instead.

**Side:** Client · **Waits:** no

```ts title="Signature"
ShowKeyHint(id: string, hint: KeyHintRequest): void
```

```lua title="Lua"
exports['ai-core']:ShowKeyHint(id, hint) -- or aiLib.keyHints.show(id, hint)
```

#### Parameters

<TypeTable
  type={{
    id: { type: 'string', description: 'Your name for this hint (`"camera_zoom"`). Showing the same id again replaces the hint. Ids are per resource, so another script\'s `camera_zoom` is a different hint.', required: true },
    hint: { type: 'KeyHintRequest', description: 'What the row shows. Fields below.', required: true, typeDescriptionLink: '/docs/developers/api/types#keyhintrequest' },
  }}
/>

#### KeyHintRequest

See also [KeyHintRequest](/docs/developers/api/types#keyhintrequest).

<TypeTable
  type={{
    label: { type: 'string', description: 'What the key does, already translated (`Locale("HINT_ZOOM")`). Cut to 60 characters.', required: true },
    keybind: { type: 'string', description: 'The `name` of a keybind: the hint shows the key the player has bound to it now, and follows when they rebind it. Wins over `key`.' },
    key: { type: 'string', description: 'A literal key text (`"SCROLL"`, `"SHIFT"`) when no keybind stands behind it. Cut to 16 characters.' },
    icon: { type: 'string', description: 'A Font Awesome solid icon name without `fa-` (`"magnifying-glass"`). HUDs draw a key icon when they do not know it. Cut to 32 characters.' },
  }}
/>

#### Returns

Nothing. A hint without a text `label`, or a non-string `id`, is ignored. A hint whose key resolves to nothing (neither `keybind` nor `key` gives a key) is kept but not listed.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/camera.ts"
import { keyHints } from "@aicore-fivem/lib/client";
import { Locale } from "common";

export function startCamera(): void {
  keyHints.show("camera_zoom", { label: Locale("HINT_ZOOM"), key: "SCROLL", icon: "magnifying-glass" });
  keyHints.show("camera_exit", { label: Locale("HINT_EXIT"), keybind: "myscript_camera" });
}

export function stopCamera(): void {
  keyHints.hide("camera_zoom");
  keyHints.hide("camera_exit");
}
```
</Tab>
<Tab value="Lua">
```lua title="client/camera.lua"
local Locale = aiLib.locale()

local function startCamera()
  aiLib.keyHints.show('camera_zoom', { label = Locale('HINT_ZOOM'), key = 'SCROLL', icon = 'magnifying-glass' })
  aiLib.keyHints.show('camera_exit', { label = Locale('HINT_EXIT'), keybind = 'myscript_camera' })
end

local function stopCamera()
  aiLib.keyHints.hide('camera_zoom')
  aiLib.keyHints.hide('camera_exit')
end
```
</Tab>
</Tabs>

<Callout type="info">
Hints are listed in the order scripts showed them, after the hints keybinds declare. Your resource's hints are removed when it stops.
</Callout>

### HideKeyHint

Hides one key hint your resource showed.

**Side:** Client · **Waits:** no

```ts title="Signature"
HideKeyHint(id: string): void
```

```lua title="Lua"
exports['ai-core']:HideKeyHint(id) -- or aiLib.keyHints.hide(id)
```

#### Parameters

<TypeTable
  type={{
    id: { type: 'string', description: 'The id you passed to `ShowKeyHint`. An id your resource never showed does nothing.', required: true },
  }}
/>

#### Returns

Nothing.

#### Example

See the example of [ShowKeyHint](#showkeyhint).

### GetKeyHints

Returns the key hint rows HUDs should show right now: the hints keybinds declare for the player's situation (on foot or in a vehicle, as the server owner set them in the panel) plus the hints scripts show. A HUD reads it once at start and then follows the client event `ai-core:client:keyHints`, which carries the same list after every change.

**Side:** Client · **Waits:** no

```ts title="Signature"
GetKeyHints(): KeyHintView[]
```

```lua title="Lua"
local hints = exports['ai-core']:GetKeyHints() -- array of { id, key, label, icon? }
```

#### Parameters

None.

#### Returns

[`KeyHintView[]`](/docs/developers/api/types#keyhintview), in display order. An empty array when no hint applies.

<TypeTable
  type={{
    id: { type: 'string', description: 'The keybind name, or `<resource>:<id>` for a hint a script showed.', required: true },
    key: { type: 'string', description: 'The key as the player has it bound now (`"E"`, `"F5"`).', required: true },
    label: { type: 'string', description: 'What it does, already translated.', required: true },
    icon: { type: 'string', description: 'Font Awesome solid icon name without `fa-`; absent when none was given.' },
  }}
/>

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hints.ts"
import { resourceExport } from "@aicore-fivem/lib/client";
import { KEY_HINTS, type KeyHintView } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// A custom HUD's key hint list.
function draw(hints: KeyHintView[]): void {
  SendNUIMessage({ action: "keyHints", data: hints });
}

draw(core.GetKeyHints());
on(KEY_HINTS.changedEvent, draw);
```
</Tab>
<Tab value="Lua">
```lua title="client/hints.lua"
-- A custom HUD's key hint list.
local function draw(hints)
  SendNUIMessage({ action = 'keyHints', data = hints })
end

draw(exports['ai-core']:GetKeyHints())
AddEventHandler('ai-core:client:keyHints', draw)
```
</Tab>
</Tabs>

### OpenKeyboard

Opens ai-core's keys screen: a keyboard where every key that has an action is colored, with what each key does below it. Keys are shown as the player has bound them now. The radial menu's Keys entry opens it; any script can. While it is open, HUDs are hidden.

**Side:** Client · **Waits:** no

```ts title="Signature"
OpenKeyboard(): void
```

```lua title="Lua"
exports['ai-core']:OpenKeyboard()
```

#### Parameters

None.

#### Returns

Nothing. Calling it while the screen is already open does nothing. The player closes it in the screen.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aicore-fivem/lib/client";

const core = resourceExport("ai-core");

RegisterCommand("keys", () => core.OpenKeyboard(), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('keys', function() exports['ai-core']:OpenKeyboard() end, false)
```
</Tab>
</Tabs>
