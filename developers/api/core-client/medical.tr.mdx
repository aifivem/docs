Ölüm script’leri yerdeki bir oyuncunun ped’ini canlandırabilmek için canlı tutar (yerde yatma, sürünme, last stand). Bu, GTA’nın kendi `IsEntityDead`’inin yerdeki bir oyuncu için çoğu zaman "canlı" dediği anlamına gelir. ai-core’un **sağlık katmanı** sunucunun çalıştırdığı ölüm script’ine sorar (ai-death, qbx_medical, ars_ambulancejob, qb-ambulancejob, esx_ambulancejob, tgiann-ambulance, wasabi_ambulance, osp_ambulance, brutal_ambulancejob) ve her resource’a aynı cevabı verir.

### IsDead

Hangi ölüm script’i çalışıyorsa ona göre yerel oyuncunun şu an yerde, ölü ya da last stand’de olup olmadığını söyler. Yerdeki bir oyuncunun yapmaması gereken bir aksiyondan önce kullan (menü açmak, eşya kullanmak, araca binmek).

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
IsDead(): boolean
```

```lua title="Lua"
local down = exports['ai-core']:IsDead() -- boolean
```

#### Parametreler

Yok.

#### Dönüş değeri

`boolean`: oyuncu aktif ölüm script’inde yerdeyken `true`. Ayaktayken ya da desteklenen bir ölüm script’i çalışmıyorken `false`.

Lib’in `medical.isDead()`’i (TypeScript) GTA’nın kendisi ped’in öldüğünü söylediğinde de `true` cevabı verir; bu da ölüm script’i olmayan sunucuları kapsar. Export’u bir kez okur ve sonra `ai-core:client:dead` client event’ini izler, bu yüzden onu sık çağırmanın bir maliyeti yoktur. Lua’da yardımcı yoktur: export’u çağır ya da event’i izle.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/phone.ts"
import { medical, notify } from "@aicore-fivem/lib/client";
import { Locale } from "common";

RegisterCommand(
  "phone",
  () => {
    if (medical.isDead()) return notify(Locale("CANT_WHILE_DOWN"), "error");
    SetNuiFocus(true, true);
    SendNUIMessage({ action: "open" });
  },
  false,
);

// Oyuncu yere düştüğü anda telefonu kapat.
medical.onChange((dead) => {
  if (!dead) return;
  SetNuiFocus(false, false);
  SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client/phone.lua"
local Locale = aiLib.locale()

-- ai-core’dan tutulur: bir kez oku, sonra event’i izle.
local down = exports['ai-core']:IsDead()

RegisterCommand('phone', function()
  if down then return aiLib.notify(Locale('CANT_WHILE_DOWN'), 'error') end
  SetNuiFocus(true, true)
  SendNUIMessage({ action = 'open' })
end, false)

-- Oyuncu yere düştüğü anda telefonu kapat.
AddEventHandler('ai-core:client:dead', function(dead)
  down = dead
  if not dead then return end
  SetNuiFocus(false, false)
  SendNUIMessage({ action = 'close' })
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Bu, oyuncunun gördükleri için yerel oyuncunun kendi durumudur. Server kararları (canlandırma, bir bedeni soyma, bir aksiyonu reddetme) asla bir client’ın cevabına değil, server’ın sağlık export’larına bakar.
</Callout>
