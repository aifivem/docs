Эти экспорты идут через **слой внешности** ai-core: работу выполняет скрипт одежды, который использует сервер (ai-appearance, tgiann-clothing, illenium-appearance, qb-clothing, crm-appearance, rcore_clothing, bl_appearance). Ваш скрипт никогда не касается собственного формата скрипта одежды, поэтому продолжает работать, когда владелец сервера его меняет.

**Внешность** ([`CharacterAppearance`](/ru/docs/developers/api/types#characterappearance)) - это `{ model, data }`: хэш модели педа и собственные данные скрипта одежды. Считайте `data` закрытой коробкой: получайте внешность с сервера (`appearance.get(charId)` в серверной библиотеке, `aiLib.appearance.get` в Lua) или из `GetPedAppearance` и возвращайте её без изменений.

### ApplyAppearance

Надевает внешность на педа через активный скрипт одежды. Используйте, чтобы одеть локального педа как персонажа (продавец, похожий на владельца, спящее тело, фото) или чтобы вернуть игроку сохранённую внешность.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
ApplyAppearance(ped: number, look: CharacterAppearance): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:ApplyAppearance(ped, look) -- или aiLib.appearance.apply(ped, look)
```

#### Параметры

<TypeTable
  type={{
    ped: { type: 'number', description: 'Хэндл педа. Его модель должна совпадать с `model` внешности: создавайте педа с `look.model`.', required: true },
    look: { type: 'CharacterAppearance', description: '`{ model, data }` ровно в том виде, в каком их дал сервер или `GetPedAppearance`.', required: true, typeDescriptionLink: '/ru/docs/developers/api/types#characterappearance' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда скрипт одежды получил внешность. `false`, когда пед не существует, его модель отличается от `look.model`, внешность не является таблицей `{ model, data }` или не работает ни один скрипт одежды.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { appearance, onClientCallback, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Собственная сохранённая внешность запросившего игрока.
onClientCallback("myscript:myLook", async (source) => {
  const character = core.GetCharacter(source);
  return character ? await appearance.get(character.id) : null;
});
```

```ts title="resource/client/index.ts"
import { appearance, requestModel, triggerServerCallback } from "@aifivem/lib/client";
import { toCharacterAppearance } from "@aifivem/shared";

// Локальная копия игрока, стоящая в точке и одетая как он.
export async function spawnLookalike(x: number, y: number, z: number): Promise<number> {
  const look = toCharacterAppearance(await triggerServerCallback("myscript:myLook", []));
  if (!look) return 0;
  await requestModel(look.model);
  const ped = CreatePed(4, look.model, x, y, z, 0, false, false);
  SetModelAsNoLongerNeeded(look.model);
  appearance.apply(ped, look);
  return ped;
}
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
-- Собственная сохранённая внешность запросившего игрока.
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  return character and aiLib.appearance.get(character.id) or nil
end)
```

```lua title="client.lua"
-- Локальная копия игрока, стоящая в точке и одетая как он (вызывать из потока).
local function spawnLookalike(x, y, z)
  local look = aiLib.triggerServerCallback('myscript:myLook', {})
  if not look then return 0 end
  aiLib.requestModel(look.model)
  local ped = CreatePed(4, look.model, x, y, z, 0.0, false, false)
  SetModelAsNoLongerNeeded(look.model)
  aiLib.appearance.apply(ped, look)
  return ped
end
```
</Tab>
</Tabs>

<Callout type="warn">
На собственном педе игрока `ApplyAppearance` меняет то, что он носит сейчас. Сохраняется ли это изменение, решает скрипт одежды, а не ai-core. Чтобы одеть игрока в форму, которая никогда не сохраняется, используйте [WearOutfit](#wearoutfit).
</Callout>

### GetPedAppearance

Возвращает внешность, которую пед носит прямо сейчас, в той же форме `{ model, data }`, что и сохранённые на сервере внешности.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
GetPedAppearance(ped: number): CharacterAppearance | null
```

```lua title="Lua"
local look = exports['ai-core']:GetPedAppearance(ped) -- или aiLib.appearance.read(ped)
```

#### Параметры

<TypeTable
  type={{
    ped: { type: 'number', description: 'Хэндл педа (`cache.ped` для локального игрока).', required: true },
  }}
/>

#### Возвращает

[`CharacterAppearance`](/ru/docs/developers/api/types#characterappearance): `model` - хэш модели педа, `data` - данные скрипта одежды. `null`, когда пед не существует, не работает ни один скрипт одежды или скрипт одежды не может прочитать этого педа (некоторые читают только собственного педа локального игрока).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/photo.ts"
import { appearance, cache } from "@aifivem/lib/client";

// Копирует то, что игрок носит сейчас, на другого педа той же модели.
export function copyPlayerLook(target: number): boolean {
  const look = appearance.read(cache.ped);
  return look !== null && appearance.apply(target, look);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/photo.lua"
-- Копирует то, что игрок носит сейчас, на другого педа той же модели.
local function copyPlayerLook(target)
  local look = aiLib.appearance.read(aiLib.cache.ped)
  return look ~= nil and aiLib.appearance.apply(target, look)
end
```
</Tab>
</Tabs>

### OpenClothingMenu

Открывает для локального игрока одно из меню активного скрипта одежды: магазин одежды, парикмахерскую или сохранённые наряды. Используйте для собственных маркеров магазинов или гардероба в доме.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
OpenClothingMenu(menu: ClothingMenu): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenClothingMenu(menu) -- или aiLib.appearance.openMenu(menu)
```

#### Параметры

<TypeTable
  type={{
    menu: { type: '"clothing" | "barber" | "outfits"', description: '`clothing`: магазин одежды. `barber`: волосы, борода и макияж. `outfits`: сохранённые наряды игрока (гардероб).', required: true, typeDescriptionLink: '/ru/docs/developers/api/types#clothingmenu' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда скрипт одежды открыл меню. `false` для неизвестного `menu`, когда не работает ни один скрипт одежды или у запущенного нет такого меню.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/wardrobe.ts"
import { appearance, notify, Points } from "@aifivem/lib/client";
import { Locale } from "common";

const points = new Points();

// Гардероб в номере мотеля.
points.add("motel_wardrobe", {
  coords: { x: 151.3, y: -1001.2, z: -99.0 },
  label: Locale("WARDROBE"),
  onPressed: () => {
    if (!appearance.openMenu("outfits")) notify(Locale("NO_WARDROBE"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/wardrobe.lua"
local Locale = aiLib.locale()

RegisterCommand('wardrobe', function()
  if not aiLib.appearance.openMenu('outfits') then
    aiLib.notify(Locale('NO_WARDROBE'), 'error')
  end
end, false)
```
</Tab>
</Tabs>

### WearOutfit

Надевает на локального игрока рабочую форму до вызова `ReloadSkin`. Меняются только перечисленные вами части; остальная одежда остаётся. Форма никогда не сохраняется как собственная внешность игрока.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
WearOutfit(outfit: JobOutfit): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:WearOutfit(outfit) -- или aiLib.appearance.wearOutfit(outfit)
```

#### Параметры

<TypeTable
  type={{
    outfit: { type: 'JobOutfit', description: 'Части, которые нужно надеть. Поля ниже.', required: true, typeDescriptionLink: '/ru/docs/developers/api/types#joboutfit' },
  }}
/>

#### JobOutfit

<TypeTable
  type={{
    components: { type: 'OutfitPiece[]', description: 'Компоненты одежды (торс, ноги, обувь...): `id` 0-11.', required: true, typeDescriptionLink: '/ru/docs/developers/api/types#outfitpiece' },
    props: { type: 'OutfitPiece[]', description: 'Аксессуары (шляпы, очки, часы...): `id` 0-13.', required: true, typeDescriptionLink: '/ru/docs/developers/api/types#outfitpiece' },
  }}
/>

#### OutfitPiece

См. также [OutfitPiece](/ru/docs/developers/api/types#outfitpiece).

<TypeTable
  type={{
    id: { type: 'number', description: 'Id компонента (0-11) или id аксессуара (0-13).', required: true },
    collection: { type: 'string', description: 'Имя коллекции одежды (DLC), из которой взята часть; `""` для базовой игры. Не более 64 символов.', required: true },
    index: { type: 'number', description: 'Индекс drawable внутри этой коллекции (0-1023). Для аксессуара `-1` снимает его.', required: true },
    texture: { type: 'number', description: 'Текстура (вариант цвета). Отсутствующее или отрицательное значение считается 0.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, когда скрипт одежды надел форму. `false`, когда после проверки не осталось ни одной допустимой части, не работает ни один скрипт одежды или запущенный не умеет надевать наряды. Недопустимые части (неверный диапазон id, плохой индекс) отбрасываются по одной; допустимые всё равно надеваются.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/locker.ts"
import { appearance } from "@aifivem/lib/client";
import type { JobOutfit } from "@aifivem/shared";

// Простая форма из частей базовой игры: рубашка, брюки, обувь, без головного убора.
const UNIFORM: JobOutfit = {
  components: [
    { id: 11, collection: "", index: 55, texture: 0 },
    { id: 4, collection: "", index: 35, texture: 0 },
    { id: 6, collection: "", index: 25, texture: 0 },
  ],
  props: [{ id: 0, collection: "", index: -1, texture: 0 }],
};

export const putOnUniform = (): boolean => appearance.wearOutfit(UNIFORM);
export const takeOffUniform = (): boolean => appearance.reloadSkin();
```
</Tab>
<Tab value="Lua">
```lua title="client/locker.lua"
-- Простая форма из частей базовой игры: рубашка, брюки, обувь, без головного убора.
local UNIFORM = {
  components = {
    { id = 11, collection = '', index = 55, texture = 0 },
    { id = 4, collection = '', index = 35, texture = 0 },
    { id = 6, collection = '', index = 25, texture = 0 },
  },
  props = { { id = 0, collection = '', index = -1, texture = 0 } },
}

local function putOnUniform() return aiLib.appearance.wearOutfit(UNIFORM) end
local function takeOffUniform() return aiLib.appearance.reloadSkin() end
```
</Tab>
</Tabs>

<Callout type="info">
Индексы drawable отличаются у мужской и женской моделей freemode: держите по наряду на модель и выбирайте его по модели игрока.
</Callout>

### ReloadSkin

Возвращает локальному игроку его сохранённую внешность. Используйте, чтобы снять рабочую форму.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
ReloadSkin(): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:ReloadSkin() -- или aiLib.appearance.reloadSkin()
```

#### Параметры

Нет.

#### Возвращает

`boolean`: `true`, когда скрипт одежды получил запрос на перезагрузку внешности. `false`, когда не работает ни один скрипт одежды или запущенный не умеет перезагружать.

#### Пример

См. пример [WearOutfit](#wearoutfit).
