Jedes `ai-*`-Skript zeigt Benachrichtigungen über ai-lib an (`notify` in der Lib, `aiLib.notify` in Lua). ai-lib zeichnet seine eigenen Karten, es sei denn, der Serverbesitzer hat im Panel von ai-core eine andere Benachrichtigungs-UI gewählt (tgiann-lumihud, okokNotify, ox_lib, mythic_notify, brutal_notify). Dann übergibt ai-lib jede Karte an ai-core, und ai-core übersetzt sie in den Aufruf dieser UI.

**Du rufst das nicht selbst auf.** Um eine Benachrichtigung anzuzeigen, nutze `notify(text, kind, duration)` der Lib oder `aiLib.notify(text, kind, duration)`: Sie wählen die richtige UI. Diese Seite existiert, damit du weißt, was der Export tut, wenn du ihn siehst.

### ExternalNotify

Zeigt eine Benachrichtigungskarte von ai-lib in der Benachrichtigungs-UI an, die das Panel gewählt hat. ai-lib ruft es für jede Karte auf, solange eine UI eines Drittanbieters gewählt ist.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
ExternalNotify(notification: Notification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:ExternalNotify({ text = 'Saved', kind = 'success' }) -- boolean
```

#### Parameter

<TypeTable
  type={{
    notification: { type: 'Notification', description: 'Die Karte. Felder unten.', required: true, typeDescriptionLink: '/de/docs/developers/api/types#notification' },
  }}
/>

#### Notification

<TypeTable
  type={{
    text: { type: 'string', description: 'Die Nachricht, bereits übersetzt. Auf 300 Zeichen gekürzt.', required: true },
    title: { type: 'string', description: 'Ein optionaler Titel, bereits übersetzt. Auf 60 Zeichen gekürzt.' },
    kind: { type: '"success" | "error" | "info" | "warning"', description: 'Der Stil der Karte. Alles andere zählt als `"info"`. Jede UI bekommt ihr eigenes Wort dafür (zum Beispiel `inform` von ox_lib für `info`).', required: true },
    duration: { type: 'number', description: 'Millisekunden auf dem Bildschirm. UIs, die einen Wert brauchen, bekommen 4000, wenn er weggelassen wird.' },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn eine UI eines Drittanbieters gewählt ist, läuft und die Karte bekommen hat. `false`, wenn die Karte keinen Text hat oder keine UI eines Drittanbieters gewählt ist oder läuft: Dann zeichnet ai-lib die Karte selbst.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { notify } from "@aicore-fivem/lib/client";
import { Locale } from "common";

// Der richtige Weg zu benachrichtigen: ai-lib ruft ExternalNotify für dich auf, wenn eine UI eines Drittanbieters gewählt ist.
RegisterCommand("saved", () => notify(Locale("SAVED"), "success", 3000), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

-- Der richtige Weg zu benachrichtigen: ai-lib ruft ExternalNotify für dich auf, wenn eine UI eines Drittanbieters gewählt ist.
RegisterCommand('saved', function() aiLib.notify(Locale('SAVED'), 'success', 3000) end, false)
```
</Tab>
</Tabs>

<Callout type="info">
Der Ressourcenname der gewählten UI steht im GlobalState `ai:notify` (nicht gesetzt, solange ai-lib seine eigenen Karten zeichnet). Siehe [State Bags](/de/docs/developers/api/events/state-bags).
</Callout>
