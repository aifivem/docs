---
title: Médical
description: Savoir si le joueur local est à terre (mort ou en dernier souffle), quel que soit le script de mort du serveur.
icon: HeartPulse
---

Les scripts de mort gardent en vie le ped d’un joueur à terre pour pouvoir l’animer (allongé au sol, en train de ramper, dernier souffle). Cela signifie que le propre `IsEntityDead` de GTA dit souvent « vivant » pour un joueur à terre. La **couche médicale** d’ai-core interroge le script de mort qu’utilise le serveur (ai-death, qbx_medical, ars_ambulancejob, qb-ambulancejob, esx_ambulancejob, tgiann-ambulance, wasabi_ambulance, osp_ambulance, brutal_ambulancejob) et donne la même réponse à toutes les ressources.

### IsDead

Indique si le joueur local est à terre en ce moment, mort ou en dernier souffle, quel que soit le script de mort qui tourne. Utilisez-le avant une action qu’un joueur à terre ne doit pas faire (ouvrir un menu, utiliser un objet, monter dans un véhicule).

**Côté :** Client · **Attend :** non

```ts title="Signature"
IsDead(): boolean
```

```lua title="Lua"
local down = exports['ai-core']:IsDead() -- boolean
```

#### Paramètres

Aucun.

#### Retour

`boolean` : `true` tant que le joueur est à terre dans le script de mort actif. `false` quand il est debout, ou quand aucun script de mort pris en charge ne tourne.

`medical.isDead()` de la lib (TypeScript) répond `true` aussi quand GTA lui-même dit que le ped est mort, ce qui couvre les serveurs sans script de mort. Il lit l’export une fois puis suit l’événement client `ai-core:client:dead`, si bien que l’appeler souvent ne coûte rien. En Lua, il n’y a pas d’utilitaire : appelez l’export, ou suivez l’événement.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/phone.ts"
import { medical, notify } from "@aifivem/lib/client";
import { Locale } from "common";

RegisterCommand(
  "phone",
  () => {
    if (medical.isDead()) return notify(Locale("CANT_WHILE_DOWN"), "error");
    SetNuiFocus(true, true);
    SendNUIMessage({ action: "open" });
  },
  false,
);

// Fermer le téléphone dès que le joueur tombe.
medical.onChange((dead) => {
  if (!dead) return;
  SetNuiFocus(false, false);
  SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client/phone.lua"
local Locale = aiLib.locale()

-- Gardé depuis ai-core : lire une fois, puis suivre l’événement.
local down = exports['ai-core']:IsDead()

RegisterCommand('phone', function()
  if down then return aiLib.notify(Locale('CANT_WHILE_DOWN'), 'error') end
  SetNuiFocus(true, true)
  SendNUIMessage({ action = 'open' })
end, false)

-- Fermer le téléphone dès que le joueur tombe.
AddEventHandler('ai-core:client:dead', function(dead)
  down = dead
  if not dead then return end
  SetNuiFocus(false, false)
  SendNUIMessage({ action = 'close' })
end)
```
</Tab>
</Tabs>

<Callout type="warn">
C’est l’état propre du joueur local, pour ce qu’il voit. Les décisions du serveur (réanimer, fouiller un corps, refuser une action) vérifient les exports médicaux du serveur, jamais la réponse d’un client.
</Callout>
