ai-core führt Buch über jede Taste, die Skripte mit `Keybind` der Lib (TypeScript) oder `aiLib.Keybind` (Lua) registrieren. So kann der Tab Keybinds im Admin-Panel die Standardtaste eines Skripts ändern, so können HUDs links auf dem Bildschirm Tastenhinweise auflisten, und so kann der Tastenbildschirm jede Taste mit einer Aktion zeigen.

Ein **Tastenhinweis** ist eine kurze Zeile im HUD: eine Taste und was sie tut (`E  Kofferraum öffnen`). Keybinds können über ihre Option `hint` einen deklarieren. Ein Skript kann außerdem mit `ShowKeyHint` für eine Weile Hinweise zeigen, zum Beispiel die Steuerung eines Werkzeugs, solange es benutzt wird.

### GetKeybindKey

Gibt die Taste zurück, mit der ein `Keybind` der Lib registriert wurde: die Taste, die der Serverbesitzer im Tab Keybinds des Admin-Panels festgelegt hat, sonst die eigene Standardtaste des Skripts. Der Spieler kann sie trotzdem in den Tasteneinstellungen von GTA geändert haben; für die Taste, die er wirklich drückt, lies stattdessen `Keybind.currentKey` deines Keybinds.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
GetKeybindKey(name: string): string | null
```

```lua title="Lua"
local key = exports['ai-core']:GetKeybindKey(name) -- String oder nil
```

#### Parameter

<TypeTable
  type={{
    name: { type: 'string', description: 'Der `name` des Keybinds, so wie das Skript ihn an `Keybind` übergeben hat (`"myscript_open"`).', required: true },
  }}
/>

#### Rückgabe

`string`: die Taste in Großbuchstaben (`"F5"`, `"E"`) oder `""` für ein Keybind ohne Standardtaste. `null`, bis ai-core dieses Keybind beantwortet hat (kurz nachdem seine Ressource startet), und für Namen, die keine laufende Ressource registriert hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { Keybind, resourceExport } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const core = resourceExport("ai-core");

const open = new Keybind({
  name: "myscript_open",
  description: Locale("KEY_OPEN"),
  defaultKey: "F5",
  onPressed: () => console.log("open"),
});

RegisterCommand(
  "myscript_keys",
  () => {
    console.log(`registered with: ${core.GetKeybindKey("myscript_open") ?? "not yet"}`);
    console.log(`the player presses: ${open.currentKey}`);
  },
  false,
);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local Locale = aiLib.locale()

aiLib.Keybind.new({
  name = 'myscript_open',
  description = Locale('KEY_OPEN'),
  defaultKey = 'F5',
  onPressed = function() print('open') end,
})

RegisterCommand('myscript_keys', function()
  print(('registered with: %s'):format(exports['ai-core']:GetKeybindKey('myscript_open') or 'not yet'))
end, false)
```
</Tab>
</Tabs>

### ShowKeyHint

Zeigt einen Tastenhinweis deiner Ressource in der Tastenhinweisliste des HUD, bis du ihn ausblendest. Nutze es für Tasten, die nur für eine Weile wichtig sind: die Steuerung eines Werkzeugs, ein Minispiel, ein Kameramodus. Tasten, die deine Keybinds immer anbieten, gehören stattdessen in die Option `hint` des `Keybind`.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
ShowKeyHint(id: string, hint: KeyHintRequest): void
```

```lua title="Lua"
exports['ai-core']:ShowKeyHint(id, hint) -- oder aiLib.keyHints.show(id, hint)
```

#### Parameter

<TypeTable
  type={{
    id: { type: 'string', description: 'Dein Name für diesen Hinweis (`"camera_zoom"`). Wird dieselbe ID erneut gezeigt, ersetzt das den Hinweis. IDs gelten pro Ressource, sodass `camera_zoom` eines anderen Skripts ein anderer Hinweis ist.', required: true },
    hint: { type: 'KeyHintRequest', description: 'Was die Zeile zeigt. Felder unten.', required: true, typeDescriptionLink: '/de/docs/developers/api/types#keyhintrequest' },
  }}
/>

#### KeyHintRequest

Siehe auch [KeyHintRequest](/de/docs/developers/api/types#keyhintrequest).

<TypeTable
  type={{
    label: { type: 'string', description: 'Was die Taste tut, bereits übersetzt (`Locale("HINT_ZOOM")`). Auf 60 Zeichen gekürzt.', required: true },
    keybind: { type: 'string', description: 'Der `name` eines Keybinds: Der Hinweis zeigt die Taste, die der Spieler ihm gerade zugewiesen hat, und folgt, wenn er sie neu belegt. Hat Vorrang vor `key`.' },
    key: { type: 'string', description: 'Ein wörtlicher Tastentext (`"SCROLL"`, `"SHIFT"`), wenn kein Keybind dahintersteht. Auf 16 Zeichen gekürzt.' },
    icon: { type: 'string', description: 'Name eines Font-Awesome-Solid-Icons ohne `fa-` (`"magnifying-glass"`). HUDs zeichnen ein Tasten-Icon, wenn sie es nicht kennen. Auf 32 Zeichen gekürzt.' },
  }}
/>

#### Rückgabe

Nichts. Ein Hinweis ohne Text-`label` oder eine `id`, die kein String ist, wird ignoriert. Ein Hinweis, dessen Taste zu nichts aufgelöst wird (weder `keybind` noch `key` ergibt eine Taste), wird behalten, aber nicht gelistet.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/camera.ts"
import { keyHints } from "@aicore-fivem/lib/client";
import { Locale } from "common";

export function startCamera(): void {
  keyHints.show("camera_zoom", { label: Locale("HINT_ZOOM"), key: "SCROLL", icon: "magnifying-glass" });
  keyHints.show("camera_exit", { label: Locale("HINT_EXIT"), keybind: "myscript_camera" });
}

export function stopCamera(): void {
  keyHints.hide("camera_zoom");
  keyHints.hide("camera_exit");
}
```
</Tab>
<Tab value="Lua">
```lua title="client/camera.lua"
local Locale = aiLib.locale()

local function startCamera()
  aiLib.keyHints.show('camera_zoom', { label = Locale('HINT_ZOOM'), key = 'SCROLL', icon = 'magnifying-glass' })
  aiLib.keyHints.show('camera_exit', { label = Locale('HINT_EXIT'), keybind = 'myscript_camera' })
end

local function stopCamera()
  aiLib.keyHints.hide('camera_zoom')
  aiLib.keyHints.hide('camera_exit')
end
```
</Tab>
</Tabs>

<Callout type="info">
Hinweise werden in der Reihenfolge gelistet, in der Skripte sie gezeigt haben, nach den Hinweisen, die Keybinds deklarieren. Die Hinweise deiner Ressource werden entfernt, wenn sie stoppt.
</Callout>

### HideKeyHint

Blendet einen Tastenhinweis aus, den deine Ressource gezeigt hat.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
HideKeyHint(id: string): void
```

```lua title="Lua"
exports['ai-core']:HideKeyHint(id) -- oder aiLib.keyHints.hide(id)
```

#### Parameter

<TypeTable
  type={{
    id: { type: 'string', description: 'Die ID, die du an `ShowKeyHint` übergeben hast. Eine ID, die deine Ressource nie gezeigt hat, bewirkt nichts.', required: true },
  }}
/>

#### Rückgabe

Nichts.

#### Beispiel

Siehe das Beispiel zu [ShowKeyHint](#showkeyhint).

### GetKeyHints

Gibt die Tastenhinweis-Zeilen zurück, die HUDs gerade zeigen sollen: die Hinweise, die Keybinds für die Situation des Spielers deklarieren (zu Fuß oder im Fahrzeug, wie der Serverbesitzer sie im Panel festgelegt hat), plus die Hinweise, die Skripte zeigen. Ein HUD liest es einmal beim Start und folgt dann dem Client-Event `ai-core:client:keyHints`, das nach jeder Änderung dieselbe Liste trägt.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
GetKeyHints(): KeyHintView[]
```

```lua title="Lua"
local hints = exports['ai-core']:GetKeyHints() -- Array von { id, key, label, icon? }
```

#### Parameter

Keine.

#### Rückgabe

[`KeyHintView[]`](/de/docs/developers/api/types#keyhintview), in Anzeigereihenfolge. Ein leeres Array, wenn kein Hinweis zutrifft.

<TypeTable
  type={{
    id: { type: 'string', description: 'Der Keybind-Name oder `<resource>:<id>` für einen Hinweis, den ein Skript gezeigt hat.', required: true },
    key: { type: 'string', description: 'Die Taste, wie der Spieler sie gerade belegt hat (`"E"`, `"F5"`).', required: true },
    label: { type: 'string', description: 'Was sie tut, bereits übersetzt.', required: true },
    icon: { type: 'string', description: 'Name eines Font-Awesome-Solid-Icons ohne `fa-`; fehlt, wenn keines angegeben wurde.' },
  }}
/>

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hints.ts"
import { resourceExport } from "@aicore-fivem/lib/client";
import { KEY_HINTS, type KeyHintView } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Die Tastenhinweisliste eines eigenen HUD.
function draw(hints: KeyHintView[]): void {
  SendNUIMessage({ action: "keyHints", data: hints });
}

draw(core.GetKeyHints());
on(KEY_HINTS.changedEvent, draw);
```
</Tab>
<Tab value="Lua">
```lua title="client/hints.lua"
-- Die Tastenhinweisliste eines eigenen HUD.
local function draw(hints)
  SendNUIMessage({ action = 'keyHints', data = hints })
end

draw(exports['ai-core']:GetKeyHints())
AddEventHandler('ai-core:client:keyHints', draw)
```
</Tab>
</Tabs>

### OpenKeyboard

Öffnet den Tastenbildschirm von ai-core: eine Tastatur, auf der jede Taste mit einer Aktion eingefärbt ist, darunter, was jede Taste tut. Tasten werden so angezeigt, wie der Spieler sie gerade belegt hat. Der Eintrag Keys (Tasten) des Radialmenüs öffnet ihn; jedes Skript kann es. Solange er offen ist, sind HUDs ausgeblendet.

**Seite:** Client · **Wartet:** nein

```ts title="Signature"
OpenKeyboard(): void
```

```lua title="Lua"
exports['ai-core']:OpenKeyboard()
```

#### Parameter

Keine.

#### Rückgabe

Nichts. Ein Aufruf, während der Bildschirm bereits offen ist, bewirkt nichts. Der Spieler schließt ihn im Bildschirm.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aicore-fivem/lib/client";

const core = resourceExport("ai-core");

RegisterCommand("keys", () => core.OpenKeyboard(), false);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
RegisterCommand('keys', function() exports['ai-core']:OpenKeyboard() end, false)
```
</Tab>
</Tabs>
