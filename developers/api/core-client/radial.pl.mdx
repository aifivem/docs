Menu radialne to koło, które gracze otwierają klawiszem, aby wybrać szybkie akcje (drzwi pojazdu, emotki, akcje pracy). Skrypty dodają swoje elementy do ai-core, a ai-core przekazuje je do menu radialnego, którego używa serwer: ai-radialmenu albo obsługiwanego zewnętrznego (tgiann-radialmenu, qb-radialmenu, codem-supreme-radialmenu, radial z ox_lib).

ai-core trzyma każdy element. Gdy menu radialne się restartuje albo właściciel serwera przełącza się na inne, ai-core sam dodaje każdy element ponownie, więc twój skrypt dodaje swoje elementy **raz przy starcie** i nigdy nie musi obserwować zasobu menu radialnego. Elementy są usuwane, gdy zatrzymuje się zasób, który je dodał.

### AddRadialItem

Dodaje element do menu radialnego albo zastępuje element o tym samym id. Funkcje elementu (`canShow`, `onPressed`) działają wewnątrz twojego zasobu.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
AddRadialItem(item: RadialItem): void
```

```lua title="Lua"
exports['ai-core']:AddRadialItem(item) -- albo aiLib.radial.add(item)
```

#### Zwraca

Nic. Element bez tekstowego `id` lub `label` nie jest dodawany, a ai-core wypisuje ostrzeżenie z nazwą twojego zasobu.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/radial.ts"
import { cache, radial } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import { Locale } from "common";

// Raz przy starcie: przełącznik silnika w podmenu pojazdu, tylko dla kierowcy.
radial.add({
  id: "myscript_engine",
  label: Locale("RADIAL_ENGINE"),
  icon: "power-off",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && cache.seat === -1,
  onPressed: () => {
    if (cache.vehicle === false) return;
    SetVehicleEngineOn(cache.vehicle, !GetIsVehicleEngineRunning(cache.vehicle), false, true);
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/radial.lua"
local Locale = aiLib.locale()

-- Raz przy starcie: przełącznik silnika w podmenu pojazdu, tylko dla kierowcy.
aiLib.radial.add({
  id = 'myscript_engine',
  label = Locale('RADIAL_ENGINE'),
  icon = 'power-off',
  parent = 'vehicle',
  canShow = function() return aiLib.cache.vehicle ~= false and aiLib.cache.seat == -1 end,
  onPressed = function()
    local vehicle = aiLib.cache.vehicle
    if not vehicle then return end
    SetVehicleEngineOn(vehicle, not GetIsVehicleEngineRunning(vehicle), false, true)
  end,
})
```
</Tab>
</Tabs>

<Callout type="warn">
`canShow` działa przy każdym otwarciu koła: niech będzie tani (czytaj `cache`, zmienną lokalną lub `HasItem`), nigdy nie wywołuj z niego serwera. Nie dodawaj tych samych elementów ponownie, gdy menu radialne się restartuje; ai-core już to robi.
</Callout>

### RemoveRadialItem

Usuwa element według jego id.

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
RemoveRadialItem(id: string): void
```

```lua title="Lua"
exports['ai-core']:RemoveRadialItem(id) -- albo aiLib.radial.remove(id)
```

#### Parametry

<TypeTable
  type={{
    id: { type: 'string', description: 'Id, z którym element został dodany. Nieznane id nic nie robi.', required: true },
  }}
/>

#### Zwraca

Nic.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/duty.ts"
import { onPlayerData, radial } from "@aifivem/lib/client";
import { Locale } from "common";

// Akcja skucia tylko na służbie w policji.
onPlayerData("duty", (duty) => {
  if (duty === "police")
    radial.add({ id: "myscript_cuff", label: Locale("RADIAL_CUFF"), icon: "handcuffs", onPressed: () => ExecuteCommand("cuff") });
  else radial.remove("myscript_cuff");
});
```
</Tab>
<Tab value="Lua">
```lua title="client/duty.lua"
local Locale = aiLib.locale()

-- Akcja skucia tylko na służbie w policji.
aiLib.playerData.onChange('duty', function(duty)
  if duty == 'police' then
    aiLib.radial.add({ id = 'myscript_cuff', label = Locale('RADIAL_CUFF'), icon = 'handcuffs', onPressed = function() ExecuteCommand('cuff') end })
  else
    aiLib.radial.remove('myscript_cuff')
  end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Id nie jest sprawdzane względem zasobu, który dodał element: usunięcie `"myscript_cuff"` usuwa go niezależnie od tego, kto go dodał. Używaj id zaczynających się od nazwy twojego zasobu. Dla elementu, który często pojawia się i znika, `canShow` jest prostsze niż dodawanie i usuwanie.
</Callout>

### RefreshRadial

Ponownie czyta każde `canShow` otwartego koła, więc elementy pojawiają się lub znikają, gdy gracz na nie patrzy. Wywołaj to po zmianie czegoś, co czyta `canShow` (gracz wsiadł do pojazdu, wszedł na służbę).

**Strona:** Klient · **Czeka:** nie

```ts title="Sygnatura"
RefreshRadial(): void
```

```lua title="Lua"
exports['ai-core']:RefreshRadial() -- albo aiLib.radial.refresh()
```

#### Parametry

Brak.

#### Zwraca

Nic. Bez działającego menu radialnego nic nie robi.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/radial.ts"
import { onCache, radial } from "@aifivem/lib/client";

// Elementy pojazdu zależą od miejsca: odśwież, gdy się zmieni.
onCache("seat", () => radial.refresh());
```
</Tab>
<Tab value="Lua">
```lua title="client/radial.lua"
-- Elementy pojazdu zależą od miejsca: odśwież, gdy się zmieni.
aiLib.cache.onChange('seat', function() aiLib.radial.refresh() end)
```
</Tab>
</Tabs>
