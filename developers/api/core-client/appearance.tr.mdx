Bu export’lar ai-core’un **görünüm katmanı** üzerinden gider: işi sunucunun çalıştırdığı kıyafet script’i yapar (ai-appearance, tgiann-clothing, illenium-appearance, qb-clothing, crm-appearance, rcore_clothing, bl_appearance). Script’in asla bir kıyafet script’inin kendi biçimine dokunmaz, bu yüzden sunucu sahibi onu değiştirdiğinde çalışmaya devam eder.

Bir **görünüm** ([`CharacterAppearance`](/tr/docs/developers/api/types#characterappearance)) `{ model, data }`’dır: ped model hash’i ve kıyafet script’inin kendi verisi. `data`’yı kapalı bir kutu gibi ele al: bir görünümü server’dan (server lib’inde `appearance.get(charId)`, Lua’da `aiLib.appearance.get`) ya da `GetPedAppearance`’tan al ve değiştirmeden geri ver.

### ApplyAppearance

Aktif kıyafet script’i üzerinden bir ped’e bir görünüm giydirir. Yerel bir ped’i bir karakter gibi giydirmek için (sahibine benzeyen bir dükkancı, uyuyan bir beden, bir fotoğraf) ya da kayıtlı bir görünümü oyuncuya geri giydirmek için kullan.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
ApplyAppearance(ped: number, look: CharacterAppearance): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:ApplyAppearance(ped, look) -- ya da aiLib.appearance.apply(ped, look)
```

#### Parametreler

<TypeTable
  type={{
    ped: { type: 'number', description: 'Ped handle’ı. Modeli görünümün `model`’i olmalıdır: ped’i `look.model` ile oluştur.', required: true },
    look: { type: 'CharacterAppearance', description: 'Server’ın ya da `GetPedAppearance`’ın verdiği haliyle tam olarak `{ model, data }`.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#characterappearance' },
  }}
/>

#### Dönüş değeri

`boolean`: görünüm kıyafet script’ine verildiğinde `true`. Ped yoksa, modeli `look.model`’den farklıysa, görünüm bir `{ model, data }` tablosu değilse ya da hiçbir kıyafet script’i çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { appearance, onClientCallback, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Soran oyuncunun kendi kayıtlı görünümü.
onClientCallback("myscript:myLook", async (source) => {
  const character = core.GetCharacter(source);
  return character ? await appearance.get(character.id) : null;
});
```

```ts title="resource/client/index.ts"
import { appearance, requestModel, triggerServerCallback } from "@aicore-fivem/lib/client";
import { toCharacterAppearance } from "@aicore-fivem/shared";

// Oyuncunun bir noktada duran, onun gibi giyinmiş yerel bir kopyası.
export async function spawnLookalike(x: number, y: number, z: number): Promise<number> {
  const look = toCharacterAppearance(await triggerServerCallback("myscript:myLook", []));
  if (!look) return 0;
  await requestModel(look.model);
  const ped = CreatePed(4, look.model, x, y, z, 0, false, false);
  SetModelAsNoLongerNeeded(look.model);
  appearance.apply(ped, look);
  return ped;
}
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
-- Soran oyuncunun kendi kayıtlı görünümü.
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  return character and aiLib.appearance.get(character.id) or nil
end)
```

```lua title="client.lua"
-- Oyuncunun bir noktada duran, onun gibi giyinmiş yerel bir kopyası (bir thread içinden çağır).
local function spawnLookalike(x, y, z)
  local look = aiLib.triggerServerCallback('myscript:myLook', {})
  if not look then return 0 end
  aiLib.requestModel(look.model)
  local ped = CreatePed(4, look.model, x, y, z, 0.0, false, false)
  SetModelAsNoLongerNeeded(look.model)
  aiLib.appearance.apply(ped, look)
  return ped
end
```
</Tab>
</Tabs>

<Callout type="warn">
Oyuncunun kendi ped’inde `ApplyAppearance` şu an giydiklerini değiştirir. Bu değişikliğin kaydedilip kaydedilmeyeceği ai-core’un değil, kıyafet script’inin kuralıdır. Oyuncuya asla kaydedilmeyen bir üniforma giydirmek için [WearOutfit](#wearoutfit) kullan.
</Callout>

### GetPedAppearance

Bir ped’in şu an giydiği görünümü, server’ın kayıtlı görünümlerinin kullandığı aynı `{ model, data }` şeklinde döndürür.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
GetPedAppearance(ped: number): CharacterAppearance | null
```

```lua title="Lua"
local look = exports['ai-core']:GetPedAppearance(ped) -- ya da aiLib.appearance.read(ped)
```

#### Parametreler

<TypeTable
  type={{
    ped: { type: 'number', description: 'Ped handle’ı (yerel oyuncu için `cache.ped`).', required: true },
  }}
/>

#### Dönüş değeri

[`CharacterAppearance`](/tr/docs/developers/api/types#characterappearance): `model` ped’in model hash’i, `data` kıyafet script’inin verisi. Ped yoksa, hiçbir kıyafet script’i çalışmıyorsa ya da kıyafet script’i o ped’i okuyamıyorsa (bazıları yalnızca yerel oyuncunun kendi ped’ini okur) `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/photo.ts"
import { appearance, cache } from "@aicore-fivem/lib/client";

// Oyuncunun şu an giydiklerini aynı modelden başka bir ped’e kopyalar.
export function copyPlayerLook(target: number): boolean {
  const look = appearance.read(cache.ped);
  return look !== null && appearance.apply(target, look);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/photo.lua"
-- Oyuncunun şu an giydiklerini aynı modelden başka bir ped’e kopyalar.
local function copyPlayerLook(target)
  local look = aiLib.appearance.read(aiLib.cache.ped)
  return look ~= nil and aiLib.appearance.apply(target, look)
end
```
</Tab>
</Tabs>

### OpenClothingMenu

Yerel oyuncu için aktif kıyafet script’inin menülerinden birini açar: kıyafet dükkanı, berber ya da kayıtlı kıyafetleri. Kendi dükkan işaretlerin ya da bir evdeki gardırop için kullan.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
OpenClothingMenu(menu: ClothingMenu): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenClothingMenu(menu) -- ya da aiLib.appearance.openMenu(menu)
```

#### Parametreler

<TypeTable
  type={{
    menu: { type: '"clothing" | "barber" | "outfits"', description: '`clothing`: kıyafet dükkanı. `barber`: saç, sakal ve makyaj. `outfits`: oyuncunun kayıtlı kıyafetleri (bir gardırop).', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#clothingmenu' },
  }}
/>

#### Dönüş değeri

`boolean`: kıyafet script’i menüyü açtığında `true`. Bilinmeyen bir `menu` için, hiçbir kıyafet script’i çalışmıyorsa ya da çalışanın böyle bir menüsü yoksa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/wardrobe.ts"
import { appearance, notify, Points } from "@aicore-fivem/lib/client";
import { Locale } from "common";

const points = new Points();

// Bir motel odasında bir gardırop.
points.add("motel_wardrobe", {
  coords: { x: 151.3, y: -1001.2, z: -99.0 },
  label: Locale("WARDROBE"),
  onPressed: () => {
    if (!appearance.openMenu("outfits")) notify(Locale("NO_WARDROBE"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/wardrobe.lua"
local Locale = aiLib.locale()

RegisterCommand('wardrobe', function()
  if not aiLib.appearance.openMenu('outfits') then
    aiLib.notify(Locale('NO_WARDROBE'), 'error')
  end
end, false)
```
</Tab>
</Tabs>

### WearOutfit

Yerel oyuncuya `ReloadSkin`’e kadar bir meslek kıyafeti (üniforma) giydirir. Yalnızca listelediğin parçalar değişir; kıyafetlerinin geri kalanı kalır. Kıyafet asla oyuncunun kendi görünümü olarak kaydedilmez.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
WearOutfit(outfit: JobOutfit): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:WearOutfit(outfit) -- ya da aiLib.appearance.wearOutfit(outfit)
```

#### Parametreler

<TypeTable
  type={{
    outfit: { type: 'JobOutfit', description: 'Giydirilecek parçalar. Alanlar aşağıda.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#joboutfit' },
  }}
/>

#### JobOutfit

<TypeTable
  type={{
    components: { type: 'OutfitPiece[]', description: 'Kıyafet bileşenleri (gövde, bacaklar, ayakkabılar...): `id` 0-11.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#outfitpiece' },
    props: { type: 'OutfitPiece[]', description: 'Props (şapkalar, gözlükler, saatler...): `id` 0-13.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#outfitpiece' },
  }}
/>

#### OutfitPiece

Ayrıca bkz. [OutfitPiece](/tr/docs/developers/api/types#outfitpiece).

<TypeTable
  type={{
    id: { type: 'number', description: 'Bileşen id’si (0-11) ya da prop id’si (0-13).', required: true },
    collection: { type: 'string', description: 'Parçanın geldiği kıyafet koleksiyonu adı (DLC); temel oyun için `""`. En fazla 64 karakter.', required: true },
    index: { type: 'number', description: 'O koleksiyon içindeki drawable indeksi (0-1023). Bir prop için `-1` prop’u çıkarır.', required: true },
    texture: { type: 'number', description: 'Doku (renk varyantı). Eksik ya da negatif bir değer 0 sayılır.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: kıyafet script’i kıyafeti giydirdiğinde `true`. Kontrolden sonra geçerli parça kalmadıysa, hiçbir kıyafet script’i çalışmıyorsa ya da çalışan kıyafet giydiremiyorsa `false`. Geçersiz parçalar (yanlış id aralığı, kötü indeks) tek tek atılır; geçerli olanlar yine de giyilir.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/locker.ts"
import { appearance } from "@aicore-fivem/lib/client";
import type { JobOutfit } from "@aicore-fivem/shared";

// Temel oyun parçalarından düz bir üniforma: gömlek, pantolon, ayakkabı, şapka yok.
const UNIFORM: JobOutfit = {
  components: [
    { id: 11, collection: "", index: 55, texture: 0 },
    { id: 4, collection: "", index: 35, texture: 0 },
    { id: 6, collection: "", index: 25, texture: 0 },
  ],
  props: [{ id: 0, collection: "", index: -1, texture: 0 }],
};

export const putOnUniform = (): boolean => appearance.wearOutfit(UNIFORM);
export const takeOffUniform = (): boolean => appearance.reloadSkin();
```
</Tab>
<Tab value="Lua">
```lua title="client/locker.lua"
-- Temel oyun parçalarından düz bir üniforma: gömlek, pantolon, ayakkabı, şapka yok.
local UNIFORM = {
  components = {
    { id = 11, collection = '', index = 55, texture = 0 },
    { id = 4, collection = '', index = 35, texture = 0 },
    { id = 6, collection = '', index = 25, texture = 0 },
  },
  props = { { id = 0, collection = '', index = -1, texture = 0 } },
}

local function putOnUniform() return aiLib.appearance.wearOutfit(UNIFORM) end
local function takeOffUniform() return aiLib.appearance.reloadSkin() end
```
</Tab>
</Tabs>

<Callout type="info">
Drawable indeksleri erkek ve kadın freemode modelleri arasında farklıdır: model başına bir kıyafet tut ve oyuncunun modeline göre seç.
</Callout>

### ReloadSkin

Yerel oyuncunun kayıtlı görünümünü geri giydirir. Bir meslek kıyafetini çıkarmak için kullan.

**Taraf:** Client · **Bekler:** hayır

```ts title="İmza"
ReloadSkin(): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:ReloadSkin() -- ya da aiLib.appearance.reloadSkin()
```

#### Parametreler

Yok.

#### Dönüş değeri

`boolean`: kıyafet script’inden görünümü yeniden yüklemesi istendiğinde `true`. Hiçbir kıyafet script’i çalışmıyorsa ya da çalışan yeniden yükleyemiyorsa `false`.

#### Örnek

[WearOutfit](#wearoutfit) örneğine bak.
