O MDT (mobile data terminal) é o computador da polícia: fichas, mandados, relatórios. A **camada de MDT** do ai-core abre o que o servidor roda, então um item radial, uma tecla ou um laptop de viatura no seu script abre a tela certa. MDTs suportados que podem ser abertos por outro script: tgiann-mdt, ps-mdt, wasabi_mdt.

### OpenMdt

Abre a tela do MDT ativo para o jogador local. O MDT verifica o emprego do jogador ele mesmo e recusa um jogador que não pode usá-lo.

**Lado:** Cliente · **Espera:** não

```ts title="Assinatura"
OpenMdt(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenMdt() -- ou aiLib.mdt.open()
```

#### Parâmetros

Nenhum.

#### Retorno

`boolean`: `true` quando o MDT ativo recebeu o pedido de abrir. `false` quando nenhum MDT suportado está rodando, ou o que está rodando não pode ser aberto por outro script. `true` não significa que a tela apareceu: o MDT ainda pode recusar o emprego do jogador.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/laptop.ts"
import { cache, getPlayerData, mdt, notify, radial } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import { Locale } from "common";

// Uma entrada de laptop no submenu do veículo para policiais em serviço.
radial.add({
  id: "myscript_mdt",
  label: Locale("RADIAL_MDT"),
  icon: "laptop",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && getPlayerData("duty") === "police",
  onPressed: () => {
    if (!mdt.open()) notify(Locale("NO_MDT"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/laptop.lua"
local Locale = aiLib.locale()

-- Uma entrada de laptop no submenu do veículo para policiais em serviço.
aiLib.radial.add({
  id = 'myscript_mdt',
  label = Locale('RADIAL_MDT'),
  icon = 'laptop',
  parent = 'vehicle',
  canShow = function()
    return aiLib.cache.vehicle ~= false and aiLib.playerData.get('duty') == 'police'
  end,
  onPressed = function()
    if not aiLib.mdt.open() then aiLib.notify(Locale('NO_MDT'), 'error') end
  end,
})
```
