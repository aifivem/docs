MDT (mobile data terminal) - это полицейский компьютер: досье, ордера, рапорты. **Слой MDT** в ai-core открывает тот, что работает на сервере, поэтому пункт радиального меню, клавиша или ноутбук в транспорте в вашем скрипте откроет нужный экран. Поддерживаемые MDT, которые можно открыть из другого скрипта: tgiann-mdt, ps-mdt, wasabi_mdt.

### OpenMdt

Открывает экран активного MDT для локального игрока. MDT сам проверяет работу игрока и отказывает тому, кому пользоваться им нельзя.

**Сторона:** клиент · **Ожидание:** нет

```ts title="Сигнатура"
OpenMdt(): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenMdt() -- или aiLib.mdt.open()
```

#### Параметры

Нет.

#### Возвращает

`boolean`: `true`, когда активный MDT получил запрос на открытие. `false`, когда не работает ни один поддерживаемый MDT или запущенный нельзя открыть из другого скрипта. `true` не означает, что экран показался: MDT всё ещё может отказать из-за работы игрока.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/laptop.ts"
import { cache, getPlayerData, mdt, notify, radial } from "@aifivem/lib/client";
import { RADIAL_VEHICLE } from "@aifivem/shared";
import { Locale } from "common";

// Пункт «ноутбук» в подменю транспорта для полиции на дежурстве.
radial.add({
  id: "myscript_mdt",
  label: Locale("RADIAL_MDT"),
  icon: "laptop",
  parent: RADIAL_VEHICLE,
  canShow: () => cache.vehicle !== false && getPlayerData("duty") === "police",
  onPressed: () => {
    if (!mdt.open()) notify(Locale("NO_MDT"), "error");
  },
});
```
</Tab>
<Tab value="Lua">
```lua title="client/laptop.lua"
local Locale = aiLib.locale()

-- Пункт «ноутбук» в подменю транспорта для полиции на дежурстве.
aiLib.radial.add({
  id = 'myscript_mdt',
  label = Locale('RADIAL_MDT'),
  icon = 'laptop',
  parent = 'vehicle',
  canShow = function()
    return aiLib.cache.vehicle ~= false and aiLib.playerData.get('duty') == 'police'
  end,
  onPressed = function()
    if not aiLib.mdt.open() then aiLib.notify(Locale('NO_MDT'), 'error') end
  end,
})
```
