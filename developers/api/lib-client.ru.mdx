```ts title="TypeScript"
import { Points, notify, progress, cache } from "@aicore-fivem/lib/client";
```

Клиентский вход также реэкспортирует функции `/fivem` (`every`, `ByResource`, `Reasons`, `caller`, `onStop`, `plateOf`, функции экспортов и локализации, классы state bag): см. [Библиотека: shared и fivem](/ru/docs/developers/api/lib-shared). Последний столбец называет аналог в `aiLib` ([Библиотека для Lua](/ru/docs/developers/api/lua)).

## Связь с сервером

| Функция | Что | Lua |
| --- | --- | --- |
| `triggerServerCallback(name, args = [], timeoutMs?): Promise<unknown>` | Спрашивает сервер (там `onClientCallback`); разберите ответ. | `triggerServerCallback` |
| `onServerCallback(name, handler: (...args) => unknown): void` | Отвечает на `triggerClientCallback` сервера. | `onServerCallback` |
| `onServerEvent(name, handler)` / `onServerEvent(name, { args }, handler)` | Сетевое событие от сервера; вызовы не от сервера отбрасываются. `args` разбирает данные. | `onServerEvent` |
| `fromServer(): boolean` | Пришло ли обрабатываемое событие от сервера. | |
| `callAction(name, args = [], { fallback, timeout?, silent? })` | Выполняет серверное действие, сам показывает переведённый отказ, возвращает ответ ok или null. | `callAction` |
| `isActionOk(reply)`, `replyError(reply, fallback)` | Чтение `ActionResult` вручную. | |

```ts title="TypeScript"
const reply = await callAction("buy", [itemId], { fallback: "BUY_FAILED" });
if (reply) notify(t("BOUGHT"), "success");
```

| `readPlayerState(ped)`, `readWeapon(ped)` | Транспорт, место и оружие педа прямо сейчас. | |
| `player.coords()`, `player.heading()`, `player.distanceTo(point)`, `player.ped()` | Чтение позиции (из кэша). | `player` |
| `player.freeze(state: boolean)` | Замораживает педа. | `player.freeze` |
| `player.teleport(to: { x, y, z? }, { heading?, ground?, fade?, keepVehicle? }): Promise<void>` | Телепорт за затемнением с загрузкой коллизии; без `z` приземляет на землю. | `player.teleport` |
| `player.playAnim(dict, clip, options?): Promise<void>`, `player.stopAnim()` | Запускает или останавливает анимацию. | `player.playAnim`, `player.stopAnim` |
| `player.holdAnim(dict, clip, { ...options, while? })` | Держит анимацию до `stop()` или пока `while()` не вернёт false. | |
| `fadeOut(ms = 300)`, `fadeIn(ms = 400)` | Затемнение экрана; каждое завершается, когда готово. | `fadeOut`, `fadeIn` |
| `getPlayerData(key)`, `onPlayerData(key, handler): () => void`, `seedPlayerData(data)` | Данные игрока из ai-core (`character`, `money`, `jobs`, `duty`, `job`, `gangs`, `activeGang`, `metadata`). | `playerData.get`, `playerData.onChange` |
| `hasJob(jobs, minGrade = 0)`, `inGang(gangs, minGrade = 0)`, `onDutyIn(jobs)` | Проверки членства (пустой список = все). | |
| `onMembershipChange(fn)` | Изменились работы, смена или банды. | |
| `allows(rule: AccessRule): boolean` | Может ли игрок пользоваться местом (серверный `online.allows` решает так же). | |
| `playerPed(serverId): number` | Пед игрока по серверному id, 0 вне зоны. | `playerPed` |
| `nearestPlayer(metres, { from?, filter? }): number \| null` | Серверный id ближайшего другого игрока. | `nearestPlayer` |

## Места и мир

| Функция | Что | Lua |
| --- | --- | --- |
| `new Points()` | Каждое место, которым пользуется игрок: подсказка или таргет (выбор владельца), NPC, метка. | `Points.new()` |
| `points.add(id, { coords, label, icon?, radius?, height?, canShow?, onPressed, onEnter?, onExit?, ped?, blip?, world?, promptOnly?, preferTarget? })` | Добавляет точку; `label` может быть функцией. | `points:add` |
| `points.addModel(id, { models, label, icon?, radius?, canShow?(entity), onPressed(entity), vehicles?, inVehicle? })` | Точка на каждом объекте нужных моделей (банкоматы, стулья). | `points:addModel` |
| `points.addVehicle(id, { label, icon?, radius?, canShow?(vehicle), onPressed(vehicle) })` | Точка на каждом сетевом транспорте. | `points:addVehicle` |
| `points.remove(id)`, `clear()`, `refresh(id?)`, `isInside(id)` | Управление точками; `refresh` заново читает `canShow`. | |
| `new Zones()`: `add(id, options)`, `remove`, `clear`, `isInside`, `size` | Области без взаимодействия. | `Zones.new()` |
| `new LocalPed({ model, coords, ... })`: `entity`, `remove` | Пед, которого видит только этот клиент, создаётся рядом с игроком. | `LocalPed.new()` |
| `new Blips()`: `add(id, options)`, `get`, `remove`, `clear`; `createBlip(options)` | Именованные метки. | `Blips.new()`, `Blips.create()` |
| `showPrompt(id, text, at?)`, `hidePrompt(id)`, `onPromptPressed(handler)` | Подсказка ai-lib вручную (её использует `Points`). | `showPrompt`, `hidePrompt`, `onPromptPressed` |
| `new AdminWorld(files)`: `get`, `onChange`, `view`, `records` | Клиентская копия файлов панели скрипта с `sync: "all"`. | |

```ts title="TypeScript"
const points = new Points();
points.add("shop", {
  coords: { x: 25.7, y: -1347.3, z: 29.5 },
  label: t("OPEN_SHOP"),
  icon: "basket-shopping",
  blip: { sprite: 52, color: 2, scale: 0.8, label: t("SHOP") },
  onPressed: () => openShop(),
});
```

| `radial.add(item)`, `radial.remove(id)`, `radial.refresh()` | Пункты в запущенном радиальном меню. | `radial` |
| `controls.disable(reason, controls, group?)`, `controls.enable(reason)`, `controls.disableAll(reason, except?)` | Отключённое управление, одна задача на кадр. | `controls` |
| `new Keybind({ name, description, defaultKey, defaultMapper, hint?, icon?, hintLabel?, onPressed, onReleased })` | Переназначаемая клавиша; панель может задать её по умолчанию. `isPressed()`, `currentKey()`, `disable(state)`. | `Keybind.new()` |

```ts title="TypeScript"
const done = await progress({
  label: t("REPAIRING"),
  duration: 8000,
  anim: { dict: "mini@repair", clip: "fixing_a_player" },
  canCancel: true,
});
```
