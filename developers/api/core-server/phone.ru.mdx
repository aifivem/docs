Телефонные вызовы идут через ai-core, а не через собственные экспорты телефонного скрипта. ai-core передаёт каждый вызов **первому запущенному телефонному скрипту** (tgiann-phone, lb-phone, gksphone и остальным из списка совместимости). Пока ни один телефон не работает, каждый вызов отвечает `null` или `false`.

### GetPhoneNumber

Номер телефона игрока.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`phone.number`](/ru/docs/developers/api/lib-server/phone-appearance#phonenumber)

```ts title="Сигнатура"
GetPhoneNumber(source: number): string | null
```

```lua title="Lua"
local number = exports['ai-core']:GetPhoneNumber(source) -- string или nil
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
  }}
/>

#### Возвращает

`string | null`: номер в том виде, в каком его пишет телефонный скрипт. `null`, когда у игрока его нет, ни один телефон не работает или `source` не число.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Предмет «визитка» показывает номер владельца.
onClientCallback("myscript:myNumber", (source) => {
  const number = core.GetPhoneNumber(source);
  return number ? { ok: true, number } : fail("NO_PHONE_NUMBER");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myNumber', function(source)
  local number = exports['ai-core']:GetPhoneNumber(source)
  if not number then return aiLib.fail('NO_PHONE_NUMBER') end
  return { ok = true, number = number }
end)
```
</Tab>
</Tabs>

### GetSourceByPhone

Игрок в сети, у которого есть этот номер телефона.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`phone.sourceOf`](/ru/docs/developers/api/lib-server/phone-appearance#phonesourceof)

```ts title="Сигнатура"
GetSourceByPhone(number: string): number | null
```

```lua title="Lua"
local src = exports['ai-core']:GetSourceByPhone('5551234') -- number или nil
```

#### Параметры

<TypeTable
  type={{
    number: { type: 'string', description: 'Номер телефона, записанный так, как его пишет телефонный скрипт.', required: true },
  }}
/>

#### Возвращает

`number | null`: серверный id. `null`, когда владельца номера нет в сети, номер неизвестен, ни один телефон не работает или `number` не текст.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { notify, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** A taxi job tells the caller their cab is on the way, if they are online. */
export function cabOnTheWay(callerNumber: string): void {
  const caller = core.GetSourceByPhone(callerNumber);
  if (caller !== null) notify(caller, Locale("NOTIFY_CAB_COMING"), "info");
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function CabOnTheWay(callerNumber)
  local caller = exports['ai-core']:GetSourceByPhone(callerNumber)
  if caller then aiLib.notify(caller, Locale('NOTIFY_CAB_COMING'), 'info') end
end
```
</Tab>
</Tabs>

### HasPhone

Есть ли у игрока телефон (для телефонных скриптов, которым нужен предмет телефона: носит ли он его).

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`phone.hasPhone`](/ru/docs/developers/api/lib-server/phone-appearance#phonehasphone)

```ts title="Сигнатура"
HasPhone(source: number): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasPhone(source)
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, когда телефонный скрипт говорит, что у игрока есть телефон. `false`, когда нет, когда ни один телефон не работает или `source` не число.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Работе, которая раздаёт задания через SMS, нужен телефон.
onClientCallback("myscript:startDeliveries", (source) =>
  core.HasPhone(source) ? { ok: true } : fail("NEED_PHONE"),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:startDeliveries', function(source)
  if not exports['ai-core']:HasPhone(source) then return aiLib.fail('NEED_PHONE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SendPhoneMail

Отправляет письмо на телефон игрока.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`phone.mail`](/ru/docs/developers/api/lib-server/phone-appearance#phonemail)

```ts title="Сигнатура"
SendPhoneMail(to: number | string, mail: PhoneMail): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMail(source, { sender = 'LS Customs', subject = 'Invoice', message = '...' })
```

#### Параметры

<TypeTable
  type={{
    to: { type: 'number | string', description: 'Серверный id игрока (его номер ищется сам) или номер телефона / почтовый адрес телефона.', required: true },
    mail: { type: 'PhoneMail', description: 'Письмо. Поля ниже.', required: true },
  }}
/>

#### PhoneMail

<TypeTable
  type={{
    sender: { type: 'string', description: 'Показывается как отправитель (компания, `Los Santos Customs`).', default: '""' },
    subject: { type: 'string', description: 'Тема. Обрезается до 120 символов.', required: true },
    message: { type: 'string', description: 'Текст. Обрезается до 4000 символов.', required: true },
  }}
/>

Тексты показываются как есть: передавайте переведённые тексты. См. [PhoneMail](/ru/docs/developers/api/types#phonemail).

#### Возвращает

`boolean`: `true`, когда телефонный скрипт принял письмо. `false`, когда у игрока нет номера, отсутствует `subject` или `message`, ни один телефон не работает или он отказал.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The heist contact mails the location after the job was accepted. */
export function mailHeistLocation(source: number, street: string): void {
  core.SendPhoneMail(source, {
    sender: Locale("MAIL_CONTACT"),
    subject: Locale("MAIL_HEIST_SUBJECT"),
    message: Locale("MAIL_HEIST_BODY", street),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function MailHeistLocation(source, street)
  exports['ai-core']:SendPhoneMail(source, {
    sender = Locale('MAIL_CONTACT'),
    subject = Locale('MAIL_HEIST_SUBJECT'),
    message = Locale('MAIL_HEIST_BODY', street),
  })
end
```
</Tab>
</Tabs>

### SendPhoneMessage

Отправляет SMS с одного номера игроку или на номер.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`phone.message`](/ru/docs/developers/api/lib-server/phone-appearance#phonemessage)

```ts title="Сигнатура"
SendPhoneMessage(from: string, to: number | string, text: string): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMessage('Dispatch', source, 'Your cab is here.')
```

#### Параметры

<TypeTable
  type={{
    from: { type: 'string', description: 'Номер или имя отправителя в том виде, в каком его принимает телефонный скрипт.', required: true },
    to: { type: 'number | string', description: 'Серверный id игрока (его номер ищется сам) или номер телефона.', required: true },
    text: { type: 'string', description: 'Сообщение, уже переведённое. Обрезается до 1000 символов.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, когда телефонный скрипт принял сообщение. `false`, когда у получателя нет номера, `from` или `text` не текст, ни один телефон не работает или он отказал.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The next delivery address arrives by text. */
export function textNextStop(source: number, street: string): void {
  if (!core.SendPhoneMessage(Locale("SENDER_DISPATCH"), source, Locale("TEXT_NEXT_STOP", street)))
    console.log(`player ${source} could not get the text`);
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TextNextStop(source, street)
  if not exports['ai-core']:SendPhoneMessage(Locale('SENDER_DISPATCH'), source, Locale('TEXT_NEXT_STOP', street)) then
    print(('player %d could not get the text'):format(source))
  end
end
```
</Tab>
</Tabs>

### PhoneNotify

Показывает уведомление на телефоне игрока.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`phone.notify`](/ru/docs/developers/api/lib-server/phone-appearance#phonenotify)

```ts title="Сигнатура"
PhoneNotify(source: number, notification: PhoneNotification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:PhoneNotify(source, { title = 'Bank', message = 'Salary paid', app = 'bank' })
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
    notification: { type: 'PhoneNotification', description: 'Что показать. Поля ниже.', required: true },
  }}
/>

#### PhoneNotification

<TypeTable
  type={{
    title: { type: 'string', description: 'Заголовок. Обрезается до 80 символов.', required: true },
    message: { type: 'string', description: 'Текст. Обрезается до 500 символов.', default: '""' },
    app: { type: 'string', description: 'Id приложения телефона, к которому оно относится, если телефон его знает (`messages`, `mail`, `bank`).' },
  }}
/>

См. [PhoneNotification](/ru/docs/developers/api/types#phonenotification).

#### Возвращает

`boolean`: `true`, когда телефонный скрипт его показал. `false`, когда отсутствует `title`, ни один телефон не работает, `source` не число или он отказал.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Tells the owner their car was towed. */
export function towedNotice(source: number, plate: string): void {
  core.PhoneNotify(source, { title: Locale("PHONE_TOW_TITLE"), message: Locale("PHONE_TOW_TEXT", plate) });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TowedNotice(source, plate)
  exports['ai-core']:PhoneNotify(source, { title = Locale('PHONE_TOW_TITLE'), message = Locale('PHONE_TOW_TEXT', plate) })
end
```
</Tab>
</Tabs>
