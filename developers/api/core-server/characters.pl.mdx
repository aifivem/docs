icon: Users
---

**Gracz** to połączona osoba z id serwera (`source`). **Postać** to jedna z osób, którymi gra ten gracz; ma id w bazie danych (`charId`) i citizen id (`citizenid`, krótki tekst, taki jak `ABC12345`). Gracz ma wczytaną postać po wybraniu jej na ekranie postaci. Większość eksportów tutaj odpowiada przed tym `null`.

Wywołania eksportów kopiują swoją odpowiedź, więc odczytaj to, czego potrzebujesz, raz i śledź zdarzenia ai-core (`ai-core:playerLoaded`, `ai-core:playerUnloaded`) zamiast pytać ponownie. Zobacz [Zdarzenia i stan](/pl/docs/developers/api/events).

### GetPlayerData

Wszystko, co ai-core trzyma dla wczytanego gracza, w jednym obiekcie: postać, pieniądze, prace, służba, gangi i metadane. Używaj tego, gdy zasób startuje późno i raz potrzebuje pełnego stanu gracza; dla pojedynczych wartości używaj mniejszych eksportów poniżej.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak na serwerze (`getPlayerData` z klienckiego liba czyta te same dane w grze gracza)

```ts title="Sygnatura"
GetPlayerData(src: number): AiPlayerData | null
```

```lua title="Lua"
local data = exports['ai-core']:GetPlayerData(source) -- table lub nil
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
  }}
/>

#### Zwraca

`AiPlayerData | null`: kopia danych gracza ([AiPlayerData](/pl/docs/developers/api/types#aiplayerdata)). `null`, gdy nikt z tym id serwera nie ma wczytanej postaci (niepołączony albo jeszcze na ekranie postaci). Kopia nie zmienia się później: wywołaj ponownie albo śledź zdarzenia, aby dostać nowe wartości.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("whoami", { help: "Shows your character", restricted: true }, (source) => {
  const data = core.GetPlayerData(source);
  if (!data?.character) return;
  const { firstname, lastname } = data.character;
  console.log(`${firstname} ${lastname}: job ${data.job.job} (grade ${data.job.grade}), cash ${data.money.cash ?? 0}`);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('whoami', { help = 'Shows your character', restricted = true }, function(source)
  local data = exports['ai-core']:GetPlayerData(source)
  if not data or not data.character then return end
  print(('%s %s: job %s (grade %d), cash %d'):format(
    data.character.firstname, data.character.lastname,
    data.job.job, data.job.grade, data.money.cash or 0))
end)
```
</Tab>
</Tabs>

<Callout type="info">
Cały obiekt jest kopiowany przy każdym wywołaniu. Nigdy nie wywołuj tego w pętli po wszystkich graczach ani na timerze: czytaj pojedyncze wartości (`GetMoney`, `GetDutyJob`) albo używaj lustra `online` liba.
</Callout>

### GetCharacter

Wczytana postać gracza: id w bazie danych, citizen id, slot, imię i nazwisko, data urodzenia, płeć i narodowość. Używaj tego, aby pokazać imię albo zapisać coś według id postaci.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak ([`online.character(source)`](/pl/docs/developers/api/lib-server/players#onlinecharacter) czyta to samo z lustra liba bez wywołania eksportu)

```ts title="Sygnatura"
GetCharacter(src: number): CharacterInfo | null
```

```lua title="Lua"
local character = exports['ai-core']:GetCharacter(source) -- table lub nil
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
  }}
/>

#### Zwraca

`CharacterInfo | null`: postać ([CharacterInfo](/pl/docs/developers/api/types#characterinfo)). `null`, gdy gracz nie ma wczytanej postaci.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:profile", (source) => {
  const character = core.GetCharacter(source);
  if (!character) return fail("NO_CHARACTER");
  return { ok: true, name: `${character.firstname} ${character.lastname}`, citizenid: character.citizenid };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:profile', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return aiLib.fail('NO_CHARACTER') end
  return { ok = true, name = character.firstname .. ' ' .. character.lastname, citizenid = character.citizenid }
end)
```
</Tab>
</Tabs>

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak



#### Parametry

<TypeTable

#### Przykład

### GetLoadedSources

Id serwera każdego gracza, który ma wczytaną postać. Używaj tego do rzadkiej pracy na całym serwerze (ostrzeżenie o restarcie, lista dla administratora).

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`online.sources()`](/pl/docs/developers/api/lib-server/players#onlinesources) czyta to samo z lustra liba

```ts title="Sygnatura"
GetLoadedSources(): number[]
```

```lua title="Lua"
local sources = exports['ai-core']:GetLoadedSources() -- lista liczb
```

#### Parametry

Brak.

#### Zwraca

`number[]`: jedno id serwera na wczytanego gracza, bez ustalonej kolejności. Pusta lista, gdy nikt nie ma wczytanej postaci. Gracze, którzy są jeszcze na ekranie postaci, nie są w niej.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

addCommand("announce", {
  help: "Sends a notification to every player",
  params: [{ name: "text", type: "longString" }],
  restricted: true,
}, (_source, args) => {
  for (const target of core.GetLoadedSources())
    notify(target, Locale("NOTIFY_ANNOUNCEMENT", args.text), "warning");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.addCommand('announce', {
  help = 'Sends a notification to every player',
  params = { { name = 'text', type = 'longString' } },
  restricted = true,
}, function(_, args)
  for _, target in ipairs(exports['ai-core']:GetLoadedSources()) do
    aiLib.notify(target, Locale('NOTIFY_ANNOUNCEMENT', args.text), 'warning')
  end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Nigdy nie wywołuj innego eksportu dla każdego id z tej listy na częstej ścieżce (`GetLoadedSources()` + `GetDutyJob` dla każdego gracza co sekundę). Kto jest na służbie, imiona i prace wielu graczy pochodzą z lustra `online` liba; kto jest w pobliżu, z `playersNear`.
</Callout>

### GetCharacterInfo

Postać według id w bazie danych, wczytana lub nie, z id konta, do którego należy. Używaj tego, aby pokazać, kto jest właścicielem czegoś, gdy ta osoba może być offline.

**Strona:** Serwer · **Czeka:** nie (odpowiada przez `done`) · **Lib:** brak

```ts title="Sygnatura"
GetCharacterInfo(
  charId: number,
  done: (info: (CharacterInfo & { userId: number }) | null) => void,
): void
```

```lua title="Lua"
exports['ai-core']:GetCharacterInfo(charId, function(info) end) -- info: table lub nil
```

#### Parametry

<TypeTable
  type={{
    charId: { type: 'number', description: 'Id postaci w bazie danych.', required: true },
    done: { type: '(info) => void', description: 'Wywoływany raz z odpowiedzią. Od razu dla postaci wczytanej lub niedawno odczytanej, w przeciwnym razie po jednym odczycie z bazy danych.', required: true },
  }}
/>

#### Zwraca

Nic. `done` dostaje [CharacterInfo](/pl/docs/developers/api/types#characterinfo) z jednym polem więcej, `userId` (id konta), albo `null` dla nieznanej lub usuniętej postaci, złego id albo nieudanego odczytu. Bez funkcji jako `done` wywołanie nic nie robi.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("charinfo", {
  help: "Shows a character by id",
  params: [{ name: "charId", type: "number" }],
  restricted: true,
}, (_source, args) => {
  core.GetCharacterInfo(args.charId, (info) => {
    if (!info) return console.log("no such character");
    console.log(`${info.firstname} ${info.lastname} (${info.citizenid}), account ${info.userId}`);
  });
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('charinfo', {
  help = 'Shows a character by id',
  params = { { name = 'charId', type = 'number' } },
  restricted = true,
}, function(_, args)
  exports['ai-core']:GetCharacterInfo(args.charId, function(info)
    if not info then return print('no such character') end
    print(('%s %s (%s), account %d'):format(info.firstname, info.lastname, info.citizenid, info.userId))
  end)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Zapisana postać jest trzymana przez 5 minut po odczycie, więc imię zmienione w panelu administratora może tak długo pokazywać starą wartość. Wczytana postać zawsze odpowiada z pamięci.
</Callout>

### SwitchCharacter

Wysyła gracza z powrotem na ekran postaci bez opuszczania serwera, jak wylogowanie. ai-core najpierw zapisuje i zwalnia postać, potem otwiera ekran.

**Strona:** Serwer · **Czeka:** nie (zwolnienie postaci odbywa się po powrocie z wywołania) · **Lib:** brak

```ts title="Sygnatura"
SwitchCharacter(src: number): boolean
```

```lua title="Lua"
local started = exports['ai-core']:SwitchCharacter(source) -- boolean
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy zmiana się rozpoczęła. `false`, gdy gracz nie ma wczytanej postaci.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Przycisk "Zmień postać" w twoim menu.
onClientCallback("myscript:logout", (source) =>
  core.SwitchCharacter(source) ? { ok: true } : fail("NO_CHARACTER"),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:logout', function(source)
  if exports['ai-core']:SwitchCharacter(source) then return { ok = true } end
  return aiLib.fail('NO_CHARACTER')
end)
```
</Tab>
</Tabs>

<Callout type="info">
Twój zasób słyszy `ai-core:playerUnloaded` z powodem `"switch"`, gdy postaci już nie ma. Tam sprzątaj stan per postać, nie zaraz po tym wywołaniu.
</Callout>

### SetOfflinePosition

Przenosi miejsce pojawienia się postaci, która nie jest wczytana: następnym razem, gdy ta postać zostanie wybrana, pojawi się tam. Używaj tego, gdy coś przenosi śpiące ciało lub postać offline (wyniesione ciało, odholowany gracz).

**Strona:** Serwer · **Czeka:** nie (zapis następuje w tle) · **Lib:** [`characters.setOfflinePosition`](/pl/docs/developers/api/lib-server/world#characterssetofflineposition)

```ts title="Sygnatura"
SetOfflinePosition(
  charId: number,
  position: { x: number; y: number; z: number; heading?: number },
): boolean
```

```lua title="Lua"
local accepted = exports['ai-core']:SetOfflinePosition(charId, { x = x, y = y, z = z, heading = h })
```

#### Parametry

<TypeTable
  type={{
    charId: { type: 'number', description: 'Id postaci w bazie danych. Liczba całkowita.', required: true },
    position: { type: '{ x, y, z, heading? }', description: 'Nowe miejsce pojawienia się we współrzędnych świata (metry). `heading` w stopniach.', required: true, typeDescription: '{ x: number; y: number; z: number; heading?: number }' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy przeniesienie zostało przyjęte; zapis do bazy danych następuje, gdy nie trwa żadne wczytywanie ani zapis tej postaci (czeka do 30 sekund). `false`, gdy postać jest teraz wczytana, `charId` nie jest liczbą całkowitą albo brakuje współrzędnej lub nie jest skończoną liczbą. Brakujący `heading` jest zapisywany jako 0.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");
const HOSPITAL = { x: 298.6, y: -584.5, z: 43.3, heading: 70 };

/** A body left in the world too long is moved to the hospital. */
export function sendBodyToHospital(charId: number): void {
  if (!core.SetOfflinePosition(charId, HOSPITAL))
    console.log(`character ${charId} is online, not moved`);
}
```
</Tab>
<Tab value="Lua">
```lua
local HOSPITAL = { x = 298.6, y = -584.5, z = 43.3, heading = 70.0 }

function SendBodyToHospital(charId)
  if not exports['ai-core']:SetOfflinePosition(charId, HOSPITAL) then
    print(('character %d is online, not moved'):format(charId))
  end
end
```
</Tab>
</Tabs>

<Callout type="warn">
Jeśli postać zostanie wczytana, gdy zapis czeka, zapis jest pomijany: ped wczytanej postaci jest tam, gdzie naprawdę jest.
</Callout>

### GetPlayersInScope

Gracze w zasięgu OneSync innego gracza: każdy, czyja gra obecnie streamuje tego gracza, około 424 metrów wokół. ai-core prowadzi tę listę ze zdarzeń zasięgu FiveM raz dla każdego zasobu, więc inne zasoby nigdy same nie nasłuchują tych zdarzeń.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`playersNear(source, radius)`](/pl/docs/developers/api/lib-server/players#playersnear) i [`playersNearEntity(entity, radius)`](/pl/docs/developers/api/lib-server/players#playersnearentity) bazują na tym i filtrują według odległości

```ts title="Sygnatura"
GetPlayersInScope(source: number): number[]
```

```lua title="Lua"
local nearby = exports['ai-core']:GetPlayersInScope(source) -- lista id serwera
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza pośrodku.', required: true },
  }}
/>

#### Zwraca

`number[]`: id serwera pozostałych graczy w zasięgu (sam gracz nie jest na liście). Pusta lista dla samotnego gracza, nieznanego id albo wartości, która nie jest liczbą.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { coordsOf, resourceExport } from "@aicore-fivem/lib/server";
import { distance } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

/** Plays a sound for everyone within 30 m of a player. */
export function playNear(source: number, sound: string): void {
  const at = coordsOf(source);
  for (const other of [source, ...core.GetPlayersInScope(source)])
    if (distance(coordsOf(other), at) <= 30) emitNet("myscript:sound", other, sound);
}
```
</Tab>
<Tab value="Lua">
```lua
function PlayNear(source, sound)
  local at = GetEntityCoords(GetPlayerPed(source))
  local targets = exports['ai-core']:GetPlayersInScope(source)
  targets[#targets + 1] = source
  for _, other in ipairs(targets) do
    if #(GetEntityCoords(GetPlayerPed(other)) - at) <= 30.0 then
      TriggerClientEvent('myscript:sound', other, sound)
    end
  end
end
```
</Tab>
</Tabs>
