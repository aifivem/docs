Wyglądy przechodzą przez ai-core, nigdy przez własne eksporty, zdarzenia lub tabele skryptu ubrań (łącznie z ai-appearance). ai-core czyta je z **aktywnego skryptu ubrań**: tego, który wybiera ustawienie **Clothing script** w panelu, albo pierwszego działającego. Nakładanie wyglądu na peda dzieje się na kliencie (kliencki eksport `ApplyAppearance`, `appearance.apply` liba); zobacz [Eksporty klienckie](/pl/docs/developers/api/core-client).

Wygląd to [CharacterAppearance](/pl/docs/developers/api/types#characterappearance): `{ model, data }`. `model` to hash modelu peda; `data` to własny format skryptu ubrań. Traktuj `data` jak zaplombowaną skrzynkę: oddaj ją do `ApplyAppearance` bez zmian.

### GetAppearanceSystem

Nazwa zasobu skryptu ubrań, z którego ai-core czyta wyglądy.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`appearance.provider()`](/pl/docs/developers/api/lib-server/phone-appearance#appearanceprovider)

```ts title="Sygnatura"
GetAppearanceSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetAppearanceSystem() -- string lub nil
```

#### Parametry

Brak.

#### Zwraca

`string | null`: nazwa zasobu skryptu ubrań. `null`, gdy żaden nie działa (pedy noszą wtedy domyślne ubrania).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("clothingsystem", { help: "Shows the clothing script in use", restricted: true }, () => {
  console.log(core.GetAppearanceSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('clothingsystem', { help = 'Shows the clothing script in use', restricted = true }, function()
  print(exports['ai-core']:GetAppearanceSystem() or 'none')
end)
```
</Tab>
</Tabs>

### GetCharacterAppearance

Zapisany wygląd postaci, niezależnie od tego, czy postać jest wczytana. Używaj tego, aby ubrać peda jak tę postać: śpiące ciało, posąg, zdjęcie, podgląd.

**Strona:** Serwer · **Czeka:** nie (odpowiada przez `done`) · **Lib:** [`appearance.get(charId)`](/pl/docs/developers/api/lib-server/phone-appearance#appearanceget) zwraca Promise

```ts title="Sygnatura"
GetCharacterAppearance(charId: number, done: (look: CharacterAppearance | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetCharacterAppearance(charId, function(look) end) -- look: table lub nil
```

#### Parametry

<TypeTable
  type={{
    charId: { type: 'number', description: 'Id postaci w bazie danych. Dodatnia liczba całkowita.', required: true },
    done: { type: '(look) => void', description: 'Wywoływany raz z wyglądem, po odpowiedzi skryptu ubrań.', required: true, typeDescription: '(look: CharacterAppearance | null) => void' },
  }}
/>

#### Zwraca

Nic. `done` dostaje `{ model, data }` albo `null`, gdy postać nie ma zapisanego wyglądu, nie działa żaden skrypt ubrań, `charId` nie jest dodatnią liczbą całkowitą albo skrypt ubrań zawiódł (zapisane w logu). Bez funkcji jako `done` wywołanie nic nie robi.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import type { CharacterAppearance } from "@aifivem/shared";

const core = resourceExport("ai-core");

// Klient prosi o własny wygląd gracza, aby ubrać peda w fotobudce.
onClientCallback("myscript:myLook", async (source) => {
  const charId = online.charId(source);
  if (charId === undefined) return fail("NO_CHARACTER");
  const look = await new Promise<CharacterAppearance | null>((resolve) => core.GetCharacterAppearance(charId, resolve));
  return look ? { ok: true, look } : fail("NO_LOOK");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return aiLib.fail('NO_CHARACTER') end
  local p = promise.new()
  exports['ai-core']:GetCharacterAppearance(character.id, function(look) p:resolve(look or false) end)
  local look = Citizen.Await(p)
  if not look then return aiLib.fail('NO_LOOK') end
  return { ok = true, look = look }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Wygląd może mieć kilka kilobajtów. Wysyłaj go do jednego gracza, który go potrzebuje, nigdy do wszystkich (`-1`).
</Callout>
