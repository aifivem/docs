Görünümler ai-core üzerinden gider, hiçbir zaman bir kıyafet script’inin kendi export’ları, event’leri ya da tabloları üzerinden değil (ai-appearance dahil). ai-core onları **aktif kıyafet script’inden** okur: panelin **Clothing script** ayarının seçtiği ya da çalışan ilk script. Bir görünümü bir ped’e giydirmek client’ta olur (client export’u `ApplyAppearance`, lib `appearance.apply`); bkz. [Client export’ları](/tr/docs/developers/api/core-client).

Bir görünüm bir [CharacterAppearance](/tr/docs/developers/api/types#characterappearance)’dır: `{ model, data }`. `model` ped model hash’idir; `data` kıyafet script’inin kendi biçimidir. `data`’yı mühürlü bir kutu gibi ele al: `ApplyAppearance`’a değiştirmeden geri ver.

### GetAppearanceSystem

ai-core’un görünümleri okuduğu kıyafet script’inin resource adı.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`appearance.provider()`](/tr/docs/developers/api/lib-server/phone-appearance#appearanceprovider)

```ts title="İmza"
GetAppearanceSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetAppearanceSystem() -- string ya da nil
```

#### Parametreler

Yok.

#### Dönüş değeri

`string | null`: kıyafet script’inin resource adı. Hiçbiri çalışmıyorsa `null` (ped’ler o zaman varsayılan kıyafetleri giyer).

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("clothingsystem", { help: "Shows the clothing script in use", restricted: true }, () => {
  console.log(core.GetAppearanceSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('clothingsystem', { help = 'Shows the clothing script in use', restricted = true }, function()
  print(exports['ai-core']:GetAppearanceSystem() or 'none')
end)
```
</Tab>
</Tabs>

### GetCharacterAppearance

Karakter yüklü olsun olmasın bir karakterin kayıtlı görünümü. Bir ped’i o karakter gibi giydirmek için kullan: uyuyan bir beden, bir heykel, bir fotoğraf, bir önizleme.

**Taraf:** Server · **Bekler:** hayır (`done` ile cevap verir) · **Lib:** [`appearance.get(charId)`](/tr/docs/developers/api/lib-server/phone-appearance#appearanceget) bir Promise döndürür

```ts title="İmza"
GetCharacterAppearance(charId: number, done: (look: CharacterAppearance | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetCharacterAppearance(charId, function(look) end) -- look: tablo ya da nil
```

#### Parametreler

<TypeTable
  type={{
    charId: { type: 'number', description: 'Karakterin veritabanı id’si. Pozitif bir tam sayı.', required: true },
    done: { type: '(look) => void', description: 'Kıyafet script’i cevap verdikten sonra görünümle bir kez çağrılır.', required: true, typeDescription: '(look: CharacterAppearance | null) => void' },
  }}
/>

#### Dönüş değeri

Hiçbir şey. `done` `{ model, data }` alır; karakterin kayıtlı görünümü yoksa, hiçbir kıyafet script’i çalışmıyorsa, `charId` pozitif bir tam sayı değilse ya da kıyafet script’i başarısız olduysa (loglanır) `null` alır. `done` olarak bir fonksiyon verilmezse çağrı hiçbir şey yapmaz.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import type { CharacterAppearance } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Client, bir fotoğraf kabini ped’ini giydirmek için oyuncunun kendi görünümünü ister.
onClientCallback("myscript:myLook", async (source) => {
  const charId = online.charId(source);
  if (charId === undefined) return fail("NO_CHARACTER");
  const look = await new Promise<CharacterAppearance | null>((resolve) => core.GetCharacterAppearance(charId, resolve));
  return look ? { ok: true, look } : fail("NO_LOOK");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return aiLib.fail('NO_CHARACTER') end
  local p = promise.new()
  exports['ai-core']:GetCharacterAppearance(character.id, function(look) p:resolve(look or false) end)
  local look = Citizen.Await(p)
  if not look then return aiLib.fail('NO_LOOK') end
  return { ok = true, look = look }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Bir görünüm birkaç kilobayt olabilir. Onu yalnızca ihtiyacı olan oyuncuya gönder, asla herkese (`-1`) değil.
</Callout>
