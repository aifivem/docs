Postać może mieć **kilka prac i kilka gangów** (do wartości **Most jobs per character** i **Most gangs per character** w panelu). Naraz **na służbie jest najwyżej jedna praca** i tylko ta praca płaci pensję. **Aktywny jest najwyżej jeden gang**. Prace i gangi z ich stopniami są zdefiniowane w panelu administratora (sekcje Jobs i Gangs).

**Stopień** to pozycja na liście stopni pracy, liczona od 0: stopień 0 to pierwszy wiersz w panelu, stopień 1 drugi i tak dalej.

Każda zmiana wysyła serwerowe zdarzenie (`ai-core:jobsChanged`, `ai-core:dutyChanged`, `ai-core:gangsChanged`, `ai-core:activeGangChanged`) i dociera do własnej gry gracza. Zasoby, które potrzebują prac wielu graczy, śledzą te zdarzenia przez lustro `online` liba zamiast wywoływać poniższe eksporty dla każdego gracza. Zobacz [Zdarzenia i stan](/pl/docs/developers/api/events).

### GetJobs

Każde członkostwo w pracy postaci gracza.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`online.jobs(source)`](/pl/docs/developers/api/lib-server/players#onlinejobs) czyta to samo z lustra liba

```ts title="Sygnatura"
GetJobs(src: number): JobMembership[] | null
```

```lua title="Lua"
local jobs = exports['ai-core']:GetJobs(source) -- lista { job, grade } lub nil
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
  }}
/>

#### Zwraca

`JobMembership[] | null`: jedno `{ job, grade }` na pracę ([JobMembership](/pl/docs/developers/api/types#jobmembership)). Pusta lista, gdy postać nie ma pracy (praca bezrobotnego z panelu nigdy nie jest zapisywana). `null`, gdy gracz nie ma wczytanej postaci.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Ekran urzędu pracy wyświetla prace gracza z ich etykietami.
onClientCallback("myscript:myJobs", (source) => {
  const jobs = core.GetJobs(source);
  if (!jobs) return fail("NO_CHARACTER");
  return {
    ok: true,
    jobs: jobs.map(({ job, grade }) => ({
      job,
      label: core.GetJobDefinition(job)?.label ?? job,
      grade,
    })),
  };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myJobs', function(source)
  local jobs = exports['ai-core']:GetJobs(source)
  if not jobs then return aiLib.fail('NO_CHARACTER') end
  local rows = {}
  for _, m in ipairs(jobs) do
    local def = exports['ai-core']:GetJobDefinition(m.job)
    rows[#rows + 1] = { job = m.job, label = def and def.label or m.job, grade = m.grade }
  end
  return { ok = true, jobs = rows }
end)
```
</Tab>
</Tabs>

### GetCurrentJob

Jedna praca, którą inne skrypty powinny traktować jako "tę" pracę gracza: praca na służbie, w przeciwnym razie ostatnia praca, w której gracz był na służbie, w przeciwnym razie pierwsza praca, w przeciwnym razie praca bezrobotnego z panelu. Skrypty ESX i QB widzą tę pracę przez most.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`jobs.current`](/pl/docs/developers/api/lib-server/jobs#jobscurrent)

```ts title="Sygnatura"
GetCurrentJob(src: number): JobMembership | null
```

```lua title="Lua"
local job = exports['ai-core']:GetCurrentJob(source) -- { job, grade } lub nil
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
  }}
/>

#### Zwraca

`JobMembership | null`: `{ job, grade }`. Dla postaci bez żadnej pracy to praca bezrobotnego (ustawienie panelu, domyślnie `unemployed`) ze stopniem 0. `null` tylko wtedy, gdy gracz nie ma wczytanej postaci.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

```ts
const core = resourceExport("ai-core");

addCommand("job", { help: "Shows a player job", params: [{ name: "id", type: "playerId" }], restricted: true }, (_source, args) => {
  const job = core.GetCurrentJob(args.id);
  if (job) console.log(`${job.job} grade ${job.grade}`);

```
</Tab>

### SetDuty

Wprowadza gracza na służbę w jednej z jego prac (i zdejmuje ze służby w każdej innej) albo zdejmuje go ze służby.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`jobs.setDuty`](/pl/docs/developers/api/lib-server/jobs#jobsduty-and-jobssetduty)

```ts title="Sygnatura"
SetDuty(src: number, job: string | null): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDuty(source, 'police') -- nil = poza służbą
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
    job: { type: 'string | null', description: 'Praca, w której wejść na służbę (gracz musi ją mieć), albo `null` (w Lua `nil`), aby zejść ze służby.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy gracz jest teraz na służbie w `job` (lub poza służbą dla `null`), także gdy nic nie musiało się zmienić. `false`, gdy gracz nie ma `job` albo nie ma wczytanej postaci.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const LOCKER_ROOM = { x: 452.3, y: -993.2, z: 30.7 };

// Przełącznik służby w szatni komisariatu.
onClientCallback("myscript:toggleDuty", { guards: [near(LOCKER_ROOM, 3)] }, (source) => {
  const onDuty = core.GetDutyJob(source) === "police";
  return core.SetDuty(source, onDuty ? null : "police") ? { ok: true, onDuty: !onDuty } : fail("NOT_POLICE");
});
```
</Tab>
<Tab value="Lua">
```lua
local LOCKER_ROOM = vector3(452.3, -993.2, 30.7)

aiLib.onClientCallback('myscript:toggleDuty', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - LOCKER_ROOM) > 3.0 then return aiLib.fail('TOO_FAR') end
  local onDuty = exports['ai-core']:GetDutyJob(source) == 'police'
  if not exports['ai-core']:SetDuty(source, (not onDuty) and 'police' or nil) then return aiLib.fail('NOT_POLICE') end
  return { ok = true, onDuty = not onDuty }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Służba nie jest zapisywana: gracz, który dołącza, jest poza służbą, chyba że w panelu włączone jest ustawienie **Keep duty after rejoining**.
</Callout>

### SetJob

Daje graczowi pracę albo zmienia stopień pracy, którą już ma.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`jobs.set`](/pl/docs/developers/api/lib-server/jobs#jobsset)

```ts title="Sygnatura"
SetJob(src: number, job: string, grade: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetJob(source, 'mechanic', 0)
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
    job: { type: 'string', description: 'Nazwa pracy z panelu (`police`, `mechanic`).', required: true },
    grade: { type: 'number', description: 'Indeks stopnia, liczony od 0. Musi istnieć na liście stopni pracy.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy postać ma teraz `job` ze stopniem `grade`. `false`, gdy praca nie istnieje, stopień nie istnieje (nie jest liczbą całkowitą, jest poniżej 0 albo za ostatnim stopniem), postać ma już tyle prac, ile pozwala **Most jobs per character**, albo gracz nie ma wczytanej postaci.

Gdy w panelu wyłączone jest ustawienie **Several jobs per character**, nowa praca zastępuje drugą pracę postaci.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail, readText } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Urząd pracy: każdy może wziąć pracę z listy panelu, ze stopniem 0.
onClientCallback(
  "myscript:takeJob",
  { args: ([job]) => { const name = readText(job, 32); return name ? [name] : null; } },
  (source, job) => {
    if (!core.GetJobDefinition(job)?.listed) return fail("JOB_NOT_LISTED");
    return core.SetJob(source, job, 0) ? { ok: true } : fail("JOB_LIMIT");
  },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:takeJob', function(source, job)
  if type(job) ~= 'string' then return aiLib.fail('BAD_JOB') end
  local def = exports['ai-core']:GetJobDefinition(job)
  if not def or not def.listed then return aiLib.fail('JOB_NOT_LISTED') end
  if not exports['ai-core']:SetJob(source, job, 0) then return aiLib.fail('JOB_LIMIT') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### GetUnemployedJob

Nazwa pracy, którą ma postać bez pracy, ustawiona w panelu administracyjnym.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`jobs.unemployed()`](/pl/docs/developers/api/lib-server/jobs#jobsunemployed)

```ts title="Sygnatura"
GetUnemployedJob(): string
```

```lua title="Lua"
local name = exports['ai-core']:GetUnemployedJob()
```

#### Zwraca

`string`: nazwa pracy. Nigdy nie zakładaj `"unemployed"` - właściciel serwera może ją zmienić, a ai-core nigdy nie zapisuje jej jako przynależności: postać bez wierszy pracy **jest** bezrobotna.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs } from "@aifivem/lib/server";

/** "Czy ten gracz jest bez pracy?", bez zgadywania nazwy. */
export function isJobless(source: number): boolean {
  return jobs.current(source)?.job === jobs.unemployed();
}
```
</Tab>
<Tab value="Lua">
```lua
local current = exports['ai-core']:GetCurrentJob(source)
local jobless = current and current.job == exports['ai-core']:GetUnemployedJob()
```
</Tab>
</Tabs>

<Callout type="info">
Ustawienie gracza na pracę bezrobotnego to nie `SetJob`: zabierz mu prace przez [RemoveJob](#removejob) (albo [RemoveOfflineJob](/pl/docs/developers/api/core-server/stored-characters#setofflinejob-and-removeofflinejob) dla postaci, która nie jest połączona).
</Callout>

### IsPrimeTime

Czy teraz są godziny szczytu dla pracy. Godziny szczytu pochodzą ze źródła wybranego w panelu: skryptu, który trzyma własne godziny (tgiann-policealert), dopóki działa, w przeciwnym razie z własnych godzin ai-core (własne okno pracy lub domyślne). Używaj tego dla reguł zmieniających się z godzinami ruchu, jak napad, który płaci więcej.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`isPrimeTime(job?)`](/pl/docs/developers/api/lib-server/jobs#isprimetime)

```ts title="Sygnatura"
IsPrimeTime(job?: string): boolean
```

```lua title="Lua"
local prime = exports['ai-core']:IsPrimeTime('police')
```

#### Parametry

<TypeTable
  type={{
    job: { type: 'string', description: 'Nazwa pracy. Bez niej (albo z pustym tekstem) sprawdzane są domyślne godziny.' },
  }}
/>

#### Zwraca

`boolean`: `true` w godzinach szczytu. Godziny to czas lokalny serwera; okno, którego początek jest późniejszy niż koniec, trwa po północy, a ten sam początek i koniec oznacza cały dzień. Gdy panel wybiera skrypt jako źródło, a ten skrypt jest zatrzymany, każda godzina liczy się jako godziny szczytu. Działa niezależnie od tego, czy cięcie wypłaty poza godzinami szczytu jest włączone.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** A store robbery pays 50% more outside police prime time. */
export function robberyReward(base: number): number {
  return core.IsPrimeTime("police") ? base : Math.round(base * 1.5);
}
```
</Tab>
<Tab value="Lua">
```lua
function RobberyReward(base)
  if exports['ai-core']:IsPrimeTime('police') then return base end
  return math.floor(base * 1.5 + 0.5)
end
```
</Tab>
</Tabs>

### GetJobDefinitions

Każda definicja pracy z panelu, jako jedna kopia. Używaj tego do rzadkich odczytów, takich jak jednorazowe budowanie listy; dla jednej pracy używaj `GetJobDefinition`.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
GetJobDefinitions(): Record<string, JobDefinition>
```

```lua title="Lua"
local jobs = exports['ai-core']:GetJobDefinitions() -- tabela z nazwą pracy jako kluczem
```

#### Parametry

Brak.

#### Zwraca

`Record<string, JobDefinition>`: każda praca z nazwą jako kluczem. Każda ma `label`, `type`, `defaultDuty`, `listed` (pokazywana w urzędach pracy) i `grades` (każdy z `label`, `salary` i `boss`). Zobacz [JobDefinition](/pl/docs/developers/api/types#jobdefinition) i [GradeDefinition](/pl/docs/developers/api/types#gradedefinition).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Urząd pracy wyświetla każdą pracę oznaczoną w panelu jako "listed".
onClientCallback("myscript:jobCenter", () => ({
  ok: true,
  jobs: Object.entries(core.GetJobDefinitions())
    .filter(([, def]) => def.listed)
    .map(([name, def]) => ({ name, label: def.label, salary: def.grades[0]?.salary ?? 0 })),
}));
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:jobCenter', function()
  local list = {}
  for name, def in pairs(exports['ai-core']:GetJobDefinitions()) do
    if def.listed then
      list[#list + 1] = { name = name, label = def.label, salary = def.grades[1] and def.grades[1].salary or 0 }
    end
  end
  return { ok = true, jobs = list }
end)
```
</Tab>
</Tabs>

<Callout type="info">
W Lua `def.grades[1]` to stopień 0: listy Lua zaczynają się od 1, stopnie od 0.
</Callout>

### GetJobDefinition

Definicja jednej pracy: etykieta, typ, domyślna służba, czy urzędy pracy ją wyświetlają, i jej stopnie.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`definitions.job(name)`](/pl/docs/developers/api/lib-server/jobs#definitionsjob) (czyta każdą pracę raz i zapomina ją, gdy panel ją zmieni)

```ts title="Sygnatura"
GetJobDefinition(job: string): JobDefinition | null
```

```lua title="Lua"
local def = exports['ai-core']:GetJobDefinition('police') -- table lub nil
```

#### Parametry

<TypeTable
  type={{
    job: { type: 'string', description: 'Nazwa pracy.', required: true },
  }}
/>

#### Zwraca

`JobDefinition | null`: praca ([JobDefinition](/pl/docs/developers/api/types#jobdefinition)). `null` dla nieznanej pracy albo wartości, która nie jest tekstem.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Tylko stopień szefa może otworzyć menu szefa.
onClientCallback("myscript:bossMenu", (source) => {
  const job = online.dutyJob(source);
  const grade = job ? online.jobGrade(source, job) : null;
  if (!job || grade === null) return fail("NOT_ON_DUTY");
  if (!core.GetJobDefinition(job)?.grades[grade]?.boss) return fail("NOT_BOSS");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:bossMenu', function(source)
  local job = exports['ai-core']:GetCurrentJob(source)
  if not job or exports['ai-core']:GetDutyJob(source) ~= job.job then return aiLib.fail('NOT_ON_DUTY') end
  local def = exports['ai-core']:GetJobDefinition(job.job)
  local grade = def and def.grades[job.grade + 1]
  if not grade or not grade.boss then return aiLib.fail('NOT_BOSS') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### RegisterJobDefinition and RemoveJobDefinition

Praca, która przychodzi z Twoim skryptem, nie z panelu: należy do wołającego resource, nigdy nie jest zapisywana do pliku panelu i znika, gdy Twój resource się zatrzyma.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`definitions.registerJob`](/pl/docs/developers/api/lib-server/jobs#definitionsregisterjob-and-definitionsremovejob)
