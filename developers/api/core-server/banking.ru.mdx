Банковский слой обращается к **активному банковскому скрипту**: тому, что выбран в настройке панели **Banking script**, или первому запущенному. Он открывает экран этого скрипта и сообщает балансы организаций. Сами деньги работ и банд всегда перемещаются через денежные экспорты ai-core ([Деньги и счета](/ru/docs/developers/api/core-server/money)), а не через банковский скрипт.

Как счета работ и банд связаны с банковским скриптом, зависит от настройки панели **Job and gang accounts**:

- **ai-core's accounts** (по умолчанию): деньги хранит ai-core; банковский скрипт показывает тот же баланс, а деньги, перемещённые на его экране, перемещаются и в ai-core.
- **The script's own accounts**: деньги хранит банковский скрипт; счета `bank` работ и банд в ai-core читают и меняют счета скрипта.

### GetBankingSystem

Имя ресурса банковского скрипта, который использует ai-core.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`banking.provider()`](/ru/docs/developers/api/lib-server/money#bankingprovider)

```ts title="Сигнатура"
GetBankingSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetBankingSystem() -- string или nil
```

#### Параметры

Нет.

#### Возвращает

`string | null`: имя ресурса банковского скрипта. `null`, когда ни один не работает (тогда деньги работ остаются только в ai-core).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("bankingsystem", { help: "Shows the banking script in use", restricted: true }, () => {
  console.log(core.GetBankingSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('bankingsystem', { help = 'Shows the banking script in use', restricted = true }, function()
  print(exports['ai-core']:GetBankingSystem() or 'none')
end)
```
</Tab>
</Tabs>

### OpenBank

Открывает экран банковского скрипта для игрока. Используйте из собственного банкомата или банковской стойки.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`banking.open`](/ru/docs/developers/api/lib-server/money#bankingopen)

```ts title="Сигнатура"
OpenBank(source: number): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenBank(source)
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока. У него должен быть загружен персонаж.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, когда экран открылся. `false`, когда у игрока нет загруженного персонажа, ни один банковский скрипт не работает или его экран нельзя открыть из другого скрипта.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const COUNTER = { x: 149.9, y: -1040.5, z: 29.4 };

onClientCallback("myscript:bankCounter", { guards: [near(COUNTER, 2)] }, (source) =>
  core.OpenBank(source) ? { ok: true } : fail("BANK_UNAVAILABLE"),
);
```
</Tab>
<Tab value="Lua">
```lua
local COUNTER = vector3(149.9, -1040.5, 29.4)

aiLib.onClientCallback('myscript:bankCounter', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - COUNTER) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenBank(source) then return aiLib.fail('BANK_UNAVAILABLE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### GetBankSocietyBalance

Баланс организации работы так, как его показывает банковская настройка: счёт `bank` работы в ai-core при **ai-core's accounts**, собственный счёт скрипта при **The script's own accounts**. Используйте для отображения (меню босса); чтобы перемещать деньги работы, используйте денежные экспорты.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`banking.societyBalance`](/ru/docs/developers/api/lib-server/money#bankingsocietybalance)

```ts title="Сигнатура"
GetBankSocietyBalance(job: string): number | null
```

```lua title="Lua"
local balance = exports['ai-core']:GetBankSocietyBalance('police') -- number или nil
```

#### Параметры

<TypeTable
  type={{
    job: { type: 'string', description: 'Имя работы.', required: true },
  }}
/>

#### Возвращает

`number | null`: баланс. `null`, когда ни один банковский скрипт не работает, у работы нет счёта (неизвестная работа или скрипт не ведёт для неё счёт) или `job` не текст. Без банковского скрипта читайте счёт работы через `GetSharedMoney("job", job, "bank")`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The boss menu balance, with or without a banking script. */
export function societyBalance(job: string): number {
  return core.GetBankSocietyBalance(job) ?? core.GetSharedMoney("job", job, "bank") ?? 0;
}
```
</Tab>
<Tab value="Lua">
```lua
function SocietyBalance(job)
  return exports['ai-core']:GetBankSocietyBalance(job)
    or exports['ai-core']:GetSharedMoney('job', job, 'bank')
    or 0
end
```
</Tab>
</Tabs>
