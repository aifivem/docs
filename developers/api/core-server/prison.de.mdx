---
title: Gefängnis
description: Spieler einsperren, freilassen und die Restzeit lesen, über das Gefängnis-Skript, das der Server nutzt.
icon: Lock
---

Gefängnis-Aufrufe laufen über ai-core, nie über die eigenen Exports oder Events eines Gefängnis-Skripts (ai-prison eingeschlossen). ai-core leitet jeden Aufruf an das **erste laufende Gefängnis-Skript** weiter: ai-prison, qb-prison, rcore_prison, xt-prison, dann tgiann-policejob. Solange keines läuft, antwortet jeder Aufruf mit `false` oder `0`.

### JailPlayer

Schickt einen Spieler für eine Anzahl von Minuten ins Gefängnis.

**Seite:** Server · **Wartet:** nein · **Lib:** [`prison.jail`](/de/docs/developers/api/lib-server/jobs#prisonjail)

```ts title="Signature"
JailPlayer(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local jailed = exports['ai-core']:JailPlayer(target, 20, source)
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers, der eingesperrt wird.', required: true },
    minutes: { type: 'number', description: 'Länge der Strafe in Minuten. Über 0.', required: true },
    by: { type: 'number', description: 'Server-ID des Beamten, für Gefängnis-Skripte, die festhalten, wer es getan hat.', default: '0' },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Gefängnis-Skript den Spieler übernommen hat. `false`, wenn `minutes` nicht über 0 liegt, `source` keine Zahl ist, kein Gefängnis-Skript läuft oder es abgelehnt hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("jail", {
  help: "Jails a player",
  params: [{ name: "id", type: "playerId" }, { name: "minutes", type: "number" }],
  restricted: "ai.job.police",
}, (source, args) => {
  if (core.GetDutyJob(source) !== "police") return;
  core.JailPlayer(args.id, args.minutes, source);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('jail', {
  help = 'Jails a player',
  params = { { name = 'id', type = 'playerId' }, { name = 'minutes', type = 'number' } },
  restricted = 'ai.job.police',
}, function(source, args)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return end
  exports['ai-core']:JailPlayer(args.id, args.minutes, source)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Schreibe die passende MDT-Akte mit [`AddMdtRecord`](/de/docs/developers/api/core-server/mdt) (`kind: "jail"`), wenn der Server ein MDT nutzt.
</Callout>

### ReleasePlayer

Lässt einen Spieler aus dem Gefängnis frei.

**Seite:** Server · **Wartet:** nein · **Lib:** [`prison.release`](/de/docs/developers/api/lib-server/jobs#prisonrelease)

```ts title="Signature"
ReleasePlayer(source: number): boolean
```

```lua title="Lua"
local released = exports['ai-core']:ReleasePlayer(target)
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Gefangenen.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Gefängnis-Skript den Spieler freigelassen hat. `false`, wenn das Gefängnis-Skript ihn nicht freigelassen hat (zum Beispiel, weil er nicht im Gefängnis war), `source` keine Zahl ist oder kein Gefängnis-Skript läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("unjail", { help: "Releases a player", params: [{ name: "id", type: "playerId" }], restricted: true }, (_source, args) => {
  console.log(core.ReleasePlayer(args.id) ? "released" : "not in prison");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('unjail', { help = 'Releases a player', params = { { name = 'id', type = 'playerId' } }, restricted = true }, function(_, args)
  print(exports['ai-core']:ReleasePlayer(args.id) and 'released' or 'not in prison')
end)
```
</Tab>
</Tabs>

### GetJailTime

Wie lange ein Spieler noch absitzen muss.

**Seite:** Server · **Wartet:** nein · **Lib:** [`prison.timeLeft`](/de/docs/developers/api/lib-server/jobs#prisontimeleft)

```ts title="Signature"
GetJailTime(source: number): number
```

```lua title="Lua"
local minutes = exports['ai-core']:GetJailTime(source)
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers.', required: true },
  }}
/>

#### Rückgabe

`number`: verbleibende Minuten. `0`, wenn der Spieler nicht im Gefängnis ist, `source` keine Zahl ist oder kein Gefängnis-Skript läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Gefangene können die Telefonzelle nicht benutzen.
onClientCallback("myscript:phoneBooth", (source) =>
  core.GetJailTime(source) > 0 ? fail("IN_PRISON") : { ok: true },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:phoneBooth', function(source)
  if exports['ai-core']:GetJailTime(source) > 0 then return aiLib.fail('IN_PRISON') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
