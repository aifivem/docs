title: Charaktere und Spieler
description: Die Daten und den Charakter eines geladenen Spielers lesen, einen Spieler per Charakter-ID oder Citizen-ID finden, den Charakter wechseln, einen Offline-Charakter versetzen, Spieler in Reichweite.
icon: Users
---

Ein **Spieler** ist eine verbundene Person mit einer Server-ID (`source`). Ein **Charakter** ist eine der Personen, die dieser Spieler spielt; er hat eine Datenbank-ID (`charId`) und eine Citizen-ID (`citizenid`, ein kurzer Text wie `ABC12345`). Ein Spieler hat einen geladenen Charakter, nachdem er auf dem Charakterbildschirm einen gewählt hat. Die meisten Exports hier antworten vorher mit `null`.

Export-Aufrufe kopieren ihre Antwort, also lies einmal, was du brauchst, und folge den Events von ai-core (`ai-core:playerLoaded`, `ai-core:playerUnloaded`), statt erneut zu fragen. Siehe [Events und Zustand](/de/docs/developers/api/events).

### GetPlayerData

Alles, was ai-core für einen geladenen Spieler hält, in einem Objekt: Charakter, Geld, Jobs, Dienst, Gangs und Metadaten. Nutze es, wenn eine Ressource spät startet und den vollständigen Zustand eines Spielers einmal braucht; für einzelne Werte nutze die kleineren Exports unten.

**Seite:** Server · **Wartet:** nein · **Lib:** keine auf dem Server (`getPlayerData` der Client-Lib liest dieselben Daten im Spiel des Spielers)

```ts title="Signature"
GetPlayerData(src: number): AiPlayerData | null
```

```lua title="Lua"
local data = exports['ai-core']:GetPlayerData(source) -- Tabelle oder nil
```

#### Parameter

<TypeTable
  type={{
    src: { type: 'number', description: 'Server-ID des Spielers.', required: true },
  }}
/>

#### Rückgabe

`AiPlayerData | null`: eine Kopie der Daten des Spielers ([AiPlayerData](/de/docs/developers/api/types#aiplayerdata)). `null`, wenn niemand mit dieser Server-ID einen geladenen Charakter hat (nicht verbunden oder noch auf dem Charakterbildschirm). Die Kopie ändert sich später nicht: Rufe erneut auf oder folge den Events für neue Werte.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("whoami", { help: "Shows your character", restricted: true }, (source) => {
  const data = core.GetPlayerData(source);
  if (!data?.character) return;
  const { firstname, lastname } = data.character;
  console.log(`${firstname} ${lastname}: job ${data.job.job} (grade ${data.job.grade}), cash ${data.money.cash ?? 0}`);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('whoami', { help = 'Shows your character', restricted = true }, function(source)
  local data = exports['ai-core']:GetPlayerData(source)
  if not data or not data.character then return end
  print(('%s %s: job %s (grade %d), cash %d'):format(
    data.character.firstname, data.character.lastname,
    data.job.job, data.job.grade, data.money.cash or 0))
end)
```
</Tab>
</Tabs>

<Callout type="info">
Das ganze Objekt wird bei jedem Aufruf kopiert. Rufe es nie in einer Schleife über alle Spieler oder in einem Timer auf: Lies einzelne Werte (`GetMoney`, `GetDutyJob`) oder nutze den `online`-Spiegel der Lib.
</Callout>

### GetCharacter

Der geladene Charakter eines Spielers: Datenbank-ID, Citizen-ID, Slot, Namen, Geburtsdatum, Geschlecht und Nationalität. Nutze es, um einen Namen anzuzeigen oder etwas nach Charakter-ID zu speichern.

**Seite:** Server · **Wartet:** nein · **Lib:** keine ([`online.character(source)`](/de/docs/developers/api/lib-server/players#onlinecharacter) liest dasselbe aus dem Spiegel der Lib ohne Export-Aufruf)

```ts title="Signature"
GetCharacter(src: number): CharacterInfo | null
```

```lua title="Lua"
local character = exports['ai-core']:GetCharacter(source) -- Tabelle oder nil
```

#### Parameter

<TypeTable
  type={{
    src: { type: 'number', description: 'Server-ID des Spielers.', required: true },
  }}
/>

#### Rückgabe

`CharacterInfo | null`: der Charakter ([CharacterInfo](/de/docs/developers/api/types#characterinfo)). `null`, wenn der Spieler keinen geladenen Charakter hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:profile", (source) => {
  const character = core.GetCharacter(source);
  if (!character) return fail("NO_CHARACTER");
  return { ok: true, name: `${character.firstname} ${character.lastname}`, citizenid: character.citizenid };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:profile', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return aiLib.fail('NO_CHARACTER') end
  return { ok = true, name = character.firstname .. ' ' .. character.lastname, citizenid = character.citizenid }
end)
```
</Tab>
</Tabs>

### GetSourceByCharId

Die Server-ID des Spielers, der gerade einen Charakter spielt. Nutze es, wenn du eine Charakter-ID gespeichert hast (einen Besitzer, einen Kontakt) und diese Person im Spiel erreichen musst.

**Seite:** Server · **Wartet:** nein · **Lib:** keine

```ts title="Signature"
GetSourceByCharId(charId: number): number | null
```

```lua title="Lua"
local src = exports['ai-core']:GetSourceByCharId(charId) -- Zahl oder nil
```

#### Parameter

<TypeTable
  type={{
    charId: { type: 'number', description: 'Datenbank-ID des Charakters (`CharacterInfo.id`).', required: true },
  }}
/>

#### Rückgabe

`number | null`: die Server-ID des Spielers. `null`, wenn gerade niemand diesen Charakter spielt (offline, oder ein anderer Charakter ist geladen).

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

</Tab>

### GetLoadedSources

Die Server-IDs aller Spieler, die einen geladenen Charakter haben. Nutze es für seltene Arbeit über den ganzen Server (eine Neustartwarnung, eine Admin-Liste).

**Seite:** Server · **Wartet:** nein · **Lib:** [`online.sources()`](/de/docs/developers/api/lib-server/players#onlinesources) liest dasselbe aus dem Spiegel der Lib

```ts title="Signature"
GetLoadedSources(): number[]
```

```lua title="Lua"
local sources = exports['ai-core']:GetLoadedSources() -- Liste von Zahlen
```

#### Parameter

Keine.

#### Rückgabe

`number[]`: eine Server-ID pro geladenem Spieler, in keiner festen Reihenfolge. Eine leere Liste, wenn niemand einen Charakter geladen hat. Spieler, die noch auf dem Charakterbildschirm sind, sind nicht enthalten.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

addCommand("announce", {
  help: "Sends a notification to every player",
  params: [{ name: "text", type: "longString" }],
  restricted: true,
}, (_source, args) => {
  for (const target of core.GetLoadedSources())
    notify(target, Locale("NOTIFY_ANNOUNCEMENT", args.text), "warning");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.addCommand('announce', {
  help = 'Sends a notification to every player',
  params = { { name = 'text', type = 'longString' } },
  restricted = true,
}, function(_, args)
  for _, target in ipairs(exports['ai-core']:GetLoadedSources()) do
    aiLib.notify(target, Locale('NOTIFY_ANNOUNCEMENT', args.text), 'warning')
  end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Rufe auf einem häufigen Pfad nie einen weiteren Export für jede ID dieser Liste auf (`GetLoadedSources()` + `GetDutyJob` pro Spieler jede Sekunde). Wer im Dienst ist, Namen und Jobs vieler Spieler kommen aus dem `online`-Spiegel der Lib; wer in der Nähe ist, aus `playersNear`.
</Callout>

### GetCharacterInfo

Ein Charakter per Datenbank-ID, geladen oder nicht, mit der ID des Accounts, zu dem er gehört. Nutze es, um zu zeigen, wem etwas gehört, wenn diese Person offline sein kann.

**Seite:** Server · **Wartet:** nein (antwortet über `done`) · **Lib:** keine

```ts title="Signature"
GetCharacterInfo(
  charId: number,
  done: (info: (CharacterInfo & { userId: number }) | null) => void,
): void
```

```lua title="Lua"
exports['ai-core']:GetCharacterInfo(charId, function(info) end) -- info: Tabelle oder nil
```

#### Parameter

<TypeTable
  type={{
    charId: { type: 'number', description: 'Datenbank-ID des Charakters.', required: true },
    done: { type: '(info) => void', description: 'Wird einmal mit der Antwort aufgerufen. Sofort für einen geladenen oder kürzlich gelesenen Charakter, sonst nach einem Datenbank-Lesevorgang.', required: true },
  }}
/>

#### Rückgabe

Nichts. `done` erhält ein [CharacterInfo](/de/docs/developers/api/types#characterinfo) mit einem zusätzlichen Feld, `userId` (die Account-ID), oder `null` für einen unbekannten oder gelöschten Charakter, eine falsche ID oder einen fehlgeschlagenen Lesevorgang. Ohne eine Funktion als `done` tut der Aufruf nichts.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("charinfo", {
  help: "Shows a character by id",
  params: [{ name: "charId", type: "number" }],
  restricted: true,
}, (_source, args) => {
  core.GetCharacterInfo(args.charId, (info) => {
    if (!info) return console.log("no such character");
    console.log(`${info.firstname} ${info.lastname} (${info.citizenid}), account ${info.userId}`);
  });
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('charinfo', {
  help = 'Shows a character by id',
  params = { { name = 'charId', type = 'number' } },
  restricted = true,
}, function(_, args)
  exports['ai-core']:GetCharacterInfo(args.charId, function(info)
    if not info then return print('no such character') end
    print(('%s %s (%s), account %d'):format(info.firstname, info.lastname, info.citizenid, info.userId))
  end)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Ein gespeicherter Charakter wird nach dem Lesen 5 Minuten lang vorgehalten, sodass ein im Admin-Panel geänderter Name so lange den alten Wert zeigen kann. Ein geladener Charakter antwortet immer aus dem Speicher.
</Callout>

### SwitchCharacter

Schickt einen Spieler zurück zum Charakterbildschirm, ohne den Server zu verlassen, wie ein Logout. ai-core speichert und entlädt den Charakter zuerst und öffnet dann den Bildschirm.

**Seite:** Server · **Wartet:** nein (das Entladen läuft, nachdem der Aufruf zurückkehrt) · **Lib:** keine

```ts title="Signature"
SwitchCharacter(src: number): boolean
```

```lua title="Lua"
local started = exports['ai-core']:SwitchCharacter(source) -- boolean
```

#### Parameter

<TypeTable
  type={{
    src: { type: 'number', description: 'Server-ID des Spielers.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn der Wechsel gestartet ist. `false`, wenn der Spieler keinen geladenen Charakter hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Ein Button „Charakter wechseln“ in deinem Menü.
onClientCallback("myscript:logout", (source) =>
  core.SwitchCharacter(source) ? { ok: true } : fail("NO_CHARACTER"),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:logout', function(source)
  if exports['ai-core']:SwitchCharacter(source) then return { ok = true } end
  return aiLib.fail('NO_CHARACTER')
end)
```
</Tab>
</Tabs>

<Callout type="info">
Deine Ressource hört `ai-core:playerUnloaded` mit dem Grund `"switch"`, wenn der Charakter weg ist. Räume den Zustand pro Charakter dort auf, nicht direkt nach diesem Aufruf.
</Callout>

### SetOfflinePosition

Verschiebt den Spawnpunkt eines Charakters, der nicht geladen ist: Wenn dieser Charakter das nächste Mal gewählt wird, erscheint er dort. Nutze es, wenn etwas einen schlafenden Körper oder einen Offline-Charakter bewegt (ein weggetragener Körper, ein abgeschleppter Spieler).

**Seite:** Server · **Wartet:** nein (das Schreiben folgt im Hintergrund) · **Lib:** [`characters.setOfflinePosition`](/de/docs/developers/api/lib-server/world#characterssetofflineposition)

```ts title="Signature"
SetOfflinePosition(
  charId: number,
  position: { x: number; y: number; z: number; heading?: number },
): boolean
```

```lua title="Lua"
local accepted = exports['ai-core']:SetOfflinePosition(charId, { x = x, y = y, z = z, heading = h })
```

#### Parameter

<TypeTable
  type={{
    charId: { type: 'number', description: 'Datenbank-ID des Charakters. Eine ganze Zahl.', required: true },
    position: { type: '{ x, y, z, heading? }', description: 'Der neue Spawnpunkt in Weltkoordinaten (Meter). `heading` in Grad.', required: true, typeDescription: '{ x: number; y: number; z: number; heading?: number }' },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn die Verschiebung angenommen wurde; das Schreiben in die Datenbank folgt, sobald kein Laden oder Speichern dieses Charakters läuft (es wartet bis zu 30 Sekunden). `false`, wenn der Charakter gerade geladen ist, `charId` keine ganze Zahl ist oder eine Koordinate fehlt oder keine endliche Zahl ist. Ein fehlendes `heading` wird als 0 gespeichert.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");
const HOSPITAL = { x: 298.6, y: -584.5, z: 43.3, heading: 70 };

/** Ein Körper, der zu lange in der Welt liegt, wird ins Krankenhaus gebracht. */
export function sendBodyToHospital(charId: number): void {
  if (!core.SetOfflinePosition(charId, HOSPITAL))
    console.log(`character ${charId} is online, not moved`);
}
```
</Tab>
<Tab value="Lua">
```lua
local HOSPITAL = { x = 298.6, y = -584.5, z = 43.3, heading = 70.0 }

function SendBodyToHospital(charId)
  if not exports['ai-core']:SetOfflinePosition(charId, HOSPITAL) then
    print(('character %d is online, not moved'):format(charId))
  end
end
```
</Tab>
</Tabs>

<Callout type="warn">
Wird der Charakter geladen, während das Schreiben wartet, wird das Schreiben übersprungen: Der Ped eines geladenen Charakters ist dort, wo er wirklich ist.
</Callout>

### GetPlayersInScope

Die Spieler im OneSync-Scope eines anderen Spielers: alle, deren Spiel diesen Spieler gerade streamt, etwa 424 Meter im Umkreis. ai-core führt diese Liste einmal für jede Ressource aus den Scope-Events von FiveM, sodass andere Ressourcen nie selbst auf diese Events hören.

**Seite:** Server · **Wartet:** nein · **Lib:** [`playersNear(source, radius)`](/de/docs/developers/api/lib-server/players#playersnear) und [`playersNearEntity(entity, radius)`](/de/docs/developers/api/lib-server/players#playersnearentity) bauen darauf auf und filtern nach Entfernung

```ts title="Signature"
GetPlayersInScope(source: number): number[]
```

```lua title="Lua"
local nearby = exports['ai-core']:GetPlayersInScope(source) -- Liste von Server-IDs
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers in der Mitte.', required: true },
  }}
/>

#### Rückgabe

`number[]`: die Server-IDs der anderen Spieler im Scope (der Spieler selbst ist nicht in der Liste). Eine leere Liste für einen Spieler allein, eine unbekannte ID oder einen Wert, der keine Zahl ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { coordsOf, resourceExport } from "@aicore-fivem/lib/server";
import { distance } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

/** Spielt einen Sound für alle im Umkreis von 30 m um einen Spieler. */
export function playNear(source: number, sound: string): void {
  const at = coordsOf(source);
  for (const other of [source, ...core.GetPlayersInScope(source)])
    if (distance(coordsOf(other), at) <= 30) emitNet("myscript:sound", other, sound);
}
```
</Tab>
<Tab value="Lua">
```lua
function PlayNear(source, sound)
  local at = GetEntityCoords(GetPlayerPed(source))
  local targets = exports['ai-core']:GetPlayersInScope(source)
  targets[#targets + 1] = source
  for _, other in ipairs(targets) do
    if #(GetEntityCoords(GetPlayerPed(other)) - at) <= 30.0 then
      TriggerClientEvent('myscript:sound', other, sound)
    end
  end
end
```
</Tab>
</Tabs>
