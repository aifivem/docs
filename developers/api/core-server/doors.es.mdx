---
title: Cerraduras de puertas
description: Cierra, abre y lee puertas a través del script de cerraduras que tenga el servidor.
icon: DoorClosed
---

Las llamadas de puertas pasan por ai-core, nunca por los exports o eventos propios de un script de cerraduras (ai-doorlock incluido). ai-core reenvía cada llamada al **script de cerraduras activo**: el que elige el ajuste **Door lock script** (script de cerraduras) del panel, o el primero que esté en marcha (ai-doorlock, ox_doorlock, tgiann-doorlock y los demás de la lista de compatibilidad).

Una puerta se nombra por **el id de puerta propio de ese script**: el id que ves en su lista de puertas (ai-doorlock: el id de la puerta en el panel de administración; ox_doorlock: su número en la base de datos).

### GetDoorlockSystem

El nombre de recurso del script de cerraduras al que reenvía ai-core.

**Lado:** Servidor · **Espera:** no · **Lib:** [`doors.provider()`](/es/docs/developers/api/lib-server/world#doorsprovider)

```ts title="Firma"
GetDoorlockSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetDoorlockSystem() -- string o nil
```

#### Parámetros

Ninguno.

#### Devuelve

`string | null`: el nombre de recurso del script de cerraduras. `null` cuando no hay ninguno en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Los ids de puerta de tu config pertenecen a un script de cerraduras: avisa cuando hay otro en marcha.
if (core.GetDoorlockSystem() !== "ai-doorlock")
  console.log("myscript: door ids are written for ai-doorlock");
```
</Tab>
<Tab value="Lua">
```lua
if exports['ai-core']:GetDoorlockSystem() ~= 'ai-doorlock' then
  print('myscript: door ids are written for ai-doorlock')
end
```
</Tab>
</Tabs>

### SetDoorLocked

Cierra o abre una puerta.

**Lado:** Servidor · **Espera:** no · **Lib:** [`doors.setLocked`](/es/docs/developers/api/lib-server/world#doorssetlocked)

```ts title="Firma"
SetDoorLocked(id: string, locked: boolean, by?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDoorLocked('pacific_vault', false, source)
```

#### Parámetros

<TypeTable
  type={{
    id: { type: 'string', description: 'El id de puerta del script de cerraduras. Un número entero (ids de ox_doorlock) se convierte en texto. Como mucho 128 caracteres.', required: true },
    locked: { type: 'boolean', description: '`true` cierra, `false` abre. Debe ser un booleano de verdad.', required: true },
    by: { type: 'number', description: 'Id de servidor del jugador que lo hace. Los scripts de cerraduras sin API de servidor necesitan un jugador cuyo juego lleve el cambio; se ignora si ese jugador no está conectado.' },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de cerraduras aceptó el cambio. `false` cuando no hay ningún script de cerraduras en marcha, la puerta es desconocida, el script lo rechazó, `id` está vacío o `locked` no es un booleano.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, progressFor, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const VAULT = { x: 253.9, y: 225.2, z: 101.9 };

onClientCallback("myscript:hackVault", { guards: [near(VAULT, 2)], lock: true }, async (source) => {
  if (!core.HasItem(source, "laptop")) return fail("NO_LAPTOP");
  if (!(await progressFor(source, { label: Locale("HACKING"), duration: 15000 }))) return fail("CANCELLED");
  return core.SetDoorLocked("pacific_vault", false, source) ? { ok: true } : fail("DOOR_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local VAULT = vector3(253.9, 225.2, 101.9)

aiLib.onClientCallback('myscript:hackVault', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - VAULT) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:HasItem(source, 'laptop') then return aiLib.fail('NO_LAPTOP') end
  if not aiLib.progressFor(source, { label = Locale('HACKING'), duration = 15000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:SetDoorLocked('pacific_vault', false, source) then return aiLib.fail('DOOR_FAILED') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### IsDoorLocked

Si una puerta está cerrada.

**Lado:** Servidor · **Espera:** no · **Lib:** [`doors.isLocked`](/es/docs/developers/api/lib-server/world#doorsislocked)

```ts title="Firma"
IsDoorLocked(id: string): boolean | null
```

```lua title="Lua"
local locked = exports['ai-core']:IsDoorLocked('pacific_vault') -- true, false o nil
```

#### Parámetros

<TypeTable
  type={{
    id: { type: 'string', description: 'El id de puerta del script de cerraduras (un número entero se convierte en texto).', required: true },
  }}
/>

#### Devuelve

`boolean | null`: `true` cerrada, `false` abierta. `null` cuando se desconoce: no hay ningún script de cerraduras en marcha, la puerta no existe, el script no puede saberlo en el servidor o `id` está vacío.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** The heist may start only while the vault is still closed. */
export function vaultClosed(): boolean {
  return core.IsDoorLocked("pacific_vault") !== false;
}
```
</Tab>
<Tab value="Lua">
```lua
function VaultClosed()
  return exports['ai-core']:IsDoorLocked('pacific_vault') ~= false
end
```
</Tab>
</Tabs>

<Callout type="info">
Decide qué significa `null` para tu función. El ejemplo trata "desconocido" como cerrado, así que la falta de un script de cerraduras nunca abre el golpe antes de tiempo.
</Callout>
