ai-core udostępnia jeden panel administratora dla każdego skryptu. Większość eksportów na tej stronie to instalacja, którą `@aifivem/lib` wywołuje za ciebie: skrypt zbudowany z `AdminPanel` i `addCommand` z liba nigdy sam nie wywołuje `RegisterAdminPanel`, `AdminPanelChanged` ani `RegisterCommands`. Są opisane, abyś wiedział, co się dzieje, i mógł je obsłużyć z innego języka. `RegisterExternalPanel` i `GetLookupValues` przydają się każdemu skryptowi.

### RegisterAdminPanel

Ogłasza, że wywołujący zasób ma sekcję w panelu. ai-core pyta go wtedy o schemat i dane za każdym razem, gdy administrator otwiera panel.

**Strona:** Serwer · **Czeka:** nie · **Lib:** wywoływany przez [`AdminPanel`](/pl/docs/developers/api/lib-server/admin-panel#adminpanel) z liba przy jego starcie

```ts title="Sygnatura"
RegisterAdminPanel(resource: string): void
```

```lua title="Lua"
exports['ai-core']:RegisterAdminPanel(GetCurrentResourceName())
```

#### Parametry

<TypeTable
  type={{
    resource: { type: 'string', description: 'Zachowany dla starszych wywołań i ignorowany: panel zawsze należy do zasobu, który wywołuje.', required: true },
  }}
/>

#### Zwraca

Nic. Rejestracja jest usuwana, gdy zasób się zatrzymuje.

#### Przykład

Bez przykładu: wywołuje to `AdminPanel` z liba. Zasób, który rejestruje się bez liba, musi też odpowiadać na eksporty, które ai-core wywołuje zwrotnie (`AdminPanelSnapshot`, `AdminPanelData`, `AdminPanelSummary`, typowane `AdminPanelResourceExports` w `@aifivem/shared`), co jest zadaniem liba.

### AdminPanelChanged

Zasób panelu mówi ai-core, że jeden z jego rekordów się zmienił. ai-core przekazuje zmianę każdemu administratorowi, który ma otwarty panel, więc jego ekran aktualizuje się bez przeładowania.

**Strona:** Serwer · **Czeka:** nie · **Lib:** wywoływany przez [`AdminPanel`](/pl/docs/developers/api/lib-server/admin-panel#adminpanel) z liba po każdej zapisanej zmianie

```ts title="Sygnatura"
AdminPanelChanged(delta: AdminDelta): void
```

```lua title="Lua"
exports['ai-core']:AdminPanelChanged({ resource = GetCurrentResourceName(), file = 'shops', key = 'shop_1', value = record })
```

#### Parametry

<TypeTable
  type={{
    delta: { type: 'AdminDelta', description: 'Co się zmieniło: `resource`, `file` (nazwa pliku danych), `key` (rekord, nieobecny dla całego pliku ustawień) i nowa `value` (`null` dla usuniętego rekordu).', required: true, typeDescription: '{ resource: string; file: string; key?: string; value: unknown }' },
  }}
/>

Zobacz [AdminDelta](/pl/docs/developers/api/types#admindelta).

#### Zwraca

Nic. ai-core nie sprawdza delty; wysyła ją tak, jak została podana.

#### Przykład

Bez przykładu: `AdminPanel` z liba wywołuje to po sprawdzeniu i zapisaniu zmiany.

### RegisterCommands

Wyświetla komendy zasobu w karcie **Commands** panelu, z ich pomocą, parametrami i tym, kto może ich używać.

**Strona:** Serwer · **Czeka:** nie · **Lib:** wywoływany przez [`addCommand`](/pl/docs/developers/api/lib-server/commands#addcommand) z liba (TypeScript i `aiLib.addCommand` w Lua)

```ts title="Sygnatura"
RegisterCommands(resource: string, commands: CommandInfo[]): void
```

```lua title="Lua"
exports['ai-core']:RegisterCommands(GetCurrentResourceName(), commands)
```

#### Parametry

<TypeTable
  type={{
    resource: { type: 'string', description: 'Zachowany dla starszych wywołań i ignorowany: komendy należą do zasobu, który wywołuje.', required: true },
    commands: { type: 'CommandInfo[]', description: 'Każda komenda zasobu: `names` (pierwsza = nazwa, reszta = aliasy), `help`, `params` i `aces` (`null` = wszyscy). Niepoprawne wpisy są pomijane z ostrzeżeniem w konsoli.', required: true },
  }}
/>

Zobacz [CommandInfo](/pl/docs/developers/api/types#commandinfo) i [CommandParam](/pl/docs/developers/api/types#commandparam).

#### Zwraca

Nic. Lista jest usuwana, gdy zasób się zatrzymuje. Dla komend ograniczonych do principala (`group.admin`) ai-core nadaje temu principalowi także `command.<name>`, co wymaga `add_ace resource.ai-core command.add_ace allow` (i `command.remove_ace`) w `permission.cfg`.

#### Przykład

Bez przykładu: użyj `addCommand` z liba (TypeScript) lub `aiLib.addCommand` (Lua), a komenda sama pojawi się w karcie. Komendy utworzone gołym `RegisterCommand` też są wyświetlane, oznaczone jako zwykłe.

### GetLookupValues

Wartości jednej listy wyszukiwania: nazwy przedmiotów aktywnego ekwipunku, nazwy prac, nazwy gangów i tak dalej. Walidacja panelu w libie używa tego, aby sprawdzić, czy wartość wpisana przez administratora istnieje.

**Strona:** Serwer · **Czeka:** nie · **Lib:** używany przez walidację [`AdminPanel`](/pl/docs/developers/api/lib-server/admin-panel#adminpanel) z liba

```ts title="Sygnatura"
GetLookupValues(source: LookupSource): string[]
```

```lua title="Lua"
local items = exports['ai-core']:GetLookupValues('item') -- lista nazw przedmiotów
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'LookupSource', description: 'Która lista.', required: true, typeDescription: '"item" | "job" | "gang" | "account" | "resource" | "player" | "vehicle" | "ped"' },
  }}
/>

| `source` | Wartości |
| --- | --- |
| `item` | Nazwy przedmiotów aktywnego ekwipunku. |
| `job` / `gang` | Nazwy prac / gangów z panelu. |
| `account` | Nazwy typów kont (`cash`, `bank`...). |
| `resource` | Nazwy uruchomionych zasobów. |
| `player` | Citizen id graczy z wczytaną postacią. |
| `vehicle` / `ped` | Zawsze puste: tylko gra administratora może wyświetlić listę modeli. |

Zobacz [LookupSource](/pl/docs/developers/api/types#lookupsource).

#### Zwraca

`string[]`: wartości posortowane według etykiety. Pusta lista dla nieznanego `source`, dla `vehicle` i `ped` oraz gdy lista nie jest jeszcze znana (nie działa żaden ekwipunek): traktuj pustą listę jako "nie da się sprawdzić", nie jako "nic nie jest poprawne".

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Checks a reward item from your config; unknown is fine while no inventory runs. */
export function isKnownItem(name: string): boolean {
  const items = core.GetLookupValues("item");
  return items.length === 0 || items.includes(name);
}
```
</Tab>
<Tab value="Lua">
```lua
function IsKnownItem(name)
  local items = exports['ai-core']:GetLookupValues('item')
  if #items == 0 then return true end
  for _, item in ipairs(items) do
    if item == name then return true end
  end
  return false
end
```
</Tab>
</Tabs>

<Callout type="info">
Lista jest budowana od nowa przy każdym wywołaniu (lista przedmiotów może być długa). Wywołuj to przy walidacji, nie w pętli.
</Callout>

### RegisterExternalPanel

Wyświetla własny ekran ustawień innego skryptu na dashboardzie panelu ai-core, więc właściciel serwera znajduje ustawienia każdego skryptu w jednym miejscu. Karta otwiera ekran komendą czatu albo pokazuje stronę internetową wewnątrz panelu.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
RegisterExternalPanel(panel: {
  id?: string;
  label: string;
  icon?: string;
  description?: string;
  command?: string;
  url?: string;
}): void
```

```lua title="Lua"
exports['ai-core']:RegisterExternalPanel({ label = 'My script', command = 'myscriptconfig' })
```

#### Parametry

<TypeTable
  type={{
    panel: { type: 'object', description: 'Karta dashboardu. Pola poniżej.', required: true },
  }}
/>

#### Pola panelu

<TypeTable
  type={{
    id: { type: 'string', description: 'Id karty, unikalne w obrębie twojego zasobu (2-48 liter, cyfr, `_`, `.`, `-`). Drugie wywołanie z tym samym id zastępuje kartę.', default: 'nazwa zasobu' },
    label: { type: 'string', description: 'Tytuł karty. Obcinany do 48 znaków.', required: true },
    icon: { type: 'string', description: 'Nazwa ikony karty. Obcinana do 32 znaków.' },
    description: { type: 'string', description: 'Jedna linia pod tytułem. Obcinana do 160 znaków.' },
    command: { type: 'string', description: 'Komenda czatu, która otwiera twój ekran (początkowy `/` jest usuwany). Podaj `command` lub `url`.' },
    url: { type: 'string', description: 'Strona internetowa pokazywana wewnątrz panelu. Tylko adresy `https://` (strona NUI twojego zasobu lub strona, której ufasz); obcinana do 300 znaków.' },
  }}
/>

#### Zwraca

Nic. Bez `label` albo bez obu `command` i `url` karta nie jest dodawana. Karty są usuwane, gdy twój zasób się zatrzymuje.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Raz przy starcie.
core.RegisterExternalPanel({
  label: "My script",
  icon: "gear",
  description: "Shops, prices and rewards",
  command: "myscriptconfig",
});
```
</Tab>
<Tab value="Lua">
```lua
exports['ai-core']:RegisterExternalPanel({
  label = 'My script',
  icon = 'gear',
  description = 'Shops, prices and rewards',
  command = 'myscriptconfig',
})
```
</Tab>
</Tabs>

<Callout type="info">
Skrypt, którego nie możesz zmienić, może zostać wyświetlony przez linie w jego `fxmanifest.lua`: `ai_admin_label`, `ai_admin_command` lub `ai_admin_url` i opcjonalnie `ai_admin_icon` oraz `ai_admin_description`. Właściciel serwera może też dodawać karty ręcznie w panelu.
</Callout>
