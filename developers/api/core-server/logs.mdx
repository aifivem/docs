Every resource logs through ai-core. Your resource names a **channel** (`purchases`, `robberies`) and writes a message; ai-core decides where it goes. The server owner turns providers on in the admin panel (console, Discord, Fivemanage, FiveM Stats), sets the minimum level, and pastes Discord webhook urls per resource and channel. A resource never posts to a webhook or a log service itself, and never holds a webhook url.

Pass the players involved as `source` and `target` instead of writing their names into the message: ai-core adds each player's name, character, citizen id and identifiers (the IP only when the panel allows it).

### Log

Sends one log entry of your resource.

**Side:** Server · **Waits:** no · **Lib:** [`aiLog(channel, message, options?)`](/docs/developers/api/lib-server/logs#ailog) (Lua: `aiLib.aiLog`; both print to the console instead while ai-core is not running)

```ts title="Signature"
Log(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { price = 25000 } })
```

#### Parameters

<TypeTable
  type={{
    channel: { type: 'string', description: 'Channel name of your resource (`purchases`). The webhook and the on/off switch are per channel. `log` when not a text.', required: true },
    message: { type: 'string', description: 'What happened, in plain English. Other values are turned into text.', required: true },
    options: { type: 'LogOptions', description: 'Level, players and extra values. Fields below.' },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: 'How important it is. Entries below the panel minimum level are dropped.', default: '"info"' },
    source: { type: 'number', description: 'Server id of the player who did it; their name, character and identifiers are added.' },
    target: { type: 'number', description: 'Server id of the player it was done to.' },
    metadata: { type: 'Record<string, unknown>', description: 'Extra values (amounts, item names, coordinates). Not a table: ignored.' },
  }}
/>

See [LogOptions](/docs/developers/api/types#logoptions) and [LogLevel](/docs/developers/api/types#loglevel).

#### Returns

Nothing. The entry is dropped without a word when its level is below the panel's minimum or its channel is switched off with `LogChannels`.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:buyCar", { lock: true }, (source) => {
  const price = 25_000;
  if (!core.RemoveMoney(source, "bank", price, "car_purchase")) return fail("NOT_ENOUGH_MONEY");
  // ... create and store the car
  core.Log("purchases", "Bought a car", { source, metadata: { model: "sultan", price } });
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:buyCar', function(source)
  local price = 25000
  if not exports['ai-core']:RemoveMoney(source, 'bank', price, 'car_purchase') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  -- ... create and store the car
  exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { model = 'sultan', price = price } })
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Logs are for the server owner, so the message stays English and is not translated. Keep the message short and put values into `metadata`, where log services can filter them.
</Callout>

### LogChannels

Describes your resource's channels: their dataset name for Fivemanage and FiveM Stats, and whether each is on. Call it once when your resource starts. Channels you never describe still work with the defaults.

**Side:** Server · **Waits:** no · **Lib:** [`aiLogChannels(channels)`](/docs/developers/api/lib-server/logs#ailogchannels)

```ts title="Signature"
LogChannels(channels: Record<string, LogChannel>): void
```

```lua title="Lua"
exports['ai-core']:LogChannels({ purchases = { dataset = 'myscript-sales' }, debug = { active = false } })
```

#### Parameters

<TypeTable
  type={{
    channels: { type: 'Record<string, LogChannel>', description: 'Channel name to its settings. Fields of each below.', required: true },
  }}
/>

#### LogChannel

<TypeTable
  type={{
    dataset: { type: 'string', description: 'Dataset name for Fivemanage and FiveM Stats.', default: 'the resource name' },
    active: { type: 'boolean', description: '`false` turns the channel off: its entries are dropped.', default: 'true' },
  }}
/>

See [LogChannel](/docs/developers/api/types#logchannel).

#### Returns

Nothing. A second call replaces the whole description of your resource. It is dropped when your resource stops. A value that is not a table does nothing.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Once at start.
core.LogChannels({
  purchases: { dataset: "myscript-sales" },
  robberies: { dataset: "myscript-crime" },
  debug: { active: false },
});
```
</Tab>
<Tab value="Lua">
```lua
exports['ai-core']:LogChannels({
  purchases = { dataset = 'myscript-sales' },
  robberies = { dataset = 'myscript-crime' },
  debug = { active = false },
})
```
</Tab>
</Tabs>

<Callout type="warn">
Webhook urls never go here or anywhere in your resource: the server owner sets them in ai-core's panel, which keeps them in a file that is not shared.
</Callout>
