La couche bancaire atteint le **script bancaire actif** : celui que choisit le réglage **Banking script** du panneau, ou le premier qui tourne. Elle ouvre l’écran de ce script et rapporte les soldes de société. L’argent des métiers et des gangs lui-même circule toujours via les exports d’argent d’ai-core ([Argent et comptes](/fr/docs/developers/api/core-server/money)), jamais via un script bancaire.

Le lien entre les comptes de métier et de gang et le script bancaire dépend du réglage **Job and gang accounts** (comptes de métier et de gang) du panneau :

- **ai-core's accounts** (les comptes d’ai-core, par défaut) : ai-core garde l’argent ; le script bancaire affiche le même solde, et l’argent déplacé sur son écran est aussi déplacé dans ai-core.
- **The script's own accounts** (les propres comptes du script) : le script bancaire garde l’argent ; les comptes `bank` de métier et de gang d’ai-core lisent et modifient les comptes du script.

### GetBankingSystem

Le nom de ressource du script bancaire qu’utilise ai-core.

**Côté :** Serveur · **Attend :** non · **Lib :** [`banking.provider()`](/fr/docs/developers/api/lib-server/money#bankingprovider)

```ts title="Signature"
GetBankingSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetBankingSystem() -- string ou nil
```

#### Paramètres

Aucun.

#### Retour

`string | null` : le nom de ressource du script bancaire. `null` quand aucun ne tourne (l’argent des métiers reste alors uniquement dans ai-core).

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("bankingsystem", { help: "Shows the banking script in use", restricted: true }, () => {
  console.log(core.GetBankingSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('bankingsystem', { help = 'Shows the banking script in use', restricted = true }, function()
  print(exports['ai-core']:GetBankingSystem() or 'none')
end)
```
</Tab>
</Tabs>

### OpenBank

Ouvre l’écran du script bancaire pour un joueur. Utilisez-le depuis votre propre distributeur ou guichet de banque.

**Côté :** Serveur · **Attend :** non · **Lib :** [`banking.open`](/fr/docs/developers/api/lib-server/money#bankingopen)

```ts title="Signature"
OpenBank(source: number): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenBank(source)
```

#### Paramètres

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serveur du joueur. Doit avoir un personnage chargé.', required: true },
  }}
/>

#### Retour

`boolean` : `true` quand l’écran s’est ouvert. `false` quand le joueur n’a pas de personnage chargé, qu’aucun script bancaire ne tourne, ou que son écran ne peut pas être ouvert depuis un autre script.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const COUNTER = { x: 149.9, y: -1040.5, z: 29.4 };

onClientCallback("myscript:bankCounter", { guards: [near(COUNTER, 2)] }, (source) =>
  core.OpenBank(source) ? { ok: true } : fail("BANK_UNAVAILABLE"),
);
```
</Tab>
<Tab value="Lua">
```lua
local COUNTER = vector3(149.9, -1040.5, 29.4)

aiLib.onClientCallback('myscript:bankCounter', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - COUNTER) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenBank(source) then return aiLib.fail('BANK_UNAVAILABLE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### GetBankSocietyBalance

Le solde de société d’un métier tel que le montre la configuration bancaire : le compte `bank` du métier dans ai-core avec **ai-core's accounts**, le propre compte du script avec **The script's own accounts**. Utilisez-le pour l’affichage (un menu de patron) ; pour déplacer l’argent du métier, utilisez les exports d’argent.

**Côté :** Serveur · **Attend :** non · **Lib :** [`banking.societyBalance`](/fr/docs/developers/api/lib-server/money#bankingsocietybalance)

```ts title="Signature"
GetBankSocietyBalance(job: string): number | null
```

```lua title="Lua"
local balance = exports['ai-core']:GetBankSocietyBalance('police') -- number ou nil
```

#### Paramètres

<TypeTable
  type={{
    job: { type: 'string', description: 'Nom du métier.', required: true },
  }}
/>

#### Retour

`number | null` : le solde. `null` quand aucun script bancaire ne tourne, que le métier n’a pas de compte (métier inconnu, ou le script n’en garde pas pour lui), ou que `job` n’est pas un texte. Sans script bancaire, lisez le compte du métier avec `GetSharedMoney("job", job, "bank")`.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The boss menu balance, with or without a banking script. */
export function societyBalance(job: string): number {
  return core.GetBankSocietyBalance(job) ?? core.GetSharedMoney("job", job, "bank") ?? 0;
}
```
</Tab>
<Tab value="Lua">
```lua
function SocietyBalance(job)
  return exports['ai-core']:GetBankSocietyBalance(job)
    or exports['ai-core']:GetSharedMoney('job', job, 'bank')
    or 0
end
```
</Tab>
</Tabs>
