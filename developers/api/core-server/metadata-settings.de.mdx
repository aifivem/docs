### GetMeta

Ein Wert aus den **Metadaten** eines Charakters: ein freier Beutel benannter Werte, der mit dem Charakter gespeichert wird. ESX- und QB-Skripte legen dort über die Brücke ihre zusätzlichen Charakterdaten ab (`hunger`, `thirst`, `armor`, `isdead`...), und dein Skript kann eigene kleine Werte ablegen.

**Seite:** Server · **Wartet:** nein · **Lib:** keine

```ts title="Signature"
GetMeta(src: number, key: string): unknown
```

```lua title="Lua"
local value = exports['ai-core']:GetMeta(source, 'myscript_xp') -- beliebiger Wert oder nil
```

#### Parameter

<TypeTable
  type={{
    src: { type: 'number', description: 'Server-ID des Spielers.', required: true },
    key: { type: 'string', description: 'Name des Werts. Stelle deinen eigenen Schlüsseln den Namen deines Skripts voran (`myscript_xp`), damit sie nie mit einem anderen Skript kollidieren.', required: true },
  }}
/>

#### Rückgabe

`unknown`: der gespeicherte Wert (Zahl, Text, Boolean, Liste oder Tabelle), so wie er gesetzt wurde. `null`, wenn der Schlüssel nicht gesetzt ist oder der Spieler keinen geladenen Charakter hat. Prüfe den Typ, bevor du ihn nutzt: Der Wert kann von einem anderen Skript oder einer älteren Version deines eigenen geschrieben worden sein.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** Das Angel-Level des Charakters, 1, wenn noch keines gespeichert wurde. */
export function fishingLevel(source: number): number {
  const value = core.GetMeta(source, "myscript_level");
  return typeof value === "number" && Number.isInteger(value) && value > 0 ? value : 1;
}
```
</Tab>
<Tab value="Lua">
```lua
function FishingLevel(source)
  local value = exports['ai-core']:GetMeta(source, 'myscript_level')
  if math.type(value) == 'integer' and value > 0 then return value end
  return 1
end
```
</Tab>
</Tabs>

### SetMeta

Speichert einen Wert in den Metadaten eines Charakters. Der Wert wird beim nächsten regelmäßigen Speichern des Charakters gesichert (Panel-Einstellung, standardmäßig alle 5 Minuten), beim Logout und wenn der Server stoppt.

**Seite:** Server · **Wartet:** nein · **Lib:** keine

```ts title="Signature"
SetMeta(src: number, key: string, value: unknown): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetMeta(source, 'myscript_level', 3)
```

#### Parameter

<TypeTable
  type={{
    src: { type: 'number', description: 'Server-ID des Spielers.', required: true },
    key: { type: 'string', description: 'Name des Werts. Stelle deinen eigenen Schlüsseln den Namen deines Skripts voran.', required: true },
    value: { type: 'unknown', description: 'Jeder Wert, der in JSON passt: Zahl, Text, Boolean, Liste oder Tabelle. `null` (Lua `nil`) entfernt den Schlüssel.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn der Wert gespeichert (oder entfernt) wurde. `false`, wenn der Spieler keinen geladenen Charakter hat oder `key` kein Text ist.

Die Änderung erreicht sofort das eigene Spiel des Spielers und löst das Server-Event `ai-core:metaChanged (src, key, value)` aus.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** Ein Level höher nach genug Fängen. */
export function levelUp(source: number): void {
  const level = core.GetMeta(source, "myscript_level");
  const next = (typeof level === "number" ? level : 1) + 1;
  core.SetMeta(source, "myscript_level", next);
}
```
</Tab>
<Tab value="Lua">
```lua
function LevelUp(source)
  local level = exports['ai-core']:GetMeta(source, 'myscript_level')
  if type(level) ~= 'number' then level = 1 end
  exports['ai-core']:SetMeta(source, 'myscript_level', level + 1)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Metadaten sind für kleine Werte, die zu einem Charakter gehören (ein Level, ein Flag, ein paar Zahlen). Listen, die wachsen (ein Verlauf, jeder Fang), und alles, was du über Charaktere hinweg suchst oder zählst, gehören in deine eigene Datenbanktabelle. Werte in den Metadaten werden nicht sofort gespeichert: Geld und Items gehören nie dorthin.
</Callout>

### GetBranding

Name, Untertitel, Slogans und Hintergrundbild des Servers aus den allgemeinen Einstellungen (General) des Panels. Nutze es, um denselben Namen in deinen eigenen Vollbildmenüs anzuzeigen.

**Seite:** Server · **Wartet:** nein · **Lib:** keine

```ts title="Signature"
GetBranding(): Branding
```

```lua title="Lua"
local brand = exports['ai-core']:GetBranding() -- Tabelle
```

#### Parameter

Keine.

#### Rückgabe

`Branding`: eine Kopie mit `name`, `subtitle`, `tagline`, `taglineSub` und `background` (`"skyline"` oder `"wet-drive"`, ein Bild in ai-core). Siehe [Branding](/de/docs/developers/api/types#branding).

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Der Willkommensbildschirm zeigt den Servernamen.
onClientCallback("myscript:welcome", () => {
  const { name, tagline } = core.GetBranding();
  return { ok: true, name, tagline };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:welcome', function()
  local brand = exports['ai-core']:GetBranding()
  return { ok = true, name = brand.name, tagline = brand.tagline }
end)
```
</Tab>
</Tabs>

### GetUpdates

Die Skripte mit einem neueren GitHub-Release als der laufenden Version, aus der Update-Prüfung von ai-core. ai-core fragt GitHub höchstens einmal alle 6 Stunden pro Skript (und wenn ein Skript startet), für jedes gestartete Skript mit einer `repository`-Zeile in seiner `fxmanifest.lua`, es sei denn, **Check for updates** (nach Updates suchen) im Panel ist aus.

**Seite:** Server · **Wartet:** nein · **Lib:** keine

```ts title="Signature"
GetUpdates(): UpdateInfo[]
```

```lua title="Lua"
local outdated = exports['ai-core']:GetUpdates() -- Liste von Tabellen
```

#### Parameter

Keine.

#### Rückgabe

`UpdateInfo[]`: ein Eintrag pro veraltetem Skript mit `resource`, `label` (der Name, unter dem man es kennt), `current` (laufende Version), `latest` (neuestes Release) und `url` (die Release-Seite). Eine leere Liste, wenn alles aktuell ist oder noch nichts geprüft wurde (die erste Prüfung läuft 15 Sekunden nach dem Start). Siehe [UpdateInfo](/de/docs/developers/api/types#updateinfo).

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("outdated", { help: "Lists outdated scripts", restricted: true }, () => {
  for (const u of core.GetUpdates()) console.log(`${u.label}: ${u.current} -> ${u.latest} (${u.url})`);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('outdated', { help = 'Lists outdated scripts', restricted = true }, function()
  for _, u in ipairs(exports['ai-core']:GetUpdates()) do
    print(('%s: %s -> %s (%s)'):format(u.label, u.current, u.latest, u.url))
  end
end)
```
</Tab>
</Tabs>
