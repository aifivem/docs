title: Empregos e gangues
description: Leia e altere os empregos, gangues, cargos e serviço de um personagem, conte jogadores em serviço, horário nobre, leia definições de empregos e gangues.
icon: Briefcase
---

Um personagem pode ter **vários empregos e várias gangues** (até **Most jobs per character** e **Most gangs per character** do painel). No máximo **um emprego fica em serviço** de cada vez, e só esse emprego paga salário. No máximo **uma gangue fica ativa**. Empregos e gangues, com seus cargos, são definidos no painel de administração (seções Jobs e Gangs).

Um **cargo** é uma posição na lista de cargos do emprego, contada a partir de 0: o cargo 0 é a primeira linha no painel, o cargo 1 a segunda, e assim por diante.

Cada mudança dispara um evento de servidor (`ai-core:jobsChanged`, `ai-core:dutyChanged`, `ai-core:gangsChanged`, `ai-core:activeGangChanged`) e chega ao próprio jogo do jogador. Recursos que precisam dos empregos de muitos jogadores seguem esses eventos pelo espelho `online` da lib em vez de chamar os exports abaixo para cada jogador. Veja [Eventos e estado](/pt/docs/developers/api/events).

### GetJobs

Cada vínculo de emprego do personagem de um jogador.

**Lado:** Servidor · **Espera:** não · **Lib:** [`online.jobs(source)`](/pt/docs/developers/api/lib-server/players#onlinejobs) lê o mesmo do espelho da lib

```ts title="Assinatura"
GetJobs(src: number): JobMembership[] | null
```

```lua title="Lua"
local jobs = exports['ai-core']:GetJobs(source) -- lista de { job, grade } ou nil
```

#### Parâmetros

<TypeTable
  type={{
    src: { type: 'number', description: 'Id de servidor do jogador.', required: true },
  }}
/>

#### Retorno

`JobMembership[] | null`: um `{ job, grade }` por emprego ([JobMembership](/pt/docs/developers/api/types#jobmembership)). Uma lista vazia quando o personagem não tem emprego (o emprego de desempregado do painel nunca é gravado). `null` quando o jogador não tem personagem carregado.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// A tela de uma agência de empregos lista os empregos do jogador com seus rótulos.
onClientCallback("myscript:myJobs", (source) => {
  const jobs = core.GetJobs(source);
  if (!jobs) return fail("NO_CHARACTER");
  return {
    ok: true,
    jobs: jobs.map(({ job, grade }) => ({
      job,
      label: core.GetJobDefinition(job)?.label ?? job,
      grade,
    })),
  };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myJobs', function(source)
  local jobs = exports['ai-core']:GetJobs(source)
  if not jobs then return aiLib.fail('NO_CHARACTER') end
  local rows = {}
  for _, m in ipairs(jobs) do
    local def = exports['ai-core']:GetJobDefinition(m.job)
    rows[#rows + 1] = { job = m.job, label = def and def.label or m.job, grade = m.grade }
  end
  return { ok = true, jobs = rows }
end)
```
</Tab>
</Tabs>

### GetCurrentJob

O único emprego que os outros scripts devem tratar como "o" emprego do jogador: o emprego em serviço, senão o último emprego em que o jogador esteve em serviço, senão o primeiro emprego, senão o emprego de desempregado do painel. Os scripts de ESX e QB veem este emprego pela ponte.

**Lado:** Servidor · **Espera:** não · **Lib:** [`jobs.current`](/pt/docs/developers/api/lib-server/jobs#jobscurrent)

```ts title="Assinatura"
GetCurrentJob(src: number): JobMembership | null
```

```lua title="Lua"
local job = exports['ai-core']:GetCurrentJob(source) -- { job, grade } ou nil
```

#### Parâmetros

<TypeTable
  type={{
    src: { type: 'number', description: 'Id de servidor do jogador.', required: true },
  }}
/>

#### Retorno

`JobMembership | null`: `{ job, grade }`. Para um personagem sem nenhum emprego é o emprego de desempregado (configuração do painel, `unemployed` por padrão) com cargo 0. `null` só quando o jogador não tem personagem carregado.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("job", { help: "Shows a player job", params: [{ name: "id", type: "playerId" }], restricted: true }, (_source, args) => {
  const job = core.GetCurrentJob(args.id);
  if (job) console.log(`${job.job} grade ${job.grade}`);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('job', { help = 'Shows a player job', params = { { name = 'id', type = 'playerId' } }, restricted = true }, function(_, args)
  local job = exports['ai-core']:GetCurrentJob(args.id)
  if job then print(('%s grade %d'):format(job.job, job.grade)) end
end)
```
</Tab>
</Tabs>

### SetDuty

Coloca um jogador em serviço num dos empregos dele (e fora de serviço em qualquer outro), ou fora de serviço.

**Lado:** Servidor · **Espera:** não · **Lib:** [`jobs.setDuty`](/pt/docs/developers/api/lib-server/jobs#jobsduty-and-jobssetduty)

```ts title="Assinatura"
SetDuty(src: number, job: string | null): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDuty(source, 'police') -- nil = fora de serviço
```

#### Parâmetros

<TypeTable
  type={{
    src: { type: 'number', description: 'Id de servidor do jogador.', required: true },
    job: { type: 'string | null', description: 'O emprego em que entrar em serviço (o jogador precisa tê-lo), ou `null` (`nil` em Lua) para sair de serviço.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o jogador agora está em serviço em `job` (ou fora de serviço para `null`), também quando nada precisou mudar. `false` quando o jogador não tem `job` ou não tem personagem carregado.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const LOCKER_ROOM = { x: 452.3, y: -993.2, z: 30.7 };

// Um interruptor de serviço no vestiário da delegacia.
onClientCallback("myscript:toggleDuty", { guards: [near(LOCKER_ROOM, 3)] }, (source) => {
  const onDuty = core.GetDutyJob(source) === "police";
  return core.SetDuty(source, onDuty ? null : "police") ? { ok: true, onDuty: !onDuty } : fail("NOT_POLICE");
});
```
</Tab>
<Tab value="Lua">
```lua
local LOCKER_ROOM = vector3(452.3, -993.2, 30.7)

aiLib.onClientCallback('myscript:toggleDuty', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - LOCKER_ROOM) > 3.0 then return aiLib.fail('TOO_FAR') end
  local onDuty = exports['ai-core']:GetDutyJob(source) == 'police'
  if not exports['ai-core']:SetDuty(source, (not onDuty) and 'police' or nil) then return aiLib.fail('NOT_POLICE') end
  return { ok = true, onDuty = not onDuty }
end)
```
</Tab>
</Tabs>

<Callout type="info">
O serviço não é salvo: um jogador que entra fica fora de serviço, a menos que a configuração **Keep duty after rejoining** do painel esteja ligada.
</Callout>

### SetJob

Dá um emprego a um jogador, ou muda o cargo de um emprego que ele já tem.

**Lado:** Servidor · **Espera:** não · **Lib:** [`jobs.set`](/pt/docs/developers/api/lib-server/jobs#jobsset)

```ts title="Assinatura"
SetJob(src: number, job: string, grade: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetJob(source, 'mechanic', 0)
```

#### Parâmetros

<TypeTable
  type={{
    src: { type: 'number', description: 'Id de servidor do jogador.', required: true },
    job: { type: 'string', description: 'Nome do emprego no painel (`police`, `mechanic`).', required: true },
    grade: { type: 'number', description: 'Índice do cargo, contado a partir de 0. Precisa existir na lista de cargos do emprego.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o personagem agora tem `job` no cargo `grade`. `false` quando o emprego não existe, o cargo não existe (não é um número inteiro, está abaixo de 0 ou passa do último cargo), o personagem já tem tantos empregos quanto **Most jobs per character** permite ou o jogador não tem personagem carregado.

Quando a configuração **Several jobs per character** do painel está desligada, um novo emprego substitui o outro emprego do personagem.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail, readText } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Uma agência de empregos: qualquer um pode pegar um emprego que o painel lista, no cargo 0.
onClientCallback(
  "myscript:takeJob",
  { args: ([job]) => { const name = readText(job, 32); return name ? [name] : null; } },
  (source, job) => {
    if (!core.GetJobDefinition(job)?.listed) return fail("JOB_NOT_LISTED");
    return core.SetJob(source, job, 0) ? { ok: true } : fail("JOB_LIMIT");
  },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:takeJob', function(source, job)
  if type(job) ~= 'string' then return aiLib.fail('BAD_JOB') end
  local def = exports['ai-core']:GetJobDefinition(job)
  if not def or not def.listed then return aiLib.fail('JOB_NOT_LISTED') end
  if not exports['ai-core']:SetJob(source, job, 0) then return aiLib.fail('JOB_LIMIT') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### RemoveJob

Tira um emprego de um jogador. Um jogador em serviço nesse emprego sai de serviço antes.

**Lado:** Servidor · **Espera:** não · **Lib:** [`jobs.remove`](/pt/docs/developers/api/lib-server/jobs#jobsremove)

```ts title="Assinatura"
RemoveJob(src: number, job: string): boolean
```

```lua title="Lua"

```

#### Parâmetros

<TypeTable
  type={{
    src: { type: 'number', description: 'Id de servidor do jogador.', required: true },
    job: { type: 'string', description: 'Nome do emprego a remover.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o emprego foi removido. `false` quando o personagem não o tem ou o jogador não tem personagem carregado.

### GetUnemployedJob

O nome do emprego que uma personagem sem emprego tem, tal como está definido no painel de administração.

**Lado:** Servidor · **Espera:** não · **Lib:** [`jobs.unemployed()`](/pt/docs/developers/api/lib-server/jobs#jobsunemployed)

```ts title="Assinatura"
GetUnemployedJob(): string
```

```lua title="Lua"
local name = exports['ai-core']:GetUnemployedJob()
```

#### Retorno

`string`: o nome do emprego. Nunca assuma `"unemployed"` - o proprietário pode renomeá-lo, e o ai-core nunca o guarda como pertença: uma personagem sem linhas de emprego **é** desempregada.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { jobs } from "@aifivem/lib/server";

/** "Este jogador está sem emprego?", sem adivinhar o nome. */
export function isJobless(source: number): boolean {
  return jobs.current(source)?.job === jobs.unemployed();
}
```
</Tab>
<Tab value="Lua">
```lua
local current = exports['ai-core']:GetCurrentJob(source)
local jobless = current and current.job == exports['ai-core']:GetUnemployedJob()
```
</Tab>
</Tabs>

<Callout type="info">
Pôr um jogador no emprego de desempregado não é um `SetJob`: retire-lhe os empregos com [RemoveJob](#removejob) (ou [RemoveOfflineJob](/pt/docs/developers/api/core-server/stored-characters#setofflinejob-and-removeofflinejob) para uma personagem não ligada).
</Callout>

### IsPrimeTime

Se agora é horário nobre para um emprego. As horas do horário nobre vêm da fonte que o painel escolhe: um script que mantém as próprias horas (tgiann-policealert) enquanto ele roda, senão as horas próprias do ai-core (a janela do próprio emprego ou a padrão). Use para regras que mudam com as horas de movimento, como um assalto que paga mais.

**Lado:** Servidor · **Espera:** não · **Lib:** [`isPrimeTime(job?)`](/pt/docs/developers/api/lib-server/jobs#isprimetime)

```ts title="Assinatura"
IsPrimeTime(job?: string): boolean
```

```lua title="Lua"
local prime = exports['ai-core']:IsPrimeTime('police')
```

#### Parâmetros

<TypeTable
  type={{
    job: { type: 'string', description: 'Nome do emprego. Sem ele (ou com um texto vazio) as horas padrão são verificadas.' },
  }}
/>

#### Retorno

`boolean`: `true` durante o horário nobre. As horas são o horário local do servidor; uma janela cujo início é depois do fim passa da meia-noite, e o mesmo início e fim significa o dia inteiro. Quando o painel escolhe um script como fonte e esse script está parado, toda hora conta como horário nobre. Funciona esteja ou não ligado o corte do salário no horário nobre.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** A store robbery pays 50% more outside police prime time. */
export function robberyReward(base: number): number {
  return core.IsPrimeTime("police") ? base : Math.round(base * 1.5);
}
```
</Tab>
<Tab value="Lua">
```lua
function RobberyReward(base)
  if exports['ai-core']:IsPrimeTime('police') then return base end
  return math.floor(base * 1.5 + 0.5)
end
```
</Tab>
</Tabs>

### GetJobDefinitions

Cada definição de emprego do painel, como uma cópia. Use para leituras raras, como montar uma lista uma vez; para um emprego use `GetJobDefinition`.

**Lado:** Servidor · **Espera:** não · **Lib:** nenhuma

```ts title="Assinatura"
GetJobDefinitions(): Record<string, JobDefinition>
```

```lua title="Lua"
local jobs = exports['ai-core']:GetJobDefinitions() -- table indexada pelo nome do emprego
```

#### Parâmetros

Nenhum.

#### Retorno

`Record<string, JobDefinition>`: cada emprego indexado pelo nome. Cada um tem `label`, `type`, `defaultDuty`, `listed` (mostrado nas agências de empregos) e `grades` (cada um com `label`, `salary` e `boss`). Veja [JobDefinition](/pt/docs/developers/api/types#jobdefinition) e [GradeDefinition](/pt/docs/developers/api/types#gradedefinition).

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// A agência de empregos lista cada emprego marcado como "listed" no painel.
onClientCallback("myscript:jobCenter", () => ({
  ok: true,
  jobs: Object.entries(core.GetJobDefinitions())
    .filter(([, def]) => def.listed)
    .map(([name, def]) => ({ name, label: def.label, salary: def.grades[0]?.salary ?? 0 })),
}));
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:jobCenter', function()
  local list = {}
  for name, def in pairs(exports['ai-core']:GetJobDefinitions()) do
    if def.listed then
      list[#list + 1] = { name = name, label = def.label, salary = def.grades[1] and def.grades[1].salary or 0 }
    end
  end
  return { ok = true, jobs = list }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Em Lua, `def.grades[1]` é o cargo 0: as listas de Lua começam em 1, os cargos começam em 0.
</Callout>

### GetJobDefinition

A definição de um emprego: rótulo, tipo, serviço padrão, se as agências de empregos o listam, e os cargos dele.

**Lado:** Servidor · **Espera:** não · **Lib:** [`definitions.job(name)`](/pt/docs/developers/api/lib-server/jobs#definitionsjob) (lê cada emprego uma vez e o esquece quando o painel o muda)

```ts title="Assinatura"
GetJobDefinition(job: string): JobDefinition | null
```

```lua title="Lua"
local def = exports['ai-core']:GetJobDefinition('police') -- table ou nil
```

#### Parâmetros

<TypeTable
  type={{
    job: { type: 'string', description: 'Nome do emprego.', required: true },
  }}
/>

#### Retorno

`JobDefinition | null`: o emprego ([JobDefinition](/pt/docs/developers/api/types#jobdefinition)). `null` para um emprego desconhecido ou um valor que não é texto.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Só um cargo de chefe pode abrir o menu de chefe.
onClientCallback("myscript:bossMenu", (source) => {
  const job = online.dutyJob(source);
  const grade = job ? online.jobGrade(source, job) : null;
  if (!job || grade === null) return fail("NOT_ON_DUTY");
  if (!core.GetJobDefinition(job)?.grades[grade]?.boss) return fail("NOT_BOSS");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:bossMenu', function(source)
  local job = exports['ai-core']:GetCurrentJob(source)
  if not job or exports['ai-core']:GetDutyJob(source) ~= job.job then return aiLib.fail('NOT_ON_DUTY') end
  local def = exports['ai-core']:GetJobDefinition(job.job)
  local grade = def and def.grades[job.grade + 1]
  if not grade or not grade.boss then return aiLib.fail('NOT_BOSS') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### RegisterJobDefinition and RemoveJobDefinition

Um emprego que vem com o seu script em vez do painel: pertence ao resource que chama, nunca é escrito no ficheiro do painel, e desaparece quando o seu resource para.

**Lado:** Servidor · **Espera:** não · **Lib:** [`definitions.registerJob`](/pt/docs/developers/api/lib-server/jobs#definitionsregisterjob-and-definitionsremovejob)

```ts title="Assinatura"
RegisterJobDefinition(name: string, definition: JobDefinition): CharacterResult
RemoveJobDefinition(name: string): boolean
```

```lua title="Lua"
local result = exports['ai-core']:RegisterJobDefinition(name, definition)
local ok = exports['ai-core']:RemoveJobDefinition(name)
```

#### Parâmetros

<TypeTable
  type={{
    name: { type: 'string', description: 'O nome de emprego que o seu script usa.', required: true },
    definition: { type: 'JobDefinition', typeDescriptionLink: '/pt/docs/developers/api/types#jobdefinition', description: 'O emprego: `label`, `type`, `defaultDuty`, `listed` e `grades` (cada um com `label`, `salary`, `boss`).', required: true },
  }}
/>

#### Retorno

O `RegisterJobDefinition` responde [ActionResult](/pt/docs/developers/api/types#actionresult): `{ ok: true }`, ou `{ ok: false, error }` com uma chave de idioma quando o painel já tem um emprego com esse nome, ou outro resource o registou - o painel do proprietário ganha sempre. O `RemoveJobDefinition` responde `true` só para um emprego deste resource.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

const result = core.RegisterJobDefinition("garbage", {
  label: "Garbage",
```
