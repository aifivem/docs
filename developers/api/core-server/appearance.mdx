---
title: Appearance
description: Read a character's stored look from whichever clothing script the server runs.
icon: Shirt
---

Looks go through ai-core, never through a clothing script's own exports, events or tables (ai-appearance included). ai-core reads them from the **active clothing script**: the one the panel's **Clothing script** setting picks, or the first one running. Putting a look on a ped happens on the client (client export `ApplyAppearance`, lib `appearance.apply`); see [Client exports](/docs/developers/api/core-client).

A look is a [CharacterAppearance](/docs/developers/api/types#characterappearance): `{ model, data }`. `model` is the ped model hash; `data` is the clothing script's own format. Treat `data` as a sealed box: pass it back to `ApplyAppearance` unchanged.

### GetAppearanceSystem

The resource name of the clothing script ai-core reads looks from.

**Side:** Server · **Waits:** no · **Lib:** [`appearance.provider()`](/docs/developers/api/lib-server/phone-appearance#appearanceprovider)

```ts title="Signature"
GetAppearanceSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetAppearanceSystem() -- string or nil
```

#### Parameters

None.

#### Returns

`string | null`: the clothing script's resource name. `null` when none runs (peds then wear default clothes).

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("clothingsystem", { help: "Shows the clothing script in use", restricted: true }, () => {
  console.log(core.GetAppearanceSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('clothingsystem', { help = 'Shows the clothing script in use', restricted = true }, function()
  print(exports['ai-core']:GetAppearanceSystem() or 'none')
end)
```
</Tab>
</Tabs>

### GetCharacterAppearance

A character's stored look, whether the character is loaded or not. Use it to dress a ped as that character: a sleeping body, a statue, a photo, a preview.

**Side:** Server · **Waits:** no (answers through `done`) · **Lib:** [`appearance.get(charId)`](/docs/developers/api/lib-server/phone-appearance#appearanceget) returns a Promise

```ts title="Signature"
GetCharacterAppearance(charId: number, done: (look: CharacterAppearance | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetCharacterAppearance(charId, function(look) end) -- look: table or nil
```

#### Parameters

<TypeTable
  type={{
    charId: { type: 'number', description: 'Database id of the character. A positive whole number.', required: true },
    done: { type: '(look) => void', description: 'Called once with the look, after the clothing script answered.', required: true, typeDescription: '(look: CharacterAppearance | null) => void' },
  }}
/>

#### Returns

Nothing. `done` gets `{ model, data }`, or `null` when the character has no stored look, no clothing script runs, `charId` is not a positive whole number, or the clothing script failed (logged). Without a function as `done` the call does nothing.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import type { CharacterAppearance } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// The client asks for the player's own look to dress a photo-booth ped.
onClientCallback("myscript:myLook", async (source) => {
  const charId = online.charId(source);
  if (charId === undefined) return fail("NO_CHARACTER");
  const look = await new Promise<CharacterAppearance | null>((resolve) => core.GetCharacterAppearance(charId, resolve));
  return look ? { ok: true, look } : fail("NO_LOOK");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return aiLib.fail('NO_CHARACTER') end
  local p = promise.new()
  exports['ai-core']:GetCharacterAppearance(character.id, function(look) p:resolve(look or false) end)
  local look = Citizen.Await(p)
  if not look then return aiLib.fail('NO_LOOK') end
  return { ok = true, look = look }
end)
```
</Tab>
</Tabs>

<Callout type="info">
A look can be a few kilobytes. Send it to the one player who needs it, never to everyone (`-1`).
</Callout>
