Każde wywołanie przedmiotów przechodzi przez ai-core, nigdy przez własne eksporty skryptu ekwipunku. ai-core przekazuje każde wywołanie do **aktywnego ekwipunku**: tego, który wybiera ustawienie **Inventory script** w panelu, albo pierwszego działającego, gdy ustawione jest automatycznie (ai-inventory, ox_inventory, qb-inventory, tgiann-inventory i inne z listy zgodności). Gdy właściciel serwera zmienia ekwipunek, twój skrypt działa dalej bez zmian.

Co trzeba wiedzieć:

- **Ekwipunek** jest nazywany przez `InventoryRef`: id serwera gracza (liczba) dla kieszeni tego gracza albo tekstowe id dla wszystkiego innego (nazwa schowka, tablica bagażnika). Zobacz [InventoryRef](/pl/docs/developers/api/types#inventoryref).
- **Nazwy przedmiotów** to nazwy przedmiotów w ekwipunku (`water`, `bandage`, `WEAPON_PISTOL`).
- **Metadane** to tabela dodatkowych wartości na jednym stosie (numer seryjny, wytrzymałość). Zobacz [ItemMetadata](/pl/docs/developers/api/types#itemmetadata).
- Dopóki **nie działa żaden ekwipunek**, każde wywołanie odpowiada swoją wartością "nic": `false`, `0`, pustą listą lub `null`.
- Schowki, sklepy i używalne przedmioty, które rejestrujesz, są **trzymane przez ai-core** i przekazywane każdemu ekwipunkowi, który stanie się aktywny później, także po restarcie ekwipunku. Rejestruj je raz, gdy twój skrypt startuje.

### AddItem

Daje przedmioty do ekwipunku.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`inventory.addItem`](/pl/docs/developers/api/lib-server/items#inventoryadditem)

```ts title="Sygnatura"
AddItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:AddItem(source, 'water', 2)
```

#### Parametry

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Id serwera gracza albo id schowka / bagażnika.', required: true, typeDescription: 'number | string' },
    item: { type: 'string', description: 'Nazwa przedmiotu.', required: true },
    count: { type: 'number', description: 'Ile sztuk. Liczba 1 lub większa; ułamek jest zaokrąglany w dół.', default: '1' },
    metadata: { type: 'ItemMetadata', description: 'Dodatkowe wartości dla nowego stosu. Wszystko, co nie jest tabelą, jest ignorowane.' },
    slot: { type: 'number', description: 'Slot, do którego je włożyć (liczba całkowita powyżej 0). W przeciwnym razie ignorowany; wybiera ekwipunek.' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy ekwipunek dodał przedmioty. `false`, gdy się nie mieszczą, przedmiot nie istnieje w ekwipunku, argument jest zły (`count` poniżej 1, pusta nazwa przedmiotu) albo nie działa żaden ekwipunek.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const TAP = { x: 1206.4, y: -3110.2, z: 5.6 };

onClientCallback("myscript:fillBottle", { guards: [near(TAP, 2)], lock: true }, (source) => {
  if (!core.RemoveItem(source, "empty_bottle")) return fail("NO_BOTTLE");
  if (!core.AddItem(source, "water")) {
    core.AddItem(source, "empty_bottle");
    return fail("NO_SPACE");
  }
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local TAP = vector3(1206.4, -3110.2, 5.6)

aiLib.onClientCallback('myscript:fillBottle', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - TAP) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:RemoveItem(source, 'empty_bottle') then return aiLib.fail('NO_BOTTLE') end
  if not exports['ai-core']:AddItem(source, 'water') then
    exports['ai-core']:AddItem(source, 'empty_bottle')
    return aiLib.fail('NO_SPACE')
  end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### RemoveItem

Zabiera przedmioty z ekwipunku.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`inventory.removeItem`](/pl/docs/developers/api/lib-server/items#inventoryremoveitem)

```ts title="Sygnatura"
RemoveItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:RemoveItem(source, 'lockpick', 1)
```

#### Parametry

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Id serwera gracza albo id schowka / bagażnika.', required: true, typeDescription: 'number | string' },
    item: { type: 'string', description: 'Nazwa przedmiotu.', required: true },
    count: { type: 'number', description: 'Ile sztuk. Liczba 1 lub większa; ułamek jest zaokrąglany w dół.', default: '1' },
    metadata: { type: 'ItemMetadata', description: 'Zabieraj tylko stosy z tymi wartościami metadanych.' },
    slot: { type: 'number', description: 'Zabieraj tylko z tego slotu (liczba całkowita powyżej 0).' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy przedmioty zostały zabrane. `false`, gdy ekwipunek ma ich mniej (wtedy nic nie jest zabierane), argument jest zły albo nie działa żaden ekwipunek.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, minigameFor, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:pickLock", { lock: true }, async (source) => {
  if (!core.HasItem(source, "lockpick")) return fail("NO_LOCKPICK");
  const result = await minigameFor(source, { game: "lockpick", minMs: 1500 });
  if (result === "broken") core.RemoveItem(source, "lockpick");
  return result === "won" ? { ok: true } : fail("LOCKPICK_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:pickLock', function(source)
  if not exports['ai-core']:HasItem(source, 'lockpick') then return aiLib.fail('NO_LOCKPICK') end
  local result = aiLib.minigameFor(source, { game = 'lockpick', minMs = 1500 })
  if result == 'broken' then exports['ai-core']:RemoveItem(source, 'lockpick') end
  if result ~= 'won' then return aiLib.fail('LOCKPICK_FAILED') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### HasItem


#### Parametry

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Id serwera gracza albo id schowka / bagażnika.', required: true, typeDescription: 'number | string' },
    item: { type: 'string', description: 'Nazwa przedmiotu.', required: true },
    count: { type: 'number', description: 'Ile sztuk jest potrzebnych (1 lub więcej; ułamek jest zaokrąglany w dół).', default: '1' },

#### Zwraca

`boolean`: `true`, gdy ekwipunek ma `count` lub więcej. `false`, gdy ma mniej, `count` jest poniżej 1 albo nie działa żaden ekwipunek.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, progressFor, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");

onClientCallback("myscript:repair", { lock: true }, async (source) => {
  if (!core.HasItem(source, "repairkit")) return fail("NO_KIT");
  if (!(await progressFor(source, { label: Locale("REPAIRING"), duration: 8000 }))) return fail("CANCELLED");
  if (!core.RemoveItem(source, "repairkit")) return fail("NO_KIT");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.onClientCallback('myscript:repair', function(source)
  if not exports['ai-core']:HasItem(source, 'repairkit') then return aiLib.fail('NO_KIT') end
  if not aiLib.progressFor(source, { label = Locale('REPAIRING'), duration = 8000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:RemoveItem(source, 'repairkit') then return aiLib.fail('NO_KIT') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Po wszystkim, co czeka (pasek postępu, minigra), sprawdź ponownie odpowiedzią `RemoveItem`: gracz mógł w międzyczasie wyrzucić przedmiot.

### GetItems

Każdy stos w ekwipunku, z etykietami.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`inventory.getItems`](/pl/docs/developers/api/lib-server/items#inventorygetitems)

```ts title="Sygnatura"
GetItems(inv: InventoryRef): InventoryStack[]
```

```lua title="Lua"
local stacks = exports['ai-core']:GetItems(source) -- lista tabel
```

#### Parametry

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Id serwera gracza albo id schowka / bagażnika.', required: true, typeDescription: 'number | string' },
  }}
/>

#### Zwraca

`InventoryStack[]`: jeden wpis na stos z `name`, `label`, `count`, `slot` i `metadata`. Zobacz [InventoryStack](/pl/docs/developers/api/types#inventorystack). Pusta lista dla pustego lub nieznanego ekwipunku, złego argumentu albo gdy nie działa żaden ekwipunek.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Lombard wyświetla każdy przedmiot, który gracz nosi, a który lombard skupuje.
const BUYS: Record<string, number> = { gold_ring: 120, rolex: 400 };

onClientCallback("myscript:pawnList", (source) => ({
  ok: true,
  rows: core.GetItems(source)
    .filter((stack) => BUYS[stack.name] !== undefined)
    .map((stack) => ({ slot: stack.slot, label: stack.label, count: stack.count, price: BUYS[stack.name] })),
}));
```
</Tab>
<Tab value="Lua">
```lua
local BUYS = { gold_ring = 120, rolex = 400 }

aiLib.onClientCallback('myscript:pawnList', function(source)
  local rows = {}
  for _, stack in ipairs(exports['ai-core']:GetItems(source)) do
    if BUYS[stack.name] then
      rows[#rows + 1] = { slot = stack.slot, label = stack.label, count = stack.count, price = BUYS[stack.name] }
    end
  end
  return { ok = true, rows = rows }
end)
```
</Tab>
</Tabs>

### RegisterStash

Tworzy schowek: skrzynię, którą gracze otwierają po jej nazwie. ai-core trzyma go i rejestruje ponownie w każdym ekwipunku, który staje się aktywny.

```ts title="Sygnatura"
RegisterStash(name: string, label: string, slots: number, maxWeight: number, jobs?: string[]): void
```

```lua title="Lua"
exports['ai-core']:RegisterStash('police_evidence', 'Evidence', 100, 500000, { 'police' })
```

#### Parametry

<TypeTable
  type={{
    name: { type: 'string', description: 'Unikalne id schowka, a także `InventoryRef` do jego otwarcia (`police_evidence`).', required: true },
    label: { type: 'string', description: 'Tytuł pokazywany na ekranie schowka. Podaj przetłumaczony tekst.', required: true, default: 'name' },
    slots: { type: 'number', description: 'Liczba slotów (powyżej 0, zaokrąglana w dół).', required: true, default: '50' },
    maxWeight: { type: 'number', description: 'Limit wagi w jednostce ekwipunku (gramy w ai-inventory). Powyżej 0.', required: true, default: '100000' },
    jobs: { type: 'string[]', description: 'Prace, które mogą go otworzyć w ekwipunkach sprawdzających prace. Pusto: wszyscy.', default: '[]' },
  }}
/>

Wartości domyślne obowiązują, gdy wartości brakuje lub jest zła.

#### Zwraca

Nic. Bez tekstowego `name` wywołanie nic nie robi. Ponowne zarejestrowanie tej samej nazwy zastępuje schowek.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const LOCKER = { x: 474.9, y: -994.7, z: 26.3 };

// Raz przy starcie; ai-core przekazuje go ekwipunkom, które wystartują później.
core.RegisterStash("police_evidence", Locale("STASH_EVIDENCE"), 100, 500_000, ["police"]);

onClientCallback("myscript:openEvidence", { guards: [near(LOCKER, 2)] }, (source) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  return core.OpenInventory(source, "police_evidence") ? { ok: true } : fail("STASH_FAILED");
});
```
</Tab>


### OpenInventory

Otwiera schowek, bagażnik lub ekwipunek innego gracza na ekranie gracza, obok jego własnego.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`inventory.openInventory`](/pl/docs/developers/api/lib-server/items#inventoryopeninventory)

```ts title="Sygnatura"
OpenInventory(source: number, inv: InventoryRef): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenInventory(source, 'police_evidence')
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza, który widzi ekran.', required: true },
    inv: { type: 'InventoryRef', description: 'Co otworzyć: id schowka, id bagażnika albo id serwera innego gracza (przeszukanie gracza).', required: true, typeDescription: 'number | string' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy ekwipunek otworzył ekran. `false`, gdy nie mógł (nieznany schowek, gracz nie ma ekwipunku), argument jest zły albo nie działa żaden ekwipunek.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, isNear, coordsOf, resourceExport } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Policja przeszukuje skutego gracza, który stoi obok.
onClientCallback("myscript:search", { args: oneArg(readId) }, (source, target) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  if (target === source || !isNear(target, coordsOf(source), 2)) return fail("TOO_FAR");
  return core.OpenInventory(source, target) ? { ok: true } : fail("SEARCH_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:search', function(source, target)
  if math.type(target) ~= 'integer' or target == source then return aiLib.fail('BAD_TARGET') end
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  local a, b = GetEntityCoords(GetPlayerPed(source)), GetEntityCoords(GetPlayerPed(target))
  if #(a - b) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenInventory(source, target) then return aiLib.fail('SEARCH_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Ekwipunek nie sprawdza tutaj ani zasięgu, ani uprawnień. Sam sprawdź pracę, odległość i stan celu, zanim to wywołasz.
</Callout>

### RegisterShop

Tworzy sklep skryptu: listę przedmiotów z cenami, którą twój skrypt otwiera dla gracza (zbrojownia, automat). Ekwipunek rysuje sklep i pobiera płatność po swojemu (gotówka, potem bank). ai-core trzyma go i przekazuje każdemu ekwipunkowi, który staje się aktywny.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`inventory.registerShop`](/pl/docs/developers/api/lib-server/items#inventoryregistershop)

```ts title="Sygnatura"
RegisterShop(name: string, label: string, items: ShopProduct[]): void
```

```lua title="Lua"
exports['ai-core']:RegisterShop('police_armoury', 'Armoury', { { name = 'bandage', price = 0 } })
```

#### Parametry

<TypeTable
  type={{
    name: { type: 'string', description: 'Unikalne id sklepu (`police_armoury`).', required: true },
    label: { type: 'string', description: 'Tytuł ekranu sklepu. Podaj przetłumaczony tekst.', required: true, default: 'name' },
    items: { type: 'ShopProduct[]', description: 'Produkty: `{ name, price }` z całkowitą ceną 0 lub więcej za sztukę. Najwyżej 200; wiersze ze złą nazwą lub ceną są pomijane.', required: true, typeDescription: '{ name: string; price: number }[]' },
  }}
/>

Zobacz [ShopProduct](/pl/docs/developers/api/types#shopproduct).

#### Zwraca

Nic. Bez tekstowego `name` albo bez żadnego poprawnego produktu wywołanie nic nie robi. Ponowne zarejestrowanie tej samej nazwy zastępuje sklep.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const ARMOURY = { x: 482.6, y: -995.2, z: 30.7 };

core.RegisterShop("police_armoury", Locale("SHOP_ARMOURY"), [
  { name: "WEAPON_STUNGUN", price: 0 },
  { name: "bandage", price: 10 },
]);

onClientCallback("myscript:armoury", { guards: [near(ARMOURY, 2)] }, (source) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  return core.OpenShop(source, "police_armoury") ? { ok: true } : fail("SHOP_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

exports['ai-core']:RegisterShop('police_armoury', Locale('SHOP_ARMOURY'), {

  if not exports['ai-core']:OpenShop(source, 'police_armoury') then return aiLib.fail('SHOP_FAILED') end

end)
```

### RegisterUsableItem

Robi z przedmiotu przedmiot używalny: gdy gracz użyje go w ekwipunku, działa twoja funkcja. ai-core trzyma funkcję, więc działa z ekwipunkami, które wystartują później, i przetrwa restart ekwipunku.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`inventory.registerUsableItem`](/pl/docs/developers/api/lib-server/items#inventoryregisterusableitem)

```ts title="Sygnatura"
RegisterUsableItem(name: string, handler: UsableItemHandler): void
// UsableItemHandler = (source: number, item: UsedItem) => unknown
```

```lua title="Lua"
exports['ai-core']:RegisterUsableItem('bandage', function(source, item) end)
```

#### Parametry

<TypeTable
  type={{
    name: { type: 'string', description: 'Nazwa przedmiotu.', required: true },
    handler: { type: 'UsableItemHandler', description: 'Działa przy każdym użyciu z id serwera gracza i użytym stosem (`name`, `slot`, `count`, `metadata`). Zwróć `false`, aby zatrzymać przedmiot.', required: true, typeDescription: '(source: number, item: UsedItem) => unknown' },
  }}
/>

Zobacz [UsableItemHandler](/pl/docs/developers/api/types#usableitemhandler) i [UsedItem](/pl/docs/developers/api/types#useditem).

#### Zwraca

Nic. Bez tekstowego `name` albo funkcji wywołanie nic nie robi. Drugie wywołanie dla tego samego przedmiotu zastępuje handler.

To, co dzieje się z przedmiotem po użyciu, zależy od ekwipunku: ekwipunki, które same zabierają użyty przedmiot (ai-inventory zabiera ilość **consume** przedmiotu), zatrzymują go, gdy twój handler zwróci `false`; inne ekwipunki działają według własnych ustawień przedmiotu, więc tam w razie potrzeby usuń przedmiot sam.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { progressFor, resourceExport } from "@aifivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

core.RegisterUsableItem("bandage", (source) => {
  // Handler musi odpowiedzieć od razu; część czasowa działa osobno.
  void (async () => {
    if (!(await progressFor(source, { label: Locale("BANDAGING"), duration: 4000 }))) return;
    if (!core.RemoveItem(source, "bandage")) return;
    emitNet("myscript:client:heal", source, 25); // twój skrypt kliencki dodaje zdrowie
  })();
  return false; // zatrzymaj go: zostaje usunięty powyżej, gdy pasek się skończy
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

exports['ai-core']:RegisterUsableItem('bandage', function(source, item)
  CreateThread(function()
    if not aiLib.progressFor(source, { label = Locale('BANDAGING'), duration = 4000 }) then return end
    if not exports['ai-core']:RemoveItem(source, 'bandage') then return end
    TriggerClientEvent('myscript:client:heal', source, 25) -- twój skrypt kliencki dodaje zdrowie
  end)
  return false
end)
```
</Tab>
</Tabs>

<Callout type="info">
Użycie wysyła też serwerowe zdarzenie `ai-core:itemUsed (src, name, status)`, które śledzą efekty przedmiotów, takie jak głód i pragnienie. Zobacz [Zdarzenia i stan](/pl/docs/developers/api/events).
</Callout>

### GetItemDefinition

Jeden przedmiot tak, jak definiuje go aktywny ekwipunek: etykieta, waga, czy się łączy w stosy, obrazek.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`inventory.getItemDefinition`](/pl/docs/developers/api/lib-server/items#inventorygetitemdefinition)

```ts title="Sygnatura"
GetItemDefinition(name: string): ItemDefinition | null
```

```lua title="Lua"
local def = exports['ai-core']:GetItemDefinition('water') -- table lub nil
```

#### Parametry

<TypeTable
  type={{
    name: { type: 'string', description: 'Nazwa przedmiotu.', required: true },
  }}
/>

#### Zwraca

`ItemDefinition | null`: przedmiot z `name`, `label`, `weight`, `unique`, `close`, `description` i `image`, gdy ekwipunek go ma. Zobacz [ItemDefinition](/pl/docs/developers/api/types#itemdefinition). `null` dla nieznanego przedmiotu, pustej nazwy albo gdy nie działa żaden ekwipunek.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { notify, resourceExport } from "@aifivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** "You received 2x Water" with the inventory's own label. */
export function giveWithNotice(source: number, item: string, count: number): void {
  if (!core.AddItem(source, item, count)) return;
  const label = core.GetItemDefinition(item)?.label ?? item;
  notify(source, Locale("NOTIFY_RECEIVED", count, label), "success");
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function GiveWithNotice(source, item, count)
  if not exports['ai-core']:AddItem(source, item, count) then return end
  local def = exports['ai-core']:GetItemDefinition(item)
  aiLib.notify(source, Locale('NOTIFY_RECEIVED', count, def and def.label or item), 'success')
end
```
</Tab>

### GetItemDefinitions

Każdy przedmiot zdefiniowany przez aktywny ekwipunek, z nazwą jako kluczem. Używaj tego rzadko (jednorazowe budowanie listy); dla jednego przedmiotu używaj `GetItemDefinition`.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
GetItemDefinitions(): Record<string, ItemDefinition>
```

```lua title="Lua"
local items = exports['ai-core']:GetItemDefinitions() -- tabela z nazwą przedmiotu jako kluczem
```

#### Parametry

Brak.

#### Zwraca

`Record<string, ItemDefinition>`: każdy przedmiot. Pusta tabela, dopóki nie działa żaden ekwipunek.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Warns at start about items in your config that the inventory does not know. */
export function checkItems(names: string[]): void {
  const known = core.GetItemDefinitions();
  for (const name of names) if (!known[name]) console.log(`unknown item: ${name}`);
}
```
</Tab>
<Tab value="Lua">
```lua
function CheckItems(names)
  local known = exports['ai-core']:GetItemDefinitions()
  for _, name in ipairs(names) do
    if not known[name] then print('unknown item: ' .. name) end
  end
end
```
</Tab>
</Tabs>

<Callout type="info">
Uruchamiaj takie sprawdzenie po starcie ekwipunku: zaraz po starcie serwera ekwipunek może jeszcze nie działać, a tabela jest pusta.
</Callout>
