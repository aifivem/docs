ai-core содержит одну админ-панель для всех скриптов. Большинство экспортов на этой странице - это внутренняя проводка, которую `@aicore-fivem/lib` вызывает за вас: скрипт, построенный на `AdminPanel` и `addCommand` из библиотеки, никогда сам не вызывает `RegisterAdminPanel`, `AdminPanelChanged` или `RegisterCommands`. Они описаны, чтобы вы знали, что происходит, и могли поддержать их из другого языка. `RegisterExternalPanel` и `GetLookupValues` полезны любому скрипту.

### RegisterAdminPanel

Сообщает, что у вызывающего ресурса есть раздел в панели. После этого ai-core запрашивает у него схему и данные каждый раз, когда админ открывает панель.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** вызывается [`AdminPanel`](/ru/docs/developers/api/lib-server/admin-panel#adminpanel) из библиотеки при его старте

```ts title="Сигнатура"
RegisterAdminPanel(resource: string): void
```

```lua title="Lua"
exports['ai-core']:RegisterAdminPanel(GetCurrentResourceName())
```

#### Параметры

<TypeTable
  type={{
    resource: { type: 'string', description: 'Оставлен для старых вызовов и игнорируется: панель всегда принадлежит вызывающему ресурсу.', required: true },
  }}
/>

#### Возвращает

Ничего. Регистрация удаляется, когда ресурс останавливается.

#### Пример

Без примера: его вызывает `AdminPanel` из библиотеки. Ресурс, который регистрируется без библиотеки, должен также отвечать на экспорты, которые ai-core вызывает в ответ (`AdminPanelSnapshot`, `AdminPanelData`, `AdminPanelSummary`, типизированы как `AdminPanelResourceExports` в `@aicore-fivem/shared`), а это работа библиотеки.

### AdminPanelChanged

Ресурс панели сообщает ai-core, что одна из его записей изменилась. ai-core передаёт изменение каждому админу, у которого открыта панель, чтобы его экран обновился без перезагрузки.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** вызывается [`AdminPanel`](/ru/docs/developers/api/lib-server/admin-panel#adminpanel) из библиотеки после каждого сохранённого изменения

```ts title="Сигнатура"
AdminPanelChanged(delta: AdminDelta): void
```

```lua title="Lua"
exports['ai-core']:AdminPanelChanged({ resource = GetCurrentResourceName(), file = 'shops', key = 'shop_1', value = record })
```

#### Параметры

<TypeTable
  type={{
    delta: { type: 'AdminDelta', description: 'Что изменилось: `resource`, `file` (имя файла данных), `key` (запись, отсутствует для целого файла настроек) и новое `value` (`null` для удалённой записи).', required: true, typeDescription: '{ resource: string; file: string; key?: string; value: unknown }' },
  }}
/>

См. [AdminDelta](/ru/docs/developers/api/types#admindelta).

#### Возвращает

Ничего. ai-core не проверяет дельту; он отправляет её как есть.

#### Пример

Без примера: его вызывает `AdminPanel` из библиотеки после того, как изменение проверено и сохранено.

### RegisterCommands

Выводит команды ресурса во вкладке **Commands** панели, с их справкой, параметрами и тем, кто может их использовать.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** вызывается [`addCommand`](/ru/docs/developers/api/lib-server/commands#addcommand) из библиотеки (TypeScript и Lua `aiLib.addCommand`)

```ts title="Сигнатура"
RegisterCommands(resource: string, commands: CommandInfo[]): void
```

```lua title="Lua"
exports['ai-core']:RegisterCommands(GetCurrentResourceName(), commands)
```

#### Параметры

<TypeTable
  type={{
    resource: { type: 'string', description: 'Оставлен для старых вызовов и игнорируется: команды принадлежат вызывающему ресурсу.', required: true },
    commands: { type: 'CommandInfo[]', description: 'Все команды ресурса: `names` (первое - имя, остальные - псевдонимы), `help`, `params` и `aces` (`null` = все). Недопустимые записи пропускаются с предупреждением в консоли.', required: true },
  }}
/>

См. [CommandInfo](/ru/docs/developers/api/types#commandinfo) и [CommandParam](/ru/docs/developers/api/types#commandparam).

#### Возвращает

Ничего. Список удаляется, когда ресурс останавливается. Для команд, ограниченных principal (`group.admin`), ai-core также выдаёт этому principal `command.<name>`, для чего нужно `add_ace resource.ai-core command.add_ace allow` (и `command.remove_ace`) в `permission.cfg`.

#### Пример

Без примера: используйте `addCommand` из библиотеки (TypeScript) или `aiLib.addCommand` (Lua), и команда сама появится во вкладке. Команды, созданные голым `RegisterCommand`, тоже выводятся, с пометкой «простая».

### GetLookupValues

Значения одного справочного списка: имена предметов активного инвентаря, имена работ, имена банд и так далее. Проверка панели в библиотеке использует его, чтобы убедиться, что значение, которое ввёл админ, существует.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** используется проверкой [`AdminPanel`](/ru/docs/developers/api/lib-server/admin-panel#adminpanel) из библиотеки

```ts title="Сигнатура"
GetLookupValues(source: LookupSource): string[]
```

```lua title="Lua"
local items = exports['ai-core']:GetLookupValues('item') -- список имён предметов
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'LookupSource', description: 'Какой список.', required: true, typeDescription: '"item" | "job" | "gang" | "account" | "resource" | "player" | "vehicle" | "ped"' },
  }}
/>

| `source` | Значения |
| --- | --- |
| `item` | Имена предметов активного инвентаря. |
| `job` / `gang` | Имена работ / банд из панели. |
| `account` | Имена типов счетов (`cash`, `bank`...). |
| `resource` | Имена запущенных ресурсов. |
| `player` | Citizen id игроков с загруженным персонажем. |
| `vehicle` / `ped` | Всегда пусто: перечислить модели может только игра админа. |

См. [LookupSource](/ru/docs/developers/api/types#lookupsource).

#### Возвращает

`string[]`: значения, отсортированные по подписи. Пустой список для неизвестного `source`, для `vehicle` и `ped` и когда список ещё неизвестен (не работает ни один инвентарь): считайте пустой список значением «проверить нельзя», а не «ничего не допустимо».

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** Checks a reward item from your config; unknown is fine while no inventory runs. */
export function isKnownItem(name: string): boolean {
  const items = core.GetLookupValues("item");
  return items.length === 0 || items.includes(name);
}
```
</Tab>
<Tab value="Lua">
```lua
function IsKnownItem(name)
  local items = exports['ai-core']:GetLookupValues('item')
  if #items == 0 then return true end
  for _, item in ipairs(items) do
    if item == name then return true end
  end
  return false
end
```
</Tab>
</Tabs>

<Callout type="info">
Список строится заново при каждом вызове (список предметов может быть длинным). Вызывайте при проверке, а не в цикле.
</Callout>

### RegisterExternalPanel

Выводит собственный экран настроек другого скрипта на дашборде панели ai-core, чтобы владелец сервера находил настройки всех скриптов в одном месте. Карточка открывает экран чат-командой или показывает веб-страницу внутри панели.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** нет

```ts title="Сигнатура"
RegisterExternalPanel(panel: {
  id?: string;
  label: string;
  icon?: string;
  description?: string;
  command?: string;
  url?: string;
}): void
```

```lua title="Lua"
exports['ai-core']:RegisterExternalPanel({ label = 'My script', command = 'myscriptconfig' })
```

#### Параметры

<TypeTable
  type={{
    panel: { type: 'object', description: 'Карточка дашборда. Поля ниже.', required: true },
  }}
/>

#### Поля panel

<TypeTable
  type={{
    id: { type: 'string', description: 'Id карточки, уникальный в пределах вашего ресурса (2-48 букв, цифр, `_`, `.`, `-`). Второй вызов с тем же id заменяет карточку.', default: 'имя ресурса' },
    label: { type: 'string', description: 'Заголовок карточки. Обрезается до 48 символов.', required: true },
    icon: { type: 'string', description: 'Имя иконки для карточки. Обрезается до 32 символов.' },
    description: { type: 'string', description: 'Одна строка под заголовком. Обрезается до 160 символов.' },
    command: { type: 'string', description: 'Чат-команда, которая открывает ваш экран (ведущий `/` удаляется). Укажите `command` или `url`.' },
    url: { type: 'string', description: 'Веб-страница, показываемая внутри панели. Только адреса `https://` (NUI-страница вашего ресурса или сайт, которому вы доверяете); обрезается до 300 символов.' },
  }}
/>

#### Возвращает

Ничего. Без `label` или без `command` и `url` одновременно карточка не добавляется. Карточки удаляются, когда ваш ресурс останавливается.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Один раз при старте.
core.RegisterExternalPanel({
  label: "My script",
  icon: "gear",
  description: "Shops, prices and rewards",
  command: "myscriptconfig",
});
```
</Tab>
<Tab value="Lua">
```lua
exports['ai-core']:RegisterExternalPanel({
  label = 'My script',
  icon = 'gear',
  description = 'Shops, prices and rewards',
  command = 'myscriptconfig',
})
```
</Tab>
</Tabs>

<Callout type="info">
Скрипт, который вы не можете изменить, можно вывести строками в его `fxmanifest.lua`: `ai_admin_label`, `ai_admin_command` или `ai_admin_url` и при желании `ai_admin_icon` и `ai_admin_description`. Владелец сервера также может добавлять карточки вручную в панели.
</Callout>
