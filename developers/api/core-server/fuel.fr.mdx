---
title: Carburant
description: Lire et fixer le niveau de carburant d’un véhicule via le script de carburant qu’utilise le serveur.
icon: Fuel
---

Le carburant passe par ai-core, jamais par les exports, décorateurs ou state bags propres à un script de carburant (ai-fuel compris). ai-core transmet chaque appel au **script de carburant actif** : celui que choisit le réglage **Fuel script** du panneau, ou le premier qui tourne (ai-fuel, ox_fuel, LegacyFuel et les autres de la liste de compatibilité). Sans script de carburant, le niveau est simplement le state bag `fuel` du véhicule.

Un niveau est un nombre de **0 (vide) à 100 (plein)**. Un véhicule est un **handle d’entité serveur**.

### GetFuelSystem

Le nom de ressource du script de carburant auquel ai-core transmet.

**Côté :** Serveur · **Attend :** non · **Lib :** [`fuel.provider()`](/fr/docs/developers/api/lib-server/vehicles#fuelprovider)

```ts title="Signature"
GetFuelSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetFuelSystem() -- 'ai-fuel', 'ox_fuel'... ou nil
```

#### Paramètres

Aucun.

#### Retour

`string | null` : le nom de ressource du script de carburant. `null` quand aucun ne tourne.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("fuelsystem", { help: "Shows the fuel script in use", restricted: true }, () => {
  console.log(core.GetFuelSystem() ?? "none: fuel is only the state bag");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('fuelsystem', { help = 'Shows the fuel script in use', restricted = true }, function()
  print(exports['ai-core']:GetFuelSystem() or 'none: fuel is only the state bag')
end)
```
</Tab>
</Tabs>

### GetVehicleFuel

Le niveau de carburant d’un véhicule.

**Côté :** Serveur · **Attend :** non · **Lib :** [`fuel.get`](/fr/docs/developers/api/lib-server/vehicles#fuelget) (serveur) ; sur le client, `fuel.get(vehicle)` de la lib client lit le state bag que tient ai-core

```ts title="Signature"
GetVehicleFuel(vehicle: number): number | null
```

```lua title="Lua"
local level = exports['ai-core']:GetVehicleFuel(vehicle) -- 0-100 ou nil
```

#### Paramètres

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Handle d’entité serveur d’un véhicule.', required: true },
  }}
/>

#### Retour

`number | null` : le niveau, 0-100. `null` quand le véhicule n’a pas encore de niveau, ou que `vehicle` n’est pas un véhicule existant.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aicore-fivem/lib/server";
import { fail, oneArg, readId } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Un mécanicien lit le réservoir de la voiture devant lui.
onClientCallback("myscript:checkTank", { args: oneArg(readId) }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 4 });
  if (!vehicle) return fail("TOO_FAR");
  return { ok: true, level: core.GetVehicleFuel(vehicle) };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:checkTank', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 4 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  return { ok = true, level = exports['ai-core']:GetVehicleFuel(vehicle) }
end)
```
</Tab>
</Tabs>

### SetVehicleFuel

Fixe le niveau de carburant d’un véhicule.

**Côté :** Serveur · **Attend :** non · **Lib :** [`fuel.set`](/fr/docs/developers/api/lib-server/vehicles#fuelset) (et [`spawnVehicle({ fuel })`](/fr/docs/developers/api/lib-server/vehicles#spawnvehicle) le fixe à la création)

```ts title="Signature"
SetVehicleFuel(vehicle: number, level: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetVehicleFuel(vehicle, 100.0)
```

#### Paramètres

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Handle d’entité serveur d’un véhicule.', required: true },
    level: { type: 'number', description: 'Le nouveau niveau. Les valeurs sous 0 deviennent 0, au-dessus de 100 deviennent 100.', required: true },
  }}
/>

#### Retour

`boolean` : `true` quand le niveau a été transmis au script de carburant (ou écrit dans le state bag quand aucun ne tourne). `false` quand `vehicle` n’est pas un véhicule existant, que `level` n’est pas un nombre fini, ou que le script de carburant a échoué.

Pour les scripts de carburant qui gardent le carburant dans le jeu des joueurs, le nouveau niveau atteint le véhicule via le jeu de son propriétaire un instant plus tard.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aicore-fivem/lib/server";
import { fail, oneArg, readId } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Un jerrican ajoute 25 % à la voiture à côté du joueur.
onClientCallback("myscript:jerryCan", { args: oneArg(readId), lock: true }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 3 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.RemoveItem(source, "jerrycan")) return fail("NO_JERRYCAN");
  core.SetVehicleFuel(vehicle, (core.GetVehicleFuel(vehicle) ?? 0) + 25);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:jerryCan', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 3 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:RemoveItem(source, 'jerrycan') then return aiLib.fail('NO_JERRYCAN') end
  local level = exports['ai-core']:GetVehicleFuel(vehicle) or 0
  exports['ai-core']:SetVehicleFuel(vehicle, level + 25)
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>
