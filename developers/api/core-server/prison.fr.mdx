---
title: Prison
description: Emprisonner des joueurs, les libérer et lire le temps restant, via le script de prison qu’utilise le serveur.
icon: Lock
---

Les appels de prison passent par ai-core, jamais par les exports ou événements propres à un script de prison (ai-prison compris). ai-core transmet chaque appel au **premier script de prison qui tourne** : ai-prison, qb-prison, rcore_prison, xt-prison, puis tgiann-policejob. Tant qu’aucun ne tourne, chaque appel répond `false` ou `0`.

### JailPlayer

Envoie un joueur en prison pour un nombre de minutes.

**Côté :** Serveur · **Attend :** non · **Lib :** [`prison.jail`](/fr/docs/developers/api/lib-server/jobs#prisonjail)

```ts title="Signature"
JailPlayer(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local jailed = exports['ai-core']:JailPlayer(target, 20, source)
```

#### Paramètres

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serveur du joueur à emprisonner.', required: true },
    minutes: { type: 'number', description: 'Durée de la peine en minutes. Supérieure à 0.', required: true },
    by: { type: 'number', description: 'Id serveur de l’agent, pour les scripts de prison qui enregistrent qui l’a fait.', default: '0' },
  }}
/>

#### Retour

`boolean` : `true` quand le script de prison a pris le joueur. `false` quand `minutes` n’est pas supérieur à 0, que `source` n’est pas un nombre, qu’aucun script de prison ne tourne ou qu’il a refusé.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("jail", {
  help: "Jails a player",
  params: [{ name: "id", type: "playerId" }, { name: "minutes", type: "number" }],
  restricted: "ai.job.police",
}, (source, args) => {
  if (core.GetDutyJob(source) !== "police") return;
  core.JailPlayer(args.id, args.minutes, source);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('jail', {
  help = 'Jails a player',
  params = { { name = 'id', type = 'playerId' }, { name = 'minutes', type = 'number' } },
  restricted = 'ai.job.police',
}, function(source, args)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return end
  exports['ai-core']:JailPlayer(args.id, args.minutes, source)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Écrivez l’enregistrement MDT correspondant avec [`AddMdtRecord`](/fr/docs/developers/api/core-server/mdt) (`kind: "jail"`) quand le serveur utilise un MDT.
</Callout>

### ReleasePlayer

Fait sortir un joueur de prison.

**Côté :** Serveur · **Attend :** non · **Lib :** [`prison.release`](/fr/docs/developers/api/lib-server/jobs#prisonrelease)

```ts title="Signature"
ReleasePlayer(source: number): boolean
```

```lua title="Lua"
local released = exports['ai-core']:ReleasePlayer(target)
```

#### Paramètres

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serveur du prisonnier.', required: true },
  }}
/>

#### Retour

`boolean` : `true` quand le script de prison a libéré le joueur. `false` quand le script de prison ne l’a pas libéré (par exemple, il n’était pas en prison), que `source` n’est pas un nombre ou qu’aucun script de prison ne tourne.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("unjail", { help: "Releases a player", params: [{ name: "id", type: "playerId" }], restricted: true }, (_source, args) => {
  console.log(core.ReleasePlayer(args.id) ? "released" : "not in prison");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('unjail', { help = 'Releases a player', params = { { name = 'id', type = 'playerId' } }, restricted = true }, function(_, args)
  print(exports['ai-core']:ReleasePlayer(args.id) and 'released' or 'not in prison')
end)
```
</Tab>
</Tabs>

### GetJailTime

Combien de temps un joueur doit encore purger.

**Côté :** Serveur · **Attend :** non · **Lib :** [`prison.timeLeft`](/fr/docs/developers/api/lib-server/jobs#prisontimeleft)

```ts title="Signature"
GetJailTime(source: number): number
```

```lua title="Lua"
local minutes = exports['ai-core']:GetJailTime(source)
```

#### Paramètres

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serveur du joueur.', required: true },
  }}
/>

#### Retour

`number` : minutes restantes. `0` quand le joueur n’est pas en prison, que `source` n’est pas un nombre ou qu’aucun script de prison ne tourne.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Les prisonniers ne peuvent pas utiliser la cabine téléphonique.
onClientCallback("myscript:phoneBooth", (source) =>
  core.GetJailTime(source) > 0 ? fail("IN_PRISON") : { ok: true },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:phoneBooth', function(source)
  if exports['ai-core']:GetJailTime(source) > 0 then return aiLib.fail('IN_PRISON') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
