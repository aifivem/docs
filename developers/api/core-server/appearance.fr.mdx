Les apparences passent par ai-core, jamais par les exports, événements ou tables propres à un script de vêtements (ai-appearance compris). ai-core les lit depuis le **script de vêtements actif** : celui que choisit le réglage **Clothing script** du panneau, ou le premier qui tourne. Mettre une apparence sur un ped se fait sur le client (export client `ApplyAppearance`, `appearance.apply` de la lib) ; voir [Exports client](/fr/docs/developers/api/core-client).

Une apparence est un [CharacterAppearance](/fr/docs/developers/api/types#characterappearance) : `{ model, data }`. `model` est le hash du modèle de ped ; `data` est le format propre du script de vêtements. Traitez `data` comme une boîte scellée : rendez-la inchangée à `ApplyAppearance`.

### GetAppearanceSystem

Le nom de ressource du script de vêtements depuis lequel ai-core lit les apparences.

**Côté :** Serveur · **Attend :** non · **Lib :** [`appearance.provider()`](/fr/docs/developers/api/lib-server/phone-appearance#appearanceprovider)

```ts title="Signature"
GetAppearanceSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetAppearanceSystem() -- string ou nil
```

#### Paramètres

Aucun.

#### Retour

`string | null` : le nom de ressource du script de vêtements. `null` quand aucun ne tourne (les peds portent alors les vêtements par défaut).

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("clothingsystem", { help: "Shows the clothing script in use", restricted: true }, () => {
  console.log(core.GetAppearanceSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('clothingsystem', { help = 'Shows the clothing script in use', restricted = true }, function()
  print(exports['ai-core']:GetAppearanceSystem() or 'none')
end)
```
</Tab>
</Tabs>

### GetCharacterAppearance

L’apparence enregistrée d’un personnage, qu’il soit chargé ou non. Utilisez-la pour habiller un ped comme ce personnage : un corps endormi, une statue, une photo, un aperçu.

**Côté :** Serveur · **Attend :** non (répond via `done`) · **Lib :** [`appearance.get(charId)`](/fr/docs/developers/api/lib-server/phone-appearance#appearanceget) renvoie une Promise

```ts title="Signature"
GetCharacterAppearance(charId: number, done: (look: CharacterAppearance | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetCharacterAppearance(charId, function(look) end) -- look : table ou nil
```

#### Paramètres

<TypeTable
  type={{
    charId: { type: 'number', description: 'Id en base de données du personnage. Un nombre entier positif.', required: true },
    done: { type: '(look) => void', description: 'Appelé une fois avec l’apparence, après la réponse du script de vêtements.', required: true, typeDescription: '(look: CharacterAppearance | null) => void' },
  }}
/>

#### Retour

Rien. `done` reçoit `{ model, data }`, ou `null` quand le personnage n’a pas d’apparence enregistrée, qu’aucun script de vêtements ne tourne, que `charId` n’est pas un nombre entier positif, ou que le script de vêtements a échoué (enregistré dans le log). Sans fonction comme `done`, l’appel ne fait rien.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import type { CharacterAppearance } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Le client demande la propre apparence du joueur pour habiller le ped d’un photomaton.
onClientCallback("myscript:myLook", async (source) => {
  const charId = online.charId(source);
  if (charId === undefined) return fail("NO_CHARACTER");
  const look = await new Promise<CharacterAppearance | null>((resolve) => core.GetCharacterAppearance(charId, resolve));
  return look ? { ok: true, look } : fail("NO_LOOK");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return aiLib.fail('NO_CHARACTER') end
  local p = promise.new()
  exports['ai-core']:GetCharacterAppearance(character.id, function(look) p:resolve(look or false) end)
  local look = Citizen.Await(p)
  if not look then return aiLib.fail('NO_LOOK') end
  return { ok = true, look = look }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Une apparence peut peser quelques kilo-octets. Envoyez-la au seul joueur qui en a besoin, jamais à tout le monde (`-1`).
</Callout>
