Bir karakter **birden fazla meslek ve birden fazla çeteye** sahip olabilir (panelin **Most jobs per character** ve **Most gangs per character** ayarlarına kadar). Aynı anda en fazla **bir meslekte mesaide** olunur ve yalnızca o meslek maaş öder. En fazla **bir çete aktiftir**. Meslekler ve çeteler, rütbeleriyle birlikte, admin panelinde tanımlanır (Jobs ve Gangs bölümleri).

Bir **rütbe**, mesleğin rütbe listesindeki 0’dan sayılan bir konumdur: rütbe 0 paneldeki ilk satır, rütbe 1 ikinci satır vb.

Her değişiklik bir server event’i tetikler (`ai-core:jobsChanged`, `ai-core:dutyChanged`, `ai-core:gangsChanged`, `ai-core:activeGangChanged`) ve oyuncunun kendi oyununa ulaşır. Birçok oyuncunun mesleklerine ihtiyaç duyan resource’lar, her oyuncu için aşağıdaki export’ları çağırmak yerine bu event’leri lib’in `online` aynası üzerinden izler. Bkz. [Event’ler ve durum](/tr/docs/developers/api/events).

### GetJobs

Bir oyuncunun karakterinin her meslek üyeliği.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`online.jobs(source)`](/tr/docs/developers/api/lib-server/players#onlinejobs) aynısını lib’in aynasından okur

```ts title="İmza"
GetJobs(src: number): JobMembership[] | null
```

```lua title="Lua"
local jobs = exports['ai-core']:GetJobs(source) -- { job, grade } listesi ya da nil
```

#### Parametreler

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
  }}
/>

#### Dönüş değeri

`JobMembership[] | null`: meslek başına bir `{ job, grade }` ([JobMembership](/tr/docs/developers/api/types#jobmembership)). Karakterin mesleği yoksa boş liste (panelin işsiz mesleği asla saklanmaz). Oyuncunun yüklü karakteri yoksa `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Bir iş merkezi ekranı oyuncunun mesleklerini etiketleriyle listeler.
onClientCallback("myscript:myJobs", (source) => {
  const jobs = core.GetJobs(source);
  if (!jobs) return fail("NO_CHARACTER");
  return {
    ok: true,
    jobs: jobs.map(({ job, grade }) => ({
      job,
      label: core.GetJobDefinition(job)?.label ?? job,
      grade,
    })),
  };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myJobs', function(source)
  local jobs = exports['ai-core']:GetJobs(source)
  if not jobs then return aiLib.fail('NO_CHARACTER') end
  local rows = {}
  for _, m in ipairs(jobs) do
    local def = exports['ai-core']:GetJobDefinition(m.job)
    rows[#rows + 1] = { job = m.job, label = def and def.label or m.job, grade = m.grade }
  end
  return { ok = true, jobs = rows }
end)
```
</Tab>
</Tabs>

### GetCurrentJob

Diğer script’lerin oyuncunun "asıl" mesleği olarak ele alması gereken tek meslek: mesaideki meslek, yoksa oyuncunun en son mesaide olduğu meslek, yoksa ilk meslek, yoksa panelin işsiz mesleği. ESX ve QB script’leri bu mesleği köprü üzerinden görür.

**Taraf:** Server · **Bekler:** hayır · **Lib:** yok

```ts title="İmza"
GetCurrentJob(src: number): JobMembership | null
```

```lua title="Lua"
local job = exports['ai-core']:GetCurrentJob(source) -- { job, grade } ya da nil
```

#### Parametreler

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
  }}
/>

#### Dönüş değeri

`JobMembership | null`: `{ job, grade }`. Hiç mesleği olmayan bir karakter için işsiz meslektir (panel ayarı, varsayılan `unemployed`), rütbe 0 ile. Yalnızca oyuncunun yüklü karakteri yoksa `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

  const job = core.GetCurrentJob(args.id);
  if (job) console.log(`${job.job} grade ${job.grade}`);
});
```
</Tab>
<Tab value="Lua">

### SetDuty

Bir oyuncuyu mesleklerinden birinde mesaiye alır (ve diğer her meslekte mesai dışına çıkarır) ya da mesai dışına çıkarır.

**Taraf:** Server · **Bekler:** hayır · **Lib:** yok

```ts title="İmza"
SetDuty(src: number, job: string | null): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDuty(source, 'police') -- nil = mesai dışı
```

#### Parametreler

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    job: { type: 'string | null', description: 'Mesaiye girilecek meslek (oyuncu ona sahip olmalı) ya da mesai dışına çıkmak için `null` (Lua `nil`).', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: oyuncu artık `job` için mesaideyse (ya da `null` için mesai dışındaysa) `true`, hiçbir şeyin değişmesi gerekmediğinde de. Oyuncu `job`’a sahip değilse ya da yüklü karakteri yoksa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const LOCKER_ROOM = { x: 452.3, y: -993.2, z: 30.7 };

// Karakoldaki soyunma odasında bir mesai anahtarı.
onClientCallback("myscript:toggleDuty", { guards: [near(LOCKER_ROOM, 3)] }, (source) => {
  const onDuty = core.GetDutyJob(source) === "police";
  return core.SetDuty(source, onDuty ? null : "police") ? { ok: true, onDuty: !onDuty } : fail("NOT_POLICE");
});
```
</Tab>
<Tab value="Lua">
```lua
local LOCKER_ROOM = vector3(452.3, -993.2, 30.7)

aiLib.onClientCallback('myscript:toggleDuty', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - LOCKER_ROOM) > 3.0 then return aiLib.fail('TOO_FAR') end
  local onDuty = exports['ai-core']:GetDutyJob(source) == 'police'
  if not exports['ai-core']:SetDuty(source, (not onDuty) and 'police' or nil) then return aiLib.fail('NOT_POLICE') end
  return { ok = true, onDuty = not onDuty }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Mesai kaydedilmez: giriş yapan bir oyuncu mesai dışıdır, panelin **Keep duty after rejoining** ayarı açık değilse.
</Callout>

### SetJob

Bir oyuncuya bir meslek verir ya da zaten sahip olduğu bir mesleğin rütbesini değiştirir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** yok

```ts title="İmza"
SetJob(src: number, job: string, grade: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetJob(source, 'mechanic', 0)
```

#### Parametreler

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    job: { type: 'string', description: 'Paneldeki meslek adı (`police`, `mechanic`).', required: true },
    grade: { type: 'number', description: '0’dan sayılan rütbe indeksi. Mesleğin rütbe listesinde var olmalıdır.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: karakter artık `job` mesleğinde `grade` rütbesindeyse `true`. Meslek yoksa, rütbe yoksa (tam sayı değil, 0’ın altında ya da son rütbeyi geçiyor), karakter zaten **Most jobs per character**’ın izin verdiği kadar mesleğe sahipse ya da oyuncunun yüklü karakteri yoksa `false`.

Panelin **Several jobs per character** ayarı kapalıyken yeni bir meslek karakterin diğer mesleğinin yerini alır.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail, readText } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Bir iş merkezi: herkes panelin listelediği bir mesleği rütbe 0’da alabilir.
onClientCallback(
  "myscript:takeJob",
  { args: ([job]) => { const name = readText(job, 32); return name ? [name] : null; } },
  (source, job) => {
    if (!core.GetJobDefinition(job)?.listed) return fail("JOB_NOT_LISTED");
    return core.SetJob(source, job, 0) ? { ok: true } : fail("JOB_LIMIT");
  },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:takeJob', function(source, job)
  if type(job) ~= 'string' then return aiLib.fail('BAD_JOB') end
  local def = exports['ai-core']:GetJobDefinition(job)
  if not def or not def.listed then return aiLib.fail('JOB_NOT_LISTED') end
  if not exports['ai-core']:SetJob(source, job, 0) then return aiLib.fail('JOB_LIMIT') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### IsPrimeTime

Bir meslek için şu an prime time olup olmadığı. Prime time saatleri panelin seçtiği kaynaktan gelir: çalışırken kendi saatlerini tutan bir script (tgiann-policealert), yoksa ai-core’un kendi saatleri (mesleğin kendi aralığı ya da varsayılan). Yoğun saatlerle değişen kurallar için kullan, daha fazla ödeyen bir soygun gibi.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`isPrimeTime(job?)`](/tr/docs/developers/api/lib-server/jobs#isprimetime)

```ts title="İmza"
IsPrimeTime(job?: string): boolean
```

```lua title="Lua"
local prime = exports['ai-core']:IsPrimeTime('police')
```

#### Parametreler

<TypeTable
  type={{
    job: { type: 'string', description: 'Meslek adı. Bu olmadan (ya da boş bir metinle) varsayılan saatler kontrol edilir.' },
  }}
/>

#### Dönüş değeri

`boolean`: prime time sırasında `true`. Saatler sunucunun yerel saatidir; başlangıcı bitişinden geç olan bir aralık gece yarısını geçer, aynı başlangıç ve bitiş de tüm gün demektir. Panel kaynak olarak bir script seçtiğinde ve o script durmuşsa her saat prime time sayılır. Maaşın prime time kesintisi açık olsun olmasın çalışır.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Bir dükkan soygunu polis prime time’ı dışında %50 daha fazla öder. */
export function robberyReward(base: number): number {
  return core.IsPrimeTime("police") ? base : Math.round(base * 1.5);
}
```
</Tab>
<Tab value="Lua">
```lua
function RobberyReward(base)
  if exports['ai-core']:IsPrimeTime('police') then return base end
  return math.floor(base * 1.5 + 0.5)
end
```
</Tab>
</Tabs>

### GetJobDefinitions

Paneldeki her meslek tanımı, tek bir kopya olarak. Bir listeyi bir kez kurmak gibi seyrek okumalar için kullan; tek bir meslek için `GetJobDefinition` kullan.

**Taraf:** Server · **Bekler:** hayır · **Lib:** yok

```ts title="İmza"
GetJobDefinitions(): Record<string, JobDefinition>
```

```lua title="Lua"
local jobs = exports['ai-core']:GetJobDefinitions() -- meslek adına göre anahtarlanmış tablo
```

#### Parametreler

Yok.

#### Dönüş değeri

`Record<string, JobDefinition>`: ada göre anahtarlanmış her meslek. Her birinin `label`, `type`, `defaultDuty`, `listed` (iş merkezlerinde gösterilir) ve `grades`’i (her biri `label`, `salary` ve `boss` ile) vardır. Bkz. [JobDefinition](/tr/docs/developers/api/types#jobdefinition) ve [GradeDefinition](/tr/docs/developers/api/types#gradedefinition).

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// İş merkezi panelde "listed" olarak işaretli her mesleği listeler.
onClientCallback("myscript:jobCenter", () => ({
  ok: true,
  jobs: Object.entries(core.GetJobDefinitions())
    .filter(([, def]) => def.listed)
    .map(([name, def]) => ({ name, label: def.label, salary: def.grades[0]?.salary ?? 0 })),
}));
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:jobCenter', function()
  local list = {}
  for name, def in pairs(exports['ai-core']:GetJobDefinitions()) do
    if def.listed then
      list[#list + 1] = { name = name, label = def.label, salary = def.grades[1] and def.grades[1].salary or 0 }
    end
  end
  return { ok = true, jobs = list }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Lua’da `def.grades[1]` rütbe 0’dır: Lua listeleri 1’den, rütbeler 0’dan başlar.
</Callout>

### GetJobDefinition

Tek bir mesleğin tanımı: etiket, tip, varsayılan mesai, iş merkezlerinin onu listeleyip listelemediği ve rütbeleri.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`definitions.job(name)`](/tr/docs/developers/api/lib-server/jobs#definitionsjob) (her mesleği bir kez okur ve panel onu değiştirdiğinde unutur)

```ts title="İmza"
GetJobDefinition(job: string): JobDefinition | null
```

```lua title="Lua"
local def = exports['ai-core']:GetJobDefinition('police') -- tablo ya da nil
```

#### Parametreler

<TypeTable
  type={{
    job: { type: 'string', description: 'Meslek adı.', required: true },
  }}
/>

#### Dönüş değeri

`JobDefinition | null`: meslek ([JobDefinition](/tr/docs/developers/api/types#jobdefinition)). Bilinmeyen bir meslek ya da metin olmayan bir değer için `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Patron menüsünü yalnızca patron rütbesi açabilir.
onClientCallback("myscript:bossMenu", (source) => {
  const job = online.dutyJob(source);
  const grade = job ? online.jobGrade(source, job) : null;
  if (!job || grade === null) return fail("NOT_ON_DUTY");
  if (!core.GetJobDefinition(job)?.grades[grade]?.boss) return fail("NOT_BOSS");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:bossMenu', function(source)
  local job = exports['ai-core']:GetCurrentJob(source)
  if not job or exports['ai-core']:GetDutyJob(source) ~= job.job then return aiLib.fail('NOT_ON_DUTY') end
  local def = exports['ai-core']:GetJobDefinition(job.job)
  local grade = def and def.grades[job.grade + 1]
  if not grade or not grade.boss then return aiLib.fail('NOT_BOSS') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
