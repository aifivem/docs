Wywołania garażu przechodzą przez ai-core, nigdy przez własne eksporty lub zdarzenia skryptu garażu (łącznie z ai-garages). ai-core przekazuje każde wywołanie do **aktywnego skryptu garażu**: tego, który wybiera ustawienie **Garage script** w panelu, albo pierwszego działającego (ai-garages, jg-advancedgarages, tgiann-realparking i inne z listy zgodności). Każdy skrypt odpowiada tylko na akcje, które naprawdę ma, więc każda akcja może odpowiedzieć `false` lub `null` przy jednym skrypcie i działać przy innym.

Pojazd to **serwerowy uchwyt encji**.

### GetGarageSystem

Nazwa zasobu skryptu garażu, do którego ai-core przekazuje wywołania.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`garages.provider()`](/pl/docs/developers/api/lib-server/vehicles#garagesprovider)

```ts title="Sygnatura"
GetGarageSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetGarageSystem() -- string lub nil
```

#### Parametry

Brak.

#### Zwraca

`string | null`: nazwa zasobu skryptu garażu. `null`, gdy żaden nie działa.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("garagesystem", { help: "Shows the garage script in use", restricted: true }, () => {
  console.log(core.GetGarageSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('garagesystem', { help = 'Shows the garage script in use', restricted = true }, function()
  print(exports['ai-core']:GetGarageSystem() or 'none')
end)
```
</Tab>
</Tabs>

### ImpoundVehicle

Wysyła pojazd ze świata na parking policyjny. Przy skryptach garażu, które mają tylko formularz odholowania na ekranie gracza, zamiast tego otwiera ten formularz dla gracza w `by`.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`garages.impound`](/pl/docs/developers/api/lib-server/vehicles#garagesimpound)

```ts title="Sygnatura"
ImpoundVehicle(vehicle: number, by?: number): boolean
```

```lua title="Lua"
local taken = exports['ai-core']:ImpoundVehicle(vehicle, source)
```

#### Parametry

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Serwerowy uchwyt encji pojazdu.', required: true },
    by: { type: 'number', description: 'Id serwera gracza, który go odholowuje (funkcjonariusz). Potrzebne skryptom z formularzem odholowania; ignorowane, gdy nie jest online.' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt garażu przejął pojazd (lub otworzył swój formularz). `false`, gdy nic go nie przejęło: nie działa żaden skrypt garażu, nie ma parkingu policyjnego, pojazd nie jest mu znany albo `vehicle` nie jest istniejącym pojazdem. Przy `false` pojazd nadal jest w świecie: usuń go sam, jeśli musi zniknąć.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aicore-fivem/lib/server";
import { fail, oneArg, readId } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:impound", { args: oneArg(readId) }, (source, netId) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  const vehicle = vehicleNearPlayer(source, netId, { metres: 5 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.ImpoundVehicle(vehicle, source)) DeleteEntity(vehicle);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:impound', function(source, netId)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 5 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:ImpoundVehicle(vehicle, source) then DeleteEntity(vehicle) end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### StoreVehicleInGarage

Odstawia pojazd ze świata do garażu, z jego stanem.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`garages.store`](/pl/docs/developers/api/lib-server/vehicles#garagesstore)

```ts title="Sygnatura"
StoreVehicleInGarage(vehicle: number, garage?: string | null, by?: number): boolean
```

```lua title="Lua"
local stored = exports['ai-core']:StoreVehicleInGarage(vehicle, 'legion', source)
```

#### Parametry

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Serwerowy uchwyt encji pojazdu.', required: true },
    garage: { type: 'string | null', description: 'Id garażu w skrypcie garażu. `null` lub pominięte: wybiera skrypt.', default: 'null' },
    by: { type: 'number', description: 'Id serwera gracza, który go odstawia. Skrypty z klienckim API działają w grze tego gracza; ignorowane, gdy nie jest online.' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt garażu przejął pojazd. `false`, gdy nic go nie przejęło (brak skryptu garażu, brak akcji odstawienia, nieznany garaż, pojazd, który nie należy do skryptu) albo `vehicle` nie jest istniejącym pojazdem.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleOf } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Parkingowy odstawia samochód, którym jedzie gracz, do najbliższego garażu.
onClientCallback("myscript:valetStore", (source) => {
  const vehicle = vehicleOf(source, { driver: true });
  if (!vehicle) return fail("NOT_DRIVING");
  return core.StoreVehicleInGarage(vehicle, null, source) ? { ok: true } : fail("STORE_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:valetStore', function(source)
  local ped = GetPlayerPed(source)
  local vehicle = GetVehiclePedIsIn(ped, false)
  if vehicle == 0 or GetPedInVehicleSeat(vehicle, -1) ~= ped then return aiLib.fail('NOT_DRIVING') end
  if not exports['ai-core']:StoreVehicleInGarage(vehicle, nil, source) then return aiLib.fail('STORE_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### OpenGarage

Otwiera menu garażu aktywnego skryptu garażu dla gracza.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`garages.open`](/pl/docs/developers/api/lib-server/vehicles#garagesopen)

```ts title="Sygnatura"
OpenGarage(source: number, garage?: string | null): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenGarage(source, 'legion')
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },
    garage: { type: 'string | null', description: 'Id garażu w skrypcie garażu. `null` lub pominięte: domyślny garaż skryptu.', default: 'null' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy menu się otworzyło. `false`, gdy gracz nie jest online, nie działa żaden skrypt garażu albo nie ma menu, które da się otworzyć z zewnątrz.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const MOTEL_GARAGE = { x: 273.1, y: -343.9, z: 44.9 };

onClientCallback("myscript:motelGarage", { guards: [near(MOTEL_GARAGE, 3)] }, (source) =>
  core.OpenGarage(source, "motel") ? { ok: true } : fail("GARAGE_FAILED"),
);
```
</Tab>
<Tab value="Lua">
```lua
local MOTEL_GARAGE = vector3(273.1, -343.9, 44.9)

aiLib.onClientCallback('myscript:motelGarage', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - MOTEL_GARAGE) > 3.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenGarage(source, 'motel') then return aiLib.fail('GARAGE_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### GetGaragedVehicles

Pojazdy gracza trzymane przez skrypt garażu: w garażu albo na parkingu policyjnym.

**Strona:** Serwer · **Czeka:** nie (odpowiada przez `done`) · **Lib:** [`garages.stored(source)`](/pl/docs/developers/api/lib-server/vehicles#garagesstored) zwraca Promise

```ts title="Sygnatura"
GetGaragedVehicles(source: number, done: (vehicles: GaragedVehicle[] | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetGaragedVehicles(source, function(vehicles) end) -- lista lub nil
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },
    done: { type: '(vehicles) => void', description: 'Wywoływany raz z odpowiedzią, po odpowiedzi skryptu garażu.', required: true, typeDescription: '(vehicles: GaragedVehicle[] | null) => void' },
  }}
/>

#### Zwraca

Nic. `done` dostaje jeden wpis na pojazd z `plate`, `model` (lub `null`), `garage` (lub `null`) i `impounded` ([GaragedVehicle](/pl/docs/developers/api/types#garagedvehicle)) albo `null`, gdy gracz nie jest online, nie działa żaden skrypt garażu, nie umie wyświetlić pojazdów albo zawiódł. Bez funkcji jako `done` wywołanie nic nie robi.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import type { GaragedVehicle } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Okienko parkingu policyjnego wyświetla odholowane samochody gracza.
onClientCallback("myscript:impoundList", async (source) => {
  const list = await new Promise<GaragedVehicle[] | null>((resolve) => core.GetGaragedVehicles(source, resolve));
  if (!list) return fail("GARAGE_UNKNOWN");
  return { ok: true, plates: list.filter((v) => v.impounded).map((v) => v.plate) };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:impoundList', function(source)
  local p = promise.new()
  exports['ai-core']:GetGaragedVehicles(source, function(list) p:resolve(list or false) end)
  local list = Citizen.Await(p)
  if not list then return aiLib.fail('GARAGE_UNKNOWN') end
  local plates = {}
  for _, v in ipairs(list) do
    if v.impounded then plates[#plates + 1] = v.plate end
  end
  return { ok = true, plates = plates }
end)
```
</Tab>
</Tabs>
