Garaj çağrıları ai-core üzerinden gider, asla bir garaj script’inin kendi export’ları ya da event’leri üzerinden değil (ai-garages dahil). ai-core her çağrıyı **aktif garaj script’ine** iletir: panelin **Garage script** ayarının seçtiği ya da çalışan ilk script (ai-garages, jg-advancedgarages, tgiann-realparking ve uyumluluk listesindeki diğerleri). Her script yalnızca gerçekten sahip olduğu aksiyonları cevaplar; bu yüzden herhangi bir aksiyon bir script’le `false` ya da `null` cevabı verip başka biriyle çalışabilir.

Araç bir **server entity handle**’ıdır.

### GetGarageSystem

ai-core’un ilettiği garaj script’inin resource adı.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`garages.provider()`](/tr/docs/developers/api/lib-server/vehicles#garagesprovider)

```ts title="İmza"
GetGarageSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetGarageSystem() -- string ya da nil
```

#### Parametreler

Yok.

#### Dönüş değeri

`string | null`: garaj script’inin resource adı. Hiçbiri çalışmıyorsa `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("garagesystem", { help: "Shows the garage script in use", restricted: true }, () => {
  console.log(core.GetGarageSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('garagesystem', { help = 'Shows the garage script in use', restricted = true }, function()
  print(exports['ai-core']:GetGarageSystem() or 'none')
end)
```
</Tab>
</Tabs>

### ImpoundVehicle

Dünyadaki bir aracı çekilmiş araç otoparkına gönderir. Yalnızca oyuncunun ekranında bir çekme formu olan garaj script’lerinde bunun yerine o formu `by` içindeki oyuncu için açar.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`garages.impound`](/tr/docs/developers/api/lib-server/vehicles#garagesimpound)

```ts title="İmza"
ImpoundVehicle(vehicle: number, by?: number): boolean
```

```lua title="Lua"
local taken = exports['ai-core']:ImpoundVehicle(vehicle, source)
```

#### Parametreler

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Aracın server entity handle’ı.', required: true },
    by: { type: 'number', description: 'Aracı çeken oyuncunun server id’si (bir memur). Çekme formu olan script’ler buna ihtiyaç duyar; çevrimiçi değilse yok sayılır.' },
  }}
/>

#### Dönüş değeri

`boolean`: garaj script’i aracı devraldığında (ya da formunu açtığında) `true`. Hiçbir şey almadığında `false`: hiçbir garaj script’i çalışmıyor, çekme özelliği yok, araç onun bildiği biri değil ya da `vehicle` mevcut bir araç değil. `false` durumunda araç hâlâ dünyadadır: gitmesi gerekiyorsa kendin sil.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:impound", { args: oneArg(readId) }, (source, netId) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  const vehicle = vehicleNearPlayer(source, netId, { metres: 5 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.ImpoundVehicle(vehicle, source)) DeleteEntity(vehicle);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:impound', function(source, netId)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 5 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:ImpoundVehicle(vehicle, source) then DeleteEntity(vehicle) end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### StoreVehicleInGarage

Dünyadaki bir aracı durumuyla birlikte bir garaja koyar.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`garages.store`](/tr/docs/developers/api/lib-server/vehicles#garagesstore)

```ts title="İmza"
StoreVehicleInGarage(vehicle: number, garage?: string | null, by?: number): boolean
```

```lua title="Lua"
local stored = exports['ai-core']:StoreVehicleInGarage(vehicle, 'legion', source)
```

#### Parametreler

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Aracın server entity handle’ı.', required: true },
    garage: { type: 'string | null', description: 'Garaj script’inin garaj id’si. `null` ya da verilmemiş: script seçer.', default: 'null' },
    by: { type: 'number', description: 'Aracı park eden oyuncunun server id’si. Client API’si olan script’ler bu oyuncunun oyununda işlem yapar; çevrimiçi değilse yok sayılır.' },
  }}
/>

#### Dönüş değeri

`boolean`: garaj script’i aracı aldığında `true`. Hiçbir şey almadığında (garaj script’i yok, park aksiyonu yok, bilinmeyen garaj, script’in sahip olmadığı bir araç) ya da `vehicle` mevcut bir araç değilse `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleOf } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Bir vale oyuncunun sürdüğü arabayı en yakın garaja park eder.
onClientCallback("myscript:valetStore", (source) => {
  const vehicle = vehicleOf(source, { driver: true });
  if (!vehicle) return fail("NOT_DRIVING");
  return core.StoreVehicleInGarage(vehicle, null, source) ? { ok: true } : fail("STORE_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:valetStore', function(source)
  local ped = GetPlayerPed(source)
  local vehicle = GetVehiclePedIsIn(ped, false)
  if vehicle == 0 or GetPedInVehicleSeat(vehicle, -1) ~= ped then return aiLib.fail('NOT_DRIVING') end
  if not exports['ai-core']:StoreVehicleInGarage(vehicle, nil, source) then return aiLib.fail('STORE_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### OpenGarage

Bir oyuncu için aktif garaj script’inin garaj menüsünü açar.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`garages.open`](/tr/docs/developers/api/lib-server/vehicles#garagesopen)

```ts title="İmza"
OpenGarage(source: number, garage?: string | null): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenGarage(source, 'legion')
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    garage: { type: 'string | null', description: 'Garaj script’inin garaj id’si. `null` ya da verilmemiş: script’in varsayılanı.', default: 'null' },
  }}
/>

#### Dönüş değeri

`boolean`: menü açıldığında `true`. Oyuncu çevrimiçi değilse, hiçbir garaj script’i çalışmıyorsa ya da dışarıdan açılabilen bir menüsü yoksa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const MOTEL_GARAGE = { x: 273.1, y: -343.9, z: 44.9 };

onClientCallback("myscript:motelGarage", { guards: [near(MOTEL_GARAGE, 3)] }, (source) =>
  core.OpenGarage(source, "motel") ? { ok: true } : fail("GARAGE_FAILED"),
);
```
</Tab>
<Tab value="Lua">
```lua
local MOTEL_GARAGE = vector3(273.1, -343.9, 44.9)

aiLib.onClientCallback('myscript:motelGarage', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - MOTEL_GARAGE) > 3.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenGarage(source, 'motel') then return aiLib.fail('GARAGE_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### GetGaragedVehicles

Garaj script’inin tuttuğu bir oyuncunun araçları: bir garajda ya da çekilmiş araç otoparkında.

**Taraf:** Server · **Bekler:** hayır (`done` ile cevap verir) · **Lib:** [`garages.stored(source)`](/tr/docs/developers/api/lib-server/vehicles#garagesstored) bir Promise döndürür

```ts title="İmza"
GetGaragedVehicles(source: number, done: (vehicles: GaragedVehicle[] | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetGaragedVehicles(source, function(vehicles) end) -- liste ya da nil
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    done: { type: '(vehicles) => void', description: 'Garaj script’i cevap verdikten sonra cevapla bir kez çağrılır.', required: true, typeDescription: '(vehicles: GaragedVehicle[] | null) => void' },
  }}
/>

#### Dönüş değeri

Hiçbir şey. `done` araç başına `plate`, `model` (ya da `null`), `garage` (ya da `null`) ve `impounded` içeren bir kayıt alır ([GaragedVehicle](/tr/docs/developers/api/types#garagedvehicle)); oyuncu çevrimiçi değilse, hiçbir garaj script’i çalışmıyorsa, araçları listeleyemiyorsa ya da başarısız olduysa `null` alır. `done` olarak bir fonksiyon verilmezse çağrı hiçbir şey yapmaz.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import type { GaragedVehicle } from "@aifivem/shared";

const core = resourceExport("ai-core");

// Çekilmiş araç masası oyuncunun çekilmiş arabalarını listeler.
onClientCallback("myscript:impoundList", async (source) => {
  const list = await new Promise<GaragedVehicle[] | null>((resolve) => core.GetGaragedVehicles(source, resolve));
  if (!list) return fail("GARAGE_UNKNOWN");
  return { ok: true, plates: list.filter((v) => v.impounded).map((v) => v.plate) };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:impoundList', function(source)
  local p = promise.new()
  exports['ai-core']:GetGaragedVehicles(source, function(list) p:resolve(list or false) end)
  local list = Citizen.Await(p)
  if not list then return aiLib.fail('GARAGE_UNKNOWN') end
  local plates = {}
  for _, v in ipairs(list) do
    if v.impounded then plates[#plates + 1] = v.plate end
  end
  return { ok = true, plates = plates }
end)
```
</Tab>
</Tabs>
