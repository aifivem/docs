Polis ihbarları ai-core üzerinden gider, asla bir ihbar script’inin kendi export’ları ya da event’leri üzerinden değil (ai-policealert dahil). ai-core her ihbarı **aktif ihbar sistemine** iletir: panelin **Alert script** ayarının seçtiği ya da çalışan ilk sistem (ai-policealert’in yerleşik kartları en son gelir). İhbar sistemi onu ihbarın mesleklerindeki mesaideki üyelere gösterir.

ai-core, bunu yapmayan ihbar sistemleri için QB’nin `police:server:policeAlert` event’ini de cevaplar, böylece QB script’lerinin ihbarları da gelir.

### SendDispatchAlert

Tek bir ihbar gönderir. Memurların (ya da başka bir mesleğin) müdahale etmesi gereken her şey için kullan: ateş açılması, dükkan soygunu, çalıntı araç.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`dispatch.alert`](/tr/docs/developers/api/lib-server/jobs#dispatchalert)

```ts title="İmza"
SendDispatchAlert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendDispatchAlert({ title = 'Store robbery', code = '10-90', source = source })
```

#### Dönüş değeri

`boolean`: ihbar sistemi ihbarı aldığında `true`. `title` eksik ya da boşsa, hiçbir ihbar sistemi çalışmıyorsa ya da başarısız olduysa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const REGISTER = { x: 24.5, y: -1345.6, z: 29.5 };

onClientCallback("myscript:robRegister", { guards: [near(REGISTER, 2)], lock: true }, (source) => {
  if (core.GetOnDutyCount("police") < 2) return fail("NOT_ENOUGH_POLICE");
  core.SendDispatchAlert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: Locale("ALERT_STORE_NAME"),
    coords: REGISTER,
    source,
    jobs: ["police"],
    icon: "cash-register",
    priority: "high",
  });
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local REGISTER = vector3(24.5, -1345.6, 29.5)

aiLib.onClientCallback('myscript:robRegister', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - REGISTER) > 2.0 then return aiLib.fail('TOO_FAR') end
  if exports['ai-core']:GetOnDutyCount('police') < 2 then return aiLib.fail('NOT_ENOUGH_POLICE') end
  exports['ai-core']:SendDispatchAlert({
    code = '10-90',
    title = Locale('ALERT_STORE_ROBBERY'),
    message = Locale('ALERT_STORE_NAME'),
    coords = { x = REGISTER.x, y = REGISTER.y, z = REGISTER.z },
    source = source,
    jobs = { 'police' },
    icon = 'cash-register',
    priority = 'high',
  })
  return { ok = true }
end, { lock = true })
```

<Callout type="warn">
Metinler verildiği gibi gösterilir: göndermeden önce `Locale` ile çevir. Her karede ya da her isabette ihbar gönderme: ateş açılması ihbarının oyuncu başına bir bekleme süresi olmalıdır.
