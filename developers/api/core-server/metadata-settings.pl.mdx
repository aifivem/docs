### GetMeta

Jedna wartość z **metadanych** postaci: dowolnego worka nazwanych wartości zapisywanego z postacią. Skrypty ESX i QB trzymają tam przez most swoje dodatkowe dane postaci (`hunger`, `thirst`, `armor`, `isdead`...), a twój skrypt może trzymać własne małe wartości.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
GetMeta(src: number, key: string): unknown
```

```lua title="Lua"
local value = exports['ai-core']:GetMeta(source, 'myscript_xp') -- dowolna wartość lub nil
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
    key: { type: 'string', description: 'Nazwa wartości. Poprzedzaj własne klucze nazwą swojego skryptu (`myscript_xp`), aby nigdy nie kolidowały z innym skryptem.', required: true },
  }}
/>

#### Zwraca

`unknown`: zapisana wartość (liczba, tekst, wartość logiczna, lista lub tabela), tak jak została ustawiona. `null`, gdy klucz nie jest ustawiony albo gracz nie ma wczytanej postaci. Sprawdź typ przed użyciem: wartość mógł zapisać inny skrypt albo starsza wersja twojego.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The character's fishing level, 1 when none was stored yet. */
export function fishingLevel(source: number): number {
  const value = core.GetMeta(source, "myscript_level");
  return typeof value === "number" && Number.isInteger(value) && value > 0 ? value : 1;
}
```
</Tab>
<Tab value="Lua">
```lua
function FishingLevel(source)
  local value = exports['ai-core']:GetMeta(source, 'myscript_level')
  if math.type(value) == 'integer' and value > 0 then return value end
  return 1
end
```
</Tab>
</Tabs>

### SetMeta

Zapisuje jedną wartość w metadanych postaci. Wartość jest zapisywana przy następnym okresowym zapisie postaci (ustawienie panelu, domyślnie co 5 minut), przy wylogowaniu i gdy serwer się zatrzymuje.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
SetMeta(src: number, key: string, value: unknown): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetMeta(source, 'myscript_level', 3)
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
    key: { type: 'string', description: 'Nazwa wartości. Poprzedzaj własne klucze nazwą swojego skryptu.', required: true },
    value: { type: 'unknown', description: 'Dowolna wartość, która mieści się w JSON: liczba, tekst, wartość logiczna, lista lub tabela. `null` (w Lua `nil`) usuwa klucz.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy wartość została zapisana (lub usunięta). `false`, gdy gracz nie ma wczytanej postaci albo `key` nie jest tekstem.

Zmiana od razu dociera do własnej gry gracza i wysyła serwerowe zdarzenie `ai-core:metaChanged (src, key, value)`.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** One level up after enough catches. */
export function levelUp(source: number): void {
  const level = core.GetMeta(source, "myscript_level");
  const next = (typeof level === "number" ? level : 1) + 1;
  core.SetMeta(source, "myscript_level", next);
}
```
</Tab>
<Tab value="Lua">
```lua
function LevelUp(source)
  local level = exports['ai-core']:GetMeta(source, 'myscript_level')
  if type(level) ~= 'number' then level = 1 end
  exports['ai-core']:SetMeta(source, 'myscript_level', level + 1)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Metadane są na małe wartości należące do jednej postaci (poziom, flaga, kilka liczb). Rosnące listy (historia, każdy połów) i wszystko, co wyszukujesz lub liczysz między postaciami, należą do twojej własnej tabeli w bazie danych. Wartości w metadanych nie są zapisywane od razu: pieniądze i przedmioty nigdy tam nie trafiają.
</Callout>

### GetBranding

Nazwa serwera, podtytuł, hasła i obraz tła z ustawień General w panelu. Używaj tego, aby pokazać tę samą nazwę na własnych pełnoekranowych menu.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
GetBranding(): Branding
```

```lua title="Lua"
local brand = exports['ai-core']:GetBranding() -- tabela
```

#### Parametry

Brak.

#### Zwraca

`Branding`: kopia z `name`, `subtitle`, `tagline`, `taglineSub` i `background` (`"skyline"` lub `"wet-drive"`, obraz w ai-core). Zobacz [Branding](/pl/docs/developers/api/types#branding).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Ekran powitalny pokazuje nazwę serwera.
onClientCallback("myscript:welcome", () => {
  const { name, tagline } = core.GetBranding();
  return { ok: true, name, tagline };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:welcome', function()
  local brand = exports['ai-core']:GetBranding()
  return { ok = true, name = brand.name, tagline = brand.tagline }
end)
```
</Tab>
</Tabs>

### GetUpdates

Skrypty z nowszym wydaniem na GitHubie niż uruchomiona wersja, ze sprawdzania aktualizacji ai-core. ai-core pyta GitHub najwyżej raz na 6 godzin na skrypt (i gdy skrypt startuje) o każdy uruchomiony skrypt z linią `repository` w jego `fxmanifest.lua`, chyba że w panelu wyłączone jest **Check for updates**.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
GetUpdates(): UpdateInfo[]
```

```lua title="Lua"
local outdated = exports['ai-core']:GetUpdates() -- lista tabel
```

#### Parametry

Brak.

#### Zwraca

`UpdateInfo[]`: jeden wpis na nieaktualny skrypt z `resource`, `label` (nazwa, pod którą ludzie go znają), `current` (uruchomiona wersja), `latest` (najnowsze wydanie) i `url` (strona wydania). Pusta lista, gdy wszystko jest aktualne albo nic jeszcze nie zostało sprawdzone (pierwsze sprawdzenie działa 15 sekund po starcie). Zobacz [UpdateInfo](/pl/docs/developers/api/types#updateinfo).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("outdated", { help: "Lists outdated scripts", restricted: true }, () => {
  for (const u of core.GetUpdates()) console.log(`${u.label}: ${u.current} -> ${u.latest} (${u.url})`);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('outdated', { help = 'Lists outdated scripts', restricted = true }, function()
  for _, u in ipairs(exports['ai-core']:GetUpdates()) do
    print(('%s: %s -> %s (%s)'):format(u.label, u.current, u.latest, u.url))
  end
end)
```
</Tab>
</Tabs>
