---
title: Combustible
description: Lee y pon el nivel de combustible de un vehículo a través del script de combustible que tenga el servidor.
icon: Fuel
---

El combustible pasa por ai-core, nunca por los exports, decorators o state bags propios de un script de combustible (ai-fuel incluido). ai-core reenvía cada llamada al **script de combustible activo**: el que elige el ajuste **Fuel script** (script de combustible) del panel, o el primero que esté en marcha (ai-fuel, ox_fuel, LegacyFuel y los demás de la lista de compatibilidad). Sin un script de combustible, el nivel es simplemente el state bag `fuel` del vehículo.

Un nivel es un número de **0 (vacío) a 100 (lleno)**. Un vehículo es un **handle de entidad del servidor**.

### GetFuelSystem

El nombre de recurso del script de combustible al que reenvía ai-core.

**Lado:** Servidor · **Espera:** no · **Lib:** [`fuel.provider()`](/es/docs/developers/api/lib-server/vehicles#fuelprovider)

```ts title="Firma"
GetFuelSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetFuelSystem() -- 'ai-fuel', 'ox_fuel'... o nil
```

#### Parámetros

Ninguno.

#### Devuelve

`string | null`: el nombre de recurso del script de combustible. `null` cuando no hay ninguno en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("fuelsystem", { help: "Shows the fuel script in use", restricted: true }, () => {
  console.log(core.GetFuelSystem() ?? "none: fuel is only the state bag");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('fuelsystem', { help = 'Shows the fuel script in use', restricted = true }, function()
  print(exports['ai-core']:GetFuelSystem() or 'none: fuel is only the state bag')
end)
```
</Tab>
</Tabs>

### GetVehicleFuel

El nivel de combustible de un vehículo.

**Lado:** Servidor · **Espera:** no · **Lib:** [`fuel.get`](/es/docs/developers/api/lib-server/vehicles#fuelget) (servidor); en el cliente, el `fuel.get(vehicle)` de la lib de cliente lee el state bag que mantiene ai-core

```ts title="Firma"
GetVehicleFuel(vehicle: number): number | null
```

```lua title="Lua"
local level = exports['ai-core']:GetVehicleFuel(vehicle) -- 0-100 o nil
```

#### Parámetros

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Handle de entidad del servidor de un vehículo.', required: true },
  }}
/>

#### Devuelve

`number | null`: el nivel, 0-100. `null` cuando el vehículo aún no tiene nivel, o `vehicle` no es un vehículo existente.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Un mecánico lee el depósito del coche que tiene delante.
onClientCallback("myscript:checkTank", { args: oneArg(readId) }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 4 });
  if (!vehicle) return fail("TOO_FAR");
  return { ok: true, level: core.GetVehicleFuel(vehicle) };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:checkTank', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 4 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  return { ok = true, level = exports['ai-core']:GetVehicleFuel(vehicle) }
end)
```
</Tab>
</Tabs>

### SetVehicleFuel

Pone el nivel de combustible de un vehículo.

**Lado:** Servidor · **Espera:** no · **Lib:** [`fuel.set`](/es/docs/developers/api/lib-server/vehicles#fuelset) (y [`spawnVehicle({ fuel })`](/es/docs/developers/api/lib-server/vehicles#spawnvehicle) lo pone al crearlo)

```ts title="Firma"
SetVehicleFuel(vehicle: number, level: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetVehicleFuel(vehicle, 100.0)
```

#### Parámetros

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Handle de entidad del servidor de un vehículo.', required: true },
    level: { type: 'number', description: 'El nuevo nivel. Los valores por debajo de 0 pasan a 0, por encima de 100 pasan a 100.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el nivel se entregó al script de combustible (o se escribió en el state bag cuando no hay ninguno en marcha). `false` cuando `vehicle` no es un vehículo existente, `level` no es un número finito o el script de combustible falló.

En los scripts de combustible que guardan el combustible en los juegos de los jugadores, el nuevo nivel llega al vehículo a través del juego de su dueño un momento después.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Un bidón añade un 25% al coche que está junto al jugador.
onClientCallback("myscript:jerryCan", { args: oneArg(readId), lock: true }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 3 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.RemoveItem(source, "jerrycan")) return fail("NO_JERRYCAN");
  core.SetVehicleFuel(vehicle, (core.GetVehicleFuel(vehicle) ?? 0) + 25);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:jerryCan', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 3 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:RemoveItem(source, 'jerrycan') then return aiLib.fail('NO_JERRYCAN') end
  local level = exports['ai-core']:GetVehicleFuel(vehicle) or 0
  exports['ai-core']:SetVehicleFuel(vehicle, level + 25)
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>
