---
title: Zamki drzwi
description: Zamykaj, otwieraj i odczytuj drzwi przez skrypt zamków drzwi, którego używa serwer.
icon: DoorClosed
---

Wywołania drzwi przechodzą przez ai-core, nigdy przez własne eksporty lub zdarzenia skryptu zamków drzwi (łącznie z ai-doorlock). ai-core przekazuje każde wywołanie do **aktywnego skryptu zamków drzwi**: tego, który wybiera ustawienie **Door lock script** w panelu, albo pierwszego działającego (ai-doorlock, ox_doorlock, tgiann-doorlock i inne z listy zgodności).

Drzwi są nazywane **własnym id drzwi tego skryptu**: id, które widzisz na jego liście drzwi (ai-doorlock: id drzwi w panelu administratora; ox_doorlock: ich numer w bazie danych).

### GetDoorlockSystem

Nazwa zasobu skryptu zamków drzwi, do którego ai-core przekazuje wywołania.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`doors.provider()`](/pl/docs/developers/api/lib-server/world#doorsprovider)

```ts title="Sygnatura"
GetDoorlockSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetDoorlockSystem() -- string lub nil
```

#### Parametry

Brak.

#### Zwraca

`string | null`: nazwa zasobu skryptu zamków drzwi. `null`, gdy żaden nie działa.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Id drzwi w twoim configu należą do jednego skryptu zamków: ostrzeż, gdy działa inny.
if (core.GetDoorlockSystem() !== "ai-doorlock")
  console.log("myscript: door ids are written for ai-doorlock");
```
</Tab>
<Tab value="Lua">
```lua
if exports['ai-core']:GetDoorlockSystem() ~= 'ai-doorlock' then
  print('myscript: door ids are written for ai-doorlock')
end
```
</Tab>
</Tabs>

### SetDoorLocked

Zamyka lub otwiera drzwi.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`doors.setLocked`](/pl/docs/developers/api/lib-server/world#doorssetlocked)

```ts title="Sygnatura"
SetDoorLocked(id: string, locked: boolean, by?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDoorLocked('pacific_vault', false, source)
```

#### Parametry

<TypeTable
  type={{
    id: { type: 'string', description: 'Id drzwi w skrypcie zamków drzwi. Liczba całkowita (id z ox_doorlock) jest zamieniana na tekst. Najwyżej 128 znaków.', required: true },
    locked: { type: 'boolean', description: '`true` zamyka, `false` otwiera. Musi być prawdziwą wartością logiczną.', required: true },
    by: { type: 'number', description: 'Id serwera gracza, który to robi. Skrypty zamków drzwi bez serwerowego API potrzebują gracza, którego gra przeniesie zmianę; ignorowane, gdy ten gracz nie jest online.' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt zamków drzwi przyjął zmianę. `false`, gdy nie działa żaden skrypt zamków drzwi, drzwi są nieznane, skrypt odmówił, `id` jest puste albo `locked` nie jest wartością logiczną.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, progressFor, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const VAULT = { x: 253.9, y: 225.2, z: 101.9 };

onClientCallback("myscript:hackVault", { guards: [near(VAULT, 2)], lock: true }, async (source) => {
  if (!core.HasItem(source, "laptop")) return fail("NO_LAPTOP");
  if (!(await progressFor(source, { label: Locale("HACKING"), duration: 15000 }))) return fail("CANCELLED");
  return core.SetDoorLocked("pacific_vault", false, source) ? { ok: true } : fail("DOOR_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local VAULT = vector3(253.9, 225.2, 101.9)

aiLib.onClientCallback('myscript:hackVault', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - VAULT) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:HasItem(source, 'laptop') then return aiLib.fail('NO_LAPTOP') end
  if not aiLib.progressFor(source, { label = Locale('HACKING'), duration = 15000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:SetDoorLocked('pacific_vault', false, source) then return aiLib.fail('DOOR_FAILED') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### IsDoorLocked

Czy drzwi są zamknięte.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`doors.isLocked`](/pl/docs/developers/api/lib-server/world#doorsislocked)

```ts title="Sygnatura"
IsDoorLocked(id: string): boolean | null
```

```lua title="Lua"
local locked = exports['ai-core']:IsDoorLocked('pacific_vault') -- true, false lub nil
```

#### Parametry

<TypeTable
  type={{
    id: { type: 'string', description: 'Id drzwi w skrypcie zamków drzwi (liczba całkowita jest zamieniana na tekst).', required: true },
  }}
/>

#### Zwraca

`boolean | null`: `true` zamknięte, `false` otwarte. `null`, gdy nie wiadomo: nie działa żaden skrypt zamków drzwi, drzwi nie istnieją, skrypt nie umie tego stwierdzić na serwerze albo `id` jest puste.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The heist may start only while the vault is still closed. */
export function vaultClosed(): boolean {
  return core.IsDoorLocked("pacific_vault") !== false;
}
```
</Tab>
<Tab value="Lua">
```lua
function VaultClosed()
  return exports['ai-core']:IsDoorLocked('pacific_vault') ~= false
end
```
</Tab>
</Tabs>

<Callout type="info">
Zdecyduj, co `null` znaczy dla twojej funkcji. Przykład traktuje "nieznane" jako zamknięte, więc brak skryptu zamków drzwi nigdy nie otworzy skoku przedwcześnie.
</Callout>
