Les appels de téléphone passent par ai-core, jamais par les exports propres à un script de téléphone. ai-core transmet chaque appel au **premier script de téléphone qui tourne** (tgiann-phone, lb-phone, gksphone et les autres de la liste de compatibilité). Tant qu’aucun téléphone ne tourne, chaque appel répond `null` ou `false`.

### GetPhoneNumber

Le numéro de téléphone d’un joueur.

**Côté :** Serveur · **Attend :** non · **Lib :** [`phone.number`](/fr/docs/developers/api/lib-server/phone-appearance#phonenumber)

```ts title="Signature"
GetPhoneNumber(source: number): string | null
```

```lua title="Lua"
local number = exports['ai-core']:GetPhoneNumber(source) -- string ou nil
```

#### Paramètres

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serveur du joueur.', required: true },
  }}
/>

#### Retour

`string | null` : le numéro tel que l’écrit le script de téléphone. `null` quand le joueur n’en a pas, qu’aucun téléphone ne tourne ou que `source` n’est pas un nombre.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Un objet carte de visite affiche le numéro du propriétaire.
onClientCallback("myscript:myNumber", (source) => {
  const number = core.GetPhoneNumber(source);
  return number ? { ok: true, number } : fail("NO_PHONE_NUMBER");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myNumber', function(source)
  local number = exports['ai-core']:GetPhoneNumber(source)
  if not number then return aiLib.fail('NO_PHONE_NUMBER') end
  return { ok = true, number = number }
end)
```
</Tab>
</Tabs>

### GetSourceByPhone

Le joueur en ligne qui possède un numéro de téléphone.

**Côté :** Serveur · **Attend :** non · **Lib :** [`phone.sourceOf`](/fr/docs/developers/api/lib-server/phone-appearance#phonesourceof)

```ts title="Signature"
GetSourceByPhone(number: string): number | null
```

```lua title="Lua"
local src = exports['ai-core']:GetSourceByPhone('5551234') -- number ou nil
```

#### Paramètres

<TypeTable
  type={{
    number: { type: 'string', description: 'Le numéro de téléphone, écrit comme l’écrit le script de téléphone.', required: true },
  }}
/>

#### Retour

`number | null` : l’id serveur. `null` quand le propriétaire de ce numéro n’est pas en ligne, que le numéro est inconnu, qu’aucun téléphone ne tourne ou que `number` n’est pas un texte.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { notify, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** A taxi job tells the caller their cab is on the way, if they are online. */
export function cabOnTheWay(callerNumber: string): void {
  const caller = core.GetSourceByPhone(callerNumber);
  if (caller !== null) notify(caller, Locale("NOTIFY_CAB_COMING"), "info");
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function CabOnTheWay(callerNumber)
  local caller = exports['ai-core']:GetSourceByPhone(callerNumber)
  if caller then aiLib.notify(caller, Locale('NOTIFY_CAB_COMING'), 'info') end
end
```
</Tab>
</Tabs>

### HasPhone

Indique si un joueur a un téléphone (pour les scripts de téléphone qui exigent un objet téléphone, s’il en porte un).

**Côté :** Serveur · **Attend :** non · **Lib :** [`phone.hasPhone`](/fr/docs/developers/api/lib-server/phone-appearance#phonehasphone)

```ts title="Signature"
HasPhone(source: number): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasPhone(source)
```

#### Paramètres

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serveur du joueur.', required: true },
  }}
/>

#### Retour

`boolean` : `true` quand le script de téléphone dit que le joueur a un téléphone. `false` sinon, quand aucun téléphone ne tourne ou que `source` n’est pas un nombre.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Un métier qui distribue des tâches par SMS a besoin d’un téléphone.
onClientCallback("myscript:startDeliveries", (source) =>
  core.HasPhone(source) ? { ok: true } : fail("NEED_PHONE"),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:startDeliveries', function(source)
  if not exports['ai-core']:HasPhone(source) then return aiLib.fail('NEED_PHONE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SendPhoneMail

Envoie un mail sur le téléphone d’un joueur.

**Côté :** Serveur · **Attend :** non · **Lib :** [`phone.mail`](/fr/docs/developers/api/lib-server/phone-appearance#phonemail)

```ts title="Signature"
SendPhoneMail(to: number | string, mail: PhoneMail): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMail(source, { sender = 'LS Customs', subject = 'Invoice', message = '...' })
```

#### Paramètres

<TypeTable
  type={{
    to: { type: 'number | string', description: 'Un id serveur de joueur (son numéro est recherché) ou un numéro de téléphone / l’adresse mail du téléphone.', required: true },
    mail: { type: 'PhoneMail', description: 'Le mail. Champs ci-dessous.', required: true },
  }}
/>

#### PhoneMail

<TypeTable
  type={{
    sender: { type: 'string', description: 'Affiché comme expéditeur (une entreprise, `Los Santos Customs`).', default: '""' },
    subject: { type: 'string', description: 'Ligne d’objet. Coupée à 120 caractères.', required: true },
    message: { type: 'string', description: 'Le texte. Coupé à 4000 caractères.', required: true },
  }}
/>

Les textes sont affichés tels quels : passez des textes traduits. Voir [PhoneMail](/fr/docs/developers/api/types#phonemail).

#### Retour

`boolean` : `true` quand le script de téléphone a accepté le mail. `false` quand le joueur n’a pas de numéro, que `subject` ou `message` manque, qu’aucun téléphone ne tourne ou qu’il a refusé.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The heist contact mails the location after the job was accepted. */
export function mailHeistLocation(source: number, street: string): void {
  core.SendPhoneMail(source, {
    sender: Locale("MAIL_CONTACT"),
    subject: Locale("MAIL_HEIST_SUBJECT"),
    message: Locale("MAIL_HEIST_BODY", street),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function MailHeistLocation(source, street)
  exports['ai-core']:SendPhoneMail(source, {
    sender = Locale('MAIL_CONTACT'),
    subject = Locale('MAIL_HEIST_SUBJECT'),
    message = Locale('MAIL_HEIST_BODY', street),
  })
end
```
</Tab>
</Tabs>

### SendPhoneMessage

Envoie un SMS d’un numéro à un joueur ou à un numéro.

**Côté :** Serveur · **Attend :** non · **Lib :** [`phone.message`](/fr/docs/developers/api/lib-server/phone-appearance#phonemessage)

```ts title="Signature"
SendPhoneMessage(from: string, to: number | string, text: string): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMessage('Dispatch', source, 'Your cab is here.')
```

#### Paramètres

<TypeTable
  type={{
    from: { type: 'string', description: 'Le numéro ou le nom de l’expéditeur, tel que l’accepte le script de téléphone.', required: true },
    to: { type: 'number | string', description: 'Un id serveur de joueur (son numéro est recherché) ou un numéro de téléphone.', required: true },
    text: { type: 'string', description: 'Le message, déjà traduit. Coupé à 1000 caractères.', required: true },
  }}
/>

#### Retour

`boolean` : `true` quand le script de téléphone a accepté le message. `false` quand le destinataire n’a pas de numéro, que `from` ou `text` n’est pas un texte, qu’aucun téléphone ne tourne ou qu’il a refusé.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The next delivery address arrives by text. */
export function textNextStop(source: number, street: string): void {
  if (!core.SendPhoneMessage(Locale("SENDER_DISPATCH"), source, Locale("TEXT_NEXT_STOP", street)))
    console.log(`player ${source} could not get the text`);
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TextNextStop(source, street)
  if not exports['ai-core']:SendPhoneMessage(Locale('SENDER_DISPATCH'), source, Locale('TEXT_NEXT_STOP', street)) then
    print(('player %d could not get the text'):format(source))
  end
end
```
</Tab>
</Tabs>

### PhoneNotify

Affiche une notification sur le téléphone d’un joueur.

**Côté :** Serveur · **Attend :** non · **Lib :** [`phone.notify`](/fr/docs/developers/api/lib-server/phone-appearance#phonenotify)

```ts title="Signature"
PhoneNotify(source: number, notification: PhoneNotification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:PhoneNotify(source, { title = 'Bank', message = 'Salary paid', app = 'bank' })
```

#### Paramètres

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serveur du joueur.', required: true },
    notification: { type: 'PhoneNotification', description: 'Quoi afficher. Champs ci-dessous.', required: true },
  }}
/>

#### PhoneNotification

<TypeTable
  type={{
    title: { type: 'string', description: 'Ligne de titre. Coupée à 80 caractères.', required: true },
    message: { type: 'string', description: 'Le texte. Coupé à 500 caractères.', default: '""' },
    app: { type: 'string', description: 'L’id de l’application du téléphone à laquelle elle appartient quand le téléphone la connaît (`messages`, `mail`, `bank`).' },
  }}
/>

Voir [PhoneNotification](/fr/docs/developers/api/types#phonenotification).

#### Retour

`boolean` : `true` quand le script de téléphone l’a affichée. `false` quand `title` manque, qu’aucun téléphone ne tourne, que `source` n’est pas un nombre ou qu’il a refusé.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Tells the owner their car was towed. */
export function towedNotice(source: number, plate: string): void {
  core.PhoneNotify(source, { title: Locale("PHONE_TOW_TITLE"), message: Locale("PHONE_TOW_TEXT", plate) });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TowedNotice(source, plate)
  exports['ai-core']:PhoneNotify(source, { title = Locale('PHONE_TOW_TITLE'), message = Locale('PHONE_TOW_TEXT', plate) })
end
```
</Tab>
</Tabs>
