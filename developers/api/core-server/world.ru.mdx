Время и погода идут через ai-core, а не через собственные экспорты или события скрипта погоды. ai-core передаёт каждый вызов **первому запущенному скрипту погоды**: Renewed-Weathersync, av_weather, cd_easytime, затем qb-weathersync (ai-weathersync отвечает под этим именем). Все они следуют контракту qb-weathersync. Пока ни один не работает, каждый вызов отвечает `null` или `false`.

Чтобы приостановить синхронизацию в игре одного игрока (интерьер со своим светом, катсцена), используйте клиентскую сторону (`PauseWorldSync`, в библиотеке `world.pauseSync`); см. [Клиентские экспорты](/ru/docs/developers/api/core-client).

### GetWeather

Текущий тип погоды.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`world.getWeather`](/ru/docs/developers/api/lib-server/world#worldgetweather)

```ts title="Сигнатура"
GetWeather(): string | null
```

```lua title="Lua"
local weather = exports['ai-core']:GetWeather() -- 'EXTRASUNNY', 'RAIN'... или nil
```

#### Параметры

Нет.

#### Возвращает

`string | null`: тип погоды заглавными буквами (`EXTRASUNNY`, `CLEAR`, `RAIN`, `THUNDER`...). `null`, когда ни один скрипт погоды не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Street races pay more in the rain. */
export function raceBonus(): number {
  const weather = core.GetWeather();
  return weather === "RAIN" || weather === "THUNDER" ? 1.25 : 1;
}
```
</Tab>
<Tab value="Lua">
```lua
function RaceBonus()
  local weather = exports['ai-core']:GetWeather()
  if weather == 'RAIN' or weather == 'THUNDER' then return 1.25 end
  return 1.0
end
```
</Tab>
</Tabs>

### SetWeather

Задаёт погоду для всех.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`world.setWeather`](/ru/docs/developers/api/lib-server/world#worldsetweather) (принимает типизированные имена `Weather`)

```ts title="Сигнатура"
SetWeather(type: string): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetWeather('RAIN')
```

#### Параметры

<TypeTable
  type={{
    type: { type: 'string', description: 'Тип погоды из контракта qb-weathersync: `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Переводится в верхний регистр перед отправкой.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, когда скрипт погоды его принял. `false`, когда `type` не текст, скрипт отказал (неизвестный тип) или ни один скрипт погоды не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";
import { isWeather } from "@aifivem/shared";

const core = resourceExport("ai-core");

addCommand("weather", { help: "Sets the weather", params: [{ name: "type", type: "string" }], restricted: true }, (_source, args) => {
  const type = args.type.toUpperCase();
  if (!isWeather(type)) return console.log("unknown weather type");
  core.SetWeather(type);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { help = 'Sets the weather', params = { { name = 'type', type = 'string' } }, restricted = true }, function(_, args)
  if not exports['ai-core']:SetWeather(args.type) then print('weather refused') end
end)
```
</Tab>
</Tabs>

### GetTime

Игровое время (внутриигровые часы).

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`world.getTime`](/ru/docs/developers/api/lib-server/world#worldgettime)

```ts title="Сигнатура"
GetTime(): { hour: number; minute: number } | null
```

```lua title="Lua"
local time = exports['ai-core']:GetTime() -- { hour, minute } или nil
```

#### Параметры

Нет.

#### Возвращает

`{ hour, minute } | null`: час 0-23 и минута 0-59. `null`, когда ни один скрипт погоды не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Наркодилер продаёт только ночью (22:00 - 05:59 игрового времени).
onClientCallback("myscript:dealer", (source) => {
  const time = core.GetTime();
  const night = time !== null && (time.hour >= 22 || time.hour < 6);
  return night ? { ok: true } : fail("COME_BACK_AT_NIGHT");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:dealer', function(source)
  local time = exports['ai-core']:GetTime()
  if not time or (time.hour < 22 and time.hour >= 6) then return aiLib.fail('COME_BACK_AT_NIGHT') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SetTime

Задаёт игровое время для всех.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`world.setTime`](/ru/docs/developers/api/lib-server/world#worldsettime)

```ts title="Сигнатура"
SetTime(hour: number, minute?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetTime(12, 0)
```

#### Параметры

<TypeTable
  type={{
    hour: { type: 'number', description: 'Час, 0-23. Округляется вниз и заворачивается (24 становится 0).', required: true },
    minute: { type: 'number', description: 'Минута, 0-59. Округляется вниз и заворачивается.', default: '0' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда скрипт погоды его принял. `false`, когда `hour` не число, скрипт отказал или ни один скрипт погоды не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("noon", { help: "Sets the time to 12:00", restricted: true }, () => {
  core.SetTime(12, 0);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('noon', { help = 'Sets the time to 12:00', restricted = true }, function()
  exports['ai-core']:SetTime(12, 0)
end)
```
</Tab>
</Tabs>

### SetBlackout

Включает или выключает блэкаут в городе (всё искусственное освещение выключено).

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`world.setBlackout`](/ru/docs/developers/api/lib-server/world#worldsetblackout)

```ts title="Сигнатура"
SetBlackout(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetBlackout(true)
```

#### Параметры

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` включает блэкаут. Всё, кроме `true`, выключает его.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, когда скрипт погоды его принял. `false`, когда у скрипта нет блэкаута, он отказал или ни один скрипт погоды не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The power plant was sabotaged: 5 minutes of darkness. */
export function sabotagePowerPlant(): void {
  if (!core.SetBlackout(true)) return;
  setTimeout(() => core.SetBlackout(false), 5 * 60_000);
}
```
</Tab>
<Tab value="Lua">
```lua
function SabotagePowerPlant()
  if not exports['ai-core']:SetBlackout(true) then return end
  SetTimeout(5 * 60000, function() exports['ai-core']:SetBlackout(false) end)
end
```
</Tab>
</Tabs>

### FreezeTime

Останавливает или снова запускает игровые часы.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`world.freezeTime`](/ru/docs/developers/api/lib-server/world#worldfreezetime)

```ts title="Сигнатура"
FreezeTime(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:FreezeTime(true)
```

#### Параметры

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` замораживает часы. Всё, кроме `true`, позволяет им идти.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, когда скрипт погоды его принял. `false`, когда скрипт не умеет замораживать время, отказал или ни один скрипт погоды не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Вечер мероприятия: всегда 21:00.
addCommand("eventnight", { help: "Freezes the clock at 21:00", restricted: true }, () => {
  core.SetTime(21, 0);
  core.FreezeTime(true);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('eventnight', { help = 'Freezes the clock at 21:00', restricted = true }, function()
  exports['ai-core']:SetTime(21, 0)
  exports['ai-core']:FreezeTime(true)
end)
```
</Tab>
</Tabs>
