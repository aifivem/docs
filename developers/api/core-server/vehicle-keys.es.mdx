---
title: Llaves de vehículos
description: Da, quita y comprueba llaves de vehículos a través del script de llaves que tenga el servidor.
icon: KeyRound
---

Cada llamada de llaves pasa por ai-core, nunca por los exports propios de un script de llaves (ai-vehiclekeys incluido). ai-core la reenvía al **sistema de llaves activo**: el que elige el ajuste **Key script** (script de llaves) del panel, o el primero que esté en marcha. Cuando no hay ningún script de llaves en marcha, cada jugador cuenta como si tuviera todas las llaves.

Un **vehículo** se da como handle de entidad del servidor (el número que devuelve `CreateVehicleServerSetter` o `spawnVehicle`) o como texto de matrícula. Antes se recortan los espacios de la matrícula y se pasa a mayúsculas, así que `" ab12cde "` y `"AB12CDE"` son la misma llave.

Cada llave tiene un **propósito** que le dice al sistema de llaves por qué la recibe el jugador. Algunos sistemas de llaves los tratan de forma distinta (un vehículo comprado recibe un objeto de llave nuevo, un vehículo de trabajo una llave fija en el contacto). Consulta [KeyPurpose](/es/docs/developers/api/types#keypurpose).

| Propósito | Cuándo |
| --- | --- |
| `purchase` | El jugador ahora es dueño del vehículo (concesionario, entrega de un admin): una llave nueva, las copias anteriores dejan de funcionar. |
| `garage` | Un vehículo en propiedad que sale del almacén: el dueño ya tiene la llave. |
| `job` | Un vehículo de trabajo para el turno. |
| `rental` | Un vehículo alquilado durante el tiempo de alquiler. |
| `temporary` | Cualquier otra cosa de corta duración (aparición por un admin, prueba de conducción, vehículo de un robo). El valor por defecto. |

### GiveVehicleKeys

Da a un jugador las llaves de un vehículo.

**Lado:** Servidor · **Espera:** no · **Lib:** [`vehicleKeys.give`](/es/docs/developers/api/lib-server/vehicles#vehiclekeysgive) (y [`spawnVehicle({ keysTo, purpose })`](/es/docs/developers/api/lib-server/vehicles#spawnvehicle) las da por ti)

```ts title="Firma"
GiveVehicleKeys(source: number, vehicle: number | string, purpose?: KeyPurpose): void
```

```lua title="Lua"
exports['ai-core']:GiveVehicleKeys(source, vehicle, 'rental')
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador que recibe las llaves.', required: true },
    vehicle: { type: 'number | string', description: 'Handle de entidad del servidor del vehículo, o su matrícula.', required: true },
    purpose: { type: 'KeyPurpose', description: 'Por qué las recibe el jugador. Cualquier otro valor cuenta como `temporary`.', default: '"temporary"', typeDescription: '"purchase" | "garage" | "job" | "rental" | "temporary"' },
  }}
/>

#### Devuelve

Nada. La llamada no hace nada cuando la entidad del vehículo no existe, la matrícula está vacía, `source` no es un número o no hay ningún sistema de llaves en marcha. Un error del sistema de llaves queda en el log, no se lanza.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, spawnVehicle } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const SPAWN = { x: -1023.5, y: -2694.1, z: 13.9, heading: 150 };

onClientCallback("myscript:rentScooter", { lock: true }, async (source) => {
  if (!core.RemoveMoney(source, "cash", 100, "scooter_rental")) return fail("NOT_ENOUGH_MONEY");
  const vehicle = await spawnVehicle({ model: "faggio", coords: SPAWN, asker: source });
  if (!vehicle) {
    core.AddMoney(source, "cash", 100, "scooter_rental_refund");
    return fail("SPAWN_FAILED");
  }
  core.GiveVehicleKeys(source, vehicle, "rental");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local SPAWN = vector4(-1023.5, -2694.1, 13.9, 150.0)

aiLib.onClientCallback('myscript:rentScooter', function(source)
  if not exports['ai-core']:RemoveMoney(source, 'cash', 100, 'scooter_rental') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  local vehicle = aiLib.spawnVehicle({ model = 'faggio', coords = SPAWN, asker = source })
  if not vehicle then
    exports['ai-core']:AddMoney(source, 'cash', 100, 'scooter_rental_refund')
    return aiLib.fail('SPAWN_FAILED')
  end
  exports['ai-core']:GiveVehicleKeys(source, vehicle, 'rental')
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Un vehículo recién creado no tiene matrícula en el servidor hasta que el cliente de su dueño lo ha sincronizado. Pasa la entidad, no una matrícula que leas justo después de crearlo; el `spawnVehicle` de la lib espera a la matrícula y puede dar las llaves por sí mismo (`keysTo`, `purpose`).
</Callout>

### RemoveVehicleKeys

Quita a un jugador las llaves de un vehículo.

**Lado:** Servidor · **Espera:** no · **Lib:** [`vehicleKeys.remove`](/es/docs/developers/api/lib-server/vehicles#vehiclekeysremove)

```ts title="Firma"
RemoveVehicleKeys(source: number, vehicle: number | string): void
```

```lua title="Lua"
exports['ai-core']:RemoveVehicleKeys(source, 'AB12CDE')
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador.', required: true },
    vehicle: { type: 'number | string', description: 'Handle de entidad del servidor del vehículo, o su matrícula.', required: true },
  }}
/>

#### Devuelve

Nada. Los mismos casos silenciosos que `GiveVehicleKeys`.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The rental ended: the keys go, then the scooter. */
export function endRental(source: number, vehicle: number): void {
  core.RemoveVehicleKeys(source, vehicle);
  if (DoesEntityExist(vehicle)) DeleteEntity(vehicle);
}
```
</Tab>
<Tab value="Lua">
```lua
function EndRental(source, vehicle)
  exports['ai-core']:RemoveVehicleKeys(source, vehicle)
  if DoesEntityExist(vehicle) then DeleteEntity(vehicle) end
end
```
</Tab>
</Tabs>

<Callout type="warn">
Quita las llaves antes de borrar el vehículo. Algunos sistemas de llaves leen la matrícula de la entidad, lo que falla cuando ya no existe.
</Callout>

### HasVehicleKeys

Si un jugador tiene las llaves de un vehículo.

**Lado:** Servidor · **Espera:** no · **Lib:** [`vehicleKeys.has`](/es/docs/developers/api/lib-server/vehicles#vehiclekeyshas)

```ts title="Firma"
HasVehicleKeys(source: number, vehicle: number | string): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasVehicleKeys(source, vehicle)
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador.', required: true },
    vehicle: { type: 'number | string', description: 'Handle de entidad del servidor del vehículo, o su matrícula.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el jugador tiene las llaves. También `true` cuando no hay ningún sistema de llaves en marcha, cuando el sistema de llaves no puede responder a esta pregunta o cuando falla, así que la falta de un script de llaves nunca deja fuera a los jugadores. `false` cuando el jugador no tiene llave, la entidad del vehículo no existe, la matrícula está vacía o `source` no es un número.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Abrir el maletero de un coche que está junto al jugador necesita sus llaves.
onClientCallback("myscript:openTrunk", { args: oneArg(readId) }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 4 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.HasVehicleKeys(source, vehicle)) return fail("NO_KEYS");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:openTrunk', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 4 }) -- 0 cuando no está cerca
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:HasVehicleKeys(source, vehicle) then return aiLib.fail('NO_KEYS') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
