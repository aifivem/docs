Wywołania więzienia przechodzą przez ai-core, nigdy przez własne eksporty lub zdarzenia skryptu więzienia (łącznie z ai-prison). ai-core przekazuje każde wywołanie do **pierwszego działającego skryptu więzienia**: ai-prison, qb-prison, rcore_prison, xt-prison, potem tgiann-policejob. Dopóki żaden nie działa, każde wywołanie odpowiada `false` lub `0`.

### JailPlayer

Wysyła gracza do więzienia na określoną liczbę minut.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`prison.jail`](/pl/docs/developers/api/lib-server/jobs#prisonjail)

```ts title="Sygnatura"
JailPlayer(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local jailed = exports['ai-core']:JailPlayer(target, 20, source)
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza do uwięzienia.', required: true },
    minutes: { type: 'number', description: 'Długość kary w minutach. Powyżej 0.', required: true },
    by: { type: 'number', description: 'Id serwera funkcjonariusza, dla skryptów więzienia, które zapisują, kto to zrobił.', default: '0' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt więzienia przyjął gracza. `false`, gdy `minutes` nie jest powyżej 0, `source` nie jest liczbą, nie działa żaden skrypt więzienia albo odmówił.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("jail", {
  help: "Jails a player",
  params: [{ name: "id", type: "playerId" }, { name: "minutes", type: "number" }],
  restricted: "ai.job.police",
}, (source, args) => {
  if (core.GetDutyJob(source) !== "police") return;
  core.JailPlayer(args.id, args.minutes, source);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('jail', {
  help = 'Jails a player',
  params = { { name = 'id', type = 'playerId' }, { name = 'minutes', type = 'number' } },
  restricted = 'ai.job.police',
}, function(source, args)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return end
  exports['ai-core']:JailPlayer(args.id, args.minutes, source)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Zapisz odpowiedni wpis MDT przez [`AddMdtRecord`](/pl/docs/developers/api/core-server/mdt) (`kind: "jail"`), gdy serwer używa MDT.
</Callout>

### ReleasePlayer

Wypuszcza gracza z więzienia.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`prison.release`](/pl/docs/developers/api/lib-server/jobs#prisonrelease)

```ts title="Sygnatura"
ReleasePlayer(source: number): boolean
```

```lua title="Lua"
local released = exports['ai-core']:ReleasePlayer(target)
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera więźnia.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt więzienia zwolnił gracza. `false`, gdy skrypt więzienia go nie zwolnił (na przykład nie był w więzieniu), `source` nie jest liczbą albo nie działa żaden skrypt więzienia.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("unjail", { help: "Releases a player", params: [{ name: "id", type: "playerId" }], restricted: true }, (_source, args) => {
  console.log(core.ReleasePlayer(args.id) ? "released" : "not in prison");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('unjail', { help = 'Releases a player', params = { { name = 'id', type = 'playerId' } }, restricted = true }, function(_, args)
  print(exports['ai-core']:ReleasePlayer(args.id) and 'released' or 'not in prison')
end)
```
</Tab>
</Tabs>

### GetJailTime

Ile czasu gracz musi jeszcze odsiedzieć.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`prison.timeLeft`](/pl/docs/developers/api/lib-server/jobs#prisontimeleft)

```ts title="Sygnatura"
GetJailTime(source: number): number
```

```lua title="Lua"
local minutes = exports['ai-core']:GetJailTime(source)
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },
  }}
/>

#### Zwraca

`number`: pozostałe minuty. `0`, gdy gracz nie jest w więzieniu, `source` nie jest liczbą albo nie działa żaden skrypt więzienia.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Więźniowie nie mogą używać budki telefonicznej.
onClientCallback("myscript:phoneBooth", (source) =>
  core.GetJailTime(source) > 0 ? fail("IN_PRISON") : { ok: true },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:phoneBooth', function(source)
  if exports['ai-core']:GetJailTime(source) > 0 then return aiLib.fail('IN_PRISON') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
