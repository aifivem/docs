title: Teléfono

icon: Smartphone
---

Las llamadas de teléfono pasan por ai-core, nunca por los exports propios de un script de teléfono. ai-core reenvía cada llamada al **primer script de teléfono en marcha** (tgiann-phone, lb-phone, gksphone y los demás de la lista de compatibilidad). Mientras no hay ningún teléfono en marcha, cada llamada responde `null` o `false`.

### GetPhoneNumber

El número de teléfono de un jugador.

**Lado:** Servidor · **Espera:** no · **Lib:** [`phone.number`](/es/docs/developers/api/lib-server/phone-appearance#phonenumber)

```ts title="Firma"
GetPhoneNumber(source: number): string | null
```

```lua title="Lua"
local number = exports['ai-core']:GetPhoneNumber(source) -- string o nil
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador.', required: true },
  }}
/>

#### Devuelve

`string | null`: el número tal como lo escribe el script de teléfono. `null` cuando el jugador no tiene, no hay ningún teléfono en marcha o `source` no es un número.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Un objeto de tarjeta de visita muestra el número del dueño.
onClientCallback("myscript:myNumber", (source) => {
  const number = core.GetPhoneNumber(source);
  return number ? { ok: true, number } : fail("NO_PHONE_NUMBER");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myNumber', function(source)
  local number = exports['ai-core']:GetPhoneNumber(source)
  if not number then return aiLib.fail('NO_PHONE_NUMBER') end
  return { ok = true, number = number }
end)
```
</Tab>
</Tabs>

### GetSourceByPhone

El jugador conectado que tiene un número de teléfono.

**Lado:** Servidor · **Espera:** no · **Lib:** [`phone.sourceOf`](/es/docs/developers/api/lib-server/phone-appearance#phonesourceof)

```ts title="Firma"
GetSourceByPhone(number: string): number | null
```

```lua title="Lua"
local src = exports['ai-core']:GetSourceByPhone('5551234') -- number o nil
```

#### Parámetros

<TypeTable
  type={{
    number: { type: 'string', description: 'El número de teléfono, escrito como lo escribe el script de teléfono.', required: true },
  }}
/>

#### Devuelve

`number | null`: el id de servidor. `null` cuando el dueño de ese número no está conectado, el número es desconocido, no hay ningún teléfono en marcha o `number` no es un texto.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { notify, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** A taxi job tells the caller their cab is on the way, if they are online. */
export function cabOnTheWay(callerNumber: string): void {
  const caller = core.GetSourceByPhone(callerNumber);
  if (caller !== null) notify(caller, Locale("NOTIFY_CAB_COMING"), "info");
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function CabOnTheWay(callerNumber)
  local caller = exports['ai-core']:GetSourceByPhone(callerNumber)
  if caller then aiLib.notify(caller, Locale('NOTIFY_CAB_COMING'), 'info') end
end
```
</Tab>
</Tabs>

### HasPhone

Si un jugador tiene un teléfono (en los scripts de teléfono que necesitan un objeto de teléfono, si lleva uno).

**Lado:** Servidor · **Espera:** no · **Lib:** [`phone.hasPhone`](/es/docs/developers/api/lib-server/phone-appearance#phonehasphone)

```ts title="Firma"
HasPhone(source: number): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasPhone(source)
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de teléfono dice que el jugador tiene teléfono. `false` cuando no, cuando no hay ningún teléfono en marcha o `source` no es un número.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Un trabajo que reparte tareas por mensaje de texto necesita un teléfono.
onClientCallback("myscript:startDeliveries", (source) =>
  core.HasPhone(source) ? { ok: true } : fail("NEED_PHONE"),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:startDeliveries', function(source)
  if not exports['ai-core']:HasPhone(source) then return aiLib.fail('NEED_PHONE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SendPhoneMail

Envía un correo al teléfono de un jugador.

**Lado:** Servidor · **Espera:** no · **Lib:** [`phone.mail`](/es/docs/developers/api/lib-server/phone-appearance#phonemail)

```ts title="Firma"
SendPhoneMail(to: number | string, mail: PhoneMail): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMail(source, { sender = 'LS Customs', subject = 'Invoice', message = '...' })
```

#### Parámetros

<TypeTable
  type={{
    to: { type: 'number | string', description: 'Un id de servidor de jugador (se busca su número) o un número de teléfono / la dirección de correo del teléfono.', required: true },
    mail: { type: 'PhoneMail', description: 'El correo. Campos abajo.', required: true },
  }}
/>

#### PhoneMail

<TypeTable
  type={{
    sender: { type: 'string', description: 'Se muestra como remitente (una empresa, `Los Santos Customs`).', default: '""' },
    subject: { type: 'string', description: 'Línea de asunto. Se corta a 120 caracteres.', required: true },
    message: { type: 'string', description: 'El texto. Se corta a 4000 caracteres.', required: true },
  }}
/>

Los textos se muestran tal cual: pasa textos traducidos. Consulta [PhoneMail](/es/docs/developers/api/types#phonemail).

#### Devuelve

`boolean`: `true` cuando el script de teléfono aceptó el correo. `false` cuando el jugador no tiene número, falta `subject` o `message`, no hay ningún teléfono en marcha o lo rechazó.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The heist contact mails the location after the job was accepted. */
export function mailHeistLocation(source: number, street: string): void {
  core.SendPhoneMail(source, {
    sender: Locale("MAIL_CONTACT"),
    subject: Locale("MAIL_HEIST_SUBJECT"),
    message: Locale("MAIL_HEIST_BODY", street),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function MailHeistLocation(source, street)
  exports['ai-core']:SendPhoneMail(source, {
    sender = Locale('MAIL_CONTACT'),
    subject = Locale('MAIL_HEIST_SUBJECT'),
    message = Locale('MAIL_HEIST_BODY', street),
  })
end
```
</Tab>
</Tabs>

### SendPhoneMessage

Envía un mensaje de texto desde un número a un jugador o a un número.

**Lado:** Servidor · **Espera:** no · **Lib:** [`phone.message`](/es/docs/developers/api/lib-server/phone-appearance#phonemessage)

```ts title="Firma"
SendPhoneMessage(from: string, to: number | string, text: string): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMessage('Dispatch', source, 'Your cab is here.')
```

#### Parámetros

<TypeTable
  type={{
    from: { type: 'string', description: 'El número o el nombre del remitente, tal como lo acepta el script de teléfono.', required: true },
    to: { type: 'number | string', description: 'Un id de servidor de jugador (se busca su número) o un número de teléfono.', required: true },
    text: { type: 'string', description: 'El mensaje, ya traducido. Se corta a 1000 caracteres.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de teléfono aceptó el mensaje. `false` cuando el destinatario no tiene número, `from` o `text` no es un texto, no hay ningún teléfono en marcha o lo rechazó.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The next delivery address arrives by text. */
export function textNextStop(source: number, street: string): void {
  if (!core.SendPhoneMessage(Locale("SENDER_DISPATCH"), source, Locale("TEXT_NEXT_STOP", street)))
    console.log(`player ${source} could not get the text`);
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TextNextStop(source, street)
  if not exports['ai-core']:SendPhoneMessage(Locale('SENDER_DISPATCH'), source, Locale('TEXT_NEXT_STOP', street)) then
    print(('player %d could not get the text'):format(source))
  end
end
```
</Tab>
</Tabs>

### PhoneNotify

Muestra una notificación en el teléfono de un jugador.

**Lado:** Servidor · **Espera:** no · **Lib:** [`phone.notify`](/es/docs/developers/api/lib-server/phone-appearance#phonenotify)

```ts title="Firma"
PhoneNotify(source: number, notification: PhoneNotification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:PhoneNotify(source, { title = 'Bank', message = 'Salary paid', app = 'bank' })
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador.', required: true },
    notification: { type: 'PhoneNotification', description: 'Qué mostrar. Campos abajo.', required: true },
  }}
/>

#### PhoneNotification

<TypeTable
  type={{
    title: { type: 'string', description: 'Línea de título. Se corta a 80 caracteres.', required: true },
    message: { type: 'string', description: 'El texto. Se corta a 500 caracteres.', default: '""' },
    app: { type: 'string', description: 'Id de la app del teléfono a la que pertenece cuando el teléfono la conoce (`messages`, `mail`, `bank`).' },
  }}
/>

Consulta [PhoneNotification](/es/docs/developers/api/types#phonenotification).

#### Devuelve

`boolean`: `true` cuando el script de teléfono la mostró. `false` cuando falta `title`, no hay ningún teléfono en marcha, `source` no es un número o lo rechazó.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Tells the owner their car was towed. */
export function towedNotice(source: number, plate: string): void {
  core.PhoneNotify(source, { title: Locale("PHONE_TOW_TITLE"), message: Locale("PHONE_TOW_TEXT", plate) });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TowedNotice(source, plate)
  exports['ai-core']:PhoneNotify(source, { title = Locale('PHONE_TOW_TITLE'), message = Locale('PHONE_TOW_TEXT', plate) })
end
```
</Tab>
</Tabs>
