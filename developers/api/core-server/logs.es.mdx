Cada recurso registra sus logs a través de ai-core. Tu recurso nombra un **canal** (`purchases`, `robberies`) y escribe un mensaje; ai-core decide adónde va. El dueño del servidor activa los proveedores en el panel de administración (consola, Discord, Fivemanage, FiveM Stats), fija el nivel mínimo y pega las urls de webhook de Discord por recurso y canal. Un recurso nunca publica en un webhook ni en un servicio de logs por sí mismo, y nunca guarda una url de webhook.

Pasa los jugadores implicados como `source` y `target` en lugar de escribir sus nombres en el mensaje: ai-core añade el nombre, el personaje, el citizen id y los identificadores de cada jugador (la IP solo cuando el panel lo permite).

### Log

Envía una entrada de log de tu recurso.

**Lado:** Servidor · **Espera:** no · **Lib:** [`aiLog(channel, message, options?)`](/es/docs/developers/api/lib-server/logs#ailog) (Lua: `aiLib.aiLog`; ambos imprimen en la consola mientras ai-core no está en marcha)

```ts title="Firma"
Log(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { price = 25000 } })
```

#### Parámetros

<TypeTable
  type={{
    channel: { type: 'string', description: 'Nombre del canal de tu recurso (`purchases`). El webhook y el interruptor de activado / desactivado son por canal. `log` cuando no es un texto.', required: true },
    message: { type: 'string', description: 'Lo que pasó, en inglés sencillo. Los demás valores se convierten en texto.', required: true },
    options: { type: 'LogOptions', description: 'Nivel, jugadores y valores extra. Campos abajo.' },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: 'Lo importante que es. Las entradas por debajo del nivel mínimo del panel se descartan.', default: '"info"' },
    source: { type: 'number', description: 'Id de servidor del jugador que lo hizo; se añaden su nombre, su personaje y sus identificadores.' },
    target: { type: 'number', description: 'Id de servidor del jugador al que se le hizo.' },
    metadata: { type: 'Record<string, unknown>', description: 'Valores extra (cantidades, nombres de objetos, coordenadas). Si no es una tabla: se ignora.' },
  }}
/>

Consulta [LogOptions](/es/docs/developers/api/types#logoptions) y [LogLevel](/es/docs/developers/api/types#loglevel).

#### Devuelve

Nada. La entrada se descarta sin aviso cuando su nivel está por debajo del mínimo del panel o su canal está desactivado con `LogChannels`.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:buyCar", { lock: true }, (source) => {
  const price = 25_000;
  if (!core.RemoveMoney(source, "bank", price, "car_purchase")) return fail("NOT_ENOUGH_MONEY");
  // ... crea y guarda el coche
  core.Log("purchases", "Bought a car", { source, metadata: { model: "sultan", price } });
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:buyCar', function(source)
  local price = 25000
  if not exports['ai-core']:RemoveMoney(source, 'bank', price, 'car_purchase') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  -- ... crea y guarda el coche
  exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { model = 'sultan', price = price } })
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Los logs son para el dueño del servidor, así que el mensaje se queda en inglés y no se traduce. Mantén el mensaje corto y pon los valores en `metadata`, donde los servicios de logs pueden filtrarlos.
</Callout>

### LogChannels

Describe los canales de tu recurso: su nombre de dataset para Fivemanage y FiveM Stats, y si cada uno está activado. Llámalo una vez cuando se inicie tu recurso. Los canales que nunca describes siguen funcionando con los valores por defecto.

**Lado:** Servidor · **Espera:** no · **Lib:** [`aiLogChannels(channels)`](/es/docs/developers/api/lib-server/logs#ailogchannels)

```ts title="Firma"
LogChannels(channels: Record<string, LogChannel>): void
```

```lua title="Lua"
exports['ai-core']:LogChannels({ purchases = { dataset = 'myscript-sales' }, debug = { active = false } })
```

#### Parámetros

<TypeTable
  type={{
    channels: { type: 'Record<string, LogChannel>', description: 'Nombre del canal a sus ajustes. Los campos de cada uno, abajo.', required: true },
  }}
/>

#### LogChannel

<TypeTable
  type={{
    dataset: { type: 'string', description: 'Nombre del dataset para Fivemanage y FiveM Stats.', default: 'el nombre del recurso' },
    active: { type: 'boolean', description: '`false` desactiva el canal: sus entradas se descartan.', default: 'true' },
  }}
/>

Consulta [LogChannel](/es/docs/developers/api/types#logchannel).

#### Devuelve

Nada. Una segunda llamada reemplaza la descripción completa de tu recurso. Se elimina cuando tu recurso se detiene. Un valor que no es una tabla no hace nada.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Una vez al iniciar.
core.LogChannels({
  purchases: { dataset: "myscript-sales" },
  robberies: { dataset: "myscript-crime" },
  debug: { active: false },
});
```
</Tab>
<Tab value="Lua">
```lua
exports['ai-core']:LogChannels({
  purchases = { dataset = 'myscript-sales' },
  robberies = { dataset = 'myscript-crime' },
  debug = { active = false },
})
```
</Tab>
</Tabs>

<Callout type="warn">
Las urls de webhook nunca van aquí ni en ninguna parte de tu recurso: el dueño del servidor las pone en el panel de ai-core, que las guarda en un archivo que no se comparte.
</Callout>
