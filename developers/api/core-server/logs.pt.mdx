Todo recurso registra logs pelo ai-core. Seu recurso nomeia um **canal** (`purchases`, `robberies`) e escreve uma mensagem; o ai-core decide para onde ela vai. O dono do servidor liga os provedores no painel de administração (console, Discord, Fivemanage, FiveM Stats), define o nível mínimo e cola as urls de webhook do Discord por recurso e canal. Um recurso nunca posta num webhook ou serviço de logs ele mesmo, e nunca guarda uma url de webhook.

Passe os jogadores envolvidos como `source` e `target` em vez de escrever os nomes deles na mensagem: o ai-core adiciona o nome, o personagem, o citizen id e os identificadores de cada jogador (o IP só quando o painel permite).

### Log

Envia uma entrada de log do seu recurso.

**Lado:** Servidor · **Espera:** não · **Lib:** [`aiLog(channel, message, options?)`](/pt/docs/developers/api/lib-server/logs#ailog) (Lua: `aiLib.aiLog`; os dois imprimem no console enquanto o ai-core não está rodando)

```ts title="Assinatura"
Log(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { price = 25000 } })
```

#### Parâmetros

<TypeTable
  type={{
    channel: { type: 'string', description: 'Nome do canal do seu recurso (`purchases`). O webhook e o interruptor de liga/desliga são por canal. `log` quando não é texto.', required: true },
    message: { type: 'string', description: 'O que aconteceu, em inglês simples. Outros valores são convertidos em texto.', required: true },
    options: { type: 'LogOptions', description: 'Nível, jogadores e valores extras. Campos abaixo.' },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: 'Quão importante é. Entradas abaixo do nível mínimo do painel são descartadas.', default: '"info"' },
    source: { type: 'number', description: 'Id de servidor do jogador que fez a ação; o nome, o personagem e os identificadores dele são adicionados.' },
    target: { type: 'number', description: 'Id de servidor do jogador que sofreu a ação.' },
    metadata: { type: 'Record<string, unknown>', description: 'Valores extras (quantias, nomes de itens, coordenadas). Se não for tabela: ignorado.' },
  }}
/>

Veja [LogOptions](/pt/docs/developers/api/types#logoptions) e [LogLevel](/pt/docs/developers/api/types#loglevel).

#### Retorno

Nada. A entrada é descartada sem aviso quando o nível dela está abaixo do mínimo do painel ou o canal dela está desligado com `LogChannels`.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:buyCar", { lock: true }, (source) => {
  const price = 25_000;
  if (!core.RemoveMoney(source, "bank", price, "car_purchase")) return fail("NOT_ENOUGH_MONEY");
  // ... cria e guarda o carro
  core.Log("purchases", "Bought a car", { source, metadata: { model: "sultan", price } });
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:buyCar', function(source)
  local price = 25000
  if not exports['ai-core']:RemoveMoney(source, 'bank', price, 'car_purchase') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  -- ... cria e guarda o carro
  exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { model = 'sultan', price = price } })
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Os logs são para o dono do servidor, então a mensagem fica em inglês e não é traduzida. Mantenha a mensagem curta e coloque os valores em `metadata`, onde os serviços de log conseguem filtrá-los.
</Callout>

### LogChannels

Descreve os canais do seu recurso: o nome do dataset para Fivemanage e FiveM Stats, e se cada um está ligado. Chame uma vez quando seu recurso inicia. Os canais que você nunca descreve continuam funcionando com os padrões.

**Lado:** Servidor · **Espera:** não · **Lib:** [`aiLogChannels(channels)`](/pt/docs/developers/api/lib-server/logs#ailogchannels)

```ts title="Assinatura"
LogChannels(channels: Record<string, LogChannel>): void
```

```lua title="Lua"
exports['ai-core']:LogChannels({ purchases = { dataset = 'myscript-sales' }, debug = { active = false } })
```

#### Parâmetros

<TypeTable
  type={{
    channels: { type: 'Record<string, LogChannel>', description: 'Nome do canal para as configurações dele. Os campos de cada um estão abaixo.', required: true },
  }}
/>

#### LogChannel

<TypeTable
  type={{
    dataset: { type: 'string', description: 'Nome do dataset para Fivemanage e FiveM Stats.', default: 'o nome do recurso' },
    active: { type: 'boolean', description: '`false` desliga o canal: as entradas dele são descartadas.', default: 'true' },
  }}
/>

Veja [LogChannel](/pt/docs/developers/api/types#logchannel).

#### Retorno

Nada. Uma segunda chamada substitui a descrição inteira do seu recurso. Ela é descartada quando seu recurso para. Um valor que não é tabela não faz nada.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Uma vez ao iniciar.
core.LogChannels({
  purchases: { dataset: "myscript-sales" },
  robberies: { dataset: "myscript-crime" },
  debug: { active: false },
});
```
</Tab>
<Tab value="Lua">
```lua
exports['ai-core']:LogChannels({
  purchases = { dataset = 'myscript-sales' },
  robberies = { dataset = 'myscript-crime' },
  debug = { active = false },
})
```
</Tab>
</Tabs>

<Callout type="warn">
As urls de webhook nunca vão aqui nem em lugar nenhum do seu recurso: o dono do servidor as define no painel do ai-core, que as guarda num arquivo que não é compartilhado.
</Callout>
