Bir **oyuncu**, server id’si (`source`) olan bağlı bir kişidir. Bir **karakter**, o oyuncunun oynadığı kişilerden biridir; bir veritabanı id’si (`charId`) ve bir citizen id’si (`citizenid`, `ABC12345` gibi kısa bir metin) vardır. Bir oyuncu karakter ekranında birini seçtikten sonra yüklü bir karaktere sahip olur. Buradaki export’ların çoğu ondan önce `null` cevabı verir.

Export çağrıları cevaplarını kopyalar; bu yüzden ihtiyacın olanı bir kez oku ve tekrar sormak yerine ai-core’un event’lerini izle (`ai-core:playerLoaded`, `ai-core:playerUnloaded`). Bkz. [Event’ler ve durum](/tr/docs/developers/api/events).

### GetPlayerData

ai-core’un yüklü bir oyuncu için tuttuğu her şey tek nesnede: karakter, para, meslekler, mesai, çeteler ve metadata. Bir resource geç başladığında ve bir oyuncunun tam durumuna bir kez ihtiyaç duyduğunda kullan; tek değerler için aşağıdaki daha küçük export’ları kullan.

**Taraf:** Server · **Bekler:** hayır · **Lib:** server’da yok (client lib’in `getPlayerData`’sı aynı veriyi oyuncunun oyununda okur)

```ts title="İmza"
GetPlayerData(src: number): AiPlayerData | null
```

```lua title="Lua"
local data = exports['ai-core']:GetPlayerData(source) -- tablo ya da nil
```

#### Parametreler

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
  }}
/>

#### Dönüş değeri

`AiPlayerData | null`: oyuncunun verisinin bir kopyası ([AiPlayerData](/tr/docs/developers/api/types#aiplayerdata)). O server id’sine sahip kimsenin yüklü karakteri yoksa (bağlı değil ya da hâlâ karakter ekranında) `null`. Kopya sonradan değişmez: yeni değerler için tekrar çağır ya da event’leri izle.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("whoami", { help: "Shows your character", restricted: true }, (source) => {
  const data = core.GetPlayerData(source);
  if (!data?.character) return;
  const { firstname, lastname } = data.character;
  console.log(`${firstname} ${lastname}: job ${data.job.job} (grade ${data.job.grade}), cash ${data.money.cash ?? 0}`);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('whoami', { help = 'Shows your character', restricted = true }, function(source)
  local data = exports['ai-core']:GetPlayerData(source)
  if not data or not data.character then return end
  print(('%s %s: job %s (grade %d), cash %d'):format(
    data.character.firstname, data.character.lastname,
    data.job.job, data.job.grade, data.money.cash or 0))
end)
```
</Tab>
</Tabs>

<Callout type="info">
Tüm nesne her çağrıda kopyalanır. Asla tüm oyuncular üzerinde bir döngüde ya da bir zamanlayıcıda çağırma: tek değerleri oku (`GetMoney`, `GetDutyJob`) ya da lib’in `online` aynasını kullan.
</Callout>

### GetCharacter

Bir oyuncunun yüklü karakteri: veritabanı id’si, citizen id, slot, adlar, doğum tarihi, cinsiyet ve uyruk. Bir ad göstermek ya da karakter id’sine göre bir şey saklamak için kullan.

**Taraf:** Server · **Bekler:** hayır · **Lib:** yok ([`online.character(source)`](/tr/docs/developers/api/lib-server/players#onlinecharacter) aynısını export çağrısı olmadan lib’in aynasından okur)

```ts title="İmza"
GetCharacter(src: number): CharacterInfo | null
```

```lua title="Lua"
local character = exports['ai-core']:GetCharacter(source) -- tablo ya da nil
```

#### Parametreler

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
  }}
/>

#### Dönüş değeri

`CharacterInfo | null`: karakter ([CharacterInfo](/tr/docs/developers/api/types#characterinfo)). Oyuncunun yüklü karakteri yoksa `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:profile", (source) => {
  const character = core.GetCharacter(source);
  if (!character) return fail("NO_CHARACTER");
  return { ok: true, name: `${character.firstname} ${character.lastname}`, citizenid: character.citizenid };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:profile', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return aiLib.fail('NO_CHARACTER') end
  return { ok = true, name = character.firstname .. ' ' .. character.lastname, citizenid = character.citizenid }
end)
```
</Tab>
</Tabs>

### GetSourceByCharId

Bir karakteri şu anda oynayan oyuncunun server id’si. Bir karakter id’si sakladığında (bir sahip, bir kişi) ve oyunda o kişiye ulaşman gerektiğinde kullan.

**Taraf:** Server · **Bekler:** hayır · **Lib:** yok

```ts title="İmza"
GetSourceByCharId(charId: number): number | null
```

```lua title="Lua"
local src = exports['ai-core']:GetSourceByCharId(charId) -- sayı ya da nil
```

#### Parametreler

<TypeTable
  type={{
    charId: { type: 'number', description: 'Karakterin veritabanı id’si (`CharacterInfo.id`).', required: true },
  }}
/>

#### Dönüş değeri

`number | null`: oyuncunun server id’si. Şu anda o karakteri kimse oynamıyorsa (çevrimdışı ya da başka bir karakter yüklü) `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

  const owner = core.GetSourceByCharId(ownerCharId);
  if (owner !== null) notify(owner, Locale("NOTIFY_DOORBELL"), "info");
}
```
</Tab>


</Tab>
</Tabs>

### GetLoadedSources

Yüklü karakteri olan her oyuncunun server id’leri. Seyrek, tüm sunucuyu kapsayan işler için kullan (bir restart uyarısı, bir admin listesi).

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`online.sources()`](/tr/docs/developers/api/lib-server/players#onlinesources) aynısını lib’in aynasından okur

```ts title="İmza"
GetLoadedSources(): number[]
```

```lua title="Lua"
local sources = exports['ai-core']:GetLoadedSources() -- sayı listesi
```

#### Parametreler

Yok.

#### Dönüş değeri

`number[]`: yüklü oyuncu başına bir server id, sabit bir sırası yok. Kimsenin karakteri yüklü değilse boş liste. Hâlâ karakter ekranındaki oyuncular içinde yoktur.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, notify, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

addCommand("announce", {
  help: "Sends a notification to every player",
  params: [{ name: "text", type: "longString" }],
  restricted: true,
}, (_source, args) => {
  for (const target of core.GetLoadedSources())
    notify(target, Locale("NOTIFY_ANNOUNCEMENT", args.text), "warning");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.addCommand('announce', {
  help = 'Sends a notification to every player',
  params = { { name = 'text', type = 'longString' } },
  restricted = true,
}, function(_, args)
  for _, target in ipairs(exports['ai-core']:GetLoadedSources()) do
    aiLib.notify(target, Locale('NOTIFY_ANNOUNCEMENT', args.text), 'warning')
  end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Bu listedeki her id için sık çalışan bir yolda asla başka bir export çağırma (her saniye `GetLoadedSources()` + oyuncu başına `GetDutyJob`). Kimin mesaide olduğu, birçok oyuncunun adları ve meslekleri lib’in `online` aynasından; kimin yakında olduğu `playersNear`’dan gelir.
</Callout>

### GetCharacterInfo

Veritabanı id’sine göre bir karakter, yüklü olsun olmasın, ait olduğu hesabın id’siyle. Kişi çevrimdışı olabilecekken bir şeyin kime ait olduğunu göstermek için kullan.

**Taraf:** Server · **Bekler:** hayır (`done` ile cevap verir) · **Lib:** yok

```ts title="İmza"
GetCharacterInfo(
  charId: number,
  done: (info: (CharacterInfo & { userId: number }) | null) => void,
): void
```

```lua title="Lua"
exports['ai-core']:GetCharacterInfo(charId, function(info) end) -- info: tablo ya da nil
```

#### Parametreler

<TypeTable
  type={{
    charId: { type: 'number', description: 'Karakterin veritabanı id’si.', required: true },
    done: { type: '(info) => void', description: 'Cevapla bir kez çağrılır. Yüklü ya da yakın zamanda okunmuş bir karakter için hemen, aksi halde bir veritabanı okumasından sonra.', required: true },
  }}
/>

#### Dönüş değeri

Hiçbir şey. `done` bir alanı fazla olan bir [CharacterInfo](/tr/docs/developers/api/types#characterinfo) alır, `userId` (hesap id’si); bilinmeyen ya da silinmiş bir karakter, yanlış bir id ya da başarısız bir okumada `null` alır. `done` olarak bir fonksiyon verilmezse çağrı hiçbir şey yapmaz.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("charinfo", {
  help: "Shows a character by id",
  params: [{ name: "charId", type: "number" }],
  restricted: true,
}, (_source, args) => {
  core.GetCharacterInfo(args.charId, (info) => {
    if (!info) return console.log("no such character");
    console.log(`${info.firstname} ${info.lastname} (${info.citizenid}), account ${info.userId}`);
  });
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('charinfo', {
  help = 'Shows a character by id',
  params = { { name = 'charId', type = 'number' } },
  restricted = true,
}, function(_, args)
  exports['ai-core']:GetCharacterInfo(args.charId, function(info)
    if not info then return print('no such character') end
    print(('%s %s (%s), account %d'):format(info.firstname, info.lastname, info.citizenid, info.userId))
  end)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Kayıtlı bir karakter okunduktan sonra 5 dakika tutulur; bu yüzden admin panelinde değiştirilen bir ad o süre boyunca eski değeri gösterebilir. Yüklü bir karakter her zaman bellekten cevap verir.
</Callout>

### SwitchCharacter

Bir oyuncuyu sunucudan çıkmadan, çıkış yapar gibi karakter ekranına geri gönderir. ai-core önce karakteri kaydeder ve kaldırır, sonra ekranı açar.

**Taraf:** Server · **Bekler:** hayır (kaldırma çağrı döndükten sonra çalışır) · **Lib:** yok

```ts title="İmza"
SwitchCharacter(src: number): boolean
```

```lua title="Lua"
local started = exports['ai-core']:SwitchCharacter(source) -- boolean
```

#### Parametreler

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: değişim başladığında `true`. Oyuncunun yüklü karakteri yoksa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Menündeki bir "Karakter değiştir" düğmesi.
onClientCallback("myscript:logout", (source) =>
  core.SwitchCharacter(source) ? { ok: true } : fail("NO_CHARACTER"),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:logout', function(source)
  if exports['ai-core']:SwitchCharacter(source) then return { ok = true } end
  return aiLib.fail('NO_CHARACTER')
end)
```
</Tab>
</Tabs>

<Callout type="info">
Karakter gittiğinde resource’un `"switch"` sebebiyle `ai-core:playerUnloaded` event’ini duyar. Karakter başına durumu bu çağrının hemen ardından değil, orada temizle.
</Callout>

### SetOfflinePosition

Yüklü olmayan bir karakterin doğma noktasını taşır: o karakter bir sonraki seçildiğinde orada görünür. Bir şey uyuyan bir bedeni ya da çevrimdışı bir karakteri taşıdığında kullan (taşınıp götürülen bir beden, çekilen bir oyuncu).

**Taraf:** Server · **Bekler:** hayır (yazma arka planda gelir) · **Lib:** [`characters.setOfflinePosition`](/tr/docs/developers/api/lib-server/world#characterssetofflineposition)

```ts title="İmza"
SetOfflinePosition(
  charId: number,
  position: { x: number; y: number; z: number; heading?: number },
): boolean
```

```lua title="Lua"
local accepted = exports['ai-core']:SetOfflinePosition(charId, { x = x, y = y, z = z, heading = h })
```

#### Parametreler

<TypeTable
  type={{
    charId: { type: 'number', description: 'Karakterin veritabanı id’si. Bir tam sayı.', required: true },
    position: { type: '{ x, y, z, heading? }', description: 'Dünya koordinatlarında (metre) yeni doğma noktası. `heading` derece cinsinden.', required: true, typeDescription: '{ x: number; y: number; z: number; heading?: number }' },
  }}
/>

#### Dönüş değeri

`boolean`: taşıma kabul edildiğinde `true`; veritabanı yazması o karakterin hiçbir yüklemesi ya da kaydı çalışmadığında gelir (en fazla 30 saniye bekler). Karakter şu an yüklüyse, `charId` bir tam sayı değilse ya da bir koordinat eksik veya sonlu bir sayı değilse `false`. Eksik bir `heading` 0 olarak saklanır.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");
const HOSPITAL = { x: 298.6, y: -584.5, z: 43.3, heading: 70 };

/** Dünyada çok uzun kalan bir beden hastaneye taşınır. */
export function sendBodyToHospital(charId: number): void {
  if (!core.SetOfflinePosition(charId, HOSPITAL))
    console.log(`character ${charId} is online, not moved`);
}
```
</Tab>
<Tab value="Lua">
```lua
local HOSPITAL = { x = 298.6, y = -584.5, z = 43.3, heading = 70.0 }

function SendBodyToHospital(charId)
  if not exports['ai-core']:SetOfflinePosition(charId, HOSPITAL) then
    print(('character %d is online, not moved'):format(charId))
  end
end
```
</Tab>
</Tabs>

<Callout type="warn">
Yazma beklerken karakter yüklenirse yazma atlanır: yüklü bir karakterin ped’i gerçekten olduğu yerdedir.
</Callout>

### GetPlayersInScope

Başka bir oyuncunun OneSync kapsamındaki oyuncular: oyunu o an o oyuncuyu stream eden herkes, çevresinde yaklaşık 424 metre. ai-core bu listeyi FiveM’in scope event’lerinden her resource için bir kez tutar, böylece diğer resource’lar o event’leri asla kendileri dinlemez.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`playersNear(source, radius)`](/tr/docs/developers/api/lib-server/players#playersnear) ve [`playersNearEntity(entity, radius)`](/tr/docs/developers/api/lib-server/players#playersnearentity) bunun üstüne kurulur ve mesafeye göre süzer

```ts title="İmza"
GetPlayersInScope(source: number): number[]
```

```lua title="Lua"
local nearby = exports['ai-core']:GetPlayersInScope(source) -- server id listesi
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Ortadaki oyuncunun server id’si.', required: true },
  }}
/>

#### Dönüş değeri

`number[]`: kapsamdaki diğer oyuncuların server id’leri (oyuncunun kendisi listede yoktur). Yalnız bir oyuncu, bilinmeyen bir id ya da sayı olmayan bir değer için boş liste.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { coordsOf, resourceExport } from "@aicore-fivem/lib/server";
import { distance } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

/** Bir oyuncunun 30 m çevresindeki herkese bir ses çalar. */
export function playNear(source: number, sound: string): void {
  const at = coordsOf(source);
  for (const other of [source, ...core.GetPlayersInScope(source)])
    if (distance(coordsOf(other), at) <= 30) emitNet("myscript:sound", other, sound);
}
```
</Tab>
<Tab value="Lua">

```lua
  local at = GetEntityCoords(GetPlayerPed(source))
  local targets = exports['ai-core']:GetPlayersInScope(source)
  targets[#targets + 1] = source
  for _, other in ipairs(targets) do
    if #(GetEntityCoords(GetPlayerPed(other)) - at) <= 30.0 then
      TriggerClientEvent('myscript:sound', other, sound)
    end
  end
end
```
