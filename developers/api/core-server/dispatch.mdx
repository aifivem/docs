---
title: Dispatch
description: Send police (or any job) alerts through whichever alert system the server runs.
icon: Siren
---

Police alerts go through ai-core, never through an alert script's own exports or events (ai-policealert included). ai-core forwards each alert to the **active alert system**: the one the panel's **Alert script** setting picks, or the first one running (ai-policealert's built-in cards come last). The alert system shows it to the on-duty members of the alert's jobs.

ai-core also answers QB's `police:server:policeAlert` event for alert systems that do not, so QB scripts' alerts arrive too.

### SendDispatchAlert

Sends one alert. Use it for anything officers (or another job) should respond to: shots fired, a store robbery, a stolen car.

**Side:** Server · **Waits:** no · **Lib:** [`dispatch.alert`](/docs/developers/api/lib-server/jobs#dispatchalert)

```ts title="Signature"
SendDispatchAlert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendDispatchAlert({ title = 'Store robbery', code = '10-90', source = source })
```

#### DispatchAlert

<TypeTable
  type={{
    title: { type: 'string', description: 'The headline (`Shots fired`), already translated. Cut to 80 characters.', required: true },
    code: { type: 'string', description: 'Radio code shown before the title (`10-71`). Cut to 12 characters.' },
    message: { type: 'string', description: 'One more line (the shop name). Cut to 160 characters.' },
    coords: { type: '{ x, y, z }', description: 'Where it happened. Without it the `source` player position is used; without both the alert has no map point.', typeDescription: '{ x: number; y: number; z: number }' },
    jobs: { type: 'string[]', description: 'Jobs whose on-duty members get it. At most 10 names of up to 32 characters.', default: 'the alert system police jobs' },
    source: { type: 'number', description: 'Server id of the player the alert is about (shooter, robber). Alert systems that describe the suspect (vehicle, sex) read this player. Ignored when not online.' },
    blip: { type: '{ sprite, color?, scale? }', description: 'Map blip: a GTA blip sprite number, colour number and scale (0.1 to 3).', default: 'the alert system blip', typeDescription: '{ sprite: number; color?: number; scale?: number }' },
    duration: { type: 'number', description: 'Seconds the alert stays (card, blip, waypoint key). 1 to 3600.', default: 'the alert system own' },
    icon: { type: 'string', description: 'Font Awesome solid icon name without `fa-` (`gun`).' },
    priority: { type: '"normal" | "high"', description: '`high` makes the card stand out (armed robbery, officer down).', default: '"normal"' },
  }}
/>

Unknown fields are dropped. See [DispatchAlert](/docs/developers/api/types#dispatchalert).

#### Returns

`boolean`: `true` when the alert system took the alert. `false` when `title` is missing or empty, no alert system runs, or it failed.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const REGISTER = { x: 24.5, y: -1345.6, z: 29.5 };

onClientCallback("myscript:robRegister", { guards: [near(REGISTER, 2)], lock: true }, (source) => {
  if (core.GetOnDutyCount("police") < 2) return fail("NOT_ENOUGH_POLICE");
  core.SendDispatchAlert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: Locale("ALERT_STORE_NAME"),
    coords: REGISTER,
    source,
    jobs: ["police"],
    icon: "cash-register",
    priority: "high",
  });
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local REGISTER = vector3(24.5, -1345.6, 29.5)

aiLib.onClientCallback('myscript:robRegister', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - REGISTER) > 2.0 then return aiLib.fail('TOO_FAR') end
  if exports['ai-core']:GetOnDutyCount('police') < 2 then return aiLib.fail('NOT_ENOUGH_POLICE') end
  exports['ai-core']:SendDispatchAlert({
    code = '10-90',
    title = Locale('ALERT_STORE_ROBBERY'),
    message = Locale('ALERT_STORE_NAME'),
    coords = { x = REGISTER.x, y = REGISTER.y, z = REGISTER.z },
    source = source,
    jobs = { 'police' },
    icon = 'cash-register',
    priority = 'high',
  })
  return { ok = true }
end, { lock = true })
```

<Callout type="warn">
Texts are shown as given: translate them with `Locale` before sending. Do not send an alert on every frame or every hit: an alert for shots fired should have a cooldown per player.
</Callout>
