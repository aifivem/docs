---
title: Hora e clima
description: Leia e defina o clima e a hora do jogo, o blackout e a hora congelada, pelo script de clima que o servidor roda.
icon: CloudSun
---

Hora e clima passam pelo ai-core, nunca pelos exports ou eventos próprios de um script de clima. O ai-core encaminha cada chamada ao **primeiro script de clima que estiver rodando**: Renewed-Weathersync, av_weather, cd_easytime e depois qb-weathersync (o ai-weathersync responde sob esse nome). Todos seguem o contrato do qb-weathersync. Enquanto nenhum está rodando, cada chamada responde `null` ou `false`.

Para pausar a sincronização no jogo de um jogador (um interior com luz própria, uma cutscene), use o lado cliente (`PauseWorldSync`, `world.pauseSync` da lib); veja [Exports de cliente](/pt/docs/developers/api/core-client).

### GetWeather

O tipo de clima atual.

**Lado:** Servidor · **Espera:** não · **Lib:** [`world.getWeather`](/pt/docs/developers/api/lib-server/world#worldgetweather)

```ts title="Assinatura"
GetWeather(): string | null
```

```lua title="Lua"
local weather = exports['ai-core']:GetWeather() -- 'EXTRASUNNY', 'RAIN'... ou nil
```

#### Parâmetros

Nenhum.

#### Retorno

`string | null`: o tipo de clima em maiúsculas (`EXTRASUNNY`, `CLEAR`, `RAIN`, `THUNDER`...). `null` quando nenhum script de clima está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Street races pay more in the rain. */
export function raceBonus(): number {
  const weather = core.GetWeather();
  return weather === "RAIN" || weather === "THUNDER" ? 1.25 : 1;
}
```
</Tab>
<Tab value="Lua">
```lua
function RaceBonus()
  local weather = exports['ai-core']:GetWeather()
  if weather == 'RAIN' or weather == 'THUNDER' then return 1.25 end
  return 1.0
end
```
</Tab>
</Tabs>

### SetWeather

Define o clima para todos.

**Lado:** Servidor · **Espera:** não · **Lib:** [`world.setWeather`](/pt/docs/developers/api/lib-server/world#worldsetweather) (recebe os nomes tipados de `Weather`)

```ts title="Assinatura"
SetWeather(type: string): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetWeather('RAIN')
```

#### Parâmetros

<TypeTable
  type={{
    type: { type: 'string', description: 'Um tipo de clima do contrato do qb-weathersync: `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Passado para maiúsculas antes de ser enviado.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o script de clima o aceitou. `false` quando `type` não é texto, o script o recusou (um tipo desconhecido) ou nenhum script de clima está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";
import { isWeather } from "@aifivem/shared";

const core = resourceExport("ai-core");

addCommand("weather", { help: "Sets the weather", params: [{ name: "type", type: "string" }], restricted: true }, (_source, args) => {
  const type = args.type.toUpperCase();
  if (!isWeather(type)) return console.log("unknown weather type");
  core.SetWeather(type);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { help = 'Sets the weather', params = { { name = 'type', type = 'string' } }, restricted = true }, function(_, args)
  if not exports['ai-core']:SetWeather(args.type) then print('weather refused') end
end)
```
</Tab>
</Tabs>

### GetTime

A hora do jogo (o relógio dentro do jogo).

**Lado:** Servidor · **Espera:** não · **Lib:** [`world.getTime`](/pt/docs/developers/api/lib-server/world#worldgettime)

```ts title="Assinatura"
GetTime(): { hour: number; minute: number } | null
```

```lua title="Lua"
local time = exports['ai-core']:GetTime() -- { hour, minute } ou nil
```

#### Parâmetros

Nenhum.

#### Retorno

`{ hour, minute } | null`: hora 0-23 e minuto 0-59. `null` quando nenhum script de clima está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// O traficante só vende à noite (22:00 - 05:59 no horário do jogo).
onClientCallback("myscript:dealer", (source) => {
  const time = core.GetTime();
  const night = time !== null && (time.hour >= 22 || time.hour < 6);
  return night ? { ok: true } : fail("COME_BACK_AT_NIGHT");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:dealer', function(source)
  local time = exports['ai-core']:GetTime()
  if not time or (time.hour < 22 and time.hour >= 6) then return aiLib.fail('COME_BACK_AT_NIGHT') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SetTime

Define a hora do jogo para todos.

**Lado:** Servidor · **Espera:** não · **Lib:** [`world.setTime`](/pt/docs/developers/api/lib-server/world#worldsettime)

```ts title="Assinatura"
SetTime(hour: number, minute?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetTime(12, 0)
```

#### Parâmetros

<TypeTable
  type={{
    hour: { type: 'number', description: 'Hora, 0-23. Arredondada para baixo e com volta (24 vira 0).', required: true },
    minute: { type: 'number', description: 'Minuto, 0-59. Arredondado para baixo e com volta.', default: '0' },
  }}
/>

#### Retorno

`boolean`: `true` quando o script de clima a aceitou. `false` quando `hour` não é um número, o script recusou ou nenhum script de clima está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("noon", { help: "Sets the time to 12:00", restricted: true }, () => {
  core.SetTime(12, 0);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('noon', { help = 'Sets the time to 12:00', restricted = true }, function()
  exports['ai-core']:SetTime(12, 0)
end)
```
</Tab>
</Tabs>

### SetBlackout

Liga ou desliga o blackout da cidade (todas as luzes artificiais apagadas).

**Lado:** Servidor · **Espera:** não · **Lib:** [`world.setBlackout`](/pt/docs/developers/api/lib-server/world#worldsetblackout)

```ts title="Assinatura"
SetBlackout(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetBlackout(true)
```

#### Parâmetros

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` liga o blackout. Qualquer coisa diferente de `true` o desliga.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o script de clima o aceitou. `false` quando o script não tem blackout, recusou ou nenhum script de clima está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The power plant was sabotaged: 5 minutes of darkness. */
export function sabotagePowerPlant(): void {
  if (!core.SetBlackout(true)) return;
  setTimeout(() => core.SetBlackout(false), 5 * 60_000);
}
```
</Tab>
<Tab value="Lua">
```lua
function SabotagePowerPlant()
  if not exports['ai-core']:SetBlackout(true) then return end
  SetTimeout(5 * 60000, function() exports['ai-core']:SetBlackout(false) end)
end
```
</Tab>
</Tabs>

### FreezeTime

Para ou reinicia o relógio do jogo.

**Lado:** Servidor · **Espera:** não · **Lib:** [`world.freezeTime`](/pt/docs/developers/api/lib-server/world#worldfreezetime)

```ts title="Assinatura"
FreezeTime(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:FreezeTime(true)
```

#### Parâmetros

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` congela o relógio. Qualquer coisa diferente de `true` o deixa correr.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o script de clima o aceitou. `false` quando o script não consegue congelar a hora, recusou ou nenhum script de clima está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Uma noite de evento: sempre 21:00.
addCommand("eventnight", { help: "Freezes the clock at 21:00", restricted: true }, () => {
  core.SetTime(21, 0);
  core.FreezeTime(true);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('eventnight', { help = 'Freezes the clock at 21:00', restricted = true }, function()
  exports['ai-core']:SetTime(21, 0)
  exports['ai-core']:FreezeTime(true)
end)
```
</Tab>
</Tabs>
