---
title: Prisão
description: Prenda jogadores, solte-os e leia o tempo restante, pelo script de prisão que o servidor roda.
icon: Lock
---

As chamadas de prisão passam pelo ai-core, nunca pelos exports ou eventos próprios de um script de prisão (ai-prison incluído). O ai-core encaminha cada chamada ao **primeiro script de prisão que estiver rodando**: ai-prison, qb-prison, rcore_prison, xt-prison e depois tgiann-policejob. Enquanto nenhum está rodando, cada chamada responde `false` ou `0`.

### JailPlayer

Manda um jogador para a prisão por alguns minutos.

**Lado:** Servidor · **Espera:** não · **Lib:** [`prison.jail`](/pt/docs/developers/api/lib-server/jobs#prisonjail)

```ts title="Assinatura"
JailPlayer(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local jailed = exports['ai-core']:JailPlayer(target, 20, source)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do jogador a prender.', required: true },
    minutes: { type: 'number', description: 'Duração da pena em minutos. Acima de 0.', required: true },
    by: { type: 'number', description: 'Id de servidor do policial, para scripts de prisão que registram quem fez.', default: '0' },
  }}
/>

#### Retorno

`boolean`: `true` quando o script de prisão recebeu o jogador. `false` quando `minutes` não está acima de 0, `source` não é um número, nenhum script de prisão está rodando ou ele recusou.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("jail", {
  help: "Jails a player",
  params: [{ name: "id", type: "playerId" }, { name: "minutes", type: "number" }],
  restricted: "ai.job.police",
}, (source, args) => {
  if (core.GetDutyJob(source) !== "police") return;
  core.JailPlayer(args.id, args.minutes, source);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('jail', {
  help = 'Jails a player',
  params = { { name = 'id', type = 'playerId' }, { name = 'minutes', type = 'number' } },
  restricted = 'ai.job.police',
}, function(source, args)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return end
  exports['ai-core']:JailPlayer(args.id, args.minutes, source)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Escreva o registro correspondente no MDT com [`AddMdtRecord`](/pt/docs/developers/api/core-server/mdt) (`kind: "jail"`) quando o servidor roda um MDT.
</Callout>

### ReleasePlayer

Solta um jogador da prisão.

**Lado:** Servidor · **Espera:** não · **Lib:** [`prison.release`](/pt/docs/developers/api/lib-server/jobs#prisonrelease)

```ts title="Assinatura"
ReleasePlayer(source: number): boolean
```

```lua title="Lua"
local released = exports['ai-core']:ReleasePlayer(target)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do prisioneiro.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o script de prisão soltou o jogador. `false` quando o script de prisão não o soltou (por exemplo, ele não estava preso), `source` não é um número ou nenhum script de prisão está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("unjail", { help: "Releases a player", params: [{ name: "id", type: "playerId" }], restricted: true }, (_source, args) => {
  console.log(core.ReleasePlayer(args.id) ? "released" : "not in prison");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('unjail', { help = 'Releases a player', params = { { name = 'id', type = 'playerId' } }, restricted = true }, function(_, args)
  print(exports['ai-core']:ReleasePlayer(args.id) and 'released' or 'not in prison')
end)
```
</Tab>
</Tabs>

### GetJailTime

Quanto tempo um jogador ainda precisa cumprir.

**Lado:** Servidor · **Espera:** não · **Lib:** [`prison.timeLeft`](/pt/docs/developers/api/lib-server/jobs#prisontimeleft)

```ts title="Assinatura"
GetJailTime(source: number): number
```

```lua title="Lua"
local minutes = exports['ai-core']:GetJailTime(source)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do jogador.', required: true },
  }}
/>

#### Retorno

`number`: minutos restantes. `0` quando o jogador não está preso, `source` não é um número ou nenhum script de prisão está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Prisioneiros não podem usar o orelhão.
onClientCallback("myscript:phoneBooth", (source) =>
  core.GetJailTime(source) > 0 ? fail("IN_PRISON") : { ok: true },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:phoneBooth', function(source)
  if exports['ai-core']:GetJailTime(source) > 0 then return aiLib.fail('IN_PRISON') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
