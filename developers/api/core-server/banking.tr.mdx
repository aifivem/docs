Banka katmanı **aktif banka script’ine** ulaşır: panelin **Banking script** ayarının seçtiği ya da çalışan ilk script. O script’in ekranını açar ve şirket bakiyelerini bildirir. Meslek ve çete parasının kendisi her zaman ai-core’un para export’ları üzerinden hareket eder ([Para ve hesaplar](/tr/docs/developers/api/core-server/money)), asla bir banka script’i üzerinden değil.

Meslek ve çete hesaplarının banka script’iyle ilişkisi panelin **Job and gang accounts** ayarına bağlıdır:

- **ai-core's accounts** (varsayılan): parayı ai-core tutar; banka script’i aynı bakiyeyi gösterir ve onun ekranında hareket eden para ai-core’da da hareket eder.
- **The script's own accounts**: parayı banka script’i tutar; ai-core’un meslek ve çete `bank` hesapları script’in hesaplarını okur ve değiştirir.

### GetBankingSystem

ai-core’un kullandığı banka script’inin resource adı.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`banking.provider()`](/tr/docs/developers/api/lib-server/money#bankingprovider)

```ts title="İmza"
GetBankingSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetBankingSystem() -- string ya da nil
```

#### Parametreler

Yok.

#### Dönüş değeri

`string | null`: banka script’inin resource adı. Hiçbiri çalışmıyorsa `null` (meslek parası o zaman yalnızca ai-core’da kalır).

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("bankingsystem", { help: "Shows the banking script in use", restricted: true }, () => {
  console.log(core.GetBankingSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('bankingsystem', { help = 'Shows the banking script in use', restricted = true }, function()
  print(exports['ai-core']:GetBankingSystem() or 'none')
end)
```
</Tab>
</Tabs>

### OpenBank

Bir oyuncu için banka script’inin ekranını açar. Kendi ATM’inden ya da banka gişenden kullan.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`banking.open`](/tr/docs/developers/api/lib-server/money#bankingopen)

```ts title="İmza"
OpenBank(source: number): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenBank(source)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si. Yüklü bir karakteri olmalıdır.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: ekran açıldığında `true`. Oyuncunun yüklü karakteri yoksa, hiçbir banka script’i çalışmıyorsa ya da ekranı başka bir script’ten açılamıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const COUNTER = { x: 149.9, y: -1040.5, z: 29.4 };

onClientCallback("myscript:bankCounter", { guards: [near(COUNTER, 2)] }, (source) =>
  core.OpenBank(source) ? { ok: true } : fail("BANK_UNAVAILABLE"),
);
```
</Tab>
<Tab value="Lua">
```lua
local COUNTER = vector3(149.9, -1040.5, 29.4)

aiLib.onClientCallback('myscript:bankCounter', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - COUNTER) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenBank(source) then return aiLib.fail('BANK_UNAVAILABLE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### GetBankSocietyBalance

Banka kurulumunun gösterdiği haliyle bir mesleğin şirket bakiyesi: **ai-core's accounts** ile ai-core’un meslek `bank` hesabı, **The script's own accounts** ile script’in kendi hesabı. Gösterim için kullan (bir patron menüsü); meslek parasını hareket ettirmek için para export’larını kullan.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`banking.societyBalance`](/tr/docs/developers/api/lib-server/money#bankingsocietybalance)

```ts title="İmza"
GetBankSocietyBalance(job: string): number | null
```

```lua title="Lua"
local balance = exports['ai-core']:GetBankSocietyBalance('police') -- sayı ya da nil
```

#### Parametreler

<TypeTable
  type={{
    job: { type: 'string', description: 'Meslek adı.', required: true },
  }}
/>

#### Dönüş değeri

`number | null`: bakiye. Hiçbir banka script’i çalışmıyorsa, mesleğin hesabı yoksa (bilinmeyen meslek ya da script onun için hesap tutmuyor) ya da `job` metin değilse `null`. Banka script’i yokken meslek hesabını `GetSharedMoney("job", job, "bank")` ile oku.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Banka script’i olsun olmasın patron menüsü bakiyesi. */
export function societyBalance(job: string): number {
  return core.GetBankSocietyBalance(job) ?? core.GetSharedMoney("job", job, "bank") ?? 0;
}
```
</Tab>
<Tab value="Lua">
```lua
function SocietyBalance(job)
  return exports['ai-core']:GetBankSocietyBalance(job)
    or exports['ai-core']:GetSharedMoney('job', job, 'bank')
    or 0
end
```
</Tab>
</Tabs>
