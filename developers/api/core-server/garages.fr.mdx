title: Garages
description: Mettre en fourrière et ranger des véhicules, ouvrir un menu de garage et lister les véhicules garés d’un joueur via le script de garages qu’utilise le serveur.

Les appels de garages passent par ai-core, jamais par les exports ou événements propres à un script de garages (ai-garages compris). ai-core transmet chaque appel au **script de garages actif** : celui que choisit le réglage **Garage script** du panneau, ou le premier qui tourne (ai-garages, jg-advancedgarages, tgiann-realparking et les autres de la liste de compatibilité). Chaque script ne répond qu’aux actions qu’il possède vraiment, si bien qu’une action peut répondre `false` ou `null` avec un script et fonctionner avec un autre.

Un véhicule est un **handle d’entité serveur**.

### GetGarageSystem

Le nom de ressource du script de garages auquel ai-core transmet.

**Côté :** Serveur · **Attend :** non · **Lib :** [`garages.provider()`](/fr/docs/developers/api/lib-server/vehicles#garagesprovider)

```ts title="Signature"
GetGarageSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetGarageSystem() -- string ou nil
```

#### Paramètres

Aucun.

#### Retour

`string | null` : le nom de ressource du script de garages. `null` quand aucun ne tourne.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("garagesystem", { help: "Shows the garage script in use", restricted: true }, () => {
  console.log(core.GetGarageSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('garagesystem', { help = 'Shows the garage script in use', restricted = true }, function()
  print(exports['ai-core']:GetGarageSystem() or 'none')
end)
```
</Tab>
</Tabs>

### ImpoundVehicle

Envoie à la fourrière un véhicule présent dans le monde. Avec les scripts de garages qui n’ont qu’un formulaire de fourrière sur l’écran du joueur, il ouvre plutôt ce formulaire pour le joueur `by`.

**Côté :** Serveur · **Attend :** non · **Lib :** [`garages.impound`](/fr/docs/developers/api/lib-server/vehicles#garagesimpound)

```ts title="Signature"
ImpoundVehicle(vehicle: number, by?: number): boolean
```

```lua title="Lua"
local taken = exports['ai-core']:ImpoundVehicle(vehicle, source)
```

#### Paramètres

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Handle d’entité serveur du véhicule.', required: true },
    by: { type: 'number', description: 'Id serveur du joueur qui le met en fourrière (un agent). Nécessaire aux scripts avec formulaire de fourrière ; ignoré quand il n’est pas en ligne.' },
  }}
/>

#### Retour

`boolean` : `true` quand le script de garages a pris le véhicule en charge (ou ouvert son formulaire). `false` quand rien ne l’a pris : aucun script de garages ne tourne, il n’a pas de fourrière, le véhicule n’est pas un véhicule qu’il connaît, ou `vehicle` n’est pas un véhicule existant. Avec `false`, le véhicule est toujours dans le monde : supprimez-le vous-même s’il doit partir.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aicore-fivem/lib/server";
import { fail, oneArg, readId } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:impound", { args: oneArg(readId) }, (source, netId) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  const vehicle = vehicleNearPlayer(source, netId, { metres: 5 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.ImpoundVehicle(vehicle, source)) DeleteEntity(vehicle);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:impound', function(source, netId)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 5 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:ImpoundVehicle(vehicle, source) then DeleteEntity(vehicle) end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### StoreVehicleInGarage

Range un véhicule présent dans le monde dans un garage, avec son état.

**Côté :** Serveur · **Attend :** non · **Lib :** [`garages.store`](/fr/docs/developers/api/lib-server/vehicles#garagesstore)

```ts title="Signature"
StoreVehicleInGarage(vehicle: number, garage?: string | null, by?: number): boolean
```

```lua title="Lua"
local stored = exports['ai-core']:StoreVehicleInGarage(vehicle, 'legion', source)
```

#### Paramètres

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Handle d’entité serveur du véhicule.', required: true },
    garage: { type: 'string | null', description: 'L’id de garage du script de garages. `null` ou omis : le script choisit.', default: 'null' },
    by: { type: 'number', description: 'Id serveur du joueur qui le range. Les scripts avec API client agissent sur le jeu de ce joueur ; ignoré quand il n’est pas en ligne.' },
  }}
/>

#### Retour

`boolean` : `true` quand le script de garages a pris le véhicule. `false` quand rien ne l’a pris (aucun script de garages, pas d’action de rangement, garage inconnu, un véhicule que le script ne possède pas) ou que `vehicle` n’est pas un véhicule existant.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleOf } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Un voiturier range la voiture que conduit le joueur dans le garage le plus proche.
onClientCallback("myscript:valetStore", (source) => {
  const vehicle = vehicleOf(source, { driver: true });
  if (!vehicle) return fail("NOT_DRIVING");
  return core.StoreVehicleInGarage(vehicle, null, source) ? { ok: true } : fail("STORE_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:valetStore', function(source)
  local ped = GetPlayerPed(source)
  local vehicle = GetVehiclePedIsIn(ped, false)
  if vehicle == 0 or GetPedInVehicleSeat(vehicle, -1) ~= ped then return aiLib.fail('NOT_DRIVING') end
  if not exports['ai-core']:StoreVehicleInGarage(vehicle, nil, source) then return aiLib.fail('STORE_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### OpenGarage

Ouvre le menu de garage du script de garages actif pour un joueur.

**Côté :** Serveur · **Attend :** non · **Lib :** [`garages.open`](/fr/docs/developers/api/lib-server/vehicles#garagesopen)

```ts title="Signature"
OpenGarage(source: number, garage?: string | null): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenGarage(source, 'legion')
```

#### Paramètres

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serveur du joueur.', required: true },
    garage: { type: 'string | null', description: 'L’id de garage du script de garages. `null` ou omis : la valeur par défaut du script.', default: 'null' },
  }}
/>

#### Retour

`boolean` : `true` quand le menu s’est ouvert. `false` quand le joueur n’est pas en ligne, qu’aucun script de garages ne tourne ou qu’il n’a pas de menu ouvrable depuis l’extérieur.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const MOTEL_GARAGE = { x: 273.1, y: -343.9, z: 44.9 };

onClientCallback("myscript:motelGarage", { guards: [near(MOTEL_GARAGE, 3)] }, (source) =>
  core.OpenGarage(source, "motel") ? { ok: true } : fail("GARAGE_FAILED"),
);
```
</Tab>
<Tab value="Lua">
```lua
local MOTEL_GARAGE = vector3(273.1, -343.9, 44.9)

aiLib.onClientCallback('myscript:motelGarage', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - MOTEL_GARAGE) > 3.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenGarage(source, 'motel') then return aiLib.fail('GARAGE_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### GetGaragedVehicles

Les véhicules d’un joueur gardés par le script de garages : dans un garage ou à la fourrière.

**Côté :** Serveur · **Attend :** non (répond via `done`) · **Lib :** [`garages.stored(source)`](/fr/docs/developers/api/lib-server/vehicles#garagesstored) renvoie une Promise

```ts title="Signature"
GetGaragedVehicles(source: number, done: (vehicles: GaragedVehicle[] | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetGaragedVehicles(source, function(vehicles) end) -- liste ou nil
```

#### Paramètres

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serveur du joueur.', required: true },
    done: { type: '(vehicles) => void', description: 'Appelé une fois avec la réponse, après la réponse du script de garages.', required: true, typeDescription: '(vehicles: GaragedVehicle[] | null) => void' },
  }}
/>

#### Retour

Rien. `done` reçoit une entrée par véhicule avec `plate`, `model` (ou `null`), `garage` (ou `null`) et `impounded` ([GaragedVehicle](/fr/docs/developers/api/types#garagedvehicle)), ou `null` quand le joueur n’est pas en ligne, qu’aucun script de garages ne tourne, qu’il ne sait pas lister les véhicules ou qu’il a échoué. Sans fonction comme `done`, l’appel ne fait rien.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import type { GaragedVehicle } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Le guichet de la fourrière liste les voitures du joueur mises en fourrière.
onClientCallback("myscript:impoundList", async (source) => {
  const list = await new Promise<GaragedVehicle[] | null>((resolve) => core.GetGaragedVehicles(source, resolve));
  if (!list) return fail("GARAGE_UNKNOWN");
  return { ok: true, plates: list.filter((v) => v.impounded).map((v) => v.plate) };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:impoundList', function(source)
  local p = promise.new()
  exports['ai-core']:GetGaragedVehicles(source, function(list) p:resolve(list or false) end)
  local list = Citizen.Await(p)
  if not list then return aiLib.fail('GARAGE_UNKNOWN') end
  local plates = {}
  for _, v in ipairs(list) do
    if v.impounded then plates[#plates + 1] = v.plate end
  end
  return { ok = true, plates = plates }
end)
```
</Tab>
</Tabs>
