title: MDT

Akten laufen über ai-core, nie über die eigenen Exports oder Events eines MDT. ai-core leitet jede Akte an das **aktive MDT** weiter: das, das die Panel-Einstellung **MDT script** (MDT-Skript) wählt, oder das erste, das läuft. Es gibt kein ai-*-MDT, deshalb werden **Akten nirgends geschrieben, solange kein MDT läuft**. Den MDT-Bildschirm zu öffnen passiert auf dem Client (Client-Export `OpenMdt`, Lib `mdt.open`).

### GetMdtSystem

Der Ressourcenname des MDT, an das ai-core weiterleitet.

**Seite:** Server · **Wartet:** nein · **Lib:** [`mdt.provider()`](/de/docs/developers/api/lib-server/jobs#mdtprovider)

```ts title="Signature"
GetMdtSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetMdtSystem() -- String oder nil
```

#### Parameter

Keine.

#### Rückgabe

`string | null`: der Ressourcenname des MDT. `null`, wenn keines läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("mdtsystem", { help: "Shows the MDT in use", restricted: true }, () => {
  console.log(core.GetMdtSystem() ?? "none: records are not written");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('mdtsystem', { help = 'Shows the MDT in use', restricted = true }, function()
  print(exports['ai-core']:GetMdtSystem() or 'none: records are not written')
end)
```
</Tab>
</Tabs>

### AddMdtRecord

Schreibt eine Akte über einen Spieler in das MDT: ein Bußgeld, einen Haftbefehl, eine Festnahme oder eine Haftstrafe. ai-core ergänzt die Citizen-IDs und Namen des Ziels und des Beamten.

**Seite:** Server · **Wartet:** nein · **Lib:** [`mdt.record`](/de/docs/developers/api/lib-server/jobs#mdtrecord)

```ts title="Signature"
AddMdtRecord(record: MdtRecord): boolean
```

```lua title="Lua"
local written = exports['ai-core']:AddMdtRecord({ kind = 'fine', target = target, by = source, title = 'Speeding', amount = 250 })
```

#### Parameter

<TypeTable
  type={{
    record: { type: 'MdtRecord', description: 'Die Akte. Felder unten.', required: true },
  }}
/>

#### MdtRecord

<TypeTable
  type={{
    kind: { type: '"fine" | "warrant" | "arrest" | "jail"', description: 'Worum es in der Akte geht.', required: true },
    target: { type: 'number', description: 'Server-ID des Spielers, um den es in der Akte geht. Muss einen geladenen Charakter haben.', required: true },
    by: { type: 'number', description: 'Server-ID des Beamten, der sie schreibt.' },
    title: { type: 'string', description: 'Was passiert ist (`Speeding`, `Armed robbery`), bereits übersetzt. Auf 120 Zeichen gekürzt.', required: true },
    amount: { type: 'number', description: 'Ein Bußgeldbetrag in Dollar. Eine ganze Zahl von 1 bis 10.000.000; sonst ignoriert.' },
    minutes: { type: 'number', description: 'Eine Haftstrafe in Minuten. Eine ganze Zahl von 1 bis 100.000; sonst ignoriert.' },
  }}
/>

Siehe [MdtRecord](/de/docs/developers/api/types#mdtrecord) und [MdtRecordKind](/de/docs/developers/api/types#mdtrecordkind).

#### Rückgabe

`boolean`: `true`, wenn das MDT sie geschrieben hat. `false`, wenn die Akte ungültig ist (falsches `kind`, kein `title`, `target` keine positive ganze Zahl), das Ziel keinen geladenen Charakter hat, kein MDT läuft oder das MDT keine Akten von Skripten annimmt oder diese Art nicht kennt.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail, readId } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");

// Ein Beamter sperrt einen Spieler für 20 Minuten ein; das MDT hält die Akte fest.
onClientCallback(
  "myscript:jail",
  { args: ([target]) => { const id = readId(target); return id === null ? null : [id]; }, lock: true },
  (source, target) => {
    if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
    if (!core.JailPlayer(target, 20, source)) return fail("JAIL_FAILED");
    core.AddMdtRecord({ kind: "jail", target, by: source, title: Locale("RECORD_ROBBERY"), minutes: 20 });
    return { ok: true };
  },
);
```
</Tab>
<Tab value="Lua">

```lua
local Locale = aiLib.locale()

aiLib.onClientCallback('myscript:jail', function(source, target)
  if math.type(target) ~= 'integer' or target < 1 then return aiLib.fail('BAD_TARGET') end
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  if not exports['ai-core']:JailPlayer(target, 20, source) then return aiLib.fail('JAIL_FAILED') end
  exports['ai-core']:AddMdtRecord({ kind = 'jail', target = target, by = source, title = Locale('RECORD_ROBBERY'), minutes = 20 })
  return { ok = true }
end, { lock = true })
```
