title: Aussehen

Das Aussehen läuft über ai-core, nie über die eigenen Exports, Events oder Tabellen eines Kleidungs-Skripts (ai-appearance eingeschlossen). ai-core liest es aus dem **aktiven Kleidungs-Skript**: dem, das die Panel-Einstellung **Clothing script** (Kleidungs-Skript) wählt, oder dem ersten, das läuft. Ein Aussehen auf einen Ped zu legen passiert auf dem Client (Client-Export `ApplyAppearance`, Lib `appearance.apply`); siehe [Client-Exports](/de/docs/developers/api/core-client).

Ein Aussehen ist ein [CharacterAppearance](/de/docs/developers/api/types#characterappearance): `{ model, data }`. `model` ist der Hash des Ped-Modells; `data` ist das eigene Format des Kleidungs-Skripts. Behandle `data` als verschlossene Kiste: Gib es unverändert an `ApplyAppearance` zurück.

### GetAppearanceSystem

Der Ressourcenname des Kleidungs-Skripts, aus dem ai-core das Aussehen liest.

**Seite:** Server · **Wartet:** nein · **Lib:** [`appearance.provider()`](/de/docs/developers/api/lib-server/phone-appearance#appearanceprovider)

```ts title="Signature"
GetAppearanceSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetAppearanceSystem() -- String oder nil
```

#### Parameter

Keine.

#### Rückgabe

`string | null`: der Ressourcenname des Kleidungs-Skripts. `null`, wenn keines läuft (Peds tragen dann Standardkleidung).

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("clothingsystem", { help: "Shows the clothing script in use", restricted: true }, () => {
  console.log(core.GetAppearanceSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('clothingsystem', { help = 'Shows the clothing script in use', restricted = true }, function()
  print(exports['ai-core']:GetAppearanceSystem() or 'none')
end)
```
</Tab>
</Tabs>

### GetCharacterAppearance

Das gespeicherte Aussehen eines Charakters, ob der Charakter geladen ist oder nicht. Nutze es, um einen Ped als diesen Charakter anzuziehen: einen schlafenden Körper, eine Statue, ein Foto, eine Vorschau.

**Seite:** Server · **Wartet:** nein (antwortet über `done`) · **Lib:** [`appearance.get(charId)`](/de/docs/developers/api/lib-server/phone-appearance#appearanceget) gibt ein Promise zurück

```ts title="Signature"
GetCharacterAppearance(charId: number, done: (look: CharacterAppearance | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetCharacterAppearance(charId, function(look) end) -- look: Tabelle oder nil
```

#### Parameter

<TypeTable
  type={{
    charId: { type: 'number', description: 'Datenbank-ID des Charakters. Eine positive ganze Zahl.', required: true },
    done: { type: '(look) => void', description: 'Wird einmal mit dem Aussehen aufgerufen, nachdem das Kleidungs-Skript geantwortet hat.', required: true, typeDescription: '(look: CharacterAppearance | null) => void' },
  }}
/>

#### Rückgabe

Nichts. `done` erhält `{ model, data }` oder `null`, wenn der Charakter kein gespeichertes Aussehen hat, kein Kleidungs-Skript läuft, `charId` keine positive ganze Zahl ist oder das Kleidungs-Skript fehlgeschlagen ist (geloggt). Ohne eine Funktion als `done` tut der Aufruf nichts.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import type { CharacterAppearance } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Der Client fragt nach dem eigenen Aussehen des Spielers, um einen Fotokabinen-Ped anzuziehen.
onClientCallback("myscript:myLook", async (source) => {
  const charId = online.charId(source);
  if (charId === undefined) return fail("NO_CHARACTER");
  const look = await new Promise<CharacterAppearance | null>((resolve) => core.GetCharacterAppearance(charId, resolve));
  return look ? { ok: true, look } : fail("NO_LOOK");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return aiLib.fail('NO_CHARACTER') end
  local p = promise.new()
  exports['ai-core']:GetCharacterAppearance(character.id, function(look) p:resolve(look or false) end)
  local look = Citizen.Await(p)
  if not look then return aiLib.fail('NO_LOOK') end
  return { ok = true, look = look }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Ein Aussehen kann einige Kilobyte groß sein. Sende es an den einen Spieler, der es braucht, nie an alle (`-1`).
</Callout>
