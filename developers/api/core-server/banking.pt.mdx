A camada de banco alcança o **script de banco ativo**: o que a configuração **Banking script** do painel escolhe, ou o primeiro que estiver rodando. Ela abre a tela desse script e informa os saldos das sociedades. O dinheiro de empregos e gangues em si sempre se move pelos exports de dinheiro do ai-core ([Dinheiro e contas](/pt/docs/developers/api/core-server/money)), nunca por um script de banco.

Como as contas de empregos e gangues se relacionam com o script de banco depende da configuração **Job and gang accounts** do painel:

- **ai-core's accounts** (contas do ai-core, o padrão): o ai-core guarda o dinheiro; o script de banco mostra o mesmo saldo, e o dinheiro movido na tela dele é movido no ai-core também.
- **The script's own accounts** (contas próprias do script): o script de banco guarda o dinheiro; as contas `bank` de empregos e gangues do ai-core leem e alteram as contas do script.

### GetBankingSystem

O nome do recurso do script de banco que o ai-core usa.

**Lado:** Servidor · **Espera:** não · **Lib:** [`banking.provider()`](/pt/docs/developers/api/lib-server/money#bankingprovider)

```ts title="Assinatura"
GetBankingSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetBankingSystem() -- string ou nil
```

#### Parâmetros

Nenhum.

#### Retorno

`string | null`: o nome do recurso do script de banco. `null` quando nenhum está rodando (o dinheiro dos empregos então fica só no ai-core).

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("bankingsystem", { help: "Shows the banking script in use", restricted: true }, () => {
  console.log(core.GetBankingSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('bankingsystem', { help = 'Shows the banking script in use', restricted = true }, function()
  print(exports['ai-core']:GetBankingSystem() or 'none')
end)
```
</Tab>
</Tabs>

### OpenBank

Abre a tela do script de banco para um jogador. Use a partir do seu próprio caixa eletrônico ou balcão de banco.

**Lado:** Servidor · **Espera:** não · **Lib:** [`banking.open`](/pt/docs/developers/api/lib-server/money#bankingopen)

```ts title="Assinatura"
OpenBank(source: number): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenBank(source)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do jogador. Precisa ter um personagem carregado.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando a tela abriu. `false` quando o jogador não tem personagem carregado, nenhum script de banco está rodando ou a tela dele não pode ser aberta por outro script.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const COUNTER = { x: 149.9, y: -1040.5, z: 29.4 };

onClientCallback("myscript:bankCounter", { guards: [near(COUNTER, 2)] }, (source) =>
  core.OpenBank(source) ? { ok: true } : fail("BANK_UNAVAILABLE"),
);
```
</Tab>
<Tab value="Lua">
```lua
local COUNTER = vector3(149.9, -1040.5, 29.4)

aiLib.onClientCallback('myscript:bankCounter', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - COUNTER) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenBank(source) then return aiLib.fail('BANK_UNAVAILABLE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### GetBankSocietyBalance

O saldo da sociedade de um emprego como a configuração de banco o mostra: a conta `bank` do emprego no ai-core com **ai-core's accounts**, a conta própria do script com **The script's own accounts**. Use para exibição (um menu de chefe); para mover dinheiro do emprego use os exports de dinheiro.

**Lado:** Servidor · **Espera:** não · **Lib:** [`banking.societyBalance`](/pt/docs/developers/api/lib-server/money#bankingsocietybalance)

```ts title="Assinatura"
GetBankSocietyBalance(job: string): number | null
```

```lua title="Lua"
local balance = exports['ai-core']:GetBankSocietyBalance('police') -- number ou nil
```

#### Parâmetros

<TypeTable
  type={{
    job: { type: 'string', description: 'Nome do emprego.', required: true },
  }}
/>

#### Retorno

`number | null`: o saldo. `null` quando nenhum script de banco está rodando, o emprego não tem conta (emprego desconhecido, ou o script não guarda nenhuma para ele) ou `job` não é texto. Sem um script de banco, leia a conta do emprego com `GetSharedMoney("job", job, "bank")`.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** The boss menu balance, with or without a banking script. */
export function societyBalance(job: string): number {
  return core.GetBankSocietyBalance(job) ?? core.GetSharedMoney("job", job, "bank") ?? 0;
}
```
</Tab>
<Tab value="Lua">
```lua
function SocietyBalance(job)
  return exports['ai-core']:GetBankSocietyBalance(job)
    or exports['ai-core']:GetSharedMoney('job', job, 'bank')
    or 0
end
```
</Tab>
</Tabs>
