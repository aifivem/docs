---
title: Fechaduras de portas
description: Tranque, destranque e leia portas pelo script de fechaduras que o servidor roda.
icon: DoorClosed
---

As chamadas de portas passam pelo ai-core, nunca pelos exports ou eventos próprios de um script de fechaduras (ai-doorlock incluído). O ai-core encaminha cada chamada ao **script de fechaduras ativo**: o que a configuração **Door lock script** do painel escolhe, ou o primeiro que estiver rodando (ai-doorlock, ox_doorlock, tgiann-doorlock e os outros da lista de compatibilidade).

Uma porta é identificada pelo **id de porta do próprio script**: o id que você vê na lista de portas dele (ai-doorlock: o id da porta no painel de administração; ox_doorlock: o número dela no banco de dados).

### GetDoorlockSystem

O nome do recurso do script de fechaduras para o qual o ai-core encaminha.

**Lado:** Servidor · **Espera:** não · **Lib:** [`doors.provider()`](/pt/docs/developers/api/lib-server/world#doorsprovider)

```ts title="Assinatura"
GetDoorlockSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetDoorlockSystem() -- string ou nil
```

#### Parâmetros

Nenhum.

#### Retorno

`string | null`: o nome do recurso do script de fechaduras. `null` quando nenhum está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Os ids de porta na sua config pertencem a um script de fechaduras: avise quando outro estiver rodando.
if (core.GetDoorlockSystem() !== "ai-doorlock")
  console.log("myscript: door ids are written for ai-doorlock");
```
</Tab>
<Tab value="Lua">
```lua
if exports['ai-core']:GetDoorlockSystem() ~= 'ai-doorlock' then
  print('myscript: door ids are written for ai-doorlock')
end
```
</Tab>
</Tabs>

### SetDoorLocked

Tranca ou destranca uma porta.

**Lado:** Servidor · **Espera:** não · **Lib:** [`doors.setLocked`](/pt/docs/developers/api/lib-server/world#doorssetlocked)

```ts title="Assinatura"
SetDoorLocked(id: string, locked: boolean, by?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDoorLocked('pacific_vault', false, source)
```

#### Parâmetros

<TypeTable
  type={{
    id: { type: 'string', description: 'O id de porta do script de fechaduras. Um número inteiro (ids do ox_doorlock) é convertido em texto. No máximo 128 caracteres.', required: true },
    locked: { type: 'boolean', description: '`true` tranca, `false` destranca. Precisa ser um boolean de verdade.', required: true },
    by: { type: 'number', description: 'Id de servidor do jogador que faz a ação. Scripts de fechaduras sem API de servidor precisam de um jogador cujo jogo leve a mudança; ignorado quando esse jogador não está online.' },
  }}
/>

#### Retorno

`boolean`: `true` quando o script de fechaduras aceitou a mudança. `false` quando nenhum script de fechaduras está rodando, a porta é desconhecida, o script recusou, `id` está vazio ou `locked` não é boolean.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, progressFor, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const VAULT = { x: 253.9, y: 225.2, z: 101.9 };

onClientCallback("myscript:hackVault", { guards: [near(VAULT, 2)], lock: true }, async (source) => {
  if (!core.HasItem(source, "laptop")) return fail("NO_LAPTOP");
  if (!(await progressFor(source, { label: Locale("HACKING"), duration: 15000 }))) return fail("CANCELLED");
  return core.SetDoorLocked("pacific_vault", false, source) ? { ok: true } : fail("DOOR_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local VAULT = vector3(253.9, 225.2, 101.9)

aiLib.onClientCallback('myscript:hackVault', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - VAULT) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:HasItem(source, 'laptop') then return aiLib.fail('NO_LAPTOP') end
  if not aiLib.progressFor(source, { label = Locale('HACKING'), duration = 15000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:SetDoorLocked('pacific_vault', false, source) then return aiLib.fail('DOOR_FAILED') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### IsDoorLocked

Se uma porta está trancada.

**Lado:** Servidor · **Espera:** não · **Lib:** [`doors.isLocked`](/pt/docs/developers/api/lib-server/world#doorsislocked)

```ts title="Assinatura"
IsDoorLocked(id: string): boolean | null
```

```lua title="Lua"
local locked = exports['ai-core']:IsDoorLocked('pacific_vault') -- true, false ou nil
```

#### Parâmetros

<TypeTable
  type={{
    id: { type: 'string', description: 'O id de porta do script de fechaduras (um número inteiro é convertido em texto).', required: true },
  }}
/>

#### Retorno

`boolean | null`: `true` trancada, `false` destrancada. `null` quando é desconhecido: nenhum script de fechaduras está rodando, a porta não existe, o script não consegue dizer no servidor ou `id` está vazio.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** The heist may start only while the vault is still closed. */
export function vaultClosed(): boolean {
  return core.IsDoorLocked("pacific_vault") !== false;
}
```
</Tab>
<Tab value="Lua">
```lua
function VaultClosed()
  return exports['ai-core']:IsDoorLocked('pacific_vault') ~= false
end
```
</Tab>
</Tabs>

<Callout type="info">
Decida o que `null` significa para o seu recurso. O exemplo trata "desconhecido" como fechado, então a falta de um script de fechaduras nunca abre o assalto antes da hora.
</Callout>
