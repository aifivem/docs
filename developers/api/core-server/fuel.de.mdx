---
title: Kraftstoff
description: Den Tankstand eines Fahrzeugs lesen und setzen, über das Tank-Skript, das der Server nutzt.
icon: Fuel
---

Kraftstoff läuft über ai-core, nie über die eigenen Exports, Decorators oder State Bags eines Tank-Skripts (ai-fuel eingeschlossen). ai-core leitet jeden Aufruf an das **aktive Tank-Skript** weiter: das, das die Panel-Einstellung **Fuel script** (Tank-Skript) wählt, oder das erste, das läuft (ai-fuel, ox_fuel, LegacyFuel und die anderen aus der Kompatibilitätsliste). Ohne Tank-Skript ist der Stand einfach die State Bag `fuel` des Fahrzeugs.

Ein Stand ist eine Zahl von **0 (leer) bis 100 (voll)**. Ein Fahrzeug ist ein **Server-Entity-Handle**.

### GetFuelSystem

Der Ressourcenname des Tank-Skripts, an das ai-core weiterleitet.

**Seite:** Server · **Wartet:** nein · **Lib:** [`fuel.provider()`](/de/docs/developers/api/lib-server/vehicles#fuelprovider)

```ts title="Signature"
GetFuelSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetFuelSystem() -- 'ai-fuel', 'ox_fuel'... oder nil
```

#### Parameter

Keine.

#### Rückgabe

`string | null`: der Ressourcenname des Tank-Skripts. `null`, wenn keines läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("fuelsystem", { help: "Shows the fuel script in use", restricted: true }, () => {
  console.log(core.GetFuelSystem() ?? "none: fuel is only the state bag");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('fuelsystem', { help = 'Shows the fuel script in use', restricted = true }, function()
  print(exports['ai-core']:GetFuelSystem() or 'none: fuel is only the state bag')
end)
```
</Tab>
</Tabs>

### GetVehicleFuel

Der Tankstand eines Fahrzeugs.

**Seite:** Server · **Wartet:** nein · **Lib:** [`fuel.get`](/de/docs/developers/api/lib-server/vehicles#fuelget) (Server); auf dem Client liest `fuel.get(vehicle)` der Client-Lib die State Bag, die ai-core führt

```ts title="Signature"
GetVehicleFuel(vehicle: number): number | null
```

```lua title="Lua"
local level = exports['ai-core']:GetVehicleFuel(vehicle) -- 0-100 oder nil
```

#### Parameter

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Server-Entity-Handle eines Fahrzeugs.', required: true },
  }}
/>

#### Rückgabe

`number | null`: der Stand, 0-100. `null`, wenn das Fahrzeug noch keinen Stand hat oder `vehicle` kein existierendes Fahrzeug ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aicore-fivem/lib/server";
import { fail, oneArg, readId } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Ein Mechaniker liest den Tank des Autos vor sich.
onClientCallback("myscript:checkTank", { args: oneArg(readId) }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 4 });
  if (!vehicle) return fail("TOO_FAR");
  return { ok: true, level: core.GetVehicleFuel(vehicle) };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:checkTank', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 4 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  return { ok = true, level = exports['ai-core']:GetVehicleFuel(vehicle) }
end)
```
</Tab>
</Tabs>

### SetVehicleFuel

Setzt den Tankstand eines Fahrzeugs.

**Seite:** Server · **Wartet:** nein · **Lib:** [`fuel.set`](/de/docs/developers/api/lib-server/vehicles#fuelset) (und [`spawnVehicle({ fuel })`](/de/docs/developers/api/lib-server/vehicles#spawnvehicle) setzt ihn beim Erstellen)

```ts title="Signature"
SetVehicleFuel(vehicle: number, level: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetVehicleFuel(vehicle, 100.0)
```

#### Parameter

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Server-Entity-Handle eines Fahrzeugs.', required: true },
    level: { type: 'number', description: 'Der neue Stand. Werte unter 0 werden zu 0, über 100 zu 100.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn der Stand an das Tank-Skript übergeben wurde (oder in die State Bag geschrieben, wenn keines läuft). `false`, wenn `vehicle` kein existierendes Fahrzeug ist, `level` keine endliche Zahl ist oder das Tank-Skript fehlgeschlagen ist.

Bei Tank-Skripten, die den Kraftstoff im Spiel der Spieler führen, erreicht der neue Stand das Fahrzeug einen Moment später über das Spiel seines Besitzers.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aicore-fivem/lib/server";
import { fail, oneArg, readId } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Ein Benzinkanister fügt dem Auto neben dem Spieler 25 % hinzu.
onClientCallback("myscript:jerryCan", { args: oneArg(readId), lock: true }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 3 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.RemoveItem(source, "jerrycan")) return fail("NO_JERRYCAN");
  core.SetVehicleFuel(vehicle, (core.GetVehicleFuel(vehicle) ?? 0) + 25);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:jerryCan', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 3 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:RemoveItem(source, 'jerrycan') then return aiLib.fail('NO_JERRYCAN') end
  local level = exports['ai-core']:GetVehicleFuel(vehicle) or 0
  exports['ai-core']:SetVehicleFuel(vehicle, level + 25)
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>
