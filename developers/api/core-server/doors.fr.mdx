---
title: Serrures de portes
description: Verrouiller, déverrouiller et lire des portes via le script de serrures qu’utilise le serveur.
icon: DoorClosed
---

Les appels de portes passent par ai-core, jamais par les exports ou événements propres à un script de serrures (ai-doorlock compris). ai-core transmet chaque appel au **script de serrures actif** : celui que choisit le réglage **Door lock script** du panneau, ou le premier qui tourne (ai-doorlock, ox_doorlock, tgiann-doorlock et les autres de la liste de compatibilité).

Une porte est désignée par **l’id de porte propre à ce script** : l’id que vous voyez dans sa liste de portes (ai-doorlock : l’id de la porte dans le panneau d’administration ; ox_doorlock : son numéro en base de données).

### GetDoorlockSystem

Le nom de ressource du script de serrures auquel ai-core transmet.

**Côté :** Serveur · **Attend :** non · **Lib :** [`doors.provider()`](/fr/docs/developers/api/lib-server/world#doorsprovider)

```ts title="Signature"
GetDoorlockSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetDoorlockSystem() -- string ou nil
```

#### Paramètres

Aucun.

#### Retour

`string | null` : le nom de ressource du script de serrures. `null` quand aucun ne tourne.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Les ids de portes de votre config appartiennent à un script de serrures : avertir quand un autre tourne.
if (core.GetDoorlockSystem() !== "ai-doorlock")
  console.log("myscript: door ids are written for ai-doorlock");
```
</Tab>
<Tab value="Lua">
```lua
if exports['ai-core']:GetDoorlockSystem() ~= 'ai-doorlock' then
  print('myscript: door ids are written for ai-doorlock')
end
```
</Tab>
</Tabs>

### SetDoorLocked

Verrouille ou déverrouille une porte.

**Côté :** Serveur · **Attend :** non · **Lib :** [`doors.setLocked`](/fr/docs/developers/api/lib-server/world#doorssetlocked)

```ts title="Signature"
SetDoorLocked(id: string, locked: boolean, by?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDoorLocked('pacific_vault', false, source)
```

#### Paramètres

<TypeTable
  type={{
    id: { type: 'string', description: 'L’id de porte du script de serrures. Un nombre entier (ids d’ox_doorlock) est converti en texte. 128 caractères au plus.', required: true },
    locked: { type: 'boolean', description: '`true` verrouille, `false` déverrouille. Doit être un vrai booléen.', required: true },
    by: { type: 'number', description: 'Id serveur du joueur qui le fait. Les scripts de serrures sans API serveur ont besoin d’un joueur dont le jeu porte le changement ; ignoré quand ce joueur n’est pas en ligne.' },
  }}
/>

#### Retour

`boolean` : `true` quand le script de serrures a accepté le changement. `false` quand aucun script de serrures ne tourne, que la porte est inconnue, que le script a refusé, que `id` est vide ou que `locked` n’est pas un booléen.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, progressFor, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const VAULT = { x: 253.9, y: 225.2, z: 101.9 };

onClientCallback("myscript:hackVault", { guards: [near(VAULT, 2)], lock: true }, async (source) => {
  if (!core.HasItem(source, "laptop")) return fail("NO_LAPTOP");
  if (!(await progressFor(source, { label: Locale("HACKING"), duration: 15000 }))) return fail("CANCELLED");
  return core.SetDoorLocked("pacific_vault", false, source) ? { ok: true } : fail("DOOR_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local VAULT = vector3(253.9, 225.2, 101.9)

aiLib.onClientCallback('myscript:hackVault', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - VAULT) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:HasItem(source, 'laptop') then return aiLib.fail('NO_LAPTOP') end
  if not aiLib.progressFor(source, { label = Locale('HACKING'), duration = 15000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:SetDoorLocked('pacific_vault', false, source) then return aiLib.fail('DOOR_FAILED') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### IsDoorLocked

Indique si une porte est verrouillée.

**Côté :** Serveur · **Attend :** non · **Lib :** [`doors.isLocked`](/fr/docs/developers/api/lib-server/world#doorsislocked)

```ts title="Signature"
IsDoorLocked(id: string): boolean | null
```

```lua title="Lua"
local locked = exports['ai-core']:IsDoorLocked('pacific_vault') -- true, false ou nil
```

#### Paramètres

<TypeTable
  type={{
    id: { type: 'string', description: 'L’id de porte du script de serrures (un nombre entier est converti en texte).', required: true },
  }}
/>

#### Retour

`boolean | null` : `true` verrouillée, `false` déverrouillée. `null` quand c’est inconnu : aucun script de serrures ne tourne, la porte n’existe pas, le script ne peut pas le dire côté serveur, ou `id` est vide.

#### Exemple

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The heist may start only while the vault is still closed. */
export function vaultClosed(): boolean {
  return core.IsDoorLocked("pacific_vault") !== false;
}
```
</Tab>
<Tab value="Lua">
```lua
function VaultClosed()
  return exports['ai-core']:IsDoorLocked('pacific_vault') ~= false
end
```
</Tab>
</Tabs>

<Callout type="info">
Décidez ce que `null` signifie pour votre fonctionnalité. L’exemple traite « inconnu » comme fermé, si bien qu’un script de serrures absent n’ouvre jamais le casse trop tôt.
</Callout>
