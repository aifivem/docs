---
title: Aspecto
description: Lee el aspecto guardado de un personaje desde el script de ropa que tenga el servidor.
icon: Shirt
---

Los aspectos pasan por ai-core, nunca por los exports, eventos o tablas propios de un script de ropa (ai-appearance incluido). ai-core los lee del **script de ropa activo**: el que elige el ajuste **Clothing script** (script de ropa) del panel, o el primero que esté en marcha. Poner un aspecto en un ped ocurre en el cliente (export de cliente `ApplyAppearance`, `appearance.apply` de la lib); consulta [Exports de cliente](/es/docs/developers/api/core-client).

Un aspecto es un [CharacterAppearance](/es/docs/developers/api/types#characterappearance): `{ model, data }`. `model` es el hash del modelo de ped; `data` es el formato propio del script de ropa. Trata `data` como una caja sellada: devuélvelo a `ApplyAppearance` sin cambios.

### GetAppearanceSystem

El nombre de recurso del script de ropa del que ai-core lee los aspectos.

**Lado:** Servidor · **Espera:** no · **Lib:** [`appearance.provider()`](/es/docs/developers/api/lib-server/phone-appearance#appearanceprovider)

```ts title="Firma"
GetAppearanceSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetAppearanceSystem() -- string o nil
```

#### Parámetros

Ninguno.

#### Devuelve

`string | null`: el nombre de recurso del script de ropa. `null` cuando no hay ninguno en marcha (los peds llevan entonces la ropa por defecto).

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("clothingsystem", { help: "Shows the clothing script in use", restricted: true }, () => {
  console.log(core.GetAppearanceSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('clothingsystem', { help = 'Shows the clothing script in use', restricted = true }, function()
  print(exports['ai-core']:GetAppearanceSystem() or 'none')
end)
```
</Tab>
</Tabs>

### GetCharacterAppearance

El aspecto guardado de un personaje, esté cargado o no. Úsalo para vestir un ped como ese personaje: un cuerpo dormido, una estatua, una foto, una vista previa.

**Lado:** Servidor · **Espera:** no (responde mediante `done`) · **Lib:** [`appearance.get(charId)`](/es/docs/developers/api/lib-server/phone-appearance#appearanceget) devuelve una Promise

```ts title="Firma"
GetCharacterAppearance(charId: number, done: (look: CharacterAppearance | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetCharacterAppearance(charId, function(look) end) -- look: table o nil
```

#### Parámetros

<TypeTable
  type={{
    charId: { type: 'number', description: 'Id del personaje en la base de datos. Un número entero positivo.', required: true },
    done: { type: '(look) => void', description: 'Se llama una vez con el aspecto, después de que responda el script de ropa.', required: true, typeDescription: '(look: CharacterAppearance | null) => void' },
  }}
/>

#### Devuelve

Nada. `done` recibe `{ model, data }`, o `null` cuando el personaje no tiene aspecto guardado, no hay ningún script de ropa en marcha, `charId` no es un número entero positivo o el script de ropa falló (queda en el log). Sin una función como `done` la llamada no hace nada.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import type { CharacterAppearance } from "@aifivem/shared";

const core = resourceExport("ai-core");

// El cliente pide el aspecto propio del jugador para vestir el ped de un fotomatón.
onClientCallback("myscript:myLook", async (source) => {
  const charId = online.charId(source);
  if (charId === undefined) return fail("NO_CHARACTER");
  const look = await new Promise<CharacterAppearance | null>((resolve) => core.GetCharacterAppearance(charId, resolve));
  return look ? { ok: true, look } : fail("NO_LOOK");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return aiLib.fail('NO_CHARACTER') end
  local p = promise.new()
  exports['ai-core']:GetCharacterAppearance(character.id, function(look) p:resolve(look or false) end)
  local look = Citizen.Await(p)
  if not look then return aiLib.fail('NO_LOOK') end
  return { ok = true, look = look }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Un aspecto puede ocupar unos kilobytes. Envíalo solo al jugador que lo necesita, nunca a todo el mundo (`-1`).
</Callout>
