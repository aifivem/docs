Stress, Hunger und Durst leben in dem HUD-Skript, das sie anzeigt. ai-core leitet Änderungen an das **erste laufende HUD, das Stress führt**, weiter: tgiann-lumihud, tgiann-hudv2, tgiann-modern-hud, qb-hud, ps-hud, dann ai-hud. Rufe nie die eigenen Events oder Exports eines HUD auf (`hud:server:GainStress`, `AddNeed` von ai-hud).

### GetStressSystem

Der Ressourcenname des HUD, dem ai-core Stress gibt.

**Seite:** Server · **Wartet:** nein · **Lib:** [`stress.provider()`](/de/docs/developers/api/lib-server/jobs#stressprovider)

```ts title="Signature"
GetStressSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetStressSystem() -- String oder nil
```

#### Parameter

Keine.

#### Rückgabe

`string | null`: der Ressourcenname des HUD. `null`, wenn kein HUD mit Stress läuft (Stressänderungen werden dann verworfen).

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("stresssystem", { help: "Shows the HUD that keeps stress", restricted: true }, () => {
  console.log(core.GetStressSystem() ?? "none: stress is dropped");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('stresssystem', { help = 'Shows the HUD that keeps stress', restricted = true }, function()
  print(exports['ai-core']:GetStressSystem() or 'none: stress is dropped')
end)
```
</Tab>
</Tabs>

### AddStress

Fügt einem Spieler Stress hinzu oder baut ihn mit einem negativen Betrag ab.

**Seite:** Server · **Wartet:** nein · **Lib:** [`stress.gain(source, amount)`](/de/docs/developers/api/lib-server/jobs#stressgain) und [`stress.relieve(source, amount)`](/de/docs/developers/api/lib-server/jobs#stressrelieve) (beide nehmen einen positiven Betrag)

```ts title="Signature"
AddStress(source: number, amount: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:AddStress(source, 5)    -- mehr Stress
local ok2 = exports['ai-core']:AddStress(source, -10) -- weniger Stress
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers. Eine positive ganze Zahl.', required: true },
    amount: { type: 'number', description: 'Stresspunkte auf der HUD-Skala 0-100: positiv fügt hinzu, negativ baut ab. Nicht 0, höchstens 100 in beide Richtungen.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn die Änderung an das HUD übergeben wurde. `false`, wenn `source` oder `amount` außerhalb des Bereichs liegt, kein HUD mit Stress läuft oder das HUD fehlgeschlagen ist. Das HUD begrenzt das Ergebnis auf 0-100.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Einen Laden auszurauben ist stressig; ein Joint entspannt.
export function robberyStarted(source: number): void {
  core.AddStress(source, 8);
}

core.RegisterUsableItem("joint", (source) => {
  core.AddStress(source, -15);
});
```
</Tab>
<Tab value="Lua">
```lua
function RobberyStarted(source)
  exports['ai-core']:AddStress(source, 8)
end

exports['ai-core']:RegisterUsableItem('joint', function(source)
  exports['ai-core']:AddStress(source, -15)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Stress durch Schießen und schnelles Fahren ist Aufgabe des HUD selbst. Nutze `AddStress` für Ereignisse, die dein Skript kennt.
</Callout>

### RefillNeeds

Füllt Hunger und Durst eines Spielers über das HUD, das sie führt, vollständig auf. Nutze es nach einer Wiederbelebung oder einem Krankenhausaufenthalt.

**Seite:** Server · **Wartet:** nein · **Lib:** [`needs.refill`](/de/docs/developers/api/lib-server/jobs#needsrefill)

```ts title="Signature"
RefillNeeds(source: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:RefillNeeds(source)
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers. Muss einen geladenen Charakter haben.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Auffüllen an das HUD übergeben wurde. Ohne ein HUD, das Bedürfnisse führt, setzt ai-core die Charakter-Metadaten `hunger` und `thirst` selbst auf 100 (und informiert HUDs im QB-Stil mit `hud:client:UpdateNeeds`) und antwortet `true`. `false`, wenn der Spieler keinen geladenen Charakter hat oder das HUD fehlgeschlagen ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const BED = { x: 317.8, y: -585.2, z: 43.3 };

// Ein Krankenhausbett: wiederbeleben, volle Gesundheit, voller Magen.
onClientCallback("myscript:hospitalBed", { guards: [near(BED, 2)], lock: true }, (source) => {
  if (!core.RemoveMoney(source, "bank", 500, "hospital_bed")) return fail("NOT_ENOUGH_MONEY");
  if (!core.RevivePlayer(source)) core.HealPlayer(source);
  core.RefillNeeds(source);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local BED = vector3(317.8, -585.2, 43.3)

aiLib.onClientCallback('myscript:hospitalBed', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - BED) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:RemoveMoney(source, 'bank', 500, 'hospital_bed') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  if not exports['ai-core']:RevivePlayer(source) then exports['ai-core']:HealPlayer(source) end
  exports['ai-core']:RefillNeeds(source)
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>
