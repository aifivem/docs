Полицейские оповещения идут через ai-core, а не через собственные экспорты или события скрипта оповещений (включая ai-policealert). ai-core передаёт каждое оповещение **активной системе оповещений**: той, что выбрана в настройке панели **Alert script**, или первой запущенной (встроенные карточки ai-policealert идут последними). Система оповещений показывает его сотрудникам работ оповещения, которые на дежурстве.

ai-core также отвечает на событие QB `police:server:policeAlert` за системы оповещений, которые этого не делают, поэтому оповещения скриптов QB тоже доходят.

### SendDispatchAlert

Отправляет одно оповещение. Используйте для всего, на что должны реагировать офицеры (или другая работа): стрельба, ограбление магазина, угнанная машина.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`dispatch.alert`](/ru/docs/developers/api/lib-server/jobs#dispatchalert)

```ts title="Сигнатура"
SendDispatchAlert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendDispatchAlert({ title = 'Store robbery', code = '10-90', source = source })
```

Неизвестные поля отбрасываются. См. [DispatchAlert](/ru/docs/developers/api/types#dispatchalert).

#### Возвращает

`boolean`: `true`, когда система оповещений приняла оповещение. `false`, когда `title` отсутствует или пуст, не работает ни одна система оповещений или она дала сбой.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const REGISTER = { x: 24.5, y: -1345.6, z: 29.5 };

onClientCallback("myscript:robRegister", { guards: [near(REGISTER, 2)], lock: true }, (source) => {
  if (core.GetOnDutyCount("police") < 2) return fail("NOT_ENOUGH_POLICE");
  core.SendDispatchAlert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: Locale("ALERT_STORE_NAME"),
    coords: REGISTER,
    source,
    jobs: ["police"],
    icon: "cash-register",
    priority: "high",
  });
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local REGISTER = vector3(24.5, -1345.6, 29.5)

aiLib.onClientCallback('myscript:robRegister', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - REGISTER) > 2.0 then return aiLib.fail('TOO_FAR') end
  if exports['ai-core']:GetOnDutyCount('police') < 2 then return aiLib.fail('NOT_ENOUGH_POLICE') end
  exports['ai-core']:SendDispatchAlert({
    code = '10-90',
    title = Locale('ALERT_STORE_ROBBERY'),
    message = Locale('ALERT_STORE_NAME'),
    coords = { x = REGISTER.x, y = REGISTER.y, z = REGISTER.z },
    source = source,
    jobs = { 'police' },
    icon = 'cash-register',
    priority = 'high',
  })
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="warn">
Тексты показываются как есть: переводите их через `Locale` перед отправкой. Не отправляйте оповещение каждый кадр или на каждое попадание: у оповещения о стрельбе должна быть задержка на игрока.
</Callout>
