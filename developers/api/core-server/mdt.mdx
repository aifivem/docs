---
title: MDT
description: Write fines, warrants, arrests and jail records into whichever police MDT the server runs.
icon: ClipboardList
---

Records go through ai-core, never through an MDT's own exports or events. ai-core forwards each record to the **active MDT**: the one the panel's **MDT script** setting picks, or the first one running. There is no ai-* MDT, so **while no MDT runs, records are not written anywhere**. Opening the MDT screen happens on the client (client export `OpenMdt`, lib `mdt.open`).

### GetMdtSystem

The resource name of the MDT ai-core forwards to.

**Side:** Server · **Waits:** no · **Lib:** [`mdt.provider()`](/docs/developers/api/lib-server/jobs#mdtprovider)

```ts title="Signature"
GetMdtSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetMdtSystem() -- string or nil
```

#### Parameters

None.

#### Returns

`string | null`: the MDT's resource name. `null` when none runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("mdtsystem", { help: "Shows the MDT in use", restricted: true }, () => {
  console.log(core.GetMdtSystem() ?? "none: records are not written");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('mdtsystem', { help = 'Shows the MDT in use', restricted = true }, function()
  print(exports['ai-core']:GetMdtSystem() or 'none: records are not written')
end)
```
</Tab>

### AddMdtRecord

Writes a record about a player into the MDT: a fine, a warrant, an arrest or a jail sentence. ai-core fills in the citizen ids and names of the target and the officer.

**Side:** Server · **Waits:** no · **Lib:** [`mdt.record`](/docs/developers/api/lib-server/jobs#mdtrecord)

```ts title="Signature"
AddMdtRecord(record: MdtRecord): boolean
```

```lua title="Lua"
local written = exports['ai-core']:AddMdtRecord({ kind = 'fine', target = target, by = source, title = 'Speeding', amount = 250 })
```

#### Parameters

<TypeTable
  type={{
    record: { type: 'MdtRecord', description: 'The record. Fields below.', required: true },
  }}
/>

#### MdtRecord

<TypeTable
  type={{
    kind: { type: '"fine" | "warrant" | "arrest" | "jail"', description: 'What the record is about.', required: true },
    target: { type: 'number', description: 'Server id of the player the record is about. Must have a loaded character.', required: true },
    by: { type: 'number', description: 'Server id of the officer who writes it.' },
    title: { type: 'string', description: 'What happened (`Speeding`, `Armed robbery`), already translated. Cut to 120 characters.', required: true },
    amount: { type: 'number', description: 'A fine amount in dollars. A whole number from 1 to 10,000,000; ignored otherwise.' },
    minutes: { type: 'number', description: 'A jail sentence in minutes. A whole number from 1 to 100,000; ignored otherwise.' },
  }}
/>

See [MdtRecord](/docs/developers/api/types#mdtrecord) and [MdtRecordKind](/docs/developers/api/types#mdtrecordkind).

#### Returns

`boolean`: `true` when the MDT wrote it. `false` when the record is invalid (wrong `kind`, no `title`, `target` not a positive whole number), the target has no loaded character, no MDT runs, the MDT takes no records from scripts or has no such kind.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail, readId } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");

// An officer jails a player for 20 minutes; the MDT keeps the record.
onClientCallback(
  "myscript:jail",
  { args: ([target]) => { const id = readId(target); return id === null ? null : [id]; }, lock: true },
  (source, target) => {
    if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
    if (!core.JailPlayer(target, 20, source)) return fail("JAIL_FAILED");
    core.AddMdtRecord({ kind: "jail", target, by: source, title: Locale("RECORD_ROBBERY"), minutes: 20 });
    return { ok: true };
  },
);
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.onClientCallback('myscript:jail', function(source, target)
  if math.type(target) ~= 'integer' or target < 1 then return aiLib.fail('BAD_TARGET') end
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  if not exports['ai-core']:JailPlayer(target, 20, source) then return aiLib.fail('JAIL_FAILED') end
  exports['ai-core']:AddMdtRecord({ kind = 'jail', target = target, by = source, title = Locale('RECORD_ROBBERY'), minutes = 20 })
  return { ok = true }
end, { lock = true })
```
