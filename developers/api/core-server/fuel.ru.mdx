Топливо идёт через ai-core, а не через собственные экспорты, декораторы или state bag скрипта топлива (включая ai-fuel). ai-core передаёт каждый вызов **активному скрипту топлива**: тому, что выбран в настройке панели **Fuel script**, или первому запущенному (ai-fuel, ox_fuel, LegacyFuel и остальные из списка совместимости). Без скрипта топлива уровень - это просто state bag `fuel` транспорта.

Уровень - это число от **0 (пусто) до 100 (полный бак)**. Транспорт задаётся **серверным хэндлом сущности**.

### GetFuelSystem

Имя ресурса скрипта топлива, которому ai-core передаёт вызовы.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`fuel.provider()`](/ru/docs/developers/api/lib-server/vehicles#fuelprovider)

```ts title="Сигнатура"
GetFuelSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetFuelSystem() -- 'ai-fuel', 'ox_fuel'... или nil
```

#### Параметры

Нет.

#### Возвращает

`string | null`: имя ресурса скрипта топлива. `null`, когда ни один не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("fuelsystem", { help: "Shows the fuel script in use", restricted: true }, () => {
  console.log(core.GetFuelSystem() ?? "none: fuel is only the state bag");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('fuelsystem', { help = 'Shows the fuel script in use', restricted = true }, function()
  print(exports['ai-core']:GetFuelSystem() or 'none: fuel is only the state bag')
end)
```
</Tab>
</Tabs>

### GetVehicleFuel

Уровень топлива транспорта.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`fuel.get`](/ru/docs/developers/api/lib-server/vehicles#fuelget) (сервер); на клиенте `fuel.get(vehicle)` из клиентской библиотеки читает state bag, который ведёт ai-core

```ts title="Сигнатура"
GetVehicleFuel(vehicle: number): number | null
```

```lua title="Lua"
local level = exports['ai-core']:GetVehicleFuel(vehicle) -- 0-100 или nil
```

#### Параметры

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Серверный хэндл сущности транспорта.', required: true },
  }}
/>

#### Возвращает

`number | null`: уровень, 0-100. `null`, когда у транспорта ещё нет уровня или `vehicle` не является существующим транспортом.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Механик смотрит бак машины перед собой.
onClientCallback("myscript:checkTank", { args: oneArg(readId) }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 4 });
  if (!vehicle) return fail("TOO_FAR");
  return { ok: true, level: core.GetVehicleFuel(vehicle) };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:checkTank', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 4 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  return { ok = true, level = exports['ai-core']:GetVehicleFuel(vehicle) }
end)
```
</Tab>
</Tabs>

### SetVehicleFuel

Задаёт уровень топлива транспорта.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`fuel.set`](/ru/docs/developers/api/lib-server/vehicles#fuelset) (а [`spawnVehicle({ fuel })`](/ru/docs/developers/api/lib-server/vehicles#spawnvehicle) задаёт его при создании)

```ts title="Сигнатура"
SetVehicleFuel(vehicle: number, level: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetVehicleFuel(vehicle, 100.0)
```

#### Параметры

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Серверный хэндл сущности транспорта.', required: true },
    level: { type: 'number', description: 'Новый уровень. Значения ниже 0 становятся 0, выше 100 становятся 100.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, когда уровень передан скрипту топлива (или записан в state bag, если ни один не работает). `false`, когда `vehicle` не является существующим транспортом, `level` не конечное число или скрипт топлива дал сбой.

У скриптов топлива, которые хранят топливо в играх игроков, новый уровень доходит до транспорта через игру его владельца чуть позже.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Канистра добавляет 25% машине рядом с игроком.
onClientCallback("myscript:jerryCan", { args: oneArg(readId), lock: true }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 3 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.RemoveItem(source, "jerrycan")) return fail("NO_JERRYCAN");
  core.SetVehicleFuel(vehicle, (core.GetVehicleFuel(vehicle) ?? 0) + 25);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:jerryCan', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 3 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:RemoveItem(source, 'jerrycan') then return aiLib.fail('NO_JERRYCAN') end
  local level = exports['ai-core']:GetVehicleFuel(vehicle) or 0
  exports['ai-core']:SetVehicleFuel(vehicle, level + 25)
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>
