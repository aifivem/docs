---
title: Prisión
description: Encarcela a jugadores, libéralos y lee el tiempo que les queda, a través del script de prisión que tenga el servidor.
icon: Lock
---

Las llamadas de cárcel pasan por ai-core, nunca por los exports o eventos propios de un script de prisión (ai-prison incluido). ai-core reenvía cada llamada al **primer script de prisión en marcha**: ai-prison, qb-prison, rcore_prison, xt-prison y después tgiann-policejob. Mientras no hay ninguno en marcha, cada llamada responde `false` o `0`.

### JailPlayer

Envía a un jugador a prisión durante un número de minutos.

**Lado:** Servidor · **Espera:** no · **Lib:** [`prison.jail`](/es/docs/developers/api/lib-server/jobs#prisonjail)

```ts title="Firma"
JailPlayer(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local jailed = exports['ai-core']:JailPlayer(target, 20, source)
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador al que se encarcela.', required: true },
    minutes: { type: 'number', description: 'Duración de la condena en minutos. Mayor que 0.', required: true },
    by: { type: 'number', description: 'Id de servidor del agente, para los scripts de prisión que registran quién lo hizo.', default: '0' },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de prisión recibió al jugador. `false` cuando `minutes` no es mayor que 0, `source` no es un número, no hay ningún script de prisión en marcha o lo rechazó.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("jail", {
  help: "Jails a player",
  params: [{ name: "id", type: "playerId" }, { name: "minutes", type: "number" }],
  restricted: "ai.job.police",
}, (source, args) => {
  if (core.GetDutyJob(source) !== "police") return;
  core.JailPlayer(args.id, args.minutes, source);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('jail', {
  help = 'Jails a player',
  params = { { name = 'id', type = 'playerId' }, { name = 'minutes', type = 'number' } },
  restricted = 'ai.job.police',
}, function(source, args)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return end
  exports['ai-core']:JailPlayer(args.id, args.minutes, source)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Escribe el registro de MDT correspondiente con [`AddMdtRecord`](/es/docs/developers/api/core-server/mdt) (`kind: "jail"`) cuando el servidor tiene un MDT.
</Callout>

### ReleasePlayer

Saca a un jugador de prisión.

**Lado:** Servidor · **Espera:** no · **Lib:** [`prison.release`](/es/docs/developers/api/lib-server/jobs#prisonrelease)

```ts title="Firma"
ReleasePlayer(source: number): boolean
```

```lua title="Lua"
local released = exports['ai-core']:ReleasePlayer(target)
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del preso.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de prisión liberó al jugador. `false` cuando el script de prisión no lo liberó (por ejemplo, no estaba en prisión), `source` no es un número o no hay ningún script de prisión en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("unjail", { help: "Releases a player", params: [{ name: "id", type: "playerId" }], restricted: true }, (_source, args) => {
  console.log(core.ReleasePlayer(args.id) ? "released" : "not in prison");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('unjail', { help = 'Releases a player', params = { { name = 'id', type = 'playerId' } }, restricted = true }, function(_, args)
  print(exports['ai-core']:ReleasePlayer(args.id) and 'released' or 'not in prison')
end)
```
</Tab>
</Tabs>

### GetJailTime

Cuánto tiempo le queda por cumplir a un jugador.

**Lado:** Servidor · **Espera:** no · **Lib:** [`prison.timeLeft`](/es/docs/developers/api/lib-server/jobs#prisontimeleft)

```ts title="Firma"
GetJailTime(source: number): number
```

```lua title="Lua"
local minutes = exports['ai-core']:GetJailTime(source)
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador.', required: true },
  }}
/>

#### Devuelve

`number`: minutos restantes. `0` cuando el jugador no está en prisión, `source` no es un número o no hay ningún script de prisión en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Los presos no pueden usar la cabina telefónica.
onClientCallback("myscript:phoneBooth", (source) =>
  core.GetJailTime(source) > 0 ? fail("IN_PRISON") : { ok: true },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:phoneBooth', function(source)
  if exports['ai-core']:GetJailTime(source) > 0 then return aiLib.fail('IN_PRISON') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
