Telefon çağrıları ai-core üzerinden gider, asla bir telefon script’inin kendi export’ları üzerinden değil. ai-core her çağrıyı **çalışan ilk telefon script’ine** iletir (tgiann-phone, lb-phone, gksphone ve uyumluluk listesindeki diğerleri). Hiçbir telefon çalışmıyorken her çağrı `null` ya da `false` cevabı verir.

### GetPhoneNumber

Bir oyuncunun telefon numarası.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`phone.number`](/tr/docs/developers/api/lib-server/phone-appearance#phonenumber)

```ts title="İmza"
GetPhoneNumber(source: number): string | null
```

```lua title="Lua"
local number = exports['ai-core']:GetPhoneNumber(source) -- string ya da nil
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
  }}
/>

#### Dönüş değeri

`string | null`: telefon script’inin yazdığı haliyle numara. Oyuncunun numarası yoksa, hiçbir telefon çalışmıyorsa ya da `source` bir sayı değilse `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Bir kartvizit eşyası sahibinin numarasını gösterir.
onClientCallback("myscript:myNumber", (source) => {
  const number = core.GetPhoneNumber(source);
  return number ? { ok: true, number } : fail("NO_PHONE_NUMBER");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myNumber', function(source)
  local number = exports['ai-core']:GetPhoneNumber(source)
  if not number then return aiLib.fail('NO_PHONE_NUMBER') end
  return { ok = true, number = number }
end)
```
</Tab>
</Tabs>

### GetSourceByPhone

Bir telefon numarasına sahip çevrimiçi oyuncu.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`phone.sourceOf`](/tr/docs/developers/api/lib-server/phone-appearance#phonesourceof)

```ts title="İmza"
GetSourceByPhone(number: string): number | null
```

```lua title="Lua"
local src = exports['ai-core']:GetSourceByPhone('5551234') -- sayı ya da nil
```

#### Parametreler

<TypeTable
  type={{
    number: { type: 'string', description: 'Telefon numarası, telefon script’inin yazdığı biçimde.', required: true },
  }}
/>

#### Dönüş değeri

`number | null`: server id. O numaranın sahibi çevrimiçi değilse, numara bilinmiyorsa, hiçbir telefon çalışmıyorsa ya da `number` metin değilse `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { notify, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Bir taksi mesleği, arayan çevrimiçiyse ona taksisinin yolda olduğunu söyler. */
export function cabOnTheWay(callerNumber: string): void {
  const caller = core.GetSourceByPhone(callerNumber);
  if (caller !== null) notify(caller, Locale("NOTIFY_CAB_COMING"), "info");
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function CabOnTheWay(callerNumber)
  local caller = exports['ai-core']:GetSourceByPhone(callerNumber)
  if caller then aiLib.notify(caller, Locale('NOTIFY_CAB_COMING'), 'info') end
end
```
</Tab>
</Tabs>

### HasPhone

Bir oyuncunun telefonu olup olmadığı (telefon eşyası isteyen telefon script’lerinde, bir tane taşıyıp taşımadığı).

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`phone.hasPhone`](/tr/docs/developers/api/lib-server/phone-appearance#phonehasphone)

```ts title="İmza"
HasPhone(source: number): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasPhone(source)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: telefon script’i oyuncunun telefonu olduğunu söylediğinde `true`. Olmadığında, hiçbir telefon çalışmıyorsa ya da `source` bir sayı değilse `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Görevleri mesajla dağıtan bir meslek telefon gerektirir.
onClientCallback("myscript:startDeliveries", (source) =>
  core.HasPhone(source) ? { ok: true } : fail("NEED_PHONE"),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:startDeliveries', function(source)
  if not exports['ai-core']:HasPhone(source) then return aiLib.fail('NEED_PHONE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SendPhoneMail

Bir oyuncunun telefonuna mail gönderir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`phone.mail`](/tr/docs/developers/api/lib-server/phone-appearance#phonemail)

```ts title="İmza"
SendPhoneMail(to: number | string, mail: PhoneMail): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMail(source, { sender = 'LS Customs', subject = 'Invoice', message = '...' })
```

#### Parametreler

<TypeTable
  type={{
    to: { type: 'number | string', description: 'Bir oyuncunun server id’si (numarası aranır) ya da bir telefon numarası / telefonun mail adresi.', required: true },
    mail: { type: 'PhoneMail', description: 'Mail. Alanlar aşağıda.', required: true },
  }}
/>

#### PhoneMail

<TypeTable
  type={{
    sender: { type: 'string', description: 'Gönderen olarak gösterilir (bir şirket, `Los Santos Customs`).', default: '""' },
    subject: { type: 'string', description: 'Konu satırı. 120 karaktere kesilir.', required: true },
    message: { type: 'string', description: 'Metin. 4000 karaktere kesilir.', required: true },
  }}
/>

Metinler verildiği gibi gösterilir: çevrilmiş metinler ver. Bkz. [PhoneMail](/tr/docs/developers/api/types#phonemail).

#### Dönüş değeri

`boolean`: telefon script’i maili kabul ettiğinde `true`. Oyuncunun numarası yoksa, `subject` ya da `message` eksikse, hiçbir telefon çalışmıyorsa ya da reddettiyse `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Soygun bağlantısı iş kabul edildikten sonra konumu mail atar. */
export function mailHeistLocation(source: number, street: string): void {
  core.SendPhoneMail(source, {
    sender: Locale("MAIL_CONTACT"),
    subject: Locale("MAIL_HEIST_SUBJECT"),
    message: Locale("MAIL_HEIST_BODY", street),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function MailHeistLocation(source, street)
  exports['ai-core']:SendPhoneMail(source, {
    sender = Locale('MAIL_CONTACT'),
    subject = Locale('MAIL_HEIST_SUBJECT'),
    message = Locale('MAIL_HEIST_BODY', street),
  })
end
```
</Tab>
</Tabs>

### SendPhoneMessage

Bir numaradan bir oyuncuya ya da numaraya mesaj gönderir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`phone.message`](/tr/docs/developers/api/lib-server/phone-appearance#phonemessage)

```ts title="İmza"
SendPhoneMessage(from: string, to: number | string, text: string): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMessage('Dispatch', source, 'Your cab is here.')
```

#### Parametreler

<TypeTable
  type={{
    from: { type: 'string', description: 'Gönderen numara ya da ad, telefon script’inin kabul ettiği biçimde.', required: true },
    to: { type: 'number | string', description: 'Bir oyuncunun server id’si (numarası aranır) ya da bir telefon numarası.', required: true },
    text: { type: 'string', description: 'Mesaj, zaten çevrilmiş. 1000 karaktere kesilir.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: telefon script’i mesajı kabul ettiğinde `true`. Alıcının numarası yoksa, `from` ya da `text` metin değilse, hiçbir telefon çalışmıyorsa ya da reddettiyse `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Bir sonraki teslimat adresi mesajla gelir. */
export function textNextStop(source: number, street: string): void {
  if (!core.SendPhoneMessage(Locale("SENDER_DISPATCH"), source, Locale("TEXT_NEXT_STOP", street)))
    console.log(`player ${source} could not get the text`);
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TextNextStop(source, street)
  if not exports['ai-core']:SendPhoneMessage(Locale('SENDER_DISPATCH'), source, Locale('TEXT_NEXT_STOP', street)) then
    print(('player %d could not get the text'):format(source))
  end
end
```
</Tab>
</Tabs>

### PhoneNotify

Bir oyuncunun telefonunda bir bildirim gösterir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`phone.notify`](/tr/docs/developers/api/lib-server/phone-appearance#phonenotify)

```ts title="İmza"
PhoneNotify(source: number, notification: PhoneNotification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:PhoneNotify(source, { title = 'Bank', message = 'Salary paid', app = 'bank' })
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    notification: { type: 'PhoneNotification', description: 'Ne gösterileceği. Alanlar aşağıda.', required: true },
  }}
/>

#### PhoneNotification

<TypeTable
  type={{
    title: { type: 'string', description: 'Başlık satırı. 80 karaktere kesilir.', required: true },
    message: { type: 'string', description: 'Metin. 500 karaktere kesilir.', default: '""' },
    app: { type: 'string', description: 'Telefon biliyorsa ait olduğu telefon uygulaması id’si (`messages`, `mail`, `bank`).' },
  }}
/>

Bkz. [PhoneNotification](/tr/docs/developers/api/types#phonenotification).

#### Dönüş değeri

`boolean`: telefon script’i gösterdiğinde `true`. `title` eksikse, hiçbir telefon çalışmıyorsa, `source` bir sayı değilse ya da reddettiyse `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Sahibine arabasının çekildiğini söyler. */
export function towedNotice(source: number, plate: string): void {
  core.PhoneNotify(source, { title: Locale("PHONE_TOW_TITLE"), message: Locale("PHONE_TOW_TEXT", plate) });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TowedNotice(source, plate)
  exports['ai-core']:PhoneNotify(source, { title = Locale('PHONE_TOW_TITLE'), message = Locale('PHONE_TOW_TEXT', plate) })
end
```
</Tab>
</Tabs>
