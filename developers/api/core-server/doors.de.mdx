---
title: Türschlösser
description: Türen ab- und aufschließen und lesen, über das Türschloss-Skript, das der Server nutzt.
icon: DoorClosed
---

Tür-Aufrufe laufen über ai-core, nie über die eigenen Exports oder Events eines Türschloss-Skripts (ai-doorlock eingeschlossen). ai-core leitet jeden Aufruf an das **aktive Türschloss-Skript** weiter: das, das die Panel-Einstellung **Door lock script** (Türschloss-Skript) wählt, oder das erste, das läuft (ai-doorlock, ox_doorlock, tgiann-doorlock und die anderen aus der Kompatibilitätsliste).

Eine Tür wird über **die eigene Tür-ID dieses Skripts** benannt: die ID, die du in seiner Türliste siehst (ai-doorlock: die ID der Tür im Admin-Panel; ox_doorlock: ihre Datenbanknummer).

### GetDoorlockSystem

Der Ressourcenname des Türschloss-Skripts, an das ai-core weiterleitet.

**Seite:** Server · **Wartet:** nein · **Lib:** [`doors.provider()`](/de/docs/developers/api/lib-server/world#doorsprovider)

```ts title="Signature"
GetDoorlockSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetDoorlockSystem() -- String oder nil
```

#### Parameter

Keine.

#### Rückgabe

`string | null`: der Ressourcenname des Türschloss-Skripts. `null`, wenn keines läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Die Tür-IDs in deiner Config gehören zu einem Türschloss-Skript: Warne, wenn ein anderes läuft.
if (core.GetDoorlockSystem() !== "ai-doorlock")
  console.log("myscript: door ids are written for ai-doorlock");
```
</Tab>
<Tab value="Lua">
```lua
if exports['ai-core']:GetDoorlockSystem() ~= 'ai-doorlock' then
  print('myscript: door ids are written for ai-doorlock')
end
```
</Tab>
</Tabs>

### SetDoorLocked

Schließt eine Tür ab oder auf.

**Seite:** Server · **Wartet:** nein · **Lib:** [`doors.setLocked`](/de/docs/developers/api/lib-server/world#doorssetlocked)

```ts title="Signature"
SetDoorLocked(id: string, locked: boolean, by?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDoorLocked('pacific_vault', false, source)
```

#### Parameter

<TypeTable
  type={{
    id: { type: 'string', description: 'Die Tür-ID des Türschloss-Skripts. Eine ganze Zahl (IDs von ox_doorlock) wird in Text umgewandelt. Höchstens 128 Zeichen.', required: true },
    locked: { type: 'boolean', description: '`true` schließt ab, `false` schließt auf. Muss ein echter Boolean sein.', required: true },
    by: { type: 'number', description: 'Server-ID des Spielers, der es tut. Türschloss-Skripte ohne Server-API brauchen einen Spieler, dessen Spiel die Änderung überträgt; wird ignoriert, wenn dieser Spieler nicht online ist.' },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Türschloss-Skript die Änderung angenommen hat. `false`, wenn kein Türschloss-Skript läuft, die Tür unbekannt ist, das Skript abgelehnt hat, `id` leer ist oder `locked` kein Boolean ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, progressFor, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const VAULT = { x: 253.9, y: 225.2, z: 101.9 };

onClientCallback("myscript:hackVault", { guards: [near(VAULT, 2)], lock: true }, async (source) => {
  if (!core.HasItem(source, "laptop")) return fail("NO_LAPTOP");
  if (!(await progressFor(source, { label: Locale("HACKING"), duration: 15000 }))) return fail("CANCELLED");
  return core.SetDoorLocked("pacific_vault", false, source) ? { ok: true } : fail("DOOR_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local VAULT = vector3(253.9, 225.2, 101.9)

aiLib.onClientCallback('myscript:hackVault', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - VAULT) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:HasItem(source, 'laptop') then return aiLib.fail('NO_LAPTOP') end
  if not aiLib.progressFor(source, { label = Locale('HACKING'), duration = 15000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:SetDoorLocked('pacific_vault', false, source) then return aiLib.fail('DOOR_FAILED') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### IsDoorLocked

Ob eine Tür abgeschlossen ist.

**Seite:** Server · **Wartet:** nein · **Lib:** [`doors.isLocked`](/de/docs/developers/api/lib-server/world#doorsislocked)

```ts title="Signature"
IsDoorLocked(id: string): boolean | null
```

```lua title="Lua"
local locked = exports['ai-core']:IsDoorLocked('pacific_vault') -- true, false oder nil
```

#### Parameter

<TypeTable
  type={{
    id: { type: 'string', description: 'Die Tür-ID des Türschloss-Skripts (eine ganze Zahl wird in Text umgewandelt).', required: true },
  }}
/>

#### Rückgabe

`boolean | null`: `true` abgeschlossen, `false` aufgeschlossen. `null`, wenn es unbekannt ist: Kein Türschloss-Skript läuft, die Tür existiert nicht, das Skript kann es auf dem Server nicht sagen, oder `id` ist leer.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** Der Überfall darf nur starten, solange der Tresor noch geschlossen ist. */
export function vaultClosed(): boolean {
  return core.IsDoorLocked("pacific_vault") !== false;
}
```
</Tab>
<Tab value="Lua">
```lua
function VaultClosed()
  return exports['ai-core']:IsDoorLocked('pacific_vault') ~= false
end
```
</Tab>
</Tabs>

<Callout type="info">
Entscheide, was `null` für deine Funktion bedeutet. Das Beispiel behandelt „unbekannt“ als geschlossen, sodass ein fehlendes Türschloss-Skript den Überfall nie zu früh öffnet.
</Callout>
