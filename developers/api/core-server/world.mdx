---
title: Time and weather
description: Read and set the weather and game time, blackout and frozen time, through whichever weather script the server runs.
icon: CloudSun
---

Time and weather go through ai-core, never through a weather script's own exports or events. ai-core forwards each call to the **first weather script running**: Renewed-Weathersync, av_weather, cd_easytime, then qb-weathersync (ai-weathersync answers under that name). They all follow the qb-weathersync contract. While none runs, every call answers `null` or `false`.

To pause the sync on one player's game (an interior with its own light, a cutscene), use the client side (`PauseWorldSync`, lib `world.pauseSync`); see [Client exports](/docs/developers/api/core-client).

### GetWeather

The current weather type.

**Side:** Server · **Waits:** no · **Lib:** [`world.getWeather`](/docs/developers/api/lib-server/world#worldgetweather)

```ts title="Signature"
GetWeather(): string | null
```

```lua title="Lua"
local weather = exports['ai-core']:GetWeather() -- 'EXTRASUNNY', 'RAIN'... or nil
```

#### Parameters

None.

#### Returns

`string | null`: the weather type in capitals (`EXTRASUNNY`, `CLEAR`, `RAIN`, `THUNDER`...). `null` when no weather script runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Street races pay more in the rain. */
export function raceBonus(): number {
  const weather = core.GetWeather();
  return weather === "RAIN" || weather === "THUNDER" ? 1.25 : 1;
}
```
</Tab>
<Tab value="Lua">
```lua
function RaceBonus()
  local weather = exports['ai-core']:GetWeather()
  if weather == 'RAIN' or weather == 'THUNDER' then return 1.25 end
  return 1.0
end
```
</Tab>
</Tabs>

### SetWeather

Sets the weather for everyone.

**Side:** Server · **Waits:** no · **Lib:** [`world.setWeather`](/docs/developers/api/lib-server/world#worldsetweather) (takes the typed `Weather` names)

```ts title="Signature"
SetWeather(type: string): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetWeather('RAIN')
```

#### Parameters

<TypeTable
  type={{
    type: { type: 'string', description: 'A weather type of the qb-weathersync contract: `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Upper-cased before it is sent.', required: true },
  }}
/>

#### Returns

`boolean`: `true` when the weather script accepted it. `false` when `type` is not a text, the script refused it (an unknown type) or no weather script runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";
import { isWeather } from "@aifivem/shared";

const core = resourceExport("ai-core");

addCommand("weather", { help: "Sets the weather", params: [{ name: "type", type: "string" }], restricted: true }, (_source, args) => {
  const type = args.type.toUpperCase();
  if (!isWeather(type)) return console.log("unknown weather type");
  core.SetWeather(type);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { help = 'Sets the weather', params = { { name = 'type', type = 'string' } }, restricted = true }, function(_, args)
  if not exports['ai-core']:SetWeather(args.type) then print('weather refused') end
end)
```
</Tab>
</Tabs>

### GetTime

The game time (the in-game clock).

**Side:** Server · **Waits:** no · **Lib:** [`world.getTime`](/docs/developers/api/lib-server/world#worldgettime)

```ts title="Signature"
GetTime(): { hour: number; minute: number } | null
```

```lua title="Lua"
local time = exports['ai-core']:GetTime() -- { hour, minute } or nil
```

#### Parameters

None.

#### Returns

`{ hour, minute } | null`: hour 0-23 and minute 0-59. `null` when no weather script runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// The drug dealer only sells at night (22:00 - 05:59 game time).
onClientCallback("myscript:dealer", (source) => {
  const time = core.GetTime();
  const night = time !== null && (time.hour >= 22 || time.hour < 6);
  return night ? { ok: true } : fail("COME_BACK_AT_NIGHT");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:dealer', function(source)
  local time = exports['ai-core']:GetTime()
  if not time or (time.hour < 22 and time.hour >= 6) then return aiLib.fail('COME_BACK_AT_NIGHT') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SetTime

Sets the game time for everyone.

**Side:** Server · **Waits:** no · **Lib:** [`world.setTime`](/docs/developers/api/lib-server/world#worldsettime)

```ts title="Signature"
SetTime(hour: number, minute?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetTime(12, 0)
```

#### Parameters

<TypeTable
  type={{
    hour: { type: 'number', description: 'Hour, 0-23. Rounded down and wrapped (24 becomes 0).', required: true },
    minute: { type: 'number', description: 'Minute, 0-59. Rounded down and wrapped.', default: '0' },
  }}
/>

#### Returns

`boolean`: `true` when the weather script accepted it. `false` when `hour` is not a number, the script refused or no weather script runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("noon", { help: "Sets the time to 12:00", restricted: true }, () => {
  core.SetTime(12, 0);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('noon', { help = 'Sets the time to 12:00', restricted = true }, function()
  exports['ai-core']:SetTime(12, 0)
end)
```
</Tab>
</Tabs>

### SetBlackout

Turns the city's blackout (all artificial lights off) on or off.

**Side:** Server · **Waits:** no · **Lib:** [`world.setBlackout`](/docs/developers/api/lib-server/world#worldsetblackout)

```ts title="Signature"
SetBlackout(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetBlackout(true)
```

#### Parameters

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` turns the blackout on. Anything other than `true` turns it off.', required: true },
  }}
/>

#### Returns

`boolean`: `true` when the weather script accepted it. `false` when the script has no blackout, refused, or no weather script runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The power plant was sabotaged: 5 minutes of darkness. */
export function sabotagePowerPlant(): void {
  if (!core.SetBlackout(true)) return;
  setTimeout(() => core.SetBlackout(false), 5 * 60_000);
}
```
</Tab>
<Tab value="Lua">
```lua
function SabotagePowerPlant()
  if not exports['ai-core']:SetBlackout(true) then return end
  SetTimeout(5 * 60000, function() exports['ai-core']:SetBlackout(false) end)
end
```
</Tab>
</Tabs>

### FreezeTime

Stops or restarts the game clock.

**Side:** Server · **Waits:** no · **Lib:** [`world.freezeTime`](/docs/developers/api/lib-server/world#worldfreezetime)

```ts title="Signature"
FreezeTime(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:FreezeTime(true)
```

#### Parameters

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` freezes the clock. Anything other than `true` lets it run.', required: true },
  }}
/>

#### Returns

`boolean`: `true` when the weather script accepted it. `false` when the script cannot freeze time, refused, or no weather script runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// An event night: always 21:00.
addCommand("eventnight", { help: "Freezes the clock at 21:00", restricted: true }, () => {
  core.SetTime(21, 0);
  core.FreezeTime(true);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('eventnight', { help = 'Freezes the clock at 21:00', restricted = true }, function()
  exports['ai-core']:SetTime(21, 0)
  exports['ai-core']:FreezeTime(true)
end)
```
</Tab>
</Tabs>
