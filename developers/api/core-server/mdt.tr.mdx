Kayıtlar ai-core üzerinden gider, asla bir MDT’nin kendi export’ları ya da event’leri üzerinden değil. ai-core her kaydı **aktif MDT’ye** iletir: panelin **MDT script** ayarının seçtiği ya da çalışan ilk MDT. ai-* MDT yoktur, bu yüzden **hiçbir MDT çalışmıyorken kayıtlar hiçbir yere yazılmaz**. MDT ekranını açmak client’ta olur (client export’u `OpenMdt`, lib `mdt.open`).

### GetMdtSystem

ai-core’un ilettiği MDT’nin resource adı.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`mdt.provider()`](/tr/docs/developers/api/lib-server/jobs#mdtprovider)

```ts title="İmza"
GetMdtSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetMdtSystem() -- string ya da nil
```

#### Parametreler

Yok.

#### Dönüş değeri

`string | null`: MDT’nin resource adı. Hiçbiri çalışmıyorsa `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("mdtsystem", { help: "Shows the MDT in use", restricted: true }, () => {
  console.log(core.GetMdtSystem() ?? "none: records are not written");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('mdtsystem', { help = 'Shows the MDT in use', restricted = true }, function()
  print(exports['ai-core']:GetMdtSystem() or 'none: records are not written')
end)
```
</Tab>
</Tabs>

### AddMdtRecord

MDT’ye bir oyuncu hakkında bir kayıt yazar: bir ceza, bir arama kararı, bir tutuklama ya da bir hapis cezası. ai-core hedefin ve memurun citizen id’lerini ve adlarını doldurur.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`mdt.record`](/tr/docs/developers/api/lib-server/jobs#mdtrecord)

```ts title="İmza"
AddMdtRecord(record: MdtRecord): boolean
```

```lua title="Lua"
local written = exports['ai-core']:AddMdtRecord({ kind = 'fine', target = target, by = source, title = 'Speeding', amount = 250 })
```

#### Parametreler

<TypeTable
  type={{
    record: { type: 'MdtRecord', description: 'Kayıt. Alanlar aşağıda.', required: true },
  }}
/>

#### MdtRecord

<TypeTable
  type={{
    kind: { type: '"fine" | "warrant" | "arrest" | "jail"', description: 'Kaydın ne hakkında olduğu.', required: true },
    target: { type: 'number', description: 'Kaydın konusu olan oyuncunun server id’si. Yüklü bir karakteri olmalıdır.', required: true },
    by: { type: 'number', description: 'Kaydı yazan memurun server id’si.' },
    title: { type: 'string', description: 'Ne olduğu (`Speeding`, `Armed robbery`), zaten çevrilmiş. 120 karaktere kesilir.', required: true },
    amount: { type: 'number', description: 'Dolar cinsinden ceza miktarı. 1 ile 10,000,000 arası bir tam sayı; aksi halde yok sayılır.' },
    minutes: { type: 'number', description: 'Dakika cinsinden hapis cezası. 1 ile 100,000 arası bir tam sayı; aksi halde yok sayılır.' },
  }}
/>

Bkz. [MdtRecord](/tr/docs/developers/api/types#mdtrecord) ve [MdtRecordKind](/tr/docs/developers/api/types#mdtrecordkind).

#### Dönüş değeri

`boolean`: MDT yazdığında `true`. Kayıt geçersizse (yanlış `kind`, `title` yok, `target` pozitif bir tam sayı değil), hedefin yüklü karakteri yoksa, hiçbir MDT çalışmıyorsa, MDT script’lerden kayıt almıyorsa ya da böyle bir türü yoksa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail, readId } from "@aifivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");

// Bir memur bir oyuncuyu 20 dakika hapse atar; kaydı MDT tutar.
onClientCallback(
  "myscript:jail",
  { args: ([target]) => { const id = readId(target); return id === null ? null : [id]; }, lock: true },
  (source, target) => {
    if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
    if (!core.JailPlayer(target, 20, source)) return fail("JAIL_FAILED");
    core.AddMdtRecord({ kind: "jail", target, by: source, title: Locale("RECORD_ROBBERY"), minutes: 20 });
    return { ok: true };
  },
);
```
</Tab>

```lua
local Locale = aiLib.locale()

aiLib.onClientCallback('myscript:jail', function(source, target)
  if math.type(target) ~= 'integer' or target < 1 then return aiLib.fail('BAD_TARGET') end

  exports['ai-core']:AddMdtRecord({ kind = 'jail', target = target, by = source, title = Locale('RECORD_ROBBERY'), minutes = 20 })
  return { ok = true }
end, { lock = true })
```
