title: Faturalar
description: "Çalışan fatura script’i ya da ai-core’un kendi faturaları üzerinden fatura gönder (cezalar, hizmet ücretleri, oyuncu faturaları), bir oyuncunun açık faturalarını listele ve öde."
icon: Receipt
---

Faturalar ai-core üzerinden gider, asla bir fatura script’inin kendi export’ları ya da event’leri üzerinden değil. ai-core her faturayı **aktif fatura script’ine** gönderir: panelin **Billing script** ayarının seçtiği ya da çalışan ilk script. Hiçbiri yoksa faturayı **ai-core’un kendi faturaları** alır: oyuncu ekranda açık faturaların bir listesini görür ve ödediğinde para hareket eder. Bir fatura asla boşa gitmez.

Bir fatura **bir meslekten** (ödemeyi mesleğin `bank` hesabı alır: polis cezaları, bir tamircinin ücreti) ya da **bir oyuncudan** (ödemeyi o oyuncu alır) gelir.

Kısaca ai-core’un kendi faturaları: açık faturalar karakter başına saklanır (çevrimdışı karakterler dahil), karakter başına en fazla 20 açık fatura olur ve ödeme parayı önce `bank`’tan, sonra `cash`’ten, faturanın silinmesiyle tek bir transaction içinde alır.

### GetBillingSystem

Faturaların nereye gittiği.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`billing.provider()`](/tr/docs/developers/api/lib-server/money#billingprovider)

```ts title="İmza"
GetBillingSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetBillingSystem() -- 'ai-core' ya da bir script adı
```

#### Parametreler

Yok.

#### Dönüş değeri

`string | null`: fatura script’inin resource adı ya da ai-core’un kendi faturaları için `"ai-core"`. ai-core’un kendi faturaları her zaman mevcut olduğundan pratikte bu `null` olmaz.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** Çevrimdışı karakterlere faturalar yalnızca ai-core’un kendi faturalarıyla çalışır. */
export function canBillOffline(): boolean {
  return core.GetBillingSystem() === "ai-core";
}
```
</Tab>
<Tab value="Lua">
```lua
function CanBillOffline()
  return exports['ai-core']:GetBillingSystem() == 'ai-core'
end
```
</Tab>
</Tabs>

### SendBill

Bir oyuncuya fatura gönderir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`billing.send`](/tr/docs/developers/api/lib-server/money#billingsend)

```ts title="İmza"
SendBill(bill: BillRequest): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendBill({ to = target, amount = 250, label = 'Speeding', from = source, job = 'police' })
```

#### Parametreler

<TypeTable
  type={{
    bill: { type: 'BillRequest', description: 'Fatura. Alanlar aşağıda.', required: true },
  }}
/>

#### BillRequest

<TypeTable
  type={{
    to: { type: 'number', description: 'Faturayı alan oyuncunun server id’si. `to` ya da `toCitizenid` ver, asla ikisini birden değil.' },
    toCitizenid: { type: 'string', description: 'Faturayı alan karakterin citizen id’si, çevrimiçi ya da çevrimdışı (harfler ve rakamlar, en fazla 16). Çevrimdışı bir karakter onu yalnızca ai-core’un kendi faturalarından alır.' },
    amount: { type: 'number', description: 'Tam dolar, 1 ile 10,000,000 arası.', required: true },
    label: { type: 'string', description: 'Ne için olduğu (`Speeding`, `Engine repair`), zaten çevrilmiş. 80 karaktere kesilir.', required: true },
    from: { type: 'number', description: 'Faturayı kesen oyuncunun server id’si (memur, tamirci). Kişisel bir fatura için (`job` yok) zorunlu: ödemeyi o oyuncu alır.' },
    job: { type: 'string', description: 'Ödemeyi hesabı alan meslek (küçük harfli ad, 2-32 karakter). Bu olmadan fatura kişiseldir.' },
  }}
/>

Bkz. [BillRequest](/tr/docs/developers/api/types#billrequest).

#### Dönüş değeri

`boolean`: fatura gönderildiğinde `true`. Şu durumlarda `false`:

- fatura geçersiz: `to` / `toCitizenid`’den ikisi birden ya da hiçbiri, `label` yok, `amount` 1 ile 10,000,000 arası bir tam sayı değil, ne `job` ne `from` var ya da `from` alıcıya eşit;
- `from` verilmiş ama yüklü bir karakteri yok ya da `job` mevcut değil;
- alıcı çevrimdışı ve faturalar bir fatura script’ine gidiyor (çevrimdışı karakterlere yalnızca ai-core’un kendi faturaları ulaşır);
- fatura script’i reddetti ya da alıcının ai-core’un kendi faturalarında zaten 20 açık faturası var.

ai-core’un kendi faturalarıyla çevrimdışı bir fatura, geçerli olduğu anda `true` cevabı verir; veritabanı yine de reddedebilir (bilinmeyen citizen id, 20 açık fatura), bu da loglanır.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, coordsOf, isNear, resourceExport } from "@aicore-fivem/lib/server";
import { fail, readId, readInt } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");

// Bir memur önündeki oyuncuya ceza keser; parayı polis hesabı alır.
onClientCallback(
  "myscript:fine",
  {
    args: ([target, amount]) => {
      const t = readId(target);
      const a = readInt(amount, 1, 50_000);
      return t === null || a === null ? null : [t, a];
    },
  },
  (source, target, amount) => {
    if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
    if (!isNear(target, coordsOf(source), 3)) return fail("TOO_FAR");
    const sent = core.SendBill({ to: target, amount, label: Locale("BILL_FINE"), from: source, job: "police" });
    return sent ? { ok: true } : fail("BILL_FAILED");
  },
);
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.onClientCallback('myscript:fine', function(source, target, amount)
  if math.type(target) ~= 'integer' or math.type(amount) ~= 'integer' or amount < 1 or amount > 50000 then
    return aiLib.fail('BAD_INPUT')
  end
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  if #(GetEntityCoords(GetPlayerPed(source)) - GetEntityCoords(GetPlayerPed(target))) > 3.0 then return aiLib.fail('TOO_FAR') end
  local sent = exports['ai-core']:SendBill({ to = target, amount = amount, label = Locale('BILL_FINE'), from = source, job = 'police' })
  if not sent then return aiLib.fail('BILL_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Hedeften parayı asla "zorla fatura" olarak kendin alma (onun hesabından `TransferMoney`): fatura, oyuncunun ödeme tercihidir.
</Callout>

### GetUnpaidBills

Bir oyuncunun açık (ödenmemiş) faturaları.

**Taraf:** Server · **Bekler:** hayır (`done` ile cevap verir) · **Lib:** [`billing.unpaid(source)`](/tr/docs/developers/api/lib-server/money#billingunpaid) bir Promise döndürür

```ts title="İmza"
GetUnpaidBills(source: number, done: (bills: UnpaidBill[] | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetUnpaidBills(source, function(bills) end) -- liste ya da nil
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    done: { type: '(bills) => void', description: 'Cevapla bir kez çağrılır.', required: true, typeDescription: '(bills: UnpaidBill[] | null) => void' },
  }}
/>

#### Dönüş değeri

Hiçbir şey. `done` her açık fatura için bir kayıt alır: `id` (fatura script’inin id’si), `label`, `amount` (hâlâ borçlu olunan) ve `sender` (meslek etiketi ya da oyuncu adı) ([UnpaidBill](/tr/docs/developers/api/types#unpaidbill)); oyuncunun yüklü karakteri yoksa ya da fatura script’i faturaları listeleyemiyorsa `null` alır. `done` olarak bir fonksiyon verilmezse çağrı hiçbir şey yapmaz.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import type { UnpaidBill } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Bir belediye gişesi oyuncunun borcunu gösterir.
onClientCallback("myscript:myBills", async (source) => {
  const bills = await new Promise<UnpaidBill[] | null>((resolve) => core.GetUnpaidBills(source, resolve));
  if (!bills) return fail("BILLS_UNAVAILABLE");
  return { ok: true, bills, total: bills.reduce((sum, b) => sum + b.amount, 0) };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myBills', function(source)
  local p = promise.new()
  exports['ai-core']:GetUnpaidBills(source, function(bills) p:resolve(bills or false) end)
  local bills = Citizen.Await(p)
  if not bills then return aiLib.fail('BILLS_UNAVAILABLE') end
  local total = 0
  for _, b in ipairs(bills) do total = total + b.amount end
  return { ok = true, bills = bills, total = total }
end)
```
</Tab>
</Tabs>

### PayBill

Oyuncu açık faturalarından birini öder.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`billing.pay`](/tr/docs/developers/api/lib-server/money#billingpay)

```ts title="İmza"
PayBill(source: number, id: string): boolean
```

```lua title="Lua"
local paid = exports['ai-core']:PayBill(source, billId)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Ödeyen oyuncunun server id’si (faturanın alıcısı).', required: true },
    id: { type: 'string', description: '`GetUnpaidBills`’ten gelen fatura `id`’si.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: fatura ödendiğinde `true`. Oyuncunun yüklü karakteri yoksa, fatura onun değilse ya da artık yoksa, ödeyemiyorsa, fatura script’i reddettiyse ya da ödemeleri yalnızca kendi ekranında alıyorsa `false`. ai-core’un kendi faturalarında kişisel bir fatura ayrıca kesenin çevrimiçi olmasını gerektirir (para onun bankasına gider).

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail, readText } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback(
  "myscript:payBill",
  { args: ([id]) => { const v = readText(id, 64); return v ? [v] : null; }, lock: true },
  (source, id) => (core.PayBill(source, id) ? { ok: true } : fail("BILL_NOT_PAID")),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:payBill', function(source, id)
  if type(id) ~= 'string' or not exports['ai-core']:PayBill(source, id) then return aiLib.fail('BILL_NOT_PAID') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>
