Her resource ai-core üzerinden loglar. Resource’un bir **kanal** adı verir (`purchases`, `robberies`) ve bir mesaj yazar; nereye gideceğine ai-core karar verir. Sunucu sahibi sağlayıcıları admin panelinde açar (konsol, Discord, Fivemanage, FiveM Stats), en düşük seviyeyi ayarlar ve resource ve kanal başına Discord webhook url’lerini yapıştırır. Bir resource asla kendisi bir webhook’a ya da log servisine gönderim yapmaz ve asla bir webhook url’si tutmaz.

İlgili oyuncuları adlarını mesaja yazmak yerine `source` ve `target` olarak ver: ai-core her oyuncunun adını, karakterini, citizen id’sini ve tanımlayıcılarını ekler (IP’yi yalnızca panel izin verdiğinde).

### Log

Resource’unun tek bir log kaydını gönderir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`aiLog(channel, message, options?)`](/tr/docs/developers/api/lib-server/logs#ailog) (Lua: `aiLib.aiLog`; ai-core çalışmıyorken ikisi de bunun yerine konsola yazar)

```ts title="İmza"
Log(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { price = 25000 } })
```

#### Parametreler

<TypeTable
  type={{
    channel: { type: 'string', description: 'Resource’unun kanal adı (`purchases`). Webhook ve açma/kapama anahtarı kanal başınadır. Metin değilse `log`.', required: true },
    message: { type: 'string', description: 'Ne olduğu, düz İngilizce. Diğer değerler metne çevrilir.', required: true },
    options: { type: 'LogOptions', description: 'Seviye, oyuncular ve ek değerler. Alanlar aşağıda.' },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: 'Ne kadar önemli olduğu. Panelin en düşük seviyesinin altındaki kayıtlar atılır.', default: '"info"' },
    source: { type: 'number', description: 'Bunu yapan oyuncunun server id’si; adı, karakteri ve tanımlayıcıları eklenir.' },
    target: { type: 'number', description: 'Bunun yapıldığı oyuncunun server id’si.' },
    metadata: { type: 'Record<string, unknown>', description: 'Ek değerler (miktarlar, eşya adları, koordinatlar). Tablo değilse yok sayılır.' },
  }}
/>

Bkz. [LogOptions](/tr/docs/developers/api/types#logoptions) ve [LogLevel](/tr/docs/developers/api/types#loglevel).

#### Dönüş değeri

Hiçbir şey. Seviyesi panelin en düşük seviyesinin altındaysa ya da kanalı `LogChannels` ile kapatılmışsa kayıt sessizce atılır.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:buyCar", { lock: true }, (source) => {
  const price = 25_000;
  if (!core.RemoveMoney(source, "bank", price, "car_purchase")) return fail("NOT_ENOUGH_MONEY");
  // ... arabayı oluştur ve sakla
  core.Log("purchases", "Bought a car", { source, metadata: { model: "sultan", price } });
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:buyCar', function(source)
  local price = 25000
  if not exports['ai-core']:RemoveMoney(source, 'bank', price, 'car_purchase') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  -- ... arabayı oluştur ve sakla
  exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { model = 'sultan', price = price } })
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Loglar sunucu sahibi içindir, bu yüzden mesaj İngilizce kalır ve çevrilmez. Mesajı kısa tut ve değerleri log servislerinin süzebileceği `metadata` içine koy.
</Callout>

### LogChannels

Resource’unun kanallarını tanımlar: Fivemanage ve FiveM Stats için dataset adlarını ve her birinin açık olup olmadığını. Resource’un başladığında bir kez çağır. Hiç tanımlamadığın kanallar varsayılanlarla çalışmaya devam eder.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`aiLogChannels(channels)`](/tr/docs/developers/api/lib-server/logs#ailogchannels)

```ts title="İmza"
LogChannels(channels: Record<string, LogChannel>): void
```

```lua title="Lua"
exports['ai-core']:LogChannels({ purchases = { dataset = 'myscript-sales' }, debug = { active = false } })
```

#### Parametreler

<TypeTable
  type={{
    channels: { type: 'Record<string, LogChannel>', description: 'Kanal adından ayarlarına. Her birinin alanları aşağıda.', required: true },
  }}
/>

#### LogChannel

<TypeTable
  type={{
    dataset: { type: 'string', description: 'Fivemanage ve FiveM Stats için dataset adı.', default: 'resource’un adı' },
    active: { type: 'boolean', description: '`false` kanalı kapatır: kayıtları atılır.', default: 'true' },
  }}
/>

Bkz. [LogChannel](/tr/docs/developers/api/types#logchannel).

#### Dönüş değeri

Hiçbir şey. İkinci bir çağrı resource’unun tüm tanımını değiştirir. Resource’un durduğunda silinir. Tablo olmayan bir değer hiçbir şey yapmaz.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Açılışta bir kez.
core.LogChannels({
  purchases: { dataset: "myscript-sales" },
  robberies: { dataset: "myscript-crime" },
  debug: { active: false },
});
```
</Tab>
<Tab value="Lua">
```lua
exports['ai-core']:LogChannels({
  purchases = { dataset = 'myscript-sales' },
  robberies = { dataset = 'myscript-crime' },
  debug = { active = false },
})
```
</Tab>
</Tabs>

<Callout type="warn">
Webhook url’leri asla buraya ya da resource’unun herhangi bir yerine girmez: sunucu sahibi onları ai-core’un panelinde ayarlar, panel de onları paylaşılmayan bir dosyada tutar.
</Callout>
