---
title: Door locks
description: Lock, unlock and read doors through whichever door lock script the server runs.
icon: DoorClosed
---

Door calls go through ai-core, never through a door lock script's own exports or events (ai-doorlock included). ai-core forwards each call to the **active door lock script**: the one the panel's **Door lock script** setting picks, or the first one running (ai-doorlock, ox_doorlock, tgiann-doorlock and the others in the compatibility list).

A door is named by **that script's own door id**: the id you see in its door list (ai-doorlock: the door's id in the admin panel; ox_doorlock: its database number).

### GetDoorlockSystem

The resource name of the door lock script ai-core forwards to.

**Side:** Server · **Waits:** no · **Lib:** [`doors.provider()`](/docs/developers/api/lib-server/world#doorsprovider)

```ts title="Signature"
GetDoorlockSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetDoorlockSystem() -- string or nil
```

#### Parameters

None.

#### Returns

`string | null`: the door lock script's resource name. `null` when none runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// The door ids in your config belong to one door lock script: warn when another runs.
if (core.GetDoorlockSystem() !== "ai-doorlock")
  console.log("myscript: door ids are written for ai-doorlock");
```
</Tab>
<Tab value="Lua">
```lua
if exports['ai-core']:GetDoorlockSystem() ~= 'ai-doorlock' then
  print('myscript: door ids are written for ai-doorlock')
end
```
</Tab>
</Tabs>

### SetDoorLocked

Locks or unlocks a door.

**Side:** Server · **Waits:** no · **Lib:** [`doors.setLocked`](/docs/developers/api/lib-server/world#doorssetlocked)

```ts title="Signature"
SetDoorLocked(id: string, locked: boolean, by?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDoorLocked('pacific_vault', false, source)
```

#### Parameters

<TypeTable
  type={{
    id: { type: 'string', description: 'The door lock script door id. A whole number (ox_doorlock ids) is turned into text. At most 128 characters.', required: true },
    locked: { type: 'boolean', description: '`true` locks, `false` unlocks. Must be a real boolean.', required: true },
    by: { type: 'number', description: 'Server id of the player who does it. Door lock scripts without a server API need a player whose game carries the change; ignored when that player is not online.' },
  }}
/>

#### Returns

`boolean`: `true` when the door lock script accepted the change. `false` when no door lock script runs, the door is unknown, the script refused, `id` is empty or `locked` is not a boolean.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, progressFor, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const VAULT = { x: 253.9, y: 225.2, z: 101.9 };

onClientCallback("myscript:hackVault", { guards: [near(VAULT, 2)], lock: true }, async (source) => {
  if (!core.HasItem(source, "laptop")) return fail("NO_LAPTOP");
  if (!(await progressFor(source, { label: Locale("HACKING"), duration: 15000 }))) return fail("CANCELLED");
  return core.SetDoorLocked("pacific_vault", false, source) ? { ok: true } : fail("DOOR_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local VAULT = vector3(253.9, 225.2, 101.9)

aiLib.onClientCallback('myscript:hackVault', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - VAULT) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:HasItem(source, 'laptop') then return aiLib.fail('NO_LAPTOP') end
  if not aiLib.progressFor(source, { label = Locale('HACKING'), duration = 15000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:SetDoorLocked('pacific_vault', false, source) then return aiLib.fail('DOOR_FAILED') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### IsDoorLocked

Whether a door is locked.

**Side:** Server · **Waits:** no · **Lib:** [`doors.isLocked`](/docs/developers/api/lib-server/world#doorsislocked)

```ts title="Signature"
IsDoorLocked(id: string): boolean | null
```

```lua title="Lua"
local locked = exports['ai-core']:IsDoorLocked('pacific_vault') -- true, false or nil
```

#### Parameters

<TypeTable
  type={{
    id: { type: 'string', description: 'The door lock script door id (a whole number is turned into text).', required: true },
  }}
/>

#### Returns

`boolean | null`: `true` locked, `false` unlocked. `null` when it is unknown: no door lock script runs, the door does not exist, the script cannot tell on the server, or `id` is empty.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The heist may start only while the vault is still closed. */
export function vaultClosed(): boolean {
  return core.IsDoorLocked("pacific_vault") !== false;
}
```
</Tab>
<Tab value="Lua">
```lua
function VaultClosed()
  return exports['ai-core']:IsDoorLocked('pacific_vault') ~= false
end
```
</Tab>
</Tabs>

<Callout type="info">
Decide what `null` means for your feature. The example treats "unknown" as closed, so a missing door lock script never opens the heist early.
</Callout>
