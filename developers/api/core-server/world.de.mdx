---
title: Zeit und Wetter
description: Wetter und Spielzeit, Blackout und eingefrorene Zeit lesen und setzen, über das Wetter-Skript, das der Server nutzt.
icon: CloudSun
---

Zeit und Wetter laufen über ai-core, nie über die eigenen Exports oder Events eines Wetter-Skripts. ai-core leitet jeden Aufruf an das **erste laufende Wetter-Skript** weiter: Renewed-Weathersync, av_weather, cd_easytime, dann qb-weathersync (ai-weathersync antwortet unter diesem Namen). Sie alle folgen dem Vertrag von qb-weathersync. Solange keines läuft, antwortet jeder Aufruf mit `null` oder `false`.

Um die Synchronisierung im Spiel eines einzelnen Spielers anzuhalten (ein Interior mit eigenem Licht, eine Zwischensequenz), nutze die Clientseite (`PauseWorldSync`, Lib `world.pauseSync`); siehe [Client-Exports](/de/docs/developers/api/core-client).

### GetWeather

Der aktuelle Wettertyp.

**Seite:** Server · **Wartet:** nein · **Lib:** [`world.getWeather`](/de/docs/developers/api/lib-server/world#worldgetweather)

```ts title="Signature"
GetWeather(): string | null
```

```lua title="Lua"
local weather = exports['ai-core']:GetWeather() -- 'EXTRASUNNY', 'RAIN'... oder nil
```

#### Parameter

Keine.

#### Rückgabe

`string | null`: der Wettertyp in Großbuchstaben (`EXTRASUNNY`, `CLEAR`, `RAIN`, `THUNDER`...). `null`, wenn kein Wetter-Skript läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Straßenrennen bringen im Regen mehr. */
export function raceBonus(): number {
  const weather = core.GetWeather();
  return weather === "RAIN" || weather === "THUNDER" ? 1.25 : 1;
}
```
</Tab>
<Tab value="Lua">
```lua
function RaceBonus()
  local weather = exports['ai-core']:GetWeather()
  if weather == 'RAIN' or weather == 'THUNDER' then return 1.25 end
  return 1.0
end
```
</Tab>
</Tabs>

### SetWeather

Setzt das Wetter für alle.

**Seite:** Server · **Wartet:** nein · **Lib:** [`world.setWeather`](/de/docs/developers/api/lib-server/world#worldsetweather) (nimmt die typisierten `Weather`-Namen)

```ts title="Signature"
SetWeather(type: string): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetWeather('RAIN')
```

#### Parameter

<TypeTable
  type={{
    type: { type: 'string', description: 'Ein Wettertyp des Vertrags von qb-weathersync: `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Wird vor dem Senden in Großbuchstaben umgewandelt.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Wetter-Skript es angenommen hat. `false`, wenn `type` kein Text ist, das Skript es abgelehnt hat (ein unbekannter Typ) oder kein Wetter-Skript läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";
import { isWeather } from "@aifivem/shared";

const core = resourceExport("ai-core");

addCommand("weather", { help: "Sets the weather", params: [{ name: "type", type: "string" }], restricted: true }, (_source, args) => {
  const type = args.type.toUpperCase();
  if (!isWeather(type)) return console.log("unknown weather type");
  core.SetWeather(type);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { help = 'Sets the weather', params = { { name = 'type', type = 'string' } }, restricted = true }, function(_, args)
  if not exports['ai-core']:SetWeather(args.type) then print('weather refused') end
end)
```
</Tab>
</Tabs>

### GetTime

Die Spielzeit (die Uhr im Spiel).

**Seite:** Server · **Wartet:** nein · **Lib:** [`world.getTime`](/de/docs/developers/api/lib-server/world#worldgettime)

```ts title="Signature"
GetTime(): { hour: number; minute: number } | null
```

```lua title="Lua"
local time = exports['ai-core']:GetTime() -- { hour, minute } oder nil
```

#### Parameter

Keine.

#### Rückgabe

`{ hour, minute } | null`: Stunde 0-23 und Minute 0-59. `null`, wenn kein Wetter-Skript läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Der Drogendealer verkauft nur nachts (22:00 - 05:59 Spielzeit).
onClientCallback("myscript:dealer", (source) => {
  const time = core.GetTime();
  const night = time !== null && (time.hour >= 22 || time.hour < 6);
  return night ? { ok: true } : fail("COME_BACK_AT_NIGHT");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:dealer', function(source)
  local time = exports['ai-core']:GetTime()
  if not time or (time.hour < 22 and time.hour >= 6) then return aiLib.fail('COME_BACK_AT_NIGHT') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SetTime

Setzt die Spielzeit für alle.

**Seite:** Server · **Wartet:** nein · **Lib:** [`world.setTime`](/de/docs/developers/api/lib-server/world#worldsettime)

```ts title="Signature"
SetTime(hour: number, minute?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetTime(12, 0)
```

#### Parameter

<TypeTable
  type={{
    hour: { type: 'number', description: 'Stunde, 0-23. Abgerundet und umgebrochen (24 wird zu 0).', required: true },
    minute: { type: 'number', description: 'Minute, 0-59. Abgerundet und umgebrochen.', default: '0' },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Wetter-Skript es angenommen hat. `false`, wenn `hour` keine Zahl ist, das Skript abgelehnt hat oder kein Wetter-Skript läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("noon", { help: "Sets the time to 12:00", restricted: true }, () => {
  core.SetTime(12, 0);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('noon', { help = 'Sets the time to 12:00', restricted = true }, function()
  exports['ai-core']:SetTime(12, 0)
end)
```
</Tab>
</Tabs>

### SetBlackout

Schaltet den Blackout der Stadt (alle künstlichen Lichter aus) ein oder aus.

**Seite:** Server · **Wartet:** nein · **Lib:** [`world.setBlackout`](/de/docs/developers/api/lib-server/world#worldsetblackout)

```ts title="Signature"
SetBlackout(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetBlackout(true)
```

#### Parameter

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` schaltet den Blackout ein. Alles außer `true` schaltet ihn aus.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Wetter-Skript es angenommen hat. `false`, wenn das Skript keinen Blackout hat, abgelehnt hat oder kein Wetter-Skript läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Das Kraftwerk wurde sabotiert: 5 Minuten Dunkelheit. */
export function sabotagePowerPlant(): void {
  if (!core.SetBlackout(true)) return;
  setTimeout(() => core.SetBlackout(false), 5 * 60_000);
}
```
</Tab>
<Tab value="Lua">
```lua
function SabotagePowerPlant()
  if not exports['ai-core']:SetBlackout(true) then return end
  SetTimeout(5 * 60000, function() exports['ai-core']:SetBlackout(false) end)
end
```
</Tab>
</Tabs>

### FreezeTime

Hält die Spieluhr an oder lässt sie wieder laufen.

**Seite:** Server · **Wartet:** nein · **Lib:** [`world.freezeTime`](/de/docs/developers/api/lib-server/world#worldfreezetime)

```ts title="Signature"
FreezeTime(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:FreezeTime(true)
```

#### Parameter

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` friert die Uhr ein. Alles außer `true` lässt sie laufen.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Wetter-Skript es angenommen hat. `false`, wenn das Skript die Zeit nicht einfrieren kann, abgelehnt hat oder kein Wetter-Skript läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Eine Event-Nacht: immer 21:00.
addCommand("eventnight", { help: "Freezes the clock at 21:00", restricted: true }, () => {
  core.SetTime(21, 0);
  core.FreezeTime(true);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('eventnight', { help = 'Freezes the clock at 21:00', restricted = true }, function()
  exports['ai-core']:SetTime(21, 0)
  exports['ai-core']:FreezeTime(true)
end)
```
</Tab>
</Tabs>
