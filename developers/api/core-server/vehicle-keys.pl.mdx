title: Klucze pojazdów
description: Dawaj, zabieraj i sprawdzaj klucze pojazdów przez skrypt kluczy, którego używa serwer.
icon: KeyRound
---

Każde wywołanie kluczy przechodzi przez ai-core, nigdy przez własne eksporty skryptu kluczy (łącznie z ai-vehiclekeys). ai-core przekazuje je do **aktywnego systemu kluczy**: tego, który wybiera ustawienie **Key script** w panelu, albo pierwszego działającego. Gdy nie działa żaden skrypt kluczy, każdy gracz liczy się jako mający każdy klucz.

**Pojazd** podaje się albo jako serwerowy uchwyt encji (liczba, którą zwraca `CreateVehicleServerSetter` lub `spawnVehicle`), albo jako tekst tablicy rejestracyjnej. Tablica jest najpierw przycinana i zamieniana na wielkie litery, więc `" ab12cde "` i `"AB12CDE"` to ten sam klucz.

Każdy klucz ma **cel**, który mówi systemowi kluczy, dlaczego gracz go dostaje. Niektóre systemy kluczy traktują cele inaczej (kupiony pojazd dostaje nowy przedmiot klucza, pojazd służbowy klucz zamocowany w stacyjce). Zobacz [KeyPurpose](/pl/docs/developers/api/types#keypurpose).

| Cel | Kiedy |
| --- | --- |
| `purchase` | Gracz jest teraz właścicielem pojazdu (dealer, nadanie przez admina): nowy klucz, starsze kopie przestają działać. |
| `garage` | Posiadany pojazd wyjęty z garażu: właściciel ma już klucz. |
| `job` | Pojazd służbowy na czas zmiany. |
| `rental` | Wypożyczony pojazd na czas wypożyczenia. |
| `temporary` | Wszystko inne krótkotrwałe (spawn admina, jazda próbna, pojazd z napadu). Domyślne. |

### GiveVehicleKeys

Daje graczowi klucze pojazdu.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`vehicleKeys.give`](/pl/docs/developers/api/lib-server/vehicles#vehiclekeysgive) (a [`spawnVehicle({ keysTo, purpose })`](/pl/docs/developers/api/lib-server/vehicles#spawnvehicle) daje je za ciebie)

```ts title="Sygnatura"
GiveVehicleKeys(source: number, vehicle: number | string, purpose?: KeyPurpose): void
```

```lua title="Lua"
exports['ai-core']:GiveVehicleKeys(source, vehicle, 'rental')
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza, który dostaje klucze.', required: true },
    vehicle: { type: 'number | string', description: 'Serwerowy uchwyt encji pojazdu albo jego tablica rejestracyjna.', required: true },
    purpose: { type: 'KeyPurpose', description: 'Dlaczego gracz je dostaje. Każda inna wartość liczy się jako `temporary`.', default: '"temporary"', typeDescription: '"purchase" | "garage" | "job" | "rental" | "temporary"' },
  }}
/>

#### Zwraca

Nic. Wywołanie nic nie robi, gdy encja pojazdu nie istnieje, tablica jest pusta, `source` nie jest liczbą albo nie działa żaden system kluczy. Błąd systemu kluczy jest zapisywany w logu, nie rzucany.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, spawnVehicle } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const SPAWN = { x: -1023.5, y: -2694.1, z: 13.9, heading: 150 };

onClientCallback("myscript:rentScooter", { lock: true }, async (source) => {
  if (!core.RemoveMoney(source, "cash", 100, "scooter_rental")) return fail("NOT_ENOUGH_MONEY");
  const vehicle = await spawnVehicle({ model: "faggio", coords: SPAWN, asker: source });
  if (!vehicle) {
    core.AddMoney(source, "cash", 100, "scooter_rental_refund");
    return fail("SPAWN_FAILED");
  }
  core.GiveVehicleKeys(source, vehicle, "rental");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local SPAWN = vector4(-1023.5, -2694.1, 13.9, 150.0)

aiLib.onClientCallback('myscript:rentScooter', function(source)
  if not exports['ai-core']:RemoveMoney(source, 'cash', 100, 'scooter_rental') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  local vehicle = aiLib.spawnVehicle({ model = 'faggio', coords = SPAWN, asker = source })
  if not vehicle then
    exports['ai-core']:AddMoney(source, 'cash', 100, 'scooter_rental_refund')
    return aiLib.fail('SPAWN_FAILED')
  end
  exports['ai-core']:GiveVehicleKeys(source, vehicle, 'rental')
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Świeżo utworzony pojazd nie ma na serwerze tablicy, dopóki klient właściciela jej nie zsynchronizuje. Przekazuj encję, a nie tablicę odczytaną zaraz po utworzeniu; `spawnVehicle` z liba czeka na tablicę i może sam dać klucze (`keysTo`, `purpose`).
</Callout>

### RemoveVehicleKeys

Zabiera graczowi klucze pojazdu.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`vehicleKeys.remove`](/pl/docs/developers/api/lib-server/vehicles#vehiclekeysremove)

```ts title="Sygnatura"
RemoveVehicleKeys(source: number, vehicle: number | string): void
```

```lua title="Lua"
exports['ai-core']:RemoveVehicleKeys(source, 'AB12CDE')
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },
    vehicle: { type: 'number | string', description: 'Serwerowy uchwyt encji pojazdu albo jego tablica rejestracyjna.', required: true },
  }}
/>

#### Zwraca

Nic. Te same ciche przypadki co w `GiveVehicleKeys`.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The rental ended: the keys go, then the scooter. */
export function endRental(source: number, vehicle: number): void {
  core.RemoveVehicleKeys(source, vehicle);
  if (DoesEntityExist(vehicle)) DeleteEntity(vehicle);
}
```
</Tab>
<Tab value="Lua">
```lua
function EndRental(source, vehicle)
  exports['ai-core']:RemoveVehicleKeys(source, vehicle)
  if DoesEntityExist(vehicle) then DeleteEntity(vehicle) end
end
```
</Tab>
</Tabs>

<Callout type="warn">
Zabierz klucze przed usunięciem pojazdu. Niektóre systemy kluczy czytają tablicę z encji, co zawodzi, gdy jej już nie ma.
</Callout>

### HasVehicleKeys

Czy gracz ma klucze pojazdu.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`vehicleKeys.has`](/pl/docs/developers/api/lib-server/vehicles#vehiclekeyshas)

```ts title="Sygnatura"
HasVehicleKeys(source: number, vehicle: number | string): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasVehicleKeys(source, vehicle)
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },
    vehicle: { type: 'number | string', description: 'Serwerowy uchwyt encji pojazdu albo jego tablica rejestracyjna.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy gracz ma klucze. Także `true`, gdy nie działa żaden system kluczy, gdy system kluczy nie umie odpowiedzieć na to pytanie albo gdy zawodzi, więc brak skryptu kluczy nigdy nie blokuje graczy. `false`, gdy gracz nie ma klucza, encja pojazdu nie istnieje, tablica jest pusta albo `source` nie jest liczbą.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Otwarcie bagażnika samochodu obok gracza wymaga jego kluczy.
onClientCallback("myscript:openTrunk", { args: oneArg(readId) }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 4 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.HasVehicleKeys(source, vehicle)) return fail("NO_KEYS");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:openTrunk', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 4 }) -- 0, gdy nie w pobliżu
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:HasVehicleKeys(source, vehicle) then return aiLib.fail('NO_KEYS') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
