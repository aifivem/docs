Każdy zasób loguje przez ai-core. Twój zasób podaje **kanał** (`purchases`, `robberies`) i pisze wiadomość; ai-core decyduje, dokąd ona trafia. Właściciel serwera włącza dostawców w panelu administratora (konsola, Discord, Fivemanage, FiveM Stats), ustawia minimalny poziom i wkleja url webhooków Discorda dla każdego zasobu i kanału. Zasób nigdy sam nie wysyła niczego na webhook ani do usługi logów i nigdy nie trzyma url webhooka.

Przekazuj zaangażowanych graczy jako `source` i `target` zamiast wpisywać ich imiona do wiadomości: ai-core dodaje imię każdego gracza, postać, citizen id i identyfikatory (IP tylko wtedy, gdy panel na to pozwala).

### Log

Wysyła jeden wpis logu twojego zasobu.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`aiLog(channel, message, options?)`](/pl/docs/developers/api/lib-server/logs#ailog) (Lua: `aiLib.aiLog`; oba wypisują do konsoli, dopóki ai-core nie działa)

```ts title="Sygnatura"
Log(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { price = 25000 } })
```

#### Parametry

<TypeTable
  type={{
    channel: { type: 'string', description: 'Nazwa kanału twojego zasobu (`purchases`). Webhook i przełącznik włącz/wyłącz są per kanał. `log`, gdy nie jest tekstem.', required: true },
    message: { type: 'string', description: 'Co się stało, prostym angielskim. Inne wartości są zamieniane na tekst.', required: true },
    options: { type: 'LogOptions', description: 'Poziom, gracze i dodatkowe wartości. Pola poniżej.' },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: 'Jak ważny jest wpis. Wpisy poniżej minimalnego poziomu z panelu są odrzucane.', default: '"info"' },
    source: { type: 'number', description: 'Id serwera gracza, który to zrobił; dodawane są jego imię, postać i identyfikatory.' },
    target: { type: 'number', description: 'Id serwera gracza, któremu to zrobiono.' },
    metadata: { type: 'Record<string, unknown>', description: 'Dodatkowe wartości (kwoty, nazwy przedmiotów, współrzędne). Nie tabela: ignorowane.' },
  }}
/>

Zobacz [LogOptions](/pl/docs/developers/api/types#logoptions) i [LogLevel](/pl/docs/developers/api/types#loglevel).

#### Zwraca

Nic. Wpis jest po cichu odrzucany, gdy jego poziom jest poniżej minimum z panelu albo jego kanał jest wyłączony przez `LogChannels`.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:buyCar", { lock: true }, (source) => {
  const price = 25_000;
  if (!core.RemoveMoney(source, "bank", price, "car_purchase")) return fail("NOT_ENOUGH_MONEY");
  // ... utwórz i zapisz samochód
  core.Log("purchases", "Bought a car", { source, metadata: { model: "sultan", price } });
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:buyCar', function(source)
  local price = 25000
  if not exports['ai-core']:RemoveMoney(source, 'bank', price, 'car_purchase') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  -- ... utwórz i zapisz samochód
  exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { model = 'sultan', price = price } })
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Logi są dla właściciela serwera, więc wiadomość zostaje po angielsku i nie jest tłumaczona. Trzymaj wiadomość krótką, a wartości wkładaj do `metadata`, gdzie usługi logów mogą je filtrować.
</Callout>

### LogChannels

Opisuje kanały twojego zasobu: ich nazwę zbioru danych dla Fivemanage i FiveM Stats oraz czy każdy jest włączony. Wywołaj to raz, gdy twój zasób startuje. Kanały, których nigdy nie opiszesz, i tak działają z wartościami domyślnymi.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`aiLogChannels(channels)`](/pl/docs/developers/api/lib-server/logs#ailogchannels)

```ts title="Sygnatura"
LogChannels(channels: Record<string, LogChannel>): void
```

```lua title="Lua"
exports['ai-core']:LogChannels({ purchases = { dataset = 'myscript-sales' }, debug = { active = false } })
```

#### Parametry

<TypeTable
  type={{
    channels: { type: 'Record<string, LogChannel>', description: 'Nazwa kanału na jego ustawienia. Pola każdego poniżej.', required: true },
  }}
/>

#### LogChannel

<TypeTable
  type={{
    dataset: { type: 'string', description: 'Nazwa zbioru danych dla Fivemanage i FiveM Stats.', default: 'nazwa zasobu' },
    active: { type: 'boolean', description: '`false` wyłącza kanał: jego wpisy są odrzucane.', default: 'true' },
  }}
/>

Zobacz [LogChannel](/pl/docs/developers/api/types#logchannel).

#### Zwraca

Nic. Drugie wywołanie zastępuje cały opis twojego zasobu. Jest usuwany, gdy twój zasób się zatrzymuje. Wartość, która nie jest tabelą, nic nie robi.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Raz przy starcie.
core.LogChannels({
  purchases: { dataset: "myscript-sales" },
  robberies: { dataset: "myscript-crime" },
  debug: { active: false },
});
```
</Tab>
<Tab value="Lua">
```lua
exports['ai-core']:LogChannels({
  purchases = { dataset = 'myscript-sales' },
  robberies = { dataset = 'myscript-crime' },
  debug = { active = false },
})
```
</Tab>
</Tabs>

<Callout type="warn">
Url webhooków nigdy nie trafiają tutaj ani nigdzie w twoim zasobie: właściciel serwera ustawia je w panelu ai-core, który trzyma je w pliku, który nie jest udostępniany.
</Callout>
