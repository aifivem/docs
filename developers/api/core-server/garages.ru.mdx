Вызовы гаражей идут через ai-core, а не через собственные экспорты или события скрипта гаражей (включая ai-garages). ai-core передаёт каждый вызов **активному скрипту гаражей**: тому, что выбран в настройке панели **Garage script**, или первому запущенному (ai-garages, jg-advancedgarages, tgiann-realparking и остальные из списка совместимости). Каждый скрипт отвечает только на те действия, которые у него действительно есть, поэтому любое действие может отвечать `false` или `null` с одним скриптом и работать с другим.

Транспорт задаётся **серверным хэндлом сущности**.

### GetGarageSystem

Имя ресурса скрипта гаражей, которому ai-core передаёт вызовы.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`garages.provider()`](/ru/docs/developers/api/lib-server/vehicles#garagesprovider)

```ts title="Сигнатура"
GetGarageSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetGarageSystem() -- string или nil
```

#### Параметры

Нет.

#### Возвращает

`string | null`: имя ресурса скрипта гаражей. `null`, когда ни один не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("garagesystem", { help: "Shows the garage script in use", restricted: true }, () => {
  console.log(core.GetGarageSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('garagesystem', { help = 'Shows the garage script in use', restricted = true }, function()
  print(exports['ai-core']:GetGarageSystem() or 'none')
end)
```
</Tab>
</Tabs>

### ImpoundVehicle

Отправляет транспорт из мира на штрафстоянку. Со скриптами гаражей, у которых есть только форма штрафстоянки на экране игрока, вместо этого открывает эту форму игроку из `by`.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`garages.impound`](/ru/docs/developers/api/lib-server/vehicles#garagesimpound)

```ts title="Сигнатура"
ImpoundVehicle(vehicle: number, by?: number): boolean
```

```lua title="Lua"
local taken = exports['ai-core']:ImpoundVehicle(vehicle, source)
```

#### Параметры

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Серверный хэндл сущности транспорта.', required: true },
    by: { type: 'number', description: 'Серверный id игрока, который отправляет транспорт на штрафстоянку (офицер). Нужен скриптам с формой штрафстоянки; игнорируется, если его нет в сети.' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда скрипт гаражей забрал транспорт (или открыл свою форму). `false`, когда ничто его не забрало: ни один скрипт гаражей не работает, у него нет штрафстоянки, это не знакомый ему транспорт или `vehicle` не является существующим транспортом. При `false` транспорт всё ещё в мире: удалите его сами, если он должен исчезнуть.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aicore-fivem/lib/server";
import { fail, oneArg, readId } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:impound", { args: oneArg(readId) }, (source, netId) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  const vehicle = vehicleNearPlayer(source, netId, { metres: 5 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.ImpoundVehicle(vehicle, source)) DeleteEntity(vehicle);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:impound', function(source, netId)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 5 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:ImpoundVehicle(vehicle, source) then DeleteEntity(vehicle) end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### StoreVehicleInGarage

Ставит транспорт из мира в гараж вместе с его состоянием.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`garages.store`](/ru/docs/developers/api/lib-server/vehicles#garagesstore)

```ts title="Сигнатура"
StoreVehicleInGarage(vehicle: number, garage?: string | null, by?: number): boolean
```

```lua title="Lua"
local stored = exports['ai-core']:StoreVehicleInGarage(vehicle, 'legion', source)
```

#### Параметры

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Серверный хэндл сущности транспорта.', required: true },
    garage: { type: 'string | null', description: 'Id гаража в скрипте гаражей. `null` или не указан: выбирает скрипт.', default: 'null' },
    by: { type: 'number', description: 'Серверный id игрока, который ставит транспорт. Скрипты с клиентским API действуют в игре этого игрока; игнорируется, если его нет в сети.' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда скрипт гаражей принял транспорт. `false`, когда ничто его не приняло (нет скрипта гаражей, нет действия парковки, неизвестный гараж, транспорт, которым скрипт не владеет) или `vehicle` не является существующим транспортом.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleOf } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Парковщик ставит машину, которой управляет игрок, в ближайший гараж.
onClientCallback("myscript:valetStore", (source) => {
  const vehicle = vehicleOf(source, { driver: true });
  if (!vehicle) return fail("NOT_DRIVING");
  return core.StoreVehicleInGarage(vehicle, null, source) ? { ok: true } : fail("STORE_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:valetStore', function(source)
  local ped = GetPlayerPed(source)
  local vehicle = GetVehiclePedIsIn(ped, false)
  if vehicle == 0 or GetPedInVehicleSeat(vehicle, -1) ~= ped then return aiLib.fail('NOT_DRIVING') end
  if not exports['ai-core']:StoreVehicleInGarage(vehicle, nil, source) then return aiLib.fail('STORE_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### OpenGarage

Открывает игроку меню гаража активного скрипта гаражей.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`garages.open`](/ru/docs/developers/api/lib-server/vehicles#garagesopen)

```ts title="Сигнатура"
OpenGarage(source: number, garage?: string | null): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenGarage(source, 'legion')
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
    garage: { type: 'string | null', description: 'Id гаража в скрипте гаражей. `null` или не указан: значение скрипта по умолчанию.', default: 'null' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда меню открылось. `false`, когда игрока нет в сети, ни один скрипт гаражей не работает или у него нет меню, которое можно открыть извне.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const MOTEL_GARAGE = { x: 273.1, y: -343.9, z: 44.9 };

onClientCallback("myscript:motelGarage", { guards: [near(MOTEL_GARAGE, 3)] }, (source) =>
  core.OpenGarage(source, "motel") ? { ok: true } : fail("GARAGE_FAILED"),
);
```
</Tab>
<Tab value="Lua">
```lua
local MOTEL_GARAGE = vector3(273.1, -343.9, 44.9)

aiLib.onClientCallback('myscript:motelGarage', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - MOTEL_GARAGE) > 3.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenGarage(source, 'motel') then return aiLib.fail('GARAGE_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### GetGaragedVehicles

Транспорт игрока, который хранит скрипт гаражей: в гараже или на штрафстоянке.

**Сторона:** сервер · **Ожидание:** нет (отвечает через `done`) · **Библиотека:** [`garages.stored(source)`](/ru/docs/developers/api/lib-server/vehicles#garagesstored) возвращает Promise

```ts title="Сигнатура"
GetGaragedVehicles(source: number, done: (vehicles: GaragedVehicle[] | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetGaragedVehicles(source, function(vehicles) end) -- список или nil
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
    done: { type: '(vehicles) => void', description: 'Вызывается один раз с ответом, после того как скрипт гаражей ответил.', required: true, typeDescription: '(vehicles: GaragedVehicle[] | null) => void' },
  }}
/>

#### Возвращает

Ничего. `done` получает по записи на каждый транспорт с `plate`, `model` (или `null`), `garage` (или `null`) и `impounded` ([GaragedVehicle](/ru/docs/developers/api/types#garagedvehicle)) или `null`, когда игрока нет в сети, ни один скрипт гаражей не работает, он не умеет перечислять транспорт или дал сбой. Если `done` не функция, вызов ничего не делает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import type { GaragedVehicle } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

// Стойка штрафстоянки показывает машины игрока на штрафстоянке.
onClientCallback("myscript:impoundList", async (source) => {
  const list = await new Promise<GaragedVehicle[] | null>((resolve) => core.GetGaragedVehicles(source, resolve));
  if (!list) return fail("GARAGE_UNKNOWN");
  return { ok: true, plates: list.filter((v) => v.impounded).map((v) => v.plate) };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:impoundList', function(source)
  local p = promise.new()
  exports['ai-core']:GetGaragedVehicles(source, function(list) p:resolve(list or false) end)
  local list = Citizen.Await(p)
  if not list then return aiLib.fail('GARAGE_UNKNOWN') end
  local plates = {}
  for _, v in ipairs(list) do
    if v.impounded then plates[#plates + 1] = v.plate end
  end
  return { ok = true, plates = plates }
end)
```
</Tab>
</Tabs>
