Wywołania telefonu przechodzą przez ai-core, nigdy przez własne eksporty skryptu telefonu. ai-core przekazuje każde wywołanie do **pierwszego działającego skryptu telefonu** (tgiann-phone, lb-phone, gksphone i inne z listy zgodności). Dopóki nie działa żaden telefon, każde wywołanie odpowiada `null` lub `false`.

### GetPhoneNumber

Numer telefonu gracza.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`phone.number`](/pl/docs/developers/api/lib-server/phone-appearance#phonenumber)

```ts title="Sygnatura"
GetPhoneNumber(source: number): string | null
```

```lua title="Lua"
local number = exports['ai-core']:GetPhoneNumber(source) -- string lub nil
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },
  }}
/>

#### Zwraca

`string | null`: numer tak, jak zapisuje go skrypt telefonu. `null`, gdy gracz go nie ma, nie działa żaden telefon albo `source` nie jest liczbą.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Przedmiot wizytówki pokazuje numer właściciela.
onClientCallback("myscript:myNumber", (source) => {
  const number = core.GetPhoneNumber(source);
  return number ? { ok: true, number } : fail("NO_PHONE_NUMBER");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myNumber', function(source)
  local number = exports['ai-core']:GetPhoneNumber(source)
  if not number then return aiLib.fail('NO_PHONE_NUMBER') end
  return { ok = true, number = number }
end)
```
</Tab>
</Tabs>

### GetSourceByPhone

Gracz online, który ma dany numer telefonu.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`phone.sourceOf`](/pl/docs/developers/api/lib-server/phone-appearance#phonesourceof)

```ts title="Sygnatura"
GetSourceByPhone(number: string): number | null
```

```lua title="Lua"
local src = exports['ai-core']:GetSourceByPhone('5551234') -- number lub nil
```

#### Parametry

<TypeTable
  type={{
    number: { type: 'string', description: 'Numer telefonu zapisany tak, jak zapisuje go skrypt telefonu.', required: true },
  }}
/>

#### Zwraca

`number | null`: id serwera. `null`, gdy właściciel tego numeru nie jest online, numer jest nieznany, nie działa żaden telefon albo `number` nie jest tekstem.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { notify, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** A taxi job tells the caller their cab is on the way, if they are online. */
export function cabOnTheWay(callerNumber: string): void {
  const caller = core.GetSourceByPhone(callerNumber);
  if (caller !== null) notify(caller, Locale("NOTIFY_CAB_COMING"), "info");
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function CabOnTheWay(callerNumber)
  local caller = exports['ai-core']:GetSourceByPhone(callerNumber)
  if caller then aiLib.notify(caller, Locale('NOTIFY_CAB_COMING'), 'info') end
end
```
</Tab>
</Tabs>

### HasPhone

Czy gracz ma telefon (dla skryptów telefonu, które wymagają przedmiotu telefonu: czy go nosi).

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`phone.hasPhone`](/pl/docs/developers/api/lib-server/phone-appearance#phonehasphone)

```ts title="Sygnatura"
HasPhone(source: number): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasPhone(source)
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt telefonu mówi, że gracz ma telefon. `false`, gdy nie ma, gdy nie działa żaden telefon albo `source` nie jest liczbą.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Praca, która rozdaje zadania wiadomościami tekstowymi, wymaga telefonu.
onClientCallback("myscript:startDeliveries", (source) =>
  core.HasPhone(source) ? { ok: true } : fail("NEED_PHONE"),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:startDeliveries', function(source)
  if not exports['ai-core']:HasPhone(source) then return aiLib.fail('NEED_PHONE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SendPhoneMail

Wysyła mail na telefon gracza.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`phone.mail`](/pl/docs/developers/api/lib-server/phone-appearance#phonemail)

```ts title="Sygnatura"
SendPhoneMail(to: number | string, mail: PhoneMail): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMail(source, { sender = 'LS Customs', subject = 'Invoice', message = '...' })
```

#### Parametry

<TypeTable
  type={{
    to: { type: 'number | string', description: 'Id serwera gracza (jego numer jest wyszukiwany) albo numer telefonu / adres mailowy w telefonie.', required: true },
    mail: { type: 'PhoneMail', description: 'Mail. Pola poniżej.', required: true },
  }}
/>

#### PhoneMail

<TypeTable
  type={{
    sender: { type: 'string', description: 'Pokazywany jako nadawca (firma, `Los Santos Customs`).', default: '""' },
    subject: { type: 'string', description: 'Temat. Obcinany do 120 znaków.', required: true },
    message: { type: 'string', description: 'Tekst. Obcinany do 4000 znaków.', required: true },
  }}
/>

Teksty są pokazywane tak, jak zostały podane: przekazuj przetłumaczone teksty. Zobacz [PhoneMail](/pl/docs/developers/api/types#phonemail).

#### Zwraca

`boolean`: `true`, gdy skrypt telefonu przyjął mail. `false`, gdy gracz nie ma numeru, brakuje `subject` lub `message`, nie działa żaden telefon albo odmówił.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The heist contact mails the location after the job was accepted. */
export function mailHeistLocation(source: number, street: string): void {
  core.SendPhoneMail(source, {
    sender: Locale("MAIL_CONTACT"),
    subject: Locale("MAIL_HEIST_SUBJECT"),
    message: Locale("MAIL_HEIST_BODY", street),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function MailHeistLocation(source, street)
  exports['ai-core']:SendPhoneMail(source, {
    sender = Locale('MAIL_CONTACT'),
    subject = Locale('MAIL_HEIST_SUBJECT'),
    message = Locale('MAIL_HEIST_BODY', street),
  })
end
```
</Tab>
</Tabs>

### SendPhoneMessage

Wysyła wiadomość tekstową z jednego numeru do gracza lub numeru.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`phone.message`](/pl/docs/developers/api/lib-server/phone-appearance#phonemessage)

```ts title="Sygnatura"
SendPhoneMessage(from: string, to: number | string, text: string): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMessage('Dispatch', source, 'Your cab is here.')
```

#### Parametry

<TypeTable
  type={{
    from: { type: 'string', description: 'Numer lub nazwa nadawcy, tak jak przyjmuje je skrypt telefonu.', required: true },
    to: { type: 'number | string', description: 'Id serwera gracza (jego numer jest wyszukiwany) albo numer telefonu.', required: true },
    text: { type: 'string', description: 'Wiadomość, już przetłumaczona. Obcinana do 1000 znaków.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt telefonu przyjął wiadomość. `false`, gdy odbiorca nie ma numeru, `from` lub `text` nie jest tekstem, nie działa żaden telefon albo odmówił.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The next delivery address arrives by text. */
export function textNextStop(source: number, street: string): void {
  if (!core.SendPhoneMessage(Locale("SENDER_DISPATCH"), source, Locale("TEXT_NEXT_STOP", street)))
    console.log(`player ${source} could not get the text`);
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TextNextStop(source, street)
  if not exports['ai-core']:SendPhoneMessage(Locale('SENDER_DISPATCH'), source, Locale('TEXT_NEXT_STOP', street)) then
    print(('player %d could not get the text'):format(source))
  end
end
```
</Tab>
</Tabs>

### PhoneNotify

Pokazuje powiadomienie na telefonie gracza.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`phone.notify`](/pl/docs/developers/api/lib-server/phone-appearance#phonenotify)

```ts title="Sygnatura"
PhoneNotify(source: number, notification: PhoneNotification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:PhoneNotify(source, { title = 'Bank', message = 'Salary paid', app = 'bank' })
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza.', required: true },
    notification: { type: 'PhoneNotification', description: 'Co pokazać. Pola poniżej.', required: true },
  }}
/>

#### PhoneNotification

<TypeTable
  type={{
    title: { type: 'string', description: 'Linia tytułu. Obcinana do 80 znaków.', required: true },
    message: { type: 'string', description: 'Tekst. Obcinany do 500 znaków.', default: '""' },
    app: { type: 'string', description: 'Id aplikacji telefonu, do której należy, gdy telefon ją zna (`messages`, `mail`, `bank`).' },
  }}
/>

Zobacz [PhoneNotification](/pl/docs/developers/api/types#phonenotification).

#### Zwraca

`boolean`: `true`, gdy skrypt telefonu je pokazał. `false`, gdy brakuje `title`, nie działa żaden telefon, `source` nie jest liczbą albo odmówił.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Tells the owner their car was towed. */
export function towedNotice(source: number, plate: string): void {
  core.PhoneNotify(source, { title: Locale("PHONE_TOW_TITLE"), message: Locale("PHONE_TOW_TEXT", plate) });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TowedNotice(source, plate)
  exports['ai-core']:PhoneNotify(source, { title = Locale('PHONE_TOW_TITLE'), message = Locale('PHONE_TOW_TEXT', plate) })
end
```
</Tab>
</Tabs>
