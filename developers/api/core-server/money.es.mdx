---
title: Dinero y cuentas
description: Lee y cambia los saldos de un jugador y las cuentas de trabajos y bandas, mueve dinero entre dos cuentas en una sola transacción, lee los tipos de cuenta.
icon: Wallet
---

Cada personaje tiene un saldo por **tipo de cuenta**. Los tipos vienen de la lista Accounts del panel de administración; un servidor nuevo tiene `cash`, `bank`, `black_money` y `crypto`. Cada trabajo y cada banda tiene también una cuenta de cada tipo (el dinero de la sociedad), que empieza vacía.

Cómo funciona el dinero en ai-core:

- Las cantidades son **números enteros** (dólares, sin céntimos). Una fracción, `NaN` o un número fuera del rango de enteros seguros de JavaScript se rechaza.
- Un cambio se aplica al momento en memoria y se escribe en la base de datos en unos 50 ms, junto con una fila del registro de movimientos (`ai_core_transactions`). El registro guarda el `reason` que pasas; sin él guarda el nombre del recurso que llamó.
- Un saldo no puede bajar de 0 salvo que su tipo de cuenta tenga activado **Can go below zero** (puede bajar de cero) en el panel.
- Cada cambio en la cuenta de un jugador dispara el evento de servidor `ai-core:moneyChanged (src, account, balance, delta, reason)` y llega al propio juego del jugador. Consulta [Eventos y estado](/es/docs/developers/api/events).

### GetMoney

El saldo de un jugador en una cuenta.

**Lado:** Servidor · **Espera:** no · **Lib:** ninguna

```ts title="Firma"
GetMoney(src: number, account: string): number | null
```

```lua title="Lua"
local balance = exports['ai-core']:GetMoney(source, 'bank') -- number o nil
```

#### Parámetros

<TypeTable
  type={{
    src: { type: 'number', description: 'Id de servidor del jugador.', required: true },
    account: { type: 'string', description: 'Nombre del tipo de cuenta del panel: `cash`, `bank`, `black_money`, `crypto` o uno que hayas añadido.', required: true },
  }}
/>

#### Devuelve

`number | null`: el saldo. `null` cuando el jugador no tiene un personaje cargado o el tipo de cuenta no existe.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:balance", (source) => {
  const bank = core.GetMoney(source, "bank");
  if (bank === null) return fail("NO_CHARACTER");
  return { ok: true, bank };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:balance', function(source)
  local bank = exports['ai-core']:GetMoney(source, 'bank')
  if not bank then return aiLib.fail('NO_CHARACTER') end
  return { ok = true, bank = bank }
end)
```
</Tab>
</Tabs>

### AddMoney

Añade dinero a la cuenta de un jugador. Úsalo para recompensas, sueldos que paga tu script o ingresos de ventas.

**Lado:** Servidor · **Espera:** no · **Lib:** ninguna

```ts title="Firma"
AddMoney(src: number, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:AddMoney(source, 'cash', 250, 'fishing_sale')
```

#### Parámetros

<TypeTable
  type={{
    src: { type: 'number', description: 'Id de servidor del jugador.', required: true },
    account: { type: 'string', description: 'Nombre del tipo de cuenta (`cash`, `bank`...).', required: true },
    amount: { type: 'number', description: 'Cuánto añadir. Un número entero mayor que 0.', required: true },
    reason: { type: 'string', description: 'Etiqueta corta o clave de idioma guardada en el registro de movimientos (`fishing_sale`).', default: 'el nombre del recurso que llama' },
  }}
/>

#### Devuelve

`boolean`: `true` cuando se añadió el dinero. `false` cuando el jugador no tiene un personaje cargado, el tipo de cuenta no existe o `amount` no es un número entero mayor que 0.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, inventory, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const BUYER = { x: -1845.2, y: -1197.4, z: 14.3 };

onClientCallback("myscript:sellFish", { guards: [near(BUYER, 3)], lock: true }, (source) => {
  const fish = inventory.getItemCount(source, "fish");
  if (fish < 1) return fail("NO_FISH");
  if (!inventory.removeItem(source, "fish", fish)) return fail("SELL_FAILED");
  core.AddMoney(source, "cash", fish * 25, "fishing_sale");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local BUYER = vector3(-1845.2, -1197.4, 14.3)

aiLib.onClientCallback('myscript:sellFish', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - BUYER) > 3.0 then return aiLib.fail('TOO_FAR') end
  local fish = exports['ai-core']:GetItemCount(source, 'fish')
  if fish < 1 then return aiLib.fail('NO_FISH') end
  if not exports['ai-core']:RemoveItem(source, 'fish', fish) then return aiLib.fail('SELL_FAILED') end
  exports['ai-core']:AddMoney(source, 'cash', fish * 25, 'fishing_sale')
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="warn">
Para mover dinero de una cuenta a otra (un jugador que paga a un trabajo, una transferencia bancaria), usa `TransferMoney`, no un par `RemoveMoney` + `AddMoney`: una transferencia es una sola transacción en la base de datos, un par son dos cambios separados.
</Callout>

### RemoveMoney

Quita dinero de la cuenta de un jugador. Úsalo para cobrar algo.

**Lado:** Servidor · **Espera:** no · **Lib:** ninguna

```ts title="Firma"
RemoveMoney(src: number, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local paid = exports['ai-core']:RemoveMoney(source, 'bank', 500, 'license_fee')
```

#### Parámetros

<TypeTable
  type={{
    src: { type: 'number', description: 'Id de servidor del jugador.', required: true },
    account: { type: 'string', description: 'Nombre del tipo de cuenta (`cash`, `bank`...).', required: true },
    amount: { type: 'number', description: 'Cuánto quitar. Un número entero mayor que 0.', required: true },
    reason: { type: 'string', description: 'Etiqueta corta o clave de idioma guardada en el registro de movimientos.', default: 'el nombre del recurso que llama' },
  }}
/>

#### Devuelve

`boolean`: `true` cuando se quitó el dinero. `false` cuando el saldo es demasiado bajo (y el tipo de cuenta no permite saldos negativos), el jugador no tiene un personaje cargado, el tipo de cuenta no existe o `amount` no es un número entero mayor que 0. Con `false` no cambió nada.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, inventory, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const PRICE = 500;

onClientCallback("myscript:buyLicense", { lock: true }, (source) => {
  if (!inventory.canCarryItem(source, "driver_license")) return fail("NO_SPACE");
  if (!core.RemoveMoney(source, "bank", PRICE, "license_fee")) return fail("NOT_ENOUGH_MONEY");
  inventory.addItem(source, "driver_license");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local PRICE = 500

aiLib.onClientCallback('myscript:buyLicense', function(source)
  if not exports['ai-core']:CanCarryItem(source, 'driver_license') then return aiLib.fail('NO_SPACE') end
  if not exports['ai-core']:RemoveMoney(source, 'bank', PRICE, 'license_fee') then
    return aiLib.fail('NOT_ENOUGH_MONEY')
  end
  exports['ai-core']:AddItem(source, 'driver_license')
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Comprueba lo que puede fallar antes de quitar el dinero (espacio en el inventario, existencias), o devuelve el dinero con `AddMoney` cuando falle el paso siguiente.
</Callout>

### SetMoney

Pone el saldo de un jugador a un valor exacto. Úsalo para herramientas de admin; las funciones del juego deberían añadir y quitar.

**Lado:** Servidor · **Espera:** no · **Lib:** ninguna

```ts title="Firma"
SetMoney(src: number, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetMoney(source, 'cash', 0, 'admin_reset')
```

#### Parámetros

<TypeTable
  type={{
    src: { type: 'number', description: 'Id de servidor del jugador.', required: true },
    account: { type: 'string', description: 'Nombre del tipo de cuenta (`cash`, `bank`...).', required: true },
    amount: { type: 'number', description: 'El nuevo saldo. Un número entero; menor que 0 solo cuando el tipo de cuenta permite saldos negativos.', required: true },
    reason: { type: 'string', description: 'Etiqueta corta o clave de idioma guardada en el registro de movimientos (la fila guarda la diferencia).', default: 'el nombre del recurso que llama' },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el saldo es ahora `amount` (también cuando ya lo era). `false` cuando el jugador no tiene un personaje cargado, el tipo de cuenta no existe, `amount` no es un número entero o es menor que 0 en una cuenta que no lo permite.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("setcash", {
  help: "Sets a player cash",
  params: [{ name: "id", type: "playerId" }, { name: "amount", type: "number" }],
  restricted: true,
}, (_source, args) => {
  console.log(core.SetMoney(args.id, "cash", args.amount, "admin_set") ? "done" : "refused");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('setcash', {
  help = 'Sets a player cash',
  params = { { name = 'id', type = 'playerId' }, { name = 'amount', type = 'number' } },
  restricted = true,
}, function(_, args)
  print(exports['ai-core']:SetMoney(args.id, 'cash', args.amount, 'admin_set') and 'done' or 'refused')
```

</Tab>

### GetSharedMoney

El saldo de la cuenta de un trabajo o una banda (dinero de la sociedad).

**Lado:** Servidor · **Espera:** no · **Lib:** ninguna ([`banking.societyBalance`](/es/docs/developers/api/lib-server/money#bankingsocietybalance) pregunta a la capa de banca, que puede leer de un script de banca en su lugar)

```ts title="Firma"
GetSharedMoney(ownerType: "job" | "gang", ownerId: string, account: string): number | null
```

```lua title="Lua"
local balance = exports['ai-core']:GetSharedMoney('job', 'police', 'bank') -- number o nil
```

#### Parámetros

<TypeTable
  type={{
    ownerType: { type: '"job" | "gang"', description: 'De quién es la cuenta: un trabajo o una banda.', required: true },
    ownerId: { type: 'string', description: 'El nombre del trabajo o la banda del panel (`police`, `ballas`).', required: true },
    account: { type: 'string', description: 'Nombre del tipo de cuenta (`bank`, `cash`...).', required: true },
  }}
/>

#### Devuelve

`number | null`: el saldo. `null` cuando el trabajo, la banda o el tipo de cuenta no existen (o sus cuentas aún no están cargadas).

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Un menú de jefe muestra el dinero del trabajo; solo los miembros del trabajo pueden pedirlo.
onClientCallback("myscript:societyBalance", (source) => {
  const job = online.dutyJob(source);
  if (!job) return fail("NOT_ON_DUTY");
  return { ok: true, balance: core.GetSharedMoney("job", job, "bank") ?? 0 };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:societyBalance', function(source)
  local job = exports['ai-core']:GetDutyJob(source)
  if not job then return aiLib.fail('NOT_ON_DUTY') end
  return { ok = true, balance = exports['ai-core']:GetSharedMoney('job', job, 'bank') or 0 }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Cuando el ajuste del panel **Job and gang accounts** está en **The script's own accounts**, las cuentas `bank` de los trabajos y bandas viven en ese script: entonces este export lee el saldo del script. Consulta [Banca](/es/docs/developers/api/core-server/banking).
</Callout>

### TransferMoney

Mueve dinero de una cuenta a otra en **una sola transacción de la base de datos** con ambas filas del registro. Cada lado puede ser la cuenta de un jugador cargado o la cuenta de un trabajo o una banda. Úsalo para cada pago entre dos cuentas: un jugador que paga a un negocio, una transferencia bancaria, un ingreso en la sociedad.

**Lado:** Servidor · **Espera:** no · **Lib:** [`money.transfer`](/es/docs/developers/api/lib-server/money#moneytransfer)

```ts title="Firma"
TransferMoney(from: MoneyRef, to: MoneyRef, amount: number, reason?: string, fee?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:TransferMoney(
  { source = source, account = 'bank' },
  { owner = 'job', id = 'mechanic', account = 'bank' },
  750, 'repair', 0)
```

#### Parámetros

<TypeTable
  type={{
    from: { type: 'MoneyRef', description: 'La cuenta que paga. También paga `fee`.', required: true, typeDescription: '{ source: number; account: string } | { owner: "job" | "gang"; id: string; account: string }' },
    to: { type: 'MoneyRef', description: 'La cuenta que recibe `amount`.', required: true, typeDescription: '{ source: number; account: string } | { owner: "job" | "gang"; id: string; account: string }' },
    amount: { type: 'number', description: 'Cuánto recibe `to`. Un número entero mayor que 0.', required: true },
    reason: { type: 'string', description: 'Etiqueta corta o clave de idioma guardada en ambas filas del registro.', default: 'el nombre del recurso que llama' },
    fee: { type: 'number', description: 'Cantidad extra que paga `from` y que nadie recibe (una comisión bancaria). Un número entero, 0 o más.', default: '0' },
  }}
/>

`MoneyRef` es `{ source, account }` para la cuenta de un jugador cargado, o `{ owner, id, account }` para la cuenta de un trabajo o una banda. Consulta [MoneyRef](/es/docs/developers/api/types#moneyref).

#### Devuelve

`boolean`: `true` cuando `from` pagó `amount + fee` y `to` recibió `amount`. `false` cuando falta una cuenta (jugador no cargado, trabajo desconocido, tipo de cuenta desconocido), ambos lados son la misma cuenta, `from` no puede pagar `amount + fee`, `amount` no es un número entero mayor que 0 o `fee` no es un número entero de 0 o más. Con `false` no cambió nada.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail, readInt } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Un ingreso en cajero en la cuenta de la propia banda del jugador, con una comisión del 2%.
onClientCallback(
  "myscript:gangDeposit",
  { args: ([amount]) => { const n = readInt(amount, 1, 1_000_000); return n === null ? null : [n]; }, lock: true },
  (source, amount) => {
    const gang = core.GetActiveGang(source);
    if (!gang) return fail("NO_GANG");
    const fee = Math.ceil(amount * 0.02);
    const ok = core.TransferMoney(
      { source, account: "bank" },
      { owner: "gang", id: gang, account: "bank" },
      amount, "gang_deposit", fee,
    );
    return ok ? { ok: true } : fail("NOT_ENOUGH_MONEY");
  },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:gangDeposit', function(source, amount)
  if math.type(amount) ~= 'integer' or amount < 1 or amount > 1000000 then return aiLib.fail('BAD_AMOUNT') end
  local gang = exports['ai-core']:GetActiveGang(source)
  if not gang then return aiLib.fail('NO_GANG') end
  local fee = math.ceil(amount * 0.02)
  local ok = exports['ai-core']:TransferMoney(
    { source = source, account = 'bank' },
    { owner = 'gang', id = gang, account = 'bank' },
    amount, 'gang_deposit', fee)
  if not ok then return aiLib.fail('NOT_ENOUGH_MONEY') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Ambos lados disparan su cambio habitual (el lado de un jugador dispara `ai-core:moneyChanged`). Dos jugadores pueden ser los dos lados: `{ source: a, account: "bank" }` a `{ source: b, account: "bank" }`.
</Callout>

### GetAccountTypes

Cada tipo de cuenta de la lista Accounts del panel, con su etiqueta, su cantidad inicial y si puede quedar en negativo. Úsalo para construir un menú de cuentas o para comprobar un nombre.

**Lado:** Servidor · **Espera:** no · **Lib:** ninguna

```ts title="Firma"
GetAccountTypes(): Record<string, AccountTypeDefinition>
```

```lua title="Lua"
local types = exports['ai-core']:GetAccountTypes() -- tabla con el nombre de la cuenta como clave
```

#### Parámetros

Ninguno.

#### Devuelve

`Record<string, AccountTypeDefinition>`: una copia con el nombre de la cuenta como clave (`cash`, `bank`...). Cada valor tiene `label` (lo que ven los jugadores), `start` (lo que recibe un personaje nuevo) y `allowNegative`. Consulta [AccountTypeDefinition](/es/docs/developers/api/types#accounttypedefinition).

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// La pantalla de la cartera lista cada cuenta con su etiqueta y su saldo.
onClientCallback("myscript:wallet", (source) => {
  const rows = Object.entries(core.GetAccountTypes()).map(([name, type]) => ({
    name,
    label: type.label,
    balance: core.GetMoney(source, name) ?? 0,
  }));
  return { ok: true, rows };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:wallet', function(source)
  local rows = {}
  for name, accountType in pairs(exports['ai-core']:GetAccountTypes()) do
    rows[#rows + 1] = { name = name, label = accountType.label, balance = exports['ai-core']:GetMoney(source, name) or 0 }
  end
  return { ok = true, rows = rows }
end)
```
</Tab>
</Tabs>
