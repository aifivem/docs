---
title: Médico
description: Reviva e cure jogadores e verifique se um jogador está caído, pelo script de morte que o servidor roda.
icon: HeartPulse
---

Mortes e revives passam pelo ai-core, nunca pelos exports ou state bags próprios de um script de morte (ai-death incluído). O ai-core encaminha cada chamada ao **primeiro script de morte que estiver rodando**: ai-death, qbx_medical, ars_ambulancejob, qb-ambulancejob, esx_ambulancejob e os outros da lista de compatibilidade. Sem nenhum rodando, ninguém conta como caído e nada pode ser revivido.

"Caído" significa morto ou em last stand, como o script de morte vê. Scripts de morte mantêm vivo um ped caído, então nunca use o `IsEntityDead` do jogo para perguntar se um jogador está caído.

Para reagir quando um jogador morre, escute o evento de servidor do ai-core `ai-core:playerDied (src, killer, weaponHash)` em vez de verificar a vida. Veja [Eventos e estado](/pt/docs/developers/api/events).

### GetMedicalSystem

O nome do recurso do script de morte para o qual o ai-core encaminha.

**Lado:** Servidor · **Espera:** não · **Lib:** [`medical.provider()`](/pt/docs/developers/api/lib-server/jobs#medicalprovider)

```ts title="Assinatura"
GetMedicalSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetMedicalSystem() -- string ou nil
```

#### Parâmetros

Nenhum.

#### Retorno

`string | null`: o nome do recurso do script de morte. `null` quando nenhum está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("deathsystem", { help: "Shows the death script in use", restricted: true }, () => {
  console.log(core.GetMedicalSystem() ?? "none: revive and heal do nothing");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('deathsystem', { help = 'Shows the death script in use', restricted = true }, function()
  print(exports['ai-core']:GetMedicalSystem() or 'none: revive and heal do nothing')
end)
```
</Tab>
</Tabs>

### RevivePlayer

Levanta um jogador caído onde ele está.

**Lado:** Servidor · **Espera:** não · **Lib:** [`medical.revive`](/pt/docs/developers/api/lib-server/jobs#medicalrevive)

```ts title="Assinatura"
RevivePlayer(source: number): boolean
```

```lua title="Lua"
local revived = exports['ai-core']:RevivePlayer(source)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do jogador caído.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o jogador estava caído e o script de morte o reviveu. `false` quando o jogador não estava caído, não está online, nenhum script de morte está rodando ou ele falhou.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, coordsOf, isNear, progressFor, resourceExport } from "@aicore-fivem/lib/server";
import { fail, oneArg, readId } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");

// Um médico revive um jogador caído ao lado com um kit médico.
onClientCallback("myscript:revive", { args: oneArg(readId), lock: true }, async (source, target) => {
  if (core.GetDutyJob(source) !== "ambulance") return fail("NOT_EMS");
  if (target === source || !isNear(target, coordsOf(source), 2)) return fail("TOO_FAR");
  if (!core.IsPlayerDead(target)) return fail("NOT_DOWN");
  if (!(await progressFor(source, { label: Locale("REVIVING"), duration: 10000 }))) return fail("CANCELLED");
  if (!core.RemoveItem(source, "medkit")) return fail("NO_MEDKIT");
  core.RevivePlayer(target);
  core.RefillNeeds(target);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.onClientCallback('myscript:revive', function(source, target)
  if math.type(target) ~= 'integer' or target == source then return aiLib.fail('BAD_TARGET') end
  if exports['ai-core']:GetDutyJob(source) ~= 'ambulance' then return aiLib.fail('NOT_EMS') end
  if #(GetEntityCoords(GetPlayerPed(source)) - GetEntityCoords(GetPlayerPed(target))) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:IsPlayerDead(target) then return aiLib.fail('NOT_DOWN') end
  if not aiLib.progressFor(source, { label = Locale('REVIVING'), duration = 10000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:RemoveItem(source, 'medkit') then return aiLib.fail('NO_MEDKIT') end
  exports['ai-core']:RevivePlayer(target)
  exports['ai-core']:RefillNeeds(target)
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### HealPlayer

Dá vida cheia a um jogador que não está caído.

**Lado:** Servidor · **Espera:** não · **Lib:** [`medical.heal`](/pt/docs/developers/api/lib-server/jobs#medicalheal)

```ts title="Assinatura"
HealPlayer(source: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:HealPlayer(source)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do jogador.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando a cura foi entregue ao script de morte. `false` quando o jogador não está online, nenhum script de morte está rodando ou ele falhou. Um jogador caído precisa de `RevivePlayer`; o que um script de morte faz com uma cura num jogador caído é decisão dele.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const CHECK_IN = { x: 308.4, y: -595.3, z: 43.3 };

// Check-in no hospital: pague e seja tratado.
onClientCallback("myscript:checkIn", { guards: [near(CHECK_IN, 2)], lock: true }, (source) => {
  if (core.IsPlayerDead(source)) return fail("IS_DOWN");
  if (!core.RemoveMoney(source, "bank", 250, "hospital")) return fail("NOT_ENOUGH_MONEY");
  core.HealPlayer(source);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local CHECK_IN = vector3(308.4, -595.3, 43.3)

aiLib.onClientCallback('myscript:checkIn', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - CHECK_IN) > 2.0 then return aiLib.fail('TOO_FAR') end
  if exports['ai-core']:IsPlayerDead(source) then return aiLib.fail('IS_DOWN') end
  if not exports['ai-core']:RemoveMoney(source, 'bank', 250, 'hospital') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  exports['ai-core']:HealPlayer(source)
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### IsPlayerDead

Se um jogador está caído (morto ou em last stand) no script de morte que estiver rodando.

**Lado:** Servidor · **Espera:** não · **Lib:** [`medical.isDead`](/pt/docs/developers/api/lib-server/jobs#medicalisdead) (servidor); no cliente, o `medical.isDead()` da lib lê o estado do jogador local sem uma chamada

```ts title="Assinatura"
IsPlayerDead(source: number): boolean
```

```lua title="Lua"
local down = exports['ai-core']:IsPlayerDead(source)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do jogador.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o jogador está caído. `false` quando está de pé, não está online ou nenhum script de morte está rodando.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Um jogador caído não pode abrir o menu da loja de celulares.
onClientCallback("myscript:openShop", (source) =>
  core.IsPlayerDead(source) ? fail("IS_DOWN") : { ok: true },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:openShop', function(source)
  if exports['ai-core']:IsPlayerDead(source) then return aiLib.fail('IS_DOWN') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
