---
title: Тюрьма
description: Сажать игроков в тюрьму, освобождать их и читать оставшийся срок через тот тюремный скрипт, который использует сервер.
icon: Lock
---

Тюремные вызовы идут через ai-core, а не через собственные экспорты или события тюремного скрипта (включая ai-prison). ai-core передаёт каждый вызов **первому запущенному тюремному скрипту**: ai-prison, qb-prison, rcore_prison, xt-prison, затем tgiann-policejob. Пока ни один не работает, каждый вызов отвечает `false` или `0`.

### JailPlayer

Отправляет игрока в тюрьму на заданное число минут.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`prison.jail`](/ru/docs/developers/api/lib-server/jobs#prisonjail)

```ts title="Сигнатура"
JailPlayer(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local jailed = exports['ai-core']:JailPlayer(target, 20, source)
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока, которого нужно посадить.', required: true },
    minutes: { type: 'number', description: 'Длительность срока в минутах. Больше 0.', required: true },
    by: { type: 'number', description: 'Серверный id офицера, для тюремных скриптов, которые записывают, кто это сделал.', default: '0' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда тюремный скрипт принял игрока. `false`, когда `minutes` не больше 0, `source` не число, ни один тюремный скрипт не работает или он отказал.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("jail", {
  help: "Jails a player",
  params: [{ name: "id", type: "playerId" }, { name: "minutes", type: "number" }],
  restricted: "ai.job.police",
}, (source, args) => {
  if (core.GetDutyJob(source) !== "police") return;
  core.JailPlayer(args.id, args.minutes, source);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('jail', {
  help = 'Jails a player',
  params = { { name = 'id', type = 'playerId' }, { name = 'minutes', type = 'number' } },
  restricted = 'ai.job.police',
}, function(source, args)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return end
  exports['ai-core']:JailPlayer(args.id, args.minutes, source)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Если на сервере работает MDT, запишите соответствующую запись через [`AddMdtRecord`](/ru/docs/developers/api/core-server/mdt) (`kind: "jail"`).
</Callout>

### ReleasePlayer

Выпускает игрока из тюрьмы.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`prison.release`](/ru/docs/developers/api/lib-server/jobs#prisonrelease)

```ts title="Сигнатура"
ReleasePlayer(source: number): boolean
```

```lua title="Lua"
local released = exports['ai-core']:ReleasePlayer(target)
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id заключённого.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, когда тюремный скрипт освободил игрока. `false`, когда тюремный скрипт его не освободил (например, он не был в тюрьме), `source` не число или ни один тюремный скрипт не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("unjail", { help: "Releases a player", params: [{ name: "id", type: "playerId" }], restricted: true }, (_source, args) => {
  console.log(core.ReleasePlayer(args.id) ? "released" : "not in prison");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('unjail', { help = 'Releases a player', params = { { name = 'id', type = 'playerId' } }, restricted = true }, function(_, args)
  print(exports['ai-core']:ReleasePlayer(args.id) and 'released' or 'not in prison')
end)
```
</Tab>
</Tabs>

### GetJailTime

Сколько игроку ещё осталось сидеть.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`prison.timeLeft`](/ru/docs/developers/api/lib-server/jobs#prisontimeleft)

```ts title="Сигнатура"
GetJailTime(source: number): number
```

```lua title="Lua"
local minutes = exports['ai-core']:GetJailTime(source)
```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока.', required: true },
  }}
/>

#### Возвращает

`number`: оставшиеся минуты. `0`, когда игрок не в тюрьме, `source` не число или ни один тюремный скрипт не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Заключённые не могут пользоваться телефонной будкой.
onClientCallback("myscript:phoneBooth", (source) =>
  core.GetJailTime(source) > 0 ? fail("IN_PRISON") : { ok: true },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:phoneBooth', function(source)
  if exports['ai-core']:GetJailTime(source) > 0 then return aiLib.fail('IN_PRISON') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
