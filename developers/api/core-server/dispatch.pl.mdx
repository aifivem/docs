title: Dispatch
description: Wysyłaj alerty policji (lub dowolnej pracy) przez system alertów, którego używa serwer.

Alerty policyjne przechodzą przez ai-core, nigdy przez własne eksporty lub zdarzenia skryptu alertów (łącznie z ai-policealert). ai-core przekazuje każdy alert do **aktywnego systemu alertów**: tego, który wybiera ustawienie **Alert script** w panelu, albo pierwszego działającego (wbudowane karty ai-policealert są na końcu). System alertów pokazuje go członkom prac alertu, którzy są na służbie.

ai-core odpowiada też na zdarzenie QB `police:server:policeAlert` za systemy alertów, które tego nie robią, więc alerty skryptów QB też docierają.

### SendDispatchAlert

Wysyła jeden alert. Używaj tego do wszystkiego, na co funkcjonariusze (lub inna praca) powinni zareagować: strzały, napad na sklep, skradziony samochód.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`dispatch.alert`](/pl/docs/developers/api/lib-server/jobs#dispatchalert)

```ts title="Sygnatura"
SendDispatchAlert(alert: DispatchAlert): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendDispatchAlert({ title = 'Store robbery', code = '10-90', source = source })
```

#### Zwraca

`boolean`: `true`, gdy system alertów przyjął alert. `false`, gdy brakuje `title` lub jest puste, nie działa żaden system alertów albo zawiódł.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const REGISTER = { x: 24.5, y: -1345.6, z: 29.5 };

onClientCallback("myscript:robRegister", { guards: [near(REGISTER, 2)], lock: true }, (source) => {
  if (core.GetOnDutyCount("police") < 2) return fail("NOT_ENOUGH_POLICE");
  core.SendDispatchAlert({
    code: "10-90",
    title: Locale("ALERT_STORE_ROBBERY"),
    message: Locale("ALERT_STORE_NAME"),
    coords: REGISTER,
    source,
    jobs: ["police"],
    icon: "cash-register",
    priority: "high",
  });
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local REGISTER = vector3(24.5, -1345.6, 29.5)

aiLib.onClientCallback('myscript:robRegister', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - REGISTER) > 2.0 then return aiLib.fail('TOO_FAR') end
  if exports['ai-core']:GetOnDutyCount('police') < 2 then return aiLib.fail('NOT_ENOUGH_POLICE') end
  exports['ai-core']:SendDispatchAlert({
    code = '10-90',
    title = Locale('ALERT_STORE_ROBBERY'),
    message = Locale('ALERT_STORE_NAME'),
    coords = { x = REGISTER.x, y = REGISTER.y, z = REGISTER.z },
    source = source,
    jobs = { 'police' },
    icon = 'cash-register',
    priority = 'high',
  })
  return { ok = true }
end, { lock = true })
```

<Callout type="warn">
Teksty są pokazywane tak, jak zostały podane: przetłumacz je przez `Locale` przed wysłaniem. Nie wysyłaj alertu w każdej klatce ani przy każdym trafieniu: alert o strzałach powinien mieć czas odnowienia na gracza.
</Callout>
