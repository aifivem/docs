### GetMeta

Одно значение из **метаданных** персонажа: свободного набора именованных значений, который сохраняется вместе с персонажем. Скрипты ESX и QB держат там свои дополнительные данные персонажа через мост (`hunger`, `thirst`, `armor`, `isdead`...), и ваш скрипт может хранить там свои небольшие значения.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** нет

```ts title="Сигнатура"
GetMeta(src: number, key: string): unknown
```

```lua title="Lua"
local value = exports['ai-core']:GetMeta(source, 'myscript_xp') -- любое значение или nil
```

#### Параметры

<TypeTable
  type={{
    src: { type: 'number', description: 'Серверный id игрока.', required: true },
    key: { type: 'string', description: 'Имя значения. Начинайте собственные ключи с имени своего скрипта (`myscript_xp`), чтобы они никогда не пересекались с другим скриптом.', required: true },
  }}
/>

#### Возвращает

`unknown`: сохранённое значение (число, текст, boolean, список или таблица) в том виде, в каком его задали. `null`, когда ключ не задан или у игрока нет загруженного персонажа. Проверяйте тип перед использованием: значение мог записать другой скрипт или более старая версия вашего.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The character's fishing level, 1 when none was stored yet. */
export function fishingLevel(source: number): number {
  const value = core.GetMeta(source, "myscript_level");
  return typeof value === "number" && Number.isInteger(value) && value > 0 ? value : 1;
}
```
</Tab>
<Tab value="Lua">
```lua
function FishingLevel(source)
  local value = exports['ai-core']:GetMeta(source, 'myscript_level')
  if math.type(value) == 'integer' and value > 0 then return value end
  return 1
end
```
</Tab>
</Tabs>

### SetMeta

Сохраняет одно значение в метаданных персонажа. Значение сохраняется при следующем периодическом сохранении персонажа (настройка панели, по умолчанию каждые 5 минут), при выходе и при остановке сервера.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** нет

```ts title="Сигнатура"
SetMeta(src: number, key: string, value: unknown): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetMeta(source, 'myscript_level', 3)
```

#### Параметры

<TypeTable
  type={{
    src: { type: 'number', description: 'Серверный id игрока.', required: true },
    key: { type: 'string', description: 'Имя значения. Начинайте собственные ключи с имени своего скрипта.', required: true },
    value: { type: 'unknown', description: 'Любое значение, которое помещается в JSON: число, текст, boolean, список или таблица. `null` (`nil` в Lua) удаляет ключ.', required: true },
  }}
/>

#### Возвращает

`boolean`: `true`, когда значение сохранено (или удалено). `false`, когда у игрока нет загруженного персонажа или `key` не текст.

Изменение сразу доходит до игры самого игрока и вызывает серверное событие `ai-core:metaChanged (src, key, value)`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** One level up after enough catches. */
export function levelUp(source: number): void {
  const level = core.GetMeta(source, "myscript_level");
  const next = (typeof level === "number" ? level : 1) + 1;
  core.SetMeta(source, "myscript_level", next);
}
```
</Tab>
<Tab value="Lua">
```lua
function LevelUp(source)
  local level = exports['ai-core']:GetMeta(source, 'myscript_level')
  if type(level) ~= 'number' then level = 1 end
  exports['ai-core']:SetMeta(source, 'myscript_level', level + 1)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Метаданные - для небольших значений, принадлежащих одному персонажу (уровень, флаг, несколько чисел). Растущие списки (история, каждый улов) и всё, что вы ищете или считаете по многим персонажам, должны лежать в вашей собственной таблице базы данных. Значения в метаданных сохраняются не сразу: деньги и предметы туда никогда не кладут.
</Callout>

### GetBranding

Название сервера, подзаголовок, слоганы и фоновая картинка из общих настроек панели (General). Используйте, чтобы показывать то же название в собственных полноэкранных меню.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** нет

```ts title="Сигнатура"
GetBranding(): Branding
```

```lua title="Lua"
local brand = exports['ai-core']:GetBranding() -- таблица
```

#### Параметры

Нет.

#### Возвращает

`Branding`: копия с `name`, `subtitle`, `tagline`, `taglineSub` и `background` (`"skyline"` или `"wet-drive"`, картинка в ai-core). См. [Branding](/ru/docs/developers/api/types#branding).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Экран приветствия показывает название сервера.
onClientCallback("myscript:welcome", () => {
  const { name, tagline } = core.GetBranding();
  return { ok: true, name, tagline };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:welcome', function()
  local brand = exports['ai-core']:GetBranding()
  return { ok = true, name = brand.name, tagline = brand.tagline }
end)
```
</Tab>
</Tabs>

### GetUpdates

Скрипты, у которых на GitHub есть релиз новее запущенной версии, по проверке обновлений ai-core. ai-core спрашивает GitHub не чаще раза в 6 часов на скрипт (и при старте скрипта) для каждого запущенного скрипта со строкой `repository` в его `fxmanifest.lua`, если в панели не выключено **Check for updates**.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** нет

```ts title="Сигнатура"
GetUpdates(): UpdateInfo[]
```

```lua title="Lua"
local outdated = exports['ai-core']:GetUpdates() -- список таблиц
```

#### Параметры

Нет.

#### Возвращает

`UpdateInfo[]`: по записи на каждый устаревший скрипт с `resource`, `label` (имя, под которым его знают), `current` (запущенная версия), `latest` (новейший релиз) и `url` (страница релиза). Пустой список, когда всё актуально или ещё ничего не проверялось (первая проверка идёт через 15 секунд после старта). См. [UpdateInfo](/ru/docs/developers/api/types#updateinfo).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("outdated", { help: "Lists outdated scripts", restricted: true }, () => {
  for (const u of core.GetUpdates()) console.log(`${u.label}: ${u.current} -> ${u.latest} (${u.url})`);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('outdated', { help = 'Lists outdated scripts', restricted = true }, function()
  for _, u in ipairs(exports['ai-core']:GetUpdates()) do
    print(('%s: %s -> %s (%s)'):format(u.label, u.current, u.latest, u.url))
  end
end)
```
</Tab>
</Tabs>
