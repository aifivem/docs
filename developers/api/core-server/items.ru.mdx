Каждый вызов предметов идёт через ai-core, а не через собственные экспорты скрипта инвентаря. ai-core передаёт каждый вызов **активному инвентарю**: тому, что выбран в настройке панели **Inventory script**, или первому запущенному, когда выбрано автоматически (ai-inventory, ox_inventory, qb-inventory, tgiann-inventory и остальные из списка совместимости). Когда владелец сервера меняет инвентарь, ваш скрипт продолжает работать без изменений.

Что нужно знать:

- **Инвентарь** задаётся через `InventoryRef`: серверный id игрока (число) для карманов этого игрока или текстовый id для всего остального (имя тайника, номер багажника). См. [InventoryRef](/ru/docs/developers/api/types#inventoryref).
- **Имена предметов** - это имена предметов в инвентаре (`water`, `bandage`, `WEAPON_PISTOL`).
- **Метаданные** - таблица дополнительных значений одной стопки (серийный номер, прочность). См. [ItemMetadata](/ru/docs/developers/api/types#itemmetadata).
- Пока **ни один инвентарь не работает**, каждый вызов отвечает своим «пустым» значением: `false`, `0`, пустой список или `null`.
- Тайники, магазины и используемые предметы, которые вы регистрируете, **хранит ai-core** и передаёт каждому инвентарю, который становится активным позже, в том числе после перезапуска инвентаря. Регистрируйте их один раз при старте скрипта.

### AddItem

Выдаёт предметы в инвентарь.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`inventory.addItem`](/ru/docs/developers/api/lib-server/items#inventoryadditem)

```ts title="Сигнатура"
AddItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:AddItem(source, 'water', 2)
```

#### Параметры

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Серверный id игрока или id тайника / багажника.', required: true, typeDescription: 'number | string' },
    item: { type: 'string', description: 'Имя предмета.', required: true },
    count: { type: 'number', description: 'Сколько штук. Число от 1; дробная часть отбрасывается.', default: '1' },
    metadata: { type: 'ItemMetadata', description: 'Дополнительные значения для новой стопки. Всё, что не является таблицей, игнорируется.' },
    slot: { type: 'number', description: 'Слот, в который их положить (целое число больше 0). Иначе игнорируется; слот выбирает инвентарь.' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда инвентарь добавил предметы. `false`, когда они не помещаются, предмета нет в инвентаре, аргумент неверен (`count` меньше 1, пустое имя предмета) или ни один инвентарь не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const TAP = { x: 1206.4, y: -3110.2, z: 5.6 };

onClientCallback("myscript:fillBottle", { guards: [near(TAP, 2)], lock: true }, (source) => {
  if (!core.RemoveItem(source, "empty_bottle")) return fail("NO_BOTTLE");
  if (!core.AddItem(source, "water")) {
    core.AddItem(source, "empty_bottle");
    return fail("NO_SPACE");
  }
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local TAP = vector3(1206.4, -3110.2, 5.6)

aiLib.onClientCallback('myscript:fillBottle', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - TAP) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:RemoveItem(source, 'empty_bottle') then return aiLib.fail('NO_BOTTLE') end
  if not exports['ai-core']:AddItem(source, 'water') then
    exports['ai-core']:AddItem(source, 'empty_bottle')
    return aiLib.fail('NO_SPACE')
  end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### RemoveItem

#### Параметры

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Серверный id игрока или id тайника / багажника.', required: true, typeDescription: 'number | string' },

/>

#### Возвращает

`boolean`: `true`, когда предметы забраны. `false`, когда в инвентаре их меньше (тогда не забирается ничего), аргумент неверен или ни один инвентарь не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, minigameFor, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:pickLock", { lock: true }, async (source) => {
  if (!core.HasItem(source, "lockpick")) return fail("NO_LOCKPICK");
  const result = await minigameFor(source, { game: "lockpick", minMs: 1500 });
  if (result === "broken") core.RemoveItem(source, "lockpick");
  return result === "won" ? { ok: true } : fail("LOCKPICK_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:pickLock', function(source)
  if not exports['ai-core']:HasItem(source, 'lockpick') then return aiLib.fail('NO_LOCKPICK') end

  if result == 'broken' then exports['ai-core']:RemoveItem(source, 'lockpick') end
  if result ~= 'won' then return aiLib.fail('LOCKPICK_FAILED') end
  return { ok = true }
end, { lock = true })
```
</Tab>

### HasItem

Есть ли в инвентаре хотя бы заданное количество предмета.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`inventory.hasItem`](/ru/docs/developers/api/lib-server/items#inventoryhasitem)

```ts title="Сигнатура"
HasItem(inv: InventoryRef, item: string, count?: number): boolean
```

```lua title="Lua"

```

#### Параметры

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Серверный id игрока или id тайника / багажника.', required: true, typeDescription: 'number | string' },
    item: { type: 'string', description: 'Имя предмета.', required: true },
    count: { type: 'number', description: 'Сколько нужно (1 или больше; дробная часть отбрасывается).', default: '1' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда в инвентаре `count` или больше. `false`, когда меньше, `count` меньше 1 или ни один инвентарь не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, progressFor, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");

onClientCallback("myscript:repair", { lock: true }, async (source) => {
  if (!core.HasItem(source, "repairkit")) return fail("NO_KIT");
  if (!(await progressFor(source, { label: Locale("REPAIRING"), duration: 8000 }))) return fail("CANCELLED");
  if (!core.RemoveItem(source, "repairkit")) return fail("NO_KIT");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.onClientCallback('myscript:repair', function(source)
  if not exports['ai-core']:HasItem(source, 'repairkit') then return aiLib.fail('NO_KIT') end
  if not aiLib.progressFor(source, { label = Locale('REPAIRING'), duration = 8000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:RemoveItem(source, 'repairkit') then return aiLib.fail('NO_KIT') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Проверяйте снова по ответу `RemoveItem` после всего, что ждёт (полоса прогресса, мини-игра): игрок мог тем временем выбросить предмет.
</Callout>

### GetItems

Все стопки в инвентаре, с названиями.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`inventory.getItems`](/ru/docs/developers/api/lib-server/items#inventorygetitems)

```ts title="Сигнатура"
GetItems(inv: InventoryRef): InventoryStack[]
```

```lua title="Lua"
local stacks = exports['ai-core']:GetItems(source) -- список таблиц
```

#### Параметры

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Серверный id игрока или id тайника / багажника.', required: true, typeDescription: 'number | string' },
  }}
/>

#### Возвращает

`InventoryStack[]`: по записи на каждую стопку с `name`, `label`, `count`, `slot` и `metadata`. См. [InventoryStack](/ru/docs/developers/api/types#inventorystack). Пустой список для пустого или неизвестного инвентаря, неверного аргумента или когда ни один инвентарь не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Ломбард перечисляет все предметы игрока, которые он покупает.
const BUYS: Record<string, number> = { gold_ring: 120, rolex: 400 };

onClientCallback("myscript:pawnList", (source) => ({
  ok: true,
  rows: core.GetItems(source)
    .filter((stack) => BUYS[stack.name] !== undefined)
    .map((stack) => ({ slot: stack.slot, label: stack.label, count: stack.count, price: BUYS[stack.name] })),
}));
```
</Tab>
<Tab value="Lua">
```lua
local BUYS = { gold_ring = 120, rolex = 400 }

aiLib.onClientCallback('myscript:pawnList', function(source)
  local rows = {}
  for _, stack in ipairs(exports['ai-core']:GetItems(source)) do
    if BUYS[stack.name] then
      rows[#rows + 1] = { slot = stack.slot, label = stack.label, count = stack.count, price = BUYS[stack.name] }
    end
  end
  return { ok = true, rows = rows }
end)
```
</Tab>
</Tabs>

### RegisterStash

Создаёт тайник: ящик для хранения, который игроки открывают по его имени. ai-core хранит его и снова регистрирует в каждом инвентаре, который становится активным.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`inventory.registerStash`](/ru/docs/developers/api/lib-server/items#inventoryregisterstash)

```ts title="Сигнатура"
RegisterStash(name: string, label: string, slots: number, maxWeight: number, jobs?: string[]): void
```

```lua title="Lua"
exports['ai-core']:RegisterStash('police_evidence', 'Evidence', 100, 500000, { 'police' })
```

#### Параметры

<TypeTable
  type={{
    name: { type: 'string', description: 'Уникальный id тайника, он же `InventoryRef` для его открытия (`police_evidence`).', required: true },
    label: { type: 'string', description: 'Заголовок на экране тайника. Передавайте переведённый текст.', required: true, default: 'name' },
    slots: { type: 'number', description: 'Число слотов (больше 0, округляется вниз).', required: true, default: '50' },
    maxWeight: { type: 'number', description: 'Лимит веса в единицах инвентаря (граммы в ai-inventory). Больше 0.', required: true, default: '100000' },
    jobs: { type: 'string[]', description: 'Работы, которым разрешено его открывать, в инвентарях, которые проверяют работы. Пусто: всем.', default: '[]' },
  }}
/>

Значения по умолчанию применяются, когда значение отсутствует или неверно.

#### Возвращает

Ничего. Без текстового `name` вызов ничего не делает. Повторная регистрация того же имени заменяет тайник.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const LOCKER = { x: 474.9, y: -994.7, z: 26.3 };

// Один раз при старте; ai-core передаёт его инвентарям, которые стартуют позже.
core.RegisterStash("police_evidence", Locale("STASH_EVIDENCE"), 100, 500_000, ["police"]);

onClientCallback("myscript:openEvidence", { guards: [near(LOCKER, 2)] }, (source) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  return core.OpenInventory(source, "police_evidence") ? { ok: true } : fail("STASH_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua

exports['ai-core']:RegisterStash('police_evidence', Locale('STASH_EVIDENCE'), 100, 500000, { 'police' })

  if #(GetEntityCoords(GetPlayerPed(source)) - LOCKER) > 2.0 then return aiLib.fail('TOO_FAR') end
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  if not exports['ai-core']:OpenInventory(source, 'police_evidence') then return aiLib.fail('STASH_FAILED') end
```

### OpenInventory

Открывает на экране игрока тайник, багажник или инвентарь другого игрока рядом с его собственным.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`inventory.openInventory`](/ru/docs/developers/api/lib-server/items#inventoryopeninventory)

```ts title="Сигнатура"
OpenInventory(source: number, inv: InventoryRef): boolean
```

```lua title="Lua"

```

#### Параметры

<TypeTable
  type={{
    source: { type: 'number', description: 'Серверный id игрока, который видит экран.', required: true },
    inv: { type: 'InventoryRef', description: 'Что открыть: id тайника, id багажника или серверный id другого игрока (обыск игрока).', required: true, typeDescription: 'number | string' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда инвентарь открыл экран. `false`, когда не смог (неизвестный тайник, у игрока нет инвентаря), аргумент неверен или ни один инвентарь не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, isNear, coordsOf, resourceExport } from "@aicore-fivem/lib/server";
import { fail, oneArg, readId } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Полиция обыскивает стоящего рядом игрока в наручниках.
onClientCallback("myscript:search", { args: oneArg(readId) }, (source, target) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  if (target === source || !isNear(target, coordsOf(source), 2)) return fail("TOO_FAR");
  return core.OpenInventory(source, target) ? { ok: true } : fail("SEARCH_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:search', function(source, target)
  if math.type(target) ~= 'integer' or target == source then return aiLib.fail('BAD_TARGET') end
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  local a, b = GetEntityCoords(GetPlayerPed(source)), GetEntityCoords(GetPlayerPed(target))
  if #(a - b) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenInventory(source, target) then return aiLib.fail('SEARCH_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Инвентарь здесь не проверяет ни расстояние, ни права. Проверьте работу, расстояние и состояние цели сами, прежде чем вызывать.
</Callout>

### RegisterShop

Создаёт магазин скрипта: список предметов с ценами, который ваш скрипт открывает игроку (оружейная, торговый автомат). Инвентарь рисует магазин и принимает оплату по-своему (наличные, затем банк). ai-core хранит его и передаёт каждому инвентарю, который становится активным.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`inventory.registerShop`](/ru/docs/developers/api/lib-server/items#inventoryregistershop)

```ts title="Сигнатура"
RegisterShop(name: string, label: string, items: ShopProduct[]): void
```

```lua title="Lua"
exports['ai-core']:RegisterShop('police_armoury', 'Armoury', { { name = 'bandage', price = 0 } })
```

#### Параметры

<TypeTable
  type={{
    name: { type: 'string', description: 'Уникальный id магазина (`police_armoury`).', required: true },
    label: { type: 'string', description: 'Заголовок экрана магазина. Передавайте переведённый текст.', required: true, default: 'name' },
    items: { type: 'ShopProduct[]', description: 'Товары: `{ name, price }` с целой ценой от 0 за каждый предмет. Не более 200; строки с неверным именем или ценой пропускаются.', required: true, typeDescription: '{ name: string; price: number }[]' },
  }}
/>

См. [ShopProduct](/ru/docs/developers/api/types#shopproduct).

#### Возвращает

Ничего. Без текстового `name` или без единого допустимого товара вызов ничего не делает. Повторная регистрация того же имени заменяет магазин.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const ARMOURY = { x: 482.6, y: -995.2, z: 30.7 };

core.RegisterShop("police_armoury", Locale("SHOP_ARMOURY"), [
  { name: "WEAPON_STUNGUN", price: 0 },
  { name: "bandage", price: 10 },
]);

onClientCallback("myscript:armoury", { guards: [near(ARMOURY, 2)] }, (source) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  return core.OpenShop(source, "police_armoury") ? { ok: true } : fail("SHOP_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua

exports['ai-core']:RegisterShop('police_armoury', Locale('SHOP_ARMOURY'), {

  if #(GetEntityCoords(GetPlayerPed(source)) - ARMOURY) > 2.0 then return aiLib.fail('TOO_FAR') end
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  if not exports['ai-core']:OpenShop(source, 'police_armoury') then return aiLib.fail('SHOP_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### RegisterUsableItem

Делает предмет используемым: когда игрок использует его в инвентаре, выполняется ваша функция. ai-core хранит функцию, поэтому она работает с инвентарями, которые стартуют позже, и переживает перезапуск инвентаря.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`inventory.registerUsableItem`](/ru/docs/developers/api/lib-server/items#inventoryregisterusableitem)

```ts title="Сигнатура"
RegisterUsableItem(name: string, handler: UsableItemHandler): void
// UsableItemHandler = (source: number, item: UsedItem) => unknown
```

```lua title="Lua"
exports['ai-core']:RegisterUsableItem('bandage', function(source, item) end)
```

#### Параметры

<TypeTable
  type={{
    name: { type: 'string', description: 'Имя предмета.', required: true },
    handler: { type: 'UsableItemHandler', description: 'Выполняется при каждом использовании с серверным id игрока и использованной стопкой (`name`, `slot`, `count`, `metadata`). Верните `false`, чтобы оставить предмет.', required: true, typeDescription: '(source: number, item: UsedItem) => unknown' },
  }}
/>

См. [UsableItemHandler](/ru/docs/developers/api/types#usableitemhandler) и [UsedItem](/ru/docs/developers/api/types#useditem).

#### Возвращает

Ничего. Без текстового `name` или функции вызов ничего не делает. Второй вызов для того же предмета заменяет обработчик.

Что происходит с предметом после использования, зависит от инвентаря: инвентари, которые сами забирают использованный предмет (ai-inventory забирает количество **consume** предмета), оставляют его, когда ваш обработчик возвращает `false`; другие инвентари следуют своим настройкам предметов, поэтому там при необходимости забирайте предмет сами.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { progressFor, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

core.RegisterUsableItem("bandage", (source) => {
  // Обработчик должен ответить сразу; часть со временем выполняется отдельно.
  void (async () => {
    if (!(await progressFor(source, { label: Locale("BANDAGING"), duration: 4000 }))) return;
    if (!core.RemoveItem(source, "bandage")) return;
    emitNet("myscript:client:heal", source, 25); // ваш клиентский скрипт добавляет здоровье
  })();
  return false; // оставить: он забирается выше, когда полоса закончилась
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

exports['ai-core']:RegisterUsableItem('bandage', function(source, item)
  CreateThread(function()
    if not aiLib.progressFor(source, { label = Locale('BANDAGING'), duration = 4000 }) then return end
    if not exports['ai-core']:RemoveItem(source, 'bandage') then return end
    TriggerClientEvent('myscript:client:heal', source, 25) -- ваш клиентский скрипт добавляет здоровье
  end)
  return false
end)
```
</Tab>
</Tabs>

<Callout type="info">
Использование также вызывает серверное событие `ai-core:itemUsed (src, name, status)`, за которым следят эффекты предметов вроде голода и жажды. См. [События и состояние](/ru/docs/developers/api/events).
</Callout>

### GetItemDefinition

Один предмет так, как его определяет активный инвентарь: название, вес, складывается ли в стопку, картинка.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`inventory.getItemDefinition`](/ru/docs/developers/api/lib-server/items#inventorygetitemdefinition)

<TypeTable

#### Возвращает

```ts
/** "You received 2x Water" with the inventory's own label. */
export function giveWithNotice(source: number, item: string, count: number): void {
  if (!core.AddItem(source, item, count)) return;

  notify(source, Locale("NOTIFY_RECEIVED", count, label), "success");
}
```

```lua
function GiveWithNotice(source, item, count)

end
```
