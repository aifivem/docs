---
title: Prison
description: Jail players, release them and read the time left, through whichever prison script the server runs.
icon: Lock
---

Jail calls go through ai-core, never through a prison script's own exports or events (ai-prison included). ai-core forwards each call to the **first prison script running**: ai-prison, qb-prison, rcore_prison, xt-prison, then tgiann-policejob. While none runs, every call answers `false` or `0`.

### JailPlayer

Sends a player to prison for a number of minutes.

**Side:** Server · **Waits:** no · **Lib:** [`prison.jail`](/docs/developers/api/lib-server/jobs#prisonjail)

```ts title="Signature"
JailPlayer(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local jailed = exports['ai-core']:JailPlayer(target, 20, source)
```

#### Parameters

<TypeTable
  type={{
    source: { type: 'number', description: 'Server id of the player to jail.', required: true },
    minutes: { type: 'number', description: 'Length of the sentence in minutes. Above 0.', required: true },
    by: { type: 'number', description: 'Server id of the officer, for prison scripts that record who did it.', default: '0' },
  }}
/>

#### Returns

`boolean`: `true` when the prison script took the player. `false` when `minutes` is not above 0, `source` is not a number, no prison script runs or it refused.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("jail", {
  help: "Jails a player",
  params: [{ name: "id", type: "playerId" }, { name: "minutes", type: "number" }],
  restricted: "ai.job.police",
}, (source, args) => {
  if (core.GetDutyJob(source) !== "police") return;
  core.JailPlayer(args.id, args.minutes, source);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('jail', {
  help = 'Jails a player',
  params = { { name = 'id', type = 'playerId' }, { name = 'minutes', type = 'number' } },
  restricted = 'ai.job.police',
}, function(source, args)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return end
  exports['ai-core']:JailPlayer(args.id, args.minutes, source)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Write the matching MDT record with [`AddMdtRecord`](/docs/developers/api/core-server/mdt) (`kind: "jail"`) when the server runs an MDT.
</Callout>

### ReleasePlayer

Lets a player out of prison.

**Side:** Server · **Waits:** no · **Lib:** [`prison.release`](/docs/developers/api/lib-server/jobs#prisonrelease)

```ts title="Signature"
ReleasePlayer(source: number): boolean
```

```lua title="Lua"
local released = exports['ai-core']:ReleasePlayer(target)
```

#### Parameters

<TypeTable
  type={{
    source: { type: 'number', description: 'Server id of the prisoner.', required: true },
  }}
/>

#### Returns

`boolean`: `true` when the prison script released the player. `false` when the prison script did not release them (for example, they were not in prison), `source` is not a number or no prison script runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("unjail", { help: "Releases a player", params: [{ name: "id", type: "playerId" }], restricted: true }, (_source, args) => {
  console.log(core.ReleasePlayer(args.id) ? "released" : "not in prison");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('unjail', { help = 'Releases a player', params = { { name = 'id', type = 'playerId' } }, restricted = true }, function(_, args)
  print(exports['ai-core']:ReleasePlayer(args.id) and 'released' or 'not in prison')
end)
```
</Tab>
</Tabs>

### GetJailTime

How long a player still has to serve.

**Side:** Server · **Waits:** no · **Lib:** [`prison.timeLeft`](/docs/developers/api/lib-server/jobs#prisontimeleft)

```ts title="Signature"
GetJailTime(source: number): number
```

```lua title="Lua"
local minutes = exports['ai-core']:GetJailTime(source)
```

#### Parameters

<TypeTable
  type={{
    source: { type: 'number', description: 'Server id of the player.', required: true },
  }}
/>

#### Returns

`number`: minutes left. `0` when the player is not in prison, `source` is not a number or no prison script runs.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Prisoners cannot use the phone booth.
onClientCallback("myscript:phoneBooth", (source) =>
  core.GetJailTime(source) > 0 ? fail("IN_PRISON") : { ok: true },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:phoneBooth', function(source)
  if exports['ai-core']:GetJailTime(source) > 0 then return aiLib.fail('IN_PRISON') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
