---
title: Hora y clima
description: Lee y pon el clima y la hora del juego, el apagón y la hora congelada, a través del script de clima que tenga el servidor.
icon: CloudSun
---

La hora y el clima pasan por ai-core, nunca por los exports o eventos propios de un script de clima. ai-core reenvía cada llamada al **primer script de clima en marcha**: Renewed-Weathersync, av_weather, cd_easytime y después qb-weathersync (ai-weathersync responde con ese nombre). Todos siguen el contrato de qb-weathersync. Mientras no hay ninguno en marcha, cada llamada responde `null` o `false`.

Para pausar la sincronización en el juego de un jugador (un interior con su propia luz, una cinemática), usa el lado de cliente (`PauseWorldSync`, `world.pauseSync` de la lib); consulta [Exports de cliente](/es/docs/developers/api/core-client).

### GetWeather

El tipo de clima actual.

**Lado:** Servidor · **Espera:** no · **Lib:** [`world.getWeather`](/es/docs/developers/api/lib-server/world#worldgetweather)

```ts title="Firma"
GetWeather(): string | null
```

```lua title="Lua"
local weather = exports['ai-core']:GetWeather() -- 'EXTRASUNNY', 'RAIN'... o nil
```

#### Parámetros

Ninguno.

#### Devuelve

`string | null`: el tipo de clima en mayúsculas (`EXTRASUNNY`, `CLEAR`, `RAIN`, `THUNDER`...). `null` cuando no hay ningún script de clima en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Street races pay more in the rain. */
export function raceBonus(): number {
  const weather = core.GetWeather();
  return weather === "RAIN" || weather === "THUNDER" ? 1.25 : 1;
}
```
</Tab>
<Tab value="Lua">
```lua
function RaceBonus()
  local weather = exports['ai-core']:GetWeather()
  if weather == 'RAIN' or weather == 'THUNDER' then return 1.25 end
  return 1.0
end
```
</Tab>
</Tabs>

### SetWeather

Pone el clima para todo el mundo.

**Lado:** Servidor · **Espera:** no · **Lib:** [`world.setWeather`](/es/docs/developers/api/lib-server/world#worldsetweather) (recibe los nombres tipados de `Weather`)

```ts title="Firma"
SetWeather(type: string): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetWeather('RAIN')
```

#### Parámetros

<TypeTable
  type={{
    type: { type: 'string', description: 'Un tipo de clima del contrato de qb-weathersync: `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Se pasa a mayúsculas antes de enviarlo.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de clima lo aceptó. `false` cuando `type` no es un texto, el script lo rechazó (un tipo desconocido) o no hay ningún script de clima en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";
import { isWeather } from "@aifivem/shared";

const core = resourceExport("ai-core");

addCommand("weather", { help: "Sets the weather", params: [{ name: "type", type: "string" }], restricted: true }, (_source, args) => {
  const type = args.type.toUpperCase();
  if (!isWeather(type)) return console.log("unknown weather type");
  core.SetWeather(type);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { help = 'Sets the weather', params = { { name = 'type', type = 'string' } }, restricted = true }, function(_, args)
  if not exports['ai-core']:SetWeather(args.type) then print('weather refused') end
end)
```
</Tab>
</Tabs>

### GetTime

La hora del juego (el reloj dentro del juego).

**Lado:** Servidor · **Espera:** no · **Lib:** [`world.getTime`](/es/docs/developers/api/lib-server/world#worldgettime)

```ts title="Firma"
GetTime(): { hour: number; minute: number } | null
```

```lua title="Lua"
local time = exports['ai-core']:GetTime() -- { hour, minute } o nil
```

#### Parámetros

Ninguno.

#### Devuelve

`{ hour, minute } | null`: hora 0-23 y minuto 0-59. `null` cuando no hay ningún script de clima en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// El camello solo vende de noche (de 22:00 a 05:59, hora del juego).
onClientCallback("myscript:dealer", (source) => {
  const time = core.GetTime();
  const night = time !== null && (time.hour >= 22 || time.hour < 6);
  return night ? { ok: true } : fail("COME_BACK_AT_NIGHT");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:dealer', function(source)
  local time = exports['ai-core']:GetTime()
  if not time or (time.hour < 22 and time.hour >= 6) then return aiLib.fail('COME_BACK_AT_NIGHT') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SetTime

Pone la hora del juego para todo el mundo.

**Lado:** Servidor · **Espera:** no · **Lib:** [`world.setTime`](/es/docs/developers/api/lib-server/world#worldsettime)

```ts title="Firma"
SetTime(hour: number, minute?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetTime(12, 0)
```

#### Parámetros

<TypeTable
  type={{
    hour: { type: 'number', description: 'Hora, 0-23. Se redondea hacia abajo y da la vuelta (24 pasa a 0).', required: true },
    minute: { type: 'number', description: 'Minuto, 0-59. Se redondea hacia abajo y da la vuelta.', default: '0' },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de clima lo aceptó. `false` cuando `hour` no es un número, el script lo rechazó o no hay ningún script de clima en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("noon", { help: "Sets the time to 12:00", restricted: true }, () => {
  core.SetTime(12, 0);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('noon', { help = 'Sets the time to 12:00', restricted = true }, function()
  exports['ai-core']:SetTime(12, 0)
end)
```
</Tab>
</Tabs>

### SetBlackout

Activa o desactiva el apagón de la ciudad (todas las luces artificiales apagadas).

**Lado:** Servidor · **Espera:** no · **Lib:** [`world.setBlackout`](/es/docs/developers/api/lib-server/world#worldsetblackout)

```ts title="Firma"
SetBlackout(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetBlackout(true)
```

#### Parámetros

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` activa el apagón. Cualquier cosa distinta de `true` lo desactiva.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de clima lo aceptó. `false` cuando el script no tiene apagón, lo rechazó o no hay ningún script de clima en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The power plant was sabotaged: 5 minutes of darkness. */
export function sabotagePowerPlant(): void {
  if (!core.SetBlackout(true)) return;
  setTimeout(() => core.SetBlackout(false), 5 * 60_000);
}
```
</Tab>
<Tab value="Lua">
```lua
function SabotagePowerPlant()
  if not exports['ai-core']:SetBlackout(true) then return end
  SetTimeout(5 * 60000, function() exports['ai-core']:SetBlackout(false) end)
end
```
</Tab>
</Tabs>

### FreezeTime

Detiene o vuelve a poner en marcha el reloj del juego.

**Lado:** Servidor · **Espera:** no · **Lib:** [`world.freezeTime`](/es/docs/developers/api/lib-server/world#worldfreezetime)

```ts title="Firma"
FreezeTime(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:FreezeTime(true)
```

#### Parámetros

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` congela el reloj. Cualquier cosa distinta de `true` lo deja correr.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el script de clima lo aceptó. `false` cuando el script no puede congelar la hora, lo rechazó o no hay ningún script de clima en marcha.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Una noche de evento: siempre las 21:00.
addCommand("eventnight", { help: "Freezes the clock at 21:00", restricted: true }, () => {
  core.SetTime(21, 0);
  core.FreezeTime(true);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('eventnight', { help = 'Freezes the clock at 21:00', restricted = true }, function()
  exports['ai-core']:SetTime(21, 0)
  exports['ai-core']:FreezeTime(true)
end)
```
</Tab>
</Tabs>
