Каждый ресурс пишет логи через ai-core. Ваш ресурс называет **канал** (`purchases`, `robberies`) и пишет сообщение; ai-core решает, куда оно пойдёт. Владелец сервера включает провайдеров в админ-панели (консоль, Discord, Fivemanage, FiveM Stats), задаёт минимальный уровень и вставляет url вебхуков Discord для каждого ресурса и канала. Ресурс никогда сам не отправляет данные в вебхук или сервис логов и никогда не хранит url вебхука.

Передавайте участвующих игроков как `source` и `target`, а не пишите их имена в сообщение: ai-core добавляет имя каждого игрока, персонажа, citizen id и идентификаторы (IP только тогда, когда это разрешает панель).

### Log

Отправляет одну запись лога вашего ресурса.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`aiLog(channel, message, options?)`](/ru/docs/developers/api/lib-server/logs#ailog) (Lua: `aiLib.aiLog`; оба выводят в консоль, пока ai-core не запущен)

```ts title="Сигнатура"
Log(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { price = 25000 } })
```

#### Параметры

<TypeTable
  type={{
    channel: { type: 'string', description: 'Имя канала вашего ресурса (`purchases`). Вебхук и переключатель вкл/выкл задаются для каждого канала. `log`, если не текст.', required: true },
    message: { type: 'string', description: 'Что произошло, простым английским языком. Другие значения превращаются в текст.', required: true },
    options: { type: 'LogOptions', description: 'Уровень, игроки и дополнительные значения. Поля ниже.' },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: 'Насколько это важно. Записи ниже минимального уровня из панели отбрасываются.', default: '"info"' },
    source: { type: 'number', description: 'Серверный id игрока, который это сделал; добавляются его имя, персонаж и идентификаторы.' },
    target: { type: 'number', description: 'Серверный id игрока, с которым это сделали.' },
    metadata: { type: 'Record<string, unknown>', description: 'Дополнительные значения (суммы, имена предметов, координаты). Если не таблица: игнорируется.' },
  }}
/>

См. [LogOptions](/ru/docs/developers/api/types#logoptions) и [LogLevel](/ru/docs/developers/api/types#loglevel).

#### Возвращает

Ничего. Запись молча отбрасывается, когда её уровень ниже минимального в панели или её канал выключен через `LogChannels`.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:buyCar", { lock: true }, (source) => {
  const price = 25_000;
  if (!core.RemoveMoney(source, "bank", price, "car_purchase")) return fail("NOT_ENOUGH_MONEY");
  // ... создать и сохранить машину
  core.Log("purchases", "Bought a car", { source, metadata: { model: "sultan", price } });
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:buyCar', function(source)
  local price = 25000
  if not exports['ai-core']:RemoveMoney(source, 'bank', price, 'car_purchase') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  -- ... создать и сохранить машину
  exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { model = 'sultan', price = price } })
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Логи предназначены владельцу сервера, поэтому сообщение остаётся на английском и не переводится. Делайте сообщение коротким, а значения кладите в `metadata`, где сервисы логов могут по ним фильтровать.
</Callout>

### LogChannels

Описывает каналы вашего ресурса: их имя набора данных для Fivemanage и FiveM Stats и включён ли каждый. Вызовите один раз при старте ресурса. Каналы, которые вы так и не описали, всё равно работают со значениями по умолчанию.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`aiLogChannels(channels)`](/ru/docs/developers/api/lib-server/logs#ailogchannels)

```ts title="Сигнатура"
LogChannels(channels: Record<string, LogChannel>): void
```

```lua title="Lua"
exports['ai-core']:LogChannels({ purchases = { dataset = 'myscript-sales' }, debug = { active = false } })
```

#### Параметры

<TypeTable
  type={{
    channels: { type: 'Record<string, LogChannel>', description: 'Имя канала и его настройки. Поля каждого ниже.', required: true },
  }}
/>

#### LogChannel

<TypeTable
  type={{
    dataset: { type: 'string', description: 'Имя набора данных для Fivemanage и FiveM Stats.', default: 'имя ресурса' },
    active: { type: 'boolean', description: '`false` выключает канал: его записи отбрасываются.', default: 'true' },
  }}
/>

См. [LogChannel](/ru/docs/developers/api/types#logchannel).

#### Возвращает

Ничего. Второй вызов заменяет всё описание вашего ресурса. Оно удаляется, когда ваш ресурс останавливается. Значение, которое не является таблицей, ничего не делает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Один раз при старте.
core.LogChannels({
  purchases: { dataset: "myscript-sales" },
  robberies: { dataset: "myscript-crime" },
  debug: { active: false },
});
```
</Tab>
<Tab value="Lua">
```lua
exports['ai-core']:LogChannels({
  purchases = { dataset = 'myscript-sales' },
  robberies = { dataset = 'myscript-crime' },
  debug = { active = false },
})
```
</Tab>
</Tabs>

<Callout type="warn">
Url вебхуков никогда не пишутся ни сюда, ни куда-либо в вашем ресурсе: их задаёт владелец сервера в панели ai-core, которая хранит их в файле, не попадающем в общий доступ.
</Callout>
