title: Celular

As chamadas de celular passam pelo ai-core, nunca pelos exports próprios de um script de celular. O ai-core encaminha cada chamada ao **primeiro script de celular que estiver rodando** (tgiann-phone, lb-phone, gksphone e os outros da lista de compatibilidade). Enquanto nenhum celular está rodando, cada chamada responde `null` ou `false`.

### GetPhoneNumber

O número de celular de um jogador.

**Lado:** Servidor · **Espera:** não · **Lib:** [`phone.number`](/pt/docs/developers/api/lib-server/phone-appearance#phonenumber)

```ts title="Assinatura"
GetPhoneNumber(source: number): string | null
```

```lua title="Lua"
local number = exports['ai-core']:GetPhoneNumber(source) -- string ou nil
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do jogador.', required: true },
  }}
/>

#### Retorno

`string | null`: o número como o script de celular o escreve. `null` quando o jogador não tem um, nenhum celular está rodando ou `source` não é um número.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Um item de cartão de visita mostra o número do dono.
onClientCallback("myscript:myNumber", (source) => {
  const number = core.GetPhoneNumber(source);
  return number ? { ok: true, number } : fail("NO_PHONE_NUMBER");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myNumber', function(source)
  local number = exports['ai-core']:GetPhoneNumber(source)
  if not number then return aiLib.fail('NO_PHONE_NUMBER') end
  return { ok = true, number = number }
end)
```
</Tab>
</Tabs>

### GetSourceByPhone

O jogador online que tem um número de celular.

**Lado:** Servidor · **Espera:** não · **Lib:** [`phone.sourceOf`](/pt/docs/developers/api/lib-server/phone-appearance#phonesourceof)

```ts title="Assinatura"
GetSourceByPhone(number: string): number | null
```

```lua title="Lua"
local src = exports['ai-core']:GetSourceByPhone('5551234') -- number ou nil
```

#### Parâmetros

<TypeTable
  type={{
    number: { type: 'string', description: 'O número de celular, escrito do jeito que o script de celular o escreve.', required: true },
  }}
/>

#### Retorno

`number | null`: o id de servidor. `null` quando o dono desse número não está online, o número é desconhecido, nenhum celular está rodando ou `number` não é texto.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { notify, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** A taxi job tells the caller their cab is on the way, if they are online. */
export function cabOnTheWay(callerNumber: string): void {
  const caller = core.GetSourceByPhone(callerNumber);
  if (caller !== null) notify(caller, Locale("NOTIFY_CAB_COMING"), "info");
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function CabOnTheWay(callerNumber)
  local caller = exports['ai-core']:GetSourceByPhone(callerNumber)
  if caller then aiLib.notify(caller, Locale('NOTIFY_CAB_COMING'), 'info') end
end
```
</Tab>
</Tabs>

### HasPhone

Se um jogador tem celular (para scripts de celular que precisam de um item de celular, se ele carrega um).

**Lado:** Servidor · **Espera:** não · **Lib:** [`phone.hasPhone`](/pt/docs/developers/api/lib-server/phone-appearance#phonehasphone)

```ts title="Assinatura"
HasPhone(source: number): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasPhone(source)
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do jogador.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o script de celular diz que o jogador tem celular. `false` quando não tem, quando nenhum celular está rodando ou `source` não é um número.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Um emprego que distribui tarefas por mensagem de texto precisa de um celular.
onClientCallback("myscript:startDeliveries", (source) =>
  core.HasPhone(source) ? { ok: true } : fail("NEED_PHONE"),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:startDeliveries', function(source)
  if not exports['ai-core']:HasPhone(source) then return aiLib.fail('NEED_PHONE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SendPhoneMail

Envia um e-mail para o celular de um jogador.

**Lado:** Servidor · **Espera:** não · **Lib:** [`phone.mail`](/pt/docs/developers/api/lib-server/phone-appearance#phonemail)

```ts title="Assinatura"
SendPhoneMail(to: number | string, mail: PhoneMail): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMail(source, { sender = 'LS Customs', subject = 'Invoice', message = '...' })
```

#### Parâmetros

<TypeTable
  type={{
    to: { type: 'number | string', description: 'O id de servidor de um jogador (o número dele é procurado) ou um número de celular / o endereço de e-mail do celular.', required: true },
    mail: { type: 'PhoneMail', description: 'O e-mail. Campos abaixo.', required: true },
  }}
/>

#### PhoneMail

<TypeTable
  type={{
    sender: { type: 'string', description: 'Mostrado como remetente (uma empresa, `Los Santos Customs`).', default: '""' },
    subject: { type: 'string', description: 'Linha de assunto. Cortada em 120 caracteres.', required: true },
    message: { type: 'string', description: 'O texto. Cortado em 4000 caracteres.', required: true },
  }}
/>

Os textos são mostrados como foram enviados: passe textos traduzidos. Veja [PhoneMail](/pt/docs/developers/api/types#phonemail).

#### Retorno

`boolean`: `true` quando o script de celular aceitou o e-mail. `false` quando o jogador não tem número, `subject` ou `message` falta, nenhum celular está rodando ou ele recusou.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The heist contact mails the location after the job was accepted. */
export function mailHeistLocation(source: number, street: string): void {
  core.SendPhoneMail(source, {
    sender: Locale("MAIL_CONTACT"),
    subject: Locale("MAIL_HEIST_SUBJECT"),
    message: Locale("MAIL_HEIST_BODY", street),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function MailHeistLocation(source, street)
  exports['ai-core']:SendPhoneMail(source, {
    sender = Locale('MAIL_CONTACT'),
    subject = Locale('MAIL_HEIST_SUBJECT'),
    message = Locale('MAIL_HEIST_BODY', street),
  })
end
```
</Tab>
</Tabs>

### SendPhoneMessage

Envia uma mensagem de texto de um número para um jogador ou número.

**Lado:** Servidor · **Espera:** não · **Lib:** [`phone.message`](/pt/docs/developers/api/lib-server/phone-appearance#phonemessage)

```ts title="Assinatura"
SendPhoneMessage(from: string, to: number | string, text: string): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMessage('Dispatch', source, 'Your cab is here.')
```

#### Parâmetros

<TypeTable
  type={{
    from: { type: 'string', description: 'O número ou nome do remetente, como o script de celular o aceita.', required: true },
    to: { type: 'number | string', description: 'O id de servidor de um jogador (o número dele é procurado) ou um número de celular.', required: true },
    text: { type: 'string', description: 'A mensagem, já traduzida. Cortada em 1000 caracteres.', required: true },
  }}
/>

#### Retorno

`boolean`: `true` quando o script de celular aceitou a mensagem. `false` quando o destinatário não tem número, `from` ou `text` não é texto, nenhum celular está rodando ou ele recusou.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The next delivery address arrives by text. */
export function textNextStop(source: number, street: string): void {
  if (!core.SendPhoneMessage(Locale("SENDER_DISPATCH"), source, Locale("TEXT_NEXT_STOP", street)))
    console.log(`player ${source} could not get the text`);
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TextNextStop(source, street)
  if not exports['ai-core']:SendPhoneMessage(Locale('SENDER_DISPATCH'), source, Locale('TEXT_NEXT_STOP', street)) then
    print(('player %d could not get the text'):format(source))
  end
end
```
</Tab>
</Tabs>

### PhoneNotify

Mostra uma notificação no celular de um jogador.

**Lado:** Servidor · **Espera:** não · **Lib:** [`phone.notify`](/pt/docs/developers/api/lib-server/phone-appearance#phonenotify)

```ts title="Assinatura"
PhoneNotify(source: number, notification: PhoneNotification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:PhoneNotify(source, { title = 'Bank', message = 'Salary paid', app = 'bank' })
```

#### Parâmetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor do jogador.', required: true },
    notification: { type: 'PhoneNotification', description: 'O que mostrar. Campos abaixo.', required: true },
  }}
/>

#### PhoneNotification

<TypeTable
  type={{
    title: { type: 'string', description: 'Linha de título. Cortada em 80 caracteres.', required: true },
    message: { type: 'string', description: 'O texto. Cortado em 500 caracteres.', default: '""' },
    app: { type: 'string', description: 'Id do app do celular a que pertence, quando o celular o conhece (`messages`, `mail`, `bank`).' },
  }}
/>

Veja [PhoneNotification](/pt/docs/developers/api/types#phonenotification).

#### Retorno

`boolean`: `true` quando o script de celular a mostrou. `false` quando `title` falta, nenhum celular está rodando, `source` não é um número ou ele recusou.

#### Exemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Tells the owner their car was towed. */
export function towedNotice(source: number, plate: string): void {
  core.PhoneNotify(source, { title: Locale("PHONE_TOW_TITLE"), message: Locale("PHONE_TOW_TEXT", plate) });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TowedNotice(source, plate)
  exports['ai-core']:PhoneNotify(source, { title = Locale('PHONE_TOW_TITLE'), message = Locale('PHONE_TOW_TEXT', plate) })
end
```
</Tab>
</Tabs>
