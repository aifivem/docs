title: Garagen
description: Fahrzeuge beschlagnahmen und einparken, ein Garagenmenü öffnen und die eingeparkten Fahrzeuge eines Spielers auflisten, über das Garagen-Skript, das der Server nutzt.
icon: Warehouse
---

Garagen-Aufrufe laufen über ai-core, nie über die eigenen Exports oder Events eines Garagen-Skripts (ai-garages eingeschlossen). ai-core leitet jeden Aufruf an das **aktive Garagen-Skript** weiter: das, das die Panel-Einstellung **Garage script** (Garagen-Skript) wählt, oder das erste, das läuft (ai-garages, jg-advancedgarages, tgiann-realparking und die anderen aus der Kompatibilitätsliste). Jedes Skript beantwortet nur die Aktionen, die es wirklich hat, sodass jede Aktion mit einem Skript `false` oder `null` antworten und mit einem anderen funktionieren kann.

Ein Fahrzeug ist ein **Server-Entity-Handle**.

### GetGarageSystem

Der Ressourcenname des Garagen-Skripts, an das ai-core weiterleitet.

**Seite:** Server · **Wartet:** nein · **Lib:** [`garages.provider()`](/de/docs/developers/api/lib-server/vehicles#garagesprovider)

```ts title="Signature"
GetGarageSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetGarageSystem() -- String oder nil
```

#### Parameter

Keine.

#### Rückgabe

`string | null`: der Ressourcenname des Garagen-Skripts. `null`, wenn keines läuft.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("garagesystem", { help: "Shows the garage script in use", restricted: true }, () => {
  console.log(core.GetGarageSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('garagesystem', { help = 'Shows the garage script in use', restricted = true }, function()
  print(exports['ai-core']:GetGarageSystem() or 'none')
end)
```
</Tab>
</Tabs>

### ImpoundVehicle

Schickt ein Fahrzeug in der Welt zur Beschlagnahmestelle. Bei Garagen-Skripten, die nur ein Beschlagnahme-Formular auf dem Bildschirm des Spielers haben, öffnet es stattdessen dieses Formular für den Spieler in `by`.

**Seite:** Server · **Wartet:** nein · **Lib:** [`garages.impound`](/de/docs/developers/api/lib-server/vehicles#garagesimpound)

```ts title="Signature"
ImpoundVehicle(vehicle: number, by?: number): boolean
```

```lua title="Lua"
local taken = exports['ai-core']:ImpoundVehicle(vehicle, source)
```

#### Parameter

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Server-Entity-Handle des Fahrzeugs.', required: true },
    by: { type: 'number', description: 'Server-ID des Spielers, der es beschlagnahmt (ein Beamter). Wird von Skripten mit Beschlagnahme-Formular gebraucht; wird ignoriert, wenn er nicht online ist.' },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Garagen-Skript das Fahrzeug übernommen (oder sein Formular geöffnet) hat. `false`, wenn nichts es übernommen hat: Kein Garagen-Skript läuft, es hat keine Beschlagnahme, das Fahrzeug ist ihm unbekannt, oder `vehicle` ist kein existierendes Fahrzeug. Bei `false` ist das Fahrzeug noch in der Welt: Lösche es selbst, wenn es weg muss.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:impound", { args: oneArg(readId) }, (source, netId) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  const vehicle = vehicleNearPlayer(source, netId, { metres: 5 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.ImpoundVehicle(vehicle, source)) DeleteEntity(vehicle);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:impound', function(source, netId)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 5 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:ImpoundVehicle(vehicle, source) then DeleteEntity(vehicle) end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### StoreVehicleInGarage

Stellt ein Fahrzeug aus der Welt mit seinem Zustand in eine Garage.

**Seite:** Server · **Wartet:** nein · **Lib:** [`garages.store`](/de/docs/developers/api/lib-server/vehicles#garagesstore)

```ts title="Signature"
StoreVehicleInGarage(vehicle: number, garage?: string | null, by?: number): boolean
```

```lua title="Lua"
local stored = exports['ai-core']:StoreVehicleInGarage(vehicle, 'legion', source)
```

#### Parameter

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Server-Entity-Handle des Fahrzeugs.', required: true },
    garage: { type: 'string | null', description: 'Die Garagen-ID des Garagen-Skripts. `null` oder weggelassen: Das Skript wählt.', default: 'null' },
    by: { type: 'number', description: 'Server-ID des Spielers, der es einparkt. Skripte mit Client-API handeln im Spiel dieses Spielers; wird ignoriert, wenn er nicht online ist.' },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Garagen-Skript das Fahrzeug übernommen hat. `false`, wenn nichts es übernommen hat (kein Garagen-Skript, keine Einpark-Aktion, unbekannte Garage, ein Fahrzeug, das dem Skript nicht gehört) oder `vehicle` kein existierendes Fahrzeug ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleOf } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Ein Parkservice stellt das Auto, das der Spieler fährt, in die nächste Garage.
onClientCallback("myscript:valetStore", (source) => {
  const vehicle = vehicleOf(source, { driver: true });
  if (!vehicle) return fail("NOT_DRIVING");
  return core.StoreVehicleInGarage(vehicle, null, source) ? { ok: true } : fail("STORE_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:valetStore', function(source)
  local ped = GetPlayerPed(source)
  local vehicle = GetVehiclePedIsIn(ped, false)
  if vehicle == 0 or GetPedInVehicleSeat(vehicle, -1) ~= ped then return aiLib.fail('NOT_DRIVING') end
  if not exports['ai-core']:StoreVehicleInGarage(vehicle, nil, source) then return aiLib.fail('STORE_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### OpenGarage

Öffnet das Garagenmenü des aktiven Garagen-Skripts für einen Spieler.

**Seite:** Server · **Wartet:** nein · **Lib:** [`garages.open`](/de/docs/developers/api/lib-server/vehicles#garagesopen)

```ts title="Signature"
OpenGarage(source: number, garage?: string | null): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenGarage(source, 'legion')
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers.', required: true },
    garage: { type: 'string | null', description: 'Die Garagen-ID des Garagen-Skripts. `null` oder weggelassen: der Standard des Skripts.', default: 'null' },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn sich das Menü geöffnet hat. `false`, wenn der Spieler nicht online ist, kein Garagen-Skript läuft oder es kein Menü hat, das von außen geöffnet werden kann.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const MOTEL_GARAGE = { x: 273.1, y: -343.9, z: 44.9 };

onClientCallback("myscript:motelGarage", { guards: [near(MOTEL_GARAGE, 3)] }, (source) =>
  core.OpenGarage(source, "motel") ? { ok: true } : fail("GARAGE_FAILED"),
);
```
</Tab>
<Tab value="Lua">
```lua
local MOTEL_GARAGE = vector3(273.1, -343.9, 44.9)

aiLib.onClientCallback('myscript:motelGarage', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - MOTEL_GARAGE) > 3.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenGarage(source, 'motel') then return aiLib.fail('GARAGE_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### GetGaragedVehicles

Die Fahrzeuge eines Spielers, die das Garagen-Skript verwahrt: in einer Garage oder in der Beschlagnahmestelle.

**Seite:** Server · **Wartet:** nein (antwortet über `done`) · **Lib:** [`garages.stored(source)`](/de/docs/developers/api/lib-server/vehicles#garagesstored) gibt ein Promise zurück

```ts title="Signature"
GetGaragedVehicles(source: number, done: (vehicles: GaragedVehicle[] | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetGaragedVehicles(source, function(vehicles) end) -- Liste oder nil
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers.', required: true },
    done: { type: '(vehicles) => void', description: 'Wird einmal mit der Antwort aufgerufen, nachdem das Garagen-Skript geantwortet hat.', required: true, typeDescription: '(vehicles: GaragedVehicle[] | null) => void' },
  }}
/>

#### Rückgabe

Nichts. `done` erhält einen Eintrag pro Fahrzeug mit `plate`, `model` (oder `null`), `garage` (oder `null`) und `impounded` ([GaragedVehicle](/de/docs/developers/api/types#garagedvehicle)), oder `null`, wenn der Spieler nicht online ist, kein Garagen-Skript läuft, es keine Fahrzeuge auflisten kann oder fehlgeschlagen ist. Ohne eine Funktion als `done` tut der Aufruf nichts.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import type { GaragedVehicle } from "@aifivem/shared";

const core = resourceExport("ai-core");

// Der Schalter der Beschlagnahmestelle listet die beschlagnahmten Autos des Spielers.
onClientCallback("myscript:impoundList", async (source) => {
  const list = await new Promise<GaragedVehicle[] | null>((resolve) => core.GetGaragedVehicles(source, resolve));
  if (!list) return fail("GARAGE_UNKNOWN");
  return { ok: true, plates: list.filter((v) => v.impounded).map((v) => v.plate) };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:impoundList', function(source)
  local p = promise.new()
  exports['ai-core']:GetGaragedVehicles(source, function(list) p:resolve(list or false) end)
  local list = Citizen.Await(p)
  if not list then return aiLib.fail('GARAGE_UNKNOWN') end
  local plates = {}
  for _, v in ipairs(list) do
    if v.impounded then plates[#plates + 1] = v.plate end
  end
  return { ok = true, plates = plates }
end)
```
</Tab>
</Tabs>
