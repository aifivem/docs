### GetMeta

Bir karakterin **metadata**’sından tek bir değer: karakterle birlikte kaydedilen isimli değerlerin serbest bir çantası. ESX ve QB script’leri ek karakter verilerini köprü üzerinden orada tutar (`hunger`, `thirst`, `armor`, `isdead`...) ve senin script’in de kendi küçük değerlerini tutabilir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** yok

```ts title="İmza"
GetMeta(src: number, key: string): unknown
```

```lua title="Lua"
local value = exports['ai-core']:GetMeta(source, 'myscript_xp') -- herhangi bir değer ya da nil
```

#### Parametreler

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    key: { type: 'string', description: 'Değerin adı. Kendi anahtarlarının başına script adını ekle (`myscript_xp`), böylece başka bir script’le asla çakışmazlar.', required: true },
  }}
/>

#### Dönüş değeri

`unknown`: saklanan değer (sayı, metin, boolean, liste ya da tablo), ayarlandığı gibi. Anahtar ayarlanmamışsa ya da oyuncunun yüklü karakteri yoksa `null`. Kullanmadan önce tipini kontrol et: değer başka bir script ya da senin script’inin eski bir sürümü tarafından yazılmış olabilir.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Karakterin balıkçılık seviyesi, henüz saklanmamışsa 1. */
export function fishingLevel(source: number): number {
  const value = core.GetMeta(source, "myscript_level");
  return typeof value === "number" && Number.isInteger(value) && value > 0 ? value : 1;
}
```
</Tab>
<Tab value="Lua">
```lua
function FishingLevel(source)
  local value = exports['ai-core']:GetMeta(source, 'myscript_level')
  if math.type(value) == 'integer' and value > 0 then return value end
  return 1
end
```
</Tab>
</Tabs>

### SetMeta

Bir karakterin metadata’sına tek bir değer saklar. Değer karakterin bir sonraki periyodik kaydıyla (panel ayarı, varsayılan olarak her 5 dakikada), çıkışta ve sunucu durduğunda kaydedilir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** yok

```ts title="İmza"
SetMeta(src: number, key: string, value: unknown): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetMeta(source, 'myscript_level', 3)
```

#### Parametreler

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    key: { type: 'string', description: 'Değerin adı. Kendi anahtarlarının başına script adını ekle.', required: true },
    value: { type: 'unknown', description: 'JSON’a sığan herhangi bir değer: sayı, metin, boolean, liste ya da tablo. `null` (Lua `nil`) anahtarı kaldırır.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: değer saklandığında (ya da kaldırıldığında) `true`. Oyuncunun yüklü karakteri yoksa ya da `key` metin değilse `false`.

Değişiklik oyuncunun kendi oyununa hemen ulaşır ve `ai-core:metaChanged (src, key, value)` server event’ini tetikler.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Yeterince yakalamadan sonra bir seviye atlar. */
export function levelUp(source: number): void {
  const level = core.GetMeta(source, "myscript_level");
  const next = (typeof level === "number" ? level : 1) + 1;
  core.SetMeta(source, "myscript_level", next);
}
```
</Tab>
<Tab value="Lua">
```lua
function LevelUp(source)
  local level = exports['ai-core']:GetMeta(source, 'myscript_level')
  if type(level) ~= 'number' then level = 1 end
  exports['ai-core']:SetMeta(source, 'myscript_level', level + 1)
end
```
</Tab>
</Tabs>

<Callout type="warn">
Metadata tek bir karaktere ait küçük değerler içindir (bir seviye, bir bayrak, birkaç sayı). Büyüyen listeler (bir geçmiş, her yakalama) ve karakterler arasında aradığın ya da saydığın her şey kendi veritabanı tablona aittir. Metadata’daki değerler hemen kaydedilmez: para ve eşyalar asla oraya girmez.
</Callout>

### GetBranding

Panelin General ayarlarından sunucunun adı, alt başlığı, sloganları ve arka plan resmi. Kendi tam ekran menülerinde aynı adı göstermek için kullan.

**Taraf:** Server · **Bekler:** hayır · **Lib:** yok

```ts title="İmza"
GetBranding(): Branding
```

```lua title="Lua"
local brand = exports['ai-core']:GetBranding() -- tablo
```

#### Parametreler

Yok.

#### Dönüş değeri

`Branding`: `name`, `subtitle`, `tagline`, `taglineSub` ve `background` (`"skyline"` ya da `"wet-drive"`, ai-core’daki bir resim) içeren bir kopya. Bkz. [Branding](/tr/docs/developers/api/types#branding).

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Karşılama ekranı sunucu adını gösterir.
onClientCallback("myscript:welcome", () => {
  const { name, tagline } = core.GetBranding();
  return { ok: true, name, tagline };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:welcome', function()
  local brand = exports['ai-core']:GetBranding()
  return { ok = true, name = brand.name, tagline = brand.tagline }
end)
```
</Tab>
</Tabs>

### GetUpdates

ai-core’un güncelleme kontrolüne göre GitHub sürümü çalışan sürümden yeni olan script’ler. ai-core, `fxmanifest.lua` dosyasında `repository` satırı olan her başlatılmış script için GitHub’a script başına en fazla 6 saatte bir (ve bir script başladığında) sorar, panelin **Check for updates** ayarı kapalı değilse.

**Taraf:** Server · **Bekler:** hayır · **Lib:** yok

```ts title="İmza"
GetUpdates(): UpdateInfo[]
```

```lua title="Lua"
local outdated = exports['ai-core']:GetUpdates() -- tablo listesi
```

#### Parametreler

Yok.

#### Dönüş değeri

`UpdateInfo[]`: güncel olmayan her script için `resource`, `label` (insanların bildiği adı), `current` (çalışan sürüm), `latest` (en yeni sürüm) ve `url` (sürüm sayfası) içeren bir kayıt. Her şey güncelse ya da henüz hiçbir şey kontrol edilmediyse boş liste (ilk kontrol açılıştan 15 saniye sonra çalışır). Bkz. [UpdateInfo](/tr/docs/developers/api/types#updateinfo).

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("outdated", { help: "Lists outdated scripts", restricted: true }, () => {
  for (const u of core.GetUpdates()) console.log(`${u.label}: ${u.current} -> ${u.latest} (${u.url})`);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('outdated', { help = 'Lists outdated scripts', restricted = true }, function()
  for _, u in ipairs(exports['ai-core']:GetUpdates()) do
    print(('%s: %s -> %s (%s)'):format(u.label, u.current, u.latest, u.url))
  end
end)
```
</Tab>
</Tabs>
