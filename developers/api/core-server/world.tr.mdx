Saat ve hava ai-core üzerinden gider, asla bir hava script’inin kendi export’ları ya da event’leri üzerinden değil. ai-core her çağrıyı **çalışan ilk hava script’ine** iletir: Renewed-Weathersync, av_weather, cd_easytime, sonra qb-weathersync (ai-weathersync bu adla cevap verir). Hepsi qb-weathersync sözleşmesine uyar. Hiçbiri çalışmıyorken her çağrı `null` ya da `false` cevabı verir.

Senkronu tek bir oyuncunun oyununda duraklatmak için (kendi ışığı olan bir iç mekan, bir ara sahne) client tarafını kullan (`PauseWorldSync`, lib `world.pauseSync`); bkz. [Client export’ları](/tr/docs/developers/api/core-client).

### GetWeather

Şu anki hava tipi.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`world.getWeather`](/tr/docs/developers/api/lib-server/world#worldgetweather)

```ts title="İmza"
GetWeather(): string | null
```

```lua title="Lua"
local weather = exports['ai-core']:GetWeather() -- 'EXTRASUNNY', 'RAIN'... ya da nil
```

#### Parametreler

Yok.

#### Dönüş değeri

`string | null`: büyük harfle hava tipi (`EXTRASUNNY`, `CLEAR`, `RAIN`, `THUNDER`...). Hiçbir hava script’i çalışmıyorsa `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** Sokak yarışları yağmurda daha fazla öder. */
export function raceBonus(): number {
  const weather = core.GetWeather();
  return weather === "RAIN" || weather === "THUNDER" ? 1.25 : 1;
}
```
</Tab>
<Tab value="Lua">
```lua
function RaceBonus()
  local weather = exports['ai-core']:GetWeather()
  if weather == 'RAIN' or weather == 'THUNDER' then return 1.25 end
  return 1.0
end
```
</Tab>
</Tabs>

### SetWeather

Herkes için havayı ayarlar.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`world.setWeather`](/tr/docs/developers/api/lib-server/world#worldsetweather) (tipli `Weather` adlarını alır)

```ts title="İmza"
SetWeather(type: string): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetWeather('RAIN')
```

#### Parametreler

<TypeTable
  type={{
    type: { type: 'string', description: 'qb-weathersync sözleşmesinin bir hava tipi: `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Gönderilmeden önce büyük harfe çevrilir.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: hava script’i kabul ettiğinde `true`. `type` metin değilse, script reddettiyse (bilinmeyen bir tip) ya da hiçbir hava script’i çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";
import { isWeather } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

addCommand("weather", { help: "Sets the weather", params: [{ name: "type", type: "string" }], restricted: true }, (_source, args) => {
  const type = args.type.toUpperCase();
  if (!isWeather(type)) return console.log("unknown weather type");
  core.SetWeather(type);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { help = 'Sets the weather', params = { { name = 'type', type = 'string' } }, restricted = true }, function(_, args)
  if not exports['ai-core']:SetWeather(args.type) then print('weather refused') end
end)
```
</Tab>
</Tabs>

### GetTime

Oyun saati (oyun içi saat).

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`world.getTime`](/tr/docs/developers/api/lib-server/world#worldgettime)

```ts title="İmza"
GetTime(): { hour: number; minute: number } | null
```

```lua title="Lua"
local time = exports['ai-core']:GetTime() -- { hour, minute } ya da nil
```

#### Parametreler

Yok.

#### Dönüş değeri

`{ hour, minute } | null`: saat 0-23 ve dakika 0-59. Hiçbir hava script’i çalışmıyorsa `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Uyuşturucu satıcısı yalnızca gece satar (oyun saatiyle 22:00 - 05:59).
onClientCallback("myscript:dealer", (source) => {
  const time = core.GetTime();
  const night = time !== null && (time.hour >= 22 || time.hour < 6);
  return night ? { ok: true } : fail("COME_BACK_AT_NIGHT");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:dealer', function(source)
  local time = exports['ai-core']:GetTime()
  if not time or (time.hour < 22 and time.hour >= 6) then return aiLib.fail('COME_BACK_AT_NIGHT') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SetTime

Herkes için oyun saatini ayarlar.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`world.setTime`](/tr/docs/developers/api/lib-server/world#worldsettime)

```ts title="İmza"
SetTime(hour: number, minute?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetTime(12, 0)
```

#### Parametreler

<TypeTable
  type={{
    hour: { type: 'number', description: 'Saat, 0-23. Aşağı yuvarlanır ve başa sarar (24, 0 olur).', required: true },
    minute: { type: 'number', description: 'Dakika, 0-59. Aşağı yuvarlanır ve başa sarar.', default: '0' },
  }}
/>

#### Dönüş değeri

`boolean`: hava script’i kabul ettiğinde `true`. `hour` bir sayı değilse, script reddettiyse ya da hiçbir hava script’i çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("noon", { help: "Sets the time to 12:00", restricted: true }, () => {
  core.SetTime(12, 0);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('noon', { help = 'Sets the time to 12:00', restricted = true }, function()
  exports['ai-core']:SetTime(12, 0)
end)
```
</Tab>
</Tabs>

### SetBlackout

Şehrin karartmasını (tüm yapay ışıklar kapalı) açar ya da kapatır.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`world.setBlackout`](/tr/docs/developers/api/lib-server/world#worldsetblackout)

```ts title="İmza"
SetBlackout(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetBlackout(true)
```

#### Parametreler

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` karartmayı açar. `true` dışındaki her şey kapatır.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: hava script’i kabul ettiğinde `true`. Script’te karartma yoksa, reddettiyse ya da hiçbir hava script’i çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** Elektrik santrali sabote edildi: 5 dakika karanlık. */
export function sabotagePowerPlant(): void {
  if (!core.SetBlackout(true)) return;
  setTimeout(() => core.SetBlackout(false), 5 * 60_000);
}
```
</Tab>
<Tab value="Lua">
```lua
function SabotagePowerPlant()
  if not exports['ai-core']:SetBlackout(true) then return end
  SetTimeout(5 * 60000, function() exports['ai-core']:SetBlackout(false) end)
end
```
</Tab>
</Tabs>

### FreezeTime

Oyun saatini durdurur ya da yeniden başlatır.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`world.freezeTime`](/tr/docs/developers/api/lib-server/world#worldfreezetime)

```ts title="İmza"
FreezeTime(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:FreezeTime(true)
```

#### Parametreler

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` saati dondurur. `true` dışındaki her şey saatin işlemesine izin verir.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: hava script’i kabul ettiğinde `true`. Script zamanı donduramıyorsa, reddettiyse ya da hiçbir hava script’i çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Bir etkinlik gecesi: her zaman 21:00.
addCommand("eventnight", { help: "Freezes the clock at 21:00", restricted: true }, () => {
  core.SetTime(21, 0);
  core.FreezeTime(true);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('eventnight', { help = 'Freezes the clock at 21:00', restricted = true }, function()
  exports['ai-core']:SetTime(21, 0)
  exports['ai-core']:FreezeTime(true)
end)
```
</Tab>
</Tabs>
