title: Kapı kilitleri

Kapı çağrıları ai-core üzerinden gider, asla bir kapı kilidi script’inin kendi export’ları ya da event’leri üzerinden değil (ai-doorlock dahil). ai-core her çağrıyı **aktif kapı kilidi script’ine** iletir: panelin **Door lock script** ayarının seçtiği ya da çalışan ilk script (ai-doorlock, ox_doorlock, tgiann-doorlock ve uyumluluk listesindeki diğerleri).

Bir kapı **o script’in kendi kapı id’siyle** adlandırılır: onun kapı listesinde gördüğün id (ai-doorlock: kapının admin panelindeki id’si; ox_doorlock: veritabanı numarası).

### GetDoorlockSystem

ai-core’un ilettiği kapı kilidi script’inin resource adı.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`doors.provider()`](/tr/docs/developers/api/lib-server/world#doorsprovider)

```ts title="İmza"
GetDoorlockSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetDoorlockSystem() -- string ya da nil
```

#### Parametreler

Yok.

#### Dönüş değeri

`string | null`: kapı kilidi script’inin resource adı. Hiçbiri çalışmıyorsa `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Config’indeki kapı id’leri tek bir kapı kilidi script’ine aittir: başkası çalışıyorsa uyar.
if (core.GetDoorlockSystem() !== "ai-doorlock")
  console.log("myscript: door ids are written for ai-doorlock");
```
</Tab>
<Tab value="Lua">
```lua
if exports['ai-core']:GetDoorlockSystem() ~= 'ai-doorlock' then
  print('myscript: door ids are written for ai-doorlock')
end
```
</Tab>
</Tabs>

### SetDoorLocked

Bir kapıyı kilitler ya da kilidini açar.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`doors.setLocked`](/tr/docs/developers/api/lib-server/world#doorssetlocked)

```ts title="İmza"
SetDoorLocked(id: string, locked: boolean, by?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDoorLocked('pacific_vault', false, source)
```

#### Parametreler

<TypeTable
  type={{
    id: { type: 'string', description: 'Kapı kilidi script’inin kapı id’si. Bir tam sayı (ox_doorlock id’leri) metne çevrilir. En fazla 128 karakter.', required: true },
    locked: { type: 'boolean', description: '`true` kilitler, `false` açar. Gerçek bir boolean olmalıdır.', required: true },
    by: { type: 'number', description: 'Bunu yapan oyuncunun server id’si. Server API’si olmayan kapı kilidi script’leri değişikliği oyunu taşıyacak bir oyuncuya ihtiyaç duyar; o oyuncu çevrimiçi değilse yok sayılır.' },
  }}
/>

#### Dönüş değeri

`boolean`: kapı kilidi script’i değişikliği kabul ettiğinde `true`. Hiçbir kapı kilidi script’i çalışmıyorsa, kapı bilinmiyorsa, script reddettiyse, `id` boşsa ya da `locked` bir boolean değilse `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, progressFor, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const VAULT = { x: 253.9, y: 225.2, z: 101.9 };

onClientCallback("myscript:hackVault", { guards: [near(VAULT, 2)], lock: true }, async (source) => {
  if (!core.HasItem(source, "laptop")) return fail("NO_LAPTOP");
  if (!(await progressFor(source, { label: Locale("HACKING"), duration: 15000 }))) return fail("CANCELLED");
  return core.SetDoorLocked("pacific_vault", false, source) ? { ok: true } : fail("DOOR_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local VAULT = vector3(253.9, 225.2, 101.9)

aiLib.onClientCallback('myscript:hackVault', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - VAULT) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:HasItem(source, 'laptop') then return aiLib.fail('NO_LAPTOP') end
  if not aiLib.progressFor(source, { label = Locale('HACKING'), duration = 15000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:SetDoorLocked('pacific_vault', false, source) then return aiLib.fail('DOOR_FAILED') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### IsDoorLocked

Bir kapının kilitli olup olmadığı.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`doors.isLocked`](/tr/docs/developers/api/lib-server/world#doorsislocked)

```ts title="İmza"
IsDoorLocked(id: string): boolean | null
```

```lua title="Lua"
local locked = exports['ai-core']:IsDoorLocked('pacific_vault') -- true, false ya da nil
```

#### Parametreler

<TypeTable
  type={{
    id: { type: 'string', description: 'Kapı kilidi script’inin kapı id’si (bir tam sayı metne çevrilir).', required: true },
  }}
/>

#### Dönüş değeri

`boolean | null`: `true` kilitli, `false` açık. Bilinmediğinde `null`: hiçbir kapı kilidi script’i çalışmıyor, kapı yok, script server’da söyleyemiyor ya da `id` boş.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** Soygun yalnızca kasa hâlâ kapalıyken başlayabilir. */
export function vaultClosed(): boolean {
  return core.IsDoorLocked("pacific_vault") !== false;
}
```
</Tab>
<Tab value="Lua">
```lua
function VaultClosed()
  return exports['ai-core']:IsDoorLocked('pacific_vault') ~= false
end
```
</Tab>
</Tabs>

<Callout type="info">
`null`’ın özelliğin için ne anlama geldiğine karar ver. Örnek "bilinmiyor"u kapalı sayar, böylece eksik bir kapı kilidi script’i soygunu asla erken açmaz.
</Callout>
