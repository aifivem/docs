---
title: Jobs und Gangs
description: Jobs, Gangs, Ränge und Dienst eines Charakters lesen und ändern, Spieler im Dienst zählen, Prime Time, Job- und Gang-Definitionen lesen.
icon: Briefcase
---

Ein Charakter kann **mehrere Jobs und mehrere Gangs** haben (bis zu den Panel-Werten **Most jobs per character** und **Most gangs per character**). Höchstens **ein Job ist gleichzeitig im Dienst**, und nur dieser Job zahlt ein Gehalt. Höchstens **eine Gang ist aktiv**. Jobs und Gangs mit ihren Rängen werden im Admin-Panel definiert (Bereiche Jobs und Gangs).

Ein **Rang** ist eine Position in der Rangliste des Jobs, gezählt ab 0: Rang 0 ist die erste Zeile im Panel, Rang 1 die zweite und so weiter.

Jede Änderung löst ein Server-Event aus (`ai-core:jobsChanged`, `ai-core:dutyChanged`, `ai-core:gangsChanged`, `ai-core:activeGangChanged`) und erreicht das eigene Spiel des Spielers. Ressourcen, die die Jobs vieler Spieler brauchen, folgen diesen Events über den `online`-Spiegel der Lib, statt die Exports unten für jeden Spieler aufzurufen. Siehe [Events und Zustand](/de/docs/developers/api/events).

### GetJobs

Jede Job-Mitgliedschaft des Charakters eines Spielers.

**Seite:** Server · **Wartet:** nein · **Lib:** [`online.jobs(source)`](/de/docs/developers/api/lib-server/players#onlinejobs) liest dasselbe aus dem Spiegel der Lib

```ts title="Signature"
GetJobs(src: number): JobMembership[] | null
```

```lua title="Lua"
local jobs = exports['ai-core']:GetJobs(source) -- Liste von { job, grade } oder nil
```

#### Parameter

<TypeTable
  type={{
    src: { type: 'number', description: 'Server-ID des Spielers.', required: true },
  }}
/>

#### Rückgabe

`JobMembership[] | null`: ein `{ job, grade }` pro Job ([JobMembership](/de/docs/developers/api/types#jobmembership)). Eine leere Liste, wenn der Charakter keinen Job hat (der Arbeitslosen-Job des Panels wird nie gespeichert). `null`, wenn der Spieler keinen geladenen Charakter hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Ein Jobcenter-Bildschirm listet die Jobs des Spielers mit ihren Labels.
onClientCallback("myscript:myJobs", (source) => {
  const jobs = core.GetJobs(source);
  if (!jobs) return fail("NO_CHARACTER");
  return {
    ok: true,
    jobs: jobs.map(({ job, grade }) => ({
      job,
      label: core.GetJobDefinition(job)?.label ?? job,
      grade,
    })),
  };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myJobs', function(source)
  local jobs = exports['ai-core']:GetJobs(source)
  if not jobs then return aiLib.fail('NO_CHARACTER') end
  local rows = {}
  for _, m in ipairs(jobs) do
    local def = exports['ai-core']:GetJobDefinition(m.job)
    rows[#rows + 1] = { job = m.job, label = def and def.label or m.job, grade = m.grade }
  end
  return { ok = true, jobs = rows }
end)
```
</Tab>
</Tabs>

### GetCurrentJob

Der eine Job, den andere Skripte als „den“ Job des Spielers behandeln sollen: der Job im Dienst, sonst der letzte Job, für den der Spieler im Dienst war, sonst der erste Job, sonst der Arbeitslosen-Job des Panels. ESX- und QB-Skripte sehen diesen Job über die Brücke.

**Seite:** Server · **Wartet:** nein · **Lib:** keine

```ts title="Signature"
GetCurrentJob(src: number): JobMembership | null
```

```lua title="Lua"
local job = exports['ai-core']:GetCurrentJob(source) -- { job, grade } oder nil
```

#### Parameter

<TypeTable
  type={{
    src: { type: 'number', description: 'Server-ID des Spielers.', required: true },
  }}
/>

#### Rückgabe

`JobMembership | null`: `{ job, grade }`. Für einen Charakter ohne Job ist es der Arbeitslosen-Job (Panel-Einstellung, standardmäßig `unemployed`) mit Rang 0. `null` nur, wenn der Spieler keinen geladenen Charakter hat.

#### Beispiel

</Tab>

### SetDuty

Setzt einen Spieler für einen seiner Jobs in den Dienst (und für jeden anderen außer Dienst) oder außer Dienst.

**Seite:** Server · **Wartet:** nein · **Lib:** keine

```ts title="Signature"
SetDuty(src: number, job: string | null): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDuty(source, 'police') -- nil = außer Dienst
```

#### Parameter

<TypeTable
  type={{
    src: { type: 'number', description: 'Server-ID des Spielers.', required: true },
    job: { type: 'string | null', description: 'Der Job, für den der Dienst beginnt (der Spieler muss ihn haben), oder `null` (Lua `nil`), um außer Dienst zu gehen.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn der Spieler jetzt für `job` im Dienst ist (oder bei `null` außer Dienst), auch wenn sich nichts ändern musste. `false`, wenn der Spieler `job` nicht hat oder keinen geladenen Charakter hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const LOCKER_ROOM = { x: 452.3, y: -993.2, z: 30.7 };

// Ein Dienstschalter im Umkleideraum der Wache.
onClientCallback("myscript:toggleDuty", { guards: [near(LOCKER_ROOM, 3)] }, (source) => {
  const onDuty = core.GetDutyJob(source) === "police";
  return core.SetDuty(source, onDuty ? null : "police") ? { ok: true, onDuty: !onDuty } : fail("NOT_POLICE");
});
```
</Tab>
<Tab value="Lua">
```lua
local LOCKER_ROOM = vector3(452.3, -993.2, 30.7)

aiLib.onClientCallback('myscript:toggleDuty', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - LOCKER_ROOM) > 3.0 then return aiLib.fail('TOO_FAR') end
  local onDuty = exports['ai-core']:GetDutyJob(source) == 'police'
  if not exports['ai-core']:SetDuty(source, (not onDuty) and 'police' or nil) then return aiLib.fail('NOT_POLICE') end
  return { ok = true, onDuty = not onDuty }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Der Dienst wird nicht gespeichert: Ein Spieler, der beitritt, ist außer Dienst, es sei denn, die Panel-Einstellung **Keep duty after rejoining** (Dienst nach erneutem Beitritt behalten) ist aktiv.
</Callout>

### SetJob

Gibt einem Spieler einen Job oder ändert den Rang eines Jobs, den er bereits hat.

**Seite:** Server · **Wartet:** nein · **Lib:** keine

```ts title="Signature"
SetJob(src: number, job: string, grade: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetJob(source, 'mechanic', 0)
```

#### Parameter

<TypeTable
  type={{
    src: { type: 'number', description: 'Server-ID des Spielers.', required: true },
    job: { type: 'string', description: 'Jobname aus dem Panel (`police`, `mechanic`).', required: true },
    grade: { type: 'number', description: 'Rang-Index, gezählt ab 0. Muss in der Rangliste des Jobs existieren.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn der Charakter jetzt `job` mit `grade` hat. `false`, wenn der Job nicht existiert, der Rang nicht existiert (keine ganze Zahl, unter 0 oder nach dem letzten Rang), der Charakter bereits so viele Jobs hat, wie **Most jobs per character** erlaubt, oder der Spieler keinen geladenen Charakter hat.

Wenn die Panel-Einstellung **Several jobs per character** (mehrere Jobs pro Charakter) aus ist, ersetzt ein neuer Job den anderen Job des Charakters.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail, readText } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Ein Jobcenter: Jeder darf einen Job, den das Panel listet, mit Rang 0 annehmen.
onClientCallback(
  "myscript:takeJob",
  { args: ([job]) => { const name = readText(job, 32); return name ? [name] : null; } },
  (source, job) => {
    if (!core.GetJobDefinition(job)?.listed) return fail("JOB_NOT_LISTED");
    return core.SetJob(source, job, 0) ? { ok: true } : fail("JOB_LIMIT");
  },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:takeJob', function(source, job)
  if type(job) ~= 'string' then return aiLib.fail('BAD_JOB') end
  local def = exports['ai-core']:GetJobDefinition(job)
  if not def or not def.listed then return aiLib.fail('JOB_NOT_LISTED') end
  if not exports['ai-core']:SetJob(source, job, 0) then return aiLib.fail('JOB_LIMIT') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### IsPrimeTime

Ob gerade Prime Time für einen Job ist. Die Prime-Time-Stunden kommen aus der Quelle, die das Panel wählt: ein Skript, das eigene Stunden führt (tgiann-policealert), solange es läuft, sonst die eigenen Stunden von ai-core (das eigene Zeitfenster des Jobs oder das Standardfenster). Nutze es für Regeln, die sich mit den Stoßzeiten ändern, etwa einen Überfall, der mehr bringt.

**Seite:** Server · **Wartet:** nein · **Lib:** [`isPrimeTime(job?)`](/de/docs/developers/api/lib-server/jobs#isprimetime)

```ts title="Signature"
IsPrimeTime(job?: string): boolean
```

```lua title="Lua"
local prime = exports['ai-core']:IsPrimeTime('police')
```

#### Parameter

<TypeTable
  type={{
    job: { type: 'string', description: 'Jobname. Ohne ihn (oder mit einem leeren Text) werden die Standardstunden geprüft.' },
  }}
/>

#### Rückgabe

`boolean`: `true` während der Prime Time. Die Stunden sind die lokale Zeit des Servers; ein Fenster, dessen Start später als sein Ende liegt, läuft über Mitternacht, und gleicher Start und gleiches Ende bedeuten den ganzen Tag. Wenn das Panel ein Skript als Quelle wählt und dieses Skript gestoppt ist, zählt jede Stunde als Prime Time. Es funktioniert unabhängig davon, ob die Prime-Time-Kürzung des Gehalts aktiv ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Ein Ladenüberfall bringt außerhalb der Polizei-Prime-Time 50 % mehr. */
export function robberyReward(base: number): number {
  return core.IsPrimeTime("police") ? base : Math.round(base * 1.5);
}
```
</Tab>
<Tab value="Lua">
```lua
function RobberyReward(base)
  if exports['ai-core']:IsPrimeTime('police') then return base end
  return math.floor(base * 1.5 + 0.5)
end
```
</Tab>
</Tabs>

### GetJobDefinitions

Jede Job-Definition aus dem Panel, als eine Kopie. Nutze es für seltene Lesevorgänge, etwa um eine Liste einmal aufzubauen; für einen einzelnen Job nutze `GetJobDefinition`.

**Seite:** Server · **Wartet:** nein · **Lib:** keine

```ts title="Signature"
GetJobDefinitions(): Record<string, JobDefinition>
```

```lua title="Lua"
local jobs = exports['ai-core']:GetJobDefinitions() -- Tabelle mit Jobnamen als Schlüssel
```

#### Parameter

Keine.

#### Rückgabe

`Record<string, JobDefinition>`: jeder Job nach Namen. Jeder hat `label`, `type`, `defaultDuty`, `listed` (in Jobcentern angezeigt) und `grades` (jeder mit `label`, `salary` und `boss`). Siehe [JobDefinition](/de/docs/developers/api/types#jobdefinition) und [GradeDefinition](/de/docs/developers/api/types#gradedefinition).

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Das Jobcenter listet jeden Job, der im Panel als „listed“ markiert ist.
onClientCallback("myscript:jobCenter", () => ({
  ok: true,
  jobs: Object.entries(core.GetJobDefinitions())
    .filter(([, def]) => def.listed)
    .map(([name, def]) => ({ name, label: def.label, salary: def.grades[0]?.salary ?? 0 })),
}));
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:jobCenter', function()
  local list = {}
  for name, def in pairs(exports['ai-core']:GetJobDefinitions()) do
    if def.listed then
      list[#list + 1] = { name = name, label = def.label, salary = def.grades[1] and def.grades[1].salary or 0 }
    end
  end
  return { ok = true, jobs = list }
end)
```
</Tab>
</Tabs>

<Callout type="info">
In Lua ist `def.grades[1]` Rang 0: Lua-Listen beginnen bei 1, Ränge bei 0.
</Callout>
