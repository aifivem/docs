Wpisy przechodzą przez ai-core, nigdy przez własne eksporty lub zdarzenia MDT. ai-core przekazuje każdy wpis do **aktywnego MDT**: tego, który wybiera ustawienie **MDT script** w panelu, albo pierwszego działającego. Nie ma MDT ai-*, więc **dopóki nie działa żadne MDT, wpisy nie są nigdzie zapisywane**. Otwieranie ekranu MDT dzieje się na kliencie (kliencki eksport `OpenMdt`, `mdt.open` liba).

### GetMdtSystem

Nazwa zasobu MDT, do którego ai-core przekazuje wpisy.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`mdt.provider()`](/pl/docs/developers/api/lib-server/jobs#mdtprovider)

```ts title="Sygnatura"
GetMdtSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetMdtSystem() -- string lub nil
```

#### Parametry

Brak.

#### Zwraca

`string | null`: nazwa zasobu MDT. `null`, gdy żadne nie działa.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("mdtsystem", { help: "Shows the MDT in use", restricted: true }, () => {
  console.log(core.GetMdtSystem() ?? "none: records are not written");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('mdtsystem', { help = 'Shows the MDT in use', restricted = true }, function()
  print(exports['ai-core']:GetMdtSystem() or 'none: records are not written')
end)
```
</Tab>

### AddMdtRecord

Zapisuje w MDT wpis o graczu: mandat, nakaz, aresztowanie albo karę więzienia. ai-core uzupełnia citizen id i imiona celu oraz funkcjonariusza.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`mdt.record`](/pl/docs/developers/api/lib-server/jobs#mdtrecord)

```ts title="Sygnatura"
AddMdtRecord(record: MdtRecord): boolean
```

```lua title="Lua"
local written = exports['ai-core']:AddMdtRecord({ kind = 'fine', target = target, by = source, title = 'Speeding', amount = 250 })
```

#### Parametry

<TypeTable
  type={{
    record: { type: 'MdtRecord', description: 'Wpis. Pola poniżej.', required: true },
  }}
/>

#### MdtRecord

<TypeTable
  type={{
    kind: { type: '"fine" | "warrant" | "arrest" | "jail"', description: 'Czego dotyczy wpis.', required: true },
    target: { type: 'number', description: 'Id serwera gracza, którego dotyczy wpis. Musi mieć wczytaną postać.', required: true },
    by: { type: 'number', description: 'Id serwera funkcjonariusza, który go pisze.' },
    title: { type: 'string', description: 'Co się stało (`Speeding`, `Armed robbery`), już przetłumaczone. Obcinane do 120 znaków.', required: true },
    amount: { type: 'number', description: 'Kwota mandatu w dolarach. Liczba całkowita od 1 do 10 000 000; w przeciwnym razie ignorowana.' },
    minutes: { type: 'number', description: 'Kara więzienia w minutach. Liczba całkowita od 1 do 100 000; w przeciwnym razie ignorowana.' },
  }}
/>

Zobacz [MdtRecord](/pl/docs/developers/api/types#mdtrecord) i [MdtRecordKind](/pl/docs/developers/api/types#mdtrecordkind).

#### Zwraca

`boolean`: `true`, gdy MDT go zapisało. `false`, gdy wpis jest niepoprawny (zły `kind`, brak `title`, `target` nie jest dodatnią liczbą całkowitą), cel nie ma wczytanej postaci, nie działa żadne MDT albo MDT nie przyjmuje wpisów od skryptów lub nie ma takiego rodzaju.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail, readId } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");

// Funkcjonariusz wsadza gracza do więzienia na 20 minut; MDT zachowuje wpis.
onClientCallback(
  "myscript:jail",
  { args: ([target]) => { const id = readId(target); return id === null ? null : [id]; }, lock: true },
  (source, target) => {
    if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
    if (!core.JailPlayer(target, 20, source)) return fail("JAIL_FAILED");
    core.AddMdtRecord({ kind: "jail", target, by: source, title: Locale("RECORD_ROBBERY"), minutes: 20 });
    return { ok: true };
  },
);
```
</Tab>

end, { lock = true })
