EMS katmanı her script için iki soruyu cevaplar: "kaç sağlıkçı çağrı alabilir?" ve "sağlıkçılara bir yardım çağrısı gönder". ai-core panelin **EMS source** ayarının seçtiği **EMS kaynağına** ya da çalışan ilk EMS script’ine sorar. O script’in cevaplayamadığını ai-core kendisi cevaplar: boş sağlıkçıları kendi mesai sayılarından, yardım çağrısını da [ihbar katmanı](/tr/docs/developers/api/core-server/dispatch) üzerinden mesleklere yüksek öncelikli bir ihbar olarak.

### GetEmsSystem

Kullanımdaki EMS kaynağı.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`ems.provider()`](/tr/docs/developers/api/lib-server/jobs#emsprovider)

```ts title="İmza"
GetEmsSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetEmsSystem() -- 'ai-core' ya da bir script adı
```

#### Parametreler

Yok.

#### Dönüş değeri

`string | null`: EMS script’inin resource adı ya da ai-core’un kendi parçası cevaplıyorsa `"ai-core"` (hiçbir EMS script’i çalışmıyor). ai-core’un kendi parçası her zaman oradadır, bu yüzden pratikte bu asla `null` olmaz.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("emssystem", { help: "Shows the EMS source", restricted: true }, () => {
  console.log(core.GetEmsSystem());
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('emssystem', { help = 'Shows the EMS source', restricted = true }, function()
  print(exports['ai-core']:GetEmsSystem())
end)
```
</Tab>
</Tabs>

### GetAvailableMedics

Verilen mesleklerde şu an kaç sağlıkçının çağrı alabileceği. Kendi ihbar sistemi olan bir EMS script’i meşgul sağlıkçıları dışarıda bırakır; ai-core’un kendi cevabı mesaideki herkestir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`ems.available`](/tr/docs/developers/api/lib-server/jobs#emsavailable)

```ts title="İmza"
GetAvailableMedics(jobs: string[]): number
```

```lua title="Lua"
local medics = exports['ai-core']:GetAvailableMedics({ 'ambulance' })
```

#### Parametreler

<TypeTable
  type={{
    jobs: { type: 'string[]', description: 'Sağlıkçı sayılan meslek adları (`ambulance`). Yalnızca ilk 10 metin kullanılır.', required: true },
  }}
/>

#### Dönüş değeri

`number`: boş sağlıkçılar. Hiç yoksa, boş bir liste ya da liste olmayan bir değer için `0`. EMS script’i başarısız olduğunda ai-core’un kendi mesai sayısı cevap verir.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const EMS_JOBS = ["ambulance"];

// "Hastanede yeniden doğ" düğmesi yalnızca hiçbir sağlıkçı gelemezken çalışır.
onClientCallback("myscript:respawn", (source) => {
  if (!core.IsPlayerDead(source)) return fail("NOT_DOWN");
  if (core.GetAvailableMedics(EMS_JOBS) > 0) return fail("MEDICS_AVAILABLE");
  // ... oyuncuyu hastaneye taşı ve canlandır
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local EMS_JOBS = { 'ambulance' }

aiLib.onClientCallback('myscript:respawn', function(source)
  if not exports['ai-core']:IsPlayerDead(source) then return aiLib.fail('NOT_DOWN') end
  if exports['ai-core']:GetAvailableMedics(EMS_JOBS) > 0 then return aiLib.fail('MEDICS_AVAILABLE') end
  -- ... oyuncuyu hastaneye taşı ve canlandır
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SendDistress

Yerdeki bir oyuncunun yardım çağrısını sağlıkçılara gönderir. Çağrı alan bir EMS script’i varsa çağrı oraya gider; yoksa ai-core aktif ihbar sistemi üzerinden `jobs` içindeki mesaideki üyelere yüksek öncelikli bir ihbar gönderir (kod `10-52`, bir ilk yardım çantası ikonu, oyuncunun konumu).

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`ems.distress`](/tr/docs/developers/api/lib-server/jobs#emsdistress)

```ts title="İmza"
SendDistress(source: number, call: DistressCall): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendDistress(source, { jobs = { 'ambulance' }, message = 'Unconscious' })
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Yerdeki oyuncunun server id’si.', required: true },
    call: { type: 'DistressCall', description: 'Kimin aldığı ve isteğe bağlı ek bir satır. Alanlar aşağıda.', required: true },
  }}
/>

#### DistressCall

<TypeTable
  type={{
    jobs: { type: 'string[]', description: 'Mesaideki üyelerinin aldığı meslekler. En az bir; yalnızca ilk 10 kullanılır.', required: true },
    message: { type: 'string', description: 'Bir satır daha, zaten çevrilmiş (`Unconscious`). 160 karaktere kesilir.' },
  }}
/>

Bkz. [DistressCall](/tr/docs/developers/api/types#distresscall).

#### Dönüş değeri

`boolean`: bir şey çağrıyı aldığında `true`. Oyuncu çevrimiçi değilse, `jobs` boşsa, EMS script’i reddettiyse ya da ai-core’un kendi ihbarı çalışan bir ihbar sistemi bulamadıysa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, Cooldowns, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const cooldowns = new Cooldowns();

// Ölüm ekranındaki "sağlıkçı çağır" düğmesi, dakikada bir kez.
onClientCallback("myscript:distress", (source) => {
  if (!core.IsPlayerDead(source)) return fail("NOT_DOWN");
  if (!cooldowns.take(source, 60_000)) return fail("WAIT");
  const sent = core.SendDistress(source, { jobs: ["ambulance"], message: Locale("DISTRESS_UNCONSCIOUS") });
  return sent ? { ok: true } : fail("NO_MEDICS");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local lastCall = {}

aiLib.onClientCallback('myscript:distress', function(source)
  if not exports['ai-core']:IsPlayerDead(source) then return aiLib.fail('NOT_DOWN') end
  local now = GetGameTimer()
  if lastCall[source] and now - lastCall[source] < 60000 then return aiLib.fail('WAIT') end
  lastCall[source] = now
  local sent = exports['ai-core']:SendDistress(source, { jobs = { 'ambulance' }, message = Locale('DISTRESS_UNCONSCIOUS') })
  if not sent then return aiLib.fail('NO_MEDICS') end
  return { ok = true }
end)

AddEventHandler('playerDropped', function() lastCall[source] = nil end)
```
</Tab>
</Tabs>
