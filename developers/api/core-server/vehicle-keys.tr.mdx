Her anahtar çağrısı ai-core üzerinden gider, asla bir anahtar script’inin kendi export’ları üzerinden değil (ai-vehiclekeys dahil). ai-core onu **aktif anahtar sistemine** iletir: panelin **Key script** ayarının seçtiği ya da çalışan ilk sistem. Hiçbir anahtar script’i çalışmıyorken her oyuncu her anahtara sahip sayılır.

Bir **araç** ya bir server entity handle’ı (`CreateVehicleServerSetter`’ın ya da `spawnVehicle`’ın döndürdüğü sayı) ya da bir plaka metni olarak verilir. Plaka önce kırpılır ve büyük harfe çevrilir, bu yüzden `" ab12cde "` ve `"AB12CDE"` aynı anahtardır.

Her anahtarın, anahtar sistemine oyuncunun onu neden aldığını söyleyen bir **amacı** vardır. Bazı anahtar sistemleri bunları farklı ele alır (satın alınan bir araç yeni bir anahtar eşyası, bir iş aracı kontağa sabit bir anahtar alır). Bkz. [KeyPurpose](/tr/docs/developers/api/types#keypurpose).

| Amaç | Ne zaman |
| --- | --- |
| `purchase` | Oyuncu artık aracın sahibi (galeri, admin verdi): yeni bir anahtar, eski kopyalar çalışmayı bırakır. |
| `garage` | Depodan çıkarılan sahipli bir araç: sahibinde anahtar zaten vardır. |
| `job` | Vardiya için bir iş aracı. |
| `rental` | Kiralama süresi boyunca kiralık bir araç. |
| `temporary` | Kısa ömürlü başka her şey (admin spawn’ı, test sürüşü, soygun aracı). Varsayılan. |

### GiveVehicleKeys

Bir oyuncuya bir aracın anahtarlarını verir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`vehicleKeys.give`](/tr/docs/developers/api/lib-server/vehicles#vehiclekeysgive) (ve [`spawnVehicle({ keysTo, purpose })`](/tr/docs/developers/api/lib-server/vehicles#spawnvehicle) onları senin için verir)

```ts title="İmza"
GiveVehicleKeys(source: number, vehicle: number | string, purpose?: KeyPurpose): void
```

```lua title="Lua"
exports['ai-core']:GiveVehicleKeys(source, vehicle, 'rental')
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Anahtarları alan oyuncunun server id’si.', required: true },
    vehicle: { type: 'number | string', description: 'Aracın server entity handle’ı ya da plakası.', required: true },
    purpose: { type: 'KeyPurpose', description: 'Oyuncunun onları neden aldığı. Başka herhangi bir değer `temporary` sayılır.', default: '"temporary"', typeDescription: '"purchase" | "garage" | "job" | "rental" | "temporary"' },
  }}
/>

#### Dönüş değeri

Hiçbir şey. Araç entity’si yoksa, plaka boşsa, `source` bir sayı değilse ya da hiçbir anahtar sistemi çalışmıyorsa çağrı hiçbir şey yapmaz. Bir anahtar sisteminin hatası fırlatılmaz, loglanır.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, spawnVehicle } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const SPAWN = { x: -1023.5, y: -2694.1, z: 13.9, heading: 150 };

onClientCallback("myscript:rentScooter", { lock: true }, async (source) => {
  if (!core.RemoveMoney(source, "cash", 100, "scooter_rental")) return fail("NOT_ENOUGH_MONEY");
  const vehicle = await spawnVehicle({ model: "faggio", coords: SPAWN, asker: source });
  if (!vehicle) {
    core.AddMoney(source, "cash", 100, "scooter_rental_refund");
    return fail("SPAWN_FAILED");
  }
  core.GiveVehicleKeys(source, vehicle, "rental");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local SPAWN = vector4(-1023.5, -2694.1, 13.9, 150.0)

aiLib.onClientCallback('myscript:rentScooter', function(source)
  if not exports['ai-core']:RemoveMoney(source, 'cash', 100, 'scooter_rental') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  local vehicle = aiLib.spawnVehicle({ model = 'faggio', coords = SPAWN, asker = source })
  if not vehicle then
    exports['ai-core']:AddMoney(source, 'cash', 100, 'scooter_rental_refund')
    return aiLib.fail('SPAWN_FAILED')
  end
  exports['ai-core']:GiveVehicleKeys(source, vehicle, 'rental')
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Yeni oluşturulmuş bir aracın, sahibi olan client onu senkronlayana kadar server’da plakası yoktur. Oluşturduktan hemen sonra okuduğun bir plakayı değil, entity’yi ver; lib’in `spawnVehicle`’ı plakayı bekler ve anahtarları kendisi verebilir (`keysTo`, `purpose`).
</Callout>

### RemoveVehicleKeys

Bir oyuncudan bir aracın anahtarlarını alır.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`vehicleKeys.remove`](/tr/docs/developers/api/lib-server/vehicles#vehiclekeysremove)

```ts title="İmza"
RemoveVehicleKeys(source: number, vehicle: number | string): void
```

```lua title="Lua"
exports['ai-core']:RemoveVehicleKeys(source, 'AB12CDE')
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    vehicle: { type: 'number | string', description: 'Aracın server entity handle’ı ya da plakası.', required: true },
  }}
/>

#### Dönüş değeri

Hiçbir şey. `GiveVehicleKeys` ile aynı sessiz durumlar.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Kiralama bitti: önce anahtarlar gider, sonra scooter. */
export function endRental(source: number, vehicle: number): void {
  core.RemoveVehicleKeys(source, vehicle);
  if (DoesEntityExist(vehicle)) DeleteEntity(vehicle);
}
```
</Tab>
<Tab value="Lua">
```lua
function EndRental(source, vehicle)
  exports['ai-core']:RemoveVehicleKeys(source, vehicle)
  if DoesEntityExist(vehicle) then DeleteEntity(vehicle) end
end
```
</Tab>
</Tabs>

<Callout type="warn">
Aracı silmeden önce anahtarları al. Bazı anahtar sistemleri plakayı entity’den okur, entity gittikten sonra bu başarısız olur.
</Callout>

### HasVehicleKeys

Bir oyuncunun bir aracın anahtarlarına sahip olup olmadığı.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`vehicleKeys.has`](/tr/docs/developers/api/lib-server/vehicles#vehiclekeyshas)

```ts title="İmza"
HasVehicleKeys(source: number, vehicle: number | string): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasVehicleKeys(source, vehicle)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    vehicle: { type: 'number | string', description: 'Aracın server entity handle’ı ya da plakası.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: oyuncu anahtarlara sahipse `true`. Hiçbir anahtar sistemi çalışmıyorsa, anahtar sistemi bu soruyu cevaplayamıyorsa ya da başarısız olursa da `true`; böylece eksik bir anahtar script’i oyuncuları asla dışarıda bırakmaz. Oyuncunun anahtarı yoksa, araç entity’si yoksa, plaka boşsa ya da `source` bir sayı değilse `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Oyuncunun yanındaki bir arabanın bagajını açmak anahtarlarını gerektirir.
onClientCallback("myscript:openTrunk", { args: oneArg(readId) }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 4 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.HasVehicleKeys(source, vehicle)) return fail("NO_KEYS");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:openTrunk', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 4 }) -- yakında değilse 0
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:HasVehicleKeys(source, vehicle) then return aiLib.fail('NO_KEYS') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
