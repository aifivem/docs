Jede Ressource loggt über ai-core. Deine Ressource nennt einen **Kanal** (`purchases`, `robberies`) und schreibt eine Nachricht; ai-core entscheidet, wohin sie geht. Der Serverbesitzer schaltet im Admin-Panel Anbieter ein (Konsole, Discord, Fivemanage, FiveM Stats), legt das Mindestlevel fest und fügt Discord-Webhook-URLs pro Ressource und Kanal ein. Eine Ressource postet nie selbst an einen Webhook oder einen Log-Dienst und hält nie eine Webhook-URL.

Übergib die beteiligten Spieler als `source` und `target`, statt ihre Namen in die Nachricht zu schreiben: ai-core fügt Name, Charakter, Citizen-ID und Identifier jedes Spielers hinzu (die IP nur, wenn das Panel es erlaubt).

### Log

Sendet einen Log-Eintrag deiner Ressource.

**Seite:** Server · **Wartet:** nein · **Lib:** [`aiLog(channel, message, options?)`](/de/docs/developers/api/lib-server/logs#ailog) (Lua: `aiLib.aiLog`; beide geben stattdessen in die Konsole aus, solange ai-core nicht läuft)

```ts title="Signature"
Log(channel: string, message: string, options?: LogOptions): void
```

```lua title="Lua"
exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { price = 25000 } })
```

#### Parameter

<TypeTable
  type={{
    channel: { type: 'string', description: 'Kanalname deiner Ressource (`purchases`). Der Webhook und der Ein-/Aus-Schalter gelten pro Kanal. `log`, wenn kein Text.', required: true },
    message: { type: 'string', description: 'Was passiert ist, in einfachem Englisch. Andere Werte werden in Text umgewandelt.', required: true },
    options: { type: 'LogOptions', description: 'Level, Spieler und zusätzliche Werte. Felder unten.' },
  }}
/>

#### LogOptions

<TypeTable
  type={{
    level: { type: '"debug" | "info" | "warn" | "error"', description: 'Wie wichtig es ist. Einträge unter dem Mindestlevel des Panels werden verworfen.', default: '"info"' },
    source: { type: 'number', description: 'Server-ID des Spielers, der es getan hat; sein Name, Charakter und seine Identifier werden hinzugefügt.' },
    target: { type: 'number', description: 'Server-ID des Spielers, dem es angetan wurde.' },
    metadata: { type: 'Record<string, unknown>', description: 'Zusätzliche Werte (Beträge, Item-Namen, Koordinaten). Keine Tabelle: ignoriert.' },
  }}
/>

Siehe [LogOptions](/de/docs/developers/api/types#logoptions) und [LogLevel](/de/docs/developers/api/types#loglevel).

#### Rückgabe

Nichts. Der Eintrag wird stillschweigend verworfen, wenn sein Level unter dem Mindestwert des Panels liegt oder sein Kanal mit `LogChannels` ausgeschaltet ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:buyCar", { lock: true }, (source) => {
  const price = 25_000;
  if (!core.RemoveMoney(source, "bank", price, "car_purchase")) return fail("NOT_ENOUGH_MONEY");
  // ... das Auto erstellen und speichern
  core.Log("purchases", "Bought a car", { source, metadata: { model: "sultan", price } });
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:buyCar', function(source)
  local price = 25000
  if not exports['ai-core']:RemoveMoney(source, 'bank', price, 'car_purchase') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  -- ... das Auto erstellen und speichern
  exports['ai-core']:Log('purchases', 'Bought a car', { source = source, metadata = { model = 'sultan', price = price } })
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Logs sind für den Serverbesitzer, deshalb bleibt die Nachricht englisch und wird nicht übersetzt. Halte die Nachricht kurz und lege Werte in `metadata` ab, wo Log-Dienste nach ihnen filtern können.
</Callout>

### LogChannels

Beschreibt die Kanäle deiner Ressource: ihren Dataset-Namen für Fivemanage und FiveM Stats und ob jeder aktiv ist. Rufe es einmal auf, wenn deine Ressource startet. Kanäle, die du nie beschreibst, funktionieren trotzdem mit den Standardwerten.

**Seite:** Server · **Wartet:** nein · **Lib:** [`aiLogChannels(channels)`](/de/docs/developers/api/lib-server/logs#ailogchannels)

```ts title="Signature"
LogChannels(channels: Record<string, LogChannel>): void
```

```lua title="Lua"
exports['ai-core']:LogChannels({ purchases = { dataset = 'myscript-sales' }, debug = { active = false } })
```

#### Parameter

<TypeTable
  type={{
    channels: { type: 'Record<string, LogChannel>', description: 'Kanalname zu seinen Einstellungen. Felder jedes Kanals unten.', required: true },
  }}
/>

#### LogChannel

<TypeTable
  type={{
    dataset: { type: 'string', description: 'Dataset-Name für Fivemanage und FiveM Stats.', default: 'der Ressourcenname' },
    active: { type: 'boolean', description: '`false` schaltet den Kanal aus: Seine Einträge werden verworfen.', default: 'true' },
  }}
/>

Siehe [LogChannel](/de/docs/developers/api/types#logchannel).

#### Rückgabe

Nichts. Ein zweiter Aufruf ersetzt die gesamte Beschreibung deiner Ressource. Sie wird verworfen, wenn deine Ressource stoppt. Ein Wert, der keine Tabelle ist, bewirkt nichts.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Einmal beim Start.
core.LogChannels({
  purchases: { dataset: "myscript-sales" },
  robberies: { dataset: "myscript-crime" },
  debug: { active: false },
});
```
</Tab>
<Tab value="Lua">
```lua
exports['ai-core']:LogChannels({
  purchases = { dataset = 'myscript-sales' },
  robberies = { dataset = 'myscript-crime' },
  debug = { active = false },
})
```
</Tab>
</Tabs>

<Callout type="warn">
Webhook-URLs gehören nie hierher oder irgendwo in deine Ressource: Der Serverbesitzer legt sie im Panel von ai-core fest, das sie in einer Datei hält, die nicht geteilt wird.
</Callout>
