Her eşya çağrısı ai-core üzerinden gider, asla bir envanter script’inin kendi export’ları üzerinden değil. ai-core her çağrıyı **aktif envantere** iletir: panelin **Inventory script** ayarının seçtiği ya da otomatik ayarlıyken çalışan ilk envanter (ai-inventory, ox_inventory, qb-inventory, tgiann-inventory ve uyumluluk listesindeki diğerleri). Sunucu sahibi envanteri değiştirdiğinde script’in hiç değişmeden çalışmaya devam eder.

Bilmen gerekenler:

- Bir **envanter** bir `InventoryRef` ile adlandırılır: o oyuncunun cepleri için oyuncunun server id’si (bir sayı), başka her şey için bir metin id (bir stash adı, bir bagaj plakası). Bkz. [InventoryRef](/tr/docs/developers/api/types#inventoryref).
- **Eşya adları** envanterin eşya adlarıdır (`water`, `bandage`, `WEAPON_PISTOL`).
- **Metadata** tek bir yığındaki ek değerlerin tablosudur (seri numarası, dayanıklılık). Bkz. [ItemMetadata](/tr/docs/developers/api/types#itemmetadata).
- **Hiçbir envanter çalışmıyorken** her çağrı kendi "hiçbir şey" değerini döndürür: `false`, `0`, boş bir liste ya da `null`.
- Kaydettiğin stash’ler, dükkanlar ve kullanılabilir eşyalar **ai-core tarafından tutulur** ve sonradan aktif olan her envantere, bir envanter yeniden başladıktan sonra da verilir. Onları script’in başladığında bir kez kaydet.

### AddItem

Bir envantere eşya verir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`inventory.addItem`](/tr/docs/developers/api/lib-server/items#inventoryadditem)

```ts title="İmza"
AddItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:AddItem(source, 'water', 2)
```

#### Parametreler

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Bir oyuncunun server id’si ya da bir stash / bagaj id’si.', required: true, typeDescription: 'number | string' },
    item: { type: 'string', description: 'Eşya adı.', required: true },
    count: { type: 'number', description: 'Kaç tane. 1 ya da daha büyük bir sayı; kesirli sayı aşağı yuvarlanır.', default: '1' },
    metadata: { type: 'ItemMetadata', description: 'Yeni yığın için ek değerler. Tablo olmayan her şey yok sayılır.' },
    slot: { type: 'number', description: 'Konacakları slot (0’ın üstünde bir tam sayı). Aksi halde yok sayılır; envanter seçer.' },
  }}
/>

#### Dönüş değeri

`boolean`: envanter eşyaları eklediğinde `true`. Sığmıyorlarsa, eşya envanterde yoksa, bir argüman yanlışsa (`count` 1’in altında, boş eşya adı) ya da hiçbir envanter çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const TAP = { x: 1206.4, y: -3110.2, z: 5.6 };

onClientCallback("myscript:fillBottle", { guards: [near(TAP, 2)], lock: true }, (source) => {
  if (!core.RemoveItem(source, "empty_bottle")) return fail("NO_BOTTLE");
  if (!core.AddItem(source, "water")) {
    core.AddItem(source, "empty_bottle");
    return fail("NO_SPACE");
  }
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local TAP = vector3(1206.4, -3110.2, 5.6)

aiLib.onClientCallback('myscript:fillBottle', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - TAP) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:RemoveItem(source, 'empty_bottle') then return aiLib.fail('NO_BOTTLE') end
  if not exports['ai-core']:AddItem(source, 'water') then
    exports['ai-core']:AddItem(source, 'empty_bottle')
    return aiLib.fail('NO_SPACE')
  end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### RemoveItem

Bir envanterden eşya alır.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`inventory.removeItem`](/tr/docs/developers/api/lib-server/items#inventoryremoveitem)

```ts title="İmza"
RemoveItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:RemoveItem(source, 'lockpick', 1)
```

#### Parametreler

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Bir oyuncunun server id’si ya da bir stash / bagaj id’si.', required: true, typeDescription: 'number | string' },
    item: { type: 'string', description: 'Eşya adı.', required: true },
    count: { type: 'number', description: 'Kaç tane. 1 ya da daha büyük bir sayı; kesirli sayı aşağı yuvarlanır.', default: '1' },
    metadata: { type: 'ItemMetadata', description: 'Yalnızca bu metadata değerlerine sahip yığınlardan al.' },
    slot: { type: 'number', description: 'Yalnızca bu slottan al (0’ın üstünde bir tam sayı).' },
  }}
/>

#### Dönüş değeri

`boolean`: eşyalar alındığında `true`. Envanterde daha az varsa (o zaman hiçbiri alınmaz), bir argüman yanlışsa ya da hiçbir envanter çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, minigameFor, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:pickLock", { lock: true }, async (source) => {
  if (!core.HasItem(source, "lockpick")) return fail("NO_LOCKPICK");
  const result = await minigameFor(source, { game: "lockpick", minMs: 1500 });
  if (result === "broken") core.RemoveItem(source, "lockpick");
  return result === "won" ? { ok: true } : fail("LOCKPICK_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:pickLock', function(source)
  if not exports['ai-core']:HasItem(source, 'lockpick') then return aiLib.fail('NO_LOCKPICK') end
  local result = aiLib.minigameFor(source, { game = 'lockpick', minMs = 1500 })
  if result == 'broken' then exports['ai-core']:RemoveItem(source, 'lockpick') end
  if result ~= 'won' then return aiLib.fail('LOCKPICK_FAILED') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### HasItem

Bir envanterde bir eşyadan en az belli sayıda olup olmadığı.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`inventory.hasItem`](/tr/docs/developers/api/lib-server/items#inventoryhasitem)

```ts title="İmza"
HasItem(inv: InventoryRef, item: string, count?: number): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasItem(source, 'repairkit')
```

#### Parametreler

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Bir oyuncunun server id’si ya da bir stash / bagaj id’si.', required: true, typeDescription: 'number | string' },
    item: { type: 'string', description: 'Eşya adı.', required: true },
    count: { type: 'number', description: 'Kaç tane gerektiği (1 ya da daha fazla; kesirli sayı aşağı yuvarlanır).', default: '1' },
  }}
/>

#### Dönüş değeri

`boolean`: envanterde `count` ya da daha fazla varsa `true`. Daha az varsa, `count` 1’in altındaysa ya da hiçbir envanter çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, progressFor, resourceExport } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");

onClientCallback("myscript:repair", { lock: true }, async (source) => {
  if (!core.HasItem(source, "repairkit")) return fail("NO_KIT");
  if (!(await progressFor(source, { label: Locale("REPAIRING"), duration: 8000 }))) return fail("CANCELLED");
  if (!core.RemoveItem(source, "repairkit")) return fail("NO_KIT");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

aiLib.onClientCallback('myscript:repair', function(source)
  if not exports['ai-core']:HasItem(source, 'repairkit') then return aiLib.fail('NO_KIT') end
  if not aiLib.progressFor(source, { label = Locale('REPAIRING'), duration = 8000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:RemoveItem(source, 'repairkit') then return aiLib.fail('NO_KIT') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Bekleyen her şeyden sonra (bir ilerleme çubuğu, bir mini oyun) `RemoveItem`’ın cevabıyla tekrar kontrol et: oyuncu bu arada eşyayı bırakmış olabilir.
</Callout>

### GetItems

Bir envanterdeki her yığın, etiketleriyle.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`inventory.getItems`](/tr/docs/developers/api/lib-server/items#inventorygetitems)

```ts title="İmza"
GetItems(inv: InventoryRef): InventoryStack[]
```

```lua title="Lua"
local stacks = exports['ai-core']:GetItems(source) -- tablo listesi
```

#### Parametreler

<TypeTable
  type={{
    inv: { type: 'InventoryRef', description: 'Bir oyuncunun server id’si ya da bir stash / bagaj id’si.', required: true, typeDescription: 'number | string' },
  }}
/>

#### Dönüş değeri

`InventoryStack[]`: yığın başına `name`, `label`, `count`, `slot` ve `metadata` içeren bir kayıt. Bkz. [InventoryStack](/tr/docs/developers/api/types#inventorystack). Boş ya da bilinmeyen bir envanter, yanlış bir argüman ya da çalışan envanter yokken boş liste.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Bir rehinci, oyuncunun taşıdığı ve kendisinin satın aldığı her eşyayı listeler.
const BUYS: Record<string, number> = { gold_ring: 120, rolex: 400 };

onClientCallback("myscript:pawnList", (source) => ({
  ok: true,
  rows: core.GetItems(source)
    .filter((stack) => BUYS[stack.name] !== undefined)
    .map((stack) => ({ slot: stack.slot, label: stack.label, count: stack.count, price: BUYS[stack.name] })),
}));
```
</Tab>
<Tab value="Lua">
```lua
local BUYS = { gold_ring = 120, rolex = 400 }

aiLib.onClientCallback('myscript:pawnList', function(source)
  local rows = {}
  for _, stack in ipairs(exports['ai-core']:GetItems(source)) do
    if BUYS[stack.name] then
      rows[#rows + 1] = { slot = stack.slot, label = stack.label, count = stack.count, price = BUYS[stack.name] }
    end
  end
  return { ok = true, rows = rows }
end)
```
</Tab>
</Tabs>

### RegisterStash

Bir stash oluşturur: oyuncuların adıyla açtığı bir depolama kutusu. ai-core onu tutar ve aktif olan her envantere yeniden kaydeder.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`inventory.registerStash`](/tr/docs/developers/api/lib-server/items#inventoryregisterstash)

```ts title="İmza"
RegisterStash(name: string, label: string, slots: number, maxWeight: number, jobs?: string[]): void
```

```lua title="Lua"
exports['ai-core']:RegisterStash('police_evidence', 'Evidence', 100, 500000, { 'police' })
```

#### Parametreler

<TypeTable
  type={{
    name: { type: 'string', description: 'Benzersiz stash id’si, onu açmak için `InventoryRef` de budur (`police_evidence`).', required: true },
    label: { type: 'string', description: 'Stash ekranında gösterilen başlık. Çevrilmiş bir metin ver.', required: true, default: 'name' },
    slots: { type: 'number', description: 'Slot sayısı (0’ın üstünde, aşağı yuvarlanır).', required: true, default: '50' },
    maxWeight: { type: 'number', description: 'Envanter biriminde ağırlık sınırı (ai-inventory’de gram). 0’ın üstünde.', required: true, default: '100000' },
    jobs: { type: 'string[]', description: 'Meslek kontrol eden envanterlerde açmasına izin verilen meslekler. Boş: herkes.', default: '[]' },
  }}
/>

Bir değer eksik ya da yanlış olduğunda varsayılanlar uygulanır.

#### Dönüş değeri

Hiçbir şey. Metin bir `name` olmadan çağrı hiçbir şey yapmaz. Aynı adı tekrar kaydetmek stash’i değiştirir.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const LOCKER = { x: 474.9, y: -994.7, z: 26.3 };

// Açılışta bir kez; ai-core onu sonradan başlayan envanterlere verir.
core.RegisterStash("police_evidence", Locale("STASH_EVIDENCE"), 100, 500_000, ["police"]);

onClientCallback("myscript:openEvidence", { guards: [near(LOCKER, 2)] }, (source) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  return core.OpenInventory(source, "police_evidence") ? { ok: true } : fail("STASH_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local LOCKER = vector3(474.9, -994.7, 26.3)

exports['ai-core']:RegisterStash('police_evidence', Locale('STASH_EVIDENCE'), 100, 500000, { 'police' })

aiLib.onClientCallback('myscript:openEvidence', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - LOCKER) > 2.0 then return aiLib.fail('TOO_FAR') end
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  if not exports['ai-core']:OpenInventory(source, 'police_evidence') then return aiLib.fail('STASH_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### OpenInventory

Bir oyuncunun ekranında, kendi envanterinin yanında bir stash, bir bagaj ya da başka bir oyuncunun envanterini açar.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`inventory.openInventory`](/tr/docs/developers/api/lib-server/items#inventoryopeninventory)

```ts title="İmza"
OpenInventory(source: number, inv: InventoryRef): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenInventory(source, 'police_evidence')
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Ekranı gören oyuncunun server id’si.', required: true },
    inv: { type: 'InventoryRef', description: 'Ne açılacağı: bir stash id’si, bir bagaj id’si ya da başka bir oyuncunun server id’si (oyuncu araması).', required: true, typeDescription: 'number | string' },
  }}
/>

#### Dönüş değeri

`boolean`: envanter ekranı açtığında `true`. Açamadığında (bilinmeyen stash, oyuncunun envanteri yok), bir argüman yanlışsa ya da hiçbir envanter çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, isNear, coordsOf, resourceExport } from "@aicore-fivem/lib/server";
import { fail, oneArg, readId } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");

// Polis yanında duran kelepçeli bir oyuncuyu arar.
onClientCallback("myscript:search", { args: oneArg(readId) }, (source, target) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  if (target === source || !isNear(target, coordsOf(source), 2)) return fail("TOO_FAR");
  return core.OpenInventory(source, target) ? { ok: true } : fail("SEARCH_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:search', function(source, target)
  if math.type(target) ~= 'integer' or target == source then return aiLib.fail('BAD_TARGET') end
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  local a, b = GetEntityCoords(GetPlayerPed(source)), GetEntityCoords(GetPlayerPed(target))
  if #(a - b) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenInventory(source, target) then return aiLib.fail('SEARCH_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Envanter burada mesafe ya da yetki kontrolü yapmaz. Çağırmadan önce mesleği, mesafeyi ve hedefin durumunu kendin kontrol et.
</Callout>

### RegisterShop

Bir script dükkanı oluşturur: script’inin bir oyuncu için açtığı fiyatlı bir eşya listesi (bir cephanelik, bir otomat). Envanter dükkanı çizer ve ödemeyi kendi yöntemiyle alır (önce nakit, sonra banka). ai-core onu tutar ve aktif olan her envantere verir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`inventory.registerShop`](/tr/docs/developers/api/lib-server/items#inventoryregistershop)

```ts title="İmza"
RegisterShop(name: string, label: string, items: ShopProduct[]): void
```

```lua title="Lua"
exports['ai-core']:RegisterShop('police_armoury', 'Armoury', { { name = 'bandage', price = 0 } })
```

#### Parametreler

<TypeTable
  type={{
    name: { type: 'string', description: 'Benzersiz dükkan id’si (`police_armoury`).', required: true },
    label: { type: 'string', description: 'Dükkan ekranının başlığı. Çevrilmiş bir metin ver.', required: true, default: 'name' },
    items: { type: 'ShopProduct[]', description: 'Ürünler: eşya başına 0 ya da daha büyük tam bir fiyatla `{ name, price }`. En fazla 200; adı ya da fiyatı yanlış satırlar atlanır.', required: true, typeDescription: '{ name: string; price: number }[]' },
  }}
/>

Bkz. [ShopProduct](/tr/docs/developers/api/types#shopproduct).

#### Dönüş değeri

Hiçbir şey. Metin bir `name` olmadan ya da geçerli ürün olmadan çağrı hiçbir şey yapmaz. Aynı adı tekrar kaydetmek dükkanı değiştirir.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const ARMOURY = { x: 482.6, y: -995.2, z: 30.7 };

core.RegisterShop("police_armoury", Locale("SHOP_ARMOURY"), [
  { name: "WEAPON_STUNGUN", price: 0 },
  { name: "bandage", price: 10 },
]);

onClientCallback("myscript:armoury", { guards: [near(ARMOURY, 2)] }, (source) => {
  if (core.GetDutyJob(source) !== "police") return fail("NOT_POLICE");
  return core.OpenShop(source, "police_armoury") ? { ok: true } : fail("SHOP_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local ARMOURY = vector3(482.6, -995.2, 30.7)

exports['ai-core']:RegisterShop('police_armoury', Locale('SHOP_ARMOURY'), {
  { name = 'WEAPON_STUNGUN', price = 0 },
  { name = 'bandage', price = 10 },
})

aiLib.onClientCallback('myscript:armoury', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - ARMOURY) > 2.0 then return aiLib.fail('TOO_FAR') end
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return aiLib.fail('NOT_POLICE') end
  if not exports['ai-core']:OpenShop(source, 'police_armoury') then return aiLib.fail('SHOP_FAILED') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### RegisterUsableItem

Bir eşyayı kullanılabilir yapar: bir oyuncu onu envanterde kullandığında fonksiyonun çalışır. ai-core fonksiyonu tutar, böylece sonradan başlayan envanterlerle çalışır ve bir envanter yeniden başlamasından sağ çıkar.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`inventory.registerUsableItem`](/tr/docs/developers/api/lib-server/items#inventoryregisterusableitem)

```ts title="İmza"
RegisterUsableItem(name: string, handler: UsableItemHandler): void
// UsableItemHandler = (source: number, item: UsedItem) => unknown
```

```lua title="Lua"
exports['ai-core']:RegisterUsableItem('bandage', function(source, item) end)
```

#### Parametreler

<TypeTable
  type={{
    name: { type: 'string', description: 'Eşya adı.', required: true },
    handler: { type: 'UsableItemHandler', description: 'Her kullanımda oyuncunun server id’si ve kullanılan yığınla (`name`, `slot`, `count`, `metadata`) çalışır. Eşyayı tutmak için `false` döndür.', required: true, typeDescription: '(source: number, item: UsedItem) => unknown' },
  }}
/>

Bkz. [UsableItemHandler](/tr/docs/developers/api/types#usableitemhandler) ve [UsedItem](/tr/docs/developers/api/types#useditem).

#### Dönüş değeri

Hiçbir şey. Metin bir `name` ya da bir fonksiyon olmadan çağrı hiçbir şey yapmaz. Aynı eşya için ikinci bir çağrı handler’ı değiştirir.

Kullanımdan sonra eşyaya ne olacağı envantere bağlıdır: kullanılan eşyayı kendisi alan envanterler (ai-inventory eşyanın **consume** miktarını alır) handler’ın `false` döndürdüğünde onu tutar; diğer envanterler kendi eşya ayarlarına uyar, bu yüzden orada gerektiğinde eşyayı kendin çıkar.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { progressFor, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

core.RegisterUsableItem("bandage", (source) => {
  // Handler hemen cevap vermelidir; zamanlı kısım kendi başına çalışır.
  void (async () => {
    if (!(await progressFor(source, { label: Locale("BANDAGING"), duration: 4000 }))) return;
    if (!core.RemoveItem(source, "bandage")) return;
    emitNet("myscript:client:heal", source, 25); // client script’in canı ekler
  })();
  return false; // yerinde tut: çubuk bittiğinde yukarıda çıkarılır
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

exports['ai-core']:RegisterUsableItem('bandage', function(source, item)
  CreateThread(function()
    if not aiLib.progressFor(source, { label = Locale('BANDAGING'), duration = 4000 }) then return end
    if not exports['ai-core']:RemoveItem(source, 'bandage') then return end
    TriggerClientEvent('myscript:client:heal', source, 25) -- client script’in canı ekler
  end)
  return false
end)
```
</Tab>
</Tabs>

<Callout type="info">
Bir kullanım ayrıca açlık ve susuzluk gibi eşya etkilerinin izlediği `ai-core:itemUsed (src, name, status)` server event’ini tetikler. Bkz. [Event’ler ve durum](/tr/docs/developers/api/events).
</Callout>

### GetItemDefinition

Aktif envanterin tanımladığı haliyle tek bir eşya: etiket, ağırlık, yığılıp yığılmadığı, resim.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`inventory.getItemDefinition`](/tr/docs/developers/api/lib-server/items#inventorygetitemdefinition)

```ts title="İmza"
GetItemDefinition(name: string): ItemDefinition | null
```

```lua title="Lua"
local def = exports['ai-core']:GetItemDefinition('water') -- tablo ya da nil
```

#### Parametreler

<TypeTable
  type={{
    name: { type: 'string', description: 'Eşya adı.', required: true },
  }}
/>

#### Dönüş değeri

`ItemDefinition | null`: `name`, `label`, `weight`, `unique`, `close`, `description` ve envanterde varsa `image` içeren eşya. Bkz. [ItemDefinition](/tr/docs/developers/api/types#itemdefinition). Bilinmeyen bir eşya, boş bir ad ya da çalışan envanter yokken `null`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { notify, resourceExport } from "@aicore-fivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Envanterin kendi etiketiyle "2x Water aldın". */
export function giveWithNotice(source: number, item: string, count: number): void {
  if (!core.AddItem(source, item, count)) return;
  const label = core.GetItemDefinition(item)?.label ?? item;
  notify(source, Locale("NOTIFY_RECEIVED", count, label), "success");
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function GiveWithNotice(source, item, count)
  if not exports['ai-core']:AddItem(source, item, count) then return end
  local def = exports['ai-core']:GetItemDefinition(item)
  aiLib.notify(source, Locale('NOTIFY_RECEIVED', count, def and def.label or item), 'success')
end
```
</Tab>
</Tabs>

### GetItemDefinitions

Aktif envanterin tanımladığı her eşya, ada göre anahtarlanmış. Seyrek kullan (bir listeyi bir kez kurmak); tek bir eşya için `GetItemDefinition` kullan.


```lua title="Lua"

```

#### Parametreler

Yok.

#### Dönüş değeri

`Record<string, ItemDefinition>`: her eşya. Hiçbir envanter çalışmıyorken boş tablo.

#### Örnek
