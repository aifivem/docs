Warstwa bankowości dociera do **aktywnego skryptu bankowego**: tego, który wybiera ustawienie **Banking script** w panelu, albo pierwszego działającego. Otwiera ekran tego skryptu i podaje salda firm. Same pieniądze prac i gangów zawsze przechodzą przez eksporty pieniędzy ai-core ([Pieniądze i konta](/pl/docs/developers/api/core-server/money)), nigdy przez skrypt bankowy.

To, jak konta prac i gangów mają się do skryptu bankowego, zależy od ustawienia **Job and gang accounts** w panelu:

- **ai-core's accounts** (konta ai-core, domyślnie): pieniądze trzyma ai-core; skrypt bankowy pokazuje to samo saldo, a pieniądze przesunięte na jego ekranie są przesuwane także w ai-core.
- **The script's own accounts** (własne konta skryptu): pieniądze trzyma skrypt bankowy; konta `bank` prac i gangów w ai-core czytają i zmieniają konta skryptu.

### GetBankingSystem

Nazwa zasobu skryptu bankowego, którego używa ai-core.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`banking.provider()`](/pl/docs/developers/api/lib-server/money#bankingprovider)

```ts title="Sygnatura"
GetBankingSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetBankingSystem() -- string lub nil
```

#### Parametry

Brak.

#### Zwraca

`string | null`: nazwa zasobu skryptu bankowego. `null`, gdy żaden nie działa (pieniądze prac zostają wtedy tylko w ai-core).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

addCommand("bankingsystem", { help: "Shows the banking script in use", restricted: true }, () => {
  console.log(core.GetBankingSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('bankingsystem', { help = 'Shows the banking script in use', restricted = true }, function()
  print(exports['ai-core']:GetBankingSystem() or 'none')
end)
```
</Tab>
</Tabs>

### OpenBank

Otwiera ekran skryptu bankowego dla gracza. Używaj tego z własnego bankomatu lub okienka bankowego.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`banking.open`](/pl/docs/developers/api/lib-server/money#bankingopen)

```ts title="Sygnatura"
OpenBank(source: number): boolean
```

```lua title="Lua"
local opened = exports['ai-core']:OpenBank(source)
```

#### Parametry

<TypeTable
  type={{
    source: { type: 'number', description: 'Id serwera gracza. Musi mieć wczytaną postać.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy ekran się otworzył. `false`, gdy gracz nie ma wczytanej postaci, nie działa żaden skrypt bankowy albo jego ekranu nie da się otworzyć z innego skryptu.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";

const core = resourceExport("ai-core");
const COUNTER = { x: 149.9, y: -1040.5, z: 29.4 };

onClientCallback("myscript:bankCounter", { guards: [near(COUNTER, 2)] }, (source) =>
  core.OpenBank(source) ? { ok: true } : fail("BANK_UNAVAILABLE"),
);
```
</Tab>
<Tab value="Lua">
```lua
local COUNTER = vector3(149.9, -1040.5, 29.4)

aiLib.onClientCallback('myscript:bankCounter', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - COUNTER) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:OpenBank(source) then return aiLib.fail('BANK_UNAVAILABLE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### GetBankSocietyBalance

Saldo firmy pracy tak, jak pokazuje je konfiguracja bankowa: konto `bank` pracy w ai-core przy **ai-core's accounts**, własne konto skryptu przy **The script's own accounts**. Używaj tego do wyświetlania (menu szefa); do przesuwania pieniędzy pracy używaj eksportów pieniędzy.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`banking.societyBalance`](/pl/docs/developers/api/lib-server/money#bankingsocietybalance)

```ts title="Sygnatura"
GetBankSocietyBalance(job: string): number | null
```

```lua title="Lua"
local balance = exports['ai-core']:GetBankSocietyBalance('police') -- number lub nil
```

#### Parametry

<TypeTable
  type={{
    job: { type: 'string', description: 'Nazwa pracy.', required: true },
  }}
/>

#### Zwraca

`number | null`: saldo. `null`, gdy nie działa żaden skrypt bankowy, praca nie ma konta (nieznana praca albo skrypt nie trzyma dla niej konta) albo `job` nie jest tekstem. Bez skryptu bankowego czytaj konto pracy przez `GetSharedMoney("job", job, "bank")`.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** The boss menu balance, with or without a banking script. */
export function societyBalance(job: string): number {
  return core.GetBankSocietyBalance(job) ?? core.GetSharedMoney("job", job, "bank") ?? 0;
}
```
</Tab>
<Tab value="Lua">
```lua
function SocietyBalance(job)
  return exports['ai-core']:GetBankSocietyBalance(job)
    or exports['ai-core']:GetSharedMoney('job', job, 'bank')
    or 0
end
```
</Tab>
</Tabs>
