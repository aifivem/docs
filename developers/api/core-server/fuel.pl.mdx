Paliwo przechodzi przez ai-core, nigdy przez własne eksporty, dekoratory lub state bagi skryptu paliwa (łącznie z ai-fuel). ai-core przekazuje każde wywołanie do **aktywnego skryptu paliwa**: tego, który wybiera ustawienie **Fuel script** w panelu, albo pierwszego działającego (ai-fuel, ox_fuel, LegacyFuel i inne z listy zgodności). Bez skryptu paliwa poziom to po prostu state bag `fuel` pojazdu.

Poziom to liczba od **0 (pusty) do 100 (pełny)**. Pojazd to **serwerowy uchwyt encji**.

### GetFuelSystem

Nazwa zasobu skryptu paliwa, do którego ai-core przekazuje wywołania.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`fuel.provider()`](/pl/docs/developers/api/lib-server/vehicles#fuelprovider)

```ts title="Sygnatura"
GetFuelSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetFuelSystem() -- 'ai-fuel', 'ox_fuel'... lub nil
```

#### Parametry

Brak.

#### Zwraca

`string | null`: nazwa zasobu skryptu paliwa. `null`, gdy żaden nie działa.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("fuelsystem", { help: "Shows the fuel script in use", restricted: true }, () => {
  console.log(core.GetFuelSystem() ?? "none: fuel is only the state bag");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('fuelsystem', { help = 'Shows the fuel script in use', restricted = true }, function()
  print(exports['ai-core']:GetFuelSystem() or 'none: fuel is only the state bag')
end)
```
</Tab>
</Tabs>

### GetVehicleFuel

Poziom paliwa pojazdu.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`fuel.get`](/pl/docs/developers/api/lib-server/vehicles#fuelget) (serwer); na kliencie `fuel.get(vehicle)` z klienckiego liba czyta state bag, który prowadzi ai-core

```ts title="Sygnatura"
GetVehicleFuel(vehicle: number): number | null
```

```lua title="Lua"
local level = exports['ai-core']:GetVehicleFuel(vehicle) -- 0-100 lub nil
```

#### Parametry

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Serwerowy uchwyt encji pojazdu.', required: true },
  }}
/>

#### Zwraca

`number | null`: poziom, 0-100. `null`, gdy pojazd nie ma jeszcze poziomu albo `vehicle` nie jest istniejącym pojazdem.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Mechanik odczytuje bak samochodu przed sobą.
onClientCallback("myscript:checkTank", { args: oneArg(readId) }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 4 });
  if (!vehicle) return fail("TOO_FAR");
  return { ok: true, level: core.GetVehicleFuel(vehicle) };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:checkTank', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 4 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  return { ok = true, level = exports['ai-core']:GetVehicleFuel(vehicle) }
end)
```
</Tab>
</Tabs>

### SetVehicleFuel

Ustawia poziom paliwa pojazdu.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`fuel.set`](/pl/docs/developers/api/lib-server/vehicles#fuelset) (a [`spawnVehicle({ fuel })`](/pl/docs/developers/api/lib-server/vehicles#spawnvehicle) ustawia go przy tworzeniu)

```ts title="Sygnatura"
SetVehicleFuel(vehicle: number, level: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetVehicleFuel(vehicle, 100.0)
```

#### Parametry

<TypeTable
  type={{
    vehicle: { type: 'number', description: 'Serwerowy uchwyt encji pojazdu.', required: true },
    level: { type: 'number', description: 'Nowy poziom. Wartości poniżej 0 stają się 0, powyżej 100 stają się 100.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy poziom został przekazany skryptowi paliwa (lub zapisany w state bagu, gdy żaden nie działa). `false`, gdy `vehicle` nie jest istniejącym pojazdem, `level` nie jest skończoną liczbą albo skrypt paliwa zawiódł.

Przy skryptach paliwa, które trzymają paliwo w grach graczy, nowy poziom dociera do pojazdu przez grę jego właściciela chwilę później.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, vehicleNearPlayer } from "@aifivem/lib/server";
import { fail, oneArg, readId } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Kanister dodaje 25% samochodowi obok gracza.
onClientCallback("myscript:jerryCan", { args: oneArg(readId), lock: true }, (source, netId) => {
  const vehicle = vehicleNearPlayer(source, netId, { metres: 3 });
  if (!vehicle) return fail("TOO_FAR");
  if (!core.RemoveItem(source, "jerrycan")) return fail("NO_JERRYCAN");
  core.SetVehicleFuel(vehicle, (core.GetVehicleFuel(vehicle) ?? 0) + 25);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:jerryCan', function(source, netId)
  local vehicle = aiLib.vehicleNearPlayer(source, netId, { metres = 3 })
  if vehicle == 0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:RemoveItem(source, 'jerrycan') then return aiLib.fail('NO_JERRYCAN') end
  local level = exports['ai-core']:GetVehicleFuel(vehicle) or 0
  exports['ai-core']:SetVehicleFuel(vehicle, level + 25)
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>
