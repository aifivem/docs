---
title: Pieniądze i konta
description: Odczytuj i zmieniaj salda gracza, konta prac i gangów, przesuwaj pieniądze między dwoma kontami w jednej transakcji, odczytuj typy kont.
icon: Wallet
---

Każda postać ma jedno saldo na **typ konta**. Typy pochodzą z listy Accounts w panelu administratora; nowy serwer ma `cash`, `bank`, `black_money` i `crypto`. Każda praca i każdy gang mają też jedno konto każdego typu (pieniądze firmy), które startuje puste.

Jak działają pieniądze w ai-core:

- Kwoty to **liczby całkowite** (dolary, bez centów). Ułamek, `NaN` albo liczba poza bezpiecznym zakresem liczb całkowitych JavaScriptu jest odrzucana.
- Zmiana działa od razu w pamięci i jest zapisywana do bazy danych w ciągu około 50 ms, razem z wierszem księgi (`ai_core_transactions`). Księga zapisuje `reason`, który podajesz; bez niego zapisuje nazwę zasobu, który wywołał.
- Saldo nie może zejść poniżej 0, chyba że jego typ konta ma w panelu włączone **Can go below zero**.
- Każda zmiana konta gracza wysyła serwerowe zdarzenie `ai-core:moneyChanged (src, account, balance, delta, reason)` i dociera do własnej gry gracza. Zobacz [Zdarzenia i stan](/pl/docs/developers/api/events).

### GetMoney

Saldo gracza na jednym koncie.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
GetMoney(src: number, account: string): number | null
```

```lua title="Lua"
local balance = exports['ai-core']:GetMoney(source, 'bank') -- number lub nil
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
    account: { type: 'string', description: 'Nazwa typu konta z panelu: `cash`, `bank`, `black_money`, `crypto` albo taka, którą dodałeś.', required: true },
  }}
/>

#### Zwraca

`number | null`: saldo. `null`, gdy gracz nie ma wczytanej postaci albo typ konta nie istnieje.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

onClientCallback("myscript:balance", (source) => {
  const bank = core.GetMoney(source, "bank");
  if (bank === null) return fail("NO_CHARACTER");
  return { ok: true, bank };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:balance', function(source)
  local bank = exports['ai-core']:GetMoney(source, 'bank')
  if not bank then return aiLib.fail('NO_CHARACTER') end
  return { ok = true, bank = bank }
end)
```
</Tab>
</Tabs>

### AddMoney

Dodaje pieniądze na konto gracza. Używaj tego dla nagród, pensji wypłacanych przez twój skrypt albo przychodu ze sprzedaży.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
AddMoney(src: number, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:AddMoney(source, 'cash', 250, 'fishing_sale')
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
    account: { type: 'string', description: 'Nazwa typu konta (`cash`, `bank`...).', required: true },
    amount: { type: 'number', description: 'Ile dodać. Liczba całkowita powyżej 0.', required: true },
    reason: { type: 'string', description: 'Krótki znacznik lub klucz językowy zapisany w księdze (`fishing_sale`).', default: 'nazwa wywołującego zasobu' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy pieniądze zostały dodane. `false`, gdy gracz nie ma wczytanej postaci, typ konta nie istnieje albo `amount` nie jest liczbą całkowitą powyżej 0.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, inventory, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const BUYER = { x: -1845.2, y: -1197.4, z: 14.3 };

onClientCallback("myscript:sellFish", { guards: [near(BUYER, 3)], lock: true }, (source) => {
  const fish = inventory.getItemCount(source, "fish");
  if (fish < 1) return fail("NO_FISH");
  if (!inventory.removeItem(source, "fish", fish)) return fail("SELL_FAILED");
  core.AddMoney(source, "cash", fish * 25, "fishing_sale");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local BUYER = vector3(-1845.2, -1197.4, 14.3)

aiLib.onClientCallback('myscript:sellFish', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - BUYER) > 3.0 then return aiLib.fail('TOO_FAR') end
  local fish = exports['ai-core']:GetItemCount(source, 'fish')
  if fish < 1 then return aiLib.fail('NO_FISH') end
  if not exports['ai-core']:RemoveItem(source, 'fish', fish) then return aiLib.fail('SELL_FAILED') end
  exports['ai-core']:AddMoney(source, 'cash', fish * 25, 'fishing_sale')
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="warn">
Aby przesunąć pieniądze z jednego konta na drugie (gracz płacący pracy, przelew bankowy), używaj `TransferMoney`, a nie pary `RemoveMoney` + `AddMoney`: przelew to jedna transakcja w bazie danych, para to dwie osobne zmiany.
</Callout>

### RemoveMoney

Zabiera pieniądze z konta gracza. Używaj tego, aby pobrać opłatę za coś.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
RemoveMoney(src: number, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local paid = exports['ai-core']:RemoveMoney(source, 'bank', 500, 'license_fee')
```

#### Parametry

<TypeTable
  type={{
    src: { type: 'number', description: 'Id serwera gracza.', required: true },
    account: { type: 'string', description: 'Nazwa typu konta (`cash`, `bank`...).', required: true },
    amount: { type: 'number', description: 'Ile zabrać. Liczba całkowita powyżej 0.', required: true },
    reason: { type: 'string', description: 'Krótki znacznik lub klucz językowy zapisany w księdze.', default: 'nazwa wywołującego zasobu' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy pieniądze zostały zabrane. `false`, gdy saldo jest za niskie (a typ konta nie pozwala na ujemne salda), gracz nie ma wczytanej postaci, typ konta nie istnieje albo `amount` nie jest liczbą całkowitą powyżej 0. Przy `false` nic się nie zmieniło.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, inventory, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const PRICE = 500;

onClientCallback("myscript:buyLicense", { lock: true }, (source) => {
  if (!inventory.canCarryItem(source, "driver_license")) return fail("NO_SPACE");
  if (!core.RemoveMoney(source, "bank", PRICE, "license_fee")) return fail("NOT_ENOUGH_MONEY");
  inventory.addItem(source, "driver_license");
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua

aiLib.onClientCallback('myscript:buyLicense', function(source)
  if not exports['ai-core']:CanCarryItem(source, 'driver_license') then return aiLib.fail('NO_SPACE') end
  if not exports['ai-core']:RemoveMoney(source, 'bank', PRICE, 'license_fee') then
    return aiLib.fail('NOT_ENOUGH_MONEY')
  end
  exports['ai-core']:AddItem(source, 'driver_license')
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Sprawdź to, co może zawieść, zanim zabierzesz pieniądze (miejsce w ekwipunku, zapas), albo oddaj pieniądze przez `AddMoney`, gdy następny krok zawiedzie.
</Callout>

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
SetMoney(src: number, account: string, amount: number, reason?: string): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetMoney(source, 'cash', 0, 'admin_reset')
```

#### Parametry

<TypeTable
  type={{

### GetSharedMoney

Saldo konta pracy lub gangu (pieniądze firmy).

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak ([`banking.societyBalance`](/pl/docs/developers/api/lib-server/money#bankingsocietybalance) pyta warstwę bankowości, która może zamiast tego czytać skrypt bankowy)

```ts title="Sygnatura"
GetSharedMoney(ownerType: "job" | "gang", ownerId: string, account: string): number | null
```

```lua title="Lua"
local balance = exports['ai-core']:GetSharedMoney('job', 'police', 'bank') -- number lub nil
```

#### Parametry

<TypeTable
  type={{
    ownerType: { type: '"job" | "gang"', description: 'Czyje to konto: pracy czy gangu.', required: true },
    ownerId: { type: 'string', description: 'Nazwa pracy lub gangu z panelu (`police`, `ballas`).', required: true },
    account: { type: 'string', description: 'Nazwa typu konta (`bank`, `cash`...).', required: true },
  }}
/>

#### Zwraca

`number | null`: saldo. `null`, gdy praca, gang lub typ konta nie istnieje (albo jego konta nie są jeszcze wczytane).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Menu szefa pokazuje pieniądze pracy; pytać mogą tylko członkowie pracy.
onClientCallback("myscript:societyBalance", (source) => {
  const job = online.dutyJob(source);
  if (!job) return fail("NOT_ON_DUTY");
  return { ok: true, balance: core.GetSharedMoney("job", job, "bank") ?? 0 };
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:societyBalance', function(source)
  local job = exports['ai-core']:GetDutyJob(source)
  if not job then return aiLib.fail('NOT_ON_DUTY') end
  return { ok = true, balance = exports['ai-core']:GetSharedMoney('job', job, 'bank') or 0 }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Gdy ustawienie panelu **Job and gang accounts** ma wartość **The script's own accounts**, konta `bank` pracy i gangu żyją w tym skrypcie: ten eksport czyta wtedy saldo skryptu. Zobacz [Bankowość](/pl/docs/developers/api/core-server/banking).
</Callout>

### TransferMoney

Przesuwa pieniądze z jednego konta na drugie w **jednej transakcji w bazie danych** z oboma wierszami księgi. Każda strona może być kontem wczytanego gracza albo kontem pracy lub gangu. Używaj tego przy każdej płatności między dwoma kontami: gracz płacący firmie, przelew bankowy, wpłata na konto firmy.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`money.transfer`](/pl/docs/developers/api/lib-server/money#moneytransfer)

```ts title="Sygnatura"
TransferMoney(from: MoneyRef, to: MoneyRef, amount: number, reason?: string, fee?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:TransferMoney(
  { source = source, account = 'bank' },
  { owner = 'job', id = 'mechanic', account = 'bank' },
  750, 'repair', 0)
```

#### Parametry

<TypeTable
  type={{
    from: { type: 'MoneyRef', description: 'Konto, które płaci. Płaci też `fee`.', required: true, typeDescription: '{ source: number; account: string } | { owner: "job" | "gang"; id: string; account: string }' },
    to: { type: 'MoneyRef', description: 'Konto, które otrzymuje `amount`.', required: true, typeDescription: '{ source: number; account: string } | { owner: "job" | "gang"; id: string; account: string }' },
    amount: { type: 'number', description: 'Ile otrzymuje `to`. Liczba całkowita powyżej 0.', required: true },
    reason: { type: 'string', description: 'Krótki znacznik lub klucz językowy zapisany w obu wierszach księgi.', default: 'nazwa wywołującego zasobu' },
    fee: { type: 'number', description: 'Dodatkowa kwota, którą płaci `from`, a której nikt nie otrzymuje (opłata bankowa). Liczba całkowita, 0 lub więcej.', default: '0' },
  }}
/>

`MoneyRef` to `{ source, account }` dla konta wczytanego gracza albo `{ owner, id, account }` dla konta pracy lub gangu. Zobacz [MoneyRef](/pl/docs/developers/api/types#moneyref).

#### Zwraca

`boolean`: `true`, gdy `from` zapłacił `amount + fee`, a `to` otrzymał `amount`. `false`, gdy brakuje konta (gracz niewczytany, nieznana praca, nieznany typ konta), obie strony to to samo konto, `from` nie może zapłacić `amount + fee`, `amount` nie jest liczbą całkowitą powyżej 0 albo `fee` nie jest liczbą całkowitą 0 lub większą. Przy `false` nic się nie zmieniło.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail, readInt } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Wpłata w bankomacie na konto własnego gangu gracza, z opłatą 2%.
onClientCallback(
  "myscript:gangDeposit",
  { args: ([amount]) => { const n = readInt(amount, 1, 1_000_000); return n === null ? null : [n]; }, lock: true },
  (source, amount) => {
    const gang = core.GetActiveGang(source);
    if (!gang) return fail("NO_GANG");
    const fee = Math.ceil(amount * 0.02);
    const ok = core.TransferMoney(
      { source, account: "bank" },
      { owner: "gang", id: gang, account: "bank" },
      amount, "gang_deposit", fee,
    );
    return ok ? { ok: true } : fail("NOT_ENOUGH_MONEY");
  },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:gangDeposit', function(source, amount)
  if math.type(amount) ~= 'integer' or amount < 1 or amount > 1000000 then return aiLib.fail('BAD_AMOUNT') end
  local gang = exports['ai-core']:GetActiveGang(source)
  if not gang then return aiLib.fail('NO_GANG') end
  local fee = math.ceil(amount * 0.02)
  local ok = exports['ai-core']:TransferMoney(
    { source = source, account = 'bank' },
    { owner = 'gang', id = gang, account = 'bank' },
    amount, 'gang_deposit', fee)
  if not ok then return aiLib.fail('NOT_ENOUGH_MONEY') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

<Callout type="info">
Obie strony wysyłają swoją zwykłą zmianę (strona gracza wysyła `ai-core:moneyChanged`). Dwaj gracze mogą być dwiema stronami: `{ source: a, account: "bank" }` do `{ source: b, account: "bank" }`.
</Callout>

### GetAccountTypes

Każdy typ konta z listy Accounts w panelu, z jego etykietą, kwotą startową i tym, czy może zejść poniżej zera. Używaj tego, aby zbudować menu kont albo sprawdzić nazwę.

**Strona:** Serwer · **Czeka:** nie · **Lib:** brak

```ts title="Sygnatura"
GetAccountTypes(): Record<string, AccountTypeDefinition>
```

```lua title="Lua"
local types = exports['ai-core']:GetAccountTypes() -- tabela z nazwą konta jako kluczem
```

#### Parametry

Brak.

#### Zwraca

`Record<string, AccountTypeDefinition>`: kopia z nazwą konta jako kluczem (`cash`, `bank`...). Każda wartość ma `label` (pokazywane graczom), `start` (co dostaje nowa postać) i `allowNegative`. Zobacz [AccountTypeDefinition](/pl/docs/developers/api/types#accounttypedefinition).

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Ekran portfela wyświetla każde konto z jego etykietą i saldem.
onClientCallback("myscript:wallet", (source) => {
  const rows = Object.entries(core.GetAccountTypes()).map(([name, type]) => ({
    name,
    label: type.label,
    balance: core.GetMoney(source, name) ?? 0,
```
