---
title: Внешность
description: Прочитать сохранённую внешность персонажа из того скрипта одежды, который использует сервер.
icon: Shirt
---

Внешность идёт через ai-core, а не через собственные экспорты, события или таблицы скрипта одежды (включая ai-appearance). ai-core читает её из **активного скрипта одежды**: того, что выбран в настройке панели **Clothing script**, или первого запущенного. Надевание внешности на педа происходит на клиенте (клиентский экспорт `ApplyAppearance`, в библиотеке `appearance.apply`); см. [Клиентские экспорты](/ru/docs/developers/api/core-client).

Внешность - это [CharacterAppearance](/ru/docs/developers/api/types#characterappearance): `{ model, data }`. `model` - хэш модели педа; `data` - собственный формат скрипта одежды. Считайте `data` запечатанной коробкой: передавайте её обратно в `ApplyAppearance` без изменений.

### GetAppearanceSystem

Имя ресурса скрипта одежды, из которого ai-core читает внешность.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`appearance.provider()`](/ru/docs/developers/api/lib-server/phone-appearance#appearanceprovider)

```ts title="Сигнатура"
GetAppearanceSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetAppearanceSystem() -- string или nil
```

#### Параметры

Нет.

#### Возвращает

`string | null`: имя ресурса скрипта одежды. `null`, когда ни один не работает (тогда педы носят одежду по умолчанию).

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("clothingsystem", { help: "Shows the clothing script in use", restricted: true }, () => {
  console.log(core.GetAppearanceSystem() ?? "none");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('clothingsystem', { help = 'Shows the clothing script in use', restricted = true }, function()
  print(exports['ai-core']:GetAppearanceSystem() or 'none')
end)
```
</Tab>
</Tabs>

### GetCharacterAppearance

Сохранённая внешность персонажа, загружен он или нет. Используйте, чтобы одеть педа как этого персонажа: спящее тело, статуя, фото, предпросмотр.

**Сторона:** сервер · **Ожидание:** нет (отвечает через `done`) · **Библиотека:** [`appearance.get(charId)`](/ru/docs/developers/api/lib-server/phone-appearance#appearanceget) возвращает Promise

```ts title="Сигнатура"
GetCharacterAppearance(charId: number, done: (look: CharacterAppearance | null) => void): void
```

```lua title="Lua"
exports['ai-core']:GetCharacterAppearance(charId, function(look) end) -- look: table или nil
```

#### Параметры

<TypeTable
  type={{
    charId: { type: 'number', description: 'Id персонажа в базе данных. Положительное целое число.', required: true },
    done: { type: '(look) => void', description: 'Вызывается один раз с внешностью, после того как скрипт одежды ответил.', required: true, typeDescription: '(look: CharacterAppearance | null) => void' },
  }}
/>

#### Возвращает

Ничего. `done` получает `{ model, data }` или `null`, когда у персонажа нет сохранённой внешности, не работает ни один скрипт одежды, `charId` не положительное целое число или скрипт одежды дал сбой (записывается в лог). Если `done` не функция, вызов ничего не делает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, online, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";
import type { CharacterAppearance } from "@aifivem/shared";

const core = resourceExport("ai-core");

// Клиент запрашивает собственную внешность игрока, чтобы одеть педа в фотобудке.
onClientCallback("myscript:myLook", async (source) => {
  const charId = online.charId(source);
  if (charId === undefined) return fail("NO_CHARACTER");
  const look = await new Promise<CharacterAppearance | null>((resolve) => core.GetCharacterAppearance(charId, resolve));
  return look ? { ok: true, look } : fail("NO_LOOK");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myLook', function(source)
  local character = exports['ai-core']:GetCharacter(source)
  if not character then return aiLib.fail('NO_CHARACTER') end
  local p = promise.new()
  exports['ai-core']:GetCharacterAppearance(character.id, function(look) p:resolve(look or false) end)
  local look = Citizen.Await(p)
  if not look then return aiLib.fail('NO_LOOK') end
  return { ok = true, look = look }
end)
```
</Tab>
</Tabs>

<Callout type="info">
Внешность может весить несколько килобайт. Отправляйте её одному игроку, которому она нужна, и никогда всем (`-1`).
</Callout>
