ai-core her script için tek bir admin paneli barındırır. Bu sayfadaki export’ların çoğu `@aicore-fivem/lib`’in senin yerine çağırdığı altyapıdır: lib’in `AdminPanel`’i ve `addCommand`’ı ile yapılmış bir script `RegisterAdminPanel`, `AdminPanelChanged` ya da `RegisterCommands`’ı asla kendisi çağırmaz. Ne olduğunu bilmen ve başka bir dilden destekleyebilmen için belgelenmiştir. `RegisterExternalPanel` ve `GetLookupValues` her script için işe yarar.

### RegisterAdminPanel

Çağıran resource’un bir panel bölümü olduğunu bildirir. Bundan sonra ai-core, bir admin paneli her açtığında ondan şemasını ve verisini ister.

**Taraf:** Server · **Bekler:** hayır · **Lib:** lib’in [`AdminPanel`](/tr/docs/developers/api/lib-server/admin-panel#adminpanel)’i başlarken çağırır

```ts title="İmza"
RegisterAdminPanel(resource: string): void
```

```lua title="Lua"
exports['ai-core']:RegisterAdminPanel(GetCurrentResourceName())
```

#### Parametreler

<TypeTable
  type={{
    resource: { type: 'string', description: 'Eski çağıranlar için tutulur ve yok sayılır: panel her zaman çağıran resource’a aittir.', required: true },
  }}
/>

#### Dönüş değeri

Hiçbir şey. Resource durduğunda kayıt silinir.

#### Örnek

Örnek yok: lib’in `AdminPanel`’i bunu çağırır. Lib olmadan kayıt yapan bir resource, ai-core’un geri çağırdığı export’ları da cevaplamalıdır (`AdminPanelSnapshot`, `AdminPanelData`, `AdminPanelSummary`, `@aicore-fivem/shared` içinde `AdminPanelResourceExports` olarak tiplenmiş); bu lib’in işidir.

### AdminPanelChanged

Bir panel resource’u ai-core’a kayıtlarından birinin değiştiğini söyler. ai-core değişikliği paneli açık olan her admin’e iletir, böylece ekranları yeniden yüklemeden güncellenir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** lib’in [`AdminPanel`](/tr/docs/developers/api/lib-server/admin-panel#adminpanel)’i kaydedilen her değişiklikten sonra çağırır

```ts title="İmza"
AdminPanelChanged(delta: AdminDelta): void
```

```lua title="Lua"
exports['ai-core']:AdminPanelChanged({ resource = GetCurrentResourceName(), file = 'shops', key = 'shop_1', value = record })
```

#### Parametreler

<TypeTable
  type={{
    delta: { type: 'AdminDelta', description: 'Ne değiştiği: `resource`, `file` (veri dosyasının adı), `key` (kayıt, tüm bir settings dosyası için bulunmaz) ve yeni `value` (silinmiş bir kayıt için `null`).', required: true, typeDescription: '{ resource: string; file: string; key?: string; value: unknown }' },
  }}
/>

Bkz. [AdminDelta](/tr/docs/developers/api/types#admindelta).

#### Dönüş değeri

Hiçbir şey. ai-core delta’yı kontrol etmez; verildiği gibi gönderir.

#### Örnek

Örnek yok: lib’in `AdminPanel`’i bunu bir değişiklik doğrulanıp kaydedildikten sonra çağırır.

### RegisterCommands

Bir resource’un komutlarını panelin **Commands** sekmesinde, yardım metinleri, parametreleri ve kimlerin kullanabileceğiyle listeler.

**Taraf:** Server · **Bekler:** hayır · **Lib:** lib’in [`addCommand`](/tr/docs/developers/api/lib-server/commands#addcommand)’ı çağırır (TypeScript ve Lua `aiLib.addCommand`)

```ts title="İmza"
RegisterCommands(resource: string, commands: CommandInfo[]): void
```

```lua title="Lua"
exports['ai-core']:RegisterCommands(GetCurrentResourceName(), commands)
```

#### Parametreler

<TypeTable
  type={{
    resource: { type: 'string', description: 'Eski çağıranlar için tutulur ve yok sayılır: komutlar çağıran resource’a aittir.', required: true },
    commands: { type: 'CommandInfo[]', description: 'Resource’un her komutu: `names` (ilki = ad, gerisi = takma adlar), `help`, `params` ve `aces` (`null` = herkes). Geçersiz kayıtlar konsolda bir uyarıyla atlanır.', required: true },
  }}
/>

Bkz. [CommandInfo](/tr/docs/developers/api/types#commandinfo) ve [CommandParam](/tr/docs/developers/api/types#commandparam).

#### Dönüş değeri

Hiçbir şey. Resource durduğunda liste silinir. Bir principal’a (`group.admin`) kısıtlı komutlar için ai-core o principal’a `command.<name>` da verir; bunun için `permission.cfg` içinde `add_ace resource.ai-core command.add_ace allow` (ve `command.remove_ace`) gerekir.

#### Örnek

Örnek yok: lib’in `addCommand`’ını (TypeScript) ya da `aiLib.addCommand`’ı (Lua) kullan, komut sekmede kendiliğinden görünür. Çıplak `RegisterCommand` ile yapılmış komutlar da listelenir, düz olarak işaretlenir.

### GetLookupValues

Tek bir lookup listesinin değerleri: aktif envanterin eşya adları, meslek adları, çete adları vb. Lib’in panel doğrulaması bir admin’in yazdığı değerin var olup olmadığını kontrol etmek için bunu kullanır.

**Taraf:** Server · **Bekler:** hayır · **Lib:** lib’in [`AdminPanel`](/tr/docs/developers/api/lib-server/admin-panel#adminpanel) doğrulaması kullanır

```ts title="İmza"
GetLookupValues(source: LookupSource): string[]
```

```lua title="Lua"
local items = exports['ai-core']:GetLookupValues('item') -- eşya adları listesi
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'LookupSource', description: 'Hangi liste.', required: true, typeDescription: '"item" | "job" | "gang" | "account" | "resource" | "player" | "vehicle" | "ped"' },
  }}
/>

| `source` | Değerler |
| --- | --- |
| `item` | Aktif envanterin eşya adları. |
| `job` / `gang` | Paneldeki meslek / çete adları. |
| `account` | Hesap tipi adları (`cash`, `bank`...). |
| `resource` | Başlatılmış resource’ların adları. |
| `player` | Yüklü karakteri olan oyuncuların citizen id’leri. |
| `vehicle` / `ped` | Her zaman boş: modelleri yalnızca admin’in oyunu listeleyebilir. |

Bkz. [LookupSource](/tr/docs/developers/api/types#lookupsource).

#### Dönüş değeri

`string[]`: değerler, etiketlerine göre sıralı. Bilinmeyen bir `source` için, `vehicle` ve `ped` için ve liste henüz bilinmiyorken (envanter çalışmıyor) boş liste: boşu "hiçbir şey geçerli değil" olarak değil, "kontrol edilemiyor" olarak ele al.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** Config’indeki bir ödül eşyasını kontrol eder; envanter çalışmıyorken bilinmemesi sorun değil. */
export function isKnownItem(name: string): boolean {
  const items = core.GetLookupValues("item");
  return items.length === 0 || items.includes(name);
}
```
</Tab>
<Tab value="Lua">
```lua
function IsKnownItem(name)
  local items = exports['ai-core']:GetLookupValues('item')
  if #items == 0 then return true end
  for _, item in ipairs(items) do
    if item == name then return true end
  end
  return false
end
```
</Tab>
</Tabs>

<Callout type="info">
Liste her çağrıda baştan kurulur (eşya listesi uzun olabilir). Döngüde değil, doğrularken çağır.
</Callout>

### RegisterExternalPanel

Başka bir script’in kendi ayar ekranını ai-core’un panel gösterge paneline ekler, böylece sunucu sahibi her script’in ayarlarını tek yerde bulur. Kart ekranı bir sohbet komutuyla açar ya da panelin içinde bir web sayfası gösterir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** yok

```ts title="İmza"
RegisterExternalPanel(panel: {
  id?: string;
  label: string;
  icon?: string;
  description?: string;
  command?: string;
  url?: string;
}): void
```

```lua title="Lua"
exports['ai-core']:RegisterExternalPanel({ label = 'My script', command = 'myscriptconfig' })
```

#### Parametreler

<TypeTable
  type={{
    panel: { type: 'object', description: 'Gösterge paneli kartı. Alanlar aşağıda.', required: true },
  }}
/>

#### Panel alanları

<TypeTable
  type={{
    id: { type: 'string', description: 'Kart id’si, resource’un içinde benzersiz (2-48 harf, rakam, `_`, `.`, `-`). Aynı id ile ikinci bir çağrı kartı değiştirir.', default: 'resource’un adı' },
    label: { type: 'string', description: 'Kart başlığı. 48 karaktere kesilir.', required: true },
    icon: { type: 'string', description: 'Kartın ikon adı. 32 karaktere kesilir.' },
    description: { type: 'string', description: 'Başlığın altında tek satır. 160 karaktere kesilir.' },
    command: { type: 'string', description: 'Ekranını açan sohbet komutu (baştaki `/` kaldırılır). `command` ya da `url` ver.' },
    url: { type: 'string', description: 'Panelin içinde gösterilen bir web sayfası. Yalnızca `https://` adresleri (resource’unun bir NUI sayfası ya da güvendiğin bir site); 300 karaktere kesilir.' },
  }}
/>

#### Dönüş değeri

Hiçbir şey. `label` olmadan ya da hem `command` hem `url` olmadan kart eklenmez. Resource’un durduğunda kartlar silinir.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Açılışta bir kez.
core.RegisterExternalPanel({
  label: "My script",
  icon: "gear",
  description: "Shops, prices and rewards",
  command: "myscriptconfig",
});
```
</Tab>
<Tab value="Lua">
```lua
exports['ai-core']:RegisterExternalPanel({
  label = 'My script',
  icon = 'gear',
  description = 'Shops, prices and rewards',
  command = 'myscriptconfig',
})
```
</Tab>
</Tabs>

<Callout type="info">
Değiştiremediğin bir script, bunun yerine kendi `fxmanifest.lua` dosyasındaki satırlarla listelenebilir: `ai_admin_label`, `ai_admin_command` ya da `ai_admin_url`, isteğe bağlı olarak `ai_admin_icon` ve `ai_admin_description`. Sunucu sahibi panelde elle de kart ekleyebilir.
</Callout>
