---
title: Phone
description: Phone numbers, mails, text messages and phone notifications through whichever phone script the server runs.
icon: Smartphone
---

Phone calls go through ai-core, never through a phone script's own exports. ai-core forwards each call to the **first phone script running** (tgiann-phone, lb-phone, gksphone and the others in the compatibility list). While no phone runs, every call answers `null` or `false`.

### GetPhoneNumber

A player's phone number.

**Side:** Server · **Waits:** no · **Lib:** [`phone.number`](/docs/developers/api/lib-server/phone-appearance#phonenumber)

```ts title="Signature"
GetPhoneNumber(source: number): string | null
```

```lua title="Lua"
local number = exports['ai-core']:GetPhoneNumber(source) -- string or nil
```

#### Parameters

<TypeTable
  type={{
    source: { type: 'number', description: 'Server id of the player.', required: true },
  }}
/>

#### Returns

`string | null`: the number as the phone script writes it. `null` when the player has none, no phone runs or `source` is not a number.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// A business card item shows the owner's number.
onClientCallback("myscript:myNumber", (source) => {
  const number = core.GetPhoneNumber(source);
  return number ? { ok: true, number } : fail("NO_PHONE_NUMBER");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myNumber', function(source)
  local number = exports['ai-core']:GetPhoneNumber(source)
  if not number then return aiLib.fail('NO_PHONE_NUMBER') end
  return { ok = true, number = number }
end)
```
</Tab>
</Tabs>

### GetSourceByPhone

The online player who has a phone number.

**Side:** Server · **Waits:** no · **Lib:** [`phone.sourceOf`](/docs/developers/api/lib-server/phone-appearance#phonesourceof)

```ts title="Signature"
GetSourceByPhone(number: string): number | null
```

```lua title="Lua"
local src = exports['ai-core']:GetSourceByPhone('5551234') -- number or nil
```

#### Parameters

<TypeTable
  type={{
    number: { type: 'string', description: 'The phone number, written the way the phone script writes it.', required: true },
  }}
/>

#### Returns

`number | null`: the server id. `null` when that number's owner is not online, the number is unknown, no phone runs or `number` is not a text.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { notify, resourceExport } from "@aifivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** A taxi job tells the caller their cab is on the way, if they are online. */
export function cabOnTheWay(callerNumber: string): void {
  const caller = core.GetSourceByPhone(callerNumber);
  if (caller !== null) notify(caller, Locale("NOTIFY_CAB_COMING"), "info");
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function CabOnTheWay(callerNumber)
  local caller = exports['ai-core']:GetSourceByPhone(callerNumber)
  if caller then aiLib.notify(caller, Locale('NOTIFY_CAB_COMING'), 'info') end
end
```
</Tab>
</Tabs>

### HasPhone

Whether a player has a phone (for phone scripts that need a phone item, whether they carry one).

**Side:** Server · **Waits:** no · **Lib:** [`phone.hasPhone`](/docs/developers/api/lib-server/phone-appearance#phonehasphone)

```ts title="Signature"
HasPhone(source: number): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasPhone(source)
```

#### Parameters

<TypeTable
  type={{
    source: { type: 'number', description: 'Server id of the player.', required: true },
  }}
/>

#### Returns

`boolean`: `true` when the phone script says the player has a phone. `false` when not, when no phone runs or `source` is not a number.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// A job that hands out tasks by text message needs a phone.
onClientCallback("myscript:startDeliveries", (source) =>
  core.HasPhone(source) ? { ok: true } : fail("NEED_PHONE"),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:startDeliveries', function(source)
  if not exports['ai-core']:HasPhone(source) then return aiLib.fail('NEED_PHONE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SendPhoneMail

Sends a mail to a player's phone.

**Side:** Server · **Waits:** no · **Lib:** [`phone.mail`](/docs/developers/api/lib-server/phone-appearance#phonemail)

```ts title="Signature"
SendPhoneMail(to: number | string, mail: PhoneMail): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMail(source, { sender = 'LS Customs', subject = 'Invoice', message = '...' })
```

#### Parameters

<TypeTable
  type={{
    to: { type: 'number | string', description: 'A player server id (their number is looked up) or a phone number / the phone mail address.', required: true },
    mail: { type: 'PhoneMail', description: 'The mail. Fields below.', required: true },
  }}
/>

#### PhoneMail

<TypeTable
  type={{
    sender: { type: 'string', description: 'Shown as the sender (a company, `Los Santos Customs`).', default: '""' },
    subject: { type: 'string', description: 'Subject line. Cut to 120 characters.', required: true },
    message: { type: 'string', description: 'The text. Cut to 4000 characters.', required: true },
  }}
/>

Texts are shown as given: pass translated texts. See [PhoneMail](/docs/developers/api/types#phonemail).

#### Returns

`boolean`: `true` when the phone script accepted the mail. `false` when the player has no number, `subject` or `message` is missing, no phone runs or it refused.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The heist contact mails the location after the job was accepted. */
export function mailHeistLocation(source: number, street: string): void {
  core.SendPhoneMail(source, {
    sender: Locale("MAIL_CONTACT"),
    subject: Locale("MAIL_HEIST_SUBJECT"),
    message: Locale("MAIL_HEIST_BODY", street),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function MailHeistLocation(source, street)
  exports['ai-core']:SendPhoneMail(source, {
    sender = Locale('MAIL_CONTACT'),
    subject = Locale('MAIL_HEIST_SUBJECT'),
    message = Locale('MAIL_HEIST_BODY', street),
  })
end
```
</Tab>
</Tabs>

### SendPhoneMessage

Sends a text message from one number to a player or number.

**Side:** Server · **Waits:** no · **Lib:** [`phone.message`](/docs/developers/api/lib-server/phone-appearance#phonemessage)

```ts title="Signature"
SendPhoneMessage(from: string, to: number | string, text: string): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMessage('Dispatch', source, 'Your cab is here.')
```

#### Parameters

<TypeTable
  type={{
    from: { type: 'string', description: 'The sender number or name, as the phone script accepts it.', required: true },
    to: { type: 'number | string', description: 'A player server id (their number is looked up) or a phone number.', required: true },
    text: { type: 'string', description: 'The message, already translated. Cut to 1000 characters.', required: true },
  }}
/>

#### Returns

`boolean`: `true` when the phone script accepted the message. `false` when the receiver has no number, `from` or `text` is not a text, no phone runs or it refused.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** The next delivery address arrives by text. */
export function textNextStop(source: number, street: string): void {
  if (!core.SendPhoneMessage(Locale("SENDER_DISPATCH"), source, Locale("TEXT_NEXT_STOP", street)))
    console.log(`player ${source} could not get the text`);
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TextNextStop(source, street)
  if not exports['ai-core']:SendPhoneMessage(Locale('SENDER_DISPATCH'), source, Locale('TEXT_NEXT_STOP', street)) then
    print(('player %d could not get the text'):format(source))
  end
end
```
</Tab>
</Tabs>

### PhoneNotify

Shows a notification on a player's phone.

**Side:** Server · **Waits:** no · **Lib:** [`phone.notify`](/docs/developers/api/lib-server/phone-appearance#phonenotify)

```ts title="Signature"
PhoneNotify(source: number, notification: PhoneNotification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:PhoneNotify(source, { title = 'Bank', message = 'Salary paid', app = 'bank' })
```

#### Parameters

<TypeTable
  type={{
    source: { type: 'number', description: 'Server id of the player.', required: true },
    notification: { type: 'PhoneNotification', description: 'What to show. Fields below.', required: true },
  }}
/>

#### PhoneNotification

<TypeTable
  type={{
    title: { type: 'string', description: 'Title line. Cut to 80 characters.', required: true },
    message: { type: 'string', description: 'The text. Cut to 500 characters.', default: '""' },
    app: { type: 'string', description: 'Phone app id it belongs to when the phone knows it (`messages`, `mail`, `bank`).' },
  }}
/>

See [PhoneNotification](/docs/developers/api/types#phonenotification).

#### Returns

`boolean`: `true` when the phone script showed it. `false` when `title` is missing, no phone runs, `source` is not a number or it refused.

#### Example

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Tells the owner their car was towed. */
export function towedNotice(source: number, plate: string): void {
  core.PhoneNotify(source, { title: Locale("PHONE_TOW_TITLE"), message: Locale("PHONE_TOW_TEXT", plate) });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TowedNotice(source, plate)
  exports['ai-core']:PhoneNotify(source, { title = Locale('PHONE_TOW_TITLE'), message = Locale('PHONE_TOW_TEXT', plate) })
end
```
</Tab>
</Tabs>
