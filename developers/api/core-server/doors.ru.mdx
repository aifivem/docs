---
title: Дверные замки
description: Запирать, отпирать и читать двери через тот скрипт дверных замков, который использует сервер.
icon: DoorClosed
---

Вызовы дверей идут через ai-core, а не через собственные экспорты или события скрипта замков (включая ai-doorlock). ai-core передаёт каждый вызов **активному скрипту замков**: тому, что выбран в настройке панели **Door lock script**, или первому запущенному (ai-doorlock, ox_doorlock, tgiann-doorlock и остальные из списка совместимости).

Дверь задаётся **собственным id двери этого скрипта**: id, который вы видите в его списке дверей (ai-doorlock: id двери в админ-панели; ox_doorlock: её номер в базе данных).

### GetDoorlockSystem

Имя ресурса скрипта дверных замков, которому ai-core передаёт вызовы.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`doors.provider()`](/ru/docs/developers/api/lib-server/world#doorsprovider)

```ts title="Сигнатура"
GetDoorlockSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetDoorlockSystem() -- string или nil
```

#### Параметры

Нет.

#### Возвращает

`string | null`: имя ресурса скрипта дверных замков. `null`, когда ни один не работает.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

// Id дверей в вашем конфиге принадлежат одному скрипту замков: предупредить, когда работает другой.
if (core.GetDoorlockSystem() !== "ai-doorlock")
  console.log("myscript: door ids are written for ai-doorlock");
```
</Tab>
<Tab value="Lua">
```lua
if exports['ai-core']:GetDoorlockSystem() ~= 'ai-doorlock' then
  print('myscript: door ids are written for ai-doorlock')
end
```
</Tab>
</Tabs>

### SetDoorLocked

Запирает или отпирает дверь.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`doors.setLocked`](/ru/docs/developers/api/lib-server/world#doorssetlocked)

```ts title="Сигнатура"
SetDoorLocked(id: string, locked: boolean, by?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetDoorLocked('pacific_vault', false, source)
```

#### Параметры

<TypeTable
  type={{
    id: { type: 'string', description: 'Id двери в скрипте замков. Целое число (id ox_doorlock) превращается в текст. Не более 128 символов.', required: true },
    locked: { type: 'boolean', description: '`true` запирает, `false` отпирает. Должно быть настоящим boolean.', required: true },
    by: { type: 'number', description: 'Серверный id игрока, который это делает. Скриптам замков без серверного API нужен игрок, чья игра передаст изменение; игнорируется, если этого игрока нет в сети.' },
  }}
/>

#### Возвращает

`boolean`: `true`, когда скрипт замков принял изменение. `false`, когда ни один скрипт замков не работает, дверь неизвестна, скрипт отказал, `id` пустой или `locked` не boolean.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, progressFor, resourceExport, near } from "@aicore-fivem/lib/server";
import { fail } from "@aicore-fivem/lib/shared";
import { Locale } from "common";

const core = resourceExport("ai-core");
const VAULT = { x: 253.9, y: 225.2, z: 101.9 };

onClientCallback("myscript:hackVault", { guards: [near(VAULT, 2)], lock: true }, async (source) => {
  if (!core.HasItem(source, "laptop")) return fail("NO_LAPTOP");
  if (!(await progressFor(source, { label: Locale("HACKING"), duration: 15000 }))) return fail("CANCELLED");
  return core.SetDoorLocked("pacific_vault", false, source) ? { ok: true } : fail("DOOR_FAILED");
});
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()
local VAULT = vector3(253.9, 225.2, 101.9)

aiLib.onClientCallback('myscript:hackVault', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - VAULT) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:HasItem(source, 'laptop') then return aiLib.fail('NO_LAPTOP') end
  if not aiLib.progressFor(source, { label = Locale('HACKING'), duration = 15000 }) then return aiLib.fail('CANCELLED') end
  if not exports['ai-core']:SetDoorLocked('pacific_vault', false, source) then return aiLib.fail('DOOR_FAILED') end
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>

### IsDoorLocked

Заперта ли дверь.

**Сторона:** сервер · **Ожидание:** нет · **Библиотека:** [`doors.isLocked`](/ru/docs/developers/api/lib-server/world#doorsislocked)

```ts title="Сигнатура"
IsDoorLocked(id: string): boolean | null
```

```lua title="Lua"
local locked = exports['ai-core']:IsDoorLocked('pacific_vault') -- true, false или nil
```

#### Параметры

<TypeTable
  type={{
    id: { type: 'string', description: 'Id двери в скрипте замков (целое число превращается в текст).', required: true },
  }}
/>

#### Возвращает

`boolean | null`: `true` заперта, `false` отперта. `null`, когда это неизвестно: ни один скрипт замков не работает, двери нет, скрипт не может определить это на сервере или `id` пустой.

#### Пример

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aicore-fivem/lib/server";

const core = resourceExport("ai-core");

/** The heist may start only while the vault is still closed. */
export function vaultClosed(): boolean {
  return core.IsDoorLocked("pacific_vault") !== false;
}
```
</Tab>
<Tab value="Lua">
```lua
function VaultClosed()
  return exports['ai-core']:IsDoorLocked('pacific_vault') ~= false
end
```
</Tab>
</Tabs>

<Callout type="info">
Решите, что `null` означает для вашей функции. Пример считает «неизвестно» закрытым, поэтому отсутствующий скрипт замков никогда не откроет ограбление раньше времени.
</Callout>
