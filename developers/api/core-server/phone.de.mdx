Handy-Aufrufe laufen über ai-core, nie über die eigenen Exports eines Handy-Skripts. ai-core leitet jeden Aufruf an das **erste laufende Handy-Skript** weiter (tgiann-phone, lb-phone, gksphone und die anderen aus der Kompatibilitätsliste). Solange kein Handy läuft, antwortet jeder Aufruf mit `null` oder `false`.

### GetPhoneNumber

Die Telefonnummer eines Spielers.

**Seite:** Server · **Wartet:** nein · **Lib:** [`phone.number`](/de/docs/developers/api/lib-server/phone-appearance#phonenumber)

```ts title="Signature"
GetPhoneNumber(source: number): string | null
```

```lua title="Lua"
local number = exports['ai-core']:GetPhoneNumber(source) -- String oder nil
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers.', required: true },
  }}
/>

#### Rückgabe

`string | null`: die Nummer, so wie das Handy-Skript sie schreibt. `null`, wenn der Spieler keine hat, kein Handy läuft oder `source` keine Zahl ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Ein Visitenkarten-Item zeigt die Nummer des Besitzers.
onClientCallback("myscript:myNumber", (source) => {
  const number = core.GetPhoneNumber(source);
  return number ? { ok: true, number } : fail("NO_PHONE_NUMBER");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:myNumber', function(source)
  local number = exports['ai-core']:GetPhoneNumber(source)
  if not number then return aiLib.fail('NO_PHONE_NUMBER') end
  return { ok = true, number = number }
end)
```
</Tab>
</Tabs>

### GetSourceByPhone

Der Online-Spieler, der eine Telefonnummer hat.

**Seite:** Server · **Wartet:** nein · **Lib:** [`phone.sourceOf`](/de/docs/developers/api/lib-server/phone-appearance#phonesourceof)

```ts title="Signature"
GetSourceByPhone(number: string): number | null
```

```lua title="Lua"
local src = exports['ai-core']:GetSourceByPhone('5551234') -- Zahl oder nil
```

#### Parameter

<TypeTable
  type={{
    number: { type: 'string', description: 'Die Telefonnummer, so geschrieben, wie das Handy-Skript sie schreibt.', required: true },
  }}
/>

#### Rückgabe

`number | null`: die Server-ID. `null`, wenn der Besitzer dieser Nummer nicht online ist, die Nummer unbekannt ist, kein Handy läuft oder `number` kein Text ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { notify, resourceExport } from "@aifivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Ein Taxi-Job teilt dem Anrufer mit, dass sein Taxi unterwegs ist, wenn er online ist. */
export function cabOnTheWay(callerNumber: string): void {
  const caller = core.GetSourceByPhone(callerNumber);
  if (caller !== null) notify(caller, Locale("NOTIFY_CAB_COMING"), "info");
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function CabOnTheWay(callerNumber)
  local caller = exports['ai-core']:GetSourceByPhone(callerNumber)
  if caller then aiLib.notify(caller, Locale('NOTIFY_CAB_COMING'), 'info') end
end
```
</Tab>
</Tabs>

### HasPhone

Ob ein Spieler ein Handy hat (bei Handy-Skripten, die ein Handy-Item brauchen: ob er eines trägt).

**Seite:** Server · **Wartet:** nein · **Lib:** [`phone.hasPhone`](/de/docs/developers/api/lib-server/phone-appearance#phonehasphone)

```ts title="Signature"
HasPhone(source: number): boolean
```

```lua title="Lua"
local has = exports['ai-core']:HasPhone(source)
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Handy-Skript sagt, dass der Spieler ein Handy hat. `false`, wenn nicht, wenn kein Handy läuft oder `source` keine Zahl ist.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Ein Job, der Aufträge per Textnachricht verteilt, braucht ein Handy.
onClientCallback("myscript:startDeliveries", (source) =>
  core.HasPhone(source) ? { ok: true } : fail("NEED_PHONE"),
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:startDeliveries', function(source)
  if not exports['ai-core']:HasPhone(source) then return aiLib.fail('NEED_PHONE') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SendPhoneMail

Sendet eine Mail an das Handy eines Spielers.

**Seite:** Server · **Wartet:** nein · **Lib:** [`phone.mail`](/de/docs/developers/api/lib-server/phone-appearance#phonemail)

```ts title="Signature"
SendPhoneMail(to: number | string, mail: PhoneMail): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMail(source, { sender = 'LS Customs', subject = 'Invoice', message = '...' })
```

#### Parameter

<TypeTable
  type={{
    to: { type: 'number | string', description: 'Die Server-ID eines Spielers (seine Nummer wird nachgeschlagen) oder eine Telefonnummer / die Mail-Adresse des Handys.', required: true },
    mail: { type: 'PhoneMail', description: 'Die Mail. Felder unten.', required: true },
  }}
/>

#### PhoneMail

<TypeTable
  type={{
    sender: { type: 'string', description: 'Wird als Absender angezeigt (eine Firma, `Los Santos Customs`).', default: '""' },
    subject: { type: 'string', description: 'Betreffzeile. Auf 120 Zeichen gekürzt.', required: true },
    message: { type: 'string', description: 'Der Text. Auf 4000 Zeichen gekürzt.', required: true },
  }}
/>

Texte werden so angezeigt, wie sie übergeben werden: Übergib übersetzte Texte. Siehe [PhoneMail](/de/docs/developers/api/types#phonemail).

#### Rückgabe

`boolean`: `true`, wenn das Handy-Skript die Mail angenommen hat. `false`, wenn der Spieler keine Nummer hat, `subject` oder `message` fehlt, kein Handy läuft oder es abgelehnt hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Der Überfall-Kontakt mailt den Ort, nachdem der Auftrag angenommen wurde. */
export function mailHeistLocation(source: number, street: string): void {
  core.SendPhoneMail(source, {
    sender: Locale("MAIL_CONTACT"),
    subject: Locale("MAIL_HEIST_SUBJECT"),
    message: Locale("MAIL_HEIST_BODY", street),
  });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function MailHeistLocation(source, street)
  exports['ai-core']:SendPhoneMail(source, {
    sender = Locale('MAIL_CONTACT'),
    subject = Locale('MAIL_HEIST_SUBJECT'),
    message = Locale('MAIL_HEIST_BODY', street),
  })
end
```
</Tab>
</Tabs>

### SendPhoneMessage

Sendet eine Textnachricht von einer Nummer an einen Spieler oder eine Nummer.

**Seite:** Server · **Wartet:** nein · **Lib:** [`phone.message`](/de/docs/developers/api/lib-server/phone-appearance#phonemessage)

```ts title="Signature"
SendPhoneMessage(from: string, to: number | string, text: string): boolean
```

```lua title="Lua"
local sent = exports['ai-core']:SendPhoneMessage('Dispatch', source, 'Your cab is here.')
```

#### Parameter

<TypeTable
  type={{
    from: { type: 'string', description: 'Die Nummer oder der Name des Absenders, so wie das Handy-Skript sie annimmt.', required: true },
    to: { type: 'number | string', description: 'Die Server-ID eines Spielers (seine Nummer wird nachgeschlagen) oder eine Telefonnummer.', required: true },
    text: { type: 'string', description: 'Die Nachricht, bereits übersetzt. Auf 1000 Zeichen gekürzt.', required: true },
  }}
/>

#### Rückgabe

`boolean`: `true`, wenn das Handy-Skript die Nachricht angenommen hat. `false`, wenn der Empfänger keine Nummer hat, `from` oder `text` kein Text ist, kein Handy läuft oder es abgelehnt hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Die nächste Lieferadresse kommt per Textnachricht. */
export function textNextStop(source: number, street: string): void {
  if (!core.SendPhoneMessage(Locale("SENDER_DISPATCH"), source, Locale("TEXT_NEXT_STOP", street)))
    console.log(`player ${source} could not get the text`);
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TextNextStop(source, street)
  if not exports['ai-core']:SendPhoneMessage(Locale('SENDER_DISPATCH'), source, Locale('TEXT_NEXT_STOP', street)) then
    print(('player %d could not get the text'):format(source))
  end
end
```
</Tab>
</Tabs>

### PhoneNotify

Zeigt eine Benachrichtigung auf dem Handy eines Spielers.

**Seite:** Server · **Wartet:** nein · **Lib:** [`phone.notify`](/de/docs/developers/api/lib-server/phone-appearance#phonenotify)

```ts title="Signature"
PhoneNotify(source: number, notification: PhoneNotification): boolean
```

```lua title="Lua"
local shown = exports['ai-core']:PhoneNotify(source, { title = 'Bank', message = 'Salary paid', app = 'bank' })
```

#### Parameter

<TypeTable
  type={{
    source: { type: 'number', description: 'Server-ID des Spielers.', required: true },
    notification: { type: 'PhoneNotification', description: 'Was angezeigt wird. Felder unten.', required: true },
  }}
/>

#### PhoneNotification

<TypeTable
  type={{
    title: { type: 'string', description: 'Titelzeile. Auf 80 Zeichen gekürzt.', required: true },
    message: { type: 'string', description: 'Der Text. Auf 500 Zeichen gekürzt.', default: '""' },
    app: { type: 'string', description: 'ID der Handy-App, zu der sie gehört, wenn das Handy sie kennt (`messages`, `mail`, `bank`).' },
  }}
/>

Siehe [PhoneNotification](/de/docs/developers/api/types#phonenotification).

#### Rückgabe

`boolean`: `true`, wenn das Handy-Skript sie angezeigt hat. `false`, wenn `title` fehlt, kein Handy läuft, `source` keine Zahl ist oder es abgelehnt hat.

#### Beispiel

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";
import { Locale } from "common";

const core = resourceExport("ai-core");

/** Teilt dem Besitzer mit, dass sein Auto abgeschleppt wurde. */
export function towedNotice(source: number, plate: string): void {
  core.PhoneNotify(source, { title: Locale("PHONE_TOW_TITLE"), message: Locale("PHONE_TOW_TEXT", plate) });
}
```
</Tab>
<Tab value="Lua">
```lua
local Locale = aiLib.locale()

function TowedNotice(source, plate)

end
```
</Tab>
