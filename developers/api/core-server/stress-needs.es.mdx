El estrés, el hambre y la sed viven en el script de HUD que los muestra. ai-core reenvía los cambios al **primer HUD en marcha que guarda estrés**: tgiann-lumihud, tgiann-hudv2, tgiann-modern-hud, qb-hud, ps-hud y después ai-hud. Nunca llames a los eventos o exports propios de un HUD (`hud:server:GainStress`, el `AddNeed` de ai-hud).

### GetStressSystem

El nombre de recurso del HUD al que ai-core da el estrés.

**Lado:** Servidor · **Espera:** no · **Lib:** [`stress.provider()`](/es/docs/developers/api/lib-server/jobs#stressprovider)

```ts title="Firma"
GetStressSystem(): string | null
```

```lua title="Lua"
local system = exports['ai-core']:GetStressSystem() -- string o nil
```

#### Parámetros

Ninguno.

#### Devuelve

`string | null`: el nombre de recurso del HUD. `null` cuando no hay ningún HUD con estrés en marcha (los cambios de estrés se descartan entonces).

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("stresssystem", { help: "Shows the HUD that keeps stress", restricted: true }, () => {
  console.log(core.GetStressSystem() ?? "none: stress is dropped");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('stresssystem', { help = 'Shows the HUD that keeps stress', restricted = true }, function()
  print(exports['ai-core']:GetStressSystem() or 'none: stress is dropped')
end)
```
</Tab>
</Tabs>

### AddStress

Añade estrés a un jugador, o lo alivia con una cantidad negativa.

**Lado:** Servidor · **Espera:** no · **Lib:** [`stress.gain(source, amount)`](/es/docs/developers/api/lib-server/jobs#stressgain) y [`stress.relieve(source, amount)`](/es/docs/developers/api/lib-server/jobs#stressrelieve) (ambos reciben una cantidad positiva)

```ts title="Firma"
AddStress(source: number, amount: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:AddStress(source, 5)    -- más estrés
local ok2 = exports['ai-core']:AddStress(source, -10) -- menos estrés
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador. Un número entero positivo.', required: true },
    amount: { type: 'number', description: 'Puntos de estrés en la escala 0-100 del HUD: positivo añade, negativo alivia. No 0, como mucho 100 en cualquier sentido.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el cambio se entregó al HUD. `false` cuando `source` o `amount` están fuera de rango, no hay ningún HUD con estrés en marcha o el HUD falló. El HUD limita el resultado a 0-100.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Robar una tienda estresa; fumarse un porro relaja.
export function robberyStarted(source: number): void {
  core.AddStress(source, 8);
}

core.RegisterUsableItem("joint", (source) => {
  core.AddStress(source, -15);
});
```
</Tab>
<Tab value="Lua">
```lua
function RobberyStarted(source)
  exports['ai-core']:AddStress(source, 8)
end

exports['ai-core']:RegisterUsableItem('joint', function(source)
  exports['ai-core']:AddStress(source, -15)
end)
```
</Tab>
</Tabs>

<Callout type="info">
El estrés por disparar y por conducir rápido es trabajo del propio HUD. Usa `AddStress` para los sucesos que conoce tu script.
</Callout>

### RefillNeeds

Llena del todo el hambre y la sed de un jugador a través del HUD que los guarda. Úsalo después de una reanimación o una estancia en el hospital.

**Lado:** Servidor · **Espera:** no · **Lib:** [`needs.refill`](/es/docs/developers/api/lib-server/jobs#needsrefill)

```ts title="Firma"
RefillNeeds(source: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:RefillNeeds(source)
```

#### Parámetros

<TypeTable
  type={{
    source: { type: 'number', description: 'Id de servidor del jugador. Debe tener un personaje cargado.', required: true },
  }}
/>

#### Devuelve

`boolean`: `true` cuando el relleno se entregó al HUD. Sin un HUD que guarde las necesidades, ai-core pone él mismo los metadatos `hunger` y `thirst` del personaje a 100 (y avisa a los HUD al estilo QB con `hud:client:UpdateNeeds`) y responde `true`. `false` cuando el jugador no tiene un personaje cargado o el HUD falló.

#### Ejemplo

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport, near } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");
const BED = { x: 317.8, y: -585.2, z: 43.3 };

// Una cama de hospital: reanimación, salud completa, estómago lleno.
onClientCallback("myscript:hospitalBed", { guards: [near(BED, 2)], lock: true }, (source) => {
  if (!core.RemoveMoney(source, "bank", 500, "hospital_bed")) return fail("NOT_ENOUGH_MONEY");
  if (!core.RevivePlayer(source)) core.HealPlayer(source);
  core.RefillNeeds(source);
  return { ok: true };
});
```
</Tab>
<Tab value="Lua">
```lua
local BED = vector3(317.8, -585.2, 43.3)

aiLib.onClientCallback('myscript:hospitalBed', function(source)
  if #(GetEntityCoords(GetPlayerPed(source)) - BED) > 2.0 then return aiLib.fail('TOO_FAR') end
  if not exports['ai-core']:RemoveMoney(source, 'bank', 500, 'hospital_bed') then return aiLib.fail('NOT_ENOUGH_MONEY') end
  if not exports['ai-core']:RevivePlayer(source) then exports['ai-core']:HealPlayer(source) end
  exports['ai-core']:RefillNeeds(source)
  return { ok = true }
end, { lock = true })
```
</Tab>
</Tabs>
