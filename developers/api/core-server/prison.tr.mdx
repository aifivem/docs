Hapis çağrıları ai-core üzerinden gider, asla bir hapishane script’inin kendi export’ları ya da event’leri üzerinden değil (ai-prison dahil). ai-core her çağrıyı **çalışan ilk hapishane script’ine** iletir: ai-prison, qb-prison, rcore_prison, xt-prison, sonra tgiann-policejob. Hiçbiri çalışmıyorken her çağrı `false` ya da `0` cevabı verir.

### JailPlayer

Bir oyuncuyu belli bir dakika boyunca hapse gönderir.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`prison.jail`](/tr/docs/developers/api/lib-server/jobs#prisonjail)

```ts title="İmza"
JailPlayer(source: number, minutes: number, by?: number): boolean
```

```lua title="Lua"
local jailed = exports['ai-core']:JailPlayer(target, 20, source)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Hapse atılacak oyuncunun server id’si.', required: true },
    minutes: { type: 'number', description: 'Dakika cinsinden ceza süresi. 0’ın üstünde.', required: true },
    by: { type: 'number', description: 'Memurun server id’si, bunu kimin yaptığını kaydeden hapishane script’leri için.', default: '0' },
  }}
/>

#### Dönüş değeri

`boolean`: hapishane script’i oyuncuyu aldığında `true`. `minutes` 0’ın üstünde değilse, `source` bir sayı değilse, hiçbir hapishane script’i çalışmıyorsa ya da reddettiyse `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("jail", {
  help: "Jails a player",
  params: [{ name: "id", type: "playerId" }, { name: "minutes", type: "number" }],
  restricted: "ai.job.police",
}, (source, args) => {
  if (core.GetDutyJob(source) !== "police") return;
  core.JailPlayer(args.id, args.minutes, source);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('jail', {
  help = 'Jails a player',
  params = { { name = 'id', type = 'playerId' }, { name = 'minutes', type = 'number' } },
  restricted = 'ai.job.police',
}, function(source, args)
  if exports['ai-core']:GetDutyJob(source) ~= 'police' then return end
  exports['ai-core']:JailPlayer(args.id, args.minutes, source)
end)
```
</Tab>
</Tabs>

<Callout type="info">
Sunucu bir MDT çalıştırıyorsa eşleşen MDT kaydını [`AddMdtRecord`](/tr/docs/developers/api/core-server/mdt) (`kind: "jail"`) ile yaz.
</Callout>

### ReleasePlayer

Bir oyuncuyu hapisten çıkarır.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`prison.release`](/tr/docs/developers/api/lib-server/jobs#prisonrelease)

```ts title="İmza"
ReleasePlayer(source: number): boolean
```

```lua title="Lua"
local released = exports['ai-core']:ReleasePlayer(target)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Mahkumun server id’si.', required: true },
  }}
/>

#### Dönüş değeri

`boolean`: hapishane script’i oyuncuyu serbest bıraktığında `true`. Hapishane script’i onu serbest bırakmadıysa (örneğin hapiste değildi), `source` bir sayı değilse ya da hiçbir hapishane script’i çalışmıyorsa `false`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

addCommand("unjail", { help: "Releases a player", params: [{ name: "id", type: "playerId" }], restricted: true }, (_source, args) => {
  console.log(core.ReleasePlayer(args.id) ? "released" : "not in prison");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('unjail', { help = 'Releases a player', params = { { name = 'id', type = 'playerId' } }, restricted = true }, function(_, args)
  print(exports['ai-core']:ReleasePlayer(args.id) and 'released' or 'not in prison')
end)
```
</Tab>
</Tabs>

### GetJailTime

Bir oyuncunun daha ne kadar yatması gerektiği.

**Taraf:** Server · **Bekler:** hayır · **Lib:** [`prison.timeLeft`](/tr/docs/developers/api/lib-server/jobs#prisontimeleft)

```ts title="İmza"
GetJailTime(source: number): number
```

```lua title="Lua"
local minutes = exports['ai-core']:GetJailTime(source)
```

#### Parametreler

<TypeTable
  type={{
    source: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
  }}
/>

#### Dönüş değeri

`number`: kalan dakika. Oyuncu hapiste değilse, `source` bir sayı değilse ya da hiçbir hapishane script’i çalışmıyorsa `0`.

#### Örnek

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Mahkumlar telefon kulübesini kullanamaz.
onClientCallback("myscript:phoneBooth", (source) =>
  core.GetJailTime(source) > 0 ? fail("IN_PRISON") : { ok: true },
);
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:phoneBooth', function(source)
  if exports['ai-core']:GetJailTime(source) > 0 then return aiLib.fail('IN_PRISON') end
  return { ok = true }
end)
```
</Tab>
</Tabs>
