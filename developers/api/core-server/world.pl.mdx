Czas i pogoda przechodzą przez ai-core, nigdy przez własne eksporty lub zdarzenia skryptu pogody. ai-core przekazuje każde wywołanie do **pierwszego działającego skryptu pogody**: Renewed-Weathersync, av_weather, cd_easytime, potem qb-weathersync (ai-weathersync odpowiada pod tą nazwą). Wszystkie trzymają się kontraktu qb-weathersync. Dopóki żaden nie działa, każde wywołanie odpowiada `null` lub `false`.

Aby wstrzymać synchronizację w grze jednego gracza (wnętrze z własnym światłem, przerywnik), użyj strony klienckiej (`PauseWorldSync`, `world.pauseSync` liba); zobacz [Eksporty klienckie](/pl/docs/developers/api/core-client).

### GetWeather

Bieżący typ pogody.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`world.getWeather`](/pl/docs/developers/api/lib-server/world#worldgetweather)

```ts title="Sygnatura"
GetWeather(): string | null
```

```lua title="Lua"
local weather = exports['ai-core']:GetWeather() -- 'EXTRASUNNY', 'RAIN'... lub nil
```

#### Parametry

Brak.

#### Zwraca

`string | null`: typ pogody wielkimi literami (`EXTRASUNNY`, `CLEAR`, `RAIN`, `THUNDER`...). `null`, gdy nie działa żaden skrypt pogody.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** Street races pay more in the rain. */
export function raceBonus(): number {
  const weather = core.GetWeather();
  return weather === "RAIN" || weather === "THUNDER" ? 1.25 : 1;
}
```
</Tab>
<Tab value="Lua">
```lua
function RaceBonus()
  local weather = exports['ai-core']:GetWeather()
  if weather == 'RAIN' or weather == 'THUNDER' then return 1.25 end
  return 1.0
end
```
</Tab>
</Tabs>

### SetWeather

Ustawia pogodę dla wszystkich.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`world.setWeather`](/pl/docs/developers/api/lib-server/world#worldsetweather) (przyjmuje typowane nazwy `Weather`)

```ts title="Sygnatura"
SetWeather(type: string): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetWeather('RAIN')
```

#### Parametry

<TypeTable
  type={{
    type: { type: 'string', description: 'Typ pogody z kontraktu qb-weathersync: `EXTRASUNNY`, `CLEAR`, `NEUTRAL`, `SMOG`, `FOGGY`, `OVERCAST`, `CLOUDS`, `CLEARING`, `RAIN`, `THUNDER`, `SNOW`, `BLIZZARD`, `SNOWLIGHT`, `XMAS`, `HALLOWEEN`. Zamieniany na wielkie litery przed wysłaniem.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt pogody go przyjął. `false`, gdy `type` nie jest tekstem, skrypt go odrzucił (nieznany typ) albo nie działa żaden skrypt pogody.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";
import { isWeather } from "@aifivem/shared";

const core = resourceExport("ai-core");

addCommand("weather", { help: "Sets the weather", params: [{ name: "type", type: "string" }], restricted: true }, (_source, args) => {
  const type = args.type.toUpperCase();
  if (!isWeather(type)) return console.log("unknown weather type");
  core.SetWeather(type);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('weather', { help = 'Sets the weather', params = { { name = 'type', type = 'string' } }, restricted = true }, function(_, args)
  if not exports['ai-core']:SetWeather(args.type) then print('weather refused') end
end)
```
</Tab>
</Tabs>

### GetTime

Czas gry (zegar w grze).

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`world.getTime`](/pl/docs/developers/api/lib-server/world#worldgettime)

```ts title="Sygnatura"
GetTime(): { hour: number; minute: number } | null
```

```lua title="Lua"
local time = exports['ai-core']:GetTime() -- { hour, minute } lub nil
```

#### Parametry

Brak.

#### Zwraca

`{ hour, minute } | null`: godzina 0-23 i minuta 0-59. `null`, gdy nie działa żaden skrypt pogody.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { onClientCallback, resourceExport } from "@aifivem/lib/server";
import { fail } from "@aifivem/lib/shared";

const core = resourceExport("ai-core");

// Diler sprzedaje tylko w nocy (22:00 - 05:59 czasu gry).
onClientCallback("myscript:dealer", (source) => {
  const time = core.GetTime();
  const night = time !== null && (time.hour >= 22 || time.hour < 6);
  return night ? { ok: true } : fail("COME_BACK_AT_NIGHT");
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.onClientCallback('myscript:dealer', function(source)
  local time = exports['ai-core']:GetTime()
  if not time or (time.hour < 22 and time.hour >= 6) then return aiLib.fail('COME_BACK_AT_NIGHT') end
  return { ok = true }
end)
```
</Tab>
</Tabs>

### SetTime

Ustawia czas gry dla wszystkich.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`world.setTime`](/pl/docs/developers/api/lib-server/world#worldsettime)

```ts title="Sygnatura"
SetTime(hour: number, minute?: number): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetTime(12, 0)
```

#### Parametry

<TypeTable
  type={{
    hour: { type: 'number', description: 'Godzina, 0-23. Zaokrąglana w dół i zawijana (24 staje się 0).', required: true },
    minute: { type: 'number', description: 'Minuta, 0-59. Zaokrąglana w dół i zawijana.', default: '0' },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt pogody go przyjął. `false`, gdy `hour` nie jest liczbą, skrypt odmówił albo nie działa żaden skrypt pogody.

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts

const core = resourceExport("ai-core");

addCommand("noon", { help: "Sets the time to 12:00", restricted: true }, () => {
  core.SetTime(12, 0);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('noon', { help = 'Sets the time to 12:00', restricted = true }, function()
  exports['ai-core']:SetTime(12, 0)
end)
```
</Tab>
</Tabs>

### SetBlackout

Włącza lub wyłącza blackout miasta (wszystkie sztuczne światła wyłączone).

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`world.setBlackout`](/pl/docs/developers/api/lib-server/world#worldsetblackout)

```ts title="Sygnatura"
SetBlackout(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:SetBlackout(true)
```

#### Parametry

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` włącza blackout. Wszystko inne niż `true` go wyłącza.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt pogody go przyjął. `false`, gdy skrypt nie ma blackoutu, odmówił albo nie działa żaden skrypt pogody.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

/** The power plant was sabotaged: 5 minutes of darkness. */
export function sabotagePowerPlant(): void {
  if (!core.SetBlackout(true)) return;
  setTimeout(() => core.SetBlackout(false), 5 * 60_000);
}
```
</Tab>
<Tab value="Lua">
```lua
function SabotagePowerPlant()
  if not exports['ai-core']:SetBlackout(true) then return end
  SetTimeout(5 * 60000, function() exports['ai-core']:SetBlackout(false) end)
end
```
</Tab>
</Tabs>

### FreezeTime

Zatrzymuje lub ponownie uruchamia zegar gry.

**Strona:** Serwer · **Czeka:** nie · **Lib:** [`world.freezeTime`](/pl/docs/developers/api/lib-server/world#worldfreezetime)

```ts title="Sygnatura"
FreezeTime(on: boolean): boolean
```

```lua title="Lua"
local ok = exports['ai-core']:FreezeTime(true)
```

#### Parametry

<TypeTable
  type={{
    on: { type: 'boolean', description: '`true` zamraża zegar. Wszystko inne niż `true` pozwala mu chodzić.', required: true },
  }}
/>

#### Zwraca

`boolean`: `true`, gdy skrypt pogody go przyjął. `false`, gdy skrypt nie umie zamrozić czasu, odmówił albo nie działa żaden skrypt pogody.

#### Przykład

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts
import { addCommand, resourceExport } from "@aifivem/lib/server";

const core = resourceExport("ai-core");

// Wieczór eventowy: zawsze 21:00.
addCommand("eventnight", { help: "Freezes the clock at 21:00", restricted: true }, () => {
  core.SetTime(21, 0);
  core.FreezeTime(true);
});
```
</Tab>
<Tab value="Lua">
```lua
aiLib.addCommand('eventnight', { help = 'Freezes the clock at 21:00', restricted = true }, function()
  exports['ai-core']:SetTime(21, 0)
  exports['ai-core']:FreezeTime(true)
end)
```
</Tab>
</Tabs>
