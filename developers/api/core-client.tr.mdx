`@aicore-fivem/shared` (`exports.ts`) içinde `AiCoreClientExports` olarak tiplidir.

```ts title="TypeScript"
import { resourceExport } from "@aicore-fivem/lib/client";
const core = resourceExport("ai-core");
```

Çoğunun kullanımı daha kolay bir lib yardımcısı var (son sütunda); Lua resource’larda aynı yardımcılar `aiLib` üzerinde.

## Oyuncu

| Export | Ne | Lib |
| --- | --- | --- |
| `GetPlayerData(): AiPlayerData \| null` | Yerel oyuncunun verisi: karakter, para, meslekler, mesai, meslek, çeteler, aktif çete, metadata. | `getPlayerData`, `onPlayerData` |
| `IsPlayerLoaded(): boolean` | Bir karakter yüklü mü. | |
| `IsDead(): boolean` | Yerel oyuncu, hangi ölüm script’i çalışıyorsa onda yerde. | `medical.isDead` |
| `GetDefinitions(file: "jobs" \| "gangs"): Record<string, unknown> \| null` | Panel dosyasındaki haliyle meslek ya da çete tanımları. | |

```lua title="Lua"
local data = exports['ai-core']:GetPlayerData()
if data and data.duty == 'police' then
  -- on duty
end
```

## HUD

| Export | Ne | Lib |
| --- | --- | --- |
| `HideHud(reason: string): void` | Herhangi bir sebep sürdükçe bütün HUD’ları gizler (duran bir resource’un sebepleri onunla gider). | `hud.hide` |
| `ShowHud(reason: string): void` | Bir sebebi kaldırır. | `hud.show` |
| `IsHudVisible(): boolean` | HUD’lar şu an görünüyor mu. | `hud.visible` |
| `OpenHudSettings(): boolean` | Çalışan HUD’un kendi ayarlarını açar; yoksa false. | |
| `HasHudSettings(): boolean` | Çalışan HUD’un ayarları var mı. | |

```ts title="TypeScript"
core.HideHud("photo-mode");
// ...
core.ShowHud("photo-mode");
```

```lua title="Lua"
exports['ai-core']:HideHud('photo-mode')
exports['ai-core']:ShowHud('photo-mode')
```

## Tuşlar ve tuş ipuçları

| Export | Ne | Lib |
| --- | --- | --- |
| `GetKeybindKey(name: string): string \| null` | Bir lib `Keybind`’ının kaydedildiği tuş; kaydedilene kadar null. | `Keybind.currentKey` |
| `ShowKeyHint(id: string, hint: KeyHintRequest): void` | Gizlenene kadar bir tuş ipucu gösterir (`label`, `keybind?`, `key?`, `icon?`). | `keyHints.show` |
| `HideKeyHint(id: string): void` | Gizler. | `keyHints.hide` |
| `GetKeyHints(): KeyHintView[]` | HUD’ların şu an gösterdiği ipuçları (`id`, `key`, `label`, `icon?`). | |
| `OpenKeyboard(): void` | Tuşlar ekranını açar: eylemi olan her tuş. | |

```lua title="Lua"
exports['ai-core']:ShowKeyHint('noclip_speed', { label = 'Speed', key = 'SHIFT', icon = 'gauge' })
```

## Radyal menü

Öğeler hangi radyal menü çalışıyorsa ona ulaşır; ekleyen resource durunca ai-core onları kaldırır.

| Export | Ne | Lib |
| --- | --- | --- |
| `AddRadialItem(item: RadialItem): void` | Bir öğe ekler ya da değiştirir (`id`, `label`, `icon?`, `parent?`, `items?`, `canShow?`, `onPressed?`, `keepOpen?`, `whileDead?`). | `radial.add` |
| `RemoveRadialItem(id: string): void` | Bir öğeyi kaldırır. | `radial.remove` |
| `RefreshRadial(): void` | Açık bir çarkın her `canShow`’unu yeniden okur. | `radial.refresh` |

```lua title="Lua"
exports['ai-core']:AddRadialItem({
  id = 'myscript_engine', label = 'Engine', icon = 'power-off', parent = 'vehicle',
  canShow = function() return IsPedInAnyVehicle(PlayerPedId(), false) end,
  onPressed = function() ExecuteCommand('engine') end,
})
```

## Görünüm

| Export | Ne | Lib |
| --- | --- | --- |
| `ApplyAppearance(ped: number, look: CharacterAppearance): boolean` | `GetCharacterAppearance`’tan gelen görünümü, aktif kıyafet script’iyle aynı modeldeki bir ped’e giydirir. | `appearance.apply` |
| `GetPedAppearance(ped: number): CharacterAppearance \| null` | Bir ped’in şu an giydiği görünüm. | `appearance.read` |

Menüler, giriş diyalogları, bildirimler, istemler, ilerleme çubuğu ve mini oyunlar ai-core’un değil ai-lib’in: bkz. [Script export’ları](/tr/docs/developers/api/scripts#ai-lib).
