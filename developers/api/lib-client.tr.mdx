```ts title="TypeScript"
import { Points, notify, progress, cache } from "@aicore-fivem/lib/client";
```

Client girişi `/fivem` yardımcılarını da yeniden dışa aktarır (`every`, `ByResource`, `Reasons`, `caller`, `onStop`, `plateOf`, export ve dil yardımcıları, state bag sınıfları): bkz. [Lib: shared ve fivem](/tr/docs/developers/api/lib-shared). Son sütun `aiLib` üzerindeki Lua karşılığını verir ([Lua için lib](/tr/docs/developers/api/lua)).

## Sunucuyla konuşmak

| Yardımcı | Ne | Lua |
| --- | --- | --- |
| `triggerServerCallback(name, args = [], timeoutMs?): Promise<unknown>` | Sunucuya sorar (orada `onClientCallback`); cevabı ayrıştır. | `triggerServerCallback` |
| `onServerCallback(name, handler: (...args) => unknown): void` | Sunucunun `triggerClientCallback`’ini cevaplar. | `onServerCallback` |
| `onServerEvent(name, handler)` / `onServerEvent(name, { args }, handler)` | Sunucudan bir net olayı; sunucudan gelmeyen emit’ler düşer. `args` payload’u ayrıştırır. | `onServerEvent` |
| `fromServer(): boolean` | İşlenen olay sunucudan mı geldi. | |
| `callAction(name, args = [], { fallback, timeout?, silent? })` | Bir sunucu eylemi çalıştırır, çevrilmiş reddi kendisi gösterir, ok cevabını ya da null döner. | `callAction` |
| `isActionOk(reply)`, `replyError(reply, fallback)` | Bir `ActionResult`’u elle okur. | |

```ts title="TypeScript"
const reply = await callAction("buy", [itemId], { fallback: "BUY_FAILED" });
if (reply) notify(t("BOUGHT"), "success");
```

## Yerler ve dünya

| Yardımcı | Ne | Lua |
| --- | --- | --- |
| `new Points()` | Oyuncunun kullandığı her yer: istem ya da hedef (sunucu sahibinin seçimi), NPC, blip. | `Points.new()` |
| `points.add(id, { coords, label, icon?, radius?, height?, canShow?, onPressed, onEnter?, onExit?, ped?, blip?, world?, promptOnly?, preferTarget? })` | Bir nokta ekler; `label` bir fonksiyon olabilir. | `points:add` |
| `points.addModel(id, { models, label, icon?, radius?, canShow?(entity), onPressed(entity), vehicles?, inVehicle? })` | Bazı modellerin her nesnesinde bir nokta (ATM’ler, sandalyeler). | `points:addModel` |
| `points.addVehicle(id, { label, icon?, radius?, canShow?(vehicle), onPressed(vehicle) })` | Her ağa bağlı araçta bir nokta. | `points:addVehicle` |
| `points.remove(id)`, `clear()`, `refresh(id?)`, `isInside(id)` | Noktaları yönetir; `refresh`, `canShow`’u yeniden okur. | |
| `new Zones()`: `add(id, options)`, `remove`, `clear`, `isInside`, `size` | Etkileşimsiz alanlar. | `Zones.new()` |
| `new LocalPed({ model, coords, ... })`: `entity`, `remove` | Sadece bu client’ın gördüğü, oyuncu yaklaşınca oluşan bir ped. | `LocalPed.new()` |
| `new Blips()`: `add(id, options)`, `get`, `remove`, `clear`; `createBlip(options)` | İsimli blip’ler. | `Blips.new()`, `Blips.create()` |
| `showPrompt(id, text, at?)`, `hidePrompt(id)`, `onPromptPressed(handler)` | ai-lib’in istemi, elle (`Points` bunu kullanır). | `showPrompt`, `hidePrompt`, `onPromptPressed` |
| `new AdminWorld(files)`: `get`, `onChange`, `view`, `records` | Bir script’in `sync: "all"` panel dosyalarının client kopyası. | |

```ts title="TypeScript"
const points = new Points();
points.add("shop", {
  coords: { x: 25.7, y: -1347.3, z: 29.5 },
  label: t("OPEN_SHOP"),
  icon: "basket-shopping",
  blip: { sprite: 52, color: 2, scale: 0.8, label: t("SHOP") },
  onPressed: () => openShop(),
});
```
