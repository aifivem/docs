```ts title="TypeScript"
import { Points, notify, progress, cache } from "@aicore-fivem/lib/client";
```

Der Client-Einstieg exportiert auch die `/fivem`-Helfer weiter (`every`, `ByResource`, `Reasons`, `caller`, `onStop`, `plateOf`, Export- und Locale-Helfer, State-Bag-Klassen): siehe [Lib: shared und fivem](/de/docs/developers/api/lib-shared). Die letzte Spalte nennt das Lua-Gegenstück auf `aiLib` ([Lib für Lua](/de/docs/developers/api/lua)).

## Mit dem Server sprechen

| Helfer | Was | Lua |
| --- | --- | --- |
| `triggerServerCallback(name, args = [], timeoutMs?): Promise<unknown>` | Fragt den Server (dort `onClientCallback`); parse die Antwort. | `triggerServerCallback` |
| `onServerCallback(name, handler: (...args) => unknown): void` | Beantwortet `triggerClientCallback` des Servers. | `onServerCallback` |
| `onServerEvent(name, handler)` / `onServerEvent(name, { args }, handler)` | Ein Net-Event vom Server; Emits, die nicht vom Server kommen, werden verworfen. `args` parst den Payload. | `onServerEvent` |
| `fromServer(): boolean` | Ob das gerade verarbeitete Event vom Server kam. | |
| `callAction(name, args = [], { fallback, timeout?, silent? })` | Führt eine Server-Aktion aus, zeigt die übersetzte Ablehnung selbst an, liefert die ok-Antwort oder null. | `callAction` |
| `isActionOk(reply)`, `replyError(reply, fallback)` | Ein `ActionResult` von Hand lesen. | |

```ts title="TypeScript"
const reply = await callAction("buy", [itemId], { fallback: "BUY_FAILED" });
if (reply) notify(t("BOUGHT"), "success");
```

## Der lokale Spieler

| Helfer | Was | Lua |
| --- | --- | --- |
| `cache` | `ped`, `playerId`, `serverId`, `vehicle`, `seat`, `weapon` (`false` = keins), gepflegt von dem einen Watcher von ai-core. | `cache` |
| `onCache(key, handler: (value, old) => void): void` | Läuft, wenn sich ein gecachter Wert ändert. | `cache.onChange` |
| `readPlayerState(ped)`, `readWeapon(ped)` | Fahrzeug, Sitz und Waffe eines Peds in diesem Moment. | |
| `player.coords()`, `player.heading()`, `player.distanceTo(point)`, `player.ped()` | Positionswerte (aus dem Cache). | `player` |
| `player.freeze(state: boolean)` | Friert den Ped ein. | `player.freeze` |
| `player.teleport(to: { x, y, z? }, { heading?, ground?, fade?, keepVehicle? }): Promise<void>` | Teleport hinter einer Abblende mit Laden der Kollision; ohne `z` landet man auf dem Boden. | `player.teleport` |
| `player.playAnim(dict, clip, options?): Promise<void>`, `player.stopAnim()` | Spielt oder stoppt eine Animation. | `player.playAnim`, `player.stopAnim` |
| `player.holdAnim(dict, clip, { ...options, while? })` | Hält eine Animation am Laufen, bis `stop()` oder `while()` false ist. | |
| `fadeOut(ms = 300)`, `fadeIn(ms = 400)` | Bildschirm abblenden; beide lösen auf, wenn fertig. | `fadeOut`, `fadeIn` |
| `getPlayerData(key)`, `onPlayerData(key, handler): () => void`, `seedPlayerData(data)` | Die Spielerdaten von ai-core (`character`, `money`, `jobs`, `duty`, `job`, `gangs`, `activeGang`, `metadata`). | `playerData.get`, `playerData.onChange` |
| `hasJob(jobs, minGrade = 0)`, `inGang(gangs, minGrade = 0)`, `onDutyIn(jobs)` | Mitgliedschaftsprüfungen (eine leere Liste = alle). | |
| `onMembershipChange(fn)` | Jobs, Dienst oder Gangs haben sich geändert. | |
| `allows(rule: AccessRule): boolean` | Ob der Spieler einen Ort nutzen darf (`online.allows` auf dem Server entscheidet dasselbe). | |
| `playerPed(serverId): number` | Der Ped eines Spielers nach Server-ID, 0 außerhalb des Scopes. | `playerPed` |
| `nearestPlayer(metres, { from?, filter? }): number \| null` | Die Server-ID des nächsten anderen Spielers. | `nearestPlayer` |

## Orte und die Welt

| Helfer | Was | Lua |
| --- | --- | --- |
| `new Points()` | Jeder Ort, den ein Spieler nutzt: Prompt oder Target (die Wahl des Betreibers), NPC, Blip. | `Points.new()` |
| `points.add(id, { coords, label, icon?, radius?, height?, canShow?, onPressed, onEnter?, onExit?, ped?, blip?, world?, promptOnly?, preferTarget? })` | Fügt einen Punkt hinzu; `label` darf eine Funktion sein. | `points:add` |
| `points.addModel(id, { models, label, icon?, radius?, canShow?(entity), onPressed(entity), vehicles?, inVehicle? })` | Ein Punkt auf jedem Objekt bestimmter Modelle (Geldautomaten, Stühle). | `points:addModel` |
| `points.addVehicle(id, { label, icon?, radius?, canShow?(vehicle), onPressed(vehicle) })` | Ein Punkt auf jedem vernetzten Fahrzeug. | `points:addVehicle` |
| `points.remove(id)`, `clear()`, `refresh(id?)`, `isInside(id)` | Punkte verwalten; `refresh` liest `canShow` erneut. | |
| `new Zones()`: `add(id, options)`, `remove`, `clear`, `isInside`, `size` | Bereiche ohne Interaktion. | `Zones.new()` |
| `new LocalPed({ model, coords, ... })`: `entity`, `remove` | Ein Ped, den nur dieser Client sieht, erzeugt in der Nähe des Spielers. | `LocalPed.new()` |
| `new Blips()`: `add(id, options)`, `get`, `remove`, `clear`; `createBlip(options)` | Benannte Blips. | `Blips.new()`, `Blips.create()` |
| `showPrompt(id, text, at?)`, `hidePrompt(id)`, `onPromptPressed(handler)` | Der Prompt von ai-lib von Hand (`Points` nutzt ihn). | `showPrompt`, `hidePrompt`, `onPromptPressed` |
| `new AdminWorld(files)`: `get`, `onChange`, `view`, `records` | Die Client-Kopie der `sync: "all"`-Panel-Dateien eines Skripts. | |

```ts title="TypeScript"
const points = new Points();
points.add("shop", {
  coords: { x: 25.7, y: -1347.3, z: 29.5 },
  label: t("OPEN_SHOP"),
  icon: "basket-shopping",
  blip: { sprite: 52, color: 2, scale: 0.8, label: t("SHOP") },
  onPressed: () => openShop(),
});
```

| `radial.add(item)`, `radial.remove(id)`, `radial.refresh()` | Einträge im laufenden Radialmenü. | `radial` |
| `controls.disable(reason, controls, group?)`, `controls.enable(reason)`, `controls.disableAll(reason, except?)` | Deaktivierte Steuerungen, ein Job pro Frame. | `controls` |
| `new Keybind({ name, description, defaultKey, defaultMapper, hint?, icon?, hintLabel?, onPressed, onReleased })` | Eine umbelegbare Taste; das Panel kann ihre Vorgabe setzen. `isPressed()`, `currentKey()`, `disable(state)`. | `Keybind.new()` |

```ts title="TypeScript"
const done = await progress({
  label: t("REPAIRING"),
  duration: 8000,
  anim: { dict: "mini@repair", clip: "fixing_a_player" },
  canCancel: true,
});
```
