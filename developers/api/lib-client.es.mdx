```ts title="TypeScript"
import { Points, notify, progress, cache } from "@aicore-fivem/lib/client";
```

La entrada de cliente también reexporta las utilidades de `/fivem` (`every`, `ByResource`, `Reasons`, `caller`, `onStop`, `plateOf`, las de exports y de idioma, las clases de state bags): ver [Lib: shared y fivem](/es/docs/developers/api/lib-shared). La última columna nombra la gemela en Lua de `aiLib` ([Lib para Lua](/es/docs/developers/api/lua)).

## Hablar con el servidor

| Utilidad | Qué | Lua |
| --- | --- | --- |
| `triggerServerCallback(name, args = [], timeoutMs?): Promise<unknown>` | Pregunta al servidor (allí `onClientCallback`); valida la respuesta. | `triggerServerCallback` |
| `onServerCallback(name, handler: (...args) => unknown): void` | Responde al `triggerClientCallback` del servidor. | `onServerCallback` |
| `onServerEvent(name, handler)` / `onServerEvent(name, { args }, handler)` | Un evento de red del servidor; los emits que no vienen del servidor se descartan. `args` valida los datos. | `onServerEvent` |
| `fromServer(): boolean` | Si el evento que se está manejando vino del servidor. | |
| `callAction(name, args = [], { fallback, timeout?, silent? })` | Ejecuta una acción del servidor, muestra por sí misma el rechazo traducido y resuelve la respuesta ok o null. | `callAction` |
| `isActionOk(reply)`, `replyError(reply, fallback)` | Leen un `ActionResult` a mano. | |

```ts title="TypeScript"
const reply = await callAction("buy", [itemId], { fallback: "BUY_FAILED" });
if (reply) notify(t("BOUGHT"), "success");
```

## El jugador local

| Utilidad | Qué | Lua |
| --- | --- | --- |
| `cache` | `ped`, `playerId`, `serverId`, `vehicle`, `seat`, `weapon` (`false` = ninguno), mantenidos por el único vigilante de ai-core. | `cache` |
| `onCache(key, handler: (value, old) => void): void` | Se ejecuta cuando cambia un valor en caché. | `cache.onChange` |
| `readPlayerState(ped)`, `readWeapon(ped)` | Vehículo, asiento y arma de un ped en este momento. | |
| `player.coords()`, `player.heading()`, `player.distanceTo(point)`, `player.ped()` | Lecturas de posición (desde la caché). | `player` |
| `player.freeze(state: boolean)` | Congela el ped. | `player.freeze` |
| `player.teleport(to: { x, y, z? }, { heading?, ground?, fade?, keepVehicle? }): Promise<void>` | Teletransporte tras un fundido con carga de colisiones; sin `z` cae al suelo. | `player.teleport` |
| `player.playAnim(dict, clip, options?): Promise<void>`, `player.stopAnim()` | Reproduce o detiene una animación. | `player.playAnim`, `player.stopAnim` |
| `player.holdAnim(dict, clip, { ...options, while? })` | Mantiene una animación hasta `stop()` o hasta que `while()` sea false. | |
| `fadeOut(ms = 300)`, `fadeIn(ms = 400)` | Fundidos de pantalla; cada uno resuelve al terminar. | `fadeOut`, `fadeIn` |
| `getPlayerData(key)`, `onPlayerData(key, handler): () => void`, `seedPlayerData(data)` | Los datos del jugador de ai-core (`character`, `money`, `jobs`, `duty`, `job`, `gangs`, `activeGang`, `metadata`). | `playerData.get`, `playerData.onChange` |
| `hasJob(jobs, minGrade = 0)`, `inGang(gangs, minGrade = 0)`, `onDutyIn(jobs)` | Comprobaciones de pertenencia (una lista vacía = todos). | |
| `onMembershipChange(fn)` | Cambiaron trabajos, servicio o bandas. | |
| `allows(rule: AccessRule): boolean` | Si el jugador puede usar un lugar (el `online.allows` del servidor decide lo mismo). | |
| `playerPed(serverId): number` | El ped de un jugador por id de servidor, 0 fuera de scope. | `playerPed` |
| `nearestPlayer(metres, { from?, filter? }): number \| null` | El id de servidor del otro jugador más cercano. | `nearestPlayer` |

## Lugares y el mundo

| Utilidad | Qué | Lua |
| --- | --- | --- |
| `new Points()` | Cada lugar que usa un jugador: prompt o target (lo elige el dueño), NPC, blip. | `Points.new()` |
| `points.add(id, { coords, label, icon?, radius?, height?, canShow?, onPressed, onEnter?, onExit?, ped?, blip?, world?, promptOnly?, preferTarget? })` | Añade un punto; `label` puede ser una función. | `points:add` |
| `points.addModel(id, { models, label, icon?, radius?, canShow?(entity), onPressed(entity), vehicles?, inVehicle? })` | Un punto en cada objeto de ciertos modelos (cajeros, sillas). | `points:addModel` |
| `points.addVehicle(id, { label, icon?, radius?, canShow?(vehicle), onPressed(vehicle) })` | Un punto en cada vehículo en red. | `points:addVehicle` |
| `points.remove(id)`, `clear()`, `refresh(id?)`, `isInside(id)` | Gestionan los puntos; `refresh` vuelve a leer `canShow`. | |
| `new Zones()`: `add(id, options)`, `remove`, `clear`, `isInside`, `size` | Áreas sin interacción. | `Zones.new()` |
| `new LocalPed({ model, coords, ... })`: `entity`, `remove` | Un ped que solo ve este cliente, creado cerca del jugador. | `LocalPed.new()` |
| `new Blips()`: `add(id, options)`, `get`, `remove`, `clear`; `createBlip(options)` | Blips con nombre. | `Blips.new()`, `Blips.create()` |
| `showPrompt(id, text, at?)`, `hidePrompt(id)`, `onPromptPressed(handler)` | El prompt de ai-lib a mano (`Points` lo usa). | `showPrompt`, `hidePrompt`, `onPromptPressed` |
| `new AdminWorld(files)`: `get`, `onChange`, `view`, `records` | La copia en el cliente de los archivos del panel `sync: "all"` de un script. | |

```ts title="TypeScript"
const points = new Points();
points.add("shop", {
  coords: { x: 25.7, y: -1347.3, z: 29.5 },
  label: t("OPEN_SHOP"),
  icon: "basket-shopping",
  blip: { sprite: 52, color: 2, scale: 0.8, label: t("SHOP") },
  onPressed: () => openShop(),
});
```

| `hud.hide(reason)`, `hud.show(reason)`, `hud.visible()`, `hud.onChange(fn)` | Ocultan los HUD alrededor de una interfaz a pantalla completa. | `hud` |
| `keyHints.show(id, { label, keybind?, key?, icon? })`, `keyHints.hide(id)` | Una línea de ayuda de teclas en el HUD. | `keyHints` |
| `radial.add(item)`, `radial.remove(id)`, `radial.refresh()` | Elementos en el menú radial que esté en marcha. | `radial` |
| `controls.disable(reason, controls, group?)`, `controls.enable(reason)`, `controls.disableAll(reason, except?)` | Controles desactivados, una sola tarea por frame. | `controls` |
| `new Keybind({ name, description, defaultKey, defaultMapper, hint?, icon?, hintLabel?, onPressed, onReleased })` | Una tecla reasignable; el panel puede fijar su valor por defecto. `isPressed()`, `currentKey()`, `disable(state)`. | `Keybind.new()` |

```ts title="TypeScript"
const done = await progress({
  label: t("REPAIRING"),
  duration: 8000,
  anim: { dict: "mini@repair", clip: "fixing_a_player" },
  canCancel: true,
});
```
