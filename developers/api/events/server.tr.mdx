ai-core bu event’leri server’da `TriggerEvent` ile tetikler (local: diğer server resource’ları duyar, client’lar asla duymaz). Lib’in `online` aynası ve ESX / QB / vRP köprüleri bunların üstüne kurulmuştur, bu yüzden oyuncuları izlemenin en ucuz yoludur: export çağrısı yok, yoklama yok.

Her event’in handler’ı ai-core değişikliğin ortasındayken **senkron** çalışır: handler’ları kısa tut ve içlerinde asla bekleme. Beklemen gerekiyorsa (bir veritabanı yazması) bloklamadan başlat.

### ai-core:playerLoaded

Bir oyuncunun karakteri yüklendi ve verisi client’ına gönderildi. Karakter yüklemesi başına bir kez tetiklenir, karakter değişiminden sonra da. Doğma seçimi açıkken oyuncu nerede görüneceğini seçmeden önce tetiklenir; seçimin ardından `ai-core:playerSpawned` gelir.

**Taraf:** Server · **Sabit:** `CORE.playerLoadedEvent`

#### Argümanlar

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    character: { type: 'CharacterInfo', description: 'Karakter: `id`, `citizenid`, `slot`, `firstname`, `lastname`, `birthdate`, `sex`, `nationality`.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#characterinfo' },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { CORE, type CharacterInfo } from "@aifivem/shared";

on(CORE.playerLoadedEvent, (src: number, character: CharacterInfo) => {
  console.log(`#${character.id} ${character.firstname} ${character.lastname} loaded (src ${src})`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
AddEventHandler('ai-core:playerLoaded', function(src, character)
  print(('#%d %s %s loaded (src %d)'):format(character.id, character.firstname, character.lastname, src))
end)
```
</Tab>
</Tabs>

<Callout type="info">
Resource’un başlamadan önce zaten yüklenmiş karakterler bunu senin için asla tetiklemez. Onları yeniden oynatan lib’in `onCharacter({ loaded })`’ını (Lua’da `aiLib.onCharacter`) kullan.
</Callout>

### ai-core:playerSpawned

Yüklü karakter dünyaya kondu. `ai-core:playerLoaded`’dan hemen sonra ya da sunucu seçmelerine izin veriyorsa oyuncu bir doğma noktası seçtikten sonra tetiklenir. Dünyada ped gerektiren şeyler için kullan (bir karşılama mesajı, bir ışınlanma).

**Taraf:** Server · **Sabit:** `CORE.playerSpawnedEvent`

#### Argümanlar

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    charId: { type: 'number', description: 'Doğan karakter id’si.', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>

</Tab>

### ai-core:playerUnloaded

Bir karakter bırakılıyor: oyuncu sunucudan ayrıldı ya da karakter ekranına döndü. ai-core karakteri bırakmadan **önce** tetiklenir, bu yüzden ai-core’un export’ları handler’ının içinde onun için hâlâ cevap verir. Oyuncu başına tuttuğun her şeyi burada temizle.

**Taraf:** Server · **Sabit:** `CORE.playerUnloadedEvent`

#### Argümanlar

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    charId: { type: 'number', description: 'Kaldırılan karakter id’si.', required: true },
    reason: { type: '"dropped" | "switch"', description: '`dropped`: oyuncu ayrıldı. `switch`: karakter ekranına döndü ve bağlı kalıyor.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#unloadreason' },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { CORE } from "@aifivem/shared";

const activeJobs = new Map<number, string>();

on(CORE.playerUnloadedEvent, (src: number, _charId: number, reason: "dropped" | "switch") => {
  activeJobs.delete(src);
  console.log(`${src} unloaded (${reason})`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
local activeJobs = {}

AddEventHandler('ai-core:playerUnloaded', function(src, charId, reason)
  activeJobs[src] = nil
  print(('%d unloaded (%s)'):format(src, reason))
end)
```
</Tab>
</Tabs>

<Callout type="info">
`reason = "switch"` ile aynı server id bir an sonra başka bir karakter yükleyebilir. Karakter başına verini `charId` ile anahtarla ya da burada temizle; bir server id’nin tek bir karakteri koruduğunu asla varsayma.
</Callout>

### ai-core:moneyChanged

Yüklü bir karakterin bir hesap bakiyesi değişti. Değişiklik uygulandıktan sonra, değişiklik başına bir kez, yalnızca bakiye gerçekten hareket ettiğinde tetiklenir.

**Taraf:** Server · **Sabit:** `CORE.moneyChangedEvent`

#### Argümanlar

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    account: { type: 'string', description: 'Hesap adı (`"cash"`, `"bank"` ya da panelin tanımladığı başka bir hesap).', required: true },
    balance: { type: 'number', description: 'Yeni bakiye.', required: true },
    delta: { type: 'number', description: 'Ne kadar değiştiği: giren para için pozitif, çıkan para için negatif.', required: true },
    reason: { type: 'string', description: 'Parayı hareket ettiren script’in verdiği sebep (para loguna yazılır).', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { CORE } from "@aifivem/shared";

// Büyük nakit ödemeleri yetkililer için işaretler.
on(CORE.moneyChangedEvent, (src: number, account: string, balance: number, delta: number, reason: string) => {
  if (account === "cash" && delta >= 100_000)
    console.log(`${src} got $${delta} cash (${reason}), now $${balance}`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
-- Büyük nakit ödemeleri yetkililer için işaretler.
AddEventHandler('ai-core:moneyChanged', function(src, account, balance, delta, reason)

    print(('%d got $%d cash (%s), now $%d'):format(src, delta, reason, balance))
  end
end)
```
</Tab>
</Tabs>

### ai-core:jobsChanged

Yüklü bir karakterin sahip olduğu meslekler listesi değişti: bir meslek eklendi ya da kaldırıldı veya bir rütbe değişti.

**Taraf:** Server · **Sabit:** `CORE.jobsChangedEvent`

#### Argümanlar

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    jobs: { type: 'JobMembership[]', description: 'Tam yeni liste: her meslek için `{ job, grade }`.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#jobmembership' },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { CORE, type JobMembership } from "@aifivem/shared";

on(CORE.jobsChangedEvent, (src: number, jobs: JobMembership[]) => {
  const police = jobs.find((m) => m.job === "police");
  console.log(police ? `${src} is police grade ${police.grade}` : `${src} is not police`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
AddEventHandler('ai-core:jobsChanged', function(src, jobs)
  for _, m in ipairs(jobs) do
    if m.job == 'police' then return print(('%d is police grade %d'):format(src, m.grade)) end
  end
  print(('%d is not police'):format(src))
end)
```
</Tab>
</Tabs>

### ai-core:itemUsed

Bir oyuncu bir eşya kullandı. Eşyanın verdiği ihtiyaçları (açlık, susuzluk, stres) taşır, böylece bir HUD ya da ihtiyaç script’i envanteri bilmeden onları uygular. ai-hud bunu dinler.

**Taraf:** Server · **Sabit:** `CORE.itemUsedEvent`

#### Argümanlar

<TypeTable
  type={{
    src: { type: 'number', description: 'Oyuncunun server id’si.', required: true },
    name: { type: 'string', description: 'Eşya adı (`"sandwich"`).', required: true },
    status: { type: 'Record<string, number> | null', description: 'Eşya tanımının ayarladığı haliyle, eşyanın ada göre verdiği ihtiyaçlar (`{ hunger: 25 }`). Eşya hiçbir şey vermiyorsa `null`.', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/needs.ts"
import { CORE } from "@aifivem/shared";

on(CORE.itemUsedEvent, (src: number, name: string, status: Record<string, number> | null) => {
  if (!status) return;
  for (const [need, amount] of Object.entries(status))
    console.log(`${src} used ${name}: ${need} ${amount > 0 ? "+" : ""}${amount}`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server/needs.lua"
AddEventHandler('ai-core:itemUsed', function(src, name, status)
  if not status then return end
  for need, amount in pairs(status) do
    print(('%d used %s: %s %s'):format(src, name, need, amount))
  end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Bugün eşya kullanımlarını ai-core’a yalnızca ai-inventory bildirir: başka bir envanterle bu event tetiklenmez. Bir envanterin kendi kullanım event’ini değil bu event’i dinle, böylece script’in envanter ai-inventory iken çalışır ve başkaları eklendiğinde de çalışmaya devam eder.
</Callout>

### ai-core:playerDied

Yüklü karakteri olan bir oyuncu öldü. ai-core bunu FXServer’ın kendi ped ölüm raporundan alır (FXServer 38039 ya da daha yeni), bu yüzden hiçbir client’a güvenilmez.

**Taraf:** Server · **Sabit:** `CORE.playerDiedEvent`

#### Argümanlar

<TypeTable
  type={{
    src: { type: 'number', description: 'Ölen oyuncunun server id’si.', required: true },
    killer: { type: 'number | null', description: 'Oyunun öldürmeyi ped’ine yazdığı oyuncunun server id’si; yüklü bir oyuncu değilse (bir NPC, bir düşme, oyuncusuz bir araba) `null`. `src`’nin kendisi olabilir.', required: true },
    weaponHash: { type: 'number', description: 'Oyunun bildirdiği silahın ya da sebebin hash’i.', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/killfeed.ts"
import { CORE } from "@aifivem/shared";

on(CORE.playerDiedEvent, (src: number, killer: number | null, weaponHash: number) => {
  if (killer !== null && killer !== src)
    console.log(`${GetPlayerName(String(killer))} killed ${GetPlayerName(String(src))} (weapon ${weaponHash})`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server/killfeed.lua"
AddEventHandler('ai-core:playerDied', function(src, killer, weaponHash)
  if killer and killer ~= src then
    print(('%s killed %s (weapon %d)'):format(GetPlayerName(killer), GetPlayerName(src), weaponHash))
  end
end)
```
</Tab>
</Tabs>

<Callout type="info">
Bu, ölüm script’inin "yerde" durumu değil, oyunun ölümüdür: bir ölüm script’i yerdeki bir oyuncuyu canlandırmak için canlı tutabilir. "Bu oyuncu yerde mi" için server lib’inin `medical`’ını ya da ai-core’un server sağlık export’larını kullan.
</Callout>

## Diğer ai-* script’lerinin event’leri

Bunları ai-core değil ai-* script’leri tetikler, ama birçok resource onları dinler. Tam başvuruları her script’in developer sayfasındadır.

### ai-vehicles:owners

Bellekteki sahipli araçların sahipleri değişti (bir karakter garajıyla yüklendi, bir araç satın alındı, satıldı ya da silindi). Server tick’i başına en fazla bir kez, o tick’in her değişikliğiyle tetiklenir. Anahtar script’leri her seferinde ai-vehicles’a sormadan plakadan sahibe bir harita tutmak için bunu kullanır.

**Taraf:** Server · **Sabit:** `VEHICLES_EVENTS.owners`

#### Argümanlar

<TypeTable
  type={{
    puts: { type: '[plate: string, ownerType: string, ownerId: string][]', description: 'Sahip tipiyle (`"character"`, `"job"`, `"gang"`, `"resource"`) ve sahip id’siyle eklenen ya da değişen plakalar.', required: true },
    removes: { type: 'string[]', description: 'Artık bellekte olmayan plakalar.', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/owners.ts"
import { resourceExport } from "@aifivem/lib/server";
import { VEHICLES_EVENTS } from "@aifivem/shared";

const owners = new Map<string, string>();

// Tam listeden başla, sonra değişiklikleri izle.
for (const [plate, type, id] of resourceExport("ai-vehicles").GetPlateOwners()) owners.set(plate, `${type}:${id}`);

on(VEHICLES_EVENTS.owners, (puts: Array<[string, string, string]>, removes: string[]) => {
  for (const [plate, type, id] of puts) owners.set(plate, `${type}:${id}`);
  for (const plate of removes) owners.delete(plate);
});
```
</Tab>
<Tab value="Lua">
```lua title="server/owners.lua"
local owners = {}

-- Tam listeden başla, sonra değişiklikleri izle.
for _, row in ipairs(exports['ai-vehicles']:GetPlateOwners()) do owners[row[1]] = row[2] .. ':' .. row[3] end

AddEventHandler('ai-vehicles:owners', function(puts, removes)
  for _, row in ipairs(puts) do owners[row[1]] = row[2] .. ':' .. row[3] end
  for _, plate in ipairs(removes) do owners[plate] = nil end
end)
```
</Tab>
</Tabs>

### chatMessage

ai-chat, bir oyuncunun mesajını iletmeden önce klasik FiveM `chatMessage` event’ini tetikler. Handler’ında `CancelEvent()` çağırmak mesajı atar.

**Taraf:** Server · **Sabit:** yok (FiveM’in kendi adı)

#### Argümanlar

<TypeTable
  type={{
    source: { type: 'number', description: 'Yazan oyuncunun server id’si.', required: true },
    author: { type: 'string', description: 'Sohbette gösterilen yazar adı.', required: true },
    text: { type: 'string', description: 'Mesaj metni.', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/filter.ts"
on("chatMessage", (source: number, _author: string, text: string) => {
  if (text.toLowerCase().includes("discord.gg")) {
    CancelEvent();
    console.log(`blocked an invite link from ${source}`);
  }
});
```
</Tab>
<Tab value="Lua">
```lua title="server/filter.lua"
AddEventHandler('chatMessage', function(source, author, text)
  if text:lower():find('discord.gg', 1, true) then
    CancelEvent()
    print(('blocked an invite link from %d'):format(source))
  end
end)
```
</Tab>
</Tabs>
