---
title: Eventos de servidor
description: Cada evento local de servidor que o ai-core dispara - personagens, dinheiro, empregos, serviço, gangues, metadata, definições, itens, mortes - com argumentos e listeners em TypeScript e Lua.
icon: Server
---

O ai-core dispara estes eventos no servidor com `TriggerEvent` (locais: outros recursos de servidor os ouvem, os clientes nunca). O espelho `online` da lib e as pontes ESX / QB / vRP são construídos sobre eles, então eles são o jeito mais barato de acompanhar os jogadores: nenhuma chamada de export, nenhuma consulta repetida.

O handler de cada evento roda de forma **síncrona** enquanto o ai-core está no meio da mudança: mantenha os handlers curtos e nunca espere dentro deles. Se precisar esperar (uma gravação no banco de dados), inicie-a sem bloquear.

### ai-core:playerLoaded

O personagem de um jogador foi carregado e os dados dele enviados ao cliente. Dispara uma vez por carregamento de personagem, também depois de uma troca de personagem. Com a escolha de spawn ligada, dispara antes de o jogador escolher onde aparecer; `ai-core:playerSpawned` vem depois da escolha.

**Lado:** Servidor · **Constante:** `CORE.playerLoadedEvent`

#### Argumentos

<TypeTable
  type={{
    src: { type: 'number', description: 'O id de servidor do jogador.', required: true },
    character: { type: 'CharacterInfo', description: 'O personagem: `id`, `citizenid`, `slot`, `firstname`, `lastname`, `birthdate`, `sex`, `nationality`.', required: true, typeDescriptionLink: '/docs/developers/api/types#characterinfo' },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { CORE, type CharacterInfo } from "@aicore-fivem/shared";

on(CORE.playerLoadedEvent, (src: number, character: CharacterInfo) => {
  console.log(`#${character.id} ${character.firstname} ${character.lastname} loaded (src ${src})`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
AddEventHandler('ai-core:playerLoaded', function(src, character)
  print(('#%d %s %s loaded (src %d)'):format(character.id, character.firstname, character.lastname, src))
end)
```
</Tab>
</Tabs>

<Callout type="info">
Os personagens já carregados antes de seu recurso iniciar nunca disparam isto para você. Use o `onCharacter({ loaded })` da lib (`aiLib.onCharacter` em Lua), que os repete.
</Callout>

### ai-core:playerSpawned

O personagem carregado foi colocado no mundo. Dispara logo depois de `ai-core:playerLoaded`, ou depois que o jogador escolheu um ponto de spawn quando o servidor deixa escolher. Use para coisas que precisam do ped no mundo (uma mensagem de boas-vindas, um teleporte).

**Lado:** Servidor · **Constante:** `CORE.playerSpawnedEvent`

#### Argumentos

<TypeTable
  type={{
    src: { type: 'number', description: 'O id de servidor do jogador.', required: true },
    charId: { type: 'number', description: 'O id do personagem que apareceu.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { notify } from "@aicore-fivem/lib/server";
import { CORE } from "@aicore-fivem/shared";
import { Locale } from "common";

on(CORE.playerSpawnedEvent, (src: number, _charId: number) => {
  notify(src, Locale("WELCOME_BACK"), "info");
});
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"

end)
```
</Tab>
</Tabs>

### ai-core:playerUnloaded

Um personagem está sendo liberado: o jogador saiu do servidor ou voltou para a tela de personagens. Dispara **antes** de o ai-core descartar o personagem, então os exports do ai-core ainda respondem por ele dentro do seu handler. Limpe aqui tudo o que você guarda por jogador.

**Lado:** Servidor · **Constante:** `CORE.playerUnloadedEvent`

#### Argumentos

<TypeTable
  type={{
    src: { type: 'number', description: 'O id de servidor do jogador.', required: true },
    charId: { type: 'number', description: 'O id do personagem que está sendo descarregado.', required: true },
    reason: { type: '"dropped" | "switch"', description: '`dropped`: o jogador saiu. `switch`: ele voltou para a tela de personagens e continua conectado.', required: true, typeDescriptionLink: '/docs/developers/api/types#unloadreason' },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { CORE } from "@aicore-fivem/shared";

const activeJobs = new Map<number, string>();

on(CORE.playerUnloadedEvent, (src: number, _charId: number, reason: "dropped" | "switch") => {
  activeJobs.delete(src);
  console.log(`${src} unloaded (${reason})`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
local activeJobs = {}

AddEventHandler('ai-core:playerUnloaded', function(src, charId, reason)
  activeJobs[src] = nil
  print(('%d unloaded (%s)'):format(src, reason))
end)
```
</Tab>
</Tabs>

<Callout type="info">
Com `reason = "switch"` o mesmo id de servidor pode carregar outro personagem um momento depois. Indexe seus dados por personagem pelo `charId` ou limpe-os aqui; nunca suponha que um id de servidor mantém um só personagem.
</Callout>

### ai-core:moneyChanged

O saldo de uma conta de um personagem carregado mudou. Dispara depois que a mudança é aplicada, uma vez por mudança, só quando o saldo realmente se moveu.

**Lado:** Servidor · **Constante:** `CORE.moneyChangedEvent`

#### Argumentos

<TypeTable
  type={{
    src: { type: 'number', description: 'O id de servidor do jogador.', required: true },
    account: { type: 'string', description: 'O nome da conta (`"cash"`, `"bank"` ou outra conta que o painel define).', required: true },
    balance: { type: 'number', description: 'O novo saldo.', required: true },
    delta: { type: 'number', description: 'Quanto mudou: positivo para dinheiro que entra, negativo para dinheiro que sai.', required: true },
    reason: { type: 'string', description: 'O motivo que o script que moveu o dinheiro informou (escrito no log de dinheiro).', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { CORE } from "@aicore-fivem/shared";

// Sinaliza pagamentos grandes em dinheiro vivo para a staff.
on(CORE.moneyChangedEvent, (src: number, account: string, balance: number, delta: number, reason: string) => {
  if (account === "cash" && delta >= 100_000)
    console.log(`${src} got $${delta} cash (${reason}), now $${balance}`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
-- Sinaliza pagamentos grandes em dinheiro vivo para a staff.
AddEventHandler('ai-core:moneyChanged', function(src, account, balance, delta, reason)
  if account == 'cash' and delta >= 100000 then
    print(('%d got $%d cash (%s), now $%d'):format(src, delta, reason, balance))
  end
end)
```
</Tab>
</Tabs>

### ai-core:jobsChanged

A lista de empregos que um personagem carregado tem mudou: um emprego adicionado ou removido, ou um cargo mudou.

**Lado:** Servidor · **Constante:** `CORE.jobsChangedEvent`

#### Argumentos

<TypeTable
  type={{
    src: { type: 'number', description: 'O id de servidor do jogador.', required: true },
    jobs: { type: 'JobMembership[]', description: 'A nova lista completa: `{ job, grade }` para cada emprego.', required: true, typeDescriptionLink: '/docs/developers/api/types#jobmembership' },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { CORE, type JobMembership } from "@aicore-fivem/shared";

on(CORE.jobsChangedEvent, (src: number, jobs: JobMembership[]) => {
  const police = jobs.find((m) => m.job === "police");
  console.log(police ? `${src} is police grade ${police.grade}` : `${src} is not police`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
AddEventHandler('ai-core:jobsChanged', function(src, jobs)
  for _, m in ipairs(jobs) do
    if m.job == 'police' then return print(('%d is police grade %d'):format(src, m.grade)) end
  end
  print(('%d is not police'):format(src))
end)
```
</Tab>
</Tabs>

### ai-core:itemUsed

Um jogador usou um item. Traz as necessidades que o item dá (fome, sede, estresse), para que um HUD ou script de necessidades as aplique sem conhecer o inventário. O ai-hud o escuta.

**Lado:** Servidor · **Constante:** `CORE.itemUsedEvent`

#### Argumentos

<TypeTable
  type={{
    src: { type: 'number', description: 'O id de servidor do jogador.', required: true },
    name: { type: 'string', description: 'O nome do item (`"sandwich"`).', required: true },
    status: { type: 'Record<string, number> | null', description: 'As necessidades que o item dá, por nome (`{ hunger: 25 }`), como a definição do item as define. `null` quando o item não dá nenhuma.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/needs.ts"
import { CORE } from "@aicore-fivem/shared";

on(CORE.itemUsedEvent, (src: number, name: string, status: Record<string, number> | null) => {
  if (!status) return;
  for (const [need, amount] of Object.entries(status))
    console.log(`${src} used ${name}: ${need} ${amount > 0 ? "+" : ""}${amount}`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server/needs.lua"
AddEventHandler('ai-core:itemUsed', function(src, name, status)
  if not status then return end
  for need, amount in pairs(status) do
    print(('%d used %s: %s %s'):format(src, name, need, amount))
  end
end)
```
</Tab>
</Tabs>

<Callout type="warn">
Hoje só o ai-inventory informa usos de itens ao ai-core: com outro inventário este evento não dispara. Escute este evento, não o evento de uso próprio de um inventário, para que seu script funcione quando o ai-inventory é o inventário e continue funcionando quando outros forem adicionados.
</Callout>

### ai-core:playerDied

Um jogador com um personagem carregado morreu. O ai-core pega isto do próprio relatório de morte de ped do FXServer (FXServer 38039 ou mais novo), então nenhum cliente é considerado confiável.

**Lado:** Servidor · **Constante:** `CORE.playerDiedEvent`

#### Argumentos

<TypeTable
  type={{
    src: { type: 'number', description: 'O id de servidor do jogador que morreu.', required: true },
    killer: { type: 'number | null', description: 'O id de servidor do jogador a cujo ped o jogo credita a morte, `null` quando não era um jogador carregado (um NPC, uma queda, um carro sem jogador). Pode ser o próprio `src`.', required: true },
    weaponHash: { type: 'number', description: 'O hash da arma ou da causa que o jogo informa.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/killfeed.ts"
import { CORE } from "@aicore-fivem/shared";

on(CORE.playerDiedEvent, (src: number, killer: number | null, weaponHash: number) => {
  if (killer !== null && killer !== src)
    console.log(`${GetPlayerName(String(killer))} killed ${GetPlayerName(String(src))} (weapon ${weaponHash})`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server/killfeed.lua"
AddEventHandler('ai-core:playerDied', function(src, killer, weaponHash)
  if killer and killer ~= src then
    print(('%s killed %s (weapon %d)'):format(GetPlayerName(killer), GetPlayerName(src), weaponHash))
  end
end)
```
</Tab>
</Tabs>

<Callout type="info">
Esta é a morte do jogo, não o estado de "caído" do script de morte: um script de morte pode manter vivo um jogador caído para animá-lo. Para "este jogador está caído", use o `medical` da lib de servidor ou os exports médicos de servidor do ai-core.
</Callout>

## Eventos de outros scripts ai-*

Estes são disparados por scripts ai-*, não pelo ai-core, mas muitos recursos os escutam. A referência completa deles está na página de desenvolvedor de cada script.

### ai-vehicles:owners

Os donos dos veículos próprios em memória mudaram (um personagem carregou com a garagem dele, um veículo foi comprado, vendido ou apagado). Dispara no máximo uma vez por tick do servidor com cada mudança desse tick. Scripts de chaves o usam para manter um mapa de placa para dono sem perguntar ao ai-vehicles toda vez.

**Lado:** Servidor · **Constante:** `VEHICLES_EVENTS.owners`

#### Argumentos

<TypeTable
  type={{
    puts: { type: '[plate: string, ownerType: string, ownerId: string][]', description: 'Placas adicionadas ou alteradas, com o tipo de dono (`"character"`, `"job"`, `"gang"`, `"resource"`) e o id do dono.', required: true },
    removes: { type: 'string[]', description: 'Placas que não estão mais em memória.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/owners.ts"
import { resourceExport } from "@aicore-fivem/lib/server";
import { VEHICLES_EVENTS } from "@aicore-fivem/shared";

const owners = new Map<string, string>();

// Comece pela lista completa, depois siga as mudanças.
for (const [plate, type, id] of resourceExport("ai-vehicles").GetPlateOwners()) owners.set(plate, `${type}:${id}`);

on(VEHICLES_EVENTS.owners, (puts: Array<[string, string, string]>, removes: string[]) => {
  for (const [plate, type, id] of puts) owners.set(plate, `${type}:${id}`);
  for (const plate of removes) owners.delete(plate);
});
```
</Tab>
<Tab value="Lua">
```lua title="server/owners.lua"
local owners = {}

-- Comece pela lista completa, depois siga as mudanças.
for _, row in ipairs(exports['ai-vehicles']:GetPlateOwners()) do owners[row[1]] = row[2] .. ':' .. row[3] end

AddEventHandler('ai-vehicles:owners', function(puts, removes)
  for _, row in ipairs(puts) do owners[row[1]] = row[2] .. ':' .. row[3] end
  for _, plate in ipairs(removes) do owners[plate] = nil end
end)
```
</Tab>

### chatMessage

O ai-chat dispara o clássico evento `chatMessage` do FiveM antes de entregar a mensagem de um jogador. Chamar `CancelEvent()` no seu handler descarta a mensagem.

**Lado:** Servidor · **Constante:** nenhuma (o nome próprio do FiveM)

#### Argumentos

<TypeTable
  type={{
    source: { type: 'number', description: 'O id de servidor do jogador que a escreveu.', required: true },
    author: { type: 'string', description: 'O nome do autor mostrado no chat.', required: true },
    text: { type: 'string', description: 'O texto da mensagem.', required: true },
  }}
/>

on("chatMessage", (source: number, _author: string, text: string) => {
  if (text.toLowerCase().includes("discord.gg")) {
    CancelEvent();

  }
});

AddEventHandler('chatMessage', function(source, author, text)

end)
