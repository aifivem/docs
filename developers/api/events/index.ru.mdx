ai-core сообщает другим скриптам, когда что-то меняется: загрузился персонаж, переместились деньги, сменилась работа, игрок упал, HUD скрылся. Ваш скрипт **слушает**, а не спрашивает снова и снова. В этом разделе перечислены все события и общие значения состояния, которые используют другие ресурсы.

## Три вида

| Вид | Что это | Как слушать |
| --- | --- | --- |
| **Локальное событие** | Отправляется на одной стороне (сервер или один клиент) для всех ресурсов на этой стороне. Никогда не пересекает сеть. Большинство событий ai-core локальные. | TS: `on(name, handler)`. Lua: `AddEventHandler(name, handler)`. |
| **Сетевое событие** | Отправляется с сервера на клиент одного игрока (или наоборот). | TS-клиент: `onServerEvent(name, ...)` из библиотеки. Lua-клиент: `aiLib.onServerEvent(name, handler)`. |
| **State bag** | Значение, хранящееся в GlobalState, у игрока или у сущности. Читать его могут все; записывает только ресурс-владелец. | `GlobalKey`, `PlayerState`, `EntityState`, `GlobalGroup` из библиотеки или `GlobalState[...]`, `Player(src).state[...]`, `Entity(e).state[...]` в Lua. |

## Имена берутся из констант

В TypeScript никогда не набирайте имя события вручную. Это константы в `@aifivem/shared`:

| Константа | События |
| --- | --- |
| `CORE` | Серверные и клиентские события ai-core (`CORE.playerLoadedEvent`, `CORE.clientDeadEvent`...) и ключи GlobalState (`CORE.pvpStateKey`...). |
| `KEY_HINTS` | `KEY_HINTS.changedEvent`. |
| `MENU_EVENTS`, `LIB_UI` | Ответы интерфейса ai-lib. |
| `VEHICLES_EVENTS` | Поток владельцев ai-vehicles. |
| `VRP` | `VRP.configEvent`. |
| `PLAYER_BAGS`, `VEHICLE_BAGS`, `INVENTORY_STATE_KEY`, `APPEARANCE_STATE_KEY`, `dutyCountKey(job)`... | Ключи state bag. |

В Lua констант нет: используйте строку, указанную рядом с каждым событием.

## Первый обработчик

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/server/index.ts"
import { CORE, type CharacterInfo } from "@aifivem/shared";

on(CORE.playerLoadedEvent, (src: number, character: CharacterInfo) => {
  console.log(`${character.firstname} ${character.lastname} joined as ${src}`);
});
```
</Tab>
<Tab value="Lua">
```lua title="server.lua"
AddEventHandler('ai-core:playerLoaded', function(src, character)
  print(('%s %s joined as %d'):format(character.firstname, character.lastname, src))
end)
```
</Tab>
</Tabs>

<Callout type="info">
Для всей жизни персонажа на сервере (загружен, выгружен, а также персонажи, которые уже в мире, когда ваш ресурс перезапускается) используйте `onCharacter({ loaded, unloaded })` из библиотеки (`aiLib.onCharacter` в Lua) вместо двух событий вручную. Ресурс, который стартует поздно, пропускает события, отправленные до его старта; `onCharacter` воспроизводит этих персонажей за вас.
</Callout>

<Callout type="warn">
Локальные события ai-core локальны намеренно. Никогда не делайте `RegisterNetEvent` (или `onNet`) для их имён: это позволит клиенту любого игрока отправить поддельный `ai-core:moneyChanged` или `ai-core:playerLoaded` в ваш обработчик. Простой `AddEventHandler` / `on` слышит только события, отправленные на той же стороне.
</Callout>
