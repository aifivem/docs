Bir net event server ile bir oyuncunun client’ı arasında gider. ai-core bunlardan çok azını gönderir: bir oyuncunun kendi verisi karakter yüklendiğinde bir kez, sonra yalnızca değişen değerler ve yalnızca o oyuncuya gider. Script’inin ihtiyaç duyduğu diğer her şey bir [client event’i](/tr/docs/developers/api/events/client) ya da bir [state bag](/tr/docs/developers/api/events/state-bags)’dir.

<Callout type="info">
Bu event’lere nadiren doğrudan ihtiyacın olur. Lib’in `onPlayerData(key, handler)`’ı (TypeScript) ve `aiLib.playerData.onChange(key, handler)` (Lua) ikisini de senin için dinler, para ve metadata yamalarını birleştirir ve başlangıç değerlerini ai-core’dan okur.
</Callout>

### ai-core:client:playerData

Server oyuncunun kendi verisinin tek bir değerini gönderir: tek bir anahtarın tüm değeri. Karakter yüklendiğinde anahtar başına bir kez, sonra o değer her değiştiğinde tetiklenir (bir meslek, mesai, bir çete...).

**Taraf:** Server’dan oyuncunun kendi client’ına

#### Argümanlar

<TypeTable
  type={{
    key: { type: '"character" | "money" | "jobs" | "duty" | "job" | "gangs" | "activeGang" | "metadata"', description: 'Bunun `AiPlayerData`’nın hangi değeri olduğu.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#aiplayerdata' },
    value: { type: 'unknown', description: 'O anahtarın tüm yeni değeri (tipi, alanın `AiPlayerData` içindeki tipidir).', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { onPlayerData } from "@aifivem/lib/client";

// Lib ai-core:client:playerData ve playerDataPatch’i senin için dinler.
onPlayerData("job", (job) => console.log(`main job: ${job.job} grade ${job.grade}`));
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
-- Yalnızca server’dan: aiLib.onServerEvent yerel sahteleri atar.
aiLib.onServerEvent('ai-core:client:playerData', function(key, value)
  if key == 'job' then print(('main job: %s grade %d'):format(value.job, value.grade)) end
end)
```
</Tab>
</Tabs>

### ai-core:client:playerDataPatch

Server bir harita değerinin yalnızca değişen kayıtlarını gönderir: `money` (bir hesabın yeni bakiyesi) ya da `metadata` (tek bir anahtar). Yamayı elindekiyle birleştir.

**Taraf:** Server’dan oyuncunun kendi client’ına

#### Argümanlar

<TypeTable
  type={{
    key: { type: '"money" | "metadata"', description: 'Hangi haritanın değiştiği.', required: true },
    patch: { type: 'Record<string, unknown>', description: 'Yalnızca değişen kayıtlar, örneğin `{ cash: 450 }`. `null`’a ayarlanmış bir metadata kaydı kaldırılmıştır.', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { getPlayerData, onPlayerData } from "@aifivem/lib/client";

// Lib yamaları birleştirir: handler birleştirilmiş tüm para haritasını alır.
const show = (money: Record<string, number>): void => SendNUIMessage({ action: "cash", data: money.cash ?? 0 });
show(getPlayerData("money") ?? {});
onPlayerData("money", show);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
-- aiLib.playerData yamaları birleştirir: handler birleştirilmiş tüm para tablosunu alır.
local function show(money) SendNUIMessage({ action = 'cash', data = (money and money.cash) or 0 }) end
show(aiLib.playerData.get('money'))
aiLib.playerData.onChange('money', show)
```
</Tab>
</Tabs>

<Callout type="warn">
Bir client’ta net event’leri yalnızca lib’in `onServerEvent`’i (TypeScript) ya da `aiLib.onServerEvent` (Lua) üzerinden dinle. Event’in gerçekten server’dan geldiğini kontrol ederler; çıplak bir `RegisterNetEvent` handler’ı başka bir client resource’u adı yerel olarak tetiklediğinde de çalışır.
</Callout>

## ai-core’un kendi trafiği: tetikleme

Bu net event’ler ve callback’ler, ai-core’un server’ı ile client’ı (ya da lib) arasındaki dahili trafiğidir. Loglarda tanıyabilmen için listelenmiştir. Onları asla başka bir script’ten tetikleme ve üzerlerine bir şey kurma: argümanları değişebilir.

| Ad | Yön | Ne |
| --- | --- | --- |
| `ai-core:client:spawn` | server’dan client’a | Yüklü karakteri dünyaya koyar. |
| `ai-core:client:chooseSpawn` | server’dan client’a | Oyuncunun seçeceği doğma seçenekleri. |
| `ai-core:client:openCharacters` | server’dan client’a | Bir değişimden sonra karakter ekranını yeniden gösterir. |
| `ai-core:client:characterLooks` | server’dan client’a (latent) | Karakter ekranının görünümleri. |
| `ai-core:client:bills` | server’dan client’a | Fatura listesi için oyuncunun açık ai-core faturaları. |
| `ai-core:client:stress` | server’dan client’a | Stresi yalnızca kendi client’ından alan bir HUD için stres. |
| `ai-core:client:vehicleKeys`, `ai-core:client:garages` | server’dan client’a | Yalnızca client API’si olan anahtar ve garaj script’leri için çağrılar. |
| `ai-core:clientError`, `ai-core:fuelReport` | client’tan server’a | Client paketlerinin hata raporları; client tarafı yakıt script’lerinden yakıt seviyeleri. |
| `ai-core:characters`, `ai-core:createCharacter`, `ai-core:deleteCharacter`, `ai-core:selectCharacter`, `ai-core:spawnChoice`, `ai-core:payBill`, `ai-core:vehicleType` | callback’ler | Karakter ekranı, doğma seçimi, faturalar ve araç spawn’ı. |
| `ai-core:admin:*`, `<resource>:admin:world` | ikisi de | Admin paneli ve her resource’un panel verisi. |
| `ai-lib:client:notify`, `ai-lib:progressFor`, `ai-lib:minigameFor`, `ai-lib:client:progressForCancel` | server’dan client’a | ai-lib’in bildirimleri, server’ın çalıştırdığı ilerleme çubukları ve mini oyunlar (lib’in `notify`, `progressFor`, `minigameFor`’unu kullan). |
