ai-core kendini `es_extended`, `qb-core`, `qbx_core` ve `vrp` olarak sunar, böylece o framework’ler için yazılmış script’ler değişiklik olmadan çalışır. Bunun bir parçası, ai-core’da bir şey değiştiğinde framework’ün kendi event’lerini tetiklemektir: bir karakter yüklenir, para hareket eder, bir meslek değişir. Bu sayfa köprünün tetiklediği her framework event’ini, köprünün gönderdiği argümanlarla, ve cevapladığı framework event’lerini listeler.

**Yeni kod bunları kullanmamalıdır.** ai-core’un kendi event’lerine ([server](/tr/docs/developers/api/events/server), [client](/tr/docs/developers/api/events/client)) ve lib’e göre yaz: daha fazlasını taşırlar (birden fazla meslek, çeteler, mesai) ve bir framework şekline bağlı değildirler. Bu sayfa mevcut ESX / QB / vRP script’lerini çalıştırmak ve düzeltmek içindir.

<Callout type="info">
Framework görünümleri oyuncu başına tek bir meslek tutar: oyuncunun mesaide olduğu meslek, yoksa ilk mesleği. ai-core’un kendisi birden fazla mesleğe izin verir. ESX’te çete yoktur; ESX’in `money` hesabı ai-core’un `cash`’idir.
</Callout>

## QBCore ve Qbox: server

Köprü bunları server’da `TriggerEvent` ile tetikler. Qbox script’leri aynı QBCore adlarını dinler; köprü yalnızca Qbox’a özel hiçbir event tetiklemez.

### QBCore:Server:PlayerLoaded

Bir karakter yüklendi (`ai-core:playerLoaded`’dan).

**Taraf:** Server

## QBCore ve Qbox: client

Oyuncunun kendi client’ında `TriggerEvent` ile tetiklenir.

| Event | Ne zaman | Argümanlar |
| --- | --- | --- |
| `QBCore:Client:OnPlayerLoaded` | Karakter dünyada duruyor. | yok |
| `QBCore:Client:OnPlayerUnload` | Oyuncu karakter ekranına döndü. | yok |
| `QBCore:Player:SetPlayerData` | Yüklemeden sonra ve her para, meslek, çete ya da metadata değişikliğinden sonra. | `(PlayerData: table)` tüm QB PlayerData’sı. |
| `QBCore:Client:OnJobUpdate` | Framework mesleği değişti. | `(job: table)` QB meslek tablosu (server’daki gibi). |
| `QBCore:Client:SetDuty` | Aynı meslek için mesai değişti. | `(onDuty: boolean)` |
| `QBCore:Client:OnGangUpdate` | Framework çetesi değişti. | `(gang: table)` QB çete tablosu. |
| `QBCore:Client:OnMoneyChange` | Bir hesap bakiyesi değişti. | `(account: string, balance: number)` ai-core’un hesap adı ve yeni bakiye. |

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
on("QBCore:Client:OnPlayerLoaded", () => console.log("loaded"));
on("QBCore:Client:OnJobUpdate", (job: { name: string }) => console.log(`job: ${job.name}`));
on("QBCore:Client:SetDuty", (onDuty: boolean) => console.log(`on duty: ${onDuty}`));
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('QBCore:Client:OnPlayerLoaded', function() print('loaded') end)
AddEventHandler('QBCore:Client:OnJobUpdate', function(job) print(('job: %s'):format(job.name)) end)
AddEventHandler('QBCore:Client:SetDuty', function(onDuty) print(('on duty: %s'):format(tostring(onDuty))) end)
```
</Tab>
</Tabs>

<Callout type="warn">
`QBCore:Client:OnMoneyChange`, qb-core’un kendi argümanlarını değil, yeni bakiyeyi `(account, balance)` olarak taşır. Bunu miktar olarak okuyan bir QB script’i bakiyeyi görür. `QBCore:Player:SetPlayerData`’yı ya da ai-core’un `onPlayerData("money", ...)`’ını tercih et.
</Callout>

## ai-core’un cevapladığı framework event’leri

Bir framework için yazılmış script’ler bu event’leri framework’ün cevaplamasını bekleyerek gönderir. Onun yerine ai-core cevaplar.

| Event | Taraf | ai-core ne yapar |
| --- | --- | --- |
| `QBCore:GetObject`, `esx:getSharedObject` | ikisi de | Callback’i core nesnesiyle (`QBCore` / `ESX`) çağırır. |
| `QBCore:Server:TriggerCallback`, `esx:triggerServerCallback` | server (client’lardan) | `CreateCallback` / `RegisterServerCallback` ile kaydedilmiş framework callback’ini çalıştırır ve cevaplar. Oyuncu başına herhangi bir 10 saniyede en fazla 30 istek. |
| `QBCore:Notify`, `esx:showNotification`, `esx:showAdvancedNotification`, `ESX:Notify` | client (server’dan) | ai-lib’in bildirimini gösterir. |
| `esx:showHelpNotification`, `ESX:TextUI`, `ESX:HideUI`, `qb-core:client:DrawText`, `qb-core:client:ChangeText`, `qb-core:client:HideText`, `qb-core:client:KeyPressed` | client | ai-lib’in istemini gösterir ya da gizler. |
| `qb-menu:client:openMenu`, `qb-menu:client:closeMenu` | client | ai-lib’in menüsünü qb-menu öğeleriyle açar ya da kapatır. |
| `progressbar:client:cancel` | client | Köprünün ilerleme çubuğunu iptal eder. |
| `police:server:policeAlert` | server | Oyuncunun konumunda aktif ihbar sistemine bir polis ihbarı gönderir. Client’lar `(text)` gönderir (oyuncu başına 10 saniyede bir); server script’leri onu `(text, camId, playerSource)` ile `TriggerEvent` eder. |
| `qb-weathersync:client:DisableSync` / `EnableSync`, `cd_easytime:PauseSync`, `vSync:toggle` | client | Hava ve saat senkronunun duraklatma sebepleri olarak sayılır (bkz. [Hava ve saat senkronu](/tr/docs/developers/api/core-client/world)). |
