Le client d’ai-core déclenche ces événements avec `TriggerEvent` dans le jeu du joueur lui-même. Chaque ressource client de ce joueur les entend ; les autres joueurs jamais. Ils décrivent uniquement le joueur **local**.

### ai-core:client:playerLoaded

Le personnage du joueur local se tient dans le monde. Lancez ici votre travail client propre au personnage (valeurs du HUD, blips de métier, boucles).

**Côté :** Client · **Constante :** `CORE.clientPlayerLoadedEvent`

#### Arguments

<TypeTable
  type={{
    data: { type: 'AiPlayerData', description: 'Tout sur le personnage à cet instant : `character`, `money`, `jobs`, `duty`, `job`, `gangs`, `activeGang`, `metadata`. Identique à l’export `GetPlayerData`.', required: true, typeDescriptionLink: '/fr/docs/developers/api/types#aiplayerdata' },
  }}
/>

#### Écouteur

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aicore-fivem/lib/client";
import { CORE, type AiPlayerData } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

function start(data: AiPlayerData): void {
  console.log(`hello ${data.character?.firstname}, cash ${data.money.cash ?? 0}`);
}

// Couvre aussi un redémarrage de ressource alors que le joueur est déjà dans le monde.
const now = core.GetPlayerData();
if (now) start(now);
on(CORE.clientPlayerLoadedEvent, start);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local function start(data)
  print(('hello %s, cash %d'):format(data.character.firstname, data.money.cash or 0))
end

-- Couvre aussi un redémarrage de ressource alors que le joueur est déjà dans le monde.
local now = exports['ai-core']:GetPlayerData()
if now then start(now) end
AddEventHandler('ai-core:client:playerLoaded', start)
```
</Tab>
</Tabs>

### ai-core:client:playerUnloaded

Le personnage local a été libéré : le joueur est revenu à l’écran des personnages. Arrêtez le travail propre au personnage et effacez ce que vous gardiez pour lui. (Quand le joueur quitte le serveur, son jeu se ferme ; rien ne se déclenche.)

**Côté :** Client · **Constante :** `CORE.clientPlayerUnloadedEvent`

#### Arguments

Aucun.

#### Écouteur

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { CORE } from "@aicore-fivem/shared";

on(CORE.clientPlayerUnloadedEvent, () => {
  SendNUIMessage({ action: "reset" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:playerUnloaded', function()
  SendNUIMessage({ action = 'reset' })
end)
```
</Tab>
</Tabs>

### ai-core:client:dead

Le joueur local est tombé (mort ou dernier souffle) ou s’est relevé, quel que soit le script de mort utilisé. Ne se déclenche que lors d’un changement.

**Côté :** Client · **Constante :** `CORE.clientDeadEvent` · **Lib :** `medical.onChange`

#### Arguments

<TypeTable
  type={{
    dead: { type: 'boolean', description: '`true` : le joueur est tombé. `false` : il s’est relevé (réanimé, réapparu).', required: true },
  }}
/>

#### Écouteur

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { medical } from "@aicore-fivem/lib/client";

// Identique à on(CORE.clientDeadEvent, ...).
medical.onChange((dead) => {
  if (dead) SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:dead', function(dead)
  if dead then SendNUIMessage({ action = 'close' }) end
end)
```
</Tab>
</Tabs>

### ai-core:client:cache

Une valeur en cache du joueur local a changé. Un seul observateur dans ai-core lit le ped, le véhicule, le siège et l’arme pour toutes les ressources et ne déclenche ceci que lorsqu’une valeur change, si bien qu’aucune ressource n’a à les interroger en boucle. `cache` et `onCache` de la lib (`aiLib.cache` et `aiLib.cache.onChange` en Lua) reposent dessus ; utilisez-les.

**Côté :** Client · **Constante :** `CORE.clientCacheEvent`

#### Arguments

<TypeTable
  type={{
    key: { type: '"ped" | "vehicle" | "seat" | "weapon"', description: 'Quelle valeur a changé.', required: true, typeDescriptionLink: '/fr/docs/developers/api/types#playercache' },
    value: { type: 'number | false', description: '`ped` : le nouveau handle du ped. `vehicle` : le handle du véhicule, `false` à pied. `seat` : l’index du siège (`-1` = conducteur), `false` à pied. `weapon` : le hash de l’arme en main, `false` sans arme.', required: true },
  }}
/>

#### Écouteur

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { onCache } from "@aicore-fivem/lib/client";

onCache("vehicle", (vehicle, old) => {
  if (vehicle !== false) console.log(`entered vehicle ${vehicle}`);
  else if (old !== false) console.log("left the vehicle");
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
aiLib.cache.onChange('vehicle', function(vehicle, old)
  if vehicle then print(('entered vehicle %d'):format(vehicle))
  elseif old then print('left the vehicle') end
end)
```
</Tab>
</Tabs>

### ai-core:client:hudVisible

Les HUD doivent s’afficher ou se masquer : une interface plein écran s’est ouverte ou la dernière s’est fermée. Une ressource de HUD l’écoute.

**Côté :** Client · **Constante :** `CORE.clientHudVisibleEvent` · **Lib :** `hud.onChange`

#### Arguments

<TypeTable
  type={{
    visible: { type: 'boolean', description: '`true` : afficher le HUD. `false` : le masquer.', required: true },
  }}
/>

#### Écouteur

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { hud } from "@aicore-fivem/lib/client";

hud.onChange((visible) => SendNUIMessage({ action: "visible", data: visible }));
```
</Tab>
<Tab value="Lua">
```lua title="client/hud.lua"
AddEventHandler('ai-core:client:hudVisible', function(visible)

```
</Tab>
</Tabs>

### ai-core:client:worldSync

La synchro de la météo et de l’heure a été mise en pause ou reprend. Un script météo l’écoute. Voir [Synchro de la météo et de l’heure](/fr/docs/developers/api/core-client/world).

**Côté :** Client · **Constante :** `CORE.clientWorldSyncEvent`

#### Arguments

<TypeTable
  type={{
    paused: { type: 'boolean', description: '`true` : cesser d’appliquer la météo et l’heure du serveur. `false` : les appliquer à nouveau.', required: true },
  }}
/>

#### Écouteur

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/weather.ts"
import { CORE } from "@aicore-fivem/shared";

on(CORE.clientWorldSyncEvent, (paused: boolean) => {
  console.log(paused ? "weather sync paused" : "weather sync running");
});
```
</Tab>
<Tab value="Lua">
```lua title="client/weather.lua"
AddEventHandler('ai-core:client:worldSync', function(paused)
  print(paused and 'weather sync paused' or 'weather sync running')
end)
```
</Tab>
</Tabs>

### ai-core:client:definitions

Un métier ou un gang a été ajouté, modifié ou supprimé dans le panneau d’administration. Se déclenche sur chaque client, une fois par métier ou gang modifié. Associez-le à l’export `GetDefinitions`.

**Côté :** Client · **Constante :** `CORE.clientDefinitionsEvent`

#### Arguments

<TypeTable
  type={{
    file: { type: '"jobs" | "gangs"', description: 'Quelle liste a changé.', required: true },
    name: { type: 'string', description: 'Le nom du métier ou du gang.', required: true },
    definition: { type: 'unknown', description: 'Le nouvel enregistrement tel que le panneau le stocke, `null` s’il a été supprimé.', required: true },
  }}
/>

#### Écouteur

Voir l’exemple de [GetDefinitions](/fr/docs/developers/api/core-client/player#getdefinitions).

### ai-core:client:characterPortrait

Une photo de portrait pour une carte de personnage sur l’écran des personnages. Un script de vêtements (ai-appearance) le déclenche ; l’écran des personnages d’ai-core l’écoute et affiche la photo. Déclenchez-le vous-même uniquement si vous écrivez un script de vêtements.

**Côté :** Client · **Constante :** `CORE.clientCharacterPortraitEvent` · **Déclenché par :** le script de vêtements, entendu par ai-core

#### Arguments

<TypeTable
  type={{
    charId: { type: 'number', description: 'L’id du personnage de la carte.', required: true },
    url: { type: 'string', description: 'L’url de la photo, par exemple une texture de portrait `https://nui-img/<txd>/<txd>`.', required: true },
  }}
/>

#### Écouteur

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/portraits.ts"
import { CORE } from "@aicore-fivem/shared";

// Un script de vêtements transmet un portrait à l’écran des personnages.
export function sendPortrait(charId: number, txd: string): void {
  emit(CORE.clientCharacterPortraitEvent, charId, `https://nui-img/${txd}/${txd}`);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/portraits.lua"
-- Un script de vêtements transmet un portrait à l’écran des personnages.
local function sendPortrait(charId, txd)
  TriggerEvent('ai-core:client:characterPortrait', charId, ('https://nui-img/%s/%s'):format(txd, txd))
end
```
</Tab>
</Tabs>

### ai-core:client:seatbelt

La ceinture de sécurité du joueur local a changé, quel que soit le script de ceinture que lit ai-core. Se déclenche depuis les scripts qui signalent les changements (ai-smallresources, qbx_seatbelt) ; avec la ceinture propre à un HUD, lisez `GetSeatbelt` quand vous en avez besoin.

**Côté :** Client · **Constante :** `CORE.clientSeatbeltEvent` · **Lib :** `seatbelt.onChange`

#### Arguments

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true` : ceinture attachée. `false` : ceinture détachée. `null` : le script n’a pas donné de réponse claire.', required: true },
  }}
/>

#### Écouteur

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { seatbelt } from "@aicore-fivem/lib/client";

seatbelt.onChange((worn) => SendNUIMessage({ action: "belt", data: worn === true }));
```
</Tab>
<Tab value="Lua">
```lua title="client/hud.lua"
aiLib.seatbelt.onChange(function(worn)
  SendNUIMessage({ action = 'belt', data = worn == true })
end)
```
</Tab>
</Tabs>

### ai-smallresources:seatbelt

L’événement de ceinture propre à ai-smallresources. Les HUD qui ne prennent en charge qu’ai-smallresources l’écoutent. Le nouveau code doit écouter `ai-core:client:seatbelt` ci-dessus, qui fonctionne avec chaque script de ceinture pris en charge.

**Côté :** Client · **Constante :** `SEATBELT_EVENT`

#### Arguments

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true` : ceinture attachée. `false` : ceinture détachée. `null` : inconnu.', required: true },
  }}
/>

#### Écouteur

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { SEATBELT_EVENT } from "@aicore-fivem/shared";
```

## Événements client internes

Le `Keybind` de la lib parle au client d’ai-core avec deux événements locaux. Ne les déclenchez pas et n’y répondez pas vous-même ; utilisez `Keybind` (TS) ou `aiLib.Keybind` (Lua).

| Événement | Constante | Sens | Arguments |
| --- | --- | --- | --- |
| `ai-core:client:keybind` | `KEYBIND.announceEvent` | lib vers ai-core | `(info: KeybindInfo)` un raccourci attend sa touche par défaut. |
| `ai-core:client:keybindKey` | `KEYBIND.keyEvent` | ai-core vers lib | `(resource: string, name: string, key: string)` la touche à enregistrer : celle du panneau, sinon celle du script. |
