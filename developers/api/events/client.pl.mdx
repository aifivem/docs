Klient ai-core wysyła te zdarzenia przez `TriggerEvent` we własnej grze gracza. Słyszy je każdy kliencki zasób tego gracza; inni gracze nigdy. Opisują tylko **lokalnego** gracza.

### ai-core:client:playerLoaded

Postać lokalnego gracza stoi w świecie. Tutaj rozpocznij kliencką pracę per postać (wartości HUD, blipy pracy, pętle).

**Strona:** Klient · **Stała:** `CORE.clientPlayerLoadedEvent`

#### Argumenty

<TypeTable
  type={{
    data: { type: 'AiPlayerData', description: 'Wszystko o postaci w tej chwili: `character`, `money`, `jobs`, `duty`, `job`, `gangs`, `activeGang`, `metadata`. To samo co eksport `GetPlayerData`.', required: true, typeDescriptionLink: '/pl/docs/developers/api/types#aiplayerdata' },
  }}
/>

#### Nasłuchiwanie

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aifivem/lib/client";
import { CORE, type AiPlayerData } from "@aifivem/shared";

const core = resourceExport("ai-core");

function start(data: AiPlayerData): void {
  console.log(`hello ${data.character?.firstname}, cash ${data.money.cash ?? 0}`);
}

// Obejmuje też restart zasobu, gdy gracz jest już w świecie.
const now = core.GetPlayerData();
if (now) start(now);
on(CORE.clientPlayerLoadedEvent, start);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local function start(data)
  print(('hello %s, cash %d'):format(data.character.firstname, data.money.cash or 0))
end

-- Obejmuje też restart zasobu, gdy gracz jest już w świecie.
local now = exports['ai-core']:GetPlayerData()
if now then start(now) end
AddEventHandler('ai-core:client:playerLoaded', start)
```
</Tab>
</Tabs>

### ai-core:client:playerUnloaded

Lokalna postać została zwolniona: gracz wrócił do ekranu postaci. Zatrzymaj pracę per postać i wyczyść to, co trzymałeś dla tej postaci. (Gdy gracz opuszcza serwer, jego gra się zamyka; nic nie jest wysyłane.)

**Strona:** Klient · **Stała:** `CORE.clientPlayerUnloadedEvent`

#### Argumenty

Brak.

#### Nasłuchiwanie

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { CORE } from "@aifivem/shared";

on(CORE.clientPlayerUnloadedEvent, () => {
  SendNUIMessage({ action: "reset" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:playerUnloaded', function()
  SendNUIMessage({ action = 'reset' })
end)
```
</Tab>
</Tabs>

### ai-core:client:dead

Lokalny gracz został powalony (martwy lub last stand) albo wstał, według działającego skryptu śmierci. Wysyłane tylko przy zmianie.

**Strona:** Klient · **Stała:** `CORE.clientDeadEvent` · **Lib:** `medical.onChange`

#### Argumenty

<TypeTable
  type={{
    dead: { type: 'boolean', description: '`true`: gracz został powalony. `false`: wstał (reanimowany, odrodzony).', required: true },
  }}
/>

#### Nasłuchiwanie

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { medical } from "@aifivem/lib/client";

// To samo co on(CORE.clientDeadEvent, ...).
medical.onChange((dead) => {
  if (dead) SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:dead', function(dead)
  if dead then SendNUIMessage({ action = 'close' }) end
end)
```
</Tab>
</Tabs>

### ai-core:client:cache

Zmieniła się wartość lokalnego gracza w pamięci podręcznej. Jeden obserwator w ai-core czyta peda, pojazd, miejsce i broń dla każdego zasobu i wysyła to tylko wtedy, gdy wartość się zmienia, więc żaden zasób nie musi ich odpytywać. `cache` i `onCache` z liba (`aiLib.cache` i `aiLib.cache.onChange` w Lua) są na tym zbudowane; używaj ich.

**Strona:** Klient · **Stała:** `CORE.clientCacheEvent`

#### Argumenty

<TypeTable
  type={{
    key: { type: '"ped" | "vehicle" | "seat" | "weapon"', description: 'Która wartość się zmieniła.', required: true, typeDescriptionLink: '/pl/docs/developers/api/types#playercache' },
    value: { type: 'number | false', description: '`ped`: nowy uchwyt peda. `vehicle`: uchwyt pojazdu, `false` pieszo. `seat`: indeks miejsca (`-1` = kierowca), `false` pieszo. `weapon`: hash broni w ręce, `false` bez broni.', required: true },
  }}
/>

#### Nasłuchiwanie

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { onCache } from "@aifivem/lib/client";

onCache("vehicle", (vehicle, old) => {
  if (vehicle !== false) console.log(`entered vehicle ${vehicle}`);
  else if (old !== false) console.log("left the vehicle");
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
aiLib.cache.onChange('vehicle', function(vehicle, old)
  if vehicle then print(('entered vehicle %d'):format(vehicle))
  elseif old then print('left the vehicle') end
end)
```
</Tab>
</Tabs>

### ai-core:client:worldSync

Synchronizacja pogody i czasu została wstrzymana albo działa znowu. Nasłuchuje tego skrypt pogody. Zobacz [Synchronizacja pogody i czasu](/pl/docs/developers/api/core-client/world).

**Strona:** Klient · **Stała:** `CORE.clientWorldSyncEvent`

#### Argumenty

<TypeTable
  type={{
    paused: { type: 'boolean', description: '`true`: przestań stosować pogodę i czas serwera. `false`: stosuj je znowu.', required: true },
  }}
/>

#### Nasłuchiwanie

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/weather.ts"
import { CORE } from "@aifivem/shared";

on(CORE.clientWorldSyncEvent, (paused: boolean) => {
  console.log(paused ? "weather sync paused" : "weather sync running");
});
```
</Tab>
<Tab value="Lua">
```lua title="client/weather.lua"
AddEventHandler('ai-core:client:worldSync', function(paused)
  print(paused and 'weather sync paused' or 'weather sync running')
end)
```
</Tab>
</Tabs>

### ai-core:client:definitions

Praca lub gang zostały dodane, zmienione lub usunięte w panelu administratora. Wysyłane na każdym kliencie, raz na każdą zmienioną pracę lub gang. Używaj w parze z eksportem `GetDefinitions`.

**Strona:** Klient · **Stała:** `CORE.clientDefinitionsEvent`

#### Argumenty

<TypeTable
  type={{
    file: { type: '"jobs" | "gangs"', description: 'Która lista się zmieniła.', required: true },
    name: { type: 'string', description: 'Nazwa pracy lub gangu.', required: true },
    definition: { type: 'unknown', description: 'Nowy rekord tak, jak zapisuje go panel, `null`, gdy został usunięty.', required: true },
  }}
/>

#### Nasłuchiwanie

Zobacz przykład [GetDefinitions](/pl/docs/developers/api/core-client/player#getdefinitions).

### ai-core:client:characterPortrait

Obraz portretu dla karty postaci na ekranie postaci. Wysyła go skrypt ubrań (ai-appearance); ekran postaci ai-core nasłuchuje i pokazuje obraz. Wysyłaj to sam tylko wtedy, gdy piszesz skrypt ubrań.

**Strona:** Klient · **Stała:** `CORE.clientCharacterPortraitEvent` · **Wysyła:** skrypt ubrań, słucha ai-core

#### Argumenty

<TypeTable
  type={{
    charId: { type: 'number', description: 'Id postaci z karty.', required: true },
    url: { type: 'string', description: 'Url obrazu, na przykład tekstura headshotu `https://nui-img/<txd>/<txd>`.', required: true },
  }}
/>

#### Nasłuchiwanie

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/portraits.ts"
import { CORE } from "@aifivem/shared";

// Skrypt ubrań przekazuje portret do ekranu postaci.
export function sendPortrait(charId: number, txd: string): void {
  emit(CORE.clientCharacterPortraitEvent, charId, `https://nui-img/${txd}/${txd}`);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/portraits.lua"
-- Skrypt ubrań przekazuje portret do ekranu postaci.
local function sendPortrait(charId, txd)
  TriggerEvent('ai-core:client:characterPortrait', charId, ('https://nui-img/%s/%s'):format(txd, txd))
end
```
</Tab>
</Tabs>

### ai-core:client:seatbelt

Zmienił się pas bezpieczeństwa lokalnego gracza, według skryptu pasów, który czyta ai-core. Wysyłane ze skryptów, które zgłaszają zmiany (ai-smallresources, qbx_seatbelt); przy własnym pasie HUD odczytuj `GetSeatbelt`, gdy go potrzebujesz.

**Strona:** Klient · **Stała:** `CORE.clientSeatbeltEvent` · **Lib:** `seatbelt.onChange`

#### Argumenty

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true`: pas zapięty. `false`: pas odpięty. `null`: skrypt nie dał jasnej odpowiedzi.', required: true },
  }}
/>

#### Nasłuchiwanie

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { seatbelt } from "@aifivem/lib/client";

seatbelt.onChange((worn) => SendNUIMessage({ action: "belt", data: worn === true }));
```
</Tab>

```lua title="client/hud.lua"
aiLib.seatbelt.onChange(function(worn)
  SendNUIMessage({ action = 'belt', data = worn == true })

```
</Tab>

## Wewnętrzne zdarzenia klienckie

`Keybind` z liba rozmawia z klientem ai-core przez dwa zdarzenia lokalne. Nie wysyłaj ich i nie odpowiadaj na nie sam; używaj `Keybind` (TS) lub `aiLib.Keybind` (Lua).

| Zdarzenie | Stała | Kierunek | Argumenty |
| --- | --- | --- | --- |
| `ai-core:client:keybind` | `KEYBIND.announceEvent` | lib do ai-core | `(info: KeybindInfo)` skrót klawiszowy czeka na swój domyślny klawisz. |
| `ai-core:client:keybindKey` | `KEYBIND.keyEvent` | ai-core do liba | `(resource: string, name: string, key: string)` klawisz do zarejestrowania: klawisz z panelu, w przeciwnym razie własny klawisz skryptu. |
