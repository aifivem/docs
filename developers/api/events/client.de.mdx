Der Client von ai-core löst diese Events mit `TriggerEvent` im eigenen Spiel des Spielers aus. Jede Client-Ressource dieses Spielers hört sie; andere Spieler nie. Sie beschreiben nur den **lokalen** Spieler.

### ai-core:client:playerLoaded

Der Charakter des lokalen Spielers steht in der Welt. Starte hier deine Client-Arbeit pro Charakter (HUD-Werte, Job-Blips, Schleifen).

**Seite:** Client · **Konstante:** `CORE.clientPlayerLoadedEvent`

#### Argumente

<TypeTable
  type={{
    data: { type: 'AiPlayerData', description: 'Alles über den Charakter in diesem Moment: `character`, `money`, `jobs`, `duty`, `job`, `gangs`, `activeGang`, `metadata`. Dasselbe wie der Export `GetPlayerData`.', required: true, typeDescriptionLink: '/de/docs/developers/api/types#aiplayerdata' },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aifivem/lib/client";
import { CORE, type AiPlayerData } from "@aifivem/shared";

const core = resourceExport("ai-core");

function start(data: AiPlayerData): void {
  console.log(`hello ${data.character?.firstname}, cash ${data.money.cash ?? 0}`);
}

// Deckt auch einen Neustart der Ressource ab, während der Spieler schon in der Welt ist.
const now = core.GetPlayerData();
if (now) start(now);
on(CORE.clientPlayerLoadedEvent, start);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local function start(data)
  print(('hello %s, cash %d'):format(data.character.firstname, data.money.cash or 0))
end

-- Deckt auch einen Neustart der Ressource ab, während der Spieler schon in der Welt ist.
local now = exports['ai-core']:GetPlayerData()
if now then start(now) end
AddEventHandler('ai-core:client:playerLoaded', start)
```
</Tab>
</Tabs>

### ai-core:client:playerUnloaded

Der lokale Charakter wurde losgelassen: Der Spieler ist zum Charakterbildschirm zurückgekehrt. Stoppe die Arbeit pro Charakter und lösche, was du für diesen Charakter gehalten hast. (Wenn der Spieler den Server verlässt, schließt sich sein Spiel; nichts wird ausgelöst.)

**Seite:** Client · **Konstante:** `CORE.clientPlayerUnloadedEvent`

#### Argumente

Keine.

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { CORE } from "@aifivem/shared";

on(CORE.clientPlayerUnloadedEvent, () => {
  SendNUIMessage({ action: "reset" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:playerUnloaded', function()
  SendNUIMessage({ action = 'reset' })
end)
```
</Tab>
</Tabs>

### ai-core:client:dead

Der lokale Spieler ist zu Boden gegangen (tot oder Last Stand) oder wieder aufgestanden, im laufenden Tod-Skript. Wird nur bei einer Änderung ausgelöst.

**Seite:** Client · **Konstante:** `CORE.clientDeadEvent` · **Lib:** `medical.onChange`

#### Argumente

<TypeTable
  type={{
    dead: { type: 'boolean', description: '`true`: Der Spieler ist zu Boden gegangen. `false`: Er ist wieder aufgestanden (wiederbelebt, respawnt).', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { medical } from "@aifivem/lib/client";

// Dasselbe wie on(CORE.clientDeadEvent, ...).
medical.onChange((dead) => {
  if (dead) SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:dead', function(dead)
  if dead then SendNUIMessage({ action = 'close' }) end
end)
```
</Tab>
</Tabs>

### ai-core:client:cache

Ein gecachter Wert des lokalen Spielers hat sich geändert. Ein Beobachter in ai-core liest Ped, Fahrzeug, Sitz und Waffe für jede Ressource und löst dies nur aus, wenn sich ein Wert ändert, sodass keine Ressource sie abfragen muss. `cache` und `onCache` der Lib (`aiLib.cache` und `aiLib.cache.onChange` in Lua) bauen darauf auf; nutze diese.

**Seite:** Client · **Konstante:** `CORE.clientCacheEvent`

#### Argumente

<TypeTable
  type={{
    key: { type: '"ped" | "vehicle" | "seat" | "weapon"', description: 'Welcher Wert sich geändert hat.', required: true, typeDescriptionLink: '/de/docs/developers/api/types#playercache' },
    value: { type: 'number | false', description: '`ped`: das neue Ped-Handle. `vehicle`: das Fahrzeug-Handle, `false` zu Fuß. `seat`: der Sitzindex (`-1` = Fahrer), `false` zu Fuß. `weapon`: der Hash der Waffe in der Hand, `false`, wenn unbewaffnet.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { onCache } from "@aifivem/lib/client";

onCache("vehicle", (vehicle, old) => {
  if (vehicle !== false) console.log(`entered vehicle ${vehicle}`);
  else if (old !== false) console.log("left the vehicle");
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
aiLib.cache.onChange('vehicle', function(vehicle, old)
  if vehicle then print(('entered vehicle %d'):format(vehicle))
  elseif old then print('left the vehicle') end
end)
```
</Tab>
</Tabs>

### ai-core:client:worldSync

**Seite:** Client · **Konstante:** `CORE.clientWorldSyncEvent`

#### Argumente

<TypeTable
  type={{
    paused: { type: 'boolean', description: '`true`: Wetter und Zeit des Servers nicht mehr anwenden. `false`: sie wieder anwenden.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/weather.ts"

on(CORE.clientWorldSyncEvent, (paused: boolean) => {
```

### ai-core:client:definitions

Ein Job oder eine Gang wurde im Admin-Panel hinzugefügt, geändert oder gelöscht. Wird auf jedem Client ausgelöst, einmal pro geändertem Job oder geänderter Gang. Kombiniere es mit dem Export `GetDefinitions`.

**Seite:** Client · **Konstante:** `CORE.clientDefinitionsEvent`

#### Argumente

<TypeTable
  type={{
    file: { type: '"jobs" | "gangs"', description: 'Welche Liste sich geändert hat.', required: true },
    name: { type: 'string', description: 'Der Job- oder Gangname.', required: true },
    definition: { type: 'unknown', description: 'Der neue Datensatz, wie das Panel ihn speichert, `null`, wenn er gelöscht wurde.', required: true },
  }}
/>

#### Listener

Siehe das Beispiel zu [GetDefinitions](/de/docs/developers/api/core-client/player#getdefinitions).

### ai-core:client:characterPortrait

Ein Porträtbild für eine Charakterkarte auf dem Charakterbildschirm. Ein Kleidungs-Skript (ai-appearance) löst es aus; der Charakterbildschirm von ai-core hört darauf und zeigt das Bild. Löse es nur selbst aus, wenn du ein Kleidungs-Skript schreibst.

**Seite:** Client · **Konstante:** `CORE.clientCharacterPortraitEvent` · **Ausgelöst von:** dem Kleidungs-Skript, gehört von ai-core

#### Argumente

<TypeTable
  type={{
    charId: { type: 'number', description: 'Die Charakter-ID der Karte.', required: true },
    url: { type: 'string', description: 'Die Bild-URL, zum Beispiel eine Headshot-Textur `https://nui-img/<txd>/<txd>`.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/portraits.ts"
import { CORE } from "@aifivem/shared";

// Ein Kleidungs-Skript übergibt ein Porträt an den Charakterbildschirm.
export function sendPortrait(charId: number, txd: string): void {
  emit(CORE.clientCharacterPortraitEvent, charId, `https://nui-img/${txd}/${txd}`);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/portraits.lua"
-- Ein Kleidungs-Skript übergibt ein Porträt an den Charakterbildschirm.
local function sendPortrait(charId, txd)
  TriggerEvent('ai-core:client:characterPortrait', charId, ('https://nui-img/%s/%s'):format(txd, txd))
end
```
</Tab>
</Tabs>

### ai-core:client:seatbelt

Der Sicherheitsgurt des lokalen Spielers hat sich geändert, in dem Gurt-Skript, das ai-core liest. Wird von den Skripten ausgelöst, die Änderungen melden (ai-smallresources, qbx_seatbelt); bei einem eigenen Gurt eines HUD lies `GetSeatbelt`, wenn du es brauchst.

**Seite:** Client · **Konstante:** `CORE.clientSeatbeltEvent` · **Lib:** `seatbelt.onChange`

#### Argumente

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true`: Gurt angelegt. `false`: Gurt abgelegt. `null`: Das Skript hat keine klare Antwort gegeben.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { seatbelt } from "@aifivem/lib/client";

seatbelt.onChange((worn) => SendNUIMessage({ action: "belt", data: worn === true }));
```
</Tab>
<Tab value="Lua">
```lua title="client/hud.lua"
aiLib.seatbelt.onChange(function(worn)
  SendNUIMessage({ action = 'belt', data = worn == true })
```

</Tab>

## Interne Client-Events

`Keybind` der Lib spricht über zwei lokale Events mit dem Client von ai-core. Löse sie nicht selbst aus und beantworte sie nicht; nutze `Keybind` (TS) oder `aiLib.Keybind` (Lua).

| Event | Konstante | Richtung | Argumente |
| --- | --- | --- | --- |
| `ai-core:client:keybind` | `KEYBIND.announceEvent` | Lib an ai-core | `(info: KeybindInfo)` ein Keybind wartet auf seine Standardtaste. |
| `ai-core:client:keybindKey` | `KEYBIND.keyEvent` | ai-core an Lib | `(resource: string, name: string, key: string)` die zu registrierende Taste: die Taste des Panels, sonst die eigene des Skripts. |
