O cliente do ai-core dispara estes eventos com `TriggerEvent` no próprio jogo do jogador. Cada recurso de cliente desse jogador os ouve; os outros jogadores nunca. Eles descrevem só o jogador **local**.

### ai-core:client:playerLoaded

O personagem do jogador local está no mundo. Comece aqui o seu trabalho de cliente por personagem (valores do HUD, blips de emprego, loops).

**Lado:** Cliente · **Constante:** `CORE.clientPlayerLoadedEvent`

#### Argumentos

<TypeTable
  type={{
    data: { type: 'AiPlayerData', description: 'Tudo sobre o personagem neste momento: `character`, `money`, `jobs`, `duty`, `job`, `gangs`, `activeGang`, `metadata`. O mesmo que o export `GetPlayerData`.', required: true, typeDescriptionLink: '/pt/docs/developers/api/types#aiplayerdata' },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aifivem/lib/client";
import { CORE, type AiPlayerData } from "@aifivem/shared";

const core = resourceExport("ai-core");

function start(data: AiPlayerData): void {
  console.log(`hello ${data.character?.firstname}, cash ${data.money.cash ?? 0}`);
}

// Também cobre um restart do recurso enquanto o jogador já está no mundo.
const now = core.GetPlayerData();
if (now) start(now);
on(CORE.clientPlayerLoadedEvent, start);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local function start(data)
  print(('hello %s, cash %d'):format(data.character.firstname, data.money.cash or 0))
end

-- Também cobre um restart do recurso enquanto o jogador já está no mundo.
local now = exports['ai-core']:GetPlayerData()
if now then start(now) end
AddEventHandler('ai-core:client:playerLoaded', start)
```
</Tab>
</Tabs>

### ai-core:client:playerUnloaded

O personagem local foi liberado: o jogador voltou para a tela de personagens. Pare o trabalho por personagem e limpe o que você guardou para esse personagem. (Quando o jogador sai do servidor, o jogo dele fecha; nada dispara.)

**Lado:** Cliente · **Constante:** `CORE.clientPlayerUnloadedEvent`

#### Argumentos

Nenhum.

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { CORE } from "@aifivem/shared";

on(CORE.clientPlayerUnloadedEvent, () => {
  SendNUIMessage({ action: "reset" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:playerUnloaded', function()
  SendNUIMessage({ action = 'reset' })
end)
```
</Tab>
</Tabs>

### ai-core:client:dead

O jogador local caiu (morto ou last stand) ou se levantou, no script de morte que estiver rodando. Só dispara numa mudança.

**Lado:** Cliente · **Constante:** `CORE.clientDeadEvent` · **Lib:** `medical.onChange`

#### Argumentos

<TypeTable
  type={{
    dead: { type: 'boolean', description: '`true`: o jogador caiu. `false`: ele se levantou (revivido, renasceu).', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { medical } from "@aifivem/lib/client";

// O mesmo que on(CORE.clientDeadEvent, ...).
medical.onChange((dead) => {
  if (dead) SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:dead', function(dead)
  if dead then SendNUIMessage({ action = 'close' }) end
end)
```
</Tab>
</Tabs>

### ai-core:client:cache

Um valor em cache do jogador local mudou. Um único observador no ai-core lê o ped, o veículo, o assento e a arma para todos os recursos e só dispara isto quando um valor muda, então nenhum recurso precisa consultá-los repetidamente. O `cache` e o `onCache` da lib (`aiLib.cache` e `aiLib.cache.onChange` em Lua) são construídos sobre ele; use-os.

**Lado:** Cliente · **Constante:** `CORE.clientCacheEvent`

#### Argumentos

<TypeTable
  type={{
    key: { type: '"ped" | "vehicle" | "seat" | "weapon"', description: 'Qual valor mudou.', required: true, typeDescriptionLink: '/pt/docs/developers/api/types#playercache' },
    value: { type: 'number | false', description: '`ped`: o novo handle do ped. `vehicle`: o handle do veículo, `false` a pé. `seat`: o índice do assento (`-1` = motorista), `false` a pé. `weapon`: o hash da arma na mão, `false` desarmado.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { onCache } from "@aifivem/lib/client";

onCache("vehicle", (vehicle, old) => {
  if (vehicle !== false) console.log(`entered vehicle ${vehicle}`);
  else if (old !== false) console.log("left the vehicle");
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
aiLib.cache.onChange('vehicle', function(vehicle, old)
  if vehicle then print(('entered vehicle %d'):format(vehicle))
  elseif old then print('left the vehicle') end
end)
```
</Tab>
</Tabs>

### ai-core:client:worldSync

**Lado:** Cliente · **Constante:** `CORE.clientWorldSyncEvent`

#### Argumentos

<TypeTable
  type={{
    paused: { type: 'boolean', description: '`true`: pare de aplicar o clima e a hora do servidor. `false`: aplique-os de novo.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

### ai-core:client:definitions

Um emprego ou gangue foi adicionado, alterado ou apagado no painel de administração. Dispara em cada cliente, uma vez por emprego ou gangue que mudou. Combine com o export `GetDefinitions`.

**Lado:** Cliente · **Constante:** `CORE.clientDefinitionsEvent`

#### Argumentos

<TypeTable
  type={{
    file: { type: '"jobs" | "gangs"', description: 'Qual lista mudou.', required: true },
    name: { type: 'string', description: 'O nome do emprego ou da gangue.', required: true },
    definition: { type: 'unknown', description: 'O novo registro como o painel o grava, `null` quando foi apagado.', required: true },
  }}
/>

#### Listener

Veja o exemplo de [GetDefinitions](/pt/docs/developers/api/core-client/player#getdefinitions).

### ai-core:client:characterPortrait

Uma imagem de retrato para o card de um personagem na tela de personagens. Um script de roupas (ai-appearance) o dispara; a tela de personagens do ai-core escuta e mostra a imagem. Dispare-o você mesmo só se escrever um script de roupas.

**Lado:** Cliente · **Constante:** `CORE.clientCharacterPortraitEvent` · **Disparado por:** o script de roupas, ouvido pelo ai-core

#### Argumentos

<TypeTable
  type={{
    charId: { type: 'number', description: 'O id do personagem do card.', required: true },
    url: { type: 'string', description: 'A url da imagem, por exemplo uma textura de headshot `https://nui-img/<txd>/<txd>`.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/portraits.ts"
import { CORE } from "@aifivem/shared";

// Um script de roupas entrega um retrato à tela de personagens.
export function sendPortrait(charId: number, txd: string): void {
  emit(CORE.clientCharacterPortraitEvent, charId, `https://nui-img/${txd}/${txd}`);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/portraits.lua"
-- Um script de roupas entrega um retrato à tela de personagens.
local function sendPortrait(charId, txd)
  TriggerEvent('ai-core:client:characterPortrait', charId, ('https://nui-img/%s/%s'):format(txd, txd))
end
```
</Tab>
</Tabs>

### ai-core:client:seatbelt

O cinto de segurança do jogador local mudou, no script de cinto que o ai-core lê. Dispara a partir dos scripts que avisam mudanças (ai-smallresources, qbx_seatbelt); com o cinto próprio de um HUD, leia `GetSeatbelt` quando precisar.

**Lado:** Cliente · **Constante:** `CORE.clientSeatbeltEvent` · **Lib:** `seatbelt.onChange`

#### Argumentos

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true`: cinto posto. `false`: cinto solto. `null`: o script não deu uma resposta clara.', required: true },
  }}
/>

#### Listener

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { seatbelt } from "@aifivem/lib/client";

seatbelt.onChange((worn) => SendNUIMessage({ action: "belt", data: worn === true }));
```
</Tab>

```lua title="client/hud.lua"
aiLib.seatbelt.onChange(function(worn)

```
</Tab>

## Eventos internos de cliente

O `Keybind` da lib conversa com o cliente do ai-core por dois eventos locais. Não os dispare nem os responda você mesmo; use `Keybind` (TS) ou `aiLib.Keybind` (Lua).

| Evento | Constante | Direção | Argumentos |
| --- | --- | --- | --- |
| `ai-core:client:keybind` | `KEYBIND.announceEvent` | da lib para o ai-core | `(info: KeybindInfo)` um keybind espera pela tecla padrão dele. |
| `ai-core:client:keybindKey` | `KEYBIND.keyEvent` | do ai-core para a lib | `(resource: string, name: string, key: string)` a tecla a registrar: a tecla do painel, senão a do próprio script. |
