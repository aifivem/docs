El cliente de ai-core dispara estos eventos con `TriggerEvent` en el propio juego del jugador. Todos los recursos de cliente de ese jugador los oyen; los demás jugadores nunca. Solo describen al jugador **local**.

### ai-core:client:playerLoaded

El personaje del jugador local está en el mundo. Empieza aquí tu trabajo de cliente por personaje (valores del HUD, blips de trabajo, bucles).

**Lado:** Cliente · **Constante:** `CORE.clientPlayerLoadedEvent`

#### Argumentos

<TypeTable
  type={{
    data: { type: 'AiPlayerData', description: 'Todo sobre el personaje en este momento: `character`, `money`, `jobs`, `duty`, `job`, `gangs`, `activeGang`, `metadata`. Lo mismo que el export `GetPlayerData`.', required: true, typeDescriptionLink: '/docs/developers/api/types#aiplayerdata' },
  }}
/>

#### Oyente

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aicore-fivem/lib/client";
import { CORE, type AiPlayerData } from "@aicore-fivem/shared";

const core = resourceExport("ai-core");

function start(data: AiPlayerData): void {
  console.log(`hello ${data.character?.firstname}, cash ${data.money.cash ?? 0}`);
}

// También cubre el reinicio de un recurso mientras el jugador ya está en el mundo.
const now = core.GetPlayerData();
if (now) start(now);
on(CORE.clientPlayerLoadedEvent, start);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local function start(data)
  print(('hello %s, cash %d'):format(data.character.firstname, data.money.cash or 0))
end

-- También cubre el reinicio de un recurso mientras el jugador ya está en el mundo.
local now = exports['ai-core']:GetPlayerData()
if now then start(now) end
AddEventHandler('ai-core:client:playerLoaded', start)
```
</Tab>
</Tabs>

### ai-core:client:playerUnloaded

Se soltó al personaje local: el jugador volvió a la pantalla de personajes. Detén el trabajo por personaje y borra lo que guardabas para ese personaje. (Cuando el jugador sale del servidor, su juego se cierra; no se dispara nada.)

**Lado:** Cliente · **Constante:** `CORE.clientPlayerUnloadedEvent`

#### Argumentos

Ninguno.

#### Oyente

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { CORE } from "@aicore-fivem/shared";

on(CORE.clientPlayerUnloadedEvent, () => {
  SendNUIMessage({ action: "reset" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:playerUnloaded', function()
  SendNUIMessage({ action = 'reset' })
end)
```
</Tab>
</Tabs>

### ai-core:client:dead

El jugador local cayó (muerto o last stand) o se levantó, en el script de muerte que esté en marcha. Solo se dispara cuando hay un cambio.

**Lado:** Cliente · **Constante:** `CORE.clientDeadEvent` · **Lib:** `medical.onChange`

#### Argumentos

<TypeTable
  type={{
    dead: { type: 'boolean', description: '`true`: el jugador cayó. `false`: se levantó (reanimado, reaparecido).', required: true },
  }}
/>

#### Oyente

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { medical } from "@aicore-fivem/lib/client";

// Lo mismo que on(CORE.clientDeadEvent, ...).
medical.onChange((dead) => {
  if (dead) SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:dead', function(dead)
  if dead then SendNUIMessage({ action = 'close' }) end
end)
```
</Tab>
</Tabs>

### ai-core:client:cache

Cambió un valor en caché del jugador local. Un único observador de ai-core lee el ped, el vehículo, el asiento y el arma para todos los recursos y solo dispara esto cuando cambia un valor, así que ningún recurso tiene que consultarlos una y otra vez. `cache` y `onCache` de la lib (`aiLib.cache` y `aiLib.cache.onChange` en Lua) se basan en él; usa esos.

**Lado:** Cliente · **Constante:** `CORE.clientCacheEvent`

#### Argumentos

<TypeTable
  type={{
    key: { type: '"ped" | "vehicle" | "seat" | "weapon"', description: 'Qué valor cambió.', required: true, typeDescriptionLink: '/docs/developers/api/types#playercache' },
    value: { type: 'number | false', description: '`ped`: el nuevo handle del ped. `vehicle`: el handle del vehículo, `false` a pie. `seat`: el índice del asiento (`-1` = conductor), `false` a pie. `weapon`: el hash del arma en la mano, `false` cuando va desarmado.', required: true },
  }}
/>

#### Oyente

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { onCache } from "@aicore-fivem/lib/client";

onCache("vehicle", (vehicle, old) => {
  if (vehicle !== false) console.log(`entered vehicle ${vehicle}`);
  else if (old !== false) console.log("left the vehicle");
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
aiLib.cache.onChange('vehicle', function(vehicle, old)
  if vehicle then print(('entered vehicle %d'):format(vehicle))
  elseif old then print('left the vehicle') end
end)
```
</Tab>
</Tabs>

### ai-core:client:hudVisible

Los HUD deberían mostrarse u ocultarse: se abrió una interfaz a pantalla completa o se cerró la última. Un recurso de HUD lo escucha.

**Lado:** Cliente · **Constante:** `CORE.clientHudVisibleEvent` · **Lib:** `hud.onChange`

#### Argumentos

<TypeTable
  type={{
    visible: { type: 'boolean', description: '`true`: muestra el HUD. `false`: ocúltalo.', required: true },
  }}
/>

#### Oyente

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { hud } from "@aicore-fivem/lib/client";

hud.onChange((visible) => SendNUIMessage({ action: "visible", data: visible }));
```

</Tab>
</Tabs>

### ai-core:client:worldSync

La sincronización de clima y hora se pausó o vuelve a correr. Un script de clima lo escucha. Consulta [Sincronización de clima y hora](/es/docs/developers/api/core-client/world).

**Lado:** Cliente · **Constante:** `CORE.clientWorldSyncEvent`

#### Argumentos

<TypeTable
  type={{
    paused: { type: 'boolean', description: '`true`: deja de aplicar el clima y la hora del servidor. `false`: vuelve a aplicarlos.', required: true },
  }}
/>

#### Oyente

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/weather.ts"
import { CORE } from "@aicore-fivem/shared";

on(CORE.clientWorldSyncEvent, (paused: boolean) => {
  console.log(paused ? "weather sync paused" : "weather sync running");
});
```
</Tab>
<Tab value="Lua">
```lua title="client/weather.lua"
AddEventHandler('ai-core:client:worldSync', function(paused)
  print(paused and 'weather sync paused' or 'weather sync running')
end)
```
</Tab>
</Tabs>

### ai-core:client:definitions

Se añadió, cambió o borró un trabajo o una banda en el panel de administración. Se dispara en cada cliente, una vez por cada trabajo o banda que cambió. Úsalo junto con el export `GetDefinitions`.

**Lado:** Cliente · **Constante:** `CORE.clientDefinitionsEvent`

#### Argumentos

<TypeTable
  type={{
    file: { type: '"jobs" | "gangs"', description: 'Qué lista cambió.', required: true },
    name: { type: 'string', description: 'El nombre del trabajo o la banda.', required: true },
    definition: { type: 'unknown', description: 'El nuevo registro tal como lo guarda el panel, `null` cuando se borró.', required: true },
  }}
/>

#### Oyente

Consulta el ejemplo de [GetDefinitions](/es/docs/developers/api/core-client/player#getdefinitions).

### ai-core:client:characterPortrait

Una imagen de retrato para la tarjeta de un personaje en la pantalla de personajes. La dispara un script de ropa (ai-appearance); la pantalla de personajes de ai-core la escucha y muestra la imagen. Dispárala tú solo si escribes un script de ropa.

**Lado:** Cliente · **Constante:** `CORE.clientCharacterPortraitEvent` · **Lo dispara:** el script de ropa, lo oye ai-core

#### Argumentos

<TypeTable
  type={{
    charId: { type: 'number', description: 'El id del personaje de la tarjeta.', required: true },
    url: { type: 'string', description: 'La url de la imagen, por ejemplo una textura de headshot `https://nui-img/<txd>/<txd>`.', required: true },
  }}
/>

#### Oyente

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/portraits.ts"
import { CORE } from "@aicore-fivem/shared";

// Un script de ropa entrega un retrato a la pantalla de personajes.
export function sendPortrait(charId: number, txd: string): void {
  emit(CORE.clientCharacterPortraitEvent, charId, `https://nui-img/${txd}/${txd}`);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/portraits.lua"
-- Un script de ropa entrega un retrato a la pantalla de personajes.
local function sendPortrait(charId, txd)
  TriggerEvent('ai-core:client:characterPortrait', charId, ('https://nui-img/%s/%s'):format(txd, txd))
end
```
</Tab>
</Tabs>

### ai-core:client:seatbelt

Cambió el cinturón del jugador local, en el script de cinturón que lee ai-core. Se dispara desde los scripts que avisan de los cambios (ai-smallresources, qbx_seatbelt); con el cinturón propio de un HUD, lee `GetSeatbelt` cuando lo necesites.

**Lado:** Cliente · **Constante:** `CORE.clientSeatbeltEvent` · **Lib:** `seatbelt.onChange`

#### Argumentos

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true`: cinturón puesto. `false`: cinturón quitado. `null`: el script no dio una respuesta clara.', required: true },
  }}
/>

#### Oyente

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { seatbelt } from "@aicore-fivem/lib/client";

seatbelt.onChange((worn) => SendNUIMessage({ action: "belt", data: worn === true }));
```
</Tab>
<Tab value="Lua">
```lua title="client/hud.lua"
aiLib.seatbelt.onChange(function(worn)
  SendNUIMessage({ action = 'belt', data = worn == true })
end)
```
</Tab>
</Tabs>

### ai-smallresources:seatbelt

El evento de cinturón propio de ai-smallresources. Los HUD que solo son compatibles con ai-smallresources lo escuchan. El código nuevo debería escuchar `ai-core:client:seatbelt` (arriba), que funciona con todos los scripts de cinturón compatibles.

**Lado:** Cliente · **Constante:** `SEATBELT_EVENT`

#### Argumentos

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true`: cinturón puesto. `false`: cinturón quitado. `null`: desconocido.', required: true },
  }}
/>

#### Oyente

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">

## Eventos internos de cliente

El `Keybind` de la lib habla con el cliente de ai-core con dos eventos locales. No los dispares ni los respondas tú; usa `Keybind` (TS) o `aiLib.Keybind` (Lua).

| Evento | Constante | Dirección | Argumentos |
| --- | --- | --- | --- |
| `ai-core:client:keybind` | `KEYBIND.announceEvent` | de la lib a ai-core | `(info: KeybindInfo)` un keybind espera su tecla por defecto. |
| `ai-core:client:keybindKey` | `KEYBIND.keyEvent` | de ai-core a la lib | `(resource: string, name: string, key: string)` la tecla que registrar: la del panel; si no, la propia del script. |
