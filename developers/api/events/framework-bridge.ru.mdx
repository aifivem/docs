ai-core представляется как `es_extended`, `qb-core`, `qbx_core` и `vrp`, поэтому скрипты, написанные под эти фреймворки, работают без изменений. Частью этого является отправка собственных событий фреймворка, когда в ai-core что-то меняется: загружается персонаж, перемещаются деньги, меняется работа. На этой странице перечислены все события фреймворков, которые отправляет мост, с аргументами в том виде, в каком их отправляет мост, и события фреймворков, на которые он отвечает.

**Новый код не должен их использовать.** Пишите под собственные события ai-core ([серверные](/ru/docs/developers/api/events/server), [клиентские](/ru/docs/developers/api/events/client)) и библиотеку: они несут больше (несколько работ, банды, дежурство) и не зависят от формы фреймворка. Эта страница нужна для запуска и исправления существующих скриптов ESX / QB / vRP.

<Callout type="info">
Представления фреймворков хранят одну работу на игрока: работу, на которой игрок на дежурстве, иначе его первую работу. Сам ai-core разрешает несколько работ. В ESX нет банд; счёт `money` в ESX - это `cash` в ai-core.
</Callout>

## QBCore и Qbox: сервер

Мост отправляет их на сервере через `TriggerEvent`. Скрипты Qbox слушают те же имена QBCore; мост не отправляет событий, существующих только в Qbox.

### QBCore:Server:PlayerLoaded

Персонаж загружен (из `ai-core:playerLoaded`).

**Сторона:** сервер

<TypeTable
  type={{
    Player: { type: 'table', description: 'Объект Player из QB: `PlayerData` (`source`, `citizenid`, `name`, `money`, `charinfo`, `job`, `gang`, `metadata`...) и `Functions` (`AddMoney`, `RemoveMoney`, `SetJob`, `GetMetaData`...).', required: true },
  }}
/>

<Tabs items={['TypeScript', 'Lua']}>

## QBCore и Qbox: клиент

Отправляются на клиенте самого игрока через `TriggerEvent`.

| Событие | Когда | Аргументы |
| --- | --- | --- |
| `QBCore:Client:OnPlayerLoaded` | Персонаж находится в мире. | нет |
| `QBCore:Client:OnPlayerUnload` | Игрок вернулся на экран персонажей. | нет |
| `QBCore:Player:SetPlayerData` | После загрузки и после каждого изменения денег, работы, банды или метаданных. | `(PlayerData: table)` весь PlayerData из QB. |
| `QBCore:Client:OnJobUpdate` | Изменилась работа во фреймворке. | `(job: table)` таблица работы QB (как на сервере). |
| `QBCore:Client:SetDuty` | Изменилось дежурство по той же работе. | `(onDuty: boolean)` |
| `QBCore:Client:OnGangUpdate` | Изменилась банда во фреймворке. | `(gang: table)` таблица банды QB. |
| `QBCore:Client:OnMoneyChange` | Изменился баланс счёта. | `(account: string, balance: number)` имя счёта в ai-core и новый баланс. |

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
on("QBCore:Client:OnPlayerLoaded", () => console.log("loaded"));
on("QBCore:Client:OnJobUpdate", (job: { name: string }) => console.log(`job: ${job.name}`));
on("QBCore:Client:SetDuty", (onDuty: boolean) => console.log(`on duty: ${onDuty}`));
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('QBCore:Client:OnPlayerLoaded', function() print('loaded') end)
AddEventHandler('QBCore:Client:OnJobUpdate', function(job) print(('job: %s'):format(job.name)) end)
AddEventHandler('QBCore:Client:SetDuty', function(onDuty) print(('on duty: %s'):format(tostring(onDuty))) end)
```
</Tab>
</Tabs>

<Callout type="warn">
`QBCore:Client:OnMoneyChange` несёт `(account, balance)`, то есть новый баланс, а не собственные аргументы qb-core. Скрипт QB, который читает его как сумму, увидит баланс. Предпочитайте `QBCore:Player:SetPlayerData` или `onPlayerData("money", ...)` из ai-core.
</Callout>

## ESX: клиент

Отправляются на клиенте самого игрока через `TriggerEvent`.

| Событие | Когда | Аргументы |

### vRP:playerJoinGroup and vRP:playerLeaveGroup

Персонаж получил или потерял группу vRP. Группы - это работы ai-core, активная банда, имена групп, которые владелец сервера сопоставил в панели (вкладка «vRP scripts»), и дополнительные группы, которые добавляют скрипты vRP. ## События фреймворков, на которые отвечает ai-core

Скрипты, написанные под фреймворк, отправляют эти события, ожидая ответа от фреймворка. Вместо него отвечает ai-core.

| Событие | Сторона | Что делает ai-core |
| --- | --- | --- |
| `QBCore:GetObject`, `esx:getSharedObject` | обе | Вызывает callback с объектом ядра (`QBCore` / `ESX`). |
| `QBCore:Server:TriggerCallback`, `esx:triggerServerCallback` | сервер (от клиентов) | Выполняет callback фреймворка, зарегистрированный через `CreateCallback` / `RegisterServerCallback`, и отвечает. Не более 30 запросов на игрока за любые 10 секунд. |
| `QBCore:Notify`, `esx:showNotification`, `esx:showAdvancedNotification`, `ESX:Notify` | клиент (от сервера) | Показывает уведомление ai-lib. |
| `esx:showHelpNotification`, `ESX:TextUI`, `ESX:HideUI`, `qb-core:client:DrawText`, `qb-core:client:ChangeText`, `qb-core:client:HideText`, `qb-core:client:KeyPressed` | клиент | Показывает или скрывает подсказку ai-lib. |
| `qb-menu:client:openMenu`, `qb-menu:client:closeMenu` | клиент | Открывает или закрывает меню ai-lib с пунктами qb-menu. |
| `progressbar:client:cancel` | клиент | Отменяет полосу прогресса моста. |
| `police:server:policeAlert` | сервер | Отправляет полицейское оповещение в активную систему оповещений с позицией игрока. Клиенты отправляют `(text)` (одно на игрока за 10 секунд); серверные скрипты вызывают его через `TriggerEvent` с `(text, camId, playerSource)`. |
| `qb-weathersync:client:DisableSync` / `EnableSync`, `cd_easytime:PauseSync`, `vSync:toggle` | клиент | Считаются причинами паузы синхронизации погоды и времени (см. [Синхронизация погоды и времени](/ru/docs/developers/api/core-client/world)). |
