ai-core’un client’ı bu event’leri oyuncunun kendi oyununda `TriggerEvent` ile tetikler. O oyuncunun her client resource’u onları duyar; diğer oyuncular asla duymaz. Yalnızca **yerel** oyuncuyu anlatırlar.

### ai-core:client:playerLoaded

Yerel oyuncunun karakteri dünyada duruyor. Karakter başına client işini burada başlat (HUD değerleri, meslek blip’leri, döngüler).

**Taraf:** Client · **Sabit:** `CORE.clientPlayerLoadedEvent`

#### Argümanlar

<TypeTable
  type={{
    data: { type: 'AiPlayerData', description: 'Bu andaki karakter hakkında her şey: `character`, `money`, `jobs`, `duty`, `job`, `gangs`, `activeGang`, `metadata`. `GetPlayerData` export’uyla aynı.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#aiplayerdata' },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { resourceExport } from "@aifivem/lib/client";
import { CORE, type AiPlayerData } from "@aifivem/shared";

const core = resourceExport("ai-core");

function start(data: AiPlayerData): void {
  console.log(`hello ${data.character?.firstname}, cash ${data.money.cash ?? 0}`);
}

// Oyuncu zaten dünyadayken bir resource restart’ını da kapsar.
const now = core.GetPlayerData();
if (now) start(now);
on(CORE.clientPlayerLoadedEvent, start);
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
local function start(data)
  print(('hello %s, cash %d'):format(data.character.firstname, data.money.cash or 0))
end

-- Oyuncu zaten dünyadayken bir resource restart’ını da kapsar.
local now = exports['ai-core']:GetPlayerData()
if now then start(now) end
AddEventHandler('ai-core:client:playerLoaded', start)
```
</Tab>
</Tabs>

### ai-core:client:playerUnloaded

Yerel karakter bırakıldı: oyuncu karakter ekranına döndü. Karakter başına işi durdur ve o karakter için tuttuklarını temizle. (Oyuncu sunucudan ayrıldığında oyunu kapanır; hiçbir şey tetiklenmez.)

**Taraf:** Client · **Sabit:** `CORE.clientPlayerUnloadedEvent`

#### Argümanlar

Yok.

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { CORE } from "@aifivem/shared";

on(CORE.clientPlayerUnloadedEvent, () => {
  SendNUIMessage({ action: "reset" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:playerUnloaded', function()
  SendNUIMessage({ action = 'reset' })
end)
```
</Tab>
</Tabs>

### ai-core:client:dead

Hangi ölüm script’i çalışıyorsa onda yerel oyuncu yere düştü (ölü ya da last stand) veya ayağa kalktı. Yalnızca bir değişiklikte tetiklenir.

**Taraf:** Client · **Sabit:** `CORE.clientDeadEvent` · **Lib:** `medical.onChange`

#### Argümanlar

<TypeTable
  type={{
    dead: { type: 'boolean', description: '`true`: oyuncu yere düştü. `false`: ayağa kalktı (canlandırıldı, yeniden doğdu).', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { medical } from "@aifivem/lib/client";

// on(CORE.clientDeadEvent, ...) ile aynı.
medical.onChange((dead) => {
  if (dead) SendNUIMessage({ action: "close" });
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
AddEventHandler('ai-core:client:dead', function(dead)
  if dead then SendNUIMessage({ action = 'close' }) end
end)
```
</Tab>
</Tabs>

### ai-core:client:cache

Yerel oyuncunun önbellekteki bir değeri değişti. ai-core’daki tek bir izleyici her resource için ped’i, aracı, koltuğu ve silahı okur ve bunu yalnızca bir değer değiştiğinde tetikler, böylece hiçbir resource onları yoklamak zorunda kalmaz. Lib’in `cache` ve `onCache`’i (Lua’da `aiLib.cache` ve `aiLib.cache.onChange`) bunun üstüne kurulmuştur; onları kullan.

**Taraf:** Client · **Sabit:** `CORE.clientCacheEvent`

#### Argümanlar

<TypeTable
  type={{
    key: { type: '"ped" | "vehicle" | "seat" | "weapon"', description: 'Hangi değerin değiştiği.', required: true, typeDescriptionLink: '/tr/docs/developers/api/types#playercache' },
    value: { type: 'number | false', description: '`ped`: yeni ped handle’ı. `vehicle`: araç handle’ı, yayayken `false`. `seat`: koltuk indeksi (`-1` = sürücü), yayayken `false`. `weapon`: eldeki silah hash’i, silahsızken `false`.', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/index.ts"
import { onCache } from "@aifivem/lib/client";

onCache("vehicle", (vehicle, old) => {
  if (vehicle !== false) console.log(`entered vehicle ${vehicle}`);
  else if (old !== false) console.log("left the vehicle");
});
```
</Tab>
<Tab value="Lua">
```lua title="client.lua"
aiLib.cache.onChange('vehicle', function(vehicle, old)
  if vehicle then print(('entered vehicle %d'):format(vehicle))
  elseif old then print('left the vehicle') end
end)
```
</Tab>
</Tabs>

### ai-core:client:worldSync

Hava ve saat senkronu duraklatıldı ya da yeniden çalışıyor. Bir hava script’i bunu dinler. Bkz. [Hava ve saat senkronu](/tr/docs/developers/api/core-client/world).

**Taraf:** Client · **Sabit:** `CORE.clientWorldSyncEvent`

#### Argümanlar

<TypeTable
  type={{
    paused: { type: 'boolean', description: '`true`: sunucunun havasını ve saatini uygulamayı bırak. `false`: onları yeniden uygula.', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/weather.ts"
import { CORE } from "@aifivem/shared";

on(CORE.clientWorldSyncEvent, (paused: boolean) => {
  console.log(paused ? "weather sync paused" : "weather sync running");
```

</Tab>
</Tabs>

### ai-core:client:definitions

Admin panelinde bir meslek ya da çete eklendi, değiştirildi veya silindi. Her client’ta, değişen her meslek ya da çete için bir kez tetiklenir. `GetDefinitions` export’uyla birlikte kullan.

**Taraf:** Client · **Sabit:** `CORE.clientDefinitionsEvent`

#### Argümanlar

<TypeTable
  type={{
    file: { type: '"jobs" | "gangs"', description: 'Hangi listenin değiştiği.', required: true },
    name: { type: 'string', description: 'Meslek ya da çete adı.', required: true },
    definition: { type: 'unknown', description: 'Panelin sakladığı haliyle yeni kayıt, silindiyse `null`.', required: true },
  }}
/>

#### Dinleyici

[GetDefinitions](/tr/docs/developers/api/core-client/player#getdefinitions) örneğine bak.

### ai-core:client:characterPortrait

Karakter ekranındaki bir karakter kartı için bir portre resmi. Bir kıyafet script’i (ai-appearance) bunu tetikler; ai-core’un karakter ekranı dinler ve resmi gösterir. Yalnızca bir kıyafet script’i yazıyorsan kendin tetikle.

**Taraf:** Client · **Sabit:** `CORE.clientCharacterPortraitEvent` · **Tetikleyen:** kıyafet script’i, dinleyen ai-core

#### Argümanlar

<TypeTable
  type={{
    charId: { type: 'number', description: 'Kartın karakter id’si.', required: true },
    url: { type: 'string', description: 'Resim url’si, örneğin bir vesikalık dokusu `https://nui-img/<txd>/<txd>`.', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/portraits.ts"
import { CORE } from "@aifivem/shared";

// Bir kıyafet script’i karakter ekranına bir portre verir.
export function sendPortrait(charId: number, txd: string): void {
  emit(CORE.clientCharacterPortraitEvent, charId, `https://nui-img/${txd}/${txd}`);
}
```
</Tab>
<Tab value="Lua">
```lua title="client/portraits.lua"
-- Bir kıyafet script’i karakter ekranına bir portre verir.
local function sendPortrait(charId, txd)
  TriggerEvent('ai-core:client:characterPortrait', charId, ('https://nui-img/%s/%s'):format(txd, txd))
end
```
</Tab>
</Tabs>

### ai-core:client:seatbelt

ai-core’un okuduğu emniyet kemeri script’i hangisiyse onda yerel oyuncunun emniyet kemeri değişti. Değişiklikleri bildiren script’lerden (ai-smallresources, qbx_seatbelt) tetiklenir; bir HUD’ın kendi kemeriyle ihtiyacın olduğunda `GetSeatbelt`’i oku.

**Taraf:** Client · **Sabit:** `CORE.clientSeatbeltEvent` · **Lib:** `seatbelt.onChange`

#### Argümanlar

<TypeTable
  type={{
    worn: { type: 'boolean | null', description: '`true`: kemer takılı. `false`: kemer çıkarıldı. `null`: script net bir cevap vermedi.', required: true },
  }}
/>

#### Dinleyici

<Tabs items={['TypeScript', 'Lua']}>
<Tab value="TypeScript">
```ts title="resource/client/hud.ts"
import { seatbelt } from "@aifivem/lib/client";

seatbelt.onChange((worn) => SendNUIMessage({ action: "belt", data: worn === true }));
```

</Tab>
<Tab value="Lua">

```lua title="client/hud.lua"
aiLib.seatbelt.onChange(function(worn)
```

</Tab>

## Dahili client event’leri

Lib’in `Keybind`’ı ai-core’un client’ıyla iki local event ile konuşur. Onları kendin tetikleme ya da cevaplama; `Keybind` (TS) ya da `aiLib.Keybind` (Lua) kullan.

| Event | Sabit | Yön | Argümanlar |
| --- | --- | --- | --- |
| `ai-core:client:keybind` | `KEYBIND.announceEvent` | lib’den ai-core’a | `(info: KeybindInfo)` bir keybind varsayılan tuşunu bekliyor. |
| `ai-core:client:keybindKey` | `KEYBIND.keyEvent` | ai-core’dan lib’e | `(resource: string, name: string, key: string)` kaydedilecek tuş: panelin tuşu, yoksa script’in kendisininki. |
