As páginas da API escrevem os tipos pelo nome (`Vec3`, `ActionResult`, `InventoryRef`...). Esta página explica cada um uma vez: os campos, o que cada campo significa e um valor de exemplo.

De onde vem um tipo:

| Pacote | Import | Tipos |
| --- | --- | --- |
| `@aifivem/shared` | `import type { AiPlayerData } from "@aifivem/shared";` | Tudo nesta página, a menos que o título diga outra coisa. |
| `@aifivem/lib/shared` | `import type { Vec3 } from "@aifivem/lib/shared";` | `Vec3`, `Vec4`, `AccessRule`, `BlipStyle`, `ZoneShape`, `VehicleProps`, `VehicleSetup`, `PlacePed`. |
| `@aifivem/lib/client` | `import type { ProgressOptions } from "@aifivem/lib/client";` | `ProgressOptions`. |
| `@aifivem/lib/server` | `import type { ProgressForOptions } from "@aifivem/lib/server";` | `ProgressForOptions`. |

<Callout type="info">
O Lua não tem tipos em tempo de execução. Uma table Lua com as mesmas chaves é o mesmo valor: `{ x = 1.0, y = 2.0, z = 3.0 }` é um `Vec3`. Arrays são listas Lua (`{ 'police', 'sheriff' }`), `null` é `nil`. Veja [Lib para Lua](/pt/docs/developers/api/lua) para vetores.
</Callout>

## Posições

### Vec3

Um ponto no mundo, em metros. No GTA, `x` é o leste, `y` é o norte, `z` é para cima.

<TypeTable
  type={{
    x: { type: 'number', description: 'Posição leste-oeste em metros.', required: true },
    y: { type: 'number', description: 'Posição norte-sul em metros.', required: true },
    z: { type: 'number', description: 'Altura em metros.', required: true },
  }}
/>

```ts title="Exemplo"
const counter: Vec3 = { x: 25.7, y: -1347.3, z: 29.5 };
```

```lua title="Lua"
local counter = vector3(25.7, -1347.3, 29.5) -- ou { x = 25.7, y = -1347.3, z = 29.5 }
```

### Vec4

Um ponto com uma direção: onde um ped fica ou um veículo aparece e para que lado ele olha. Os campos `vec4` do painel e a ferramenta de pontos do painel gravam este formato.

<TypeTable
  type={{
    x: { type: 'number', description: 'Posição leste-oeste em metros.', required: true },
    y: { type: 'number', description: 'Posição norte-sul em metros.', required: true },
    z: { type: 'number', description: 'Altura em metros.', required: true },
    heading: { type: 'number', description: "Direção em graus, 0-360 (a do GTA: 0 = norte, sentido anti-horário).", required: true },
  }}
/>

```ts title="Exemplo"
const spawn: Vec4 = { x: -42.1, y: -1098.4, z: 26.4, heading: 158.0 };
```

<Callout type="info">
Um `vector4` do Lua chama a direção de `w`. Os leitores da lib ([readVec4](/pt/docs/developers/api/lib-shared/input#readvec4)) aceitam tanto `heading` quanto `w`.
</Callout>

### ZoneShape

Uma área no mundo. Usada pelos `Zones` do cliente e pelas verificações de área do servidor ([geometria de zonas](/pt/docs/developers/api/lib-shared/zones)). É um de três formatos, escolhido por `type`.

**Esfera** (uma bola ao redor de um ponto):

<TypeTable
  type={{
    type: { type: '"sphere"', description: 'Escolhe este formato.', required: true },
    center: { type: 'Vec3', description: 'Centro da bola.', required: true, typeDescription: '{ x, y, z }' },
    radius: { type: 'number', description: 'Raio em metros.', required: true },
  }}
/>

**Cilindro** (um círculo no chão, que se estende para cima e para baixo):

<TypeTable
  type={{
    type: { type: '"cylinder"', description: 'Escolhe este formato.', required: true },
    center: { type: 'Vec3', description: 'Centro do círculo.', required: true },
    radius: { type: 'number', description: 'Raio no plano do chão, em metros.', required: true },
    height: { type: 'number', description: 'Até onde a zona se estende para cima e para baixo a partir de `center.z`, em metros (a altura total é o dobro disto).', required: true },
  }}
/>

**Polígono** (um polígono no chão entre duas alturas):

<TypeTable
  type={{
    type: { type: '"poly"', description: 'Escolhe este formato.', required: true },
    points: { type: 'Array<{ x: number; y: number }>', description: 'Cantos no chão, em ordem ao redor da área. Pelo menos 3.', required: true },
    minZ: { type: 'number', description: 'Altura mais baixa dentro da zona.', required: true },
    maxZ: { type: 'number', description: 'Altura mais alta dentro da zona.', required: true },
  }}
/>

```ts title="Exemplo"
const yard: ZoneShape = { type: "sphere", center: { x: 440.1, y: -981.2, z: 30.7 }, radius: 25 };
const lot: ZoneShape = {
  type: "poly",
  points: [ { x: 210, y: -810 }, { x: 240, y: -800 }, { x: 230, y: -770 }, { x: 200, y: -780 } ],
  minZ: 28,
  maxZ: 36,
};
```

## Resultados

### ActionResult

O que toda ação do servidor responde a um cliente: ou sucesso, ou uma chave de idioma que o cliente mostra como motivo. Campos extras podem ir no ramo de sucesso (`ActionResult<{ id: number }>`). O novo estado em si nunca viaja na resposta: ele chega como um delta.

**Sucesso:**

<TypeTable
  type={{
    ok: { type: 'true', description: 'A ação rodou.', required: true },
    '...T': { type: 'T', description: 'Campos extras de `ActionResult<T>` (por exemplo o id do novo registro).' },
  }}
/>

**Recusa:**

<TypeTable
  type={{
    ok: { type: 'false', description: 'A ação foi recusada.', required: true },
    error: { type: 'string', description: 'Uma chave de idioma dos `locales/*.json` do recurso (`"NOT_ENOUGH_MONEY"`). O cliente a traduz e a mostra.', required: true },
  }}
/>

```ts title="Exemplo"
const done: ActionResult = { ok: true };
const created: ActionResult<{ id: number }> = { ok: true, id: 42 };
const refused: ActionResult = { ok: false, error: "NOT_ENOUGH_MONEY" };
```

```lua title="Lua"
return { ok = true }
return aiLib.fail('NOT_ENOUGH_MONEY') -- { ok = false, error = 'NOT_ENOUGH_MONEY' }
```

Monte recusas com [fail](/pt/docs/developers/api/lib-shared/input#fail); leia respostas com [isActionOk](/pt/docs/developers/api/lib-shared/input#isactionok) e [replyError](/pt/docs/developers/api/lib-shared/input#replyerror).

    duty: { type: 'string | null', description: 'O emprego em que o personagem está em serviço, `null` quando fora de serviço.', required: true },

    gangs: { type: 'GangMembership[]', description: 'Cada gangue em que o personagem está.', required: true },
    activeGang: { type: 'string | null', description: 'A gangue em nome da qual o personagem age agora, `null` quando nenhuma.', required: true },
    metadata: { type: 'Record<string, unknown>', description: 'Valores livres gravados com o personagem (as pontes de framework guardam aqui a metadata de QB / ESX). As mudanças viajam por chave.', required: true },

## Dinheiro

### Nomes de contas

O dinheiro fica em contas com nome. A lista **Accounts** do painel define quais existem; o ai-core vem com estas:

| Nome | Rótulo | Quantia inicial |
| --- | --- | --- |
| `cash` | Cash (dinheiro vivo) | 500 |
| `bank` | Bank (banco) | 5000 |
| `black_money` | Dirty money (dinheiro sujo) | 0 |
| `crypto` | Crypto | 0 |

O dono de um servidor pode adicionar, renomear ou remover contas no painel, então leia a lista com o export `GetAccountTypes` em vez de supor qual é. Quando a lista está vazia, o ai-core mantém uma única conta `cash`.

```ts title="Exemplo"
core.AddMoney(source, "bank", 250, "Paycheck");
```

## Inventário

### InventoryRef

Em qual inventário uma chamada trabalha.

| Valor | Significa |
| --- | --- |
| `number` | O id de servidor de um jogador: o inventário desse jogador. |
| `string` | Qualquer outro inventário pelo id: o nome de um baú, o id de um porta-malas ou porta-luvas. |

```ts title="Exemplo"
inventory.addItem(source, "water", 2);          // um jogador
inventory.addItem("police_evidence", "phone", 1); // um baú
```

### ItemMetadata

Dados livres gravados numa pilha de itens (`Record<string, unknown>`): um número de série, a durabilidade, uma nota. Cada inventário mostra algumas chaves ele mesmo (`label`, `description`, `image` na maioria deles).

```ts title="Exemplo"
const metadata: ItemMetadata = { serial: "AB-1029", durability: 100 };
```

<Callout type="warn">
Mantenha a metadata pequena e segura para JSON (strings, números, booleans, objetos e arrays simples). Duas pilhas com metadata diferente nunca se juntam.
</Callout>

### UsableItemHandler

`(source: number, item: UsedItem) => unknown`: roda quando um jogador usa o item. Retornar `false` mantém o item em inventários que tiram um item usado eles mesmos (o ai-inventory tira a quantidade de `consume` do item); outros inventários seguem as próprias configurações de itens.

```ts title="Exemplo"
const onUse: UsableItemHandler = (source, item) => {
  if (item.metadata.durability === 0) return false; // mantém o item
  return true;
};
```
