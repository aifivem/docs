`@aicore-fivem/shared` (`exports.ts`) içinde `AiCoreServerExports` olarak tiplidir. TypeScript’te dosya başına bir handle al; Lua’da doğrudan `exports['ai-core']` çağır.

```ts title="TypeScript"
import { resourceExport } from "@aicore-fivem/lib/server";
const core = resourceExport("ai-core");
```

Aşağıda kullanılan tipler: `CharacterInfo`, `AiPlayerData`, `JobMembership` (`{ job, grade }`), `GangMembership` (`{ gang, grade }`), `InventoryRef` (bir oyuncunun sunucu id’si ya da başka bir envanterin id’si: depo adı, plaka), `KeyPurpose` (`purchase`, `garage`, `job`, `rental`, `temporary`); hepsi `@aicore-fivem/shared` içinde.

## Karakterler ve oyuncular

| Export | Ne |
| --- | --- |
| `GetPlayerData(src: number): AiPlayerData \| null` | ai-core’un yüklü bir oyuncu için tuttuğu her şey: karakter, para, meslekler, mesai, çeteler, metadata. |
| `GetCharacter(src: number): CharacterInfo \| null` | Yüklü karakter (id, citizenid, isimler, doğum tarihi, cinsiyet, uyruk). |
| `GetSourceByCharId(charId: number): number \| null` | O karakteri oynayan oyuncunun sunucu id’si. |
| `GetSourceByCitizenId(citizenid: string): number \| null` | Aynısı, citizen id ile. |
| `GetLoadedSources(): number[]` | Karakteri yüklü her oyuncunun sunucu id’si. |
| `GetFivemId(src: number): string \| null` | Oyuncunun FiveM kimliği. |
| `SwitchCharacter(src: number): boolean` | Oyuncuyu karakter ekranına geri gönderir. |
| `SetOfflinePosition(charId: number, position: { x, y, z, heading? }): boolean` | Kayıtlı (yüklü olmayan) bir karakterin doğma noktasını taşır; yüklüyken false. |
| `GetPlayersInScope(source: number): number[]` | Bir oyuncunun OneSync kapsamındaki oyuncular (yaklaşık 424 m). |

```ts title="TypeScript"
const character = core.GetCharacter(source);
if (character) console.log(character.firstname, character.lastname);
```

```lua title="Lua"
local character = exports['ai-core']:GetCharacter(source)
if character then print(character.firstname, character.lastname) end
```

## Para

Hesaplar panelin Hesaplar listesindekilerdir (varsayılan `cash`, `bank`). `reason` deftere yazılır.

| Export | Ne |
| --- | --- |
| `GetMoney(src: number, account: string): number \| null` | Bir oyuncunun bakiyesi. |
| `AddMoney(src: number, account: string, amount: number, reason?: string): boolean` | Para ekler. |
| `RemoveMoney(src: number, account: string, amount: number, reason?: string): boolean` | Para alır; hesap ödeyemezse false. |
| `SetMoney(src: number, account: string, amount: number, reason?: string): boolean` | Bakiyeyi ayarlar. |
| `GetSharedMoney(ownerType: "job" \| "gang", ownerId: string, account: string): number \| null` | Bir mesleğin ya da çetenin ortak hesabı. |
| `AddSharedMoney(ownerType, ownerId, account, amount: number, reason?: string): boolean` | Ortak hesaba ekler. |
| `RemoveSharedMoney(ownerType, ownerId, account, amount: number, reason?: string): boolean` | Ortak hesaptan alır. |
| `TransferMoney(from: MoneyRef, to: MoneyRef, amount: number, reason?: string, fee?: number): boolean` | İki hesap arasında tek işlemde, iki defter satırıyla para taşır; `fee`’yi de `from` öder. |
| `GetAccountTypes(): Record<string, AccountTypeDefinition>` | Hesap listesi (`label`, `start`, `allowNegative`). |

`MoneyRef`, yüklü bir oyuncu için `{ source, account }`, ortak hesap için `{ owner: "job" \| "gang", id, account }`.

```ts title="TypeScript"
if (core.RemoveMoney(source, "bank", 500, "fine")) {
  core.AddSharedMoney("job", "police", "bank", 500, "fine");
}
```

```lua title="Lua"
if exports['ai-core']:RemoveMoney(source, 'bank', 500, 'fine') then
  exports['ai-core']:AddSharedMoney('job', 'police', 'bank', 500, 'fine')
end
```

## Meslekler ve çeteler

Bir karakter birden çok meslek ve çeteye sahip olabilir; en fazla bir mesaideki meslek ve bir aktif çete.

| Export | Ne |
| --- | --- |
| `GetJobs(src: number): JobMembership[] \| null` | Her meslek üyeliği. |
| `GetCurrentJob(src: number): JobMembership \| null` | Diğer script’lerin "meslek" olarak gördüğü: mesaideki, yoksa son mesaideki, yoksa ilki. |
| `GetDutyJob(src: number): string \| null` | Oyuncunun mesaide olduğu meslek. |
| `SetDuty(src: number, job: string \| null): boolean` | Oyuncuyu bir meslekte mesaiye alır ya da mesaiden çıkarır (`null`). |
| `SetJob(src: number, job: string, grade: number): boolean` | Meslek ekler ya da rütbesini değiştirir. |
| `RemoveJob(src: number, job: string): boolean` | Bir meslek üyeliğini kaldırır. |
| `GetOnDutyCount(job: string): number` | Bir meslekte kaç oyuncunun mesaide olduğu. |
| `IsPrimeTime(job?: string): boolean` | Bir meslek için yoğun saat mi (tgiann-policealert çalışırken onun saatleri, yoksa panelin saatleri). |
| `GetGangs(src: number): GangMembership[] \| null` | Her çete üyeliği. |
| `GetActiveGang(src: number): string \| null` | Aktif çete. |
| `SetGang(src: number, gang: string, grade: number): boolean` | Çete ekler ya da rütbesini değiştirir. |
| `RemoveGang(src: number, gang: string): boolean` | Bir çete üyeliğini kaldırır. |
| `SetActiveGang(src: number, gang: string \| null): boolean` | Aktif çeteyi seçer. |
| `GetJobDefinitions(): Record<string, JobDefinition>` | Her meslek tanımı (bir kopya: seyrek okumalar için). |
| `GetJobDefinition(job: string): JobDefinition \| null` | Tek meslek: `label`, `type`, `defaultDuty`, `listed?`, `grades` (`label`, `salary`, `boss`). |
| `GetGangDefinitions(): Record<string, GangDefinition>` | Her çete tanımı. |
| `GetGangDefinition(gang: string): GangDefinition \| null` | Tek çete: `label`, `grades`. |

```ts title="TypeScript"
if (core.GetDutyJob(source) === "police") {
  const officers = core.GetOnDutyCount("police");
}
```

```lua title="Lua"
if exports['ai-core']:GetDutyJob(source) == 'police' then
  local officers = exports['ai-core']:GetOnDutyCount('police')
end
```

## Eşyalar

ai-core’un envanter katmanı: aktif envanter cevap verir (hiçbiri çalışmıyorken false, 0 ya da boş).

| Export | Ne |
| --- | --- |
| `AddItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean` | Eşya ekler. |
| `RemoveItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean` | Eşya alır. |
| `GetItemCount(inv: InventoryRef, item: string, metadata?: ItemMetadata): number` | Bir eşyadan kaç tane. |
| `HasItem(inv: InventoryRef, item: string, count?: number): boolean` | Envanterde en az `count` tane var mı. |
| `CanCarryItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata): boolean` | Eşyalar sığar mı. |
| `GetItems(inv: InventoryRef): InventoryStack[]` | Her yığın (`name`, `label`, `count`, `slot`, `metadata`). |
| `ClearInventory(inv: InventoryRef): void` | Bir envanteri boşaltır. |
| `RegisterStash(name: string, label: string, slots: number, maxWeight: number, jobs?: string[]): void` | Bir depo; saklanır ve aktif olan her envantere yeniden kaydedilir. |
| `OpenInventory(source: number, inv: InventoryRef): boolean` | Bir depoyu ya da başka bir envanteri oyuncunun ekranında açar. |
| `RegisterUsableItem(name: string, handler: UsableItemHandler): void` | Kullanımda `handler(source, item)` çalışır; false dönerse eşya kalır. Envanter yeniden başlasa da saklanır. |
| `GetItemDefinition(name: string): ItemDefinition \| null` | Tek eşya (`name`, `label`, `weight`, `unique`, `close`, `description`, `image?`). |
| `GetItemDefinitions(): Record<string, ItemDefinition>` | Her eşya. |
| `UseItem(source: number, name: string, item?: unknown): unknown` | Kayıtlı handler’ı çalıştırır (köprü çağırır). |
| `IsUsableItem(name: string): boolean` | Bir handler kayıtlı mı. |

```ts title="TypeScript"
core.RegisterUsableItem("bandage", (source, item) => {
  // heal, then let the inventory take the item
});
if (core.CanCarryItem(source, "water", 2)) core.AddItem(source, "water", 2);
```

```lua title="Lua"
exports['ai-core']:RegisterUsableItem('bandage', function(source, item)
  -- heal, then let the inventory take the item
end)
if exports['ai-core']:CanCarryItem(source, 'water', 2) then
  exports['ai-core']:AddItem(source, 'water', 2)
end
```

## İhbar

| Export | Ne |
| --- | --- |
| `SendDispatchAlert(alert: DispatchAlert): boolean` | Aktif ihbar sistemiyle `jobs` mesleklerindeki mesaidekilere bir ihbar gösterir; hiçbiri çalışmıyorsa false. |

`DispatchAlert`: `title`, ve isteğe bağlı `code`, `message`, `coords`, `jobs`, `source` (şüpheli), `blip` (`sprite`, `color?`, `scale?`), `duration` (saniye), `icon`, `priority` (`normal` ya da `high`). Metinler zaten çevrilmiş olur.

```ts title="TypeScript"
core.SendDispatchAlert({
  code: "10-90",
  title: "Store robbery",
  jobs: ["police"],
  source,
  priority: "high",
});
```

```lua title="Lua"
exports['ai-core']:SendDispatchAlert({
  code = '10-90', title = 'Store robbery', jobs = { 'police' }, source = source, priority = 'high',
})
```
