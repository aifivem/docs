Typowane jako `AiCoreServerExports` w `@aicore-fivem/shared` (`exports.ts`). W TypeScript weź jeden uchwyt na plik; w Lua wywołuj bezpośrednio `exports['ai-core']`.

```ts title="TypeScript"
import { resourceExport } from "@aicore-fivem/lib/server";
const core = resourceExport("ai-core");
```

Typy używane poniżej: `CharacterInfo`, `AiPlayerData`, `JobMembership` (`{ job, grade }`), `GangMembership` (`{ gang, grade }`), `InventoryRef` (id serwerowe gracza albo id innego ekwipunku: nazwa schowka, tablica), `KeyPurpose` (`purchase`, `garage`, `job`, `rental`, `temporary`), wszystkie w `@aicore-fivem/shared`.

## Postacie i gracze

| Eksport | Co |
| --- | --- |
| `GetPlayerData(src: number): AiPlayerData \| null` | Wszystko, co ai-core trzyma dla wczytanego gracza: postać, pieniądze, prace, służba, gangi, metadane. |
| `GetCharacter(src: number): CharacterInfo \| null` | Wczytana postać (id, citizenid, imię i nazwisko, data urodzenia, płeć, narodowość). |
| `GetSourceByCharId(charId: number): number \| null` | Id serwerowe gracza grającego tą postacią. |
| `GetSourceByCitizenId(citizenid: string): number \| null` | To samo według citizen id. |
| `GetLoadedSources(): number[]` | Id serwerowe każdego gracza z wczytaną postacią. |
| `GetFivemId(src: number): string \| null` | Identyfikator FiveM gracza. |
| `SwitchCharacter(src: number): boolean` | Odsyła gracza do ekranu postaci. |
| `SetOfflinePosition(charId: number, position: { x, y, z, heading? }): boolean` | Przenosi punkt pojawienia się zapisanej (niewczytanej) postaci; false, gdy jest wczytana. |
| `GetPlayersInScope(source: number): number[]` | Gracze w zasięgu OneSync danego gracza (około 424 m). |

```ts title="TypeScript"
const character = core.GetCharacter(source);
if (character) console.log(character.firstname, character.lastname);
```

```lua title="Lua"
local character = exports['ai-core']:GetCharacter(source)
if character then print(character.firstname, character.lastname) end
```

## Pieniądze

Konta to te z listy Accounts w panelu (domyślnie `cash`, `bank`). `reason` trafia do księgi.

| Eksport | Co |
| --- | --- |
| `GetMoney(src: number, account: string): number \| null` | Saldo gracza. |
| `AddMoney(src: number, account: string, amount: number, reason?: string): boolean` | Dodaje pieniądze. |
| `RemoveMoney(src: number, account: string, amount: number, reason?: string): boolean` | Zabiera pieniądze; false, gdy konto nie może zapłacić. |
| `SetMoney(src: number, account: string, amount: number, reason?: string): boolean` | Ustawia saldo. |
| `GetSharedMoney(ownerType: "job" \| "gang", ownerId: string, account: string): number \| null` | Wspólne konto pracy lub gangu. |
| `AddSharedMoney(ownerType, ownerId, account, amount: number, reason?: string): boolean` | Dodaje do wspólnego konta. |
| `RemoveSharedMoney(ownerType, ownerId, account, amount: number, reason?: string): boolean` | Zabiera ze wspólnego konta. |
| `TransferMoney(from: MoneyRef, to: MoneyRef, amount: number, reason?: string, fee?: number): boolean` | Przenosi pieniądze między dwoma kontami w jednej transakcji z oboma wpisami w księdze; `from` płaci też `fee`. |
| `GetAccountTypes(): Record<string, AccountTypeDefinition>` | Lista kont (`label`, `start`, `allowNegative`). |

`MoneyRef` to `{ source, account }` dla wczytanego gracza albo `{ owner: "job" \| "gang", id, account }` dla wspólnego konta.

```ts title="TypeScript"
if (core.RemoveMoney(source, "bank", 500, "fine")) {
  core.AddSharedMoney("job", "police", "bank", 500, "fine");
}
```

```lua title="Lua"
if exports['ai-core']:RemoveMoney(source, 'bank', 500, 'fine') then
  exports['ai-core']:AddSharedMoney('job', 'police', 'bank', 500, 'fine')
end
```

## Prace i gangi

Postać może mieć kilka prac i gangów, z co najwyżej jedną pracą na służbie i jednym aktywnym gangiem.

| Eksport | Co |
| --- | --- |
| `GetJobs(src: number): JobMembership[] \| null` | Każde członkostwo w pracy. |
| `GetCurrentJob(src: number): JobMembership \| null` | Praca, którą inne skrypty widzą jako „tę” pracę: na służbie, inaczej ostatnia na służbie, inaczej pierwsza. |
| `GetDutyJob(src: number): string \| null` | Praca, w której gracz jest na służbie. |
| `SetDuty(src: number, job: string \| null): boolean` | Wprowadza gracza na służbę w pracy albo zdejmuje ze służby (`null`). |
| `SetJob(src: number, job: string, grade: number): boolean` | Dodaje pracę albo zmienia jej stopień. |
| `RemoveJob(src: number, job: string): boolean` | Usuwa członkostwo w pracy. |
| `GetOnDutyCount(job: string): number` | Ilu graczy jest na służbie w pracy. |
| `IsPrimeTime(job?: string): boolean` | Prime time dla pracy (godziny tgiann-policealert, gdy działa, inaczej godziny z panelu). |
| `GetGangs(src: number): GangMembership[] \| null` | Każde członkostwo w gangu. |
| `GetActiveGang(src: number): string \| null` | Aktywny gang. |
| `SetGang(src: number, gang: string, grade: number): boolean` | Dodaje gang albo zmienia jego stopień. |
| `RemoveGang(src: number, gang: string): boolean` | Usuwa członkostwo w gangu. |
| `SetActiveGang(src: number, gang: string \| null): boolean` | Wybiera aktywny gang. |
| `GetJobDefinitions(): Record<string, JobDefinition>` | Każda definicja pracy (kopia: do rzadkich odczytów). |
| `GetJobDefinition(job: string): JobDefinition \| null` | Jedna praca: `label`, `type`, `defaultDuty`, `listed?`, `grades` (`label`, `salary`, `boss`). |
| `GetGangDefinitions(): Record<string, GangDefinition>` | Każda definicja gangu. |
| `GetGangDefinition(gang: string): GangDefinition \| null` | Jeden gang: `label`, `grades`. |

```ts title="TypeScript"
if (core.GetDutyJob(source) === "police") {
  const officers = core.GetOnDutyCount("police");
}
```

```lua title="Lua"
if exports['ai-core']:GetDutyJob(source) == 'police' then
  local officers = exports['ai-core']:GetOnDutyCount('police')
end
```

## Przedmioty

Warstwa ekwipunku ai-core: odpowiada aktywny ekwipunek (false, 0 albo pusto, gdy żaden nie działa).

| Eksport | Co |
| --- | --- |
| `AddItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean` | Dodaje przedmioty. |
| `RemoveItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata, slot?: number): boolean` | Usuwa przedmioty. |
| `GetItemCount(inv: InventoryRef, item: string, metadata?: ItemMetadata): number` | Ile jest danego przedmiotu. |
| `HasItem(inv: InventoryRef, item: string, count?: number): boolean` | Czy ekwipunek ma co najmniej `count`. |
| `CanCarryItem(inv: InventoryRef, item: string, count?: number, metadata?: ItemMetadata): boolean` | Czy przedmioty się zmieszczą. |
| `GetItems(inv: InventoryRef): InventoryStack[]` | Każdy stos (`name`, `label`, `count`, `slot`, `metadata`). |
| `ClearInventory(inv: InventoryRef): void` | Opróżnia ekwipunek. |
| `RegisterStash(name: string, label: string, slots: number, maxWeight: number, jobs?: string[]): void` | Schowek; zapamiętany i rejestrowany ponownie w każdym ekwipunku, który staje się aktywny. |
| `OpenInventory(source: number, inv: InventoryRef): boolean` | Otwiera schowek albo inny ekwipunek na ekranie gracza. |
| `RegisterUsableItem(name: string, handler: UsableItemHandler): void` | `handler(source, item)` działa przy użyciu; zwrócenie false zostawia przedmiot. Zachowany po restarcie ekwipunku. |
| `GetItemDefinition(name: string): ItemDefinition \| null` | Jeden przedmiot (`name`, `label`, `weight`, `unique`, `close`, `description`, `image?`). |
| `GetItemDefinitions(): Record<string, ItemDefinition>` | Każdy przedmiot. |
| `UseItem(source: number, name: string, item?: unknown): unknown` | Uruchamia zarejestrowany handler (wywołuje go most). |
| `IsUsableItem(name: string): boolean` | Czy handler jest zarejestrowany. |

```ts title="TypeScript"
core.RegisterUsableItem("bandage", (source, item) => {
  // heal, then let the inventory take the item
});
if (core.CanCarryItem(source, "water", 2)) core.AddItem(source, "water", 2);
```

```lua title="Lua"
exports['ai-core']:RegisterUsableItem('bandage', function(source, item)
  -- heal, then let the inventory take the item
end)
if exports['ai-core']:CanCarryItem(source, 'water', 2) then
  exports['ai-core']:AddItem(source, 'water', 2)
end
```

| Eksport | Co |
| --- | --- |

| `HasPhone(source: number): boolean` | Czy gracz ma telefon. |
| `SendPhoneMail(to: number \| string, mail: PhoneMail): boolean` | Mail (`sender`, `subject`, `message`) do gracza lub na numer. |

## Dispatch

| Eksport | Co |
| --- | --- |
| `SendDispatchAlert(alert: DispatchAlert): boolean` | Pokazuje alert członkom `jobs` na służbie przez aktywny system alertów; false, gdy żaden nie działa. |

`DispatchAlert`: `title` oraz opcjonalnie `code`, `message`, `coords`, `jobs`, `source` (podejrzany), `blip` (`sprite`, `color?`, `scale?`), `duration` (sekundy), `icon`, `priority` (`normal` albo `high`). Teksty są już przetłumaczone.

```ts title="TypeScript"
core.SendDispatchAlert({
  code: "10-90",
  title: "Store robbery",
  jobs: ["police"],
  source,
  priority: "high",
});
```

```lua title="Lua"
exports['ai-core']:SendDispatchAlert({
  code = '10-90', title = 'Store robbery', jobs = { 'police' }, source = source, priority = 'high',
})
```

## Panel administratora i komendy
