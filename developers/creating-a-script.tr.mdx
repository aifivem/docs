description: Boş şablondan admin panelli bir script’e, AI Core usulüyle.
icon: FilePlus
---

<Steps>
<Step>

### Şablondan oluştur

```bash
bun run new garbagejob "Garbage routes with pay per stop"
bun install
cd resources/[ai]/ai-garbagejob && git init && bun run build
```

Sonra `server.cfg`’ye `ensure ai-garbagejob` ekle. Şablon sana `resource/client`, `resource/server`, `resource/common`, `locales/en.json`, doldurulacak bir `CLAUDE.md` ve derleme ayarlarını verir.

</Step>
<Step>

### Paneli ekle

`resource/server/schema.ts` yaz (dosyalar, sekmeler, kartlar, widget’lar) ve sunucuda `new AdminPanel(schema)` oluştur. Dünyanın ihtiyaç duyduğu veri (yerler, blip’ler, oyuncuların gördüğü fiyatlar) `sync: "all"` olur ve client’ta `new AdminWorld([...])` ile okunur; geri kalan her şey sunucuda kalır.

</Step>
<Step>

### Her şey için lib’i kullan

```ts
// client: oyuncuların kullandığı bir yer; istem ya da hedef seçeneği olarak görünür
const points = new Points();
points.add("depot", {
  coords: route.depot,
  label: Locale("PROMPT_START"),
  icon: "truck",
  canShow: () => hasJob(["garbage"]),
  onPressed: () => callAction(EVENTS.start, [route.id], { fallback: "ERR_FAR" }),
});
```

```ts
// server: istek, bir şey değişmeden önce kontrol edilir
onClientCallback(
  EVENTS.start,
  { args: oneArg((v) => readText(v, 32)), guards: [hasCharacter()], lock: true },
  (source, id) => {
    if (!isNear(source, route.depot, 3)) return fail("ERR_FAR");
    return { ok: true };
  },
);
```

</Step>
<Step>

### Kontrol et ve yeniden başlat

```bash
bun run typecheck && bun run lint && bun run build
bun tools/rcon.ts --log ../logs/fxserver.log --wait 3 "ensure ai-garbagejob"
```

</Step>
</Steps>
