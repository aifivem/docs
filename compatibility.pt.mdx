Quase todo script de FiveM é escrito para ESX, QBCore ou Qbox, então rodá-los é um objetivo principal. O AI Core não traz scripts de terceiros e não favorece nenhum fornecedor: você instala os seus.

## Três camadas

<Steps>
<Step>

### Ponte de frameworks

O AI Core fornece `es_extended`, `qb-core` e `qbx_core` e responde aos exports, core objects, player objects, callbacks, eventos e inclusões de arquivos deles (`@qb-core/shared/locale.lua`, `@es_extended/imports.lua`, `@qbx_core/modules/playerdata.lua`), então scripts escritos para ESX, QBCore ou Qbox enxergam o AI Core como seu framework e rodam sem alterações. Os menus, avisos de texto, barras de progresso e caixas de entrada deles são desenhados com a própria UI do AI Core.

</Step>
<Step>

### Camadas de integração

O AI Core e os scripts `ai-*` precisam de coisas que outros scripts fornecem. Cada categoria tem uma interface e cada script suportado é um adaptador. O AI Core detecta o script instalado na inicialização e quando scripts iniciam ou param; o painel de administração pode substituir a escolha.

| Categoria | Exemplos |
| --- | --- |
| Inventário | ai-inventory, ox_inventory, qb-inventory, tgiann-inventory e mais |
| Chaves de veículos | ai-vehiclekeys, qbx_vehiclekeys e outros |
| Dispatch (alertas da polícia) | ai-policealert e scripts de alerta |
| Celular | tgiann-phone, lb-phone |
| Roupas | ai-appearance, tgiann-clothing |
| Morte | ai-death |
| Clima e hora | ai-weathersync, qb-weathersync, Renewed-Weathersync, cd_easytime |
| Prisão | ai-prison, qb-prison |
| Menu radial | ai-radialmenu, qb-radialmenu, ox_lib |

</Step>
<Step>

### Substitutos

Vários scripts `ai-*` respondem à API do script que substituem, então scripts de terceiros funcionam com eles sem adaptador: ai-mysql substitui o oxmysql (e também o mysql-async e o ghmattimysql), ai-inventory o ox_inventory e o qb-inventory, ai-target o ox_target, ai-voice o pma-voice, ai-chat o chat, ai-vehicles e ai-vehiclekeys os scripts de veículos do Qbox.

</Step>
</Steps>

Veja a lista de [scripts compatíveis](/pt/scripts) para saber com o que o AI Core se integra hoje.

## Substituindo um script ai-*

Se você instalar um script pago que substitui um `ai-*` (por exemplo, outro inventário), o AI Core diz qual pasta apagar e recusa conexões enquanto os dois estiverem rodando, para que dois scripts nunca briguem pela mesma tarefa.

## Adicionando um script

Dar suporte a um novo script é um trabalho pequeno e repetível: copie o modelo de adaptador da categoria, preencha as chamadas e adicione uma linha ao registro. Você pode pedir para sua IA fazer isso.
